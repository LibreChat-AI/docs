[Arcmira](https://arcmira.com) provides a remote MCP server at `https://mcp.arcmira.com/mcp`.
This guide configures a separate Arcmira API key for each LibreChat user.

## Prerequisites

- A running LibreChat instance and access to its `librechat.yaml`.
- An Arcmira account and API key for each person connecting.
- A model that supports tools in LibreChat.

Use a read-only Arcmira key for transcript research. Monitor management requires a key with write access.
Review [Arcmira's setup guide](https://arcmira.com/docs/mcp-server) for current account and key options.

## Configure the server

Merge this entry into the existing `mcpServers` section of `librechat.yaml`:

```yaml
mcpServers:
  arcmira:
    title: Arcmira
    description: "YouTube transcript search and monitoring for your AI: exact quotes, full transcripts and speakers."
    type: streamable-http
    url: https://mcp.arcmira.com/mcp
    startup: false
    requiresOAuth: false
    headers:
      Authorization: "Bearer {{ARCMIRA_API_KEY}}"
    customUserVars:
      ARCMIRA_API_KEY:
        title: Arcmira API key
        description: Enter your own Arcmira API key, without the Bearer prefix.
        sensitive: true
```

Restart LibreChat after saving the configuration. Connect to Arcmira from the chat composer's MCP controls and enter your key when prompted.
Each user's key is stored separately. Do not replace the placeholder with a shared key or commit a key to the configuration file.

`requiresOAuth: false` selects API-key authentication for this configuration. It avoids an OAuth-discovery probe without the user's header.
`startup: false` defers connection until a user connects.
See [credentials and variables](/docs/features/mcp) and the [MCP configuration reference](/docs/configuration/librechat_yaml/object_structure/mcp_servers).

## Try a source-linked search

Enable Arcmira's tools for the conversation and try:

```text
Use Arcmira to find three passages about vibe coding. Include the exact quote,
video title and timestamped YouTube link for each. If the speaker is not
identified, say so rather than inferring their name from the channel.
```

Open each returned source link to check the passage in context. Results depend on the available catalog and account access.

Review [usage and billing](https://arcmira.com/docs/usage-and-billing) and your account limits before running research.

## Troubleshooting

- **Authentication fails:** use Configure in the MCP controls to replace an expired or revoked key. Enter the key alone; the configuration adds `Bearer`.
- **A usage limit is reached:** check the returned error and account usage. Reconnecting does not increase the limit.
- **Tools are unavailable:** confirm the YAML is loaded, restart LibreChat after configuration changes, and select a tool-capable model.
- **A monitor action is refused:** a read-only key cannot manage monitors. Keep that restriction for research-only users.
