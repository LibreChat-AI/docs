The ACE Music plugin adds song generation, lyrics and task lookup to a LibreChat instance. Each user authorizes access to their own Ace Data Cloud account.

## Install the plugin

From the LibreChat server, clone the [plugin source](https://github.com/AceDataCloud/LibreChatPlugins/tree/c5c5a4b18321cb9867f92b7dbece4e197b98f3f9/plugins/acemusic) and install ACE Music into the instance's [Agent Plugins directory](/docs/configuration/agent_plugins). Replace the example path with the directory mounted by your deployment.

```bash
git clone https://github.com/AceDataCloud/LibreChatPlugins.git
cd LibreChatPlugins
git checkout c5c5a4b18321cb9867f92b7dbece4e197b98f3f9
python3 scripts/install.py acemusic --plugin-dir /path/to/LibreChat/plugin
```

Restart LibreChat to load the plugin. Open the MCP server selector, choose `acemusic-by-acedatacloud`, and sign in to Ace Data Cloud when prompted. The plugin connects to `https://acemusic.mcp.acedata.cloud/mcp` over Streamable HTTP. See [Agent Plugins](/docs/features/agent_plugins) for host and configuration requirements.

## Use ACE Music

Start by listing the available models with `acemusic_list_models`. Before creating music or lyrics, check [ACE Music pricing](https://platform.acedata.cloud/services/acemusic). Keep the task ID returned by generation and use `acemusic_get_task` to retrieve that task's status and finished tracks. If a submission times out after returning an ID, use that ID to check progress before submitting again.
