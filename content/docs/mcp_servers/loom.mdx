[ClickHouse Loom](https://github.com/ClickHouse/loom) provides agent memory and document search over MCP. This guide connects LibreChat to Loom's read-only assistant tools so each user can search the namespaces their viewer token allows.

## Add the server

1. In **MCP Settings**, click **Add MCP** and name the server **Loom**.
2. Use your Loom deployment's HTTPS URL with `/mcp?toolset=assistant` and select **Streamable HTTPS**.
3. Select **API Key**, set **Header Format** to **Bearer**, and check **Each user provides their own key**.
4. Check **I trust this application** and click **Create**.

## Search team documents

Each user opens **Configure** for the Loom server, enters their Loom viewer token, and saves it. Connect the server in a chat or [add its tools to an agent](/docs/features/mcp#add-a-server-to-an-agent). Ask for a known team document and its source URL.

See the [Loom configuration guide for LibreChat](https://github.com/ClickHouse/loom/blob/v1.3.0/docs/features/integrations/librechat.md#how-a-call-reaches-loom) for token, transport, and toolset requirements.
