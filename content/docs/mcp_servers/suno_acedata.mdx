This independent integration connects **Suno** through **Ace Data Cloud**. It is not published by the Suno service brand or the LibreChat maintainers. Model-chat credentials and this tool connection are separate.

## Install the native package

The experimental [Agent Plugins](/docs/features/agent_plugins) format loads each operator-installed plugin at startup. Review the [package source](https://github.com/AceDataCloud/LibreChatPlugins/tree/v0.1.0/plugins/suno) and install only the service you need:

```bash
python3 scripts/install.py suno --plugin-dir /path/to/LibreChat/plugin
```

[Release v0.1.0](https://github.com/AceDataCloud/LibreChatPlugins/releases/tag/v0.1.0) contains one independently downloadable ZIP per service plus `SHA256SUMS`. Verify the selected file, then extract its single service directory into the administrator-controlled plugin directory; preserve existing plugin/data directories. Each archive includes its own license, English/Chinese illustrated guides and screenshots. Alternatively, run the command above from a `v0.1.0` source checkout of `AceDataCloud/LibreChatPlugins`. The selected plugin directory must be visible inside the LibreChat filesystem (`/app/plugin` by default); preserve existing Docker mounts. Restart that instance. The package adds the `suno-by-acedatacloud` MCP connection and a service-specific Skill to that instance's tool catalog. It is not an installation into every LibreChat instance or a global marketplace entry.

The [English and Chinese illustrated package guides](https://github.com/AceDataCloud/LibreChatPlugins/tree/v0.1.0) include installation, account setup, current limits and troubleshooting. The package reuses [SunoMCP](https://github.com/AceDataCloud/SunoMCP); it does not implement its own billing or generation API.

## Connect your account

![Official LibreChat MCP settings reference](/images/mcp/mcp_ui_settings_panel.png)

This official screenshot shows LibreChat v0.8.2 and a different sample server. It locates the settings controls; it is not an Ace connection or a guarantee of the current UI layout.


1. Register or sign in at [Ace Data Cloud Applications](https://platform.acedata.cloud/console/applications?utm_source=librechat&utm_medium=referral&utm_campaign=evergreen&utm_content=suno_official_guide_key).
2. Find **General application**, or initialize it if absent. Check Suno access, [current pricing and balance](https://platform.acedata.cloud/models?utm_source=librechat&utm_medium=referral&utm_campaign=evergreen&utm_content=suno_official_guide_pricing).
3. For the native URL-only plugin, open **+ → MCP Servers** or **MCP Settings**, select `suno-by-acedatacloud`, and complete the Ace OAuth connection in the same browser session. A discovered service is not yet an authenticated connection.

For an explicit personal Token route, use the separately configured [customUserVars](/docs/configuration/librechat_yaml/object_structure/mcp_servers#customuservars) fields instead of putting credentials in a plugin. Copy the application API key or choose **Keys / Manage Keys → Create**, set the service/API restrictions and expiry you need, and paste the raw value in the service's MCP Token field. Do not use an account-management Token or the chat-model key dialog. A YAML MCP entry takes precedence over a same-name plugin server; choose one authentication route.

## First use and task results

Confirm the connection lists tools before sending a paid operation. To inspect an existing result, call `suno_get_task` with a task ID already belonging to your account. If the host requires a model to trigger the call, that model can have its own cost.

For a new `suno_generate_music` request, review the exact tool schema and current price first. Submit once after the user confirms the selected service, inputs and bounded spend. Store the returned task ID and query the same ID until terminal success or failure. Do not regenerate to poll. A pending preview is not final media, and a connected plugin does not prove a unique bill. Stop on terminal failure.

## Troubleshooting

- Missing service: check the host implements Agent Plugins, directory mounting and startup diagnostics.
- Authentication error: verify the chosen OAuth or personal-Token route, API permissions, expiry and balance. Do not combine fixed credentials with OAuth on one connection.
- Pending: retrieve the same task ID; do not repeat generation.
- Rate limit or timeout: inspect the existing response/task and reduce concurrency before a new request.
