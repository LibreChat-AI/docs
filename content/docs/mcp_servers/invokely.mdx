Invokely provides official statistics through a hosted MCP service. This guide configures its no-account trial endpoint in LibreChat over Streamable HTTP. The trial allows 25 calls per day per IP address and needs no API key or OAuth.

## Add the server

Add this entry to the top-level `mcpServers` section of `librechat.yaml`:

```yaml filename="librechat.yaml"
mcpServers:
  invokely:
    type: streamable-http
    url: 'https://invokely.ai/mcp/trial'
    requiresOAuth: false
```

If `mcpSettings.allowedDomains` is configured, add `invokely.ai` to its existing list. It is a strict allowlist, so keep every other public domain your configured servers require.

Save the file and restart LibreChat so it loads the new MCP configuration.

## Use Invokely in a chat

Open a chat and select **+** in the composer, then choose **MCP Servers** and select **Invokely**. It appears as a chip in the composer. If you are chatting with an Agent, configure Invokely for that Agent instead; the server picker is hidden in Agent chats.

Try a request such as:

> Find an official population indicator for Spain and retrieve its latest available value. Include the unit, period, publisher, source URL, retrieval date, and citation.

For comparisons, ask LibreChat to explain whether the values are comparable. If Invokely marks them as not comparable, have it describe the differences in sources or periods. Coverage and available periods vary by indicator and place.
