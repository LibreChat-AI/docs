アプリの最上部に、すべてのユーザーに対して重要なメッセージを表示します。お知らせ、メンテナンス通知、またはアップデートの告知に最適です。

<Callout type="info" title="クイック概要">
  - 一度にアクティブにできる**バナーは1つだけ**です
  - バナーが自動的に表示・非表示されるようにスケジュールを設定する
  - ユーザーがバナーを非表示にできるかどうかを選択します
  - バナーを全員に表示するか、ログインユーザーのみに表示するかを選択します
</Callout>

---

## バナーの作成 [#creating-a-banner]

このコマンドを実行して、バナーを作成または更新します：

```bash
npm run update-banner
```

Dockerを使用している場合は、代わりに`api`コンテナ内でスクリプトを実行してください:

```bash
docker compose exec api npm run update-banner
```

いくつかの簡単なプロンプトを通じて案内されます：

```ansi
--------------------------
Update the banner!
--------------------------
Display From (Format: yyyy-mm-ddTHH:MM:SSZ, Default: now):
> 2025-12-02T09:00:00Z

Display To (Format: yyyy-mm-ddTHH:MM:SSZ, Default: not specified):
> 2025-12-31T23:59:59Z

Enter your message (Enter a single dot "." on a new line to finish):
> 🎉 Welcome to LibreChat! Check out our new features.
> .

Is public (y/N):
> n

Is persistable (cannot be dismissed) (y/N):
> n
```

<Callout type="tip" title="これらのオプションはどういう意味ですか？">
  - **Display From/To**: バナーを表示する開始日時と終了日時です。プロンプトで Enter キーを押すと、「now」(現在)と「forever」(無期限)が使用されます。
  - **Is public**: ログインしていない訪問者（ログインページなど）に表示します
  - **永続表示可能**: はいの場合、ユーザーはバナーを閉じることができません(重要なお知らせに使用します)
</Callout>

<Callout type="warning" title="これを再度実行すると、既存のバナーが置き換えられます">

バナーは常に1つしか存在できません。`update-banner` は既存のバナーを探してその場で上書きし、存在しない場合にのみ新規作成します。そのため、後日のために2つ目のバナーをキューに入れたり、スケジュールされた2つの期間を重複させたりすることはできません。コマンドを再度実行すると、以前のバナーのメッセージとスケジュールは破棄されます。

バナーを変更するには、再度 `update-banner` を実行してください。`Display To`（表示終了日時）より前にバナーを削除するには、以下の `delete-banner` を使用してください。

</Callout>

## バナーの削除 [#deleting-a-banner]

```bash
npm run delete-banner
```

Docker を使用している場合は、`docker compose exec api npm run delete-banner` を実行してください。

現在のバナーが表示され、削除する前に確認を求められます。

<Callout type="warning" title="有効なバナーのみ削除できます">

`delete-banner` は現在有効なバナーのみを検索します。つまり、`Display From` の時刻を過ぎており、かつ `Display To` の時刻が未来であるか、設定されていないバナーが対象です。表示開始日が未来のバナーや、`Display To` の時刻を既に過ぎているバナーは、"No banner found to delete" と報告され、データベースに残ったままになります。そのようなバナーを置き換えるには、`update-banner` を再度実行してください。

</Callout>

この方法でバナーを削除することは、期限前にバナーを取り下げる方法でもあります。「無効化」フラグは存在しません。バナーは、`Display To`（表示終了日時）を過ぎると自動的に消えますが、`Display To`を設定せずに保存されたバナーは、削除するまで表示され続けます。

## Example Banners [#example-banners]

<Tabs items={['ウェルカムメッセージ', 'メンテナンス通知', 'セキュリティ警告']}>
  <Tabs.Tab>
    ユーザーが閉じることができるシンプルなウェルカムメッセージ：

    ```bash
    npm run update-banner "" "" "👋 Welcome to LibreChat!" "false" "false"
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    閉じることのできない定期メンテナンスの通知：

    ```bash
    npm run update-banner "2025-12-20T00:00:00Z" "2025-12-21T06:00:00Z" "⚠️ Scheduled maintenance on Dec 20th, 2-6 AM UTC" "true" "true"
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    全員に表示される緊急セキュリティ通知:

    ```bash
    npm run update-banner "" "" "🔒 Please update your password by January 1st" "true" "true"
    ```
  </Tabs.Tab>
</Tabs>

<Callout type="info" title="空の日付引数でも引き続きプロンプトが表示される">

空文字列(`""`)の日付は未入力として扱われるため、スクリプトは引き続き `Display From` と `Display To` を対話形式で尋ねます。各プロンプトで Enter キーを押すとデフォルト値が採用されます。最初の 2 つの引数として ISO 日付(`yyyy-mm-ddTHH:MM:SSZ`)を渡すと、プロンプトなしでコマンドを実行できます。メッセージのプロンプトを省略するには、メッセージ引数も必須です。また、`isPublic` と `persistable` の各引数は `true` または `false` を指定することで、それぞれのプロンプトを省略できます。

</Callout>

## 日付形式 [#date-format]

日付には `yyyy-mm-ddTHH:MM:SSZ` の形式を使用してください。

**例:**
- `2025-12-25T09:00:00Z` → 2025年12月25日 午前9:00 (UTC)
- `2025-01-01T00:00:00Z` → 2025年1月1日 午前0時 (UTC)

プロンプトが表示されたら、日付を入力せずに Enter キーを押すと、`Display From` には現在時刻が、`Display To` には終了日なしが使用されます。
