## Pengantar Ucapan (Speech) [#speech-introduction]

Konfigurasi Speech mencakup pengaturan untuk Speech-to-Text (STT) dan Text-to-Speech (TTS) di bawah bagian `speech:` yang terpadu. Selain itu, terdapat menu `speechTab` baru untuk pengaturan khusus pengguna.

> **Lihat Juga:** Untuk skema konfigurasi YAML yang mendetail dan semua opsi yang tersedia, lihat dokumentasi [Speech Object Structure](/docs/configuration/librechat_yaml/object_structure/speech).

### Variabel Lingkungan [#environment-variables]

Saat menggunakan layanan STT/TTS berbasis cloud, Anda perlu mengatur kunci API di dalam file `.env` Anda:

```bash filename=".env"
# Speech-to-Text API key (e.g., OpenAI Whisper)
STT_API_KEY=your-stt-api-key

# Text-to-Speech API key (e.g., OpenAI TTS, ElevenLabs)
TTS_API_KEY=your-tts-api-key
```

Kunci-kunci ini kemudian direferensikan dalam konfigurasi `librechat.yaml` Anda menggunakan `${STT_API_KEY}` dan `${TTS_API_KEY}`.

### Satu penyedia per layanan [#one-provider-per-service]

Masing-masing `speech.stt` dan `speech.tts` hanya menerima paling banyak satu blok penyedia, dan kedua bagian tersebut boleh dihilangkan untuk tetap menggunakan mesin browser bawaan untuk layanan tersebut. Jika suatu bagian memiliki lebih dari satu penyedia, permintaan akan gagal dengan pesan error "Multiple providers are set. Please set only one provider."

### Mesin yang di-host sendiri memerlukan entri allowedAddresses [#self-hosted-engines-need-an-allowedaddresses-entry]

Baik `speech.stt` maupun `speech.tts` menerima daftar `allowedAddresses`. Permintaan ucapan keluar divalidasi terhadap IP yang diselesaikan dan diblokir agar tidak mencapai ruang alamat privat, loopback, dan link-local, sehingga mesin yang di-host sendiri di `localhost`, alamat LAN, atau nama layanan Docker tidak dapat dijangkau sampai Anda mencantumkannya:

```yaml filename="librechat.yaml"
speech:
  tts:
    allowedAddresses:
      - 'host.docker.internal:8080'
    localai:
      url: 'http://host.docker.internal:8080/tts'
      # ...
```

Entri berupa pasangan `host:port` polos: tanpa skema atau path, port wajib disertakan, IPv6 menggunakan tanda kurung seperti `[::1]:8080`, dan literal IP harus bersifat privat. Endpoint cloud publik seperti OpenAI, Azure, dan ElevenLabs tidak memerlukan entri. Guard bekerja berdasarkan IP yang telah di-resolve, bukan hostname, sehingga endpoint cloud yang diakses melalui Private Link, DNS privat, atau VPN akan di-resolve ke ruang alamat privat dan perlu mencantumkan `host:port` yang tepat seperti target privat lainnya. Bidang dan aturan yang sama berlaku di bawah `speech.stt`. Lihat [SSRF protection](/docs/configuration/librechat_yaml/object_structure/web_search#ssrf-protection-and-private-providers) untuk format entri selengkapnya.

## Tab Ucapan (opsional) [#speech-tab-optional]

Menu `speechTab` menyediakan opsi yang dapat disesuaikan untuk mode percakapan dan mode lanjutan, serta pengaturan terperinci untuk STT dan TTS. Ini akan menetapkan pengaturan default bagi pengguna.

Gunakan `browser` untuk ucapan peramban bawaan atau `external` untuk penyedia sisi server yang dikonfigurasi di bawah. Default khusus penyedia yang lebih lama tetap diterima untuk kompatibilitas dan dinormalisasi ke `external`; jika layanan eksternal yang cocok tidak tersedia, LibreChat akan kembali ke `browser`.

contoh:

```yaml
speech:
  speechTab:
    conversationMode: true
    advancedMode: false
    speechToText:
      engineSTT: "external"
      languageSTT: "English (US)"
      autoTranscribeAudio: true
      decibelValue: -45
      autoSendText: 0
    textToSpeech:
      engineTTS: "external"
      voice: "alloy"
      languageTTS: "en"
      automaticPlayback: true
      playbackRate: 1.0
      cacheTTS: true
```

`speechTab` menetapkan nilai awal yang dilihat pengguna; masing-masing tetap dapat diubah per pengguna di tab pengaturan ucapan.

## STT (Speech-to-Text) [#stt-speech-to-text]

Fitur Speech-to-Text (STT) mengubah kata-kata yang diucapkan menjadi teks tertulis. Untuk mengaktifkan STT, klik tombol STT (di dekat tombol kirim) atau gunakan kombinasi tombol ++Shift+Alt+L++ untuk memulai transkripsi.

### Layanan STT yang Tersedia [#available-stt-services]

- **STT Lokal**
  - Berbasis peramban
  - Whisper (diuji pada LocalAI)
- **Cloud STT**
  - OpenAI Whisper
  - Azure Whisper
  - Layanan STT lain yang kompatibel dengan OpenAI

### Mengonfigurasi STT Lokal [#configuring-local-stt]

- #### Browser-based
  Tidak diperlukan pengaturan. Pastikan tombol "Speech To Text" di tab pengaturan suara telah diaktifkan dan "Browser" telah dipilih di menu tarik-turun engine.

- #### Whisper Local [#whisper-local]
  Memerlukan instance Whisper lokal.

```yaml
speech:
  stt:
    openai:
      url: 'http://host.docker.internal:8080/v1/audio/transcriptions'
      apiKey: '${STT_API_KEY}'
      model: 'whisper'
```

Kolom `apiKey` wajib diisi untuk setiap blok STT yang kompatibel dengan OpenAI, termasuk yang berjalan secara lokal. Jika server Anda tidak memeriksa kunci, gunakan nilai placeholder apa pun.

### Mengonfigurasi Cloud STT [#configuring-cloud-stt]

- #### OpenAI Whisper [#openai-whisper]

```yaml
speech:
  stt:
    openai:
      apiKey: '${STT_API_KEY}'
      model: 'whisper-1'
```

- #### Azure Whisper [#azure-whisper]

```yaml
speech:
  stt:
    azureOpenAI:
      instanceName: 'instanceName'
      apiKey: '${STT_API_KEY}'
      deploymentName: 'deploymentName'
      apiVersion: 'apiVersion'
```

<Callout type="info" title="Dukungan Domain endpoint Azure">
Kolom `instanceName` mendukung kedua format domain Azure OpenAI:
- **Format baru**: `.cognitiveservices.azure.com` (contoh: `my-instance.cognitiveservices.azure.com`)
- **Format lama**: `.openai.azure.com` (contoh: `my-instance.openai.azure.com`)

Anda dapat menentukan domain lengkap atau hanya nama instans. Jika Anda memberikan domain lengkap termasuk `.azure.com`, domain tersebut akan digunakan apa adanya. Jika tidak, format `.openai.azure.com` lama akan diterapkan untuk kompatibilitas mundur.
</Callout>

- #### Kompatibel dengan OpenAI [#openai-compatible]

Lihat bagian OpenAI Whisper, dan sesuaikan `url` serta `model` sesuai kebutuhan. Kolom `apiKey` tetap wajib diisi.

contoh
  
```yaml
speech:
  stt:
    openai:
      url: 'http://host.docker.internal:8080/v1/audio/transcriptions'
      apiKey: '${STT_API_KEY}'
      model: 'whisper'
```


## TTS (Text-to-Speech) [#tts-text-to-speech]

Fitur Text-to-Speech (TTS) mengubah teks tertulis menjadi kata-kata yang diucapkan. Berbagai layanan TTS tersedia:

### Layanan TTS yang Tersedia [#available-tts-services]

- **TTS Lokal**
  - Berbasis peramban
  - Piper (diuji pada LocalAI)
  - Coqui (diuji pada LocalAI)
- **Cloud TTS**
  - OpenAI TTS
  - Azure OpenAI
  - ElevenLabs
  - Layanan TTS lain yang kompatibel dengan OpenAI/ElevenLabs

Teks yang lebih panjang dari `speech.tts.maxInputChars` (default 20000 karakter) akan dipotong sebelum dibacakan. Lihat [Struktur Objek Speech](/docs/configuration/librechat_yaml/object_structure/speech) untuk detail selengkapnya.

### Mengonfigurasi TTS Lokal [#configuring-local-tts]

- #### Browser-based [#browser-based-1]

Tidak diperlukan pengaturan. Pastikan tombol "Text To Speech" di tab pengaturan suara diaktifkan dan "Browser" dipilih di menu tarik-turun mesin.

- #### Piper [#piper]

Memerlukan instance Piper lokal.

```yaml
speech:
  tts:
    localai:
      url: "http://host.docker.internal:8080/tts"
      apiKey: "EMPTY"
      voices: [
        "en-us-amy-low.onnx",
        "en-us-danny-low.onnx",
        "en-us-libritts-high.onnx",
        "en-us-ryan-high.onnx",
      ]
      backend: "piper"
```

- #### Coqui [#coqui]

Memerlukan instance Coqui lokal.

```yaml
speech:
  tts:
    localai:
      url: 'http://localhost:8080/v1/audio/synthesize'
      voices: ['tts_models/en/ljspeech/glow-tts', 'tts_models/en/ljspeech/tacotron2', 'tts_models/en/ljspeech/waveglow']
      backend: 'coqui'
```

### Mengonfigurasi Cloud TTS [#configuring-cloud-tts]

- #### OpenAI TTS [#openai-tts]

```yaml
speech:
  tts:
    openai:
      apiKey: '${TTS_API_KEY}'
      model: 'tts-1'
      voices: ['alloy', 'echo', 'fable', 'onyx', 'nova', 'shimmer']
```

- #### Azure OpenAI [#azure-openai]

```yaml
speech:
  tts:
    azureOpenAI:
      instanceName: ''
      apiKey: '${TTS_API_KEY}'
      deploymentName: ''
      apiVersion: ''
      model: 'tts-1'
      voices: ['alloy', 'echo', 'fable', 'onyx', 'nova', 'shimmer']
```

<Callout type="info" title="Dukungan Domain endpoint Azure">
Kolom `instanceName` mendukung kedua format domain Azure OpenAI:
- **Format baru**: `.cognitiveservices.azure.com` (contoh: `my-instance.cognitiveservices.azure.com`)
- **Format lama**: `.openai.azure.com` (contoh: `my-instance.openai.azure.com`)

Anda dapat menentukan domain lengkap atau hanya nama instans. Jika Anda memberikan domain lengkap termasuk `.azure.com`, domain tersebut akan digunakan apa adanya. Jika tidak, format `.openai.azure.com` lama akan diterapkan untuk kompatibilitas mundur.
</Callout>

- #### ElevenLabs [#elevenlabs]

```yaml
speech:
  tts:
    elevenlabs:
      apiKey: '${TTS_API_KEY}'
      model: 'eleven_multilingual_v2'
      voices: ['202898wioas09d2', 'addwqr324tesfsf', '3asdasr3qrq44w', 'adsadsa']
```

Parameter tambahan khusus ElevenLabs dapat ditambahkan sebagai berikut:

```yaml
      voice_settings:
        similarity_boost: 0.75 # number
        stability: 0.5 # number
        style: 0 # number
        use_speaker_boost: true # boolean
      pronunciation_dictionary_locators: [''] # list of strings (array)
```

- #### Kompatibel dengan OpenAI [#openai-compatible-1]

Lihat bagian OpenAI TTS, sesuaikan variabel `url` jika diperlukan

contoh:

```yaml
speech:
  tts:
    openai:
      url: 'http://host.docker.internal:8080/v1/audio/synthesize'
      apiKey: '${TTS_API_KEY}'
      model: 'tts-1'
      voices: ['alloy', 'echo', 'fable', 'onyx', 'nova', 'shimmer']
```

- #### Kompatibel dengan ElevenLabs [#elevenlabs-compatible]

Lihat bagian ElevenLabs, sesuaikan variabel `url` jika diperlukan

contoh:

```yaml
speech:
  tts:
    elevenlabs:
      url: 'http://host.docker.internal:8080/v1/audio/synthesize'
      apiKey: '${TTS_API_KEY}'
      model: 'eleven_multilingual_v2'
      voices: ['202898wioas09d2', 'addwqr324tesfsf', '3asdasr3qrq44w', 'adsadsa']
```
