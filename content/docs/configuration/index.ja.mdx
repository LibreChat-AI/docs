LibreChat は 4 つの主要な設定ファイルを使用します。それぞれが、環境変数からカスタム AI エンドポイント、Docker サービスのオーバーライドまで、アプリケーションの異なる側面を制御します。

## 一般的な変更ワークフロー [#common-change-workflow]

ほとんどの設定変更は、同じパターンに従います：

1. `.env` を編集して、シークレット、APIキー、およびサーバーレベルの機能フラグを設定します。
2. `librechat.yaml` を編集して、カスタム endpoint、Model Specs、インターフェース設定、MCP サーバー、エージェント、および高度なアプリの動作を設定します。
3. Dockerの場合、LibreChatが`librechat.yaml`を読み込めるようにするためには、事前に`docker-compose.override.yml`を通じてマウントされていることを確認してください。
4. 設定を変更するたびにLibreChatを再起動してください。
5. 変更がUIに反映されない場合は、APIログを確認してください。

例えば、OpenRouterを有効にするには、`.env`に`OPENROUTER_KEY`を追加し、`librechat.yaml`にOpenRouterのendpointを追加し、Dockerが`librechat.yaml`をマウントしていることを確認して再起動した後、endpointセレクターからOpenRouterを選択します。

## 設定ファイル [#configuration-files]

  <FileTree.Folder name="LibreChat (project root)" defaultOpen>
    <FileTree.File name=".env" active />
    <FileTree.File name="librechat.yaml" active />
    <FileTree.File name="docker-compose.yml" />
    <FileTree.File name="docker-compose.override.yml" active />
  </FileTree.Folder>
</FileTree>

**`.env`**: サーバーレベルの設定です。APIキー、データベース接続文字列、機能フラグ、認証シークレットなどが含まれます。ほとんどのデプロイメントにおける主要な設定ファイルです。利用可能なすべての変数については、[.env リファレンス](/docs/configuration/dotenv)を参照してください。

**`librechat.yaml`**: カスタムAIエンドポイント、モデル設定、インターフェースオプション、そしてMCPサーバーやエージェントなどの高度な機能を設定します。このファイルは任意です。存在しない場合でも、LibreChatはデフォルト設定で動作します。設定手順については、[librechat.yamlガイド](/docs/configuration/librechat_yaml)を参照してください。

**`docker-compose.yml`**: Docker のサービス(`api`、`admin-panel`、`mongodb`、`meilisearch`、`vectordb`、`rag_api`)を定義します。このファイルは直接編集しないでください。変更がアップデート後も維持されるよう、代わりにオーバーライドファイルを使用してください。

**`docker-compose.override.yml`**: Docker サービスに対するローカルのカスタマイズ（ボリュームマウント、ポートマッピング、環境変数の上書き）を記述します。Docker Compose はこのファイルをメインのファイルと自動的にマージします。詳しくは [Docker override ガイド](/docs/configuration/docker_override) をご覧ください。

## 変更の適用 [#applying-changes]

<Callout type="warning" title="再起動が必要です">

設定ファイルを編集した後は、変更を反映させるためにLibreChatを再起動する必要があります。

<Tabs items={['Docker', 'ローカル']}>
  <Tabs.Tab>

```bash
docker compose down && docker compose up -d
```

  </Tabs.Tab>
  <Tabs.Tab>

実行中のプロセスを停止し (Ctrl+C)、再起動します:

```bash
npm run backend
```

  </Tabs.Tab>
</Tabs>

</Callout>
