これらの設定は、[自動モデレーション](/docs/features/mod_system)機能のページで説明されているレート制限、違反スコア、およびBANを制御します。これらはすべて`.env`ファイル内の環境変数です。ログインと登録の制限は常に適用されます。また、[`.env.example`](https://github.com/danny-avila/LibreChat/blob/dev/.env.example)では、BANと同時実行およびIP単位のメッセージ制限も有効になります。アップロード、音声、インポートの制限は、`librechat.yaml`の[`rateLimits`](/docs/configuration/librechat_yaml/object_structure/config#ratelimits)ブロックでも設定できます。

BANは、ユーザーのセッションを終了させ、そのアカウントと発信元のIPアドレスの両方をブロックします。BANは MongoDB の `logs` コレクションに保存され、`BAN_DURATION` の経過後に期限切れとなります。期限前に解除するには、該当するエントリを同コレクションから削除してください。違反スコアは `data/violations.json` に保存されます(`USE_REDIS` が有効な場合は Redis に保存されます)。個々の違反は、ユーザーごとに `data/logs.json` に記録されます。

## OpenAI テキストモデレーション [#openai-text-moderation]

有効にすると、通常のチャットエンドポイントおよびエージェントに送信されたチャットメッセージ(引用テキストを含む)は、モデルに渡される前に OpenAI の moderation API でチェックされます。フラグが立てられたメッセージは拒否され、ユーザーにはメッセージを編集するよう案内が表示されます。ホスト型の Assistants エンドポイントでの会話はチェックされません。
