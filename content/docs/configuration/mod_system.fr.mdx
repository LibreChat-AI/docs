Ces paramètres contrôlent les limites de débit, les scores de violation et les bannissements décrits sur la page de fonctionnalité [Automated Moderation](/docs/features/mod_system). Tous sont des variables d'environnement dans votre fichier `.env` ; les limites de connexion et d'inscription s'appliquent toujours, et [`.env.example`](https://github.com/danny-avila/LibreChat/blob/dev/.env.example) active également le bannissement ainsi que les limites de messages simultanés et par IP. Les limites de téléversement, de synthèse vocale et d'importation peuvent aussi être définies dans le bloc [`rateLimits`](/docs/configuration/librechat_yaml/object_structure/config#ratelimits) de `librechat.yaml`.

## Configuration [#setup]

### Violation, Interval, Duration [#violation-interval-duration]

<OptionTable

    ['BAN_INTERVAL', 'integer', 'L\'utilisateur sera banni chaque fois que son score atteindra ou dépassera le seuil de l\'intervalle.','BAN_INTERVAL=20'],
    ['VIOLATION_SCORE_TTL', 'integer', 'Combien de temps (en millisecondes) un score de violation est conservé sans nouvelle violation. Chaque nouvelle violation relance le compte à rebours. 0 conserve les scores indéfiniment (comportement précédent). Par défaut : une heure.','VIOLATION_SCORE_TTL=1000 * 60 * 60'],
  ]}
/>

Un bannissement met fin aux sessions de l'utilisateur et bloque à la fois le compte et l'adresse IP d'où provenait la demande. Les bannissements sont stockés dans la collection `logs` de MongoDB et expirent après `BAN_DURATION` ; pour le lever avant terme, supprimez ses entrées dans cette collection. Les scores de violation sont conservés dans `data/violations.json` (dans Redis lorsque `USE_REDIS` est activé), et chaque violation individuelle est enregistrée par utilisateur dans `data/logs.json`.

### Requêtes de modèle illégales [#illegal-model-requests]

Une requête pour un modèle que l'endpoint ne propose pas provient presque toujours d'un script plutôt que de l'interface utilisateur. Il convient donc de lui attribuer un score relativement élevé, 5 ou plus. Lorsqu'il n'est pas défini, il compte pour 1.

## Modération de texte OpenAI [#openai-text-moderation]

Lorsque cette option est activée, les messages envoyés aux endpoints de chat classiques et aux agents (y compris le texte cité) sont vérifiés avec l'API de modération d'OpenAI avant d'atteindre le modèle. Les messages signalés sont rejetés et l'utilisateur est invité à modifier son message. Les conversations sur les endpoints Assistants hébergés ne sont pas vérifiées.
