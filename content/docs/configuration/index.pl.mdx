LibreChat używa czterech głównych plików konfiguracyjnych. Każdy z nich steruje innym aspektem aplikacji, od zmiennych środowiskowych, przez niestandardowe endpointy AI, aż po nadpisania usług Docker.

## Typowy przepływ pracy przy zmianach [#common-change-workflow]

Większość zmian w konfiguracji przebiega według tego samego schematu:

1. Edytuj `.env`, aby skonfigurować sekrety, klucze API oraz flagi funkcji na poziomie serwera.
2. Edytuj `librechat.yaml`, aby skonfigurować niestandardowe endpoint, Model Specs, ustawienia interfejsu, serwery MCP, agentów oraz zaawansowane zachowanie aplikacji.
3. W przypadku Docker, upewnij się, że `librechat.yaml` jest zamontowany poprzez `docker-compose.override.yml`, zanim oczekujesz, że LibreChat go odczyta.
4. Po każdej zmianie konfiguracji zrestartuj LibreChat.
5. Sprawdź logi API, jeśli zmiana nie pojawia się w interfejsie użytkownika.

Na przykład, aby włączyć OpenRouter, dodaj `OPENROUTER_KEY` do pliku `.env`, dodaj endpoint OpenRouter w `librechat.yaml`, upewnij się, że Docker montuje `librechat.yaml`, zrestartuj aplikację, a następnie wybierz OpenRouter z selektora endpointów.

## Pliki konfiguracyjne [#configuration-files]

**`.env`**: Ustawienia na poziomie serwera: klucze API, ciągi połączeń z bazą danych, flagi funkcji i sekrety uwierzytelniania. Jest to główny plik konfiguracyjny dla większości wdrożeń. Wszystkie dostępne zmienne znajdziesz w [dokumentacji .env](/docs/configuration/dotenv).

**`librechat.yaml`**: Niestandardowe endpointy AI, ustawienia modeli, opcje interfejsu oraz zaawansowane funkcje, takie jak serwery MCP i agenci. Ten plik jest opcjonalny. LibreChat działa z ustawieniami domyślnymi, jeśli plik nie istnieje. Instrukcje konfiguracji znajdziesz w [przewodniku librechat.yaml](/docs/configuration/librechat_yaml).

**`docker-compose.yml`**: Definiuje usługi Docker (`api`, `admin-panel`, `mongodb`, `meilisearch`, `vectordb` oraz `rag_api`). Nie edytuj tego pliku bezpośrednio. Zamiast tego użyj pliku nadpisań (override), dzięki czemu Twoje zmiany przetrwają aktualizacje.

**`docker-compose.override.yml`**: Twoje lokalne dostosowania usług Docker: montowania woluminów, mapowania portów, nadpisania zmiennych środowiskowych. Docker Compose automatycznie scala ten plik z głównym plikiem. Zobacz [przewodnik po override dla Docker](/docs/configuration/docker_override).

## Wprowadzanie zmian [#applying-changes]

<Callout type="warning" title="Wymagany restart">

Po edycji dowolnego pliku konfiguracyjnego musisz zrestartować LibreChat, aby zmiany weszły w życie.

<Tabs items={['Docker', 'Lokalny']}>
  <Tabs.Tab>

```bash
docker compose down && docker compose up -d
```

  </Tabs.Tab>
  <Tabs.Tab>

Zatrzymaj uruchomiony proces (Ctrl+C) i uruchom ponownie:

```bash
npm run backend
```

  </Tabs.Tab>
</Tabs>

</Callout>
