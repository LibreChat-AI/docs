These settings control the rate limits, violation scores, and bans described on the [Automated Moderation](/docs/features/mod_system) feature page. All of them are environment variables in your `.env` file; login and registration limits always apply, and [`.env.example`](https://github.com/danny-avila/LibreChat/blob/dev/.env.example) also turns on banning and the concurrent and per-IP message limits. Upload, speech, and import limits can also be set in the [`rateLimits`](/docs/configuration/librechat_yaml/object_structure/config#ratelimits) block of `librechat.yaml`.

## Configuración [#setup]

### Violación, Intervalo, Duración [#violation-interval-duration]

<OptionTable
  options={[
    ['BAN_VIOLATIONS', 'boolean', 'Si se debe habilitar o no la prohibición de usuarios por infracciones (aún así serán registrados).','BAN_VIOLATIONS=true'],
    ['BAN_DURATION', 'integer', 'Cuánto tiempo se bloquea al usuario y a la IP asociada (en milisegundos).','BAN_DURATION=1000 * 60 * 60 * 2'],
    ['BAN_INTERVAL', 'integer', 'El usuario será baneado cada vez que su puntuación alcance o supere el umbral del intervalo.','BAN_INTERVAL=20'],
    ['VIOLATION_SCORE_TTL', 'integer', 'How long (in milliseconds) a violation score is kept without new violations. Each new violation restarts the countdown. 0 keeps scores forever (the old behavior). Default: one hour.','VIOLATION_SCORE_TTL=1000 * 60 * 60'],
  ]}
/>

A ban ends the user's sessions and blocks both the account and the IP it came from. Bans are stored in the `logs` collection in MongoDB and expire after `BAN_DURATION`; to lift one early, delete its entries there. Violation scores are kept in `data/violations.json` (in Redis when `USE_REDIS` is enabled), and every individual violation is recorded per user in `data/logs.json`.

## Moderación de texto de OpenAI [#openai-text-moderation]

When enabled, chat messages sent to regular chat endpoints and agents (including quoted text) are checked with the OpenAI moderation API before they reach the model. Flagged messages are rejected and the user is told to edit the message. Conversations on the hosted Assistants endpoints are not checked.
