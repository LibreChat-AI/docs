이 설정들은 [자동 모더레이션](/docs/features/mod_system) 기능 페이지에 설명된 요청 제한, 위반 점수, 차단을 제어합니다. 모든 설정은 `.env` 파일의 환경 변수이며, 로그인 및 회원가입 제한은 항상 적용됩니다. [`.env.example`](https://github.com/danny-avila/LibreChat/blob/dev/.env.example)에서는 차단 기능과 동시 메시지 및 IP별 메시지 제한도 활성화됩니다. 업로드, 음성, 가져오기 제한은 `librechat.yaml`의 [`rateLimits`](/docs/configuration/librechat_yaml/object_structure/config#ratelimits) 블록에서도 설정할 수 있습니다.

## 설정 [#setup]

차단이 적용되면 사용자의 세션이 종료되고, 해당 계정과 요청이 들어온 IP가 모두 차단됩니다. 차단 정보는 MongoDB의 `logs` 컬렉션에 저장되며, `BAN_DURATION`이 지나면 만료됩니다. 차단을 조기에 해제하려면 해당 차단 항목을 MongoDB에서 삭제하면 됩니다. 위반 점수는 `data/violations.json`에 저장되며, `USE_REDIS`가 활성화된 경우에는 Redis에 저장됩니다. 각 위반 내역은 사용자별로 `data/logs.json`에 기록됩니다.
