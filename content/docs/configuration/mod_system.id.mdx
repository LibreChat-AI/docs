Pengaturan ini mengontrol batas laju (rate limit), skor pelanggaran, dan pemblokiran sebagaimana dijelaskan di halaman fitur [Moderasi Otomatis](/docs/features/mod_system). Semua pengaturan ini berupa variabel lingkungan di file `.env` Anda; batas login dan registrasi selalu berlaku, dan [`.env.example`](https://github.com/danny-avila/LibreChat/blob/dev/.env.example) juga mengaktifkan pemblokiran serta batas pesan bersamaan dan batas pesan per IP. Batas unggahan, suara, dan impor juga dapat diatur dalam blok [`rateLimits`](/docs/configuration/librechat_yaml/object_structure/config#ratelimits) pada `librechat.yaml`.

Ban mengakhiri sesi pengguna dan memblokir akun serta IP asal ban tersebut. Ban disimpan dalam koleksi `logs` di MongoDB dan kedaluwarsa setelah `BAN_DURATION`; untuk mencabut ban lebih awal, hapus entri-entrinya di sana. Skor pelanggaran disimpan dalam `data/violations.json` (di Redis saat `USE_REDIS` diaktifkan), dan setiap pelanggaran individual dicatat per pengguna dalam `data/logs.json`.

## Moderasi teks OpenAI [#openai-text-moderation]

Ketika diaktifkan, pesan obrolan yang dikirim ke endpoint obrolan biasa dan agen (termasuk teks yang dikutip) diperiksa dengan API moderasi OpenAI sebelum mencapai model. Pesan yang ditandai akan ditolak dan pengguna diminta untuk mengedit pesan tersebut. Percakapan pada endpoint Assistants yang di-host tidak diperiksa.
