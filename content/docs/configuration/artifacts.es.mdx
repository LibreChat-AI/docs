Esta página cubre el lado de administración de [Artifacts](/docs/features/artifacts). Los usuarios activan los artifacts por agente en el Agent Builder; la configuración aquí determina si esa opción existe y desde dónde se cargan las vistas previas.

## Habilitar artefactos [#enabling-artifacts]

Los artefactos son una capacidad de los agentes. `artifacts` forma parte de la lista predeterminada de [`endpoints.agents.capabilities`](/docs/configuration/librechat_yaml/object_structure/agents#capabilities), por lo que está disponible a menos que definas tu propia lista sin incluirla. Si sobrescribes `capabilities`, incluye `artifacts` para mantener la opción en el Agent Builder.

Para asignar artefactos de especificación de modelo sin crear un agente, establece [`artifacts`](/docs/configuration/librechat_yaml/object_structure/model_specs#artifacts) en la especificación. `true` usa el modo predeterminado; también puedes pasar el nombre de un modo: `default`, `shadcnui` o `custom`.

## Abrir el panel en una nueva ventana [#opening-the-panel-in-a-new-window]

El panel tiene un botón **Abrir en una nueva ventana** que lo mueve a una ventana separada del navegador. Está activado de forma predeterminada. Si tu despliegue se ejecuta en un entorno donde las ventanas emergentes no funcionan, como una webview integrada, desactívalo con [`interface.artifactUndocking: false`](/docs/configuration/librechat_yaml/object_structure/interface#artifactundocking); el panel acoplado seguirá funcionando.

## Content-Security-Policy

LibreChat's propia CSP permite frames HTTPS, por lo que el bundler predeterminado de CodeSandbox se carga sin cambios. Si un reverse proxy o CDN delante de LibreChat establece un `Content-Security-Policy` más restrictivo, permite el origen del bundler en `frame-src`: `https://*.codesandbox.io` para el bundler público, o tus propias URLs de bundler si lo alojas tú mismo. Cuando solo necesites extender la política integrada de LibreChat, usa `CSP_FRAME_SRC_EXTRA`.

Las vistas previas de React también cargan Tailwind desde `cdn.tailwindcss.com`, por lo que ese host debe ser accesible desde los navegadores de los usuarios.

## Autoalojamiento del empaquetador Sandpack [#self-hosting-the-sandpack-bundler]

Las vistas previas se renderizan con [Sandpack](https://sandpack.codesandbox.io/), que de forma predeterminada obtiene su bundler desde la CDN pública de CodeSandbox. Esa CDN también envía telemetría de uso. Para redes privadas, requisitos de cumplimiento o para eliminar la dependencia de un servicio externo, [aloje usted mismo el bundler](https://sandpack.codesandbox.io/docs/guides/hosting-the-bundler).

[LibreChat-AI/codesandbox-client](https://github.com/LibreChat-AI/codesandbox-client) es una bifurcación preparada para LibreChat, en la que se han eliminado las solicitudes de telemetría, incluidas las de las imágenes de contenedor.

LibreChat utiliza dos empaquetadores (bundlers). `SANDPACK_BUNDLER_URL` sirve los artefactos de React, y `SANDPACK_STATIC_BUNDLER_URL` sirve la plantilla estática que se encuentra detrás de las vistas previas de HTML, SVG, Markdown, código y archivos de Office. Configure ambas al alojar LibreChat por su cuenta: si solo se configura una, los demás tipos de artefactos seguirán cargándose desde el CDN público. Ambas aparecen en la [referencia de `.env`](/docs/configuration/dotenv#artifacts). Los diagramas de Mermaid se renderizan directamente en la página y no utilizan ninguno de los dos empaquetadores.

Ejecutar tu propio bundler significa que tú eres responsable de su configuración de CORS, de las actualizaciones de seguridad y de los recursos de alojamiento. Reinicia LibreChat después de cambiar estas variables; las URL se envían al navegador en la configuración de inicio.
