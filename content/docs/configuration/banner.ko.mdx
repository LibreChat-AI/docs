앱 상단에 모든 사용자에게 중요한 메시지를 표시합니다. 공지사항, 유지보수 알림 또는 업데이트에 적합합니다.

<Callout type="info" title="빠른 개요">
  - 한 번에 **하나의 배너**만 활성화할 수 있습니다
  - 배너가 자동으로 나타나고 사라지도록 예약하세요
  - 사용자가 배너를 닫을 수 있는지 여부를 선택하세요
  - 모든 사용자 또는 로그인한 사용자에게만 배너 표시
</Callout>

---

## 배너 생성하기 [#creating-a-banner]

배너를 생성하거나 업데이트하려면 다음 명령어를 실행하세요:

```bash
npm run update-banner
```

Docker를 사용하는 경우, 대신 `api` 컨테이너 안에서 스크립트를 실행하세요:

```bash
docker compose exec api npm run update-banner
```

몇 가지 간단한 프롬프트를 통해 안내를 받게 됩니다:

```ansi
--------------------------
Update the banner!
--------------------------
Display From (Format: yyyy-mm-ddTHH:MM:SSZ, Default: now):
> 2025-12-02T09:00:00Z

Display To (Format: yyyy-mm-ddTHH:MM:SSZ, Default: not specified):
> 2025-12-31T23:59:59Z

Enter your message (Enter a single dot "." on a new line to finish):
> 🎉 Welcome to LibreChat! Check out our new features.
> .

Is public (y/N):
> n

Is persistable (cannot be dismissed) (y/N):
> n
```

<Callout type="tip" title="이 옵션들은 무엇을 의미하나요?">
  - **Display From/To**: 배너가 표시되고 사라지는 시점입니다. 프롬프트에서 Enter를 누르면 "now"(지금)와 "forever"(영구)가 사용됩니다.
  - **Is public**: 로그인하지 않은 방문자에게 표시 (로그인 페이지 등)
  - **지속 가능 여부**: 예(Yes)인 경우 사용자는 배너를 닫을 수 없습니다(중요한 공지에 사용하세요).
</Callout>

<Callout type="warning" title="이 작업을 다시 실행하면 기존 배너가 교체됩니다">

배너는 항상 하나만 존재할 수 있습니다. `update-banner`는 기존 배너를 찾아 그 자리에 덮어쓰며, 배너가 없을 때만 새로 생성합니다. 따라서 나중에 표시할 배너를 대기열에 추가하거나 두 개의 예약된 기간이 겹치게 설정할 수 없습니다. 명령을 다시 실행하면 이전 배너의 메시지와 일정은 삭제됩니다.

배너를 변경하려면 `update-banner`를 다시 실행하세요. `Display To` 시간 이전에 배너를 내리려면 아래의 `delete-banner`를 사용하세요.

</Callout>

## 배너 삭제하기 [#deleting-a-banner]

```bash
npm run delete-banner
```

Docker를 사용하여 `docker compose exec api npm run delete-banner`를 실행하세요.

현재 배너가 표시되며 삭제하기 전에 확인을 요청받게 됩니다.

<Callout type="warning" title="활성 배너만 삭제할 수 있습니다">

`delete-banner`은 현재 활성 상태인 배너만 찾습니다. 즉, `Display From` 시간이 이미 지났고, `Display To` 시간이 미래이거나 설정되지 않은 경우에만 해당합니다. 예약된 날짜가 아직 오지 않은 배너나 `Display To` 시간이 이미 지난 배너는 "No banner found to delete"로 보고되며 데이터베이스에 그대로 남습니다. 이러한 배너를 교체하려면 `update-banner`를 다시 실행하세요.

</Callout>

이런 방식으로 배너를 제거하는 것은 배너를 조기에 내리는 방법이기도 합니다. "비활성화(disable)" 플래그는 따로 존재하지 않습니다. 배너는 `Display To` 시간이 지나면 자동으로 사라지며, `Display To` 설정 없이 저장된 배너는 삭제할 때까지 계속 표시됩니다.

## 예시 배너 [#example-banners]

<Tabs items={['환영 메시지', '유지보수 공지', '보안 경고']}>
  <Tabs.Tab>
    사용자가 닫을 수 있는 간단한 환영 메시지:

    ```bash
    npm run update-banner "" "" "👋 Welcome to LibreChat!" "false" "false"
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    닫을 수 없는 예정된 유지보수 알림:

    ```bash
    npm run update-banner "2025-12-20T00:00:00Z" "2025-12-21T06:00:00Z" "⚠️ Scheduled maintenance on Dec 20th, 2-6 AM UTC" "true" "true"
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    모든 사용자에게 표시되는 긴급 보안 공지:

    ```bash
    npm run update-banner "" "" "🔒 Please update your password by January 1st" "true" "true"
    ```
  </Tabs.Tab>
</Tabs>

<Callout type="info" title="빈 날짜 인수에도 여전히 프롬프트가 표시됨">

빈 문자열(`""`)을 날짜로 입력하면 누락된 값으로 처리되므로, 스크립트는 여전히 `Display From`과 `Display To`를 대화형으로 묻습니다. 각 프롬프트에서 Enter를 눌러 기본값을 수락하거나, 첫 두 인수로 ISO 날짜(`yyyy-mm-ddTHH:MM:SSZ`)를 전달하면 프롬프트 없이 명령을 실행할 수 있습니다. 메시지 인수도 필수이며, 메시지 프롬프트를 건너뛰려면 이를 지정해야 합니다. 또한 `isPublic`과 `persistable` 인수는 프롬프트를 건너뛰기 위해 `true` 또는 `false`로 지정해야 합니다.

</Callout>

## 날짜 형식 [#date-format]

날짜 형식은 `yyyy-mm-ddTHH:MM:SSZ`를 사용하세요.

**예시:**
- `2025-12-25T09:00:00Z` → 2025년 12월 25일 오전 9:00 (UTC)
- `2025-01-01T00:00:00Z` → 2025년 1월 1일 자정 (UTC)

`Display From`에 대해 입력 요청이 나오면 날짜를 입력하지 않고 Enter를 누르면 현재 시간이 사용되며, `Display To`에 대해서는 종료 날짜를 입력하지 않고 Enter를 누르면 종료 날짜가 설정되지 않습니다.
