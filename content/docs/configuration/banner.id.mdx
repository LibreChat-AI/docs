Tampilkan pesan penting kepada semua pengguna Anda di bagian atas aplikasi. Sangat cocok untuk pengumuman, pemberitahuan pemeliharaan, atau pembaruan.

<Callout type="info" title="Tinjauan Singkat">
  - Hanya **satu banner** yang dapat aktif dalam satu waktu
  - Jadwalkan banner agar muncul dan hilang secara otomatis
  - Pilih apakah pengguna dapat menutup banner atau tidak
  - Tampilkan banner kepada semua orang, atau hanya kepada pengguna yang telah masuk
</Callout>

---

## Membuat Banner [#creating-a-banner]

Jalankan perintah ini untuk membuat atau memperbarui banner:

```bash
npm run update-banner
```

Dengan Docker, jalankan skrip di dalam kontainer `api` sebagai gantinya:

```bash
docker compose exec api npm run update-banner
```

Anda akan dipandu melalui beberapa perintah sederhana:

```ansi
--------------------------
Update the banner!
--------------------------
Display From (Format: yyyy-mm-ddTHH:MM:SSZ, Default: now):
> 2025-12-02T09:00:00Z

Display To (Format: yyyy-mm-ddTHH:MM:SSZ, Default: not specified):
> 2025-12-31T23:59:59Z

Enter your message (Enter a single dot "." on a new line to finish):
> 🎉 Welcome to LibreChat! Check out our new features.
> .

Is public (y/N):
> n

Is persistable (cannot be dismissed) (y/N):
> n
```

<Callout type="tip" title="Apa arti opsi-opsi ini?">
  - **Tampilkan Dari/Hingga**: Kapan banner harus muncul dan menghilang. Tekan Enter pada prompt untuk menggunakan "now" dan "forever"
  - **Is public**: Tampilkan kepada pengunjung yang belum masuk (seperti pada halaman masuk)
  - **Dapat disimpan**: Jika ya, pengguna tidak dapat menutup banner (gunakan untuk pemberitahuan penting)
</Callout>

<Callout type="warning" title="Menjalankan ini lagi akan menggantikan banner yang sudah ada">

Hanya ada satu banner pada satu waktu. `update-banner` mencari banner yang sudah ada dan menimpanya secara langsung, serta hanya membuatnya jika belum ada, sehingga Anda tidak dapat mengantrekan banner kedua untuk tanggal mendatang, dan Anda tidak dapat memiliki dua jadwal yang tumpang tindih. Menjalankan perintah tersebut lagi akan membuang pesan dan jadwal banner sebelumnya.

Untuk mengubah banner, jalankan `update-banner` kembali. Untuk menghapusnya sebelum waktu `Display To` berakhir, gunakan `delete-banner` di bawah ini.

</Callout>

## Menghapus Banner [#deleting-a-banner]

```bash
npm run delete-banner
```

Dengan Docker, jalankan `docker compose exec api npm run delete-banner`.

Anda akan melihat banner saat ini dan diminta untuk melakukan konfirmasi sebelum menghapus.

<Callout type="warning" title="Hanya banner yang aktif yang dapat dihapus">

`delete-banner` hanya menemukan banner yang sedang aktif: waktu `Display From`-nya harus sudah lewat, dan waktu `Display To`-nya harus berada di masa depan atau tidak diatur. Banner yang dijadwalkan untuk tanggal yang lebih nanti, atau banner yang waktu `Display To`-nya sudah lewat, akan dilaporkan sebagai "No banner found to delete" dan tetap berada di database. Untuk mengganti banner seperti itu, jalankan kembali `update-banner`.

</Callout>

Menghapus banner dengan cara ini juga merupakan cara untuk menurunkannya lebih awal: tidak ada flag "disable". Banner lainnya akan hilang dengan sendirinya setelah `Display To` terlewati, dan banner yang disimpan tanpa `Display To` akan tetap muncul sampai Anda menghapusnya.

## Contoh Banner [#example-banners]

<Tabs items={['Pesan Selamat Datang', 'Pemberitahuan Pemeliharaan', 'Peringatan Keamanan']}>
  <Tabs.Tab>
    Pesan selamat datang sederhana yang dapat ditutup oleh pengguna:

    ```bash
    npm run update-banner "" "" "👋 Welcome to LibreChat!" "false" "false"
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    Pemberitahuan pemeliharaan terjadwal yang tidak dapat ditutup:

    ```bash
    npm run update-banner "2025-12-20T00:00:00Z" "2025-12-21T06:00:00Z" "⚠️ Scheduled maintenance on Dec 20th, 2-6 AM UTC" "true" "true"
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    Pemberitahuan keamanan mendesak yang terlihat oleh semua orang:

    ```bash
    npm run update-banner "" "" "🔒 Please update your password by January 1st" "true" "true"
    ```
  </Tabs.Tab>
</Tabs>

<Callout type="info" title="Argumen tanggal kosong masih memunculkan prompt">

Sebuah string kosong (`""`) untuk tanggal diperlakukan sebagai data yang hilang, sehingga skrip tetap meminta `Display From` dan `Display To` secara interaktif. Tekan Enter pada setiap prompt untuk menerima nilai default, atau berikan tanggal ISO (`yyyy-mm-ddTHH:MM:SSZ`) sebagai dua argumen pertama untuk menjalankan perintah tanpa prompt. Argumen message juga wajib diisi untuk melewati prompt pesan, dan argumen `isPublic` serta `persistable` harus diberikan sebagai `true` atau `false` untuk melewati prompt masing-masing.

</Callout>

## Format Tanggal [#date-format]

Gunakan format ini untuk tanggal: `yyyy-mm-ddTHH:MM:SSZ`

**Contoh:**
- `2025-12-25T09:00:00Z` → 25 Desember 2025 pukul 09.00 (UTC)
- `2025-01-01T00:00:00Z` → 1 Januari 2025 tengah malam (UTC)

Saat diminta, tekan Enter tanpa mengetik tanggal untuk menggunakan waktu saat ini untuk `Display From`, atau tanpa tanggal akhir untuk `Display To`.
