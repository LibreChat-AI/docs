O LibreChat usa quatro arquivos principais de configuração. Cada um controla um aspecto diferente da aplicação, desde variáveis de ambiente até endpoints de IA personalizados e substituições de serviços do Docker.

## Fluxo de Trabalho de Alteração Comum [#common-change-workflow]

A maioria das alterações de configuração segue o mesmo padrão:

1. Edite o `.env` para segredos, chaves de API e sinalizadores de recursos em nível de servidor.
2. Edite o `librechat.yaml` para endpoints personalizados, Model Specs, configurações de interface, servidores MCP, agentes e comportamento avançado do aplicativo.
3. Para Docker, certifique-se de que o `librechat.yaml` esteja montado através do `docker-compose.override.yml` antes de esperar que o LibreChat o leia.
4. Reinicie o LibreChat após cada alteração de configuração.
5. Verifique os logs da API se a alteração não aparecer na UI.

Por exemplo, para habilitar o OpenRouter, você adiciona `OPENROUTER_KEY` ao `.env`, adiciona um endpoint do OpenRouter no `librechat.yaml`, certifica-se de que o Docker monte o `librechat.yaml`, reinicia e, em seguida, seleciona o OpenRouter no seletor de endpoint.

## Arquivos de Configuração [#configuration-files]

    <FileTree.File name="librechat.yaml" active />

  </FileTree.Folder>

**`.env`**: Configurações em nível de servidor: chaves de API, strings de conexão com o banco de dados, feature flags e segredos de autenticação. Este é o principal arquivo de configuração para a maioria das implantações. Consulte a [referência do .env](/docs/configuration/dotenv) para todas as variáveis disponíveis.

**`librechat.yaml`**: Endpoints de IA personalizados, configurações de modelos, opções de interface e recursos avançados, como servidores MCP e agentes. Este arquivo é opcional. O LibreChat funciona com os padrões caso ele não exista. Consulte o [guia do librechat.yaml](/docs/configuration/librechat_yaml) para instruções de configuração.

**`docker-compose.yml`**: Define os serviços do Docker (`api`, `admin-panel`, `mongodb`, `meilisearch`, `vectordb` e `rag_api`). Não edite este arquivo diretamente. Use um arquivo de override em vez disso, para que suas alterações sobrevivam às atualizações.

**`docker-compose.override.yml`**: Suas personalizações locais para os serviços do Docker: montagens de volumes, mapeamentos de portas, substituições de variáveis de ambiente. O Docker Compose mescla isso automaticamente com o arquivo principal. Consulte o [guia de override do Docker](/docs/configuration/docker_override).

## Aplicando Alterações [#applying-changes]

<Callout type="warning" title="Reinicialização necessária">

Após editar qualquer arquivo de configuração, você deve reiniciar o LibreChat para que as alterações entrem em vigor.

<Tabs items={['Docker', 'Local']}>
  <Tabs.Tab>

```bash
docker compose down && docker compose up -d
```

  </Tabs.Tab>
  <Tabs.Tab>

Interrompa o processo em execução (Ctrl+C) e reinicie:

```bash
npm run backend
```

  </Tabs.Tab>
</Tabs>

</Callout>
