Voor de Google endpoint kun je ofwel de **Gemini API via Google AI Studio** of de **Vertex AI API** gebruiken.

De Generative Language API gebruikt een API-sleutel, die je kunt verkrijgen via **Google AI Studio**.

Voor Vertex AI heb je een Service Account JSON-sleutelbestand nodig, met de juiste toegangsrechten geconfigureerd.

Instructies voor beide worden hieronder gegeven.

## Generative Language API (Gemini) [#generative-language-api-gemini]

**[Zie hier voor Gemini API-prijzen en limieten](https://ai.google.dev/pricing)**

⚠️ Hoewel Google-modellen gratis zijn, gebruiken ze jouw input/output om het model te verbeteren, waarbij gegevens worden geanonimiseerd van je Google-account en API-sleutel.
⚠️ Tijdens deze periode kunnen jouw berichten "toegankelijk zijn voor getrainde beoordelaars."

Om Gemini-modellen via Google AI Studio te gebruiken, heb je een API-sleutel nodig. Als je er nog geen hebt, maak dan een sleutel aan in Google AI Studio.

Haal hier een API-sleutel op: **[aistudio.google.com](https://aistudio.google.com/app/apikey)**

Zodra je je sleutel hebt, voer je deze in je .env bestand in, waardoor alle gebruikers van je instantie deze kunnen gebruiken.

```bash filename=".env"
GOOGLE_KEY=mY_SeCreT_w9347w8_kEY
```

Of je kunt gebruikers dit laten opgeven vanuit de frontend door het volgende in te stellen:

```bash filename=".env"
GOOGLE_KEY=user_provided
```

Sommige reverse proxies ondersteunen de `X-goog-api-key` header niet. Je kunt LibreChat configureren om in plaats daarvan de `Authorization` header te gebruiken:

```bash filename=".env"
GOOGLE_AUTH_HEADER=true
```

Aangezien het ophalen van de modellenlijst nog niet wordt ondersteund, moet je de modellen die je wilt gebruiken instellen in het .env bestand.

Bijvoorbeeld, de volgende huidige modellen kunnen worden geconfigureerd voor de Gemini API:

```bash filename=".env"
GOOGLE_MODELS=gemini-4-argon,gemini-3.8-flash,gemini-3.7-flash,gemini-3.6-flash,gemini-3.5-flash,gemini-3.5-flash-lite,gemini-3.1-pro-preview,gemini-3.1-pro-preview-customtools,gemini-3.1-flash-lite-preview,gemini-2.5-pro,gemini-2.5-flash,gemini-2.5-flash-lite,gemini-2.0-flash,gemini-2.0-flash-lite
```

Je kunt de lijst ook instellen in `librechat.yaml` met `endpoints.google.models`, een array van model-ID's. Een lijst die daar is geconfigureerd, vervangt `GOOGLE_MODELS`. Deze wordt gelezen uit de configuratie die voor elk verzoek wordt bepaald, zodat een configuratie-override die op een rol of groep is toegepast, deze lijst voor die gebruikers kan beperken.

<Callout type="note" title="Opmerkingen:">

- Gemini 3.8 Flash, Gemini 3.7 Flash, Gemini 3.6 Flash, Gemini 3.5 Flash en Gemini 3.5 Flash-Lite worden ondersteund via zowel Google AI Studio als het Google Cloud Gemini Enterprise Agent Platform. LibreChat wijst aan elk een contextvenster van 1.048.576 tokens toe; Gemini 3.8 Flash ondersteunt tot 65.536 output-tokens.
- LibreChat stelt voor Gemini 3.8 Flash, Gemini 3.7 Flash, Gemini 3.6 Flash en Gemini 3.5 Flash standaard `MEDIUM` thinking in, en voor Gemini 3.5 Flash-Lite `MINIMAL`. Gemini 3.8 en 3.7 Flash wijzen `MINIMAL` af, dus LibreChat vervangt dit door `LOW` wanneer dat niveau wordt aangevraagd; andere ondersteunde expliciete `thinkingLevel` waarden blijven behouden.
- Voor deze modellen verwijdert LibreChat niet-ondersteunde sampling- en penalty-parameters (`temperature`, `topP`, `topK`, `presencePenalty` en `frequencyPenalty`), negeert het de oudere numerieke `thinkingBudget` en gebruikt het in plaats daarvan `thinkingLevel`.
- Gemini Flash-modellen vanaf 3.6 ondersteunen geen assistant prefill. LibreChat voorkomt dat bewerkte assistant-antwoorden opnieuw worden ingediend als een niet-ondersteunde trailing model-role turn.
- Ingebouwde kostenramingen gebruiken de Gemini 3.6/3.7/3.8 Flash introductietarieven tot en met 31 december 2026: $0,75 input, $3,75 output en $0,075 gecachte input per miljoen tokens. Vanaf 1 januari 2027 zijn de tarieven respectievelijk $1,50, $7,50 en $0,15.
- Met het Google endpoint kun je niet tegelijkertijd Vertex AI en de Generative Language API gebruiken. Je moet kiezen voor de een of de ander.

</Callout>

## URL Context [#url-context]

De URL Context-tool van Google stelt ondersteunde Gemini-modellen in staat om URL's te lezen die zijn opgenomen in het gebruikersbericht, zoals webpagina's, afbeeldingen en PDF's. Schakel dit in LibreChat in met de Google endpoint-parameter `url_context`.

```yaml filename="modelSpecs / list / preset"
preset:
  endpoint: google
  model: gemini-2.5-flash
  url_context: true
```

Je kunt het ook inschakelen voor een custom endpoint in Google-stijl met `addParams` of parameter-standaardwaarden:

```yaml filename="endpoints / custom"
custom:
  - name: 'Google Gateway'
    apiKey: '${GOOGLE_KEY}'
    baseURL: 'https://gateway.example.com/v1'
    models:
      default: ['gemini-2.5-flash']
    customParams:
      defaultParamsEndpoint: google
    addParams:
      url_context: true
```

`url_context` is beschikbaar op ondersteunde Gemini-tekstmodellen, inclusief Gemini 2.5+ en Gemini 3.x-modellen. YouTube-links worden afzonderlijk afgehandeld met de eigen videobegrip-functionaliteit van Gemini wanneer `url_context` is ingeschakeld, omdat de URL Context-tool van Google YouTube-URL's niet rechtstreeks ondersteunt.

## Vertex AI [#vertex-ai]

**[Zie hier voor prijzen en limieten van de Vertex API](https://cloud.google.com/vertex-ai/generative-ai/pricing)**

Om Google LLM's in te stellen (via Google Cloud Vertex AI), moet je je eerst aanmelden voor Google Cloud: **[cloud.google.com](https://cloud.google.com/)**

Je kunt meestal **$300 aan starttegoed** krijgen, waardoor deze optie 90 dagen lang gratis is.

1. Zodra je bent aangemeld, schakel je de Vertex AI API in op Google Cloud:
   - Ga naar de **[Vertex AI-pagina in de Google Cloud console](https://console.cloud.google.com/vertex-ai)**
   - Klik op `Enable API` indien daarom gevraagd
2. Maak een Service Account aan met de Vertex AI-rol:
   - **[Klik hier om een Service Account aan te maken](https://console.cloud.google.com/projectselector/iam-admin/serviceaccounts/create?walkthrough_id=iam--create-service-account#step_index=1)**
   - **Selecteer of maak een project**
   - Voer een service account ID in (verplicht), naam en beschrijving zijn optioneel
     - ![image](https://github.com/danny-avila/LibreChat/assets/110412045/0c5cd177-029b-44fa-a398-a794aeb09de6)
   - Klik op "Create and Continue" om ten minste de rol "Vertex AI User" toe te wijzen
     - ![image](https://github.com/danny-avila/LibreChat/assets/110412045/22d3a080-e71e-446e-8485-bcc5bf558dbb)
   - **Klik op "Continue/Done"**
3. Maak een JSON-sleutel aan om op te slaan in uw projectmap:
   - **Ga terug naar [de Service Accounts pagina](https://console.cloud.google.com/projectselector/iam-admin/serviceaccounts)**
   - **Selecteer uw serviceaccount**
   - Klik op "Keys"
     - ![image](https://github.com/danny-avila/LibreChat/assets/110412045/735a7bbe-25a6-4b4c-9bb5-e0d8aa91be3d)
   - Klik op "Add Key" en vervolgens op "Create new key"
     - ![image](https://github.com/danny-avila/LibreChat/assets/110412045/cfbb20d3-94a8-4cd1-ac39-f9cd8c2fceaa)
   - **Kies JSON als het sleuteltype en klik op "Create"**
   - **Download het sleutelbestand en hernoem het naar 'auth.json'**
   - **Sla het op in de projectmap, in `/api/data/`**
     - ![image](https://github.com/danny-avila/LibreChat/assets/110412045/f5b8bcb5-1b20-4751-81a1-d3757a4b3f2f)

<Callout type="info" title="Alternatief: GOOGLE_SERVICE_KEY_FILE gebruiken">
  In plaats van het sleutelbestand op te slaan in `/api/data/auth.json`, kun je de `GOOGLE_SERVICE_KEY_FILE` omgevingsvariabele gebruiken om het pad naar je serviceaccount-sleutelbestand op te geven. Dit biedt meer flexibiliteit in hoe je je inloggegevens beheert. Zie de sectie over omgevingsvariabelen hieronder voor meer details.
</Callout>

**Het opslaan van je JSON-sleutelbestand in de projectmap, waardoor alle gebruikers van je LibreChat-instantie het kunnen gebruiken.**

Als alternatief kun je gebruikers dit laten opgeven vanuit de frontend door het volgende in te stellen:

```bash filename=".env"
# Note: this configures both the Vertex AI Service Account JSON key file
# and the Generative Language API key to be provided from the frontend.
GOOGLE_KEY=user_provided
```

Je kunt het service account key-bestand ook opgeven met de `GOOGLE_SERVICE_KEY_FILE` omgevingsvariabele:

```bash filename=".env"
# Path to the service account JSON key file
GOOGLE_SERVICE_KEY_FILE=/path/to/auth.json

# Or provide as a URL
GOOGLE_SERVICE_KEY_FILE=https://example.com/path/to/auth.json

# Or provide as stringified JSON
GOOGLE_SERVICE_KEY_FILE='{"type":"service_account","project_id":"your-project",...}'

# Or provide as base64 encoded JSON
GOOGLE_SERVICE_KEY_FILE=eyJ0eXBlIjogInNlcnZpY2VfYWNjb3VudCIsICJwcm9qZWN0X2lkIjogInlvdXItcHJvamVjdC1pZCIsIC4uLn0=
```

Dit is bijzonder nuttig voor functies die Vertex AI-authenticatie vereisen, zoals OCR-mogelijkheden.

Je kunt ook de Google Cloud-locatie opgeven voor Vertex AI API-verzoeken:

```bash filename=".env"
# Google Cloud region for Vertex AI (defaults to us-central1)
# The multi-region locations us, eu, and global are also accepted.
GOOGLE_LOC=us-central1

# Alternative region for Gemini Image Generation (defaults to global)
GOOGLE_CLOUD_LOCATION=global
```

Aangezien het ophalen van de modellenlijst nog niet wordt ondersteund, moet je de modellen die je wilt gebruiken instellen in het .env bestand.

Voor Vertex AI, gebruik de Vertex model-ID's waar deze afwijken van de Gemini API:

```bash filename=".env"
GOOGLE_MODELS=gemini-4-argon,gemini-3.8-flash,gemini-3.7-flash,gemini-3.6-flash,gemini-3.5-flash,gemini-3.5-flash-lite,gemini-3.1-pro-preview,gemini-3.1-pro-preview-customtools,gemini-3.1-flash-lite-preview,gemini-2.5-pro,gemini-2.5-flash,gemini-2.5-flash-lite,gemini-2.0-flash-001,gemini-2.0-flash-lite-001
```

Op Vertex AI wordt `gemini-4-argon` alleen aangeboden via de multi-regionale endpoints `global`, `us` en `eu`, niet via regionale locaties zoals `us-central1`. Wanneer `GOOGLE_LOC` niet is ingesteld, gebruikt LibreChat `global` voor dit model. Als `GOOGLE_LOC` is ingesteld op een `us-`- of `europe-`-regio, verplaatst LibreChat het verzoek naar de `us`- of `eu`-multi-regio, zodat de gegevens in dezelfde geografie blijven. Een regio buiten `us` en `eu` blijft behouden zoals geconfigureerd, en het verzoek mislukt tenzij u `GOOGLE_LOC` instelt op `global`, `us` of `eu`.

Opgeslagen Agents die de `vertexai` provider gebruiken, maken ook gebruik van deze gedeelde Google-modelcatalogus in de Agent Builder en tijdens runtime. Als de implementatie een expliciete `vertexai` modelcatalogus levert, krijgt die provider-specifieke lijst voorrang; anders wordt `GOOGLE_MODELS` gebruikt voor Vertex AI-selectie en -validatie.

<Callout type="note" title="Als je Docker gebruikt">
Als je Docker gebruikt en het `auth.json` bestand wilt aanleveren, moet je ook de volume mounten in docker-compose.override.yml

```yaml filename="docker-compose.override.yml"
services:
  api:
    volumes:
      - type: bind
        source: ./api/data/auth.json
        target: /app/api/data/auth.json
```

</Callout>

## Google Safety Settings [#google-safety-settings]

Om veiligheidsinstellingen in te stellen voor zowel Vertex AI als de Generative Language API, kun je het volgende instellen in je .env bestand:

```bash filename=".env"
GOOGLE_SAFETY_SEXUALLY_EXPLICIT=BLOCK_ONLY_HIGH
GOOGLE_SAFETY_HATE_SPEECH=BLOCK_ONLY_HIGH
GOOGLE_SAFETY_HARASSMENT=BLOCK_ONLY_HIGH
GOOGLE_SAFETY_DANGEROUS_CONTENT=BLOCK_ONLY_HIGH
GOOGLE_SAFETY_CIVIC_INTEGRITY=BLOCK_ONLY_HIGH
```

Je kunt veiligheidsinstellingen ook uitsluiten door het volgende in je .env bestand in te stellen, waardoor de standaardinstellingen van de provider worden gebruikt. Dit kan nuttig zijn als je problemen ondervindt met specifieke veiligheidsinstellingen.

```bash filename=".env"
GOOGLE_EXCLUDE_SAFETY_SETTINGS=true
```

Categorieën die u niet instelt, worden verzonden met de drempelwaarde `HARM_BLOCK_THRESHOLD_UNSPECIFIED`, waardoor de standaardinstelling van de provider behouden blijft. De uitzondering is `GOOGLE_SAFETY_CIVIC_INTEGRITY`, die standaard `BLOCK_NONE` is wanneer deze niet is ingesteld.

OPMERKING: Uw Google-account heeft standaard geen toegang tot de instelling `BLOCK_NONE`. Verzoeken kunnen daarom worden geweigerd als deze waarde wordt verzonden (bijvoorbeeld via de standaardinstelling voor civic integrity). Stel in dat geval `GOOGLE_SAFETY_CIVIC_INTEGRITY` in op een andere drempelwaarde, of stel `GOOGLE_EXCLUDE_SAFETY_SETTINGS=true` in.
Om deze beperkte `HarmBlockThreshold`-instelling te gebruiken, moet u een van de volgende stappen uitvoeren:

- (a) Krijg toegang via een allowlist via je Google-accountteam
- (b) Wijzig uw accounttype naar maandelijkse facturering door deze instructie te volgen:
  https://cloud.google.com/billing/docs/how-to/invoiced-billing

**Opmerkingen:**

- Het Google endpoint ondersteunt alle [Shared Endpoint Settings](/docs/configuration/librechat_yaml/object_structure/shared_endpoint_settings) via het `librechat.yaml` configuratiebestand, inclusief `streamRate`, `headers`, `titleModel`, `titleMethod`, `titlePrompt`, `titlePromptTemplate` en `titleEndpoint`.
