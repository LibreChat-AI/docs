- Crea un account su **[https://platform.claude.com/](https://platform.claude.com/)**
- Vai su **[https://platform.claude.com/settings/keys](https://platform.claude.com/settings/keys)** e ottieni la tua api key
- Dovrai impostare la seguente variabile d'ambiente con la tua chiave, oppure puoi impostarla su `user_provided` per consentire agli utenti di fornire la propria.

```bash filename=".env"
ANTHROPIC_API_KEY=user_provided
```

- Puoi determinare quali modelli desideri rendere disponibili con `ANTHROPIC_MODELS`.

```bash filename=".env"
ANTHROPIC_MODELS=claude-fable-5-1,claude-fable-5,claude-opus-5-5,claude-opus-5,claude-sonnet-5-5,claude-opus-4-8,claude-opus-4-7,claude-sonnet-5,claude-sonnet-4-6,claude-haiku-5-5,claude-opus-4-6,claude-opus-4-20250514,claude-3-7-sonnet-20250219,claude-3-5-sonnet-20241022,claude-3-5-haiku-20241022
```

Puoi anche impostare l'elenco in `librechat.yaml` con `endpoints.anthropic.models`, un array di ID dei modelli. Un elenco configurato lì sostituisce `ANTHROPIC_MODELS`. Viene letto dalla configurazione risolta per ogni richiesta, quindi un override di configurazione applicato a un ruolo o a un gruppo può restringerlo per quegli utenti.

**Note:**

- Claude Opus 5.5 (`claude-opus-5-5`), Claude Sonnet 5.5 (`claude-sonnet-5-5`) e Claude Haiku 5.5 (`claude-haiku-5-5`) fanno parte del catalogo predefinito dei modelli Anthropic di LibreChat. A Haiku 5.5 è assegnata una finestra di contesto di 1M di token.

- Claude Fable 5.1 e Fable 5 sono inclusi nel catalogo dei modelli Anthropic predefiniti di LibreChat. I modelli di classe Fable/Mythos utilizzano il profilo Anthropic moderno in LibreChat: 1M di contesto, 128K di output massimo, adaptive thinking, prompt caching e supporto `thinkingDisplay` per l'output di ragionamento riassunto o omesso. Fable 5.1 mantiene le tariffe di Fable 5 di $10 per l'input e $50 per l'output per milione di token, con $12,50 per le scritture in cache e $0,25 per le letture in cache.
- Claude Opus 5 è disponibile tramite Anthropic diretto, Anthropic su Vertex AI e AWS Bedrock. Dispone di una finestra di contesto da 1M di token e un output massimo di 128K token. L'Adaptive thinking è abilitato a meno che non venga esplicitamente disabilitato; quando disabilitato, LibreChat limita lo sforzo `xhigh` o `max` a `high` per mantenere valide le richieste.
- Claude Sonnet 3.5 è disponibile tramite Anthropic diretto, Anthropic su Vertex AI e AWS Bedrock. LibreChat gli assegna una finestra di contesto di 1M di token e un output massimo di 128K token, utilizza il pensiero adattivo con visualizzazione riassunta quando il pensiero è abilitato e invia un'impostazione di disabilitazione esplicita quando un utente disattiva il pensiero.
- I controlli nativi della cache dei prompt di Anthropic e il rilevamento del contesto da 1M valutano direttamente l'ID del modello Claude configurato. Gli ID compatibili di Sonnet e Opus alla versione 4.6 o successiva, inclusi gli ID corrispondenti di versioni successive, mantengono tali controlli senza attendere una voce di catalogo esatta. I modelli non supportati mantengono i controlli della cache dei prompt nascosti nell'Agent Builder.
- L'endpoint Anthropic supporta tutte le [Shared Endpoint Settings](/docs/configuration/librechat_yaml/object_structure/shared_endpoint_settings) tramite il file di configurazione `librechat.yaml`, inclusi `streamRate`, `headers`, `titleModel`, `titleMethod`, `titlePrompt`, `titlePromptTemplate` e `titleEndpoint`
- Per configurare Anthropic o un gateway compatibile con Anthropic come endpoint personalizzato separato, utilizza [`provider: "anthropic"`](/docs/configuration/librechat_yaml/object_structure/custom_endpoint#provider).

## Vertex AI [#vertex-ai]

LibreChat supporta l'esecuzione dei modelli Anthropic Claude tramite **Google Cloud Vertex AI**. Questo è utile se:

- Hai già un'infrastruttura Google Cloud
- Vuoi utilizzare la tua fatturazione e le tue credenziali GCP esistenti
- È necessario rispettare i requisiti regionali di residenza dei dati

### Configurazione rapida (Variabili d'ambiente) [#quick-setup-environment-variables]

Imposta le seguenti variabili d'ambiente per abilitare Anthropic tramite Vertex AI:

```bash filename=".env"
# Enable Vertex AI mode for Anthropic
ANTHROPIC_USE_VERTEX=true

# Vertex AI region (optional, defaults to 'us-east5')
# Modern models such as Fable 5.1 and Opus 5 require global, us, or eu.
# Specific regions serve Sonnet 4.6 and earlier.
ANTHROPIC_VERTEX_REGION=global

# Path to Google service account key file (optional)
# If not specified, uses default path: api/data/auth.json
GOOGLE_SERVICE_KEY_FILE=/path/to/service-account.json

# Google Cloud project ID (optional)
# Takes priority over the project_id in the service account key file.
# A project ID set in librechat.yaml (endpoints.anthropic.vertex) takes priority over both.
VERTEX_PROJECT_ID=your-project-id
```

### Prerequisiti [#prerequisites]

1. **Google Cloud Project** con Vertex AI API abilitata
2. **Service Account** con i seguenti ruoli:
   - `Vertex AI User` (`roles/aiplatform.user`)
   - O `Vertex AI Administrator` per l'accesso completo
3. Modelli **Claude** abilitati nel tuo Vertex AI Model Garden
4. **Service Account Key** (file JSON) scaricata e accessibile a LibreChat

### Configurazione Avanzata [#advanced-configuration]

Per la mappatura dei nomi dei modelli e le impostazioni avanzate (simili alla configurazione di Azure OpenAI), utilizza il file `librechat.yaml`:

```yaml filename="librechat.yaml"
endpoints:
  anthropic:
    vertex:
      region: global
      models:
        claude-fable-5-1:
          deploymentName: claude-fable-5-1
        claude-opus-5:
          deploymentName: claude-opus-5
        claude-opus-5-5:
          deploymentName: claude-opus-5-5
        claude-sonnet-5-5:
          deploymentName: claude-sonnet-5-5
        claude-haiku-5-5:
          deploymentName: claude-haiku-5-5
        claude-sonnet-5:
          deploymentName: claude-sonnet-5
        claude-3.5-haiku:
          deploymentName: claude-3-5-haiku@20241022
```

Per opzioni di configurazione YAML dettagliate, consulta [Anthropic Vertex AI Configuration](/docs/configuration/librechat_yaml/object_structure/anthropic_vertex).
