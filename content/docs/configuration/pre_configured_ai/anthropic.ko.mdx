- **[https://platform.claude.com/](https://platform.claude.com/)**에서 계정을 만드세요.
- **[https://platform.claude.com/settings/keys](https://platform.claude.com/settings/keys)**로 이동하여 api key를 받으세요.
- 다음 환경 변수를 귀하의 키로 설정해야 하며, 사용자가 직접 키를 제공하도록 하려면 `user_provided`로 설정할 수 있습니다.

```bash filename=".env"
ANTHROPIC_API_KEY=user_provided
```

- `ANTHROPIC_MODELS`를 사용하여 사용 가능한 모델을 결정할 수 있습니다.

```bash filename=".env"
ANTHROPIC_MODELS=claude-fable-5-1,claude-fable-5,claude-opus-5-5,claude-opus-5,claude-sonnet-5-5,claude-opus-4-8,claude-opus-4-7,claude-sonnet-5,claude-sonnet-4-6,claude-haiku-5-5,claude-opus-4-6,claude-opus-4-20250514,claude-3-7-sonnet-20250219,claude-3-5-sonnet-20241022,claude-3-5-haiku-20241022
```

`librechat.yaml`에서 `endpoints.anthropic.models`를 사용해 목록을 설정할 수도 있으며, 이는 모델 ID의 배열입니다. 여기에 설정된 목록은 `ANTHROPIC_MODELS`를 대체합니다. 이 값은 각 요청에 대해 확인된 구성에서 읽히므로, 역할이나 그룹에 적용된 구성 재정의를 통해 해당 사용자에게 표시되는 목록을 좁힐 수 있습니다.

**참고:**

- Claude Opus 5.5 (`claude-opus-5-5`), Claude Sonnet 5.5 (`claude-sonnet-5-5`), 그리고 Claude Haiku 5.5 (`claude-haiku-5-5`)는 LibreChat의 기본 Anthropic 모델 카탈로그에 포함되어 있습니다. Haiku 5.5에는 1M 토큰 컨텍스트 윈도우가 할당되어 있습니다.

- Claude Fable 5.1 및 Fable 5는 LibreChat의 기본 Anthropic 모델 카탈로그에 포함되어 있습니다. Fable/Mythos 클래스 모델은 LibreChat에서 최신 Anthropic 프로필을 사용합니다: 1M 컨텍스트, 128K 최대 출력, 적응형 사고(adaptive thinking), 프롬프트 캐싱, 그리고 요약되거나 생략된 추론 출력을 위한 `thinkingDisplay` 지원이 포함됩니다. Fable 5.1은 Fable 5의 백만 토큰당 입력 $10, 출력 $50 요금 체계를 유지하며, 캐시 쓰기는 $12.50, 캐시 읽기는 $0.25입니다.
- Claude Opus 5는 직접적인 Anthropic, Vertex AI의 Anthropic, 그리고 AWS Bedrock을 통해 사용할 수 있습니다. 1M 토큰의 컨텍스트 윈도우와 128K 토큰의 최대 출력 제한을 가집니다. 적응형 사고(Adaptive thinking)는 명시적으로 비활성화하지 않는 한 활성화됩니다. 비활성화된 경우, LibreChat은 요청을 유효하게 유지하기 위해 `xhigh` 또는 `max` 노력을 `high`로 제한합니다.
- Claude Sonnet 3.5은 직접적인 Anthropic, Vertex AI의 Anthropic, 그리고 AWS Bedrock을 통해 사용할 수 있습니다. LibreChat은 이 모델에 1M 토큰의 컨텍스트 윈도우와 128K 토큰의 최대 출력 제한을 할당하며, thinking이 활성화된 경우 요약된 표시와 함께 적응형 thinking을 사용하고, 사용자가 thinking을 끄면 명시적으로 비활성화 설정을 전송합니다.
- 네이티브 Anthropic 프롬프트 캐시(prompt-cache) 제어 및 1M 컨텍스트 감지 기능은 구성된 Claude 모델 ID를 직접 평가합니다. 버전 4.6 이상인 호환 가능한 Sonnet 및 Opus ID(이후 버전 ID와 일치하는 경우 포함)는 정확한 카탈로그 항목을 기다릴 필요 없이 해당 제어 기능을 유지합니다. 지원되지 않는 모델의 경우 Agent Builder에서 프롬프트 캐시 제어 기능이 숨겨집니다.
- Anthropic endpoint는 `librechat.yaml` 구성 파일을 통해 [Shared Endpoint Settings](/docs/configuration/librechat_yaml/object_structure/shared_endpoint_settings)의 모든 설정을 지원하며, 여기에는 `streamRate`, `headers`, `titleModel`, `titleMethod`, `titlePrompt`, `titlePromptTemplate` 및 `titleEndpoint`가 포함됩니다.
- Anthropic 또는 Anthropic 호환 게이트웨이를 별도의 사용자 지정 endpoint로 구성하려면 [`provider: "anthropic"`](/docs/configuration/librechat_yaml/object_structure/custom_endpoint#provider)를 사용하세요.

## Vertex AI [#vertex-ai]

LibreChat은 **Google Cloud Vertex AI**를 통해 Anthropic Claude 모델을 실행하는 것을 지원합니다. 이는 다음과 같은 경우에 유용합니다:

- 이미 Google Cloud 인프라를 보유하고 있는 경우
- 기존 GCP 결제 및 자격 증명을 사용하고 싶으신가요?
- 지역 데이터 보존 요구 사항을 준수해야 함

### 빠른 설정 (환경 변수) [#quick-setup-environment-variables]

Vertex AI를 통해 Anthropic을 활성화하려면 다음 환경 변수를 설정하세요:

```bash filename=".env"
# Enable Vertex AI mode for Anthropic
ANTHROPIC_USE_VERTEX=true

# Vertex AI region (optional, defaults to 'us-east5')
# Modern models such as Fable 5.1 and Opus 5 require global, us, or eu.
# Specific regions serve Sonnet 4.6 and earlier.
ANTHROPIC_VERTEX_REGION=global

# Path to Google service account key file (optional)
# If not specified, uses default path: api/data/auth.json
GOOGLE_SERVICE_KEY_FILE=/path/to/service-account.json

# Google Cloud project ID (optional)
# Takes priority over the project_id in the service account key file.
# A project ID set in librechat.yaml (endpoints.anthropic.vertex) takes priority over both.
VERTEX_PROJECT_ID=your-project-id
```

### 필수 조건 [#prerequisites]

1. Vertex AI API가 활성화된 **Google Cloud Project**
2. 다음 역할을 가진 **Service Account**:
   - `Vertex AI User` (`roles/aiplatform.user`)
   - 또는 전체 액세스 권한을 위해 `Vertex AI Administrator`
3. Vertex AI Model Garden에서 활성화된 **Claude models**
4. **Service Account Key** (JSON 파일)가 다운로드되어 LibreChat에서 액세스할 수 있어야 합니다.

### 고급 구성 [#advanced-configuration]

모델 이름 매핑 및 고급 설정(Azure OpenAI 구성과 유사)을 위해서는 `librechat.yaml` 파일을 사용하세요:

```yaml filename="librechat.yaml"
endpoints:
  anthropic:
    vertex:
      region: global
      models:
        claude-fable-5-1:
          deploymentName: claude-fable-5-1
        claude-opus-5:
          deploymentName: claude-opus-5
        claude-opus-5-5:
          deploymentName: claude-opus-5-5
        claude-sonnet-5-5:
          deploymentName: claude-sonnet-5-5
        claude-haiku-5-5:
          deploymentName: claude-haiku-5-5
        claude-sonnet-5:
          deploymentName: claude-sonnet-5
        claude-3.5-haiku:
          deploymentName: claude-3-5-haiku@20241022
```

자세한 YAML 구성 옵션은 [Anthropic Vertex AI Configuration](/docs/configuration/librechat_yaml/object_structure/anthropic_vertex)을 참조하세요.
