- Maak een account aan op **[https://platform.claude.com/](https://platform.claude.com/)**
- Ga naar **[https://platform.claude.com/settings/keys](https://platform.claude.com/settings/keys)** en haal je api key op
- Je zult de volgende omgevingsvariabele moeten instellen op jouw sleutel, of je kunt deze instellen op `user_provided` zodat gebruikers hun eigen sleutel kunnen opgeven.

```bash filename=".env"
ANTHROPIC_API_KEY=user_provided
```

- Je kunt bepalen welke modellen je beschikbaar wilt hebben met `ANTHROPIC_MODELS`.

```bash filename=".env"
ANTHROPIC_MODELS=claude-fable-5-1,claude-fable-5,claude-opus-5-5,claude-opus-5,claude-sonnet-5-5,claude-opus-4-8,claude-opus-4-7,claude-sonnet-5,claude-sonnet-4-6,claude-haiku-5-5,claude-opus-4-6,claude-opus-4-20250514,claude-3-7-sonnet-20250219,claude-3-5-sonnet-20241022,claude-3-5-haiku-20241022
```

Je kunt de lijst ook instellen in `librechat.yaml` met `endpoints.anthropic.models`, een array met model-ID's. Een lijst die daar is geconfigureerd, vervangt `ANTHROPIC_MODELS`. Deze wordt gelezen uit de configuratie die voor elk verzoek is bepaald, dus een configuratieoverride die op een rol of groep wordt toegepast, kan de lijst voor die gebruikers beperken.

**Opmerkingen:**

- Claude Opus 5.5 (`claude-opus-5-5`), Claude Sonnet 5.5 (`claude-sonnet-5-5`), en Claude Haiku 5.5 (`claude-haiku-5-5`) maken deel uit van de standaard Anthropic-modelcatalogus van LibreChat. Aan Haiku 5.5 is een contextvenster van 1M tokens toegewezen.

- Claude Fable 5.1 en Fable 5 zijn opgenomen in de standaard Anthropic modelcatalogus van LibreChat. Fable/Mythos-klasse modellen gebruiken het moderne Anthropic profiel in LibreChat: 1M context, 128K max output, adaptief denken, prompt caching en `thinkingDisplay` ondersteuning voor samengevatte of weggelaten redeneeroutput. Fable 5.1 behoudt de tarieven van Fable 5 van $10 voor input en $50 voor output per miljoen tokens, met $12,50 voor cache-writes en $0,25 voor cache-reads.
- Claude Opus 5 is beschikbaar via direct Anthropic, Anthropic on Vertex AI en AWS Bedrock. Het heeft een contextvenster van 1M tokens en een maximale output van 128K tokens. Adaptive thinking is ingeschakeld, tenzij expliciet uitgeschakeld; wanneer uitgeschakeld, beperkt LibreChat `xhigh` of `max` effort tot `high` om verzoeken geldig te houden.
- Claude Sonnet 3.5 is beschikbaar via direct Anthropic, Anthropic op Vertex AI en AWS Bedrock. LibreChat wijst er een contextvenster van 1M tokens en een maximale output van 128K tokens aan toe, gebruikt adaptief denken met een samengevatte weergave wanneer denken is ingeschakeld, en verstuurt een expliciete uitgeschakelde instelling wanneer een gebruiker denken uitschakelt.
- Native Anthropic prompt-cache controls en 1M-context detectie evalueren het geconfigureerde Claude model ID direct. Compatibele Sonnet en Opus ID's op versie 4.6 of later, inclusief overeenkomende ID's van latere versies, behouden die controls zonder te wachten op een exacte catalogusvermelding. Niet-ondersteunde modellen houden prompt-cache controls verborgen in de Agent Builder.
- Het Anthropic endpoint ondersteunt alle [Shared Endpoint Settings](/docs/configuration/librechat_yaml/object_structure/shared_endpoint_settings) via het `librechat.yaml` configuratiebestand, inclusief `streamRate`, `headers`, `titleModel`, `titleMethod`, `titlePrompt`, `titlePromptTemplate` en `titleEndpoint`.
- Om Anthropic of een Anthropic-compatibele gateway als een apart aangepast endpoint te configureren, gebruik [`provider: "anthropic"`](/docs/configuration/librechat_yaml/object_structure/custom_endpoint#provider).

## Vertex AI [#vertex-ai]

LibreChat ondersteunt het draaien van Anthropic Claude-modellen via **Google Cloud Vertex AI**. Dit is nuttig als je:

- Heb je al Google Cloud-infrastructuur
- Wil je je bestaande GCP-facturering en -inloggegevens gebruiken
- Moet voldoen aan regionale vereisten voor gegevensresidentie

### Snelle installatie (omgevingsvariabelen) [#quick-setup-environment-variables]

Stel de volgende omgevingsvariabelen in om Anthropic via Vertex AI in te schakelen:

```bash filename=".env"
# Enable Vertex AI mode for Anthropic
ANTHROPIC_USE_VERTEX=true

# Vertex AI region (optional, defaults to 'us-east5')
# Modern models such as Fable 5.1 and Opus 5 require global, us, or eu.
# Specific regions serve Sonnet 4.6 and earlier.
ANTHROPIC_VERTEX_REGION=global

# Path to Google service account key file (optional)
# If not specified, uses default path: api/data/auth.json
GOOGLE_SERVICE_KEY_FILE=/path/to/service-account.json

# Google Cloud project ID (optional)
# Takes priority over the project_id in the service account key file.
# A project ID set in librechat.yaml (endpoints.anthropic.vertex) takes priority over both.
VERTEX_PROJECT_ID=your-project-id
```

### Vereisten [#prerequisites]

1. **Google Cloud Project** met Vertex AI API ingeschakeld
2. **Service Account** met de volgende rollen:
   - `Vertex AI User` (`roles/aiplatform.user`)
   - Of `Vertex AI Administrator` voor volledige toegang
3. **Claude modellen** ingeschakeld in je Vertex AI Model Garden
4. **Service Account Key** (JSON-bestand) gedownload en toegankelijk voor LibreChat

### Geavanceerde configuratie [#advanced-configuration]

Voor modelnaam-mapping en geavanceerde instellingen (vergelijkbaar met Azure OpenAI-configuratie), gebruik het `librechat.yaml` bestand:

```yaml filename="librechat.yaml"
endpoints:
  anthropic:
    vertex:
      region: global
      models:
        claude-fable-5-1:
          deploymentName: claude-fable-5-1
        claude-opus-5:
          deploymentName: claude-opus-5
        claude-opus-5-5:
          deploymentName: claude-opus-5-5
        claude-sonnet-5-5:
          deploymentName: claude-sonnet-5-5
        claude-haiku-5-5:
          deploymentName: claude-haiku-5-5
        claude-sonnet-5:
          deploymentName: claude-sonnet-5
        claude-3.5-haiku:
          deploymentName: claude-3-5-haiku@20241022
```

Voor gedetailleerde YAML-configuratieopties, zie [Anthropic Vertex AI Configuration](/docs/configuration/librechat_yaml/object_structure/anthropic_vertex).
