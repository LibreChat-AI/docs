- Crie uma conta em **[https://platform.claude.com/](https://platform.claude.com/)**
- Vá para **[https://platform.claude.com/settings/keys](https://platform.claude.com/settings/keys)** e obtenha sua api key
- Você precisará definir a seguinte variável de ambiente com sua chave ou pode defini-la como `user_provided` para que os usuários forneçam a deles.

```bash filename=".env"
ANTHROPIC_API_KEY=user_provided
```

- Você pode determinar quais modelos deseja disponibilizar com `ANTHROPIC_MODELS`.

```bash filename=".env"
ANTHROPIC_MODELS=claude-fable-5-1,claude-fable-5,claude-opus-5-5,claude-opus-5,claude-sonnet-5-5,claude-opus-4-8,claude-opus-4-7,claude-sonnet-5,claude-sonnet-4-6,claude-haiku-5-5,claude-opus-4-6,claude-opus-4-20250514,claude-3-7-sonnet-20250219,claude-3-5-sonnet-20241022,claude-3-5-haiku-20241022
```

Você também pode definir a lista no `librechat.yaml` com `endpoints.anthropic.models`, um array de IDs de modelos. Uma lista configurada ali substitui `ANTHROPIC_MODELS`. Ela é lida da configuração resolvida para cada requisição, portanto uma sobrescrita de configuração aplicada a uma função ou grupo pode restringi-la para esses usuários.

**Notas:**

- O Claude Opus 5.5 (`claude-opus-5-5`), o Claude Sonnet 5.5 (`claude-sonnet-5-5`) e o Claude Haiku 5.5 (`claude-haiku-5-5`) fazem parte do catálogo padrão de modelos da Anthropic do LibreChat. Ao Haiku 5.5 é atribuída uma janela de contexto de 1M de tokens.

- Claude Fable 5.1 e Fable 5 estão incluídos no catálogo de modelos Anthropic padrão do LibreChat. Os modelos da classe Fable/Mythos utilizam o perfil Anthropic moderno no LibreChat: 1M de contexto, 128K de saída máxima, raciocínio adaptativo, cache de prompt e suporte a `thinkingDisplay` para saída de raciocínio resumida ou omitida. O Fable 5.1 mantém as taxas do Fable 5 de US$ 10 de entrada e US$ 50 de saída por milhão de tokens, com US$ 12,50 para gravações em cache e US$ 0,25 para leituras em cache.
- O Claude Opus 5 está disponível através do Anthropic direto, Anthropic no Vertex AI e AWS Bedrock. Ele possui uma janela de contexto de 1M de tokens e uma saída máxima de 128K tokens. O pensamento adaptativo (adaptive thinking) está ativado, a menos que seja explicitamente desativado; quando desativado, o LibreChat limita o esforço `xhigh` ou `max` para `high` para manter as solicitações válidas.
- O Claude Sonnet 3.5 está disponível através da Anthropic direta, Anthropic no Vertex AI e AWS Bedrock. O LibreChat atribui a ele uma janela de contexto de 1M de tokens e uma saída máxima de 128K tokens, utiliza raciocínio adaptativo com exibição resumida quando o raciocínio está ativado e envia uma configuração explícita de desativação quando um usuário desliga o raciocínio.
- Os controles nativos de prompt-cache da Anthropic e a detecção de contexto de 1M avaliam o ID do modelo Claude configurado diretamente. IDs compatíveis do Sonnet e Opus na versão 4.6 ou posterior, incluindo IDs de versões posteriores correspondentes, mantêm esses controles sem aguardar uma entrada de catálogo exata. Modelos não suportados mantêm os controles de prompt-cache ocultos no Agent Builder.
- O endpoint Anthropic suporta todas as [Shared Endpoint Settings](/docs/configuration/librechat_yaml/object_structure/shared_endpoint_settings) através do arquivo de configuração `librechat.yaml`, incluindo `streamRate`, `headers`, `titleModel`, `titleMethod`, `titlePrompt`, `titlePromptTemplate` e `titleEndpoint`
- Para configurar a Anthropic ou um gateway compatível com a Anthropic como um endpoint personalizado separado, use [`provider: "anthropic"`](/docs/configuration/librechat_yaml/object_structure/custom_endpoint#provider).

## Vertex AI [#vertex-ai]

O LibreChat oferece suporte para executar modelos Anthropic Claude por meio do **Google Cloud Vertex AI**. Isso é útil se você:

- Já possui infraestrutura no Google Cloud
- Deseja usar seu faturamento e credenciais existentes do GCP
- Necessidade de cumprir com requisitos regionais de residência de dados

### Configuração Rápida (Variáveis de Ambiente) [#quick-setup-environment-variables]

Defina as seguintes variáveis de ambiente para habilitar o Anthropic via Vertex AI:

```bash filename=".env"
# Enable Vertex AI mode for Anthropic
ANTHROPIC_USE_VERTEX=true

# Vertex AI region (optional, defaults to 'us-east5')
# Modern models such as Fable 5.1 and Opus 5 require global, us, or eu.
# Specific regions serve Sonnet 4.6 and earlier.
ANTHROPIC_VERTEX_REGION=global

# Path to Google service account key file (optional)
# If not specified, uses default path: api/data/auth.json
GOOGLE_SERVICE_KEY_FILE=/path/to/service-account.json

# Google Cloud project ID (optional)
# Takes priority over the project_id in the service account key file.
# A project ID set in librechat.yaml (endpoints.anthropic.vertex) takes priority over both.
VERTEX_PROJECT_ID=your-project-id
```

### Pré-requisitos [#prerequisites]

1. **Google Cloud Project** com a Vertex AI API habilitada
2. **Service Account** com as seguintes funções:
   - `Vertex AI User` (`roles/aiplatform.user`)
   - Ou `Vertex AI Administrator` para acesso total
3. Modelos **Claude** habilitados no seu Vertex AI Model Garden
4. **Service Account Key** (arquivo JSON) baixada e acessível ao LibreChat

### Configuração Avançada [#advanced-configuration]

Para mapeamento de nomes de modelos e configurações avançadas (semelhante à configuração do Azure OpenAI), use o arquivo `librechat.yaml`:

```yaml filename="librechat.yaml"
endpoints:
  anthropic:
    vertex:
      region: global
      models:
        claude-fable-5-1:
          deploymentName: claude-fable-5-1
        claude-opus-5:
          deploymentName: claude-opus-5
        claude-opus-5-5:
          deploymentName: claude-opus-5-5
        claude-sonnet-5-5:
          deploymentName: claude-sonnet-5-5
        claude-haiku-5-5:
          deploymentName: claude-haiku-5-5
        claude-sonnet-5:
          deploymentName: claude-sonnet-5
        claude-3.5-haiku:
          deploymentName: claude-3-5-haiku@20241022
```

Para opções detalhadas de configuração YAML, veja [Configuração do Anthropic Vertex AI](/docs/configuration/librechat_yaml/object_structure/anthropic_vertex).
