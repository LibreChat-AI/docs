- Créez un compte sur **[https://platform.claude.com/](https://platform.claude.com/)**
- Allez sur **[https://platform.claude.com/settings/keys](https://platform.claude.com/settings/keys)** et obtenez votre clé API
- Vous devrez définir la variable d'environnement suivante avec votre clé, ou vous pouvez la définir sur `user_provided` pour permettre aux utilisateurs de fournir la leur.

```bash filename=".env"
ANTHROPIC_API_KEY=user_provided
```

- Vous pouvez déterminer quels modèles vous souhaitez rendre disponibles avec `ANTHROPIC_MODELS`.

```bash filename=".env"
ANTHROPIC_MODELS=claude-fable-5-1,claude-fable-5,claude-opus-5-5,claude-opus-5,claude-sonnet-5-5,claude-opus-4-8,claude-opus-4-7,claude-sonnet-5,claude-sonnet-4-6,claude-haiku-5-5,claude-opus-4-6,claude-opus-4-20250514,claude-3-7-sonnet-20250219,claude-3-5-sonnet-20241022,claude-3-5-haiku-20241022
```

Vous pouvez également définir la liste dans `librechat.yaml` avec `endpoints.anthropic.models`, un tableau d'identifiants de modèles. Une liste configurée à cet endroit remplace `ANTHROPIC_MODELS`. Elle est lue à partir de la configuration résolue pour chaque requête, de sorte qu'une surcharge de configuration appliquée à un rôle ou à un groupe peut la restreindre pour ces utilisateurs.

**Notes :**

- Claude Opus 5.5 (`claude-opus-5-5`), Claude Sonnet 5.5 (`claude-sonnet-5-5`) et Claude Haiku 5.5 (`claude-haiku-5-5`) font partie du catalogue de modèles Anthropic par défaut de LibreChat. Claude Haiku 5.5 se voit attribuer une fenêtre de contexte de 1M de tokens.

- Claude Fable 5.1 et Fable 5 sont inclus dans le catalogue de modèles Anthropic par défaut de LibreChat. Les modèles de classe Fable/Mythos utilisent le profil Anthropic moderne dans LibreChat : 1M de contexte, 128K de sortie maximale, réflexion adaptative, mise en cache des prompts et prise en charge de `thinkingDisplay` pour une sortie de raisonnement résumée ou omise. Fable 5.1 conserve les tarifs de Fable 5, soit 10 $ en entrée et 50 $ en sortie par million de jetons, avec 12,50 $ pour les écritures en cache et 0,25 $ pour les lectures en cache.
- Claude Opus 5 est disponible via Anthropic direct, Anthropic sur Vertex AI et AWS Bedrock. Il dispose d'une fenêtre de contexte de 1M de jetons et d'une sortie maximale de 128K jetons. La réflexion adaptative (adaptive thinking) est activée sauf si elle est explicitement désactivée ; lorsqu'elle est désactivée, LibreChat limite l'effort `xhigh` ou `max` à `high` pour maintenir la validité des requêtes.
- Claude Sonnet 3.5 est disponible via Anthropic direct, Anthropic sur Vertex AI et AWS Bedrock. LibreChat lui attribue une fenêtre de contexte de 1M de jetons et une sortie maximale de 128K jetons, utilise une réflexion adaptative avec un affichage résumé lorsque la réflexion est activée, et envoie un paramètre de désactivation explicite lorsqu'un utilisateur désactive la réflexion.
- Les contrôles natifs de prompt-cache d'Anthropic et la détection de contexte de 1M évaluent directement l'ID du modèle Claude configuré. Les IDs Sonnet et Opus compatibles en version 4.6 ou ultérieure, y compris les IDs de versions ultérieures correspondants, conservent ces contrôles sans attendre une entrée de catalogue exacte. Les modèles non pris en charge gardent les contrôles de prompt-cache masqués dans l'Agent Builder.
- L'endpoint Anthropic prend en charge tous les [Shared Endpoint Settings](/docs/configuration/librechat_yaml/object_structure/shared_endpoint_settings) via le fichier de configuration `librechat.yaml`, y compris `streamRate`, `headers`, `titleModel`, `titleMethod`, `titlePrompt`, `titlePromptTemplate` et `titleEndpoint`.
- Pour configurer Anthropic ou une passerelle compatible avec Anthropic en tant que point de terminaison personnalisé distinct, utilisez [`provider: "anthropic"`](/docs/configuration/librechat_yaml/object_structure/custom_endpoint#provider).

## Vertex AI [#vertex-ai]

LibreChat prend en charge l'exécution des modèles Anthropic Claude via **Google Cloud Vertex AI**. Ceci est utile si vous :

- Vous disposez déjà d'une infrastructure Google Cloud
- Vous souhaitez utiliser votre facturation et vos identifiants GCP existants
- Besoin de se conformer aux exigences régionales en matière de résidence des données

### Configuration rapide (Variables d'environnement) [#quick-setup-environment-variables]

Définissez les variables d'environnement suivantes pour activer Anthropic via Vertex AI :

```bash filename=".env"
# Enable Vertex AI mode for Anthropic
ANTHROPIC_USE_VERTEX=true

# Vertex AI region (optional, defaults to 'us-east5')
# Modern models such as Fable 5.1 and Opus 5 require global, us, or eu.
# Specific regions serve Sonnet 4.6 and earlier.
ANTHROPIC_VERTEX_REGION=global

# Path to Google service account key file (optional)
# If not specified, uses default path: api/data/auth.json
GOOGLE_SERVICE_KEY_FILE=/path/to/service-account.json

# Google Cloud project ID (optional)
# Takes priority over the project_id in the service account key file.
# A project ID set in librechat.yaml (endpoints.anthropic.vertex) takes priority over both.
VERTEX_PROJECT_ID=your-project-id
```

### Prérequis [#prerequisites]

1. **Google Cloud Project** avec l'API Vertex AI activée
2. **Compte de service** avec les rôles suivants :
   - `Vertex AI User` (`roles/aiplatform.user`)
   - Ou `Vertex AI Administrator` pour un accès complet
3. Modèles **Claude** activés dans votre Vertex AI Model Garden
4. **Clé de compte de service** (fichier JSON) téléchargée et accessible à LibreChat

### Configuration avancée [#advanced-configuration]

Pour le mappage des noms de modèles et les paramètres avancés (similaires à la configuration Azure OpenAI), utilisez le fichier `librechat.yaml` :

```yaml filename="librechat.yaml"
endpoints:
  anthropic:
    vertex:
      region: global
      models:
        claude-fable-5-1:
          deploymentName: claude-fable-5-1
        claude-opus-5:
          deploymentName: claude-opus-5
        claude-opus-5-5:
          deploymentName: claude-opus-5-5
        claude-sonnet-5-5:
          deploymentName: claude-sonnet-5-5
        claude-haiku-5-5:
          deploymentName: claude-haiku-5-5
        claude-sonnet-5:
          deploymentName: claude-sonnet-5
        claude-3.5-haiku:
          deploymentName: claude-3-5-haiku@20241022
```

Pour des options de configuration YAML détaillées, consultez [Configuration Anthropic Vertex AI](/docs/configuration/librechat_yaml/object_structure/anthropic_vertex).
