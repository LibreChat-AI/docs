- Buat akun di **[https://platform.claude.com/](https://platform.claude.com/)**
- Buka **[https://platform.claude.com/settings/keys](https://platform.claude.com/settings/keys)** dan dapatkan api key Anda
- Anda perlu mengatur variabel lingkungan berikut ke kunci Anda atau Anda dapat mengaturnya ke `user_provided` agar pengguna dapat menyediakan kunci mereka sendiri.

```bash filename=".env"
ANTHROPIC_API_KEY=user_provided
```

- Anda dapat menentukan model mana yang ingin Anda sediakan dengan `ANTHROPIC_MODELS`.

```bash filename=".env"
ANTHROPIC_MODELS=claude-fable-5-1,claude-fable-5,claude-opus-5-5,claude-opus-5,claude-sonnet-5-5,claude-opus-4-8,claude-opus-4-7,claude-sonnet-5,claude-sonnet-4-6,claude-haiku-5-5,claude-opus-4-6,claude-opus-4-20250514,claude-3-7-sonnet-20250219,claude-3-5-sonnet-20241022,claude-3-5-haiku-20241022
```

Anda juga dapat mengatur daftar tersebut di `librechat.yaml` dengan `endpoints.anthropic.models`, sebuah array berisi ID model. Daftar yang dikonfigurasi di sana menggantikan `ANTHROPIC_MODELS`. Daftar ini dibaca dari konfigurasi yang diselesaikan untuk setiap permintaan, sehingga override konfigurasi yang diterapkan pada peran atau grup dapat mempersempitnya untuk pengguna tersebut.

**Catatan:**

- Claude Opus 5.5 (`claude-opus-5-5`), Claude Sonnet 5.5 (`claude-sonnet-5-5`), dan Claude Haiku 5.5 (`claude-haiku-5-5`) termasuk dalam katalog model Anthropic default LibreChat. Haiku 5.5 diberi jendela konteks 1M token.

- Claude Fable 5.1 dan Fable 5 disertakan dalam katalog model Anthropic default di LibreChat. Model kelas Fable/Mythos menggunakan profil Anthropic modern di LibreChat: konteks 1M, output maks 128K, *adaptive thinking*, *prompt caching*, dan dukungan `thinkingDisplay` untuk output penalaran yang diringkas atau dihilangkan. Fable 5.1 mempertahankan tarif Fable 5 sebesar $10 untuk input dan $50 untuk output per satu juta token, dengan $12,50 untuk penulisan *cache* dan $0,25 untuk pembacaan *cache*.
- Claude Opus 5 tersedia melalui Anthropic langsung, Anthropic di Vertex AI, dan AWS Bedrock. Model ini memiliki jendela konteks 1M-token dan output maksimum 128K-token. Adaptive thinking diaktifkan kecuali jika dinonaktifkan secara eksplisit; saat dinonaktifkan, LibreChat membatasi `xhigh` atau `max` effort menjadi `high` agar permintaan tetap valid.
- Claude Sonnet 3.5 tersedia melalui Anthropic langsung, Anthropic di Vertex AI, dan AWS Bedrock. LibreChat menetapkan jendela konteks 1M-token dan output maksimum 128K-token, menggunakan adaptive thinking dengan tampilan ringkasan saat thinking diaktifkan, serta mengirimkan pengaturan nonaktif yang eksplisit saat pengguna mematikan thinking.
- Kontrol prompt-cache Anthropic bawaan dan deteksi konteks 1M mengevaluasi ID model Claude yang dikonfigurasi secara langsung. ID Sonnet dan Opus yang kompatibel pada versi 4.6 atau lebih baru, termasuk ID versi terbaru yang cocok, tetap mempertahankan kontrol tersebut tanpa menunggu entri katalog yang tepat. Model yang tidak didukung akan menyembunyikan kontrol prompt-cache di Agent Builder.
- endpoint Anthropic mendukung semua [Shared Endpoint Settings](/docs/configuration/librechat_yaml/object_structure/shared_endpoint_settings) melalui file konfigurasi `librechat.yaml`, termasuk `streamRate`, `headers`, `titleModel`, `titleMethod`, `titlePrompt`, `titlePromptTemplate`, dan `titleEndpoint`
- Untuk mengonfigurasi Anthropic atau gateway yang kompatibel dengan Anthropic sebagai endpoint kustom terpisah, gunakan [`provider: "anthropic"`](/docs/configuration/librechat_yaml/object_structure/custom_endpoint#provider).

## Vertex AI [#vertex-ai]

LibreChat mendukung penggunaan model Anthropic Claude melalui **Google Cloud Vertex AI**. Ini berguna jika Anda:

- Sudah memiliki infrastruktur Google Cloud
- Ingin menggunakan penagihan dan kredensial GCP Anda yang sudah ada
- Perlu mematuhi persyaratan residensi data regional

### Pengaturan Cepat (Variabel Lingkungan) [#quick-setup-environment-variables]

Atur variabel lingkungan berikut untuk mengaktifkan Anthropic melalui Vertex AI:

```bash filename=".env"
# Enable Vertex AI mode for Anthropic
ANTHROPIC_USE_VERTEX=true

# Vertex AI region (optional, defaults to 'us-east5')
# Modern models such as Fable 5.1 and Opus 5 require global, us, or eu.
# Specific regions serve Sonnet 4.6 and earlier.
ANTHROPIC_VERTEX_REGION=global

# Path to Google service account key file (optional)
# If not specified, uses default path: api/data/auth.json
GOOGLE_SERVICE_KEY_FILE=/path/to/service-account.json

# Google Cloud project ID (optional)
# Takes priority over the project_id in the service account key file.
# A project ID set in librechat.yaml (endpoints.anthropic.vertex) takes priority over both.
VERTEX_PROJECT_ID=your-project-id
```

### Prasyarat [#prerequisites]

1. **Google Cloud Project** dengan Vertex AI API diaktifkan
2. **Service Account** dengan peran berikut:
   - `Vertex AI User` (`roles/aiplatform.user`)
   - Atau `Vertex AI Administrator` untuk akses penuh
3. Model **Claude** diaktifkan di Vertex AI Model Garden Anda
4. **Service Account Key** (file JSON) yang telah diunduh dan dapat diakses oleh LibreChat

### Konfigurasi Lanjutan [#advanced-configuration]

Untuk pemetaan nama model dan pengaturan lanjutan (mirip dengan konfigurasi Azure OpenAI), gunakan file `librechat.yaml`:

```yaml filename="librechat.yaml"
endpoints:
  anthropic:
    vertex:
      region: global
      models:
        claude-fable-5-1:
          deploymentName: claude-fable-5-1
        claude-opus-5:
          deploymentName: claude-opus-5
        claude-opus-5-5:
          deploymentName: claude-opus-5-5
        claude-sonnet-5-5:
          deploymentName: claude-sonnet-5-5
        claude-haiku-5-5:
          deploymentName: claude-haiku-5-5
        claude-sonnet-5:
          deploymentName: claude-sonnet-5
        claude-3.5-haiku:
          deploymentName: claude-3-5-haiku@20241022
```

Untuk opsi konfigurasi YAML yang mendetail, lihat [Anthropic Vertex AI Configuration](/docs/configuration/librechat_yaml/object_structure/anthropic_vertex).
