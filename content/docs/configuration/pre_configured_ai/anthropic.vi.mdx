- Tạo tài khoản tại **[https://platform.claude.com/](https://platform.claude.com/)**
- Truy cập **[https://platform.claude.com/settings/keys](https://platform.claude.com/settings/keys)** và lấy api key của bạn
- Bạn sẽ cần đặt biến môi trường sau thành khóa của mình hoặc bạn có thể đặt nó thành `user_provided` để người dùng tự cung cấp khóa của riêng họ.

```bash filename=".env"
ANTHROPIC_API_KEY=user_provided
```

- Bạn có thể xác định những model nào bạn muốn khả dụng với `ANTHROPIC_MODELS`.

```bash filename=".env"
ANTHROPIC_MODELS=claude-fable-5-1,claude-fable-5,claude-opus-5-5,claude-opus-5,claude-sonnet-5-5,claude-opus-4-8,claude-opus-4-7,claude-sonnet-5,claude-sonnet-4-6,claude-haiku-5-5,claude-opus-4-6,claude-opus-4-20250514,claude-3-7-sonnet-20250219,claude-3-5-sonnet-20241022,claude-3-5-haiku-20241022
```

Bạn cũng có thể thiết lập danh sách trong `librechat.yaml` bằng `endpoints.anthropic.models`, một mảng các model ID. Danh sách được cấu hình tại đó sẽ thay thế `ANTHROPIC_MODELS`. Danh sách này được đọc từ cấu hình được xác định cho từng yêu cầu, vì vậy một cấu hình ghi đè áp dụng cho một vai trò hoặc nhóm có thể thu hẹp danh sách đối với những người dùng đó.

**Ghi chú:**

- Claude Opus 5.5 (`claude-opus-5-5`), Claude Sonnet 5.5 (`claude-sonnet-5-5`), và Claude Haiku 5.5 (`claude-haiku-5-5`) là một phần của danh mục mô hình Anthropic mặc định của LibreChat. Haiku 5.5 được gán cửa sổ ngữ cảnh 1M token.

- Claude Fable 5.1 và Fable 5 đã được bao gồm trong danh mục mô hình Anthropic mặc định của LibreChat. Các mô hình thuộc lớp Fable/Mythos sử dụng cấu hình Anthropic hiện đại trong LibreChat: ngữ cảnh 1M, đầu ra tối đa 128K, tư duy thích ứng (adaptive thinking), bộ nhớ đệm prompt (prompt caching) và hỗ trợ `thinkingDisplay` cho đầu ra suy luận được tóm tắt hoặc lược bỏ. Fable 5.1 giữ nguyên mức giá của Fable 5 là $10 cho đầu vào và $50 cho đầu ra trên mỗi triệu token, với $12.50 cho ghi bộ nhớ đệm và $0.25 cho đọc bộ nhớ đệm.
- Claude Opus 5 khả dụng thông qua Anthropic trực tiếp, Anthropic trên Vertex AI và AWS Bedrock. Mô hình này có cửa sổ ngữ cảnh 1M token và đầu ra tối đa 128K token. Adaptive thinking được bật theo mặc định trừ khi bị vô hiệu hóa rõ ràng; khi bị vô hiệu hóa, LibreChat sẽ giới hạn `xhigh` hoặc `max` effort xuống `high` để giữ cho các yêu cầu hợp lệ.
- Claude Sonnet 3.5 hiện đã khả dụng thông qua Anthropic trực tiếp, Anthropic trên Vertex AI và AWS Bedrock. LibreChat gán cho nó cửa sổ ngữ cảnh 1M-token và đầu ra tối đa 128K-token, sử dụng tính năng tư duy thích ứng (adaptive thinking) với hiển thị tóm tắt khi tính năng tư duy được bật, đồng thời gửi cài đặt tắt rõ ràng khi người dùng tắt tính năng tư duy.
- Các điều khiển prompt-cache gốc của Anthropic và tính năng phát hiện ngữ cảnh 1M đánh giá trực tiếp ID mô hình Claude đã được cấu hình. Các ID Sonnet và Opus tương thích ở phiên bản 4.6 trở lên, bao gồm cả các ID phiên bản sau khớp với nhau, sẽ giữ lại các điều khiển đó mà không cần chờ mục danh mục chính xác. Các mô hình không được hỗ trợ sẽ ẩn các điều khiển prompt-cache trong Agent Builder.
- Endpoint Anthropic hỗ trợ tất cả [Shared Endpoint Settings](/docs/configuration/librechat_yaml/object_structure/shared_endpoint_settings) thông qua tệp cấu hình `librechat.yaml`, bao gồm `streamRate`, `headers`, `titleModel`, `titleMethod`, `titlePrompt`, `titlePromptTemplate` và `titleEndpoint`
- Để cấu hình Anthropic hoặc một gateway tương thích với Anthropic làm một endpoint tùy chỉnh riêng biệt, hãy sử dụng [`provider: "anthropic"`](/docs/configuration/librechat_yaml/object_structure/custom_endpoint#provider).

## Vertex AI [#vertex-ai]

LibreChat hỗ trợ chạy các mô hình Anthropic Claude thông qua **Google Cloud Vertex AI**. Điều này hữu ích nếu bạn:

- Đã có sẵn cơ sở hạ tầng Google Cloud
- Bạn muốn sử dụng thông tin thanh toán và thông tin xác thực GCP hiện có của mình
- Cần tuân thủ các yêu cầu về lưu trữ dữ liệu theo khu vực

### Thiết lập nhanh (Biến môi trường) [#quick-setup-environment-variables]

Thiết lập các biến môi trường sau để kích hoạt Anthropic thông qua Vertex AI:

```bash filename=".env"
# Enable Vertex AI mode for Anthropic
ANTHROPIC_USE_VERTEX=true

# Vertex AI region (optional, defaults to 'us-east5')
# Modern models such as Fable 5.1 and Opus 5 require global, us, or eu.
# Specific regions serve Sonnet 4.6 and earlier.
ANTHROPIC_VERTEX_REGION=global

# Path to Google service account key file (optional)
# If not specified, uses default path: api/data/auth.json
GOOGLE_SERVICE_KEY_FILE=/path/to/service-account.json

# Google Cloud project ID (optional)
# Takes priority over the project_id in the service account key file.
# A project ID set in librechat.yaml (endpoints.anthropic.vertex) takes priority over both.
VERTEX_PROJECT_ID=your-project-id
```

### Điều kiện tiên quyết [#prerequisites]

1. **Google Cloud Project** với Vertex AI API đã được bật
2. **Service Account** với các vai trò sau:
   - `Vertex AI User` (`roles/aiplatform.user`)
   - Hoặc `Vertex AI Administrator` để có toàn quyền truy cập
3. Các **Claude models** được kích hoạt trong Vertex AI Model Garden của bạn
4. **Service Account Key** (tệp JSON) đã tải xuống và có thể truy cập được bởi LibreChat

### Cấu hình nâng cao [#advanced-configuration]

Để ánh xạ tên model và các cài đặt nâng cao (tương tự như cấu hình Azure OpenAI), hãy sử dụng tệp `librechat.yaml`:

```yaml filename="librechat.yaml"
endpoints:
  anthropic:
    vertex:
      region: global
      models:
        claude-fable-5-1:
          deploymentName: claude-fable-5-1
        claude-opus-5:
          deploymentName: claude-opus-5
        claude-opus-5-5:
          deploymentName: claude-opus-5-5
        claude-sonnet-5-5:
          deploymentName: claude-sonnet-5-5
        claude-haiku-5-5:
          deploymentName: claude-haiku-5-5
        claude-sonnet-5:
          deploymentName: claude-sonnet-5
        claude-3.5-haiku:
          deploymentName: claude-3-5-haiku@20241022
```

Để biết các tùy chọn cấu hình YAML chi tiết, hãy xem [Cấu hình Anthropic Vertex AI](/docs/configuration/librechat_yaml/object_structure/anthropic_vertex).
