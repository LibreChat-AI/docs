- Utwórz konto na **[https://platform.claude.com/](https://platform.claude.com/)**
- Przejdź do **[https://platform.claude.com/settings/keys](https://platform.claude.com/settings/keys)** i pobierz swój klucz API
- Będziesz musiał ustawić poniższą zmienną środowiskową na swój klucz lub ustawić ją na `user_provided`, aby użytkownicy mogli podać własny.

```bash filename=".env"
ANTHROPIC_API_KEY=user_provided
```

- Możesz określić, które modele mają być dostępne, używając `ANTHROPIC_MODELS`.

```bash filename=".env"
ANTHROPIC_MODELS=claude-fable-5-1,claude-fable-5,claude-opus-5-5,claude-opus-5,claude-sonnet-5-5,claude-opus-4-8,claude-opus-4-7,claude-sonnet-5,claude-sonnet-4-6,claude-haiku-5-5,claude-opus-4-6,claude-opus-4-20250514,claude-3-7-sonnet-20250219,claude-3-5-sonnet-20241022,claude-3-5-haiku-20241022
```

Możesz też ustawić listę w `librechat.yaml` za pomocą `endpoints.anthropic.models`, czyli tablicy identyfikatorów modeli. Lista skonfigurowana w tym miejscu zastępuje `ANTHROPIC_MODELS`. Jest odczytywana z konfiguracji rozwiązanej dla każdego żądania, więc nadpisanie konfiguracji zastosowane do roli lub grupy może ją zawęzić dla tych użytkowników.

**Uwagi:**

- Claude Opus 5.5 (`claude-opus-5-5`), Claude Sonnet 5.5 (`claude-sonnet-5-5`) i Claude Haiku 5.5 (`claude-haiku-5-5`) są częścią domyślnego katalogu modeli Anthropic w LibreChat. Modelowi Haiku 5.5 przypisano okno kontekstowe o rozmiarze 1M tokenów.

- Modele Claude Fable 5.1 oraz Fable 5 są zawarte w domyślnym katalogu modeli Anthropic w LibreChat. Modele klasy Fable/Mythos korzystają z nowoczesnego profilu Anthropic w LibreChat: 1 mln kontekstu, 128 tys. maksymalnej długości wyjściowej, adaptacyjne myślenie (adaptive thinking), buforowanie promptów (prompt caching) oraz obsługa `thinkingDisplay` dla podsumowanych lub pominiętych wyników rozumowania. Fable 5.1 utrzymuje stawki Fable 5 wynoszące 10 USD za wejście i 50 USD za wyjście na milion tokenów, przy 12,50 USD za zapisy w pamięci podręcznej i 0,25 USD za odczyty z pamięci podręcznej.
- Claude Opus 5 jest dostępny poprzez bezpośrednie Anthropic, Anthropic w Vertex AI oraz AWS Bedrock. Posiada okno kontekstowe o wielkości 1 mln tokenów oraz maksymalną długość wyjściową 128 tys. tokenów. Adaptacyjne myślenie (adaptive thinking) jest włączone, chyba że zostanie wyraźnie wyłączone; gdy jest wyłączone, LibreChat ogranicza `xhigh` lub `max` effort do `high`, aby zapewnić poprawność żądań.
- Claude Sonnet 3.5 jest dostępny poprzez bezpośrednie Anthropic, Anthropic w Vertex AI oraz AWS Bedrock. LibreChat przypisuje mu okno kontekstowe o wielkości 1M tokenów oraz maksymalną liczbę 128K tokenów na wyjściu, wykorzystuje adaptacyjne myślenie (adaptive thinking) ze skróconym wyświetlaniem, gdy funkcja myślenia jest włączona, oraz wysyła jawne ustawienie wyłączenia, gdy użytkownik wyłączy funkcję myślenia.
- Natywne kontrolki prompt-cache Anthropic oraz wykrywanie kontekstu 1M oceniają bezpośrednio skonfigurowany identyfikator modelu Claude. Kompatybilne identyfikatory Sonnet i Opus w wersji 4.6 lub nowszej, w tym pasujące identyfikatory późniejszych wersji, zachowują te kontrolki bez konieczności oczekiwania na dokładny wpis w katalogu. W przypadku nieobsługiwanych modeli kontrolki prompt-cache pozostają ukryte w Agent Builder.
- Endpoint Anthropic obsługuje wszystkie [Shared Endpoint Settings](/docs/configuration/librechat_yaml/object_structure/shared_endpoint_settings) za pośrednictwem pliku konfiguracyjnego `librechat.yaml`, w tym `streamRate`, `headers`, `titleModel`, `titleMethod`, `titlePrompt`, `titlePromptTemplate` oraz `titleEndpoint`
- Aby skonfigurować Anthropic lub bramę kompatybilną z Anthropic jako oddzielny niestandardowy endpoint, użyj [`provider: "anthropic"`](/docs/configuration/librechat_yaml/object_structure/custom_endpoint#provider).

## Vertex AI [#vertex-ai]

LibreChat obsługuje uruchamianie modeli Anthropic Claude za pośrednictwem **Google Cloud Vertex AI**. Jest to przydatne, jeśli:

- Masz już infrastrukturę Google Cloud
- Chcesz użyć swojego istniejącego rozliczenia i danych uwierzytelniających GCP
- Konieczność przestrzegania regionalnych wymogów dotyczących przechowywania danych

### Szybka konfiguracja (zmienne środowiskowe) [#quick-setup-environment-variables]

Ustaw następujące zmienne środowiskowe, aby włączyć Anthropic przez Vertex AI:

```bash filename=".env"
# Enable Vertex AI mode for Anthropic
ANTHROPIC_USE_VERTEX=true

# Vertex AI region (optional, defaults to 'us-east5')
# Modern models such as Fable 5.1 and Opus 5 require global, us, or eu.
# Specific regions serve Sonnet 4.6 and earlier.
ANTHROPIC_VERTEX_REGION=global

# Path to Google service account key file (optional)
# If not specified, uses default path: api/data/auth.json
GOOGLE_SERVICE_KEY_FILE=/path/to/service-account.json

# Google Cloud project ID (optional)
# Takes priority over the project_id in the service account key file.
# A project ID set in librechat.yaml (endpoints.anthropic.vertex) takes priority over both.
VERTEX_PROJECT_ID=your-project-id
```

### Wymagania wstępne [#prerequisites]

1. **Projekt Google Cloud** z włączonym interfejsem Vertex AI API
2. **Konto serwisowe** z następującymi rolami:
   - `Vertex AI User` (`roles/aiplatform.user`)
   - Lub `Vertex AI Administrator` dla pełnego dostępu
3. Modele **Claude** włączone w Twoim Vertex AI Model Garden
4. **Klucz konta serwisowego** (plik JSON) pobrany i dostępny dla LibreChat

### Zaawansowana konfiguracja [#advanced-configuration]

Aby uzyskać mapowanie nazw modeli i ustawienia zaawansowane (podobnie jak w konfiguracji Azure OpenAI), użyj pliku `librechat.yaml`:

```yaml filename="librechat.yaml"
endpoints:
  anthropic:
    vertex:
      region: global
      models:
        claude-fable-5-1:
          deploymentName: claude-fable-5-1
        claude-opus-5:
          deploymentName: claude-opus-5
        claude-opus-5-5:
          deploymentName: claude-opus-5-5
        claude-sonnet-5-5:
          deploymentName: claude-sonnet-5-5
        claude-haiku-5-5:
          deploymentName: claude-haiku-5-5
        claude-sonnet-5:
          deploymentName: claude-sonnet-5
        claude-3.5-haiku:
          deploymentName: claude-3-5-haiku@20241022
```

Aby uzyskać szczegółowe opcje konfiguracji YAML, zobacz [Konfiguracja Anthropic Vertex AI](/docs/configuration/librechat_yaml/object_structure/anthropic_vertex).
