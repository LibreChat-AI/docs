- **[https://platform.claude.com/](https://platform.claude.com/)** でアカウントを作成します。
- **[https://platform.claude.com/settings/keys](https://platform.claude.com/settings/keys)** にアクセスして、APIキーを取得してください。
- 以下の環境変数をキーに設定する必要があります。または、ユーザー自身がキーを入力できるように `user_provided` に設定することも可能です。

```bash filename=".env"
ANTHROPIC_API_KEY=user_provided
```

- `ANTHROPIC_MODELS` を使用して、利用可能にするモデルを決定できます。

```bash filename=".env"
ANTHROPIC_MODELS=claude-fable-5-1,claude-fable-5,claude-opus-5-5,claude-opus-5,claude-sonnet-5-5,claude-opus-4-8,claude-opus-4-7,claude-sonnet-5,claude-sonnet-4-6,claude-haiku-5-5,claude-opus-4-6,claude-opus-4-20250514,claude-3-7-sonnet-20250219,claude-3-5-sonnet-20241022,claude-3-5-haiku-20241022
```

あわせて、`librechat.yaml` の `endpoints.anthropic.models` で一覧を設定することもできます。これはモデル ID の配列です。ここで設定した一覧は `ANTHROPIC_MODELS` を置き換えます。この設定はリクエストごとに解決された構成から読み込まれるため、ロールやグループに適用された構成のオーバーライドによって、そのユーザーに対してこの一覧を絞り込むことができます。

**注記:**

- Claude Opus 5.5 (`claude-opus-5-5`)、Claude Sonnet 5.5 (`claude-sonnet-5-5`)、Claude Haiku 5.5 (`claude-haiku-5-5`) は、LibreChat のデフォルト Anthropic モデルカタログに含まれています。Haiku 5.5 には 100万トークン (1M) のコンテキストウィンドウが割り当てられています。

- Claude Fable 5.1 および Fable 5 は、LibreChat のデフォルトの Anthropic モデルカタログに含まれています。Fable/Mythos クラスのモデルは、LibreChat において最新の Anthropic プロファイルを使用します。これには、1M のコンテキスト、128K の最大出力、適応型推論（adaptive thinking）、プロンプトキャッシング、および要約または省略された推論出力をサポートする `thinkingDisplay` が含まれます。Fable 5.1 は、Fable 5 と同様に 100 万トークンあたり入力 10 ドル、出力 50 ドルの料金体系を維持しており、キャッシュ書き込みは 12.50 ドル、キャッシュ読み取りは 0.25 ドルとなっています。
- Claude Opus 5は、Anthropic直接、Vertex AI経由のAnthropic、およびAWS Bedrockを通じて利用可能です。1Mトークンのコンテキストウィンドウと128Kトークンの最大出力を備えています。アダプティブシンキング（Adaptive thinking）は明示的に無効化されない限り有効です。無効化された場合、LibreChatはリクエストを有効に保つため、`xhigh`または`max`の努力レベルを`high`に制限します。
- Claude Sonnet 3.5は、Anthropic直接、Vertex AI上のAnthropic、およびAWS Bedrockを通じて利用可能です。LibreChatはこれに1Mトークンのコンテキストウィンドウと128Kトークンの最大出力を割り当て、Thinking（思考）が有効な場合は要約表示を伴う適応型Thinkingを使用し、ユーザーがThinkingをオフにした場合は明示的に無効化設定を送信します。
- ネイティブの Anthropic プロンプトキャッシュ制御と 1M コンテキスト検出は、設定された Claude モデル ID を直接評価します。バージョン 4.6 以降の互換性のある Sonnet および Opus ID（一致する後のバージョンの ID を含む）は、正確なカタログエントリを待つことなく、それらの制御を保持します。サポートされていないモデルでは、Agent Builder 内のプロンプトキャッシュ制御は非表示のままとなります。
- Anthropic endpointは、`librechat.yaml`設定ファイルを通じて、[Shared Endpoint Settings](/docs/configuration/librechat_yaml/object_structure/shared_endpoint_settings)のすべての設定をサポートしています。これには、`streamRate`、`headers`、`titleModel`、`titleMethod`、`titlePrompt`、`titlePromptTemplate`、および`titleEndpoint`が含まれます。
- AnthropicまたはAnthropic互換のゲートウェイを個別のカスタムendpointとして設定するには、[`provider: "anthropic"`](/docs/configuration/librechat_yaml/object_structure/custom_endpoint#provider)を使用してください。

## Vertex AI [#vertex-ai]

LibreChatは、**Google Cloud Vertex AI**経由でAnthropic Claudeモデルを実行することをサポートしています。これは以下のような場合に役立ちます：

- すでにGoogle Cloudインフラストラクチャをお持ちの場合
- 既存のGCPの請求および認証情報を使用したい場合
- 地域のデータレジデンシー要件を遵守する必要がある

### クイックセットアップ (環境変数) [#quick-setup-environment-variables]

Vertex AI経由でAnthropicを有効にするには、以下の環境変数を設定してください：

```bash filename=".env"
# Enable Vertex AI mode for Anthropic
ANTHROPIC_USE_VERTEX=true

# Vertex AI region (optional, defaults to 'us-east5')
# Modern models such as Fable 5.1 and Opus 5 require global, us, or eu.
# Specific regions serve Sonnet 4.6 and earlier.
ANTHROPIC_VERTEX_REGION=global

# Path to Google service account key file (optional)
# If not specified, uses default path: api/data/auth.json
GOOGLE_SERVICE_KEY_FILE=/path/to/service-account.json

# Google Cloud project ID (optional)
# Takes priority over the project_id in the service account key file.
# A project ID set in librechat.yaml (endpoints.anthropic.vertex) takes priority over both.
VERTEX_PROJECT_ID=your-project-id
```

### 前提条件 [#prerequisites]

1. **Google Cloud Project**（Vertex AI API が有効になっているもの）
2. **Service Account**（以下のロールを持つもの）:
   - `Vertex AI User` (`roles/aiplatform.user`)
   - または、フルアクセス権限を持つ `Vertex AI Administrator`
3. Vertex AI Model Gardenで有効化された**Claude models**
4. **Service Account Key** (JSONファイル) 。ダウンロード済みで、LibreChatからアクセス可能であること。

### 高度な設定 [#advanced-configuration]

モデル名のマッピングや詳細設定（Azure OpenAIの設定と同様）については、`librechat.yaml`ファイルを使用してください：

```yaml filename="librechat.yaml"
endpoints:
  anthropic:
    vertex:
      region: global
      models:
        claude-fable-5-1:
          deploymentName: claude-fable-5-1
        claude-opus-5:
          deploymentName: claude-opus-5
        claude-opus-5-5:
          deploymentName: claude-opus-5-5
        claude-sonnet-5-5:
          deploymentName: claude-sonnet-5-5
        claude-haiku-5-5:
          deploymentName: claude-haiku-5-5
        claude-sonnet-5:
          deploymentName: claude-sonnet-5
        claude-3.5-haiku:
          deploymentName: claude-3-5-haiku@20241022
```

詳細なYAML設定オプションについては、[Anthropic Vertex AI Configuration](/docs/configuration/librechat_yaml/object_structure/anthropic_vertex) を参照してください。
