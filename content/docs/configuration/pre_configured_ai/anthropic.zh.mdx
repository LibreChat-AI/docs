- 在 **[https://platform.claude.com/](https://platform.claude.com/)** 创建一个账户
- 前往 **[https://platform.claude.com/settings/keys](https://platform.claude.com/settings/keys)** 并获取您的 api key
- 您需要将以下环境变量设置为您的密钥，或者将其设置为 `user_provided` 以便用户提供他们自己的密钥。

```bash filename=".env"
ANTHROPIC_API_KEY=user_provided
```

- 您可以通过 `ANTHROPIC_MODELS` 来决定您想要使用的模型。

```bash filename=".env"
ANTHROPIC_MODELS=claude-fable-5-1,claude-fable-5,claude-opus-5-5,claude-opus-5,claude-sonnet-5-5,claude-opus-4-8,claude-opus-4-7,claude-sonnet-5,claude-sonnet-4-6,claude-haiku-5-5,claude-opus-4-6,claude-opus-4-20250514,claude-3-7-sonnet-20250219,claude-3-5-sonnet-20241022,claude-3-5-haiku-20241022
```

你也可以在 `librechat.yaml` 中通过 `endpoints.anthropic.models` 设置该列表,它是一个模型 ID 数组。在此处配置的列表会替代 `ANTHROPIC_MODELS`。该列表从每个请求解析出的配置中读取,因此应用于某个角色或用户组的配置覆盖,可以为这些用户缩小可用列表。

**注意：**

- Claude Opus 5.5 (`claude-opus-5-5`)、Claude Sonnet 5.5 (`claude-sonnet-5-5`) 和 Claude Haiku 5.5 (`claude-haiku-5-5`) 都包含在 LibreChat 默认的 Anthropic 模型目录中。Haiku 5.5 的上下文窗口被设定为 1M 令牌。

- Claude Fable 5.1 和 Fable 5 已包含在 LibreChat 的默认 Anthropic 模型目录中。Fable/Mythos 类模型在 LibreChat 中使用现代 Anthropic 配置：1M 上下文、128K 最大输出、自适应思维（adaptive thinking）、提示缓存（prompt caching）以及支持总结或省略推理输出的 `thinkingDisplay`。Fable 5.1 保持了 Fable 5 每百万 token 10 美元的输入和 50 美元的输出费率，缓存写入为 12.50 美元，缓存读取为 0.25 美元。
- Claude Opus 5 可通过 Anthropic 直接接入、Vertex AI 上的 Anthropic 以及 AWS Bedrock 使用。它拥有 1M token 的上下文窗口和 128K token 的最大输出限制。除非明确禁用，否则默认启用自适应思维（Adaptive thinking）；当禁用时，LibreChat 会将 `xhigh` 或 `max` 努力程度限制为 `high`，以确保请求有效。
- Claude Sonnet 3.5 可通过直接使用 Anthropic、Vertex AI 上的 Anthropic 以及 AWS Bedrock 进行访问。LibreChat 为其分配了 1M token 的上下文窗口和 128K token 的最大输出限制，在启用思考功能时使用带有摘要显示的自适应思考，并在用户关闭思考功能时发送明确的禁用设置。
- 原生的 Anthropic 提示词缓存（prompt-cache）控制和 1M 上下文检测会直接评估所配置的 Claude 模型 ID。版本 4.6 或更高版本的兼容 Sonnet 和 Opus ID（包括匹配的后续版本 ID）将保留这些控制项，无需等待精确的目录条目。不支持的模型将在 Agent Builder 中隐藏提示词缓存控制项。
- Anthropic endpoint 支持通过 `librechat.yaml` 配置文件使用所有 [Shared Endpoint Settings](/docs/configuration/librechat_yaml/object_structure/shared_endpoint_settings)，包括 `streamRate`、`headers`、`titleModel`、`titleMethod`、`titlePrompt`、`titlePromptTemplate` 和 `titleEndpoint`。
- 要将 Anthropic 或兼容 Anthropic 的网关配置为单独的自定义 endpoint，请使用 [`provider: "anthropic"`](/docs/configuration/librechat_yaml/object_structure/custom_endpoint#provider)。

## Vertex AI [#vertex-ai]

LibreChat 支持通过 **Google Cloud Vertex AI** 运行 Anthropic Claude 模型。如果您有以下需求，这将非常有用：

- 已经拥有 Google Cloud 基础设施
- 想要使用您现有的 GCP 账单和凭据
- 需要符合区域数据驻留要求

### 快速设置（环境变量） [#quick-setup-environment-variables]

设置以下环境变量以通过 Vertex AI 启用 Anthropic：

```bash filename=".env"
# Enable Vertex AI mode for Anthropic
ANTHROPIC_USE_VERTEX=true

# Vertex AI region (optional, defaults to 'us-east5')
# Modern models such as Fable 5.1 and Opus 5 require global, us, or eu.
# Specific regions serve Sonnet 4.6 and earlier.
ANTHROPIC_VERTEX_REGION=global

# Path to Google service account key file (optional)
# If not specified, uses default path: api/data/auth.json
GOOGLE_SERVICE_KEY_FILE=/path/to/service-account.json

# Google Cloud project ID (optional)
# Takes priority over the project_id in the service account key file.
# A project ID set in librechat.yaml (endpoints.anthropic.vertex) takes priority over both.
VERTEX_PROJECT_ID=your-project-id
```

### 先决条件 [#prerequisites]

1. 已启用 Vertex AI API 的 **Google Cloud Project**
2. **Service Account**，并具备以下角色：
   - `Vertex AI User` (`roles/aiplatform.user`)
   - 或者 `Vertex AI Administrator` 以获得完全访问权限
3. 在您的 Vertex AI Model Garden 中启用的 **Claude models**
4. **Service Account Key** (JSON 文件)，已下载并可供 LibreChat 访问

### 高级配置 [#advanced-configuration]

对于模型名称映射和高级设置（类似于 Azure OpenAI 配置），请使用 `librechat.yaml` 文件：

```yaml filename="librechat.yaml"
endpoints:
  anthropic:
    vertex:
      region: global
      models:
        claude-fable-5-1:
          deploymentName: claude-fable-5-1
        claude-opus-5:
          deploymentName: claude-opus-5
        claude-opus-5-5:
          deploymentName: claude-opus-5-5
        claude-sonnet-5-5:
          deploymentName: claude-sonnet-5-5
        claude-haiku-5-5:
          deploymentName: claude-haiku-5-5
        claude-sonnet-5:
          deploymentName: claude-sonnet-5
        claude-3.5-haiku:
          deploymentName: claude-3-5-haiku@20241022
```

有关详细的 YAML 配置选项，请参阅 [Anthropic Vertex AI Configuration](/docs/configuration/librechat_yaml/object_structure/anthropic_vertex)。
