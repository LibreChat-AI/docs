- Erstellen Sie ein Konto unter **[https://platform.claude.com/](https://platform.claude.com/)**
- Gehen Sie zu **[https://platform.claude.com/settings/keys](https://platform.claude.com/settings/keys)** und rufen Sie Ihren API-Key ab.
- Sie müssen die folgende Umgebungsvariable auf Ihren Schlüssel setzen oder Sie können sie auf `user_provided` setzen, damit Benutzer ihre eigenen Schlüssel angeben können.

```bash filename=".env"
ANTHROPIC_API_KEY=user_provided
```

- Sie können mit `ANTHROPIC_MODELS` festlegen, welche Modelle verfügbar sein sollen.

```bash filename=".env"
ANTHROPIC_MODELS=claude-fable-5-1,claude-fable-5,claude-opus-5-5,claude-opus-5,claude-sonnet-5-5,claude-opus-4-8,claude-opus-4-7,claude-sonnet-5,claude-sonnet-4-6,claude-haiku-5-5,claude-opus-4-6,claude-opus-4-20250514,claude-3-7-sonnet-20250219,claude-3-5-sonnet-20241022,claude-3-5-haiku-20241022
```

Sie können die Liste auch in `librechat.yaml` mit `endpoints.anthropic.models` festlegen, einem Array von Modell-IDs. Eine dort konfigurierte Liste ersetzt `ANTHROPIC_MODELS`. Sie wird aus der für jede Anfrage aufgelösten Konfiguration gelesen, sodass ein auf eine Rolle oder Gruppe angewendetes Konfigurations-Override sie für diese Benutzer einschränken kann.

**Hinweise:**

- Claude Opus 5.5 (`claude-opus-5-5`), Claude Sonnet 5.5 (`claude-sonnet-5-5`) und Claude Haiku 5.5 (`claude-haiku-5-5`) sind Bestandteil des standardmäßigen Anthropic-Modellkatalogs von LibreChat. Haiku 5.5 ist ein Kontextfenster von 1 Mio. Token zugewiesen.

- Claude Fable 5.1 und Fable 5 sind im standardmäßigen Anthropic-Modellkatalog von LibreChat enthalten. Fable/Mythos-Klasse-Modelle nutzen das moderne Anthropic-Profil in LibreChat: 1M Kontext, 128K maximale Ausgabe, adaptives Denken, Prompt-Caching und `thinkingDisplay`-Unterstützung für zusammengefasste oder ausgelassene Schlussfolgerungsausgaben. Fable 5.1 behält die Preise von Fable 5 bei: 10 $ für Eingaben und 50 $ für Ausgaben pro Million Token, mit 12,50 $ für Cache-Schreibvorgänge und 0,25 $ für Cache-Lesevorgänge.
- Claude Opus 5 ist über direktes Anthropic, Anthropic auf Vertex AI und AWS Bedrock verfügbar. Es verfügt über ein Kontextfenster von 1 Mio. Token und eine maximale Ausgabe von 128.000 Token. Adaptives Denken ist standardmäßig aktiviert, sofern es nicht explizit deaktiviert wurde; wenn es deaktiviert ist, begrenzt LibreChat den Aufwand `xhigh` oder `max` auf `high`, um die Anfragen gültig zu halten.
- Claude Sonnet 3.5 ist über direktes Anthropic, Anthropic auf Vertex AI und AWS Bedrock verfügbar. LibreChat weist ihm ein Kontextfenster von 1 Mio. Token und eine maximale Ausgabe von 128.000 Token zu, verwendet adaptives Denken mit zusammengefasster Anzeige, wenn das Denken aktiviert ist, und sendet eine explizite Deaktivierungseinstellung, wenn ein Benutzer das Denken ausschaltet.
- Native Anthropic Prompt-Cache-Steuerungen und die Erkennung von 1M-Kontext evaluieren die konfigurierte Claude-Modell-ID direkt. Kompatible Sonnet- und Opus-IDs ab Version 4.6 oder höher, einschließlich übereinstimmender IDs späterer Versionen, behalten diese Steuerungen bei, ohne auf einen exakten Katalogeintrag zu warten. Nicht unterstützte Modelle lassen die Prompt-Cache-Steuerungen im Agent Builder ausgeblendet.
- Der Anthropic endpoint unterstützt alle [Shared Endpoint Settings](/docs/configuration/librechat_yaml/object_structure/shared_endpoint_settings) über die Konfigurationsdatei `librechat.yaml`, einschließlich `streamRate`, `headers`, `titleModel`, `titleMethod`, `titlePrompt`, `titlePromptTemplate` und `titleEndpoint`.
- Um Anthropic oder ein mit Anthropic kompatibles Gateway als separaten benutzerdefinierten endpoint zu konfigurieren, verwenden Sie [`provider: "anthropic"`](/docs/configuration/librechat_yaml/object_structure/custom_endpoint#provider).

## Vertex AI [#vertex-ai]

LibreChat unterstützt die Ausführung von Anthropic Claude-Modellen über **Google Cloud Vertex AI**. Dies ist nützlich, wenn Sie:

- Sie verfügen bereits über eine Google Cloud-Infrastruktur
- Möchten Sie Ihre bestehende GCP-Abrechnung und Ihre Anmeldedaten verwenden
- Muss regionale Anforderungen an die Datenresidenz erfüllen

### Schnelleinrichtung (Umgebungsvariablen) [#quick-setup-environment-variables]

Setzen Sie die folgenden Umgebungsvariablen, um Anthropic über Vertex AI zu aktivieren:

```bash filename=".env"
# Enable Vertex AI mode for Anthropic
ANTHROPIC_USE_VERTEX=true

# Vertex AI region (optional, defaults to 'us-east5')
# Modern models such as Fable 5.1 and Opus 5 require global, us, or eu.
# Specific regions serve Sonnet 4.6 and earlier.
ANTHROPIC_VERTEX_REGION=global

# Path to Google service account key file (optional)
# If not specified, uses default path: api/data/auth.json
GOOGLE_SERVICE_KEY_FILE=/path/to/service-account.json

# Google Cloud project ID (optional)
# Takes priority over the project_id in the service account key file.
# A project ID set in librechat.yaml (endpoints.anthropic.vertex) takes priority over both.
VERTEX_PROJECT_ID=your-project-id
```

### Voraussetzungen [#prerequisites]

1. **Google Cloud Project** mit aktivierter Vertex AI API
2. **Service Account** mit den folgenden Rollen:
   - `Vertex AI User` (`roles/aiplatform.user`)
   - Oder `Vertex AI Administrator` für vollen Zugriff
3. **Claude-Modelle**, die in Ihrem Vertex AI Model Garden aktiviert sind
4. **Service Account Key** (JSON-Datei), heruntergeladen und für LibreChat zugänglich

### Erweiterte Konfiguration [#advanced-configuration]

Für die Modellnamen-Zuordnung und erweiterte Einstellungen (ähnlich der Azure OpenAI-Konfiguration) verwenden Sie die `librechat.yaml` Datei:

```yaml filename="librechat.yaml"
endpoints:
  anthropic:
    vertex:
      region: global
      models:
        claude-fable-5-1:
          deploymentName: claude-fable-5-1
        claude-opus-5:
          deploymentName: claude-opus-5
        claude-opus-5-5:
          deploymentName: claude-opus-5-5
        claude-sonnet-5-5:
          deploymentName: claude-sonnet-5-5
        claude-haiku-5-5:
          deploymentName: claude-haiku-5-5
        claude-sonnet-5:
          deploymentName: claude-sonnet-5
        claude-3.5-haiku:
          deploymentName: claude-3-5-haiku@20241022
```

Für detaillierte YAML-Konfigurationsoptionen siehe [Anthropic Vertex AI Configuration](/docs/configuration/librechat_yaml/object_structure/anthropic_vertex).
