AbliteratedLLM serves abliterated (refusal-removed) and stock open-weight models through an OpenAI-compatible API that you can add to LibreChat through `endpoints.custom`.

## Get an API key

Create an API key from the [AbliteratedLLM dashboard](https://abliteratedllm.dev/dashboard/keys). Add it to your `.env` file:

```bash filename=".env"
ABLITERATEDLLM_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "AbliteratedLLM"
      apiKey: "${ABLITERATEDLLM_API_KEY}"
      baseURL: "https://api.abliteratedllm.dev/v1"
      models:
        default:
          - "glm-5.3-flash-abliterated"
        fetch: true
      titleConvo: true
      titleModel: "glm-5.3-flash-abliterated"
      modelDisplayLabel: "AbliteratedLLM"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from AbliteratedLLM's `/v1/models` endpoint, which does not require a key. The `default` array is only the initial selection.
- Use model IDs exactly as they appear in the [model list](https://api.abliteratedllm.dev/v1/models). Model availability can change over time.
- All models are reasoning models. If you set a reasoning effort, `glm-5.3-flash-abliterated` rejects `minimal` and `none`, and the other GLM models reject `none`. Leave it on Auto or choose `low` or higher.
- Image input works only on models whose `input_modalities` include `image`. The API rejects audio and file content parts.
- Trial accounts allow one request at a time and cap output at 4,096 tokens. With the default `titleTiming: "immediate"`, the title request runs alongside the response and can be rejected with HTTP 429. On a trial account, set `titleTiming: "final"` or `titleConvo: false`.
