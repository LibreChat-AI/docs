[bf16.ai](https://bf16.ai) serves verified open-weight models (DeepSeek V4.1 Flash, GLM-5.3, GLM-5.3 Flash, Kimi K3.1 Pro) with 1M context windows, prompt caching, and strict Zero Data Retention (ZDR) behind an OpenAI-compatible API.

## Get an API key

Create an API key from the [bf16.ai API Keys page](https://bf16.ai/dashboard/keys) (new accounts include `$0.20` starter credit) and add it to your `.env` file:

```bash filename=".env"
BF16_API_KEY=sk-bf16-v1-your-key-here
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: 'bf16.ai'
      apiKey: '${BF16_API_KEY}'
      baseURL: 'https://api.bf16.ai/v1'
      models:
        default:
          [
            'deepseek/deepseek-v4.1-flash-uncensored-fast',
            'deepseek/deepseek-v4.1-flash-uncensored',
            'zai-org/glm-5.3-uncensored',
            'zai-org/glm-5.3-flash-uncensored',
            'moonshotai/kimi-k3.1-pro-uncensored',
          ]
        fetch: true
      titleConvo: true
      titleModel: 'deepseek/deepseek-v4.1-flash-uncensored'
      modelDisplayLabel: 'bf16.ai'
```

## Notes

- Setting `fetch: true` automatically pulls the live model list from `https://api.bf16.ai/v1/models`.
- All listed models support tool calling, reasoning, and 1,048,576-token context windows. See the [bf16.ai models catalog](https://bf16.ai/models) for current pricing and capabilities.
