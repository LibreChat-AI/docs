TeamoRouter is an API gateway where one key calls Claude, GPT, Gemini, DeepSeek, GLM, Kimi, Qwen and other models through a single OpenAI-compatible endpoint. It is billed pay-as-you-go from a prepaid balance, with no subscription.

<Callout type="info" title="Vendor-contributed">

This page was contributed by TeamoRouter, the provider it describes.

</Callout>

## Get an API key

Create an account at [teamorouter.com](https://teamorouter.com/) and create a key in the [dashboard](https://teamorouter.com/dashboard). Add it to your `.env` file:

```bash filename=".env"
TEAMOROUTER_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "TeamoRouter"
      apiKey: "${TEAMOROUTER_API_KEY}"
      baseURL: "https://api.teamorouter.com/v1"
      models:
        default:
          - "claude-sonnet-5-5"
          - "gpt-6-astra"
          - "deepseek-v4-flash"
        fetch: true
      titleConvo: true
      titleModel: "deepseek-v4-flash"
      modelDisplayLabel: "TeamoRouter"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from TeamoRouter's OpenAI-compatible `/v1/models` endpoint. The `default` array is only the initial selection.
- Use model IDs exactly as they appear in the [TeamoRouter model list](https://teamorouter.com/models).
- A `402 Payment Required` response means the account balance is used up. Top up in the [dashboard](https://teamorouter.com/dashboard), then retry.
