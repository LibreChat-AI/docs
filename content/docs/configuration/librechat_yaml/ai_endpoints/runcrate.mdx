[Runcrate](https://www.runcrate.ai/inference/free?utm_source=librechat&utm_medium=directory&utm_campaign=gpu_pricing) serves open models (DeepSeek, GLM, Qwen, gpt-oss, Kimi and more) through an OpenAI-compatible API that you can add to LibreChat through `endpoints.custom`. Open models are free with your GitHub account.

## Get an API key

Sign in with GitHub and create a key at [runcrate.ai/dashboard/api-keys](https://www.runcrate.ai/dashboard/api-keys). Add it to your `.env` file:

```bash filename=".env"
RUNCRATE_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Runcrate"
      apiKey: "${RUNCRATE_API_KEY}"
      baseURL: "https://api.runcrate.ai/v1"
      models:
        default:
          - "deepseek-ai/DeepSeek-V4.1-Flash"
          - "zai-org/GLM-5.3"
          - "Qwen/Qwen3.8-Flash"
          - "openai/gpt-oss-120b"
        fetch: true
      titleConvo: true
      titleModel: "deepseek-ai/DeepSeek-V4.1-Flash"
      modelDisplayLabel: "Runcrate"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from Runcrate's `/v1/models` endpoint, which also lists image, audio and embedding models. The `default` array is only the initial selection; pick chat models.
- Model IDs keep their organization prefix, for example `deepseek-ai/DeepSeek-V4.1-Flash`. Use them exactly as listed at `https://api.runcrate.ai/v1/models`.
