Rapid Router is an AI model gateway that serves Claude, GPT, Gemini, DeepSeek and hundreds of other models through a single OpenAI-compatible endpoint.

## Get an API key

Create an account at [rapidrouter.ai](https://rapidrouter.ai/) and generate a key from the dashboard. The key starts with `sk-rr-v1-`. Add it to your `.env` file:

```bash filename=".env"
RAPIDROUTER_API_KEY=sk-rr-v1-your-key-here
```

Rapid Router is pay as you go from a prepaid balance, so make sure your account has a balance before sending requests to paid models.

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Rapid Router"
      apiKey: "${RAPIDROUTER_API_KEY}"
      baseURL: "https://rapidrouter.ai/api/v1"
      models:
        default: ["anthropic/claude-sonnet-5", "openai/gpt-5-mini", "google/gemini-3.5-flash"]
        fetch: true
      titleConvo: true
      titleModel: "google/gemini-3.5-flash"
      modelDisplayLabel: "Rapid Router"
```

To pin a fixed model list instead of fetching the full catalog, set `fetch: false` and list the models yourself:

```yaml filename="librechat.yaml"
      models:
        default: ["anthropic/claude-opus-5-5", "openai/gpt-5.5", "google/gemini-3.6-flash"]
        fetch: false
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`. Users then see a key input field when they select the endpoint.

## Notes

- Model ids use the `author/model` form, for example `anthropic/claude-sonnet-5` or `deepseek/deepseek-v4-pro`. With `fetch: true`, LibreChat loads the list from `https://rapidrouter.ai/api/v1/models`, so the `default` array is only the initial selection.
- Optional `HTTP-Referer` and `X-Title` headers attribute traffic to your app in the Rapid Router dashboard. Add them under `headers:` in the endpoint block if you want that.
- Rapid Router setup notes for LibreChat: [rapidrouter.ai/integrations/librechat](https://rapidrouter.ai/integrations/librechat).
