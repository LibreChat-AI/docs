Wallaby serves Moonshot AI's Kimi K3.1 Pro and Kimi K3 through an OpenAI-compatible API that you can add to LibreChat as a custom endpoint.

## Get an API key

Create a key from [wallabytoken.com](https://wallabytoken.com) ($0.50 trial credit, no card required). Add it to your `.env` file:

```bash filename=".env"
WALLABY_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Wallaby"
      apiKey: "${WALLABY_API_KEY}"
      baseURL: "https://api.wallabytoken.com/v1"
      models:
        default: ["kimi-k3.1-pro", "kimi-k3.1-pro-highspeed", "kimi-k3"]
        fetch: true
      titleConvo: true
      titleModel: "current_model"
      modelDisplayLabel: "Wallaby"
```
