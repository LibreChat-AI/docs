[OptiQ Cloud](https://mlx-optiq.com/docs/cloud/api) serves GLM 5.3 Flash, DeepSeek V4.1 Flash, MiniMax M3.1 Flash and GLM 5.3 through an OpenAI-compatible chat completions endpoint. You can add it to LibreChat through `endpoints.custom`.

## Get an API key

Create a key on the [OptiQ Cloud dashboard](https://cloud.mlx-optiq.com/dashboard/keys) and add it to your `.env` file:

```bash filename=".env"
OPTIQ_CLOUD_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "OptiQ Cloud"
      apiKey: "${OPTIQ_CLOUD_API_KEY}"
      baseURL: "https://cloud.mlx-optiq.com/api/v1"
      models:
        default:
          - "glm-5.3-flash"
          - "deepseek-v4.1-flash"
          - "minimax-m3.1-flash"
          - "glm-5.3"
        fetch: false
      titleConvo: true
      titleModel: "deepseek-v4.1-flash"
      modelDisplayLabel: "OptiQ Cloud"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- Every model thinks before it answers by default, and thinking is billed as output. To make the models think less, add `addParams` with a `reasoning_effort` of `minimal`, `low`, `medium`, `high` or `xhigh`. Only `deepseek-v4.1-flash` also takes `none`, which turns thinking off. Other values are refused with a 400.
- `GET https://cloud.mlx-optiq.com/api/v1/models` lists the current models with their prices and context windows, and needs no key.
- See the [API reference](https://mlx-optiq.com/docs/cloud/api) for the request fields, streaming and errors.
