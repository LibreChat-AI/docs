[PopNow](https://popnow.ai/api) provides an OpenAI-compatible endpoint for Claude, GPT, Gemini and other chat models through one API key, billed pay-as-you-go in USD. You can add it to LibreChat through `endpoints.custom`.

## Get an API key

Create an API key in the [PopNow API console](https://popnow.ai/api/console/keys) and add funds to your API balance. Add the key to your `.env` file:

```bash filename=".env"
POPNOW_API_KEY=sk-popnow-...
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: 'PopNow'
      apiKey: '${POPNOW_API_KEY}'
      baseURL: 'https://api.popnow.ai/v1'
      models:
        default:
          - 'google/gemini-3.7-flash/chat'
          - 'anthropic/claude-haiku-5.5/chat'
        fetch: true
      titleConvo: true
      titleModel: 'google/gemini-3.7-flash/chat'
      modelDisplayLabel: 'PopNow'
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from PopNow's OpenAI-compatible `/v1/models` endpoint. The `default` array is only the initial selection.
- Model IDs use the `provider/model/chat` format, for example `anthropic/claude-haiku-5.5/chat`. See the [PopNow chat docs](https://popnow.ai/docs/chat) for the full list and per-token prices.
- PopNow also offers image, video and music generation models through its native task API; those are not chat models and are not used by this endpoint.
