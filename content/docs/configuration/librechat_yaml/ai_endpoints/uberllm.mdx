UberLLM serves text, image and video models from many providers (DeepSeek, GLM, Kimi, Gemini, Claude, GPT, Qwen and others) through one OpenAI-compatible endpoint. Each request is sent to an available provider for that model.

## Get an API key

Create an account at [uberllm.dev](https://uberllm.dev/signup) and create a key on the [Keys page](https://uberllm.dev/dashboard/keys). The key starts with `ull_`. Accounts are prepaid, so add credit before the first request. Add the key to your `.env` file:

```bash filename=".env"
UBERLLM_API_KEY=ull_your-key-here
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "UberLLM"
      apiKey: "${UBERLLM_API_KEY}"
      baseURL: "https://api.uberllm.dev/v1"
      models:
        default: ["deepseek/deepseek-v4.1-flash", "z-ai/glm-5.2", "moonshotai/kimi-k3", "google/gemini-2.5-flash"]
        fetch: true
      titleConvo: true
      titleModel: "qwen/qwen3-vl-235b-a22b-instruct"
      modelDisplayLabel: "UberLLM"
      iconURL: "https://uberllm.dev/apple-icon"
      headers:
        HTTP-Referer: "https://librechat.ai"
        X-Title: "LibreChat"
```

To pin a fixed model list instead of fetching the full catalog, set `fetch: false` and list the models yourself. Model ids are listed at [uberllm.dev/models](https://uberllm.dev/models).

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`. Users then see a key input field when they select the endpoint.

## Notes

- With `fetch: true`, LibreChat loads the full model list from `https://api.uberllm.dev/v1/models` (about 450 models, including image and video models that do not chat). The `default` array is the initial selection and the fallback if the fetch fails.
- `titleModel` uses a fast model that answers without a reasoning step, so titles come back short. Any chat model id works here.
- `deepseek/deepseek-v4.1-flash` and `moonshotai/kimi-k3` are reasoning models: they stream their reasoning in `reasoning_content` before the answer.
- A `402` response means the UberLLM balance is empty. Add credit in the UberLLM dashboard, then retry.
- The `headers` block is optional. It tells UberLLM which app sent the request.
- Setup notes for other apps: [uberllm.dev/docs](https://uberllm.dev/docs).
