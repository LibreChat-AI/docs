[Gisoo](https://gisoo.pro) is an OpenAI-compatible, multi-model API that you can add to LibreChat through `endpoints.custom`.

## Get an API key

Create an API key from your [Gisoo](https://gisoo.pro) account. Add it to your `.env` file:

```bash filename=".env"
GISOO_API_KEY=your-api-key
```

## Configuration

Add the endpoint under `endpoints.custom` in your `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: "gisoo"
      apiKey: "${GISOO_API_KEY}"
      baseURL: "https://gisoo.pro/api/v1"
      models:
        default:
          - "gpt-5-mini"
          - "claude-sonnet-5-5"
          - "gemini-3.8-flash"
        fetch: true
      titleConvo: true
      titleModel: "gpt-5-mini"
      modelDisplayLabel: "Gisoo"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from Gisoo's public `/api/v1/models` endpoint. The `default` array is only the initial selection.
- Use model IDs exactly as they appear in the [Gisoo model list](https://gisoo.pro/docs/models).
- The catalog includes non-chat models (for example image, audio and embedding models). Choose a chat-capable model for conversations.
- Model availability can change over time. If a selected model is unavailable, choose another chat-capable model from the list.
