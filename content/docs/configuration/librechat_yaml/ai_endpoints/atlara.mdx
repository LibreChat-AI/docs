---
title: Atlara
description: Configure Atlara as a custom endpoint in LibreChat.
---

[Atlara](https://atlara.ai) serves open and frontier models through one OpenAI-compatible API. Requests are routed across cloud providers and the Atlara compute network, with failover when a route is unavailable. The `auto` model picks a suitable model for each request.

## Get an API key

Sign in at [cloud.atlara.ai](https://cloud.atlara.ai), open **API Keys** in the dashboard sidebar and create a key. Add it to your `.env` file:

```bash filename=".env"
ATLARA_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Atlara"
      apiKey: "${ATLARA_API_KEY}"
      baseURL: "https://api.atlara.ai/v1"
      models:
        default: [
          "auto",
          "GLM-5.3",
          "DeepSeek-V4.1-Flash",
          "deepseek/deepseek-v4-pro",
          "qwen3.5:122b",
          "NVIDIA-Nemotron-3-Ultra-550B-A55B",
          "gemma4:26b",
          "meta-llama/llama-4-maverick",
          ]
        fetch: false
      titleConvo: true
      titleModel: "DeepSeek-V4.1-Flash"
      modelDisplayLabel: "Atlara"
```

## Notes

- Set `fetch: true` to load the model list from `/v1/models` instead. That list contains every model enabled for your workspace, including image, audio and embedding models, so the inline list above is usually easier to pick from.
- The full catalogue with context windows and prices is public at `https://api.atlara.ai/v1/model-catalogue` and does not need an API key.
- See the [Atlara API reference](https://cloud.atlara.ai/docs) for request parameters and error codes.
