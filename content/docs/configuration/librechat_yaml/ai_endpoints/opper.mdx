[Opper](https://opper.ai) is an AI gateway that serves 700+ models from OpenAI, Anthropic, Google, Mistral, DeepSeek, and other makers through a single OpenAI-compatible API, with one key and a choice of EU- or US-hosted routes per model.

## Get an API key

Create an API key at [platform.opper.ai](https://platform.opper.ai). Keys start with `op-`. Add it to your `.env` file:

```bash filename=".env"
OPPER_API_KEY=op-your-key-here
```

## Configuration

Add the endpoint under `endpoints.custom` in your `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: "Opper"
      apiKey: "${OPPER_API_KEY}"
      baseURL: "https://api.opper.ai/v3/compat"
      models:
        default:
          - "anthropic/claude-opus-5"
          - "aws/gpt-5.6-sol"
          - "alibaba:global/deepseek-v4-pro"
        fetch: true
      titleConvo: true
      titleModel: "alibaba:global/glm-5.2"
      modelDisplayLabel: "Opper"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from Opper's OpenAI-compatible models endpoint, which lists everything your key can reach. The `default` array is only the initial selection.
- Model IDs follow a `provider/model` pattern, and the provider part can carry a region tag, for example `alibaba:global/deepseek-v4-pro` or `alibaba:eu/qwen3-vl-plus`. Use IDs exactly as the models endpoint returns them.
- For a LibreChat-specific setup guide, see [opper.ai/apps/librechat](https://opper.ai/apps/librechat).
