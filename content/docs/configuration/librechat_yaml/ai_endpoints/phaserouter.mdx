[Phase Router](https://router.phase.xyz) is an OpenAI-compatible model router: about 400 models (open models such as DeepSeek, Qwen, Llama, gpt-oss, Kimi and GLM, plus Claude models) behind one base URL and one API key. Each response reports the model that ran and its price in `usage.cost`.

## Get an API key

Create an API key (`phk_...`) in the [Phase Router dashboard](https://router.phase.xyz/dashboard). Add it to your `.env` file:

```bash filename=".env"
PHASE_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Phase Router"
      apiKey: "${PHASE_API_KEY}"
      baseURL: "https://router.phase.xyz/v1"
      models:
        default:
          - "auto"
          - "gpt-oss-120b"
          - "deepseek-v3.2"
        fetch: true
      titleConvo: true
      titleModel: "gpt-oss-120b"
      modelDisplayLabel: "Phase Router"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from Phase Router's OpenAI-compatible `/v1/models` endpoint. The `default` array is only the initial selection.
- The model `auto` lets the router pick a model for each request; any model can also be called by its id from the [model catalog](https://router.phase.xyz/models).
- See the [Phase Router docs](https://router.phase.xyz/docs) for prices, limits and the full API reference.
