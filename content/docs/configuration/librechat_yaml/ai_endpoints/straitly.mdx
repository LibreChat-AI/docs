[Straitly](https://straitly.ai) is an AI gateway that provides one OpenAI-compatible API key and base URL for more than 150 models, including Claude, GPT, Gemini, Grok, and DeepSeek.

## Get an API key

Create an account at [straitly.ai](https://straitly.ai) and generate an API key in the [Straitly console](https://straitly.ai/app/keys). Add it to your `.env` file:

```bash filename=".env"
STRAITLY_API_KEY=your-api-key
```

Make sure your account has prepaid credits, otherwise model requests will fail.

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Straitly"
      apiKey: "${STRAITLY_API_KEY}"
      baseURL: "https://api.straitly.ai/v1"
      models:
        default: ["deepseek/deepseek-v4-1-flash-1017", "claude-sonnet-5-5", "gpt-6-astra", "gemini-4-carbon"]
        fetch: true
      titleConvo: true
      titleModel: "deepseek/deepseek-v4-1-flash-1017"
      modelDisplayLabel: "Straitly"
      iconURL: "https://straitly.ai/straitly-mark.svg"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`. Users then see a key input field when they select the endpoint.

## Notes

- With `fetch: true`, LibreChat loads the full model list from `GET https://api.straitly.ai/v1/models`, so the `default` array is only the initial selection. Browse available models in the [Straitly model list](https://straitly.ai/models).
- For SDK examples and setup details, see the [Straitly quickstart documentation](https://straitly.ai/docs/quickstart).
