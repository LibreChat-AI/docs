---
title: KovAPI
description: Configure KovAPI as a custom endpoint in LibreChat.
---

KovAPI (formerly NezhaGate) is an OpenAI-compatible API for AI models: one key for Claude, GPT, Gemini, DeepSeek and Grok chat, plus image and video models such as Seedance, Veo, Kling, Nano Banana and GPT Image. LibreChat uses its chat models through a custom endpoint.

## Get an API key

Create an account at [kovapi.com](https://kovapi.com/) and create a key on the [API Keys page](https://kovapi.com/keys). Add it to your `.env` file:

```bash filename=".env"
KOVAPI_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "KovAPI"
      apiKey: "${KOVAPI_API_KEY}"
      baseURL: "https://kovapi.com/v1"
      models:
        default: [
          "gpt-6-astra",
          "gpt-6.1-sol",
          "gpt-6-sol",
          "gpt-5.6-luna",
          "claude-sonnet-4-6",
          "grok-4.7",
          "deepseek-v4.1-flash",
          ]
        fetch: false
      titleConvo: true
      titleModel: "gpt-5.6-luna"
      modelDisplayLabel: "KovAPI"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`. Users then see a key input field when they select the endpoint.

## Notes

- `fetch` is set to `false` because `GET /v1/models` on KovAPI also returns its image and video model IDs, which LibreChat can't use as chat models. Add or remove chat model IDs from the [chat model list](https://kovapi.com/market?cat=chat) by hand.
- Model IDs, parameters and per-model notes are in the [KovAPI API docs](https://docs.kovapi.com/).
