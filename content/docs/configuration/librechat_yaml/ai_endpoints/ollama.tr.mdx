Ollama, açık kaynaklı modelleri yerel olarak çalıştırır ve OpenAI uyumlu bir API sunar, böylece LibreChat'i kendi makinenize yönlendirebilirsiniz. `ollama run <model>` komutuyla modelleri indirin ve [Ollama Library](https://ollama.com/library) üzerinden nelerin mevcut olduğuna göz atın.

## Yapılandırma [#configuration]

Ollama API anahtarını görmezden gelir ancak yine de alanın mevcut olmasını bekler, bu nedenle onu herhangi bir yer tutucu (placeholder) ile ayarlayın. `baseURL` değerini Ollama sunucunuza yönlendirin. Uç noktayı (endpoint) `librechat.yaml` dosyanızdaki `endpoints` altındaki `custom` listesine ekleyin. Dosyanızda zaten bir `endpoints.custom` listesi varsa, aynı girintiyi koruyarak yalnızca `- name:` girişini içine yapıştırın:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Ollama"
      apiKey: "ollama"
      # use 'host.docker.internal' instead of localhost if running LibreChat in a docker container
      baseURL: "http://localhost:11434/v1/" 
      models:
        default: [
          "llama2",
          "mistral",
          "codellama",
          "dolphin-mixtral",
          "mistral-openorca"
          ]
        # fetching list of models is supported but the `name` field must start
        # with `ollama` (case-insensitive), as it does in this example.
        fetch: true
      titleConvo: true
      titleModel: "current_model"
      summarize: false
      summaryModel: "current_model"
      modelDisplayLabel: "Ollama"
```

## Notlar [#notes]

- `titleModel` değerini `"current_model"` olarak ayarlayın; böylece başlık oluşturma işlemi ikinci bir model yüklemek yerine mevcut konuşmanın modelini yeniden kullanır. Bu, Ollama'nın her konuşma için tek bir yüklü modelde kalmasını sağlar.
- Yukarıdaki `default` dizisi, popüler modellerin örnek bir listesidir. `fetch: true` ile LibreChat, tam listeyi sunucunuzdan çeker.

<Callout type="tip" title="Ollama -> llama3">

`stop` parametresi [varsayılan parametrelerden](/docs/configuration/librechat_yaml/object_structure/default_params) kaldırıldığında, aşağıdaki sorun artık oluşmamalıdır.

`llama3` durmadan üretmeye devam ederse, durdurma dizileriyle birlikte bir `addParams` bloğu ekleyin:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Ollama"
      apiKey: "ollama"
      baseURL: "http://host.docker.internal:11434/v1/"
      models:
        default: [
          "llama3"
        ]
        fetch: false # pinned to the list above; set true to discover models from the server
      titleConvo: true
      titleModel: "current_model"
      summarize: false
      summaryModel: "current_model"
      modelDisplayLabel: "Ollama"
      addParams:
          "stop": [
              "<|start_header_id|>",
              "<|end_header_id|>",
              "<|eot_id|>",
              "<|reserved_special_token"
          ]
```

Eğer Ollama ile sadece `llama3` çalıştırıyorsanız, `addParams` aracılığıyla yapılandırma düzeyinde `stop` ayarı yapmak uygundur. Birden fazla model çalıştırdığınızda, bunun yerine arayüz üzerinden konuşma parametreleri ve hazır ayarlar (presets) aracılığıyla durdurma dizileri ekleyin ve `addParams` kısmını atlayın:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Ollama"
      apiKey: "ollama"
      baseURL: "http://host.docker.internal:11434/v1/" 
      models:
        default: [
          "llama3:latest",
          "mistral"
          ]
        fetch: false # pinned to the list above; set true to discover models from the server
      titleConvo: true
      titleModel: "current_model"
      modelDisplayLabel: "Ollama"
```

Sohbet parametrelerinde durdurma dizilerini (stop sequences) ayarlayın (ve bunları bir ön ayar olarak kaydedin). Ollama endpoint üzerinde bir sohbet açın, sağ taraftaki parametre panelini açın ve her bir diziyi **Stop Sequences** altına ekleyin:

## Sorun Giderme [#troubleshooting]

### Ollama görünmüyor veya model listesi boş [#ollama-does-not-appear-or-the-model-list-is-empty]

Bunları sırasıyla uygulayın:

1. **Uç noktanın (endpoint) kabuğunuzdan değil, LibreChat üzerinden erişilebilir olduğunu kontrol edin.** Eğer LibreChat Docker içinde çalışıyorsa, `localhost` ana makineniz değil, API kapsayıcısının kendisidir. Docker Desktop üzerinde `http://host.docker.internal:11434/v1/` adresini veya `host.docker.internal` adresinin kullanılamadığı Linux sistemlerde ana makinenin yerel ağ (LAN) adresini kullanın. LibreChat'in Docker dışında çalıştırılması, `http://localhost:11434/v1/` adresinin doğru olduğu tek durumdur.
2. **Ollama'nın loopback dışında dinlediğinden emin olun.** Varsayılan olarak Ollama `127.0.0.1` adresine bağlanır, bu adrese bir konteyner erişemez. Ollama'nın kendi ortamında `OLLAMA_HOST=0.0.0.0` ayarını yapın ve yeniden başlatın.

   <Callout type="warning" title="0.0.0.0 adresine bağlamak, Ollama'yı tüm arayüzlerde erişilebilir kılar">
   Ollama'nın API'si kimlik doğrulaması gerektirmez. Bunu LAN veya genel bir arayüze sahip bir makinede `0.0.0.0` adresine bağlamak, 11434 numaralı bağlantı noktasına erişebilen herkese model erişimi ile modelleri çekme ve silme yetkisi verir. Bunun yerine, yalnızca LibreChat konteynerinin gerçekten ulaştığı adrese, yani compose ağının ağ geçidine (`docker network inspect <network>` komutu bunu raporlar) bağlamayı tercih edin ve 11434 numaralı bağlantı noktasını güvenlik duvarı ile kısıtlayarak başka hiçbir şeyin buraya erişememesini sağlayın.
   </Callout>
3. **Uç nokta (endpoint) adı değişikliklerinin ne anlama geldiğini bilin.** LibreChat, Ollama'nın yerel `/api/tags` yoluna yalnızca uç nokta `name` değeri büyük/küçük harf duyarsız olarak `ollama` ile başladığında erişir. Başka herhangi bir isim veya bu yerel çağrının başarısız olması durumunda, genel OpenAI uyumlu `/v1/models` isteğine geçiş yapılır. Mevcut Ollama sürümleri, yukarıdaki `/v1/` temel URL'sinde buna da yanıt verdiği için, yeniden adlandırılmış bir uç nokta genellikle yine de bir model listesi döndürür. Önek, özellikle yerel etiketler (tags) rotasına ihtiyaç duyduğunuzda önemlidir; `/v1/models` hizmeti sunan ancak `/api/tags` sunmayan barındırılan bir proxy için bu öneki kullanmamak daha iyidir.
4. `apiKey` değerini boş olmayan herhangi bir yer tutucuya ayarlayın. Ollama bu değeri görmezden gelir, ancak `apiKey` içermeyen özel bir endpoint, yapılandırma yüklenirken devre dışı bırakılır.
5. **API günlüklerini okuyun.** `docker compose logs api` komutu, bağlantı hatasını ve aslında denediği URL'i raporlar.

### Uzak veya barındırılan bir Ollama sunucusu kullanma [#using-a-remote-or-hosted-ollama-server]

URL dışında yerel bir yapılandırma gerektirmez: `baseURL` değerini uzak sunucunun OpenAI uyumlu yoluna yönlendirin ve yer tutucu yerine `apiKey` kısmına kimlik bilgilerinizi girin. İstediğiniz ismi verebilirsiniz: model getirme işlemi, genellikle barındırılan bir proxy'nin sunduğu OpenAI uyumlu `/v1/models` rotasına geri döner.

`apiKey` is only ever sent as `Authorization: Bearer <key>`, and only when your `headers` block has not already set an `Authorization` header. If your hosted proxy expects a different scheme, such as `X-API-Key` or Basic auth, put the real credential in `headers`: an `Authorization` entry there replaces the Bearer fallback, and any other header is sent alongside it. `apiKey` still has to be non-empty either way, because an endpoint without one is dropped at config load.

```yaml filename="excerpt of librechat.yaml"
- name: "Ollama"
  apiKey: "unused"
  baseURL: "https://ollama.example.com/v1/"
  headers:
    X-API-Key: "${OLLAMA_PROXY_KEY}"
  models:
    default: ["llama3:latest"]
    fetch: true
```
