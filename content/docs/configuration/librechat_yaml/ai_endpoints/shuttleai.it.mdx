ShuttleAI fornisce l'accesso ai suoi modelli Shuttle tramite un'API compatibile con OpenAI, utilizzata in LibreChat come endpoint personalizzato.

## Ottieni una API key [#get-an-api-key]

Crea una chiave dalla [pagina delle chiavi di ShuttleAI](https://shuttleai.com/keys). Aggiungila al tuo file `.env`:

```bash filename=".env"
SHUTTLEAI_API_KEY=your-api-key
```

## Configurazione [#configuration]

Aggiungi l'endpoint alla lista `custom` sotto `endpoints` nel tuo `librechat.yaml`. Se il tuo file ha già una lista `endpoints.custom`, incolla al suo interno solo la voce `- name:`, mantenendo la stessa indentazione:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "ShuttleAI"
      apiKey: "${SHUTTLEAI_API_KEY}"
      baseURL: "https://api.shuttleai.com/v1"
      models:
        default: [
          "shuttle-2.5", "shuttle-2.5-mini"
          ]
        fetch: true
      titleConvo: true
      titleModel: "shuttle-2.5-mini"
      summarize: false
      summaryModel: "shuttle-2.5-mini"
      modelDisplayLabel: "ShuttleAI"
      dropParams: ["user", "stop"]
```
