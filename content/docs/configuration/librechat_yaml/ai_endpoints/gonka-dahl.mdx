Gonka DAHL is an OpenAI-compatible inference API for open-weight models served on the Gonka decentralized GPU network. A new account gets 100 million free tokens, and sign-up asks for a username only.

## Get an API key

1. Create an account at [inference.dahl.global](https://inference.dahl.global) and save the fingerprint it shows. It works as your password and cannot be recovered.
2. On the [account page](https://inference.dahl.global/account), allocate tokens from your pool to an API key. New keys start with 0 tokens.
3. Add the key to your `.env` file:

```bash filename=".env"
DAHL_API_KEY=your-api-key
```

## Configuration

Add the endpoint under `endpoints.custom` in your `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: "Gonka DAHL"
      apiKey: "${DAHL_API_KEY}"
      baseURL: "https://inference.dahl.global/v1"
      models:
        default: [
          "MiniMaxAI/MiniMax-M2.7",
          "deepseek-ai/DeepSeek-V4-Flash-0731",
          "zai-org/GLM-5.3-Flash"
        ]
        fetch: true
      titleConvo: true
      titleModel: "current_model"
      modelDisplayLabel: "Gonka DAHL"
```

## Notes

- `fetch: true` loads the live list from `GET /v1/models`, and the `default` list is the fallback. Model IDs change over time, so check the [models docs](https://inference.dahl.global/docs/models/).
- MiniMax M2.7 returns its reasoning inside `<think>` tags in the message content.
- Busy models can return a `model_concurrency` error at peak times, and signed-in and paid accounts are admitted first. Switch to another model or retry.
- Top-ups are paid from the account page. See [Tokens & keys](https://inference.dahl.global/docs/tokens/).
