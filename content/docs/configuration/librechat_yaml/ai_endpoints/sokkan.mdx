[SOKKAN Router](https://router.sokkan.ch) is an OpenAI-compatible inference gateway operated by NINABOT Sàrl (Geneva, Switzerland). It serves open-weight models from the EU and Switzerland and supports streaming and tool calls, so you can add it to LibreChat through `endpoints.custom`.

## Get an API key

Create an account at [router.sokkan.ch](https://router.sokkan.ch), add prepaid credit and create an API key from the account page (keys start with `skr_`). Add it to your `.env` file:

```bash filename=".env"
SOKKAN_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "SOKKAN"
      apiKey: "${SOKKAN_API_KEY}"
      baseURL: "https://router.sokkan.ch/v1"
      models:
        default:
          - "qwen/qwen3.6-35b-a3b-eu"
          - "qwen/qwen3.8-27b"
          - "qwen/qwen3.5-397b-a17b"
          - "openai/gpt-oss-120b"
          - "openai/gpt-oss-20b"
        fetch: false
      titleConvo: true
      titleModel: "openai/gpt-oss-20b"
      modelDisplayLabel: "SOKKAN Router"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

### Restrict the data location

SOKKAN Router accepts an `X-Data-Location` header (`CH`, `EU` or `any`) that limits where a request may run. A model that does not run in the requested location returns `400` with code `no_provider` instead of being sent elsewhere:

```yaml filename="librechat.yaml"
    - name: "SOKKAN"
      # ...same settings as above
      headers:
        X-Data-Location: "EU"
```

## Notes

- `fetch` is set to `false` on purpose: the public `/v1/models` list also contains models offered only with committed throughput, which return `403 committed_throughput` on a pay-per-token key. Pick model IDs from the [models and pricing page](https://router.sokkan.ch/models).
- Non-streamed responses are cut by a 100 s proxy timeout; LibreChat streams by default, which avoids it.
- Every response carries `usage.cost` in USD, and the `x-sokkan-region` response header names the region that served it.
- Model availability can change over time. If a selected model is unavailable, choose another one from the catalog.
