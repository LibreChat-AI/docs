BoostRail is an OpenAI- and Anthropic-compatible API for text, image and video models from multiple labs. LibreChat connects to its OpenAI-compatible endpoint through `endpoints.custom`.

## Get an API key

Create an account at [BoostRail](https://www.boostrail.com) and create an API key in the [console](https://app.boostrail.com). Keys start with `br_`. Add the key to your `.env` file:

```bash filename=".env"
BOOSTRAIL_API_KEY=br_your-key-here
```

## Configuration

Add the endpoint under `endpoints.custom` in your `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: "BoostRail"
      apiKey: "${BOOSTRAIL_API_KEY}"
      baseURL: "https://api.boostrail.com/v1"
      models:
        default: ["deepseek-v4.1-flash"]
        fetch: true
      titleConvo: true
      titleModel: "deepseek-v4.1-flash"
      modelDisplayLabel: "BoostRail"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from BoostRail's `/v1/models` endpoint. The `default` list is used only if that request fails.
- Models marked `byok_only` in the `/v1/models` response run on your own key for that lab, added in the BoostRail console. See [Bring your own key](https://www.boostrail.com/byok/).
- Model ids and per-token prices are listed on the [BoostRail Models page](https://www.boostrail.com/models/). BoostRail's own setup guide for LibreChat is in its [docs](https://www.boostrail.com/docs/frameworks/#librechat).
