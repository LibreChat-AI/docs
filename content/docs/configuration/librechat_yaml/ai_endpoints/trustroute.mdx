> TrustRoute API key: [trustroute.ch/dashboard](https://trustroute.ch/dashboard)

**Notes:**

- **Known:** OpenAI-compatible gateway hosted in Switzerland. Fetching the model list is recommended: it returns only the models your organization's policy allows.
- Every response carries `X-TrustRoute-Provider`, `X-TrustRoute-Tier` and `X-TrustRoute-Processing` headers that name the provider that served the call and whether processing stayed in Switzerland.
- Model IDs are listed in the [catalog](https://trustroute.ch/models).

```yaml
    - name: "TrustRoute"
      apiKey: "${TRUSTROUTE_API_KEY}"
      baseURL: "https://api.trustroute.ch/v1"
      models:
        default: [
          "apertus-v1-5-70b",
          "qwen3-5-397b-a17b",
          "gemma-4-31b-it"
          ]
        fetch: true
      titleConvo: true
      titleModel: "gemma-4-31b-it"
      summarize: false
      summaryModel: "gemma-4-31b-it"
      modelDisplayLabel: "TrustRoute"
```
