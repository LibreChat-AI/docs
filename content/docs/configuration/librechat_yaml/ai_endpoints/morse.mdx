[Morse](https://trymorse.ai/inference?src=gh-librechat) is private, OpenAI-compatible inference: 80+ open-weight models at a privacy tier you choose per request (Private, TEE or E2EE), from an open-source, attestable enclave. You can add it to LibreChat through `endpoints.custom`.

## Get an API key

Create an API key in the [Morse console](https://console.trymorse.ai). Add it to your `.env` file:

```bash filename=".env"
MORSE_API_KEY=sk_morse_...
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Morse"
      apiKey: "${MORSE_API_KEY}"
      baseURL: "https://inference.trymorse.ai/v1"
      models:
        default:
          - "z-ai/glm-5.3-flash"
          - "moonshotai/kimi-k3.1-pro"
          - "deepseek/deepseek-v4.1-flash"
          - "qwen/qwen3.8-2.4t-a95b"
        fetch: true
      titleConvo: true
      titleModel: "z-ai/glm-5.3-flash"
      modelDisplayLabel: "Morse"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Set a privacy floor

Each request runs at the privacy tier you pick, and Morse refuses a request no endpoint can meet instead of sending it at a lower tier. To hold every request from this endpoint to a floor, add it to the request body with `addParams`:

```yaml filename="librechat.yaml"
      addParams:
        provider:
          min_privacy: "tee"
```

You can also set the floor on the API key in the Morse console. See [Provider routing](https://trymorse.ai/inference/docs/provider-routing?src=gh-librechat).

## Notes

- With `fetch: true`, LibreChat loads the model list from Morse's OpenAI-compatible `/v1/models` endpoint using your key. The `default` array is only the initial selection.
- Use model IDs exactly as they appear in the [Morse model list](https://trymorse.ai/inference/models?src=gh-librechat), with the lab in front (for example `z-ai/glm-5.3-flash`).
- A reasoning model's thinking comes back in `reasoning_content`, and tool calls work with Agents.
