[ScaledThought](https://scaledthought.com/go/org-librechat) provides an OpenAI-compatible API for open-weight models that you can add to LibreChat through `endpoints.custom`. It is paid from prepaid credits, with no subscription.

## Get an API key

Create an account and a key with the ScaledThought CLI, then create a link to approve a prepaid top-up by card:

```bash
npx -y scaledthought@latest init --region us --source org-librechat
npx -y scaledthought@latest billing topup --amount-usd 20
```

`init` saves the key as `ST_API_KEY` in a `.env` file in the current directory. Add it to LibreChat's `.env` file:

```bash filename=".env"
ST_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "ScaledThought"
      apiKey: "${ST_API_KEY}"
      baseURL: "https://api.us.scaledthought.com/v1"
      models:
        default:
          - "deepseek-v4-1-flash"
        fetch: true
      titleConvo: true
      titleModel: "current_model"
      addParams:
        max_tokens: 8192
      modelDisplayLabel: "ScaledThought"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from ScaledThought's OpenAI-compatible `/v1/models` endpoint. The `default` array is only the initial selection.
- Model availability and prices can change over time. See [scaledthought.com/pricing](https://scaledthought.com/pricing) for the current models and prices.
- LibreChat doesn't send `max_tokens` by default, and ScaledThought applies a short default output cap to requests without it, so the example sets one with `addParams` (see [default parameters](/docs/configuration/librechat_yaml/object_structure/default_params)). Adjust the value to your needs.
- The base URL above is the US region.
