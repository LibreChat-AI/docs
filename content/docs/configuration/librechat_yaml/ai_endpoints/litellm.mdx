LiteLLM Proxy is a self-hosted gateway that exposes models from many providers through a single OpenAI-compatible endpoint, so you can point LibreChat at your own proxy.

## Configuration

The API key matches the value set in your LiteLLM proxy config rather than a provider key, so use the placeholder below or your own. Point `baseURL` at your running proxy. Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "LiteLLM"
      apiKey: "sk-from-config-file"
      baseURL: "http://localhost:8000/v1"
      # if using LiteLLM example in docker-compose.override.yml.example, use "http://litellm:8000/v1"
      models:
        default: ["gpt-3.5-turbo"]
        fetch: true
      titleConvo: true
      titleModel: "gpt-3.5-turbo"
      summarize: false
      summaryModel: "gpt-3.5-turbo"
      modelDisplayLabel: "LiteLLM"
```

## Automatic Pricing

Naming the endpoint exactly `"LiteLLM"` (case-insensitive) also enables automatic per-model pricing. LibreChat calls your proxy's `/model/info` route using the same `apiKey` configured above — no admin/master key needed, as long as that key is allowed to call `info_routes` on your proxy (some virtual keys are scoped to inference routes only; check your proxy's key permissions if pricing doesn't populate).

Cost is read directly from LiteLLM's own model cost map, including cached-input rates where your proxy reports them. Models your proxy doesn't have pricing for are left unpriced rather than charged nothing — LibreChat falls back to its built-in rate tables for those, and logs a one-time warning per model so you know pricing wasn't found automatically.

<Callout type="warn" title="tokenConfig disables this fetch entirely">

If you add a manual [`tokenConfig`](/docs/configuration/librechat_yaml/object_structure/custom_endpoint#tokenconfig) block to this endpoint, automatic pricing turns off for **every** model on the endpoint, not just the ones you listed. Use `tokenConfig` only if you want full manual control; otherwise leave it out and let the automatic fetch handle it.

</Callout>

## Notes

- See [Using LibreChat with LiteLLM Proxy](/blog/2023-11-30_litellm) for a full walkthrough of setting up the proxy.
- With `fetch: true`, LibreChat loads the full list of models configured in your proxy, so `default` is only the initial selection.
- If you run the bundled proxy from `docker-compose.override.yml.example`, set `baseURL` to `http://litellm:8000/v1` so the containers reach each other by service name.
- Pricing refreshes on the same schedule as the model list (`models.fetch: true`) — there's no separate refresh interval to configure.
