Weflayr is an LLM gateway with an OpenAI-compatible endpoint. One key reaches models from Anthropic, OpenAI, Google, Mistral, DeepSeek, Moonshot, Alibaba and other providers, and you can add it to LibreChat through `endpoints.custom`.

## Get an API key

Create an [API key with the Gateway scope](https://docs.weflayr.com/product/api-keys) in Weflayr. Add it to your `.env` file:

```bash filename=".env"
WEFLAYR_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "weflayr"
      apiKey: "${WEFLAYR_API_KEY}"
      baseURL: "https://gateway.weflayr.com/v1"
      models:
        default:
          - "claude-sonnet-5.5"
          - "gpt-6.2-sol"
        fetch: true
      titleConvo: true
      titleModel: "claude-haiku-5.5"
      modelDisplayLabel: "Weflayr"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from Weflayr's OpenAI-compatible `/v1/models` endpoint. The `default` array is only the initial selection.
- Use model IDs exactly as they appear in the [Weflayr model catalog](https://weflayr.com/models/), without a provider prefix (`gpt-6.2-sol`, not `openai/gpt-6.2-sol`).
- The fetched list also includes your project's routing strategies, as `strategy/<slug>`. Selecting one lets Weflayr pick the model for each request.
