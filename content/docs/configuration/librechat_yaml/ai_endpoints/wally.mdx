Wally serves open-weight models such as GLM-5.3 Flash, DeepSeek V4.1 Flash, Kimi K3, and MiniMax M3 through an OpenAI-compatible API that you can add to LibreChat as a custom endpoint.

## Get an API key

Create a key from [Wally](https://www.runwally.com). Add it to your `.env` file:

```bash filename=".env"
WALLY_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Wally"
      apiKey: "${WALLY_API_KEY}"
      baseURL: "https://inference.runanywhere.ai/v1"
      models:
        default:
          - "glm-5.3-flash"
          - "deepseek-v4.1-flash"
          - "deepseek-v4.1-flash-fast"
          - "deepseek-v4-flash-0731"
          - "deepseek-v4-pro-fast"
          - "glm-5.3-fast"
          - "kimi-k3"
          - "minimax-m3"
        fetch: true
      titleConvo: true
      titleModel: "glm-5.3-flash"
      modelDisplayLabel: "Wally"
```

## Notes

- With `fetch: true`, LibreChat loads the model list from Wally's `/v1/models` endpoint. The `default` array is only the initial selection.
- All eight models support tool calling and work with [Agents](/docs/features/agents).
- DeepSeek V4.1 Flash, DeepSeek V4.1 Flash (Fast), and Kimi K3 also accept image input.
- Thinking streams as the model's thought process. GLM-5.3 Flash, GLM-5.3 (Fast), and MiniMax M3 always think. The DeepSeek V4.1 models and Kimi K3 think by default, and `reasoning_effort: "none"` turns it off. DeepSeek V4 Pro (Fast) and DeepSeek V4 Flash 0731 think only when `reasoning_effort` asks for it.
- `addParams` applies to every model on the endpoint, and the always-thinking models reject `reasoning_effort: "none"`. To run without thinking, add a second endpoint that lists only the DeepSeek and Kimi models and set `addParams: { reasoning_effort: "none" }` on it.
- See the [Wally API docs](https://docs.runanywhere.ai/wally-cloud/api) and [pricing](https://www.runwally.com/pricing) for model details.
