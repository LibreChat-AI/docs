Abstract serves open-weight models (GLM-5.3, DeepSeek-V4-Flash, Kimi-K3) through the OpenAI-compatible Chat Completions API (`/v1/chat/completions`), which you can add to LibreChat as a custom endpoint.

## Get an API key

Create a key at [platform.abstract.inc/keys](https://platform.abstract.inc/keys). Add it to your `.env` file:

```bash filename=".env"
ABSTRACT_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Abstract"
      apiKey: "${ABSTRACT_API_KEY}"
      baseURL: "https://api.abstract.inc/v1"
      models:
        default:
          - "glm-5.3:superfast"
          - "deepseek-v4-flash:superfast"
          - "kimi-k3:superfast"
        fetch: false
      titleConvo: true
      titleModel: "deepseek-v4-flash:superfast"
      modelDisplayLabel: "Abstract"
```

## Notes

- Replies stream over Chat Completions, with token usage in the final chunk.
- Keep `fetch: false`. Abstract's `/v1/models` also lists background (`:async`) models, which send their reply only once it is complete.
- The models accept text input only. See the [Abstract docs](https://abstract.inc/docs) for limits and pricing.
