---
title: Ezkielyna
description: Configure Ezkielyna as a custom endpoint in LibreChat.
---

Ezkielyna is an independent API gateway with an OpenAI-compatible endpoint that serves models from several labs, including DeepSeek, GLM, Qwen and MiniMax. You can add it to LibreChat through `endpoints.custom`.

## Get an API key

Create an API key in the [Ezkielyna dashboard](https://api.ezkielyna.store). Add it to your `.env` file:

```bash filename=".env"
EZKIELYNA_API_KEY=your-api-key
```

Each key belongs to a key group. A Standard key can call the models in the example below. Claude, GPT, Grok and Gemini Pro models need a key in the Auto or Premium group.

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Ezkielyna"
      apiKey: "${EZKIELYNA_API_KEY}"
      baseURL: "https://api.ezkielyna.store/v1"
      models:
        default:
          - "deepseek-v4.1-flash"
          - "deepseek-v4-pro"
          - "glm-5.3"
          - "glm-5.3-flash"
        fetch: true
      titleConvo: true
      titleModel: "deepseek-v4.1-flash"
      modelDisplayLabel: "Ezkielyna"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from the authenticated `/v1/models` endpoint, which lists the models available to your key. The `default` array is only the initial selection.
- Use model IDs exactly as they appear in the [model catalog](https://ezkielyna.store/models) or the public [pricing endpoint](https://api.ezkielyna.store/api/pricing).
- Model availability can change over time. The [status page](https://api.ezkielyna.store/status) shows each model's recent success rate and latency.
