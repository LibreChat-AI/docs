TopxAI serves compatible Claude, GPT, Grok, GLM, Kimi and DeepSeek chat models through one OpenAI-compatible endpoint with one prepaid key. Every model has a fixed USD price per route, listed at [api.topxai.xyz/pricing](https://api.topxai.xyz/pricing).

## Get an API key

Sign in at [api.topxai.xyz](https://api.topxai.xyz/) and create a key on the **Keys** page; pick **Auto route** so one key covers the available chat models. Add it to your `.env` file:

```bash filename=".env"
TOPXAI_API_KEY=sk-your-key-here
```

## Configuration

Add the endpoint under `endpoints.custom` in your `librechat.yaml`:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "TopxAI"
      apiKey: "${TOPXAI_API_KEY}"
      baseURL: "https://api.topxai.xyz/v1"
      models:
        default: ["claude-sonnet-5-5", "gpt-6.2-astra", "gpt-6.2-sol", "grok-4.7", "kimi-k3.1-pro", "deepseek-flash-Abliterated"]
        fetch: false
      titleConvo: true
      titleModel: "gpt-6.2-sol"
      modelDisplayLabel: "TopxAI"
```

Choose text models available to your key and set `titleModel` to one of them. Keeping `fetch: false` limits the picker to that list. A key with access to several TopxAI routes can also see image, video and System One models in `/v1/models`, which LibreChat's OpenAI-compatible chat configuration cannot use for text conversations.

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- Model ids are the plain names from the [price list](https://api.topxai.xyz/api/pricing) (`claude-sonnet-5-5`, `gpt-6.2-sol`, `grok-4.7` and so on), with no provider prefix.
- A key can be pinned to one route (for example `claude-shared`) or set to Auto route; a model the key's route does not sell answers `403` with "Model is not available on this API key route". See [routes and prices](https://api.topxai.xyz/docs/shared-pool-official-line-and-auto-route).
- This example uses Chat Completions. To use Claude through the native Messages API, configure a separate [Anthropic custom endpoint](/docs/configuration/librechat_yaml/object_structure/custom_endpoint#provider) with `provider: anthropic`, `baseURL: "https://api.topxai.xyz"` and an explicit list of Claude model IDs. See the [TopxAI API reference](https://api.topxai.xyz/docs/api-reference).
