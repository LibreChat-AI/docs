UplinkSwitch is an API gateway that serves models from Anthropic, OpenAI, Google, xAI, DeepSeek and other developers through one OpenAI-compatible endpoint, used in LibreChat as a custom endpoint.

## Get an API key

Create a key from the [UplinkSwitch console](https://uplinkswitch.com/console). Add it to your `.env` file:

```bash filename=".env"
UPLINKSWITCH_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "UplinkSwitch"
      apiKey: "${UPLINKSWITCH_API_KEY}"
      baseURL: "https://api.uplinkswitch.com/v1"
      models:
        default: [
          "claude-sonnet-5-5",
          "claude-opus-5-5",
          "gpt-6.1-sol",
          "gemini-3.1-pro-preview",
          "grok-4.6",
          "deepseek-v4-pro-0813"
          ]
        fetch: true
      titleConvo: true
      titleModel: "gpt-6.1-sol"
      summarize: false
      summaryModel: "gpt-6.1-sol"
      modelDisplayLabel: "UplinkSwitch"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from UplinkSwitch's `/v1/models` endpoint. The `default` array is only the initial selection.
- Use model IDs exactly as they appear on the [UplinkSwitch models page](https://uplinkswitch.com/models). The same list, with prices, is public JSON at `https://api.uplinkswitch.com/v1/catalog` and needs no key.
- UplinkSwitch bills prepaid credit, starting at $10, with no subscription.
