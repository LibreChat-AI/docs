[ProxyStacks Relay](https://proxystacks.com) is an AI inference gateway that provides unified OpenAI-compatible access to frontier reasoning and coding models with transparent pay-as-you-go billing and low-latency global routing.

## Get an API key

Create an account and generate an API key from [ProxyStacks Relay](https://proxystacks.com). Add it to your `.env` file:

```bash filename=".env"
RELAY_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "ProxyStacks Relay"
      apiKey: "${RELAY_API_KEY}"
      baseURL: "https://proxystacks.com/v1"
      models:
        default:
          - "kimi-k3.1-pro"
          - "glm-5.3"
          - "deepseek-v4.1-flash"
          - "gpt-5.4"
        fetch: true
      titleConvo: true
      titleModel: "deepseek-v4.1-flash"
      modelDisplayLabel: "ProxyStacks Relay"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the available model list directly from ProxyStacks Relay's OpenAI-compatible `/v1/models` endpoint. The `default` array serves as the fallback and initial selection.
- Browse exact model IDs, context windows, and per-token rates in the [ProxyStacks model catalog](https://proxystacks.com/en/models) and [pricing page](https://proxystacks.com/en/pricing).
- Deployments in Mainland China and Asia-Pacific can optionally set `baseURL` to `"https://hk.proxystacks.com/v1"` for lower-latency routing. See the [ProxyStacks documentation](https://proxystacks.com/en/docs) for details.
