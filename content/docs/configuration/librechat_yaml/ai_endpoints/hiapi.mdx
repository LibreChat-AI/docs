[HiAPI](https://hiapi.ai) is a pay-as-you-go API gateway that serves Claude, GPT, DeepSeek, Kimi, GLM and Grok models behind one OpenAI-compatible endpoint. You can add it to LibreChat through `endpoints.custom`.

## Get an API key

Create an API key from the [HiAPI dashboard](https://hiapi.ai/en/dashboard/api-keys). Add it to your `.env` file:

```bash filename=".env"
HIAPI_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "HiAPI"
      apiKey: "${HIAPI_API_KEY}"
      baseURL: "https://api.hiapi.sh/v1"
      models:
        default:
          - "claude-opus-5-5"
          - "claude-opus-5-5@aws"
          - "deepseek-v4-flash"
          - "deepseek-v4-flash-vision-exp"
          - "deepseek-v4-pro"
          - "deepseek-v4.1-flash"
          - "glm-5.3"
          - "gpt-6-astra"
          - "gpt-6.1-sol"
          - "gpt-6.1-terra"
          - "grok-4.6"
          - "grok-4.7"
          - "kimi-k3"
          - "kimi-k3.1-pro"
          - "kimi-k3.1-pro-highspeed"
        fetch: false
      titleConvo: true
      titleModel: "deepseek-v4-flash"
      modelDisplayLabel: "HiAPI"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- The model list above is written out by hand. HiAPI's `/v1/models` endpoint also returns image and video generation models, so `fetch: false` keeps the model selector limited to chat models.
- Browse the current chat models and prices on the [HiAPI pricing page](https://hiapi.ai/en/pricing), and use the model IDs exactly as they appear there.
- Several of these models spend tokens on reasoning before they answer. If a request sets a small `max_tokens`, the reply can come back with empty content because the limit was used up on reasoning.
