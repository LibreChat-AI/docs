[HopBase](https://hop-base.com/?utm_source=librechat&utm_medium=listing) is an enterprise AI gateway that serves GPT, Gemini, DeepSeek, Qwen, GLM, Kimi, Doubao Seed, Grok and Claude models, plus image and video models, behind one API key, with high-concurrency routing and automatic failover. Chat models other than Claude are available through an OpenAI-compatible endpoint that you can add to LibreChat through `endpoints.custom`.

## Get an API key

Sign in to the [HopBase console](https://api.hop-base.com/login) and create an API key. Each key includes one or more model groups, chosen when the key is created, and can call only the models in those groups. Add the key to your `.env` file:

```bash filename=".env"
HOPBASE_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "HopBase"
      apiKey: "${HOPBASE_API_KEY}"
      baseURL: "https://api.hop-base.com/v1"
      models:
        default:
          - "deepseek-v4.1-flash"
          - "qwen3.8-max"
          - "gpt-6-sol"
        fetch: true
      titleConvo: true
      titleModel: "current_model"
      modelDisplayLabel: "HopBase"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from HopBase's `/v1/models` endpoint. The list is authenticated and scoped to the key, so it shows only the models in the key's groups. The `default` array is only the initial selection; replace it with IDs your key can use.
- Use model IDs exactly as they appear in the [HopBase model catalog](https://hop-base.com/models?utm_source=librechat&utm_medium=listing). Examples include `gpt-6-sol`, `deepseek-v4.1-flash`, `qwen3.8-max`, `kimi-k3` and `glm-5.3-flash`.
- Claude models use the Anthropic protocol rather than the OpenAI-compatible endpoint. To use them, configure LibreChat's built-in Anthropic endpoint with a HopBase key that includes a Claude group, and set `ANTHROPIC_REVERSE_PROXY=https://api.hop-base.com` (no `/v1`) in your `.env` file.
- See the [HopBase documentation](https://hop-base.com/en/docs?utm_source=librechat&utm_medium=listing) for supported parameters and protocol details.
