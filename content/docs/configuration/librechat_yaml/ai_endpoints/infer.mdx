Infer by Flow7 provides an OpenAI-compatible endpoint that you can add to LibreChat through `endpoints.custom`. One API key reaches models from Anthropic, OpenAI, Google, xAI and others. The suffix of each model ID picks its route: `:low-cost`, `:balanced`, `:stable` or `:official`.

## Get an API key

Create an API key in the [Infer dashboard](https://infer.flow7.org/app#/keys). Infer is prepaid, so add wallet credit before the first request. Add the key to your `.env` file:

```bash filename=".env"
INFER_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "infer"
      apiKey: "${INFER_API_KEY}"
      baseURL: "https://infer.flow7.org/v1"
      models:
        default:
          - "infer/claude-opus-5-5:low-cost"
          - "infer/gpt-6.1-sol:low-cost"
          - "infer/claude-haiku-4-5:low-cost"
        fetch: true
      titleConvo: true
      titleModel: "infer/claude-haiku-4-5:low-cost"
      modelDisplayLabel: "Infer"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from Infer's OpenAI-compatible `/v1/models` endpoint. The `default` array is only the initial selection.
- The fetched list also includes image and video generation models. They don't work in chat, so pick a text model.
- Use model IDs exactly as Infer lists them, with the `infer/` prefix and the route suffix. The [Infer models page](https://infer.flow7.org/models) shows each route's price, context window and current availability.
- Low cost routes take text and tool calls. For image input, use a model's `:official` route.
