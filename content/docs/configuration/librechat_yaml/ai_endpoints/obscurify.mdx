[Obscurify.ai](https://obscurify.ai/?utm_source=librechat) is an OpenAI-compatible API for 200+ models (GPT, Claude, Gemini, DeepSeek, Qwen, GLM and others). Accounts are a random account number with no email, and requests only use zero-data-retention routes. Add it to LibreChat as a custom endpoint.

## Get an API key

Create an account at [obscurify.ai](https://obscurify.ai/?utm_source=librechat) (new accounts get $1 of starter credit), then click **Show API Key** on the account page and copy the key (`sk-obs1_...`). Add it to your `.env` file:

```bash filename=".env"
OBSCURIFY_API_KEY=sk-obs1_your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Obscurify"
      apiKey: "${OBSCURIFY_API_KEY}"
      baseURL: "https://obscurify.ai/v1"
      models:
        default:
          - "deepseek/deepseek-v4-flash"
          - "z-ai/glm-5.3"
        fetch: true
      titleConvo: true
      titleModel: "deepseek/deepseek-v4-flash"
      modelDisplayLabel: "Obscurify.ai"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from Obscurify.ai's `/v1/models` endpoint. The `default` array is only the initial selection.
- Model IDs use the `<lab>/<model>` form, for example `openai/gpt-5.5` or `anthropic/claude-sonnet-5.5`. Prices for every model are on the [model cards](https://obscurify.ai/model_cards) page.
- The API works on every plan with a positive balance. Frontier models need the Casual plan and uncensored models need Pro; see [pricing](https://obscurify.ai/pricing). The full API reference is at [obscurify.ai/api-docs](https://obscurify.ai/api-docs).
