Kitani provides an OpenAI-compatible endpoint for open-weight models and community fine-tunes that you can add to LibreChat through `endpoints.custom`.

## Get an API key

Create an API key from the [Kitani dashboard](https://kitani.ai/dashboard). Add it to your `.env` file:

```bash filename=".env"
KITANI_API_KEY=your-api-key
```

## Configuration

Add the endpoint under `endpoints.custom` in your `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: "Kitani"
      apiKey: "${KITANI_API_KEY}"
      baseURL: "https://api.kitani.ai/v1"
      models:
        default:
          - "z-ai/glm-5.3"
          - "deepseek/deepseek-v4.1-flash-1017"
        fetch: true
      titleConvo: true
      titleModel: "z-ai/glm-5.3"
      modelDisplayLabel: "Kitani"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from Kitani's OpenAI-compatible `/v1/models` endpoint. The `default` array is only the initial selection.
- Use model IDs exactly as they appear on the [Kitani models page](https://kitani.ai/models).
- See the [Kitani docs](https://kitani.ai/docs) for more details.
