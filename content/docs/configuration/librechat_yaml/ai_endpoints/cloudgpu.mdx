[CloudGPU](https://cloudgpu.app) is a model API for DeepSeek, Kimi, GLM, MiniMax, Qwen and more, with an OpenAI-compatible interface that you can add to LibreChat through `endpoints.custom`.

## Get an API key

Sign up with email or Google at [cloudgpu.app](https://cloudgpu.app), create an API key, and add it to your `.env` file:

```bash filename=".env"
CLOUDGPU_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "CloudGPU"
      apiKey: "${CLOUDGPU_API_KEY}"
      baseURL: "https://cloudgpu.app/v1"
      models:
        default:
          - "deepseek-v4-flash"
          - "deepseek-v4-pro"
          - "glm-5.3"
          - "kimi-k3"
          - "qwen3.5-397b"
        fetch: true
      titleConvo: true
      titleModel: "deepseek-v4-flash"
      modelDisplayLabel: "CloudGPU"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from CloudGPU's `/v1/models` endpoint, which also lists image, speech, transcription and video models. The `default` array is only the initial selection; pick chat models.
- Model IDs have no organization prefix, for example `deepseek-v4-flash`. Use them exactly as listed at `https://cloudgpu.app/v1/models`.
