Dynoyard is an OpenAI-compatible gateway for open-weight models such as Kimi K3, GLM-5.2, MiniMax M3 and Qwen3.7, with routing and failover across the providers that serve them.

## Get an API key

Create an account at [dynoyard.app](https://dynoyard.app/), then generate a key from the [Keys page](https://dynoyard.app/keys). Keys start with `sk-dyno-`. New accounts come with a small starting credit, so you can try it before adding a card.

```bash filename=".env"
DYNOYARD_KEY=sk-dyno-your-key-here
```

Each account gets its own endpoint at `https://<your-org>.dynoyard.app/v1`. Your workspace slug is shown on the dashboard overview page, and it is part of the URL rather than a header.

## Configuration

Add the endpoint under `endpoints.custom` in your `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: "Dynoyard"
      apiKey: "${DYNOYARD_KEY}"
      baseURL: "https://your-org.dynoyard.app/v1"
      models:
        default: ["kimi-k3"]
        fetch: true
      titleConvo: true
      titleModel: "qwen-plus-3-7"
      modelDisplayLabel: "Dynoyard"
```

Replace `your-org` with your own workspace slug.

To pin a fixed model list instead of fetching the catalog, set `fetch: false` and name the models yourself:

```yaml filename="librechat.yaml"
      models:
        default: ["kimi-k3", "glm-5-2", "qwen-max-3-7", "minimax-m3"]
        fetch: false
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from your account, so models you enable later appear without a config change. The `default` array is only the initial selection.
- Model IDs are plain names like `kimi-k3` and `glm-5-2`, not `vendor/model` paths. The catalog is per account, so `fetch: true` is the reliable way to see what yours has.
- `titleModel` is worth pointing at a cheaper model than your chat default, since title generation runs on every conversation.
- Reasoning models accept `reasoning_effort`. If a model rejects a parameter LibreChat sends, add it to `dropParams` for this endpoint.
- A `402` response means the account is out of credit. Top up on the billing page and retry.
