xAIは、LibreChatにカスタムendpointとして追加できるOpenAI互換APIを通じてGrokモデルを提供しています。

## APIキーを取得する [#get-an-api-key]

[xAI console](https://console.x.ai/) からキーを作成します。それを `.env` ファイルに追加してください：

```bash filename=".env"
XAI_API_KEY=your-api-key
```

## 設定 [#configuration]

`librechat.yaml` 内の `endpoints` 配下にある `custom` リストにエンドポイントを追加します。ファイルにすでに `endpoints.custom` リストが存在する場合は、インデントを維持したまま、`- name:` エントリのみをその中に貼り付けてください。

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "xai"
      apiKey: "${XAI_API_KEY}"
      baseURL: "https://api.x.ai/v1"
      models:
        default: ["grok-beta"]
        fetch: false
      titleConvo: true
      titleMethod: "completion"
      titleModel: "grok-beta"
      summarize: false
      summaryModel: "grok-beta"
      modelDisplayLabel: "Grok"
```

## 注記 [#notes]

- `titleMethod: "completion"` は、Grokがサポートしているチャット補完エンドポイントを通じて会話タイトルを生成します。
