title: Phoenix Grove
description: Configure Phoenix Grove as a custom endpoint in LibreChat.
---

Phoenix Grove serves curated open weight models such as GLM, DeepSeek, Kimi, Qwen, and MiMo on zero retention US infrastructure, exposed through an OpenAI-compatible API that you can add to LibreChat as a custom endpoint.

## Get an API key

Create a key from the [Phoenix Grove portal](https://api.pgsgrove.com). Add it to your `.env` file:

```bash filename=".env"
PGS_API_KEY=your-api-key
```

## Configuration

Add the endpoint under `endpoints.custom` in your `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: "Phoenix Grove"
      apiKey: "${PGS_API_KEY}"
      baseURL: "https://api.pgsgrove.com/v1"
      models:
        default: [
          "glm-5.3",
          "glm-5.3-flash",
          "deepseek-v4.1-flash",
          "kimi-k2.7",
          "kimi-k3",
          "mimo-v2.6-pro",
          "qwen-3.8-2.4t",
          "nemotron-3-ultra",
          ]
        fetch: true
      titleConvo: true
      titleModel: "glm-5.3-flash"
      modelDisplayLabel: "Phoenix Grove"
```

## Notes

- `fetch: true` keeps the model list current from the live catalog. The full table with per token pricing and context windows is at [api.pgsgrove.com/models](https://api.pgsgrove.com/models).
- Reasoning capable models stream their thinking in the `reasoning_content` field of the standard chat completions delta.
