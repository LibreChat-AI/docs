FutureInfra is a Korean cloud provider whose AI router serves 300+ models from OpenAI, Anthropic, and other providers through a single OpenAI-compatible endpoint.

## Get an API key

Create an account at [futureinfra.ai](https://futureinfra.ai/) and generate a key in the console under [AI Router](https://futureinfra.ai/console/?screen=ai-router). The key starts with `pk_live_`. Add it to your `.env` file:

```bash filename=".env"
FUTUREINFRA_API_KEY=pk_live_your-key-here
```

## Configuration

Add the endpoint under `endpoints.custom` in your `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: "FutureInfra"
      apiKey: "${FUTUREINFRA_API_KEY}"
      baseURL: "https://futureinfra.ai/v1/ai"
      models:
        default: ["openai/gpt-4o-mini", "anthropic/claude-sonnet-4"]
        fetch: true
      titleConvo: true
      titleModel: "openai/gpt-4o-mini"
      modelDisplayLabel: "FutureInfra"
```

To pin a fixed model list instead of fetching the full catalog, set `fetch: false` and list the models yourself.

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from `https://futureinfra.ai/v1/ai/models`. The `default` array is only the initial selection.
- Model IDs use the `vendor/model` format, for example `openai/gpt-4o-mini`.
- Usage is billed per call from the prepaid wallet in your FutureInfra account. See the [FutureInfra docs](https://futureinfra.ai/docs/) for details.
