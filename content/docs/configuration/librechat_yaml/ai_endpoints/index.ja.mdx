## はじめに [#intro]

- このセクションでは、既知の互換性のあるAI Endpoint（「カスタムEndpoint」とも呼ばれます）を一覧表示し、[Custom Config](/docs/configuration/librechat_yaml) ファイルとしても知られる `librechat.yaml` ファイルの設定例を紹介します。

- すべての例において、環境変数名は任意に定義されていますが、任意の名前を使用したり、値を `user_provided` に変更して、ユーザーがWeb UIから独自のAPIキーを送信できるようにすることも可能です。

<Callout type="warning" title="重要: 'user_provided' キーの設定">
APIキーを "user_provided" に設定すると、ユーザーはWebインターフェースを通じて独自のAPIキーを入力できるようになります。これは、.env ファイルで `ENDPOINT_KEY=user_provided`（例: `OPENAI_API_KEY=user_provided`）のように設定する、事前構成済みのエンドポイントとは異なります。

librechat.yaml 内のカスタム endpoint については、以下のように記述します：
```yaml
endpoints:
  custom:
    - name: "Your Endpoint"
      apiKey: "user_provided"  # No need for ${} syntax here
```

.env ファイル内の環境変数については、以下を使用します：
```bash
OPENAI_API_KEY=user_provided
```
</Callout>

- Endpoints listed under **既知のエンドポイント** below are recognized by LibreChat, which means they might have special handling and/or an icon already provided in the app for you.

### 注記 [#notes]

- 以下の例に進む前に、[Custom Endpoints Quick Start Guide](/docs/quick_start/custom_endpoints) に従うことを推奨します。
- 重要: `librechat.yaml` ファイルを正しく設定していることを確認してください: **[セットアップドキュメント](/docs/configuration/librechat_yaml)**。
