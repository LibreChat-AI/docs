PowerTokens is an OpenAI-compatible gateway for GLM, MiniMax, Qwen and DeepSeek models. One API key works for every model.

## Get an API key

Create an account at [powertokens.ai](https://powertokens.ai/?utm_source=github&utm_medium=librechat&utm_campaign=librechat) and generate a key on the [API keys page](https://www.powertokens.ai/en/api-keys?utm_source=github&utm_medium=librechat&utm_campaign=librechat). Add it to your `.env` file:

```bash filename=".env"
POWERTOKENS_API_KEY=your-api-key
```

## Configuration

Add the endpoint under `endpoints.custom` in your `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: "PowerTokens"
      apiKey: "${POWERTOKENS_API_KEY}"
      baseURL: "https://api.powertokens.ai/v1"
      models:
        default:
          - "glm-5.2"
          - "MiniMax-M3"
          - "glm-5-turbo"
          - "qwen3-coder-plus"
          - "deepseek-v3-2-251201"
        fetch: false
      titleConvo: true
      titleModel: "glm-5-turbo"
      modelDisplayLabel: "PowerTokens"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- Use model IDs exactly as they appear on the [PowerTokens models page](https://powertokens.ai/models?utm_source=github&utm_medium=librechat&utm_campaign=librechat).
- Set `fetch: true` to load the model list from the `/v1/models` endpoint instead of the fixed list above.
- Model details and request parameters are in the [PowerTokens docs](https://docs.powertokens.ai?utm_source=github&utm_medium=librechat&utm_campaign=librechat).
