BetterToken is a pay-as-you-go API gateway that serves Claude, GPT, DeepSeek, Kimi, GLM, MiniMax and Qwen models through one OpenAI-compatible API, used in LibreChat as a custom endpoint.

## Get an API key

[Create a BetterToken account](https://bettertoken.ai/register), add balance, and create an API key. Add it to your `.env` file:

```bash filename=".env"
BETTERTOKEN_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "BetterToken"
      apiKey: "${BETTERTOKEN_API_KEY}"
      baseURL: "https://bettertoken.ai/v1"
      models:
        default: [
          "claude-sonnet-5-5", "deepseek-flash", "kimi-k3"
          ]
        fetch: true
      titleConvo: true
      titleModel: "deepseek-flash"
      modelDisplayLabel: "BetterToken"
```

- `fetch: true` loads the models available to your key from `https://bettertoken.ai/v1/models`.
- Current model IDs and per-token prices are listed on the [BetterToken pricing page](https://bettertoken.ai/pricing).
