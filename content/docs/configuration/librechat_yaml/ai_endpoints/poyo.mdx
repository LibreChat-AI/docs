title: PoYo
description: Configure PoYo as a custom endpoint in LibreChat.
---

[PoYo](https://poyo.ai/) is a unified AI model API. Its chat models, including Claude, GPT, Gemini, Grok, DeepSeek and Kimi, are available through a single OpenAI-compatible endpoint and one API key.

## Get an API key

Create a key from the [PoYo dashboard](https://poyo.ai/dashboard/api-key) and add it to your `.env` file:

```bash filename=".env"
POYO_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "PoYo"
      apiKey: "${POYO_API_KEY}"
      baseURL: "https://api.poyo.ai/v1"
      models:
        default: [
          "claude-sonnet-5-5",
          "claude-opus-5-5",
          "claude-haiku-5-5",
          "gpt-6.1-sol",
          "gpt-6-luna",
          "gemini-4-argon",
          "gemini-3.8-flash",
          "grok-4.7",
          "deepseek-v4-pro",
          "kimi-k3",
          ]
        fetch: false
      titleConvo: true
      titleModel: "gpt-6-luna"
      modelDisplayLabel: "PoYo"
```

## Notes

- PoYo does not expose a `/v1/models` endpoint, so `fetch` is set to `false` and the model list is defined inline. The current model IDs are listed in the "Chat" section of [poyo.ai/llms.txt](https://poyo.ai/llms.txt).
- `titleModel` uses a low-cost model for conversation titles. Replace it with any model from your list.
- PoYo's image, video and music models use a separate asynchronous API and are not available as chat models in LibreChat.
