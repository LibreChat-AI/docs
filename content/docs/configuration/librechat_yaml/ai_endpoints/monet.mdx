Monet is a hosted bring-your-own-key broker that exposes an OpenAI-compatible endpoint. Each end user connects their own OpenAI account, or pastes their own API key, on Monet's hosted consent page. The credential is encrypted server-side and your LibreChat instance only ever holds a scoped bearer token.

This is useful when you run LibreChat for other people and do not want their inference billed to a single shared key.

## Get an API key

Create an account at [monet.gg](https://monet.gg/), register a product in the dashboard, and complete the connect flow to obtain a bearer token. Add it to your `.env` file:

```bash filename=".env"
MONET_KEY=your-bearer-token
```

Tokens are issued per connected user through an OAuth authorization-code exchange, so the raw provider credential never reaches LibreChat.

## Configuration

Add the endpoint under `endpoints.custom` in your `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: "Monet"
      apiKey: "${MONET_KEY}"
      baseURL: "https://monet.gg/api/v1"
      models:
        default: ["gpt-4o-mini", "gpt-5.6-luna"]
        fetch: true
      titleConvo: true
      titleModel: "gpt-4o-mini"
      modelDisplayLabel: "Monet"
```

## Notes

- With `fetch: true`, LibreChat loads the model list from `/api/v1/models`, so the `default` array is only the initial selection. Available models depend on what the connected account or key can reach.
- OpenAI and Anthropic models are both supported through the same endpoint.
- Monet records a usage event per request with provider-reported prompt and completion token counts, so usage can be attributed back to the connected user.
- Revoking a connection from the Monet dashboard invalidates the token immediately.
- Monet is free through beta.
