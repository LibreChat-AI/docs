title: Heabsy

---

[Heabsy](https://heabsy.com/platform) serves open models through an OpenAI-compatible API. Models in its EEA tier run on dedicated GPUs inside the European Economic Area with zero data retention; the [model catalog](https://heabsy.com/models) marks which models run there.

## Get an API key

Sign in to the [Heabsy console](https://platform.heabsy.com) and create an API key. Add the key to your `.env` file:

```bash filename=".env"
HEABSY_API_KEY=your-api-key
```

## Configuration

Add the endpoint under `endpoints.custom` in your `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: "Heabsy"
      apiKey: "${HEABSY_API_KEY}"
      baseURL: "https://api.heabsy.com/v1"
      models:
        default: ["qwen38"]
        fetch: true
      titleConvo: true
      titleModel: "current_model"
      modelDisplayLabel: "Heabsy"
```

For model choice and troubleshooting, see the [Heabsy guide for LibreChat](https://heabsy.com/integrations/librechat).
