---
title: Powerspring
description: Configure Powerspring as a custom endpoint in LibreChat.
---

Powerspring serves open-weight models, including gpt-oss, DeepSeek, GLM, Qwen and Gemma, through an OpenAI-compatible API. Every request runs on EU infrastructure owned by EU companies, and Powerspring does not store prompts or outputs.

## Get an API key

Create a key in the [Powerspring console](https://app.powerspring.eu/signup). Add it to your `.env` file:

```bash filename=".env"
POWERSPRING_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Powerspring"
      apiKey: "${POWERSPRING_API_KEY}"
      baseURL: "https://api.powerspring.eu/v1"
      models:
        default:
          - "gpt-oss-120b"
          - "deepseek-v4.1-flash"
          - "qwen3.8-27b"
        fetch: true
      titleConvo: true
      titleModel: "gpt-oss-20b"
      modelDisplayLabel: "Powerspring"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from Powerspring's [`/v1/models`](https://api.powerspring.eu/v1/models) endpoint. The `default` array is only the initial selection.
- `/v1/models` also returns each model's context length, capabilities and price per million tokens. The [models page](https://powerspring.eu/models) shows the same list with independent benchmark scores.
- Powerspring is paid from prepaid credits in euros. A request fails with HTTP 402 when the balance runs out.
