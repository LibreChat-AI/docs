Outrun is a prepaid, OpenAI-compatible API. One key and one USD balance reach GPT, Claude, Gemini, Grok, DeepSeek, Kimi, GLM and other models, and each request is billed per token at the published rate.

## Get an API key

Sign in at [outrun.to](https://outrun.to/key), add credit by card or crypto, and copy your key. Add it to your `.env` file:

```bash filename=".env"
OUTRUN_API_KEY=your-api-key
```

Requests are paid from your balance, so make sure it has credit. See the [Outrun docs](https://outrun.to/docs/) for details.

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Outrun"
      apiKey: "${OUTRUN_API_KEY}"
      baseURL: "https://api.outrun.to/v1"
      models:
        default:
          - "gpt-5.6-sol"
          - "claude-sonnet-5-5"
          - "claude-haiku-5-5"
          - "gemini-3.8-flash"
          - "grok-4.7"
          - "deepseek-v4-pro"
          - "kimi-k3.1-pro"
        fetch: true
      titleConvo: true
      titleModel: "claude-haiku-5-5"
      modelDisplayLabel: "Outrun"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from Outrun's `/v1/models` endpoint using your key, so the `default` array is only the initial selection. The listing needs a valid key.
- Model IDs and prices change over time. The current list is on the [Outrun pricing page](https://outrun.to/pricing) and in the keyless JSON feed at `https://api.outrun.to/pricing`. If a selected model is unavailable, pick another chat model from that list.
- `titleModel` uses a low-cost model so conversation titles stay cheap. Set it to `"current_model"` to use the chat model instead.
