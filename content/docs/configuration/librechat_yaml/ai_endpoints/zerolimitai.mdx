ZeroLimitAI is an OpenAI-compatible endpoint that routes each request to the best free model available at that moment, with automatic failover when a model is rate-limited or down.

## Get an API key

Create a key on the [ZeroLimitAI developer page](https://www.zerolimitai.com/developer). Add it to your `.env` file:

```bash filename=".env"
ZEROLIMITAI_API_KEY=your-api-key
```

## Configuration

Add the endpoint under `endpoints.custom` in your `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: "ZeroLimitAI"
      apiKey: "${ZEROLIMITAI_API_KEY}"
      baseURL: "https://www.zerolimitai.com/api/v1"
      models:
        default: ["auto"]
        fetch: true
      titleConvo: true
      titleModel: "auto"
      modelDisplayLabel: "ZeroLimitAI"
```

## Notes

- `auto` lets the router choose the model for each request; the `model` field of the response names the model that answered. The live ranking is on the [leaderboard](https://www.zerolimitai.com/leaderboard).
- With `fetch: true`, LibreChat lists the models currently in the ranking (`GET /v1/models`). The free catalogue changes over time, so `auto` is the stable choice.
- Streaming and tool calls are supported; embeddings and image inputs are not.
- A new key works for 7 days with 100 requests a day; after that the account needs a paid plan. See the [API reference](https://www.zerolimitai.com/docs/api) for limits and error codes.
