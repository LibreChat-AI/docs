Linkrra provides an OpenAI-compatible inference API for open-weight models that you can add to LibreChat through `endpoints.custom`.

## Get an API key

Sign in on the [Linkrra account page](https://synap.linkrra.com/account) and create an API key. Add it to your `.env` file:

```bash filename=".env"
LINKRRA_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Linkrra"
      apiKey: "${LINKRRA_API_KEY}"
      baseURL: "https://pool.linkrra.com/v1"
      models:
        default:
          - "qwen3-coder-30b"
          - "gpt-oss-20b"
          - "gemma-4-26b-a4b-it"
        fetch: false
      titleConvo: true
      titleModel: "qwen3-coder-30b"
      modelDisplayLabel: "Linkrra"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- Use model IDs exactly as they appear in the list above. Model availability can change over time; the current IDs are published at [`/v1/models?format=openrouter`](https://pool.linkrra.com/v1/models?format=openrouter).
- The endpoint supports chat completions with streaming. See the [Linkrra documentation](https://synap.linkrra.com/docs) for details.
