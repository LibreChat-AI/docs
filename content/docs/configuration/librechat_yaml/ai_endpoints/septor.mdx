[Septor Labs](https://septorlabs.com/) is a hosted AI gateway with a single OpenAI-compatible endpoint. It routes requests across providers with automatic failover before the first token, supports semantic caching, and uses prepaid credits with per-key budgets.

## Get an API key

Create an account at [septorlabs.com](https://septorlabs.com/) and generate a key from the dashboard. Add it to your `.env` file:

```bash filename=".env"
SEPTOR_API_KEY=your-api-key
```

Make sure the account has credits, otherwise model requests will fail.

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Septor"
      apiKey: "${SEPTOR_API_KEY}"
      baseURL: "https://api.septorlabs.com/v1"
      models:
        default: ["auto"]
        fetch: true
      titleConvo: true
      titleModel: "auto"
      modelDisplayLabel: "Septor"
      dropParams: ["user"]
```

## Notes

- With `fetch: true`, LibreChat loads the model list from `GET /v1/models`, so the `default` array is only the initial selection. The full catalog is on the [Septor models page](https://septorlabs.com/models).
- `auto` lets the gateway pick a model for each request. Replace it with any model ID from the catalog to pin one.
- `dropParams: ["user"]` stops LibreChat from sending the `user` field to the gateway.
- To check connectivity from the LibreChat API container, run `curl https://api.septorlabs.com/v1/models -H "Authorization: Bearer $SEPTOR_API_KEY"`.
- Restart the LibreChat stack after changing `librechat.yaml` or `.env`.
