[Hubris](https://hubris.pw) is a ruble-billed, OpenAI-compatible LLM gateway giving access to 400+ models (OpenAI, Anthropic, Google, and more) behind a single API key, exposed through an OpenAI-compatible API that you can add to LibreChat as a custom endpoint.

## Get an API key

Create a key at [hubris.pw/keys](https://hubris.pw/keys). Add it to your `.env` file:

```bash filename=".env"
HUBRIS_API_KEY=your-api-key
```

## Configuration

Add the endpoint under `endpoints.custom` in your `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: "Hubris"
      apiKey: "${HUBRIS_API_KEY}"
      baseURL: "https://api.hubris.pw/v1"
      models:
        default: ["claude-sonnet-5", "gpt-5.6", "gemini-3.5-pro"]
        fetch: true
      titleConvo: true
      titleModel: "current_model"
      modelDisplayLabel: "Hubris"
```

## Notes

- `fetch: true` pulls the live model list from Hubris's `/v1/models` endpoint — see the full catalog at [hubris.pw/models](https://hubris.pw/models).
