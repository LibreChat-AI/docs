[Engy](https://engy.ai/) is an OpenAI-compatible API for open-weight models. Add it to LibreChat as a custom endpoint. The API reference is at [engy.ai/docs](https://engy.ai/docs).

## Get an API key

Add your Engy API key to your `.env` file:

```bash filename=".env"
ENGY_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Engy"
      apiKey: "${ENGY_API_KEY}"
      baseURL: "https://api.engy.ai/v1"
      models:
        default:
          - "kimi-k3"
          - "glm-5.3"
          - "glm-5.3-flash"
          - "deepseek-v4.1-flash-1017"
        fetch: true
      titleConvo: true
      titleModel: "glm-5.3-flash"
      modelDisplayLabel: "Engy"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`. Users then see a key input field when they select the endpoint.

## Notes

- With `fetch: true`, LibreChat loads the model list from [`https://api.engy.ai/v1/models`](https://api.engy.ai/v1/models), so new models appear automatically. The `default` array is only the initial selection: `kimi-k3`, `glm-5.3`, `glm-5.3-flash`, and `deepseek-v4.1-flash-1017`.
- `titleModel: "glm-5.3-flash"` is the model used to generate conversation titles.
- Zero data retention (ZDR) is on by default.
