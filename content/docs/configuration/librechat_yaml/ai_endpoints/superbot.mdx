superbot provides an OpenAI-compatible endpoint that you can add to LibreChat through `endpoints.custom`. One caller key reaches the `superbot` and `superbot-fast` models and the models on your superbot account.

Try superbot in your browser first: [superbot.gg/chat](https://superbot.gg/chat?utm_source=librechat&utm_medium=registry&utm_campaign=default-slots) is free and needs no account.

## Get an API key

Create a caller key under **Account > API** on [superbot.gg](https://superbot.gg/api?utm_source=librechat&utm_medium=registry&utm_campaign=default-slots). Caller keys start with `sbc_`. Add the key to your `.env` file:

```bash filename=".env"
SUPERBOT_API_KEY=your-api-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "superbot"
      apiKey: "${SUPERBOT_API_KEY}"
      baseURL: "https://api.superbot.gg/v1"
      models:
        default:
          - "superbot"
          - "superbot-fast"
        fetch: true
      titleConvo: true
      titleModel: "superbot-fast"
      modelDisplayLabel: "superbot"
```

To let each user supply their own key through the LibreChat UI instead of reading one from `.env`, set `apiKey: "user_provided"`.

## Notes

- With `fetch: true`, LibreChat loads the model list from superbot's OpenAI-compatible `/v1/models` endpoint. The `default` array is only the initial selection.
- `superbot` has a 1,000,000-token context window and `superbot-fast` has 500,000. Both take tool calls and reasoning effort. Send the effort in `reasoning_effort`; `superbot` serves `none`, `low`, `high`, `xhigh` and `max`, and `superbot-fast` serves `none` and `low`.
- Use model IDs exactly as `GET /v1/models` returns them for your key.
- Prices are on [superbot.gg/pricing](https://superbot.gg/pricing?utm_source=librechat&utm_medium=registry&utm_campaign=default-slots).
