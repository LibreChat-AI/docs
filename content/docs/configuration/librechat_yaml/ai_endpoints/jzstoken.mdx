---
title: JZSTOKEN
description: Configure JZSTOKEN as a custom endpoint in LibreChat.
---

JZSTOKEN provides OpenAI-compatible access to OpenAI, Anthropic, Google, Kimi, DeepSeek, and other models through one endpoint and one API key.

## Get an API key

Create a JZSTOKEN account, add credits, and generate a **Standard** key from the [API Keys page](https://jzstoken.com/dashboard/keys). Add the key to your `.env` file:

```bash filename=".env"
JZSTOKEN_API_KEY=sk-your-key-here
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "JZSTOKEN"
      apiKey: "${JZSTOKEN_API_KEY}"
      baseURL: "https://jzstoken.com/api/v1"
      models:
        default: ["gpt-5.6-terra"]
        fetch: true
      titleConvo: true
      titleModel: "gpt-5.6-terra"
      modelDisplayLabel: "JZSTOKEN"
```

JZSTOKEN exposes an authenticated `/models` endpoint, so `fetch: true` populates the selector with the models available to the key. The `default` array provides an initial model while that list loads.

## Notes

- Use a **Standard** key for general models. A key created specifically for `jzs-max-3.0` only exposes that model.
- To let each user supply their own key instead of reading one from `.env`, set `apiKey: "user_provided"`.
- See the [JZSTOKEN quick start](https://jzstoken.com/docs/quick-start) and [model catalog](https://jzstoken.com/model-pricing) for the current base URL, key requirements, and model IDs.
