AI Stupid Level runs coding, reasoning and tool-use benchmarks on the major models continuously. Its Smart Router is an OpenAI-compatible endpoint that sends each request to the model that currently scores best for the kind of work, using your own provider keys (OpenAI, Anthropic, Google, DeepSeek, Kimi, GLM).

## Get an API key

Create a router key at [aistupidlevel.info/router/keys](https://aistupidlevel.info/router/keys) and add at least one provider key to your account under [Providers](https://aistupidlevel.info/router/providers). Add the router key to your `.env` file:

```bash filename=".env"
ASL_ROUTER_KEY=your-router-key
```

## Configuration

Add the endpoint to the `custom` list under `endpoints` in your `librechat.yaml`. If your file already has an `endpoints.custom` list, paste only the `- name:` entry into it, keeping the same indentation:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "AI Stupid Level"
      apiKey: "${ASL_ROUTER_KEY}"
      baseURL: "https://aistupidlevel.info/v1"
      models:
        default: ["auto-coding", "auto-reasoning", "auto-tooling", "auto-best", "auto-value"]
        fetch: true
      titleConvo: true
      titleModel: "auto-fastest-quality"
      modelDisplayLabel: "AI Stupid Level"
      iconURL: "https://aistupidlevel.info/apple-touch-icon.png"
```

## Notes

- Model IDs are routing modes: `auto-coding`, `auto-reasoning` and `auto-tooling` pick the model with the top score on that benchmark, `auto-best` the highest combined score, and `auto-value` the most benchmark points per measured dollar among near-top models. Any real model ID (for example `claude-opus-5-5`) pins that model. With `fetch: true`, LibreChat loads the full list from the router.
- Each provider bills its usage to your own provider account. The response header `X-AISM-Model` names the model that answered.
- The router routes text only: requests with image, audio or file content are rejected with `400 unsupported_content`.
- To try the configuration without spending anything, add `headers: { X-ASL-Sandbox: "true" }` to the endpoint. The router then runs its real routing and returns a mock answer. See the [router documentation](https://aistupidlevel.info/router/docs).
