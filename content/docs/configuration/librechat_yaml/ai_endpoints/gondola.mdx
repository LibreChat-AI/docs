Gondola is a marketplace for Venice AI inference. It serves an OpenAI-compatible API that routes each request to the cheapest available supplier, so prices usually land below Venice's own list. The catalog spans text, image, and video models, including uncensored ones, and is paid in USDC on Base with no subscription.

## Get an API key

Mint a key from the [Gondola keys page](https://gondola-ai.com/keys) (format `gnd_...`) and add it to your `.env` file:

```bash filename=".env"
GONDOLA_API_KEY=gnd_your-key
```

## Configuration

Add the endpoint under `endpoints.custom` in your `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: "Gondola"
      apiKey: "${GONDOLA_API_KEY}"
      baseURL: "https://api.gondola-ai.com/v1"
      models:
        default: ["deepseek-v4-flash", "claude-sonnet-5", "hermes-3-llama-3.1-405b"]
        fetch: true
      titleConvo: true
      titleModel: "deepseek-v4-flash"
      modelDisplayLabel: "Gondola"
```

## Notes

- `models.fetch: true` works out of the box: Gondola's `GET /v1/models` is public and needs no key, so LibreChat auto-populates the full catalog (100+ text models) on startup.
- Gondola is also Anthropic-compatible (`/v1/messages`), so the same key works with Anthropic-format tools.
- Prices are metered per request in USDC on Base and are typically below Venice list. See live prices at [gondola-ai.com/marketplace](https://gondola-ai.com/marketplace).
- Prompts and completions are never persisted (no content hashing); only per-request metadata (token counts, model, cost, timing) is stored.
