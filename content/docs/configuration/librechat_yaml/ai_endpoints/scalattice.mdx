Scalattice is an OpenAI-compatible inference marketplace. Add it to LibreChat as a custom endpoint and fetch the live catalog.

## Get an API key

Create a key from the [Scalattice developer docs](https://scalattice.cloud/docs/developers). Add it to your `.env` file:

```bash filename=".env"
SCALATTICE_API_KEY=your-api-key
```

## Configuration

Add the endpoint under `endpoints.custom` in your `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: "Scalattice"
      apiKey: "${SCALATTICE_API_KEY}"
      baseURL: "https://api.scalattice.cloud/v1"
      models:
        default: [
          "qwen-3-14b",
          "qwen-3-coder-30b-a3b",
          "llama-3.3-70b",
          ]
        fetch: true
      titleConvo: true
      titleModel: "current_model"
      modelDisplayLabel: "Scalattice"
```

## Notes

- Catalog IDs match `GET https://api.scalattice.cloud/v1/models` once you send a Bearer key.
- `models.fetch: true` keeps the selector in sync with whatever the fleet is serving.
