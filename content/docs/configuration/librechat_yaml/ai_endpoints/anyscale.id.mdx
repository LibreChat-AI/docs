Anyscale Endpoints menyediakan model terbuka seperti Llama melalui API yang kompatibel dengan OpenAI yang dapat Anda tambahkan ke LibreChat sebagai endpoint kustom.

## Dapatkan API key [#get-an-api-key]

Buat kunci dari [kredensial Anyscale](https://app.endpoints.anyscale.com/credentials) Anda. Tambahkan ke file `.env` Anda:

```bash filename=".env"
ANYSCALE_API_KEY=your-api-key
```

## Konfigurasi [#configuration]

Tambahkan endpoint tersebut ke daftar `custom` di bawah `endpoints` dalam `librechat.yaml` Anda. Jika file Anda sudah memiliki daftar `endpoints.custom`, tempelkan hanya entri `- name:` ke dalamnya, dengan tetap mempertahankan indentasi yang sama:

```yaml filename="librechat.yaml"
endpoints:
  custom:
    - name: "Anyscale"
      apiKey: "${ANYSCALE_API_KEY}"
      baseURL: "https://api.endpoints.anyscale.com/v1"
      models:
        default: [
          "meta-llama/Llama-2-7b-chat-hf",
          ]
        fetch: true
      titleConvo: true
      titleModel: "meta-llama/Llama-2-7b-chat-hf"
      summarize: false
      summaryModel: "meta-llama/Llama-2-7b-chat-hf"
      modelDisplayLabel: "Anyscale"
```

## Catatan [#notes]

- Dengan `fetch: true`, LibreChat memuat daftar model yang tersedia dari Anyscale, sehingga array `default` hanyalah pilihan awal.
