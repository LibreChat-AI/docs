## Panoramica [#overview]

Le MCP Apps sono interfacce interattive che un server MCP restituisce insieme al risultato di uno strumento. LibreChat le visualizza in un frame sandbox servito da un'origine separata, quindi il contenuto delle App non può raggiungere la pagina di LibreChat. L'oggetto `mcpAppSandbox` configura questo sandbox e i limiti applicati alle App.

MCP Apps vengono attivate tramite [`mcpSettings.apps`](/docs/configuration/librechat_yaml/object_structure/mcp_settings#apps). Ogni chiave sotto `mcpAppSandbox` è facoltativa e ha un valore predefinito.

## Esempio [#example]

```yaml filename="mcpAppSandbox"
mcpAppSandbox:
  url: https://mcp-sandbox.example.com/api/mcp/sandbox
  maxActiveViews: 3
  maxPersistedAppBytes: 1048576
  maxAdmissionRequestsPerMinute: 240
  operationLimits:
    maxBytes: 4194304
    timeoutMs: 30000
    maxActive: 16
```

## Hosting del sandbox [#hosting-the-sandbox]

La pagina sandbox è servita da LibreChat stesso all'indirizzo `/api/mcp/sandbox`. Assegnagli un'origine dedicata, ad esempio un secondo hostname il cui reverse proxy inoltra allo stesso server LibreChat, e imposta `url` su quella route sull'origine dedicata.

La pagina della sandbox rifiuta di essere incorporata se l'origine di LibreChat non è autorizzata a inquadrarla. Imposta [`MCP_SANDBOX_FRAME_ANCESTORS`](/docs/configuration/dotenv#mcp-server-configuration) sull'origine da cui gli utenti aprono LibreChat, ad esempio `MCP_SANDBOX_FRAME_ANCESTORS=https://chat.example.com`. Quando non è impostata, la pagina viene servita con `frame-ancestors 'none'` e i frame delle App restano vuoti.
