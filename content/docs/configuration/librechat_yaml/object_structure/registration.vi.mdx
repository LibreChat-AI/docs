## Ví dụ [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## openidDiscovery

Điều khiển cách LibreChat thử lại quá trình khám phá OpenID Connect (OpenID Connect discovery) với nhà cung cấp danh tính (identity provider) của bạn. Mỗi trường được đặt tại đây sẽ được ưu tiên hơn biến môi trường tương ứng (`OPENID_DISCOVERY_RETRY_ATTEMPTS`, `OPENID_DISCOVERY_RETRY_DELAY_MS`); các trường bạn để trống sẽ dùng giá trị của biến môi trường, và nếu không có thì dùng giá trị mặc định.
