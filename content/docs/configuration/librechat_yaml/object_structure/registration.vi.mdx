The `registration` block controls which social login buttons appear and in what order, which email domains may sign up or sign in, and a few timing settings for social and OpenID logins. Turning registration and social login on or off is done with environment variables; see [Authentication](/docs/configuration/authentication).

## Ví dụ [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## openidDiscovery

Controls how LibreChat retries fetching the OpenID provider's discovery document. Each unset field falls back to its environment variable (`OPENID_DISCOVERY_RETRY_ATTEMPTS`, `OPENID_DISCOVERY_RETRY_DELAY_MS`), then to the default.
