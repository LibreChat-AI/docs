## Ejemplo [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## socialLogins

<OptionTable
  options={[

## allowedDomains

**Clave:**
<OptionTable
  options={[
    ['allowedDomains', 'Array of Strings', 'Una lista que especifica los dominios de correo electrónico permitidos para el registro.', 'Users with email domains not listed will be restricted from registering.'],
  ]}
/>

Esta clave es opcional. Si la omites, se permite el registro con cualquier dominio de correo electrónico.

**Ejemplo:**
```yaml filename="registration / allowedDomains"
allowedDomains:
  - "gmail.com"
  - "protonmail.com"
```

## openidDiscovery

Controla cómo LibreChat reintenta el descubrimiento de OpenID Connect con tu proveedor de identidad. Cada campo configurado aquí tiene prioridad sobre la variable de entorno correspondiente (`OPENID_DISCOVERY_RETRY_ATTEMPTS`, `OPENID_DISCOVERY_RETRY_DELAY_MS`); los campos que dejes sin definir usarán la variable de entorno y, si tampoco está definida, el valor predeterminado.

**Claves:**
<OptionTable
  options={[
    ['startupAttempts', 'Integer', 'Intentos de descubrimiento realizados antes de que continúe el inicio. 0 reintentos solo en segundo plano.', 'Range: 0 to 100. Default: 1.'],
    ['retryDelayMs', 'Integer', 'Milisegundos entre cada intento de inicio y de descubrimiento en segundo plano.', 'Range: 100 to 3600000. Default: 5000.'],
  ]}
/>

**Ejemplo:**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 10000
```
