El bloque `registration` controla qué botones de inicio de sesión social aparecen y en qué orden, qué dominios de correo electrónico pueden registrarse o iniciar sesión, y algunos ajustes de tiempo para los inicios de sesión sociales y OpenID. Activar o desactivar el registro y el inicio de sesión social se hace mediante variables de entorno; consulta [Autenticación](/docs/configuration/authentication).

## Ejemplo [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## allowedDomains

**Clave:**
<OptionTable
  options={[
    ['allowedDomains', 'Array of Strings', 'Una lista de dominios de correo electrónico permitidos para registrarse e iniciar sesión.', 'Users whose email domain is not listed cannot register, and are also turned away when signing in through a social provider, OpenID, SAML, or LDAP, and when requesting a password reset.   - "protonmail.com"

## openidDiscovery

Controla cómo LibreChat reintenta obtener el documento de descubrimiento del proveedor OpenID. Cada campo no establecido recurre a su variable de entorno (`OPENID_DISCOVERY_RETRY_ATTEMPTS`, `OPENID_DISCOVERY_RETRY_DELAY_MS`) y, después, al valor predeterminado.

**Claves:**
<OptionTable
  options={[
    ['startupAttempts', 'Number', 'Intentos de descubrimiento realizados antes de que continúe el inicio.', 'Between 0 and 100. 0 skips the startup attempts and only retries in the background. Default: 1.'],
    ['retryDelayMs', 'Number', 'Milisegundos entre cada intento de inicio y de descubrimiento en segundo plano.', 'Between 100 and 3600000. Default: 5000.'],
  ]}
/>

**Ejemplo:**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 5000
```
