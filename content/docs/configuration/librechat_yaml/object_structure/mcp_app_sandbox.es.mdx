## Descripción general [#overview]

Las MCP Apps son interfaces interactivas que un servidor MCP devuelve junto con el resultado de una herramienta. LibreChat renderiza cada una en un marco aislado (sandbox) servido desde un origen separado, por lo que el contenido de las Apps no puede acceder a la página de LibreChat. El objeto `mcpAppSandbox` configura ese sandbox y los límites aplicados a las Apps.

Las MCP Apps se activan con [`mcpSettings.apps`](/docs/configuration/librechat_yaml/object_structure/mcp_settings#apps). Cada clave bajo `mcpAppSandbox` es opcional y tiene un valor predeterminado.

## Ejemplo [#example]

```yaml filename="mcpAppSandbox"
mcpAppSandbox:
  url: https://mcp-sandbox.example.com/api/mcp/sandbox
  maxActiveViews: 3
  maxPersistedAppBytes: 1048576
  maxAdmissionRequestsPerMinute: 240
  operationLimits:
    maxBytes: 4194304
    timeoutMs: 30000
    maxActive: 16
```

## Alojamiento del sandbox [#hosting-the-sandbox]

La página de sandbox es servida por el propio LibreChat en `/api/mcp/sandbox`. Asígnale un origen dedicado, como un segundo nombre de host cuyo reverse proxy reenvíe al mismo servidor de LibreChat, y establece `url` en esa ruta dentro del origen dedicado.

La página de sandbox se niega a ser incrustada a menos que el origen de LibreChat esté permitido para enmarcarla. Establece [`MCP_SANDBOX_FRAME_ANCESTORS`](/docs/configuration/dotenv#mcp-server-configuration) con el origen en el que los usuarios abren LibreChat, por ejemplo `MCP_SANDBOX_FRAME_ANCESTORS=https://chat.example.com`. Cuando no está definida, la página se sirve con `frame-ancestors 'none'` y los marcos de App permanecen en blanco.
