Diese Seite gilt sowohl für die `assistants` als auch für die `azureAssistants` endpoint.

<Callout type="warning">
OpenAI hat die Assistants API am 26. August 2026 entfernt, daher funktioniert der OpenAI `assistants` endpoint nicht mehr mit OpenAI. Verwenden Sie stattdessen [Agents](/docs/features/agents). Siehe [Assistants](/docs/configuration/pre_configured_ai/assistants) für weitere Details.
</Callout>

**Hinweis:** Um `azureAssistants` zu aktivieren, siehe die [Azure OpenAI Konfiguration](/docs/configuration/librechat_yaml/ai_endpoints/azure#using-assistants-with-azure) für weitere Informationen.

## Beispiel [#example]

```yaml filename="Assistants Endpoint"
endpoints:
  # azureAssistants: # <-- Azure-specific configuration has the same structure as `assistants`
    #  pollIntervalMs: 500
    #  timeoutMs: 10000

  assistants:
    disableBuilder: false
    # Use either `supportedIds` or `excludedIds` but not both
    supportedIds: ["asst_supportedAssistantId1", "asst_supportedAssistantId2"]
    # excludedIds: ["asst_excludedAssistantId"]
    # `privateAssistants` do not work with `supportedIds` or `excludedIds`
    # privateAssistants: false
    # (optional) Models that support retrieval, will default to latest known OpenAI models that support the feature
    # retrievalModels: ["gpt-4-turbo-preview"]
    # (optional) Assistant Capabilities available to all users. Omit the ones you wish to exclude. Defaults to list below.
    # capabilities: ["code_interpreter", "retrieval", "actions", "tools", "image_vision"]
```
> Diese Konfiguration aktiviert die Builder-Oberfläche für Assistenten und beschränkt den Endpoint auf zwei unterstützte Assistenten-IDs. Der auskommentierte `azureAssistants`-Block zeigt, wie ein Polling-Intervall von 500 ms und ein Timeout von 10 Sekunden für Läufe festgelegt werden.

## disableBuilder

**Schlüssel:**
<OptionTable
  options={[
    ['disableBuilder', 'Boolean', 'Steuert die Sichtbarkeit und Nutzung der Builder-Oberfläche für Assistants.', 'When set to `true`, disables the builder interface for the assistant, limiting direct manual interaction.'],
  ]}
/>

**Standard:** `false`

**Beispiel:**
```yaml filename="endpoints / assistants / disableBuilder"
disableBuilder: false
```

## pollIntervalMs

**Schlüssel:**
<OptionTable
  options={[
    ['pollIntervalMs', 'Integer', 'Gibt das Abfrageintervall in Millisekunden an, um nach Aktualisierungen von Ausführungen oder Änderungen in den Status von Assistant-Ausführungen zu suchen.', 'Specifies the polling interval in milliseconds for checking assistant run updates.'],
  ]}
/>

**Standard:** `2000`

**Beispiel:**
```yaml filename="endpoints / assistants / pollIntervalMs"
pollIntervalMs: 2500
```
**Hinweis:** Der Wert wird aus der Konfiguration des Endpunkts gelesen, der den Lauf bedient. Er gilt daher sowohl für `assistants` als auch für `azureAssistants`. Für Azure Assistants werden höhere Werte empfohlen, um Fehler durch Ratenbegrenzung (Rate Limiting) zu vermeiden.

## timeoutMs

**Schlüssel:**
<OptionTable
  options={[
    ['timeoutMs', 'Integer', 'Definiert die maximale Zeit in Millisekunden, die ein Assistant laufen kann, bevor die Anfrage abgebrochen wird.', 'Sets a timeout in milliseconds for assistant runs. Helps manage system load by limiting total run operation time.'],
  ]}
/>

**Standard:** `180000`

**Beispiel:**
```yaml filename="endpoints / assistants / timeoutMs"
timeoutMs: 10000
```
**Hinweis:** Der Standardwert beträgt 3 Minuten (180.000 ms). Die Laufzeiten von Operationen können zwischen 50 Sekunden und 2 Minuten liegen, aber auch darüber hinausgehen. Wenn der Wert `timeoutMs` überschritten wird, wird der Vorgang abgebrochen.

## version

**Schlüssel:**
<OptionTable
  options={[
    ['version', 'String or Number', 'API-Version, die für den Endpunkt verwendet wird.', 'Defaults to 2. azureAssistants defaults to 1 when endpoints.azureOpenAI.assistants is enabled, otherwise 2.'],
  ]}
/>

**Standard:** `2`; `azureAssistants` ist standardmäßig `1`, wenn `endpoints.azureOpenAI.assistants` aktiviert ist

**Beispiel:**
```yaml filename="endpoints / azureAssistants / version"
version: 1
```

## models

**Schlüssel:**
<OptionTable
  options={[
    ['models', 'Object', 'Steuert die Modellliste für den Endpoint.', 'Optional. Same structure as the custom endpoint [models](/docs/configuration/librechat_yaml/object_structure/custom_endpoint#models) field.'],
  ]}
/>

**Untergeordnete Schlüssel:**

<OptionTable
  options={[
    ['default', 'Array/List of Strings or Objects', 'Modelle, die für den Endpunkt aufgelistet werden sollen. Erforderlich, wenn models gesetzt ist; mindestens ein Eintrag.', ''],
    ['fetch', 'Boolean', 'Rufe die Modellliste vom Endpoint ab.', ''],
    ['userIdQuery', 'Boolean', 'Sende die LibreChat-Benutzer-ID als Query-Parameter beim Abrufen der Modelle.', ''],
  ]}
/>

**Beispiel:**
```yaml filename="endpoints / assistants / models"
models:
  default: ["gpt-4o"]
  fetch: false
```

## supportedIds

**Schlüssel:**
<OptionTable
  options={[
    ['supportedIds', 'Array/List of Strings', 'Liste der unterstützten Assistant Ids', 'Use this or `excludedIds` but not both (the `excludedIds` field will be ignored if so).'],
  ]}
/>

**Beispiel:**
```yaml filename="endpoints / assistants / supportedIds"
supportedIds:
  - "asst_supportedAssistantId1"
  - "asst_supportedAssistantId2"
```

## excludedIds

**Schlüssel:**
<OptionTable
  options={[
    ['excludedIds', 'Array/List of Strings', 'Liste der ausgeschlossenen Assistant-IDs', 'Use this or `supportedIds` but not both (the `excludedIds` field will be ignored if so).'],
  ]}
/>

**Beispiel:**
```yaml filename="endpoints / assistants / excludedIds"
excludedIds:
  - "asst_excludedAssistantId1"
  - "asst_excludedAssistantId2"
```

## privateAssistants

**Schlüssel:**
<OptionTable
  options={[
    ['privateAssistants', 'Boolean', 'Steuert, ob Assistants für den Benutzer, der sie erstellt hat, privat sind', 'Does not work with `supportedIds` or `excludedIds` (`supportedIds` and `excludedIds` will be ignored).'],
  ]}
/>

**Standard:** `false`

**Beispiel:**
```yaml filename="endpoints / assistants / privateAssistants"
privateAssistants: false
```

## retrievalModels

**Schlüssel:**
<OptionTable
  options={[
    ['retrievalModels', 'Array/List of Strings', 'Gibt die Modelle an, die Retrieval für den assistants endpoint unterstützen.', 'Defines the models that support retrieval capabilities for the assistants endpoint. By default, it uses the latest known OpenAI models that support the official Retrieval feature.'],
  ]}
/>

**Standard:** `[]` (verwendet die neuesten bekannten OpenAI-Modelle, die Retrieval unterstützen)

**Beispiel:**
```yaml filename="endpoints / assistants / retrievalModels"
retrievalModels:
  - "gpt-4-turbo-preview"
```

## capabilities

**Schlüssel:**
<OptionTable
  options={[
    ['capabilities', 'Array/List of Strings', 'Legt die Assistant-Funktionen fest, die allen Benutzern für den assistants endpoint zur Verfügung stehen.', 'Defines the assistant capabilities that are available to all users for the assistants endpoint. You can omit the capabilities you wish to exclude from the list.'],
  ]}
/>

**Standard:** `["code_interpreter", "image_vision", "retrieval", "actions", "tools"]`

**Beispiel:**
```yaml filename="endpoints / assistants / capabilities"
capabilities:
  - "code_interpreter"
  - "retrieval"
  - "actions"
  - "tools"
  - "image_vision"
```
**Hinweis:** Dieses Feld ist optional. Wenn es weggelassen wird, besteht das Standardverhalten darin, alle im Beispiel aufgeführten Funktionen einzubeziehen.
