Cette page s'applique aux deux endpoints `assistants` et `azureAssistants`.

<Callout type="warning">
OpenAI a supprimé l'Assistants API le 26 août 2026, l'endpoint `assistants` d'OpenAI ne fonctionne donc plus avec OpenAI. Utilisez plutôt les [Agents](/docs/features/agents). Consultez [Assistants](/docs/configuration/pre_configured_ai/assistants) pour plus de détails.
</Callout>

**Remarque :** Pour activer `azureAssistants`, consultez la [Configuration Azure OpenAI](/docs/configuration/librechat_yaml/ai_endpoints/azure#using-assistants-with-azure) pour plus d'informations.

## Exemple [#example]

```yaml filename="Assistants Endpoint"
endpoints:
  # azureAssistants: # <-- Azure-specific configuration has the same structure as `assistants`
    #  pollIntervalMs: 500
    #  timeoutMs: 10000

  assistants:
    disableBuilder: false
    # Use either `supportedIds` or `excludedIds` but not both
    supportedIds: ["asst_supportedAssistantId1", "asst_supportedAssistantId2"]
    # excludedIds: ["asst_excludedAssistantId"]
    # `privateAssistants` do not work with `supportedIds` or `excludedIds`
    # privateAssistants: false
    # (optional) Models that support retrieval, will default to latest known OpenAI models that support the feature
    # retrievalModels: ["gpt-4-turbo-preview"]
    # (optional) Assistant Capabilities available to all users. Omit the ones you wish to exclude. Defaults to list below.
    # capabilities: ["code_interpreter", "retrieval", "actions", "tools", "image_vision"]
```
> Cette configuration active l'interface de création pour les assistants et limite l'endpoint à deux identifiants d'assistants pris en charge. Le bloc `azureAssistants` commenté montre comment définir un intervalle d'interrogation de 500 ms et un délai d'expiration d'exécution de 10 secondes.

## disableBuilder

**Clé :**
<OptionTable
  options={[
    ['disableBuilder', 'Boolean', 'Contrôle la visibilité et l\'utilisation de l\'interface de création pour les assistants.', 'When set to `true`, disables the builder interface for the assistant, limiting direct manual interaction.'],
  ]}
/>

**Par défaut :** `false`

**Exemple :**
```yaml filename="endpoints / assistants / disableBuilder"
disableBuilder: false
```

## pollIntervalMs

**Clé :**
<OptionTable
  options={[
    ['pollIntervalMs', 'Integer', 'Spécifie l\'intervalle d\'interrogation en millisecondes pour vérifier les mises à jour des exécutions ou les changements d\'état des exécutions d\'assistant.', 'Specifies the polling interval in milliseconds for checking assistant run updates.'],
  ]}
/>

**Par défaut :** `2000`

**Exemple :**
```yaml filename="endpoints / assistants / pollIntervalMs"
pollIntervalMs: 2500
```
**Remarque :** La valeur est lue à partir de la configuration de l'endpoint qui gère l'exécution, elle s'applique donc à la fois à `assistants` et à `azureAssistants`. Des valeurs plus élevées sont recommandées pour Azure Assistants afin d'éviter les erreurs de limitation de débit (rate limiting).

## timeoutMs

**Clé :**
<OptionTable
  options={[
    ['timeoutMs', 'Integer', 'Définit la durée maximale en millisecondes pendant laquelle un assistant peut s\'exécuter avant que la requête ne soit annulée.', 'Sets a timeout in milliseconds for assistant runs. Helps manage system load by limiting total run operation time.'],
  ]}
/>

**Par défaut :** `180000`

**Exemple :**
```yaml filename="endpoints / assistants / timeoutMs"
timeoutMs: 10000
```
**Remarque :** La valeur par défaut est de 3 minutes (180 000 ms). Les temps d'exécution des opérations peuvent varier entre 50 secondes et 2 minutes, mais peuvent également dépasser cette durée. Si la valeur `timeoutMs` est dépassée, l'exécution sera annulée.

## version

**Clé :**
<OptionTable
  options={[
    ['version', 'String or Number', 'Version de l\'API utilisée pour l\'endpoint.', 'Defaults to 2. azureAssistants defaults to 1 when endpoints.azureOpenAI.assistants is enabled, otherwise 2.'],
  ]}
/>

**Par défaut :** `2` ; `azureAssistants` vaut `1` par défaut lorsque `endpoints.azureOpenAI.assistants` est activé

**Exemple :**
```yaml filename="endpoints / azureAssistants / version"
version: 1
```

## models

**Clé :**
<OptionTable
  options={[
    ['models', 'Object', 'Contrôle la liste des modèles pour l\'endpoint.', 'Optional. Same structure as the custom endpoint [models](/docs/configuration/librechat_yaml/object_structure/custom_endpoint#models) field.'],
  ]}
/>

**Sous-clés :**

<OptionTable
  options={[
    ['default', 'Array/List of Strings or Objects', 'Modèles à lister pour l\'endpoint. Obligatoire lorsque models est défini ; au moins un élément.', ''],

    ['userIdQuery', 'Boolean', 'Envoyer l\'identifiant utilisateur LibreChat sous forme de paramètre de requête lors de la récupération des modèles.', ''],

**Exemple :**
```yaml filename="endpoints / assistants / models"
models:
  default: ["gpt-4o"]
  fetch: false
```

## supportedIds

**Clé :**
<OptionTable
  options={[
    ['supportedIds', 'Array/List of Strings', 'Liste des IDs d\'assistants pris en charge', 'Use this or `excludedIds` but not both (the `excludedIds` field will be ignored if so).'],
  ]}
/>

**Exemple :**
```yaml filename="endpoints / assistants / supportedIds"
supportedIds:
  - "asst_supportedAssistantId1"
  - "asst_supportedAssistantId2"
```

## excludedIds

**Clé :**
<OptionTable
  options={[
    ['excludedIds', 'Array/List of Strings', 'Liste des IDs d\'assistants exclus', 'Use this or `supportedIds` but not both (the `excludedIds` field will be ignored if so).'],
  ]}
/>

**Exemple :**
```yaml filename="endpoints / assistants / excludedIds"
excludedIds:
  - "asst_excludedAssistantId1"
  - "asst_excludedAssistantId2"
```

## privateAssistants

**Clé :**
<OptionTable
  options={[
    ['privateAssistants', 'Boolean', 'Contrôle si les assistants sont privés pour l\'utilisateur qui les a créés', 'Does not work with `supportedIds` or `excludedIds` (`supportedIds` and `excludedIds` will be ignored).'],
  ]}
/>

**Par défaut :** `false`

**Exemple :**
```yaml filename="endpoints / assistants / privateAssistants"
privateAssistants: false
```

## retrievalModels

**Clé :**
<OptionTable
  options={[
    ['retrievalModels', 'Array/List of Strings', 'Spécifie les modèles qui prennent en charge la récupération pour l\'endpoint assistants.', 'Defines the models that support retrieval capabilities for the assistants endpoint. By default, it uses the latest known OpenAI models that support the official Retrieval feature.'],
  ]}
/>

**Par défaut :** `[]` (utilise les derniers modèles OpenAI connus qui prennent en charge la récupération)

**Exemple :**
```yaml filename="endpoints / assistants / retrievalModels"
retrievalModels:
  - "gpt-4-turbo-preview"
```

## capabilities

**Clé :**
<OptionTable
  options={[
    ['capabilities', 'Array/List of Strings', 'Spécifie les capacités de l\'assistant disponibles pour tous les utilisateurs pour le endpoint assistants.', 'Defines the assistant capabilities that are available to all users for the assistants endpoint. You can omit the capabilities you wish to exclude from the list.'],
  ]}
/>

**Par défaut :** `["code_interpreter", "image_vision", "retrieval", "actions", "tools"]`

**Exemple :**
```yaml filename="endpoints / assistants / capabilities"
capabilities:
  - "code_interpreter"
  - "retrieval"
  - "actions"
  - "tools"
  - "image_vision"
```
**Note :** Ce champ est optionnel. S'il est omis, le comportement par défaut consiste à inclure toutes les capacités listées dans l'exemple.
