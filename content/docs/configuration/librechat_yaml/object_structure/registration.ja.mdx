## 例 [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## socialLogins

**キー:**
<OptionTable
  options={[
    ['socialLogins', 'Array of Strings', '利用可能なソーシャルログインプロバイダーとその表示順序を定義します。', 'The order of the providers in the list determines their appearance order on the login/registration page. Each provider listed must be properly configured within the system to be active and available for users. This configuration allows for a tailored authentication experience, emphasizing the most relevant or preferred social login options for your user base.'],
  ]}
/>


**例:**
```yaml filename="registration / socialLogins"
socialLogins: ["google", "facebook", "github", "discord", "openid"]
```

## allowedDomains

**キー:**
<OptionTable
  options={[
    ['allowedDomains', 'Array of Strings', '登録を許可するメールアドレスのドメインを指定するリスト。', 'Users with email domains not listed will be restricted from registering.'],
  ]}
/>

このキーは任意です。省略した場合、どのメールドメインでも登録が許可されます。

**例:**
```yaml filename="registration / allowedDomains"
allowedDomains:
  - "gmail.com"
  - "protonmail.com"
```

## oauthStateTtlMs

**キー:**
<OptionTable
  options={[
    ['oauthStateTtlMs', 'Integer', 'ソーシャルログインの開始から、コールバックに到達するまでに許容されるミリ秒数。この時間を超えた場合、ログイン試行は拒否されます。', 'Range: 60000 to 3600000. Default: 600000 (10 minutes).'],
  ]}

**例:**

## openidDiscovery

LibreChatが、IDプロバイダーに対するOpenID Connectのディスカバリーを再試行する方法を制御します。ここで設定した各フィールドは、対応する環境変数(`OPENID_DISCOVERY_RETRY_ATTEMPTS`、`OPENID_DISCOVERY_RETRY_DELAY_MS`)より優先されます。未設定のフィールドは、環境変数の値に、さらにその後デフォルト値にフォールバックします。

**キー:**
<OptionTable
  options={[
    ['startupAttempts', 'Integer', '起動を続行する前に行われる検出の試行回数。0 の場合はバックグラウンドでのみ再試行します。', 'Range: 0 to 100. Default: 1.'],
    ['retryDelayMs', 'Integer', '起動時およびバックグラウンドでの検出試行の間隔（ミリ秒）。', 'Range: 100 to 3600000. Default: 5000.'],
  ]}
/>

**例:**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 10000
```
