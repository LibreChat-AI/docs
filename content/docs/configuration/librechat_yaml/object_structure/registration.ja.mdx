`registration` ブロックでは、表示されるソーシャルログインボタンとその並び順、サインアップまたはサインインを許可するメールドメイン、そしてソーシャルログインおよび OpenID ログインに関するいくつかのタイミング設定を制御します。ユーザー登録とソーシャルログインの有効/無効は環境変数で行います。詳しくは [Authentication](/docs/configuration/authentication) を参照してください。

## 例 [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## allowedDomains

**キー:**
<OptionTable
  options={[
    ['allowedDomains', 'Array of Strings', '登録およびサインインを許可するメールドメインの一覧。', 'Users whose email domain is not listed cannot register, and are also turned away when signing in through a social provider, OpenID, SAML, or LDAP, and when requesting a password reset. ## openidDiscovery

LibreChat が OpenID プロバイダーのディスカバリードキュメントを取得する際のリトライ動作を制御します。未設定の各フィールドは、環境変数（`OPENID_DISCOVERY_RETRY_ATTEMPTS`、`OPENID_DISCOVERY_RETRY_DELAY_MS`）の値にフォールバックし、それも未設定の場合はデフォルト値が使用されます。

**キー:**
<OptionTable
  options={[
    ['startupAttempts', 'Number', '起動を続行する前に行われた検出の試行。', 'Between 0 and 100. 0 skips the startup attempts and only retries in the background. Default: 1.'],
    ['retryDelayMs', 'Number', '起動時およびバックグラウンドでの検出試行の間隔（ミリ秒）。', 'Between 100 and 3600000. Default: 5000.'],
  ]}
/>

**例:**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 5000
```
