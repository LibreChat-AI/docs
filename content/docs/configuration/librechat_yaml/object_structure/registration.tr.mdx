## Örnek [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## allowedDomains

**Anahtar:**
<OptionTable
  options={[
    ['allowedDomains', 'Array of Strings', 'Kayıt için izin verilen e-posta alan adlarını belirten bir liste.', 'Users with email domains not listed will be restricted from registering.'],
  ]}
/>

Bu anahtar isteğe bağlıdır. Bunu atlarsanız, kayıt herhangi bir e-posta alan adı için kabul edilir.

**Örnek:**
```yaml filename="registration / allowedDomains"
allowedDomains:
  - "gmail.com"
  - "protonmail.com"
```

## openidDiscovery

LibreChat, OpenID Connect keşfini (discovery) kimlik sağlayıcınıza karşı nasıl yeniden deneyeceğini denetler. Burada ayarlanan her alan, eşleşen ortam değişkeninin (`OPENID_DISCOVERY_RETRY_ATTEMPTS`, `OPENID_DISCOVERY_RETRY_DELAY_MS`) önüne geçer; ayarlanmayan alanlar önce ortam değişkenine, ardından varsayılan değere geri döner.

**Anahtarlar:**
<OptionTable
  options={[
    ['startupAttempts', 'Integer', 'Başlatma devam etmeden önce yapılan keşif denemeleri. Yalnızca arka planda 0 yeniden deneme.', 'Range: 0 to 100. Default: 1.'],
    ['retryDelayMs', 'Integer', 'Başlangıç ile arka plan keşif denemeleri arasındaki milisaniye cinsinden süre.', 'Range: 100 to 3600000. Default: 5000.'],
  ]}
/>

**Örnek:**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 10000
```
