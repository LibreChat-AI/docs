`registration` bloğu, hangi sosyal giriş düğmelerinin görüneceğini ve hangi sırayla gösterileceğini, hangi e-posta alan adlarının kayıt olabileceğini veya giriş yapabileceğini ve sosyal ile OpenID girişleri için birkaç zamanlama ayarını denetler. Kayıt ve sosyal girişi açma veya kapatma işlemi ortam değişkenleriyle yapılır; bkz. [Authentication](/docs/configuration/authentication).

## Örnek [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

**Anahtar:**

## openidDiscovery

LibreChat, OpenID sağlayıcısının keşif belgesini (discovery document) almayı nasıl yeniden deneyeceğini denetler. Ayarlanmamış her alan, önce kendi ortam değişkenine (`OPENID_DISCOVERY_RETRY_ATTEMPTS`, `OPENID_DISCOVERY_RETRY_DELAY_MS`), ardından varsayılan değere geri döner.

**Anahtarlar:**
<OptionTable
  options={[
    ['startupAttempts', 'Number', 'Başlangıç devam etmeden önce yapılan keşif denemeleri.', 'Between 0 and 100. 0 skips the startup attempts and only retries in the background. Default: 1.'],
    ['retryDelayMs', 'Number', 'Başlangıç ile arka plan keşif denemeleri arasındaki milisaniye cinsinden süre.', 'Between 100 and 3600000. Default: 5000.'],
  ]}
/>

**Örnek:**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 5000
```
