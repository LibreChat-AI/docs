## Ikhtisar [#overview]

Objek `speech` memungkinkan Anda untuk mengonfigurasi penyedia Text-to-Speech (TTS) dan Speech-to-Text (STT) secara langsung di dalam file konfigurasi `librechat.yaml` Anda. Hal ini memungkinkan layanan ucapan sisi server tanpa mengharuskan pengguna untuk mengonfigurasi kunci API mereka sendiri.

**Bidang di bawah `speech`:**

- `tts` - Konfigurasi penyedia Text-to-Speech
- `stt` - Konfigurasi penyedia Speech-to-Text
- `speechTab` - Pengaturan UI default untuk fitur ucapan

**Catatan:**

- Beberapa penyedia dapat dikonfigurasi secara bersamaan
- Pengguna dapat memilih penyedia pilihan mereka dari opsi yang tersedia
- API keys dalam file config harus menggunakan referensi environment variable demi keamanan

## Contoh [#example]

```yaml filename="speech"
speech:
  tts:
    allowedAddresses: ["tts.internal:8080"]
    openai:
      apiKey: "${TTS_API_KEY}"
      model: "tts-1"
      voices: ["alloy", "echo", "fable", "onyx", "nova", "shimmer"]
    elevenlabs:
      apiKey: "${ELEVENLABS_API_KEY}"
      model: "eleven_multilingual_v2"
      voices: ["voice-id-1", "voice-id-2"]
  stt:
    allowedAddresses: ["stt.internal:8080"]
    openai:
      apiKey: "${STT_API_KEY}"
      model: "whisper-1"
  speechTab:
    conversationMode: true
    advancedMode: false
    speechToText: true
    textToSpeech: true
```

## Perlindungan SSRF [#ssrf-protection]

LibreChat melindungi URL STT dan TTS yang disediakan operator pada saat koneksi. Destinasi privat, loopback, link-local, dan cloud-metadata diblokir secara default, dan pengalihan (redirects) dinonaktifkan untuk permintaan ucapan (speech requests).

`speech.tts.allowedAddresses` dan `speech.stt.allowedAddresses` adalah daftar pengecualian terpisah, bukan daftar izin (allowlist) yang ketat. Tambahkan `host:port`, `private.ip:port`, atau `[ipv6]:port` privat yang tepat hanya jika bagian tersebut harus menjangkau layanan self-hosted tepercaya. Jangan gunakan URL, path, rentang CIDR, host/IP mentah, atau literal IP publik. Port default dinormalisasi, sehingga URL HTTPS tanpa port eksplisit akan diperiksa sebagai port `443`.

Hostname yang dikecualikan memercayai alamat privat apa pun yang diselesaikan pada port tersebut. Utamakan penggunaan literal IP privat jika memungkinkan, dan cantumkan hanya nama-nama yang DNS-nya Anda kendalikan dan tidak dapat dialihkan oleh penyerang.

Ketika forward proxy membawa permintaan hostname, proxy tersebut melakukan DNS tujuan dan egress, sehingga proxy harus menegakkan kebijakan SSRF-nya sendiri. Destinasi privat literal tetap diblokir sebelum penanganan proxy kecuali alamat dan port persisnya dikecualikan.

## Catatan [#notes]

- Selalu gunakan referensi variabel lingkungan (contoh: `${API_KEY}`) untuk kunci API di dalam file konfigurasi
- Beberapa penyedia TTS dapat dikonfigurasi; pengguna memilih opsi pilihan mereka di UI
- Pengaturan `speechTab` menentukan nilai default yang dapat diganti oleh pengguna di pengaturan pribadi mereka
- `browser` menggunakan dukungan ucapan bawaan peramban; `external` menggunakan penyedia sisi server yang dikonfigurasi di bawah `speech.stt` atau `speech.tts`
- Default STT `openai` dan `azureOpenAI` yang ada, serta default TTS `openai`, `azureOpenAI`, `elevenlabs`, dan `localai`, dimigrasikan ke `external`; mesin eksternal yang tidak tersedia akan kembali ke `browser`
- Untuk dokumentasi fitur terperinci, lihat [Speech to Text & Text to Speech](/docs/configuration/stt_tts)
