`models` 下的每一项都是记录列表的一部分，可以是布尔值或对象：

**当将模型指定为对象时：**

一个对象可用于详细配置模型，包括其 `deploymentName`、`version` 和/或 `assistants` 标志。此模式用于对模型进行更精细的控制，尤其是在同一实例或资源组下处理多个版本或部署的情况。

**示例**:
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object}"
models:
  gpt-4-vision-preview:
    deploymentName: "gpt-4-vision-preview"
    version: "2024-02-15-preview"
```

**注意：**
- **Deployment Names** 和 **Versions** 对于确保使用正确的模型至关重要。
    - 请仔细核对这些值以确保准确性，从而防止出现意外行为。

### deploymentName

**密钥：**
<OptionTable
  options={[
    ['deploymentName', 'String', '该模型部署的名称。用于标识 Azure 中该模型的部署。', 'This does not have to be the matching OpenAI model name as is convention, but must match the actual name of your deployment on Azure.'],
  ]}
/>

**必填:**否。省略时,使用分组的 `deploymentName`。对于非无服务器(non-serverless)分组,必须在模型或分组上设置该值。

**示例：**
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object} / deploymentName"
deploymentName: "gpt-4-vision-preview"
```

## assistants

**密钥：**

```yaml filename="endpoints / azureOpenAI / groups / {group_item} / assistants"

```
