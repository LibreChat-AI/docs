## Exemple [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## allowedDomains

**Clé :**
<OptionTable
  options={[
    ['allowedDomains', 'Array of Strings', 'Une liste spécifiant les domaines d\'e-mail autorisés pour l\'inscription.', 'Users with email domains not listed will be restricted from registering.'],
  ]}
/>

Cette clé est facultative. Si vous l'omettez, l'inscription est autorisée pour tout domaine d'adresse e-mail.

**Exemple :**
```yaml filename="registration / allowedDomains"
allowedDomains:
  - "gmail.com"
  - "protonmail.com"
```

## openidDiscovery

Contrôle la manière dont LibreChat relance la découverte OpenID Connect auprès de votre fournisseur d'identité. Chaque champ défini ici a priorité sur la variable d'environnement correspondante (`OPENID_DISCOVERY_RETRY_ATTEMPTS`, `OPENID_DISCOVERY_RETRY_DELAY_MS`) ; les champs que vous laissez non définis reviennent à la variable d'environnement, puis à la valeur par défaut.

**Clés :**
<OptionTable
  options={[
    ['startupAttempts', 'Integer', 'Tentatives de découverte effectuées avant la poursuite du démarrage. 0 nouvelle tentative uniquement en arrière-plan.', 'Range: 0 to 100. Default: 1.'],
    ['retryDelayMs', 'Integer', 'Millisecondes entre le démarrage et les tentatives de découverte en arrière-plan.', 'Range: 100 to 3600000. Default: 5000.'],
  ]}
/>

**Exemple :**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 10000
```
