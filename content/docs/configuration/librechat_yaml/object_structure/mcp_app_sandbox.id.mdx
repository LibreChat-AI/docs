## Ikhtisar [#overview]

Aplikasi MCP adalah antarmuka interaktif yang dikembalikan oleh server MCP bersama dengan hasil alat. LibreChat merender setiap aplikasi dalam frame sandbox yang disajikan dari origin terpisah, sehingga konten Aplikasi tidak dapat menjangkau halaman LibreChat. Objek `mcpAppSandbox` mengonfigurasi sandbox tersebut beserta batasan yang diterapkan pada Aplikasi.

Aplikasi MCP diaktifkan melalui [`mcpSettings.apps`](/docs/configuration/librechat_yaml/object_structure/mcp_settings#apps). Setiap kunci di bawah `mcpAppSandbox` bersifat opsional dan memiliki nilai default.

## Contoh [#example]

```yaml filename="mcpAppSandbox"
mcpAppSandbox:
  url: https://mcp-sandbox.example.com/api/mcp/sandbox
  maxActiveViews: 3
  maxPersistedAppBytes: 1048576
  maxAdmissionRequestsPerMinute: 240
  operationLimits:
    maxBytes: 4194304
    timeoutMs: 30000
    maxActive: 16
```

## Menjalankan sandbox secara mandiri [#hosting-the-sandbox]

Halaman sandbox disajikan oleh LibreChat itu sendiri di `/api/mcp/sandbox`. Berikan origin khusus untuknya, misalnya hostname kedua yang reverse proxy-nya meneruskan ke server LibreChat yang sama, dan atur `url` ke rute tersebut pada origin khusus itu.

Halaman sandbox menolak untuk di-embed kecuali origin LibreChat diizinkan untuk membingkainya. Atur [`MCP_SANDBOX_FRAME_ANCESTORS`](/docs/configuration/dotenv#mcp-server-configuration) ke origin tempat pengguna membuka LibreChat, misalnya `MCP_SANDBOX_FRAME_ANCESTORS=https://chat.example.com`. Jika tidak diatur, halaman akan disajikan dengan `frame-ancestors 'none'` dan frame App akan tetap kosong.
