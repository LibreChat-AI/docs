## Esempio [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## socialLogins

**Chiave:**
<OptionTable
  options={[
    ['socialLogins', 'Array of Strings', 'Definisce i provider di social login disponibili e il loro ordine di visualizzazione.', 'The order of the providers in the list determines their appearance order on the login/registration page. Each provider listed must be properly configured within the system to be active and available for users.   ]}
/>


**Esempio:**
```yaml filename="registration / socialLogins"
socialLogins: ["google", "facebook", "github", "discord", "openid"]
```

## allowedDomains

**Chiave:**
<OptionTable
  options={[
    ['allowedDomains', 'Array of Strings', 'Un elenco che specifica i domini email consentiti per la registrazione.', 'Users with email domains not listed will be restricted from registering.'],
  ]}
/>

Questa chiave è facoltativa. Se la ometti, la registrazione è consentita per qualsiasi dominio email.

**Esempio:**
```yaml filename="registration / allowedDomains"
allowedDomains:
  - "gmail.com"
  - "protonmail.com"
```

## openidDiscovery

Controlla come LibreChat ripete la discovery OpenID Connect verso il tuo identity provider. Ogni campo impostato qui ha la precedenza sulla corrispondente variabile d'ambiente (`OPENID_DISCOVERY_RETRY_ATTEMPTS`, `OPENID_DISCOVERY_RETRY_DELAY_MS`); i campi che lasci non impostati ricorrono alla variabile d'ambiente e, in mancanza di questa, al valore predefinito.

**Chiavi:**
<OptionTable
  options={[
    ['startupAttempts', 'Integer', 'Tentativi di rilevamento effettuati prima che l\'avvio prosegua. 0 nuovi tentativi solo in background.', 'Range: 0 to 100. Default: 1.'],
    ['retryDelayMs', 'Integer', 'Millisecondi tra l\'avvio e i tentativi di rilevamento in background.', 'Range: 100 to 3600000. Default: 5000.'],
  ]}
/>

**Esempio:**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 10000
```
