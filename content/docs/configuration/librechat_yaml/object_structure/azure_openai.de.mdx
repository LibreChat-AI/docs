Die Integration des Azure OpenAI Service in Ihre Anwendung ermöglicht es Ihnen, nahtlos mehrere Bereitstellungen und regionale Modelle zu nutzen, die von Azure OpenAI gehostet werden. Dieser Abschnitt beschreibt, wie Sie den Azure OpenAI endpoint für Ihre Anforderungen konfigurieren.

**[Für eine detaillierte Anleitung zur Einrichtung von Azure OpenAI-Konfigurationen, klicken Sie hier](/docs/configuration/librechat_yaml/ai_endpoints/azure)**

## Beispielkonfiguration [#example-configuration]

```yaml filename="Example Azure OpenAI Object Structure"
endpoints:
  azureOpenAI:
    titleModel: "gpt-4-turbo"
    groups:
      - group: "my-westus" # arbitrary name
        apiKey: "${WESTUS_API_KEY}"
        instanceName: "actual-instance-name" # name of the resource group or instance
        version: "2023-12-01-preview"
        # baseURL: https://prod.example.com
        # additionalHeaders:
        #   X-Custom-Header: value
        models:
          gpt-4-vision-preview:
            deploymentName: gpt-4-vision-preview
            version: "2024-02-15-preview"
          gpt-3.5-turbo:
            deploymentName: gpt-35-turbo
          gpt-3.5-turbo-1106:
            deploymentName: gpt-35-turbo-1106
          gpt-4:
            deploymentName: gpt-4
          gpt-4-1106-preview:
            deploymentName: gpt-4-1106-preview
      - group: "my-eastus"
        apiKey: "${EASTUS_API_KEY}"
        instanceName: "actual-eastus-instance-name"
        deploymentName: gpt-4-turbo
        version: "2024-02-15-preview"
        baseURL: "https://gateway.ai.cloudflare.com/v1/cloudflareId/azure/azure-openai/${INSTANCE_NAME}/${DEPLOYMENT_NAME}" # uses env variables
        additionalHeaders:
          X-Custom-Header: value
        models:
          gpt-4-turbo: true
```

> **Hinweis:** Der Azure OpenAI-Endpoint unterstützt eine Teilmenge der [Shared Endpoint Settings](/docs/configuration/librechat_yaml/object_structure/shared_endpoint_settings), darunter `streamRate`, `titleConvo`, `titleModel`, `titleMethod`, `titlePrompt`, `titlePromptTemplate`, `titleTiming` sowie die Einstellungen für Aktivitäts- und Reasoning-Labels. `titleEndpoint`, `headers` und `maxToolResultChars` sind für diesen Endpoint nicht verfügbar; verwende stattdessen `additionalHeaders` auf einer Gruppe anstelle von `headers`.

## Struktur des Gruppenobjekts [#group-object-structure]

Jedes Element unter `groups` ist Teil einer Liste von Datensätzen, die jeweils die folgenden Felder enthalten:

### group

**Schlüssel:**
<OptionTable
  options={[
    ['group', 'String', 'Bezeichner für eine Gruppe von Modellen.', ''],
  ]}
/>

**Erforderlich:** ja

**Beispiel:**
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / group"
"group": "my-westus"
```

### apiKey

**Schlüssel:**
<OptionTable
  options={[
    ['apiKey', 'String', 'Der API-Schlüssel für den Zugriff auf den Azure OpenAI Service.', 'It\'s highly recommended to use a custom env. variable reference for this field, i.e. `${YOUR_VARIABLE}`'],
  ]}
/>

**Erforderlich:** ja

**Beispiel:**
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / apiKey"
apiKey: "${WESTUS_API_KEY}"
```

### instanceName

**Schlüssel:**
<OptionTable
  options={[
    ['instanceName', 'String', 'Name der Azure-Instanz. **Unterstützt beide Domain-Formate**: `.openai.azure.com` (veraltet) und `.cognitiveservices.azure.com` (neu). Sie können entweder die vollständige Domain (z. B. `my-instance.cognitiveservices.azure.com`) oder nur den Instanznamen (z. B. `my-instance`) zur Abwärtskompatibilität mit dem alten `.openai.azure.com`-Format angeben.', 'It\'s recommended to use a custom env. variable reference for this field, i.e. `${YOUR_VARIABLE}`'],
  ]}
/>

**Erforderlich:** ja, es sei denn, die Gruppe setzt `serverless: true`. Das Setzen von `baseURL` hebt diese Anforderung nicht auf.

**Beispiel:**
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / instanceName"
# Using just the instance name (legacy format applied)
instanceName: "my-westus"
# OR using the full domain (new format)
instanceName: "my-westus.cognitiveservices.azure.com"
```
