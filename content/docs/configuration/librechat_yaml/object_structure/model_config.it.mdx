Ogni elemento sotto `models` fa parte di un elenco di record, che può essere un valore booleano o un Object:

**Quando si specifica un modello come oggetto:**

Un oggetto consente una configurazione dettagliata del modello, includendo il suo `deploymentName`, la `version` e/o il flag `assistants`. Questa modalità viene utilizzata per un controllo più granulare sui modelli, in particolare quando si lavora con più versioni o deployment all'interno di un'unica istanza o gruppo di risorse.

**Esempio**:
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object}"
models:
  gpt-4-vision-preview:
    deploymentName: "gpt-4-vision-preview"
    version: "2024-02-15-preview"
```

**Note:**
- I **Deployment Names** e le **Versions** sono fondamentali per garantire che venga utilizzato il modello corretto.
    - Controlla attentamente questi valori per verificarne l'accuratezza e prevenire comportamenti imprevisti.

### deploymentName

**Chiave:**
<OptionTable
  options={[
    ['deploymentName', 'String', 'Il nome del deployment per il modello. Identifica il deployment del modello all\'interno di Azure.', 'This does not have to be the matching OpenAI model name as is convention, but must match the actual name of your deployment on Azure.'],
  ]}
/>

**Obbligatorio:** no. Se omesso, viene utilizzato il `deploymentName` del gruppo. Per i gruppi non serverless, deve essere impostato sul modello oppure sul gruppo.

**Esempio:**
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object} / deploymentName"
deploymentName: "gpt-4-vision-preview"
```

## version

**Chiave:**
<OptionTable
  options={[
    ['version', 'String', 'Specifica la versione del modello. Definisce la versione del modello da utilizzare.', ''],
  ]}
/>

**Obbligatorio:** no. Se omesso, viene utilizzata la `version` del gruppo. Per i gruppi non serverless, deve essere impostato sul modello o sul gruppo.

**Esempio:**
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object} / version"
version: "2024-02-15-preview"
```

## assistants

**Chiave:**
<OptionTable
  options={[
    ['assistants', 'Boolean', 'Accettato su un oggetto modello dallo schema. I modelli Azure Assistants vengono selezionati tramite il flag assistants a livello di gruppo, quindi impostalo sul gruppo.', ''],

/>

**Obbligatorio:** no

**Esempio** (impostato sul gruppo, dove ha effetto):
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / assistants"
assistants: true
```
