Blok `registration` steruje tym, które przyciski logowania społecznościowego są wyświetlane i w jakiej kolejności, które domeny adresów e-mail mogą się rejestrować lub logować oraz kilkoma ustawieniami czasowymi dla logowań społecznościowych i OpenID. Włączanie i wyłączanie rejestracji oraz logowania społecznościowego odbywa się za pomocą zmiennych środowiskowych; zob. [Authentication](/docs/configuration/authentication).

## Przykład [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## openidDiscovery

Kontroluje, w jaki sposób LibreChat ponawia pobieranie dokumentu wykrywania (discovery) dostawcy OpenID. Każde nieustawione pole korzysta najpierw z odpowiadającej mu zmiennej środowiskowej (`OPENID_DISCOVERY_RETRY_ATTEMPTS`, `OPENID_DISCOVERY_RETRY_DELAY_MS`), a jeśli i ona nie jest ustawiona, z wartości domyślnej.

**Klucze:**
<OptionTable
  options={[
    ['startupAttempts', 'Number', 'Próby wykrywania podejmowane przed kontynuowaniem uruchamiania.', 'Between 0 and 100. 0 skips the startup attempts and only retries in the background. Default: 1.'],
    ['retryDelayMs', 'Number', 'Milisekundy między uruchomieniem a próbami wykrywania w tle.', 'Between 100 and 3600000. Default: 5000.'],
  ]}
/>

**Przykład:**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 5000
```
