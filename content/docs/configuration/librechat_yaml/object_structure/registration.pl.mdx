## Przykład [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## allowedDomains

**Klucz:**
<OptionTable
  options={[
    ['allowedDomains', 'Array of Strings', 'Lista określająca dozwolone domeny e-mail dla rejestracji.', 'Users with email domains not listed will be restricted from registering.'],
  ]}
/>

Ten klucz jest opcjonalny. Jeśli go pominiesz, rejestracja będzie dozwolona dla adresów e-mail z dowolnej domeny.

**Przykład:**
```yaml filename="registration / allowedDomains"
allowedDomains:
  - "gmail.com"
  - "protonmail.com"
```

## openidDiscovery

Kontroluje sposób, w jaki LibreChat ponawia próby wykrywania (discovery) OpenID Connect u Twojego dostawcy tożsamości. Każde pole ustawione tutaj ma pierwszeństwo przed odpowiadającą mu zmienną środowiskową (`OPENID_DISCOVERY_RETRY_ATTEMPTS`, `OPENID_DISCOVERY_RETRY_DELAY_MS`); pola, których nie ustawisz, przyjmują wartość ze zmiennej środowiskowej, a jeśli jej brak, wartość domyślną.

**Klucze:**
<OptionTable
  options={[
    ['startupAttempts', 'Integer', 'Próby wykrywania podejmowane przed kontynuacją uruchamiania. 0 ponowień tylko w tle.', 'Range: 0 to 100. Default: 1.'],
    ['retryDelayMs', 'Integer', 'Milisekundy między uruchomieniem a próbami wykrywania w tle.', 'Range: 100 to 3600000. Default: 5000.'],
  ]}
/>

**Przykład:**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 10000
```
