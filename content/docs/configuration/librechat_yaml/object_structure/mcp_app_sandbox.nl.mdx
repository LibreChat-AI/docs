## Overzicht [#overview]

MCP Apps zijn interactieve interfaces die een MCP-server samen met een toolresultaat terugstuurt. LibreChat rendert elke App in een gesandboxed frame dat wordt geserveerd vanaf een afzonderlijke origin, waardoor App-inhoud de LibreChat-pagina niet kan bereiken. Het `mcpAppSandbox`-object configureert die sandbox en de limieten die op Apps worden toegepast.

MCP Apps worden ingeschakeld met [`mcpSettings.apps`](/docs/configuration/librechat_yaml/object_structure/mcp_settings#apps). Elke sleutel onder `mcpAppSandbox` is optioneel en heeft een standaardwaarde.

## Voorbeeld [#example]

```yaml filename="mcpAppSandbox"
mcpAppSandbox:
  url: https://mcp-sandbox.example.com/api/mcp/sandbox
  maxActiveViews: 3
  maxPersistedAppBytes: 1048576
  maxAdmissionRequestsPerMinute: 240
  operationLimits:
    maxBytes: 4194304
    timeoutMs: 30000
    maxActive: 16
```

## De sandbox hosten [#hosting-the-sandbox]

De sandbox-pagina wordt door LibreChat zelf aangeboden op `/api/mcp/sandbox`. Geef deze een eigen origin, zoals een tweede hostnaam waarvan de reverse proxy doorstuurt naar dezelfde LibreChat-server, en stel `url` in op die route op de eigen origin.

De sandboxpagina weigert ingesloten te worden, tenzij de LibreChat-oorsprong toestemming heeft om deze in een frame te tonen. Stel [`MCP_SANDBOX_FRAME_ANCESTORS`](/docs/configuration/dotenv#mcp-server-configuration) in op de oorsprong waarop gebruikers LibreChat openen, bijvoorbeeld `MCP_SANDBOX_FRAME_ANCESTORS=https://chat.example.com`. Wanneer deze variabele niet is ingesteld, wordt de pagina geserveerd met `frame-ancestors 'none'` en blijven App-frames leeg.
