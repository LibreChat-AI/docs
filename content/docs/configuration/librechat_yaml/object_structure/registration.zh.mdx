## 示例 [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## socialLogins

**密钥：**
<OptionTable
  options={[
    ['socialLogins', 'Array of Strings', '定义可用的社交登录提供商及其显示顺序。', 'The order of the providers in the list determines their appearance order on the login/registration page. Each provider listed must be properly configured within the system to be active and available for users. This configuration allows for a tailored authentication experience, emphasizing the most relevant or preferred social login options for your user base.'],
  ]}
/>


**示例：**
```yaml filename="registration / socialLogins"
socialLogins: ["google", "facebook", "github", "discord", "openid"]
```

## allowedDomains

**密钥：**
<OptionTable
  options={[
    ['allowedDomains', 'Array of Strings', '指定允许注册的电子邮件域列表。', 'Users with email domains not listed will be restricted from registering.'],
  ]}
/>

该密钥为可选项。若省略此项,则允许任何邮箱域名进行注册。

**示例：**
```yaml filename="registration / allowedDomains"
allowedDomains:
  - "gmail.com"
  - "protonmail.com"
```

## oauthStateTtlMs

**密钥：**
<OptionTable
  options={[
    ['oauthStateTtlMs', 'Integer', '启动社交登录后，登录尝试在被拒绝之前到达回调所允许的最长时间（毫秒）。', 'Range: 60000 to 3600000. Default: 600000 (10 minutes).'],
  ]}
/>

**示例：**
```yaml filename="registration / oauthStateTtlMs"
oauthStateTtlMs: 900000
```

## openidDiscovery

控制 LibreChat 在与身份提供商进行 OpenID Connect 发现(discovery)时的重试方式。此处设置的每个字段都优先于对应的环境变量(`OPENID_DISCOVERY_RETRY_ATTEMPTS`、`OPENID_DISCOVERY_RETRY_DELAY_MS`);未设置的字段将回退到环境变量,若环境变量也未设置,则使用默认值。

**密钥:**
<OptionTable
  options={[
    ['startupAttempts', 'Integer', '启动继续前的发现尝试次数。仅在后台重试次数为 0。', 'Range: 0 to 100. Default: 1.'],
    ['retryDelayMs', 'Integer', '启动与后台发现尝试之间的毫秒间隔。', 'Range: 100 to 3600000. Default: 5000.'],
  ]}
/>

**示例：**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 10000
```
