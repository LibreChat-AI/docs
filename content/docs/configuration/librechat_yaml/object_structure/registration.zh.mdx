title: 注册对象结构

---

`registration` 配置块用于控制显示哪些社交登录按钮及其顺序、允许哪些邮箱域名注册或登录，以及社交登录和 OpenID 登录的一些时间相关设置。注册和社交登录的开启或关闭需通过环境变量完成，详见[身份验证](/docs/configuration/authentication)。

## 示例 [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## socialLogins

**密钥：**
<OptionTable
  options={[
    ['socialLogins', 'Array of Strings', '定义可用的社交登录提供商及其显示顺序。', 'The order of the providers in the list determines their order on the login and registration pages. Valid values are google, facebook, github, discord, apple, openid, and saml. A provider only shows up if it is also configured with its environment variables. Default: google, facebook, openid, github, discord, saml.'],
  ]}
/>

**示例：**
```yaml filename="registration / socialLogins"
socialLogins: ["google", "facebook", "github", "discord", "openid"]
```

## allowedDomains

**密钥：**
<OptionTable
  options={[
    ['allowedDomains', 'Array of Strings', '允许注册和登录的电子邮件域名列表。', 'Users whose email domain is not listed cannot register, and are also turned away when signing in through a social provider, OpenID, SAML, or LDAP, and when requesting a password reset. Domains must match exactly (subdomains are not included) and are compared case-insensitively. When omitted or empty, every domain is allowed.'],
  ]}
/>

**示例：**
```yaml filename="registration / allowedDomains"
allowedDomains:
  - "gmail.com"
  - "protonmail.com"
```

## oauthStateTtlMs

**密钥：**
<OptionTable
  options={[
    ['oauthStateTtlMs', 'Number', '从开始社交登录或 OpenID 登录到回调完成所允许的最长时间(以毫秒为单位)。', 'Between 60000 (1 minute) and 3600000 (1 hour). Default: 600000 (10 minutes).'],
  ]}
/>

**示例：**
```yaml filename="registration / oauthStateTtlMs"
oauthStateTtlMs: 600000
```

## openidDiscovery

控制 LibreChat 重试获取 OpenID 提供方发现文档(discovery document)的方式。每个未设置的字段会依次回退到其对应的环境变量(`OPENID_DISCOVERY_RETRY_ATTEMPTS`、`OPENID_DISCOVERY_RETRY_DELAY_MS`),最后再回退到默认值。

**密钥:**
<OptionTable
  options={[
    ['startupAttempts', 'Number', '在启动继续之前进行的发现尝试。', 'Between 0 and 100. 0 skips the startup attempts and only retries in the background. Default: 1.'],
    ['retryDelayMs', 'Number', '启动与后台发现尝试之间的毫秒间隔。', 'Between 100 and 3600000. Default: 5000.'],
  ]}
/>

**示例：**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 5000
```
