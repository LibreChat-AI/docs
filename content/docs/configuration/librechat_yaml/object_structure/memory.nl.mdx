## Overzicht [#overview]

Het `memory`-object schakelt [Gebruikersgeheugen](/docs/features/memory) in en stelt de limieten ervan in. Door de sectie toe te voegen wordt het geheugen pas ingeschakeld: opgeslagen items worden dan aan de gesprekken van elke gebruiker toegevoegd, gebruikers kunnen ze beheren in het Geheugenpaneel, en de Geheugentool (`set_memory` en `delete_memory`) wordt aangeboden in chats en agents, zolang de `memory`-capaciteit is ingeschakeld voor het agents-endpoint (dat is standaard het geval).

Automatische geheugenextractie, waarbij een afzonderlijke geheugenagent elke uitwisseling beoordeelt en feiten opslaat zonder dat erom wordt gevraagd, is een aparte optie waarvoor je moet kiezen: stel `agent.enabled: true` in en geef er een model aan.

## Voorbeeld [#example]

```yaml filename="memory"
memory:
  disabled: false
  validKeys: ['user_preferences', 'conversation_context', 'personal_info']
  tokenLimit: 2000
  charLimit: 10000
  maxInputTokens: 12000
  personalize: true
  messageWindowSize: 5
  agent:
    enabled: true
    provider: 'openAI'
    model: 'gpt-4'
    instructions: 'You are a helpful assistant that remembers user preferences and context.'
    model_parameters:
      temperature: 0.7
      max_tokens: 1000
```

## agent

<OptionTable
  options={[
    [
      'agent',
      'Object | Union',
      'Configureert de optionele automatische memory agent. Kan een verwijzing naar een bestaande agent op ID zijn of een volledige agentconfiguratie.',
      'agent: { enabled: true, provider: "openAI", model: "gpt-4" }',

Configureert de automatische geheugenagent. Deze wordt alleen uitgevoerd wanneer `enabled` is ingesteld op `true`; een `agent`-blok zonder `enabled` wordt genegeerd en LibreChat logt een waarschuwing bij het opstarten.

Wanneer deze optie is ingeschakeld, wordt de geheugenagent bij elk chatverzoek gestart, tegelijk met het hoofdantwoord. Hij bekijkt de laatste `messageWindowSize` berichten (beperkt tot `maxInputTokens`) en slaat vermeldingen op of verwijdert ze zelfstandig. Hij krijgt de tijd tot het hoofdantwoord is voltooid plus maximaal 3 seconden; als hij daarna nog steeds bezig is, wordt zijn resultaat voor dat verzoek weggegooid.

Het `agent` veld ondersteunt twee verschillende configuratieformaten:

### Agent op ID [#agent-by-id]

Wanneer je een vooraf geconfigureerde agent hebt, kun je ernaar verwijzen via zijn ID:

```yaml filename="memory / agent (by ID)"
memory:
  agent:
    enabled: true
    id: 'memory-agent-001'
```

### Aangepaste Agent-configuratie [#custom-agent-configuration]

Voor meer controle kun je een volledige agentconfiguratie definiëren:

```yaml filename="memory / agent (custom)"
memory:
  agent:
    enabled: true
    provider: 'openAI'
    model: 'gpt-4'
    instructions: 'You are a memory assistant that helps maintain conversation context and user preferences.'
    model_parameters:
      temperature: 0.3
      max_tokens: 1500
      top_p: 0.9
```

## Volledig configuratievoorbeeld [#complete-configuration-example]

Een voorbeeld met elke geheugenoptie:

```yaml filename="librechat.yaml"
version: 1.3.18
cache: true

memory:
  disabled: false
  validKeys:
    - 'user_preferences'
    - 'conversation_context'
    - 'learned_facts'
    - 'personal_information'
  tokenLimit: 3000
  charLimit: 10000
  maxInputTokens: 12000
  personalize: true
  messageWindowSize: 8
  agent:
    enabled: true
    provider: 'openAI'
    model: 'gpt-4'
    instructions: |
      Store memory using only the specified validKeys. For user_preferences: save 
      explicitly stated preferences about communication style, topics of interest, 
      or workflow preferences. For conversation_context: save important facts or 
      ongoing projects mentioned. For learned_facts: save objective information 
      about the user. For personal_information: save only what the user explicitly 
      shares about themselves. Delete outdated or incorrect information promptly.
    model_parameters:
      temperature: 0.2
      max_tokens: 2000
      top_p: 0.8
      frequency_penalty: 0.1
```

## Aangepaste endpoints gebruiken [#using-custom-endpoints]

De memory-functie ondersteunt custom endpoints. Bij het gebruik van een custom endpoint moet het `provider` veld exact overeenkomen met de `name` van het custom endpoint. Custom headers met omgevingsvariabelen en gebruikers-placeholders worden correct opgelost.

```yaml filename="librechat.yaml with custom endpoint for memory"

endpoints:
  custom:
    - name: 'Custom Memory Endpoint'
      apiKey: 'dummy'
      baseURL: 'https://api.gateway.ai/v1'
      headers:
        x-gateway-api-key: '${GATEWAY_API_KEY}'
        x-gateway-virtual-key: '${GATEWAY_OPENAI_VIRTUAL_KEY}'
        X-User-Identifier: '{{LIBRECHAT_USER_EMAIL}}'
        X-Application-Identifier: 'LibreChat - Test'
        api-key: '${TEST_CUSTOM_API_KEY}'
      models:
        default:
          - 'gpt-4o-mini'
          - 'gpt-4o'
        fetch: false

memory:
  disabled: false
  tokenLimit: 3000
  maxInputTokens: 12000
  personalize: true
  messageWindowSize: 10
  agent:
    enabled: true
    provider: 'Custom Memory Endpoint'
    model: 'gpt-4o-mini'
```

- Zie [Custom Endpoint Headers](/docs/configuration/librechat_yaml/object_structure/custom_endpoint#headers) voor alle beschikbare placeholders

## Opmerkingen [#notes]

- `personalize` bepaalt of gebruikers zich kunnen afmelden, niet of het geheugen aan staat. Gebruik `disabled` om het geheugen uit te schakelen.
- `maxInputTokens` beperkt de chatcontext die naar de automatische geheugenagent wordt gestuurd, terwijl `tokenLimit` de totale omvang van opgeslagen geheugens begrenst.
- Aangepaste `instructions` vervangen de standaard geheugeninstructies en zijn vooral nuttig in combinatie met `validKeys`.
- Toegang wordt daarnaast per rol geregeld via de geheugenrechten (gebruiken, aanmaken, lezen, bijwerken, zich afmelden). Zie [`interface.memories`](/docs/configuration/librechat_yaml/object_structure/interface#memories), het [Admin Panel](/docs/features/admin_panel), of de beheerinstellingen onderaan het Geheugen-paneel.

## Probleemoplossing [#troubleshooting]

**Geheugen werkt niet.** Controleer of de sectie `memory` aanwezig is en `disabled` niet `true` is, of de rol van de gebruiker toestemming heeft om geheugen te gebruiken, en of de gebruiker **Opgeslagen geheugen raadplegen** niet heeft uitgeschakeld. Voor de Geheugentool moet de capaciteit `memory` in de lijst `capabilities` van het agents-endpoint staan, als u er een hebt ingesteld.

**Er wordt niets automatisch opgeslagen.** Automatische extractie vereist `agent.enabled: true` en een geldige `id`, of `provider` en `model`. Zonder dit worden items alleen opgeslagen wanneer een gebruiker het model vraagt iets te onthouden terwijl de Memory-tool is ingeschakeld, of wanneer ze handmatig worden toegevoegd.

**De geheugenagent werkt niet op een aangepast endpoint.** `provider` moet exact overeenkomen met de `name` van het aangepaste endpoint. Controleer eerst of het endpoint werkt voor normale chats, en controleer vervolgens of de omgevingsvariabelen waarnaar de headers verwijzen zijn ingesteld; headerplaceholders worden voor het geheugen op dezelfde manier opgelost als voor de chat.

**Het tokengebruik is hoog.** Verlaag `maxInputTokens` of `messageWindowSize` om minder chat naar de geheugenagent te sturen, verlaag `tokenLimit` om de opgeslagen herinneringen (die aan elk verzoek worden toegevoegd) klein te houden, en beperk `validKeys`.
