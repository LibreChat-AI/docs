## 예시 [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## allowedDomains

**키:**
<OptionTable
  options={[
    ['allowedDomains', 'Array of Strings', '등록을 허용할 이메일 도메인을 지정하는 목록입니다.', 'Users with email domains not listed will be restricted from registering.'],
  ]}
/>

이 키는 선택 사항입니다. 생략하면 모든 이메일 도메인에 대해 회원가입이 허용됩니다.

**예시:**
```yaml filename="registration / allowedDomains"
allowedDomains:
  - "gmail.com"
  - "protonmail.com"
```

## oauthStateTtlMs

**키:**
<OptionTable
  options={[
    ['oauthStateTtlMs', 'Integer', '소셜 로그인이 시작된 후 콜백에 도달하기까지 허용되는 최대 시간(밀리초). 이 시간이 지나면 로그인 시도는 거부됩니다.', 'Range: 60000 to 3600000. Default: 600000 (10 minutes).'],

## openidDiscovery

LibreChat가 identity provider에 대해 OpenID Connect discovery를 재시도하는 방식을 제어합니다. 여기에서 설정한 각 필드는 해당하는 환경 변수(`OPENID_DISCOVERY_RETRY_ATTEMPTS`, `OPENID_DISCOVERY_RETRY_DELAY_MS`)보다 우선합니다. 설정하지 않은 필드는 환경 변수 값을 사용하고, 환경 변수도 없으면 기본값을 따릅니다.

**키:**
<OptionTable
  options={[
    ['startupAttempts', 'Integer', '시작 절차가 계속되기 전에 검색을 시도한 횟수입니다. 0은 백그라운드에서만 재시도함을 의미합니다.', 'Range: 0 to 100. Default: 1.'],
    ['retryDelayMs', 'Integer', '시작 시점과 백그라운드 검색 시도 사이의 밀리초 단위 간격.', 'Range: 100 to 3600000. Default: 5000.'],
  ]}
/>

**예시:**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 10000
```
