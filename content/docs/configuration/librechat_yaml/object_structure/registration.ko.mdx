`registration` 블록은 표시되는 소셜 로그인 버튼과 그 순서, 가입 또는 로그인이 허용되는 이메일 도메인, 그리고 소셜 및 OpenID 로그인에 대한 몇 가지 시간 설정을 제어합니다. 회원가입과 소셜 로그인을 켜거나 끄는 작업은 환경 변수로 수행합니다. 자세한 내용은 [Authentication](/docs/configuration/authentication)을 참조하세요.

## 예시 [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## openidDiscovery

LibreChat가 OpenID 제공자의 디스커버리 문서를 가져올 때 재시도하는 방식을 제어합니다. 설정되지 않은 각 필드는 해당 환경 변수(`OPENID_DISCOVERY_RETRY_ATTEMPTS`, `OPENID_DISCOVERY_RETRY_DELAY_MS`)로 대체되며, 그마저도 없으면 기본값이 적용됩니다.

**키:**
<OptionTable
  options={[
    ['startupAttempts', 'Number', '시작이 계속되기 전에 수행된 검색 시도.', 'Between 0 and 100. 0 skips the startup attempts and only retries in the background. Default: 1.'],
    ['retryDelayMs', 'Number', '시작 시점과 백그라운드 검색 시도 사이의 밀리초 단위 간격.', 'Between 100 and 3600000. Default: 5000.'],
  ]}
/>

**예시:**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 5000
```
