이 페이지는 `assistants` 및 `azureAssistants` endpoint 모두에 적용됩니다.

<Callout type="warning">
OpenAI는 2026년 8월 26일에 Assistants API를 제거했으므로, OpenAI `assistants` endpoint는 더 이상 OpenAI에서 작동하지 않습니다. 대신 [Agents](/docs/features/agents)를 사용하세요. 자세한 내용은 [Assistants](/docs/configuration/pre_configured_ai/assistants)를 참조하세요.
</Callout>

**참고:** `azureAssistants`를 활성화하려면 [Azure OpenAI Configuration](/docs/configuration/librechat_yaml/ai_endpoints/azure#using-assistants-with-azure)에서 자세한 내용을 확인하세요.

## 예시 [#example]

```yaml filename="Assistants Endpoint"
endpoints:
  # azureAssistants: # <-- Azure-specific configuration has the same structure as `assistants`
    #  pollIntervalMs: 500
    #  timeoutMs: 10000

  assistants:
    disableBuilder: false
    # Use either `supportedIds` or `excludedIds` but not both
    supportedIds: ["asst_supportedAssistantId1", "asst_supportedAssistantId2"]
    # excludedIds: ["asst_excludedAssistantId"]
    # `privateAssistants` do not work with `supportedIds` or `excludedIds`
    # privateAssistants: false
    # (optional) Models that support retrieval, will default to latest known OpenAI models that support the feature
    # retrievalModels: ["gpt-4-turbo-preview"]
    # (optional) Assistant Capabilities available to all users. Omit the ones you wish to exclude. Defaults to list below.
    # capabilities: ["code_interpreter", "retrieval", "actions", "tools", "image_vision"]
```
> 이 설정은 어시스턴트용 빌더 인터페이스를 활성화하고, 엔드포인트를 지원되는 어시스턴트 ID 두 개로 제한합니다. 주석 처리된 `azureAssistants` 블록은 폴링 간격을 500ms로, 실행 제한 시간을 10초로 설정하는 방법을 보여 줍니다.

## disableBuilder

**키:**
<OptionTable
  options={[
    ['disableBuilder', 'Boolean', '어시스턴트용 빌더 인터페이스의 표시 여부와 사용을 제어합니다.', 'When set to `true`, disables the builder interface for the assistant, limiting direct manual interaction.'],
  ]}
/>

**기본값:** `false`

**예시:**
```yaml filename="endpoints / assistants / disableBuilder"
disableBuilder: false
```

## pollIntervalMs

**키:**
<OptionTable
  options={[
    ['pollIntervalMs', 'Integer', '어시스턴트 실행 상태의 업데이트나 변경 사항을 확인하기 위한 폴링 간격을 밀리초 단위로 지정합니다.', 'Specifies the polling interval in milliseconds for checking assistant run updates.'],
  ]}
/>

**기본값:** `2000`

**예시:**
```yaml filename="endpoints / assistants / pollIntervalMs"
pollIntervalMs: 2500
```
**참고:** 이 값은 해당 실행을 처리하는 엔드포인트의 구성에서 읽어오므로, `assistants`와 `azureAssistants` 모두에 적용됩니다. 속도 제한(rate limiting) 오류를 피하려면 Azure Assistants에는 더 높은 값을 권장합니다.

## timeoutMs

**키:**
<OptionTable
  options={[
    ['timeoutMs', 'Integer', '어시스턴트가 실행될 수 있는 최대 시간을 밀리초 단위로 정의하며, 이 시간이 지나면 요청이 취소됩니다.', 'Sets a timeout in milliseconds for assistant runs. Helps manage system load by limiting total run operation time.'],
  ]}
/>

**기본값:** `180000`

**예시:**
```yaml filename="endpoints / assistants / timeoutMs"
timeoutMs: 10000
```
**참고:** 기본값은 3분(180,000ms)입니다. 실행 작업 시간은 50초에서 2분 사이일 수 있지만, 이를 초과할 수도 있습니다. `timeoutMs` 값을 초과하면 실행이 취소됩니다.
