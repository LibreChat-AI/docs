## Example

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## socialLogins

**Key:**
<OptionTable
  options={[
    ['socialLogins', 'Array of Strings', 'Defines the available social login providers and their display order.', 'The order of the providers in the list determines their appearance order on the login/registration page. This configuration allows for a tailored authentication experience, emphasizing the most relevant or preferred social login options for your user base.'],
  ]}
/>


**Example:**
```yaml filename="registration / socialLogins"
socialLogins: ["google", "facebook", "github", "discord", "openid"]
```

## allowedDomains

**Key:**
<OptionTable
  options={[
    ['allowedDomains', 'Array of Strings', 'A list specifying allowed email domains for registration.', 'Users with email domains not listed will be restricted from registering.'],
  ]}
/>

This key is optional. If you omit it, registration is allowed for any email domain.

**Example:**
```yaml filename="registration / allowedDomains"
allowedDomains:
  - "gmail.com"
  - "protonmail.com"
```

## oauthStateTtlMs

**Key:**
<OptionTable
  options={[
    ['oauthStateTtlMs', 'Integer', 'Milliseconds a started social login may take to reach its callback before the login attempt is rejected.', 'Range: 60000 to 3600000. Default: 600000 (10 minutes).'],
  ]}
/>

**Example:**
```yaml filename="registration / oauthStateTtlMs"

```

## openidDiscovery

Controls how LibreChat retries OpenID Connect discovery against your identity provider. Each field set here takes precedence over the matching environment variable (`OPENID_DISCOVERY_RETRY_ATTEMPTS`, `OPENID_DISCOVERY_RETRY_DELAY_MS`); fields you leave unset fall back to the environment variable, then to the default.

**Keys:**
<OptionTable
  options={[
    ['startupAttempts', 'Integer', 'Discovery attempts made before startup continues. 0 retries only in the background.', 'Range: 0 to 100. Default: 1.'],
    ['retryDelayMs', 'Integer', 'Milliseconds between startup and background discovery attempts.', 'Range: 100 to 3600000. Default: 5000.'],
  ]}
/>

**Example:**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 10000
```
