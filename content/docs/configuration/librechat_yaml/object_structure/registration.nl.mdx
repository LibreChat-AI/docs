## Voorbeeld [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## socialLogins

**Sleutel:**
<OptionTable
  options={[
    ['socialLogins', 'Array of Strings', 'Definieert de beschikbare social login-providers en hun weergavevolgorde.', 'The order of the providers in the list determines their appearance order on the login/registration page.   ]}
/>


**Voorbeeld:**
```yaml filename="registration / socialLogins"
socialLogins: ["google", "facebook", "github", "discord", "openid"]
```

## allowedDomains

**Sleutel:**
<OptionTable
  options={[
    ['allowedDomains', 'Array of Strings', 'Een lijst met toegestane e-maildomeinen voor registratie.', 'Users with email domains not listed will be restricted from registering.'],
  ]}
/>

Deze sleutel is optioneel. Als u deze weglaat, is registratie toegestaan voor elk e-maildomein.

**Voorbeeld:**
```yaml filename="registration / allowedDomains"
allowedDomains:
  - "gmail.com"
  - "protonmail.com"
```

## openidDiscovery

Bepaalt hoe LibreChat opnieuw probeert OpenID Connect-detectie uit te voeren bij uw identity provider. Elk veld dat hier is ingesteld, heeft voorrang op de bijbehorende omgevingsvariabele (`OPENID_DISCOVERY_RETRY_ATTEMPTS`, `OPENID_DISCOVERY_RETRY_DELAY_MS`); velden die u niet instelt, vallen terug op de omgevingsvariabele en vervolgens op de standaardwaarde.

**Sleutels:**
<OptionTable
  options={[
    ['startupAttempts', 'Integer', 'Discovery-pogingen worden gedaan voordat de opstart doorgaat. 0 nieuwe pogingen alleen op de achtergrond.', 'Range: 0 to 100. Default: 1.'],
    ['retryDelayMs', 'Integer', 'Milliseconden tussen opstart en pogingen tot achtergrondontdekking.', 'Range: 100 to 3600000. Default: 5000.'],
  ]}
/>

**Voorbeeld:**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 10000
```
