title: Struktur Objek Registrasi

---

Blok `registration` mengatur tombol login sosial mana yang ditampilkan dan urutannya, domain email mana yang boleh mendaftar atau masuk, serta beberapa pengaturan waktu untuk login sosial dan OpenID. Mengaktifkan atau menonaktifkan registrasi dan login sosial dilakukan melalui variabel lingkungan; lihat [Authentication](/docs/configuration/authentication).

## Contoh [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## socialLogins

**Kunci:**
<OptionTable
  options={[
    ['socialLogins', 'Array of Strings', 'Menentukan penyedia login sosial yang tersedia dan urutan tampilannya.', 'The order of the providers in the list determines their order on the login and registration pages. Valid values are google, facebook, github, discord, apple, openid, and saml. A provider only shows up if it is also configured with its environment variables. Default: google, facebook, openid, github, discord, saml.'],
  ]}
/>

**Contoh:**
```yaml filename="registration / socialLogins"
socialLogins: ["google", "facebook", "github", "discord", "openid"]
```

## allowedDomains

**Kunci:**
<OptionTable
  options={[
    ['allowedDomains', 'Array of Strings', 'Daftar domain email yang diizinkan untuk mendaftar dan masuk.', 'Users whose email domain is not listed cannot register, and are also turned away when signing in through a social provider, OpenID, SAML, or LDAP, and when requesting a password reset. Domains must match exactly (subdomains are not included) and are compared case-insensitively. When omitted or empty, every domain is allowed.'],
  ]}
/>

**Contoh:**
```yaml filename="registration / allowedDomains"
allowedDomains:
  - "gmail.com"
  - "protonmail.com"
```

## oauthStateTtlMs

**Kunci:**
<OptionTable
  options={[
    ['oauthStateTtlMs', 'Number', 'Berapa lama, dalam milidetik, proses login sosial atau OpenID yang telah dimulai boleh memerlukan waktu untuk mencapai callback-nya.', 'Between 60000 (1 minute) and 3600000 (1 hour). Default: 600000 (10 minutes).'],
  ]}
/>

**Contoh:**
```yaml filename="registration / oauthStateTtlMs"
oauthStateTtlMs: 600000
```

## openidDiscovery

Mengontrol cara LibreChat mencoba ulang pengambilan dokumen discovery dari penyedia OpenID. Setiap field yang tidak diatur akan menggunakan variabel lingkungannya (`OPENID_DISCOVERY_RETRY_ATTEMPTS`, `OPENID_DISCOVERY_RETRY_DELAY_MS`), lalu nilai default.

**Kunci:**
<OptionTable
  options={[
    ['startupAttempts', 'Number', 'Upaya penemuan yang dilakukan sebelum startup berlanjut.', 'Between 0 and 100. 0 skips the startup attempts and only retries in the background. Default: 1.'],
    ['retryDelayMs', 'Number', 'Milidetik di antara percobaan penemuan latar belakang dan startup.', 'Between 100 and 3600000. Default: 5000.'],
  ]}
/>

**Contoh:**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 5000
```
