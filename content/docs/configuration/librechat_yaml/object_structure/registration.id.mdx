## Contoh [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## socialLogins

**Kunci:**
<OptionTable
  options={[
    ['socialLogins', 'Array of Strings', 'Menentukan penyedia login sosial yang tersedia dan urutan tampilannya.', 'The order of the providers in the list determines their appearance order on the login/registration page. Each provider listed must be properly configured within the system to be active and available for users. This configuration allows for a tailored authentication experience, emphasizing the most relevant or preferred social login options for your user base.'],
  ]}
/>


**Contoh:**
```yaml filename="registration / socialLogins"
socialLogins: ["google", "facebook", "github", "discord", "openid"]
```

## allowedDomains

**Kunci:**
<OptionTable
  options={[
    ['allowedDomains', 'Array of Strings', 'Daftar yang menentukan domain email yang diizinkan untuk pendaftaran.', 'Users with email domains not listed will be restricted from registering.'],
  ]}
/>

Kunci ini bersifat opsional. Jika Anda menghilangkannya, pendaftaran diizinkan untuk domain email apa pun.

**Contoh:**
```yaml filename="registration / allowedDomains"
allowedDomains:
  - "gmail.com"
  - "protonmail.com"
```

## oauthStateTtlMs

**Kunci:**
<OptionTable
  options={[
    ['oauthStateTtlMs', 'Integer', 'Milidetik yang boleh digunakan oleh proses login sosial yang sudah dimulai untuk mencapai callback-nya sebelum percobaan login ditolak.', 'Range: 60000 to 3600000. Default: 600000 (10 minutes).'],

## openidDiscovery

Mengontrol cara LibreChat mencoba ulang OpenID Connect discovery ke identity provider Anda. Setiap field yang diatur di sini memiliki prioritas di atas environment variable yang sesuai (`OPENID_DISCOVERY_RETRY_ATTEMPTS`, `OPENID_DISCOVERY_RETRY_DELAY_MS`); field yang tidak Anda atur akan menggunakan environment variable, lalu nilai default.

**Kunci:**
<OptionTable
  options={[
    ['startupAttempts', 'Integer', 'Percobaan penemuan dilakukan sebelum startup dilanjutkan. 0 percobaan ulang hanya di latar belakang.', 'Range: 0 to 100. Default: 1.'],
    ['retryDelayMs', 'Integer', 'Milidetik di antara percobaan penemuan latar belakang dan startup.', 'Range: 100 to 3600000. Default: 5000.'],
  ]}
/>

**Contoh:**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 10000
```
