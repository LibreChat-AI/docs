`models` 配下の各項目は、レコードのリストの一部であり、ブール値またはオブジェクトのいずれかです。

**モデルをオブジェクトとして指定する場合:**

オブジェクトを使用すると、`deploymentName`、`version`、`assistants`フラグなど、モデルの詳細な設定が可能です。このモードは、1つのインスタンスやリソースグループの下で複数のバージョンやデプロイメントを扱う場合など、モデルをより細かく制御するために使用されます。

**例**:
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object}"
models:
  gpt-4-vision-preview:
    deploymentName: "gpt-4-vision-preview"
    version: "2024-02-15-preview"
```

**注記:**
- **Deployment Names** および **Versions** は、正しいモデルが使用されることを保証するために不可欠です。
    - 予期せぬ動作を防ぐため、これらの値が正確であることを再確認してください。

### deploymentName

**キー:**
<OptionTable
  options={[
    ['deploymentName', 'String', 'Azure内でのモデルのデプロイを識別する、モデルのデプロイ名です。', 'This does not have to be the matching OpenAI model name as is convention, but must match the actual name of your deployment on Azure.'],
  ]}
/>

**必須:** いいえ。省略した場合は、グループの `deploymentName` が使用されます。サーバーレス以外のグループでは、モデルまたはグループのいずれかで設定する必要があります。

**例:**
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object} / deploymentName"
deploymentName: "gpt-4-vision-preview"
```

  options={[

**例:**

## assistants

**キー:**
<OptionTable
  options={[
    ['assistants', 'Boolean', 'モデルオブジェクトでスキーマにより受け付けられます。Azure Assistantsのモデルはグループレベルの assistants フラグによって選択されるため、そのフラグはグループに設定してください。', ''],
  ]}
/>

**必須:** いいえ

**例**(効果が適用されるグループに設定します):
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / assistants"
assistants: true
```

**デフォルトグループ設定でモデルを有効にする**

**キー:**

models:
