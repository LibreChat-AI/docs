## Visão geral [#overview]

Apps MCP são interfaces interativas que um servidor MCP retorna junto com o resultado de uma ferramenta. O LibreChat renderiza cada uma delas em um frame isolado (sandbox), servido a partir de uma origem separada, de modo que o conteúdo do App não consegue acessar a página do LibreChat. O objeto `mcpAppSandbox` configura esse sandbox e os limites aplicados aos Apps.

Os MCP Apps são ativados com [`mcpSettings.apps`](/docs/configuration/librechat_yaml/object_structure/mcp_settings#apps). Cada chave em `mcpAppSandbox` é opcional e possui um valor padrão.

## Exemplo [#example]

```yaml filename="mcpAppSandbox"
mcpAppSandbox:
  url: https://mcp-sandbox.example.com/api/mcp/sandbox
  maxActiveViews: 3
  maxPersistedAppBytes: 1048576
  maxAdmissionRequestsPerMinute: 240
  operationLimits:
    maxBytes: 4194304
    timeoutMs: 30000
    maxActive: 16
```

## Hospedando o sandbox [#hosting-the-sandbox]

A página do sandbox é servida pelo próprio LibreChat em `/api/mcp/sandbox`. Atribua a ela uma origem dedicada, como um segundo hostname cujo reverse proxy encaminha para o mesmo servidor do LibreChat, e defina `url` como essa rota na origem dedicada.

A página do sandbox se recusa a ser incorporada, a menos que a origem do LibreChat seja autorizada a emoldurá-la. Defina [`MCP_SANDBOX_FRAME_ANCESTORS`](/docs/configuration/dotenv#mcp-server-configuration) com a origem em que os usuários abrem o LibreChat, por exemplo `MCP_SANDBOX_FRAME_ANCESTORS=https://chat.example.com`. Quando essa variável não está definida, a página é servida com `frame-ancestors 'none'` e os frames dos Apps ficam em branco.
