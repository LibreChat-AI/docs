## Genel Bakış [#overview]

`memory` nesnesi, [Kullanıcı Belleği](/docs/features/memory) özelliğini etkinleştirir ve sınırlarını belirler. Bu bölümün eklenmesi belleği etkinleştirmenin yoludur: kaydedilen girdiler her kullanıcının sohbetlerine eklenir, kullanıcılar bu girdileri Bellekler panelinden yönetebilir ve Bellek aracı (`set_memory` ve `delete_memory`) sohbetlerde ve agent'larda sunulur; yeter ki `memory` yeteneği agents endpoint'i için etkin olsun (varsayılan olarak etkindir).

Otomatik bellek çıkarma, yani ayrı bir bellek ajanının her konuşma alışverişini inceleyip istenmeden bilgileri kaydetmesi, ayrı bir isteğe bağlı özelliktir: `agent.enabled: true` olarak ayarlayın ve ona bir model tanımlayın.

## Örnek [#example]

```yaml filename="memory"
memory:
  disabled: false
  validKeys: ['user_preferences', 'conversation_context', 'personal_info']
  tokenLimit: 2000
  charLimit: 10000
  maxInputTokens: 12000
  personalize: true
  messageWindowSize: 5
  agent:
    enabled: true
    provider: 'openAI'
    model: 'gpt-4'
    instructions: 'You are a helpful assistant that remembers user preferences and context.'
    model_parameters:
      temperature: 0.7
      max_tokens: 1000
```

## agent

Otomatik bellek ajanını yapılandırır. Yalnızca `enabled` değeri `true` olduğunda çalışır; `enabled` olmadan tanımlanan bir `agent` bloğu yok sayılır ve LibreChat başlangıçta bir uyarı günlüğe kaydeder.

Etkinleştirildiğinde, bellek ajanı her sohbet isteğinin başında, ana yanıtla birlikte çalışır. Son `messageWindowSize` mesajı inceler (`maxInputTokens` ile sınırlandırılmış olarak) ve girdileri kendi başına kaydeder veya siler. Ana yanıtın tamamlanmasına kadar ve buna ek olarak en fazla 3 saniye süresi vardır; bu süreden sonra hâlâ çalışıyorsa, o istek için sonucu dikkate alınmaz.

`agent` alanı iki farklı yapılandırma biçimini destekler:

### ID'ye Göre Ajan [#agent-by-id]

Önceden yapılandırılmış bir ajana sahip olduğunuzda, ona kimliği (ID) ile referans verebilirsiniz:

```yaml filename="memory / agent (by ID)"
memory:
  agent:
    enabled: true
    id: 'memory-agent-001'
```

### Özel Ajan Yapılandırması [#custom-agent-configuration]

Daha fazla kontrol için tam bir ajan yapılandırması tanımlayabilirsiniz:

```yaml filename="memory / agent (custom)"
memory:
  agent:
    enabled: true
    provider: 'openAI'
    model: 'gpt-4'
    instructions: 'You are a memory assistant that helps maintain conversation context and user preferences.'
    model_parameters:
      temperature: 0.3
      max_tokens: 1500
      top_p: 0.9
```

## Tam Yapılandırma Örneği [#complete-configuration-example]

Bellekteki her seçeneği kullanan bir örnek:

```yaml filename="librechat.yaml"
version: 1.3.18
cache: true

memory:
  disabled: false
  validKeys:
    - 'user_preferences'
    - 'conversation_context'
    - 'learned_facts'
    - 'personal_information'
  tokenLimit: 3000
  charLimit: 10000
  maxInputTokens: 12000
  personalize: true
  messageWindowSize: 8
  agent:
    enabled: true
    provider: 'openAI'
    model: 'gpt-4'
    instructions: |
      Store memory using only the specified validKeys. For user_preferences: save 
      explicitly stated preferences about communication style, topics of interest, 
      or workflow preferences. For conversation_context: save important facts or 
      ongoing projects mentioned. For learned_facts: save objective information 
      about the user. For personal_information: save only what the user explicitly 
      shares about themselves. Delete outdated or incorrect information promptly.
    model_parameters:
      temperature: 0.2
      max_tokens: 2000
      top_p: 0.8
      frequency_penalty: 0.1
```

## Özel endpoint'leri Kullanma [#using-custom-endpoints]

Bellek özelliği özel endpoint'leri destekler. Özel bir endpoint kullanırken, `provider` alanı özel endpoint'in `name` değeriyle tam olarak eşleşmelidir. Ortam değişkenleri ve kullanıcı yer tutucuları içeren özel başlıklar düzgün bir şekilde çözümlenir.

```yaml filename="librechat.yaml with custom endpoint for memory"

endpoints:
  custom:
    - name: 'Custom Memory Endpoint'
      apiKey: 'dummy'
      baseURL: 'https://api.gateway.ai/v1'
      headers:
        x-gateway-api-key: '${GATEWAY_API_KEY}'
        x-gateway-virtual-key: '${GATEWAY_OPENAI_VIRTUAL_KEY}'
        X-User-Identifier: '{{LIBRECHAT_USER_EMAIL}}'
        X-Application-Identifier: 'LibreChat - Test'
        api-key: '${TEST_CUSTOM_API_KEY}'
      models:
        default:
          - 'gpt-4o-mini'
          - 'gpt-4o'
        fetch: false

memory:
  disabled: false
  tokenLimit: 3000
  maxInputTokens: 12000
  personalize: true
  messageWindowSize: 10
  agent:
    enabled: true
    provider: 'Custom Memory Endpoint'
    model: 'gpt-4o-mini'
```

- Mevcut tüm yer tutucular için [Özel Uç Nokta Başlıkları](/docs/configuration/librechat_yaml/object_structure/custom_endpoint#headers) bölümüne bakın

## Notlar [#notes]

- `personalize` kullanıcıların devre dışı bırakma seçeneğine sahip olup olmadığını denetler, belleğin açık olup olmadığını değil. Belleği kapatmak için `disabled` kullanın.
- `maxInputTokens` sınırlandırır, otomatik bellek ajanına gönderilen sohbet bağlamını, `tokenLimit` ise saklanan belleklerin toplam boyutunu sınırlar.
- Özel `instructions`, varsayılan bellek talimatlarının yerini alır ve esas olarak `validKeys` ile birlikte kullanıldığında faydalıdır.
- Erişim ayrıca bellek izinleri aracılığıyla rol bazında da kontrol edilir (kullanma, oluşturma, okuma, güncelleme, devre dışı bırakma). Bkz. [`interface.memories`](/docs/configuration/librechat_yaml/object_structure/interface#memories), [Yönetici Paneli](/docs/features/admin_panel) veya Bellek panelinin altındaki yönetici ayarları.

## Sorun Giderme [#troubleshooting]

**Bellek hiçbir şey yapmıyor.** `memory` bölümünün mevcut olduğunu ve `disabled` değerinin `true` olmadığını, kullanıcının rolünün belleklerı kullanma iznine sahip olduğunu ve kullanıcının **Kayıtlı belleklere başvur** seçeneğini kapatmadığını kontrol edin. Bellek aracı için, bir tane ayarladıysanız `memory` yeteneği agents endpoint'inin `capabilities` listesinde bulunmalıdır.

**Hiçbir şey otomatik olarak kaydedilmez.** Otomatik çıkarma için `agent.enabled: true` ve geçerli bir `id`, ya da `provider` ve `model` gerekir. Bu ayarlar yapılmadan, girdiler yalnızca kullanıcı modelden bir şeyi hatırlamasını istediğinde (Bellek aracı açıkken) kaydedilir veya kullanıcı tarafından elle eklenir.

**Özel uç noktada bellek ajanı başarısız oluyor.** `provider`, özel uç noktanın `name` değeriyle tam olarak eşleşmelidir. Önce uç noktanın normal sohbetlerde çalıştığını doğrulayın, ardından başlıklarının referans verdiği ortam değişkenlerinin ayarlandığını kontrol edin; başlık yer tutucuları bellek için de sohbetle aynı şekilde çözümlenir.

**Token kullanımı yüksek.** Bellek ajanına gönderilen sohbet miktarını azaltmak için `maxInputTokens` veya `messageWindowSize` değerini düşürün; her istekle eklenen depolanmış belleklerin küçük kalması için `tokenLimit` değerini düşürün ve `validKeys` değerini kısıtlayın.
