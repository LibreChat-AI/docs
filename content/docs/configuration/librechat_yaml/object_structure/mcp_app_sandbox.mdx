## Overview

MCP Apps are interactive interfaces that an MCP server returns alongside a tool result. LibreChat renders each one in a sandboxed frame served from a separate origin, so App content cannot reach the LibreChat page. The `mcpAppSandbox` object configures that sandbox and the limits applied to Apps.

MCP Apps are turned on with [`mcpSettings.apps`](/docs/configuration/librechat_yaml/object_structure/mcp_settings#apps). Every key under `mcpAppSandbox` is optional and has a default.

## Example

```yaml filename="mcpAppSandbox"
mcpAppSandbox:
  url: https://sandbox.example.com/
  maxActiveViews: 3
  maxPersistedAppBytes: 1048576
  maxAdmissionRequestsPerMinute: 240
  operationLimits:
    maxBytes: 4194304
    timeoutMs: 30000
    maxActive: 16
```
