Jedes Element unter `models` ist Teil einer Liste von Datensätzen, entweder ein boolescher Wert oder ein Object:

**Wenn ein Modell als Objekt angegeben wird:**

Ein Objekt ermöglicht die detaillierte Konfiguration des Modells, einschließlich seines `deploymentName`, `version` und/oder des `assistants`-Flags. Dieser Modus dient einer feineren Steuerung der Modelle, insbesondere wenn mehrere Versionen oder Deployments unter einer Instanz oder Ressourcengruppe verwendet werden.

**Beispiel**:
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object}"
models:
  gpt-4-vision-preview:
    deploymentName: "gpt-4-vision-preview"
    version: "2024-02-15-preview"
```

**Hinweise:**
- **Deployment Names** und **Versions** sind entscheidend, um sicherzustellen, dass das korrekte Modell verwendet wird.
    - Überprüfen Sie diese Werte sorgfältig auf ihre Richtigkeit, um unerwartetes Verhalten zu vermeiden.

**Erforderlich:** nein. Wird dies weggelassen, wird der `deploymentName` der Gruppe verwendet. Bei Gruppen ohne Serverless-Bereitstellung muss er entweder am Modell oder an der Gruppe gesetzt werden.
