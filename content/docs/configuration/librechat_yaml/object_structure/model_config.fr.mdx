title: Structure de configuration des modèles
icon: Cpu
---

Chaque élément sous `models` fait partie d'une liste d'enregistrements, soit une valeur booléenne, soit un Objet :

**Lors de la spécification d'un modèle en tant qu'objet :**

Un objet permet une configuration détaillée du modèle, incluant son `deploymentName`, sa `version` et/ou son indicateur `assistants`. Ce mode est utilisé pour un contrôle plus granulaire des modèles, en particulier lorsque vous travaillez avec plusieurs versions ou déploiements sous une même instance ou un même groupe de ressources.

**Exemple** :
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object}"
models:
  gpt-4-vision-preview:
    deploymentName: "gpt-4-vision-preview"
    version: "2024-02-15-preview"
```

**Notes :**
- Les **Deployment Names** et les **Versions** sont essentiels pour garantir que le modèle correct est utilisé.
    - Vérifiez deux fois ces valeurs pour en assurer l'exactitude et éviter tout comportement inattendu.

### deploymentName

**Clé :**
<OptionTable
  options={[
    ['deploymentName', 'String', 'Le nom du déploiement pour le modèle. Identifie le déploiement du modèle au sein d\'Azure.', 'This does not have to be the matching OpenAI model name as is convention, but must match the actual name of your deployment on Azure.'],
  ]}
/>

**Obligatoire :** non. Si ce champ est omis, le `deploymentName` du groupe est utilisé. Pour les groupes non serverless, il doit être défini sur le modèle ou sur le groupe.

**Exemple :**
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object} / deploymentName"
deploymentName: "gpt-4-vision-preview"
```

## version

**Clé :**
<OptionTable
  options={[
    ['version', 'String', 'Spécifie la version du modèle. Définit la version du modèle à utiliser.', ''],
  ]}
/>

**Obligatoire :** non. Lorsqu'il est omis, la `version` du groupe est utilisée. Pour les groupes non serverless, elle doit être définie sur le modèle ou sur le groupe.

**Exemple :**
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object} / version"
version: "2024-02-15-preview"
```

## assistants

**Clé :**
<OptionTable
  options={[
    ['assistants', 'Boolean', 'Accepté sur un objet de modèle par le schéma. Les modèles Azure Assistants sont sélectionnés par l\'indicateur assistants au niveau du groupe, donc définissez-le sur le groupe.', ''],
  ]}
/>

**Obligatoire :** non

**Exemple** (défini sur le groupe, où il prend effet) :
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / assistants"
assistants: true
```
