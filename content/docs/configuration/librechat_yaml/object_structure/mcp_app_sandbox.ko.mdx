## 개요 [#overview]

MCP Apps는 MCP 서버가 도구 결과와 함께 반환하는 대화형 인터페이스입니다. LibreChat은 각 App을 별도의 origin에서 제공되는 샌드박스 프레임에 렌더링하므로, App 콘텐츠는 LibreChat 페이지에 접근할 수 없습니다. `mcpAppSandbox` 객체는 해당 샌드박스와 App에 적용되는 제한을 설정합니다.

MCP Apps는 [`mcpSettings.apps`](/docs/configuration/librechat_yaml/object_structure/mcp_settings#apps)를 통해 활성화합니다. `mcpAppSandbox` 아래의 모든 키는 선택 사항이며 기본값이 있습니다.

## 예시 [#example]

```yaml filename="mcpAppSandbox"
mcpAppSandbox:
  url: https://mcp-sandbox.example.com/api/mcp/sandbox
  maxActiveViews: 3
  maxPersistedAppBytes: 1048576
  maxAdmissionRequestsPerMinute: 240
  operationLimits:
    maxBytes: 4194304
    timeoutMs: 30000
    maxActive: 16
```

## 샌드박스 호스팅 [#hosting-the-sandbox]

LibreChat 자체가 `/api/mcp/sandbox`에서 샌드박스 페이지를 제공합니다. 이 페이지에는 전용 오리진을 부여하세요. 예를 들어 같은 LibreChat 서버로 전달하는 리버스 프록시가 연결된 두 번째 호스트 이름을 사용할 수 있습니다. 그런 다음 전용 오리진에서 `url`을 해당 라우트로 설정하세요.

샌드박스 페이지는 LibreChat 출처(origin)가 프레임으로 포함하도록 허용되지 않으면 임베드되지 않습니다. 사용자가 LibreChat을 여는 출처를 [`MCP_SANDBOX_FRAME_ANCESTORS`](/docs/configuration/dotenv#mcp-server-configuration)로 설정하세요. 예를 들면 `MCP_SANDBOX_FRAME_ANCESTORS=https://chat.example.com`과 같습니다. 이 값이 설정되지 않은 경우 페이지는 `frame-ancestors 'none'`과 함께 제공되며, App 프레임은 빈 화면으로 남습니다.
