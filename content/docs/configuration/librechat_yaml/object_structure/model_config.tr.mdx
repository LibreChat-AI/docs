`models` altındaki her öğe, bir kayıt listesinin parçasıdır; ya bir boolean değeri ya da bir Object'tir:

**Bir modeli nesne olarak belirtirken:**

Bir nesne, modelin `deploymentName`, `version` ve/veya `assistants` bayrağı dahil olmak üzere ayrıntılı yapılandırılmasına olanak tanır. Bu mod, özellikle tek bir örnek veya kaynak grubu altında birden fazla sürüm ya da dağıtımla çalışırken modeller üzerinde daha ayrıntılı kontrol sağlamak için kullanılır.

**Örnek**:
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object}"
models:
  gpt-4-vision-preview:
    deploymentName: "gpt-4-vision-preview"
    version: "2024-02-15-preview"
```

**Notlar:**
- **Deployment Names** ve **Versions**, doğru modelin kullanılmasını sağlamak için kritiktir.
    - Beklenmedik davranışları önlemek için bu değerlerin doğruluğunu tekrar kontrol edin.

### deploymentName

**Anahtar:**

  options={[

**Zorunlu:** hayır. Atlandığında grubun `deploymentName` değeri kullanılır. Sunucusuz olmayan gruplar için bu değerin modelde veya grupta ayarlanmış olması gerekir.

**Örnek:**
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object} / deploymentName"

```
