## Übersicht [#overview]

MCP-Apps sind interaktive Oberflächen, die ein MCP-Server zusammen mit einem Tool-Ergebnis zurückgibt. LibreChat rendert jede davon in einem Sandbox-Frame, der von einem separaten Origin ausgeliefert wird, sodass der Inhalt der Apps die LibreChat-Seite nicht erreichen kann. Das Objekt `mcpAppSandbox` konfiguriert diese Sandbox sowie die Grenzwerte, die für Apps gelten.

MCP Apps werden mit [`mcpSettings.apps`](/docs/configuration/librechat_yaml/object_structure/mcp_settings#apps) aktiviert. Jeder Schlüssel unter `mcpAppSandbox` ist optional und besitzt einen Standardwert.

## Beispiel [#example]

```yaml filename="mcpAppSandbox"
mcpAppSandbox:
  url: https://mcp-sandbox.example.com/api/mcp/sandbox
  maxActiveViews: 3
  maxPersistedAppBytes: 1048576
  maxAdmissionRequestsPerMinute: 240
  operationLimits:
    maxBytes: 4194304
    timeoutMs: 30000
    maxActive: 16
```

## Hosting der Sandbox [#hosting-the-sandbox]

Die Sandbox-Seite wird von LibreChat selbst unter `/api/mcp/sandbox` ausgeliefert. Gib ihr einen eigenen Ursprung, etwa einen zweiten Hostnamen, dessen Reverse-Proxy an denselben LibreChat-Server weiterleitet, und setze `url` auf diese Route am eigenen Ursprung.

Die Sandbox-Seite lässt sich nur einbetten, wenn der LibreChat-Ursprung das Einbetten (Framing) der Seite erlaubt. Setze [`MCP_SANDBOX_FRAME_ANCESTORS`](/docs/configuration/dotenv#mcp-server-configuration) auf den Ursprung, unter dem Benutzer LibreChat öffnen, zum Beispiel `MCP_SANDBOX_FRAME_ANCESTORS=https://chat.example.com`. Ist die Variable nicht gesetzt, wird die Seite mit `frame-ancestors 'none'` ausgeliefert und App-Frames bleiben leer.
