## 개요 [#overview]

`speech` 객체를 사용하면 `librechat.yaml` 구성 파일에서 직접 텍스트 음성 변환(TTS) 및 음성 텍스트 변환(STT) 제공업체를 구성할 수 있습니다. 이를 통해 사용자가 자신의 API 키를 구성할 필요 없이 서버 측 음성 서비스를 활성화할 수 있습니다.

**`speech` 하위 필드:**

- `tts` - Text-to-Speech 공급자 설정
- `stt` - Speech-to-Text 공급자 구성
- `speechTab` - 음성 기능을 위한 기본 UI 설정

**참고:**

- 여러 공급자를 동시에 구성할 수 있습니다.
- 사용자는 사용 가능한 옵션 중에서 선호하는 제공업체를 선택할 수 있습니다.
- config 파일의 API 키는 보안을 위해 환경 변수 참조를 사용해야 합니다.

## 예시 [#example]

```yaml filename="speech"
speech:
  tts:
    allowedAddresses: ["tts.internal:8080"]
    openai:
      apiKey: "${TTS_API_KEY}"
      model: "tts-1"
      voices: ["alloy", "echo", "fable", "onyx", "nova", "shimmer"]
    elevenlabs:
      apiKey: "${ELEVENLABS_API_KEY}"
      model: "eleven_multilingual_v2"
      voices: ["voice-id-1", "voice-id-2"]
  stt:
    allowedAddresses: ["stt.internal:8080"]
    openai:
      apiKey: "${STT_API_KEY}"
      model: "whisper-1"
  speechTab:
    conversationMode: true
    advancedMode: false
    speechToText: true
    textToSpeech: true
```

## SSRF 보호 [#ssrf-protection]

LibreChat은 연결 시점에 운영자가 제공한 STT 및 TTS URL을 보호합니다. 사설, 루프백, 링크 로컬 및 클라우드 메타데이터 대상은 기본적으로 차단되며, 음성 요청에 대한 리디렉션은 비활성화됩니다.

`speech.tts.allowedAddresses` 및 `speech.stt.allowedAddresses`는 엄격한 허용 목록이 아닌 별도의 예외 목록입니다. 해당 섹션이 신뢰할 수 있는 자체 호스팅 서비스에 연결되어야 하는 경우에만 정확한 사설 `host:port`, `private.ip:port` 또는 `[ipv6]:port`를 추가하십시오. URL, 경로, CIDR 범위, 호스트/IP 단독, 또는 공인 IP 리터럴을 사용하지 마십시오. 기본 포트는 정규화되므로 명시적인 포트가 없는 HTTPS URL은 포트 `443`으로 확인됩니다.

면제된 호스트 이름은 해당 포트에서 확인되는 모든 사설 주소를 신뢰합니다. 가능하면 사설 IP 리터럴을 사용하는 것을 권장하며, 사용자가 DNS를 제어할 수 있고 공격자가 재지정할 수 없는 이름만 나열하십시오.

포워드 프록시가 호스트네임 요청을 전달할 때, 프록시는 대상 DNS 및 이그레스(egress)를 수행하므로 프록시 자체의 SSRF 정책을 적용해야 합니다. 리터럴 사설 대상은 정확한 주소와 포트가 예외 처리되지 않는 한, 프록시 처리 이전에 여전히 차단됩니다.

## 전체 예시 [#complete-example]

```yaml filename="librechat.yaml"
version: 1.3.17
cache: true

speech:
  tts:
    openai:
      apiKey: "${TTS_API_KEY}"
      model: "tts-1-hd"
      voices: ["alloy", "echo", "fable", "onyx", "nova", "shimmer"]
    elevenlabs:
      apiKey: "${ELEVENLABS_API_KEY}"
      model: "eleven_multilingual_v2"
      voices: ["21m00Tcm4TlvDq8ikWAM", "AZnzlk1XvdvUeBnXmlld"]
      voice_settings:
        stability: 0.5
        similarity_boost: 0.75
  stt:
    openai:
      apiKey: "${STT_API_KEY}"
      model: "whisper-1"
  speechTab:
    conversationMode: false
    advancedMode: false
    speechToText: true
    textToSpeech:
      engineTTS: "external"
      voice: "nova"
      automaticPlayback: false
```

## 참고 사항 [#notes]

- 구성 파일의 API 키에는 항상 환경 변수 참조(예: `${API_KEY}`)를 사용하세요.
- 여러 TTS 공급자를 구성할 수 있으며, 사용자는 UI에서 선호하는 옵션을 선택할 수 있습니다.
- `speechTab` 설정은 사용자가 개인 설정에서 재정의할 수 있는 기본값을 정의합니다.
- `browser`는 브라우저 내장 음성 지원을 사용하며, `external`은 `speech.stt` 또는 `speech.tts` 아래에 구성된 서버 측 제공업체를 사용합니다.
- 기존의 `openai` 및 `azureOpenAI` STT 기본값과 `openai`, `azureOpenAI`, `elevenlabs`, `localai` TTS 기본값은 `external`로 마이그레이션되며, 사용할 수 없는 외부 엔진은 `browser`로 대체됩니다.
- 자세한 기능 문서는 [Speech to Text & Text to Speech](/docs/configuration/stt_tts)를 참조하세요.
