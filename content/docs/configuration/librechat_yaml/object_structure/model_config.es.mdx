Cada elemento bajo `models` es parte de una lista de registros, ya sea un valor booleano o un Object:

**Al especificar un modelo como un objeto:**

Un objeto permite una configuración detallada del modelo, incluyendo su `deploymentName`, `version` y/o la marca `assistants`. Este modo se utiliza para un control más granular de los modelos, especialmente cuando se trabaja con múltiples versiones o despliegues bajo una misma instancia o grupo de recursos.

**Ejemplo**:
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object}"
models:
  gpt-4-vision-preview:
    deploymentName: "gpt-4-vision-preview"
    version: "2024-02-15-preview"
```

**Notas:**
- Los **Deployment Names** y **Versions** son fundamentales para garantizar que se utilice el modelo correcto.
    - Verifica dos veces estos valores para asegurar su precisión y evitar comportamientos inesperados.

### deploymentName

**Clave:**
<OptionTable
  options={[
    ['deploymentName', 'String', 'El nombre del despliegue para el modelo. Identifica el despliegue del modelo dentro de Azure.', 'This does not have to be the matching OpenAI model name as is convention, but must match the actual name of your deployment on Azure.'],
  ]}
/>

**Obligatorio:** no. Si se omite, se utiliza el `deploymentName` del grupo. Para grupos que no son serverless, debe establecerse en el modelo o en el grupo.

**Ejemplo:**
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object} / deploymentName"
deploymentName: "gpt-4-vision-preview"
```

## version

**Clave:**
<OptionTable
  options={[
    ['version', 'String', 'Especifica la versión del modelo. Define la versión del modelo que se utilizará.', ''],
  ]}
/>

**Obligatorio:** no. Si se omite, se utiliza el `version` del grupo. Para grupos no serverless, debe establecerse en el modelo o en el grupo.

**Ejemplo:**
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object} / version"
version: "2024-02-15-preview"
```

## assistants

**Clave:**
<OptionTable

**Ejemplo** (configurado en el grupo, donde surte efecto):
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / assistants"

```
