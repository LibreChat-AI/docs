Setiap item di bawah `models` merupakan bagian dari daftar rekaman, baik berupa nilai boolean atau Objek:

**Saat menentukan model sebagai objek:**

Objek memungkinkan konfigurasi model yang terperinci, termasuk `deploymentName`, `version`, dan/atau flag `assistants`. Mode ini digunakan untuk kontrol yang lebih granular terhadap model, terutama saat bekerja dengan beberapa versi atau deployment di bawah satu instance atau grup sumber daya.

**Contoh**:
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object}"
models:
  gpt-4-vision-preview:
    deploymentName: "gpt-4-vision-preview"
    version: "2024-02-15-preview"
```

**Catatan:**
- **Deployment Names** dan **Versions** sangat penting untuk memastikan bahwa model yang tepat digunakan.
    - Periksa kembali nilai-nilai ini untuk memastikan keakuratannya guna mencegah perilaku yang tidak diinginkan.

### deploymentName

**Kunci:**
<OptionTable
  options={[
    ['deploymentName', 'String', 'Nama deployment untuk model tersebut. Mengidentifikasi deployment model di dalam Azure.', 'This does not have to be the matching OpenAI model name as is convention, but must match the actual name of your deployment on Azure.'],
  ]}
/>

**Wajib:** tidak. Jika dihilangkan, `deploymentName` dari grup akan digunakan. Untuk grup non-serverless, nilai ini harus diatur pada model atau pada grup.

**Contoh:**
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object} / deploymentName"
deploymentName: "gpt-4-vision-preview"
```

## version

**Kunci:**
<OptionTable
  options={[
    ['version', 'String', 'Menentukan versi model. Menentukan versi model yang akan digunakan.', ''],
  ]}
/>

**Wajib:** tidak. Jika dihilangkan, `version` grup akan digunakan. Untuk grup non-serverless, nilai ini harus diatur pada model atau pada grup.

**Contoh:**
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object} / version"

```

## assistants

**Kunci:**
<OptionTable

**Contoh** (diatur pada grup, tempat ini berlaku):
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / assistants"

```

**Mengaktifkan Model dengan Konfigurasi Grup Default**

**Kunci:**
