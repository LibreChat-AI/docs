Elk item onder `models` maakt deel uit van een lijst met records, hetzij een booleaanse waarde of een Object:

**Bij het specificeren van een model als een object:**

Een object maakt gedetailleerde configuratie van het model mogelijk, inclusief de `deploymentName`, `version` en/of de `assistants`-vlag. Deze modus wordt gebruikt voor preciezere controle over de modellen, vooral bij het werken met meerdere versies of deployments binnen één instantie of resourcegroep.

**Voorbeeld**:
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object}"
models:
  gpt-4-vision-preview:
    deploymentName: "gpt-4-vision-preview"
    version: "2024-02-15-preview"
```

**Opmerkingen:**
- **Deployment Names** en **Versions** zijn cruciaal om ervoor te zorgen dat het juiste model wordt gebruikt.
    - Controleer deze waarden dubbel op nauwkeurigheid om onverwacht gedrag te voorkomen.

### deploymentName

**Sleutel:**
<OptionTable
  options={[
    ['deploymentName', 'String', 'De naam van de deployment voor het model. Identificeert de deployment van het model binnen Azure.', 'This does not have to be the matching OpenAI model name as is convention, but must match the actual name of your deployment on Azure.'],
  ]}
/>

**Vereist:** nee. Indien weggelaten, wordt de `deploymentName` van de groep gebruikt. Voor niet-serverless groepen moet deze ingesteld zijn op het model of op de groep.

**Voorbeeld:**
```yaml filename="endpoints / azureOpenAI / groups / {group_item} / models / {model_item=Object} / deploymentName"
deploymentName: "gpt-4-vision-preview"
```

## assistants

**Sleutel:**

