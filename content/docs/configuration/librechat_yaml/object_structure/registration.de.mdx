---
title: Struktur des Registrierungsobjekts
icon: UserPlus
---

Der Block `registration` steuert, welche Schaltflächen für die Anmeldung über soziale Netzwerke angezeigt werden und in welcher Reihenfolge, welche E-Mail-Domains sich registrieren oder anmelden dürfen sowie einige Zeiteinstellungen für Anmeldungen über soziale Netzwerke und OpenID. Die Aktivierung oder Deaktivierung von Registrierung und Anmeldung über soziale Netzwerke erfolgt über Umgebungsvariablen; siehe [Authentifizierung](/docs/configuration/authentication).

## Beispiel [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## socialLogins

**Schlüssel:**
<OptionTable
  options={[
    ['socialLogins', 'Array of Strings', 'Definiert die verfügbaren Social-Login-Anbieter und deren Anzeigereihenfolge.', 'The order of the providers in the list determines their order on the login and registration pages. Valid values are google, facebook, github, discord, apple, openid, and saml. A provider only shows up if it is also configured with its environment variables. Default: google, facebook, openid, github, discord, saml.'],
  ]}
/>

**Beispiel:**
```yaml filename="registration / socialLogins"
socialLogins: ["google", "facebook", "github", "discord", "openid"]
```

## allowedDomains

**Schlüssel:**
<OptionTable
  options={[
    ['allowedDomains', 'Array of Strings', 'Eine Liste von E-Mail-Domains, die sich registrieren und anmelden dürfen.', 'Users whose email domain is not listed cannot register, and are also turned away when signing in through a social provider, OpenID, SAML, or LDAP, and when requesting a password reset. Domains must match exactly (subdomains are not included) and are compared case-insensitively. When omitted or empty, every domain is allowed.'],
  ]}
/>

**Beispiel:**
```yaml filename="registration / allowedDomains"
allowedDomains:
  - "gmail.com"
  - "protonmail.com"
```

## oauthStateTtlMs

**Schlüssel:**
<OptionTable
  options={[
    ['oauthStateTtlMs', 'Number', 'Wie lange, in Millisekunden, ein begonnener Social- oder OpenID-Login maximal dauern darf, bis er seinen Callback erreicht.', 'Between 60000 (1 minute) and 3600000 (1 hour). Default: 600000 (10 minutes).'],
  ]}
/>

**Beispiel:**
```yaml filename="registration / oauthStateTtlMs"
oauthStateTtlMs: 600000
```

## openidDiscovery

Steuert, wie LibreChat erneut versucht, das Discovery-Dokument des OpenID-Providers abzurufen. Jedes nicht gesetzte Feld greift zuerst auf seine Umgebungsvariable zurück (`OPENID_DISCOVERY_RETRY_ATTEMPTS`, `OPENID_DISCOVERY_RETRY_DELAY_MS`) und danach auf den Standardwert.

**Schlüssel:**
<OptionTable
  options={[
    ['startupAttempts', 'Number', 'Erkennungsversuche, die vor dem Fortsetzen des Starts unternommen wurden.', 'Between 0 and 100. 0 skips the startup attempts and only retries in the background. Default: 1.'],
    ['retryDelayMs', 'Number', 'Millisekunden zwischen dem Start und den Hintergrund-Erkennungsversuchen.', 'Between 100 and 3600000. Default: 5000.'],
  ]}
/>

**Beispiel:**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 5000
```
