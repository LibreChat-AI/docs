## Beispiel [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## socialLogins

**Schlüssel:**
<OptionTable
  options={[
    ['socialLogins', 'Array of Strings', 'Definiert die verfügbaren Social-Login-Anbieter und deren Anzeigereihenfolge.', 'The order of the providers in the list determines their appearance order on the login/registration page. Each provider listed must be properly configured within the system to be active and available for users. This configuration allows for a tailored authentication experience, emphasizing the most relevant or preferred social login options for your user base.'],
  ]}
/>


**Beispiel:**
```yaml filename="registration / socialLogins"
socialLogins: ["google", "facebook", "github", "discord", "openid"]
```

## allowedDomains

**Schlüssel:**
<OptionTable
  options={[
    ['allowedDomains', 'Array of Strings', 'Eine Liste zur Festlegung der erlaubten E-Mail-Domains für die Registrierung.', 'Users with email domains not listed will be restricted from registering.'],
  ]}
/>

Dieser Schlüssel ist optional. Wenn Sie ihn weglassen, ist die Registrierung für jede E-Mail-Domain erlaubt.

**Beispiel:**
```yaml filename="registration / allowedDomains"
allowedDomains:
  - "gmail.com"
  - "protonmail.com"
```

## oauthStateTtlMs

**Schlüssel:**
<OptionTable
  options={[
    ['oauthStateTtlMs', 'Integer', 'Millisekunden, die ein gestarteter Social-Login-Vorgang benötigen darf, um seinen Callback zu erreichen, bevor der Anmeldeversuch abgelehnt wird.', 'Range: 60000 to 3600000. Default: 600000 (10 minutes).'],
  ]}
/>

**Beispiel:**
```yaml filename="registration / oauthStateTtlMs"
oauthStateTtlMs: 900000
```

## openidDiscovery

Steuert, wie LibreChat die OpenID-Connect-Erkennung (Discovery) bei Ihrem Identity Provider wiederholt. Jedes hier gesetzte Feld hat Vorrang vor der entsprechenden Umgebungsvariablen (`OPENID_DISCOVERY_RETRY_ATTEMPTS`, `OPENID_DISCOVERY_RETRY_DELAY_MS`); nicht gesetzte Felder greifen zuerst auf die Umgebungsvariable und dann auf den Standardwert zurück.

**Schlüssel:**
<OptionTable
  options={[
    ['startupAttempts', 'Integer', 'Erkennungsversuche vor dem Fortsetzen des Starts. 0 Wiederholungen nur im Hintergrund.', 'Range: 0 to 100. Default: 1.'],
    ['retryDelayMs', 'Integer', 'Millisekunden zwischen dem Start und den Hintergrund-Erkennungsversuchen.', 'Range: 100 to 3600000. Default: 5000.'],
  ]}
/>

**Beispiel:**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 10000
```
