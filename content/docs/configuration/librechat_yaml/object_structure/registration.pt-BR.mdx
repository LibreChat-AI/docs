## Exemplo [#example]

```yaml filename="Registration Object Structure"
# Example Registration Object Structure
registration:
  socialLogins: ["google", "facebook", "github", "discord", "openid"]
  allowedDomains:
    - "gmail.com"
    - "protonmail.com"
  oauthStateTtlMs: 600000
  openidDiscovery:
    startupAttempts: 1
    retryDelayMs: 5000
```

## socialLogins

**Chave:**
<OptionTable
  options={[
    ['socialLogins', 'Array of Strings', 'Define os provedores de login social disponíveis e sua ordem de exibição.', 'The order of the providers in the list determines their appearance order on the login/registration page. Each provider listed must be properly configured within the system to be active and available for users. This configuration allows for a tailored authentication experience, emphasizing the most relevant or preferred social login options for your user base.'],
  ]}
/>


**Exemplo:**
```yaml filename="registration / socialLogins"
socialLogins: ["google", "facebook", "github", "discord", "openid"]
```

## allowedDomains

**Chave:**
<OptionTable
  options={[
    ['allowedDomains', 'Array of Strings', 'Uma lista que especifica os domínios de e-mail permitidos para registro.', 'Users with email domains not listed will be restricted from registering.'],
  ]}
/>

Esta chave é opcional. Se você omiti-la, o registro será permitido para qualquer domínio de e-mail.

**Exemplo:**
```yaml filename="registration / allowedDomains"
allowedDomains:
  - "gmail.com"
  - "protonmail.com"
```

## oauthStateTtlMs

<OptionTable
  options={[

## openidDiscovery

Controla como o LibreChat tenta novamente a descoberta do OpenID Connect no seu provedor de identidade. Cada campo definido aqui tem precedência sobre a variável de ambiente correspondente (`OPENID_DISCOVERY_RETRY_ATTEMPTS`, `OPENID_DISCOVERY_RETRY_DELAY_MS`); os campos que você deixar sem definição usam a variável de ambiente e, em seguida, o valor padrão.

**Chaves:**
<OptionTable
  options={[
    ['startupAttempts', 'Integer', 'Tentativas de descoberta feitas antes da inicialização continuar. 0 tentativas apenas em segundo plano.', 'Range: 0 to 100. Default: 1.'],
    ['retryDelayMs', 'Integer', 'Milissegundos entre a inicialização e as tentativas de descoberta em segundo plano.', 'Range: 100 to 3600000. Default: 5000.'],
  ]}
/>

**Exemplo:**
```yaml filename="registration / openidDiscovery"
openidDiscovery:
  startupAttempts: 3
  retryDelayMs: 10000
```
