Esta página descreve as configurações compartilhadas para todos os endpoints. As configurações destacadas aqui estão disponíveis para todas as configurações sob o campo ["Endpoints"](/docs/configuration/librechat_yaml/object_structure/config#endpoints), a menos que indicado o contrário.

## Exemplo de Configuração [#example-configuration]

```yaml filename="Shared Endpoint Settings"
endpoints:
  # Individual endpoint configurations
  openAI:
    streamRate: 25
    titleModel: 'gpt-4o-mini'
    titleMethod: 'completion'
    titleTiming: 'immediate'
    titlePrompt: "Create a concise title for this conversation:\n\n{convo}"
    headers:
      X-Gateway-Metadata: '{"user_email":"{{LIBRECHAT_USER_EMAIL}}"}'

  azureOpenAI:
    streamRate: 35
    titleModel: 'grok-3'
    titleMethod: 'structured'
    titlePrompt: |
      Analyze this conversation and provide:
      1. A concise title in the detected language (5 words or less, no punctuation or quotation)
      2. Always provide a relevant emoji at the start of the title

      {convo}
    titleConvo: true

  anthropic:
    streamRate: 25
    titleModel: 'claude-3-5-haiku-20241022'
    titleMethod: 'completion'
    headers:
      X-Conversation-Id: '{{LIBRECHAT_BODY_CONVERSATIONID}}'

  bedrock:
    streamRate: 25
    titleModel: 'us.amazon.nova-lite-v1:0'
    titleEndpoint: 'anthropic'

  google:
    streamRate: 25
    titleModel: 'gemini-2.0-flash-lite'
    titlePromptTemplate: "Human: {input}\nAssistant: {output}"
    headers:
      X-Gateway-Metadata: '{"user_id":"{{LIBRECHAT_USER_ID}}"}'

  assistants:
    streamRate: 30

  azureAssistants:
    streamRate: 30

  agents:
    activityLabel: true
    activityEndpoint: 'openAI'
    activityModel: 'gpt-4.1-nano'
    activityMaxPerRun: 20
    activityCharLimit: 600
    activityPhaseLabel: true
    activityPhaseMaxPerRun: 5

  # Global configuration using 'all' - this applies shared settings across endpoints.
  # Most defined values override endpoint defaults; headers are merged and endpoint values win on collisions.
  all:
    headers:
      X-App: 'librechat'
    titleConvo: true
    titleModel: 'gpt-4.1-nano'
    titleTiming: 'immediate'
    titlePrompt: |
      Analyze this conversation and provide:
      1. The detected language of the conversation
      2. A concise title in the detected language (5 words or less, no punctuation or quotation)
      3. Always provide a relevant emoji at the start of the title
      {convo}
```

> **Importante:** Ao usar a configuração `all`, a maioria das propriedades compartilhadas que você define se aplica a todos os endpoints. No exemplo acima, a configuração `all` aplicaria `titleConvo`, `titleModel` e `titlePrompt` a todos os endpoints, enquanto as configurações individuais de `streamRate` seriam preservadas, já que não estão definidas em `all`. Os `headers` são mesclados separadamente: os valores de `endpoints.all.headers` aplicam-se globalmente, e os headers de nível de endpoint prevalecem em caso de colisão de chaves. As configurações de atividade são resolvidas campo a campo na mesma ordem, portanto, uma configuração `all` não relacionada não oculta a configuração de atividade de um endpoint.

## streamRate

**Chave:**

<OptionTable
  options={[
    [
      'streamRate',
      'Number',
      'A taxa na qual os dados são transmitidos a partir do endpoint. Útil para controlar o ritmo da transmissão de dados.',
      'streamRate: 25',
    ],
  ]}
/>

**Padrão:** Dependente do provedor. OpenAI, endpoints personalizados, Anthropic, Google, Bedrock e streams baseados em Agents SDK usam suavização adaptativa com um alvo de 25 ms. Manipuladores de Assistants legados e Ollama mantêm seu comportamento por chunk do provedor, com um padrão de 1 ms.

O suavizamento adaptativo emite o primeiro token de texto sem atraso, aumenta o tamanho do bloco (chunk) quando um fluxo fica lento e preserva a ordem de chamadas de ferramenta e metadados. Defina `streamRate` como um valor de milissegundos não negativo; `streamRate: 0` desativa o suavizamento adaptativo nos provedores baseados em SDK listados acima.

Um valor específico de endpoint é preservado quando `endpoints.all` existe sem `streamRate`. Definir `endpoints.all.streamRate` sobrescreve os valores do endpoint, incluindo um `0` explícito.

## titleTiming

**Chave:**

<OptionTable
  options={[
    [
      'titleTiming',

      'titleTiming: "immediate"',
    ],
  ]}
/>

**Padrão:** `"immediate"`

**Valores Disponíveis:**

- **`"immediate"`** - Gera o título assim que a solicitação é iniciada, em paralelo com a resposta do modelo, usando a primeira mensagem do usuário. Os títulos geralmente aparecem em um ou dois segundos.
- **`"final"`** - Adia a geração do título até que a resposta completa seja concluída. Isso preserva o comportamento legado.

**Exemplo:**

```yaml filename="titleTiming"
endpoints:
  all:
    titleTiming: 'immediate'
```

## Grupos de Atividade de Agentes [#agent-activity-groups]

Grupos de atividade tornam as execuções longas de Agentes mais fáceis de analisar, recolhendo cada bloco contíguo de raciocínio e chamadas de ferramenta sob um cabeçalho de uma linha gerado automaticamente. A geração do cabeçalho é executada fora do caminho principal de resposta do modelo, mas ainda é uma chamada de modelo e seu uso é registrado e cobrado.

Com os rótulos de fase pai ativados, o texto de progresso curto permanece dentro da fase ativa. Uma fase é fechada antes de um texto de resposta substancial, para que o resultado permaneça fora do resumo recolhido, e um bloco posterior de raciocínio ou chamadas de ferramenta pode iniciar outra fase na mesma execução. O LibreChat também rebaseia os limites de fase salvos quando conteúdo malformado ou omitido é compactado, preservando seu alinhamento após a recarga.

```yaml filename="endpoints / agents / activity groups"
endpoints:
  agents:
    activityLabel: true
    activityEndpoint: 'openAI'
    activityModel: 'gpt-4.1-nano'
    activityMaxPerRun: 20
    activityCharLimit: 600
    activityPhaseLabel: true
    activityPhaseMaxPerRun: 5
```

Você também pode definir esses campos em `endpoints.all` ou em um provedor de suporte/endpoint personalizado. Os valores são resolvidos de forma independente, com o primeiro valor definido prevalecendo nesta ordem: `endpoints.all`, o endpoint público `agents`, e então o provedor de suporte ou endpoint personalizado. Se `activityEndpoint` for desconhecido, o LibreChat registra um aviso e usa o provedor do Agent em seu lugar.

Os resumos de fase pai são independentes dos rótulos de atividade filho: `activityPhaseLabel` pode ser ativado com ou sem `activityLabel`. O LibreChat gasta uma chamada de modelo de resumo de fase apenas para uma fase que contenha pelo menos duas atividades lógicas. `activityCharLimit` também limita as evidências usadas para os resumos de fase. A seleção do modelo de fase é resolvida através de `activityPhaseModel`, `activityModel`, o `titleModel` do endpoint de origem e, em seguida, o modelo de execução atual; a seleção do endpoint de fase é resolvida através de `activityPhaseEndpoint`, `activityEndpoint` e, em seguida, o provedor do Agent. Um endpoint de fase configurado desconhecido registra um aviso e retorna ao provedor do Agent.

## Rótulos de Raciocínio em Tempo Real [#live-reasoning-labels]

Os rótulos de raciocínio em tempo real (live reasoning) substituem o cabeçalho genérico **Thinking** ou **Thoughts** por uma orientação curta e dinâmica para o raciocínio de nível superior do Agent, quando suficientemente longo. O LibreChat atualiza o cabeçalho de raciocínio existente no local e não adiciona ou desloca partes do conteúdo da mensagem. O raciocínio de subagentes aninhados não é rotulado por esta configuração.

Você pode definir esses campos em `endpoints.all`, no endpoint público `agents` ou em um provedor de suporte/endpoint personalizado. Cada campo é resolvido de forma independente, com o primeiro valor definido prevalecendo nesta ordem: `endpoints.all`, `endpoints.agents` e, em seguida, o provedor de suporte ou endpoint personalizado.

A seleção de modelo é resolvida através de `reasoningLabelModel`, `activityModel`, o `titleModel` do endpoint de origem e, em seguida, o modelo de execução do Agent atual. A seleção de endpoint é resolvida através de `reasoningLabelEndpoint`, `activityEndpoint` e, em seguida, o provedor do Agent. Um endpoint de rótulo desconhecido registra um aviso e retorna ao provedor do Agent.

Cada chamada envia no máximo 4.000 caracteres de raciocínio visível para o endpoint de rótulo resolvido, que pode ser um provedor diferente do Agente. Os rótulos são limitados a 120 caracteres. As revisões em streaming observam os limites de caracteres e de intervalo; ao concluir, um final significativo de pelo menos 120 novos caracteres pode acionar uma reescrita final imediatamente. Cada tentativa de revisão conta para `reasoningLabelMaxPerRun` e é uma chamada de modelo separada com seu próprio uso de tokens e custo.

Quando o rastreamento do Langfuse está ativado, o snapshot de raciocínio limitado é registrado como a entrada da geração de rótulos, a menos que a política de redação ativa suprima a chamada de rótulo. Revise o endpoint de destino e a política de rastreamento antes de ativar este recurso para conteúdo de raciocínio sensível.

## headers

**Chave:**

<OptionTable
  options={[
    [
      'headers',
      'Object/Dictionary',
      'Cabeçalhos de solicitação personalizados encaminhados para endpoints de provedores integrados suportados.',
      'Useful for AI gateways and reverse proxies that consume metadata headers while LibreChat keeps provider-native request formatting.',
    ],
  ]}
/>

**Endpoints suportados:** `openAI`, `anthropic`, `google` e `all`.

**Exemplo:**

```yaml filename="endpoints / headers"
endpoints:
  all:
    headers:
      X-App: 'librechat'
  anthropic:
    headers:
      X-Conversation-Id: '{{LIBRECHAT_BODY_CONVERSATIONID}}'
```

**Notas:**

- Os valores suportam `${ENV_VAR}`, `{{LIBRECHAT_USER_*}}` e placeholders do corpo da requisição, como `{{LIBRECHAT_BODY_CONVERSATIONID}}`.
- As solicitações de modelo de agente também oferecem suporte a `{{LIBRECHAT_USER_TENANT_ID}}` e `{{LIBRECHAT_USER_TENANTID}}`. Ambos são resolvidos a partir do tenant com escopo de solicitação autoritativo para Agentes raiz, Subagentes, rótulos de atividade, memória e chamadas de sumarização, e tornam-se uma string vazia quando a execução não possui um tenant. Este valor de tenant é intencionalmente limitado aos cabeçalhos do modelo e não é adicionado aos consumidores de placeholders de usuário em geral.
- Na etapa final de resolução de saída, os placeholders reconhecidos de usuário, corpo da requisição (request-body) e OpenID sem um valor tornam-se strings vazias em vez de serem encaminhados como texto de modelo. Nomes de placeholders desconhecidos permanecem inalterados para que erros de digitação na configuração fiquem visíveis.
- Os cabeçalhos em nível de endpoint substituem `endpoints.all.headers` em caso de colisão de chaves.
- A autenticação gerenciada pelo provedor e os cabeçalhos beta/protocolo obrigatórios permanecem como autoridade. Os valores beta da Anthropic são mesclados para que sinalizadores beta personalizados não sobrescrevam os sinalizadores obrigatórios do provedor.
- Cabeçalhos também são encaminhados para solicitações de lista de modelos de provedores suportados.
- Use cabeçalhos de metadados atrás de um gateway ou proxy reverso que os consuma. APIs de provedores nativos normalmente ignoram cabeçalhos desconhecidos.

---

**Notas:**

- Todas as configurações exibidas nesta página podem ser configuradas individualmente por endpoint ou globalmente usando a chave `all`
- Ao usar a configuração `all`, ela substituirá as configurações correspondentes em TODOS os endpoints individuais.
- A chave `all` não aceita `baseURL`
- O endpoint `azureOpenAI` aceita apenas um subconjunto dessas configurações. Ele não aceita `titleEndpoint`, `headers` ou `maxToolResultChars`. Consulte [Azure OpenAI](/docs/configuration/librechat_yaml/object_structure/azure_openai).
- As configurações não definidas em `all` preservarão seus valores de endpoint individuais
- Para `streamRate`: Valores entre 25-40 são recomendados quando se deseja um suavizamento específico para o endpoint
- Usar uma taxa de stream mais alta é essencial ao servir o aplicativo para muitos usuários em escala

**Exemplo de Comportamento de Substituição (Override):**

```yaml
endpoints:
  openAI:
    streamRate: 25 # This will be preserved
    titleModel: 'gpt-4' # This will be overridden
    titleConvo: false # This will be overridden

  all:
    titleConvo: true
    titleModel: 'gpt-3.5-turbo'
    # streamRate not defined here, so individual values are kept
```
