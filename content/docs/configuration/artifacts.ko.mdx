이 페이지는 [Artifacts](/docs/features/artifacts)의 관리자 측 설정을 다룹니다. 사용자는 Agent Builder에서 에이전트별로 artifacts를 켜며, 여기서 설정하는 값은 해당 옵션의 존재 여부와 미리보기가 로드되는 위치를 결정합니다.

## 아티팩트 활성화 [#enabling-artifacts]

아티팩트는 에이전트 기능입니다. `artifacts`는 기본 [`endpoints.agents.capabilities`](/docs/configuration/librechat_yaml/object_structure/agents#capabilities) 목록에 포함되어 있으므로, 직접 목록을 설정하면서 이를 제외하지 않는 한 사용할 수 있습니다. `capabilities`를 재정의하는 경우, Agent Builder에서 해당 옵션을 유지하려면 `artifacts`를 포함하세요.

에이전트를 구축하지 않고 모델 스펙에 아티팩트를 제공하려면, 스펙에 [`artifacts`](/docs/configuration/librechat_yaml/object_structure/model_specs#artifacts)를 설정하세요. `true`를 사용하면 기본 모드가 적용되며, `default`, `shadcnui`, `custom` 중 하나의 모드 이름을 지정할 수도 있습니다.

## 새 창에서 패널 열기 [#opening-the-panel-in-a-new-window]

패널에는 별도의 브라우저 창으로 이동시키는 **Open in new window** 버튼이 있습니다. 이 기능은 기본적으로 켜져 있습니다. 배포 환경이 임베디드 웹뷰처럼 팝업이 작동하지 않는 곳이라면, [`interface.artifactUndocking: false`](/docs/configuration/librechat_yaml/object_structure/interface#artifactundocking)로 끌 수 있으며, 이 경우에도 도킹된 패널은 계속 작동합니다.

## Content-Security-Policy

LibreChat 자체 CSP는 HTTPS 프레임을 허용하므로, 기본 CodeSandbox 번들러는 별도의 변경 없이 로드됩니다. LibreChat 앞단에 있는 리버스 프록시나 CDN이 더 엄격한 `Content-Security-Policy`를 설정한다면, `frame-src`에 번들러 오리진을 허용하세요. 공개 번들러를 사용한다면 `https://*.codesandbox.io`를, 직접 호스팅하는 경우에는 자체 번들러 URL을 추가합니다. LibreChat의 내장 정책을 확장하기만 하면 된다면 `CSP_FRAME_SRC_EXTRA`를 사용하세요.

React 미리보기는 `cdn.tailwindcss.com`에서 Tailwind도 불러오므로, 이 호스트는 사용자의 브라우저에서 접근 가능해야 합니다.

## Sandpack 번들러 자체 호스팅 [#self-hosting-the-sandpack-bundler]

미리보기는 [Sandpack](https://sandpack.codesandbox.io/)에 의해 렌더링되며, Sandpack은 기본적으로 CodeSandbox의 공개 CDN에서 번들러를 가져옵니다. 이 CDN은 사용 통계 텔레메트리도 전송합니다. 사설 네트워크, 규정 준수 요구 사항이 있거나 외부 서비스에 대한 의존성을 제거하려는 경우에는 [번들러를 직접 호스팅](https://sandpack.codesandbox.io/docs/guides/hosting-the-bundler)하십시오.

[LibreChat-AI/codesandbox-client](https://github.com/LibreChat-AI/codesandbox-client)는 LibreChat을 위해 준비된 포크로, 컨테이너 이미지를 포함하여 텔레메트리 요청을 제거한 버전입니다.

LibreChat는 두 개의 번들러를 사용합니다. `SANDPACK_BUNDLER_URL`은 React 아티팩트를 제공하고, `SANDPACK_STATIC_BUNDLER_URL`은 HTML, SVG, Markdown, 코드, Office 파일 미리보기의 바탕이 되는 정적 템플릿을 제공합니다. 자체 호스팅 시에는 두 변수를 모두 설정하세요. 하나만 설정하면 나머지 아티팩트 유형은 여전히 공용 CDN에서 로드됩니다. 두 변수 모두 [`.env` 참조](/docs/configuration/dotenv#artifacts)에 나와 있습니다. Mermaid 다이어그램은 페이지에서 직접 렌더링되며 두 번들러 중 어느 것도 사용하지 않습니다.

자체 번들러를 운영하면 CORS 설정, 보안 업데이트, 호스팅 리소스를 직접 관리해야 합니다. 이 변수들을 변경한 후에는 LibreChat을 재시작하세요. URL은 시작 구성에서 브라우저로 전송됩니다.
