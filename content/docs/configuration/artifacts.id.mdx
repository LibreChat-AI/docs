Halaman ini membahas sisi admin dari [Artifacts](/docs/features/artifacts). Pengguna mengaktifkan artifacts per agent di Agent Builder; pengaturan di sini menentukan apakah opsi tersebut tersedia dan dari mana pratinjau dimuat.

## Mengaktifkan artifacts [#enabling-artifacts]

Artefak adalah kemampuan agen. `artifacts` termasuk dalam daftar default [`endpoints.agents.capabilities`](/docs/configuration/librechat_yaml/object_structure/agents#capabilities), sehingga tersedia kecuali Anda menetapkan daftar sendiri tanpa menyertakannya. Jika Anda menimpa `capabilities`, sertakan `artifacts` agar opsi tersebut tetap tersedia di Agent Builder.

Untuk memberikan artefak model spec tanpa membangun agen, atur [`artifacts`](/docs/configuration/librechat_yaml/object_structure/model_specs#artifacts) pada spec. Nilai `true` menggunakan mode default; Anda juga dapat memberikan nama mode: `default`, `shadcnui`, atau `custom`.

## Membuka panel di jendela baru [#opening-the-panel-in-a-new-window]

Panel memiliki tombol **Open in new window** yang memindahkannya ke jendela browser terpisah. Fitur ini aktif secara default. Jika deployment Anda berjalan di lingkungan tempat pop-up tidak berfungsi, seperti embedded webview, nonaktifkan dengan [`interface.artifactUndocking: false`](/docs/configuration/librechat_yaml/object_structure/interface#artifactundocking); panel yang terpasang (docked) tetap berfungsi.

## Content-Security-Policy

LibreChat sendiri mengizinkan frame HTTPS, sehingga bundler CodeSandbox bawaan dapat dimuat tanpa perubahan. Jika reverse proxy atau CDN di depan LibreChat menetapkan `Content-Security-Policy` yang lebih ketat, izinkan origin bundler di `frame-src`: `https://*.codesandbox.io` untuk bundler publik, atau URL bundler Anda sendiri jika Anda melakukan self-host. Jika Anda hanya perlu memperluas kebijakan bawaan LibreChat, gunakan `CSP_FRAME_SRC_EXTRA`.

Pratinjau React juga memuat Tailwind dari `cdn.tailwindcss.com`, sehingga host tersebut harus dapat dijangkau dari browser pengguna.

## Self-hosting bundler Sandpack [#self-hosting-the-sandpack-bundler]

Pratinjau dirender oleh [Sandpack](https://sandpack.codesandbox.io/), yang secara default mengambil bundler-nya dari CDN publik CodeSandbox. CDN tersebut juga mengirimkan telemetri penggunaan. Untuk jaringan privat, persyaratan kepatuhan, atau untuk menghapus ketergantungan pada layanan eksternal, [hosting bundler secara mandiri](https://sandpack.codesandbox.io/docs/guides/hosting-the-bundler).

[LibreChat-AI/codesandbox-client](https://github.com/LibreChat-AI/codesandbox-client) adalah fork yang disiapkan untuk LibreChat dengan permintaan telemetri dihapus, termasuk image container.

LibreChat menggunakan dua bundler. `SANDPACK_BUNDLER_URL` melayani artefak React, dan `SANDPACK_STATIC_BUNDLER_URL` melayani template statis di balik pratinjau HTML, SVG, Markdown, kode, dan file Office. Atur keduanya saat Anda melakukan self-host: jika hanya satu yang diatur, jenis artefak lainnya tetap dimuat dari CDN publik. Keduanya tercantum dalam [referensi `.env`](/docs/configuration/dotenv#artifacts). Diagram Mermaid dirender langsung di halaman dan tidak menggunakan salah satu bundler tersebut.

Menjalankan bundler Anda sendiri berarti Anda bertanggung jawab atas pengaturan CORS, pembaruan keamanan, dan sumber daya hosting-nya. Restart LibreChat setelah mengubah variabel ini; URL tersebut dikirim ke browser dalam konfigurasi startup.
