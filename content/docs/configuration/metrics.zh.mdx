## 常规 [#general]

![LibreChat 中的活跃用户](/images/metrics/librechat-metrics-active-users.png)

LibreChat 提供了两个兼容 Prometheus 的指标接口。API 内置的 `/metrics` endpoint 会报告运行行为，例如 Redis 活动和浏览器遥测代理结果。可选的数据库导出器会报告存储在 MongoDB 中的使用数据，包括令牌总数和活跃用户数。

## 内置 API 指标 [#built-in-api-metrics]

LibreChat 通过 API 服务器的 `/metrics` 路径公开 Prometheus 指标。请设置 `METRICS_SECRET` 并使用 `Authorization: Bearer <METRICS_SECRET>` 来抓取该 endpoint。当未设置密钥、缺少请求头或令牌不匹配时，该 endpoint 将返回 `401`。

```yaml filename="prometheus.yml"
scrape_configs:
  - job_name: librechat-api
    scheme: https
    metrics_path: /metrics
    authorization:
      type: Bearer
      credentials: your-metrics-secret
    static_configs:
      - targets: ['librechat.example.com']
```

### 进程、HTTP 与请求指标 [#process-http-and-request-metrics]

该端点还会公开 `prom-client` 提供的默认 Node.js 及进程指标,以及以下指标系列。

| 分组 | 指标 | 标签 |
| --- | --- | --- |
| HTTP | `http_requests_total`, `http_request_duration_seconds` | `method`, `path`, `status` |
| HTTP | `http_requests_in_flight`, `http_request_body_bytes`(来自 `Content-Length`) | `method`, `path` |
| SSE | `sse_streams_total`, `sse_stream_duration_seconds` | `method`, `path`, `status` |
| SSE | `sse_streams_in_flight` | `method`, `path` |
| 上传 | `upload_requests_total`, `upload_request_duration_seconds` | `method`, `path`, `status` |
| 上传 | `upload_requests_in_flight`, `upload_bytes_total`(来自 `Content-Length`) | `method`, `path` |
| OpenID | `openid_user_lookup_total`, `openid_user_lookup_duration_seconds` | `result` |
| Mongoose | `mongoose_queries_total`, `mongoose_query_duration_seconds` | `model`, `operation`, `status` |
| 生成任务 | `generation_jobs_total` | `store`, `result` |
| 生成任务 | `generation_jobs_in_flight` | `store` |
| 生成流 | `generation_stream_subscriptions_total` | `store`, `type`, `result` |
| 生成流 | `generation_stream_resume_pending_events_total`, `generation_stream_early_buffer_overflows_total`, `generation_stream_first_attachment_delay_seconds` | `store` |
| 生成流 | `generation_stream_attachment_outcomes_total` | `store`, `outcome` |
| 生成流 | `generation_stream_recoveries_total`, `generation_stream_recovery_duration_seconds`, `generation_stream_recovery_events`, `generation_stream_recovery_content_parts` | `store`, `method`, `outcome` |
| 内容过滤 | `content_filter_locator_traversal_failures_total` | `operation`, `reason` |
| 内容过滤 | `content_filter_locator_traversal_size` | `operation`, `reason`, `dimension` |

生成流恢复指标描述了早期事件缓冲区溢出后如何被重建。内容过滤指标统计未完成的已解析文件定位器遍历次数。

### 智能体启动指标 [#agent-startup-metrics]

初始 Agent 聊天请求会发出两个启动指标：

- `agent_startup_milestone_duration_seconds{milestone}` 用于衡量从请求进入到每个启动里程碑的累积延迟。
- `agent_startups_total{result}` 根据终端结果统计启动尝试次数。

里程碑涵盖了请求准入、任务创建与确认、对话与历史记录加载、客户端与运行初始化、流式传输启动，以及第一个排队响应或内容事件。结果区分了内容排队、无内容增量的完成、去重、拒绝、暂停、替换、中止和错误。

当启用[后端 OpenTelemetry 追踪](/docs/configuration/dotenv#opentelemetry-traces-and-logs)时,`librechat.agent.startup` span 会以事件的形式报告相同的里程碑。它包含启动总耗时、里程碑数量、终止结果,以及分配了生成流 ID 时的该 ID。

### Redis 指标 [#redis-metrics]

Redis 支持的缓存和服务会发出两个逻辑操作指标：

- `redis_operations_total{client,use_case,operation,status}` 用于统计操作次数。
- `redis_operation_duration_seconds{client,use_case,operation,status}` 用于衡量延迟。

`client` 为 `keyv` 或 `ioredis`，`status` 为 `success` 或 `error`。有界的 `use_case` 标签用于标识诸如缓存、会话、速率限制、并发、ACL 主体、可恢复流作业和发布/订阅、MCP 注册表扫描以及领导者选举等工作。这些指标统计的是 LibreChat 的逻辑操作，而非每一次内部 Redis 的往返。连接生命周期 ping 和全局维护不包含在内，清除命名空间被计为一次逻辑操作。

当启用[后端 OpenTelemetry 追踪](/docs/configuration/dotenv#opentelemetry-traces-and-logs)时,每个 HTTP span 还会通过以下方式汇总其 Redis 操作:

- `librechat.redis.calls`
- `librechat.redis.duration_ms`
- `librechat.redis.errors`
- `librechat.redis.max_call_ms`
- `librechat.redis.operations`
- `librechat.redis.use_cases`

总持续时间最长的十个用例也会在 `librechat.redis.<use_case>.*` 下接收 `calls`、`duration_ms`、`errors` 和 `max_call_ms` 属性。此请求级别的摘要不需要命令级别的 Redis 跨度（spans）；仅在需要单个命令跨度时启用 `OTEL_IOREDIS_TRACING_ENABLED`。

### 浏览器 RUM 代理指标 [#browser-rum-proxy-metrics]

Browser RUM 代理结果报告为 `rum_proxy_requests_total{endpoint,result}`。`endpoint` 为 `traces`、`logs` 或 `unknown`；`result` 可以是 `success`、`auth_drop`、`auth_error`、`bad_request`、`not_configured`、`collector_4xx`、`collector_5xx`、`collector_error` 或 `collector_timeout`。

### 智能体事件执行者指标 [#agent-event-actor-metrics]

Durable bound Agent Events 会公开低基数的接收和恢复指标：

- `agent_event_actor_receipt_operations_total{operation,outcome,resolution}` 用于统计回执读取、结算和遗留回填操作。`operation` 为 `read`（读取）、`settle`（结算）或 `backfill`（回填）；`outcome` 为 `hit`（命中）、`miss`（未命中）、`success`（成功）、`replay`（重放）或 `conflict`（冲突）。
- `agent_event_actor_receipts_retained{resolution}` 报告了由 `checkpoint_verified`、`action_compensated` 或 `history_repaired` 解析所保留的重放回执。
- `agent_event_actor_receipts_expiry_eligible` 报告了已超过 90 天 MongoDB TTL 但尚未被移除的保留收据。
- `agent_event_actor_reconciliations_pending` 报告了正在等待终端回执的活动对账标记。
- `agent_event_actor_oldest_reconciliation_age_seconds` 报告了最旧的活跃协调（reconciliation）的持续时间（以秒为单位）。
- `agent_event_actor_deliveries{state}` 报告当前处于 `retry` 或 `dead` 状态的投递行。

存储指标在经过身份验证的抓取中进行收集，并缓存最多 60 秒。请针对持续的协调时长、死信投递或符合过期条件的收据发出警报，而不是针对单次抓取发出警报。

### 共享链接指标 [#shared-link-metrics]

`share_link_rejections_total{operation,code}` counts bounded create or update failures. `operation` is `create` or `update`; `code` is `TARGET_MESSAGE_NOT_FOUND` when the selected branch tail is not persisted, or `NO_MESSAGES` when the conversation has no persisted messages. The metric contains no conversation text or user identity.

## 数据库指标导出器 [#database-metrics-exporter]

指标导出器可在 [virtUOS/librechat_exporter](https://github.com/virtUOS/librechat_exporter) 获取。
这是一个与 LibreChat 一起部署的独立工具。

### 设置 [#setup]

要部署 exporter，只需将必要的容器添加到您的 compose 配置中，如下所示：

```yaml
services:
  metrics:
    image: ghcr.io/virtuos/librechat_exporter:main
    depends_on:
      - mongodb
    ports:
      - '8000:8000'
    restart: unless-stopped
```

您可以选择性地配置 exporter。
但通常情况下，默认设置就已经足够了。

```yaml
services:
  metrics:
    environment:
      - MONGODB_URI=mongodb://mongodb:27017/
      - LOGGING_LEVEL=info
```

### 使用方法 [#usage]

现在你可以将 exporter 添加到你的 Prometheus 抓取配置中：

```yaml
- job_name: librechat
  static_configs:
    - targets:
        - 'librechat.example.com:8000'
```

一旦开始抓取指标，请查找 `librechat_*` 指标（例如 `librechat_registered_users`）。
该导出器提供了多个指标。
