## 语音介绍 [#speech-introduction]

语音配置包含统一的 `speech:` 部分下的语音转文字 (STT) 和文字转语音 (TTS) 设置。此外，还有一个用于用户特定设置的全新 `speechTab` 菜单。

> **另请参阅：** 有关详细的 YAML 配置模式及所有可用选项，请参阅 [Speech Object Structure](/docs/configuration/librechat_yaml/object_structure/speech) 文档。

### 环境变量 [#environment-variables]

当使用基于云的 STT/TTS 服务时，你需要在 `.env` 文件中设置 API 密钥：

```bash filename=".env"
# Speech-to-Text API key (e.g., OpenAI Whisper)
STT_API_KEY=your-stt-api-key

# Text-to-Speech API key (e.g., OpenAI TTS, ElevenLabs)
TTS_API_KEY=your-tts-api-key
```

然后，这些密钥会在您的 `librechat.yaml` 配置文件中通过 `${STT_API_KEY}` 和 `${TTS_API_KEY}` 进行引用。

### 每个服务一个提供商 [#one-provider-per-service]

每个 `speech.stt` 和 `speech.tts` 最多只能包含一个提供商配置块,并且两个部分都可以省略,以便为该服务保留浏览器引擎。如果某个部分配置了多个提供商,请求将失败,并报错 "Multiple providers are set. Please set only one provider."

### 自托管引擎需要一个 allowedAddresses 条目 [#self-hosted-engines-need-an-allowedaddresses-entry]

`speech.stt` 和 `speech.tts` 都接受一个 `allowedAddresses` 列表。出站语音请求会根据其解析出的 IP 进行验证，并被阻止访问私有、回环和链路本地地址空间，因此，除非将其列入名单，否则无法访问 `localhost`、局域网地址或 Docker 服务名称上的自托管引擎：

```yaml filename="librechat.yaml"
speech:
  tts:
    allowedAddresses:
      - 'host.docker.internal:8080'
    localai:
      url: 'http://host.docker.internal:8080/tts'
      # ...
```

条目为纯粹的 `host:port` 对：无需协议或路径，必须包含端口，IPv6 需使用方括号如 `[::1]:8080`，且 IP 字面量必须为私有地址。诸如 OpenAI、Azure 和 ElevenLabs 等公有云端点无需添加条目。该防护机制作用于解析后的 IP，而非主机名，因此通过 Private Link、私有 DNS 或 VPN 访问的云端点会解析为私有地址空间，此时需要像其他私有目标一样列出其确切的 `host:port`。相同的字段和规则也适用于 `speech.stt`。有关完整条目格式，请参阅 [SSRF protection](/docs/configuration/librechat_yaml/object_structure/web_search#ssrf-protection-and-private-providers)。

## 语音选项卡 (可选) [#speech-tab-optional]

`speechTab` 菜单提供了对话模式和高级模式的可自定义选项，以及 STT 和 TTS 的详细设置。这将为用户设置默认配置。

使用 `browser` 以使用内置浏览器语音，或使用 `external` 以使用下方配置的服务器端提供商。为了兼容性，旧的特定提供商默认值仍然被接受，并会被标准化为 `external`；如果匹配的外部服务不可用，LibreChat 将回退到 `browser`。

示例：

```yaml
speech:
  speechTab:
    conversationMode: true
    advancedMode: false
    speechToText:
      engineSTT: "external"
      languageSTT: "English (US)"
      autoTranscribeAudio: true
      decibelValue: -45
      autoSendText: 0
    textToSpeech:
      engineTTS: "external"
      voice: "alloy"
      languageTTS: "en"
      automaticPlayback: true
      playbackRate: 1.0
      cacheTTS: true
```

`speechTab` 设置用户看到的初始值；每个值在语音设置选项卡中仍可由用户更改。

## STT (语音转文字) [#stt-speech-to-text]

语音转文字(STT)功能可将语音转换为书面文本。要启用 STT,请点击(位于发送按钮附近的)STT 按钮,或使用快捷键组合 ++Shift+Alt+L++ 开始转录。

### 可用的 STT 服务 [#available-stt-services]

- **本地 STT**
  - 基于浏览器的
  - Whisper (已在 LocalAI 上测试)
- **云端 STT**
  - OpenAI Whisper
  - Azure Whisper
  - 其他兼容 OpenAI 的 STT 服务

### 配置本地 STT [#configuring-local-stt]

- #### Browser-based
  无需设置。请确保在语音设置选项卡中启用了“Speech To Text”开关，并在引擎下拉菜单中选择了“Browser”。

- #### Whisper 本地部署 [#whisper-local]
  需要一个本地的 Whisper 实例。

```yaml
speech:
  stt:
    openai:
      url: 'http://host.docker.internal:8080/v1/audio/transcriptions'
      apiKey: '${STT_API_KEY}'
      model: 'whisper'
```

`apiKey` 字段对每个 OpenAI 兼容的 STT 配置块都是必填项,包括本地服务。如果您的服务器不校验密钥,可以使用任意占位值。

### 配置 Cloud STT [#configuring-cloud-stt]

- #### OpenAI Whisper [#openai-whisper]

```yaml
speech:
  stt:
    openai:
      apiKey: '${STT_API_KEY}'
      model: 'whisper-1'
```

- #### Azure Whisper [#azure-whisper]

```yaml
speech:
  stt:
    azureOpenAI:
      instanceName: 'instanceName'
      apiKey: '${STT_API_KEY}'
      deploymentName: 'deploymentName'
      apiVersion: 'apiVersion'
```

<Callout type="info" title="Azure Endpoint 域名支持">
`instanceName` 字段支持以下两种 Azure OpenAI 域名格式：
- **新格式**：`.cognitiveservices.azure.com`（例如 `my-instance.cognitiveservices.azure.com`）
- **旧版格式**：`.openai.azure.com`（例如 `my-instance.openai.azure.com`）

您可以指定完整域名或仅指定实例名称。如果您提供包含 `.azure.com` 的完整域名，它将按原样使用。否则，为了向后兼容，将应用旧版的 `.openai.azure.com` 格式。
</Callout>

- #### 兼容 OpenAI [#openai-compatible]

请参考 OpenAI Whisper 部分,根据需要调整 `url` 和 `model`。`apiKey` 字段仍然是必需的。

示例
  
```yaml
speech:
  stt:
    openai:
      url: 'http://host.docker.internal:8080/v1/audio/transcriptions'
      apiKey: '${STT_API_KEY}'
      model: 'whisper'
```


## TTS (文本转语音) [#tts-text-to-speech]

文本转语音 (TTS) 功能可将书面文本转换为口语。目前提供多种 TTS 服务：

### 可用的 TTS 服务 [#available-tts-services]

- **本地 TTS**
  - 基于浏览器的
  - Piper (已在 LocalAI 上测试)
  - Coqui (已在 LocalAI 上测试)
- **云端 TTS**
  - OpenAI TTS
  - Azure OpenAI
  - ElevenLabs
  - 其他兼容 OpenAI/ElevenLabs 的 TTS 服务

超过 `speech.tts.maxInputChars`(默认 20000 个字符)的文本在朗读前会被截断。详情请参阅 [Speech 对象结构](/docs/configuration/librechat_yaml/object_structure/speech)。

### 配置本地 TTS [#configuring-local-tts]

- #### Browser-based [#browser-based-1]

无需设置。请确保在语音设置选项卡中启用了“Text To Speech”开关，并在引擎下拉菜单中选择了“Browser”。

- #### Piper [#piper]

需要一个本地的 Piper 实例。

```yaml
speech:
  tts:
    localai:
      url: "http://host.docker.internal:8080/tts"
      apiKey: "EMPTY"
      voices: [
        "en-us-amy-low.onnx",
        "en-us-danny-low.onnx",
        "en-us-libritts-high.onnx",
        "en-us-ryan-high.onnx",
      ]
      backend: "piper"
```

- #### Coqui [#coqui]

需要本地 Coqui 实例。

```yaml
speech:
  tts:
    localai:
      url: 'http://localhost:8080/v1/audio/synthesize'
      voices: ['tts_models/en/ljspeech/glow-tts', 'tts_models/en/ljspeech/tacotron2', 'tts_models/en/ljspeech/waveglow']
      backend: 'coqui'
```

### 配置 Cloud TTS [#configuring-cloud-tts]

- #### OpenAI TTS [#openai-tts]

```yaml
speech:
  tts:
    openai:
      apiKey: '${TTS_API_KEY}'
      model: 'tts-1'
      voices: ['alloy', 'echo', 'fable', 'onyx', 'nova', 'shimmer']
```

- #### Azure OpenAI [#azure-openai]

```yaml
speech:
  tts:
    azureOpenAI:
      instanceName: ''
      apiKey: '${TTS_API_KEY}'
      deploymentName: ''
      apiVersion: ''
      model: 'tts-1'
      voices: ['alloy', 'echo', 'fable', 'onyx', 'nova', 'shimmer']
```

<Callout type="info" title="Azure Endpoint 域名支持">
`instanceName` 字段支持以下两种 Azure OpenAI 域名格式：
- **新格式**：`.cognitiveservices.azure.com`（例如 `my-instance.cognitiveservices.azure.com`）
- **旧版格式**：`.openai.azure.com`（例如 `my-instance.openai.azure.com`）

您可以指定完整域名或仅指定实例名称。如果您提供包含 `.azure.com` 的完整域名，它将按原样使用。否则，为了向后兼容，将应用旧版的 `.openai.azure.com` 格式。
</Callout>

- #### ElevenLabs [#elevenlabs]

```yaml
speech:
  tts:
    elevenlabs:
      apiKey: '${TTS_API_KEY}'
      model: 'eleven_multilingual_v2'
      voices: ['202898wioas09d2', 'addwqr324tesfsf', '3asdasr3qrq44w', 'adsadsa']
```

可以按照以下方式添加额外的 ElevenLabs 特定参数：

```yaml
      voice_settings:
        similarity_boost: 0.75 # number
        stability: 0.5 # number
        style: 0 # number
        use_speaker_boost: true # boolean
      pronunciation_dictionary_locators: [''] # list of strings (array)
```

- #### 兼容 OpenAI [#openai-compatible-1]

请参考 OpenAI TTS 部分，并根据需要调整 `url` 变量。

示例：

```yaml
speech:
  tts:
    openai:
      url: 'http://host.docker.internal:8080/v1/audio/synthesize'
      apiKey: '${TTS_API_KEY}'
      model: 'tts-1'
      voices: ['alloy', 'echo', 'fable', 'onyx', 'nova', 'shimmer']
```

- #### 兼容 ElevenLabs [#elevenlabs-compatible]

请参考 ElevenLabs 部分，并根据需要调整 `url` 变量。

示例：

```yaml
speech:
  tts:
    elevenlabs:
      url: 'http://host.docker.internal:8080/v1/audio/synthesize'
      apiKey: '${TTS_API_KEY}'
      model: 'eleven_multilingual_v2'
      voices: ['202898wioas09d2', 'addwqr324tesfsf', '3asdasr3qrq44w', 'adsadsa']
```
