OpenAI Image Tools est le kit d'outils d'agent derrière la [génération et l'édition d'images](/docs/features/image_gen) avec les modèles d'images d'OpenAI. Son ajout à un agent lui donne deux outils : l'un qui génère à partir d'un texte, et l'autre qui modifie les images téléversées ou générées précédemment.

## Configuration [#setup]

1. Créez ou réutilisez une clé API OpenAI et ajoutez-la dans `.env` :

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=sk-...
```

2. Redémarrez LibreChat.
3. Dans le Constructeur d'agents, sélectionnez **Ajouter** à côté de **Tools**, choisissez **OpenAI Image Tools**, puis enregistrez l'agent.

Si vous laissez `IMAGE_GEN_OAI_API_KEY` non défini, chaque utilisateur est invité à saisir sa propre clé lorsqu'il ajoute l'outil.

La taille d'image qu'un agent peut demander dépend du modèle : `auto`, `1024x1024`, `1536x1024` et `1024x1536` fonctionnent partout, et les modèles qui prennent en charge des dimensions personnalisées, comme `gpt-image-2.5-flare`, acceptent d'autres valeurs telles que `2048x1152` ou `3840x2160`. L'API rejette les tailles que le modèle configuré ne prend pas en charge.

OpenAI a retiré `gpt-image-1` le 23 octobre 2026. Si vous l'avez défini dans `IMAGE_GEN_OAI_MODEL`, supprimez-le ou remplacez-le par un modèle actuel.

## Conserver les grandes images [#keeping-large-images]

LibreChat redimensionne les images enregistrées de sorte que le côté le plus court soit au maximum de 768 pixels, ainsi un résultat de `3840x2160` est stocké en 1365x768. Pour conserver la taille renvoyée par le modèle, définissez [`fileConfig.imageGeneration`](/docs/configuration/librechat_yaml/object_structure/file_config#imagegeneration) avec `percentage: 100`.

## Azure OpenAI [#azure-openai]

Pointez l'URL de base vers votre déploiement d'images et définissez la version de l'API :

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=your-azure-api-key
IMAGE_GEN_OAI_BASEURL=https://your-resource.openai.azure.com/openai/deployments/your-image-deployment/
IMAGE_GEN_OAI_AZURE_API_VERSION=2025-04-01-preview
IMAGE_GEN_OAI_MODEL=your-image-deployment
```

## Proxy [#proxy]

Les requêtes respectent la variable globale `PROXY`. Lorsque `PROXY` n'est pas défini, `HTTP_PROXY`, `HTTPS_PROXY` et `NO_PROXY` s'appliquent.

## Tarification [#pricing]

OpenAI facture la génération d'images par image, en fonction du modèle, de la taille et de la qualité. Consultez le [guide de génération d'images](https://platform.openai.com/docs/guides/image-generation) d'OpenAI pour connaître les coûts actuels.
