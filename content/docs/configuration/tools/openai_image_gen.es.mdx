OpenAI Image Tools es el kit de herramientas del agente que sustenta la [generación y edición de imágenes](/docs/features/image_gen) con los modelos de imagen de OpenAI. Al añadirlo a un agente, este obtiene dos herramientas: una que genera imágenes a partir de texto y otra que edita imágenes subidas o generadas anteriormente.

## Configuración [#setup]

1. Crea o reutiliza una clave de API de OpenAI y añádela a `.env`:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=sk-...
```

2. Reinicia LibreChat.
3. En el Agent Builder, selecciona **Add** junto a **Tools**, elige **OpenAI Image Tools** y guarda el agente.

Si dejas `IMAGE_GEN_OAI_API_KEY` sin definir, se le pedirá a cada usuario su propia clave cuando añada la herramienta.

El tamaño de imagen que un agente puede solicitar depende del modelo: `auto`, `1024x1024`, `1536x1024` y `1024x1536` funcionan en todos los casos, y los modelos que admiten dimensiones personalizadas, como `gpt-image-2.5-flare`, aceptan otros como `2048x1152` o `3840x2160`. La API rechaza los tamaños que el modelo configurado no admite.

OpenAI retiró `gpt-image-1` el 23 de octubre de 2026. Si lo configuró en `IMAGE_GEN_OAI_MODEL`, elimínelo o cambie a un modelo vigente.

## Conservar imágenes grandes [#keeping-large-images]

LibreChat redimensiona las imágenes guardadas para que el lado más corto tenga como máximo 768 píxeles, por lo que un resultado de `3840x2160` se almacena a 1365x768. Para conservar el tamaño que devolvió el modelo, establece [`fileConfig.imageGeneration`](/docs/configuration/librechat_yaml/object_structure/file_config#imagegeneration) con `percentage: 100`.

## Azure OpenAI [#azure-openai]

Apunta la URL base a tu despliegue de imágenes y configura la versión de la API:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=your-azure-api-key
IMAGE_GEN_OAI_BASEURL=https://your-resource.openai.azure.com/openai/deployments/your-image-deployment/
IMAGE_GEN_OAI_AZURE_API_VERSION=2025-04-01-preview
IMAGE_GEN_OAI_MODEL=your-image-deployment
```

## Proxy [#proxy]

Las solicitudes respetan la variable global `PROXY`. Cuando `PROXY` no está definida, se aplican `HTTP_PROXY`, `HTTPS_PROXY` y `NO_PROXY`.

## Precios [#pricing]

OpenAI cobra la generación de imágenes por imagen, según el modelo, el tamaño y la calidad. Consulta la [guía de generación de imágenes](https://platform.openai.com/docs/guides/image-generation) de OpenAI para conocer los costos actuales.
