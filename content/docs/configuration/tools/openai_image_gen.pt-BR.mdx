O OpenAI Image Tools é o kit de ferramentas do agente por trás da [geração e edição de imagens](/docs/features/image_gen) com os modelos de imagem da OpenAI. Ao adicioná-lo a um agente, o agente recebe duas ferramentas: uma que gera imagens a partir de texto e outra que edita imagens enviadas ou geradas anteriormente.

## Configuração [#setup]

1. Crie ou reutilize uma chave de API da OpenAI e adicione-a ao `.env`:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=sk-...
```

2. Reinicie o LibreChat.
3. No Agent Builder, selecione **Adicionar** ao lado de **Tools**, escolha **OpenAI Image Tools** e salve o agente.

Se você deixar `IMAGE_GEN_OAI_API_KEY` sem definir, cada usuário será solicitado a informar sua própria chave ao adicionar a ferramenta.

O tamanho de imagem que um agente pode solicitar depende do modelo: `auto`, `1024x1024`, `1536x1024` e `1024x1536` funcionam em todos os casos, e modelos que suportam dimensões personalizadas, como `gpt-image-2.5-flare`, aceitam outros, como `2048x1152` ou `3840x2160`. A API rejeita tamanhos que o modelo configurado não suporta.

A OpenAI descontinuou o `gpt-image-1` em 23 de outubro de 2026. Se você o definiu em `IMAGE_GEN_OAI_MODEL`, remova-o ou troque por um modelo atual.

## Mantendo imagens grandes [#keeping-large-images]

O LibreChat redimensiona as imagens salvas para que o lado menor tenha no máximo 768 pixels, então um resultado de `3840x2160` é armazenado em 1365x768. Para manter o tamanho retornado pelo modelo, defina [`fileConfig.imageGeneration`](/docs/configuration/librechat_yaml/object_structure/file_config#imagegeneration) como `percentage: 100`.

## Azure OpenAI [#azure-openai]

Aponte a URL base para a sua implantação de imagens e defina a versão da API:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=your-azure-api-key
IMAGE_GEN_OAI_BASEURL=https://your-resource.openai.azure.com/openai/deployments/your-image-deployment/
IMAGE_GEN_OAI_AZURE_API_VERSION=2025-04-01-preview
IMAGE_GEN_OAI_MODEL=your-image-deployment
```

## Proxy [#proxy]

As requisições respeitam a variável global `PROXY`. Quando `PROXY` não estiver definida, aplicam-se `HTTP_PROXY`, `HTTPS_PROXY` e `NO_PROXY`.

## Preços [#pricing]

A OpenAI cobra a geração de imagens por imagem, com base no modelo, no tamanho e na qualidade. Consulte o [guia de geração de imagens](https://platform.openai.com/docs/guides/image-generation) da OpenAI para ver os custos atuais.
