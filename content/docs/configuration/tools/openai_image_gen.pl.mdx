OpenAI Image Tools to zestaw narzędzi dla agentów, stanowiący zaplecze [generowania i edycji obrazów](/docs/features/image_gen) z wykorzystaniem modeli obrazów OpenAI. Dodanie go do agenta przydziela mu dwa narzędzia: jedno generujące obrazy na podstawie tekstu oraz drugie edytujące przesłane lub wcześniej wygenerowane obrazy.

## Konfiguracja [#setup]

1. Utwórz lub użyj istniejącego klucza API OpenAI i dodaj go do `.env`:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=sk-...
```

2. Uruchom ponownie LibreChat.
3. W Agent Builder wybierz **Add** obok **Tools**, wybierz **OpenAI Image Tools** i zapisz agenta.

Jeśli pozostawisz `IMAGE_GEN_OAI_API_KEY` nieustawiony, każdy użytkownik zostanie poproszony o podanie własnego klucza podczas dodawania narzędzia.

Rozmiar obrazu, o jaki może poprosić agent, zależy od modelu: `auto`, `1024x1024`, `1536x1024` i `1024x1536` działają wszędzie, a modele obsługujące niestandardowe wymiary, takie jak `gpt-image-2.5-flare`, akceptują także inne, na przykład `2048x1152` lub `3840x2160`. API odrzuca rozmiary, których skonfigurowany model nie obsługuje.

OpenAI wycofało `gpt-image-1` 23 października 2026 roku. Jeśli ustawiłeś go w `IMAGE_GEN_OAI_MODEL`, usuń tę wartość lub przełącz się na aktualny model.

## Zachowywanie dużych obrazów [#keeping-large-images]

LibreChat zmienia rozmiar zapisanych obrazów tak, aby krótszy bok miał co najwyżej 768 pikseli, więc wynik `3840x2160` jest zapisywany w rozmiarze 1365x768. Aby zachować rozmiar zwrócony przez model, ustaw [`fileConfig.imageGeneration`](/docs/configuration/librechat_yaml/object_structure/file_config#imagegeneration) na `percentage: 100`.

## Azure OpenAI [#azure-openai]

Ustaw bazowy adres URL na swoje wdrożenie obrazów i określ wersję API:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=your-azure-api-key
IMAGE_GEN_OAI_BASEURL=https://your-resource.openai.azure.com/openai/deployments/your-image-deployment/
IMAGE_GEN_OAI_AZURE_API_VERSION=2025-04-01-preview
IMAGE_GEN_OAI_MODEL=your-image-deployment
```

## Proxy [#proxy]

Żądania respektują zmienną globalną `PROXY`. Gdy `PROXY` nie jest ustawiona, zastosowanie mają `HTTP_PROXY`, `HTTPS_PROXY` oraz `NO_PROXY`.

## Cennik [#pricing]

OpenAI nalicza opłaty za generowanie obrazów za każdy obraz, w zależności od modelu, rozmiaru i jakości. Aktualne ceny znajdziesz w [przewodniku dotyczącym generowania obrazów](https://platform.openai.com/docs/guides/image-generation) OpenAI.
