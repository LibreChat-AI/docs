OpenAI Image Tools 是 OpenAI 图像模型[图像生成与编辑](/docs/features/image_gen)背后的智能体工具包。将其添加到智能体后,智能体将获得两个工具:一个用于根据文本生成图像,另一个用于编辑已上传或之前生成的图像。

## 设置 [#setup]

1. 创建或复用 OpenAI API 密钥,并将其添加到 `.env` 中:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=sk-...
```

2. 重启 LibreChat。
3. 在 Agent Builder 中,点击 **Tools** 旁边的 **Add**,选择 **OpenAI Image Tools**,然后保存该 agent。

如果未设置 `IMAGE_GEN_OAI_API_KEY`,每位用户在添加该工具时都会被要求提供其各自的密钥。

代理可以请求的图像尺寸取决于模型:`auto`、`1024x1024`、`1536x1024` 和 `1024x1536` 在所有模型上均可使用;支持自定义尺寸的模型(例如 `gpt-image-2.5-flare`)还可接受其他尺寸,如 `2048x1152` 或 `3840x2160`。如果所配置的模型不支持某个尺寸,API 会拒绝该请求。

OpenAI 已于 2026 年 10 月 23 日停用 `gpt-image-1`。如果您在 `IMAGE_GEN_OAI_MODEL` 中设置了该模型,请将其删除或切换为当前可用的模型。

## 保留大图 [#keeping-large-images]

LibreChat 会将保存的图片缩放，使其较短边最多为 768 像素，因此 `3840x2160` 的结果会以 1365x768 的尺寸保存。若要保留模型返回的原始尺寸，请将 [`fileConfig.imageGeneration`](/docs/configuration/librechat_yaml/object_structure/file_config#imagegeneration) 设置为 `percentage: 100`。

## Azure OpenAI [#azure-openai]

将基础 URL 指向你的图像部署地址,并设置 API 版本:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=your-azure-api-key
IMAGE_GEN_OAI_BASEURL=https://your-resource.openai.azure.com/openai/deployments/your-image-deployment/
IMAGE_GEN_OAI_AZURE_API_VERSION=2025-04-01-preview
IMAGE_GEN_OAI_MODEL=your-image-deployment
```

## 工具描述 [#tool-descriptions]

模型会根据每个工具的描述来决定何时以及如何调用该工具。如果你想对此进行引导,例如强制执行统一的风格,可以替换内置的描述文本。

## 代理 [#proxy]

请求遵循全局变量 `PROXY`。当未设置 `PROXY` 时,`HTTP_PROXY`、`HTTPS_PROXY` 和 `NO_PROXY` 生效。

## 定价 [#pricing]

OpenAI 按图像生成的次数计费,费用取决于模型、尺寸和质量。当前的费用详情请参阅 OpenAI 的[图像生成指南](https://platform.openai.com/docs/guides/image-generation)。
