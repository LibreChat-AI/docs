OpenAI Image Tools adalah toolkit agen di balik [pembuatan dan pengeditan gambar](/docs/features/image_gen) dengan model gambar OpenAI. Dengan menambahkannya ke sebuah agen, agen tersebut mendapatkan dua tools: satu untuk membuat gambar dari teks dan satu untuk mengedit gambar yang diunggah atau gambar sebelumnya.

## Pengaturan [#setup]

1. Buat atau gunakan kembali kunci API OpenAI dan tambahkan ke `.env`:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=sk-...
```

2. Restart LibreChat.
3. Di Agent Builder, pilih **Add** di samping **Tools**, pilih **OpenAI Image Tools**, lalu simpan agen.

Jika Anda membiarkan `IMAGE_GEN_OAI_API_KEY` tidak diatur, setiap pengguna akan diminta memasukkan kunci API mereka sendiri saat menambahkan alat tersebut.

Ukuran gambar yang dapat diminta oleh agen bergantung pada model: `auto`, `1024x1024`, `1536x1024`, dan `1024x1536` berfungsi di semua model, dan model yang mendukung dimensi kustom, seperti `gpt-image-2.5-flare`, menerima ukuran lain seperti `2048x1152` atau `3840x2160`. API akan menolak ukuran yang tidak didukung oleh model yang dikonfigurasi.

OpenAI menghentikan layanan `gpt-image-1` pada 23 Oktober 2026. Jika Anda mengaturnya di `IMAGE_GEN_OAI_MODEL`, hapus atau ganti dengan model yang masih aktif.

## Menyimpan gambar berukuran besar [#keeping-large-images]

LibreChat mengubah ukuran gambar yang disimpan sehingga sisi yang lebih pendek paling besar 768 piksel, sehingga hasil `3840x2160` disimpan dengan ukuran 1365x768. Untuk mempertahankan ukuran yang dikembalikan oleh model, atur [`fileConfig.imageGeneration`](/docs/configuration/librechat_yaml/object_structure/file_config#imagegeneration) ke `percentage: 100`.

## Azure OpenAI [#azure-openai]

Arahkan base URL ke deployment image Anda dan atur versi API:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=your-azure-api-key
IMAGE_GEN_OAI_BASEURL=https://your-resource.openai.azure.com/openai/deployments/your-image-deployment/
IMAGE_GEN_OAI_AZURE_API_VERSION=2025-04-01-preview
IMAGE_GEN_OAI_MODEL=your-image-deployment
```

## Proxy [#proxy]

Permintaan mematuhi variabel global `PROXY`. Ketika `PROXY` tidak diatur, `HTTP_PROXY`, `HTTPS_PROXY`, dan `NO_PROXY` yang berlaku.

## Harga [#pricing]

OpenAI menagihkan biaya pembuatan gambar per gambar, berdasarkan model, ukuran, dan kualitas. Lihat [panduan pembuatan gambar](https://platform.openai.com/docs/guides/image-generation) dari OpenAI untuk biaya terkini.
