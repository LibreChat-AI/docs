OpenAI Image Tools는 OpenAI 이미지 모델을 사용한 [이미지 생성 및 편집](/docs/features/image_gen)을 위한 에이전트 툴킷입니다. 에이전트에 추가하면 에이전트에게 두 가지 도구가 주어집니다. 하나는 텍스트로부터 이미지를 생성하는 도구이고, 다른 하나는 업로드된 이미지나 이전에 생성된 이미지를 편집하는 도구입니다.

## 설정 [#setup]

1. OpenAI API 키를 새로 만들거나 기존 키를 재사용한 뒤, 이를 `.env`에 추가하세요:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=sk-...
```

2. LibreChat를 다시 시작하세요.
3. 에이전트 빌더에서 **Tools** 옆의 **Add**를 선택한 다음 **OpenAI Image Tools**를 선택하고 에이전트를 저장합니다.

`IMAGE_GEN_OAI_API_KEY`를 설정하지 않은 상태로 두면, 사용자가 도구를 추가할 때마다 각자의 키를 입력하라는 메시지가 표시됩니다.

에이전트가 요청할 수 있는 이미지 크기는 모델에 따라 다릅니다. `auto`, `1024x1024`, `1536x1024`, `1024x1536`은 모든 모델에서 사용할 수 있으며, `gpt-image-2.5-flare`와 같이 사용자 지정 크기를 지원하는 모델은 `2048x1152`나 `3840x2160`과 같은 다른 크기도 허용합니다. 구성된 모델이 지원하지 않는 크기는 API에서 거부됩니다.

OpenAI는 2026년 10월 23일에 `gpt-image-1`을 지원 중단했습니다. `IMAGE_GEN_OAI_MODEL`에 이 값을 설정했다면 해당 항목을 제거하거나 최신 모델로 변경하세요.

## 큰 이미지 유지하기 [#keeping-large-images]

LibreChat는 저장된 이미지의 짧은 쪽이 최대 768픽셀이 되도록 크기를 조정하므로, `3840x2160` 결과물은 1365x768로 저장됩니다. 모델이 반환한 크기를 그대로 유지하려면 [`fileConfig.imageGeneration`](/docs/configuration/librechat_yaml/object_structure/file_config#imagegeneration)을 `percentage: 100`으로 설정하세요.

## Azure OpenAI [#azure-openai]

이미지 배포의 베이스 URL을 지정하고 API 버전을 설정하세요:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=your-azure-api-key
IMAGE_GEN_OAI_BASEURL=https://your-resource.openai.azure.com/openai/deployments/your-image-deployment/
IMAGE_GEN_OAI_AZURE_API_VERSION=2025-04-01-preview
IMAGE_GEN_OAI_MODEL=your-image-deployment
```

## 프록시 [#proxy]

요청은 전역 `PROXY` 변수를 따릅니다. `PROXY`가 설정되지 않은 경우 `HTTP_PROXY`, `HTTPS_PROXY`, `NO_PROXY`가 적용됩니다.

## 가격 [#pricing]

OpenAI는 모델, 크기, 품질에 따라 이미지 한 장당 이미지 생성 비용을 청구합니다. 현재 비용은 OpenAI의 [이미지 생성 가이드](https://platform.openai.com/docs/guides/image-generation)를 참고하세요.
