OpenAI Image Tools is de agenttoolkit achter [beeldgeneratie en -bewerking](/docs/features/image_gen) met OpenAI-beeldmodellen. Door deze toolkit aan een agent toe te voegen, krijgt de agent twee tools: één die beelden genereert op basis van tekst en één die geüploade of eerder gegenereerde beelden bewerkt.

## Setup [#setup]

1. Maak een OpenAI API-sleutel aan of hergebruik een bestaande, en voeg deze toe aan `.env`:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=sk-...
```

2. Herstart LibreChat.
3. In de Agent Builder selecteer je **Add** naast **Tools**, kies je **OpenAI Image Tools** en sla je de agent op.

Als je `IMAGE_GEN_OAI_API_KEY` niet instelt, wordt elke gebruiker om hun eigen sleutel gevraagd wanneer ze de tool toevoegen.

De afbeeldingsgrootte die een agent kan aanvragen hangt af van het model: `auto`, `1024x1024`, `1536x1024` en `1024x1536` werken overal, en modellen die aangepaste afmetingen ondersteunen, zoals `gpt-image-2.5-flare`, accepteren andere formaten zoals `2048x1152` of `3840x2160`. De API weigert formaten die het geconfigureerde model niet ondersteunt.

OpenAI heeft `gpt-image-1` op 23 oktober 2026 uit dienst genomen. Als u dit model hebt ingesteld in `IMAGE_GEN_OAI_MODEL`, verwijder het dan of schakel over naar een actueel model.

## Grote afbeeldingen behouden [#keeping-large-images]

LibreChat past opgeslagen afbeeldingen zo aan dat de kortste zijde maximaal 768 pixels is, dus een resultaat van `3840x2160` wordt opgeslagen als 1365x768. Om de grootte te behouden die het model heeft teruggegeven, stel je [`fileConfig.imageGeneration`](/docs/configuration/librechat_yaml/object_structure/file_config#imagegeneration) in op `percentage: 100`.

## Azure OpenAI [#azure-openai]

Wijs de basis-URL naar uw image-deployment en stel de API-versie in:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=your-azure-api-key
IMAGE_GEN_OAI_BASEURL=https://your-resource.openai.azure.com/openai/deployments/your-image-deployment/
IMAGE_GEN_OAI_AZURE_API_VERSION=2025-04-01-preview
IMAGE_GEN_OAI_MODEL=your-image-deployment
```

## Proxy [#proxy]

Verzoeken respecteren de globale variabele `PROXY`. Wanneer `PROXY` niet is ingesteld, zijn `HTTP_PROXY`, `HTTPS_PROXY` en `NO_PROXY` van toepassing.

## Prijzen [#pricing]

OpenAI rekent beeldgeneratie per afbeelding, op basis van model, formaat en kwaliteit. Raadpleeg de [handleiding voor beeldgeneratie](https://platform.openai.com/docs/guides/image-generation) van OpenAI voor de actuele kosten.
