OpenAI Image Tools là bộ công cụ dành cho agent đứng sau [tạo và chỉnh sửa hình ảnh](/docs/features/image_gen) với các mô hình hình ảnh của OpenAI. Khi thêm vào một agent, công cụ này cung cấp cho agent hai công cụ: một công cụ tạo hình ảnh từ văn bản và một công cụ chỉnh sửa các hình ảnh đã tải lên hoặc được tạo trước đó.

## Thiết lập [#setup]

1. Tạo hoặc tái sử dụng khóa API OpenAI và thêm vào `.env`:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=sk-...
```

2. Khởi động lại LibreChat.
3. Trong Agent Builder, chọn **Add** bên cạnh **Tools**, chọn **OpenAI Image Tools**, rồi lưu agent.

Nếu bạn để trống `IMAGE_GEN_OAI_API_KEY`, mỗi người dùng sẽ được yêu cầu nhập khóa API riêng của họ khi thêm công cụ.

Kích thước ảnh mà một agent có thể yêu cầu phụ thuộc vào mô hình: `auto`, `1024x1024`, `1536x1024` và `1024x1536` hoạt động trên mọi mô hình, còn các mô hình hỗ trợ kích thước tùy chỉnh, chẳng hạn như `gpt-image-2.5-flare`, chấp nhận các kích thước khác như `2048x1152` hoặc `3840x2160`. API sẽ từ chối những kích thước mà mô hình đã cấu hình không hỗ trợ.

OpenAI đã ngừng hỗ trợ `gpt-image-1` vào ngày 23 tháng 10 năm 2026. Nếu bạn đã đặt giá trị này trong `IMAGE_GEN_OAI_MODEL`, hãy xóa nó hoặc chuyển sang một mô hình hiện hành.

## Giữ lại hình ảnh có kích thước lớn [#keeping-large-images]

LibreChat thay đổi kích thước các hình ảnh đã lưu sao cho cạnh ngắn hơn có tối đa 768 pixel, vì vậy kết quả `3840x2160` sẽ được lưu ở kích thước 1365x768. Để giữ nguyên kích thước mà mô hình trả về, hãy đặt [`fileConfig.imageGeneration`](/docs/configuration/librechat_yaml/object_structure/file_config#imagegeneration) thành `percentage: 100`.

## Azure OpenAI [#azure-openai]

Trỏ base URL đến triển khai hình ảnh của bạn và đặt phiên bản API:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=your-azure-api-key
IMAGE_GEN_OAI_BASEURL=https://your-resource.openai.azure.com/openai/deployments/your-image-deployment/
IMAGE_GEN_OAI_AZURE_API_VERSION=2025-04-01-preview
IMAGE_GEN_OAI_MODEL=your-image-deployment
```

## Mô tả công cụ [#tool-descriptions]

## Proxy [#proxy]

Các yêu cầu tuân theo biến toàn cục `PROXY`. Khi `PROXY` không được đặt, `HTTP_PROXY`, `HTTPS_PROXY` và `NO_PROXY` sẽ có hiệu lực.

## Giá cả [#pricing]

OpenAI tính phí tạo ảnh theo từng ảnh, dựa trên mô hình, kích thước và chất lượng. Xem [hướng dẫn tạo ảnh](https://platform.openai.com/docs/guides/image-generation) của OpenAI để biết chi phí hiện tại.
