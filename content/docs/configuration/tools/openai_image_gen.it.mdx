OpenAI Image Tools è il toolkit per agenti alla base della [generazione e modifica di immagini](/docs/features/image_gen) con i modelli di immagini di OpenAI. Aggiungerlo a un agente fornisce all'agente due strumenti: uno che genera immagini a partire dal testo e uno che modifica le immagini caricate o generate in precedenza.

## Setup [#setup]

1. Crea o riutilizza una chiave API di OpenAI e aggiungila a `.env`:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=sk-...
```

2. Riavvia LibreChat.
3. Nel Costruttore di agenti, seleziona **Add** accanto a **Tools**, scegli **OpenAI Image Tools**, quindi salva l'agente.

Se lasci `IMAGE_GEN_OAI_API_KEY` non impostata, a ciascun utente viene chiesta la propria chiave quando aggiunge lo strumento.

La dimensione dell'immagine che un agente può richiedere dipende dal modello: `auto`, `1024x1024`, `1536x1024` e `1024x1536` funzionano ovunque, mentre i modelli che supportano dimensioni personalizzate, come `gpt-image-2.5-flare`, accettano altre dimensioni come `2048x1152` o `3840x2160`. L'API rifiuta le dimensioni che il modello configurato non supporta.

OpenAI ha ritirato `gpt-image-1` il 23 ottobre 2026. Se l'hai impostato in `IMAGE_GEN_OAI_MODEL`, rimuovilo o passa a un modello attuale.

## Conservare le immagini di grandi dimensioni [#keeping-large-images]

LibreChat ridimensiona le immagini salvate in modo che il lato più corto sia al massimo di 768 pixel, quindi un risultato `3840x2160` viene memorizzato a 1365x768. Per mantenere la dimensione restituita dal modello, imposta [`fileConfig.imageGeneration`](/docs/configuration/librechat_yaml/object_structure/file_config#imagegeneration) su `percentage: 100`.

## Azure OpenAI [#azure-openai]

Punta l'URL di base alla tua distribuzione di immagini e imposta la versione dell'API:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=your-azure-api-key
IMAGE_GEN_OAI_BASEURL=https://your-resource.openai.azure.com/openai/deployments/your-image-deployment/
IMAGE_GEN_OAI_AZURE_API_VERSION=2025-04-01-preview
IMAGE_GEN_OAI_MODEL=your-image-deployment
```

## Proxy [#proxy]

Le richieste rispettano la variabile globale `PROXY`. Quando `PROXY` non è impostata, si applicano `HTTP_PROXY`, `HTTPS_PROXY` e `NO_PROXY`.

## Prezzi [#pricing]

OpenAI addebita la generazione di immagini per ogni immagine, in base a modello, dimensione e qualità. Consulta la [guida alla generazione di immagini](https://platform.openai.com/docs/guides/image-generation) di OpenAI per i costi aggiornati.
