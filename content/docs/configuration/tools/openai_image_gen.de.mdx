OpenAI Image Tools ist das Agent-Toolkit hinter der [Bildgenerierung und -bearbeitung](/docs/features/image_gen) mit OpenAI-Bildmodellen. Wird es einem Agenten hinzugefügt, erhält der Agent zwei Tools: eines, das aus Text generiert, und eines, das hochgeladene oder frühere Bilder bearbeitet.

## Einrichtung [#setup]

1. Erstellen Sie einen OpenAI-API-Schlüssel oder verwenden Sie einen vorhandenen und fügen Sie ihn in `.env` ein:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=sk-...
```

2. LibreChat neu starten.
3. Im Agent Builder wählen Sie neben **Tools** die Option **Add** aus, wählen **OpenAI Image Tools** und speichern den Agenten.

Wenn du `IMAGE_GEN_OAI_API_KEY` nicht setzt, wird jeder Benutzer nach seinem eigenen Schlüssel gefragt, wenn er das Tool hinzufügt.

Die Bildgröße, die ein Agent anfordern kann, hängt vom Modell ab: `auto`, `1024x1024`, `1536x1024` und `1024x1536` funktionieren überall, und Modelle, die benutzerdefinierte Abmessungen unterstützen, etwa `gpt-image-2.5-flare`, akzeptieren weitere Größen wie `2048x1152` oder `3840x2160`. Die API lehnt Größen ab, die das konfigurierte Modell nicht unterstützt.

OpenAI hat `gpt-image-1` am 23. Oktober 2026 eingestellt. Wenn Sie es in `IMAGE_GEN_OAI_MODEL` gesetzt haben, entfernen Sie es oder wechseln Sie zu einem aktuellen Modell.

## Große Bilder beibehalten [#keeping-large-images]

LibreChat skaliert gespeicherte Bilder so, dass die kürzere Seite höchstens 768 Pixel beträgt. Ein Ergebnis mit `3840x2160` wird daher mit 1365x768 gespeichert. Um die vom Modell zurückgegebene Größe beizubehalten, setzen Sie [`fileConfig.imageGeneration`](/docs/configuration/librechat_yaml/object_structure/file_config#imagegeneration) auf `percentage: 100`.

## Azure OpenAI [#azure-openai]

Setzen Sie die Basis-URL auf Ihre Bereitstellung für Bilder und legen Sie die API-Version fest:

```bash filename=".env"
IMAGE_GEN_OAI_API_KEY=your-azure-api-key
IMAGE_GEN_OAI_BASEURL=https://your-resource.openai.azure.com/openai/deployments/your-image-deployment/
IMAGE_GEN_OAI_AZURE_API_VERSION=2025-04-01-preview
IMAGE_GEN_OAI_MODEL=your-image-deployment
```

## Proxy [#proxy]

Anfragen berücksichtigen die globale Variable `PROXY`. Ist `PROXY` nicht gesetzt, gelten `HTTP_PROXY`, `HTTPS_PROXY` und `NO_PROXY`.

## Preise [#pricing]

OpenAI berechnet die Bildgenerierung pro Bild, abhängig von Modell, Größe und Qualität. Die aktuellen Kosten finden Sie im [Leitfaden zur Bildgenerierung](https://platform.openai.com/docs/guides/image-generation) von OpenAI.
