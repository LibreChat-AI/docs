La generación de imágenes con Gemini es una herramienta potente que integra los modelos de imagen Gemini de Google para la generación de texto a imagen de alta calidad y la edición de imágenes con reconocimiento de contexto. Es compatible tanto con la API simple de Gemini como con Google Cloud Vertex AI.

## Instrucciones de configuración [#setup-instructions]

Puede utilizar la API de Gemini (recomendada para la mayoría de los usuarios) o Vertex AI con una cuenta de servicio.

### Opción 1: Gemini API (Recomendado) [#option-1-gemini-api-recommended]

1. Obtén tu clave de API desde [Google AI Studio](https://aistudio.google.com/app/apikey)
2. Establezca la variable de entorno `GEMINI_API_KEY` en su archivo `.env`:

```bash
GEMINI_API_KEY=your_api_key_here
```

### Opción 2: Vertex AI (Para usuarios de Enterprise/GCP) [#option-2-vertex-ai-for-enterprisegcp-users]

1. Cree una cuenta de servicio en Google Cloud Console con permisos de Vertex AI
2. Descargue el archivo de clave JSON de la cuenta de servicio
3. Coloque el archivo JSON en el proyecto (por ejemplo, `api/data/auth.json`) o establezca la ruta:

```bash
# Path to your service account JSON file (default: api/data/auth.json)
GOOGLE_SERVICE_KEY_FILE=/path/to/service-account.json

# Optional: Set the location (default: global)
GOOGLE_CLOUD_LOCATION=us-central1
```

LibreChat elige las credenciales en este orden: la clave propia del usuario (introducida en la interfaz), `GEMINI_API_KEY`, `GOOGLE_KEY` (compartida con el endpoint de chat de Google) y, por último, el archivo de cuenta de servicio de Vertex AI. `GOOGLE_LOC` también se acepta como ubicación cuando `GOOGLE_CLOUD_LOCATION` no está definido.

Después de configurar las credenciales, reinicia LibreChat y añade **Gemini Image Tools** a la lista de **Tools** de un agente.

| Despliegue | Comando |
|------------|---------|
| Docker | `docker compose down && docker compose up -d` |
| Local | Detenga el servidor, luego ejecute `npm run backend` de nuevo |

## Opciones de configuración [#configuration-options]

### Selección de modelos [#model-selection]

Puedes elegir qué modelo de imagen de Gemini utilizar a través de una variable de entorno:

```bash
# Default model
GEMINI_IMAGE_MODEL=gemini-2.5-flash-image

# Or use the newer Gemini 3 Pro Image model
GEMINI_IMAGE_MODEL=gemini-3-pro-image-preview
```

### Modelos disponibles [#available-models]

| Modelo | Descripción |
|-------|-------------|
| `gemini-2.5-flash-image` | Modelo predeterminado, rápido y eficiente |
| `gemini-3-pro-image-preview` | Mayor calidad, generaciones más detalladas |

### Proxy [#proxy]

Las solicitudes respetan la variable global `PROXY`. Cuando `PROXY` no está definida, se aplican `HTTP_PROXY`, `HTTPS_PROXY` y `NO_PROXY`.

## Características [#features]

### Capacidades principales [#core-capabilities]

- **Generación de texto a imagen**: Cree imágenes a partir de descripciones de texto detalladas
- **Soporte de contexto de imagen**: Utilice imágenes existentes como contexto/inspiración para nuevas generaciones
- **Edición de imágenes**: Generar nuevas imágenes basadas en modificaciones de otras existentes
- **Filtrado de seguridad**: Seguridad de contenido integrada con mensajes de error fáciles de usar

### Parámetros [#parameters]

La herramienta Gemini Image Gen acepta los siguientes parámetros:

- **prompt** (obligatorio): una descripción de texto detallada de la imagen deseada, de hasta 32 000 caracteres
- **image_ids** (opcional): matriz de IDs de imágenes que se usarán como contexto visual para la generación
- **aspectRatio** (opcional): la proporción de la imagen. Uno de `1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9` o `21:9`. Por defecto es `1:1` cuando se omite.
- **imageSize** (opcional): la resolución de la imagen. Uno de `1K`, `2K` o `4K`. Por defecto es `1K` cuando se omite. Se ignora cuando el modelo es `gemini-2.5-flash-image`.

## Mejores prácticas [#best-practices]

### Redacción de Prompts [#prompt-writing]

1. **Sé específico y detallado** en tus descripciones
2. **Comienza con el tipo de imagen**: photo, oil painting, watercolor, illustration, cartoon, drawing, vector, render, etc.
3. **Incluir elementos clave**:
   - Asunto y composición
   - Estilo y enfoque artístico
   - Iluminación y atmósfera
   - Preferencias de la paleta de colores
   - Especificaciones técnicas

### Consejos para la edición de imágenes [#image-editing-tips]

Al editar imágenes existentes:

1. **Incluya el ID de la imagen original** en el array `image_ids`
2. **Usa instrucciones de edición directa**:
   - Elimina el fondo de esta imagen
   - "Añade gafas de sol a la persona en esta imagen"
   - Cambia el color del coche a rojo
3. **No reconstruyas el prompt original**: usa instrucciones de modificación simples y directas

## Ejemplos de uso [#usage-examples]

### Generación básica de imágenes [#basic-image-generation]

> Un sereno jardín japonés durante la hora dorada, que presenta un puente rojo tradicional sobre un estanque de koi. Los cerezos en flor enmarcan la escena con pétalos rosados cayendo suavemente. Estilo fotorrealista con iluminación cálida y difusa y colores intensos.

### Imagen con contexto [#image-with-context]

Cuando tengas una imagen existente y quieras crear algo inspirado en ella:

1. Haga referencia al ID de la imagen en el parámetro `image_ids`
2. Describe lo que quieres: "Crea una versión invernal de este paisaje con árboles cubiertos de nieve y un lago congelado"

### Edición de imágenes [#image-editing]

Para modificar una imagen existente:

1. Incluya el ID de la imagen en `image_ids`
2. Describe el cambio: "Elimina a la persona del fondo de esta imagen"

## Manejo de errores [#error-handling]

### Problemas comunes [#common-issues]

| Error | Solución |
|-------|----------|
| "Image blocked by content safety filters" | Modifica tu prompt para evitar contenido que infrinja las políticas de seguridad |
| "No image was generated" | Intenta con un prompt diferente o simplifica tu solicitud |
| "GEMINI_API_KEY or service account required" | Asegúrate de haber configurado la clave de API o las credenciales de Vertex AI |

### Filtrado de seguridad [#safety-filtering]

Gemini incluye filtros de seguridad integrados. Si tu imagen está bloqueada:

- Revise su prompt en busca de contenido potencialmente problemático
- Intenta reformular para ser más específico sobre la intención artística
- Evite las solicitudes de contenido dañino, violento o explícito

## Detalles técnicos [#technical-details]

### Integración de almacenamiento [#storage-integration]

Las imágenes generadas se guardan automáticamente utilizando la estrategia de archivos configurada (local, S3, Azure o Firebase). Esto lo gestiona el framework: la herramienta devuelve los datos de la imagen y el sistema de callbacks del agente los almacena como un adjunto del mensaje.

### Formato de imagen [#image-format]

- El formato de salida predeterminado es PNG, configurable a través del ajuste `imageOutputType` de la aplicación.
- Las imágenes incluyen identificadores únicos para su referencia en solicitudes posteriores

## Límites de tasa [#rate-limits]

Los límites de tasa dependen de su nivel de API:

- **Gemini API**: Consulta [Google AI Studio](https://aistudio.google.com/) para conocer los límites actuales
- **Vertex AI**: Basado en las cuotas de tu proyecto de Google Cloud
