LibreChatのツールは**Agent Builder**から選択され、エージェントが有用であると判断した際に実行されます。このセクションでは、画像生成、検索、天気、計算、プライベートインデックス検索などの組み込みエージェントツールについて説明します。

<Callout type="info" title="Web SearchやMCPとは異なります">

このページの検索ツールは、特定のAgentに追加するツールです。LibreChatの組み込みの[Web Search](/docs/features/web_search)機能は個別に設定され、カスタムのサードパーティ製ツールは通常[MCP](/docs/features/mcp)または[Actions](/docs/features/agents#actions)を通じて追加されます。

</Callout>

## クイックセットアップ [#quick-setup]

<Steps>
  <Step>

### ツールを選択 [#pick-the-tool]

以下の表からツールを選択し、必要なAPIキー、サービスURL、またはインデックス名を取得してください。

  </Step>
  <Step>

### 認証情報の追加 [#add-credentials]

`.env` ファイルに必要な値を追加するか、ツールが要求した際にユーザーが LibreChat UI から独自の認証情報を入力できるようにします。

  </Step>
  <Step>

### LibreChatを再起動する [#restart-librechat]

環境変数の変更は、再起動時に読み込まれます。

| デプロイ | コマンド |
|------------|---------|
| Docker | `docker compose down && docker compose up -d` |
| ローカル | サーバーを停止し、再度 `npm run backend` を実行します |

  </Step>
  <Step>

### エージェントにツールを追加する [#add-the-tool-to-an-agent]

LibreChatで、**Agents**を選択し、エージェントを作成または編集して、エージェントの**Tools**リストを開き、ツールを選択して、エージェントを保存します。

  </Step>
  <Step>

### チャットでテストする [#test-in-chat]

そのエージェントとのチャットを開始し、検索、計算、天気予報、画像生成など、ツールを必要とするリクエストを行ってください。

  </Step>
</Steps>

## 現在の組み込みツール [#current-built-in-tools]

| ツール | 用途 | 必要な設定 | 詳細 |
|------|------------|------------------------|---------|
| OpenAI Image Tools | OpenAI の画像モデルで画像を生成・編集する | `IMAGE_GEN_OAI_API_KEY`;任意で `IMAGE_GEN_OAI_MODEL` | [Image Generation](/docs/features/image_gen#openai-image-tools) |
| Gemini Image Tools | Gemini を使って画像を生成し、画像のコンテキストを用いて編集する | `GEMINI_API_KEY`、`GOOGLE_KEY`、または `GOOGLE_SERVICE_KEY_FILE`;任意で `GEMINI_IMAGE_MODEL` | [Gemini Image Generation](/docs/configuration/tools/gemini_image_gen) |
| Flux | クラウド上での画像生成およびファインチューニング済みの画像モデル | `FLUX_API_KEY`;任意で `FLUX_API_BASE_URL` | [Flux](/docs/configuration/tools/flux) |
| Stable Diffusion | Automatic1111 を介したローカルまたはセルフホストの画像生成 | `SD_WEBUI_URL` | [Stable Diffusion](/docs/configuration/tools/stable_diffusion) |
| Google Search | エージェント向けの Google Custom Search 結果 | `GOOGLE_SEARCH_API_KEY` および `GOOGLE_CSE_ID` | [Google Search](/docs/configuration/tools/google_search) |
| Tavily Search | エージェント向けに最適化された最新の Web 検索結果 | `TAVILY_API_KEY` | [Tavily Search](/docs/configuration/tools/tavily) |
| Traversaal | 情報源付きの AI 検索結果 | `TRAVERSAAL_API_KEY` | [Traversaal](/docs/configuration/tools/traversaal) |
| Azure AI Search | プライベートな Azure AI Search インデックスを検索する | `AZURE_AI_SEARCH_SERVICE_ENDPOINT`、`AZURE_AI_SEARCH_INDEX_NAME`、`AZURE_AI_SEARCH_API_KEY` | [Azure AI Search](/docs/configuration/tools/azure_ai_search) |
| OpenWeather | 現在、予報、過去、および日次の気象データ | `OPENWEATHER_API_KEY` | [OpenWeather](/docs/configuration/tools/openweather) |
| Wolfram\|Alpha | 数学、計算、単位、厳選された知識、およびリアルタイムデータ | `WOLFRAM_APP_ID` | [Wolfram\|Alpha](/docs/configuration/tools/wolfram) |
| Calculator | 基本的な計算および複雑な計算 | なし | [Calculator](/docs/configuration/tools/calculator) |
| GitHub Compare(エージェントのみ) | ワークスペースなしで、公開 GitHub リポジトリのコミット系統を比較する | `librechat.yaml` で `githubCompare.enabled: true`(デフォルトでは無効);任意で `githubCompare.timeoutMs`(デフォルト 10000、最大 30000) | なし |
| Ask User(エージェントのみ) | 実行中にエージェントが一時停止して明確化のための質問を行い、回答を待つ | なし | なし |

## カスタムツールの作成 [#creating-custom-tools]

ほとんどのカスタムツールは、LibreChatのソースコードを編集することなく追加できます。

- エージェントをローカルスクリプト、内部サービス、データベース、ブラウザ自動化サーバー、またはカスタムAPIラッパーに接続したい場合は、[MCP](/docs/features/mcp)を使用してください。例えば、DuckDuckGo検索ツールをMCPサーバー経由で公開し、それをAgent Builderから選択することができます。
- ツールがOpenAPIスキーマで記述可能なHTTP APIである場合は、[Actions](/docs/features/agents#actions)を使用してください。
- LibreChatのソースレベルの構造化ツールを編集するのは、LibreChat自体を開発している場合に限定してください。レガシーな[Tools and Plugins development guide](/docs/development/tools_and_plugins)はコントリビューター向けに引き続き利用可能ですが、デプロイメントにおける拡張パスとしてはMCPおよびActionsが推奨されます。

## ツール利用可能性 [#tool-availability]

ツールは、LibreChatの `api/app/clients/tools/manifest.json` にある `pluginKey` によって内部的に識別されます。

[`filteredTools`](/docs/configuration/librechat_yaml/object_structure/config#filteredtools) を使用してツールを非表示にするか、[`includedTools`](/docs/configuration/librechat_yaml/object_structure/config#includedtools) を使用して特定のツールのみを許可します：

```yaml filename="librechat.yaml"
includedTools:
  - calculator
  - image_gen_oai
  - google
```

再起動後にAgent Builderでツールが表示されない場合は、そのツールの環境変数、`includedTools`、`filteredTools`、およびエージェントの`tools`機能が有効になっているかどうかを確認してください。
