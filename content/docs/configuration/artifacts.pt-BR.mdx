Esta página aborda o lado administrativo de [Artifacts](/docs/features/artifacts). Os usuários ativam os artifacts por agente no Agent Builder; as configurações aqui definem se essa opção existe e de onde as pré-visualizações são carregadas.

## Habilitando artefatos [#enabling-artifacts]

Artefatos são uma capacidade de agente. `artifacts` está na lista padrão de [`endpoints.agents.capabilities`](/docs/configuration/librechat_yaml/object_structure/agents#capabilities), portanto fica disponível, a menos que você defina sua própria lista sem ele. Se você substituir `capabilities`, inclua `artifacts` para manter a opção no Agent Builder.

Para atribuir artefatos de especificação de modelo sem criar um agente, defina [`artifacts`](/docs/configuration/librechat_yaml/object_structure/model_specs#artifacts) na especificação. `true` usa o modo padrão; você também pode passar o nome de um modo: `default`, `shadcnui` ou `custom`.

## Abrindo o painel em uma nova janela [#opening-the-panel-in-a-new-window]

O painel tem um botão **Abrir em nova janela**, que o move para uma janela separada do navegador. Essa opção vem ativada por padrão. Se a sua implantação roda em um lugar onde pop-ups não funcionam, como um webview incorporado, desative-a com [`interface.artifactUndocking: false`](/docs/configuration/librechat_yaml/object_structure/interface#artifactundocking); o painel acoplado continua funcionando.

## Content-Security-Policy

A política de segurança de conteúdo (CSP) do próprio LibreChat permite frames HTTPS, portanto o bundler padrão do CodeSandbox é carregado sem alterações. Se um reverse proxy ou CDN na frente do LibreChat definir um `Content-Security-Policy` mais restritivo, permita a origem do bundler em `frame-src`: `https://*.codesandbox.io` para o bundler público, ou as URLs de seus próprios bundlers caso você faça self-host. Quando você precisar apenas estender a política integrada do LibreChat, use `CSP_FRAME_SRC_EXTRA`.

As pré-visualizações de React também carregam o Tailwind a partir de `cdn.tailwindcss.com`, portanto esse host precisa estar acessível a partir dos navegadores dos usuários.

## Auto-hospedagem do bundler Sandpack [#self-hosting-the-sandpack-bundler]

As prévias são renderizadas pelo [Sandpack](https://sandpack.codesandbox.io/), que, por padrão, busca o seu bundler na CDN pública da CodeSandbox. Essa CDN também envia telemetria de uso. Para redes privadas, requisitos de conformidade ou para eliminar a dependência de um serviço externo, [hospede o bundler por conta própria](https://sandpack.codesandbox.io/docs/guides/hosting-the-bundler).

[LibreChat-AI/codesandbox-client](https://github.com/LibreChat-AI/codesandbox-client) é um fork preparado para o LibreChat, com as requisições de telemetria removidas, incluindo as imagens de contêiner.

O LibreChat usa dois bundlers. `SANDPACK_BUNDLER_URL` serve os artefatos React, e `SANDPACK_STATIC_BUNDLER_URL` serve o template estático por trás das pré-visualizações de HTML, SVG, Markdown, código e arquivos do Office. Defina ambos ao fazer self-host: com apenas um definido, os outros tipos de artefato ainda são carregados a partir do CDN público. Ambos estão listados na [referência do `.env`](/docs/configuration/dotenv#artifacts). Diagramas Mermaid são renderizados diretamente na página e não usam nenhum dos dois bundlers.

Executar seu próprio bundler significa que você é responsável por suas configurações de CORS, pelas atualizações de segurança e pelos recursos de hospedagem. Reinicie o LibreChat após alterar essas variáveis, pois as URLs são enviadas ao navegador na configuração de inicialização.
