这些设置用于控制[自动审核](/docs/features/mod_system)功能页面中所述的速率限制、违规评分和封禁。它们全部是 `.env` 文件中的环境变量;登录和注册限制始终生效,而 [`.env.example`](https://github.com/danny-avila/LibreChat/blob/dev/.env.example) 还会启用封禁以及并发和单 IP 消息限制。上传、语音和导入限制也可以在 `librechat.yaml` 的 [`rateLimits`](/docs/configuration/librechat_yaml/object_structure/config#ratelimits) 配置块中设置。

## 设置 [#setup]

### 违规、间隔、持续时间 [#violation-interval-duration]

    ['BAN_DURATION', 'integer', '用户及关联 IP 被封禁的时长（以毫秒为单位）。','BAN_DURATION=1000 * 60 * 60 * 2'],
    ['BAN_INTERVAL', 'integer', '每当用户的分数达到或超过区间阈值时，该用户都将被封禁。','BAN_INTERVAL=20'],
    ['VIOLATION_SCORE_TTL', 'integer', '违规分数在没有新违规记录的情况下保留的时长(毫秒)。每次出现新的违规都会重新开始倒计时。设置为 0 时分数将永久保留(即旧版行为)。默认值:一小时。','VIOLATION_SCORE_TTL=1000 * 60 * 60'],
  ]}
/>

封禁会终止用户的会话，并同时封锁该账户及其来源 IP。封禁记录存储在 MongoDB 的 `logs` 集合中，并在 `BAN_DURATION` 时长到期后失效；若要提前解除封禁，请删除该集合中对应的记录。违规分数保存在 `data/violations.json` 中（启用 `USE_REDIS` 时则保存在 Redis 中），每一次违规行为都会按用户记录在 `data/logs.json` 中。

## OpenAI 文本审核 [#openai-text-moderation]
