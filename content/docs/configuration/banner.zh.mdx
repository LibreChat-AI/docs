在应用顶部向所有用户显示重要消息。非常适合用于公告、维护通知或更新。

<Callout type="info" title="快速概览">
  - 同一时间只能激活**一个横幅**
  - 设置横幅自动显示和隐藏的时间表
  - 选择用户是否可以关闭横幅
  - 向所有人或仅向已登录用户显示横幅
</Callout>

---

## 创建横幅 [#creating-a-banner]

运行此命令以创建或更新横幅：

```bash
npm run update-banner
```

使用 Docker 时,请改为在 `api` 容器内运行该脚本:

```bash
docker compose exec api npm run update-banner
```

您将通过几个简单的提示词获得引导：

```ansi
--------------------------
Update the banner!
--------------------------
Display From (Format: yyyy-mm-ddTHH:MM:SSZ, Default: now):
> 2025-12-02T09:00:00Z

Display To (Format: yyyy-mm-ddTHH:MM:SSZ, Default: not specified):
> 2025-12-31T23:59:59Z

Enter your message (Enter a single dot "." on a new line to finish):
> 🎉 Welcome to LibreChat! Check out our new features.
> .

Is public (y/N):
> n

Is persistable (cannot be dismissed) (y/N):
> n
```

<Callout type="tip" title="这些选项是什么意思？">
  - **显示开始/结束时间**:横幅出现和消失的时间。在提示处按 Enter 键可使用"现在"和"永久"。
  - **Is public**: 向未登录的访客显示（例如在登录页面上）
  - **是否可持久化**:如果为是,用户无法关闭该横幅(用于重要通知)
</Callout>

<Callout type="warning" title="再次运行此操作将替换现有的横幅">

始终只会存在一个横幅。`update-banner` 会查找现有的横幅并将其原地覆盖，仅在不存在横幅时创建一个新横幅，因此你无法排队设置第二个以供日后使用的横幅，也无法让两个计划窗口重叠。再次运行该命令会丢弃之前横幅的消息和计划。

若要更改横幅，请再次运行 `update-banner`。若要在其 `Display To` 时间之前将其撤下，请使用下方的 `delete-banner`。

</Callout>

## 删除横幅 [#deleting-a-banner]

```bash
npm run delete-banner
```

使用 Docker 时,运行 `docker compose exec api npm run delete-banner`。

您将看到当前的横幅，并在删除前被要求进行确认。

<Callout type="warning" title="只能删除处于活动状态的横幅">

`delete-banner` 只会查找当前处于生效状态的横幅:其 `Display From` 时间必须已经过去,且 `Display To` 时间必须在将来或未设置。对于计划在之后日期显示的横幅,或 `Display To` 时间已经过去的横幅,命令会报告 "No banner found to delete",且该横幅仍保留在数据库中。若要替换此类横幅,请再次运行 `update-banner`。

</Callout>

通过这种方式移除横幅也是将其提前撤下的方法：没有所谓的“禁用”标志。否则，横幅会在 `Display To` 时间过后自动消失，而未设置 `Display To` 的横幅将一直显示，直到您将其删除。

## 示例横幅 [#example-banners]

<Tabs items={['欢迎消息', '维护通知', '安全警报']}>
  <Tabs.Tab>
    一个用户可以关闭的简单欢迎消息：

    ```bash
    npm run update-banner "" "" "👋 Welcome to LibreChat!" "false" "false"
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    一个无法关闭的计划维护通知：

    ```bash
    npm run update-banner "2025-12-20T00:00:00Z" "2025-12-21T06:00:00Z" "⚠️ Scheduled maintenance on Dec 20th, 2-6 AM UTC" "true" "true"
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    一个对所有人可见的紧急安全通知：

    ```bash
    npm run update-banner "" "" "🔒 Please update your password by January 1st" "true" "true"
    ```
  </Tabs.Tab>
</Tabs>

<Callout type="info" title="空的日期参数仍会弹出提示">

空字符串(`""`)作为日期时会被视为缺失值,因此脚本仍会以交互方式询问 `Display From` 和 `Display To`。在每个提示处按 Enter 即可接受默认值;或者将 ISO 日期(`yyyy-mm-ddTHH:MM:SSZ`)作为前两个参数传入,即可在无提示的情况下运行该命令。同样,message 参数也必须提供,以跳过 message 提示;`isPublic` 和 `persistable` 参数则必须设置为 `true` 或 `false`,以跳过对应的提示。

</Callout>

## 日期格式 [#date-format]

请使用以下格式表示日期：`yyyy-mm-ddTHH:MM:SSZ`

**示例：**
- `2025-12-25T09:00:00Z` → 2025年12月25日上午9:00 (UTC)
- `2025-01-01T00:00:00Z` → 2025年1月1日午夜（UTC）

当系统提示时,无需输入日期,直接按 Enter 键即可将 `Display From` 设置为当前时间,或将 `Display To` 设置为不设结束日期。
