## Configurazione generale [#general-setup]

LibreChat supporta diversi provider di posta elettronica:
- **Mailgun API** - Consigliato per server che bloccano le porte SMTP
- **Servizi SMTP** - Invio di email tradizionale tramite Gmail, Outlook o server di posta personalizzati

### Configurazione comune [#common-configuration]

Queste variabili sono utilizzate sia da Mailgun che da SMTP:

<OptionTable
  options={[

    ['EMAIL_FROM_NAME', 'string', 'Nome del mittente (predefinito su APP_TITLE se non impostato).','EMAIL_FROM_NAME=LibreChat'],
  ]}
/>

### Configurazione di Mailgun (Consigliata) [#mailgun-configuration-recommended]

Mailgun è particolarmente utile per le distribuzioni su server che bloccano le porte SMTP per prevenire lo spam. Quando sia `MAILGUN_API_KEY` che `MAILGUN_DOMAIN` sono impostati, LibreChat utilizzerà Mailgun invece di SMTP.

<Callout type="warning" title="Attenzione">
**La mancata configurazione corretta di Mailgun o SMTP comporterà l'utilizzo da parte di LibreChat del ripristino password non protetto! Ciò consente a chiunque di reimpostare immediatamente qualsiasi password sul tuo server, senza che venga inviata alcuna email!**
</Callout>

## Configurazione con Mailgun [#setup-with-mailgun]

Per configurare Mailgun, segui questi passaggi:

1. Registrati per un account Mailgun su [mailgun.com](https://www.mailgun.com/)
2. Aggiungi e verifica il tuo dominio nella dashboard di Mailgun
3. Vai alla sezione API Keys e copia la tua Private API key
4. Nel file `.env`, modifica le variabili come segue:

<OptionTable
  options={[    
    ['MAILGUN_API_KEY', 'string', 'La tua chiave API privata Mailgun', 'MAILGUN_API_KEY=your-mailgun-api-key'],
    ['MAILGUN_DOMAIN', 'string', 'Il tuo dominio Mailgun verificato', 'MAILGUN_DOMAIN=mg.yourdomain.com'],
    ['EMAIL_FROM', 'string', 'Indirizzo email del mittente', 'EMAIL_FROM=noreply@yourdomain.com'],
    ['EMAIL_FROM_NAME', 'string', 'Nome mittente', 'EMAIL_FROM_NAME=LibreChat'],
    ['MAILGUN_HOST', 'string', '(Opzionale) Per la regione UE', 'MAILGUN_HOST=https://api.eu.mailgun.net'],
  ]}
/>

<Callout type="info" title="Nota">
Se il tuo account Mailgun si trova nella regione UE, assicurati di impostare `MAILGUN_HOST=https://api.eu.mailgun.net`
</Callout>

## Configurazione con Gmail [#setup-with-gmail]

Per configurare Gmail, segui questi passaggi:

1. Crea un Google Account e abilita la verifica in due passaggi.
2. Nelle **[Google Account settings](https://myaccount.google.com/)**, fai clic sulla scheda "Sicurezza" e apri la "Verifica in due passaggi".
3. Scorri verso il basso e apri "App passwords." Scegli "Mail" per l'app e seleziona "Other" per il dispositivo, quindi assegna un nome a tua scelta.
4. Fai clic su "Generate" per creare una password e copia la password generata.
5. Nel file `.env`, modifica le variabili come segue:

<OptionTable
  options={[    
    ['EMAIL_SERVICE', 'string', 'gmail', 'EMAIL_SERVICE=gmail'],
    ['EMAIL_USERNAME', 'string', 'la-tua-email', 'EMAIL_USERNAME=your-email'],
    ['EMAIL_PASSWORD', 'string', 'la-tua-password-email', 'EMAIL_PASSWORD=your-email-password'],
    ['EMAIL_FROM', 'string', 'indirizzo email per il campo from, ad esempio noreply@librechat.ai', 'EMAIL_FROM=noreply@librechat.ai'],
    ['EMAIL_FROM_NAME', 'string', 'Il mio server LibreChat', 'EMAIL_FROM_NAME=LibreChat'],
  ]}
/>

## Esempi di configurazione completi [#complete-configuration-examples]

### Esempio 1: Configurazione di Mailgun [#example-1-mailgun-configuration]

```bash
# ===================================
# Email Configuration - Mailgun
# ===================================
# Mailgun is recommended for servers that block SMTP ports

# Required Mailgun settings
MAILGUN_API_KEY=your-mailgun-api-key
MAILGUN_DOMAIN=mg.yourdomain.com

# Optional: For EU region
# MAILGUN_HOST=https://api.eu.mailgun.net

# Common email settings
EMAIL_FROM=noreply@yourdomain.com
EMAIL_FROM_NAME=LibreChat

# Enable password reset functionality
ALLOW_PASSWORD_RESET=true
```

### Esempio 2: Configurazione SMTP di Gmail [#example-2-gmail-smtp-configuration]

```bash
# ===================================
# Email Configuration - Gmail SMTP
# ===================================
# Traditional SMTP configuration

# Gmail service configuration
EMAIL_SERVICE=gmail
EMAIL_USERNAME=your-email@gmail.com
EMAIL_PASSWORD=your-app-password

# Common email settings
EMAIL_FROM=your-email@gmail.com
EMAIL_FROM_NAME=LibreChat

# Enable password reset functionality
ALLOW_PASSWORD_RESET=true
```

### Esempio 3: Configurazione del server SMTP personalizzato [#example-3-custom-smtp-server-configuration]

```bash
# ===================================
# Email Configuration - Custom SMTP
# ===================================
# For custom mail servers

# SMTP server details
EMAIL_HOST=smtp.example.com
EMAIL_PORT=587
EMAIL_ENCRYPTION=starttls
EMAIL_USERNAME=username@example.com
EMAIL_PASSWORD=your-password

# Optional settings
# EMAIL_ENCRYPTION_HOSTNAME=
# EMAIL_ALLOW_SELFSIGNED=false

# Common email settings
EMAIL_FROM=noreply@example.com
EMAIL_FROM_NAME=LibreChat

# Enable password reset functionality
ALLOW_PASSWORD_RESET=true
```

## Modifica indirizzo email [#email-address-change]

Gli utenti con un account locale (email e password) possono modificare autonomamente il proprio indirizzo email registrato da **Settings > Account**. La funzionalità è attiva per impostazione predefinita e richiede un sistema di invio email funzionante (Mailgun o SMTP, configurato sopra): in caso contrario, l'opzione rimane nascosta.

### Flusso utente [#user-flow]

1. In **Settings > Account**, accanto a **Email address**, l'utente seleziona **Change**.
2. Nella finestra di dialogo **Change email address**, inseriscono il **New email address** e la loro **Current password**, quindi selezionano **Send verification link**.
3. LibreChat invia innanzitutto un avviso di sicurezza ("Email change requested") all'indirizzo attuale, contenente l'indirizzo richiesto e l'IP della richiesta. Lo invia prima di verificare la password, in modo che il proprietario dell'account venga a conoscenza di ogni tentativo, inclusi quelli respinti. Se la richiesta supera i controlli sottostanti, un link di verifica viene inviato al nuovo indirizzo.
4. L'indirizzo cambia solo quando il link viene aperto. Sia il vecchio che il nuovo indirizzo ricevono quindi una notifica "Il tuo indirizzo email è stato modificato" e il nuovo indirizzo viene contrassegnato come verificato.

La richiesta viene rifiutata quando la password è errata, il nuovo indirizzo è uguale a quello attuale, il nuovo indirizzo appartiene già a un altro account o il suo dominio non è presente in [`registration.allowedDomains`](/docs/configuration/librechat_yaml/object_structure/registration#alloweddomains). Gli account che effettuano l'accesso tramite OAuth, OpenID Connect, SAML o LDAP non possono utilizzare questo flusso.

Il link di verifica è monouso e scade dopo `tokenTTLSeconds` (15 minuti per impostazione predefinita). Smette inoltre di funzionare se la password o l'email dell'account vengono modificate prima che venga aperto. Il completamento di una modifica invalida qualsiasi link di reimpostazione della password emesso per l'indirizzo precedente.

### Configurazione [#configuration]

<OptionTable
  options={[
    [
      'ALLOW_EMAIL_CHANGE',
      'boolean',
      'Consenti agli utenti con account locale di modificare il proprio indirizzo email. Abilitato se omesso. Sovrascritto da emailChange.enabled in librechat.yaml.',
      '# ALLOW_EMAIL_CHANGE=true',
    ],
  ]}
/>

In `librechat.yaml`, il blocco `emailChange` ha la precedenza su `ALLOW_EMAIL_CHANGE` e imposta anche la durata del link:

```yaml filename="librechat.yaml"
emailChange:
  enabled: true
  tokenTTLSeconds: 900 # 60 to 86400, default 900 (15 minutes)
```

Ogni campo ha un fallback indipendente: `enabled` su `ALLOW_EMAIL_CHANGE` e successivamente su `true`; `tokenTTLSeconds` su `900`. I limiti di frequenza (rate limits) per la richiesta di una modifica e per l'apertura dei link sono impostati in [`rateLimits.emailChange` e `rateLimits.emailChangeConfirm`](/docs/configuration/librechat_yaml/object_structure/config#ratelimits), oppure con le corrispondenti [variabili d'ambiente](/docs/configuration/dotenv#email-change-rate-limiting).

<Callout type="warning" title="Implementazioni multi-nodo">
Imposta `ALLOW_EMAIL_CHANGE=false` (o `emailChange.enabled: false`) finché ogni nodo non esegue una versione che include questa funzionalità. I nodi più vecchi emettono e accettano link di reimpostazione della password che non sono vincolati a un indirizzo, quindi un link in possesso del precedente proprietario di un indirizzo potrebbe sopravvivere alla modifica e reimpostare l'account rinominato.
</Callout>

## Risoluzione dei problemi [#troubleshooting]

### Problemi con Mailgun [#mailgun-issues]

1. **Autenticazione fallita**: Assicurati che la tua chiave API Mailgun sia corretta e disponga delle autorizzazioni di invio
2. **Dominio non trovato**: Verifica che il tuo dominio Mailgun sia configurato correttamente nel tuo account Mailgun
3. **Problemi con la regione UE**: Se il tuo account Mailgun si trova nella regione UE, assicurati di impostare `MAILGUN_HOST=https://api.eu.mailgun.net`
4. **Fallback a SMTP**: Se solo uno tra `MAILGUN_API_KEY` o `MAILGUN_DOMAIN` è impostato, il sistema passerà alla configurazione SMTP

### Problemi SMTP [#smtp-issues]

1. **Connection Refused**: Controlla se il tuo server consente connessioni SMTP in uscita sulla porta specificata
2. **Autenticazione fallita**: Verifica che il tuo nome utente e la tua password siano corretti
3. **Password dell'app Gmail**: Per Gmail, devi utilizzare una password specifica per l'app, non la tua password abituale
4. **Certificati autofirmati**: Se il tuo server di posta utilizza certificati autofirmati, imposta `EMAIL_ALLOW_SELFSIGNED=true`

### Problemi generali [#general-issues]

1. **Nessuna email inviata**: Controlla i log di LibreChat per eventuali messaggi di errore
2. **Ripristino password non protetto**: Si verifica quando né Mailgun né SMTP sono configurati correttamente
3. **Problemi con l'indirizzo mittente**: Assicurati che l'indirizzo `EMAIL_FROM` sia valido e autorizzato all'invio dal tuo servizio di posta.
