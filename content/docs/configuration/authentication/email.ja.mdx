## 一般的なセットアップ [#general-setup]

LibreChatは複数のメールプロバイダーをサポートしています：
- **Mailgun API** - SMTPポートをブロックするサーバーに推奨
- **SMTP サービス** - Gmail、Outlook、またはカスタムメールサーバーを使用した従来のメール送信

### 一般的な設定 [#common-configuration]

これらの変数は、MailgunとSMTPの両方で使用されます。

<OptionTable
  options={[

    ['EMAIL_FROM_NAME', 'string', '送信者名（設定されていない場合は APP_TITLE がデフォルトとして使用されます）。','EMAIL_FROM_NAME=LibreChat'],
  ]}
/>

### Mailgun 設定 (推奨) [#mailgun-configuration-recommended]

Mailgunは、スパム防止のためにSMTPポートをブロックしているサーバーへのデプロイにおいて特に有用です。`MAILGUN_API_KEY` と `MAILGUN_DOMAIN` の両方が設定されている場合、LibreChatはSMTPの代わりにMailgunを使用します。

  ]}

### SMTP 設定 [#smtp-configuration]

**基本設定**

定義済みのサービスを使用したい場合は、以下の変数のみを設定してください。
サポートされているメールサービスの詳細については、こちらを参照してください: https://nodemailer.com/smtp/well-known-services

<OptionTable
  options={[
    ['EMAIL_SERVICE', 'string', 'メールサービス（例：Gmail、Outlook）','EMAIL_SERVICE='],
    ['EMAIL_USERNAME', 'string', '認証用のユーザー名。','EMAIL_USERNAME='],
    ['EMAIL_PASSWORD', 'string', '認証用のパスワード。','EMAIL_PASSWORD='],
  ]}

**高度な設定**

汎用的なSMTPサービスを使用する場合や、定義済みのプロバイダーに対して高度な設定が必要な場合は、以下の変数も設定してください：

<OptionTable
  options={[
    ['EMAIL_HOST', 'string', 'メールサーバーホスト','EMAIL_HOST='],
    ['EMAIL_PORT', 'number', 'メールサーバーのポート。','EMAIL_PORT=25'],
    ['EMAIL_ENCRYPTION', 'string', '暗号化方式 (starttls, tls など)。','EMAIL_ENCRYPTION='],

  ]}
/>

<Callout type="warning" title="警告">
**Mailgun または SMTP のいずれかを適切に設定しなかった場合、LibreChat はセキュリティで保護されていないパスワードリセットを使用することになります！これにより、メールが送信されることなく、誰でも即座にサーバー上の任意のパスワードをリセットできるようになります！**
</Callout>

## Mailgun を使用したセットアップ [#setup-with-mailgun]

Mailgunをセットアップするには、以下の手順に従ってください：

1. [mailgun.com](https://www.mailgun.com/) で Mailgun アカウントにサインアップしてください。
2. Mailgunダッシュボードでドメインを追加し、検証します
3. API Keysセクションに移動し、Private API keyをコピーしてください。
4. `.env` ファイル内の変数を次のように変更します：

<OptionTable
  options={[    
    ['MAILGUN_API_KEY', 'string', 'MailgunのプライベートAPIキー', 'MAILGUN_API_KEY=your-mailgun-api-key'],
    ['MAILGUN_DOMAIN', 'string', '検証済みのMailgunドメイン', 'MAILGUN_DOMAIN=mg.yourdomain.com'],
    ['EMAIL_FROM', 'string', '送信元メールアドレス', 'EMAIL_FROM=noreply@yourdomain.com'],
    ['EMAIL_FROM_NAME', 'string', '送信者名', 'EMAIL_FROM_NAME=LibreChat'],
    ['MAILGUN_HOST', 'string', '（オプション）EU地域向け', 'MAILGUN_HOST=https://api.eu.mailgun.net'],
  ]}
/>

<Callout type="info" title="注記">
MailgunアカウントがEUリージョンにある場合は、`MAILGUN_HOST=https://api.eu.mailgun.net` を設定するようにしてください。
</Callout>

## Gmailでのセットアップ [#setup-with-gmail]

Gmailをセットアップするには、以下の手順に従ってください：

1. Googleアカウントを作成し、2段階認証を有効にします。
2. **[Google アカウント設定](https://myaccount.google.com/)**で、「セキュリティ」タブをクリックし、「2 段階認証プロセス」を開きます。
3. 下にスクロールして「App passwords」を開きます。アプリに「Mail」を選択し、デバイスに「Other」を選択してから、任意の名前を付けます。
4. 「Generate」をクリックしてパスワードを作成し、生成されたパスワードをコピーします。
5. `.env` ファイル内の変数を次のように変更します：

<OptionTable
  options={[    
    ['EMAIL_SERVICE', 'string', 'Gmail', 'EMAIL_SERVICE=gmail'],
    ['EMAIL_USERNAME', 'string', 'メールアドレス', 'EMAIL_USERNAME=your-email'],
    ['EMAIL_PASSWORD', 'string', 'あなたのメールパスワード', 'EMAIL_PASSWORD=your-email-password'],
    ['EMAIL_FROM', 'string', '送信元フィールドに使用するメールアドレス（例: noreply@librechat.ai）', 'EMAIL_FROM=noreply@librechat.ai'],
    ['EMAIL_FROM_NAME', 'string', '私のLibreChatサーバー', 'EMAIL_FROM_NAME=LibreChat'],
  ]}
/>

## 完全な設定例 [#complete-configuration-examples]

### 例 1: Mailgun の設定 [#example-1-mailgun-configuration]

```bash
# ===================================
# Email Configuration - Mailgun
# ===================================
# Mailgun is recommended for servers that block SMTP ports

# Required Mailgun settings
MAILGUN_API_KEY=your-mailgun-api-key
MAILGUN_DOMAIN=mg.yourdomain.com

# Optional: For EU region
# MAILGUN_HOST=https://api.eu.mailgun.net

# Common email settings
EMAIL_FROM=noreply@yourdomain.com
EMAIL_FROM_NAME=LibreChat

# Enable password reset functionality
ALLOW_PASSWORD_RESET=true
```

### 例 2: Gmail SMTP 設定 [#example-2-gmail-smtp-configuration]

```bash
# ===================================
# Email Configuration - Gmail SMTP
# ===================================
# Traditional SMTP configuration

# Gmail service configuration
EMAIL_SERVICE=gmail
EMAIL_USERNAME=your-email@gmail.com
EMAIL_PASSWORD=your-app-password

# Common email settings
EMAIL_FROM=your-email@gmail.com
EMAIL_FROM_NAME=LibreChat

# Enable password reset functionality
ALLOW_PASSWORD_RESET=true
```

### 例 3: カスタム SMTP サーバーの設定 [#example-3-custom-smtp-server-configuration]

```bash
# ===================================
# Email Configuration - Custom SMTP
# ===================================
# For custom mail servers

# SMTP server details
EMAIL_HOST=smtp.example.com
EMAIL_PORT=587
EMAIL_ENCRYPTION=starttls
EMAIL_USERNAME=username@example.com
EMAIL_PASSWORD=your-password

# Optional settings
# EMAIL_ENCRYPTION_HOSTNAME=
# EMAIL_ALLOW_SELFSIGNED=false

# Common email settings
EMAIL_FROM=noreply@example.com
EMAIL_FROM_NAME=LibreChat

# Enable password reset functionality
ALLOW_PASSWORD_RESET=true
```

## メールアドレスの変更 [#email-address-change]

ローカル（メールアドレスとパスワード）アカウントを持つユーザーは、**Settings > Account** から自身で登録済みメールアドレスを変更できます。この機能はデフォルトで有効になっていますが、動作するメール配信（上記で設定したMailgunまたはSMTP）が必要です。メール配信が設定されていない場合、このオプションは非表示になります。

### ユーザーフロー [#user-flow]

1. **Settings > Account** の **Email address** の横にある **Change** を選択します。
2. **Change email address** ダイアログで、**New email address** と **Current password** を入力し、**Send verification link** を選択します。
3. LibreChatはまず、現在のメールアドレスに対して、リクエストされた新しいアドレスとリクエスト元のIPアドレスを記載したセキュリティ通知（「Email change requested」）を送信します。これはパスワードの確認前に行われるため、アカウント所有者は拒否された試行を含め、すべての試行について通知を受け取ります。リクエストが以下のチェックを通過した場合、新しいアドレス宛に確認リンクが送信されます。
4. アドレスはリンクが開かれたときにのみ変更されます。その後、旧アドレスと新アドレスの両方に「Your email address was changed」という通知が届き、新アドレスが検証済みとしてマークされます。

パスワードが間違っている場合、新しいアドレスが現在のアドレスと同じである場合、新しいアドレスが既に別のアカウントに登録されている場合、またはそのドメインが [`registration.allowedDomains`](/docs/configuration/librechat_yaml/object_structure/registration#alloweddomains) に含まれていない場合、リクエストは拒否されます。OAuth、OpenID Connect、SAML、または LDAP を通じてサインインするアカウントは、このフローを使用できません。

確認リンクは1回限り有効で、`tokenTTLSeconds`（デフォルトでは15分）が経過すると期限切れになります。また、リンクを開く前にアカウントのパスワードやメールアドレスが変更された場合も無効になります。変更を完了すると、以前のアドレスに対して発行されたパスワードリセットリンクはすべて無効になります。

### 設定 [#configuration]

<OptionTable
  options={[
    [
      'ALLOW_EMAIL_CHANGE',
      'boolean',
      'ローカルアカウントのユーザーがメールアドレスを変更できるようにします。省略時は有効になります。librechat.yamlのemailChange.enabledによって上書きされます。',
      '# ALLOW_EMAIL_CHANGE=true',
    ],
  ]}
/>

`librechat.yaml` 内の `emailChange` ブロックは、`ALLOW_EMAIL_CHANGE` よりも優先され、リンクの有効期間も設定します：

```yaml filename="librechat.yaml"
emailChange:
  enabled: true
  tokenTTLSeconds: 900 # 60 to 86400, default 900 (15 minutes)
```

各フィールドは個別にフォールバックします。`enabled` は `ALLOW_EMAIL_CHANGE` に、その後 `true` にフォールバックします。`tokenTTLSeconds` は `900` にフォールバックします。変更リクエストおよびリンクを開くためのレート制限は、[`rateLimits.emailChange` および `rateLimits.emailChangeConfirm`](/docs/configuration/librechat_yaml/object_structure/config#ratelimits) で設定するか、対応する [環境変数](/docs/configuration/dotenv#email-change-rate-limiting) を使用して設定します。

<Callout type="warning" title="マルチノードのロールアウト">
すべてのノードがこの機能を含むバージョンで実行されるまで、`ALLOW_EMAIL_CHANGE=false`（または `emailChange.enabled: false`）を設定してください。古いノードはアドレスに紐付けられていないパスワードリセットリンクを発行および承認するため、アドレスの以前の所有者が保持しているリンクが変更後も有効なままとなり、名前が変更されたアカウントをリセットできてしまう可能性があります。
</Callout>

## トラブルシューティング [#troubleshooting]

### Mailgun に関する問題 [#mailgun-issues]

1. **認証失敗**: Mailgun APIキーが正しいこと、および送信権限が付与されていることを確認してください
2. **ドメインが見つかりません**: MailgunアカウントでMailgunドメインが正しく設定されていることを確認してください。
3. **EUリージョンの問題**: MailgunアカウントがEUリージョンにある場合は、`MAILGUN_HOST=https://api.eu.mailgun.net` を設定するようにしてください。
4. **SMTPへのフォールバック**: `MAILGUN_API_KEY` または `MAILGUN_DOMAIN` のいずれかのみが設定されている場合、システムはSMTP設定にフォールバックします。

### SMTPに関する問題 [#smtp-issues]

1. **Connection Refused**: 指定されたポートでサーバーがアウトバウンドSMTP接続を許可しているか確認してください
2. **Authentication Failed**: ユーザー名とパスワードが正しいことを確認してください
3. **Gmail App Password**: Gmailの場合、通常のパスワードではなく、アプリパスワードを使用する必要があります。
4. **自己署名証明書**: メールサーバーが自己署名証明書を使用している場合は、`EMAIL_ALLOW_SELFSIGNED=true` を設定してください。

### 一般的な問題 [#general-issues]

1. **メールが送信されない場合**: LibreChatのログでエラーメッセージを確認してください
2. **パスワードリセットの未保護**: これは、MailgunまたはSMTPのいずれも適切に設定されていない場合に発生します。
3. **From アドレスの問題**: `EMAIL_FROM` アドレスが有効であり、ご利用のメールサービスから送信する権限があることを確認してください。
