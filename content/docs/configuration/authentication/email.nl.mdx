## Algemene configuratie [#general-setup]

LibreChat ondersteunt meerdere e-mailproviders:
- **Mailgun API** - Aanbevolen voor servers die SMTP-poorten blokkeren
- **SMTP-services** - Traditionele e-mailverzending via Gmail, Outlook of aangepaste mailservers

### Algemene configuratie [#common-configuration]

Deze variabelen worden gebruikt door zowel Mailgun als SMTP:

### Mailgun Configuratie (Aanbevolen) [#mailgun-configuration-recommended]

Mailgun is bijzonder nuttig voor implementaties op servers die SMTP-poorten blokkeren om spam te voorkomen. Wanneer zowel `MAILGUN_API_KEY` als `MAILGUN_DOMAIN` zijn ingesteld, zal LibreChat Mailgun gebruiken in plaats van SMTP.

## Setup met Mailgun [#setup-with-mailgun]

Volg deze stappen om Mailgun in te stellen:

1. Meld je aan voor een Mailgun-account op [mailgun.com](https://www.mailgun.com/)
2. Voeg je domein toe en verifieer het in het Mailgun-dashboard
3. Navigeer naar de sectie API Keys en kopieer je Private API key
4. Wijzig de variabelen in het `.env` bestand als volgt:

<OptionTable
  options={[    
    ['MAILGUN_API_KEY', 'string', 'Uw Mailgun private API key', 'MAILGUN_API_KEY=your-mailgun-api-key'],
    ['MAILGUN_DOMAIN', 'string', 'Uw geverifieerde Mailgun-domein', 'MAILGUN_DOMAIN=mg.yourdomain.com'],
    ['EMAIL_FROM', 'string', 'E-mailadres van afzender', 'EMAIL_FROM=noreply@yourdomain.com'],
    ['EMAIL_FROM_NAME', 'string', 'Afzender naam', 'EMAIL_FROM_NAME=LibreChat'],
    ['MAILGUN_HOST', 'string', '(Optioneel) Voor de EU-regio', 'MAILGUN_HOST=https://api.eu.mailgun.net'],
  ]}
/>

<Callout type="info" title="Let op">
Als uw Mailgun-account zich in de EU-regio bevindt, zorg er dan voor dat u `MAILGUN_HOST=https://api.eu.mailgun.net` instelt.
</Callout>

## Instellen met Gmail [#setup-with-gmail]

Volg deze stappen om Gmail in te stellen:

1. Maak een Google-account aan en schakel 2-stapsverificatie in.
2. Klik in de **[Google Account settings](https://myaccount.google.com/)** op het tabblad "Beveiliging" en open "Tweestapsverificatie."
3. Scroll naar beneden en open "App passwords." Kies "Mail" voor de app en selecteer "Other" voor het apparaat, geef het vervolgens een willekeurige naam.
4. Klik op "Generate" om een wachtwoord aan te maken en kopieer het gegenereerde wachtwoord.
5. Wijzig de variabelen in het `.env` bestand als volgt:

<OptionTable
  options={[    
    ['EMAIL_SERVICE', 'string', 'gmail', 'EMAIL_SERVICE=gmail'],
    ['EMAIL_USERNAME', 'string', 'je-e-mail', 'EMAIL_USERNAME=your-email'],
    ['EMAIL_PASSWORD', 'string', 'je-e-mailwachtwoord', 'EMAIL_PASSWORD=your-email-password'],
    ['EMAIL_FROM', 'string', 'e-mailadres voor het van-veld, bijv. noreply@librechat.ai', 'EMAIL_FROM=noreply@librechat.ai'],
    ['EMAIL_FROM_NAME', 'string', 'Mijn LibreChat-server', 'EMAIL_FROM_NAME=LibreChat'],
  ]}
/>

## Volledige configuratievoorbeelden [#complete-configuration-examples]

### Voorbeeld 1: Mailgun-configuratie [#example-1-mailgun-configuration]

```bash
# ===================================
# Email Configuration - Mailgun
# ===================================
# Mailgun is recommended for servers that block SMTP ports

# Required Mailgun settings
MAILGUN_API_KEY=your-mailgun-api-key
MAILGUN_DOMAIN=mg.yourdomain.com

# Optional: For EU region
# MAILGUN_HOST=https://api.eu.mailgun.net

# Common email settings
EMAIL_FROM=noreply@yourdomain.com
EMAIL_FROM_NAME=LibreChat

# Enable password reset functionality
ALLOW_PASSWORD_RESET=true
```

### Voorbeeld 2: Gmail SMTP-configuratie [#example-2-gmail-smtp-configuration]

```bash
# ===================================
# Email Configuration - Gmail SMTP
# ===================================
# Traditional SMTP configuration

# Gmail service configuration
EMAIL_SERVICE=gmail
EMAIL_USERNAME=your-email@gmail.com
EMAIL_PASSWORD=your-app-password

# Common email settings
EMAIL_FROM=your-email@gmail.com
EMAIL_FROM_NAME=LibreChat

# Enable password reset functionality
ALLOW_PASSWORD_RESET=true
```

### Voorbeeld 3: Aangepaste SMTP-serverconfiguratie [#example-3-custom-smtp-server-configuration]

```bash
# ===================================
# Email Configuration - Custom SMTP
# ===================================
# For custom mail servers

# SMTP server details
EMAIL_HOST=smtp.example.com
EMAIL_PORT=587
EMAIL_ENCRYPTION=starttls
EMAIL_USERNAME=username@example.com
EMAIL_PASSWORD=your-password

# Optional settings
# EMAIL_ENCRYPTION_HOSTNAME=
# EMAIL_ALLOW_SELFSIGNED=false

# Common email settings
EMAIL_FROM=noreply@example.com
EMAIL_FROM_NAME=LibreChat

# Enable password reset functionality
ALLOW_PASSWORD_RESET=true
```

## E-mailadres wijzigen [#email-address-change]

Gebruikers met een lokaal account (e-mailadres en wachtwoord) kunnen hun geregistreerde e-mailadres zelf wijzigen via **Settings > Account**. Deze functie staat standaard aan en vereist een werkende e-mailbezorging (Mailgun of SMTP, zoals hierboven geconfigureerd): zonder dit is de optie verborgen.

### Gebruikersstroom [#user-flow]

1. In **Settings > Account**, naast **Email address**, selecteert de gebruiker **Change**.
2. In het dialoogvenster **Change email address** voeren ze het **New email address** en hun **Current password** in en selecteren ze vervolgens **Send verification link**.
3. LibreChat stuurt eerst een beveiligingsmelding ("Email change requested") naar het huidige adres, met het aangevraagde adres en het IP-adres van het verzoek. Dit wordt verzonden voordat het wachtwoord wordt gecontroleerd, zodat de accounteigenaar op de hoogte wordt gesteld van elke poging, inclusief afgewezen pogingen. Als het verzoek aan de onderstaande controles voldoet, wordt er een verificatielink naar het nieuwe adres gestuurd.
4. Het adres verandert pas wanneer de link wordt geopend. Zowel het oude als het nieuwe adres ontvangen vervolgens een "Your email address was changed" melding, en het nieuwe adres wordt gemarkeerd als geverifieerd.

Het verzoek wordt afgewezen wanneer het wachtwoord onjuist is, het nieuwe adres gelijk is aan het huidige, het nieuwe adres al bij een ander account hoort, of het domein niet voorkomt in [`registration.allowedDomains`](/docs/configuration/librechat_yaml/object_structure/registration#alloweddomains). Accounts die inloggen via OAuth, OpenID Connect, SAML of LDAP kunnen deze procedure niet gebruiken.

De verificatielink is voor eenmalig gebruik en verloopt na `tokenTTLSeconds` (standaard 15 minuten). Deze werkt ook niet meer als het wachtwoord of het e-mailadres van het account wordt gewijzigd voordat de link wordt geopend. Het voltooien van een wijziging maakt alle wachtwoordherstellinks ongeldig die voor het vorige adres zijn uitgegeven.

### Configuratie [#configuration]

<OptionTable
  options={[
    [
      'ALLOW_EMAIL_CHANGE',
      'boolean',
      'Sta toe dat gebruikers met een lokaal account hun e-mailadres wijzigen. Ingeschakeld wanneer weggelaten. Overschreven door emailChange.enabled in librechat.yaml.',
      '# ALLOW_EMAIL_CHANGE=true',
    ],
  ]}
/>

In `librechat.yaml` krijgt het `emailChange` blok voorrang op `ALLOW_EMAIL_CHANGE` en stelt het ook de levensduur van de link in:

```yaml filename="librechat.yaml"
emailChange:
  enabled: true
  tokenTTLSeconds: 900 # 60 to 86400, default 900 (15 minutes)
```

Elk veld valt onafhankelijk terug: `enabled` naar `ALLOW_EMAIL_CHANGE` en vervolgens naar `true`; `tokenTTLSeconds` naar `900`. Snelheidslimieten voor het aanvragen van een wijziging en voor het openen van links zijn ingesteld onder [`rateLimits.emailChange` en `rateLimits.emailChangeConfirm`](/docs/configuration/librechat_yaml/object_structure/config#ratelimits), of met de bijbehorende [omgevingsvariabelen](/docs/configuration/dotenv#email-change-rate-limiting).

<Callout type="warning" title="Multi-node uitrol">
Stel `ALLOW_EMAIL_CHANGE=false` (of `emailChange.enabled: false`) in totdat elk knooppunt een versie draait die deze functie bevat. Oudere knooppunten geven wachtwoordherstellinks uit en accepteren deze die niet aan een adres zijn gebonden, dus een link die in het bezit is van de vorige eigenaar van een adres zou de wijziging kunnen overleven en het hernoemde account kunnen resetten.
</Callout>

## Probleemoplossing [#troubleshooting]

### Mailgun problemen [#mailgun-issues]

1. **Authenticatie mislukt**: Zorg ervoor dat uw Mailgun API-sleutel correct is en over verzendrechten beschikt
2. **Domein niet gevonden**: Controleer of uw Mailgun-domein correct is geconfigureerd in uw Mailgun-account
3. **EU-regio problemen**: Als uw Mailgun-account zich in de EU-regio bevindt, zorg er dan voor dat u `MAILGUN_HOST=https://api.eu.mailgun.net` instelt.
4. **Terugvallen op SMTP**: Als slechts één van `MAILGUN_API_KEY` of `MAILGUN_DOMAIN` is ingesteld, zal het systeem terugvallen op de SMTP-configuratie

### SMTP-problemen [#smtp-issues]

1. **Connection Refused**: Controleer of uw server uitgaande SMTP-verbindingen op de opgegeven poort toestaat
2. **Authenticatie mislukt**: Controleer of uw gebruikersnaam en wachtwoord correct zijn
3. **Gmail App Password**: Voor Gmail moet je een app-specifiek wachtwoord gebruiken, niet je normale wachtwoord
4. **Zelfondertekende certificaten**: Als uw mailserver gebruikmaakt van zelfondertekende certificaten, stel dan `EMAIL_ALLOW_SELFSIGNED=true` in.

### Algemene problemen [#general-issues]

1. **Geen e-mails verzonden**: Controleer de LibreChat logs op foutmeldingen
2. **Onbeveiligde wachtwoordreset**: Dit gebeurt wanneer noch Mailgun, noch SMTP correct is geconfigureerd
3. **Problemen met het 'Van'-adres**: Zorg ervoor dat het `EMAIL_FROM`-adres geldig is en geautoriseerd is om te verzenden via uw e-mailservice
