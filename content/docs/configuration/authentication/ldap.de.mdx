Sie können einen Lightweight Directory Access Protocol (LDAP)-Authentifizierungsserver verwenden, um Benutzer zu authentifizieren.

## LDAP/AD Server Konfiguration [#ldapad-server-configuration]

**Grundlegende Konfiguration**

- `LDAP_URL` und `LDAP_USER_SEARCH_BASE` sind erforderlich.
- `LDAP_SEARCH_FILTER` ist optional; falls nicht angegeben, wird standardmäßig das Attribut `mail` verwendet. Falls angegeben, verwenden Sie das Literal `{{username}}`, um den angegebenen Benutzernamen für die Suche zu nutzen.

<OptionTable
  options={[
    ['LDAP_URL', 'string', 'LDAP-Server-URL.', 'LDAP_URL=ldap://localhost:389'],
    ['LDAP_BIND_DN', 'string', 'Bind-DN', 'LDAP_BIND_DN=cn=root'],
    ['LDAP_BIND_CREDENTIALS', 'string', 'Passwort für bindDN', 'LDAP_BIND_CREDENTIALS=password'],
    [
      'LDAP_USER_SEARCH_BASE',
      'string',
      'LDAP-Benutzersuchbasis',
      'LDAP_USER_SEARCH_BASE=o=users,o=example.com',
    ],
    ['LDAP_SEARCH_FILTER', 'string', 'LDAP-Suchfilter', 'LDAP_SEARCH_FILTER=mail={{username}}'],
  ]}
/>

**Feldzuordnungen**

Sie können eine Zuordnung zwischen den Attributen von LibreChat-Benutzern und denen von LDAP-Benutzern festlegen. Verwenden Sie diese Einstellungen, falls die Standardzuordnungen nicht ordnungsgemäß funktionieren.

<OptionTable
  options={[
    [
      'LDAP_ID',
      'string',
      'Geben Sie eine eindeutige Benutzer-ID an. Standardmäßig werden uid oder sAMAccountName, mail verwendet.',
      'LDAP_ID=uid',
    ],
    [
      'LDAP_USERNAME',
      'string',
      'Standardmäßig werden givenName oder mail verwendet.',
      'LDAP_USERNAME=givenName',
    ],
    [
      'LDAP_EMAIL',
      'string',
      'Standardmäßig wird mail verwendet.',
      'LDAP_EMAIL=userPrincipalName',
    ],
    [
      'LDAP_FULL_NAME',
      'string',
      'Standardmäßig wird eine Kombination aus givenName und surname verwendet.',
      'LDAP_FULL_NAME=givenName,surname',
    ],
  ]}
/>

**Benutzername oder E-Mail**

Standardmäßig verwendet LibreChat eine E-Mail-Adresse und ein Passwort zur Authentifizierung.
Dies kann manchmal zu Problemen mit LDAP führen und Sie möchten möglicherweise stattdessen einen Benutzernamen verwenden.
Setzen Sie `LDAP_SEARCH_FILTER`, um nach dem Benutzernamen zu filtern (z. B. `LDAP_SEARCH_FILTER=uid={{username}}`)
und konfigurieren Sie LibreChat so, dass die Anmeldung über den Benutzernamen angefordert wird:

<OptionTable
  options={[
    [
      'LDAP_LOGIN_USES_USERNAME',
      'boolean',
      'Benutzernamen anstelle von E-Mail verwenden.',
      'LDAP_LOGIN_USES_USERNAME=true',
    ],
  ]}
/>

**Active Directory über SSL**

Um eine Verbindung über SSL (ldaps://) herzustellen, etwa bei einem Unternehmen mit Windows AD, geben Sie den Pfad zum internen CA-Zertifikat mit `LDAP_CA_CERT_PATH` an.

`LDAP_TLS_REJECT_UNAUTHORIZED` wird nur angewendet, wenn `LDAP_CA_CERT_PATH` gesetzt ist. In diesem Fall ist die Zertifikatsprüfung **deaktiviert**, sofern Sie nicht explizit `LDAP_TLS_REJECT_UNAUTHORIZED=true` setzen. Wenn `LDAP_CA_CERT_PATH` nicht gesetzt ist, übergibt LibreChat keine TLS-Optionen, und das Standardverhalten von Node.js gilt (das Serverzertifikat wird gegen den Zertifikatsspeicher des Systems geprüft).

<Callout type="warning" title="Zertifikatsverifizierung aktivieren">
  Wenn Sie `LDAP_CA_CERT_PATH` setzen, ohne `LDAP_TLS_REJECT_UNAUTHORIZED=true` zu setzen, vertraut LibreChat jedem Zertifikat, das der LDAP-Server vorlegt. Dadurch sind Bind-Anmeldedaten und Benutzerpasswörter für Man-in-the-Middle-Angriffe angreifbar. Setzen Sie in Produktionsumgebungen immer `LDAP_TLS_REJECT_UNAUTHORIZED=true`.
</Callout>

<OptionTable
  options={[
    [
      'LDAP_CA_CERT_PATH',
      'string',
      'Pfad zum CA-Zertifikat.',
      'LDAP_CA_CERT_PATH=/path/to/root_ca_cert.crt',
    ],
    [
      'LDAP_TLS_REJECT_UNAUTHORIZED',
      'boolean',
      'Überprüfen Sie das LDAP-Serverzertifikat anhand von LDAP_CA_CERT_PATH. Muss auf true gesetzt sein, um die Überprüfung zu aktivieren; wird ignoriert, wenn LDAP_CA_CERT_PATH nicht gesetzt ist.',
      'LDAP_TLS_REJECT_UNAUTHORIZED=true',
    ],
  ]}
/>

**LDAP StartTLS**

Das Aktivieren von LDAP StartTLS ermöglicht es LibreChat, eine unsichere Verbindung auf eine sichere TLS-Verbindung zu aktualisieren. Dies ist nützlich, wenn Sie die Verbindung absichern möchten, ohne auf ldaps:// umzustellen.

<OptionTable
    options={[
        [
            'LDAP_STARTTLS',
            'boolean',
            'Aktiviere LDAP StartTLS für das Upgrade der Verbindung auf TLS. Auf true setzen, um diese Funktion zu aktivieren.',
            'LDAP_STARTTLS=true',
        ],
    ]}
/>
