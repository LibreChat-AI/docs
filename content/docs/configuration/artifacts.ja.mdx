このページでは、[Artifacts](/docs/features/artifacts) の管理者側について説明します。ユーザーは Agent Builder でエージェントごとに Artifacts を有効にします。ここでの設定によって、そのオプションが表示されるかどうか、およびプレビューの読み込み元が決まります。

## アーティファクトの有効化 [#enabling-artifacts]

アーティファクトはエージェントの機能です。`artifacts`は既定の[`endpoints.agents.capabilities`](/docs/configuration/librechat_yaml/object_structure/agents#capabilities)リストに含まれているため、独自のリストで除外しない限り利用できます。`capabilities`を上書きする場合は、Agent Builderでこのオプションを維持するために`artifacts`を含めてください。

エージェントを構築せずにモデルスペックのアーティファクトを設定するには、スペックに[`artifacts`](/docs/configuration/librechat_yaml/object_structure/model_specs#artifacts)を設定します。`true`を指定するとデフォルトモードが使用されます。モード名を指定することもできます: `default`、`shadcnui`、または`custom`。

## 新しいウィンドウでパネルを開く [#opening-the-panel-in-a-new-window]

パネルには**Open in new window**ボタンがあり、クリックするとパネルを別のブラウザウィンドウに切り離せます。この機能はデフォルトで有効です。埋め込みWebviewなど、ポップアップが動作しない環境でデプロイしている場合は、[`interface.artifactUndocking: false`](/docs/configuration/librechat_yaml/object_structure/interface#artifactundocking)を指定して無効にしてください。無効にしても、ドッキングされたパネルは引き続き動作します。

## Content-Security-Policy

LibreChat自体のCSPはHTTPSフレームを許可しているため、デフォルトのCodeSandboxバンドラーは変更なしで読み込まれます。LibreChatの前段にあるリバースプロキシやCDNが、より厳しい`Content-Security-Policy`を設定している場合は、`frame-src`にバンドラーのオリジンを許可してください。公開バンドラーの場合は`https://*.codesandbox.io`、自前でホストしている場合は自分のバンドラーのURLを指定します。LibreChatの組み込みポリシーを拡張するだけでよい場合は、`CSP_FRAME_SRC_EXTRA`を使用します。

React プレビューでは、`cdn.tailwindcss.com` から Tailwind も読み込まれるため、このホストがユーザーのブラウザから到達可能である必要があります。

## Sandpack バンドラーのセルフホスティング [#self-hosting-the-sandpack-bundler]

プレビューは [Sandpack](https://sandpack.codesandbox.io/) によってレンダリングされ、デフォルトでは CodeSandbox の公開 CDN からバンドラーを取得します。この CDN は利用状況のテレメトリも送信します。プライベートネットワーク、コンプライアンス要件、または外部サービスへの依存を排除するために、[バンドラーを自前でホストする](https://sandpack.codesandbox.io/docs/guides/hosting-the-bundler)ことができます。

[LibreChat-AI/codesandbox-client](https://github.com/LibreChat-AI/codesandbox-client) は、テレメトリリクエスト(コンテナイメージを含む)を削除した、LibreChat 向けに用意されたフォークです。

LibreChatは2つのバンドラーを使用します。`SANDPACK_BUNDLER_URL`はReactアーティファクトを提供し、`SANDPACK_STATIC_BUNDLER_URL`はHTML、SVG、Markdown、コード、Officeファイルのプレビューの背後にある静的テンプレートを提供します。セルフホスティングする場合は両方を設定してください。片方だけを設定すると、もう一方のアーティファクトタイプは公開CDNから読み込まれます。両方とも[`.env`リファレンス](/docs/configuration/dotenv#artifacts)に記載されています。Mermaidダイアグラムはページ内で直接レンダリングされるため、どちらのバンドラーも使用しません。

独自のバンドラーを実行する場合、CORS設定、セキュリティアップデート、ホスティングリソースの管理もご自身で行う必要があります。これらの変数を変更した後は、LibreChatを再起動してください。URLは起動時の設定で、ブラウザに送信されます。
