Hasilkan nilai acak yang aman secara kriptografis untuk rahasia yang diperlukan dalam file konfigurasi `.env` LibreChat Anda. Klik **Generate** lalu salin nilai satu per satu atau semuanya sekaligus.

<CredentialsGeneratorMDX />

## Rahasia sesi panel admin [#admin-panel-session-secret]

Jika Anda menjalankan [panel admin](/docs/features/admin_panel) yang disertakan dengan `docker-compose.yml` atau `deploy-compose.yml`, atur juga `ADMIN_PANEL_SESSION_SECRET` di `.env`. Generator tidak menghasilkannya. Ini adalah kunci enkripsi sesi dengan panjang minimal 32 karakter, dan container panel admin tidak akan mau berjalan tanpanya. Buat kunci tersebut di terminal:

```bash
openssl rand -hex 32
```
