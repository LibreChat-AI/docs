## Secret de session du panneau d'administration [#admin-panel-session-secret]

Si vous exécutez le [panneau d'administration](/docs/features/admin_panel) fourni avec `docker-compose.yml` ou `deploy-compose.yml`, définissez également `ADMIN_PANEL_SESSION_SECRET` dans `.env`. Le générateur ne le produit pas. Il s'agit d'une clé de chiffrement de session d'au moins 32 caractères, et le conteneur du panneau d'administration refuse de démarrer sans elle. Générez-la dans un terminal :

```bash
openssl rand -hex 32
```
