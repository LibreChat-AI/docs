## Admin panel session secret

If you run the bundled [admin panel](/docs/features/admin_panel) with `docker-compose.yml` or `deploy-compose.yml`, set `ADMIN_PANEL_SESSION_SECRET` in `.env` as well. The generator does not output it. It is a session encryption key of at least 32 characters, and the admin panel container refuses to start without it. Generate it in a terminal:

```bash
openssl rand -hex 32
```
