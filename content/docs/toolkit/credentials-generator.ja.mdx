LibreChat `.env` 設定ファイルに必要なシークレット用に、暗号学的に安全なランダム値を生成します。**Generate** をクリックし、個別の値またはすべての値を一度にコピーしてください。

## 管理パネルのセッションシークレット [#admin-panel-session-secret]

[admin panel](/docs/features/admin_panel) を `docker-compose.yml` または `deploy-compose.yml` で起動する場合は、`.env` に `ADMIN_PANEL_SESSION_SECRET` も設定してください。ジェネレーターはこの値を出力しません。これはセッション暗号化用のキーで、32文字以上が必要です。この値がないと、admin panel のコンテナは起動を拒否します。ターミナルで次のコマンドを実行して生成してください:

```bash
openssl rand -hex 32
```
