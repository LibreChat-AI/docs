## Pannello di amministrazione: segreto della sessione [#admin-panel-session-secret]

Se esegui il [pannello di amministrazione](/docs/features/admin_panel) incluso con `docker-compose.yml` o `deploy-compose.yml`, imposta anche `ADMIN_PANEL_SESSION_SECRET` nel file `.env`. Il generatore non lo produce. Si tratta di una chiave di crittografia della sessione di almeno 32 caratteri, e il container del pannello di amministrazione non si avvia senza di essa. Generala da un terminale:

```bash
openssl rand -hex 32
```
