## 管理面板会话密钥 [#admin-panel-session-secret]

如果你使用 `docker-compose.yml` 或 `deploy-compose.yml` 运行随附的[管理面板](/docs/features/admin_panel),请同时在 `.env` 中设置 `ADMIN_PANEL_SESSION_SECRET`。生成器不会输出该项。它是一个至少 32 个字符的会话加密密钥,缺少它时管理面板容器将拒绝启动。请在终端中生成:

```bash
openssl rand -hex 32
```
