## 관리자 패널 세션 시크릿 [#admin-panel-session-secret]

`docker-compose.yml` 또는 `deploy-compose.yml`로 번들된 [관리자 패널](/docs/features/admin_panel)을 실행하는 경우, `.env`에도 `ADMIN_PANEL_SESSION_SECRET`을 설정하십시오. 생성기는 이 값을 출력하지 않습니다. 이 값은 최소 32자 이상의 세션 암호화 키이며, 값이 없으면 관리자 패널 컨테이너가 시작되지 않습니다. 터미널에서 다음 명령으로 생성하십시오:

```bash
openssl rand -hex 32
```
