[Easypanel](https://easypanel.io) is a self-hosted Docker deployment platform, and LibreChat has a one-click deployment template there. The template provisions LibreChat alongside MongoDB, MeiliSearch, a pgvector-backed PostgreSQL instance, and the RAG API service.

## Steps

### **Install Easypanel**

[Install Easypanel](https://easypanel.io/docs/installation) on your own server, if you haven't already.

### **Click the "Deploy on Easypanel" button**

<p align="left">
    <a href="https://easypanel.io/templates/librechat">
        <img src="https://easypanel.io/img/deploy-on-easypanel-40.svg" alt="Deploy on Easypanel" height="40"/>
    </a>
</p>

### **Configure environment variables**

Review the generated environment variables for the LibreChat service. The template automatically provisions and wires up MongoDB, MeiliSearch, and the vector database, but you'll still want to add your own AI provider API keys. See [Environment Variables](/docs/configuration/dotenv) for details.

### **Deploy**

Click **Deploy**. Easypanel will build and start all five services.

### **Access your LibreChat instance**

Once the services are running, open the domain Easypanel assigns to the LibreChat service, register an account, and follow [Your First Chat](/docs/quick_start/first_chat) to add a model API key and send your first message.
