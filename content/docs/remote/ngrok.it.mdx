Per utilizzare ngrok per inoltrare il tuo server locale su internet, segui questi passaggi:

## Registrati [#sign-up]

1. Vai su **[https://ngrok.com/](https://ngrok.com/)** e registrati per un account.

## Installazione Docker [#docker-installation]

1. Copia il tuo auth token da: **[https://dashboard.ngrok.com/get-started/your-authtoken](https://dashboard.ngrok.com/get-started/your-authtoken)**
2. Apri un terminale ed esegui il seguente comando. All'interno del container ngrok, `localhost` si riferisce al container stesso, quindi il comando punta ngrok all'host Docker, dove LibreChat pubblica la porta 3080:

```bash
docker run -d -it --add-host=host.docker.internal:host-gateway -e NGROK_AUTHTOKEN=<your token> ngrok/ngrok http host.docker.internal:3080
```

Il flag `--add-host` è necessario su Linux; Docker Desktop su macOS e Windows risolve già `host.docker.internal`. Se esegui LibreChat con `deploy-compose.yml`, usa invece `host.docker.internal:80`.

## Installazione su Windows [#windows-installation]

1. Scarica il file ZIP da: **[https://ngrok.com/download](https://ngrok.com/download)**
2. Estrai il contenuto del file ZIP utilizzando 7zip o WinRar.
3. Esegui `ngrok.exe`.
4. Copia il tuo auth token da: **[https://dashboard.ngrok.com/get-started/your-authtoken](https://dashboard.ngrok.com/get-started/your-authtoken)**
5. Nel terminale `ngrok.exe`, esegui il seguente comando: `ngrok config add-authtoken <your token>`
6. Se non l'hai già fatto, avvia LibreChat normalmente.
7. Nel terminale `ngrok.exe`, esegui il seguente comando: `ngrok http 3080`

Vedrai un link che può essere utilizzato per accedere a LibreChat.

## Installazione su Linux [#linux-installation]

1. Copia il comando da: **[https://ngrok.com/download](https://ngrok.com/download)** scegliendo l'architettura **corretta**.
2. Esegui il comando nel terminale
3. Copia il tuo auth token da: **[https://dashboard.ngrok.com/get-started/your-authtoken](https://dashboard.ngrok.com/get-started/your-authtoken)**
4. esegui il seguente comando: `ngrok config add-authtoken <your token>`
5. Se non l'hai già fatto, avvia LibreChat normalmente.
6. esegui il seguente comando: `ngrok http 3080`

## Installazione su Mac [#mac-installation]

1. Scarica il file ZIP da: **[https://ngrok.com/download](https://ngrok.com/download)**
2. Estrai il contenuto del file ZIP utilizzando un'applicazione Mac adatta come Unarchiver.
3. Apri il Terminale.
4. Naviga verso la directory in cui hai estratto ngrok utilizzando il comando `cd`.
5. Esegui ngrok digitando `./ngrok`.
6. Copia il tuo auth token da: **[https://dashboard.ngrok.com/get-started/your-authtoken](https://dashboard.ngrok.com/get-started/your-authtoken)**
7. Nel terminale in cui hai eseguito ngrok, inserisci il seguente comando: `ngrok authtoken <your token>`
8. Se non l'hai già fatto, avvia LibreChat normalmente.
9. Nel terminale in cui hai eseguito ngrok, inserisci il seguente comando: `./ngrok http 3080`

## Aggiorna il tuo .env [#update-your-env]

Una volta che ngrok mostra il tuo URL pubblico, imposta `DOMAIN_CLIENT` e `DOMAIN_SERVER` nel file `.env` di LibreChat con quell'URL (ad esempio `https://example.ngrok-free.app`), quindi riavvia LibreChat in modo che i link, i cookie e i callback OAuth utilizzino l'indirizzo pubblico.
