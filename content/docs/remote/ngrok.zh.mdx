若要使用 ngrok 将本地服务器隧道映射到互联网，请按照以下步骤操作：

## 注册 [#sign-up]

1. 前往 **[https://ngrok.com/](https://ngrok.com/)** 并注册一个账户。

## Docker 安装 [#docker-installation]

1. 从以下地址复制您的 auth token：**[https://dashboard.ngrok.com/get-started/your-authtoken](https://dashboard.ngrok.com/get-started/your-authtoken)**
2. 打开终端并运行以下命令。在 ngrok 容器内,`localhost` 指向容器本身,因此该命令将 ngrok 指向 Docker 宿主机,即 LibreChat 发布端口 3080 的位置:

```bash
docker run -d -it --add-host=host.docker.internal:host-gateway -e NGROK_AUTHTOKEN=<your token> ngrok/ngrok http host.docker.internal:3080
```

在 Linux 上需要使用 `--add-host` 参数;macOS 和 Windows 上的 Docker Desktop 已经可以解析 `host.docker.internal`。如果你使用 `deploy-compose.yml` 运行 LibreChat,请改用 `host.docker.internal:80`。

## Windows 安装 [#windows-installation]

1. 从以下地址下载 ZIP 文件：**[https://ngrok.com/download](https://ngrok.com/download)**
2. 使用 7zip 或 WinRar 解压 ZIP 文件的内容。
3. 运行 `ngrok.exe`。
4. 从以下地址复制您的 auth token：**[https://dashboard.ngrok.com/get-started/your-authtoken](https://dashboard.ngrok.com/get-started/your-authtoken)**
5. 在 `ngrok.exe` 终端中，运行以下命令：`ngrok config add-authtoken <your token>`
6. 如果您尚未执行此操作，请正常启动 LibreChat。
7. 在 `ngrok.exe` 终端中，运行以下命令：`ngrok http 3080`

您将看到一个可用于访问 LibreChat 的链接。

## Linux 安装 [#linux-installation]

1. 从 **[https://ngrok.com/download](https://ngrok.com/download)** 复制命令，并选择**正确**的架构。
2. 在终端中运行该命令
3. 从以下地址复制您的 auth token：**[https://dashboard.ngrok.com/get-started/your-authtoken](https://dashboard.ngrok.com/get-started/your-authtoken)**
4. 运行以下命令：`ngrok config add-authtoken <your token>`
5. 如果您尚未执行此操作，请正常启动 LibreChat。
6. 运行以下命令：`ngrok http 3080`

## Mac 安装 [#mac-installation]

1. 从以下地址下载 ZIP 文件：**[https://ngrok.com/download](https://ngrok.com/download)**
2. 使用合适的 Mac 应用程序（如 Unarchiver）解压 ZIP 文件内容。
3. 打开终端。
4. 使用 `cd` 命令导航到你解压 ngrok 的目录。
5. 通过输入 `./ngrok` 来运行 ngrok。
6. 从以下地址复制您的 auth token：**[https://dashboard.ngrok.com/get-started/your-authtoken](https://dashboard.ngrok.com/get-started/your-authtoken)**
7. 在运行 ngrok 的终端中，输入以下命令：`ngrok authtoken <your token>`
8. 如果您尚未执行此操作，请正常启动 LibreChat。
9. 在运行 ngrok 的终端中，输入以下命令：`./ngrok http 3080`

## 更新你的 .env [#update-your-env]

一旦 ngrok 显示您的公共 URL,请将 LibreChat 的 `.env` 文件中的 `DOMAIN_CLIENT` 和 `DOMAIN_SERVER` 设置为该 URL(例如 `https://example.ngrok-free.app`),然后重启 LibreChat,以便链接、Cookie 和 OAuth 回调使用公共地址。
