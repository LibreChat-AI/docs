消息编辑器是每个聊天界面底部的输入框。除了文本输入区域外，它还包含一个 **+** 按钮，用于打开你可以添加到消息中的所有内容（文件、工具、技能、MCP 服务器以及你之前上传的文件），以及当前已启用的工具的快捷选项卡，还有用于推理、听写和发送的控件。

## 组合框中有什么 [#whats-on-the-composer]

| 元素 | 功能 |
|---|---|
| **+** (**附件与工具**) | 打开面板：包含上传选项、工具、技能、MCP 服务器以及您最近的文件，所有内容均可通过一个字段进行搜索。 |
| 工具卡片 (Tool chips) | 每个已启用的工具或 MCP 服务器对应一张卡片，位于 **+** 按钮旁边。移除卡片即可关闭该工具。 |
| 暂存上下文 (Staged context) | 附加到您下一条消息的文件、引用和技能，显示在文本输入框上方。 |
| **思考** | 为支持该功能的模型提供推理能力。 |
| 上下文使用量 | 在 Token 使用量可用时，显示对话占用了模型上下文窗口的比例。 |
| **使用麦克风** | 在启用语音转文字功能时，通过语音输入您的消息。 |
| 发送 / 停止 | 发送消息，或停止正在生成的响应。 |

To see which keys apply right now, such as `/ for prompts`, `@ for models` or `Enter to send`, turn on **Show composer tips** in **Settings > General**. A one-line tip then appears under the text field. It is off by default.

## 添加文件 [#add-files]

点击 **+** 并在 **Attach** 部分选择一个选项。你也可以将文件拖拽到输入框中或直接粘贴。

默认情况下，LibreChat 使用统一上传器：您只需选择一个来源，它会根据文件类型和 endpoint 决定每个文件如何到达模型（原生提供商上传、文本提取或诸如 File Search 之类的工具）。

| 选项 | 出现时机 |
|---|---|
| **From Local Computer** | 始终出现，使用默认上传器。 |
| **From SharePoint** | 当启用了 [SharePoint file picker](/docs/configuration/sharepoint) 时。 |

如果管理员设置了 [`fileConfig.legacyFileUploadUX: true`](/docs/configuration/librechat_yaml/object_structure/file_config#legacyfileuploadux)，您将需要自行选择上传目标。此时，**Attach**（附件）部分会优先显示主要选项，并将其余选项折叠在 **More upload options**（更多上传选项）之下：

| 选项 | 出现时机 |
|---|---|
| **Upload to Provider** | 提供商直接接受文档（例如 OpenAI、Anthropic、Google、Bedrock、OpenRouter 和自定义 endpoint，或启用了 Responses API 的 Azure OpenAI）。 |
| **Upload Image** | 当提供商仅接受图像时，显示此选项以代替 **Upload to Provider**。 |
| **Upload as Text** | 已启用 [context capability](/docs/features/upload_as_text)。 |
| **Upload for File Search** | 已启用 File Search 且当前 agent 允许使用。选择此项也会开启 File Search。 |
| **Upload to Code Environment** | 已启用代码执行且当前 agent 允许使用。选择此项也会开启 **Run Code**。 |
| **Attach Files** | Assistants endpoint，通过 assistant 自身的配置来处理文件。 |

当在此模式下启用 SharePoint 时，每个选项也都有一个 SharePoint 版本，例如标记为 **Upload to Provider (From SharePoint)**。

### 重复使用之前上传的文件 [#reuse-a-file-you-uploaded-before]

面板的 **Your files** 部分列出了您最近使用的文件。选择一个文件即可再次附加，无需重新上传。在搜索栏中输入内容，即可按名称搜索您的所有文件。

在相应部分选择 **Show all**，即可在对话框中浏览所有文件。该对话框包含 **All**（全部）、**Images**（图片）和 **Documents**（文档）视图，并提供搜索栏以及图片和 PDF 的预览功能。

调色板最多显示五个最近使用的文件。管理员可以使用 [`interface.composerRecentFiles`](/docs/configuration/librechat_yaml/object_structure/interface#composerrecentfiles) 来降低该数量，或将其设置为 `0` 以隐藏列表。

## 启用工具、技能和 MCP 服务器 [#turn-on-tools-skills-and-mcp-servers]

调色板列出了您可以为当前对话开启的所有内容，并按部分进行了分组：

- **Tools**: 内置工具，例如 **Web Search**、**Run Code**、**File Search**、**Skills**、**Memory** 和 **Artifacts**，每项工具仅在启用且您拥有访问权限时才会显示。
- **Skills**: 您可以附加到下一条消息中的单个 [skills](/docs/features/skills)。
- **MCP Servers**: 聊天中可用的 [MCP servers](/docs/features/mcp)。

选择一个工具或 MCP 服务器以将其开启或关闭。面板会保持打开状态，因此您可以在一次访问中切换多个工具。每个已开启的工具都会在输入框中显示为一个标签（chip）；移除该标签即可将其关闭。部分标签带有模式菜单，例如 **Artifacts** 生成模式。

选择一个技能会将其暂存以供下一条消息使用：它会出现在 [staged context](#staged-context) 中，而不是以卡片（chip）的形式显示。

MCP 服务器行显示每个服务器的连接状态。选择一个未连接的服务器将启动其连接（如果服务器需要，包括 OAuth 登录），或者在需要您的凭据时首先打开其配置。连接后，需要用户凭据的服务器在行中也会有一个 **Configure** 控件，而 **Web Search** 则有一个用于其 API 密钥的控件。

<Callout type="info" title="Agent 可以自带工具">
  当选中一个 agent 时，**Tools** 和 **MCP Servers** 部分会被隐藏，因为 agent 自身的配置决定了它使用哪些工具。在其他 endpoint 上，带有 `hideBadgeRow: true` 的 [model spec](/docs/configuration/librechat_yaml/object_structure/model_specs#hidebadgerow) 会隐藏 **Tools**、**Skills** 和 **MCP Servers** 部分。**Attach** 和 **Your files** 在任何情况下都保持可用。
</Callout>

### 显示全部 [#show-all]

调色板在每个部分显示少量行。在 **Skills**、**MCP Servers** 或 **Your files** 标题上选择 **Show all**，即可打开一个包含完整列表、搜索字段和过滤器的对话框。Skills 和 MCP servers 具有三种视图：**All**、**Made by you** 和 **Favorites**。

### 收藏与置顶工具 [#favorites-and-pinned-tools]

点击行旁边的星号将其添加到**收藏夹**，收藏夹位于面板顶部。选中某一行后，按下 <kbd>Ctrl</kbd>+<kbd>D</kbd>（macOS 上为 <kbd>Cmd</kbd>+<kbd>D</kbd>）即可收藏或取消收藏。收藏内容会保存到您的账户中。

管理员可以使用 [`interface.defaultPinnedTools`](/docs/configuration/librechat_yaml/object_structure/interface#defaultpinnedtools) 来固定内置工具。即使工具处于关闭状态，固定的工具也会在输入框（composer）上保留其图标（chip），因此您可以一键将其开启。移除处于关闭状态的固定工具的图标即可取消固定。

## 分阶段上下文 [#staged-context]

在您发送下一条消息之前，所有附加的内容都会显示在文本框上方：

- **文件**，支持上传进度显示和图片预览。长文本粘贴也可以作为文件存放在此处，您可以对其进行编辑或将其移回消息中。
- **引用**您从之前的消息中选择的内容。
- **Skills**，即你从面板中选择或通过 `$` 命令选取的技能。

使用移除按钮移除任何项目。所有暂存的内容都将随您的下一条消息一起发送。

## 思考与努力 [#thinking-and-effort]

对于具有推理设置的模型，**Thinking**（思考）控件会打开一个从 **Faster**（更快）到 **Smarter**（更智能）的滑块，此外还包括提供商的独立模式，如 **Auto**（自动）或关闭。它会更改与“参数”面板相同的参数，因此当模型没有推理设置，或者部署通过 `interface.parameters` 关闭参数时，该控件将被隐藏。

## 在响应流式传输时进行排队和引导 [#queue-and-steer-while-a-response-streams]

当响应正在流式传输时，您可以继续输入。根据 endpoint 和您的设置，按下 <kbd>Enter</kbd> 键要么会将消息排队以在响应结束后发送，要么会引导智能体的当前响应。输入框提示会显示 <kbd>Enter</kbd> 键在当前时刻执行的操作。

排队的消息会显示在输入框上方的 **Queued messages** 栏中，您可以在此处：

- **编辑消息**以将其移回文本框。
- **Remove message** 以将其从队列中移除。
- **Send now** 以立即发送，无需等待。
- 通过拖拽消息，或聚焦某条消息并使用上下箭头键，可以重新排序消息。

有关 steering 的工作原理及其可用时间，请参阅 [Steering and Queued Messages](/docs/features/agents#steering-and-queued-messages)。

## 键盘快捷键 [#keyboard-shortcuts]

### 在文本框中 [#in-the-text-field]

| 键位 | 操作 |
|---|---|
| <kbd>Enter</kbd> | 发送消息（在响应流式传输时排队或引导）。 |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | 换行。 |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) | 在响应流式传输时：执行替代操作，当 <kbd>Enter</kbd> 为排队时**立即发送**，或当 <kbd>Enter</kbd> 为引导时**排队**。 |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> (<kbd>Option</kbd>+<kbd>Enter</kbd>) | 在智能体响应时：中断并发送（如果可用）。 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>) | 停止响应。 |
| `/` | 插入保存的提示词。 |
| `@` | 切换到其他模型、预设或智能体。 |
| `+` | 添加模型或预设以获取额外响应。 |
| `$` | 为下一条消息选择技能。 |

如果您关闭了 **按回车键发送消息**，<kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) 将用于发送消息，而 <kbd>Enter</kbd> 将用于换行。

### 在调色板中 [#in-the-palette]

| 键位 | 操作 |
|---|---|
| Type | 搜索工具、技能、服务器、上传选项和文件。 |
| <kbd>↑</kbd> / <kbd>↓</kbd> | 在行之间移动。 |
| <kbd>Enter</kbd> | 选择高亮显示的行。 |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd>) | 将高亮显示的行添加到收藏夹，或将其移除。 |
| <kbd>Backspace</kbd> (在搜索框为空时) | 关闭面板。 |
| <kbd>Escape</kbd> | 关闭面板。 |
