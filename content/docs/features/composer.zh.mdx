输入框是每个聊天底部的文本框。文本框旁边有一个用于文件、工具、技能和 MCP 服务器的 **+** 按钮，每个已启用的工具都会显示一个标签，另外还有推理强度、语音输入和发送的控件。

点击 **+**(屏幕阅读器会朗读为 **Attach and tools**)打开面板。面板中的所有内容都可以通过顶部的搜索框进行搜索,因此输入几个字母通常比滚动查找更快。

## 添加文件 [#add-files]

在 **Attach** 部分选择 **From Local Computer**,或将文件拖放到输入框中,或直接粘贴。LibreChat 会根据文件类型和端点决定每个文件如何传递给模型(直接发送给提供商、提取为文本,或为 File Search 建立索引),因此您只需选择文件的来源。当管理员已连接 SharePoint 时,**From SharePoint** 会显示在它旁边。

有些部署使用旧版上传器,由您自行选择上传目标:**上传至提供商**(对于仅支持图片的提供商则为**上传图片**)、**以文本形式上传**、**上传用于文件搜索**以及**上传至代码环境**。第一个选项会直接显示,其余选项则位于**更多上传选项**之后。选择**上传用于文件搜索**或**上传至代码环境**也会同时启用该工具。

### 重复使用之前上传的文件 [#reuse-a-file-you-uploaded-before]

**你的文件**面板中会列出你最近使用过的文件(默认显示五个)。选择某个文件即可重新附加,无需再次上传。在搜索框中输入内容,可按名称搜索你的所有文件。点击**显示全部**会打开一个对话框,其中列出所有文件,并分为**全部**、**图片**和**文档**三个标签页,图片和 PDF 文件可预览。

## 启用工具、技能和 MCP 服务器 [#turn-on-tools-skills-and-mcp-servers]

在 **Attach** 下方,调色板将可添加到对话中的内容进行了分组:

- **工具**:内置工具,例如 **网络搜索**、**运行代码**、**文件搜索**、**技能**、**记忆** 和 **Artifacts**。您只会看到已启用且您有权访问的工具。
- **Skills**：将要附加到下一条消息的[技能](/docs/features/skills)。
- **MCP 服务器**:聊天中可用的 [MCP 服务器](/docs/features/mcp),每个服务器均显示其连接状态。

选择工具或 MCP 服务器即可将其开启或关闭,选择面板保持打开状态,因此您可以一次切换多个。每个已开启的工具都会在输入框上显示一个标签;移除该标签即可将其关闭。部分标签带有自己的菜单,例如 **Artifacts** 的生成模式。

选择技能的方式有所不同:它会被暂存,用于您的下一条消息(参见[暂存上下文](#staged-context)),而不会变成一个标签。

如果某个 MCP 服务器尚未连接,选择它即可启动连接,若该服务器需要,还会包括 OAuth 登录。需要您自行提供凭据的服务器会先请求您输入凭据,之后每一行上都会保留一个 **Configure** 按钮,方便您随时修改这些凭据。

当选择了智能体时,**Tools**(工具)和 **MCP Servers**(MCP 服务器)部分会隐藏,因为智能体自身的配置决定了它使用哪些工具。Assistants 的情况也是如此。

### 显示全部与收藏 [#show-all-and-favorites]

每个部分最多显示五行。点击 **Skills**、**MCP Servers** 或 **Your files** 标题上的 **Show all** 可打开完整列表,其中包含搜索和筛选功能;技能和服务器可以进一步筛选为 **Made by you** 或 **Favorites**。

要收藏某一行,请先选中该行,然后按 <kbd>Ctrl</kbd>+<kbd>D</kbd>(macOS 上为 <kbd>Cmd</kbd>+<kbd>D</kbd>)。收藏的条目会移至面板顶部,并保存到您的账户中。

您的管理员还可以固定内置工具。被固定的工具即使处于关闭状态,其标签(chip)仍会保留在输入框上,因此只需一次点击即可使用。移除已关闭的固定工具的标签,会为您取消该工具的固定。

## 分阶段上下文 [#staged-context]

在您发送下一条消息之前,附加的任何内容都会显示在输入框上方。

- 文件,支持上传进度和图片预览。
- 长文本粘贴。当[作为文本上传](/docs/features/upload_as_text#pasting-long-text)可用时,粘贴超过 2,500 个字符的内容会将文本作为 `pasted-text.txt` 附加,而不是填充到输入框中。选择该附件即可在更大的对话框中编辑文本,或选择**移回消息**将其放回文本输入框。在**设置 > 聊天**中关闭**将长文本粘贴为文件**即可禁用此功能。
- 通过 **添加到对话**(参见 [引用摘录](/docs/features/message_actions#quote-excerpts))引用的先前消息中的摘录。
- 你从调色板中选择或通过 `$` 调用的技能。

在发送之前删除任何你不再需要的内容;剩下的所有内容都会随消息一起发送。你也可以不输入任何文字,直接单独发送文件。

## 思考 [#thinking]

在支持推理设置的模型上,**Thinking** 控件会打开一个从 **Faster** 到 **Smarter** 的滑块,以及提供商提供的其他独立模式(例如 **Auto**)。它更改的值与参数面板相同。如果模型没有推理设置,或者管理员隐藏了参数,则不会显示该控件。

## 在响应流式传输时进行排队和引导 [#queue-and-steer-while-a-response-streams]

你可以在回复流式输出的同时继续输入。此时发送消息的行为取决于你在 **设置 > 聊天** 中 **生成期间,按下 Enter 将** 选项所设置的默认值(参见[个人设置](/docs/features/settings#chat))。

- Queue: 消息会排队等待,并在回复结束后发送。
- Steer:运行中的响应会在下一个安全节点接收你的消息,且不会取消工具调用或推理过程。
- 中断:正在进行的工具调用和推理会被取消,已完成的输出将被保留,并以您的消息继续响应。

有关引导（steering）在智能体中的工作方式及其可用时机，请参阅[引导与排队消息](/docs/features/agents#steering-and-queued-messages)。

排队中的消息会在输入框上方的**排队消息**列表中等待。对于每条消息,您可以**立即发送**、**移除消息**,或打开**更多选项**来**编辑消息**(将其移回文本输入框)、**在新对话中开始**,或**禁用队列**,使其不再自动发送。拖动消息即可重新排序,或聚焦某条消息后使用上下方向键进行调整。

## 键盘快捷键 [#keyboard-shortcuts]

### 在文本框中 [#in-the-text-field]

该表格假设已开启**按 Enter 发送消息**选项,这是默认设置。关闭该选项后,<kbd>Enter</kbd> 会添加新行,而 <kbd>Ctrl</kbd>+<kbd>Enter</kbd> 用于发送消息。

| 按键 | 操作 |
|---|---|
| <kbd>Enter</kbd> | 发送。回复生成期间,按 **While generating, Enter will** 所选的方式执行。 |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | 换行。 |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd>(<kbd>Cmd</kbd>+<kbd>Enter</kbd>) | 换行。回复生成期间,执行另一种操作:若 <kbd>Enter</kbd> 为排队,则立即发送;若 <kbd>Enter</kbd> 为引导或打断,则改为排队。 |
| <kbd>Alt</kbd>+<kbd>Enter</kbd>(<kbd>Option</kbd>+<kbd>Enter</kbd>) | 回复生成期间:在运行允许的情况下,以你的消息打断当前回复。 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd>(<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd>) | 与 <kbd>Alt</kbd>+<kbd>Enter</kbd> 相同。 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>(<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>) | 停止回复。 |
| `/` | 插入已保存的提示词。 |
| `@` | 切换模型、预设或智能体。 |
| `+` | 添加另一个模型或预设,以并排查看回复。 |
| `$` | 为下一条消息选择技能。 |

您可以在账户菜单中重新绑定或关闭快捷键;参见[键盘快捷键](/docs/features/settings#keyboard-shortcuts)。

### 在调色板中 [#in-the-palette]

| 按键 | 操作 |
|---|---|
| 输入 | 搜索工具、技能、服务器、上传选项和文件。 |
| <kbd>↑</kbd> / <kbd>↓</kbd> | 在行之间移动。 |
| <kbd>Enter</kbd> | 选择高亮的行。 |
| <kbd>Ctrl</kbd>+<kbd>D</kbd>(<kbd>Cmd</kbd>+<kbd>D</kbd>) | 收藏或取消收藏高亮的行。 |
| 搜索框为空时按 <kbd>Backspace</kbd>,或按 <kbd>Escape</kbd> | 关闭面板。 |

## 设置 [#setup]

输入框无需任何设置。管理员可以控制其中显示的内容：使用 [`fileConfig.legacyFileUploadUX`](/docs/configuration/librechat_yaml/object_structure/file_config#legacyfileuploadux) 启用旧版上传器，使用 [`interface.composerRecentFiles`](/docs/configuration/librechat_yaml/object_structure/interface#composerrecentfiles) 设置最近文件的数量，使用 [`interface.defaultPinnedTools`](/docs/configuration/librechat_yaml/object_structure/interface#defaultpinnedtools) 设置固定工具，并通过 [SharePoint 集成](/docs/configuration/sharepoint) 配置 SharePoint。设置了 `hideBadgeRow` 的 [模型规范](/docs/configuration/librechat_yaml/object_structure/model_specs#hidebadgerow) 会隐藏该规范对应的工具区域。
