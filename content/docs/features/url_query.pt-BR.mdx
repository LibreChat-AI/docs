Você pode adicionar parâmetros de consulta a uma URL de chat para escolher o endpoint e o modelo, carregar um agente ou uma especificação de modelo (model spec), preencher o prompt ou alterar as configurações do modelo antes que o chat comece. É assim que você cria um favorito, um atalho de launcher (Raycast, Alfred, uma palavra-chave do navegador) ou um link de outro aplicativo que leva alguém diretamente para a configuração certa.

```
https://chat.example.com/c/new?endpoint=anthropic&model=claude-sonnet-4-5&prompt=Summarize%20this%20article
```

Os parâmetros funcionam em um novo chat (`/c/new`) e em um chat existente (`/c/<conversation-id>`). Depois que o LibreChat os lê, ele os remove da barra de endereços, de modo que recarregar a página não os aplica novamente.

## Escolha o endpoint e o modelo [#pick-the-endpoint-and-model]

`endpoint` e `model` juntos são a combinação mais previsível.

- `endpoint` sozinho alterna para esse endpoint e usa o modelo que você escolheu por último nele, ou o primeiro modelo da sua lista.
- `model` sozinho alterna o modelo dentro do endpoint atual, caso esse endpoint o possua.

Os valores de endpoint integrados são `openAI`, `azureOpenAI`, `google`, `anthropic`, `bedrock`, `agents`, `assistants` e `azureAssistants`. Para um [endpoint personalizado](/docs/quick_start/custom_endpoints), use o nome definido na sua configuração; a correspondência não diferencia maiúsculas de minúsculas, então `endpoint=openrouter` encontra um endpoint chamado `OpenRouter`.

## Carregar um agente, assistente ou especificação de modelo [#load-an-agent-assistant-or-model-spec]

```
/c/new?agent_id=agent_abc123
/c/new?assistant_id=asst_abc123
/c/new?spec=meeting-notes
```

`agent_id` e `assistant_id` definem o endpoint para você. `spec` carrega uma [especificação de modelo](/docs/configuration/librechat_yaml/object_structure/model_specs) pelo seu `name`. Quaisquer outras configurações na mesma URL são aplicadas sobre o preset da especificação. Se o seu administrador impõe especificações de modelo, inclua `spec` em todos os links e espere que os valores da própria especificação prevaleçam sobre a URL.

## Preencha ou envie o prompt [#fill-in-or-send-the-prompt]

`prompt` (ou o mais curto `q`) coloca texto na caixa de mensagem. Se ambos estiverem presentes, `prompt` tem prioridade.

Adicione `submit=true` para enviá-lo assim que o chat estiver pronto:

```
/c/new?endpoint=openAI&model=gpt-4o&prompt=Explain%20quantum%20computing&submit=true
```

Se as configurações solicitadas não puderem ser aplicadas em alguns segundos, o prompt é mantido na caixa de mensagem em vez de ser enviado. Seu administrador também pode desativar o envio automático, caso em que `submit=true` apenas preenche o prompt e você pressiona enviar por conta própria.

Os valores devem ser codificados em URL. Em JavaScript, `encodeURIComponent()` faz isso:

```js
const url = `/c/new?prompt=${encodeURIComponent('Write a function: def hello()')}`;
// /c/new?prompt=Write%20a%20function%3A%20def%20hello()
```

## Alterar configurações do modelo [#change-model-settings]

Qualquer um destes pode ser adicionado à URL. Cada um só tem efeito em endpoints que o suportam, e os valores são verificados antes de serem aplicados; qualquer valor inválido é descartado sem gerar erro.

| Endpoint | Parâmetros |
| --- | --- |
| Qualquer | `maxContextTokens`, `resendFiles`, `promptPrefix` (instruções personalizadas) |
| OpenAI, Azure OpenAI, personalizado | `temperature`, `top_p`, `presence_penalty`, `frequency_penalty`, `stop`, `max_tokens`, `reasoning_effort`, `reasoning_summary`, `verbosity`, `useResponsesApi`, `disableStreaming`, `imageDetail` (`low`, `auto`, `high`) |
| OpenAI Responses API | `reasoning_mode` (`standard`, `pro`), `reasoning_context` (`auto`, `current_turn`, `all_turns`) |
| OpenAI, Anthropic, Google | `web_search` (`true`/`false`), `fileTokenLimit` (limite de tokens para o conteúdo de arquivos) |
| Anthropic, Google | `temperature`, `topP`, `topK`, `maxOutputTokens`, `thinking`, `thinkingBudget`, `thinkingLevel` |
| Anthropic | `effort` (`low`, `medium`, `high`, `xhigh`, `max`), `thinkingDisplay` (`auto`, `summarized`, `omitted`, ou `updates` para apenas as notas de progresso entre chamadas de ferramentas) |
| Anthropic, Bedrock (modelos Anthropic), OpenRouter | `promptCache` (`true`/`false`), `promptCacheTtl` (`5m` ou `1h`) |
| Google | `url_context=true` permite que o Gemini leia URLs na sua mensagem |
| Bedrock | `region`, `maxTokens`, `temperature`, `topP`, `reasoning_effort` |
| Assistants | `instructions` (substitui as instruções do assistente para esta execução), `append_current_datetime=true` |

O significado e os valores permitidos de cada campo estão listados em [campos de preset de model spec](/docs/configuration/librechat_yaml/object_structure/model_specs). Passar um valor que o provedor rejeita (um `max_tokens` acima do limite do modelo, por exemplo) gera um erro de API ao enviar; inicie um **Novo chat** para limpá-lo.

## Definir o modo de cor [#set-the-color-mode]

Se o seu administrador ativar essa opção, `theme=light`, `theme=dark` ou `theme=system` em um link define o seu modo de cor, para que um aplicativo que direciona para o LibreChat possa fornecer o próprio tema. Ele é salvo como sua preferência até que você o altere nas configurações.

## Configuração [#setup]

Os parâmetros de consulta funcionam sem configuração. Administradores podem impedir que `submit=true` envie automaticamente com [`interface.autoSubmitFromUrl`](/docs/configuration/librechat_yaml/object_structure/interface#autosubmitfromurl), e habilitar o parâmetro `theme` com [`interface.colorModeFromUrl`](/docs/configuration/librechat_yaml/object_structure/interface#colormodefromurl).
