Skill adalah file `SKILL.md`: blok frontmatter singkat yang menjelaskan kapan skill tersebut berlaku, dan badan markdown yang berisi instruksinya. Gunakan skill untuk apa pun yang biasanya harus Anda tempelkan ke chat berulang kali, seperti panduan gaya, daftar periksa tinjauan, atau langkah-langkah untuk laporan rutin. Agen hanya memuat skill ketika relevan, sehingga Anda dapat menyimpan banyak skill tanpa membuat setiap prompt menjadi membengkak.

LibreChat tidak dilengkapi dengan skill apa pun. Setiap skill ditulis atau diunggah oleh pengguna, dibuat oleh agen selama chat, atau disediakan oleh admin Anda.

## Membuat skill [#create-a-skill]

Buka **Skills** dari panel samping dan klik **+**. Pilih **Write skill instructions** untuk menulis instruksi di editor, atau **Upload a skill** untuk mengimpor file `.md`, atau arsip `.zip` atau `.skill` yang berisi `SKILL.md`. Jika Skills tidak ada di panel samping, admin Anda telah menonaktifkannya atau peran Anda tidak dapat menggunakannya.

Sebuah keterampilan minimal:

```md filename="SKILL.md"
---
name: brand-guidelines
description: Use when writing public-facing copy that must follow the company voice and terminology.
---

Write in a concise, practical tone.
Prefer active voice.
Say "workspace", never "project space".
```

Nama harus dalam format kebab-case (huruf kecil, angka, dan tanda hubung), maksimal 64 karakter, dan unik di antara skill Anda; mengunggah skill dengan nama yang sudah Anda gunakan akan gagal alih-alih menimpa skill yang ada. Nama yang diawali dengan `anthropic-` atau `claude-`, serta kata perintah seperti `help` atau `settings`, bersifat dicadangkan.

Deskripsi adalah bagian terpenting dalam file ini: deskripsi inilah yang dibaca model untuk memutuskan apakah skill tersebut berlaku. "Use when writing release notes for the mobile app" akan memicu skill, sedangkan "Writing helper" tidak. Letakkan frasa pemicu di awal dan jaga agar deskripsi tetap di bawah 250 karakter, karena deskripsi yang lebih panjang akan terpotong di daftar yang dilihat model. Batas maksimum adalah 1.024 karakter untuk deskripsi dan 100.000 karakter untuk isi.

### Opsi Frontmatter [#frontmatter-options]

Selain `name` dan `description`, sebuah skill dapat mengatur:

- `always-apply: true`: muat skill pada setiap giliran alih-alih menunggu model memintanya.
- `user-invocable: false`: sembunyikan dari menu `$`.
- `disable-model-invocation: true`: jangan sertakan dalam daftar yang dipilih model. Anda tetap dapat memanggilnya dengan `$`.
- `allowed-tools`: daftar alat (misalnya `["execute_code"]`) yang diberikan kepada agen untuk giliran tersebut ketika skill dipanggil dengan `$` atau selalu diterapkan, meskipun agen biasanya tidak memiliki alat tersebut.
- `compatibility`: catatan bebas tentang apa yang dibutuhkan skill, misalnya server MCP tertentu. LibreChat menyimpan nilai ini tetapi tidak memberlakukannya.

`when-to-use` berfungsi sebagai pengganti `description`, dan `alwaysApply` sebagai pengganti `always-apply`. Kunci tidak peka terhadap huruf besar/kecil, dan kunci lain yang Anda tambahkan akan dipertahankan sebagai metadata.

### Berkas yang Disertakan [#bundled-files]

Sebuah skill dapat memuat lebih dari satu file. Tata letak yang umum digunakan adalah `references/` untuk dokumen panjang, `scripts/` untuk kode yang dapat dijalankan oleh agen, dan `assets/` untuk template. Agen membaca file-file ini saat skill sedang digunakan, sehingga `SKILL.md` dapat tetap singkat dan merujuk ke file-file tersebut. Ketika Run Code diaktifkan, file-file tersebut juga tersedia di sandbox pada `/mnt/data/skills/<skill-name>/`. Di penampil skill, tautan relatif antar file Markdown milik skill akan membuka file yang ditautkan.

Dalam sebuah arsip, `SKILL.md` harus berada di tingkat teratas atau di dalam tepat satu folder. Unggahan dibatasi hingga 50 MB secara default (admin Anda dapat mengubah batas ini), 500 file, dan 10 MB per file; file dengan jalur yang tidak aman akan dilewati dan dilaporkan. Skill yang memiliki file terlampir akan menampilkan panah di sebelah namanya pada sidebar Skills; klik panah tersebut untuk menelusuri file dan membuka salah satunya.

## Menggunakan skill [#use-a-skill]

Ada tiga cara sebuah skill sampai ke dalam percakapan:

- **Anda yang memilih.** Ketik `$` di kotak chat dan pilih sebuah skill. Tidak ada yang ditambahkan ke teks Anda; skill akan ditampilkan sebagai chip di atas composer dan dimuat untuk pesan tersebut.
- **Model yang memilihnya.** Agen melihat nama dan deskripsi skill yang tersedia baginya, dan memuat salah satunya ketika permintaan Anda sesuai.
- **Selalu diterapkan.** Skill dengan `always-apply: true` dimuat pada setiap giliran.

Selama skill dimuat, pesan menampilkan **Loading** diikuti dengan nama skill, lalu **Loaded** setelah skill berada dalam konteks.

Model hanya melihat nama dan deskripsi dalam daftarnya (hingga 100 skill), bukan instruksinya. Skill yang Anda pilih atau yang selalu diterapkan akan memuat `SKILL.md` lengkap untuk giliran tersebut. Satu giliran menerima hingga 10 skill yang dipilih dan 20 skill yang selalu diterapkan, dengan total 30; jika melebihi batas tersebut, skill yang selalu diterapkan akan dibuang terlebih dahulu.

## Skill apa saja yang dapat digunakan oleh agen [#which-skills-an-agent-can-use]

Dua hal menentukannya.

Pertama, daftar Anda sendiri. Setiap skill memiliki sakelar **Available to agent**. Matikan sakelar tersebut dan skill akan hilang dari menu `$`, dari daftar yang dapat dipilih model, dan dari always-apply, tanpa menghapusnya. Skill yang Anda buat akan langsung aktif. Skill yang dibagikan kepada Anda akan nonaktif, kecuali admin Anda telah mengaktifkan skill bersama secara default.

Kedua, agen. Bagian **Skills** di Agent Builder memiliki tiga pengaturan:

- **Off**: agen tidak menggunakan skill apa pun.
- **Semua**: setiap skill yang telah Anda aktifkan.
- **Dipilih**: hanya skill yang Anda tambahkan ke dalam daftar.

**Selected** adalah pilihan yang lebih baik untuk agen yang fokus. Agen dukungan dengan 40 keterampilan untuk dipilih akan lebih sering memilih yang salah dibandingkan agen dengan tiga keterampilan yang dibutuhkannya.

## Keterampilan yang ditulis oleh agen [#skills-written-by-agents]

Agen dengan skills yang diaktifkan juga dapat menulis skills saat bekerja, misalnya untuk menyimpan prosedur yang baru saja berhasil. Agen dapat membuat skill baru jika peran Anda diizinkan untuk membuat skills, dan mengedit skills yang sudah ada hanya jika Anda memiliki izin untuk mengeditnya dan skills tersebut berada dalam cakupan agen. Skills dari admin Anda tetap hanya-baca. Dengan **Selected** dan daftar kosong, agen tidak melihat satu pun skills yang ada milik Anda, tetapi tetap dapat membuat skills baru.

## Berbagi [#sharing]

Skill dibagikan dengan cara yang sama seperti agen dan prompt, dengan peran Viewer (dapat menggunakan, tidak dapat mengedit), Editor, dan Owner. Berbagi memerlukan izin share pada peran Anda, yang secara default nonaktif untuk pengguna biasa. Lihat [Access Control](/docs/features/access_control).

Admin Anda juga dapat menyediakan skill, dari sistem file server, dari [Agent Plugins](/docs/features/agent_plugins), atau yang di-mirror dari repositori GitHub. Skill ini bersifat hanya-baca di LibreChat; ubah di sumbernya. Skill dari sistem file dan plugin langsung aktif saat pertama kali dimuat.

## Pengaturan [#setup]

Skills diaktifkan secara default untuk semua pengguna. Admin dapat menonaktifkan fitur ini dengan kapabilitas agen `skills` (lihat [konfigurasi endpoint agents](/docs/configuration/librechat_yaml/object_structure/agents#capabilities)), mengatur siapa yang dapat membuat dan membagikan skills di [Admin Panel](/docs/features/admin_panel) atau [`interface.skills`](/docs/configuration/librechat_yaml/object_structure/interface#skills), menyediakan skills dari disk atau GitHub sebagaimana dijelaskan di [Skill Sync](/docs/configuration/librechat_yaml/object_structure/skill_sync), serta mengubah batas ukuran unggahan dengan [`fileConfig.skills`](/docs/configuration/librechat_yaml/object_structure/file_config#skills).
