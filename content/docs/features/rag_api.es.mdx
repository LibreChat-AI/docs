La búsqueda de archivos te permite subir documentos y hacer preguntas sobre ellos sin pegar su contenido en el chat. LibreChat envía cada archivo a la API de RAG, que lo divide en fragmentos y los indexa; cuando haces una pregunta, el modelo busca en ese índice y responde a partir de los pasajes que encuentra.

Úsalo cuando un documento sea demasiado largo para leerlo completo en cada turno, o cuando quieras obtener respuestas de varios archivos a la vez.

## Sube un archivo para la búsqueda [#upload-a-file-for-search]

Haz clic en **+** en el [compositor de mensajes](/docs/features/composer) para abrir la paleta, expande **Más opciones de carga** y luego elige **Subir para Búsqueda de archivos** y selecciona tus archivos. También puedes buscarlo en la paleta. Al subir archivos de esta manera, **Búsqueda de archivos** también se activa para el chat. Los archivos grandes pueden tardar un momento en indexarse; la carga se completa una vez finalizada la indexación.

Una vez que la conversación tiene archivos indexados, el modelo recibe una herramienta `file_search`. Él decide cuándo llamarla: una pregunta sobre el documento activa una búsqueda, mientras que la conversación informal no. La respuesta muestra un paso de "Buscando en tus archivos" mientras se ejecuta y, cuando las citas están habilitadas, los fragmentos utilizados aparecen en **Fuentes** con el nombre del archivo, para que puedas abrir el documento y verificarlos.

## Cómo funciona la búsqueda [#how-search-works]

Cuando el modelo llama a `file_search`, escribe una consulta de búsqueda. LibreChat solicita a la API de RAG los 5 fragmentos más cercanos de cada archivo adjunto y conserva los 10 más cercanos en total. Esos fragmentos se devuelven al modelo junto con el nombre del archivo y una puntuación de relevancia, y el modelo responde a partir de ellos.

La recuperación encuentra fragmentos cuyo significado es cercano al de la consulta, por lo que es buena para buscar datos específicos en documentos extensos. Para las preguntas que necesitan el documento completo a la vez, como un resumen, Upload as Text suele funcionar mejor.

Eliminar un archivo en LibreChat también elimina sus vectores de la API de RAG.

## Reutilizar archivos que ya subiste [#reuse-files-you-already-uploaded]

Los archivos indexados permanecen en tu cuenta. Abre la paleta y busca en **Tus archivos** para adjuntar uno a un nuevo mensaje o conversación sin volver a subirlo.

Los archivos cargados mientras un endpoint de Assistants estaba activo se almacenan en OpenAI, no se indexan con la RAG API y no pueden adjuntarse a otros endpoints.

## Búsqueda de archivos en agentes [#file-search-in-agents]

Para un agente, active [**Búsqueda de archivos**](/docs/features/agents#file-search) en el Constructor de agentes y suba archivos allí. Estos se convierten en la base de conocimiento del agente: cualquier persona que chatee con el agente puede hacer que busque en esos archivos, sin necesidad de subir nada por su cuenta. El agente debe estar guardado antes de poder agregarle archivos.

## Búsqueda de archivos o carga como texto [#file-search-or-upload-as-text]

[**Subir como texto**](/docs/features/upload_as_text) se encuentra en el mismo menú. Extrae el texto del archivo y lo incorpora completo a la conversación, lo cual funciona para documentos cortos en los que el modelo debe leer cada palabra. La búsqueda de archivos solo envía los fragmentos que coinciden con cada consulta, por lo que escala a documentos largos y a muchos archivos, pero el modelo nunca ve las partes que no fueron recuperadas.

La API de RAG también sirve Upload as Text, como extractor de texto para tipos de archivo que el analizador integrado no puede leer. Consulta [cómo se extrae el texto](/docs/features/upload_as_text#how-the-text-is-extracted).

## Configuración [#setup]

La búsqueda de archivos necesita el servicio RAG API y una base de datos vectorial. La configuración predeterminada de Docker incluye ambos; un administrador configura el proveedor de embeddings y, para otras instalaciones, `RAG_API_URL`. Consulta [Configuración de RAG API](/docs/configuration/rag_api) y el [repositorio de RAG API](https://github.com/LibreChat-AI/rag-api) para conocer los endpoints y variables propios del servicio.
