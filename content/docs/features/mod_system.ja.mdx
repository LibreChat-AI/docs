LibreChatは、ログインフォームへの連続した試行、許可された速度を超えるメッセージ送信、スクリプトからのAPI呼び出しといった不正なパターンを監視し、そのたびにユーザーに対する違反として記録します。ユーザーの違反スコアが閾値を超えると、そのアカウントとIPアドレスは一定期間禁止されます。この仕組みは、一人または少数の悪意あるユーザーを止めることを目的としており、大量のトラフィックへの対策ではありません。公開インスタンスの場合は、そのためにリバースプロキシやCloudflareなどのDDoS対策サービスを前段に配置してください。

## 違反とみなされるもの [#what-counts-as-a-violation]

ほとんどの違反はレート制限に起因します。リクエストが制限を超えると、「リクエストが多すぎます」といった趣旨のエラーで拒否され、その試行はユーザーのスコアに加算されます。制限の対象は次のとおりです。

- IPごとのログインおよび登録。短時間に多数のサインイン失敗があった場合、「短時間に多すぎるログイン試行が行われました。」と表示されます。
- メッセージ:1人のユーザーが同時に実行できる応答の数(「一度に実行できるメッセージは1つだけです」)と、IPごと、およびオプションでユーザーごとに1分あたりに送信できるメッセージの数。
- パスワードリセットおよびメールアドレス確認のリクエスト、ならびにその後に続くリンクの送信。
- 2要素認証コードの試行回数とパスキーの登録について。
- 会話のインポート(IPアドレスごとに15分ごとに100件、ユーザーごとに15分ごとに50件)、フォーク(IPアドレスごとに毎分30件、ユーザーごとに毎分7件)、および共有リンクの閲覧は、それぞれIPアドレスごとおよびユーザーごとに同時に制限されます。
- ファイルアップロード、テキスト読み上げ、音声認識、ツール呼び出し。

以下のケースは、レート制限とは無関係に違反として扱われます。ブラウザ以外から送信されたリクエスト、エンドポイントが提供していないモデルへのリクエスト（ほぼ常にサーバーを探査するスクリプトによるものです）、およびユーザー本人が所有していない会話を開こうとする試みです。

各違反タイプにはそれぞれ独自のスコアがあります。デフォルトでは、ブラウザ以外からのリクエストが大きくスコアに加算されます。また、サンプルの `.env` では一部のタイプが 0 に設定されているため、上限を超えた場合はブロックされますが、ユーザーの BAN に向けたスコアは増加しません。

## バン [#bans]

ユーザーの合計スコアが、ban間隔（デフォルトでは20）の倍数に達するたびにBanが発動します。そのユーザーのセッションは直ちに終了され、アカウントと接続元のIPアドレスの両方が、Banの期間（デフォルトでは2時間）ロックされます。Banされたユーザーには「Your account is temporarily banned for violating the terms of service.」と表示されます。Banは自動的に期限切れとなります。スコアも減衰します。デフォルトでは、新たな違反がない状態が1時間続くと、ユーザーのスコアはリセットされます。新たな違反があるたびに、その1時間の計測は最初からやり直されます。

早期に禁止を解除するには、管理者が MongoDB の `logs` コレクションからその禁止のエントリを削除します。違反スコアと、ユーザーごとの各違反の履歴は、LibreChat ディレクトリ内の `data/violations.json` と `data/logs.json` に保存されています(Redis が有効な場合、スコアは代わりに Redis に保存され、すべてのレプリカが同じスコアを参照できるようになります。禁止情報は、いずれの場合も MongoDB に残ります)。ユーザーが禁止された理由を知りたいときは、これらのファイルを確認してください。

## メッセージのモデレーション [#message-moderation]

スコアリングシステムとは別に、管理者はチャットメッセージがモデルに届く前に OpenAI モデレーション API を経由させることができます。これは通常のチャットとエージェントが対象で、ホステッド Assistants エンドポイントは対象外です。フラグが立てられたメッセージは送信されず、ユーザーには「このメッセージはモデレーションシステムによってフラグが立てられました。」と表示されます。

## セットアップ [#setup]

レート制限とBAN（アクセス禁止）は、上記の値でデフォルトで有効になっています。管理者は、環境変数を通じてすべての制限値、スコア、およびBANの設定を調整でき、同じ方法でOpenAIのモデレーションを有効にできます。詳細は[Automated Moderation configuration](/docs/configuration/mod_system)を参照してください。アップロード、音声、および会話インポートの制限も、`librechat.yaml`の[`rateLimits`](/docs/configuration/librechat_yaml/object_structure/config#ratelimits)ブロックで設定できます。
