Sie können Unterhaltungen importieren, die aus ChatGPT, Claude und [ChatbotUI v1](https://github.com/mckaywrigley/chatbot-ui/tree/b865b0555f53957e96727bc0bbb369c9eaecd83b?tab=readme-ov-file#legacy-code) exportiert wurden, sowie eine aus LibreChat als JSON exportierte Unterhaltung. Importierte Chats erscheinen in Ihrem Verlauf wie alle anderen. Der Export funktioniert jeweils nur für eine Unterhaltung.

## Die Datei importieren [#import-the-file]

Gehe zu **Einstellungen** > **Daten & Datenschutz**, wähle neben „Gespräche aus einer JSON-Datei importieren“ die Option **Importieren** aus und wähle die Datei aus. Die Dateiauswahl akzeptiert nur `.json`, daher musst du ChatGPT- und Claude-Archive zuerst entpacken. Während der Verarbeitung zeigt die Schaltfläche „Wird importiert“ an, und wenn der Vorgang abgeschlossen ist, erscheint „Gespräche erfolgreich importiert“.

LibreChat ermittelt das Format anhand des Dateiinhalts und nicht anhand des Dateinamens. Wenn die Datei nicht erkannt wird, erscheint die Meldung "Unsupported import type".

Ein LibreChat-Import übernimmt weder den gespeicherten Genehmigungsmodus für Code (einschließlich **Full access**) noch den Status „ungelesen“ der Unterhaltung. Der importierte Chat verwendet deine eigene aktuelle Genehmigungseinstellung sowie die Richtlinie der Bereitstellung.

### Limits [#limits]

- Die Datei darf bis zu 250 MiB groß sein, sofern Ihr Administrator kein anderes Limit festgelegt hat. Größere Dateien werden vor dem Hochladen abgelehnt.
- Eine einzelne Unterhaltung oder Nachricht darf nicht größer als etwa 16 MB sein, was ein Datenbanklimit ist.
- Importe sind pro Benutzer und pro IP-Adresse ratenbegrenzt. Wenn Sie also viele Dateien hintereinander importieren, kann der Vorgang für eine gewisse Zeit abgelehnt werden.

## Konversation exportieren [#export-a-conversation]

Öffnen Sie die Unterhaltung, öffnen Sie das Menü **Chat-Optionen** (die Schaltfläche `...` in der Kopfzeile oder das Kopfzeilenmenü auf kleinen Bildschirmen) und wählen Sie **Exportieren**. Wählen Sie einen Dateinamen und einen Typ aus und klicken Sie anschließend auf **Exportieren**.

| Typ | Was Sie erhalten |
| --- | --- |
| `markdown` (.md) | Ein lesbares Transkript. Dies ist die Standardeinstellung. |
| `text` (.txt) | Ein Klartext-Transkript. |
| `json` (.json) | Die vollständigen Nachrichtendaten. Dies ist das Format, das LibreChat erneut importieren kann. |
| `csv` (.csv) | Eine Zeile pro Nachricht. |
| `screenshot` (.png) | Ein Bild der Unterhaltung, so wie sie auf dem Bildschirm erscheint. |

**Alle Nachrichtenzweige exportieren** funktioniert für `json` und `csv`; die anderen Typen exportieren nur den Zweig, den Sie gerade ansehen. **Endpoint-Optionen einbeziehen** fügt das Modell und seine Einstellungen hinzu und ist für `csv` oder `screenshot` nicht verfügbar. Für `json` können Sie außerdem **Rekursiv** (Nachrichten verschachtelt unter ihrer übergeordneten Nachricht) oder sequenziell wählen.

Es gibt keinen Export aller Unterhaltungen auf einmal, und in einem neuen Chat oder einem Suchergebnis gibt es nichts zu exportieren, weshalb dort das Menü nicht erscheint.

## Einrichtung [#setup]

Import und Export funktionieren für jeden Benutzer ohne zusätzliche Einrichtung. Administratoren können die maximale Importgröße mit `CONVERSATION_IMPORT_MAX_FILE_SIZE_BYTES` und die Ratenbegrenzungen mit den Variablen `IMPORT_*` anpassen; siehe die [.env-Referenz](/docs/configuration/dotenv#conversation-import).
