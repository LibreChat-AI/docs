Mit dem Konversationsimport können Sie Konversationen, die aus anderen KI-Chat-Anwendungen exportiert wurden, in LibreChat importieren. Unterstützte Quellen sind [ChatGPT](https://chatgpt.com/), [Claude](https://claude.ai/) und [ChatbotUI v1](https://github.com/mckaywrigley/chatbot-ui/tree/b865b0555f53957e96727bc0bbb369c9eaecd83b?tab=readme-ov-file#legacy-code).

<Callout type="info" title="Wo Sie es finden">
Der Import befindet sich unter **Settings** → **Data Controls** in LibreChat.
</Callout>

## Export aus der Quellanwendung [#export-from-the-source-application]

Exportieren Sie zunächst Ihre Daten aus der Anwendung, von der Sie migrieren möchten. Die Schritte unterscheiden sich je nach Quelle.

<Callout type="info" title="Möchten Sie stattdessen Daten aus LibreChat exportieren?">
Siehe [Export from LibreChat](#export-from-librechat) am Ende dieser Seite.
</Callout>

</Step>

**Laden Sie das Archiv herunter.** Sie erhalten eine E-Mail mit einem Download-Link. Das Archiv ist eine ZIP-Datei mit einem zufälligen Namen wie `d119d98bb3711aff7a2c73bcc7ea53d96c984650d8f7e033faef78386a9907-2024-01-01-10-30-00.zip`.

## Import in LibreChat [#import-into-librechat]

<Steps>
<Step>

**Open Data Controls.** Navigieren Sie in LibreChat zu **Settings** → **Data Controls**.

</Step>
<Step>

**Wählen Sie Ihre Datei aus.** Klicken Sie auf **Import** und wählen Sie die Datei `conversations.json` aus Ihrem entpackten Archiv (oder die exportierte JSON-Datei für ChatbotUI v1) aus.

</Step>
<Step>

**Auf Bestätigung warten.** Eine Benachrichtigung erscheint, sobald der Import abgeschlossen ist.

</Step>
</Steps>

## Einstellungen zur Genehmigung von importiertem Code [#imported-code-approval-settings]

Beim Importieren einer LibreChat-Konversation wird der gespeicherte Code-Genehmigungsmodus (einschließlich **Vollzugriff**) nicht übernommen. Neue Importe verwenden die bestehende Einstellung/Standardeinstellung des Empfängers sowie die aktuelle Richtlinie der Bereitstellung/des Workers. Eine Massenaktualisierung kann eine lokal gespeicherte Genehmigungsauswahl nicht überschreiben. Diese Schutzmaßnahme setzt bestehende Konversationen nicht rückwirkend zurück; Benutzer können weiterhin einen unterstützten Modus über LibreChat auswählen und speichern. Siehe [Berechtigungen für Tools in der angehängten Umgebung](/docs/features/code_interpreter#attached-environment-tool-permissions).

## Export aus LibreChat [#export-from-librechat]

Der Export erfolgt pro Konversation und befindet sich im Menü **Export and Share** in der Chat-Kopfzeile (unter dem Überlaufmenü auf Mobilgeräten). Öffnen Sie die gewünschte Konversation, wählen Sie **Export**, wählen Sie ein Format und bestätigen Sie.

<OptionTable
  options={[
    ['markdown', '.md', 'Lesbares Transkript. Der Standard.', ''],
    ['text', '.txt', 'Klartext-Transkript.', ''],
    ['json', '.json', 'Strukturierter Export, der die vollständigen Nachrichtendaten beibehält.', 'Supports exporting all message branches'],
    ['csv', '.csv', 'Tabellarischer Export, eine Zeile pro Nachricht.', 'Supports exporting all message branches'],
    ['screenshot', '.png', 'Bild der gerenderten Konversation.', ''],
  ]}
/>

Zwei Optionen im Dialog hängen von dem Format ab, das Sie wählen:

- **Export all message branches** gilt nur für `json` und `csv`. Andere Formate exportieren nur den sichtbaren Zweig.
- Die verbleibenden Exportoptionen sind für `csv` und `screenshot` nicht verfügbar.

<Callout type="info" title="Geltungsbereich">

Es gibt keinen integrierten Massenexport für alle Unterhaltungen auf einmal, und eine brandneue Unterhaltung oder ein Suchergebnis enthalten nichts, was exportiert werden könnte, daher erscheint das Menü für diese nicht.

</Callout>
