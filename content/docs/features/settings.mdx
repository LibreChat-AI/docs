title: Personal Settings
icon: Settings
description: The preferences each user can change for themselves, from theme and font size to send behavior, notifications and keyboard shortcuts.

Open the account menu and choose **Settings**. The dialog has tabs for **General**, **Chat**, **Speech**, **Data & Privacy** and **Account**, plus **Langfuse** and **About** on deployments that offer them. If you know roughly what you want, type it into **Search settings**: it matches labels and related words ("dark", "rtl", "paste") and jumps to the right tab and section.

Most preferences are saved in the current browser, not in your account. A setting changed on your laptop does not follow you to your phone. The exceptions are noted below.

## General

| Setting | What it does | Default |
|---|---|---|
| Theme | **System**, **Light**, **Dark**, or a high contrast light or dark theme. | System |
| Language | The interface language. | Browser language |
| Message Font Size | Text size of messages, from **Extra Small** to **Extra Large**. | Medium |
| UI scale | Scales the whole interface between 50% and 150%, independent of browser zoom. | 100% |
| Chat direction | **Auto**, left to right, or right to left. | Auto |
| Clock Format | System, 12-hour or 24-hour times across messages, schedules and dates. | System |
| Week Starts On | System, Sunday or Monday. Changes the order of weekdays in [Scheduled Chats](/docs/features/scheduled_chats), not when a schedule runs. | System |
| Maximize chat space | Widens the conversation column. | Off |
| Center Chat Input on Welcome Screen | Puts the message box in the middle of a new chat. | On |
| Show Lia on the Welcome Screen | A small decorative pixel mascot around the message box. Only shown when the deployment allows it. | Off |
| Scroll to the end button | A button that jumps to the latest message. | On |
| Show chat beside the sidebar on mobile | Keeps a strip of the conversation visible next to the [mobile drawer](/docs/features/navigation#mobile-drawer); tap the strip to close the drawer. | Off |
| Display chat title in tab | Uses the conversation title as the browser tab title. | On |
| Keep screen awake during response generation | Asks the browser not to dim or lock the screen while a reply streams. | On |

Administrators also see an **Admin Panel** link here when the deployment has one.

### Notifications

These control how you hear about replies that finish while you are in another chat or another tab:

- **Show unread count in the tab title** puts the number of chats with unread replies in the tab title and icon. On by default.
- **Notify me when a reply arrives** shows a desktop notification. Off by default. Your browser asks for permission the first time you turn it on, and nothing is shown while you are looking at LibreChat.
- **Play a sound for new replies** plays a short chime. Off by default. Browsers block audio until you have clicked somewhere on the page, so the first chime after opening a tab may stay silent.

The toggles are per device; the unread state itself is saved to your account (see [Unread Replies](/docs/features/navigation#unread-replies)). If one of these toggles is missing, your administrator turned it off with [`interface.replyNotifications`](/docs/configuration/librechat_yaml/object_structure/interface#replynotifications).

**Resize images before upload** can be locked: if an administrator sets [`fileConfig.clientImageResize.enabled`](/docs/configuration/librechat_yaml/object_structure/config#clientimageresize), the toggle is disabled and follows that value.

## Speech

Turn **Speech to Text** and **Text to Speech** on or off, pick the engine, language and voice, set the playback rate, and choose whether replies play automatically. Which engines appear depends on what the deployment set up; see [Speech to Text and Text to Speech](/docs/configuration/stt_tts).

## Data & Privacy

- **Memory**: **Reference saved memories** lets the assistant use your [memories](/docs/features/memory). Saved to your account, so it applies on every device.
- **Code execution**: **Default stateful workspace** and **Code environments**, when the deployment offers stateful code sessions.
- **Your data**: **Import conversations**, **Shared chats** (manage your [shared links](/docs/features/shareable_links)), **Manage files**, **Archive all chats**, and **Allow analytics** if the deployment collects analytics. **Archive all chats** moves every active chat to [Archived chats](/docs/features/navigation#archived-conversations) without deleting anything.
- **API keys**: **Provider API keys** for endpoints that ask for your own key, **Agent API keys** for the Agents API, and **Revoke all provider API keys**.
- **Danger zone**: **Delete cache** clears text-to-speech audio cached in this browser. **Delete all chats** permanently deletes your conversations.

## Account

**Avatar** and, for email logins where it is allowed, **Email address**. Under **Security**: **Two-factor authentication**, **Backup codes** once two-factor is on, and **Passkeys** if the deployment supports them. **Pull request account** connects GitHub or another git host for [pull requests](/docs/features/pull_requests). **Token balance** and **Auto-refill** appear when the deployment tracks balances, and **Delete account** when it allows users to delete themselves.

## Keyboard Shortcuts

Open the account menu and choose **Help**, then **Keyboard Shortcuts** (or press <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>/</kbd>). Click a row to record a new combination; it needs <kbd>Cmd</kbd>, <kbd>Ctrl</kbd> or <kbd>Alt</kbd>, and LibreChat warns you if another action already uses it. **Reset all to defaults** undoes your changes. The rows under **Open panels** (agents, prompts, memories, parameters, files, bookmarks, MCP settings) have no keys until you assign one.

The **Keyboard Shortcuts** switch at the top turns every shortcut off and hides the hints in the interface. Your custom keys are kept for when you turn it back on. Both the switch and your bindings are saved in this browser.
