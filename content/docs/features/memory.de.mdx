Memory ist ein kleiner Speicher mit Fakten über dich, die als Schlüssel-Wert-Paare gespeichert werden und die LibreChat dem Kontext jeder neuen Nachricht hinzufügt. Sag dem Modell einmal „Merke dir, dass ich Python schreibe und kurze Antworten bevorzuge“, und es wird dies auch in deinem nächsten Gespräch wissen.

Es handelt sich nicht um eine Suche in Ihrem Chatverlauf. Inhalte aus älteren Unterhaltungen werden nur abgerufen, wenn sie als Memory-Eintrag gespeichert wurden, und der gesamte Speicher wird in jede Anfrage aufgenommen. Er ist daher für einige wenige dauerhafte Fakten gedacht, nicht für Notizen oder Dokumente.

## Eine Erinnerung speichern [#saving-a-memory]

Klicken Sie auf **+** im [Nachrichteneditor](/docs/features/composer), um die Palette zu öffnen, und wählen Sie anschließend **Memory** im Abschnitt **Tools** aus. Ist die Option aktiviert, erhält das Modell zwei Tools, `set_memory` und `delete_memory`, und wird angewiesen, diese nur dann zu verwenden, wenn Sie es bitten, etwas zu speichern, zu aktualisieren oder zu vergessen. Eine Nachricht wie „remember that my team uses pnpm“ erzeugt in der Antwort einen Schritt „Saved memory“, der mit dem Schlüssel des Speichereintrags beschriftet ist; klappen Sie ihn auf, um den gespeicherten Wert zu sehen. „Forget where I work“ erzeugt „Deleted memory“. Führt das Modell in einer Antwort mehrere Speicheraufrufe aus, werden diese unter einem einzigen Schritt zusammengefasst, etwa „Ran 2 actions“.

Die Option „Memory“ wird nur angezeigt, wenn deine Rolle das Erstellen und Aktualisieren von Erinnerungen erlaubt. Wenn du mit einem Agenten chattest, enthält die Palette keine Option „Memory“; der Agent verwendet den Speicher, sofern Memory im Agent Builder aktiviert ist.

Ein Agent kann außerdem so eingestellt werden, dass **Erinnerungen für diesen Agenten getrennt gespeichert werden**: Er liest und schreibt dann in seinem eigenen Speicher, der von deinen gemeinsamen Erinnerungen und von anderen Agenten isoliert ist. Diese Einträge folgen dem Zugriff auf den Agenten: Verlierst du den Zugriff auf ihn, können seine separaten Erinnerungen nicht mehr gelesen oder aktualisiert werden, du kannst die Erinnerungen eines entfernten Agenten jedoch weiterhin löschen.

Manche Bereitstellungen betreiben zusätzlich einen Hintergrund-Speicheragenten, der jeden Austausch prüft und Fakten eigenständig speichert, ohne dass Sie darum bitten. Ob das geschieht, entscheidet Ihr Administrator.

## Erinnerungen anzeigen und bearbeiten [#viewing-and-editing-memories]

Öffnen Sie **Memories** im Seitenbereich, um alles zu sehen, was über Sie gespeichert wurde. Von dort aus können Sie:

- Filtere die Liste nach Schlüssel oder Wert oder nach Agent, wenn du agentenspezifische Erinnerungen hast (gekennzeichnet als "Agent-scoped memory").
- Klicke auf **+** (**Create Memory**), um selbst einen Eintrag hinzuzufügen. Schlüssel verwenden nur Kleinbuchstaben und Unterstriche, und jeder Schlüssel darf nur einmal vorkommen.
- Bearbeiten oder löschen Sie jeden Eintrag.

Wenn Ihr Administrator ein Größenlimit festlegt, zeigt das Panel an, wie viel davon Sie verwenden. Sobald der Speicher voll ist, schlagen neue Speichervorgänge mit „Memory Storage Full“ fehl, bis Sie etwas löschen. Auch einzelne Einträge haben eine maximale Länge.

## Memory für sich selbst deaktivieren [#turning-memory-off-for-yourself]

Die Schaltfläche **Use memory** im Bereich Memories, die auch als **Reference saved memories** unter **Settings** > **Data & Privacy** verfügbar ist, steuert, ob deine gespeicherten Erinnerungen deinen Unterhaltungen hinzugefügt werden. Wenn du sie deaktivierst, fügt LibreChat sie nicht mehr hinzu und bietet das Memory-Tool nicht mehr an; deine Einträge bleiben erhalten und stehen wieder zur Verfügung, sobald du die Option erneut aktivierst.

Dieser Schalter wird nur angezeigt, wenn Ihr Administrator es Benutzern erlaubt, sich abzumelden. Der Speicher kann außerdem nach Rolle eingeschränkt werden, daher sehen manche Benutzer möglicherweise das Panel, können aber keine Einträge erstellen oder bearbeiten.

## Einrichtung [#setup]

Der Speicher ist deaktiviert, bis ein Administrator einen `memory`-Abschnitt in `librechat.yaml` hinzufügt. Der Hintergrund-Speicheragent ist eine separate Option, die aktiviert werden muss und ein eigenes Modell benötigt. Informationen zu Grenzwerten, zulässigen Schlüsseln, dem Speicheragenten und zur Fehlerbehebung finden Sie unter [Speicherkonfiguration](/docs/configuration/librechat_yaml/object_structure/memory).
