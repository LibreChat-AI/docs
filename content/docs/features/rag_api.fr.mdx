La recherche de fichiers vous permet de téléverser des documents et de poser des questions à leur sujet sans coller leur contenu dans le chat. LibreChat envoie chaque fichier à l'API RAG, qui le découpe en fragments et les indexe ; lorsque vous posez une question, le modèle parcourt cet index et répond à partir des passages trouvés.

Utilisez-le lorsqu'un document est trop long pour être lu intégralement à chaque tour, ou lorsque vous souhaitez obtenir des réponses couvrant plusieurs fichiers à la fois.

## Télécharger un fichier pour la recherche [#upload-a-file-for-search]

Cliquez sur **+** dans le [compositeur de messages](/docs/features/composer) pour ouvrir la palette, développez **More upload options**, puis choisissez **Upload for File Search** et sélectionnez vos fichiers. Rechercher cette option dans la palette fonctionne également. Ce mode de téléversement active aussi **File Search** pour la conversation. Les fichiers volumineux peuvent prendre un moment à être indexés ; le téléversement se termine une fois l'indexation terminée.

Une fois que les fichiers de la conversation sont indexés, le modèle dispose d'un outil `file_search`. C'est lui qui décide quand l'appeler : une question portant sur le document déclenche une recherche, tandis qu'une conversation banale n'en déclenche pas. La réponse affiche une étape « Recherche dans vos fichiers » pendant son exécution. Lorsque les citations sont activées, les passages utilisés apparaissent sous **Sources** avec le nom du fichier, afin que vous puissiez ouvrir le document et vérifier.

## Comment fonctionne la recherche [#how-search-works]

Lorsque le modèle appelle `file_search`, il rédige une requête de recherche. LibreChat demande à l'API RAG les 5 fragments les plus proches dans chaque fichier joint, et conserve les 10 fragments les plus proches au total. Ces fragments sont renvoyés au modèle avec le nom de leur fichier et un score de pertinence, et le modèle répond à partir de ceux-ci.

La recherche (retrieval) trouve des passages dont le sens est proche de celui de la requête, ce qui la rend efficace pour rechercher des faits précis dans de longs documents. Pour les questions qui nécessitent le document entier à la fois, comme un résumé, l'option Upload as Text donne généralement de meilleurs résultats.

Supprimer un fichier dans LibreChat supprime également ses vecteurs de l'API RAG.

## Réutiliser les fichiers que vous avez déjà téléversés [#reuse-files-you-already-uploaded]

Les fichiers indexés restent dans votre compte. Ouvrez la palette et consultez la section **Vos fichiers** pour joindre un fichier à un nouveau message ou à une nouvelle conversation sans le téléverser à nouveau.

Les fichiers téléversés pendant qu'un point de terminaison Assistants était actif sont stockés chez OpenAI, ne sont pas indexés par l'API RAG et ne peuvent pas être attachés à d'autres points de terminaison.

## Recherche de fichiers dans les agents [#file-search-in-agents]

Pour un agent, activez la [**Recherche de fichiers**](/docs/features/agents#file-search) dans le Créateur d'agents et téléversez-y des fichiers. Ils deviennent la base de connaissances de l'agent : tous les utilisateurs qui discutent avec l'agent peuvent lui demander de rechercher dans ces fichiers, sans rien téléverser eux-mêmes. L'agent doit être enregistré avant que vous puissiez y ajouter des fichiers.

## Recherche de fichiers ou téléversement sous forme de texte [#file-search-or-upload-as-text]

[**Télécharger comme texte**](/docs/features/upload_as_text) se trouve dans le même menu. Il extrait le texte du fichier et insère l'intégralité de celui-ci dans la conversation, ce qui convient aux documents courts dont le modèle doit lire chaque mot. La recherche de fichiers n'envoie que les passages correspondant à chaque requête ; elle s'adapte donc aux documents longs et aux nombreux fichiers, mais le modèle ne voit jamais les parties qu'elle n'a pas récupérées.

The RAG API prend également en charge Upload as Text, en tant qu'extracteur de texte pour les types de fichiers que l'analyseur intégré ne peut pas lire. Voir [comment le texte est extrait](/docs/features/upload_as_text#how-the-text-is-extracted).

## Configuration [#setup]

La recherche de fichiers nécessite le service RAG API et une base de données vectorielle. La configuration Docker par défaut inclut les deux ; un administrateur définit le fournisseur d'embeddings et, pour les autres installations, `RAG_API_URL`. Consultez la [configuration de RAG API](/docs/configuration/rag_api), ainsi que le [dépôt RAG API](https://github.com/LibreChat-AI/rag-api) pour les points de terminaison et les variables propres au service.
