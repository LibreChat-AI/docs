A shared link is a read-only copy of a conversation that other people can open in their browser. Recipients see the messages, every branch, and any artifacts, but they can't reply in your chat. If they want to keep going, they can copy it into their own account.

## Share a conversation

Open **Share** from either place:

- the conversation's menu in the sidebar, or
- the **Chat options** menu (the `...` button) in the header of an open chat.

The **Share link to chat** dialog opens. Select **Create a shared link** and LibreChat publishes the conversation up to the latest message of the branch you're on, then shows the link with a QR code under it.

Your name and any custom instructions are not included. A chat with no saved messages can't be shared yet, and if the latest message is still being saved, the dialog asks you to try again in a moment.

Once a chat has a link, it shows a link icon in the sidebar list, and the **Chat options** button in the header shows a small dot. To list only those chats, use the **Shared only** filter in the [chat list menu](/docs/features/navigation#filter-and-sort-the-chat-list).

### Files

If your admin allows it, the dialog has a **Share files in this conversation** switch, on by default. With it on, recipients can preview and download the images and files from the conversation through the link. With it off, those files are hidden from viewers. The files are copied as they were when you shared; if you later delete or replace the original, the link stops serving it.

## What's in the link, and updating it

A link is a snapshot. Messages you send after sharing do not show up until you select **Update link** (the circular arrow button) and confirm. Updating republishes the latest messages and your current file choice to the same URL, so anyone who already has the link sees the new version.

Edits to messages that are already in the snapshot show up right away, without an update.

**Delete Link** removes the link for everyone who has it. Deleting the conversation itself also breaks the link; visitors see "Shared link not found". If a link fails to load for some other reason, the page offers **Retry**.

If the conversation is a [temporary chat](/docs/features/temporary_chat), or your instance deletes chats after a retention period, the link expires when the conversation does.

## Who can open a link

When you create a link, it starts in one of two states, depending on the permissions your role has:

- **Shared with everyone**: anyone signed in to this LibreChat instance can open it. If the admin allows public links, people without an account can open it too.
- **Private**: only you, until you grant access to specific people.

Select **Manage Access** (the people icon) to change this. You can add specific users (and groups or roles, if the admin has enabled them in the people picker), or turn **Share with everyone** on or off. The button only appears if your role is allowed to share links.

## What recipients see

The shared page shows the title, the date the snapshot was published, and the conversation. Recipients can:

- switch between branches with the arrows under a message,
- open artifacts (React components, HTML previews, Mermaid diagrams) and read their code,
- change the theme and language from the settings menu on the page, without affecting your settings.

### Continue a shared chat

**Continue this chat** copies the branch the recipient has selected (only the direct path to the message on screen, plus any shared files on it) into their own account, and opens it as a normal chat they can reply to. The shared link and your conversation are not changed. Recipients who aren't signed in are sent to the login page first. If you updated the link while they had it open, LibreChat reloads the latest version and asks them to try again.

## Manage all your links

Go to **Settings** > **Data & Privacy** and select **Manage** next to **Shared chats**. The dialog lists every link you've created with its date. You can search by title, open the source chat in a new tab, delete a single link, or select several and delete them at once.

## Setup

Shared links are on by default. Admins can turn the feature off, allow public (no login) viewing, or disable file sharing with the `ALLOW_SHARED_LINKS`, `ALLOW_SHARED_LINKS_PUBLIC`, and `SHARED_LINKS_SNAPSHOT_FILES` variables in the [.env reference](/docs/configuration/dotenv#shared-links). Which roles can create links, share them, or share with everyone is a role permission, set in the Admin Panel or seeded from [`interface.sharedLinks`](/docs/configuration/librechat_yaml/object_structure/interface#sharedlinks).
