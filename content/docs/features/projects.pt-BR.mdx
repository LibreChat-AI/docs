Um projeto é uma pasta para conversas que pertencem juntas, como um cliente, um curso ou um trabalho extenso. Os chats em um projeto compartilham as instruções do projeto e podem usar seus arquivos de referência, assim você define o contexto uma única vez, em vez de repeti-lo em cada novo chat.

Projetos são pessoais. Ninguém mais vê seus projetos nem quais chats estão neles, e um projeto não pode ser compartilhado nem transferido para outra pessoa. Um projeto não define um modelo: cada chat mantém seu próprio modelo, agente e parâmetros.

## Criar um projeto [#create-a-project]

Na barra lateral, o cabeçalho da seção **Projects** tem um botão **All projects** que abre a página de projetos; escolha **New project** ali. (Até que você tenha um projeto, a seção da barra lateral mostra **New project** diretamente.) Dê a ele um nome de até 100 caracteres e, se quiser, uma descrição, e depois selecione **Create project**. O LibreChat abre o espaço de trabalho do novo projeto.

A página de projetos exibe cada projeto como um cartão com sua descrição e a quantidade de conversas. **Pesquisar projetos** busca por nomes e descrições, e o menu de ordenação oferece **Atividade mais recente**, **Criação** e **Nome**.

## Iniciar ou mover conversas [#start-or-move-chats]

A partir do workspace de um projeto, ou do ícone de nova conversa ao lado do projeto na barra lateral, inicie um chat com **New chat in** seguido do nome do projeto. A caixa de mensagem exibe um chip do projeto: use-o para trocar para outro projeto ou selecione seu × para remover o projeto antes de enviar. Depois de enviado, o chat pertence ao projeto.

Para arquivar um chat existente em um projeto, abra o menu dele e escolha **Change project**, depois selecione um projeto na lista pesquisável. **Remove from project** o retira novamente. No desktop, você também pode arrastar um chat até um projeto na barra lateral. Um chat passa a usar as instruções e os arquivos do projeto a partir da sua próxima mensagem e deixa de usá-los assim que sai do projeto.

Um chat dentro de um projeto exibe o nome do projeto no topo da conversa; selecione-o para abrir o workspace. Na barra lateral, cada projeto se expande para listar os seus chats, e a lista principal **Chats** mostra apenas os chats fora de qualquer projeto. O workspace do projeto lista somente os seus próprios chats, ordenados por **Atualizado** ou **Criado**.

## Instruções [#instructions]

**Instruções** no workspace contêm o contexto, o tom ou os objetivos de todos os chats do projeto. Selecione **Editar** para alterá-las. As regras de sistema do seu servidor continuam sendo aplicadas por cima.

As instruções se aplicam às mensagens enviadas após você salvá-las, em conversas regulares, conversas com agentes e conversas com Assistants. As respostas anteriores não são reescritas. Elas podem ter até 16.000 caracteres por padrão.

Se você editou o projeto em outra aba nesse meio tempo, o salvamento falha com **Este projeto foi alterado em outra sessão. Recarregue para ver a versão mais recente.** Recarregue a página e faça a alteração novamente.

## Arquivos [#files]

**Arquivos** armazena documentos de referência do projeto. Use **Adicionar arquivos** para enviar com **Enviar do dispositivo** ou escolha um arquivo enviado anteriormente com **Escolher dos seus arquivos**. Cada arquivo mostra **Processando** enquanto é indexado e **Pronto** quando os chats já podem usá-lo. **Escolher dos seus arquivos** lista apenas os arquivos que foram enviados para pesquisa em arquivos e que não expiraram. Um arquivo que posteriormente for excluído ou expirar continua listado como **Indisponível** e é ignorado.

Os chats no projeto pesquisam esses arquivos e trazem apenas as passagens relevantes, não documentos inteiros. Isso só acontece quando a **Pesquisa de Arquivos** está ativada para o chat ou agente. Se o seu servidor não tiver configurado a pesquisa de arquivos, ou se a sua função não tiver permissão para usá-la, você não poderá enviar novos arquivos ao projeto.

Um projeto comporta até 50 arquivos, a menos que seu administrador tenha alterado o limite. Remover um arquivo afeta apenas as mensagens futuras; respostas que já o utilizaram permanecem como estão.

## Renomear ou excluir [#rename-or-delete]

Clique no nome ou na descrição do projeto no workspace para editá-lo, ou use **Editar projeto** no menu do projeto na barra lateral.

**Excluir projeto**, no menu **Opções do projeto** do espaço de trabalho ou como **Excluir** no menu da barra lateral, solicita confirmação e remove apenas o projeto. Seus chats permanecem no seu histórico, sem estarem mais atribuídos a nenhum projeto. Se você estiver visualizando um projeto no momento em que ele for excluído, o LibreChat o redirecionará para a página de projetos.

## Configuração [#setup]

Os projetos estão disponíveis para todos os usuários a partir da versão 0.8.7 do LibreChat; nenhuma configuração ou permissão de função os oculta. Administradores podem alterar o limite de arquivos por projeto e o tamanho máximo das instruções e descrições na chave [`projects`](/docs/configuration/librechat_yaml/object_structure/config#projects) em `librechat.yaml`. Os arquivos de projeto dependem da [pesquisa em arquivos](/docs/features/rag_api).
