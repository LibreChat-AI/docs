Projetos permitem que cada usuário organize conversas relacionadas em espaços de trabalho nomeados. Eles são úteis para fluxos de trabalho de longa duração, equipes, clientes, aulas ou qualquer tópico onde você queira um conjunto focado de chats que compartilhem o mesmo contexto sem repeti-lo em cada conversa.

<Callout type="info" title="Disponibilidade">
  Projetos foram adicionados ao LibreChat na **v0.8.7**. Não existe uma opção ou permissão de função que oculte Projetos, portanto, todo usuário conectado em uma versão compatível possui o recurso. Administradores podem ajustar as instruções, a descrição e os limites de arquivos com o bloco [`projects`](/docs/configuration/librechat_yaml/object_structure/config#projects) no `librechat.yaml`. Se você não conseguir encontrar Projetos em lugar algum na interface, a instância está executando uma versão mais antiga e precisa ser atualizada.
</Callout>

## O que os Projects fazem [#what-projects-do]

- Agrupe conversas em um workspace nomeado com uma descrição opcional
- Dê a cada chat no projeto as mesmas **Instructions**
- Anexe **Files** de referência que os chats no projeto podem pesquisar
- Inicie um novo chat já vinculado a um projeto, ou mova chats existentes para dentro ou para fora dele
- Navegue, ordene, mova, remova ou exclua chats do espaço de trabalho do projeto
- Pesquise projetos por nome ou descrição e ordene-os por atividade mais recente, data de criação ou nome

Projetos são pessoais para o usuário que os cria. Outros usuários não veem sua lista de projetos, e um projeto não pode ser compartilhado ou transferido. Projetos não carregam configurações de modelo: cada chat mantém seu próprio modelo, Agent e parâmetros.

## Criar um Projeto [#create-a-project]

<Steps>
<Step>

**Abra a página de projetos.** Na barra lateral, o cabeçalho da seção **Projects** possui um botão **All projects** que a abre.

</Step>
<Step>

**Escolha New project**, que está sempre disponível no cabeçalho da página de projetos.

</Step>
<Step>

**Dê um nome ao projeto.** Um nome é obrigatório e uma descrição é opcional. O LibreChat abrirá então o espaço de trabalho do projeto.

</Step>
</Steps>

Embora você ainda não tenha projetos, a seção **Projects** na barra lateral também oferece um botão **New project**. Assim que você tiver projetos, a seção será expandida por padrão até que você a recolha.

Os nomes dos projetos são limitados a 100 caracteres. As descrições são limitadas a 1.000 caracteres por padrão, e nomes de projetos duplicados são permitidos.

A página de projetos mostra cada projeto como um cartão de pasta com sua descrição e contagem de chats.

## Instruções [#instructions]

As Instructions definem o tom, os objetivos ou o contexto para cada chat no projeto, por exemplo, o guia de estilo de um cliente ou o curso ao qual um conjunto de chats pertence. As regras da plataforma e de segurança ainda se aplicam sobre elas.

<Steps>
<Step>

**Abra o workspace do projeto** e encontre a seção **Instructions**.

</Step>
<Step>

**Escolha Edit** para abrir a caixa de diálogo de instruções.

</Step>
<Step>

**Insira as instruções do workspace e salve.** Por padrão, as instruções podem ter até 16.000 caracteres.

</Step>
</Steps>

As Instructions são usadas para novas mensagens no projeto. Alterá-las não reescreve mensagens anteriores: as respostas que já foram geradas permanecem como estão, e a próxima mensagem em qualquer um dos chats do projeto usa a versão atual. As Instructions se aplicam a chats de modelos regulares e Agents, e a conversas de Assistants.

Se o projeto foi alterado em outra sessão enquanto a caixa de diálogo estava aberta, salvar exibirá **This project was changed in another session. Reload to see the latest version.** Recarregue e reaplique sua edição.

## Arquivos [#files]

Arquivos de projeto fornecem documentos para os chats do projeto referenciarem. Quando a Pesquisa de Arquivos está habilitada, os chats usam trechos relevantes desses arquivos em vez de arquivos inteiros.

Na seção **Files** do workspace, escolha **Add files** e então:

- **Upload from device** para enviar novos documentos. Cada envio mostrará **Processing** até que esteja **Ready**.
- **Escolha a partir de seus arquivos** para anexar arquivos que você já enviou.

Apenas arquivos que foram enviados para File Search (anexos de mensagens incorporados) e que não expiraram podem ser anexados, portanto, **Choose from your files** lista apenas esses arquivos. Um projeto comporta até 50 arquivos por padrão.

Os arquivos de projeto são usados através do File Search, portanto, um chat só pode lê-los quando:

- o Agent, ou o chat comum, está com **File Search** habilitado
- A Pesquisa de Arquivos (File Search) está habilitada para o endpoint Agents e o serviço de pesquisa de arquivos da implantação está disponível

Um arquivo que é excluído ou expira permanece listado como **Unavailable** e é ignorado. Remover um arquivo do projeto afeta mensagens futuras, não o histórico de chat.

## Trabalhar em um Projeto [#work-in-a-project]

Abra um projeto para ver sua descrição, instruções, arquivos e chats atribuídos. Selecione o nome ou a descrição do projeto para editá-los no local. A lista de **Chats** no espaço de trabalho pode ser classificada por data da última atualização ou data de criação.

Use **New chat** no cabeçalho da área de trabalho para abrir um compositor com escopo definido para o projeto; o chip do projeto confirma que a nova conversa será atribuída a ele. A barra lateral mostra a mesma ação em cada linha de projeto.

Os chats que pertencem a um projeto exibem um selo de projeto com o nome do projeto no topo da conversa. Selecione o selo para abrir o espaço de trabalho do projeto.

Cada chat de projeto possui um menu de opções com estas ações:

- **Change project** abre um seletor de projetos pesquisável
- **Remove from project** mantém a conversa, mas remove sua atribuição ao projeto
- **Delete** exclui a conversa após confirmação

## Mover Chats Existentes [#move-existing-chats]

Abra o menu de uma conversa e escolha **Change project**, então selecione o projeto ao qual deseja atribuí-la. Para remover um chat de um projeto, use **Remove from project**, que só é exibido para chats que já pertencem a um. No desktop, você também pode arrastar um chat para um projeto na barra lateral; veja [Sidebar and Navigation](/docs/features/navigation#desktop-sidebar).

O contexto do projeto é lido novamente a cada mensagem, portanto, um chat que você move para um projeto passa a utilizar as instruções e arquivos do projeto na próxima mensagem, e um chat que você remove de um projeto para de utilizá-los.

Na barra lateral, cada linha de projeto se expande para listar seus próprios chats, com **Show all** para listas mais longas. A seção **Chats** lista apenas as conversas que não estão em um projeto, portanto, um chat de projeto aparece em apenas um lugar. Três casos ainda listam todos os chats:

- enquanto você pesquisa conversas
- na visualização de **Chats arquivados** do [menu da lista de chats](/docs/features/navigation#filter-and-sort-the-chat-list)
- quando seus projetos falharem ao carregar

## Gerenciar Projetos [#manage-projects]

Use o menu de um projeto na barra lateral para:

- **Abrir projeto**
- **Editar projeto**, que abre o workspace com o nome e a descrição prontos para edição
- **Excluir** o projeto

A página de projetos oferece as mesmas ações de editar e excluir, e o cabeçalho do workspace possui um menu de opções de projeto com **Delete project**.

Excluir um projeto remove a atribuição do projeto de seus chats. As conversas em si não são excluídas.

## Encontrar um Projeto [#find-a-project]

A página de projetos possui uma caixa de **Search projects** que corresponde aos nomes e descrições dos projetos, e um controle de ordenação que oferece **Latest activity**, **Created** e **Name**. Listas mais longas são paginadas com **Load more**.

## Notas [#notes]

- Novos chats iniciados a partir de um projeto mantêm essa atribuição quando a conversa é criada.
- As pesquisas de projeto não diferenciam maiúsculas de minúsculas e correspondem tanto a nomes quanto a descrições.
- Se um projeto for excluído enquanto você o estiver visualizando, o LibreChat o levará de volta à lista de projetos.
