El compositor de mensajes es el cuadro en la parte inferior de cada chat. Además del campo de texto, contiene un botón **+** que abre todo lo que puedes añadir a un mensaje (archivos, herramientas, habilidades, servidores MCP y archivos que hayas subido anteriormente), las fichas (chips) de las herramientas que están activadas actualmente y los controles para razonamiento, dictado y envío.

## Qué hay en el composer [#whats-on-the-composer]

| Elemento | Qué hace |
|---|---|
| **+** (**Adjuntar y herramientas**) | Abre la paleta: opciones de carga, herramientas, habilidades, servidores MCP y tus archivos recientes, todo buscable desde un solo campo. |
| Chips de herramientas | Un chip por cada herramienta o servidor MCP que esté activo, junto al botón **+**. Elimina un chip para desactivar esa herramienta. |
| Contexto preparado | Archivos, citas y habilidades adjuntos a tu próximo mensaje, mostrados sobre el campo de texto. |
| **Pensando** | Esfuerzo de razonamiento para los modelos que lo soportan. |
| Uso del contexto | Cuánto de la ventana de contexto del modelo utiliza la conversación, cuando el uso de tokens está disponible. |
| **Usar micrófono** | Dicta tu mensaje con voz a texto, cuando la función de voz a texto está habilitada. |
| Enviar / Detener | Envía el mensaje o detiene la respuesta que se está transmitiendo. |

To see which keys apply right now, such as `/ for prompts`, `@ for models` or `Enter to send`, turn on **Show composer tips** in **Settings > General**. A one-line tip then appears under the text field. It is off by default.

## Agregar archivos [#add-files]

Haz clic en **+** y elige una opción en la sección **Attach**. También puedes arrastrar archivos al compositor o pegarlos.

De forma predeterminada, LibreChat utiliza el cargador unificado: solo seleccionas una fuente y este decide cómo llega cada archivo al modelo (carga nativa del proveedor, extracción de texto o una herramienta como File Search) a partir del tipo de archivo y el endpoint.

| Opción | Cuándo aparece |
|---|---|
| **From Local Computer** | Siempre, con el cargador predeterminado. |
| **From SharePoint** | Cuando el [SharePoint file picker](/docs/configuration/sharepoint) está habilitado. |

Si un administrador establece [`fileConfig.legacyFileUploadUX: true`](/docs/configuration/librechat_yaml/object_structure/file_config#legacyfileuploadux), usted elige el destino por su cuenta. La sección **Attach** muestra entonces la opción principal primero y oculta el resto detrás de **More upload options**:

| Opción | Cuándo aparece |
|---|---|
| **Upload to Provider** | El proveedor acepta documentos directamente (por ejemplo, OpenAI, Anthropic, Google, Bedrock, OpenRouter y endpoints personalizados, o Azure OpenAI con la API de respuestas activada). |
| **Upload Image** | Se muestra en lugar de **Upload to Provider** cuando el proveedor solo acepta imágenes. |
| **Upload as Text** | La [funcionalidad de contexto](/docs/features/upload_as_text) está habilitada. |
| **Upload for File Search** | La búsqueda de archivos (File Search) está habilitada y permitida para el agente actual. Seleccionarla también activa la búsqueda de archivos. |
| **Upload to Code Environment** | La ejecución de código está habilitada y permitida para el agente actual. Seleccionarla también activa **Run Code**. |
| **Attach Files** | Endpoints de Assistants, que gestionan archivos con la propia configuración del asistente. |

Con SharePoint habilitado en este modo, cada opción también tiene una versión de SharePoint, etiquetada por ejemplo como **Upload to Provider (From SharePoint)**.

### Reutilizar un archivo que subiste anteriormente [#reuse-a-file-you-uploaded-before]

La sección **Your files** de la paleta enumera los archivos que has utilizado recientemente. Selecciona uno para adjuntarlo de nuevo sin tener que subirlo. Escribir en el campo de búsqueda permite buscar todos tus archivos por nombre.

Seleccione **Show all** en la sección para explorar todos los archivos en un diálogo, con vistas de **All**, **Images** y **Documents**, un campo de búsqueda y una vista previa para imágenes y archivos PDF.

La paleta muestra hasta cinco archivos recientes. Los administradores pueden reducir ese número, o ocultar la lista con `0`, utilizando [`interface.composerRecentFiles`](/docs/configuration/librechat_yaml/object_structure/interface#composerrecentfiles).

## Activar herramientas, habilidades y servidores MCP [#turn-on-tools-skills-and-mcp-servers]

La paleta enumera todo lo que puede activar para la conversación actual, agrupado en secciones:

- **Herramientas**: herramientas integradas como **Web Search**, **Run Code**, **File Search**, **Skills**, **Memory** y **Artifacts**, cada una mostrada solo cuando está habilitada y tienes acceso a ella.
- **Skills**: [skills](/docs/features/skills) individuales que puedes adjuntar a tu próximo mensaje.
- **Servidores MCP**: los [servidores MCP](/docs/features/mcp) disponibles en el chat.

Seleccione una herramienta o servidor MCP para activarlo o desactivarlo. La paleta permanece abierta, por lo que puede cambiar varios en una sola visita. Cada herramienta que está activada aparece como una etiqueta (chip) en el compositor; elimine la etiqueta para desactivarla. Algunas etiquetas incluyen un menú de modo, por ejemplo, el modo de generación de **Artifacts**.

Seleccionar una skill la prepara para tu siguiente mensaje en su lugar: aparece en el [staged context](#staged-context) en lugar de como un chip.

Las filas de los servidores MCP muestran el estado de conexión de cada servidor. Seleccionar un servidor que no está conectado inicia su conexión (incluyendo un inicio de sesión OAuth, cuando el servidor lo requiere) o abre su configuración primero si necesita tus credenciales. Una vez conectados, los servidores que requieren credenciales de usuario también tienen un control de **Configure** en la fila, y **Web Search** tiene uno para sus claves de API.

<Callout type="info" title="Los agentes traen sus propias herramientas">
  Con un agente seleccionado, las secciones **Tools** y **MCP Servers** se ocultan, ya que la propia configuración del agente decide qué herramientas utiliza. En otros endpoint, un [model spec](/docs/configuration/librechat_yaml/object_structure/model_specs#hidebadgerow) con `hideBadgeRow: true` oculta las secciones **Tools**, **Skills** y **MCP Servers**. **Attach** y **Your files** permanecen disponibles en todos los casos.
</Callout>

### Mostrar todo [#show-all]

La paleta muestra un puñado de filas por sección. Elija **Show all** en el encabezado de **Skills**, **MCP Servers** o **Your files** para abrir un diálogo con la lista completa, un campo de búsqueda y filtros. Skills y MCP servers tienen tres vistas: **All**, **Made by you** y **Favorites**.

### Favoritos y herramientas ancladas [#favorites-and-pinned-tools]

Marca una fila con una estrella para añadirla a **Favoritos**, que se sitúa en la parte superior de la paleta. Con una fila resaltada, presiona <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd> en macOS) para marcarla o desmarcarla como favorita. Los Favoritos se guardan en tu cuenta.

Los administradores pueden fijar herramientas integradas con [`interface.defaultPinnedTools`](/docs/configuration/librechat_yaml/object_structure/interface#defaultpinnedtools). Una herramienta fijada mantiene su chip en el compositor incluso cuando está desactivada, por lo que puede activarla con un solo clic. Eliminar el chip de una herramienta fijada que está desactivada la desancla.

## Contexto escalonado [#staged-context]

Todo lo que adjuntes a tu próximo mensaje aparecerá sobre el campo de texto antes de que lo envíes:

- **Archivos**, con progreso de carga y una vista previa para imágenes. El texto largo pegado también puede aparecer aquí como un archivo, el cual puedes editar o mover de vuelta al mensaje.
- **Citas** que seleccionaste de mensajes anteriores.
- **Skills** que seleccionaste desde la paleta o con el comando `$`.

Elimina cualquier elemento con su botón de eliminar. Todo lo que esté preparado se enviará con tu próximo mensaje.

## Pensamiento y esfuerzo [#thinking-and-effort]

Para los modelos con una configuración de razonamiento, el control **Thinking** abre un control deslizante que va desde **Faster** (Más rápido) hasta **Smarter** (Más inteligente), además de los modos separados del proveedor, como **Auto** o desactivado. Cambia el mismo parámetro que el panel de Parameters, por lo que se oculta cuando el modelo no tiene una configuración de razonamiento o cuando la implementación desactiva los parámetros con `interface.parameters`.

## Encolar y dirigir mientras se transmite una respuesta [#queue-and-steer-while-a-response-streams]

Puedes seguir escribiendo mientras se transmite una respuesta. Dependiendo del endpoint y de tus ajustes, presionar <kbd>Enter</kbd> pone el mensaje en cola para enviarlo después de la respuesta o dirige la respuesta actual de un agente. El consejo del compositor indica la acción que <kbd>Enter</kbd> realiza en ese momento.

Los mensajes en cola aparecen en una barra de **Queued messages** sobre el compositor, donde puedes:

- **Editar mensaje** para moverlo de nuevo al campo de texto.
- **Remove message** para sacarlo de la cola.
- **Enviar ahora** para enviarlo inmediatamente en lugar de esperar.
- Reordena los mensajes arrastrándolos, o enfocando uno y presionando las teclas de flecha hacia arriba y hacia abajo.

Para obtener información sobre cómo funciona la dirección (steering) y cuándo está disponible, consulta [Steering and Queued Messages](/docs/features/agents#steering-and-queued-messages).

## Atajos de teclado [#keyboard-shortcuts]

### En el campo de texto [#in-the-text-field]

| Teclas | Acción |
|---|---|
| <kbd>Enter</kbd> | Enviar el mensaje (poner en cola o dirigir mientras se transmite una respuesta). |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Nueva línea. |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) | Mientras se transmite una respuesta: la acción alternativa, **enviar ahora** cuando <kbd>Enter</kbd> pone en cola, o **poner en cola** cuando <kbd>Enter</kbd> dirige. |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> (<kbd>Option</kbd>+<kbd>Enter</kbd>) | Mientras un agente responde: interrumpir y enviar, cuando esté disponible. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>) | Detener la respuesta. |
| `/` | Insertar un prompt guardado. |
| `@` | Cambiar a otro modelo, ajuste preestablecido o agente. |
| `+` | Añadir un modelo o ajuste preestablecido para una respuesta adicional. |
| `$` | Elegir una habilidad para el siguiente mensaje. |

Si desactivaste **Presionar Enter para enviar mensajes**, <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) envía el mensaje y <kbd>Enter</kbd> añade una nueva línea.

### En la paleta [#in-the-palette]

| Teclas | Acción |
|---|---|
| Escribir | Buscar herramientas, habilidades, servidores, opciones de carga y archivos. |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Moverse a través de las filas. |
| <kbd>Enter</kbd> | Seleccionar la fila resaltada. |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd>) | Agregar la fila resaltada a Favoritos, o eliminarla. |
| <kbd>Backspace</kbd> en una búsqueda vacía | Cerrar la paleta. |
| <kbd>Escape</kbd> | Cerrar la paleta. |
