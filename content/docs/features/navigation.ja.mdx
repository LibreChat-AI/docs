LibreChatのサイドバーでは、会話履歴、ピン留めされたチャット、プロジェクト、およびデプロイメントで有効化された追加パネルを利用できます。利用可能なパネルのリストには、チャット、ブックマーク、プロンプト、メモリ、およびSkillsが含まれます。

## デスクトップサイドバー [#desktop-sidebar]

サイドバーの切り替えを使用して、ナビゲーションを開閉します。ナビゲーションレールからパネルを選択するか、設定されている場合は会話検索を使用するか、**New chat** を選択して会話を開始します。プロジェクトには独自のサイドバーセクションとスコープ付きの新規チャットショートカットがあります。詳細は [Projects](/docs/features/projects) を参照してください。

統合された **Pinned** セクションでは、ピン留めされた会話と、お気に入りのモデル、Agent、プリセットが混在して表示されます。ポインターベースのデスクトップ環境では、アイテムをドラッグして並べ替えることができます。会話を **Pinned** にドラッグするとピン留めされ、プロジェクトにドラッグするとそのプロジェクトに整理され、**Chats** にドラッグするとプロジェクトの割り当てが解除されます。ピン留めされた会話は通常の履歴とは独立して読み込まれ、ピン留め、ピン留めの解除、または並べ替えは、新しい会話アクティビティとしてはカウントされません。タッチ操作の場合は、ドラッグ操作の代わりに既存のメニューを使用します。

## チャットリストのフィルタリングと並べ替え [#filter-and-sort-the-chat-list]

**Chats**見出しにある**Filter and sort chats**ボタンは、チャットリストメニューを開きます。このメニューには3つの行があり、それぞれ現在の値が表示されています：

- **Show** は **Active chats** と **Archived chats** を切り替えます。
- **Sort**（並び替え）では、リストを**Updated**（更新日時）、**Created**（作成日時）、または**Title**（タイトル）で並び替えることができます。アーカイブ表示では**Date Archived**（アーカイブ日時）も選択可能です。**Order**（順序）では、日付の場合は**Newest first**（新しい順）または**Oldest first**（古い順）を、タイトルの場合は**A to Z**（昇順）または**Z to A**（降順）を選択します。
- **Filter**（フィルター）はリストを絞り込みます。**Search filters**（検索フィルター）ボックスでは、名前でフィルターや値を検索できます。

**Filter** サブメニューでは、以下が提供されます：

| フィルター | 選択肢 |
| --- | --- |
| **更新日**, **作成日** | **いつでも**, **今日**, **過去7日間**, **過去30日間**, **過去1年間** |
| **Endpoint** | デプロイメントが提供する1つ以上のendpoint |
| **添付ファイルあり** | ファイルを含むチャットのみ |
| **共有のみ** | アクティブな共有リンクを持つチャットのみ。共有リンクが有効な場合に表示されます |
| **ブックマーク** | 1つ以上のブックマーク。ブックマークを使用できるロールに対して表示されます |

デフォルトのリストと異なる設定がある場合、ボタンには有効な設定の数が表示されます。メニューヘッダーの **Reset** はリスト全体を復元し、**Filter** サブメニュー下部の **Clear filters** はフィルターのみをクリアします。表示およびフィルターの選択内容は、リロードまたはサインアウトするまで保持されます。並び順は現在のブラウザに記憶されます。管理者は、[`conversationList`](/docs/configuration/librechat_yaml/object_structure/config#conversationlist) を使用して、1つのフィルターで選択できる endpoint の数を制限できます。

## 未読の返信 [#unread-replies]

別のチャットを開いている間やLibreChatから離れている間に返信が完了すると、その会話を開いて返信が画面に表示されるまで、チャットリストに未読ドットが表示されます。既読状態はアカウントに保存されるため、あるデバイスでチャットを開くと、他のデバイスのドットも消去されます。

後でチャットに戻るには、チャットのメニューを開いて **Mark as unread** を選択します。このオプションは、現在開いているチャットや、すでに未読状態のチャットには表示されません。

一時的なチャットは未読として表示されることはなく、最初のトークンが生成される前に停止された返信など、読むべき内容がない場合も同様です。タブタイトルのカウント、デスクトップ通知、およびサウンドについては、[Notifications](/docs/features/settings#notifications) を参照してください。

## モバイルドロワー [#mobile-drawer]

モバイルでは、サイドバーはデフォルトで全画面ドロワーとして開きます。そのヘッダーにはサイドバーの切り替えボタン、ラベル付きのパネルスイッチャー、**New chat**アイコンボタン、アカウントコントロールが配置されており、どのパネルでも共通です。Agent Marketplaceへのアクセス権を持つユーザーには、パネルコンテンツの上に**Agent Marketplace**の行も表示されます。ボトムバーには会話検索のみが配置され、これはチャット履歴パネルがアクティブな間のみ表示されます。

ブラウザ専用の **Settings > General > Layout > Show chat beside the sidebar on mobile** 設定は、デフォルトでオフになっています。これをオンにすると、ドロワーがビューポートの80%に制限され、現在の会話の薄暗い帯が表示されたままになります。その帯をタップすると、ドロワーが閉じて会話に戻ります。

タッチジェスチャーで操作することも可能です：

- チャットペインを右にスワイプしてドロワーを開きます。
- 開いているドロワー内で左にスワイプすると閉じます。

ドロワーはジェスチャーに追従し、距離と速度に基づいて開閉状態が決定されます。デフォルトの全幅ドロワーでは、ボタン、キーボード、または会話による操作で閉じると、新しく読み込まれたコンテンツを動かすことなく、すでに配置されているチャットが表示されます。チャットストリップが有効な場合、ドロワーと表示されている会話は一緒に移動します。どの終了パスでも、移動するサーフェスが再びインタラクティブになった後、ヘッダーのオープナーまたはチャットペインにフォーカスが戻ります。垂直スクロール、テキストフィールド、テキスト選択、およびコードブロックなどの水平方向にスクロール可能なコンテンツは、それぞれのジェスチャー制御を維持します。モーション低減設定が有効な場合、ドロワーとストリップのトランジションは無効になります。

## アーカイブされた会話 [#archived-conversations]

アカウントメニューから **Archived chats** を開き、アーカイブされた会話の閲覧や復元を行うか、[chat list menu](#filter-and-sort-the-chat-list) の **Show** を使用してサイドバーのリストをアーカイブ済みチャットに切り替えます。新しくアーカイブされたチャットは、アーカイブされた日時順に並べ替えられます。LibreChat がそのタイムスタンプを記録する前にアーカイブされた会話は、作成日に基づいて並べ替えられます。

会話を削除せずにアクティブなチャットリストをクリアするには、**Settings > Data Controls > Your data** にある **Archive all chats** を使用し、操作を確定してください。

アーカイブ、アーカイブ解除、ピン留め、およびピン留めの解除を行っても、会話のチャットアクティビティ時間は更新されなくなりました。これにより、履歴やプロジェクトのアクティビティは、実際の会話の変更に基づいた状態が維持されます。
