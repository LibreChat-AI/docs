### Zmienne [#variables]

Użyj `{{notes}}`, aby poprosić o tekst, lub `{{length:3 bullets|5 bullets}}`, aby zaproponować wybór:

```text
Summarize these notes in {{length:3 bullets|5 bullets}}.

Notes: {{notes}}
```

LibreChat prosi o podanie tych wartości, gdy używasz promptu w czacie. Zmienne specjalne, takie jak `{{current_date}}`, `{{current_datetime}}`, `{{iso_datetime}}` i `{{current_user}}`, są wypełniane automatycznie. Pozostałe zmienne pozostają jako dosłowny tekst, jeśli nic ich nie wypełni.

### Wersje i produkcja [#versions-and-production]

Zapisanie edycji tworzy nową wersję. Jedna wersja jest oznaczona jako **Production**. Biblioteka i menu `/` używają tej wersji.

| Ustawienie edytora | Co się dzieje po zapisaniu |
| --- | --- |
| **Zaawansowany edytor promptów** wyłączony | Lista wersji jest ukryta. Każdy zapis staje się wersją Production. |
| Zaawansowany edytor włączony; **Zawsze twórz nowe wersje promptów jako Production** włączone | Każdy zapis staje się wersją Production. Możesz także przeglądać wcześniejsze wersje. |
| Zaawansowany edytor włączony; automatyczna wersja Production wyłączona | Zapisz wersję, a następnie użyj **Deploy**, aby oznaczyć ją jako Production. |

Te ustawienia dotyczą Twojej przeglądarki. Wyłączenie zaawansowanego edytora włącza również automatyczną produkcję. Ten przełącznik możesz ponownie zmienić przy włączonym zaawansowanym edytorze.

### Produkcja czy przypięta wersja? [#production-or-a-pinned-version]

Wybierz **Production**, aby śledzić aktualizacje właściciela promptu. Wybierz konkretną wersję, aby zachować te same instrukcje do momentu zmiany linku.

![Przed promocją wersji 4 oba agenty używają wersji 3. Po promocji agent śledzący Production używa wersji 4, a agent przypięty do wersji 3 pozostaje przy wersji 3. Natywne ustawienia pamięci podręcznej mogą opóźnić aktualizację Production.](/images/features/prompts/production-vs-pinned.svg)

Dla promptów LibreChat **Production** oznacza wersję oznaczoną jako Production. Dla promptów Langfuse oznacza wersję z etykietą `production`.

### Kiedy instrukcje są rozwiązywane [#when-instructions-are-resolved]

Zapisanie agenta sprawdza prompt, ale nie kopiuje jego tekstu. LibreChat rozwiązuje link przy każdej turze. Aktualizacje natywnych promptów mogą być opóźnione przez [cache](/docs/configuration/librechat_yaml/object_structure/agents#linkedinstructions); linki Langfuse są pobierane za każdym razem.

Zmienne specjalne działają tak samo jak w [instrukcjach agenta w tekście](/docs/features/agents#instructions-from-a-saved-prompt). Zmienne niestandardowe, takie jak `{{notes}}`, **nie są uzupełniane** w przypadku powiązanych instrukcji. Model otrzymuje je jako dosłowny tekst.

<Callout type="warning" title="Jeśli prompt jest niedostępny">
  Agent uruchamia się z **pustymi instrukcjami**. Nie korzysta z zapisanego w nim tekstu wbudowanego.
Agent pamięci stanowi wyjątek: korzysta z jego domyślnych instrukcji.
</Callout>

## Prompty z Langfuse [#prompts-from-langfuse]

Zsynchronizowane prompty Langfuse mają ikonę chmury z etykietą **Managed in Langfuse**. Możesz je podglądać i używać w LibreChat. Edytuj ich treść, promuj wersje i usuwaj je w Langfuse.

        <img src="/images/features/prompts/langfuse-preview.jpg" alt="Podgląd promptu Langfuse tylko do odczytu z wersją, etykietami i opcją Open in Langfuse." loading="lazy" style={{ position: 'absolute', width: '168.09339%', maxWidth: 'none', top: '-42.24719%', left: '-34.04669%' }} />

Obsługiwane są wyłącznie **promptów tekstowych** z Langfuse. Otwarcie takiego promptu pobiera jego treść z Langfuse bez zapisywania jej w pamięci podręcznej. Usunięcie promptu w Langfuse pozostawia wpis w bibliotece LibreChat, ale wpis ten nie może już zostać rozwiązany.

### Linki Langfuse [#langfuse-links]

Administrator musi włączyć [synchronizację katalogu promptów](/docs/configuration/langfuse#prompt-catalog) oraz [instrukcje agenta Langfuse](/docs/configuration/langfuse#prompts-as-agent-instructions). Łączenie jest domyślnie wyłączone. Synchronizacja katalogu musi pozostać włączona, aby zapisane połączenia działały.

Jeśli łączenie jest wyłączone, prompty z Langfuse znikają z selektora w Builderze, z wyjątkiem zapisanego wyboru agenta. Builder wyświetla przy tym wyborze notatkę. Powiązanie pozostaje zapisane, ale agent działa bez tych instrukcji. Ponowne włączenie łączenia przywraca je bez konieczności edycji agenta.

## Udostępnianie i uprawnienia [#sharing-and-permissions]

Właściciel promptu może udostępnić go użytkownikom, grupom lub rolom z uprawnieniami **Viewer**, **Editor** lub **Owner**. Zobacz [Kontrola dostępu](/docs/features/access_control).

### Kto może linkować i kto może uruchamiać [#who-can-link-and-who-can-run]

| Zadanie | Wymagany dostęp |
| --- | --- |
| Korzystanie z biblioteki promptów | Uprawnienie `PROMPTS` `USE` przypisane do Twojej roli oraz dostęp do promptu. |
| Dodanie lub zmiana linku do promptu agenta | `PROMPTS` `USE` oraz VIEW na prompt, a także `AGENTS` `CREATE` dla nowego agenta lub EDIT dla istniejącego agenta. |
| Zachowanie lub usunięcie linku; przełączenie na instrukcje inline | Ten sam dostęp na poziomie agenta. Dostęp do promptu nie jest ponownie sprawdzany. |
| Czat z agentem, który używa promptu | Dostęp do czatu z agentem. Dostęp do powiązanego promptu nie jest wymagany. |
| Udostępnianie promptu | `SHARE` dla wybranych użytkowników, grup lub ról; `SHARE_PUBLIC` dla wszystkich. |

Współedytor bez dostępu do promptu widzi **Restricted prompt**. Może zastąpić link lub przełączyć się na instrukcje inline. Nie może zobaczyć jego celu. Widz-agent nigdy nie widzi linku.

Administratorzy ustawiają uprawnienia ról w [Panelu administratora](/docs/features/admin_panel) lub w [konfiguracji kontroli dostępu](/docs/configuration/access_control#feature-permissions). Delegowani administratorzy z uprawnieniem `manage:prompts` mogą przeglądać i łączyć dowolną grupę bez oddzielnego uprawnienia VIEW. Łączenie nadal wymaga uprawnienia `PROMPTS` `USE`.

## Szczegóły i rozwiązywanie problemów [#details-and-troubleshooting]

<Accordions type="single" collapsible>
  <Accordion title="Historia wersji, duplikowanie i przywracanie">
    Zmiana promptu, jego wersji lub źródła instrukcji dodaje wpis do historii wersji agenta.

    **Duplikuj** i **Przywróć** kopiują zapisany link bez ponownego sprawdzania uprawnień USE ani VIEW. Jeśli nowy edytor nie może wyświetlić promptu, Builder pokazuje **Ograniczony prompt**.
  </Accordion>
  <Accordion title="Co oznacza licznik użycia">
    Każdy połączony agent dodaje jedno użycie po pomyślnym zakończeniu inicjalizacji. Jest to ten sam licznik, który jest używany przez karty promptów i menu ukośnika. Przekazania (handoffs) i subagenty mogą dodać kilka użyć w jednej turze.

    Wznowienie wstrzymanego uruchomienia nie generuje dodatkowego użycia. Agent pamięci nigdy nie dolicza użycia.
  </Accordion>
  <Accordion title="Ograniczenia API do zarządzania">
    Ustaw linki do promptów w Agent Builder. Management API oraz jego specyfikacja OpenAPI nie akceptują ani nie zwracają `instructionsPrompt`.

    Zmiana `instructions` za pomocą tego API nie zmienia tego, czego używa powiązany agent. Pierwszeństwo ma powiązanie. Powiązania z Langfuse obsługują wyłącznie prompty tekstowe; natywne grupy promptów nie mają tego ograniczenia.
  </Accordion>
  <Accordion title="Rozwiązywanie problemów z komunikatami Buildera">

    | Wiadomość | Co zrobić |
| --- | --- |
| "Ten wybór promptu jest obecnie niedostępny." | Wybierz inny prompt lub wersję albo spróbuj ponownie, gdy problem zostanie rozwiązany. Wersja mogła zostać usunięta, zablokowana przez zasady lub być niedostępna w Langfuse. Łączenie może być wyłączone, a źródło grupy mogło ulec zmianie. |
| "Nie masz uprawnień do połączenia tego promptu." | Poproś administratora o uprawnienie `PROMPTS` `USE` lub właściciela o uprawnienie VIEW dla grupy. |
| "Nie masz dostępu do biblioteki promptów." | Selektor lub lista wersji wymaga uprawnienia `PROMPTS` `USE` oraz VIEW dla grupy. Poproś administratora lub właściciela. |
| "Źródło tego promptu jest obecnie niedostępne." | Sprawdź konfigurację synchronizacji z Langfuse lub zastąp połączenie. Synchronizacja może być wyłączona lub nieskonfigurowana, źródło mogło ulec zmianie, albo prompt mógł zostać zmieniony na prompt czatu. |
| "Nie udało się załadować promptów." | Spróbuj ponownie. Jeśli problem będzie się powtarzać, poproś administratora o sprawdzenie logów serwera. Jest to nieoczekiwany błąd ładowania, a nie błąd uprawnień ani źródła. |
| "Wybrana wersja (nie jest już dostępna)" | Natywna rewizja została usunięta. Wybierz **Production** lub inną wersję. |
| "Wersja N (nie jest już dostępna)" | Wersja Langfuse nie znajduje się już na liście. Wybierz **Production** lub inną wersję. |
| "Prompt z ograniczeniami" | Poproś o uprawnienie VIEW, zastąp połączenie lub przełącz się na instrukcje inline. Grupa mogła również zostać usunięta. Ten komunikat może pojawić się nawet dla właściciela agenta. |
| "Nie znaleziono promptu" | Grupa została usunięta. Wybierz inny prompt lub przełącz się na instrukcje inline. Użytkownicy z uprawnieniem `manage:prompts` lub rolą `ADMIN` zobaczą ten komunikat zamiast **Prompt z ograniczeniami**. |
| "Nie udało się zweryfikować połączonego promptu. Spróbuj ponownie." | Nieoczekiwany błąd uniemożliwił weryfikację. Spróbuj zapisać ponownie. |

  </Accordion>
</Accordions>
