### 변수 [#variables]

다음 문장을 한국어로 번역하면 다음과 같습니다.

`{{notes}}`를 사용하면 텍스트를 입력받을 수 있고, `{{length:3 bullets|5 bullets}}`를 사용하면 선택지를 제공할 수 있습니다.

```text
Summarize these notes in {{length:3 bullets|5 bullets}}.

Notes: {{notes}}
```

LibreChat은 채팅에서 프롬프트를 사용할 때 이 값들을 요청합니다. `{{current_date}}`, `{{current_datetime}}`, `{{iso_datetime}}`, `{{current_user}}`와 같은 특수 변수는 자동으로 채워집니다. 그 외의 변수는 채워지는 값이 없으면 그대로 리터럴 텍스트로 남습니다.

### 버전 및 프로덕션 [#versions-and-production]

편집을 저장하면 새 버전이 생성됩니다. 버전 중 하나는 **Production**으로 표시됩니다. 라이브러리와 `/` 메뉴는 해당 버전을 사용합니다.

| 편집기 설정 | 저장 시 일어나는 일 |
| --- | --- |
| **고급 프롬프트 편집기** 끔 | 버전 목록이 숨겨집니다. 저장할 때마다 Production이 됩니다. |
| 고급 편집기 켬; **항상 새 프롬프트 버전을 Production으로 만들기** 켬 | 저장할 때마다 Production이 됩니다. 이전 버전도 찾아볼 수 있습니다. |
| 고급 편집기 켬; 자동 Production 끔 | 버전을 저장한 다음 **Deploy**를 사용하여 Production으로 만듭니다. |

이 설정은 사용자의 브라우저에 적용됩니다. 고급 편집기를 끄면 자동 Production도 함께 켜집니다. 고급 편집기를 다시 켠 상태에서 이 스위치를 다시 변경할 수 있습니다.

### 프로덕션 또는 고정 버전? [#production-or-a-pinned-version]

**Production**을 선택하면 프롬프트 소유자가 업데이트한 내용을 따릅니다. 특정 버전을 선택하면 링크를 변경할 때까지 동일한 지침을 유지합니다.

![버전 4가 Production으로 승격되기 전에는 두 에이전트 모두 버전 3을 사용합니다. 승격 후에는 Production을 따르는 에이전트는 버전 4를 사용하고, 버전 3에 고정된 에이전트는 계속 버전 3을 사용합니다. 네이티브 캐시 설정으로 인해 Production 업데이트가 지연될 수 있습니다.](/images/features/prompts/production-vs-pinned.svg)

LibreChat 프롬프트의 경우 **Production**은 Production으로 표시된 리비전을 의미합니다. Langfuse 프롬프트의 경우에는 `production` 레이블이 지정된 버전을 의미합니다.

### 지침이 해석되는 시점 [#when-instructions-are-resolved]

에이전트를 저장하면 프롬프트를 확인하지만 해당 텍스트를 복사하지는 않습니다. LibreChat은 각 턴마다 링크를 해석합니다. 네이티브 프롬프트 업데이트는 [캐시](/docs/configuration/librechat_yaml/object_structure/agents#linkedinstructions)에 의해 지연될 수 있으며, Langfuse 링크는 매번 가져옵니다.

특수 변수는 [인라인 에이전트 지침](/docs/features/agents#instructions-from-a-saved-prompt)에서와 동일하게 작동합니다. `{{notes}}`와 같은 사용자 정의 변수는 연결된 지침에서 **채워지지 않습니다**. 모델은 이를 리터럴 텍스트로 받습니다.

<Callout type="warning" title="프롬프트를 사용할 수 없는 경우">
  해당 에이전트는 **빈 지침(empty instructions)**으로 해당 턴을 실행합니다. 저장된 인라인 텍스트는 사용하지 않습니다.
  메모리 에이전트는 예외로, 기본 지침을 사용합니다.
</Callout>

## Langfuse에서 가져온 프롬프트 [#prompts-from-langfuse]

Langfuse에서 동기화된 프롬프트에는 **Langfuse에서 관리됨**이라고 표시된 클라우드 아이콘이 있습니다. LibreChat에서 프롬프트를 미리 보고 사용할 수 있습니다. 프롬프트의 내용을 편집하고, 버전을 승격하고, 삭제하는 작업은 Langfuse에서 수행합니다.

Langfuse **텍스트 프롬프트**만 지원됩니다. 프롬프트를 열면 Langfuse에서 내용을 가져오며, 이 내용은 캐시되지 않습니다. Langfuse에서 프롬프트를 삭제하면 LibreChat 라이브러리에는 항목이 그대로 남지만, 해당 항목은 더 이상 내용을 불러올 수 없습니다.

### Langfuse 링크 [#langfuse-links]

[프롬프트 카탈로그 동기화](/docs/configuration/langfuse#prompt-catalog)와 [Langfuse 에이전트 지침](/docs/configuration/langfuse#prompts-as-agent-instructions)을 관리자가 활성화해야 합니다. 링크 연결은 기본적으로 꺼져 있습니다. 저장된 링크가 작동하려면 카탈로그 동기화가 계속 활성화되어 있어야 합니다.

연결을 비활성화하면 Langfuse 프롬프트는 Builder의 선택 목록에서 사라지며, 에이전트에 저장된 선택 항목만 예외로 남습니다. Builder에는 해당 선택 항목에 대한 안내 메시지가 표시됩니다. 연결 정보는 그대로 저장되지만, 에이전트는 해당 지침 없이 실행됩니다. 연결을 다시 활성화하면 에이전트를 수정하지 않아도 연결이 복원됩니다.

## 공유 및 권한 [#sharing-and-permissions]

프롬프트 소유자는 프롬프트를 사용자, 그룹 또는 역할에게 **Viewer**, **Editor**, 또는 **Owner** 권한으로 공유할 수 있습니다. [접근 제어](/docs/features/access_control)를 참조하세요.

### 누가 링크할 수 있고 누가 실행할 수 있는지 [#who-can-link-and-who-can-run]

| 작업 | 필요한 권한 |
| --- | --- |
| 프롬프트 라이브러리 사용 | 역할의 `PROMPTS` `USE` 권한과 해당 프롬프트에 대한 접근 권한. |
| 에이전트의 프롬프트 링크 추가 또는 변경 | 프롬프트에 대한 `PROMPTS` `USE` 및 VIEW 권한, 그리고 새 에이전트의 경우 `AGENTS` `CREATE`, 기존 에이전트의 경우 EDIT 권한. |
| 링크 유지 또는 제거; 인라인 지침으로 전환 | 동일한 에이전트 수준 접근 권한. 프롬프트의 접근 권한은 다시 확인하지 않음. |
| 프롬프트를 사용하는 에이전트와 채팅 | 해당 에이전트와 채팅할 수 있는 접근 권한. 연결된 프롬프트에 대한 접근 권한은 필요하지 않음. |
| 프롬프트 공유 | 선택한 사용자, 그룹 또는 역할의 경우 `SHARE`; 모든 사용자의 경우 `SHARE_PUBLIC`. |

공동 편집자가 프롬프트에 접근 권한이 없으면 **제한된 프롬프트**가 표시됩니다. 이 경우 링크를 교체하거나 인라인 지침으로 전환할 수 있습니다. 링크의 대상은 볼 수 없습니다. 에이전트 뷰어에는 링크가 전혀 표시되지 않습니다.

관리자는 [관리자 패널](/docs/features/admin_panel) 또는 [액세스 제어 구성](/docs/configuration/access_control#feature-permissions)에서 역할 권한을 설정합니다. `manage:prompts` 권한이 위임된 관리자는 별도의 VIEW 권한 없이도 모든 그룹을 조회하고 연결할 수 있습니다. 다만 연결하려면 여전히 `PROMPTS` `USE` 권한이 필요합니다.

## 세부 정보 및 문제 해결 [#details-and-troubleshooting]

<Accordions type="single" collapsible>
  <Accordion title="버전 기록, 복제, 되돌리기">
    프롬프트, 프롬프트 버전 또는 지침 소스를 변경하면 에이전트의 버전 기록에 항목이 추가됩니다.

    **Duplicate**와 **Revert**는 저장된 링크를 새 USE 또는 VIEW 검사 없이 복사합니다. 새 편집자가 해당 프롬프트를 볼 수 없는 경우, Builder에는 **Restricted prompt**가 표시됩니다.
  </Accordion>
  <Accordion title="사용량 횟수의 의미">
    각 연결된 에이전트는 초기화에 성공하면 사용 횟수를 1회 추가합니다. 이 카운터는 프롬프트 카드와 슬래시 메뉴에서 사용하는 것과 동일합니다. 핸드오프와 서브에이전트는 한 턴에서 여러 번의 사용 횟수를 추가할 수 있습니다.

    재개된 일시 중지 실행은 추가 사용량을 발생시키지 않습니다. 메모리 에이전트도 사용량을 추가하지 않습니다.
  </Accordion>
  <Accordion title="Management API 제한 사항">
    Agent Builder에서 프롬프트 링크를 설정합니다. Management API와 해당 OpenAPI 명세는 `instructionsPrompt`를 입력받거나 반환하지 않습니다.

    that API로 `instructions`를 변경해도 연결된 에이전트가 사용하는 내용은 바뀌지 않습니다. 연결(link)이 우선 적용됩니다. Langfuse 연결은 텍스트 프롬프트만 지원하며, 네이티브 프롬프트 그룹에는 이러한 제한이 없습니다.
  </Accordion>

    | 메시지 | 해야 할 일 |

## 구성 참조 [#configuration-reference]

- [Linked instructions](/docs/configuration/librechat_yaml/object_structure/agents#linkedinstructions): 타임아웃, 네이티브 캐시, 런타임 동작, 실패 원인.
- [Langfuse 설정 및 롤아웃](/docs/configuration/langfuse#prompts-as-agent-instructions): 모든 서버가 업데이트된 후에 링크 기능을 활성화하세요.
- [Feature permissions](/docs/configuration/access_control#feature-permissions): 역할별 프롬프트 접근 권한을 설정합니다. [`interface.prompts`](/docs/configuration/librechat_yaml/object_structure/interface#prompts)는 기본 역할의 권한을 초기값으로 설정합니다.
