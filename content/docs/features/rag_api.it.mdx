La ricerca nei file ti permette di caricare documenti e porre domande su di essi senza incollarne il contenuto nella chat. LibreChat invia ogni file alla RAG API, che lo suddivide in blocchi (chunk) e li indicizza; quando fai una domanda, il modello cerca nell'indice e risponde basandosi sui passaggi che trova.

Usalo quando un documento è troppo lungo per essere letto per intero a ogni turno, oppure quando vuoi ottenere risposte da più file contemporaneamente.

## Carica un file per la ricerca [#upload-a-file-for-search]

Clicca su **+** nel [compositore di messaggi](/docs/features/composer) per aprire la tavolozza, espandi **Altre opzioni di caricamento**, quindi scegli **Carica per File Search** e seleziona i tuoi file. Puoi anche cercarla direttamente nella tavolozza. Caricando in questo modo viene attivato anche **File Search** per la chat. I file di grandi dimensioni possono richiedere un po' di tempo per essere indicizzati; il caricamento termina al completamento dell'indicizzazione.

Una volta che i file della conversazione sono stati indicizzati, il modello riceve uno strumento `file_search`. È il modello a decidere quando richiamarlo: una domanda sul documento attiva una ricerca, mentre le conversazioni di cortesia no. Durante l'esecuzione, la risposta mostra un passaggio "Searching your files"; quando le citazioni sono abilitate, i passaggi utilizzati compaiono sotto **Sources** con il nome del file, così puoi aprire il documento e verificarli.

## Come funziona la ricerca [#how-search-works]

Quando il modello chiama `file_search`, scrive una query di ricerca. LibreChat chiede all'API RAG i 5 frammenti più vicini in ciascun file allegato e conserva i 10 più vicini in totale. Questi frammenti vengono restituiti al modello insieme al nome del file e a un punteggio di pertinenza, e il modello risponde basandosi su di essi.

Il recupero individua i passaggi il cui significato è vicino a quello della query, quindi è efficace nel cercare fatti specifici all'interno di documenti di grandi dimensioni. Per le domande che richiedono l'intero documento in una sola volta, come un riassunto, Upload as Text di solito dà risultati migliori.

Eliminare un file in LibreChat rimuove anche i suoi vettori dalla RAG API.

## Riutilizzare i file già caricati [#reuse-files-you-already-uploaded]

I file indicizzati restano nel tuo account. Apri la palette e cerca in **I tuoi file** per allegarne uno a un nuovo messaggio o a una nuova conversazione senza caricarlo di nuovo.

I file caricati mentre un endpoint Assistants era attivo vengono archiviati presso OpenAI, non vengono indicizzati dalla RAG API e non possono essere allegati ad altri endpoint.

## Ricerca di file negli agenti [#file-search-in-agents]

Per un agente, attiva [**File Search**](/docs/features/agents#file-search) nell'Agent Builder e carica lì i file. Diventano la base di conoscenza dell'agente: chiunque chatti con l'agente può fare in modo che cerchi in quei file, senza dover caricare nulla personalmente. L'agente deve essere salvato prima di poter aggiungere file.

## Ricerca nei file o caricamento come testo [#file-search-or-upload-as-text]

[**Carica come testo**](/docs/features/upload_as_text) si trova nello stesso menu. Estrae il testo del file e lo inserisce interamente nella conversazione, il che funziona per documenti brevi in cui il modello deve leggere ogni parola. La ricerca nei file invia solo i passaggi che corrispondono a ciascuna query, quindi si adatta a documenti lunghi e a molti file, ma il modello non vede mai le parti che non sono state recuperate.

L'API RAG gestisce anche Upload as Text, come estrattore di testo per i tipi di file che il parser integrato non è in grado di leggere. Vedi [come viene estratto il testo](/docs/features/upload_as_text#how-the-text-is-extracted).

## Setup [#setup]

La ricerca nei file richiede il servizio RAG API e un database vettoriale. La configurazione Docker predefinita include entrambi; un amministratore imposta il provider degli embeddings e, per le altre installazioni, `RAG_API_URL`. Vedi [configurazione di RAG API](/docs/configuration/rag_api) e il [repository di RAG API](https://github.com/LibreChat-AI/rag-api) per gli endpoint e le variabili del servizio stesso.
