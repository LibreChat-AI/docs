L'**API RAG (Retrieval-Augmented Generation)** è un servizio separato che indicizza i file caricati in LibreChat e restituisce i passaggi più pertinenti a una domanda, così che il modello possa rispondere basandosi sui tuoi documenti e non solo sui dati del suo addestramento.

È un'app Python FastAPI basata su LangChain, che memorizza gli embedding in PostgreSQL con l'estensione pgvector.

**Per configurarlo, consulta [Configurazione di RAG API](/docs/configuration/rag_api).**

In LibreChat, RAG alimenta la funzionalità **File Search** degli [Agenti](/docs/features/agents#file-search) (`file_search`). I file allegati alla File Search di un agente, oppure a un'esecuzione che seleziona File Search, vengono indicizzati dalla RAG API e recuperati su richiesta. Gli altri endpoint di chat non utilizzano l'indicizzazione né il recupero RAG, anche se possono comunque usare la RAG API per estrarre il testo, come descritto di seguito.

L'API RAG espone anche una route `/text` che LibreChat può utilizzare per estrarre il testo dai file caricati; vedi [Carica come testo](/docs/features/upload_as_text#what-happens-under-the-hood) per sapere quando si applica.

## Come funziona [#how-it-works]

1. **Indicizzazione.** Quando un file deve essere ricercabile (al caricamento nel File Search di un agente, oppure quando un'esecuzione di chat utilizza per la prima volta il File Search su un allegato), LibreChat lo invia alla RAG API, che suddivide il testo in blocchi sovrapposti (`CHUNK_SIZE` e `CHUNK_OVERLAP`), trasforma ciascun blocco in un embedding tramite il provider configurato e archivia i vettori in pgvector.
2. **Recupero.** Quando il modello invoca File Search, scrive una query di ricerca. LibreChat chiede all'API RAG i 5 frammenti più vicini in ciascun file allegato, quindi mantiene i 10 più vicini nel complesso.
3. **Rispondere.** Questi frammenti vengono restituiti al modello con il nome del file e un punteggio di pertinenza, e il modello risponde basandosi su di essi. Quando le [citazioni dei file](/docs/configuration/librechat_yaml/object_structure/interface#filecitations) sono abilitate, la risposta può citare i file utilizzati.

Eliminare un file in LibreChat rimuove anche i suoi vettori dalla RAG API.

Il recupero individua solo i passaggi semanticamente vicini alla query, quindi funziona al meglio per cercare fatti specifici in documenti di grandi dimensioni. Per le domande che richiedono l'intero documento, come riassumerlo, [Carica come testo](/docs/features/upload_as_text) di solito offre risultati migliori.

## Cos'è la RAG? [#what-is-rag]

La Retrieval-Augmented Generation (RAG) ancorano un modello linguistico a una fonte di conoscenza esterna. Invece di affidarsi solo a ciò che il modello ha appreso durante l'addestramento, l'applicazione recupera innanzitutto i frammenti pertinenti da quella fonte e li aggiunge al prompt; il modello genera quindi la risposta a partire da essi. Poiché la conoscenza risiede al di fuori del modello, è possibile aggiungere o aggiornare documenti senza riaddestrare nulla.
