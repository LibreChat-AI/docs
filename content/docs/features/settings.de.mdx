Öffnen Sie das Kontomenü und wählen Sie **Einstellungen**. Der Dialog enthält die Reiter **Allgemein**, **Chat**, **Sprache**, **Daten & Datenschutz** und **Konto** sowie **Langfuse** und **Info** bei Bereitstellungen, die diese anbieten. Wenn Sie ungefähr wissen, was Sie suchen, geben Sie es in **Einstellungen durchsuchen** ein: Die Suche berücksichtigt Bezeichnungen und verwandte Begriffe ("dunkel", "rtl", "einfügen") und springt zum passenden Reiter und Abschnitt.

Die meisten Einstellungen werden im aktuellen Browser gespeichert, nicht in Ihrem Konto. Eine Einstellung, die Sie auf Ihrem Laptop ändern, wird nicht auf Ihr Telefon übertragen. Ausnahmen sind unten vermerkt.

## Allgemein [#general]

| Einstellung | Funktion | Standard |
|---|---|---|
| Design | **System**, **Hell**, **Dunkel** oder ein Design mit hohem Kontrast in hell oder dunkel. | System |
| Sprache | Die Sprache der Benutzeroberfläche. | Browsersprache |
| Schriftgröße der Nachrichten | Textgröße der Nachrichten, von **Sehr klein** bis **Sehr groß**. | Mittel |
| UI-Skalierung | Skaliert die gesamte Benutzeroberfläche zwischen 50 % und 150 %, unabhängig vom Browser-Zoom. | 100 % |
| Chat-Richtung | **Automatisch**, von links nach rechts oder von rechts nach links. | Automatisch |
| Uhrzeitformat | System, 12-Stunden- oder 24-Stunden-Zeitangaben in Nachrichten, Zeitplänen und Datumsangaben. | System |
| Woche beginnt am | System, Sonntag oder Montag. Ändert die Reihenfolge der Wochentage in [Geplante Chats](/docs/features/scheduled_chats), nicht den Zeitpunkt, zu dem ein Zeitplan ausgeführt wird. | System |
| Chatbereich maximieren | Verbreitert die Gesprächsspalte. | Aus |
| Chat-Eingabe auf dem Willkommensbildschirm zentrieren | Platziert das Nachrichtenfeld in der Mitte eines neuen Chats. | Ein |
| Lia auf dem Willkommensbildschirm anzeigen | Ein kleines dekoratives Pixel-Maskottchen rund um das Nachrichtenfeld. Wird nur angezeigt, wenn die Bereitstellung dies erlaubt. | Aus |
| Schaltfläche „Zum Ende scrollen“ | Eine Schaltfläche, die zur neuesten Nachricht springt. | Ein |
| Chat neben der Seitenleiste auf Mobilgeräten anzeigen | Hält einen Streifen des Gesprächs neben der [mobilen Schublade](/docs/features/navigation#mobile-drawer) sichtbar; tippen Sie auf den Streifen, um die Schublade zu schließen. | Aus |
| Chat-Titel im Tab anzeigen | Verwendet den Gesprächstitel als Tab-Titel des Browsers. | Ein |
| Bildschirm während der Antwortgenerierung wach halten | Bittet den Browser, den Bildschirm während des Streamings einer Antwort nicht abzudunkeln oder zu sperren. | Ein |

Administratoren sehen hier auch einen **Admin Panel**-Link, wenn die Bereitstellung über ein solches verfügt.

### Benachrichtigungen [#notifications]

Diese Einstellungen steuern, wie du benachrichtigt wirst, wenn Antworten fertiggestellt werden, während du in einem anderen Chat oder einem anderen Tab bist:

- **Anzahl ungelesener Nachrichten im Tab-Titel anzeigen** zeigt die Anzahl der Chats mit ungelesenen Antworten im Titel und Symbol des Tabs an. Standardmäßig aktiviert.
- **Benachrichtige mich, wenn eine Antwort eintrifft** zeigt eine Desktop-Benachrichtigung an. Standardmäßig ist diese Option deaktiviert. Beim ersten Aktivieren fragt dein Browser nach der Berechtigung, und solange du LibreChat geöffnet hast, wird nichts angezeigt.
- **Einen Ton für neue Antworten abspielen** spielt einen kurzen Glockenton ab. Standardmäßig deaktiviert. Browser blockieren Audio, bis Sie irgendwo auf der Seite geklickt haben. Daher bleibt der erste Glockenton nach dem Öffnen eines Tabs möglicherweise stumm.

Die Schalter gelten pro Gerät; der Status "ungelesen" selbst wird in deinem Konto gespeichert (siehe [Ungelesene Antworten](/docs/features/navigation#unread-replies)). Wenn einer dieser Schalter fehlt, hat dein Administrator ihn mit [`interface.replyNotifications`](/docs/configuration/librechat_yaml/object_structure/interface#replynotifications) deaktiviert.

|---|---|---|

| Während der Generierung bewirkt Enter | Was das Senden tut, während eine Antwort noch gestreamt wird: **Steuern**, **Unterbrechen** oder **In Warteschlange**. Siehe [Composer](/docs/features/composer). | Steuern |
| Entwürfe lokal speichern | Behält nicht gesendeten Text und Anhänge auf diesem Gerät, bis die Nachricht gesendet wird. | Ein |
| Bilder vor dem Hochladen verkleinern | Verkleinert große JPEG-, PNG- und WebP-Bilder im Browser, bevor sie hochgeladen werden. | Ein |
| Lange Texte als Datei einfügen | Fügt sehr lange eingefügte Texte als Textdatei an, statt das Nachrichtenfeld zu füllen. Siehe [Als Text hochladen](/docs/features/upload_as_text). | Ein |
| Status der Werkzeug-Badges speichern | Neue Chats übernehmen die Werkzeug-Badges aus deinem letzten Chat, statt sie zurückzusetzen. | Aus |
| Befehle "@" / "+" / "/" umschalten | Schaltet die Befehle `@` (Modell oder Endpunkt wechseln), `+` (eine parallele Antwort hinzufügen) und `/` (einen Prompt einfügen) ein oder aus. `+` und `/` erscheinen nur, wenn diese Funktionen verfügbar sind. | Ein |
| Benutzernachrichten als Markdown darstellen | Formatiert deine eigenen Nachrichten als Markdown. | Ein |
| Lange Benutzernachrichten einklappen | Lange Nachrichten, die du gesendet hast, werden als Vorschau mit **Mehr anzeigen** angezeigt. Der vollständige Text bleibt auf der Seite zum Kopieren und Suchen erhalten. | Ein |
| Benutzername in Nachrichten anzeigen | Zeigt deinen Namen über deinen Nachrichten an, statt "Du". | Ein |
| LaTeX in Nachrichten verarbeiten | Rendert Mathematik. Wenn deaktiviert, wird die Inline-Mathematik `$...$` nicht mehr gerendert; `$$...$$`, `\(...\)` und `\[...\]` werden weiterhin dargestellt. | Ein |
| Denkprozess-Dropdowns standardmäßig öffnen | Klappt die Argumentation eines Modells aus, statt sie einzuklappen. | Aus |
| Sanftes Streaming von Text | Blendet neue Wörter ein, während eine Antwort gestreamt wird. Siehe [Sanftes Streaming](/docs/features/smooth_streaming). | Ein |
| Nachrichten als Rich Text kopieren | Beim Kopieren einer Nachricht wird zusätzlich eine formatierte Version in die Zwischenablage gelegt, zum Einfügen in Word, Outlook oder Teams. | Aus |
| Details von Werkzeugen automatisch ausklappen | Öffnet die Details von Werkzeugaufrufen standardmäßig. | Aus |
| Beim neuen Chat zum Chatverlauf wechseln | Ein neuer Chat, während Prompts, Erinnerungen oder ein anderes Panel geöffnet ist, schaltet die Seitenleiste zurück zu deinen Chats. | Ein |
| Beim Öffnen eines Chats zur neuesten Nachricht scrollen | Öffnet einen Chat bei der neuesten Nachricht. Deaktiviere dies, um deine Position beim Zurückkehren beizubehalten. | Ein |
| Wechsel von Endpunkten während der Unterhaltung erlauben | Ermöglicht es, Modell oder Endpunkt innerhalb einer Unterhaltung zu ändern. | Ein |
| Standardmäßig temporärer Chat | Neue Chats beginnen als [temporäre Chats](/docs/features/temporary_chat). | Aus |
| Standardoption für Forks verwenden | Überspringt das Fork-Menü und verwendet immer die hier gewählte Option. Siehe [Forking](/docs/features/fork). | Aus |
| Erweiterter Prompt-Editor | Aktiviert Versionen und Produktionskennzeichnungen für Prompts. | Aus |
| Neue Prompt-Versionen immer als Produktion festlegen | Markiert jede neue Prompt-Version als die aktuell verwendete. | Ein |
| Prompts bei Auswahl senden | Sendet einen Prompt, sobald du ihn auswählst. | Ein |

**Bilder vor dem Hochladen verkleinern** kann gesperrt sein: Wenn ein Administrator [`fileConfig.clientImageResize.enabled`](/docs/configuration/librechat_yaml/object_structure/config#clientimageresize) festlegt, ist der Schalter deaktiviert und richtet sich nach diesem Wert.

## Sprache [#speech]

Aktivieren oder deaktivieren Sie **Sprache zu Text** und **Text zu Sprache**, wählen Sie die Engine, die Sprache und die Stimme aus, legen Sie die Wiedergabegeschwindigkeit fest und bestimmen Sie, ob Antworten automatisch abgespielt werden. Welche Engines angezeigt werden, hängt davon ab, was in der Bereitstellung eingerichtet wurde; siehe [Sprache zu Text und Text zu Sprache](/docs/configuration/stt_tts).

## Daten & Datenschutz [#data--privacy]

- **Speicher**: **Gespeicherte Erinnerungen referenzieren** ermöglicht dem Assistenten, Ihre [Erinnerungen](/docs/features/memory) zu verwenden. Sie werden in Ihrem Konto gespeichert und gelten daher auf jedem Gerät.
- **Codeausführung**: **Standardmäßiger zustandsbehafteter Arbeitsbereich** und **Code-Umgebungen**, sofern die Bereitstellung zustandsbehaftete Code-Sitzungen anbietet.
- **Ihre Daten**: **Unterhaltungen importieren**, **Geteilte Chats** (verwalten Sie Ihre [geteilten Links](/docs/features/shareable_links)), **Dateien verwalten**, **Alle Chats archivieren** und **Analysen erlauben**, sofern die Bereitstellung Analysedaten erfasst. **Alle Chats archivieren** verschiebt jeden aktiven Chat in [Archivierte Chats](/docs/features/navigation#archived-conversations), ohne etwas zu löschen.
- **API-Schlüssel**: **Provider-API-Schlüssel** für Endpunkte, die einen eigenen Schlüssel verlangen, **Agent-API-Schlüssel** für die Agents-API und **Alle Provider-API-Schlüssel widerrufen**.
- **Gefahrenbereich**: **Cache löschen** entfernt die im Browser zwischengespeicherten Text-zu-Sprache-Audiodateien. **Alle Chats löschen** entfernt deine Unterhaltungen dauerhaft.

## Konto [#account]

**Avatar** und, bei E-Mail-Anmeldungen, sofern dies zulässig ist, **E-Mail-Adresse**. Unter **Sicherheit**: **Zwei-Faktor-Authentifizierung**, **Backup-Codes**, sobald die Zwei-Faktor-Authentifizierung aktiviert ist, und **Passkeys**, sofern die Bereitstellung diese unterstützt. **Pull-Request-Konto** verbindet GitHub oder einen anderen Git-Host für [Pull Requests](/docs/features/pull_requests). **Token-Guthaben** und **Automatisch aufladen** erscheinen, wenn die Bereitstellung Guthaben erfasst, und **Konto löschen**, wenn sie Benutzern erlaubt, sich selbst zu löschen.

## Tastaturkürzel [#keyboard-shortcuts]

Öffne das Kontomenü und wähle **Hilfe** und dann **Tastenkürzel** (oder drücke <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>/</kbd>). Klicke auf eine Zeile, um eine neue Tastenkombination festzulegen; sie muss <kbd>Cmd</kbd>, <kbd>Ctrl</kbd> oder <kbd>Alt</kbd> enthalten, und LibreChat warnt dich, wenn eine andere Aktion diese Kombination bereits verwendet. **Alle auf Standardwerte zurücksetzen** macht deine Änderungen rückgängig. Die Zeilen unter **Geöffnete Panels** (Agents, Prompts, Erinnerungen, Parameter, Dateien, Lesezeichen, MCP-Einstellungen) haben keine Tasten, bis du ihnen eine zuweist.

Der Schalter **Keyboard Shortcuts** oben deaktiviert alle Tastenkombinationen und blendet die Hinweise in der Oberfläche aus. Deine benutzerdefinierten Tasten bleiben erhalten, falls du ihn wieder einschaltest. Sowohl der Schalter als auch deine Tastenbelegungen werden in diesem Browser gespeichert.
