LibreChat erstellt und bearbeitet Bilder über Agenten-Tools. Statten Sie einen Agenten mit einem Bild-Tool aus, beschreiben Sie, was Sie möchten, und das Bild erscheint in der Unterhaltung. Laden Sie zusammen mit Ihrer Nachricht ein Bild hoch, kann der Agent es verändern, anstatt bei null anzufangen.

## Die Bildwerkzeuge [#the-image-tools]

| Tool | Was es macht | Bearbeitet Bilder |
| --- | --- | --- |
| OpenAI Image Tools | Generiert Bilder aus Text und bearbeitet hochgeladene oder frühere Bilder mit OpenAI-Bildmodellen. Ein guter Standard. | Ja |
| Gemini Image Tools | Generiert Bilder mit den Bildmodellen von Google Gemini und kann optional frühere Bilder als visuellen Kontext verwenden. | Ja |
| Flux | Generiert Bilder mit den Flux-Modellen von Black Forest Labs, einschließlich eigener feinabgestimmter Modelle. | Nein |
| Stable Diffusion | Generiert Bilder auf Ihrem eigenen Automatic1111-Server, sodass nichts Ihr Netzwerk verlässt. | Nein |

Welche davon Sie sehen, hängt davon ab, was Ihr Administrator konfiguriert hat.

## Bild generieren [#generate-an-image]

<Steps>
<Step>
Öffne den Agenten im Agent Builder und wähle **Hinzufügen** neben **Tools** aus.
</Step>
<Step>
Wählen Sie ein Bildwerkzeug aus, zum Beispiel **OpenAI Image Tools**, und speichern Sie den Agenten. Falls das Werkzeug einen API-Schlüssel verlangt, hat Ihr Administrator diesen jedem Benutzer selbst überlassen; geben Sie Ihren eigenen ein.
</Step>
<Step>
Starte einen Chat mit dem Agenten und beschreibe das Bild.
</Step>
</Steps>

Der Agent wandelt deine Anfrage in einen Prompt für das Tool um, sodass du ganz normal sprechen kannst („ein Plakat für einen Kuchenbasar, Querformat, viele Pastellfarben“). Wünsche zu Form und Größe werden weitergegeben, sofern das Tool sie unterstützt: OpenAI akzeptiert quadratische, Querformat- oder Hochformat-Größen (neuere Modelle unterstützen außerdem benutzerdefinierte Größen bis 4K) sowie eine Qualitätsstufe und einen transparenten Hintergrund. Gemini akzeptiert Seitenverhältnisse wie 16:9 oder 9:16 und bei neueren Modellen eine Auflösung bis 4K. Stable Diffusion erzeugt immer 1024x1024.

## Ein Bild bearbeiten [#edit-an-image]

Fügen Sie ein Bild mit **Upload Image** an und bitten Sie um eine Änderung: „entferne die Personen im Hintergrund“, „mach daraus ein Aquarell“, „setze dieses Logo auf eine Kaffeetasse“. Mit OpenAI Image Tools ruft der Agent das Bearbeitungswerkzeug auf; mit Gemini übergibt er Ihr Bild als Kontext für eine neue Generierung.

Sie können an einem Bild, das der Agent gerade erzeugt hat, weiterarbeiten (z. B. „Mach den Himmel dunkler“), ohne etwas hochzuladen. Jedes hochgeladene oder erzeugte Bild hat eine ID, auf die sich das Modell bezieht. Das funktioniert, solange das Bild noch im Kontextfenster der Unterhaltung liegt. Bei einer langen Unterhaltung hängen Sie das Bild einfach erneut an.

Flux und Stable Diffusion arbeiten nur mit Text, daher können sie nicht bearbeiten.

## Was das Modell sieht [#what-the-model-sees]

Ein generiertes Bild wird dem Modell direkt nach seiner Erstellung einmalig angezeigt, damit es seine eigene Arbeit beschreiben oder überprüfen kann. Danach sieht das Modell nur noch Bilder, die an deine Nachrichten angehängt sind. Wenn du ein älteres Bild erst mehrere Nachrichten später besprechen möchtest, hänge es bitte erneut an.

Da das Bild zurück an das Modell übergeben wird, verwenden Sie für Agenten mit Bildwerkzeugen ein Modell mit Bildverarbeitungsfähigkeit. Ein reines Textmodell kann im Gesprächsschritt nach der Bildgenerierung fehlschlagen.

Generierte Bilder werden wie jede andere Datei-Upload gespeichert, gemäß den Einstellungen Ihres Administrators für den Dateispeicher. Standardmäßig werden sie so verkleinert, dass die kürzere Seite höchstens 768 Pixel beträgt. Ein 4K-Bild wird daher kleiner gespeichert, als das Modell es erzeugt hat, sofern Ihr Administrator diese Einstellung nicht ändert.

## Bilder von MCP-Servern [#images-from-mcp-servers]

MCP-Tools können auch Bilder zurückgeben, zum Beispiel einen Browser-Server, der Screenshots erstellt. Bilder, die der Server im Bildformat von MCP zurückgibt, werden im Chat genauso angezeigt wie die Ausgabe der integrierten Tools. Manche Server geben nur eine URL zum Bild zurück, was LibreChat nicht als Bildausgabe behandelt.

## Prompts schreiben [#writing-prompts]

Bildmodelle reagieren auf konkrete Beschreibungen. Beginnen Sie mit dem Motiv und dem Medium (Foto, Ölgemälde, flache Vektorillustration), und ergänzen Sie anschließend Komposition, Beleuchtung und die Details, die wichtig sind. Beschreiben Sie, was Sie sehen möchten, statt aufzulisten, was Sie vermeiden wollen. Wenn ein Ergebnis nahe am Ziel liegt, bitten Sie gezielt um die konkrete Änderung, anstatt den gesamten Prompt neu zu schreiben.

## Einrichtung [#setup]

Jedes Tool benötigt einen API-Schlüssel oder eine Server-URL. Ein Administrator legt diese in `.env` fest; bei den schlüsselbasierten Tools kann ein Administrator stattdessen auch festlegen, dass jeder Benutzer den Schlüssel selbst eingibt. Einrichtung für jedes Tool: [OpenAI Image Tools](/docs/configuration/tools/openai_image_gen), [Gemini Image Tools](/docs/configuration/tools/gemini_image_gen), [Flux](/docs/configuration/tools/flux) und [Stable Diffusion](/docs/configuration/tools/stable_diffusion). Wo Bilder gespeichert werden, wird über [`fileStrategy`](/docs/configuration/librechat_yaml/object_structure/config#filestrategy) festgelegt.
