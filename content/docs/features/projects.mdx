A project is a folder for conversations that belong together, such as a client, a course, or a long piece of work. Chats in a project share the project's instructions and can draw on its reference files, so you set the context once instead of repeating it in every new chat.

Projects are personal. Nobody else sees your projects or which chats are in them, and a project cannot be shared or handed to someone else. A project does not set a model: each chat keeps its own model, agent, and parameters.

## Create a project

In the sidebar, the **Projects** section header has an **All projects** button that opens the projects page; choose **New project** there. (Until you have a project, the sidebar section shows **New project** directly.) Give it a name of up to 100 characters and, if you like, a description, then select **Create project**. LibreChat opens the new project's workspace.

The projects page shows each project as a card with its description and chat count. **Search projects** matches names and descriptions, and the sort menu offers **Latest activity**, **Created**, and **Name**.

## Start or move chats

From a project's workspace, or the new chat icon next to the project in the sidebar, start a chat with **New chat in** followed by the project name. The message box shows a project chip: use it to switch to another project, or select its × to drop the project before you send. Once sent, the chat belongs to the project.

To file an existing chat, open its menu and choose **Change project**, then pick a project from the searchable list. **Remove from project** takes it out again. On desktop you can also drag a chat onto a project in the sidebar. A chat picks up the project's instructions and files from its next message, and stops using them as soon as it leaves.

A chat in a project shows the project name at the top of the conversation; select it to open the workspace. In the sidebar, each project expands to list its chats, and the main **Chats** list shows only chats outside any project. The project workspace lists only its own chats, sorted by **Updated** or **Created**.

## Instructions

**Instructions** in the workspace hold background, tone, or goals for every chat in the project. Select **Edit** to change them. Your server's own system rules still apply on top.

Instructions apply to messages sent after you save them, in regular chats, agent chats, and Assistants chats. Earlier replies are not rewritten. They can be up to 16,000 characters by default.

If you edited the project in another tab in the meantime, saving fails with **This project was changed in another session. Reload to see the latest version.** Reload and make the change again.

## Files

**Files** holds reference documents for the project. Use **Add files** to upload with **Upload from device** or pick one you uploaded before with **Choose from your files**. Each file shows **Processing** while it is indexed and **Ready** once chats can use it. **Choose from your files** lists only files that were uploaded for file search and have not expired. A file that is later deleted or expires stays listed as **Unavailable** and is skipped.

Chats in the project search these files and pull in the relevant passages, not whole documents. That only happens when **File Search** is on for the chat or agent. If your server has not set up file search, or your role is not allowed to use it, you cannot upload new project files.

A project holds up to 50 files unless your admin changed the limit. Removing a file affects future messages only; replies that already used it stay as they are.

## Rename or delete

Click the project name or description in the workspace to edit it, or use **Edit project** from the project's menu in the sidebar.

**Delete project**, in the workspace's **Project options** menu or as **Delete** in the sidebar menu, asks for confirmation and removes only the project. Its chats stay in your history, no longer assigned to any project. If you are viewing a project when it is deleted, LibreChat returns you to the projects page.

## Setup

Projects are available to every user from LibreChat v0.8.7 on; no setting or role permission hides them. Admins can change the per-project file limit and the maximum length of instructions and descriptions under the [`projects`](/docs/configuration/librechat_yaml/object_structure/config#projects) key in `librechat.yaml`. Project files rely on [file search](/docs/features/rag_api).
