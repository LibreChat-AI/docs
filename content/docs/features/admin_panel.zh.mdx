Admin Panel 是一个独立的 Web 应用,用于在浏览器中管理 LibreChat 实例。你可以使用它来管理用户、群组和角色,决定每个角色允许执行的操作,分配管理员权限,并更改配置(对所有人生效,或仅对特定角色或群组生效),而无需编辑 `librechat.yaml` 或重启服务。

它是一项独立的服务，拥有自己的 URL，开发仓库位于 [LibreChat-AI/admin-panel](https://github.com/LibreChat-AI/admin-panel)。它本身不保存任何数据：所有更改都会通过 LibreChat 的管理 API 进行，并最终写入 LibreChat 的数据库。

## 登录 [#signing-in]

您使用 LibreChat 账户登录,可以使用电子邮件和密码,也可以通过实例上配置的单点登录(例如 OpenID Connect 或 Google)登录。该账户需要具有 `ADMIN` 角色,或者被授予 `access:admin` 权限(直接授予,或通过其所属的群组或角色授予)。LibreChat 会在每个请求中检查此项,因此面板无法赋予自身超出账户所拥有的访问权限。默认情况下,会话在 30 分钟无活动后结束。使用单点登录时,面板会在后台刷新您的 LibreChat 会话,每次刷新时都会再次检查该账户是否未被封禁且仍具有管理员访问权限;一旦失去访问权限,面板会话即告结束。

配置管理面板 URL 后,拥有管理员权限的用户还可以在 LibreChat 的 **设置 > 通用** 中找到 **Admin Panel** 链接。其他用户看不到该链接。

## 你可以做什么 [#what-you-can-do]

侧边栏的各个部分对应主要功能:

- **用户**:列出并搜索实例上的每个账户,按角色筛选,并在不同角色之间调整用户。(面板中有删除操作,但当前版本的 LibreChat 尚不支持通过管理 API 删除用户;请改用删除用户脚本。)
- **访问**:创建除 `USER` 和 `ADMIN` 之外的自定义角色,并编辑每个角色的功能权限;创建群组并管理其成员。在此创建的群组和角色可以在 LibreChat 的分享对话框中选择。
- **配置**:以表单形式查看和编辑 LibreChat 的设置。这些表单由 LibreChat 自身的配置模式(schema)生成,因此新增设置无需更新面板即可显示。
- **授权(Grants)**:将个别管理能力(例如管理用户或编辑配置的某一部分)授予某个用户、群组或角色,而无需使其成为完整的管理员。

每个人在面板中看到的内容取决于其权限。例如，仅被允许管理 `interface` 部分的用户，只会看到该部分。只能读取角色的用户可以看到角色，但无法修改；没有任何访问权限的用户，则会在该部分看到访问被拒绝页面。

## 针对特定角色和群组的配置 [#configuration-for-specific-roles-and-groups]

除了适用于所有人的基础配置文件(Base profile)之外,您还可以为单个角色、用户组或用户保存一组覆盖配置。其中只存储您更改过的设置,其余设置均继承自基础配置。每个配置文件都有一个优先级(角色配置文件默认为 10,用户组配置文件默认为 20,用户配置文件默认为 100)。当 LibreChat 为某个用户构建配置时,它会从 `librechat.yaml` 和基础配置文件开始,然后按优先级从低到高依次应用与该用户匹配的配置文件,因此默认情况下用户配置文件会覆盖用户组或角色配置文件。通过这种方式,研究小组可以获得额外的端点,或者承包商可以使用更严格的界面,而无需运行第二个实例。

编辑配置时需要注意以下几点:

- 对更改会按照与 `librechat.yaml` 相同的规则进行检查。如果某项编辑会导致配置无效，该编辑将被拒绝，且不会保存任何内容。如果升级后某个较早保存的值变为无效，LibreChat 会忽略该字段，回退到其下层的值，并记录一条警告，因此升级后请检查日志。
- API 密钥以及您输入的其他机密信息（例如用于网络搜索、语音、OCR、Langfuse 或自定义端点的密钥）会以加密方式存储，之后仅以掩码形式显示。如果您更改已保存密钥的发送目标，例如服务器或基础 URL，则必须重新输入该密钥。
- `${ENV_VAR}` 引用仅对 LibreChat 已知的变量,或运维人员明确允许的变量生效。
- 有些设置只能保存在 `librechat.yaml` 中:运行本地进程的 MCP 服务器(`type: stdio`,或 `command`、`args`、`env`),以及 Langfuse 网关请求头。面板无法添加、修改或删除这些设置。远程 MCP 服务器则可以正常管理。

功能权限不是覆盖设置:决定某个角色能否使用或共享智能体、提示词及其他功能的开关,都在角色本身的 **Access**(访问)下进行编辑。有关角色、组和权限如何协同工作,请参阅 [访问控制](/docs/features/access_control)。每个智能体的使用情况位于 LibreChat 内独立的 [Insights](/docs/features/insights) 仪表板中。

## 设置 [#setup]

面板以 `admin-panel` 服务的形式随 LibreChat 的 `docker-compose.yml` 和 `deploy-compose.yml` 一同提供，在您于 `.env` 中设置 `ADMIN_PANEL_SESSION_SECRET` 之前，它不会启动。它需要 LibreChat v0.8.5 或更高版本。端口、独立域名托管、SSO 重定向、所有环境变量以及面板使用的管理 API，均在 [Admin Panel configuration](/docs/configuration/admin_panel) 中说明。
