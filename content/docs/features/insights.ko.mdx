Admin Insights는 배포 환경의 기본 MongoDB에 저장된 활동 데이터를 바탕으로 에이전트 사용 현황을 검토할 수 있는 선택형 대시보드입니다. 조회하는 사용자가 볼 수 있는 에이전트에 대해 시간별 대화 수, 고유 사용자 수, 저장된 메시지 수, 기록된 토큰 수를 보여주며, 상위 사용자, 이탈, 최근 대화 보기를 제공합니다.

## Insights 활성화 [#enable-insights]

`.env` 파일에서 `ENABLE_INSIGHTS=true`를 설정한 다음, LibreChat을 재시작하세요:

```sh filename=".env"
ENABLE_INSIGHTS=true
```

계정이 하나 이상의 에이전트 인사이트를 볼 수 있을 때 이 기능이 활성화되면, 데스크톱 사이드바와 모바일 패널 전환기에 **Insights**가 표시됩니다. 비활성화되면 접근 경로와 데이터 경로는 `404`를 반환하고, 탐색 항목은 계속 숨겨집니다.

## 액세스 요구 사항 [#access-requirements]

로그인한 계정이 검토할 수 있는 에이전트는 해당 계정이 누구인지에 따라 달라집니다:

- `ADMIN` 역할을 가진 계정은 모든 Agent를 볼 수 있습니다.
- `read:insights` 시스템 기능(capability)을 보유한 계정은 모든 Agent를 볼 수 있습니다.
- 다른 사용자는 에이전트의 접근 목록을 통해 **VIEW**와 **View insights** 권한을 모두 보유한 에이전트만 볼 수 있습니다.

`GET /api/insights/access`는 계정이 접근할 수 있는 Agent가 하나도 없을 때에만 `403`을 반환하며, 대시보드 라우트는 요청이 해당 집합에 속하지 않은 Agent를 지정하면 `403`을 반환합니다.

에이전트에 대한 **인사이트 보기** 권한은 관리자만 부여할 수 있습니다. 이는 에이전트의 공유 대화상자에 있는 별도의 토글이며 다른 사용자에게는 표시되지 않습니다. 또한 공개 주체(public principals)에게는 부여할 수 없습니다. 관리자는 항상 접근 권한을 가집니다. `read:insights` 기능을 할당하려면 [관리자 패널](/docs/features/admin_panel)을 사용하고, 권한 비트에 대해서는 [접근 제어](/docs/features/access_control)를 참조하십시오.

모든 Insights 쿼리는 인증된 계정으로부터 테넌트 범위를 도출합니다. 테넌트 계정은 자신의 테넌트에 속한 Agents와 레코드만 볼 수 있으며, 테넌트가 없는 계정은 범위가 지정되지 않은 레코드만 볼 수 있습니다.

<Callout type="warning" title="민감한 운영 데이터">
  Insights에는 사용자 이름과 이메일 주소, 대화 ID, 최근 대화의 첫 번째 메시지가 표시될 수 있습니다. `read:insights` 또는 **View insights** 권한은 이 데이터를 검토해야 하는 사람에게만 부여하세요.
</Callout>

## 대시보드 지표 [#dashboard-metrics]

메트릭은 조회자가 볼 수 있는 에이전트와의 대화로 범위가 한정되며, 에이전트 필터로 추가로 좁힐 수 있습니다. 네 가지 요약 메트릭과 일별 스파크라인은 선택한 날짜 범위를 사용합니다.

- **대화:** 선택한 기간 내에 생성된 선택한 에이전트와의 대화
- **고유 사용자:** 해당 대화에서 저장된 메시지 활동이 일치하는 사용자 수
- **메시지:** 해당 대화에 저장된 사용자 및 어시스턴트 메시지
- **Tokens:** 기록된 메시지 `tokenCount` 값의 합계

대시보드에는 다음 항목도 포함되어 있습니다:

- **상위 사용자:** 메시지 수 기준으로 정렬된 최대 8명의 사용자와 각 사용자의 대화 및 메시지 총계
- **이탈 사용자:** 선택한 기간 동안 선택한 에이전트 중 어느 하나에 보낸 가장 최근 메시지가 28일 경과한 사용자 최대 8명
- **최신 대화:** 날짜, 소유자, 첫 번째 메시지, 유지된 메시지 수 및 기록된 토큰이 포함된 페이지네이션된 대화

이것은 데이터베이스 활동 지표이며, 청구 또는 Langfuse 분석이 아닙니다. 토큰 합계는 메시지와 함께 저장된 값에 따라 달라지며 금전적 비용을 계산하지 않습니다.

## 날짜 범위 및 검색 [#date-ranges-and-search]

기본 범위는 7일입니다. 사전 설정은 최근 24시간, 7일 또는 30일을 포함합니다. 사용자 지정 범위는 최대 30일까지 설정할 수 있으며 브라우저의 현재 시간대를 기준으로 그룹화됩니다.

Agent 필터는 액세스 가능한 모든 Agent를 선택하거나 선택 해제할 수 있는 고정된 **All agents** 컨트롤과 함께 명시적 체크박스를 사용합니다. 10개 이상의 Agent를 사용할 수 있는 경우, 검색 필터는 현재 결과 외부에 있는 선택 항목을 해제하지 않고 대소문자를 구분하지 않고 이름을 검색합니다.

최근 대화 검색은 대화 ID 또는 사용자 식별자와 일치하는 항목을 찾습니다. 검색은 3자부터 시작하여 최대 200자까지 입력할 수 있으며, 최근 대화 테이블은 페이지당 10개 행으로 페이징이 유지됩니다. 요약 카드, 상위 사용자 및 이탈 지표는 검색 결과 하위 집합이 아닌 선택된 날짜 범위를 계속해서 나타냅니다.

## 데이터 및 배포 참고 사항 [#data-and-deployment-notes]

Insights는 기존 Conversation, Message 및 User 컬렉션을 직접 쿼리하며 별도의 분석 데이터베이스가 필요하지 않습니다. 결과는 영구 저장된 레코드만 반영하므로, MongoDB에서 더 이상 존재하지 않는 임시 데이터나 삭제된 데이터는 나타날 수 없습니다. API는 집계(aggregation)를 실행하기 전에 사용자 지정 범위, 결과 목록, 페이지 크기, 검색 입력 및 테넌트 범위를 제한합니다.

배포 스위치에 대해서는 [`ENABLE_INSIGHTS`](/docs/configuration/dotenv#admin-insights)를 참조하세요.
