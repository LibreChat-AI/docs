De message composer is het tekstvak onderaan elke chat. Naast het tekstveld bevat het één **+** knop die alles opent wat je aan een bericht kunt toevoegen (bestanden, tools, skills, MCP servers en eerder geüploade bestanden), de chips voor de tools die momenteel zijn ingeschakeld, en de bedieningselementen voor reasoning, dicteren en verzenden.

## Wat staat er in de composer [#whats-on-the-composer]

| Element | Wat het doet |
|---|---|
| **+** (**Bijvoegen en tools**) | Opent het palet: uploadopties, tools, skills, MCP servers en je recente bestanden, allemaal doorzoekbaar vanuit één veld. |
| Tool chips | Eén chip per tool of MCP server die is ingeschakeld, naast de **+** knop. Verwijder een chip om die tool uit te schakelen. |
| Staged context | Bestanden, citaten en skills die aan je volgende bericht zijn toegevoegd, weergegeven boven het tekstveld. |
| **Thinking** | Redeneerinspanning voor modellen die dit ondersteunen. |
| Context usage | Hoeveel van het contextvenster van het model de conversatie gebruikt, wanneer tokengebruik beschikbaar is. |
| **Use microphone** | Dicteert je bericht met spraak-naar-tekst, wanneer spraak-naar-tekst is ingeschakeld. |
| Send / Stop | Verzendt het bericht, of stopt het antwoord dat wordt gestreamd. |

To see which keys apply right now, such as `/ for prompts`, `@ for models` or `Enter to send`, turn on **Show composer tips** in **Settings > General**. A one-line tip then appears under the text field. It is off by default.

## Bestanden toevoegen [#add-files]

Klik op **+** en kies een optie in het gedeelte **Attach**. Je kunt ook bestanden naar de composer slepen of ze plakken.

Standaard gebruikt LibreChat de uniforme uploader: je kiest alleen een bron, en deze bepaalt op basis van het bestandstype en de endpoint hoe elk bestand het model bereikt (native provider-upload, tekstextractie of een tool zoals File Search).

| Optie | Wanneer deze verschijnt |
|---|---|
| **From Local Computer** | Altijd, met de standaard uploader. |
| **From SharePoint** | Wanneer de [SharePoint file picker](/docs/configuration/sharepoint) is ingeschakeld. |

Als een beheerder [`fileConfig.legacyFileUploadUX: true`](/docs/configuration/librechat_yaml/object_structure/file_config#legacyfileuploadux) instelt, kies je in plaats daarvan zelf de bestemming. De sectie **Attach** toont dan eerst de hoofdoptie en verbergt de rest achter **More upload options**:

| Optie | Wanneer het verschijnt |
|---|---|
| **Upload to Provider** | De provider accepteert documenten rechtstreeks (bijvoorbeeld OpenAI, Anthropic, Google, Bedrock, OpenRouter en aangepaste endpoints, of Azure OpenAI met de Responses API ingeschakeld). |
| **Upload Image** | Wordt getoond in plaats van **Upload to Provider** wanneer de provider alleen afbeeldingen accepteert. |
| **Upload as Text** | De [context capability](/docs/features/upload_as_text) is ingeschakeld. |
| **Upload for File Search** | File Search is ingeschakeld en toegestaan voor de huidige agent. Het selecteren hiervan schakelt ook File Search in. |
| **Upload to Code Environment** | Code-uitvoering is ingeschakeld en toegestaan voor de huidige agent. Het selecteren hiervan schakelt ook **Run Code** in. |
| **Attach Files** | Assistants endpoints, die bestanden afhandelen met de eigen configuratie van de assistant. |

Met SharePoint ingeschakeld in deze modus, heeft elke optie ook een SharePoint-versie, bijvoorbeeld gelabeld als **Upload to Provider (From SharePoint)**.

### Een eerder geüpload bestand hergebruiken [#reuse-a-file-you-uploaded-before]

De sectie **Your files** van het palet bevat een lijst met uw meest recent gebruikte bestanden. Selecteer er een om deze opnieuw bij te voegen zonder het bestand opnieuw te uploaden. Typen in het zoekveld doorzoekt al uw bestanden op naam.

Kies **Show all** in de sectie om elk bestand in een dialoogvenster te doorzoeken, met weergaven voor **All**, **Images** en **Documents**, een zoekveld en een voorbeeldweergave voor afbeeldingen en PDF's.

Het palet toont maximaal vijf recente bestanden. Beheerders kunnen dat aantal verlagen, of de lijst verbergen met `0`, door gebruik te maken van [`interface.composerRecentFiles`](/docs/configuration/librechat_yaml/object_structure/interface#composerrecentfiles).

## Schakel tools, skills en MCP servers in [#turn-on-tools-skills-and-mcp-servers]

Het palet bevat alles wat je kunt inschakelen voor het huidige gesprek, gegroepeerd in secties:

- **Tools**: ingebouwde tools zoals **Web Search**, **Run Code**, **File Search**, **Skills**, **Memory** en **Artifacts**, die elk alleen worden getoond wanneer ze zijn ingeschakeld en je er toegang toe hebt.
- **Skills**: individuele [skills](/docs/features/skills) die je aan je volgende bericht kunt koppelen.
- **MCP Servers**: de [MCP servers](/docs/features/mcp) die beschikbaar zijn in de chat.

Selecteer een tool of MCP server om deze in of uit te schakelen. Het palet blijft open, zodat je er tijdens één bezoek meerdere kunt in- of uitschakelen. Elke ingeschakelde tool verschijnt als een chip in de composer; verwijder de chip om deze uit te schakelen. Sommige chips bevatten een modusmenu, bijvoorbeeld de **Artifacts** generatiemodus.

Het selecteren van een skill plaatst deze in de wachtrij voor je volgende bericht: het verschijnt in de [staged context](#staged-context) in plaats van als een chip.

MCP-serverrijen tonen de verbindingsstatus van elke server. Het selecteren van een server die niet is verbonden, start de verbinding (inclusief een OAuth-aanmelding, wanneer de server er een vereist) of opent eerst de configuratie als deze uw inloggegevens nodig heeft. Zodra ze zijn verbonden, hebben servers die gebruikersgegevens vereisen ook een **Configure**-besturingselement in de rij, en **Web Search** heeft er een voor zijn API-sleutels.

<Callout type="info" title="Agents brengen hun eigen tools mee">
  Wanneer een agent is geselecteerd, zijn de secties **Tools** en **MCP Servers** verborgen, omdat de eigen configuratie van de agent bepaalt welke tools deze gebruikt. Op andere endpoints verbergt een [model spec](/docs/configuration/librechat_yaml/object_structure/model_specs#hidebadgerow) met `hideBadgeRow: true` de secties **Tools**, **Skills** en **MCP Servers**. **Attach** en **Your files** blijven in elk geval beschikbaar.
</Callout>

### Alles weergeven [#show-all]

Het palet toont een handvol rijen per sectie. Kies **Show all** bij de kop **Skills**, **MCP Servers** of **Your files** om een dialoogvenster te openen met de volledige lijst, een zoekveld en filters. Skills en MCP servers hebben drie weergaven: **All**, **Made by you** en **Favorites**.

### Favorieten en vastgezette tools [#favorites-and-pinned-tools]

Markeer een rij met een ster om deze toe te voegen aan **Favorieten**, die bovenaan het palet worden weergegeven. Druk, terwijl een rij is geselecteerd, op <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd> op macOS) om deze toe te voegen aan of te verwijderen uit je favorieten. Favorieten worden opgeslagen in je account.

Beheerders kunnen ingebouwde tools vastzetten met [`interface.defaultPinnedTools`](/docs/configuration/librechat_yaml/object_structure/interface#defaultpinnedtools). Een vastgezette tool houdt zijn chip op de composer, zelfs wanneer deze uitgeschakeld is, zodat je hem met één klik kunt inschakelen. Het verwijderen van de chip van een vastgezette tool die uitgeschakeld is, maakt deze weer los.

## Staged context [#staged-context]

Alles wat aan je volgende bericht is toegevoegd, verschijnt boven het tekstveld voordat je het verzendt:

- **Bestanden**, met uploadvoortgang en een voorbeeldweergave voor afbeeldingen. Lange geplakte tekst kan hier ook als bestand terechtkomen, die je kunt bewerken of terug kunt verplaatsen naar het bericht.
- **Citaten** die je hebt geselecteerd uit eerdere berichten.
- **Skills** die je hebt gekozen uit het palet of met het `$` commando.

Verwijder elk item met de bijbehorende verwijderknop. Alles wat klaarstaat wordt met je volgende bericht verzonden.

## Denken en inspanning [#thinking-and-effort]

Voor modellen met een redeneerinstelling opent de **Thinking**-regelaar een schuifbalk die loopt van **Faster** naar **Smarter**, plus de afzonderlijke modi van de provider zoals **Auto** of uit. Deze wijzigt dezelfde parameter als het Parameters-paneel, dus deze is verborgen wanneer het model geen redeneerinstelling heeft of wanneer de implementatie parameters uitschakelt met `interface.parameters`.

## Wachtrij en stuur terwijl een antwoord streamt [#queue-and-steer-while-a-response-streams]

Je kunt blijven typen terwijl een antwoord wordt gestreamd. Afhankelijk van de endpoint en je instellingen, zorgt het indrukken van <kbd>Enter</kbd> er ofwel voor dat het bericht in de wachtrij wordt geplaatst om na het antwoord te worden verzonden, of het stuurt het huidige antwoord van een agent bij. De tip in de composer benoemt de actie die <kbd>Enter</kbd> op dat moment uitvoert.

Wachtrijberichten verschijnen in een **Queued messages**-balk boven de composer, waar je het volgende kunt doen:

- **Bewerk bericht** om het terug te verplaatsen naar het tekstveld.
- **Remove message** om het uit de wachtrij te verwijderen.
- **Nu verzenden** om het direct te versturen in plaats van te wachten.
- Herschik berichten door ze te verslepen, of door er een te selecteren en op de pijl-omhoog of pijl-omlaag toetsen te drukken.

Voor informatie over hoe steering werkt en wanneer het beschikbaar is, zie [Steering and Queued Messages](/docs/features/agents#steering-and-queued-messages).

## Sneltoetsen [#keyboard-shortcuts]

### In het tekstveld [#in-the-text-field]

| Keys | Action |
|---|---|
| <kbd>Enter</kbd> | Verzend het bericht (wachtrij of stuur terwijl een antwoord streamt). |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Nieuwe regel. |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) | Terwijl een antwoord streamt: de alternatieve actie, **nu verzenden** wanneer <kbd>Enter</kbd> in de wachtrij plaatst, of **in de wachtrij plaatsen** wanneer <kbd>Enter</kbd> stuurt. |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> (<kbd>Option</kbd>+<kbd>Enter</kbd>) | Terwijl een agent reageert: onderbreken en verzenden, indien beschikbaar. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>) | Stop het antwoord. |
| `/` | Voeg een opgeslagen prompt in. |
| `@` | Schakel over naar een ander model, preset of agent. |
| `+` | Voeg een model of preset toe voor een extra antwoord. |
| `$` | Kies een vaardigheid voor het volgende bericht. |

Als je **Druk op Enter om berichten te verzenden** hebt uitgeschakeld, verzendt <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) het bericht en voegt <kbd>Enter</kbd> een nieuwe regel toe.

### In het palet [#in-the-palette]

| Keys | Action |
|---|---|
| Type | Zoek naar tools, skills, servers, uploadopties en bestanden. |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Navigeer door de rijen. |
| <kbd>Enter</kbd> | Selecteer de gemarkeerde rij. |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd>) | Voeg de gemarkeerde rij toe aan Favorieten, of verwijder deze. |
| <kbd>Backspace</kbd> bij een lege zoekopdracht | Sluit het palet. |
| <kbd>Escape</kbd> | Sluit het palet. |
