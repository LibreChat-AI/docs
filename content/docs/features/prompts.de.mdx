### Variablen [#variables]

Verwende `{{notes}}`, um nach Text zu fragen, oder `{{length:3 bullets|5 bullets}}`, um Auswahlmöglichkeiten anzubieten:

```text
Summarize these notes in {{length:3 bullets|5 bullets}}.

Notes: {{notes}}
```

LibreChat fragt diese Werte ab, wenn du den Prompt im Chat verwendest. Spezielle Variablen wie `{{current_date}}`, `{{current_datetime}}`, `{{iso_datetime}}` und `{{current_user}}` werden automatisch ausgefüllt. Andere Variablen bleiben als wörtlicher Text erhalten, wenn nichts sie ausfüllt.

### Versionen und Produktion [#versions-and-production]

Das Speichern einer Bearbeitung erstellt eine neue Version. Eine Version ist als **Production** markiert. Die Bibliothek und das `/`-Menü verwenden diese Version.

| Editor-Einstellung | Was beim Speichern passiert |
| --- | --- |
| **Erweiterter Prompt-Editor** aus | Die Versionsliste wird ausgeblendet. Jedes Speichern wird zu Production. |
| Erweiterter Editor an; **Neue Prompt-Versionen immer als Production erstellen** an | Jedes Speichern wird zu Production. Sie können außerdem frühere Versionen durchsuchen. |
| Erweiterter Editor an; automatisches Production aus | Speichern Sie eine Version und verwenden Sie dann **Deploy**, um sie zu Production zu machen. |

Diese Einstellungen gelten für Ihren Browser. Wenn Sie den erweiterten Editor ausschalten, wird auch die automatische Produktion aktiviert. Sie können diesen Schalter erneut ändern, wenn der erweiterte Editor eingeschaltet ist.

## Einen Prompt als Agenten-Anweisungen verwenden [#use-a-prompt-as-agent-instructions]

Verknüpfe einen Agenten mit einem gespeicherten LibreChat-Prompt oder einem synchronisierten Langfuse-Prompt. Die Verknüpfung wählt die Anweisungen des Agenten für jeden Durchlauf aus.

<Steps>
  <Step>Öffnen Sie den Agenten im **Agent Builder**. Wählen Sie unter **Instructions** die Option **Prompt** aus.</Step>
  <Step>Wählen Sie einen Prompt aus und anschließend **Production** oder eine bestimmte Version.</Step>
  <Step>Speichern Sie den Agenten. Füllen Sie bei einem neuen Agenten die erforderlichen Felder aus und klicken Sie auf **Create**.</Step>
</Steps>

### Produktion oder eine fixierte Version? [#production-or-a-pinned-version]

Wählen Sie **Production**, um den Aktualisierungen des Prompt-Eigentümers zu folgen. Wählen Sie eine bestimmte Version, um dieselben Anweisungen beizubehalten, bis Sie den Link ändern.

![Bevor Version 4 veröffentlicht wird, verwenden beide Agents Version 3. Nach der Veröffentlichung verwendet der Agent, der Production folgt, Version 4, während der Agent, der auf Version 3 festgelegt ist, bei Version 3 bleibt. Native Cache-Einstellungen können die Aktualisierung von Production verzögern.](/images/features/prompts/production-vs-pinned.svg)

Für LibreChat-Prompts bezeichnet **Production** die Revision, die als Production markiert ist. Für Langfuse-Prompts bezieht sich dies auf die Version mit dem Label `production`.

### Wann Anweisungen aufgelöst werden [#when-instructions-are-resolved]

Das Speichern des Agenten prüft den Prompt, kopiert jedoch nicht dessen Text. LibreChat löst den Link bei jedem Durchlauf auf. Aktualisierungen nativer Prompts können durch den [Cache](/docs/configuration/librechat_yaml/object_structure/agents#linkedinstructions) verzögert werden; Langfuse-Links werden bei jedem Abruf neu geladen.

Spezielle Variablen funktionieren so wie in [Inline-Agentenanweisungen](/docs/features/agents#instructions-from-a-saved-prompt). Benutzerdefinierte Variablen wie `{{notes}}` werden für verlinkte Anweisungen **nicht ausgefüllt**. Das Modell erhält sie als wörtlichen Text.

<Callout type="warning" title="Wenn der Prompt nicht verfügbar ist">
  Der Agent führt diesen Durchlauf mit **leeren Anweisungen** aus. Er verwendet nicht seinen gespeicherten Inline-Text.
  Der Memory-Agent ist eine Ausnahme: Er verwendet seine Standardanweisungen.
</Callout>

## Prompts aus Langfuse [#prompts-from-langfuse]

Synchronisierte Langfuse-Prompts haben ein Wolkensymbol mit der Bezeichnung **Managed in Langfuse**. Du kannst sie in LibreChat in der Vorschau anzeigen und verwenden. Bearbeite ihren Inhalt, stufe Versionen hoch und lösche sie in Langfuse.

<ImageZoom src="/images/features/prompts/langfuse-preview.jpg" alt="Schreibgeschützte Langfuse-Prompt-Vorschau mit Version, Labels und In Langfuse öffnen.">
      <span className="relative mx-auto block w-full overflow-hidden rounded-lg" style={{ maxWidth: 1028, aspectRatio: '1028 / 445' }}>
        <img src="/images/features/prompts/langfuse-preview.jpg" alt="Schreibgeschützte Langfuse-Prompt-Vorschau mit Version, Labels und In Langfuse öffnen." loading="lazy" style={{ position: 'absolute', width: '168.09339%', maxWidth: 'none', top: '-42.24719%', left: '-34.04669%' }} />

Nur Langfuse-**Textprompts** werden unterstützt. Beim Öffnen wird der Inhalt aus Langfuse abgerufen, ohne ihn zwischenzuspeichern. Wird er in Langfuse gelöscht, bleibt sein Bibliothekseintrag in LibreChat erhalten, der Eintrag kann jedoch nicht mehr aufgelöst werden.

### Langfuse-Links [#langfuse-links]

Ein Administrator muss die [Synchronisierung des Prompt-Katalogs](/docs/configuration/langfuse#prompt-catalog) und die [Langfuse-Agentenanweisungen](/docs/configuration/langfuse#prompts-as-agent-instructions) aktivieren. Die Verknüpfung ist standardmäßig deaktiviert. Die Synchronisierung des Katalogs muss aktiviert bleiben, damit gespeicherte Verknüpfungen funktionieren.

Wenn das Verknüpfen deaktiviert ist, verschwinden Langfuse-Prompts aus der Auswahl im Builder, mit Ausnahme der gespeicherten Auswahl des Agenten. Der Builder zeigt für diese Auswahl einen Hinweis an. Die Verknüpfung bleibt gespeichert, der Agent läuft jedoch ohne diese Anweisungen. Wenn das Verknüpfen wieder aktiviert wird, wird sie ohne Bearbeitung des Agenten wiederhergestellt.

## Teilen und Berechtigungen [#sharing-and-permissions]

Ein Prompt-Eigentümer kann ihn mit Benutzern, Gruppen oder Rollen als **Viewer**, **Editor** oder **Owner** teilen. Siehe [Access Control](/docs/features/access_control).

### Wer kann verknüpfen und wer kann ausführen [#who-can-link-and-who-can-run]

| Aufgabe | Erforderlicher Zugriff |
| --- | --- |
| Die Prompt-Bibliothek verwenden | Die Berechtigung `PROMPTS` `USE` deiner Rolle und Zugriff auf den Prompt. |
| Einen Prompt-Link eines Agenten hinzufügen oder ändern | `PROMPTS` `USE` und VIEW für den Prompt sowie `AGENTS` `CREATE` für einen neuen Agenten oder EDIT für einen bestehenden Agenten. |
| Einen Link behalten oder entfernen; zu Inline-Anweisungen wechseln | Dieselben Zugriffsrechte auf Agentenebene. Der Zugriff auf den Prompt wird nicht erneut geprüft. |
| Mit einem Agenten chatten, der einen Prompt verwendet | Zugriff, um mit dem Agenten zu chatten. Zugriff auf den verknüpften Prompt ist nicht erforderlich. |
| Einen Prompt teilen | `SHARE` für ausgewählte Benutzer, Gruppen oder Rollen; `SHARE_PUBLIC` für alle. |

Ein Mit-Bearbeiter ohne Zugriff auf den Prompt sieht **Eingeschränkter Prompt**. Er kann den Link ersetzen oder zu Inline-Anweisungen wechseln. Das Ziel des Links kann er nicht sehen. Ein Agent-Betrachter sieht den Link niemals.

Administratoren legen Rollenberechtigungen im [Admin-Panel](/docs/features/admin_panel) oder in der [Zugriffskontrollkonfiguration](/docs/configuration/access_control#feature-permissions) fest. Delegierte Administratoren mit `manage:prompts` können jede Gruppe ohne separate VIEW-Berechtigung anzeigen und verknüpfen. Für das Verknüpfen ist weiterhin `PROMPTS` `USE` erforderlich.

## Details und Fehlerbehebung [#details-and-troubleshooting]

<Accordions type="single" collapsible>
  <Accordion title="Versionsverlauf, Duplizieren und Zurücksetzen">
    Das Ändern des Prompts, seiner Version oder der Anweisungsquelle fügt einen Eintrag zum Versionsverlauf des Agenten hinzu.

    **Duplizieren** und **Zurücksetzen** kopieren den gespeicherten Link, ohne eine neue USE- oder VIEW-Prüfung durchzuführen. Wenn der neue Editor den Prompt nicht anzeigen kann, zeigt der Builder **Eingeschränkter Prompt** an.
  </Accordion>
  <Accordion title="Was die Nutzungsanzahl bedeutet">
    Jeder verknüpfte Agent verbraucht nach erfolgreicher Initialisierung eine Nutzung. Dabei wird derselbe Zähler verwendet wie bei Prompt-Karten und dem Slash-Menü. Übergaben (Handoffs) und Subagenten können innerhalb eines einzelnen Durchgangs mehrere Nutzungen hinzufügen.

    Das Fortsetzen eines pausierten Laufs verursacht keine zusätzliche Nutzung. Der Memory-Agent verursacht niemals eine zusätzliche Nutzung.
  </Accordion>
  <Accordion title="Management-API-Einschränkungen">
    Setze Prompt-Links im Agent Builder. Die Management API und ihre OpenAPI-Spezifikation akzeptieren oder liefern `instructionsPrompt` nicht.

    Das Ändern von `instructions` über diese API ändert nicht, was ein verknüpfter Agent verwendet. Die Verknüpfung hat Vorrang. Langfuse-Verknüpfungen unterstützen nur Textprompts; native Prompt-Gruppen haben diese Einschränkung nicht.
  </Accordion>
  <Accordion title="Fehlerbehebung bei Builder-Nachrichten">

    | Nachricht | Was zu tun ist |
    | --- | --- |
    | "Diese Prompt-Auswahl ist im Moment nicht verfügbar." | Wähle einen anderen Prompt oder eine andere Version oder versuche es erneut, sobald das Problem behoben ist. Die Version wurde möglicherweise gelöscht, durch eine Richtlinie blockiert oder ist bei Langfuse nicht verfügbar. Die Verknüpfung ist möglicherweise deaktiviert, oder die Quelle der Gruppe wurde geändert. |
    | "Du hast keine Berechtigung, diesen Prompt zu verknüpfen." | Bitte einen Administrator um `PROMPTS` `USE` oder den Eigentümer um VIEW für die Gruppe. |
    | "Du hast keinen Zugriff auf die Prompt-Bibliothek." | Die Auswahl oder die Versionsliste benötigt `PROMPTS` `USE` und VIEW für die Gruppe. Bitte einen Administrator oder den Eigentümer um Zugriff. |
    | "Die Quelle dieses Prompts ist im Moment nicht verfügbar." | Überprüfe die Langfuse-Synchronisationskonfiguration oder ersetze die Verknüpfung. Die Synchronisation ist möglicherweise deaktiviert oder nicht konfiguriert, die Quelle wurde geändert, oder der Prompt ist inzwischen ein Chat-Prompt. |
    | "Prompts konnten nicht geladen werden." | Versuche es erneut. Wenn das Problem weiterhin besteht, bitte einen Administrator, die Server-Logs zu prüfen. Dies ist ein unerwarteter Ladefehler und kein Berechtigungs- oder Quellenfehler. |
    | "Ausgewählte Version (nicht mehr verfügbar)" | Die native Revision wurde gelöscht. Wähle **Production** oder eine andere Version aus. |
    | "Version N (nicht mehr verfügbar)" | Die Langfuse-Version wird nicht mehr aufgeführt. Wähle **Production** oder eine andere Version aus. |
    | "Eingeschränkter Prompt" | Fordere VIEW an, ersetze die Verknüpfung oder wechsle zu Inline-Anweisungen. Die Gruppe wurde möglicherweise auch gelöscht. Dies kann auch für den Eigentümer des Agenten angezeigt werden. |
    | "Prompt nicht gefunden" | Die Gruppe wurde gelöscht. Wähle einen anderen Prompt oder wechsle zu Inline-Anweisungen. Benutzer mit `manage:prompts` oder `ADMIN` sehen diese Meldung anstelle von **Eingeschränkter Prompt**. |
    | "Der verknüpfte Prompt konnte nicht überprüft werden. Bitte versuche es erneut." | Ein unerwarteter Fehler verhinderte die Überprüfung. Versuche, erneut zu speichern. |

  </Accordion>
</Accordions>
