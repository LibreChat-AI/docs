계정 메뉴를 열고 **Settings**를 선택하여 LibreChat의 개인 기본 설정 및 데이터 제어를 관리하세요. **Search settings**를 사용하여 레이블이나 관련 키워드로 설정을 찾을 수 있습니다. 결과를 선택하면 해당 탭과 섹션이 열립니다. 설정 레이아웃은 탭 탐색을 숨기지 않고 모바일 화면에 맞게 조정됩니다.

## 일반 [#general]

**Display chat title in tab**은 현재 대화 제목을 브라우저 탭 제목으로 사용합니다. 이 기능은 기본적으로 활성화되어 있으며 현재 브라우저에 저장됩니다. 이 기능을 끄면 모든 탭에서 배포된 애플리케이션 제목이 유지됩니다. 새 대화는 실제 대화 제목이 지정되기 전까지 애플리케이션 제목을 계속 사용합니다.

**Clock Format**(시계 형식)은 시간이 시스템 관례, 12시간제, 또는 24시간제 중 무엇을 따를지 제어합니다. **System**(시스템)은 선택된 LibreChat 번역이 아닌 현재 브라우저의 지역 로캘을 읽습니다. 이 설정은 메시지 타임스탬프, 예약된 채팅 제어 및 요약, 키 만료 및 잔액 충전 날짜, 에이전트 및 프롬프트 버전 날짜, 메모리, 프로젝트 채팅 목록에 적용됩니다.

**Week Starts On**은 달력 스타일의 요일 목록이 시스템 관례, 일요일, 또는 월요일 중 무엇을 따를지 제어합니다. 시스템 관례는 토요일과 같이 해당 지역의 다른 첫 요일로 결정될 수 있습니다. 이는 예약된 채팅(Scheduled Chats)의 요일 제어 및 요약 순서를 변경하지만, 일정이 실행되는 요일 자체를 변경하지는 않습니다.

두 지역 설정 모두 현재 브라우저에 저장되므로, 기기마다 각자의 로캘을 따르거나 명시적으로 재정의할 수 있습니다.

**Show chat beside the sidebar on mobile**은 **Layout** 아래에 있으며, 기본적으로 꺼져 있습니다. 활성화되면 모바일 서랍(drawer)이 뷰포트의 80% 지점에서 멈추고 현재 대화의 일부가 보이도록 유지합니다. 해당 영역을 탭하면 서랍이 닫힙니다. 이 설정은 현재 브라우저에 저장됩니다. [Mobile Drawer](/docs/features/navigation#mobile-drawer)를 참조하세요.

**레이아웃(Layout)** 아래에 있는 **작성기 팁 표시(Show composer tips)**는 기본적으로 꺼져 있으며 현재 브라우저에 저장됩니다. 이를 켜면 메시지 작성기에 키보드 단축키 힌트가 표시됩니다.

**Archived chats**는 이 탭이 아닌 계정 메뉴에 있습니다. [Archived Conversations](/docs/features/navigation#archived-conversations)를 참조하세요.

### 알림 [#notifications]

**Notifications** 섹션은 사용자가 다른 작업을 하는 동안 응답이 완료되었을 때 LibreChat이 이를 어떻게 알릴지 제어합니다:

- **Show unread count in the tab title**은 브라우저 탭 제목과 아이콘에 읽지 않은 답장이 있는 대화 수를 표시합니다. 기본적으로 켜져 있습니다.
- **Notify me when a reply arrives**는 데스크톱 알림을 표시합니다. 기본적으로 꺼져 있으며, 켜면 브라우저의 알림 권한을 요청합니다. 채팅 목록에서 이미 답장을 확인 중일 때는 표시되므로, LibreChat을 보고 있지 않을 때만 알림이 나타납니다.
- **Play a sound for new replies**는 사용자가 자리를 비운 동안 응답이 도착하면 짧은 알림음을 재생합니다. 기본적으로 꺼져 있습니다. 브라우저는 페이지와 상호작용하기 전까지 오디오 재생을 차단하므로, 탭을 연 후 첫 번째 알림음은 재생되지 않을 수 있습니다.

이러한 기본 설정은 기기별로 저장되므로 노트북과 휴대폰의 설정이 다를 수 있습니다. 읽지 않은 상태 자체는 기기 간에 동기화됩니다([읽지 않은 답글](/docs/features/navigation#unread-replies) 참조). 관리자는 [`interface.replyNotifications`](/docs/configuration/librechat_yaml/object_structure/interface#replynotifications)를 사용하여 배포 환경에서 이러한 설정을 끌 수 있으며, 이 경우 해당 토글이 숨겨집니다.

## 채팅 [#chat]

**Conversations** 아래의 **Switch to Chat History on new chat**는 기본적으로 켜져 있으며 현재 브라우저에 저장됩니다. Prompts나 Memories와 같은 다른 패널이 열려 있는 상태에서 사이드바를 통해 새 채팅을 시작하면 사이드바가 다시 채팅 목록으로 전환됩니다. 현재 패널을 유지하려면 이 기능을 끄십시오.

**Auto-Scroll to latest message on chat open**은 새로 연 대화를 가장 최근에 렌더링된 메시지로 이동시킵니다. 대화로 돌아올 때 현재 스크롤 위치를 유지하려면 이 기능을 끄십시오. LibreChat은 탐색 및 메시지 로딩이 서로 다른 시간에 완료되는 경우를 포함하여, 대상 대화 행이 렌더링될 때까지 기다린 후 해당 위치로 이동합니다.

**Resize images before upload**를 사용하면 사용자가 대용량 JPEG, PNG 및 WebP 파일을 브라우저에서 전송하기 전에 축소할 수 있습니다. 이 설정은 기본적으로 꺼져 있으며 현재 브라우저에 저장됩니다.

관리자는 이 기능이 개인의 선택으로 남을지 여부를 제어할 수 있습니다. [`fileConfig.clientImageResize.enabled`](/docs/configuration/librechat_yaml/object_structure/config#clientimageresize)가 명시적으로 `true` 또는 `false`로 설정된 경우, LibreChat은 해당 값을 강제하고 사용자 토글을 잠급니다. 해당 필드가 생략된 경우, 사용자의 설정이 적용됩니다.

**Paste long text as a file**는 기본적으로 활성화되어 있으며 현재 브라우저에 저장됩니다. Upload as Text 컨텍스트 업로드를 사용할 수 있는 경우, 일반 메시지 작성기에 2,500자 이상의 텍스트를 붙여넣으면 입력창을 채우는 대신 `pasted-text.txt`로 텍스트가 첨부됩니다. 더 짧은 텍스트를 붙여넣거나 `context` 기능 없이 붙여넣은 경우에는 인라인으로 유지됩니다. [Upload Files as Text](/docs/features/upload_as_text#paste-long-text-as-a-file)를 참조하세요.

**긴 사용자 메시지 접기(Collapse long user messages)**는 기본적으로 꺼져 있습니다. 활성화되면 256픽셀보다 높은 사용자 메시지가 **더 보기(Show more)** 및 **간략히 보기(Show less)** 컨트롤이 포함된 축소된 미리보기로 표시됩니다. 이 접기 기능은 시각적인 효과일 뿐이며, 전체 메시지는 복사, 브라우저 검색 및 보조 공학 기기에서 그대로 사용할 수 있습니다.

**메시지 내 LaTeX 구문 분석**은 기본적으로 활성화되어 있습니다. 이 토글은 `$50`과 같이 통화와 유사한 텍스트를 리터럴로 유지하는 경계 규칙을 따르는 모호한 단일 달러 `$...$` 인라인 수식 형식을 제어합니다. 토글이 꺼져 있어도 명확한 `$$...$$`, `\(...\)`, `\[...\]` 수식은 계속 지원됩니다. 인라인 코드, 펜스 코드 및 자동 링크는 단일 달러 수식으로 해석되지 않습니다.

## 모델 매개변수 [#model-parameters]

사이드 패널의 모델 **Parameters** 패널은 대화 설정을 **Identity**, **Sampling**, **Limits**, **Reasoning**, **Context**, **Advanced**, **Misc.**와 같은 제목으로 그룹화합니다. 현재 endpoint가 사용하는 섹션만 표시되며, 사용자 지정 endpoint 고유의 매개변수와 같이 패널이 인식하지 못하는 설정은 **Misc.** 아래에 나열됩니다. 각 제목에는 해당 섹션에서 변경된 설정의 개수가 표시되므로, **Reset**을 선택하기 전에 무엇이 변경되었는지 확인할 수 있습니다. **Reset**과 **Save As Preset**은 패널 하단에 함께 위치합니다. [Presets](/docs/user_guides/presets)를 참조하세요.

## 키보드 단축키 [#keyboard-shortcuts]

계정 메뉴에서 **Keyboard Shortcuts**를 열어 바인딩을 검토하거나 사용자 지정하세요. **Keyboard Shortcuts** 스위치는 기본적으로 활성화되어 있습니다. 이를 끄면 모든 단축키가 비활성화되고 인터페이스에서 단축키 힌트가 제거되지만, 사용자 지정 바인딩은 유지됩니다. 단축키를 다시 켜려면 계정 메뉴에서 동일한 대화 상자를 여세요.

단축키 활성화 및 사용자 지정 바인딩은 현재 브라우저에 저장됩니다. 단축키가 꺼져 있어도 바인딩 행은 계속 표시되지만, 단축키를 다시 활성화할 때까지 편집 및 재설정 컨트롤은 비활성화된 상태로 유지됩니다.

## 데이터 제어 [#data-controls]

**Data Controls** 탭은 개인 데이터 관리 작업을 한곳으로 그룹화합니다:

- **Manage files**는 업로드된 파일 관리자를 엽니다.
- **Import conversations**는 지원되는 대화 내보내기 파일을 가져옵니다.
- **Shared chats**는 게시된 대화 링크를 나열하고 관리합니다.
- **Provider API keys**는 구성된 제공업체에 대해 제공된 키를 관리합니다.
- **Revoke all provider API keys**는 사용자가 제공한 모든 공급자 키를 제거합니다.
- **Default stateful workspace**는 **Code execution** 아래에 있으며, 새로 생성된 Agent에 제안할 워크스페이스 범위를 선택합니다. 이 설정은 Stateful Code Sessions를 사용할 수 있을 때만 나타나며, 이를 변경한다고 해서 stateful 세션이 활성화되거나 기존 Agent가 변경되지는 않습니다.
- **Delete TTS cache storage**는 브라우저에 캐시된 텍스트 음성 변환(TTS) 오디오를 제거합니다. 캐시가 비어 있으면 이 옵션을 사용할 수 없습니다.
- **모든 채팅 보관**은 확인 절차를 거친 후 활성 대화를 삭제하지 않고 **보관된 채팅**으로 이동합니다.
- **모든 대화 삭제**는 확인 절차를 거친 후 사용자의 대화 내용을 영구적으로 제거합니다.

데이터 삭제 및 키 취소 작업은 서버에서 지원되며 되돌릴 수 없을 수 있습니다. 브라우저 전용 기본 설정 및 캐시는 모든 기기가 아닌 현재 브라우저 프로필에만 적용됩니다.
