계정 메뉴를 열고 **설정**을 선택하세요. 설정 대화상자에는 **일반**, **채팅**, **음성**, **데이터 및 개인정보 보호**, **계정** 탭이 있으며, 해당 기능을 제공하는 배포 환경에서는 **Langfuse**와 **정보** 탭도 함께 표시됩니다. 원하는 설정이 어디에 있는지 대략 알고 있다면 **설정 검색**에 입력하세요. 레이블과 관련 단어("dark", "rtl", "paste" 등)와 일치하는 항목을 찾아 해당 탭과 섹션으로 바로 이동합니다.

대부분의 설정은 사용자 계정이 아니라 현재 브라우저에 저장됩니다. 노트북에서 변경한 설정은 휴대폰에 자동으로 적용되지 않습니다. 예외 사항은 아래에 표시되어 있습니다.

### 알림 [#notifications]

이 설정은 다른 채팅이나 다른 탭에 있는 동안 응답이 완료되었을 때 이를 알려주는 방식을 제어합니다:

- **Show unread count in the tab title** 은 읽지 않은 답변이 있는 채팅의 수를 탭 제목과 아이콘에 표시합니다. 기본적으로 켜져 있습니다.
- **답변이 도착하면 알림 받기**를 켜면 데스크톱 알림이 표시됩니다. 기본값은 꺼짐입니다. 처음 켤 때 브라우저가 권한을 요청하며, LibreChat 화면을 보고 있는 동안에는 알림이 표시되지 않습니다.
- **새 답변 알림음 재생**은 짧은 알림음을 재생합니다. 기본값은 꺼짐입니다. 브라우저는 페이지를 한 번 클릭하기 전까지 오디오 재생을 차단하므로, 탭을 연 뒤 처음 재생되는 알림음은 들리지 않을 수 있습니다.

토글은 기기별로 적용되며, 읽지 않은 상태 자체는 계정에 저장됩니다(참고: [읽지 않은 답변](/docs/features/navigation#unread-replies)). 이러한 토글 중 하나가 보이지 않는다면, 관리자가 [`interface.replyNotifications`](/docs/configuration/librechat_yaml/object_structure/interface#replynotifications)를 통해 해당 기능을 끈 것입니다.

## 음성 [#speech]

**Speech to Text**과 **Text to Speech**를 켜거나 끄고, 엔진, 언어, 음성을 선택하며, 재생 속도를 설정하고, 응답을 자동으로 재생할지 여부를 선택할 수 있습니다. 표시되는 엔진은 배포 환경에서 설정한 내용에 따라 달라집니다. 자세한 내용은 [Speech to Text and Text to Speech](/docs/configuration/stt_tts)를 참고하세요.

## 데이터 및 개인정보 보호 [#data--privacy]

- **Memory**: **저장된 메모리 참조**를 사용하면 어시스턴트가 [메모리](/docs/features/memory)를 활용할 수 있습니다. 계정에 저장되므로 모든 기기에서 적용됩니다.
- **코드 실행**: 배포 환경에서 상태 유지형 코드 세션을 제공하는 경우 **기본 상태 유지형 작업 공간**과 **코드 환경**.
- **데이터 관리**: **대화 가져오기**, **공유된 채팅**([공유 링크](/docs/features/shareable_links) 관리), **파일 관리**, **모든 채팅 보관**, 그리고 배포 환경에서 분석 데이터를 수집하는 경우 **분석 허용**. **모든 채팅 보관**은 아무것도 삭제하지 않고 활성 상태의 모든 채팅을 [보관된 채팅](/docs/features/navigation#archived-conversations)으로 이동합니다.
- **API 키**: 키를 직접 입력해야 하는 엔드포인트를 위한 **제공자 API 키**, Agents API용 **에이전트 API 키**, 그리고 **모든 제공자 API 키 해지**.
- **위험 구역**: **캐시 삭제**는 이 브라우저에 캐시된 텍스트 음성 변환(TTS) 오디오를 지웁니다. **모든 채팅 삭제**는 대화 내용을 영구적으로 삭제합니다.

## 계정 [#account]

**아바타**, 그리고 이메일 로그인이 허용된 경우 **이메일 주소**. **보안** 항목 아래에는 **2단계 인증**, 2단계 인증이 켜진 뒤에 표시되는 **백업 코드**, 그리고 배포 환경이 지원하는 경우 **패스키**가 있습니다. **Pull request 계정**은 [pull requests](/docs/features/pull_requests)를 위해 GitHub 또는 다른 git 호스트를 연결합니다. **토큰 잔액**과 **자동 충전**은 배포 환경이 잔액을 추적할 때 표시되며, **계정 삭제**는 사용자가 직접 자신의 계정을 삭제하도록 허용된 경우에 표시됩니다.

## 키보드 단축키 [#keyboard-shortcuts]

계정 메뉴를 열고 **도움말**, 그다음 **키보드 단축키**를 선택하세요(또는 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>/</kbd>를 누르세요). 행을 클릭하면 새 조합을 기록할 수 있으며, 조합에는 <kbd>Cmd</kbd>, <kbd>Ctrl</kbd> 또는 <kbd>Alt</kbd>가 포함되어야 합니다. 다른 작업이 이미 같은 조합을 사용 중이면 LibreChat이 경고를 표시합니다. **모두 기본값으로 재설정**을 누르면 변경 사항이 취소됩니다. **패널 열기** 아래의 행(에이전트, 프롬프트, 메모리, 매개변수, 파일, 북마크, MCP 설정)은 단축키를 지정하기 전까지 키가 없습니다.

**키보드 단축키** 스위치를 켜거나 끄면 인터페이스의 모든 단축키가 비활성화되고 힌트가 숨겨집니다. 사용자 지정 키 설정은 스위치를 다시 켤 때를 위해 유지됩니다. 스위치 상태와 단축키 설정 모두 이 브라우저에 저장됩니다.
