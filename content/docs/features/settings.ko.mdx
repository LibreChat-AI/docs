계정 메뉴를 열고 **설정**을 선택하여 LibreChat의 개인 환경설정과 데이터 제어 항목을 관리하세요. 탭은 일반, 채팅, 음성, 데이터 및 개인정보 보호, 계정이며, 배포 환경에서 표시하는 경우 정보 탭도 함께 나타납니다. **설정 검색**을 사용하면 항목의 레이블이나 관련 키워드로 원하는 제어 항목을 찾을 수 있습니다. 검색 결과를 선택하면 해당하는 탭과 섹션이 열립니다. 설정 화면은 모바일 화면에 맞게 조정되며, 탭 탐색 메뉴는 숨겨지지 않습니다.

## 일반 [#general]

**Display chat title in tab**은 현재 대화 제목을 브라우저 탭 제목으로 사용합니다. 이 기능은 기본적으로 활성화되어 있으며 현재 브라우저에 저장됩니다. 이 기능을 끄면 모든 탭에서 배포된 애플리케이션 제목이 유지됩니다. 새 대화는 실제 대화 제목이 지정되기 전까지 애플리케이션 제목을 계속 사용합니다.

**Clock Format**(시계 형식)은 시간이 시스템 관례, 12시간제, 또는 24시간제 중 무엇을 따를지 제어합니다. **System**(시스템)은 선택된 LibreChat 번역이 아닌 현재 브라우저의 지역 로캘을 읽습니다. 이 설정은 메시지 타임스탬프, 예약된 채팅 제어 및 요약, 키 만료 및 잔액 충전 날짜, 에이전트 및 프롬프트 버전 날짜, 메모리, 프로젝트 채팅 목록에 적용됩니다.

**Week Starts On**은 달력 스타일의 요일 목록이 시스템 관례, 일요일, 또는 월요일 중 무엇을 따를지 제어합니다. 시스템 관례는 토요일과 같이 해당 지역의 다른 첫 요일로 결정될 수 있습니다. 이는 예약된 채팅(Scheduled Chats)의 요일 제어 및 요약 순서를 변경하지만, 일정이 실행되는 요일 자체를 변경하지는 않습니다.

두 지역 설정 모두 현재 브라우저에 저장되므로, 기기마다 각자의 로캘을 따르거나 명시적으로 재정의할 수 있습니다.

**Show chat beside the sidebar on mobile**은 **Layout** 아래에 있으며, 기본적으로 꺼져 있습니다. 활성화되면 모바일 서랍(drawer)이 뷰포트의 80% 지점에서 멈추고 현재 대화의 일부가 보이도록 유지합니다. 해당 영역을 탭하면 서랍이 닫힙니다. 이 설정은 현재 브라우저에 저장됩니다. [Mobile Drawer](/docs/features/navigation#mobile-drawer)를 참조하세요.

이 탭의 다른 설정들은 현재 브라우저에 저장됩니다:

| 설정 | 기능 | 기본값 |
|---|---|---|
| UI 배율 | 전체 인터페이스 크기를 50%에서 150% 사이로 조정합니다. 브라우저 확대/축소에는 영향을 주지 않습니다. | 100% |
| 메시지 글꼴 크기 | 메시지 텍스트 크기를 매우 작게, 작게, 보통, 크게, 매우 크게 중에서 설정합니다. | 보통 |
| 채팅 방향 | 채팅의 텍스트 방향을 자동, 왼쪽에서 오른쪽, 오른쪽에서 왼쪽 중에서 설정합니다. 자동은 입력된 내용을 기준으로 방향을 결정합니다. | 자동 |
| 채팅 공간 최대화 | 대화가 화면에서 더 넓은 공간을 차지하도록 합니다. | 끄기 |
| 환영 화면에서 채팅 입력창 가운데 정렬 | 새 채팅의 환영 화면에서 입력창을 가운데에 배치합니다. | 켜기 |
| 맨 아래로 스크롤 버튼 | 최신 메시지로 바로 이동하는 버튼을 표시합니다. | 켜기 |
| 응답 생성 중 화면 켜짐 유지 | 응답이 생성되는 동안 브라우저가 화면을 어둡게 하거나 잠그지 않도록 요청합니다. | 켜기 |
| 환영 화면에 Lia 표시 | 환영 화면의 입력창 주변에 장식용 픽셀 마스코트 Lia를 표시합니다. 배포 환경에서 허용된 경우에만 나타납니다. | 끄기 |

**Archived chats**는 이 탭이 아닌 계정 메뉴에 있습니다. [Archived Conversations](/docs/features/navigation#archived-conversations)를 참조하세요.

### 알림 [#notifications]

**Notifications** 섹션은 사용자가 다른 작업을 하는 동안 응답이 완료되었을 때 LibreChat이 이를 어떻게 알릴지 제어합니다:

- **Show unread count in the tab title**은 브라우저 탭 제목과 아이콘에 읽지 않은 답장이 있는 대화 수를 표시합니다. 기본적으로 켜져 있습니다.
- **Notify me when a reply arrives**는 데스크톱 알림을 표시합니다. 기본적으로 꺼져 있으며, 켜면 브라우저의 알림 권한을 요청합니다. 채팅 목록에서 이미 답장을 확인 중일 때는 표시되므로, LibreChat을 보고 있지 않을 때만 알림이 나타납니다.
- **Play a sound for new replies**는 사용자가 자리를 비운 동안 응답이 도착하면 짧은 알림음을 재생합니다. 기본적으로 꺼져 있습니다. 브라우저는 페이지와 상호작용하기 전까지 오디오 재생을 차단하므로, 탭을 연 후 첫 번째 알림음은 재생되지 않을 수 있습니다.

이러한 기본 설정은 기기별로 저장되므로 노트북과 휴대폰의 설정이 다를 수 있습니다. 읽지 않은 상태 자체는 기기 간에 동기화됩니다([읽지 않은 답글](/docs/features/navigation#unread-replies) 참조). 관리자는 [`interface.replyNotifications`](/docs/configuration/librechat_yaml/object_structure/interface#replynotifications)를 사용하여 배포 환경에서 이러한 설정을 끌 수 있으며, 이 경우 해당 토글이 숨겨집니다.

## 채팅 [#chat]

**Conversations** 아래의 **Switch to Chat History on new chat**는 기본적으로 켜져 있으며 현재 브라우저에 저장됩니다. Prompts나 Memories와 같은 다른 패널이 열려 있는 상태에서 사이드바를 통해 새 채팅을 시작하면 사이드바가 다시 채팅 목록으로 전환됩니다. 현재 패널을 유지하려면 이 기능을 끄십시오.

**채팅을 열 때 최신 메시지로 자동 스크롤** 옵션은 기본적으로 켜져 있으며, 새로 열린 대화를 가장 최근에 렌더링된 메시지로 이동시킵니다. 이 옵션을 끄면 채팅으로 돌아올 때 현재 스크롤 위치가 그대로 유지됩니다. LibreChat은 대상 대화의 행(row)이 렌더링될 때까지 기다린 후 해당 위치로 이동하며, 이는 페이지 이동과 메시지 로딩이 서로 다른 시점에 완료되는 경우에도 마찬가지입니다.

**Resize images before upload** 기능을 사용하면 사용자는 큰 JPEG, PNG, WebP 파일을 전송하기 전에 브라우저에서 축소할 수 있습니다. 이 설정은 기본적으로 켜져 있으며, 현재 브라우저에 저장됩니다.

관리자는 이 기능이 개인의 선택으로 남을지 여부를 제어할 수 있습니다. [`fileConfig.clientImageResize.enabled`](/docs/configuration/librechat_yaml/object_structure/config#clientimageresize)가 명시적으로 `true` 또는 `false`로 설정된 경우, LibreChat은 해당 값을 강제하고 사용자 토글을 잠급니다. 해당 필드가 생략된 경우, 사용자의 설정이 적용됩니다.

**Paste long text as a file**는 기본적으로 활성화되어 있으며 현재 브라우저에 저장됩니다. Upload as Text 컨텍스트 업로드를 사용할 수 있는 경우, 일반 메시지 작성기에 2,500자 이상의 텍스트를 붙여넣으면 입력창을 채우는 대신 `pasted-text.txt`로 텍스트가 첨부됩니다. 더 짧은 텍스트를 붙여넣거나 `context` 기능 없이 붙여넣은 경우에는 인라인으로 유지됩니다. [Upload Files as Text](/docs/features/upload_as_text#paste-long-text-as-a-file)를 참조하세요.

**긴 사용자 메시지 접기**는 기본적으로 켜져 있습니다. 이 기능이 활성화되면 높이가 256픽셀을 넘는 사용자 메시지는 **더 보기**와 **접기** 컨트롤이 있는 간략한 미리보기로 표시됩니다. 접기는 시각적인 효과일 뿐이며, 전체 메시지는 복사, 브라우저 검색, 보조 기술에서 여전히 사용할 수 있습니다.

**메시지 내 LaTeX 구문 분석**은 기본적으로 활성화되어 있습니다. 이 토글은 `$50`과 같이 통화와 유사한 텍스트를 리터럴로 유지하는 경계 규칙을 따르는 모호한 단일 달러 `$...$` 인라인 수식 형식을 제어합니다. 토글이 꺼져 있어도 명확한 `$$...$$`, `\(...\)`, `\[...\]` 수식은 계속 지원됩니다. 인라인 코드, 펜스 코드 및 자동 링크는 단일 달러 수식으로 해석되지 않습니다.

전송 키는 [입력창](/docs/features/composer#keyboard-shortcuts)에서 설명합니다. 이 탭의 다른 설정은 현재 브라우저에 저장됩니다:

| 설정 | 기능 | 기본값 |
|---|---|---|
| Press Enter to send messages | 켜져 있으면 Enter로 메시지를 보냅니다. 꺼져 있으면 Enter는 줄바꿈을 입력하고 Ctrl/Cmd+Enter로 보냅니다. | 켜짐 |
| While generating, Enter will | 응답이 스트리밍되는 동안 전송 시 동작을 설정합니다: Steer, Interrupt 또는 Queue. [Steering and Queued Messages](/docs/features/agents#steering-and-queued-messages)를 참조하세요. | Steer |
| Save drafts locally | 보내지 않은 텍스트와 첨부 파일을 이 기기에 임시 저장하고, 메시지를 보내면 삭제합니다. | 켜짐 |
| Save badges state | 새 채팅을 시작할 때 초기화하지 않고, 채팅 배지(도구)를 마지막 상태대로 유지합니다. | 꺼짐 |
| Toggle command "@" for switching endpoints, models, presets, etc. | `@` 명령어를 켜거나 끕니다. | 켜짐 |
| Toggle command "+" for adding a multi-response setting | `+` 명령어를 켜거나 끕니다. 다중 응답을 사용할 수 있을 때만 표시됩니다. | 켜짐 |
| Toggle command "/" for selecting a prompt via keyboard | `/` 명령어를 켜거나 끕니다. 프롬프트를 사용할 수 있을 때만 표시됩니다. | 켜짐 |
| Render user messages as markdown | 사용자 메시지를 Markdown으로 렌더링합니다. | 켜짐 |
| Display username in messages | 메시지 위에 "You" 대신 사용자 이름을 표시합니다. | 켜짐 |
| Open Thinking Dropdowns by Default | 모델의 추론 블록을 접지 않고 기본으로 펼칩니다. | 꺼짐 |
| Auto-expand tool details | 도구 호출 세부 정보를 기본으로 펼칩니다. | 꺼짐 |
| Advanced prompts editor | 프롬프트의 버전 관리와 프로덕션 제어를 활성화합니다. | 꺼짐 |
| Always make new prompt versions production | 새로 만든 프롬프트 버전을 프로덕션 버전으로 표시합니다. 고급 프롬프트 편집기를 끄면 다시 켜짐으로 설정됩니다. | 켜짐 |
| Send prompts on select | 프롬프트를 선택하는 즉시 채팅에 전송합니다. | 켜짐 |
| Enable switching Endpoints mid-conversation | 하나의 대화 안에서 엔드포인트나 모델을 변경할 수 있습니다. | 켜짐 |

음성 입력 및 재생 기능은 **Speech** 탭에서 설정할 수 있습니다. 자세한 내용은 [Speech Settings](/docs/configuration/stt_tts)를 참고하세요.

## 모델 매개변수 [#model-parameters]

사이드 패널의 모델 **Parameters** 패널은 대화 설정을 **Identity**, **Sampling**, **Limits**, **Reasoning**, **Context**, **Advanced**, **Misc.**와 같은 제목으로 그룹화합니다. 현재 endpoint가 사용하는 섹션만 표시되며, 사용자 지정 endpoint 고유의 매개변수와 같이 패널이 인식하지 못하는 설정은 **Misc.** 아래에 나열됩니다. 각 제목에는 해당 섹션에서 변경된 설정의 개수가 표시되므로, **Reset**을 선택하기 전에 무엇이 변경되었는지 확인할 수 있습니다. **Reset**과 **Save As Preset**은 패널 하단에 함께 위치합니다. [Presets](/docs/user_guides/presets)를 참조하세요.

## 키보드 단축키 [#keyboard-shortcuts]

계정 메뉴에서 **Keyboard Shortcuts**를 열어 바인딩을 검토하거나 사용자 지정하세요. **Keyboard Shortcuts** 스위치는 기본적으로 활성화되어 있습니다. 이를 끄면 모든 단축키가 비활성화되고 인터페이스에서 단축키 힌트가 제거되지만, 사용자 지정 바인딩은 유지됩니다. 단축키를 다시 켜려면 계정 메뉴에서 동일한 대화 상자를 여세요.

단축키 활성화 및 사용자 지정 바인딩은 현재 브라우저에 저장됩니다. 단축키가 꺼져 있어도 바인딩 행은 계속 표시되지만, 단축키를 다시 활성화할 때까지 편집 및 재설정 컨트롤은 비활성화된 상태로 유지됩니다.

## 데이터 및 개인정보 보호 [#data--privacy]

**Data & Privacy** 탭은 여러 섹션으로 나뉩니다:

- **메모리**: **저장된 메모리 참조**를 사용하면 어시스턴트가 응답할 때 저장된 메모리를 활용할 수 있습니다. 이 설정은 계정에 저장되며, 배포 환경에 메모리 설정이 적용되는 경우에만 표시됩니다.
- **코드 실행**: **기본 상태 저장 워크스페이스**는 새로 생성되는 에이전트에 제안되는 워크스페이스 범위를 선택합니다. 이 옵션은 상태 저장 코드 세션을 사용할 수 있을 때만 표시되며, 변경해도 상태 저장 세션이 활성화되거나 기존 에이전트가 변경되지 않습니다. **코드 환경**은 동일한 사용 가능 조건에서, 사용자가 제어하는 VM에서 실행되는 샌드박스 워커를 연결합니다.
- **Your data**: **Manage files**는 업로드한 파일 관리자를 엽니다. **Import conversations**는 지원되는 대화 내보내기 파일을 가져옵니다. **Shared chats**는 게시된 대화 링크를 나열하고 관리합니다. **Archive all chats**는 확인 후 활성 대화를 삭제하지 않고 **Archived chats**로 이동합니다. **Allow analytics**는 분석 프롬프트에 대한 응답을 변경하며, 배포 환경에서 분석이 설정된 경우에만 표시됩니다.
- **API 키**: **Provider API 키**는 구성된 제공자에 대해 제공된 키를 관리하며, 엔드포인트가 사용자 제공 키를 사용하는 경우에만 표시됩니다. **Agent API 키**는 Agents API의 키를 관리하며, 원격 에이전트를 사용할 수 있는 경우에만 표시됩니다. **모든 Provider API 키 취소**는 사용자가 제공한 모든 제공자 키를 제거합니다.
- **위험 구역**: **캐시 삭제**는 브라우저에 캐시된 텍스트 음성 변환(TTS) 오디오를 제거합니다. 캐시가 비어 있으면 사용할 수 없습니다. **모든 채팅 삭제**는 확인 후 사용자의 대화를 영구적으로 제거합니다.

데이터 삭제 및 키 취소 작업은 서버에서 지원되며 되돌릴 수 없을 수 있습니다. 브라우저 전용 기본 설정 및 캐시는 모든 기기가 아닌 현재 브라우저 프로필에만 적용됩니다.

## 계정 [#account]

**Account** 탭에는 프로필, 보안, 결제 및 삭제 관련 설정이 있습니다. 이 중 일부는 배포 환경이 해당 기능을 지원하는 경우에만 표시됩니다:

| 설정 | 기능 |
|---|---|
| 아바타 | 프로필 사진을 변경합니다. |
| 백업 코드 | 2단계 인증 백업 코드를 표시하고 다시 생성합니다. 2단계 인증이 활성화된 경우에만 나타납니다. |
| 토큰 잔액 | 토큰 크레딧을 표시합니다. 잔액 추적이 활성화된 경우에만 나타납니다. |
| 자동 충전 | 자동 잔액 충전을 표시하거나 설정합니다. 잔액 추적이 활성화된 경우에만 나타납니다. |
| 계정 삭제 | 계정과 데이터를 영구적으로 삭제합니다. 배포 환경에서 계정 삭제가 허용된 경우에만 나타납니다. |
