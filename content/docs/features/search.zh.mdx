消息搜索可以在你的所有对话中查找文本,让你无需在侧边栏中翻找,就能找回三周前的那条回答。该功能由 Meilisearch 提供支持,它可以边输入边匹配,并能容忍少量拼写错误。

## 搜索 [#searching]

在侧边栏中的**搜索消息**框中输入内容,或按 Ctrl+/(macOS 上为 ⌘ /)跳转到该框。停止输入片刻后,结果会加载出来。主区域会列出匹配的消息及其数量,每条消息都附有所属对话的标题;点击标题即可打开该对话。同时,侧边栏中的对话列表会缩小为匹配的对话,匹配依据可以是标题、标签,或其中某条消息与搜索内容相符。

按 Escape 键,或删除最后一个字符,即可清除搜索内容。此操作还会退出搜索结果页面并开始新的对话。

要在不输入查询的情况下按日期、端点、附件、分享或书签来筛选聊天列表,请改用[聊天列表筛选器](/docs/features/navigation#filter-and-sort-the-chat-list)。

## 可搜索的内容 [#what-is-searchable]

搜索涵盖对话标题、标签，以及您自己发送的消息和助手回复的文本。您永远不会看到其他用户对话中的搜索结果。

它匹配的是你输入的词语，而不是其含义。搜索"banana"会找到包含"banana"一词的消息，而不会找到一条没有使用该词、但内容是关于水果的消息。LibreChat 中基于含义的检索仅适用于上传的文件，通过[文件搜索](/docs/features/rag_api)实现。

临时对话不会被索引,因此它们永远不会出现在搜索结果中。新消息在保存后会很快被索引;在大型现有数据库上,开启搜索后首次完整索引可能需要一段时间,较早的对话会随着索引进度逐步出现。

## 设置 [#setup]

在管理员运行 Meilisearch 并设置 `SEARCH=true` 之前,搜索功能处于关闭状态;未设置时,搜索框不会显示。有关 Docker 和源码部署方式以及重新同步索引的说明,请参阅 [Meilisearch](/docs/configuration/meilisearch)。
