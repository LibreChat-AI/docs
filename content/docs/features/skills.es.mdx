Una skill es un archivo `SKILL.md`: un breve bloque de frontmatter que indica cuándo se aplica la skill, y un cuerpo en markdown con las instrucciones. Úsala para cualquier contenido que de otro modo pegarías en el chat una y otra vez, como una guía de estilo, una lista de verificación de revisión o los pasos de un informe recurrente. Los agentes cargan una skill solo cuando es relevante, así que puedes tener muchas sin sobrecargar cada prompt.

LibreChat no incluye ninguna skill. Cada una es escrita o subida por un usuario, creada por un agente durante un chat, o proporcionada por tu administrador.

## Crear una skill [#create-a-skill]

Abre **Skills** desde el panel lateral y haz clic en **+**. Elige **Write skill instructions** para escribir una en el editor, o **Upload a skill** para importar un archivo `.md`, o un archivo `.zip` o `.skill` que contenga un `SKILL.md`. Si Skills no aparece en el panel lateral, es posible que tu administrador lo haya desactivado o que tu rol no tenga permiso para usarlo.

Una habilidad mínima:

```md filename="SKILL.md"
---
name: brand-guidelines
description: Use when writing public-facing copy that must follow the company voice and terminology.
---

Write in a concise, practical tone.
Prefer active voice.
Say "workspace", never "project space".
```

El nombre debe estar en kebab-case (letras minúsculas, dígitos y guiones), tener como máximo 64 caracteres y ser único entre tus skills; si subes una skill con un nombre que ya utilizas, la operación falla en lugar de sobrescribirla. Los nombres que comienzan con `anthropic-` o `claude-`, así como las palabras de comando como `help` o `settings`, están reservados.

La descripción es lo más importante de todo el archivo: es lo que el modelo lee para decidir si la skill es aplicable. "Úsala al redactar las notas de la versión de la app móvil" se activará; "Asistente de redacción" no. Coloca las frases desencadenantes al principio y mantén la descripción por debajo de 250 caracteres, porque las descripciones más largas se recortan en la lista que ve el modelo. El límite máximo es de 1.024 caracteres para la descripción y de 100.000 para el cuerpo.

### Opciones de frontmatter [#frontmatter-options]

Además de `name` y `description`, una skill puede definir:

- `always-apply: true`: cargar la skill en cada turno en lugar de esperar a que el modelo la solicite.
- `user-invocable: false`: ocultarlo del menú `$`.
- `disable-model-invocation: true`: déjalo fuera de la lista de la que elige el modelo. Aun así, puedes invocarlo con `$`.
- `allowed-tools`: una lista de herramientas (por ejemplo `["execute_code"]`) que el agente obtiene para ese turno cuando la skill se invoca con `$` o siempre se aplica, incluso si el agente normalmente no las tiene.
- `compatibility`: notas de texto libre sobre lo que necesita la skill, como un servidor MCP concreto. LibreChat lo conserva, pero no lo aplica.

Cuando se usa `when-to-use` en lugar de `description`, y `alwaysApply` en lugar de `always-apply`. Las claves no distinguen entre mayúsculas y minúsculas, y las demás claves que añadas se conservan como metadatos.

### Archivos incluidos [#bundled-files]

Una skill puede contener más de un archivo. Un diseño habitual usa `references/` para documentos extensos, `scripts/` para código que el agente puede ejecutar y `assets/` para plantillas. El agente lee estos archivos cuando la skill está en uso, de modo que `SKILL.md` puede mantenerse breve y remitir a ellos. Cuando Run Code está activado, los archivos también están disponibles en el sandbox en `/mnt/data/skills/<skill-name>/`. En el visor de skills, los enlaces relativos entre los archivos Markdown de la skill abren el archivo enlazado.

En un archivo, `SKILL.md` debe estar en el nivel superior o dentro de exactamente una carpeta. Una carga está limitada a 50 MB de forma predeterminada (tu administrador puede cambiar este valor), 500 archivos y 10 MB por archivo; los archivos con rutas no seguras se omiten y se informan. Una skill con archivos incluidos muestra una flecha junto a su nombre en la barra lateral de Skills; expándela para explorar los archivos y abrir uno.

## Usa una habilidad [#use-a-skill]

Existen tres formas en que una skill llega a la conversación:

- **Tú lo eliges.** Escribe `$` en el cuadro de chat y selecciona una habilidad. No se añade nada a tu texto; la habilidad aparece como una etiqueta encima del editor y se carga para ese mensaje.
- **El modelo lo elige.** El agente ve los nombres y las descripciones de las habilidades disponibles para él, y carga una cuando tu solicitud coincide con ella.
- **Siempre se aplica.** Las Skills con `always-apply: true` se cargan en cada turno.

Mientras se carga una habilidad, el mensaje muestra **Loading** seguido del nombre de la habilidad, y luego **Loaded** una vez que está en el contexto.

El modelo solo ve los nombres y las descripciones en su lista (hasta 100 skills), no las instrucciones. Un skill que tú seleccionas o que se aplica siempre carga su `SKILL.md` completo para ese turno. Un turno admite hasta 10 skills seleccionados y 20 skills aplicados siempre, 30 en total; si se supera ese límite, los skills aplicados siempre se descartan primero.

## Qué habilidades puede usar un agente [#which-skills-an-agent-can-use]

Dos cosas lo deciden.

Primero, tu propia lista. Cada skill tiene un interruptor **Available to agent**. Si lo desactivas, la skill desaparece del menú `$`, de las opciones que puede elegir el modelo y de la aplicación siempre activa, sin que se elimine. Las skills que creas empiezan activadas. Las skills compartidas contigo empiezan desactivadas, salvo que tu administrador haya activado las skills compartidas por defecto.

Segundo, el agente. La sección **Skills** del Agent Builder tiene tres ajustes:

- **Desactivado**: el agente no usa ninguna habilidad.
- **Todas**: cada habilidad que tienes activada.
- **Seleccionado**: solo las habilidades que agregues a la lista.

**Seleccionado** es la mejor opción para un agente enfocado. Un agente de soporte con 40 habilidades entre las que elegir escogerá la incorrecta con más frecuencia que uno con las tres que necesita.

## Habilidades escritas por agentes [#skills-written-by-agents]

Un agente con las habilidades activadas también puede escribir habilidades mientras trabaja, por ejemplo, para guardar un procedimiento que acaba de funcionar. Puede crear una nueva habilidad si tu rol tiene permiso para crear habilidades, y editar habilidades existentes solo si tienes permiso para editarlas y están dentro del alcance del agente. Las habilidades de tu administrador siguen siendo de solo lectura. Con **Selected** y una lista vacía, el agente no ve ninguna de tus habilidades existentes, pero aún puede crear otras nuevas.

## Compartir [#sharing]

Las Skills se comparten de la misma forma que los agentes y los prompts, con los roles Viewer (usar, sin poder editar), Editor y Owner. Compartir requiere el permiso de compartir en tu rol, que está desactivado por defecto para los usuarios regulares. Consulta [Control de acceso](/docs/features/access_control).

Tu administrador también puede proporcionar skills, desde el sistema de archivos del servidor, desde [Agent Plugins](/docs/features/agent_plugins), o reflejadas desde un repositorio de GitHub. Estas son de solo lectura en LibreChat; cámbialas en su origen. Las skills del sistema de archivos y de los plugins se activan por defecto.

## Configuración [#setup]

Las habilidades están activadas de forma predeterminada para todos los usuarios. Los administradores pueden desactivar la función con la capacidad de agente `skills` (consulta [configuración del endpoint de agentes](/docs/configuration/librechat_yaml/object_structure/agents#capabilities)), controlar quién puede crear y compartir habilidades en el [Panel de administración](/docs/features/admin_panel) o en [`interface.skills`](/docs/configuration/librechat_yaml/object_structure/interface#skills), proporcionar habilidades desde el disco o desde GitHub como se describe en [Sincronización de habilidades](/docs/configuration/librechat_yaml/object_structure/skill_sync), y cambiar el límite de tamaño de carga con [`fileConfig.skills`](/docs/configuration/librechat_yaml/object_structure/file_config#skills).
