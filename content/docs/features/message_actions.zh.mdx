每条聊天消息下方都有一排小按钮。在桌面端,将鼠标悬停在消息上或将键盘焦点移动到消息上时,这些按钮会显示出来。在回复仍在流式输出时无意义的按钮会保持隐藏,直到回复结束。

## 每个按钮的功能 [#what-each-button-does]

| 按钮 | 功能 |
|---|---|
| **朗读** | 在启用文本转语音时,使用语音朗读该消息。 |
| **复制到剪贴板** | 复制消息文本。 |
| **编辑** | 在编辑器中打开该消息。请参阅[编辑并重新运行](#edit-and-rerun)。 |
| **分支** | 从该消息开始一个新对话。请参阅[分支对话](/docs/features/fork)。 |
| **点赞** / **需要改进** | 对回复进行评分。你可以添加原因和评论。 |
| **重新生成** | 请求模型对同一消息生成新的回复。旧回复会作为较早的版本保留。 |
| **继续** | 当最新回复因达到输出 token 上限等原因在完成前停止时显示在该回复上。从中断处继续生成。 |

显示哪些按钮取决于端点和消息类型。例如,用户消息没有评分按钮或**重新生成**按钮。

## 编辑并重新运行 [#edit-and-rerun]

在您自己的消息或回复上选择**编辑**。编辑器有三个按钮:

- **Save** 会保存你的更改，但不会生成任何新内容。
- **更新并重新运行**会重新发送你编辑后的消息并获得新的回复。当你没有做任何修改时，按钮显示为**重新运行**；当你在编辑一条回复时，该按钮会重新执行此前的那条用户消息。
- **取消** 会关闭编辑器。

在编辑时,<kbd>Ctrl</kbd>+<kbd>S</kbd>(<kbd>Cmd</kbd>+<kbd>S</kbd>)用于保存,<kbd>Ctrl</kbd>+<kbd>Enter</kbd>(<kbd>Cmd</kbd>+<kbd>Enter</kbd>)用于重新运行,<kbd>Escape</kbd>用于取消。

重新运行会保留原始消息中附加的文件、引用摘录和技能,因此您无需再次添加它们。仅包含文件而没有文本的消息也可以进行编辑和重新运行。

来自智能体的回复可能不仅包含文本。编辑器仅允许修改文本和推理部分;工具调用、错误和构件会显示出来,但为只读。重新运行时每次只应用一个已编辑的部分,因此如果修改了多个部分,请使用 **Save**。

## 复制 [#copy]

**复制到剪贴板**会复制消息中可见的文本。对于智能体回复,推理过程、工具调用和错误信息不会被复制。引用会被转换为易于阅读的参考格式。

如果你要粘贴到 Teams、Outlook 或 Word 等应用中,请在 **Settings > Chat** 中开启 **Copy messages as rich text**。开启后,复制时剪贴板中还会包含格式化版本,因此标题、列表、表格和代码会保留其样式。

## 引用摘录 [#quote-excerpts]

在任意消息中选中一段文字,然后选择**添加到对话**。该摘录会暂存在输入框上方,并在您发送下一条消息时以引用的形式一并发送,这样模型就能准确知道您指的是哪一部分。每条消息最多可附加 10 段摘录,每段摘录最多保留 1,500 个字符,超出部分将被截断。

引用同样适用于[引导与排队消息](/docs/features/agents#steering-and-queued-messages):引文会保留在你排队或引导的消息中。

## 代码块 [#code-blocks]

回复中的代码块在其标题栏中带有各自的按钮:

- **复制代码** 会复制该代码块。
- **下载代码**会将其保存为以代码块语言命名的文件，例如 `code.py` 或 `code.toml`。没有指定语言的代码块，或语言名称不像文件扩展名的代码块，将下载为 `code.txt`。错误代码块没有下载按钮。
- **运行代码**会在可用的情况下，使用[代码解释器](/docs/features/code_interpreter)运行该代码块，前提是该语言支持代码解释器。
