メッセージコンポーザーは、すべてのチャット画面の下部にあるボックスです。テキストフィールドの他に、メッセージに追加できるすべての要素（ファイル、ツール、スキル、MCPサーバー、および以前にアップロードしたファイル）を開くための **+** ボタン、現在有効になっているツールのチップ、そして推論、音声入力、送信のためのコントロールが配置されています。

## コンポーザーの内容 [#whats-on-the-composer]

| 要素 | 機能 |
|---|---|
| **+** (**添付とツール**) | パレットを開きます。アップロードオプション、ツール、スキル、MCPサーバー、最近使用したファイルがすべて1つのフィールドから検索可能です。 |
| ツールチップ | **+** ボタンの横にある、有効なツールまたはMCPサーバーごとのチップです。チップを削除すると、そのツールをオフにできます。 |
| ステージングされたコンテキスト | 次のメッセージに添付されたファイル、引用、スキルです。テキストフィールドの上に表示されます。 |
| **思考 (Thinking)** | 対応モデルにおける推論の取り組みです。 |
| コンテキスト使用量 | トークン使用量が利用可能な場合、会話がモデルのコンテキストウィンドウをどれだけ使用しているかを示します。 |
| **マイクを使用** | 音声テキスト変換が有効な場合、音声でメッセージを入力します。 |
| 送信 / 停止 | メッセージを送信するか、ストリーミング中の応答を停止します。 |

To see which keys apply right now, such as `/ for prompts`, `@ for models` or `Enter to send`, turn on **Show composer tips** in **Settings > General**. A one-line tip then appears under the text field. It is off by default.

## ファイルの追加 [#add-files]

**+** をクリックし、**Attach** セクションでオプションを選択します。ファイルをコンポーザーにドラッグ＆ドロップしたり、貼り付けたりすることもできます。

デフォルトでは、LibreChatは統合アップローダーを使用します。ソースを選択するだけで、ファイルの種類とendpointに基づいて、各ファイルがどのようにモデルに到達するか（ネイティブプロバイダーへのアップロード、テキスト抽出、またはFile Searchなどのツール）が自動的に決定されます。

| オプション | 表示されるタイミング |
|---|---|
| **From Local Computer** | 常に表示（デフォルトのアップローダー使用時）。 |
| **From SharePoint** | [SharePoint file picker](/docs/configuration/sharepoint) が有効な場合に表示。 |

管理者が [`fileConfig.legacyFileUploadUX: true`](/docs/configuration/librechat_yaml/object_structure/file_config#legacyfileuploadux) を設定している場合、代わりに保存先を自分で選択することになります。その際、**Attach** セクションにはメインのオプションが最初に表示され、残りは **More upload options** の中に折りたたまれます。

| オプション | 表示されるタイミング |
|---|---|
| **Upload to Provider** | プロバイダーがドキュメントを直接受け入れる場合（例: OpenAI、Anthropic、Google、Bedrock、OpenRouter、カスタムエンドポイント、または Responses API が有効な Azure OpenAI）。 |
| **Upload Image** | プロバイダーが画像のみを受け入れる場合に **Upload to Provider** の代わりに表示されます。 |
| **Upload as Text** | [context capability](/docs/features/upload_as_text) が有効な場合。 |
| **Upload for File Search** | File Search が有効であり、現在のエージェントに対して許可されている場合。これを選択すると File Search もオンになります。 |
| **Upload to Code Environment** | コード実行が有効であり、現在のエージェントに対して許可されている場合。これを選択すると **Run Code** もオンになります。 |
| **Attach Files** | Assistants エンドポイント。アシスタント独自の設定でファイルを処理します。 |

このモードでSharePointを有効にすると、各オプションにもSharePointバージョンが用意され、例えば **Upload to Provider (From SharePoint)** のようにラベル付けされます。

### 以前アップロードしたファイルを再利用する [#reuse-a-file-you-uploaded-before]

パレットの **Your files** セクションには、最近使用したファイルが一覧表示されます。ファイルを選択すると、再アップロードすることなく再度添付できます。検索フィールドに入力すると、すべてのファイルを名前で検索できます。

セクションの **Show all** を選択すると、ダイアログですべてのファイルを閲覧できます。**All**（すべて）、**Images**（画像）、**Documents**（ドキュメント）の各ビュー、検索フィールド、および画像やPDFのプレビュー機能が利用可能です。

パレットには最大5つの最近使用したファイルが表示されます。管理者は、[`interface.composerRecentFiles`](/docs/configuration/librechat_yaml/object_structure/interface#composerrecentfiles) を使用してその数を減らすか、`0` に設定してリストを非表示にすることができます。

## ツール、スキル、および MCP サーバーを有効にする [#turn-on-tools-skills-and-mcp-servers]

パレットには、現在の会話で有効にできるすべての項目がセクションごとにグループ化されて一覧表示されます。

- **Tools**: **Web Search**（ウェブ検索）、**Run Code**（コード実行）、**File Search**（ファイル検索）、**Skills**（スキル）、**Memory**（メモリ）、**Artifacts**（アーティファクト）などの組み込みツール。それぞれ、有効化されており、かつアクセス権がある場合にのみ表示されます。
- **Skills**: 次のメッセージに添付できる個別の [skills](/docs/features/skills)。
- **MCP Servers**: チャットで利用可能な [MCP servers](/docs/features/mcp)。

ツールまたはMCPサーバーを選択して、オン/オフを切り替えます。パレットは開いたままになるため、一度の操作で複数を切り替えることができます。オンになっている各ツールはコンポーザー上にチップとして表示されます。チップを削除するとオフになります。一部のチップには、例えば**Artifacts**生成モードのようなモードメニューが含まれています。

スキルを選択すると、そのスキルはチップとしてではなく[staged context](#staged-context)に表示され、次のメッセージのために準備（ステージング）されます。

MCPサーバーの行には、各サーバーの接続状態が表示されます。接続されていないサーバーを選択すると、接続が開始されます（サーバーが必要とする場合はOAuthサインインが含まれます）。また、認証情報が必要な場合は、最初に設定画面が開きます。接続が完了すると、ユーザー認証情報を必要とするサーバーの行には「**Configure**（設定）」コントロールが表示され、**Web Search**にはAPIキー用のコントロールが表示されます。

<Callout type="info" title="エージェントは独自のツールを持参します">
  エージェントが選択されている場合、**Tools**（ツール）および **MCP Servers**（MCPサーバー）セクションは非表示になります。これは、エージェント自身の構成によって使用するツールが決定されるためです。他のエンドポイントでは、`hideBadgeRow: true` を設定した [model spec](/docs/configuration/librechat_yaml/object_structure/model_specs#hidebadgerow) を使用することで、**Tools**、**Skills**（スキル）、および **MCP Servers** セクションを非表示にできます。**Attach**（添付）および **Your files**（自分のファイル）は、いずれの場合も引き続き利用可能です。
</Callout>

### すべて表示 [#show-all]

パレットには、セクションごとにいくつかの行が表示されます。**Skills**、**MCP Servers**、または **Your files** ヘッダーの **Show all** を選択すると、全リスト、検索フィールド、フィルターを備えたダイアログが開きます。Skills と MCP servers には、**All**、**Made by you**、**Favorites** の3つのビューがあります。

### お気に入りおよびピン留めされたツール [#favorites-and-pinned-tools]

行にスターを付けると、パレットの最上部に表示される**お気に入り**に追加されます。行がハイライトされている状態で <kbd>Ctrl</kbd>+<kbd>D</kbd>（macOSの場合は <kbd>Cmd</kbd>+<kbd>D</kbd>）を押すと、スターの追加や解除ができます。お気に入りはアカウントに保存されます。

管理者は [`interface.defaultPinnedTools`](/docs/configuration/librechat_yaml/object_structure/interface#defaultpinnedtools) を使用して、組み込みツールをピン留めできます。ピン留めされたツールは、オフの状態であってもコンポーザー上にチップが表示され続けるため、ワンクリックでオンに切り替えることができます。オフになっているピン留めされたツールのチップを削除すると、そのピン留めは解除されます。

## Staged context [#staged-context]

次のメッセージに添付されたすべての項目は、送信前にテキストフィールドの上に表示されます：

- **Files**。アップロードの進捗状況や画像のプレビューが表示されます。長いテキストを貼り付けた場合もファイルとしてここに保存され、編集したりメッセージ内に戻したりすることができます。
- 以前のメッセージから選択した**引用**。
- パレットから、または `$` コマンドを使用して選択した **Skills**。

削除ボタンを使用して項目を削除します。ステージングされたすべての項目は、次のメッセージと一緒に送信されます。

## 思考と労力 (Thinking and effort) [#thinking-and-effort]

推論設定を持つモデルの場合、**Thinking**コントロールを開くと、**Faster**から**Smarter**まで調整できるスライダーが表示されます。これに加えて、**Auto**やオフといったプロバイダー固有のモードも選択可能です。これはParametersパネルと同じパラメータを変更するものであるため、モデルに推論設定がない場合や、デプロイメントで `interface.parameters` を使用してパラメータが無効化されている場合は非表示になります。

## レスポンスのストリーミング中にキューイングとステアリングを行う [#queue-and-steer-while-a-response-streams]

レスポンスのストリーミング中も入力を続けることができます。endpointや設定に応じて、<kbd>Enter</kbd>キーを押すと、メッセージをレスポンス終了後の送信待ち行列に入れるか、エージェントの現在のレスポンスを制御（ステアリング）するかのいずれかの動作が行われます。コンポーザーのヒントには、その時点で<kbd>Enter</kbd>キーが実行するアクションが表示されます。

キューに入れられたメッセージは、コンポーザーの上の **Queued messages** レールに表示され、そこで以下の操作が可能です：

- **Edit message** をクリックして、メッセージをテキストフィールドに戻します。
- **Remove message** を選択してキューから削除します。
- **Send now** をクリックすると、待機せずにすぐに送信できます。
- メッセージをドラッグするか、メッセージにフォーカスを当てて上下の矢印キーを押すことで、メッセージの順序を並べ替えることができます。

ステアリングの仕組みと利用可能なタイミングについては、[Steering and Queued Messages](/docs/features/agents#steering-and-queued-messages) を参照してください。

## キーボードショートカット [#keyboard-shortcuts]

### テキストフィールド内 [#in-the-text-field]

| キー | アクション |
|---|---|
| <kbd>Enter</kbd> | メッセージを送信します（レスポンスのストリーミング中にキューイングまたはステアリングを行います）。 |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | 改行します。 |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) | レスポンスのストリーミング中：代替アクションを実行します。<kbd>Enter</kbd>がキューイングの場合は**今すぐ送信**、<kbd>Enter</kbd>がステアリングの場合は**キューイング**を行います。 |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> (<kbd>Option</kbd>+<kbd>Enter</kbd>) | エージェントが応答中：利用可能な場合に割り込んで送信します。 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>) | レスポンスを停止します。 |
| `/` | 保存されたプロンプトを挿入します。 |
| `@` | 別のモデル、プリセット、またはエージェントに切り替えます。 |
| `+` | 追加のレスポンス用にモデルまたはプリセットを追加します。 |
| `$` | 次のメッセージに使用するスキルを選択します。 |

**Press Enter to send messages**（Enterキーでメッセージを送信）をオフにした場合、<kbd>Ctrl</kbd>+<kbd>Enter</kbd>（<kbd>Cmd</kbd>+<kbd>Enter</kbd>）で送信され、<kbd>Enter</kbd>で改行が追加されます。

### パレット内 [#in-the-palette]

| キー | アクション |
|---|---|
| 入力 | ツール、スキル、サーバー、アップロードオプション、ファイルを検索します。 |
| <kbd>↑</kbd> / <kbd>↓</kbd> | 行を移動します。 |
| <kbd>Enter</kbd> | ハイライトされた行を選択します。 |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd>) | ハイライトされた行をお気に入りに追加、または削除します。 |
| 検索が空の状態で <kbd>Backspace</kbd> | パレットを閉じます。 |
| <kbd>Escape</kbd> | パレットを閉じます。 |
