コンポーザーは、すべてのチャットの下部にあるボックスです。テキスト入力欄の横には、ファイル、ツール、スキル、MCPサーバー用の**+**ボタン、有効にしたツールごとのチップ、そして推論の強度、音声入力、送信のためのコントロールが並んでいます。

**+**(スクリーンリーダーでは**Attach and tools**と読み上げられます)をクリックしてパレットを開きます。パレット内のすべての項目は上部のフィールドから検索できるため、数文字入力するだけでスクロールするより速く見つけられることがよくあります。

## ファイルの追加 [#add-files]

**Attach** セクションで **From Local Computer** を選択するか、ファイルをコンポーザーにドラッグ&ドロップするか、貼り付けてください。LibreChat は、ファイルの種類とエンドポイントに基づいて、各ファイルをモデルへどのように渡すか（プロバイダーへ直接送信、テキストとして抽出、または File Search 用にインデックス化）を決定するため、ユーザーが選ぶのはファイルの取得元だけで済みます。管理者が SharePoint を接続している場合は、その横に **From SharePoint** が表示されます。

一部のデプロイメントでは、アップロード先を自分で選択する従来のアップローダーが使われています。選択肢は **Upload to Provider**(画像のみに対応するプロバイダーの場合は **Upload Image**)、**Upload as Text**、**Upload for File Search**、**Upload to Code Environment** です。最初の選択肢は表示されていますが、残りは **More upload options** の内側にあります。**Upload for File Search** または **Upload to Code Environment** を選択すると、そのツールも有効になります。

### 以前アップロードしたファイルを再利用する [#reuse-a-file-you-uploaded-before]

**Your files** in the palette lists your most recently used files (five by default). Select one to attach it again without uploading it. Typing in the search field searches all of your files by name, and **Show all** opens a dialog with every file, split into **All**, **Images** and **Documents**, with previews for images and PDFs.

## ツール、スキル、および MCP サーバーを有効にする [#turn-on-tools-skills-and-mcp-servers]

**Attach** の下には、会話に追加できるものがパレットにグループ分けして表示されます。

- **ツール**: **Web Search**、**Run Code**、**File Search**、**Skills**、**Memory**、**Artifacts** などの組み込みツールです。有効化されており、アクセス権のあるツールのみが表示されます。
- **Skills**: [skills](/docs/features/skills) を次のメッセージに添付できます。
- **MCP Servers**: チャットで利用可能な[MCP servers](/docs/features/mcp)と、それぞれの接続ステータス。

ツールまたは MCP サーバーを選択すると、それがオンまたはオフに切り替わります。パレットは開いたままになるため、複数のツールを続けて切り替えられます。オンになっている各ツールには入力欄(コンポーザー)にチップが表示されます。チップを削除すると、そのツールはオフになります。一部のチップには独自のメニューがあります。たとえば **Artifacts** の生成モードがそれにあたります。

スキルの選択は別の仕組みで動作します。チップとして表示されるのではなく、次のメッセージ用に準備されます([準備済みのコンテキスト](#staged-context)を参照してください)。

MCP サーバーがまだ接続されていない場合、そのサーバーを選択すると接続が開始されます。サーバーが必要とする場合は、OAuth によるサインインも行われます。ご自身の認証情報が必要なサーバーでは、まず認証情報の入力が求められます。その後も各行に **Configure** ボタンが残るため、認証情報をいつでも変更できます。

エージェントを選択している場合、**ツール**と**MCP サーバー**のセクションは表示されなくなります。これは、使用するツールがエージェント自身の構成によって決まるためです。アシスタントの場合も同様です。

### すべて表示とお気に入り [#show-all-and-favorites]

各セクションには最大5行まで表示されます。**Skills**、**MCP Servers**、または **Your files** のヘッダーにある **Show all** を選ぶと、検索とフィルターを備えた全件のリストが開きます。Skills と MCP Servers は **Made by you** または **Favorites** で絞り込むことができます。

行を お気に入り に登録するには、その行をハイライトして <kbd>Ctrl</kbd>+<kbd>D</kbd>(macOS では <kbd>Cmd</kbd>+<kbd>D</kbd>)を押します。お気に入りはパレットの一番上に移動し、アカウントに保存されます。

管理者は組み込みツールを固定（ピン留め）することもできます。固定されたツールは、オフの状態でもコンポーザー上にチップが表示されるため、ワンクリックで利用できます。オフの状態で固定されているツールのチップを削除すると、そのツールの固定は解除されます。

## Staged context [#staged-context]

次のメッセージに添付したものは、送信前にテキスト入力欄の上に表示されます。

- アップロードの進捗表示と画像プレビュー付きのファイル。
- 長いテキストの貼り付け。[テキストとしてアップロード](/docs/features/upload_as_text#pasting-long-text)が利用可能な場合、2,500文字を超えるテキストを貼り付けると、入力欄に入力される代わりに、テキストが `pasted-text.txt` として添付されます。それを選択すると、より大きなダイアログでテキストを編集できます。または **メッセージに戻す** を選択して、テキスト入力欄に戻すこともできます。この動作を無効にするには、**設定 > チャット** の **長いテキストをファイルとして貼り付ける** をオフにします。
- 以前のメッセージから引用した抜粋を、**チャットに追加**で追加します([抜粋を引用](/docs/features/message_actions#quote-excerpts)を参照)。
- パレットから選択した、または `$` で指定したスキル。

送信する前に、不要なものはすべて削除してください。残っているものはすべてメッセージと一緒に送信されます。テキストを入力せずに、ファイルだけを送信することもできます。

## 思考 [#thinking]

推論設定のあるモデルでは、**Thinking**コントロールを開くと、**Faster**から**Smarter**までのスライダーが表示されます。プロバイダーが提供する別モードがある場合（**Auto**など）は、それも表示されます。このコントロールはパラメータパネルと同じ値を変更します。モデルに推論設定がない場合、または管理者がパラメータを非表示にしている場合は、このコントロールは表示されません。

## レスポンスのストリーミング中にキューイングとステアリングを行う [#queue-and-steer-while-a-response-streams]

応答のストリーミング中も入力を続けることができます。その時点で送信を行ったときの動作は、**Settings > Chat** の **While generating, Enter will** で設定したデフォルト値によって決まります（[Personal Settings](/docs/features/settings#chat) を参照）。

- キュー: メッセージは待機し、返信が完了した時点で送信されます。
- Steer: 実行中のレスポンスは、ツールや推論をキャンセルすることなく、次の安全なポイントであなたのメッセージを取り込みます。
- 中断: 実行中のツールと推論はキャンセルされ、完了済みの出力は保持されます。そのうえで、あなたのメッセージに基づいて応答が続けられます。

エージェントでのステアリングの仕組みと利用可能なタイミングについては、[ステアリングとキュー済みメッセージ](/docs/features/agents#steering-and-queued-messages)を参照してください。

キューに入ったメッセージは、コンポーザーの上にある**Queued messages**リストで待機します。各メッセージからは、**Send now**（今すぐ送信）、**Remove message**（メッセージを削除）を選択するか、**More options**（その他のオプション）を開いて、**Edit message**（メッセージを編集、テキストフィールドに戻されます）、**Start in a new chat**（新しいチャットで開始）、または**Disable Queue**（キューを無効にし、自動では送信されないようにする）を実行できます。メッセージをドラッグして並べ替えるか、メッセージにフォーカスを合わせて上下の矢印キーを使用することもできます。

## キーボードショートカット [#keyboard-shortcuts]

### テキストフィールド内 [#in-the-text-field]

この表は **Enterキーでメッセージを送信** がオンになっていること(デフォルト設定)を前提としています。オフの場合、<kbd>Enter</kbd> は改行を追加し、<kbd>Ctrl</kbd>+<kbd>Enter</kbd> で送信します。

| キー | 動作 |
|---|---|
| <kbd>Enter</kbd> | 送信します。返信がストリーミング中は、**While generating, Enter will** で選んだ動作を実行します。 |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | 改行します。 |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd>(<kbd>Cmd</kbd>+<kbd>Enter</kbd>) | 改行します。返信がストリーミング中は、もう一方の動作を実行します。<kbd>Enter</kbd> がキューイングする設定の場合は今すぐ送信し、割り込みまたは方向転換する設定の場合はキューに追加します。 |
| <kbd>Alt</kbd>+<kbd>Enter</kbd>(<kbd>Option</kbd>+<kbd>Enter</kbd>) | 返信がストリーミング中に、実行中の処理が許可していればメッセージで割り込みます。 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd>(<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd>) | <kbd>Alt</kbd>+<kbd>Enter</kbd> と同じです。 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>(<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>) | 返信を停止します。 |
| `/` | 保存済みのプロンプトを挿入します。 |
| `@` | モデル、プリセット、またはエージェントを切り替えます。 |
| `+` | 並べて表示する返信用に、別のモデルまたはプリセットを追加します。 |
| `$` | 次のメッセージで使用するスキルを選択します。 |

アカウントメニューからショートカットキーの割り当てを変更したり、無効にしたりできます。詳しくは[キーボードショートカット](/docs/features/settings#keyboard-shortcuts)をご覧ください。

### パレット内 [#in-the-palette]

| キー | 操作 |
|---|---|
| 入力 | ツール、スキル、サーバー、アップロードオプション、ファイルを検索します。 |
| <kbd>↑</kbd> / <kbd>↓</kbd> | 行を移動します。 |
| <kbd>Enter</kbd> | 強調表示されている行を選択します。 |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd>) | 強調表示されている行をお気に入りに追加または解除します。 |
| 検索欄が空の状態で<kbd>Backspace</kbd>、または<kbd>Escape</kbd> | パレットを閉じます。 |

## セットアップ [#setup]

コンポーザーに設定は必要ありません。管理者は、そこに表示される内容を制御できます。従来のアップローダーは[`fileConfig.legacyFileUploadUX`](/docs/configuration/librechat_yaml/object_structure/file_config#legacyfileuploadux)で、最近のファイルの数は[`interface.composerRecentFiles`](/docs/configuration/librechat_yaml/object_structure/interface#composerrecentfiles)で、固定されたツールは[`interface.defaultPinnedTools`](/docs/configuration/librechat_yaml/object_structure/interface#defaultpinnedtools)で、SharePointは[SharePoint連携](/docs/configuration/sharepoint)で制御します。`hideBadgeRow`を設定した[モデルスペック](/docs/configuration/librechat_yaml/object_structure/model_specs#hidebadgerow)では、そのスペックのツールセクションが非表示になります。
