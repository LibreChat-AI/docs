La mémoire est un petit espace de stockage de faits vous concernant, enregistrés sous forme de paires clé/valeur, que LibreChat ajoute au contexte de chaque nouveau message. Dites au modèle « retiens que j'écris en Python et que je préfère des réponses courtes » une seule fois, et il s'en souviendra également lors de votre prochaine conversation.

Ce n'est pas une recherche dans votre historique de conversations. Rien des anciennes conversations n'est rappelé, sauf s'il a été enregistré sous forme d'entrée de mémoire. L'ensemble du stockage est inclus dans chaque requête ; il est donc conçu pour quelques faits durables, et non pour des notes ou des documents.

## Enregistrer une mémoire [#saving-a-memory]

Cliquez sur **+** dans le [compositeur de messages](/docs/features/composer) pour ouvrir la palette, puis sélectionnez **Memory** dans la section **Tools**. Une fois activé, le modèle reçoit deux outils, `set_memory` et `delete_memory`, et il est instruit de ne les utiliser que lorsque vous lui demandez de mémoriser, de mettre à jour ou d'oublier quelque chose. Un message tel que « remember that my team uses pnpm » produit une étape « Saved memory » dans la réponse, libellée avec la clé de la mémoire ; développez-la pour voir la valeur enregistrée. « Forget where I work » produit « Deleted memory ». Lorsque le modèle effectue plusieurs appels de mémoire dans une même réponse, ceux-ci sont regroupés sous une seule étape, par exemple « Ran 2 actions ».

L'option Mémoire n'apparaît que si votre rôle est autorisé à créer et mettre à jour des mémoires. Lorsque vous discutez avec un agent, la palette ne propose aucune option Mémoire ; l'agent utilise la mémoire si celle-ci est activée dans le Constructeur d'agents.

Un agent peut également être configuré pour **Conserver les mémoires séparées pour cet agent** : il lit et écrit alors son propre espace de stockage, isolé de vos mémoires partagées et des autres agents. Ces entrées suivent l'accès à l'agent : si vous perdez l'accès à celui-ci, ses mémoires séparées ne peuvent plus être lues ni mises à jour, bien que vous puissiez toujours supprimer les mémoires d'un agent qui a été supprimé.

Certains déploiements exécutent également un agent de mémoire en arrière-plan qui examine chaque échange et enregistre des faits de sa propre initiative, sans que vous le demandiez. C'est à votre administrateur de décider si cela se produit.

## Consulter et modifier les souvenirs [#viewing-and-editing-memories]

Ouvrez **Mémoires** dans le panneau latéral pour voir tout ce qui est enregistré à votre sujet. Depuis cet endroit, vous pouvez :

- Filtrez la liste par clé ou par valeur, ou par agent lorsque vous avez des mémoires limitées à un agent (indiquées « Mémoire limitée à l'agent »).
- Cliquez sur **+** (**Create Memory**) pour ajouter une entrée vous-même. Les clés n'utilisent que des lettres minuscules et des underscores, et chaque clé ne peut exister qu'une seule fois.
- Modifier ou supprimer n'importe quelle entrée.

Lorsque votre administrateur définit une limite de taille, le panneau affiche la quantité que vous utilisez. Une fois le stockage plein, les nouvelles sauvegardes échouent avec le message « Memory Storage Full » jusqu'à ce que vous supprimiez des éléments. Les entrées individuelles ont également une limite de longueur.

## Désactiver la mémoire pour soi-même [#turning-memory-off-for-yourself]

Le bouton **Use memory** dans le panneau Memories, également disponible sous le nom **Reference saved memories** dans **Settings** > **Data & Privacy**, permet de contrôler si vos souvenirs enregistrés sont ajoutés à vos conversations. Lorsque vous le désactivez, LibreChat cesse de les ajouter et ne propose plus l'outil Memory ; vos entrées sont conservées et réapparaissent lorsque vous le réactivez.

Ce bouton bascule n'est affiché que lorsque votre administrateur autorise les utilisateurs à le désactiver. La mémoire peut également être limitée selon le rôle, de sorte que certains utilisateurs peuvent voir le panneau sans pouvoir créer ni modifier des entrées.

## Configuration [#setup]

La mémoire est désactivée tant qu'un administrateur n'ajoute pas une section `memory` dans `librechat.yaml`. L'agent de mémoire en arrière-plan est une option distincte, à activer explicitement, et qui nécessite son propre modèle. Consultez la [configuration de la mémoire](/docs/configuration/librechat_yaml/object_structure/memory) pour les limites, les clés autorisées, l'agent de mémoire et le dépannage.
