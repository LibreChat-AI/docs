Il compositore è la casella in fondo a ogni chat. Accanto al campo di testo si trovano un pulsante **+** per file, strumenti, skill e server MCP, un chip per ogni strumento attivato e i controlli per lo sforzo di ragionamento, la dettatura e l'invio.

Fai clic su **+** (gli screen reader lo annunciano come **Allega e strumenti**) per aprire la palette. Tutto ciò che contiene è ricercabile dal campo in alto, quindi digitare alcune lettere è di solito più veloce che scorrere l'elenco.

## Aggiungi file [#add-files]

Scegli **Dal computer locale** nella sezione **Allega**, trascina i file nell'area di composizione oppure incollali. LibreChat decide come ogni file raggiunge il modello (inviato direttamente al provider, estratto come testo o indicizzato per File Search) in base al tipo di file e all'endpoint, quindi devi solo scegliere da dove proviene il file. **Da SharePoint** compare accanto a questa opzione quando il tuo amministratore ha collegato SharePoint.

Alcune installazioni utilizzano il vecchio sistema di caricamento, in cui è l'utente a scegliere la destinazione: **Carica su Provider** (oppure **Carica immagine** per i provider che accettano solo immagini), **Carica come testo**, **Carica per File Search** e **Carica su Code Environment**. La prima opzione è visibile, mentre le altre si trovano dietro **Altre opzioni di caricamento**. Selezionare **Carica per File Search** o **Carica su Code Environment** attiva anche lo strumento corrispondente.

### Riutilizza un file caricato in precedenza [#reuse-a-file-you-uploaded-before]

**I tuoi file** nella palette elenca i file utilizzati più di recente (cinque per impostazione predefinita). Selezionane uno per allegarlo di nuovo senza caricarlo. Digitando nel campo di ricerca vengono cercati tutti i tuoi file per nome, mentre **Mostra tutti** apre una finestra di dialogo con ogni file, suddivisi in **Tutti**, **Immagini** e **Documenti**, con anteprime per immagini e PDF.

## Attiva strumenti, skill e server MCP [#turn-on-tools-skills-and-mcp-servers]

Sotto **Allega**, la palette raggruppa ciò che puoi aggiungere alla conversazione:

- **Strumenti**: strumenti integrati come **Ricerca web**, **Esegui codice**, **Ricerca nei file**, **Skills**, **Memoria** e **Artefatti**. Vedi solo quelli abilitati e a cui hai accesso.
- **Skills**: [skills](/docs/features/skills) da allegare al tuo prossimo messaggio.
- **MCP Servers**: i [server MCP](/docs/features/mcp) disponibili nella chat, ciascuno con il proprio stato di connessione.

Selezionare uno strumento o un server MCP lo attiva o disattiva, e la palette rimane aperta così da poterne modificare più di uno in una sola operazione. Ogni strumento attivo ottiene un chip nel composer; rimuovi il chip per disattivarlo. Alcuni chip hanno un menu proprio, ad esempio la modalità di generazione per **Artifacts**.

La selezione di una skill funziona in modo diverso: viene preparata per il tuo messaggio successivo (vedi [Contesto preparato](#staged-context)) invece di diventare un chip.

Se un server MCP non è ancora connesso, selezionarlo avvia la connessione, incluso l'accesso OAuth quando il server lo richiede. I server che necessitano delle tue credenziali le chiedono per primo e, successivamente, mantengono un pulsante **Configure** sulla riga così da poterle modificare.

Con un agente selezionato, le sezioni **Tools** e **MCP Servers** scompaiono, perché è la configurazione dell'agente stesso a decidere quali strumenti utilizza. Lo stesso vale per gli Assistants.

### Mostra tutti e preferiti [#show-all-and-favorites]

Ogni sezione mostra fino a cinque righe. **Mostra tutto** nell'intestazione **Skills**, **MCP Servers** o **I tuoi file** apre l'elenco completo con ricerca e filtri; skills e server possono essere limitati a **Creati da te** o **Preferiti**.

Per aggiungere una riga ai preferiti, evidenziala e premi <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd> su macOS). I preferiti vengono spostati in cima alla palette e salvati nel tuo account.

Anche il tuo amministratore può fissare gli strumenti integrati. Uno strumento fissato mantiene il suo chip nell'area di composizione anche quando è disattivato, così è disponibile con un solo clic. Rimuovere il chip di uno strumento fissato disattivato lo rimuove anche dai fissati per te.

## Contesto a fasi [#staged-context]

Qualsiasi cosa allegata al tuo prossimo messaggio appare sopra il campo di testo prima dell'invio:

- File, con avanzamento del caricamento e anteprima dell'immagine.
- Testo lungo incollato. Quando [Carica come testo](/docs/features/upload_as_text#pasting-long-text) è disponibile, incollare più di 2.500 caratteri allega il testo come `pasted-text.txt` invece di riempire la casella. Selezionalo per modificare il testo in una finestra di dialogo più grande, oppure scegli **Sposta di nuovo nel messaggio** per riportarlo nel campo di testo. Puoi disattivare questa opzione con **Incolla testo lungo come file** in **Impostazioni > Chat**.
- Estratti citati dai messaggi precedenti con **Aggiungi alla chat** (vedi [Citare estratti](/docs/features/message_actions#quote-excerpts)).
- Competenze selezionate dalla tavolozza o con `$`.

Rimuovi tutto ciò che non desideri più prima dell'invio; tutto ciò che resta viene inviato insieme al messaggio. Puoi inviare i file anche senza digitare alcun testo.

## Ragionamento [#thinking]

Sui modelli con un'impostazione di ragionamento, il controllo **Thinking** apre un cursore che va da **Faster** a **Smarter**, oltre a eventuali modalità separate offerte dal provider, come **Auto**. Modifica lo stesso valore del pannello Parameters. Se il modello non dispone di un'impostazione di ragionamento, oppure se l'amministratore ha nascosto i parametri, il controllo non viene mostrato.

## Metti in coda e guida mentre una risposta è in streaming [#queue-and-steer-while-a-response-streams]

Puoi continuare a digitare mentre una risposta è in fase di streaming. Ciò che accade all'invio in quel momento dipende dall'impostazione predefinita che hai scelto in **Durante la generazione, Invio** in **Impostazioni > Chat** (vedi [Impostazioni personali](/docs/features/settings#chat)):

- Coda: il messaggio attende e viene inviato al termine della risposta.
- Steer: la risposta in corso riceve il tuo messaggio al successivo punto sicuro, senza interrompere gli strumenti o il ragionamento.
- Interrompi: gli strumenti attivi e il ragionamento vengono annullati, l'output completato viene conservato e la risposta prosegue con il tuo messaggio.

Per come funziona lo steering con gli agenti e quando è disponibile, vedi [Steering e messaggi in coda](/docs/features/agents#steering-and-queued-messages).

I messaggi in coda attendono nell'elenco **Messaggi in coda** sopra il campo di composizione. Per ciascuno puoi **Invia ora**, **Rimuovi messaggio**, oppure aprire **Altre opzioni** per **Modifica messaggio** (lo riporta nel campo di testo), **Avvia in una nuova chat**, o **Disabilita coda** in modo che non venga inviato automaticamente. Trascina i messaggi per riordinarli, oppure seleziona un messaggio e usa i tasti freccia su e giù.

## Scorciatoie da tastiera [#keyboard-shortcuts]

### Nel campo di testo [#in-the-text-field]

La tabella presuppone che l'opzione **Premi Invio per inviare i messaggi** sia attiva, che è l'impostazione predefinita. Con l'opzione disattivata, <kbd>Invio</kbd> aggiunge una nuova riga e <kbd>Ctrl</kbd>+<kbd>Invio</kbd> invia il messaggio.

| Tasti | Azione |
|---|---|
| <kbd>Enter</kbd> | Invia. Mentre una risposta viene trasmessa in streaming, esegue la scelta **While generating, Enter will**. |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Nuova riga. |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) | Nuova riga. Mentre una risposta viene trasmessa in streaming, esegue l'altra azione: invia subito se <kbd>Enter</kbd> mette in coda, mette in coda se <kbd>Enter</kbd> guida o interrompe. |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> (<kbd>Option</kbd>+<kbd>Enter</kbd>) | Mentre una risposta viene trasmessa in streaming: interrompe con il tuo messaggio, quando l'esecuzione lo consente. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd>) | Uguale a <kbd>Alt</kbd>+<kbd>Enter</kbd>. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>) | Interrompe la risposta. |
| `/` | Inserisce un prompt salvato. |
| `@` | Cambia modello, preset o agente. |
| `+` | Aggiunge un altro modello o preset per una risposta affiancata. |
| `$` | Seleziona una skill per il messaggio successivo. |

Puoi riassegnare o disattivare le scorciatoie da tastiera dal menu dell'account; vedi [Scorciatoie da tastiera](/docs/features/settings#keyboard-shortcuts).

### Nella palette [#in-the-palette]

| Tasti | Azione |
|---|---|
| Digita | Cerca strumenti, competenze, server, opzioni di caricamento e file. |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Spostati tra le righe. |
| <kbd>Enter</kbd> | Seleziona la riga evidenziata. |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd>) | Aggiungi o rimuovi dai preferiti la riga evidenziata. |
| <kbd>Backspace</kbd> su una ricerca vuota, oppure <kbd>Escape</kbd> | Chiudi la palette. |

## Setup [#setup]

Il compositore non richiede alcuna configurazione. Gli amministratori controllano ciò che vi appare: l'uploader precedente con [`fileConfig.legacyFileUploadUX`](/docs/configuration/librechat_yaml/object_structure/file_config#legacyfileuploadux), il numero di file recenti con [`interface.composerRecentFiles`](/docs/configuration/librechat_yaml/object_structure/interface#composerrecentfiles), gli strumenti fissati con [`interface.defaultPinnedTools`](/docs/configuration/librechat_yaml/object_structure/interface#defaultpinnedtools) e SharePoint tramite [integrazione SharePoint](/docs/configuration/sharepoint). Una [model spec](/docs/configuration/librechat_yaml/object_structure/model_specs#hidebadgerow) con `hideBadgeRow` nasconde le sezioni degli strumenti per quella spec.
