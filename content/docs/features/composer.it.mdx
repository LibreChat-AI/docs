Il compositore di messaggi è la casella situata nella parte inferiore di ogni chat. Oltre al campo di testo, contiene un pulsante **+** che apre tutto ciò che è possibile aggiungere a un messaggio (file, strumenti, competenze, server MCP e file caricati in precedenza), i chip per gli strumenti attualmente attivi e i controlli per il ragionamento, la dettatura e l'invio.

## Cosa c'è nel composer [#whats-on-the-composer]

| Elemento | Cosa fa |
|---|---|
| **+** (**Allega e strumenti**) | Apre la tavolozza: opzioni di caricamento, strumenti, competenze, server MCP e i tuoi file recenti, tutto ricercabile da un unico campo. |
| Chip degli strumenti | Un chip per ogni strumento o server MCP attivo, accanto al pulsante **+**. Rimuovi un chip per disattivare quello strumento. |
| Contesto in sospeso | File, citazioni e competenze allegati al tuo prossimo messaggio, mostrati sopra il campo di testo. |
| **Ragionamento** | Sforzo di ragionamento per i modelli che lo supportano. |
| Utilizzo del contesto | Quanto della finestra di contesto del modello utilizza la conversazione, quando l'utilizzo dei token è disponibile. |
| **Usa microfono** | Detta il tuo messaggio con la sintesi vocale, quando la funzione è abilitata. |
| Invia / Interrompi | Invia il messaggio o interrompe la risposta in streaming. |

To see which keys apply right now, such as `/ for prompts`, `@ for models` or `Enter to send`, turn on **Show composer tips** in **Settings > General**. A one-line tip then appears under the text field. It is off by default.

## Aggiungi file [#add-files]

Fai clic su **+** e scegli un'opzione nella sezione **Attach**. Puoi anche trascinare i file nel composer o incollarli.

Per impostazione predefinita, LibreChat utilizza l'uploader unificato: selezioni solo una sorgente e il sistema decide come ogni file raggiunge il modello (caricamento nativo del provider, estrazione del testo o uno strumento come File Search) in base al tipo di file e all'endpoint.

| Opzione | Quando appare |
|---|---|
| **From Local Computer** | Sempre, con l'uploader predefinito. |
| **From SharePoint** | Quando il [SharePoint file picker](/docs/configuration/sharepoint) è abilitato. |

Se un amministratore imposta [`fileConfig.legacyFileUploadUX: true`](/docs/configuration/librechat_yaml/object_structure/file_config#legacyfileuploadux), sarai tu a scegliere la destinazione. La sezione **Attach** mostrerà quindi l'opzione principale per prima e raggrupperà le altre sotto **More upload options**:

| Opzione | Quando appare |
|---|---|
| **Upload to Provider** | Il provider accetta documenti direttamente (ad esempio OpenAI, Anthropic, Google, Bedrock, OpenRouter e endpoint personalizzati, o Azure OpenAI con le Responses API attive). |
| **Upload Image** | Mostrato al posto di **Upload to Provider** quando il provider accetta solo immagini. |
| **Upload as Text** | La [context capability](/docs/features/upload_as_text) è abilitata. |
| **Upload for File Search** | File Search è abilitato e consentito per l'agente corrente. Selezionarlo attiva anche File Search. |
| **Upload to Code Environment** | L'esecuzione di codice è abilitata e consentita per l'agente corrente. Selezionarlo attiva anche **Run Code**. |
| **Attach Files** | Endpoint Assistants, che gestiscono i file con la configurazione propria dell'assistente. |

Con SharePoint abilitato in questa modalità, ogni opzione ha anche una versione SharePoint, etichettata ad esempio **Upload to Provider (From SharePoint)**.

### Riutilizza un file caricato in precedenza [#reuse-a-file-you-uploaded-before]

La sezione **Your files** della palette elenca i file utilizzati più di recente. Selezionane uno per allegarlo di nuovo senza doverlo caricare. Digitando nel campo di ricerca, potrai cercare tutti i tuoi file per nome.

Scegli **Show all** nella sezione per sfogliare ogni file in una finestra di dialogo, con le viste **All**, **Images** e **Documents**, un campo di ricerca e un'anteprima per immagini e PDF.

La tavolozza mostra fino a cinque file recenti. Gli amministratori possono ridurre tale numero, o nascondere l'elenco con `0`, utilizzando [`interface.composerRecentFiles`](/docs/configuration/librechat_yaml/object_structure/interface#composerrecentfiles).

## Attiva strumenti, skill e server MCP [#turn-on-tools-skills-and-mcp-servers]

La tavolozza elenca tutto ciò che puoi attivare per la conversazione corrente, raggruppato in sezioni:

- **Tools**: strumenti integrati come **Web Search**, **Run Code**, **File Search**, **Skills**, **Memory** e **Artifacts**, ognuno dei quali viene mostrato solo quando è abilitato e se ne ha accesso.
- **Skills**: [skills](/docs/features/skills) individuali che puoi allegare al tuo prossimo messaggio.
- **MCP Servers**: i [MCP servers](/docs/features/mcp) disponibili nella chat.

Seleziona uno strumento o un server MCP per attivarlo o disattivarlo. La tavolozza rimane aperta, così puoi attivarne diversi in una sola volta. Ogni strumento attivo appare come una chip sul composer; rimuovi la chip per disattivarlo. Alcune chip includono un menu di modalità, ad esempio la modalità di generazione **Artifacts**.

Selezionare una skill la prepara per il tuo prossimo messaggio: apparirà nel [staged context](#staged-context) invece che come chip.

Le righe dei server MCP mostrano lo stato di connessione di ciascun server. Selezionando un server non connesso si avvia la sua connessione (incluso un accesso OAuth, quando il server ne richiede uno) oppure si apre prima la sua configurazione se necessita delle tue credenziali. Una volta connessi, i server che richiedono credenziali utente presentano anche un controllo **Configure** sulla riga, e **Web Search** ne ha uno per le sue chiavi API.

<Callout type="info" title="Gli agenti portano i propri strumenti">
  Con un agente selezionato, le sezioni **Tools** e **MCP Servers** vengono nascoste, poiché la configurazione stessa dell'agente determina quali strumenti utilizzare. Su altri endpoint, una [model spec](/docs/configuration/librechat_yaml/object_structure/model_specs#hidebadgerow) con `hideBadgeRow: true` nasconde le sezioni **Tools**, **Skills** e **MCP Servers**. **Attach** e **Your files** rimangono disponibili in ogni caso.
</Callout>

### Mostra tutto [#show-all]

La tavolozza mostra alcune righe per sezione. Scegli **Show all** sull'intestazione **Skills**, **MCP Servers** o **Your files** per aprire una finestra di dialogo con l'elenco completo, un campo di ricerca e dei filtri. Skills e MCP servers hanno tre viste: **All**, **Made by you** e **Favorites**.

### Preferiti e strumenti fissati [#favorites-and-pinned-tools]

Aggiungi una stella a una riga per inserirla nei **Preferiti**, che si trovano nella parte superiore della tavolozza. Con una riga evidenziata, premi <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd> su macOS) per aggiungere o rimuovere la stella. I Preferiti vengono salvati nel tuo account.

Gli amministratori possono fissare gli strumenti integrati con [`interface.defaultPinnedTools`](/docs/configuration/librechat_yaml/object_structure/interface#defaultpinnedtools). Uno strumento fissato mantiene la sua chip sul composer anche quando è disattivato, così da poterlo attivare con un solo clic. Rimuovere la chip di uno strumento fissato che è disattivato lo rimuove dai fissati.

## Contesto a fasi [#staged-context]

Tutto ciò che viene allegato al tuo prossimo messaggio appare sopra il campo di testo prima che tu lo invii:

- **File**, con avanzamento del caricamento e un'anteprima per le immagini. Anche i testi lunghi incollati possono essere salvati qui come file, che puoi modificare o spostare nuovamente nel messaggio.
- **Citazioni** selezionate da messaggi precedenti.
- **Skills** che hai selezionato dalla tavolozza o con il comando `$`.

Rimuovi qualsiasi elemento con il relativo pulsante di rimozione. Tutto ciò che è in sospeso verrà inviato con il tuo prossimo messaggio.

## Pensiero e impegno [#thinking-and-effort]

Per i modelli con un'impostazione di ragionamento, il controllo **Thinking** apre uno slider che va da **Faster** a **Smarter**, oltre alle modalità separate del provider come **Auto** o disattivato. Modifica lo stesso parametro del pannello Parameters, quindi viene nascosto quando il modello non dispone di un'impostazione di ragionamento o quando la distribuzione disabilita i parametri con `interface.parameters`.

## Metti in coda e guida mentre una risposta è in streaming [#queue-and-steer-while-a-response-streams]

Puoi continuare a scrivere mentre una risposta è in fase di streaming. A seconda dell'endpoint e delle tue impostazioni, premere <kbd>Enter</kbd> mette in coda il messaggio da inviare dopo la risposta, oppure guida la risposta corrente di un agente. Il suggerimento nel compositore indica l'azione che <kbd>Enter</kbd> esegue in quel momento.

I messaggi in coda appaiono in una barra **Queued messages** sopra il compositore, dove puoi:

- **Modifica messaggio** per riportarlo nel campo di testo.
- **Rimuovi messaggio** per toglierlo dalla coda.
- **Invia ora** per inviarlo immediatamente invece di attendere.
- Riordina i messaggi trascinandoli, oppure selezionandone uno e utilizzando i tasti freccia su e giù.

Per informazioni su come funziona lo steering e quando è disponibile, consulta [Steering and Queued Messages](/docs/features/agents#steering-and-queued-messages).

## Scorciatoie da tastiera [#keyboard-shortcuts]

### Nel campo di testo [#in-the-text-field]

| Tasti | Azione |
|---|---|
| <kbd>Enter</kbd> | Invia il messaggio (accoda o guida mentre una risposta è in streaming). |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Nuova riga. |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) | Mentre una risposta è in streaming: l'azione alternativa, **invia ora** quando <kbd>Enter</kbd> accoda, o **accoda** quando <kbd>Enter</kbd> guida. |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> (<kbd>Option</kbd>+<kbd>Enter</kbd>) | Mentre un agente risponde: interrompi e invia, quando disponibile. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>) | Interrompi la risposta. |
| `/` | Inserisci un prompt salvato. |
| `@` | Passa a un altro modello, preset o agente. |
| `+` | Aggiungi un modello o un preset per una risposta aggiuntiva. |
| `$` | Scegli una skill per il messaggio successivo. |

Se hai disattivato **Premi Invio per inviare messaggi**, <kbd>Ctrl</kbd>+<kbd>Invio</kbd> (<kbd>Cmd</kbd>+<kbd>Invio</kbd>) invia il messaggio e <kbd>Invio</kbd> aggiunge una nuova riga.

### Nella palette [#in-the-palette]

| Tasti | Azione |
|---|---|
| Digitare | Cerca strumenti, competenze, server, opzioni di caricamento e file. |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Spostarsi tra le righe. |
| <kbd>Enter</kbd> | Selezionare la riga evidenziata. |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd>) | Aggiungere la riga evidenziata ai Preferiti, o rimuoverla. |
| <kbd>Backspace</kbd> su una ricerca vuota | Chiudere la palette. |
| <kbd>Escape</kbd> | Chiudere la palette. |
