Otwórz menu konta i wybierz **Ustawienia**. Okno dialogowe zawiera karty **Ogólne**, **Czat**, **Mowa**, **Dane i prywatność** oraz **Konto**, a także **Langfuse** i **Informacje** w wdrożeniach, które je oferują. Jeśli w przybliżeniu wiesz, czego szukasz, wpisz to w polu **Szukaj ustawień**: pole dopasowuje etykiety i powiązane słowa (np. „dark”, „rtl”, „paste”) i przenosi do odpowiedniej karty i sekcji.

Większość preferencji jest zapisywana w bieżącej przeglądarce, a nie na Twoim koncie. Zmiana ustawienia na laptopie nie przenosi się na telefon. Wyjątki są opisane poniżej.

## Ogólne [#general]

| Ajustement | Co robi | Domyślnie |
|---|---|---|
| Motyw | **System**, **Jasny**, **Ciemny** lub jasny albo ciemny motyw wysokiego kontrastu. | System |
| Język | Język interfejsu. | Język przeglądarki |
| Rozmiar czcionki wiadomości | Rozmiar tekstu wiadomości, od **Bardzo mały** do **Bardzo duży**. | Średni |
| Skala interfejsu | Skaluje cały interfejs w zakresie od 50% do 150%, niezależnie od powiększenia przeglądarki. | 100% |
| Kierunek czatu | **Auto**, od lewej do prawej lub od prawej do lewej. | Auto |
| Format zegara | System, 12-godzinny lub 24-godzinny format godzin w wiadomościach, harmonogramach i datach. | System |
| Tydzień zaczyna się od | System, niedziela lub poniedziałek. Zmienia kolejność dni tygodnia w [Zaplanowanych czatach](/docs/features/scheduled_chats), a nie moment uruchomienia harmonogramu. | System |
| Maksymalizuj przestrzeń czatu | Poszerza kolumnę rozmowy. | Wyłączone |
| Wyśrodkuj pole czatu na ekranie powitalnym | Umieszcza pole wiadomości na środku nowego czatu. | Włączone |
| Pokaż Lię na ekranie powitalnym | Mała dekoracyjna pikselowa maskotka wokół pola wiadomości. Wyświetlana tylko wtedy, gdy wdrożenie na to pozwala. | Wyłączone |
| Przycisk przewijania do końca | Przycisk, który przenosi do najnowszej wiadomości. | Włączone |
| Pokaż czat obok paska bocznego na urządzeniach mobilnych | Zachowuje wąski pasek rozmowy widoczny obok [szuflady mobilnej](/docs/features/navigation#mobile-drawer); dotknij paska, aby zamknąć szufladę. | Wyłączone |
| Wyświetl tytuł czatu w karcie | Używa tytułu rozmowy jako tytułu karty przeglądarki. | Włączone |
| Nie wyłączaj ekranu podczas generowania odpowiedzi | Prosi przeglądarkę, aby nie przygasała ani nie blokowała ekranu, gdy odpowiedź jest strumieniowana. | Włączone |

Administratorzy widzą tutaj również link **Admin Panel**, jeśli wdrożenie go posiada.

### Powiadomienia [#notifications]

Te ustawienia określają, w jaki sposób dowiadujesz się o odpowiedziach, które zakończyły się, gdy jesteś w innym czacie lub na innej karcie:

- **Pokaż liczbę nieprzeczytanych wiadomości w tytule karty** wyświetla liczbę czatów z nieprzeczytanymi odpowiedziami w tytule karty i ikonie. Domyślnie włączone.
- **Powiadom mnie, gdy nadejdzie odpowiedź** wyświetla powiadomienie na pulpicie. Domyślnie wyłączone. Przeglądarka poprosi o zgodę przy pierwszym włączeniu tej opcji, a podczas przeglądania LibreChat żadne powiadomienie nie będzie wyświetlane.
- **Odtwarzaj dźwięk dla nowych odpowiedzi** odtwarza krótki sygnał dźwiękowy. Domyślnie wyłączone. Przeglądarki blokują dźwięk, dopóki nie klikniesz gdzieś na stronie, więc pierwszy sygnał po otwarciu karty może pozostać niesłyszalny.

Przełączniki działają dla każdego urządzenia osobno, natomiast stan nieprzeczytanych odpowiedzi jest zapisywany na Twoim koncie (zobacz [Nieprzeczytane odpowiedzi](/docs/features/navigation#unread-replies)). Jeśli któregoś z tych przełączników brakuje, oznacza to, że administrator wyłączył je za pomocą [`interface.replyNotifications`](/docs/configuration/librechat_yaml/object_structure/interface#replynotifications).

| Ustawienie | Co robi | Domyślnie |
|---|---|---|

| Podczas generowania Enter będzie | Co wysłanie robi, gdy odpowiedź jest nadal strumieniowana: **Steer**, **Interrupt** lub **Queue**. Zobacz [Composer](/docs/features/composer). | Steer |
| Zapisuj szkice lokalnie | Zachowuje niewysłany tekst i załączniki na tym urządzeniu, aż wiadomość zostanie wysłana. | Włączone |
| Zmieniaj rozmiar obrazów przed przesłaniem | Zmniejsza duże obrazy JPEG, PNG i WebP w przeglądarce przed przesłaniem. | Włączone |
| Wklejaj długi tekst jako plik | Dołącza bardzo długie wklejone fragmenty jako plik tekstowy zamiast wypełniać pole wiadomości. Zobacz [Upload as Text](/docs/features/upload_as_text). | Włączone |
| Zapisuj stan odznak | Nowe czaty zachowują odznaki narzędzi z ostatniego czatu zamiast je resetować. | Wyłączone |

| Renderuj wiadomości użytkownika jako markdown | Formatuje Twoje wiadomości jako Markdown. | Włączone |
| Zwijaj długie wiadomości użytkownika | Długie wysłane wiadomości są pokazywane jako podgląd z przyciskiem **Show more**. Pełny tekst nadal znajduje się na stronie, aby można go było kopiować i wyszukiwać. | Włączone |

| Płynne strumieniowanie tekstu | Płynnie wyświetla nowe słowa podczas strumieniowania odpowiedzi. Zobacz [Smooth Streaming](/docs/features/smooth_streaming). | Włączone |
| Kopiuj wiadomości jako tekst sformatowany | Kopiowanie wiadomości umieszcza również sformatowaną wersję w schowku, do wklejenia do Worda, Outlooka lub Teams. | Wyłączone |
| Automatycznie rozwijaj szczegóły narzędzi | Domyślnie otwiera szczegóły wywołań narzędzi. | Wyłączone |
| Przełączaj na historię czatów przy nowym czacie | Rozpoczęcie nowego czatu, gdy otwarte są Prompty, Pamięci lub inny panel, przełącza pasek boczny z powrotem na Twoje czaty. | Włączone |
| Automatycznie przewijaj do najnowszej wiadomości po otwarciu czatu | Otwiera czat na jego najnowszej wiadomości. Wyłącz, aby zachować swoje miejsce po powrocie. | Włączone |
| Włącz przełączanie Endpointów w trakcie rozmowy | Pozwala zmienić model lub endpoint w ramach jednej rozmowy. | Włączone |
| Czat tymczasowy domyślnie | Nowe czaty rozpoczynają się jako [czaty tymczasowe](/docs/features/temporary_chat). | Wyłączone |

| Zaawansowany edytor promptów | Włącza wersje i etykiety produkcyjne dla promptów. | Wyłączone |
| Zawsze ustawiaj nowe wersje promptów jako produkcyjne | Oznacza każdą nową wersję promptu jako aktualnie używaną. | Włączone |

## Mowa [#speech]

Włącz lub wyłącz **Zamianę mowy na tekst** oraz **Zamianę tekstu na mowę**, wybierz silnik, język i głos, ustaw szybkość odtwarzania oraz zdecyduj, czy odpowiedzi mają być odtwarzane automatycznie. Dostępne silniki zależą od tego, co zostało skonfigurowane we wdrożeniu; zobacz [Zamiana mowy na tekst i tekstu na mowę](/docs/configuration/stt_tts).

## Dane i prywatność [#data--privacy]

- **Pamięć**: **Odwołuj się do zapisanych wspomnień** pozwala asystentowi korzystać z Twoich [wspomnień](/docs/features/memory). Są zapisane na Twoim koncie, więc obowiązują na każdym urządzeniu.
- **Wykonywanie kodu**: **Domyślna stanowa przestrzeń robocza** oraz **Środowiska kodu**, gdy wdrożenie udostępnia stanowe sesje kodu.
- **Twoje dane**: **Importuj rozmowy**, **Udostępnione czaty** (zarządzaj swoimi [linkami do udostępniania](/docs/features/shareable_links)), **Zarządzaj plikami**, **Archiwizuj wszystkie czaty** oraz **Zezwól na analitykę**, jeśli wdrożenie zbiera dane analityczne. **Archiwizuj wszystkie czaty** przenosi każdy aktywny czat do [Zarchiwizowanych czatów](/docs/features/navigation#archived-conversations) bez usuwania czegokolwiek.
- **Klucze API**: **Klucze API dostawców** dla endpointów, które wymagają Twojego własnego klucza, **Klucze API agentów** dla Agents API oraz **Unieważnij wszystkie klucze API dostawców**.
- **Strefa niebezpieczna**: **Usuń pamięć podręczną** czyści pamięć podręczną audio zamiany tekstu na mowę, zapisaną w tej przeglądarce. **Usuń wszystkie czaty** trwale usuwa Twoje rozmowy.

## Konto [#account]

**Awatar** oraz, dla logowania e-mailem tam, gdzie jest to dozwolone, **Adres e-mail**. W sekcji **Bezpieczeństwo**: **Uwierzytelnianie dwuskładnikowe**, **Kody zapasowe** po włączeniu uwierzytelniania dwuskładnikowego oraz **Klucze dostępu** (passkeys), jeśli wdrożenie je obsługuje. **Konto pull request** łączy GitHub lub inny host git z [pull requestami](/docs/features/pull_requests). **Saldo tokenów** i **Automatyczne doładowanie** pojawiają się, gdy wdrożenie śledzi salda, a **Usuń konto**, gdy pozwala użytkownikom usuwać własne konta.

## Skróty klawiszowe [#keyboard-shortcuts]

Otwórz menu konta i wybierz **Pomoc**, a następnie **Skróty klawiszowe** (lub naciśnij <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>/</kbd>). Kliknij wiersz, aby zarejestrować nową kombinację; musi ona zawierać <kbd>Cmd</kbd>, <kbd>Ctrl</kbd> lub <kbd>Alt</kbd>, a LibreChat ostrzeże Cię, jeśli inna akcja już jej używa. **Przywróć wszystkie domyślne** cofa wprowadzone zmiany. Wiersze w sekcji **Otwierane panele** (agenci, prompty, wspomnienia, parametry, pliki, zakładki, ustawienia MCP) nie mają przypisanych klawiszy, dopóki sam ich nie przypiszesz.

Przełącznik **Skróty klawiaturowe** u góry wyłącza wszystkie skróty i ukrywa podpowiedzi w interfejsie. Twoje własne klawisze są zachowywane na wypadek, gdyby ponownie go włączyć. Zarówno przełącznik, jak i Twoje przypisania są zapisywane w tej przeglądarce.
