Ketika agen bekerja pada repositori di dalam workspace kode yang terlampir, LibreChat menemukan pull request untuk branch tempat workspace berada dan menampilkannya di samping chat. Anda dapat melihat apakah pull request tersebut siap untuk di-merge, apakah pemeriksaan (checks) berhasil, dan membukanya tanpa meninggalkan percakapan. Fitur ini mendukung GitHub, GitLab (yang disebut merge request), dan Bitbucket Cloud, dengan satu penyedia untuk setiap deployment.

Hanya obrolan yang menjalankan kode di workspace terlampir yang dapat memiliki pull request. Obrolan biasa, atau workspace yang belum melaporkan branch, tidak menampilkan apa pun.

## Di header chat [#in-the-chat-header]

Pada layar lebar, sebuah chip di sebelah kiri header menampilkan ikon pull request, titik CI kecil di sudut ikonnya, dan judul pull request. Arahkan kursor atau fokus ke chip untuk membuka kartu berisi detailnya. Kartu tetap terbuka selama kursor atau fokus keyboard Anda berada di dalamnya.

Pada layar kecil tidak ada chip. Buka menu tiga titik di header, lalu pilih entri `PR #number` (`MR !number` di GitLab) untuk menampilkan kartu yang sama dalam dialog.

Header ini memperbarui dirinya sendiri: ia memeriksa ulang sekitar setiap 20 detik selama pemeriksaan sedang berjalan atau penyedia masih menentukan apakah branch dapat digabung, dan sekitar setiap 60 detik di luar kondisi tersebut. Pemeriksaan berhenti setelah pull request digabung atau ditutup dan tidak ada lagi yang sedang berjalan.

## Di sidebar [#in-the-sidebar]

Percakapan yang memiliki pull request mendapatkan ikon dan titik CI yang sama di akhir barisnya. Baris tetap menampilkan judul percakapan itu sendiri. Arahkan kursor ke baris, atau fokus atau klik tanda tersebut, untuk membuka kartu di sebelahnya; mengklik tanda tersebut tidak membuka percakapan.

Sidebar tidak melakukan polling. Sebuah baris sesegar terakhir kali daftar dimuat, dan baris tersebut akan dimuat ulang ketika Anda kembali ke jendela dan datanya sudah lebih dari satu menit. Jika penyegaran gagal untuk pull request yang sudah pernah ditemukan, tanda tetap ada dan kartu menampilkan "Couldn't refresh the pull request" dengan tombol **Retry**. Percakapan yang pull request-nya belum pernah ditemukan tidak menampilkan tanda apa pun, bahkan ketika pencarian tersebut gagal.

## Membaca kartu [#reading-the-card]

Kartu menampilkan `PR #number` (`MR !number` di GitLab), baris yang ditambahkan dalam warna hijau dan dihapus dalam warna merah, tautan **Open in GitHub**, **Open in GitLab**, atau **Open in Bitbucket**, judul, serta dua lencana:

- Status: Open, Conflicts, Draft, Merged, atau Closed. Conflicts menggantikan Open ketika cabang tidak dapat digabungkan secara bersih.
- Pemeriksaan: Lulus, Gagal, Sedang berjalan, atau Tidak ada. Di GitLab, ini adalah pipeline utama (head pipeline), dan hanya jika pipeline tersebut dijalankan untuk commit saat ini. Di Bitbucket, ini adalah status commit.

Warna ikon dan titik CI merangkum informasi yang sama secara sekilas:

| Pull request                         | Ikon    | Titik CI        |
| ------------------------------------ | ------- | --------------- |
| Terbuka, dapat digabungkan           | Hijau   | Dari pemeriksaan |
| Terbuka, status dapat digabungkan belum diketahui | Netral | Dari pemeriksaan |
| Terbuka, terdapat konflik penggabungan | Merah | Dari pemeriksaan |
| Draf                                 | Netral  | Dari pemeriksaan |
| Digabungkan                          | Ungu    | Tidak ada       |
| Ditutup                              | Netral  | Tidak ada       |

Titik berwarna hijau menandakan pemeriksaan yang lolos, merah untuk pemeriksaan yang gagal, dan kuning oranye untuk pemeriksaan yang sedang berjalan. Tidak ada titik yang ditampilkan ketika repositori tidak melaporkan pemeriksaan apa pun. Pemeriksaan yang gagal lebih diutamakan daripada pemeriksaan yang masih berjalan.

## Pull request mana yang Anda lihat [#which-pull-request-you-see]

Workspace melaporkan repositori, branch, dan commit tempat chat terakhir dijalankan, dan LibreChat mencari pull request dari branch tersebut:

- Jika output perintah chat itu sendiri mencetak tautan ke pull request dalam repositori yang sama (misalnya URL yang dicetak oleh `gh pr create`), pull request tersebut akan digunakan, selama berasal dari branch chat.
- Selain itu, pull request yang masih terbuka untuk branch tersebut lebih diutamakan daripada yang sudah ditutup, sehingga pull request lama yang sudah ditutup pada nama branch yang digunakan kembali tidak akan menyembunyikan pull request yang sedang berlaku.
- Sebuah pull request hanya dihitung jika berisi commit tempat chat terakhir dijalankan. Menghapus sebuah branch dan menggunakan kembali namanya tidak akan memulihkan pull request yang lama.
- Cabang baru yang belum memiliki commit tidak cocok dengan apa pun.

Repositori yang tidak diizinkan untuk diakses oleh server berperilaku sama persis dengan repositori tanpa pull request: tidak ada tanda, dan tidak ada error.

## Hubungkan akun Anda sendiri [#connect-your-own-account]

Jika admin Anda telah mengaturnya, Anda dapat mencari pull request dengan akun GitHub, GitLab, atau Bitbucket Anda sendiri. Buka **Settings**, lalu masuk ke **Account**, dan di bawah **Connected accounts** klik **Connect** di samping **Pull request account**. Jendela masuk akan terbuka di penyedia layanan; setujui, dan baris tersebut akan menampilkan **Connected**. Jika jendela tidak terbuka, izinkan pop-up untuk LibreChat dan coba lagi.

Setelah terhubung, pencarian menggunakan akun Anda, sehingga Anda dapat melihat pull request di repositori mana pun yang dapat Anda baca, dengan batas laju (rate limit) milik Anda sendiri. **Disconnect** menghapus koneksi dan Anda dapat menghubungkannya kembali kapan saja. Jika server tidak dapat menyegarkan koneksi Anda (misalnya, penyedia sedang tidak tersedia), pull request Anda akan ditampilkan sebagai tidak tersedia, bukan diam-diam beralih ke token server. Jika Anda mencabut aplikasi di penyedia, LibreChat akan menghapus koneksi tersebut dan Anda kembali ke status belum terhubung.

Jika baris menunjukkan **Not in use**, admin Anda telah menonaktifkan koneksi akun dan pencarian tidak lagi menggunakan akun Anda. Klik **Disconnect** untuk menghapus koneksi yang tersimpan.

## Pengaturan [#setup]

Fitur ini aktif secara default, tetapi tetap tersembunyi hingga admin memberikan token kepada LibreChat dan daftar repositori yang boleh dicari, atau menyiapkan aplikasi sehingga pengguna dapat menghubungkan akun mereka sendiri. Fitur ini juga memerlukan ruang kerja kode yang terlampir dan melaporkan cabang git-nya. Lihat [Konfigurasi Pull Requests](/docs/configuration/pull_requests).
