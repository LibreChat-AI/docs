启用平滑流式传输后,响应中的每个新词在到达时都会淡入显示,而不是突然出现在屏幕上,这使得快速流式输出更易于跟读。该效果仅作用于正在生成的最新响应,包括你已展开的推理文本。

默认情况下已开启。要关闭它，请打开 **设置** > **聊天** > **消息**，然后关闭 **平滑流式文本（逐字淡入）**。该设置保存在您的浏览器中。

## 变更内容与不变内容 [#what-it-changes-and-what-it-does-not]

淡入效果仅为视觉效果。令牌的到达速度不变,无论是否开启淡入,响应文本和保存的消息都完全相同。淡入开启时,流末尾的方块光标会被隐藏,因为淡入效果本身已表明文本仍在持续输出。

代码块、数学公式、Artifacts、引用以及 MCP UI 内容不会逐字淡入。已经显示在屏幕上的文本,在流式连接重新建立或切换对话时,也不会再次播放动画。

当智能体的运行被划分为多个活动阶段时,新生成的阶段摘要会将其上方的活动折叠进对应的收起分组中,并附带一段简短的过渡提示。之后加载的历史记录会直接显示这些已经折叠好的分组。

如果您的设备请求减少动态效果(即 `prefers-reduced-motion` 设置),无论开关如何设置,LibreChat 都会跳过所有这些动画。

## 已用时间 [#elapsed-time]

While a response is generating, a timer under it shows how long it has been running, in seconds and then minutes. It counts from when you sent the message, including if you navigate away and back in the same session. After a full page reload during generation it restarts from when the response reappears. The timer shows only on the latest response while it is generating, is not saved, and stays visible whether Smooth Streaming is on or off.

## 设置 [#setup]

平滑流式输出无需任何配置,每位用户可在各自的设置中自行控制。活动阶段摘要由管理员开启;请参阅[Agent Activity Groups](/docs/configuration/librechat_yaml/object_structure/shared_endpoint_settings#agent-activity-groups)。
