### Variabel [#variables]

Gunakan `{{notes}}` untuk meminta teks, atau `{{length:3 bullets|5 bullets}}` untuk menawarkan pilihan:

```text
Summarize these notes in {{length:3 bullets|5 bullets}}.

Notes: {{notes}}
```

LibreChat meminta nilai-nilai ini saat Anda menggunakan prompt di chat. Variabel khusus seperti `{{current_date}}`, `{{current_datetime}}`, `{{iso_datetime}}`, dan `{{current_user}}` akan terisi secara otomatis. Variabel lain akan tetap berupa teks harfiah jika tidak ada yang mengisinya.

### Versi dan Produksi [#versions-and-production]

Menyimpan suatu suntingan akan membuat versi baru. Satu versi ditandai sebagai **Production**. Pustaka dan menu `/` menggunakan versi tersebut.

| Pengaturan editor | Yang terjadi saat Anda menyimpan |
| --- | --- |
| **Editor prompt lanjutan** nonaktif | Daftar versi disembunyikan. Setiap penyimpanan menjadi Production. |
| Editor lanjutan aktif; **Always make new prompt versions production** aktif | Setiap penyimpanan menjadi Production. Anda juga dapat menelusuri versi sebelumnya. |
| Editor lanjutan aktif; Production otomatis nonaktif | Simpan sebuah versi, lalu gunakan **Deploy** untuk menjadikannya Production. |

Pengaturan ini berlaku untuk browser Anda. Mematikan editor lanjutan juga mengaktifkan Production secara otomatis. Anda dapat mengubah sakelar tersebut lagi dengan editor lanjutan yang aktif.

### Produksi atau versi yang di-pin? [#production-or-a-pinned-version]

Pilih **Production** untuk mengikuti pembaruan dari pemilik prompt. Pilih versi tertentu untuk mempertahankan instruksi yang sama hingga Anda mengubah tautan.

![Sebelum versi 4 dipromosikan, kedua agen menggunakan versi 3. Setelah promosi, agen yang mengikuti Production menggunakan versi 4, sementara agen yang dipasangkan ke versi 3 tetap menggunakan versi 3. Pengaturan cache native dapat menunda pembaruan Production.](/images/features/prompts/production-vs-pinned.svg)

Untuk prompt LibreChat, **Production** berarti revisi yang ditandai Production. Untuk prompt Langfuse, berarti versi dengan label `production`.

### Kapan instruksi diselesaikan [#when-instructions-are-resolved]

Menyimpan agen akan memeriksa prompt tetapi tidak menyalin teksnya. LibreChat me-resolve tautan tersebut pada setiap giliran. Pembaruan prompt native dapat tertunda oleh [cache](/docs/configuration/librechat_yaml/object_structure/agents#linkedinstructions); tautan Langfuse diambil setiap kali.

Variabel khusus bekerja seperti pada [instruksi agen inline](/docs/features/agents#instructions-from-a-saved-prompt). Variabel kustom seperti `{{notes}}` **tidak diisi** untuk instruksi yang ditautkan. Model menerimanya sebagai teks literal.

<Callout type="warning" title="Jika prompt tidak tersedia">
  Agen menjalankan giliran tersebut dengan **instruksi kosong**. Agen tidak menggunakan teks inline yang tersimpan.
Agen memori adalah pengecualian: agen menggunakan instruksi default-nya.
</Callout>

## Prompt dari Langfuse [#prompts-from-langfuse]

Prompt Langfuse yang telah disinkronisasi memiliki ikon awan dengan label **Managed in Langfuse**. Anda dapat melihat pratinjau dan menggunakannya di LibreChat. Ubah isinya, promosikan versi, dan hapus prompt tersebut di Langfuse.

Hanya **prompt teks** Langfuse yang didukung. Membuka prompt tersebut akan mengambil kontennya dari Langfuse tanpa menyimpannya di cache. Menghapus prompt di Langfuse akan membuat entri pustakanya di LibreChat tetap ada, tetapi entri tersebut tidak lagi dapat diselesaikan.

### Tautan Langfuse [#langfuse-links]

Admin harus mengaktifkan [sinkronisasi katalog prompt](/docs/configuration/langfuse#prompt-catalog) dan [instruksi agen Langfuse](/docs/configuration/langfuse#prompts-as-agent-instructions). Penautan dinonaktifkan secara default. Sinkronisasi katalog harus tetap diaktifkan agar tautan yang disimpan dapat berfungsi.

Jika penautan dinonaktifkan, prompt Langfuse akan hilang dari pemilih (picker) di Builder, kecuali pilihan tersimpan milik agen. Builder menampilkan catatan pada pilihan tersebut. Tautan tetap tersimpan, tetapi agen berjalan tanpa instruksi tersebut. Mengaktifkan kembali penautan akan memulihkannya tanpa perlu mengedit agen.

## Berbagi dan izin [#sharing-and-permissions]

Pemilik prompt dapat membagikannya kepada pengguna, grup, atau peran sebagai **Viewer**, **Editor**, atau **Owner**. Lihat [Access Control](/docs/features/access_control).

### Siapa yang dapat menautkan dan siapa yang dapat menjalankan [#who-can-link-and-who-can-run]

| Tugas | Akses yang diperlukan |
| --- | --- |
| Menggunakan pustaka prompt | Izin `PROMPTS` `USE` untuk peran Anda dan akses ke prompt tersebut. |
| Menambah atau mengubah tautan prompt agen | `PROMPTS` `USE` dan VIEW pada prompt, ditambah `AGENTS` `CREATE` untuk agen baru atau EDIT untuk agen yang sudah ada. |
| Mempertahankan atau menghapus tautan; beralih ke instruksi inline | Akses tingkat agen yang sama. Akses prompt tidak diperiksa lagi. |
| Chat dengan agen yang menggunakan prompt | Akses untuk chat dengan agen tersebut. Akses ke prompt tertaut tidak diperlukan. |
| Membagikan prompt | `SHARE` untuk pengguna, grup, atau peran tertentu; `SHARE_PUBLIC` untuk semua orang. |

Seorang co-editor yang tidak memiliki akses ke prompt akan melihat **Restricted prompt**. Mereka dapat mengganti tautan atau beralih ke instruksi inline. Mereka tidak dapat melihat tujuannya. Agent viewer tidak pernah melihat tautan tersebut.

Admin menetapkan izin peran di [Admin Panel](/docs/features/admin_panel) atau [konfigurasi access-control](/docs/configuration/access_control#feature-permissions). Admin yang didelegasikan dengan `manage:prompts` dapat melihat dan menautkan grup mana pun tanpa izin VIEW terpisah. Penautan tetap memerlukan `PROMPTS` `USE`.

## Detail dan pemecahan masalah [#details-and-troubleshooting]

<Accordions type="single" collapsible>
  <Accordion title="Riwayat versi, duplikasi, dan pengembalian">
    Mengubah prompt, versinya, atau sumber instruksinya akan menambahkan entri ke riwayat versi agen.

    **Duplikat** dan **Kembalikan** menyalin tautan yang tersimpan tanpa pemeriksaan USE atau VIEW baru. Jika editor baru tidak dapat melihat prompt, Builder menampilkan **Prompt terbatas**.
  </Accordion>
  <Accordion title="Arti jumlah penggunaan">
    Setiap agen yang ditautkan menambahkan satu penggunaan setelah selesai diinisialisasi dengan berhasil. Ini adalah penghitung yang sama dengan yang digunakan oleh kartu prompt dan menu garis miring (slash). Handoff dan subagen dapat menambahkan beberapa penggunaan dalam satu giliran.

    Melanjutkan proses yang dijeda tidak menambah penggunaan. Agen memori tidak pernah menambah penggunaan.
  </Accordion>
  <Accordion title="Keterbatasan Management API">
    Atur tautan prompt di Agent Builder. Management API dan spesifikasi OpenAPI-nya tidak menerima maupun mengembalikan `instructionsPrompt`.

    Mengubah `instructions` melalui API tersebut tidak mengubah apa yang digunakan oleh agen yang tertaut. Tautan tersebut memiliki prioritas. Tautan Langfuse hanya mendukung prompt teks; grup prompt native tidak memiliki batasan tersebut.
  </Accordion>
  <Accordion title="Memecahkan Masalah Pesan Builder">

    | Pesan | Apa yang harus dilakukan |
| --- | --- |
| "Pilihan prompt ini tidak tersedia saat ini." | Pilih prompt atau versi lain, atau coba lagi setelah masalah teratasi. Versi tersebut mungkin telah dihapus, diblokir oleh kebijakan, atau tidak tersedia dari Langfuse. Penautan mungkin dinonaktifkan, atau sumber grup mungkin telah berubah. |
| "Anda tidak memiliki izin untuk menautkan prompt ini." | Minta admin untuk izin `PROMPTS` `USE`, atau pemilik untuk izin VIEW pada grup. |
| "Anda tidak memiliki akses ke pustaka prompt." | Pemilih atau daftar versi memerlukan izin `PROMPTS` `USE` dan VIEW pada grup. Minta admin atau pemilik. |
| "Sumber prompt ini tidak tersedia saat ini." | Periksa konfigurasi sinkronisasi Langfuse, atau ganti tautan. Sinkronisasi mungkin dinonaktifkan atau belum dikonfigurasi, sumber mungkin telah berubah, atau prompt kini mungkin berupa prompt chat. |
| "Tidak dapat memuat prompt." | Coba lagi. Minta admin untuk memeriksa log server jika masalah berlanjut. Ini adalah kesalahan pemuatan yang tidak terduga, bukan kesalahan izin atau sumber. |
| "Versi yang dipilih (tidak lagi tersedia)" | Revisi asli telah dihapus. Pilih **Production** atau versi lain. |
| "Versi N (tidak lagi tersedia)" | Versi Langfuse tidak lagi tercantum. Pilih **Production** atau versi lain. |
| "Prompt terbatas" | Minta izin VIEW, ganti tautan, atau beralih ke instruksi sebaris. Grup mungkin juga telah dihapus. Pesan ini dapat muncul bahkan untuk pemilik agen. |
| "Prompt tidak ditemukan" | Grup telah dihapus. Pilih prompt lain atau beralih ke instruksi sebaris. Pengguna dengan `manage:prompts` atau `ADMIN` akan melihat pesan ini sebagai pengganti **Prompt terbatas**. |
| "Tidak dapat memvalidasi prompt yang ditautkan. Silakan coba lagi." | Kesalahan yang tidak terduga mencegah validasi. Coba simpan lagi. |

  </Accordion>
</Accordions>
