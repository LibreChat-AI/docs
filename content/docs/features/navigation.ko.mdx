LibreChat의 사이드바는 대화 기록, 고정된 채팅, 프로젝트 및 배포 시 활성화된 추가 패널을 제공합니다. 사용 가능한 패널 목록에는 채팅, 북마크, 프롬프트, 메모리 및 Skills가 포함될 수 있습니다.

## 데스크톱 사이드바 [#desktop-sidebar]

사이드바 토글을 사용하여 탐색 창을 열거나 접을 수 있습니다. 탐색 레일에서 패널을 선택하거나, 설정된 경우 대화 검색을 사용하거나, **New chat**을 선택하여 대화를 시작하세요. 프로젝트는 고유한 사이드바 섹션과 프로젝트별 새 대화 바로가기를 가지고 있습니다. [Projects](/docs/features/projects)를 참조하세요.

통합된 **Pinned** 섹션은 고정된 대화와 즐겨찾는 모델, 에이전트, 프리셋을 함께 보여줍니다. 포인터 기반 데스크톱 환경에서는 항목을 드래그하여 순서를 변경할 수 있습니다. 대화를 **Pinned**로 드래그하여 고정하거나, 프로젝트로 드래그하여 해당 프로젝트에 분류하거나, **Chats**로 드래그하여 프로젝트 할당을 해제할 수 있습니다. 고정된 대화는 일반 기록과 독립적으로 로드되며, 고정, 고정 해제 또는 순서 변경은 새로운 대화 활동으로 간주되지 않습니다. 터치 환경에서는 드래그 상호작용 대신 기존 메뉴를 사용합니다.

## 채팅 목록 필터링 및 정렬 [#filter-and-sort-the-chat-list]

**Chats** 제목에 있는 **Filter and sort chats** 버튼을 누르면 채팅 목록 메뉴가 열립니다. 이 메뉴에는 세 개의 행이 있으며, 각 행은 현재 값을 보여줍니다:

- **Show**는 **Active chats**와 **Archived chats** 사이를 전환합니다.
- **정렬(Sort)**은 목록을 **업데이트 날짜(Updated)**, **생성 날짜(Created)**, 또는 **제목(Title)** 기준으로 정렬하며, 보관함 보기에서는 **보관 날짜(Date Archived)** 기준도 지원합니다. **순서(Order)** 항목에서 날짜의 경우 **최신순(Newest first)** 또는 **오래된순(Oldest first)**을 선택하고, 제목의 경우 **가나다순(A to Z)** 또는 **역순(Z to A)**을 선택할 수 있습니다.
- **Filter**는 목록을 좁힙니다. **Search filters** 상자는 이름으로 필터나 값을 찾습니다.

**필터(Filter)** 하위 메뉴는 다음을 제공합니다:

| 필터 | 선택 항목 |
| --- | --- |
| **업데이트됨**, **생성됨** | **언제든지**, **오늘**, **지난 7일**, **지난 30일**, **지난 1년** |
| **Endpoint** | 배포가 제공하는 하나 이상의 endpoint |
| **첨부 파일 포함** | 파일이 있는 채팅만 |
| **공유됨만** | 활성 공유 링크가 있는 채팅만; 공유 링크가 활성화된 경우 표시됨 |
| **북마크** | 하나 이상의 북마크; 북마크를 사용할 수 있는 역할에 표시됨 |

기본 목록과 다른 점이 있을 경우, 버튼에 활성화된 설정 개수가 표시됩니다. 메뉴 헤더의 **Reset**은 전체 목록을 복원하며, **Filter** 하위 메뉴 하단의 **Clear filters**는 필터만 초기화합니다. 표시(Show) 및 필터(Filter) 선택 사항은 새로고침하거나 로그아웃할 때까지 유지되며, 정렬 순서는 현재 브라우저에 기억됩니다. 관리자는 [`conversationList`](/docs/configuration/librechat_yaml/object_structure/config#conversationlist)를 사용하여 하나의 필터가 선택할 수 있는 endpoint 개수를 제한할 수 있습니다.

## 읽지 않은 답글 [#unread-replies]

다른 채팅에 있거나 LibreChat에서 자리를 비운 사이에 응답이 완료되면, 해당 대화는 사용자가 대화를 열어 응답이 화면에 나타날 때까지 채팅 목록에 읽지 않음 점이 표시됩니다. 읽음 상태는 계정에 저장되므로, 한 기기에서 채팅을 열면 다른 기기의 점도 사라집니다.

나중에 다시 채팅을 확인하려면, 해당 채팅의 메뉴를 열고 **Mark as unread**를 선택하세요. 현재 열려 있는 채팅이나 이미 읽지 않음으로 표시된 채팅에는 이 옵션이 제공되지 않습니다.

임시 채팅은 읽지 않음으로 표시되지 않으며, 첫 번째 토큰이 생성되기 전에 중단된 응답과 같이 읽을 내용이 없는 응답도 마찬가지입니다. 탭 제목 개수, 데스크톱 알림 및 소리에 대한 자세한 내용은 [Notifications](/docs/features/settings#notifications)를 참조하세요.

## 모바일 서랍 [#mobile-drawer]

모바일 환경에서 사이드바는 기본적으로 전체 화면 서랍(drawer) 형태로 열립니다. 사이드바 헤더에는 사이드바 토글, 레이블이 지정된 패널 전환기, **New chat** 아이콘 버튼, 계정 제어 기능이 포함되어 있으며, 모든 패널에서 동일하게 유지됩니다. Agent Marketplace에 접근 권한이 있는 사용자는 패널 콘텐츠 상단에 **Agent Marketplace** 행을 추가로 볼 수 있습니다. 하단 바에는 대화 기록 패널이 활성화된 경우에만 대화 검색 기능이 표시됩니다.

브라우저 전용 **Settings > General > Layout > Show chat beside the sidebar on mobile** 설정은 기본적으로 꺼져 있습니다. 이 설정을 켜면 서랍(drawer)이 뷰포트의 80%로 제한되며, 현재 대화의 흐릿한 영역이 표시됩니다. 해당 영역을 탭하면 서랍이 닫히고 대화 화면으로 돌아갑니다.

터치 제스처를 사용하여 탐색할 수도 있습니다:

- 채팅 창을 오른쪽으로 스와이프하여 서랍(drawer)을 엽니다.
- 열려 있는 서랍 안에서 왼쪽으로 스와이프하여 닫으세요.

서랍(drawer)은 제스처를 따라 움직이며, 거리와 속도에 따라 열리거나 닫힌 상태로 고정됩니다. 기본 전체 너비 서랍의 경우, 버튼, 키보드, 대화 기반으로 닫으면 새로 로드된 콘텐츠를 이동시키지 않고 이미 배치된 채팅이 나타납니다. 채팅 스트립(chat strip)이 활성화되면 서랍과 표시된 대화가 함께 움직입니다. 모든 닫기 경로는 움직이는 표면이 다시 상호작용 가능해진 후 헤더 오프너나 채팅 창으로 포커스를 복원합니다. 수직 스크롤, 텍스트 필드, 텍스트 선택, 그리고 코드 블록과 같이 가로로 스크롤 가능한 콘텐츠는 자체 제어권을 유지합니다. 동작 줄이기(reduced-motion) 환경 설정이 적용되면 서랍 및 스트립 전환 효과가 제거됩니다.

## 보관된 대화 [#archived-conversations]

계정 메뉴에서 **Archived chats**를 열어 보관된 대화를 탐색하거나 복원할 수 있으며, [채팅 목록 메뉴](#filter-and-sort-the-chat-list)의 **Show**를 사용하여 사이드바 목록을 보관된 채팅으로 전환할 수 있습니다. 새로 보관된 채팅은 보관된 시점순으로 정렬됩니다. LibreChat이 해당 타임스탬프를 기록하기 전에 보관된 대화는 생성 날짜를 기준으로 정렬됩니다.

대화 내용을 삭제하지 않고 활성 대화 목록을 비우려면, **Settings > Data Controls > Your data** 아래에 있는 **Archive all chats**를 사용하고 해당 작업을 확인하세요.

대화 보관, 보관 해제, 고정 및 고정 해제 시 더 이상 대화의 채팅 활동 시간이 업데이트되지 않으므로, 기록 및 프로젝트 활동은 실제 대화 변경 사항을 기준으로 유지됩니다.
