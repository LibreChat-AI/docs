LibreChat에서 내보낸 대화를 JSON 형식으로 가져올 수 있을 뿐만 아니라, ChatGPT, Claude, [ChatbotUI v1](https://github.com/mckaywrigley/chatbot-ui/tree/b865b0555f53957e96727bc0bbb369c9eaecd83b?tab=readme-ov-file#legacy-code)에서 내보낸 대화도 가져올 수 있습니다. 가져온 대화는 다른 대화와 마찬가지로 기록에 표시됩니다. 내보내기는 한 번에 대화 하나씩 진행됩니다.

## 파일 가져오기 [#import-the-file]

**Settings** > **Data & Privacy**로 이동한 다음, "Import conversations from a JSON file" 옆의 **Import**를 선택하고 파일을 고르세요. 파일 선택기는 `.json` 파일만 허용하므로, ChatGPT와 Claude 아카이브는 먼저 압축을 풀어야 합니다. 가져오기가 진행되는 동안 버튼에 "Importing"이 표시되며, 완료되면 "Conversations imported successfully"가 나타납니다.

LibreChat는 파일 이름이 아니라 파일의 내용을 보고 형식을 판단합니다. 형식을 인식하지 못하면 "Unsupported import type" 오류가 표시됩니다.

LibreChat 가져오기는 대화에 저장된 코드 승인 모드(**Full access** 포함)나 읽지 않음 상태를 가져오지 않습니다. 가져온 대화에는 사용자의 현재 승인 설정과 배포 환경의 정책이 적용됩니다.

### 제한 사항 [#limits]

- 파일은 관리자가 다른 한도를 설정하지 않은 경우 최대 250 MiB까지 가능합니다. 이보다 큰 파일은 업로드 전에 거부됩니다.
- 단일 대화나 메시지는 데이터베이스 제한으로 인해 약 16MB를 넘을 수 없습니다.
- 가져오기는 사용자별 및 IP별로 요청 횟수가 제한되므로, 여러 파일을 연속해서 가져오면 일정 시간 동안 요청이 거부될 수 있습니다.

## 대화 내보내기 [#export-a-conversation]

대화를 열고 **Chat options** 메뉴(헤더의 `...` 버튼, 또는 작은 화면에서는 헤더 메뉴)를 엽니다. **Export**를 선택합니다. 파일 이름과 유형을 선택한 다음 **Export**를 선택합니다.

| 유형 | 제공되는 내용 |
| --- | --- |
| `markdown` (.md) | 읽기 쉬운 대화 기록입니다. 기본값입니다. |
| `text` (.txt) | 일반 텍스트 대화 기록입니다. |
| `json` (.json) | 전체 메시지 데이터입니다. LibreChat에서 다시 가져올 수 있는 형식입니다. |
| `csv` (.csv) | 메시지당 한 행입니다. |
| `screenshot` (.png) | 화면에 표시된 대화의 이미지입니다. |

**모든 메시지 분기 내보내기**는 `json`과 `csv` 형식에서만 작동하며, 다른 형식은 현재 보고 있는 분기만 내보냅니다. **엔드포인트 옵션 포함**은 모델과 해당 설정을 추가하며, `csv` 및 `screenshot` 형식에서는 사용할 수 없습니다. `json` 형식에서는 **재귀적**(상위 메시지 아래에 중첩된 메시지) 또는 순차적 방식을 선택할 수도 있습니다.

한 번에 모든 대화를 내보내는 기능은 없으며, 새 채팅이나 검색 결과에는 내보낼 내용이 없으므로 메뉴가 표시되지 않습니다.

## 설정 [#setup]

가져오기 및 내보내기는 별도의 설정 없이 모든 사용자가 사용할 수 있습니다. 관리자는 `CONVERSATION_IMPORT_MAX_FILE_SIZE_BYTES`로 가져오기 파일 크기 제한을 변경하고, `IMPORT_*` 변수로 속도 제한을 변경할 수 있습니다. 자세한 내용은 [.env 참조](/docs/configuration/dotenv#conversation-import)를 확인하세요.
