Una skill è un file `SKILL.md`: un breve blocco di frontmatter che indica quando la skill si applica, e un corpo in markdown con le istruzioni. Usane una per qualsiasi cosa che incolleresti altrimenti in chat più volte, come una guida allo stile, una checklist di revisione o i passaggi per un report ricorrente. Gli agenti caricano una skill solo quando è pertinente, quindi puoi conservarne molte senza appesantire ogni prompt.

LibreChat non include alcuna skill. Ciascuna viene scritta o caricata da un utente, creata da un agente durante una chat, oppure fornita dal tuo amministratore.

## Crea una skill [#create-a-skill]

Apri **Skills** dal pannello laterale e fai clic su **+**. Scegli **Write skill instructions** per scrivere una skill direttamente nell'editor, oppure **Upload a skill** per importare un file `.md`, oppure un archivio `.zip` o `.skill` che contenga un `SKILL.md`. Se Skills non compare nel pannello laterale, significa che il tuo amministratore lo ha disattivato oppure che il tuo ruolo non può utilizzarlo.

A minimal skill:

```md filename="SKILL.md"
---
name: brand-guidelines
description: Use when writing public-facing copy that must follow the company voice and terminology.
---

Write in a concise, practical tone.
Prefer active voice.
Say "workspace", never "project space".
```

Il nome deve essere in kebab-case (lettere minuscole, cifre e trattini), lungo al massimo 64 caratteri e univoco tra le tue skill; caricare una skill con un nome già in uso non va a buon fine invece di sovrascrivere la skill esistente. I nomi che iniziano con `anthropic-` o `claude-`, così come le parole di comando come `help` o `settings`, sono riservati.

La descrizione è l'elemento più importante del file: è ciò che il modello legge per decidere se la skill si applica. "Use when writing release notes for the mobile app" attiverà la skill; "Writing helper" no. Inserisci per primi i trigger e mantieni la descrizione sotto i 250 caratteri, perché le descrizioni più lunghe vengono troncate nell'elenco che il modello vede. Il limite massimo è di 1.024 caratteri per la descrizione e di 100.000 per il corpo.

### Opzioni del frontmatter [#frontmatter-options]

Oltre a `name` e `description`, una skill può impostare:

- `always-apply: true`: carica la skill a ogni turno invece di attendere che il modello la richieda.
- `user-invocable: false`: nasconderlo dal menu `$`.
- `disable-model-invocation: true`: escluso dall'elenco da cui il modello sceglie. Puoi comunque invocarlo con `$`.
- `allowed-tools`: un elenco di strumenti (ad esempio `["execute_code"]`) che l'agente riceve per quel turno quando la skill viene invocata con `$` o applicata sempre, anche se normalmente l'agente non dispone di tali strumenti.
- `compatibility`: note in testo libero su ciò di cui la skill ha bisogno, ad esempio un particolare server MCP. LibreChat la conserva ma non la applica.

`when-to-use` funziona al posto di `description`, e `alwaysApply` al posto di `always-apply`. Le chiavi non distinguono tra maiuscole e minuscole, e le altre chiavi che aggiungi vengono mantenute come metadati.

### File inclusi [#bundled-files]

Una skill può contenere più di un file. Una disposizione comune prevede `references/` per i documenti lunghi, `scripts/` per il codice che l'agente può eseguire e `assets/` per i template. L'agente legge questi file quando la skill è in uso, quindi `SKILL.md` può rimanere breve e rimandare ad essi. Quando Run Code è attivo, i file sono disponibili anche nella sandbox sotto `/mnt/data/skills/<skill-name>/`. Nel visualizzatore delle skill, i link relativi tra i file Markdown della skill aprono il file collegato.

In un archivio, `SKILL.md` deve trovarsi al livello più alto oppure all'interno di esattamente una cartella. Un caricamento è limitato per impostazione predefinita a 50 MB (l'amministratore può modificare questo valore), 500 file e 10 MB per file; i file con percorsi non sicuri vengono ignorati e segnalati. Una skill con file allegati mostra una freccia accanto al suo nome nella barra laterale Skills; espandila per sfogliare i file e aprirne uno.

## Usa una skill [#use-a-skill]

Esistono tre modi in cui una skill arriva alla conversazione:

- **Scegli tu.** Digita `$` nella casella di chat e seleziona una skill. Nulla viene aggiunto al tuo testo; la skill appare come chip sopra la casella di composizione e viene caricata per quel messaggio.
- **Il modello lo sceglie.** L'agente vede i nomi e le descrizioni delle skill disponibili e ne carica una quando la tua richiesta corrisponde.
- **È sempre applicato.** Le skill con `always-apply: true` vengono caricate a ogni turno.

Mentre una skill viene caricata, il messaggio mostra **Loading** seguito dal nome della skill, poi **Loaded** una volta che è nel contesto.

Il modello vede nel proprio elenco solo i nomi e le descrizioni (fino a 100 skill), non le istruzioni. Una skill che scegli tu o che viene sempre applicata carica il proprio `SKILL.md` completo per quel turno. Un turno può includere fino a 10 skill scelte e 20 skill sempre applicate, per un totale di 30; oltre questo limite, le skill sempre applicate vengono eliminate per prime.

## Quali competenze può utilizzare un agente [#which-skills-an-agent-can-use]

Due cose decidono.

Innanzitutto, la tua lista. Ogni skill dispone di un interruttore **Disponibile per l'agente**. Disattivandolo, la skill scompare dal menu `$`, dalle opzioni tra cui può scegliere il modello e dalle skill sempre applicate, senza essere eliminata. Le skill che crei sono attive per impostazione predefinita. Le skill condivise con te sono disattivate, a meno che il tuo amministratore non abbia reso attive le skill condivise per impostazione predefinita.

Secondo, l'agente. La sezione **Skills** nell'Agent Builder ha tre impostazioni:

- **Off**: l'agente non utilizza alcuna skill.
- **Tutte**: ogni skill che hai attivato.
- **Selezionate**: solo le skill che aggiungi all'elenco.

**Selezionato** è la scelta migliore per un agente focalizzato. Un agente di supporto con 40 competenze tra cui scegliere sbaglierà più spesso la scelta rispetto a uno che ne ha solo le tre di cui ha bisogno.

## Competenze scritte dagli agenti [#skills-written-by-agents]

Un agente con le skill attivate può anche scrivere skill mentre lavora, ad esempio per salvare una procedura appena completata con successo. Può creare una nuova skill se il tuo ruolo è autorizzato a creare skill, e modificare le skill esistenti solo se tu puoi modificarle e si trovano nell'ambito dell'agente. Le skill fornite dal tuo amministratore restano in sola lettura. Con **Selezionate** e un elenco vuoto, l'agente non vede nessuna delle tue skill esistenti, ma può comunque crearne di nuove.

## Condivisione [#sharing]

Le Skill vengono condivise nello stesso modo degli agenti e dei prompt, con i ruoli Viewer (può usarle, non modificarle), Editor e Owner. La condivisione richiede il permesso di condivisione sul proprio ruolo, che è disattivato per impostazione predefinita per gli utenti regolari. Vedi [Controllo degli accessi](/docs/features/access_control).

Il tuo amministratore può anche fornire skill, dal file system del server, da [Agent Plugins](/docs/features/agent_plugins), oppure replicate da un repository GitHub. Queste sono di sola lettura in LibreChat; modificale alla fonte. Le skill provenienti dal file system e dai plugin sono attive per impostazione predefinita.

## Setup [#setup]

Le skill sono attive per impostazione predefinita per tutti gli utenti. Gli amministratori possono disattivare la funzionalità tramite la capacità dell'agente `skills` (vedi [configurazione dell'endpoint agents](/docs/configuration/librechat_yaml/object_structure/agents#capabilities)), controllare chi può creare e condividere le skill nel [Pannello di amministrazione](/docs/features/admin_panel) oppure tramite [`interface.skills`](/docs/configuration/librechat_yaml/object_structure/interface#skills), fornire le skill da disco o da GitHub come descritto in [Skill Sync](/docs/configuration/librechat_yaml/object_structure/skill_sync), e modificare il limite di dimensione dei caricamenti con [`fileConfig.skills`](/docs/configuration/librechat_yaml/object_structure/file_config#skills).
