Los Artifacts permiten que los agentes de LibreChat rendericen componentes de React, HTML, SVG, Markdown y contenido de Mermaid generados en una vista interactiva dedicada. Los usuarios pueden continuar la conversación para revisar el resultado mientras mantienen el contenido generado separado de la respuesta del chat.

## Habilitar Artifacts para un agente [#enable-artifacts-for-an-agent]

1. Cree o edite un [Agent](/docs/features/agents).
2. Abra **Add tools** y seleccione **Artifacts**.
3. Elija un modo de instrucción de artefactos.
4. Guarda el agente.

Los modos disponibles son:

- **Normal**: Inyecta las instrucciones estándar de LibreChat para artefactos de React, HTML, SVG, Markdown y Mermaid.
- **shadcn/ui**: Añade orientación sobre la biblioteca de componentes shadcn/ui para interfaces generadas con un acabado más pulido.
- **Custom**: Mantiene el renderizado de artefactos habilitado, pero no inyecta instrucciones integradas. Incluya el comportamiento completo del artefacto que desee en las instrucciones del agente.

La configuración a nivel de agente es preferible porque cada agente puede utilizar el modo y las instrucciones apropiadas para su propósito. El administrador puede ocultar Artifacts eliminando la `artifacts` [capacidad del agente](/docs/configuration/librechat_yaml/object_structure/agents#capabilities).

## Qué soportan los Artifacts [#what-artifacts-support]

- Componentes de React interactivos y páginas HTML
- Imágenes SVG y diagramas Mermaid
- Documentos Markdown renderizados
- Actualizaciones iterativas a través de mensajes de seguimiento
- Cualquier modelo disponible para el agente configurado

## Vista previa y exportación [#preview-and-export]

Utilice el control de pantalla completa en una vista previa de artefacto renderizado para expandirlo a toda la pantalla del navegador. El control sigue el estado de la Fullscreen API del navegador, se cierra normalmente con Escape o con los controles del navegador, y se oculta cuando la pantalla completa no está disponible.

En escritorio, selecciona **Open in new window** en el encabezado del panel de artefactos para mover el panel a una ventana del navegador independiente, por ejemplo, para colocarlo en una segunda pantalla. El artefacto continúa actualizándose a medida que la respuesta se transmite, y las ediciones de código no guardadas y la pestaña seleccionada se mantienen. Para devolver el panel al chat, selecciona **Dock back to panel** o cierra la ventana. LibreChat recuerda el tamaño y la posición de la ventana para la próxima vez.

- Mantenga la pestaña de chat abierta: la ventana está controlada por la pestaña de chat, y cerrar esa pestaña también cierra la ventana.
- Si el navegador bloquea la ventana, LibreChat muestra un aviso. Permita las ventanas emergentes para el sitio e inténtelo de nuevo.
- El botón no se muestra en diseños estrechos (móviles).

Los administradores pueden eliminar el botón y mantener los artifacts en el panel lateral configurando [`interface.artifactUndocking: false`](/docs/configuration/librechat_yaml/object_structure/interface#artifactundocking).

Los diagramas Mermaid aparecen como tarjetas integradas compactas que pueden abrirse en el panel de artefactos. Exporta un diagrama como SVG o PNG desde la tarjeta integrada o desde el panel. Las vistas previas de Mermaid se renderizan directamente en lugar de cargar el empaquetador Sandpack; la exportación a PNG aplica dimensiones de lienzo delimitadas para proteger al navegador de diagramas de tamaño excesivo.

Los artefactos creados por el modelo se descargan bajo su título o encabezado Markdown con una extensión que coincide con el contenido exportado. Un artefacto basado en archivos sin editar descarga el original completo con su nombre de archivo y formato originales cuando están disponibles. La descarga de contenido editado o de vista previa en caché utiliza un calificador `.preview` para que no se confunda con el archivo original.

## Content-Security-Policy

Es posible que necesites actualizar la Content-Security-Policy de tu servidor web para incluir `frame-src 'self' https://*.codesandbox.io` con el fin de cargar las aplicaciones HTML generadas en el panel de Artifacts. Esta es una dependencia de la librería [sandpack](https://sandpack.codesandbox.io/).

## Autoalojamiento del Bundler de Sandpack [#self-hosting-the-sandpack-bundler]

Los Artifacts en LibreChat utilizan la biblioteca Sandpack de CodeSandbox para renderizar código HTML/JS de forma segura. De forma predeterminada, LibreChat se conecta a la CDN pública de CodeSandbox, la cual también puede transmitir telemetría sobre su uso.

Para una mayor privacidad, cumplimiento de seguridad o entornos de red aislados, puede [alojar el bundler usted mismo.](https://sandpack.codesandbox.io/docs/guides/hosting-the-bundler)

### ¿Por qué autoalojar el Sandpack Bundler? [#why-self-host-the-sandpack-bundler]

[Autoalojar el bundler](https://sandpack.codesandbox.io/docs/guides/hosting-the-bundler) ofrece varias ventajas:

- **Privacidad y seguridad**: Mantenga la ejecución de código dentro de su propia infraestructura
- **Fiabilidad**: Eliminar la dependencia de servicios externos
- **Rendimiento**: Reduzca la latencia alojando el bundler en su red
- **Cumplimiento**: Cumplir con los requisitos de manejo de datos de la organización
- **Control**: Configure y personalice según sus necesidades específicas

### Configuración [#configuration]

Una vez que tenga un bundler autohospedado configurado, simplemente configure LibreChat para usarlo estableciendo la variable de entorno:

```bash
# `.env` file
SANDPACK_BUNDLER_URL=http://your-bundler-url
```

### Consideraciones generales [#general-considerations]

Autoalojar el bundler introduce una sobrecarga adicional:

- **Configuración de CORS**: Necesitará gestionar las políticas de intercambio de recursos de origen cruzado (cross-origin resource sharing)
- **Gestión de seguridad**: Usted se vuelve responsable de la seguridad del servicio de empaquetado (bundler).
- **Mantenimiento**: Las actualizaciones y parches deberán aplicarse manualmente
- **Requisitos de recursos**: Se necesitarán recursos de servidor adicionales para alojar el bundler

Para obtener instrucciones detalladas sobre cómo configurar y mantener su bundler autohospedado, consulte el [repositorio forked de CodeSandbox](https://github.com/LibreChat-AI/codesandbox-client) adaptado para el despliegue de LibreChat, que incluye la eliminación de telemetría de Sandpack.
