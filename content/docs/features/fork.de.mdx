Das Forken kopiert einen Teil einer Unterhaltung in einen neuen Chat. Nutzen Sie es, wenn Sie ab einem bestimmten Punkt eines Verlaufs eine andere Richtung ausprobieren möchten oder eine lange Unterhaltung in eine eigenständige aufteilen wollen, während das Original genau so erhalten bleibt, wie es war.

## Von einer Nachricht forken [#fork-from-a-message]

Fahren Sie mit der Maus über eine Nachricht und wählen Sie das Gabel-Symbol (**Open Fork Menu**). Ein Popover öffnet sich mit drei Gabeloptionen, zwei Kontrollkästchen und **Remember**. Wählen Sie eine Option aus, und die Verzweigung erfolgt sofort: LibreChat zeigt „Forking conversation...“ an und öffnet dann den neuen Chat.

Der neue Chat behält den ursprünglichen Titel. Ein Fork eines temporären Chats ist ebenfalls temporär.

Das Forken ist bei Nachrichten des Assistants-Endpoints oder bei Suchergebnissen nicht verfügbar.

## Was kopiert wird [#what-gets-copied]

Die Optionen legen fest, welche Nachrichten mitkommen. Die „Zielnachricht“ ist diejenige, von der aus du das Popover geöffnet hast.

- **Nur sichtbare Nachrichten**: Der direkte Pfad vom Anfang der Unterhaltung bis zur Zielnachricht, ohne andere Verzweigungen. Das ist das, was Sie auf dem Bildschirm sehen.
- **Verwandte Zweige einbeziehen**: derselbe Pfad sowie die alternativen Zweige (Bearbeitungen und Neugenerierungen), die sich entlang dieses Pfades abgezweigt haben.
- **Alle Nachrichten einbeziehen bis hierher**: jede Nachricht, die zum Ziel führt, einschließlich benachbarter Zweige, unabhängig davon, ob sie im sichtbaren Pfad liegen. Dies ist die Standardeinstellung.

Fahren Sie mit der Maus über das Symbol einer Option, um dieselbe Erklärung in der App zu sehen.

## Hier forken starten und Dateien ausschließen [#start-fork-here-and-leave-out-files]

**Starte den Fork hier** kehrt die Richtung um. Die Nachricht, von der aus du das Popover geöffnet hast, wird zum Startpunkt, und der Fork läuft von dort bis zur neuesten Nachricht in der Unterhaltung, je nachdem, welche Option du auswählst.

**Dateien weglassen** kopiert die Nachrichten ohne ihre angehängten oder generierten Dateien, damit spätere Nachrichten im Fork diese nicht erneut senden. Verwenden Sie es, wenn eine große oder fehlerhafte Datei im ursprünglichen Thread Probleme verursacht. Dieses Kontrollkästchen wird nie gespeichert; Sie aktivieren es für jeden Fork einzeln.

## Remember und die Standard-Fork-Option [#remember-and-the-default-fork-option]

Wenn Sie vor der Auswahl einer Option das Kontrollkästchen **Remember** aktivieren, wird diese Option als Standard gespeichert. Ab dann überspringt das Gabel-Symbol das Popover und verzweigt sofort mit dieser Option. Das Kontrollkästchen **Start fork here** bleibt immer so erhalten, wie Sie es zuletzt eingestellt haben.

Um das Popover wieder anzuzeigen oder die gespeicherte Auswahl zu ändern, öffne die **Einstellungen**, wechsle zum Tab **Chat** und suche die Fork-Einstellungen unter **Conversations**:

- **Standard-Fork-Option verwenden**: Wenn aktiviert, wird das Fork-Symbol sofort mit der Standardoption geforkt.
- **Standard-Fork-Option**: Welche der drei Optionen verwendet werden soll. Wird nur angezeigt, während der oben stehende Schalter aktiviert ist.
- **Fork ab der Zielnachricht standardmäßig starten**: Der Standardwert für **Hier Fork starten**.

## Eine geteilte Unterhaltung forken [#forking-a-shared-conversation]

Wenn dir jemand eine Unterhaltung teilt, überträgt die Schaltfläche **Diesen Chat fortsetzen** auf der geteilten Seite sie in dein eigenes Konto und folgt dabei dem von dir ausgewählten Zweig. Siehe [Teilbare Links](/docs/features/shareable_links#continue-a-shared-chat).

## Einrichtung [#setup]

Forking ist für alle aktiviert und erfordert keine Einrichtung. Administratoren können Fork-Anfragen mit den `FORK_*`-Variablen im [.env-Referenz](/docs/configuration/dotenv#conversation-forking-rate-limiting) ratenbegrenzen.
