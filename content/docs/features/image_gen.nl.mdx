LibreChat creëert en bewerkt afbeeldingen via agenttools. Geef een agent een afbeeldingstool, beschrijf wat je wilt, en de afbeelding verschijnt in het gesprek. Upload een foto met je bericht en de agent kan deze aanpassen in plaats van helemaal opnieuw te beginnen.

## De afbeeldingstools [#the-image-tools]

| Tool | Wat het doet | Bewerkt afbeeldingen |
| --- | --- | --- |
| OpenAI Image Tools | Genereert afbeeldingen op basis van tekst en bewerkt geüploade of eerdere afbeeldingen met OpenAI-beeldmodellen. Een goede standaardkeuze. | Ja |
| Gemini Image Tools | Genereert afbeeldingen met de beeldmodellen van Google Gemini, optioneel met eerdere afbeeldingen als visuele context. | Ja |
| Flux | Genereert afbeeldingen met de Flux-modellen van Black Forest Labs, inclusief je eigen fijn afgestelde modellen. | Nee |
| Stable Diffusion | Genereert afbeeldingen op je eigen Automatic1111-server, zodat niets je netwerk verlaat. | Nee |

Welke je ziet, hangt af van wat je beheerder heeft ingesteld.

## Een afbeelding genereren [#generate-an-image]

<Steps>
<Step>
Open de agent in de Agent Builder en selecteer **Toevoegen** naast **Tools**.
</Step>
<Step>
Kies een afbeeldingstool, zoals **OpenAI Image Tools**, en sla de agent op. Als de tool om een API-sleutel vraagt, heeft je beheerder deze aan elke gebruiker overgelaten; voer je eigen sleutel in.
</Step>
<Step>
Start een chat met de agent en beschrijf de afbeelding.
</Step>
</Steps>

De agent zet je verzoek om in een prompt voor de tool, zodat je gewoon normaal kunt praten ("een poster voor een bakkerijverkoop, breedformaat, veel pastelkleuren"). Verzoeken over vorm en formaat worden doorgegeven wanneer de tool dat ondersteunt: OpenAI accepteert vierkante, liggende of staande formaten (nieuwere modellen accepteren ook aangepaste formaten tot 4K) plus een kwaliteitsniveau en een transparante achtergrond, Gemini accepteert beeldverhoudingen zoals 16:9 of 9:16 en, bij nieuwere modellen, een resolutie tot 4K. Stable Diffusion produceert altijd 1024x1024.

## Een afbeelding bewerken [#edit-an-image]

Voeg een afbeelding toe met **Upload Image** en vraag om een wijziging: "verwijder de mensen op de achtergrond", "laat het eruitzien als een aquarel", "zet dit logo op een koffiemok". Met OpenAI Image Tools roept de agent de bewerkingstool aan; met Gemini geeft deze jouw afbeelding mee als context voor een nieuwe generatie.

Je kunt doorgaan met een afbeelding die de agent zojuist heeft gegenereerd ("maak de lucht donkerder") zonder iets te uploaden. Elke geüploade of gegenereerde afbeelding heeft een ID waarnaar het model verwijst, en dat werkt zolang de afbeelding nog binnen het contextvenster van het gesprek valt. Bij een lang gesprek moet je de afbeelding opnieuw bijvoegen.

Flux en Stable Diffusion werken alleen met tekst, dus ze kunnen niet bewerken.

## Wat het model ziet [#what-the-model-sees]

Een gegenereerde afbeelding wordt aan het model één keer getoond, direct nadat deze is gemaakt, zodat het de eigen werk kan beschrijven of controleren. Daarna ziet het model alleen afbeeldingen die aan je berichten zijn toegevoegd. Als je na enkele beurten opnieuw over een oudere afbeelding wilt praten, voeg deze dan opnieuw toe.

Omdat de afbeelding teruggaat naar het model, gebruik je een model met visuele mogelijkheden voor agents met afbeeldingstools. Een model dat alleen tekst verwerkt, kan mislukken bij de beurt na het genereren van de afbeelding.

Gegenereerde afbeeldingen worden opgeslagen zoals elk ander geüpload bestand, volgens de instellingen voor bestandsopslag van je beheerder. Standaard worden ze verkleind zodat de kortste zijde maximaal 768 pixels is, dus een verzoek voor 4K wordt kleiner opgeslagen dan het model heeft gemaakt, tenzij je beheerder dat aanpast.

## Afbeeldingen van MCP-servers [#images-from-mcp-servers]

MCP-tools kunnen ook afbeeldingen teruggeven, bijvoorbeeld een browserserver die screenshots maakt. Afbeeldingen die de server teruggeeft in het afbeeldingsformaat van MCP worden in de chat op dezelfde manier getoond als de uitvoer van de ingebouwde tools. Sommige servers geven alleen een URL naar de afbeelding terug, en LibreChat behandelt dat niet als afbeeldingsuitvoer.

## Prompts schrijven [#writing-prompts]

Beeldmodellen reageren op concrete beschrijvingen. Begin met het onderwerp en het medium (foto, olieverfschilderij, vlakke vectorillustratie), voeg daarna compositie, belichting en de details toe die ertoe doen. Beschrijf wat je wilt zien in plaats van op te sommen wat je wilt vermijden. Als een resultaat dichtbij is, vraag dan om de specifieke wijziging in plaats van de hele prompt te herschrijven.

## Setup [#setup]

Elke tool heeft een API-sleutel of een server-URL nodig. Een beheerder stelt deze in via `.env`; voor de op sleutel gebaseerde tools kan een beheerder er ook voor kiezen om de sleutel door elke gebruiker zelf te laten invoeren. Installatie per tool: [OpenAI Image Tools](/docs/configuration/tools/openai_image_gen), [Gemini Image Tools](/docs/configuration/tools/gemini_image_gen), [Flux](/docs/configuration/tools/flux) en [Stable Diffusion](/docs/configuration/tools/stable_diffusion). Waar afbeeldingen worden opgeslagen, wordt ingesteld via [`fileStrategy`](/docs/configuration/librechat_yaml/object_structure/config#filestrategy).
