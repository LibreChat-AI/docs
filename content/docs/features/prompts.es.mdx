### Variables [#variables]

Usa `{{notes}}` para pedir texto, o `{{length:3 bullets|5 bullets}}` para ofrecer opciones:

```text
Summarize these notes in {{length:3 bullets|5 bullets}}.

Notes: {{notes}}
```

LibreChat te pide estos valores cuando usas el prompt en el chat. Las variables especiales como `{{current_date}}`, `{{current_datetime}}`, `{{iso_datetime}}` y `{{current_user}}` se rellenan automáticamente. Las demás variables se mantienen como texto literal si nada las rellena.

### Versiones y producción [#versions-and-production]

Guardar una edición crea una nueva versión. Una versión está marcada como **Production**. La biblioteca y el menú `/` usan esa versión.

| Configuración del editor | Qué sucede al guardar |
| --- | --- |
| **Editor avanzado de prompts** desactivado | La lista de versiones se oculta. Cada guardado pasa a ser Producción. |
| Editor avanzado activado; **Crear siempre nuevas versiones de prompts en Producción** activado | Cada guardado pasa a ser Producción. También puedes explorar versiones anteriores. |
| Editor avanzado activado; Producción automática desactivada | Guarda una versión y, a continuación, usa **Desplegar** para convertirla en Producción. |

Estos ajustes se aplican a tu navegador. Desactivar el editor avanzado también activa automáticamente la opción Production. Puedes volver a cambiar ese interruptor con el editor avanzado activado.

### ¿Producción o una versión fijada? [#production-or-a-pinned-version]

Elija **Producción** para seguir las actualizaciones del propietario del prompt. Elija una versión específica para mantener las mismas instrucciones hasta que cambie el enlace.

![Antes de que la versión 4 se promueva, ambos agentes usan la versión 3. Después de la promoción, el agente que sigue Production usa la versión 4, mientras que el agente fijado a la versión 3 permanece en la versión 3. La configuración de caché nativa puede retrasar la actualización de Production.](/images/features/prompts/production-vs-pinned.svg)

Para los prompts de LibreChat, **Production** hace referencia a la revisión marcada como Production. Para los prompts de Langfuse, se refiere a la versión con la etiqueta `production`.

### Cuándo se resuelven las instrucciones [#when-instructions-are-resolved]

Guardar el agente verifica el prompt, pero no copia su texto. LibreChat resuelve el enlace en cada turno. Las actualizaciones nativas del prompt pueden tardar en reflejarse debido a la [caché](/docs/configuration/librechat_yaml/object_structure/agents#linkedinstructions); los enlaces de Langfuse se obtienen cada vez.

Las variables especiales funcionan igual que en las [instrucciones de agente en línea](/docs/features/agents#instructions-from-a-saved-prompt). Las variables personalizadas, como `{{notes}}`, **no se completan** en las instrucciones vinculadas. El modelo las recibe como texto literal.

<Callout type="warning" title="Si el prompt no está disponible">
  El agente se ejecuta con **instrucciones vacías** en ese turno. No utiliza su texto en línea guardado.
El agente de memoria es una excepción: utiliza sus instrucciones predeterminadas.
</Callout>

## Prompts de Langfuse [#prompts-from-langfuse]

Las instrucciones sincronizadas de Langfuse tienen un icono de nube etiquetado como **Gestionado en Langfuse**. Puedes previsualizarlas y usarlas en LibreChat. Edita su contenido, promueve versiones y elimínalas en Langfuse.

Solo se admiten **prompts de texto** de Langfuse. Al abrir uno, su contenido se obtiene de Langfuse sin almacenarlo en caché. Si lo elimina en Langfuse, la entrada de la biblioteca permanece en LibreChat, pero ya no se puede resolver.

### Enlaces de Langfuse [#langfuse-links]

Un administrador debe habilitar [la sincronización del catálogo de prompts](/docs/configuration/langfuse#prompt-catalog) y [las instrucciones de agente de Langfuse](/docs/configuration/langfuse#prompts-as-agent-instructions). La vinculación está desactivada de forma predeterminada. La sincronización del catálogo debe permanecer habilitada para que los vínculos guardados funcionen.

Si la vinculación está deshabilitada, los prompts de Langfuse desaparecen del selector del Builder, excepto la selección guardada del agente. El Builder muestra una nota sobre esa selección. El vínculo permanece guardado, pero el agente se ejecuta sin esas instrucciones. Volver a habilitar la vinculación lo restaura sin necesidad de editar el agente.

## Compartir y permisos [#sharing-and-permissions]

Un propietario de un prompt puede compartirlo con usuarios, grupos o roles como **Viewer**, **Editor** u **Owner**. Consulta [Control de acceso](/docs/features/access_control).

### Quién puede vincular y quién puede ejecutar [#who-can-link-and-who-can-run]

| Tarea | Acceso necesario |
| --- | --- |
| Usar la biblioteca de prompts | El permiso `PROMPTS` `USE` de tu rol y acceso al prompt. |
| Añadir o cambiar el enlace de prompt de un agente | `PROMPTS` `USE` y VIEW sobre el prompt, además de `AGENTS` `CREATE` para un agente nuevo o EDIT para un agente existente. |
| Mantener o quitar un enlace; cambiar a instrucciones en línea | El mismo acceso a nivel de agente. El acceso al prompt no se vuelve a comprobar. |
| Chatear con un agente que usa un prompt | Acceso para chatear con el agente. No se requiere acceso al prompt vinculado. |
| Compartir un prompt | `SHARE` para usuarios, grupos o roles seleccionados; `SHARE_PUBLIC` para todos. |

Un co-editor sin acceso al prompt ve **Restricted prompt**. Puede reemplazar el enlace o cambiar a instrucciones en línea. No puede ver su destino. Un visor de agente nunca ve el enlace.

Los administradores configuran los permisos de rol en el [Panel de administración](/docs/features/admin_panel) o en la [configuración de control de acceso](/docs/configuration/access_control#feature-permissions). Los administradores delegados con `manage:prompts` pueden ver y vincular cualquier grupo sin una concesión VIEW independiente. Vincular sigue requiriendo `PROMPTS` `USE`.

## Detalles y solución de problemas [#details-and-troubleshooting]

<Accordions type="single" collapsible>
  <Accordion title="Historial de versiones, duplicar y revertir">
    Cambiar el prompt, su versión o la fuente de las instrucciones añade una entrada al historial de versiones del agente.

    **Duplicar** y **Revertir** copian el enlace guardado sin una nueva verificación de USO o VISTA. Si el nuevo editor no puede ver el prompt, el Builder muestra **Prompt restringido**.
  </Accordion>
  <Accordion title="Qué significa el recuento de uso">
    Cada agente vinculado añade un uso una vez que termina de inicializarse correctamente. Este es el mismo contador que usan las tarjetas de prompts y el menú de barra diagonal. Los traspasos y los subagentes pueden añadir varios usos en un mismo turno.

    Reanudar una ejecución pausada no añade ningún uso adicional. El agente de memoria nunca añade un uso.
  </Accordion>
  <Accordion title="Limitaciones de la API de gestión">
    Configura enlaces de prompts en el Agent Builder. La API de administración y su especificación OpenAPI no aceptan ni devuelven `instructionsPrompt`.

    Cambiar `instructions` a través de esa API no modifica lo que usa un agente vinculado. El vínculo tiene prioridad. Los vínculos de Langfuse solo admiten prompts de texto; los grupos de prompts nativos no tienen esa restricción.
  </Accordion>
  <Accordion title="Solución de problemas de los mensajes del Builder">

    | Mensaje | Qué hacer |
| --- | --- |
| "Esta selección de prompt no está disponible en este momento." | Elige otro prompt o versión, o vuelve a intentarlo cuando se resuelva. La versión puede haberse eliminado, estar bloqueada por una política o no estar disponible en Langfuse. La vinculación puede estar deshabilitada, o el origen del grupo puede haber cambiado. |
| "No tienes permiso para vincular este prompt." | Pide a un administrador el permiso `PROMPTS` `USE`, o al propietario el permiso VIEW sobre el grupo. |
| "No tienes acceso a la biblioteca de prompts." | El selector o la lista de versiones requiere el permiso `PROMPTS` `USE` y VIEW sobre el grupo. Pide a un administrador o al propietario. |
| "El origen de este prompt no está disponible en este momento." | Revisa la configuración de sincronización de Langfuse, o reemplaza el vínculo. La sincronización puede estar deshabilitada o sin configurar, el origen puede haber cambiado, o el prompt puede ahora ser un prompt de chat. |
| "No se pudieron cargar los prompts." | Vuelve a intentarlo. Pide a un administrador que revise los registros del servidor si el problema continúa. Se trata de un error de carga inesperado, no de un error de permisos u origen. |
| "Versión seleccionada (ya no disponible)" | La revisión nativa fue eliminada. Selecciona **Production** u otra versión. |
| "Versión N (ya no disponible)" | La versión de Langfuse ya no aparece en la lista. Selecciona **Production** u otra versión. |
| "Prompt restringido" | Solicita el permiso VIEW, reemplaza el vínculo o cambia a instrucciones en línea. El grupo también podría haber sido eliminado. Este mensaje puede aparecer incluso para el propietario del agente. |
| "Prompt no encontrado" | El grupo fue eliminado. Selecciona otro prompt o cambia a instrucciones en línea. Los usuarios con `manage:prompts` o `ADMIN` ven este mensaje en lugar de **Prompt restringido**. |
| "No se pudo validar el prompt vinculado. Por favor, inténtalo de nuevo." | Un error inesperado impidió la validación. Intenta guardar nuevamente. |

  </Accordion>
</Accordions>
