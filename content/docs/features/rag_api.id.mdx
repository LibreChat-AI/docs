Pencarian file memungkinkan Anda mengunggah dokumen dan mengajukan pertanyaan tentangnya tanpa menempelkan isinya ke dalam chat. LibreChat mengirimkan setiap file ke RAG API, yang memecahnya menjadi beberapa potongan (chunk) dan mengindeksnya; ketika Anda mengajukan pertanyaan, model mencari di indeks tersebut dan menjawab berdasarkan bagian-bagian teks yang ditemukan.

Gunakan fitur ini saat sebuah dokumen terlalu panjang untuk dibaca penuh setiap kali, atau saat Anda ingin mendapatkan jawaban dari beberapa file sekaligus.

## Unggah file untuk pencarian [#upload-a-file-for-search]

Klik **+** di [message composer](/docs/features/composer) untuk membuka palet, perluas **More upload options**, lalu pilih **Upload for File Search** dan pilih file Anda. Mencari di palet juga bisa dilakukan. Mengunggah dengan cara ini juga mengaktifkan **File Search** untuk chat. File berukuran besar mungkin memerlukan waktu sejenak untuk diindeks; unggahan selesai setelah pengindeksan selesai.

Setelah percakapan mengindeks file, model akan mendapatkan alat `file_search`. Model memutuskan kapan memanggilnya: pertanyaan tentang dokumen akan memicu pencarian, sedangkan basa-basi tidak. Balasan menampilkan langkah "Searching your files" selama proses berjalan, dan ketika kutipan diaktifkan, bagian-bagian teks yang digunakan muncul di bawah **Sources** beserta nama file, sehingga Anda dapat membuka dokumen dan memeriksanya.

## Cara kerja pencarian [#how-search-works]

Ketika model memanggil `file_search`, model akan menulis sebuah kueri pencarian. LibreChat meminta RAG API untuk mengambil 5 chunk terdekat dari setiap file yang dilampirkan, lalu menyimpan 10 chunk terdekat secara keseluruhan. Chunk-chunk tersebut dikembalikan ke model beserta nama file dan skor relevansinya, kemudian model menjawab berdasarkan chunk-chunk tersebut.

Retrieval menemukan bagian teks yang maknanya dekat dengan kueri, sehingga efektif untuk mencari fakta spesifik dalam dokumen besar. Untuk pertanyaan yang memerlukan keseluruhan dokumen sekaligus, seperti ringkasan, Upload as Text biasanya memberikan hasil yang lebih baik.

Menghapus file di LibreChat juga menghapus vektornya dari RAG API.

## Gunakan kembali file yang sudah Anda unggah [#reuse-files-you-already-uploaded]

File yang diindeks tetap berada di akun Anda. Buka palet dan lihat di bawah **Your files** untuk melampirkannya ke pesan atau percakapan baru tanpa mengunggahnya lagi.

File yang diunggah saat endpoint Assistants aktif disimpan di OpenAI, tidak diindeks oleh RAG API, dan tidak dapat dilampirkan ke endpoint lain.

## Pencarian file di agen [#file-search-in-agents]

Untuk agen, aktifkan [**File Search**](/docs/features/agents#file-search) di Agent Builder dan unggah file di sana. File tersebut menjadi basis pengetahuan agen: setiap orang yang mengobrol dengan agen dapat meminta agen mencari di dalam file tersebut, tanpa perlu mengunggah apa pun sendiri. Agen harus disimpan terlebih dahulu sebelum Anda dapat menambahkan file ke dalamnya.

## Pencarian file atau unggah sebagai teks [#file-search-or-upload-as-text]

[**Upload as Text**](/docs/features/upload_as_text) berada di menu yang sama. Fitur ini mengekstrak teks dari file dan memasukkan seluruh teksnya ke dalam percakapan, yang cocok untuk dokumen pendek yang mengharuskan model membaca setiap kata. File search hanya mengirimkan bagian-bagian yang cocok dengan setiap kueri, sehingga dapat diskalakan untuk dokumen panjang dan banyak file, tetapi model tidak pernah melihat bagian-bagian yang tidak berhasil diambil.

API RAG juga menyediakan Upload as Text, sebagai ekstraktor teks untuk jenis file yang tidak dapat dibaca oleh parser bawaan. Lihat [cara teks diekstraksi](/docs/features/upload_as_text#how-the-text-is-extracted).

## Pengaturan [#setup]

Pencarian file memerlukan layanan RAG API dan basis data vektor. Pengaturan Docker default sudah menyertakan keduanya; seorang admin menetapkan penyedia embeddings dan, untuk instalasi lain, `RAG_API_URL`. Lihat [konfigurasi RAG API](/docs/configuration/rag_api), dan [repositori RAG API](https://github.com/LibreChat-AI/rag-api) untuk endpoint dan variabel milik layanan tersebut.
