Buka menu akun Anda dan pilih **Settings** untuk mengelola preferensi pribadi dan kontrol data LibreChat. Tab yang tersedia adalah General, Chat, Speech, Data & Privacy, dan Account, serta About jika ditampilkan oleh deployment. Gunakan **Search settings** untuk menemukan kontrol berdasarkan labelnya atau kata kunci terkait; memilih hasil akan membuka tab dan bagian yang sesuai. Tata letak pengaturan menyesuaikan diri dengan layar seluler tanpa menyembunyikan navigasi tab.

## Umum [#general]

**Display chat title in tab** menggunakan judul percakapan saat ini sebagai judul tab peramban. Fitur ini diaktifkan secara default dan disimpan di peramban saat ini. Matikan fitur ini untuk tetap menggunakan judul aplikasi deployment di setiap tab. Obrolan baru akan terus menggunakan judul aplikasi sampai mendapatkan judul percakapan yang sebenarnya.

**Format Jam** mengontrol apakah waktu menggunakan konvensi sistem, jam 12-jam, atau jam 24-jam. **Sistem** membaca lokal regional peramban saat ini alih-alih terjemahan LibreChat yang dipilih. Pilihan ini berlaku untuk stempel waktu pesan, kontrol dan ringkasan Obrolan Terjadwal, tanggal kedaluwarsa kunci dan pengisian ulang saldo, tanggal versi Agen dan prompt, memori, serta daftar obrolan proyek.

**Week Starts On** mengontrol apakah daftar hari dalam seminggu bergaya kalender mengikuti konvensi sistem, Minggu, atau Senin. Konvensi sistem dapat merujuk pada hari pertama regional lainnya, seperti Sabtu. Hal ini mengubah urutan kontrol hari dalam seminggu dan ringkasan untuk Obrolan Terjadwal tanpa mengubah hari apa saja jadwal tersebut dijalankan.

Kedua preferensi regional disimpan di peramban saat ini, sehingga perangkat yang berbeda dapat mengikuti lokalnya masing-masing atau penggantian eksplisit.

**Show chat beside the sidebar on mobile**, di bawah **Layout**, secara default tidak aktif. Saat diaktifkan, laci seluler akan berhenti pada 80% viewport dan menyisakan potongan percakapan saat ini agar tetap terlihat. Mengetuk potongan tersebut akan menutup laci. Preferensi ini disimpan di browser saat ini; lihat [Mobile Drawer](/docs/features/navigation#mobile-drawer).

Kontrol lain pada tab ini disimpan di peramban saat ini:

| Pengaturan | Fungsinya | Default |
|---|---|---|
| Skala UI | Menskalakan seluruh antarmuka antara 50% dan 150%. Zoom peramban tidak terpengaruh. | 100% |
| Ukuran Font Pesan | Ukuran teks pesan: Extra Small, Small, Medium, Large, atau Extra Large. | Medium |
| Arah Chat | Arah teks pada chat: Auto, kiri ke kanan, atau kanan ke kiri. Auto menentukan arah dari teks yang diketik. | Auto |
| Maksimalkan ruang chat | Memberi ruang lebih luas untuk percakapan di layar. | Off |
| Pusatkan Input Chat di Layar Selamat Datang | Memusatkan kolom input pada layar selamat datang chat baru. | On |
| Tombol gulir ke akhir | Menampilkan tombol yang langsung melompat ke pesan terbaru. | On |
| Biarkan layar tetap menyala saat respons dibuat | Meminta peramban untuk tidak meredupkan atau mengunci layar saat respons sedang dibuat. | On |
| Tampilkan Lia di Layar Selamat Datang | Menampilkan Lia, maskot piksel dekoratif, di sekitar kolom input pada layar selamat datang. Hanya muncul jika deployment mengizinkannya. | Off |

**Obrolan yang diarsipkan** berada di menu akun, bukan di tab ini; lihat [Percakapan yang Diarsipkan](/docs/features/navigation#archived-conversations).

### Notifikasi [#notifications]

Bagian **Notifications** mengontrol bagaimana LibreChat memberi tahu Anda tentang balasan yang selesai saat Anda berada di tempat lain:

- **Show unread count in the tab title** menampilkan jumlah percakapan dengan balasan yang belum dibaca pada judul dan ikon tab peramban. Fitur ini aktif secara default.
- **Beri tahu saya saat balasan tiba** akan menampilkan notifikasi desktop. Fitur ini dinonaktifkan secara default, dan mengaktifkannya akan meminta izin notifikasi peramban. Notifikasi hanya muncul saat Anda tidak sedang membuka LibreChat, karena daftar obrolan sudah menandai balasan saat Anda sedang melihatnya.
- **Play a sound for new replies** akan memutar bunyi denting singkat saat balasan tiba ketika Anda sedang tidak berada di depan layar. Fitur ini dinonaktifkan secara default. Peramban memblokir audio hingga Anda berinteraksi dengan halaman tersebut, sehingga denting pertama setelah membuka tab mungkin tidak akan berbunyi.

Preferensi ini disimpan per perangkat, sehingga laptop dan ponsel bisa berbeda; status belum dibaca itu sendiri tersinkronisasi di seluruh perangkat (lihat [Balasan Belum Dibaca](/docs/features/navigation#unread-replies)). Seorang administrator dapat mematikan salah satunya untuk deployment dengan [`interface.replyNotifications`](/docs/configuration/librechat_yaml/object_structure/interface#replynotifications), yang akan menyembunyikan tombol pengalih tersebut.

## Chat [#chat]

**Switch to Chat History on new chat**, di bawah **Conversations**, aktif secara default dan disimpan di browser saat ini. Memulai chat baru dari sidebar saat panel lain, seperti Prompts atau Memories, sedang terbuka akan mengalihkan sidebar kembali ke daftar chat. Matikan fitur ini untuk tetap berada di panel saat ini.

**Gulir Otomatis ke pesan terbaru saat chat dibuka** diaktifkan secara default dan memindahkan percakapan yang baru dibuka ke pesan terbaru yang ditampilkan. Nonaktifkan opsi ini untuk mempertahankan posisi gulir saat ini ketika kembali ke chat. LibreChat menunggu baris percakapan target selesai ditampilkan sebelum mendarat, termasuk ketika navigasi dan pemuatan pesan selesai pada waktu yang berbeda.

**Ubah ukuran gambar sebelum diunggah** memungkinkan pengguna memperkecil ukuran file JPEG, PNG, dan WebP berukuran besar di browser sebelum mengirimkannya. Preferensi ini diaktifkan secara default dan disimpan di browser saat ini.

Administrator mengontrol apakah ini tetap menjadi pilihan pribadi. Jika [`fileConfig.clientImageResize.enabled`](/docs/configuration/librechat_yaml/object_structure/config#clientimageresize) secara eksplisit diatur ke `true` atau `false`, LibreChat akan memberlakukan nilai tersebut dan mengunci tombol pilihan pengguna. Jika kolom tersebut dihilangkan, pengaturan pengguna yang akan berlaku.

**Tempel teks panjang sebagai file** diaktifkan secara default dan disimpan di browser saat ini. Ketika unggahan konteks Upload as Text tersedia, menempelkan lebih dari 2.500 karakter di penyusun pesan normal akan melampirkan teks tersebut sebagai `pasted-text.txt` alih-alih mengisi input. Tempelan yang lebih pendek dan tempelan yang dibuat tanpa kapabilitas `context` akan tetap berada di dalam baris (inline). Lihat [Upload Files as Text](/docs/features/upload_as_text#paste-long-text-as-a-file).

**Ciutkan pesan pengguna yang panjang** diaktifkan secara default. Jika diaktifkan, pesan pengguna yang tingginya lebih dari 256 piksel akan ditampilkan sebagai pratinjau ringkas dengan kontrol **Show more** dan **Show less**. Penciutan ini hanya bersifat visual: pesan lengkap tetap tersedia untuk disalin, dicari melalui pencarian browser, dan dapat diakses oleh teknologi bantu.

**Parsing LaTeX in messages** diaktifkan secara default. Tombol pengalih ini mengontrol bentuk matematika inline `$...$` dengan tanda dolar tunggal yang ambigu, yang mengikuti aturan batas untuk menjaga teks seperti mata uang, contohnya `$50`, tetap literal. Bentuk matematika `$$...$$`, `\(...\)`, dan `\[...\]` yang tidak ambigu tetap didukung saat tombol pengalih dimatikan. Kode inline, kode yang dibatasi (fenced code), dan tautan otomatis tidak diinterpretasikan sebagai matematika dengan tanda dolar tunggal.

Tombol kirim dijelaskan dalam [composer](/docs/features/composer#keyboard-shortcuts). Kontrol lain pada tab ini disimpan di peramban saat ini:

| Pengaturan | Fungsinya | Default |
|---|---|---|
| Tekan Enter untuk mengirim pesan | Saat aktif, Enter mengirim pesan. Saat nonaktif, Enter menyisipkan baris baru dan Ctrl/Cmd+Enter mengirim pesan. | Aktif |
| Saat sedang menghasilkan, Enter akan | Tindakan pengiriman saat respons sedang di-stream: Steer, Interrupt, atau Queue. Lihat [Steering and Queued Messages](/docs/features/agents#steering-and-queued-messages). | Steer |
| Simpan draf secara lokal | Menyimpan teks dan lampiran yang belum terkirim sebagai draf di perangkat ini, dan menghapusnya setelah pesan terkirim. | Aktif |
| Simpan status badge | Menyimpan badge obrolan (alat) seperti saat Anda memulai obrolan baru, alih-alih mengaturnya ulang. | Nonaktif |
| Aktifkan perintah "@" untuk beralih endpoint, model, preset, dll. | Mengaktifkan atau menonaktifkan perintah `@`. | Aktif |
| Aktifkan perintah "+" untuk menambahkan pengaturan multi-respons | Mengaktifkan atau menonaktifkan perintah `+`. Hanya ditampilkan saat multi-respons tersedia. | Aktif |
| Aktifkan perintah "/" untuk memilih prompt melalui keyboard | Mengaktifkan atau menonaktifkan perintah `/`. Hanya ditampilkan saat prompt tersedia. | Aktif |
| Render pesan pengguna sebagai markdown | Merender pesan Anda sendiri sebagai Markdown. | Aktif |
| Tampilkan nama pengguna di pesan | Menampilkan nama pengguna Anda di atas pesan alih-alih "You". | Aktif |
| Buka dropdown Thinking secara default | Memperluas blok penalaran model alih-alih menciutkannya. | Nonaktif |
| Perluas otomatis detail alat | Memperluas detail pemanggilan alat secara default. | Nonaktif |
| Editor prompt lanjutan | Mengaktifkan versioning dan kontrol produksi untuk prompt. | Nonaktif |
| Selalu jadikan versi prompt baru sebagai produksi | Menandai setiap versi prompt baru sebagai versi produksi. Menonaktifkan editor prompt lanjutan akan mengembalikannya ke aktif. | Aktif |
| Kirim prompt saat dipilih | Mengirimkan prompt ke obrolan segera setelah Anda memilihnya. | Aktif |
| Aktifkan pergantian Endpoint di tengah percakapan | Memungkinkan Anda mengubah endpoint atau model dalam satu percakapan. | Aktif |

Input dan pemutaran suara berada di tab **Speech**; lihat [Speech Settings](/docs/configuration/stt_tts).

## Parameter Model [#model-parameters]

Panel **Parameters** model di panel samping mengelompokkan pengaturan percakapan di bawah judul: **Identity**, **Sampling**, **Limits**, **Reasoning**, **Context**, **Advanced**, dan **Misc.** Hanya bagian yang digunakan oleh endpoint saat ini yang akan muncul, dan pengaturan yang tidak dikenali oleh panel, seperti parameter milik endpoint kustom, akan dicantumkan di bawah **Misc.** Sebuah judul menunjukkan berapa banyak pengaturan di bagian tersebut yang telah diubah dalam percakapan, sehingga Anda dapat melihat apa yang berbeda sebelum memilih **Reset**. **Reset** dan **Save As Preset** terletak bersamaan di bagian bawah panel. Lihat [Presets](/docs/user_guides/presets).

## Pintasan Papan Tik [#keyboard-shortcuts]

Buka **Keyboard Shortcuts** dari menu akun untuk meninjau atau menyesuaikan pintasan. Tombol **Keyboard Shortcuts** diaktifkan secara default. Mematikannya akan menonaktifkan setiap pintasan dan menghapus petunjuk pintasan dari antarmuka sembari tetap menyimpan pintasan yang telah disesuaikan. Buka dialog yang sama dari menu akun untuk mengaktifkan kembali pintasan.

Pengaktifan pintasan dan pengikatan kustom disimpan di peramban saat ini. Baris pengikatan tetap terlihat saat pintasan dimatikan, namun kontrol penyuntingan dan pengaturan ulang tetap dinonaktifkan sampai pintasan diaktifkan kembali.

## Data & Privacy [#data--privacy]

Tab **Data & Privacy** dibagi menjadi beberapa bagian:

- **Memori**: **Referensikan memori tersimpan** memungkinkan asisten menggunakan memori tersimpan Anda saat merespons. Memori ini disimpan ke akun Anda dan hanya muncul ketika preferensi memori berlaku untuk deployment Anda.
- **Eksekusi kode**: **Ruang kerja stateful default** memilih cakupan ruang kerja yang diusulkan untuk Agent yang baru dibuat. Opsi ini hanya muncul jika Sesi Kode Stateful tersedia; mengubahnya tidak mengaktifkan sesi stateful ataupun mengubah Agent yang sudah ada. **Lingkungan kode** memasangkan pekerja sandbox yang berjalan pada VM yang Anda kendalikan, dengan kondisi ketersediaan yang sama.
- **Data Anda**: **Kelola file** membuka pengelola file yang telah diunggah. **Impor percakapan** mengimpor ekspor percakapan yang didukung. **Obrolan bersama** menampilkan dan mengelola tautan percakapan yang telah dipublikasikan. **Arsipkan semua obrolan** memindahkan percakapan aktif ke **Obrolan yang diarsipkan** setelah konfirmasi tanpa menghapusnya. **Izinkan analitik** mengubah jawaban Anda atas permintaan analitik dan hanya muncul jika penerapan telah mengonfigurasi analitik.
- **Kunci API**: **Kunci API penyedia** mengelola kunci yang disediakan untuk penyedia yang telah dikonfigurasi dan hanya muncul ketika sebuah endpoint menerima kunci yang disediakan pengguna. **Kunci API agen** mengelola kunci untuk Agents API dan hanya muncul ketika agen jarak jauh tersedia. **Cabut semua kunci API penyedia** menghapus setiap kunci penyedia yang disediakan pengguna.
- **Zona berbahaya**: **Hapus cache** menghapus audio text-to-speech yang disimpan dalam cache di browser; opsi ini tidak tersedia ketika cache kosong. **Hapus semua chat** secara permanen menghapus percakapan pengguna setelah konfirmasi.

Tindakan penghapusan data dan pencabutan kunci didukung oleh server dan bisa bersifat permanen. Preferensi dan cache khusus browser hanya berlaku untuk profil browser saat ini, bukan untuk setiap perangkat.

## Akun [#account]

Tab **Account** berisi kontrol profil, keamanan, penagihan, dan penghapusan. Beberapa di antaranya hanya muncul jika deployment mendukungnya:

| Pengaturan | Fungsinya |
|---|---|
| Avatar | Mengubah foto profil Anda. |
| Kode cadangan | Menampilkan dan membuat ulang kode cadangan autentikasi dua faktor. Hanya muncul saat autentikasi dua faktor diaktifkan. |
| Saldo token | Menampilkan kredit token Anda. Hanya muncul saat pelacakan saldo diaktifkan. |
| Isi ulang otomatis | Menampilkan atau mengonfigurasi pengisian ulang saldo otomatis. Hanya muncul saat pelacakan saldo diaktifkan. |
| Hapus akun | Menghapus akun dan data Anda secara permanen. Hanya muncul saat deployment mengizinkan penghapusan akun. |
