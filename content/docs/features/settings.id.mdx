Buka menu akun dan pilih **Settings**. Dialog ini memiliki tab untuk **General**, **Chat**, **Speech**, **Data & Privacy** dan **Account**, serta **Langfuse** dan **About** pada deployment yang menyediakannya. Jika Anda sudah memiliki gambaran kasar tentang apa yang ingin diubah, ketikkan di **Search settings**: pencarian ini mencocokkan label dan kata-kata terkait ("dark", "rtl", "paste") dan langsung membawa Anda ke tab serta bagian yang tepat.

Sebagian besar preferensi disimpan di peramban saat ini, bukan di akun Anda. Pengaturan yang diubah di laptop Anda tidak akan mengikuti Anda ke ponsel. Pengecualiannya dijelaskan di bawah ini.

### Notifikasi [#notifications]

Ini mengatur cara Anda diberi tahu tentang balasan yang selesai saat Anda berada di chat lain atau tab lain:

- **Tampilkan jumlah pesan belum dibaca di judul tab** menampilkan jumlah percakapan yang memiliki balasan belum dibaca di judul dan ikon tab. Aktif secara default.
- **Beri tahu saya saat balasan tiba** menampilkan notifikasi desktop. Nonaktif secara default. Browser Anda akan meminta izin saat pertama kali Anda mengaktifkannya, dan tidak ada notifikasi yang ditampilkan saat Anda sedang melihat LibreChat.
- **Mainkan suara untuk balasan baru** memutar nada singkat. Nonaktif secara default. Browser memblokir audio hingga Anda mengklik sesuatu di halaman, sehingga nada pertama setelah membuka tab mungkin tetap senyap.

Sakelar ini bersifat per perangkat; status belum dibaca itu sendiri disimpan ke akun Anda (lihat [Unread Replies](/docs/features/navigation#unread-replies)). Jika salah satu sakelar ini tidak tersedia, administrator Anda telah mematikannya melalui [`interface.replyNotifications`](/docs/configuration/librechat_yaml/object_structure/interface#replynotifications).

## Ucapan [#speech]

Aktifkan atau nonaktifkan **Speech to Text** dan **Text to Speech**, pilih mesin, bahasa dan suara, atur kecepatan pemutaran, dan tentukan apakah balasan diputar secara otomatis. Mesin mana yang muncul bergantung pada pengaturan yang dilakukan oleh deployment, lihat [Speech to Text dan Text to Speech](/docs/configuration/stt_tts).

## Data & Privacy [#data--privacy]

- **Memori**: **Referensikan memori tersimpan** memungkinkan asisten menggunakan [memori](/docs/features/memory) Anda. Disimpan ke akun Anda, sehingga berlaku di setiap perangkat.
- **Eksekusi kode**: **Workspace stateful default** dan **Lingkungan kode**, ketika deployment menyediakan sesi kode stateful.
- **Data Anda**: **Impor percakapan**, **Obrolan bersama** (kelola [tautan bersama](/docs/features/shareable_links) Anda), **Kelola file**, **Arsipkan semua obrolan**, dan **Izinkan analitik** jika deployment mengumpulkan analitik. **Arsipkan semua obrolan** memindahkan setiap obrolan aktif ke [Obrolan yang diarsipkan](/docs/features/navigation#archived-conversations) tanpa menghapus apa pun.
- **Kunci API**: **Kunci API penyedia** untuk endpoint yang meminta kunci milik Anda sendiri, **Kunci API Agent** untuk Agents API, dan **Cabut semua kunci API penyedia**.
- **Zona berbahaya**: **Hapus cache** menghapus audio text-to-speech yang disimpan dalam cache di browser ini. **Hapus semua chat** menghapus percakapan Anda secara permanen.

## Akun [#account]

**Avatar** dan, untuk login email jika diizinkan, **Alamat email**. Di bawah **Security**: **Two-factor authentication**, **Backup codes** setelah two-factor diaktifkan, dan **Passkeys** jika deployment mendukungnya. **Pull request account** menghubungkan GitHub atau git host lain untuk [pull requests](/docs/features/pull_requests). **Token balance** dan **Auto-refill** muncul ketika deployment melacak saldo, dan **Delete account** ketika deployment mengizinkan pengguna menghapus akunnya sendiri.

## Pintasan Papan Tik [#keyboard-shortcuts]

Buka menu akun dan pilih **Help**, lalu **Keyboard Shortcuts** (atau tekan <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>/</kbd>). Klik sebuah baris untuk merekam kombinasi baru; kombinasi tersebut harus menyertakan <kbd>Cmd</kbd>, <kbd>Ctrl</kbd> atau <kbd>Alt</kbd>, dan LibreChat akan memberi peringatan jika tindakan lain sudah menggunakannya. **Reset all to defaults** membatalkan semua perubahan Anda. Baris-baris di bawah **Open panels** (agents, prompts, memories, parameters, files, bookmarks, MCP settings) tidak memiliki tombol pintas sampai Anda menetapkannya.

Sakelar **Keyboard Shortcuts** di bagian atas menonaktifkan semua pintasan dan menyembunyikan petunjuk di antarmuka. Kunci kustom Anda tetap disimpan untuk digunakan saat Anda mengaktifkannya kembali. Baik sakelar maupun pengikatan Anda disimpan di browser ini.
