title: 共有リンク
icon: Share2
description: LibreChatの共有リンク機能を使用して会話を他のユーザーと共有しましょう。QRコード、メッセージの分岐、アーティファクトのサポートも完備しています。
---

共有リンクを使用すると、会話の読み取り専用ブランチを公開でき、他のユーザーは生成されたURLやQRコードからその会話を開くことができます。受信者は、元の会話を変更することなく、公開されたメッセージ、ブランチ、およびアーティファクトを閲覧できます。サインインしている受信者は、表示されているブランチから個人のコピーとして会話を継続できます。

## 主な機能 [#key-features]

- **簡単な共有**: 数クリックでリンクを生成できます。
- **QR codes**: スマートフォンでコードをスキャンして会話を開きます。
- **ブランチング**: 共有リンクは、会話のすべてのブランチを保持します。
- **Artifacts**: Reactコンポーネント、HTMLプレビュー、およびMermaidダイアグラムはインタラクティブな状態を維持します。
- **File snapshots**: 共有リンクから参照された会話ファイルは、受信者に所有者のライブファイルACLへのアクセス権を付与することなく、プレビューまたはダウンロードが可能です。
- **コピーとして続行**: サインインしている閲覧者は、表示されているブランチを自身の会話履歴にコピーし、チャットを続行できます。
- **受信者の設定**: ビューアーは言語とテーマを切り替えることができます。
- **安定したアップデート**: URLを変更することなく、新しいターンと現在のファイル選択を公開します。
- **共有バッジ**: アクティブなリンクは、会話リストおよびチャットヘッダーにマークされます。
- **リンク管理**: 作成したすべてのリンクを確認または取り消しできる単一のダッシュボード。

## Share Link Options [#share-link-options]

リンクを作成すると、受信者に対する会話の表示方法を制御できるモーダルが開きます。

![共有リンク作成モーダル](/images/shared-links/share-modal-create.png)

![管理オプション付きの共有リンクモーダル](/images/shared-links/share-modal-options.png)

リンクが作成されると、モーダルで以下の操作が可能になります：

- **Update link**: 選択したブランチの末尾と現在のファイル共有の選択を通じて最新のメッセージを再公開し、同じURLを維持します。
- **Show QR Code** / **Hide QR Code**: モバイルからアクセスするためのQRコードを表示または非表示に切り替えます。
- **リンクをコピー**: 共有可能な URL をコピーします。
- **アクセスを管理**: リンクを開けるユーザーを制御するアクセスダイアログを開きます。このボタンは、共有リンクに対する共有権限がロールに付与されており、そのリンクに対する共有ビットを保有している場合にのみ表示されます。
- **削除リンク**: リンクを削除し、リンクを持つすべてのユーザーのアクセス権を取り消します。

ファイルスナップショットが有効な場合、ユーザーは共有されたメッセージ内で参照されているファイルを含めるかどうかを選択できます。選択されたファイルはその共有リビジョンに固定され、所有者のライブファイルACLへのアクセス権を付与することなく、共有専用のルートを通じて提供されます。リンクを更新すると、固定されたセットとファイル共有の選択が置き換えられます。安定したファイルURLは再検証されるため、削除または置き換えられたスナップショットが古いブラウザキャッシュから提供されることはありません。

公開は、選択されたブランチの正確に永続化された末尾に紐付けられます。最新のメッセージがまだ保存中の場合、LibreChatは別のブランチに切り替えることなく一度だけ再試行します。末尾がまだ利用できない場合、または会話に永続化されたメッセージがまだ存在しない場合、モーダルに特定のエラーが表示されるため、待機してから再試行することができます。利用できない共有リンクのビューでも、同じURLを再取得するための**Retry**（再試行）が提供されます。

## QRコード [#qr-codes]

共有された会話のQRコードを生成し、スマートフォンのカメラでスキャンしてリンクを開くことができます。このコードは、共有URLと同じリンク先を指しています。

![共有リンク用に生成されたQRコード](/images/shared-links/qr-code.png)

![QR code download options](/images/shared-links/qr-code-download.png)

QRコードは、プレゼンテーション、モバイルからのクイックアクセス、配布資料、カンファレンスでのデモなどに便利です。

## 共有された会話の表示 [#viewing-shared-conversations]

誰かがあなたのリンクを開くと、日付、メッセージ、アーティファクトを含む、公開されたブランチのフォーカスされた読み取り専用ビューが表示されます。

![受信者から見た共有会話](/images/shared-links/shared-view.png)

## 共有された会話を継続する [#continue-a-shared-conversation]

認証された閲覧者は、**Continue this chat**を選択することで、現在表示されているブランチから個人の会話を作成できます。LibreChatは、アクティブなメッセージへの直接パスのみをコピーし（対象となるスナップショットされたファイル参照を含みます）、閲覧者のアカウントで新しい会話を開きます。

継続しても、共有スナップショットや所有者の会話が変更されることはありません。公開閲覧者は、LibreChatがそのコピーを作成する前にサインインする必要があります。

コピーリクエストは、閲覧者が読み込んだ共有リビジョンに紐付いています。閲覧者が操作を続行する前に所有者が同じリンクを更新した場合、LibreChatは古いコンテンツからメッセージの位置をコピーするのではなく、現在のリビジョンを再読み込みし、閲覧者に再試行を促します。

## ブランチング [#branching]

共有リンクは会話のブランチを保持するため、受信者は議論がたどったさまざまなパスを追跡できます。ブランチナビゲーション矢印を使用して、それらの間を移動してください。

![共有された会話内のブランチナビゲーションメニュー](/images/shared-links/branching-menu.png)

![共有された会話でのブランチの移動](/images/shared-links/branching-support.png)

これは、異なるプロンプトがどのように異なるAIの応答を導き出すか、あるいは一つの問題に対してどのように複数のアプローチが可能かを示すのに役立ちます。

## Artifacts [#artifacts]

会話中に生成されたArtifactsは、共有リンク内でも完全に機能します。

![共有された会話内のインタラクティブなアーティファクト](/images/shared-links/artifacts-support.png)

受信者は以下が可能です：

- インタラクティブなReactコンポーネントを表示します。
- HTMLプレビューを参照してください。
- Mermaid図を確認します。
- 基盤となるコードと、それが生成されたコンテキストを読み取ります。

## 受信者の設定 [#recipient-preferences]

閲覧者は、あなたの設定に影響を与えることなく、インターフェースを自分好みに調整できます。

![共有リンクでの言語とテーマの設定](/images/shared-links/recipient-settings.png)

- **テーマ**: ライト、ダーク、またはシステム。
- **Language**: インターフェースを好みの言語で表示します。

## 共有リンクの管理 [#managing-your-shared-links]

**Settings > Data & Privacy > Your data > Shared chats** にある **Shared chats** ダッシュボードを開くと、共有したすべての会話を確認できます。

![共有リンク管理ダッシュボード](/images/shared-links/management-modal.png)

![個別の共有リンクの詳細とオプション](/images/shared-links/management-details.png)

ダッシュボードから以下の操作が可能です：

- **すべてのリンクを表示**: 共有したすべての会話を確認できます。
- **検索とフィルタリング**: 特定の共有リンクを検索し、その内容をプレビューします。
- **アクセス権の取り消し**: リンクを削除して、共有を直ちに停止します。

共有リンクが有効な会話には、サイドバーにリンクバッジが表示され、チャットヘッダーの共有コントロールにも同じアクティブ状態が表示されます。

## 設定 [#configuration]

`.env` ファイル内の3つの環境変数がこの機能を制御します：

- **`ALLOW_SHARED_LINKS`** (デフォルト: `true`): 共有リンク機能を有効にします。ユーザーによるリンク作成を停止するには `false` に設定してください。
- **`ALLOW_SHARED_LINKS_PUBLIC`** (デフォルト: `false`): 認証なしでリンクを開けるかどうかを制御します。デフォルトでは、受信者はログインしている必要があります。公開され、認証されていないアクセスを許可するには `true` に設定してください。
- **`SHARED_LINKS_SNAPSHOT_FILES`** (デフォルト: `true`): 共有リンクに参照された会話ファイルを含めることができるかどうかを制御します。この環境変数が設定されている場合、[`interface.sharedLinks.snapshotFiles`](/docs/configuration/librechat_yaml/object_structure/interface#sharedlinks) よりも優先されます。

```bash title=".env"
# Enable shared links (default)
ALLOW_SHARED_LINKS=true

# Require authentication to view shared links (default)
ALLOW_SHARED_LINKS_PUBLIC=false

# Include referenced files in shared-link snapshots (default)
SHARED_LINKS_SNAPSHOT_FILES=true
```

ロール権限によって、どのユーザーがリンクを作成し、認証済みユーザーと共有したり、インスタンス上の全員に公開したりできるかを決定します。

```yaml title="librechat.yaml"
interface:
  sharedLinks:
    create: true
    share: true
    public: false
    snapshotFiles: true
```

`sharedLinks.public` は、ユーザーが「全員と共有」を切り替えられるかどうかを制御します。`ALLOW_SHARED_LINKS_PUBLIC` は、それらの公開リンクがログインなしで閲覧可能かどうかを引き続き決定します。`sharedLinks.snapshotFiles` は YAML からのデフォルトのファイルスナップショット動作を制御し、`SHARED_LINKS_SNAPSHOT_FILES` はそれをグローバルに上書きまたは無効化できます。

<Callout type="info">
環境変数の完全なリファレンスについては、[.env Configuration](/docs/configuration/dotenv#shared-links) ページを参照してください。
</Callout>

## よくある質問 [#frequently-asked-questions]

<Accordions type="single" collapsible>
<Accordion title="共有された会話に受信者は返信できますか？">

共有されたスナップショットは読み取り専用のままです。サインインしている受信者は、**Continue this chat** を選択して個人的なコピーを作成し、そこでAIと対話することができます。

</Accordion>
<Accordion title="共有した後に会話を削除するとどうなりますか？">

リンクが機能しなくなります。そのリンクにアクセスしたユーザーには「Shared link not found」ページが表示されます。

</Accordion>
<Accordion title="共有した後に会話を編集することはできますか？">

はい。リンクに既に含まれているメッセージへの編集は、共有ビューに反映されます。公開されたブランチの末尾以降の新しいターンは、**Update link**を選択した後にのみ表示されます。URLは変わりません。

</Accordion>
<Accordion title="共有リンクはオフラインでも機能しますか？">

いいえ。共有された会話を閲覧するには、受信者にインターネット接続が必要です。

</Accordion>
</Accordions>
