Le compositeur est la zone située en bas de chaque conversation. À côté du champ de texte se trouvent un bouton **+** pour les fichiers, les outils, les compétences et les serveurs MCP, une puce pour chaque outil que vous avez activé, ainsi que les commandes de niveau de raisonnement, de dictée et d'envoi.

Cliquez sur **+** (les lecteurs d'écran annoncent **Joindre et outils**) pour ouvrir la palette. Tout ce qu'elle contient est consultable depuis le champ en haut, donc taper quelques lettres est généralement plus rapide que faire défiler la liste.

## Ajouter des fichiers [#add-files]

Choisissez **Depuis l'ordinateur local** dans la section **Joindre**, faites glisser les fichiers vers le compositeur ou collez-les. LibreChat détermine comment chaque fichier parvient au modèle (envoyé directement au fournisseur, extrait sous forme de texte ou indexé pour la recherche de fichiers) en fonction du type de fichier et de l'endpoint ; vous indiquez donc uniquement l'origine du fichier. **Depuis SharePoint** apparaît à côté lorsque votre administrateur a connecté SharePoint.

Certains déploiements utilisent l'ancien outil de téléversement, dans lequel vous choisissez vous-même la destination : **Téléverser vers le fournisseur** (ou **Téléverser une image** pour les fournisseurs qui n'acceptent que les images), **Téléverser en tant que texte**, **Téléverser pour la recherche de fichiers** et **Téléverser vers l'environnement de code**. La première option est affichée, les autres se trouvent sous **Plus d'options de téléversement**. Le choix de **Téléverser pour la recherche de fichiers** ou de **Téléverser vers l'environnement de code** active également cet outil.

### Réutiliser un fichier que vous avez déjà téléchargé [#reuse-a-file-you-uploaded-before]

**Vos fichiers** dans la palette affiche vos fichiers utilisés le plus récemment (cinq par défaut). Sélectionnez-en un pour le joindre à nouveau sans le télécharger. La saisie dans le champ de recherche effectue une recherche parmi tous vos fichiers par nom, et **Afficher tout** ouvre une boîte de dialogue contenant tous les fichiers, répartis entre **Tous**, **Images** et **Documents**, avec des aperçus pour les images et les PDF.

## Activer les outils, les compétences et les serveurs MCP [#turn-on-tools-skills-and-mcp-servers]

Sous **Attach**, la palette regroupe les éléments que vous pouvez ajouter à la conversation :

- **Outils** : outils intégrés tels que **Recherche Web**, **Exécuter du code**, **Recherche de fichiers**, **Compétences**, **Mémoire** et **Artefacts**. Vous ne voyez que ceux qui sont activés et auxquels vous avez accès.
- **Compétences** : [skills](/docs/features/skills) à joindre à votre prochain message.
- **Serveurs MCP** : les [serveurs MCP](/docs/features/mcp) disponibles dans le chat, chacun avec son statut de connexion.

Sélectionner un outil ou un serveur MCP l'active ou le désactive, et la palette reste ouverte afin que vous puissiez en basculer plusieurs d'un seul coup. Chaque outil activé affiche une puce dans la zone de saisie ; supprimez la puce pour le désactiver. Certaines puces disposent de leur propre menu, par exemple le mode de génération pour **Artifacts**.

La sélection d'une compétence fonctionne différemment : elle est préparée pour votre prochain message (voir [Contexte préparé](#staged-context)) au lieu de devenir une puce.

Si un serveur MCP n'est pas encore connecté, le sélectionner lance la connexion, y compris une connexion OAuth lorsque le serveur en a besoin. Les serveurs qui nécessitent vos propres identifiants les demandent d'abord, puis conservent sur la ligne un bouton **Configure** pour vous permettre de les modifier par la suite.

Lorsqu'un agent est sélectionné, les sections **Tools** et **MCP Servers** disparaissent, car la configuration propre à l'agent détermine les outils qu'il utilise. Il en va de même pour les Assistants.

### Afficher tout et les favoris [#show-all-and-favorites]

Chaque section affiche jusqu'à cinq lignes. **Tout afficher** dans l'en-tête **Compétences**, **Serveurs MCP** ou **Vos fichiers** ouvre la liste complète avec la recherche et les filtres ; les compétences et les serveurs peuvent être filtrés par **Créés par vous** ou **Favoris**.

Pour ajouter une ligne aux favoris, mettez-la en surbrillance et appuyez sur <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd> sur macOS). Les favoris remontent en haut de la palette et sont enregistrés dans votre compte.

Votre administrateur peut également épingler des outils intégrés. Un outil épinglé conserve sa puce sur la zone de saisie même lorsqu'il est désactivé, ce qui permet d'y accéder en un seul clic. Supprimer la puce d'un outil épinglé désactivé le désépingle pour vous.

## Contexte mis en scène [#staged-context]

Tout ce que vous joignez à votre prochain message apparaît au-dessus du champ de texte avant l'envoi :

- Fichiers, avec progression du téléversement et aperçu de l'image.
- Longs collages. Lorsque [Upload as Text](/docs/features/upload_as_text#pasting-long-text) est disponible, coller plus de 2 500 caractères joint le texte sous forme de `pasted-text.txt` au lieu de remplir la zone de saisie. Sélectionnez-le pour modifier le texte dans une boîte de dialogue plus grande, ou choisissez **Move back into message** pour le replacer dans le champ de texte. Désactivez cette option avec **Paste long text as a file** dans **Settings > Chat**.
- Extraits que vous avez cités depuis des messages précédents avec **Ajouter au chat** (voir [Citer des extraits](/docs/features/message_actions#quote-excerpts)).
- Compétences que vous avez choisies dans la palette ou avec `$`.

Supprimez tout ce que vous ne souhaitez plus envoyer avant d'envoyer le message ; tout ce qui reste est envoyé avec le message. Vous pouvez envoyer des fichiers seuls, sans rien saisir.

## Réflexion [#thinking]

Sur les modèles dotés d'un paramètre de raisonnement, le contrôle **Thinking** ouvre un curseur allant de **Faster** à **Smarter**, ainsi que les modes distincts proposés par le fournisseur, tels que **Auto**. Il modifie la même valeur que le panneau Parameters. Si le modèle ne dispose pas de paramètre de raisonnement, ou si votre administrateur a masqué les paramètres, le contrôle n'est pas affiché.

## Mettre en file d'attente et piloter pendant la diffusion d'une réponse [#queue-and-steer-while-a-response-streams]

Vous pouvez continuer à taper pendant qu'une réponse est en cours de diffusion. Ce que fait l'envoi à ce moment dépend de la valeur par défaut que vous avez définie sous **While generating, Enter will** dans **Settings > Chat** (voir [Personal Settings](/docs/features/settings#chat)) :

- File d'attente : le message attend et est envoyé lorsque la réponse se termine.
- Steer : la réponse en cours prend en compte votre message au prochain point sûr, sans annuler les outils ni le raisonnement.
- Interruption : les outils actifs et le raisonnement sont annulés, la sortie déjà produite est conservée, et la réponse se poursuit avec votre message.

Pour savoir comment fonctionne la direction (steering) avec les agents, et quand elle est disponible, consultez [Direction et messages en file d'attente](/docs/features/agents#steering-and-queued-messages).

Les messages en file d'attente patientent dans une liste **Messages en file d'attente** au-dessus du compositeur. Pour chacun d'entre eux, vous pouvez cliquer sur **Envoyer maintenant**, **Supprimer le message**, ou ouvrir **Plus d'options** pour **Modifier le message** (le renvoie dans le champ de texte), **Démarrer dans une nouvelle conversation**, ou **Désactiver la file d'attente** afin qu'il ne soit pas envoyé automatiquement. Faites glisser les messages pour les réordonner, ou placez le focus sur l'un d'eux et utilisez les touches fléchées haut et bas.

## Raccourcis clavier [#keyboard-shortcuts]

### Dans le champ de texte [#in-the-text-field]

Le tableau suppose que l'option **Appuyer sur Entrée pour envoyer les messages** est activée, ce qui est la valeur par défaut. Lorsqu'elle est désactivée, <kbd>Entrée</kbd> ajoute un saut de ligne et <kbd>Ctrl</kbd>+<kbd>Entrée</kbd> envoie le message.

| Touches | Action |
|---|---|
| <kbd>Enter</kbd> | Envoyer. Pendant qu'une réponse est en cours de génération, exécute votre choix **While generating, Enter will**. |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Nouvelle ligne. |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) | Nouvelle ligne. Pendant qu'une réponse est en cours de génération, l'autre action : envoyer immédiatement si <kbd>Enter</kbd> met en file d'attente, mettre en file d'attente si <kbd>Enter</kbd> oriente ou interrompt. |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> (<kbd>Option</kbd>+<kbd>Enter</kbd>) | Pendant qu'une réponse est en cours de génération : interrompre avec votre message, lorsque l'exécution le permet. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd>) | Identique à <kbd>Alt</kbd>+<kbd>Enter</kbd>. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>) | Arrêter la réponse. |
| `/` | Insérer un prompt enregistré. |
| `@` | Changer de modèle, de préréglage ou d'agent. |
| `+` | Ajouter un autre modèle ou préréglage pour une réponse côte à côte. |
| `$` | Choisir une compétence pour le prochain message. |

Vous pouvez reconfigurer ou désactiver les raccourcis clavier depuis le menu du compte ; voir [Raccourcis clavier](/docs/features/settings#keyboard-shortcuts).

### Dans la palette [#in-the-palette]

| Touches | Action |
|---|---|
| Taper | Rechercher des outils, des compétences, des serveurs, des options de téléversement et des fichiers. |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Se déplacer entre les lignes. |
| <kbd>Enter</kbd> | Sélectionner la ligne en surbrillance. |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd>) | Ajouter ou retirer des favoris la ligne en surbrillance. |
| <kbd>Backspace</kbd> sur une recherche vide, ou <kbd>Escape</kbd> | Fermer la palette. |

## Configuration [#setup]

Le compositeur ne nécessite aucune configuration. Les administrateurs contrôlent ce qui y apparaît : l'ancien outil de téléversement avec [`fileConfig.legacyFileUploadUX`](/docs/configuration/librechat_yaml/object_structure/file_config#legacyfileuploadux), le nombre de fichiers récents avec [`interface.composerRecentFiles`](/docs/configuration/librechat_yaml/object_structure/interface#composerrecentfiles), les outils épinglés avec [`interface.defaultPinnedTools`](/docs/configuration/librechat_yaml/object_structure/interface#defaultpinnedtools), et SharePoint via [l'intégration SharePoint](/docs/configuration/sharepoint). Une [spécification de modèle](/docs/configuration/librechat_yaml/object_structure/model_specs#hidebadgerow) avec `hideBadgeRow` masque les sections d'outils pour cette spécification.
