Le compositeur de messages est la zone située en bas de chaque discussion. En plus du champ de texte, il contient un bouton **+** qui permet d'ouvrir tout ce que vous pouvez ajouter à un message (fichiers, outils, compétences, serveurs MCP et fichiers précédemment téléchargés), les puces pour les outils actuellement activés, ainsi que les commandes pour le raisonnement, la dictée et l'envoi.

## Qu'y a-t-il sur le compositeur [#whats-on-the-composer]

| Élément | Ce qu'il fait |
|---|---|
| **+** (**Joindre et outils**) | Ouvre la palette : options de téléchargement, outils, compétences, serveurs MCP et vos fichiers récents, le tout consultable depuis un seul champ. |
| Puces d'outils | Une puce par outil ou serveur MCP activé, à côté du bouton **+**. Supprimez une puce pour désactiver cet outil. |
| Contexte préparé | Fichiers, citations et compétences joints à votre prochain message, affichés au-dessus du champ de texte. |
| **Réflexion** | Effort de raisonnement pour les modèles qui le prennent en charge. |
| Utilisation du contexte | Quelle part de la fenêtre de contexte du modèle la conversation utilise, lorsque l'utilisation des jetons est disponible. |
| **Utiliser le microphone** | Dicte votre message avec la conversion parole-texte, lorsque celle-ci est activée. |
| Envoyer / Arrêter | Envoie le message ou arrête la réponse en cours de diffusion. |

To see which keys apply right now, such as `/ for prompts`, `@ for models` or `Enter to send`, turn on **Show composer tips** in **Settings > General**. A one-line tip then appears under the text field. It is off by default.

## Ajouter des fichiers [#add-files]

Cliquez sur **+** et choisissez une option dans la section **Attach**. Vous pouvez également glisser-déposer des fichiers dans le compositeur ou les coller.

Par défaut, LibreChat utilise l'uploader unifié : vous choisissez uniquement une source, et il décide de la manière dont chaque fichier atteint le modèle (téléchargement natif du fournisseur, extraction de texte ou un outil tel que File Search) en fonction du type de fichier et de l'endpoint.

| Option | When it appears |
|---|---|
| **From Local Computer** | Toujours, avec l'uploader par défaut. |
| **From SharePoint** | Lorsque le [SharePoint file picker](/docs/configuration/sharepoint) est activé. |

Si un administrateur définit [`fileConfig.legacyFileUploadUX: true`](/docs/configuration/librechat_yaml/object_structure/file_config#legacyfileuploadux), vous choisissez vous-même la destination. La section **Joindre** affiche alors l'option principale en premier et masque le reste derrière **Plus d'options de téléchargement** :

| Option | Quand il apparaît |
|---|---|
| **Upload to Provider** | Le fournisseur accepte les documents directement (par exemple OpenAI, Anthropic, Google, Bedrock, OpenRouter et les endpoints personnalisés, ou Azure OpenAI avec l'API Responses activée). |
| **Upload Image** | Affiché à la place de **Upload to Provider** lorsque le fournisseur accepte uniquement les images. |
| **Upload as Text** | La [capacité de contexte](/docs/features/upload_as_text) est activée. |
| **Upload for File Search** | La recherche de fichiers (File Search) est activée et autorisée pour l'agent actuel. La sélectionner active également la recherche de fichiers. |
| **Upload to Code Environment** | L'exécution de code est activée et autorisée pour l'agent actuel. La sélectionner active également **Run Code**. |
| **Attach Files** | Endpoints Assistants, qui gèrent les fichiers avec la propre configuration de l'assistant. |

Avec SharePoint activé dans ce mode, chaque option dispose également d'une version SharePoint, libellée par exemple **Upload to Provider (From SharePoint)**.

### Réutiliser un fichier que vous avez déjà téléchargé [#reuse-a-file-you-uploaded-before]

La section **Vos fichiers** de la palette liste vos fichiers utilisés récemment. Sélectionnez-en un pour le joindre à nouveau sans avoir à le télécharger. Saisir du texte dans le champ de recherche permet de rechercher tous vos fichiers par nom.

Choisissez **Show all** dans la section pour parcourir chaque fichier dans une boîte de dialogue, avec les vues **All**, **Images** et **Documents**, un champ de recherche et un aperçu pour les images et les PDF.

La palette affiche jusqu'à cinq fichiers récents. Les administrateurs peuvent réduire ce nombre, ou masquer la liste avec `0`, en utilisant [`interface.composerRecentFiles`](/docs/configuration/librechat_yaml/object_structure/interface#composerrecentfiles).

## Activer les outils, les compétences et les serveurs MCP [#turn-on-tools-skills-and-mcp-servers]

La palette liste tout ce que vous pouvez activer pour la conversation actuelle, regroupé par sections :

- **Outils** : outils intégrés tels que **Web Search**, **Run Code**, **File Search**, **Skills**, **Memory** et **Artifacts**, chacun étant affiché uniquement lorsqu'il est activé et que vous y avez accès.
- **Skills** : [skills](/docs/features/skills) individuelles que vous pouvez joindre à votre prochain message.
- **Serveurs MCP** : les [serveurs MCP](/docs/features/mcp) disponibles dans le chat.

Sélectionnez un outil ou un serveur MCP pour l'activer ou le désactiver. La palette reste ouverte, vous pouvez donc en activer plusieurs lors d'une même visite. Chaque outil activé apparaît sous forme de puce (chip) dans le compositeur ; supprimez la puce pour le désactiver. Certaines puces comportent un menu de mode, par exemple le mode de génération **Artifacts**.

La sélection d'une compétence la prépare pour votre prochain message à la place : elle apparaît dans le [staged context](#staged-context) plutôt que sous forme de puce.

Les lignes des serveurs MCP indiquent l'état de connexion de chaque serveur. La sélection d'un serveur qui n'est pas connecté lance sa connexion (y compris une connexion OAuth, lorsque le serveur en nécessite une) ou ouvre d'abord sa configuration s'il a besoin de vos identifiants. Une fois connectés, les serveurs qui requièrent des identifiants utilisateur disposent également d'une commande **Configure** sur la ligne, et **Web Search** en possède une pour ses clés API.

<Callout type="info" title="Les agents apportent leurs propres outils">
  Lorsqu'un agent est sélectionné, les sections **Tools** et **MCP Servers** sont masquées, car la configuration propre à l'agent détermine les outils qu'il utilise. Sur d'autres endpoint, un [model spec](/docs/configuration/librechat_yaml/object_structure/model_specs#hidebadgerow) avec `hideBadgeRow: true` masque les sections **Tools**, **Skills** et **MCP Servers**. **Attach** et **Your files** restent disponibles dans tous les cas.
</Callout>

### Tout afficher [#show-all]

La palette affiche un nombre limité de lignes par section. Choisissez **Show all** sur l'en-tête **Skills**, **MCP Servers** ou **Your files** pour ouvrir une boîte de dialogue contenant la liste complète, un champ de recherche et des filtres. Les Skills et les MCP Servers disposent de trois vues : **All**, **Made by you** et **Favorites**.

### Favoris et outils épinglés [#favorites-and-pinned-tools]

Ajoutez une ligne aux **Favoris** en cliquant sur l'étoile ; ils apparaîtront en haut de la palette. Lorsqu'une ligne est sélectionnée, appuyez sur <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd> sur macOS) pour l'ajouter ou la retirer des favoris. Les favoris sont enregistrés sur votre compte.

Les administrateurs peuvent épingler des outils intégrés avec [`interface.defaultPinnedTools`](/docs/configuration/librechat_yaml/object_structure/interface#defaultpinnedtools). Un outil épinglé conserve sa puce sur le compositeur même lorsqu'il est désactivé, ce qui vous permet de l'activer en un seul clic. Supprimer la puce d'un outil épinglé qui est désactivé le désépingle.

## Contexte mis en scène [#staged-context]

Tout ce qui est joint à votre prochain message apparaît au-dessus du champ de texte avant que vous ne l'envoyiez :

- **Fichiers**, avec progression du téléchargement et aperçu pour les images. Les longs textes collés peuvent également être ajoutés ici en tant que fichier, que vous pouvez modifier ou replacer dans le message.
- **Citations** que vous avez sélectionnées à partir de messages précédents.
- **Compétences** que vous avez sélectionnées depuis la palette ou avec la commande `$`.

Supprimez n'importe quel élément avec son bouton de suppression. Tout ce qui est mis en attente est envoyé avec votre prochain message.

## Réflexion et effort [#thinking-and-effort]

Pour les modèles disposant d'un paramètre de raisonnement, la commande **Thinking** ouvre un curseur allant de **Faster** (Plus rapide) à **Smarter** (Plus intelligent), en plus des modes distincts du fournisseur tels que **Auto** ou désactivé. Elle modifie le même paramètre que le panneau Parameters, elle est donc masquée lorsque le modèle ne possède pas de paramètre de raisonnement ou lorsque le déploiement désactive les paramètres avec `interface.parameters`.

## Mettre en file d'attente et piloter pendant la diffusion d'une réponse [#queue-and-steer-while-a-response-streams]

Vous pouvez continuer à taper pendant qu'une réponse est en cours de génération. Selon l'endpoint et vos paramètres, appuyer sur <kbd>Enter</kbd> met le message en file d'attente pour l'envoyer après la réponse, ou oriente la réponse actuelle d'un agent. L'astuce du compositeur indique l'action que <kbd>Enter</kbd> effectue à ce moment-là.

Les messages en file d'attente apparaissent dans une barre **Queued messages** au-dessus du compositeur, où vous pouvez :

- **Modifier le message** pour le renvoyer dans le champ de texte.
- **Supprimer le message** pour le retirer de la file d'attente.
- **Envoyer maintenant** pour l'envoyer immédiatement au lieu d'attendre.
- Réorganisez les messages en les faisant glisser, ou en en sélectionnant un et en utilisant les touches fléchées haut et bas.

Pour savoir comment fonctionne le pilotage et quand il est disponible, consultez [Steering and Queued Messages](/docs/features/agents#steering-and-queued-messages).

## Raccourcis clavier [#keyboard-shortcuts]

### Dans le champ de texte [#in-the-text-field]

| Touches | Action |
|---|---|
| <kbd>Enter</kbd> | Envoyer le message (mettre en file d'attente ou diriger pendant qu'une réponse est en cours de diffusion). |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Nouvelle ligne. |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) | Pendant qu'une réponse est en cours de diffusion : l'action alternative, **envoyer maintenant** lorsque <kbd>Enter</kbd> met en file d'attente, ou **mettre en file d'attente** lorsque <kbd>Enter</kbd> dirige. |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> (<kbd>Option</kbd>+<kbd>Enter</kbd>) | Pendant qu'un agent répond : interrompre et envoyer, lorsque disponible. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>) | Arrêter la réponse. |
| `/` | Insérer un prompt enregistré. |
| `@` | Passer à un autre modèle, préréglage ou agent. |
| `+` | Ajouter un modèle ou un préréglage pour une réponse supplémentaire. |
| `$` | Choisir une compétence pour le prochain message. |

Si vous avez désactivé **Appuyer sur Entrée pour envoyer des messages**, <kbd>Ctrl</kbd>+<kbd>Entrée</kbd> (<kbd>Cmd</kbd>+<kbd>Entrée</kbd>) envoie le message et <kbd>Entrée</kbd> ajoute une nouvelle ligne.

### Dans la palette [#in-the-palette]

| Touches | Action |
|---|---|
| Type | Rechercher des outils, des compétences, des serveurs, des options de téléchargement et des fichiers. |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Naviguer entre les lignes. |
| <kbd>Enter</kbd> | Sélectionner la ligne en surbrillance. |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd>) | Ajouter la ligne en surbrillance aux favoris, ou la supprimer. |
| <kbd>Backspace</kbd> sur une recherche vide | Fermer la palette. |
| <kbd>Escape</kbd> | Fermer la palette. |
