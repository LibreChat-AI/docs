Memory adalah penyimpanan kecil berisi fakta tentang Anda, disimpan dalam bentuk pasangan kunci/nilai (key/value), yang ditambahkan LibreChat ke konteks setiap pesan baru. Beri tahu model "ingat bahwa saya menulis Python dan lebih suka jawaban singkat" sekali saja, dan model akan mengetahuinya juga dalam percakapan Anda berikutnya.

Ini bukan pencarian dalam riwayat obrolan Anda. Tidak ada yang diingat dari percakapan lama kecuali disimpan sebagai entri memori, dan seluruh penyimpanan dikirim bersama setiap permintaan, sehingga fitur ini dimaksudkan untuk sejumlah kecil fakta yang bertahan lama, bukan catatan atau dokumen.

## Menyimpan memori [#saving-a-memory]

Klik **+** di [message composer](/docs/features/composer) untuk membuka palet, lalu pilih **Memory** di bagian **Tools**. Dengan opsi ini aktif, model mendapatkan dua tool, `set_memory` dan `delete_memory`, dan diinstruksikan untuk menggunakannya hanya ketika Anda meminta untuk mengingat, memperbarui, atau melupakan sesuatu. Pesan seperti "remember that my team uses pnpm" akan menghasilkan langkah "Saved memory" dalam balasan, dengan label berupa kunci memori tersebut; perluas langkah itu untuk melihat nilai yang tersimpan. "Forget where I work" akan menghasilkan "Deleted memory". Ketika model melakukan beberapa pemanggilan memori dalam satu balasan, semuanya dikelompokkan di bawah satu langkah, seperti "Ran 2 actions".

Opsi Memory hanya muncul jika peran Anda diizinkan untuk membuat dan memperbarui memori. Saat Anda sedang mengobrol dengan agen, palet tidak memiliki opsi Memory; agen menggunakan memori jika Memory diaktifkan di Agent Builder.

Agen juga dapat diatur ke **Simpan memori secara terpisah untuk agen ini**: dalam mode ini, agen membaca dan menulis penyimpanannya sendiri, yang terisolasi dari memori bersama Anda dan dari agen lain. Entri tersebut mengikuti akses ke agen: jika Anda kehilangan akses ke agen tersebut, memori terpisahnya tidak dapat lagi dibaca atau diperbarui, meskipun Anda tetap dapat menghapus memori dari agen yang telah dihapus.

Beberapa deployment juga menjalankan agen memori di latar belakang yang meninjau setiap percakapan dan menyimpan fakta secara otomatis, tanpa Anda memintanya. Apakah fitur tersebut diaktifkan atau tidak adalah pilihan admin Anda.

## Melihat dan mengedit memori [#viewing-and-editing-memories]

Buka **Memories** di panel samping untuk melihat semua yang tersimpan tentang Anda. Dari sana, Anda dapat:

- Filter daftar berdasarkan key atau value, atau berdasarkan agent jika Anda memiliki memori yang dibatasi agent (ditandai "Agent-scoped memory").
- Klik **+** (**Create Memory**) untuk menambahkan entri secara manual. Kunci hanya menggunakan huruf kecil dan garis bawah (underscore), dan setiap kunci hanya boleh ada satu kali.
- Sunting atau hapus entri mana pun.

Ketika admin menetapkan batas ukuran, panel menampilkan seberapa besar bagian dari batas tersebut yang sedang Anda gunakan. Setelah penyimpanan penuh, penyimpanan baru akan gagal dengan pesan "Memory Storage Full" sampai Anda menghapus sesuatu. Setiap entri juga memiliki batas panjang maksimum.

## Menonaktifkan memori untuk diri sendiri [#turning-memory-off-for-yourself]

Tombol **Use memory** di panel Memories, yang juga tersedia sebagai **Reference saved memories** di bawah **Settings** > **Data & Privacy**, mengatur apakah memori tersimpan Anda ditambahkan ke percakapan Anda. Jika dimatikan, LibreChat berhenti menambahkannya dan berhenti menawarkan alat Memory; entri Anda tetap disimpan dan akan kembali saat Anda menyalakannya lagi.

Toggle ini hanya ditampilkan ketika admin Anda mengizinkan pengguna untuk menonaktifkannya. Memori juga dapat dibatasi berdasarkan peran, sehingga sebagian pengguna mungkin dapat melihat panel tetapi tidak dapat membuat atau mengedit entri.

## Pengaturan [#setup]

Memori dinonaktifkan hingga admin menambahkan bagian `memory` ke `librechat.yaml`. Agen memori latar belakang adalah fitur terpisah yang bersifat opt-in dan memerlukan model sendiri. Lihat [Konfigurasi memori](/docs/configuration/librechat_yaml/object_structure/memory) untuk batasan, kunci yang diizinkan, agen memori, dan pemecahan masalah.
