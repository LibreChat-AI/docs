Un Agent Plugin è una cartella sul server di LibreChat che raggruppa [Skills](/docs/features/skills), [server MCP](/docs/features/mcp) e hook di comando opzionali che appartengono insieme. Un operatore inserisce la cartella nella directory dei plugin e riavvia LibreChat; non c'è nulla da installare dall'interfaccia utente. LibreChat segue il formato di pacchetto aperto Agent Plugins `1.0.0`, quindi un unico pacchetto può essere condiviso con altri strumenti che supportano lo stesso formato.

I plugin per Agent sono sperimentali. Il formato dei pacchetti e il comportamento potrebbero cambiare.

## Cosa vedono gli utenti [#what-users-see]

Gli utenti non vedono mai un plugin come tale. Vedono ciò che contiene.

- Le sue Skill compaiono nell'elenco delle Skill accanto alle altre skill. Sono di sola lettura, seguono le normali autorizzazioni delle Skill e possono essere attivate o disattivate con **Disponibile per l'agente** come qualsiasi altra skill.
- I suoi server MCP compaiono nella Tool Library e possono essere aggiunti agli agenti come i server definiti in `librechat.yaml`.
- I suoi hook vengono eseguiti sul server in determinati momenti di un'esecuzione dell'agente, ad esempio prima di una chiamata a uno strumento o quando l'esecuzione si interrompe. Un hook può bloccare una chiamata a uno strumento, aggiungere contesto al prompt o interrompere un'esecuzione, e l'utente vede solo l'effetto.

Se il nome di una skill o di un server MCP coincide con uno definito altrove, prevale l'altra definizione: una skill presente nella directory delle skill della distribuzione standalone ha la precedenza su una skill di plugin, e un server definito in `librechat.yaml` ha la precedenza su un server di plugin.

## Cosa può contenere un plugin [#what-a-plugin-can-contain]

Una cartella di plugin contiene un manifest `plugin.json` e uno qualsiasi dei seguenti elementi:

- `skills/`, una cartella per ogni skill, ciascuna con un file `SKILL.md`.
- `mcp.json`, definizioni dei server MCP. I server locali (`stdio`) vengono eseguiti dall'interno della cartella del plugin e dispongono di una propria directory di dati persistente.
- `ai.librechat/hooks/hooks.json`, hook di comando. Questi vengono eseguiti come processi sull'host API e sono disabilitati a meno che l'operatore non li attivi.

Ogni parte viene caricata in modo indipendente, quindi un `mcp.json` non valido non impedisce il caricamento delle skill del plugin. I problemi vengono segnalati nei log di avvio.

## Setup [#setup]

I plugin vengono caricati da `./plugin` nella radice del progetto per impostazione predefinita, e gli hook di comando sono disattivati di default. Consulta la [configurazione dei plugin per agenti](/docs/configuration/agent_plugins) per le impostazioni della directory, la struttura dei pacchetti, le regole di validazione del manifest e di MCP, e il contratto di esecuzione degli hook.
