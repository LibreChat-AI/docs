O compositor de mensagens é a caixa na parte inferior de cada chat. Além do campo de texto, ele contém um botão **+** que abre tudo o que você pode adicionar a uma mensagem (arquivos, ferramentas, habilidades, servidores MCP e arquivos que você enviou anteriormente), os chips para as ferramentas que estão ativadas no momento e os controles para raciocínio, ditado e envio.

## O que há no compositor [#whats-on-the-composer]

| Elemento | O que ele faz |
|---|---|
| **+** (**Anexar e ferramentas**) | Abre a paleta: opções de upload, ferramentas, habilidades, servidores MCP e seus arquivos recentes, tudo pesquisável a partir de um único campo. |
| Chips de ferramenta | Um chip por ferramenta ou servidor MCP que esteja ativado, ao lado do botão **+**. Remova um chip para desativar essa ferramenta. |
| Contexto preparado | Arquivos, citações e habilidades anexados à sua próxima mensagem, exibidos acima do campo de texto. |
| **Pensando** | Esforço de raciocínio para modelos que oferecem suporte a isso. |
| Uso de contexto | Quanto da janela de contexto do modelo a conversa utiliza, quando o uso de tokens está disponível. |
| **Usar microfone** | dita sua mensagem com fala para texto, quando a conversão de fala para texto está ativada. |
| Enviar / Parar | Envia a mensagem ou interrompe a resposta que está sendo transmitida. |

To see which keys apply right now, such as `/ for prompts`, `@ for models` or `Enter to send`, turn on **Show composer tips** in **Settings > General**. A one-line tip then appears under the text field. It is off by default.

## Adicionar arquivos [#add-files]

Clique em **+** e escolha uma opção na seção **Attach**. Você também pode arrastar arquivos para o compositor ou colá-los.

Por padrão, o LibreChat usa o uploader unificado: você escolhe apenas uma origem, e ele decide como cada arquivo chega ao modelo (upload nativo do provedor, extração de texto ou uma ferramenta como File Search) a partir do tipo de arquivo e do endpoint.

| Opção | Quando aparece |
|---|---|
| **From Local Computer** | Sempre, com o uploader padrão. |
| **From SharePoint** | Quando o [SharePoint file picker](/docs/configuration/sharepoint) está habilitado. |

Se um administrador definir [`fileConfig.legacyFileUploadUX: true`](/docs/configuration/librechat_yaml/object_structure/file_config#legacyfileuploadux), você escolhe o destino por conta própria. A seção **Anexar** então mostra a opção principal primeiro e oculta o restante atrás de **Mais opções de upload**:

| Opção | Quando aparece |
|---|---|
| **Upload to Provider** | O provedor aceita documentos diretamente (por exemplo, OpenAI, Anthropic, Google, Bedrock, OpenRouter e endpoints personalizados, ou Azure OpenAI com a Responses API ativada). |
| **Upload Image** | Exibido em vez de **Upload to Provider** quando o provedor aceita apenas imagens. |
| **Upload as Text** | A [context capability](/docs/features/upload_as_text) está ativada. |
| **Upload for File Search** | O File Search está ativado e permitido para o agente atual. Selecioná-lo também ativa o File Search. |
| **Upload to Code Environment** | A execução de código está ativada e permitida para o agente atual. Selecioná-lo também ativa o **Run Code**. |
| **Attach Files** | Endpoints de Assistants, que lidam com arquivos usando a própria configuração do assistente. |

Com o SharePoint habilitado neste modo, cada opção também possui uma versão do SharePoint, rotulada, por exemplo, como **Upload to Provider (From SharePoint)**.

### Reutilize um arquivo que você enviou anteriormente [#reuse-a-file-you-uploaded-before]

A seção **Your files** da paleta lista seus arquivos usados mais recentemente. Selecione um para anexá-lo novamente sem precisar fazer o upload. Digitar no campo de busca pesquisa todos os seus arquivos por nome.

Escolha **Show all** na seção para navegar por todos os arquivos em uma caixa de diálogo, com as visualizações **All**, **Images** e **Documents**, um campo de pesquisa e uma pré-visualização para imagens e PDFs.

A paleta exibe até cinco arquivos recentes. Administradores podem reduzir esse número, ou ocultar a lista com `0`, usando [`interface.composerRecentFiles`](/docs/configuration/librechat_yaml/object_structure/interface#composerrecentfiles).

## Ative ferramentas, habilidades e servidores MCP [#turn-on-tools-skills-and-mcp-servers]

A paleta lista tudo o que você pode ativar para a conversa atual, agrupado em seções:

- **Tools**: ferramentas integradas como **Web Search**, **Run Code**, **File Search**, **Skills**, **Memory** e **Artifacts**, cada uma exibida apenas quando está habilitada e você tem acesso a ela.
- **Skills**: [skills](/docs/features/skills) individuais que você pode anexar à sua próxima mensagem.
- **MCP Servers**: os [MCP servers](/docs/features/mcp) disponíveis no chat.

Selecione uma ferramenta ou servidor MCP para ativá-lo ou desativá-lo. A paleta permanece aberta, para que você possa alternar vários em uma única visita. Cada ferramenta que está ativada aparece como um chip no compositor; remova o chip para desativá-la. Alguns chips possuem um menu de modo, por exemplo, o modo de geração de **Artifacts**.

Selecionar uma skill a prepara para sua próxima mensagem: ela aparece no [staged context](#staged-context) em vez de como um chip.

As linhas dos servidores MCP mostram o status de conexão de cada servidor. Selecionar um servidor que não está conectado inicia sua conexão (incluindo um login OAuth, quando o servidor precisar de um) ou abre sua configuração primeiro, caso ele precise de suas credenciais. Uma vez conectado, os servidores que exigem credenciais de usuário também possuem um controle **Configure** na linha, e a **Web Search** possui um para suas chaves de API.

<Callout type="info" title="Agentes trazem suas próprias ferramentas">
  Com um agente selecionado, as seções **Tools** e **MCP Servers** ficam ocultas, pois a própria configuração do agente decide quais ferramentas ele utiliza. Em outros endpoint, um [model spec](/docs/configuration/librechat_yaml/object_structure/model_specs#hidebadgerow) com `hideBadgeRow: true` oculta as seções **Tools**, **Skills** e **MCP Servers**. **Attach** e **Your files** permanecem disponíveis em todos os casos.
</Callout>

### Mostrar tudo [#show-all]

A paleta mostra algumas linhas por seção. Escolha **Show all** no cabeçalho de **Skills**, **MCP Servers** ou **Your files** para abrir uma caixa de diálogo com a lista completa, um campo de busca e filtros. Skills e MCP servers possuem três visualizações: **All**, **Made by you** e **Favorites**.

### Favoritos e ferramentas fixadas [#favorites-and-pinned-tools]

Marque uma linha com uma estrela para adicioná-la aos **Favoritos**, que ficam no topo da paleta. Com uma linha selecionada, pressione <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd> no macOS) para marcar ou desmarcar como favorita. Os Favoritos são salvos na sua conta.

Administradores podem fixar ferramentas integradas com [`interface.defaultPinnedTools`](/docs/configuration/librechat_yaml/object_structure/interface#defaultpinnedtools). Uma ferramenta fixada mantém seu chip no compositor mesmo quando está desativada, permitindo que você a ative com um clique. Remover o chip de uma ferramenta fixada que está desativada a desafixa.

## Contexto em etapas [#staged-context]

Tudo o que for anexado à sua próxima mensagem aparece acima do campo de texto antes de você enviá-la:

- **Arquivos**, com progresso de upload e uma prévia para imagens. Textos longos colados também podem ser armazenados aqui como um arquivo, o qual você pode editar ou mover de volta para a mensagem.
- **Citações** que você selecionou de mensagens anteriores.
- **Skills** que você selecionou na paleta ou com o comando `$`.

Remova qualquer item com seu botão de remover. Tudo o que estiver preparado será enviado com sua próxima mensagem.

## Pensamento e esforço [#thinking-and-effort]

Para modelos com uma configuração de raciocínio, o controle **Thinking** abre um controle deslizante que vai de **Faster** (Mais rápido) a **Smarter** (Mais inteligente), além dos modos separados do provedor, como **Auto** ou desativado. Ele altera o mesmo parâmetro que o painel de Parâmetros, portanto, ele fica oculto quando o modelo não possui uma configuração de raciocínio ou quando a implantação desativa os parâmetros com `interface.parameters`.

## Enfileire e direcione enquanto uma resposta é transmitida [#queue-and-steer-while-a-response-streams]

Você pode continuar digitando enquanto uma resposta está sendo transmitida. Dependendo do endpoint e das suas configurações, pressionar <kbd>Enter</kbd> coloca a mensagem na fila para ser enviada após a resposta ou direciona a resposta atual de um agente. A dica no compositor nomeia a ação que o <kbd>Enter</kbd> executa naquele momento.

As mensagens na fila aparecem em uma barra de **Queued messages** acima do compositor, onde você pode:

- **Editar mensagem** para movê-la de volta ao campo de texto.
- **Remover mensagem** para retirá-la da fila.
- **Send now** para enviar imediatamente em vez de aguardar.
- Reordene as mensagens arrastando-as ou focando em uma e pressionando as teclas de seta para cima e para baixo.

Para saber como o steering funciona e quando ele está disponível, consulte [Steering and Queued Messages](/docs/features/agents#steering-and-queued-messages).

## Atalhos de teclado [#keyboard-shortcuts]

### No campo de texto [#in-the-text-field]

| Chaves | Ação |
|---|---|
| <kbd>Enter</kbd> | Enviar a mensagem (colocar na fila ou direcionar enquanto uma resposta é transmitida). |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Nova linha. |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) | Enquanto uma resposta é transmitida: a ação alternativa, **enviar agora** quando <kbd>Enter</kbd> coloca na fila, ou **colocar na fila** quando <kbd>Enter</kbd> direciona. |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> (<kbd>Option</kbd>+<kbd>Enter</kbd>) | Enquanto um agente responde: interromper e enviar, quando disponível. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>) | Parar a resposta. |
| `/` | Inserir um prompt salvo. |
| `@` | Alternar para outro modelo, predefinição ou agente. |
| `+` | Adicionar um modelo ou predefinição para uma resposta adicional. |
| `$` | Escolher uma habilidade para a próxima mensagem. |

Se você desativou **Pressionar Enter para enviar mensagens**, <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) envia a mensagem e <kbd>Enter</kbd> adiciona uma nova linha.

### Na paleta [#in-the-palette]

| Teclas | Ação |
|---|---|
| Digitar | Pesquisar ferramentas, habilidades, servidores, opções de upload e arquivos. |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Navegar pelas linhas. |
| <kbd>Enter</kbd> | Selecionar a linha destacada. |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd>) | Adicionar a linha destacada aos Favoritos, ou removê-la. |
| <kbd>Backspace</kbd> em uma pesquisa vazia | Fechar a paleta. |
| <kbd>Escape</kbd> | Fechar a paleta. |
