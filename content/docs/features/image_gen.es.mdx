LibreChat crea y edita imágenes mediante herramientas de agente. Asigna a un agente una herramienta de imagen, describe lo que quieres y la imagen aparecerá en la conversación. Sube una imagen junto con tu mensaje y el agente podrá modificarla en lugar de empezar desde cero.

## Las herramientas de imagen [#the-image-tools]

| Herramienta | Qué hace | Edita imágenes |
| --- | --- | --- |
| OpenAI Image Tools | Genera a partir de texto y edita imágenes subidas o anteriores con los modelos de imagen de OpenAI. Una buena opción predeterminada. | Sí |
| Gemini Image Tools | Genera con los modelos de imagen Gemini de Google, usando opcionalmente imágenes anteriores como contexto visual. | Sí |
| Flux | Genera con los modelos Flux de Black Forest Labs, incluidos tus propios modelos ajustados (fine-tuned). | No |
| Stable Diffusion | Genera en tu propio servidor de Automatic1111, de modo que nada sale de tu red. | No |

Cuáles ves depende de lo que tu administrador haya configurado.

## Generar una imagen [#generate-an-image]

<Steps>
<Step>
Abre el agente en el Agent Builder y selecciona **Add** junto a **Tools**.
</Step>
<Step>
Elija una herramienta de imágenes, como **OpenAI Image Tools**, y guarde el agente. Si la herramienta le pide una clave de API, su administrador ha dejado que cada usuario la introduzca; ingrese su propia clave.
</Step>
<Step>
Inicia un chat con el agente y describe la imagen.
</Step>
</Steps>

El agente convierte tu solicitud en un prompt para la herramienta, por lo que puedes hablar de forma natural («un cartel para una venta de pasteles, formato ancho, con muchos colores pastel»). Las solicitudes de forma y tamaño se transmiten cuando la herramienta las admite: OpenAI acepta tamaños cuadrados, horizontales o verticales (los modelos más recientes también aceptan tamaños personalizados de hasta 4K), además de un nivel de calidad y un fondo transparente. Gemini acepta relaciones de aspecto como 16:9 o 9:16 y, en los modelos más recientes, una resolución de hasta 4K. Stable Diffusion siempre genera imágenes de 1024x1024.

## Editar una imagen [#edit-an-image]

Adjunta una imagen con **Subir imagen** y pide un cambio: "elimina a las personas del fondo", "haz que parezca una acuarela", "pon este logotipo en una taza de café". Con OpenAI Image Tools, el agente llama a la herramienta de edición; con Gemini, pasa tu imagen como contexto para generar una nueva.

Puedes seguir trabajando sobre una imagen que el agente acaba de generar (por ejemplo, "ahora oscurece el cielo") sin necesidad de subir nada. Cada imagen subida o generada tiene un ID al que el modelo puede hacer referencia, y eso funciona mientras la imagen siga dentro de la ventana de contexto de la conversación. En una conversación larga, vuelve a adjuntar la imagen.

Flux y Stable Diffusion solo funcionan a partir de texto, por lo que no pueden editar.

## Lo que ve el modelo [#what-the-model-sees]

Una imagen generada se muestra al modelo una sola vez, justo después de que se crea, para que pueda describir o revisar su propio trabajo. Después de eso, el modelo solo ve las imágenes adjuntas a tus mensajes. Si quieres hablar de una imagen anterior varios turnos más tarde, vuelve a adjuntarla.

Debido a que la imagen se devuelve al modelo, utilice un modelo con capacidad de visión para los agentes que tengan herramientas de imagen. Un modelo que solo procesa texto puede fallar en el turno posterior a la generación de la imagen.

Las imágenes generadas se almacenan como cualquier otro archivo subido, según la configuración de almacenamiento de archivos de tu administrador. De forma predeterminada, se reducen de modo que el lado más corto sea de 768 píxeles como máximo, por lo que una solicitud de 4K se guarda con un tamaño menor al que generó el modelo, a menos que tu administrador cambie esa configuración.

## Imágenes de servidores MCP [#images-from-mcp-servers]

Las herramientas de MCP también pueden devolver imágenes, por ejemplo un servidor de navegador que toma capturas de pantalla. Las imágenes que el servidor devuelve en el formato de imagen de MCP se muestran en el chat de la misma forma que la salida de las herramientas integradas. Algunos servidores devuelven únicamente una URL de la imagen, algo que LibreChat no trata como salida de imagen.

## Escribir prompts [#writing-prompts]

Los modelos de imagen responden a descripciones concretas. Empieza por el sujeto y el medio (fotografía, pintura al óleo, ilustración vectorial plana), y luego añade la composición, la iluminación y los detalles que importan. Describe lo que quieres ver en lugar de enumerar lo que quieres evitar. Si un resultado se acerca, pide el cambio específico en lugar de reescribir todo el prompt.

## Configuración [#setup]

Cada herramienta necesita una clave de API o una URL de servidor. Un administrador configura estos valores en `.env`; para las herramientas basadas en clave, un administrador también puede dejar que cada usuario introduzca su propia clave. Configuración de cada herramienta: [OpenAI Image Tools](/docs/configuration/tools/openai_image_gen), [Gemini Image Tools](/docs/configuration/tools/gemini_image_gen), [Flux](/docs/configuration/tools/flux) y [Stable Diffusion](/docs/configuration/tools/stable_diffusion). El lugar donde se almacenan las imágenes se define mediante [`fileStrategy`](/docs/configuration/librechat_yaml/object_structure/config#filestrategy).
