Artifacts 让智能体可以直接交付一个你能查看和运行的成果，而不是一大段代码：例如 React 组件、HTML 页面、SVG、Markdown 文档或 Mermaid 图表。结果会在聊天旁边的面板中打开，你可以在其中预览、阅读和编辑源代码，并进行下载。

## 为智能体开启 artifacts [#turn-on-artifacts-for-an-agent]

Artifacts 属于某个智能体,因此你所对话的智能体决定你能否获得它们。

<Steps>
<Step>
在 Agent Builder 中打开该智能体,然后找到 **Tools** 部分。
</Step>
<Step>
在 **Tools** 旁边选择 **Add**,选择 **Artifacts**,然后将其添加到智能体中。
</Step>
<Step>
选择一种 **模式**,然后保存智能体。
</Step>
</Steps>

该模式决定 LibreChat 向模型提供哪些关于 Artifacts(工件)的指令:

- **普通**:标准说明。该智能体可以生成 React、HTML、SVG、Markdown 和 Mermaid 类型的工件。
- **shadcn/ui**:添加了 shadcn/ui 组件库的使用说明,当你希望基于预构建组件快速搭建精美的界面原型时,它会很有帮助。
- **Custom**:保留面板和渲染功能开启,但不发送任何内置指令。你的智能体自身的指令必须教会模型 Artifact 的语法,以及它可以使用哪些类型。

对于自定义模式,说明中需要展示 LibreChat 查找的包装格式:

````md
:::artifact{identifier="unique-id" type="text/html" title="Short Title"}
```
Artifact content here
```
:::
````

`type` 的取值为 `text/html`、`application/vnd.react`、`image/svg+xml`、`application/vnd.mermaid` 或 `text/markdown` 之一。

## 打开 Artifact [#opening-an-artifact]

当智能体编写一个 artifact 时,消息中会显示一行内容,包含该 artifact 的标题和类型,而不是原始代码。点击该行即可打开面板,再次点击则关闭面板。如果一次对话生成了多个 artifact,面板标题栏中的版本菜单可让你在它们之间切换。

Mermaid 代码块会在任何聊天中渲染为紧凑的图表卡片，无论智能体是否启用了 artifacts。在图表上使用 **Open as artifact**，即可将其移至面板中。

## 在面板中工作 [#working-in-the-panel]

- **预览**会渲染该产物。**刷新**会重新加载预览,这在交互式组件进入异常状态时很有用。
- **代码**会在编辑器中显示源代码。待响应流式输出完成后，你可以对其进行编辑，所做的更改会保存回消息中，因此预览以及之后的访问都会显示编辑后的版本。
- 复制按钮会复制源代码。**下载**会将其保存为以该构件标题命名的文件。如果您未编辑过，由代码执行生成的文件将以原始文件名下载；经过编辑或仅用于预览的内容，其文件名中会包含 `.preview`，以免将其误认为原始文件。
- Mermaid 图表现在改为提供 **Export as SVG** 和 **Export as PNG** 选项,这两个选项同时出现在面板中和内联图表上。
- **进入全屏**会将预览扩展到整个屏幕;按 Escape 键即可退出。当您的浏览器不允许全屏时,该按钮会被隐藏。
- **在新窗口中打开**会将面板移至独立的浏览器窗口，在第二台显示器上使用非常方便。在回复流式输出时，制品会持续更新，未保存的代码编辑内容也会一并保留。请保持聊天标签页处于打开状态，因为关闭该标签页也会关闭此窗口。**停靠回面板**（或关闭窗口）可将其恢复到面板中，LibreChat 会记住该窗口的大小和位置。如果没有任何窗口打开，请允许您的 LibreChat 站点弹出窗口。在狭窄的移动端布局中不会显示此按钮。

预览在一个沙盒 iframe 中运行,使用 CodeSandbox 的 Sandpack。React 工件可以导入一组固定的常用库;模型会被告知有哪些可用库,其他库将无法加载。

代码执行写入的文件(例如 HTML 报告、Word 文档、电子表格和幻灯片)同样会在此面板中打开。关于这些预览的工作方式,请参阅 [Code Interpreter](/docs/features/code_interpreter)。

## 设置 [#setup]

默认情况下,智能体(Agent)启用 Artifacts:除非管理员将其移除,否则 `artifacts` 智能体功能处于开启状态。但每个智能体仍需在其工具中添加 Artifacts。管理员还可以在模型规范(Model Specs)上启用 Artifacts、自行托管 Sandpack 打包器,或关闭新窗口选项。详见 [Artifacts 配置](/docs/configuration/artifacts)。
