Edytor wiadomości to pole znajdujące się na dole każdego czatu. Oprócz pola tekstowego zawiera on przycisk **+**, który otwiera wszystko, co można dodać do wiadomości (pliki, narzędzia, umiejętności, serwery MCP oraz wcześniej przesłane pliki), chipy dla aktualnie włączonych narzędzi oraz elementy sterujące dla rozumowania, dyktowania i wysyłania.

## Co znajduje się w polu edytora [#whats-on-the-composer]

| Element | Co robi |
|---|---|
| **+** (**Załączniki i narzędzia**) | Otwiera paletę: opcje przesyłania, narzędzia, umiejętności, serwery MCP oraz ostatnie pliki, wszystko z możliwością wyszukiwania w jednym polu. |
| Chip narzędzi | Jeden chip na każde włączone narzędzie lub serwer MCP, obok przycisku **+**. Usuń chip, aby wyłączyć dane narzędzie. |
| Przygotowany kontekst | Pliki, cytaty i umiejętności dołączone do następnej wiadomości, wyświetlane nad polem tekstowym. |
| **Myślenie** | Wysiłek związany z rozumowaniem dla modeli, które to wspierają. |
| Wykorzystanie kontekstu | Ile z okna kontekstowego modelu zajmuje konwersacja, gdy dostępne jest użycie tokenów. |
| **Użyj mikrofonu** | Dyktuje wiadomość za pomocą zamiany mowy na tekst, gdy funkcja ta jest włączona. |
| Wyślij / Zatrzymaj | Wysyła wiadomość lub zatrzymuje odpowiedź, która jest przesyłana strumieniowo. |

To see which keys apply right now, such as `/ for prompts`, `@ for models` or `Enter to send`, turn on **Show composer tips** in **Settings > General**. A one-line tip then appears under the text field. It is off by default.

## Dodaj pliki [#add-files]

Kliknij **+** i wybierz opcję w sekcji **Attach**. Możesz również przeciągnąć pliki do pola edytora lub je wkleić.

Domyślnie LibreChat korzysta ze zunifikowanego modułu przesyłania: wybierasz tylko źródło, a on decyduje, w jaki sposób każdy plik dotrze do modelu (przesłanie przez natywnego dostawcę, ekstrakcja tekstu lub narzędzie takie jak File Search) na podstawie typu pliku oraz endpoint.

| Opcja | Kiedy się pojawia |
|---|---|
| **From Local Computer** | Zawsze, przy użyciu domyślnego przesyłania plików. |
| **From SharePoint** | Gdy włączony jest [SharePoint file picker](/docs/configuration/sharepoint). |

Jeśli administrator ustawi [`fileConfig.legacyFileUploadUX: true`](/docs/configuration/librechat_yaml/object_structure/file_config#legacyfileuploadux), wybierasz miejsce docelowe samodzielnie. Sekcja **Attach** wyświetla wtedy najpierw główną opcję, a resztę ukrywa pod **More upload options**:

| Opcja | Kiedy się pojawia |
|---|---|
| **Upload to Provider** | Dostawca akceptuje dokumenty bezpośrednio (na przykład OpenAI, Anthropic, Google, Bedrock, OpenRouter i niestandardowe endpointy lub Azure OpenAI z włączonym Responses API). |
| **Upload Image** | Wyświetlane zamiast **Upload to Provider**, gdy dostawca akceptuje tylko obrazy. |
| **Upload as Text** | Włączona jest [funkcja kontekstu](/docs/features/upload_as_text). |
| **Upload for File Search** | Funkcja File Search jest włączona i dozwolona dla bieżącego agenta. Wybranie jej również włącza File Search. |
| **Upload to Code Environment** | Wykonywanie kodu jest włączone i dozwolone dla bieżącego agenta. Wybranie jej również włącza **Run Code**. |
| **Attach Files** | Endpointy Assistants, które obsługują pliki zgodnie z własną konfiguracją asystenta. |

Gdy SharePoint jest włączony w tym trybie, każda opcja posiada również wersję dla SharePoint, oznaczoną na przykład jako **Upload to Provider (From SharePoint)**.

### Ponowne użycie wcześniej przesłanego pliku [#reuse-a-file-you-uploaded-before]

Sekcja **Twoje pliki** w palecie zawiera listę ostatnio używanych plików. Wybierz jeden z nich, aby dołączyć go ponownie bez konieczności ponownego przesyłania. Wpisanie tekstu w polu wyszukiwania pozwala przeszukać wszystkie Twoje pliki według nazwy.

Wybierz **Show all** w sekcji, aby przeglądać wszystkie pliki w oknie dialogowym, z widokami **All**, **Images** i **Documents**, polem wyszukiwania oraz podglądem obrazów i plików PDF.

Paleta wyświetla do pięciu ostatnich plików. Administratorzy mogą zmniejszyć tę liczbę lub ukryć listę za pomocą `0`, używając [`interface.composerRecentFiles`](/docs/configuration/librechat_yaml/object_structure/interface#composerrecentfiles).

## Włącz narzędzia, umiejętności i serwery MCP [#turn-on-tools-skills-and-mcp-servers]

Paleta zawiera listę wszystkich elementów, które możesz włączyć dla bieżącej konwersacji, pogrupowanych w sekcje:

- **Narzędzia**: wbudowane narzędzia, takie jak **Web Search**, **Run Code**, **File Search**, **Skills**, **Memory** oraz **Artifacts**, z których każde jest widoczne tylko wtedy, gdy jest włączone i masz do niego dostęp.
- **Skills**: indywidualne [skills](/docs/features/skills), które możesz dołączyć do swojej następnej wiadomości.
- **MCP Servers**: [serwery MCP](/docs/features/mcp) dostępne na czacie.

Wybierz narzędzie lub serwer MCP, aby je włączyć lub wyłączyć. Paleta pozostaje otwarta, dzięki czemu możesz przełączyć kilka z nich podczas jednej wizyty. Każde włączone narzędzie pojawia się jako chip w komponencie; usuń chip, aby je wyłączyć. Niektóre chipy zawierają menu trybu, na przykład tryb generowania **Artifacts**.

Wybranie umiejętności przygotowuje ją do następnej wiadomości: pojawia się ona w [staged context](#staged-context), a nie jako chip.

Wiersze serwerów MCP pokazują status połączenia każdego z nich. Wybranie serwera, który nie jest połączony, inicjuje jego połączenie (w tym logowanie OAuth, jeśli serwer tego wymaga) lub najpierw otwiera jego konfigurację, jeśli wymaga on Twoich danych uwierzytelniających. Po połączeniu, serwery wymagające danych uwierzytelniających użytkownika posiadają również kontrolkę **Configure** w wierszu, a **Web Search** posiada taką kontrolkę dla swoich kluczy API.

<Callout type="info" title="Agenci posiadają własne narzędzia">
  Gdy wybrany jest agent, sekcje **Tools** oraz **MCP Servers** są ukryte, ponieważ to własna konfiguracja agenta decyduje o tym, jakich narzędzi używa. W przypadku innych endpoint, [model spec](/docs/configuration/librechat_yaml/object_structure/model_specs#hidebadgerow) z ustawieniem `hideBadgeRow: true` ukrywa sekcje **Tools**, **Skills** oraz **MCP Servers**. Opcje **Attach** i **Your files** pozostają dostępne w każdym przypadku.
</Callout>

### Pokaż wszystko [#show-all]

Paleta wyświetla kilka wierszy na sekcję. Wybierz **Pokaż wszystko** w nagłówku **Umiejętności**, **Serwery MCP** lub **Twoje pliki**, aby otworzyć okno dialogowe z pełną listą, polem wyszukiwania i filtrami. Umiejętności i serwery MCP mają trzy widoki: **Wszystkie**, **Stworzone przez Ciebie** oraz **Ulubione**.

### Ulubione i przypięte narzędzia [#favorites-and-pinned-tools]

Oznacz wiersz gwiazdką, aby dodać go do **Ulubionych**, które znajdują się na górze palety. Gdy wiersz jest podświetlony, naciśnij <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd> w systemie macOS), aby dodać lub usunąć go z ulubionych. Ulubione są zapisywane na Twoim koncie.

Administratorzy mogą przypinać wbudowane narzędzia za pomocą [`interface.defaultPinnedTools`](/docs/configuration/librechat_yaml/object_structure/interface#defaultpinnedtools). Przypięte narzędzie utrzymuje swój chip w komponencie, nawet gdy jest wyłączone, dzięki czemu można je włączyć jednym kliknięciem. Usunięcie chipa przypiętego narzędzia, które jest wyłączone, powoduje jego odpięcie.

## Staged context [#staged-context]

Wszystko, co dołączysz do następnej wiadomości, pojawi się nad polem tekstowym przed jej wysłaniem:

- **Pliki**, z paskiem postępu przesyłania i podglądem obrazów. Długi wklejony tekst może również trafić tutaj jako plik, który możesz edytować lub przenieść z powrotem do wiadomości.
- **Cytaty** wybrane z wcześniejszych wiadomości.
- **Umiejętności** (Skills), które wybrałeś z palety lub za pomocą polecenia `$`.

Usuń dowolny element za pomocą przycisku usuwania. Wszystko, co zostało przygotowane, zostanie wysłane wraz z następną wiadomością.

## Myślenie i wysiłek [#thinking-and-effort]

W przypadku modeli z ustawieniem rozumowania, kontrolka **Thinking** otwiera suwak, który działa w zakresie od **Faster** (Szybciej) do **Smarter** (Inteligentniej), a także zawiera oddzielne tryby dostawcy, takie jak **Auto** lub wyłączone. Zmienia on ten sam parametr co panel Parameters, dlatego jest ukryty, gdy model nie posiada ustawienia rozumowania lub gdy wdrożenie wyłącza parametry za pomocą `interface.parameters`.

## Kolejkuj i steruj podczas strumieniowania odpowiedzi [#queue-and-steer-while-a-response-streams]

Możesz pisać dalej, podczas gdy odpowiedź jest przesyłana strumieniowo. W zależności od endpoint i Twoich ustawień, naciśnięcie <kbd>Enter</kbd> albo dodaje wiadomość do kolejki, aby została wysłana po zakończeniu odpowiedzi, albo steruje bieżącą odpowiedzią agenta. Wskazówka w polu edytora określa akcję, którą <kbd>Enter</kbd> wykonuje w danym momencie.

Kolejkowane wiadomości pojawiają się na pasku **Queued messages** nad polem wprowadzania tekstu, gdzie możesz:

- **Edytuj wiadomość**, aby przenieść ją z powrotem do pola tekstowego.
- **Remove message**, aby usunąć ją z kolejki.
- **Wyślij teraz**, aby wysłać wiadomość natychmiast, zamiast czekać.
- Zmień kolejność wiadomości, przeciągając je lub ustawiając na nich fokus i używając klawiszy strzałek w górę i w dół.

Aby dowiedzieć się, jak działa sterowanie i kiedy jest dostępne, zobacz [Steering and Queued Messages](/docs/features/agents#steering-and-queued-messages).

## Skróty klawiszowe [#keyboard-shortcuts]

### W polu tekstowym [#in-the-text-field]

| Klucze | Akcja |
|---|---|
| <kbd>Enter</kbd> | Wyślij wiadomość (dodaj do kolejki lub steruj podczas strumieniowania odpowiedzi). |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Nowa linia. |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) | Podczas strumieniowania odpowiedzi: akcja alternatywna, **wyślij teraz**, gdy <kbd>Enter</kbd> dodaje do kolejki, lub **dodaj do kolejki**, gdy <kbd>Enter</kbd> steruje. |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> (<kbd>Option</kbd>+<kbd>Enter</kbd>) | Podczas gdy agent odpowiada: przerwij i wyślij, jeśli dostępne. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>) | Zatrzymaj odpowiedź. |
| `/` | Wstaw zapisany prompt. |
| `@` | Przełącz na inny model, preset lub agenta. |
| `+` | Dodaj model lub preset dla dodatkowej odpowiedzi. |
| `$` | Wybierz umiejętność dla następnej wiadomości. |

Jeśli wyłączyłeś **Naciśnij Enter, aby wysłać wiadomość**, <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) wyśle wiadomość, a <kbd>Enter</kbd> doda nową linię.

### W palecie [#in-the-palette]

| Klucze | Akcja |
|---|---|
| Wpisz | Wyszukaj narzędzia, umiejętności, serwery, opcje przesyłania i pliki. |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Poruszaj się między wierszami. |
| <kbd>Enter</kbd> | Wybierz podświetlony wiersz. |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd>) | Dodaj podświetlony wiersz do Ulubionych lub usuń go. |
| <kbd>Backspace</kbd> przy pustym polu wyszukiwania | Zamknij paletę. |
| <kbd>Escape</kbd> | Zamknij paletę. |
