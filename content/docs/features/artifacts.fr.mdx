Les artefacts permettent à un agent de vous remettre quelque chose que vous pouvez consulter et exécuter, au lieu d'un mur de code : un composant React, une page HTML, un SVG, un document Markdown ou un diagramme Mermaid. Le résultat s'ouvre dans un panneau à côté du chat, où vous pouvez le prévisualiser, lire et modifier le code source, et le télécharger.

## Activer les artefacts pour un agent [#turn-on-artifacts-for-an-agent]

Les artefacts appartiennent à un agent : c'est donc l'agent avec lequel vous discutez qui décide si vous pouvez les obtenir.

<Steps>
<Step>
Ouvrez l'agent dans le Constructeur d'agents et repérez la section **Tools**.
</Step>
<Step>
Sélectionnez **Ajouter** à côté de **Tools**, choisissez **Artifacts**, puis ajoutez-le à l'agent.
</Step>
<Step>
Choisissez un **Mode**, puis enregistrez l'agent.
</Step>
</Steps>

Le mode contrôle les instructions que LibreChat donne au modèle concernant les artefacts :

- **Normal** : les instructions standard. L'agent peut produire des artefacts React, HTML, SVG, Markdown et Mermaid.
- **shadcn/ui** : ajoute des instructions pour la bibliothèque de composants shadcn/ui, utile lorsque vous souhaitez créer des maquettes d'interface soignées à partir de composants préconçus.
- **Personnalisé** : conserve le panneau et le rendu activés, mais n'envoie aucune instruction intégrée. Les instructions propres à votre agent doivent enseigner au modèle la syntaxe des artefacts et les types qu'il peut utiliser.

Pour le mode Personnalisé, les instructions doivent afficher l'enveloppe que LibreChat recherche :

````md
:::artifact{identifier="unique-id" type="text/html" title="Short Title"}
```
Artifact content here
```
:::
````

`type` est l'une des valeurs suivantes : `text/html`, `application/vnd.react`, `image/svg+xml`, `application/vnd.mermaid` ou `text/markdown`.

## Ouverture d'un artefact [#opening-an-artifact]

Lorsque l'agent rédige un artefact, le message affiche une ligne indiquant le titre et le type de l'artefact au lieu du code brut. Cliquez dessus pour ouvrir le panneau, et cliquez à nouveau pour le fermer. Si une conversation a produit plusieurs artefacts, un menu de versions dans l'en-tête du panneau vous permet de passer de l'un à l'autre.

Les blocs de code Mermaid s'affichent sous forme de cartes de diagramme compactes dans n'importe quelle conversation, que l'agent ait activé ou non les artefacts. Utilisez **Ouvrir comme artefact** sur un diagramme pour le déplacer dans le panneau.

## Travailler dans le panneau [#working-in-the-panel]

- **Aperçu** affiche l'artefact. **Actualiser** recharge l'aperçu, ce qui est utile lorsqu'un composant interactif se trouve dans un état incorrect.
- **Code** affiche le code source dans un éditeur. Vous pouvez le modifier une fois la réponse entièrement diffusée, et vos modifications sont enregistrées dans le message, de sorte que l'aperçu et les visites ultérieures affichent la version modifiée.
- Le bouton de copie copie le code source. **Télécharger** l'enregistre sous forme de fichier portant le nom du titre de l'artefact. Un fichier provenant d'une exécution de code est téléchargé sous son nom d'origine si vous ne l'avez pas modifié ; un contenu modifié ou en aperçu uniquement reçoit le suffixe `.preview` dans son nom, afin que vous ne le confondiez pas avec l'original.
- Les diagrammes Mermaid proposent à la place **Exporter en SVG** et **Exporter en PNG**, à la fois dans le panneau et sur le diagramme intégré.
- **Passer en plein écran** agrandit l'aperçu à tout l'écran ; appuyez sur Échap pour quitter. Le bouton est masqué si votre navigateur n'autorise pas le mode plein écran.
- **Ouvrir dans une nouvelle fenêtre** déplace le panneau dans une fenêtre de navigateur distincte, ce qui est pratique sur un second écran. L'artefact continue de se mettre à jour pendant le streaming de la réponse, et les modifications de code non enregistrées sont conservées. Gardez l'onglet de discussion ouvert, car sa fermeture ferme également la fenêtre. **Réancrer au panneau** (ou la fermeture de la fenêtre) ramène le panneau, et LibreChat mémorise la taille et la position de la fenêtre. Si rien ne s'ouvre, autorisez les fenêtres pop-up pour votre site LibreChat. Le bouton n'est pas affiché sur les mises en page mobiles étroites.

L'aperçu s'exécute dans un iframe isolé (sandbox) à l'aide de Sandpack de CodeSandbox. Les artefacts React peuvent importer un ensemble fixe de bibliothèques courantes ; le modèle est informé des bibliothèques disponibles, et toute autre bibliothèque ne se chargera pas.

Les fichiers générés par l'exécution de code, tels que les rapports HTML, les documents Word, les feuilles de calcul et les présentations, s'ouvrent également dans ce panneau. Consultez [Code Interpreter](/docs/features/code_interpreter) pour savoir comment fonctionnent ces aperçus.

## Configuration [#setup]

Les artefacts sont activés par défaut pour les agents : la capacité d'agent `artifacts` est activée, sauf si un administrateur la supprime, et chaque agent doit toujours avoir Artifacts ajouté dans ses outils. Les administrateurs peuvent également activer les artefacts sur une spécification de modèle, héberger eux-mêmes le bundler Sandpack, ou désactiver l'option d'ouverture dans une nouvelle fenêtre. Voir [Configuration des artefacts](/docs/configuration/artifacts).
