Les Artifacts permettent aux Agents LibreChat de rendre des composants React, du HTML, du SVG, du Markdown et du contenu Mermaid générés dans une vue interactive dédiée. Les utilisateurs peuvent poursuivre la conversation pour réviser le résultat tout en conservant le contenu généré séparément de la réponse du chat.

## Activer les Artifacts pour un Agent [#enable-artifacts-for-an-agent]

1. Créez ou modifiez un [Agent](/docs/features/agents).
2. Ouvrez **Add tools** et sélectionnez **Artifacts**.
3. Choisissez un mode d'instruction pour les artefacts.
4. Enregistrer l'agent.

Les modes disponibles sont :

- **Normal** : Injecte les instructions standard de LibreChat pour les artefacts React, HTML, SVG, Markdown et Mermaid.
- **shadcn/ui** : Ajoute des conseils sur la bibliothèque de composants shadcn/ui pour des interfaces générées plus soignées.
- **Custom** : Maintient le rendu des artefacts activé mais n'injecte aucune instruction intégrée. Insérez le comportement complet de l'artefact souhaité dans les instructions de l'agent.

La configuration au niveau de l'agent est préférable car chaque agent peut utiliser le mode et les instructions appropriés à son objectif. L'administrateur peut masquer les Artifacts en supprimant la `artifacts` [capacité de l'agent](/docs/configuration/librechat_yaml/object_structure/agents#capabilities).

## Prise en charge des Artifacts [#what-artifacts-support]

- Composants React interactifs et pages HTML
- Images SVG et diagrammes Mermaid
- Documents Markdown rendus
- Mises à jour itératives via des messages de suivi
- Tout modèle disponible pour l'agent configuré

## Prévisualisation et exportation [#preview-and-export]

Utilisez la commande plein écran dans un aperçu d'artefact rendu pour l'étendre à l'affichage complet du navigateur. La commande suit l'état de l'API Fullscreen du navigateur, se ferme normalement avec la touche Échap ou les commandes du navigateur, et est masquée lorsque le mode plein écran n'est pas disponible.

Sur ordinateur, sélectionnez **Open in new window** dans l'en-tête du panneau d'artefact pour déplacer le panneau dans une fenêtre de navigateur séparée, par exemple pour le placer sur un second écran. L'artefact continue de se mettre à jour au fur et à mesure que la réponse est diffusée, et les modifications de code non enregistrées ainsi que l'onglet sélectionné sont conservés. Pour ramener le panneau dans le chat, sélectionnez **Dock back to panel** ou fermez la fenêtre. LibreChat mémorise la taille et la position de la fenêtre pour la prochaine fois.

- Gardez l'onglet de chat ouvert : la fenêtre est contrôlée par l'onglet de chat, et la fermeture de cet onglet ferme également la fenêtre.
- Si le navigateur bloque la fenêtre, LibreChat affiche un avis. Autorisez les fenêtres contextuelles pour le site et réessayez.
- Le bouton n'est pas affiché sur les mises en page étroites (mobiles).

Les administrateurs peuvent supprimer le bouton et conserver les artifacts dans le panneau latéral en définissant [`interface.artifactUndocking: false`](/docs/configuration/librechat_yaml/object_structure/interface#artifactundocking).

Les diagrammes Mermaid apparaissent sous forme de cartes intégrées compactes qui peuvent s'ouvrir dans le panneau des artefacts. Exportez un diagramme au format SVG ou PNG depuis la carte intégrée ou le panneau. Les aperçus Mermaid s'affichent directement sans charger le bundler Sandpack ; l'exportation PNG applique des dimensions de canevas limitées pour protéger le navigateur contre les diagrammes trop volumineux.

Les artefacts créés par le modèle sont téléchargés sous leur titre ou leur titre Markdown avec une extension correspondant au contenu exporté. Un artefact non modifié basé sur un fichier télécharge l'original complet avec son nom de fichier et son format d'origine lorsqu'ils sont disponibles. Le téléchargement de contenu modifié ou mis en cache utilise un qualificateur `.preview` afin qu'il ne soit pas confondu avec le fichier original.

## Content-Security-Policy

Il se peut que vous deviez mettre à jour la Content-Security-Policy de votre serveur web pour inclure `frame-src 'self' https://*.codesandbox.io` afin de charger les applications HTML générées dans le panneau Artifacts. Il s'agit d'une dépendance de la bibliothèque [sandpack](https://sandpack.codesandbox.io/).

## Auto-hébergement du Sandpack Bundler [#self-hosting-the-sandpack-bundler]

Les Artifacts dans LibreChat utilisent la bibliothèque Sandpack de CodeSandbox pour rendre le code HTML/JS de manière sécurisée. Par défaut, LibreChat se connecte au CDN public de CodeSandbox, qui peut également transmettre des données de télémétrie concernant son utilisation.

Pour une confidentialité renforcée, une conformité en matière de sécurité ou des environnements réseau isolés, vous pouvez [auto-héberger le bundler.](https://sandpack.codesandbox.io/docs/guides/hosting-the-bundler)

### Pourquoi auto-héberger le Sandpack Bundler ? [#why-self-host-the-sandpack-bundler]

[Auto-héberger le bundler](https://sandpack.codesandbox.io/docs/guides/hosting-the-bundler) offre plusieurs avantages :

- **Confidentialité et sécurité** : Gardez l'exécution du code au sein de votre propre infrastructure
- **Fiabilité** : Supprimer la dépendance aux services externes
- **Performance** : Réduisez la latence en hébergeant le bundler sur votre réseau
- **Conformité** : Répondre aux exigences organisationnelles en matière de traitement des données
- **Contrôle** : Configurez et personnalisez selon vos besoins spécifiques

### Configuration [#configuration]

Une fois que vous avez configuré un bundler auto-hébergé, configurez simplement LibreChat pour l'utiliser en définissant la variable d'environnement :

```bash
# `.env` file
SANDPACK_BUNDLER_URL=http://your-bundler-url
```

### Considérations générales [#general-considerations]

L'auto-hébergement du bundler introduit une surcharge supplémentaire :

- **Configuration CORS** : Vous devrez gérer les politiques de partage des ressources entre origines (cross-origin resource sharing).
- **Gestion de la sécurité** : Vous devenez responsable de la sécurité du service de bundler
- **Maintenance** : Les mises à jour et les correctifs devront être appliqués manuellement
- **Exigences en matière de ressources** : Des ressources serveur supplémentaires seront nécessaires pour héberger le bundler

Pour des instructions détaillées sur la configuration et la maintenance de votre bundler auto-hébergé, veuillez vous référer au [dépôt CodeSandbox forké](https://github.com/LibreChat-AI/codesandbox-client) adapté au déploiement de LibreChat, incluant la suppression de la télémétrie de Sandpack.
