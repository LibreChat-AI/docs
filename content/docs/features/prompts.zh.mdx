### 变量 [#variables]

使用 `{{notes}}` 来请求输入文本,或使用 `{{length:3 bullets|5 bullets}}` 来提供选项:

```text
Summarize these notes in {{length:3 bullets|5 bullets}}.

Notes: {{notes}}
```

LibreChat 会在你于聊天中使用该提示词时要求你填写这些值。特殊变量如 `{{current_date}}`、`{{current_datetime}}`、`{{iso_datetime}}` 和 `{{current_user}}` 会自动填充。其他变量如果没有被填充，则保留为原始文本。

### 版本与生产环境 [#versions-and-production]

保存编辑会创建一个新版本。其中一个版本会被标记为 **Production**。资源库和 `/` 菜单使用该版本。

| 编辑器设置 | 保存时会发生什么 |
| --- | --- |
| **高级提示词编辑器** 关闭 | 版本列表会被隐藏。每次保存都会成为正式版(Production)。 |
| 高级编辑器开启;**始终将新提示词版本设为正式版** 开启 | 每次保存都会成为正式版(Production)。您还可以浏览较早的版本。 |
| 高级编辑器开启;自动设为正式版关闭 | 保存版本后,使用 **部署(Deploy)** 将其设为正式版(Production)。 |

这些设置仅适用于您的浏览器。关闭高级编辑器也会自动开启 Production 模式。您可以在高级编辑器开启的状态下再次更改该开关。

## 将提示词用作智能体指令 [#use-a-prompt-as-agent-instructions]

将智能体链接到已保存的 LibreChat 提示词或已同步的 Langfuse 提示词。该链接会在每一轮对话中为智能体选择指令。

<Steps>
  <Step>在 **Agent Builder** 中打开智能体。在 **Instructions** 下，选择 **Prompt**。</Step>
  <Step>选择一个提示词，然后选择 **Production** 或特定版本。</Step>
  <Step>保存智能体。对于新智能体，请填写其必填字段并点击 **Create**。</Step>
</Steps>

### 生产环境还是固定版本? [#production-or-a-pinned-version]

选择 **Production** 可以跟随提示词所有者的更新。选择特定版本则会保持相同的指令,直到你更改链接为止。

![在版本 4 正式发布之前,两个智能体都使用版本 3。发布之后,跟随 Production 的智能体使用版本 4,而固定到版本 3 的智能体则继续使用版本 3。原生缓存设置可能会延迟 Production 的更新。](/images/features/prompts/production-vs-pinned.svg)

对于 LibreChat 提示词,**Production** 指的是标记为 Production 的修订版本。对于 Langfuse 提示词,则指带有 `production` 标签的版本。

### 指令何时被解析 [#when-instructions-are-resolved]

保存智能体时会检查提示词,但不会复制其文本。LibreChat 会在每一轮对话时解析该链接。原生提示词更新可能会因[缓存](/docs/configuration/librechat_yaml/object_structure/agents#linkedinstructions)而延迟生效;Langfuse 链接则每次都会重新获取。

特殊变量的使用方式与[内联代理指令](/docs/features/agents#instructions-from-a-saved-prompt)中的相同。自定义变量(例如 `{{notes}}`)**不会**为链接指令填充值,模型会将其作为字面文本接收。

<Callout type="warning" title="如果提示词不可用">
  该代理会在**指令为空**的情况下运行该轮对话。它不会使用其已保存的内联文本。
  记忆代理是一个例外:它使用其默认指令。
</Callout>

## 来自 Langfuse 的提示词 [#prompts-from-langfuse]

已同步的 Langfuse 提示词带有标有 **Managed in Langfuse** 的云图标。您可以在 LibreChat 中预览并使用它们。请在 Langfuse 中编辑其内容、提升版本以及删除这些提示词。

<ImageZoom src="/images/features/prompts/langfuse-preview.jpg" alt="只读 Langfuse 提示词预览,包含版本、标签以及“在 Langfuse 中打开”。">

仅支持 Langfuse **文本提示词**。打开某个提示词时,会从 Langfuse 获取其内容,且不做缓存。若在 Langfuse 中删除该提示词,LibreChat 中的提示词库条目会保留,但该条目将无法再解析。

### Langfuse 链接 [#langfuse-links]

管理员必须启用[提示词目录同步](/docs/configuration/langfuse#prompt-catalog)和[Langfuse 智能体指令](/docs/configuration/langfuse#prompts-as-agent-instructions)。链接功能默认关闭。必须保持目录同步处于启用状态,已保存的链接才能正常工作。

如果禁用了链接,Langfuse 提示词将从 Builder 的选择器中消失,但智能体已保存的选择除外。Builder 会在该选择上显示一条提示。链接仍保留在已保存的配置中,但智能体运行时不会使用这些指令。重新启用链接即可恢复,无需编辑智能体。

## 分享与权限 [#sharing-and-permissions]

提示词的所有者可以将其以**查看者（Viewer）**、**编辑者（Editor）**或**所有者（Owner）**的权限与用户、群组或角色共享。请参阅[访问控制](/docs/features/access_control)。

### 谁可以链接，谁可以运行 [#who-can-link-and-who-can-run]

| 任务 | 所需权限 |
| --- | --- |
| 使用提示词库 | 你的角色具有 `PROMPTS` 的 `USE` 权限,并可访问该提示词。 |
| 添加或更改智能体的提示词链接 | 对提示词具有 `PROMPTS` 的 `USE` 和 VIEW 权限,并且对新智能体具有 `AGENTS` 的 `CREATE` 权限,或对现有智能体具有 EDIT 权限。 |
| 保留或移除链接;切换为内联指令 | 与智能体级别相同的权限。系统不会再次检查提示词的访问权限。 |
| 与使用提示词的智能体聊天 | 具有与该智能体聊天的权限。无需具有其关联提示词的访问权限。 |
| 共享提示词 | 与选定的用户、群组或角色共享需要 `SHARE` 权限;与所有人共享需要 `SHARE_PUBLIC` 权限。 |

一名无权访问该提示词的协作编辑者会看到**受限提示词**。他们可以替换链接，或改用内联指令，但无法看到链接指向的目标。代理查看者则永远看不到该链接。

管理员在[管理面板](/docs/features/admin_panel)或[访问控制配置](/docs/configuration/access_control#feature-permissions)中设置角色权限。拥有 `manage:prompts` 权限的委派管理员可以查看并链接任何组，无需单独的 VIEW 授权。链接操作仍需要 `PROMPTS` 的 `USE` 权限。

## 详情与故障排除 [#details-and-troubleshooting]

<Accordions type="single" collapsible>
  <Accordion title="版本历史、复制与还原">
    更改提示词、其版本或指令来源会在智能体的版本历史中添加一条记录。

    **复制**和**还原**会复制已保存的链接，而不会进行新的 USE 或 VIEW 检查。如果新的编辑器无法查看该提示词，构建器会显示**受限提示词**。
  </Accordion>
  <Accordion title="用量计数的含义">
    每个关联的智能体在成功完成初始化后会增加一次使用计数。这与提示卡片和斜杠菜单所使用的计数器相同。交接和子智能体可能在一轮对话中增加多次使用计数。

    恢复已暂停的运行不会额外增加一次使用。memory agent 也从不会增加使用次数。
  </Accordion>
  <Accordion title="管理 API 的限制">
    在 Agent Builder 中设置 prompt 链接。Management API 及其 OpenAPI 规范不接受或返回 `instructionsPrompt`。

    通过该 API 更改 `instructions` 不会改变已关联代理所使用的内容。以关联为准。Langfuse 链接仅支持文本提示词;原生提示词组则没有此限制。
  </Accordion>
  <Accordion title="排查 Builder 消息问题">

    | 消息 | 处理方法 |
| --- | --- |
| "This prompt selection isn't available right now." | 选择其他提示词或版本，或在问题解决后重试。该版本可能已被删除、被策略阻止，或无法从 Langfuse 获取。链接功能可能已被禁用，或该组的来源可能已发生变化。 |
| "You don't have permission to link this prompt." | 请向管理员申请 `PROMPTS` `USE` 权限，或向所有者申请该组的 VIEW 权限。 |
| "You don't have access to the prompt library." | 选择器或版本列表需要 `PROMPTS` `USE` 权限以及该组的 VIEW 权限。请联系管理员或所有者。 |
| "This prompt's source isn't available right now." | 请检查 Langfuse 同步配置，或替换链接。同步可能已被禁用或未配置，来源可能已发生变化，或该提示词现在可能已变为聊天提示词。 |
| "Couldn't load prompts." | 请重试。如果问题持续存在，请让管理员检查服务器日志。这是意外的加载错误，而非权限或来源错误。 |
| "Selected version (no longer available)" | 原始修订版本已被删除。请选择 **Production** 或其他版本。 |
| "Version N (no longer available)" | Langfuse 中已不再列出该版本。请选择 **Production** 或其他版本。 |
| "Restricted prompt" | 请申请 VIEW 权限、替换链接，或切换为内联指令。该组也可能已被删除。即使是智能体的所有者也可能看到此提示。 |
| "Prompt not found" | 该组已被删除。请选择其他提示词，或切换为内联指令。拥有 `manage:prompts` 或 `ADMIN` 权限的用户将看到此提示，而不是 **Restricted prompt**。 |
| "Couldn't validate the linked prompt. Please try again." | 意外错误导致验证失败。请尝试再次保存。 |

  </Accordion>
</Accordions>
