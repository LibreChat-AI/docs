OCR 让 LibreChat 能够读取仅以像素形式存在的文本:例如收据照片、扫描合同,或由截图制作的 PDF。当管理员设置了 OCR 服务后,以文本形式添加的文件会先经过该服务处理,因此模型获取到的是文字内容,而不是空结果。

## 适用 OCR 的场景 [#where-ocr-applies]

OCR 会对文件执行，其提取的文本会被放入模型的上下文中：

- **Upload as Text**(上传为文本)在聊天中,适用于显示明确上传菜单的部署环境。参见 [Upload as Text](/docs/features/upload_as_text)。
- 在智能体构建器中,**文件上下文**会将提取的文本包含在智能体每条消息的上下文中。

默认情况下，它支持处理的文件类型包括：图像（JPEG、PNG、GIF、WebP、HEIC、HEIF）、PDF、Word、PowerPoint、Excel、EPUB 和 OpenDocument 文件。其他文件将跳过 OCR，改用常规文本提取。

使用默认的**From Local Computer**选项时,具体行为取决于文件被路由到哪里。提供方支持的图片和 PDF 会直接发送给模型,跳过 OCR。被改为按文本处理的文件(例如 Word 文档,或管理员设置为按文本处理的 PDF)会与 Upload as Text 采用相同的方式提取内容,因此当 OCR 负责处理该类型文件时,会经过 OCR 处理。

## 不使用 OCR [#without-ocr]

没有 OCR 服务时，文本提取功能依然可用。LibreChat 内置的解析器可以读取 PDF、DOCX、XLS 和 XLSX、ODT 以及 ODS 文件，文件大小上限为 15 MB，且文件须包含真实的文本层，这涵盖了大多数从编辑器导出的文档。旧版 `.doc`、PowerPoint 和 EPUB 文件则需要 OCR。此外，解析器无法读取图片：扫描版 PDF 或页面照片会失败，并提示该文档可能为基于图像的文件，需要 OCR 服务。

如果已配置 OCR,但服务在处理某个文档时出错,LibreChat 会对该文件回退使用内置解析器。

## OCR 服务 [#ocr-services]

管理员选择一种策略:

- 通过 Mistral API 使用 Mistral OCR。这是默认策略。
- Mistral OCR 部署于 Azure AI Foundry。
- 在 Google Cloud Vertex AI 上部署的 Mistral OCR。
- 本地文档解析器，无需任何外部服务。它只能读取文本层，无法识别图片。

使用任何 Mistral 选项时,文件内容都会发送至该服务进行处理,因此其数据处理条款同样适用。

## 改为上传至提供商 [#upload-to-provider-instead]

许多模型自身就能读取图片和 PDF。以附件形式发送给服务商时,文件由服务商进行解析,这样可以保留文本提取会丢失的版式和图片。默认上传器会在服务商支持的情况下,自动对图片和 PDF 执行此操作;若使用旧版上传菜单,请在[输入框](/docs/features/composer#add-files)中选择**上传至服务商**。

以下这些提供商支持以这种方式接收文件:OpenAI、Anthropic、Google 和 Vertex AI、AWS Bedrock、Mistral、DeepSeek、Moonshot、OpenRouter、xAI 以及自定义端点。Azure OpenAI 仅在会话参数中启用 Responses API 时才以这种方式接收 PDF;若使用 Chat Completions,则只接收图片。

各个提供商接受的内容各不相同:

- 所有这些都支持图片和 PDF。
- Google、Vertex AI 和 OpenRouter 也支持音频和视频。
- AWS Bedrock 还支持 CSV、DOC、DOCX、XLS、XLSX、HTML、TXT 和 Markdown 格式的文件,每个文档最大 4.5 MB。对于 Claude 4 及更高版本的 PDF,以及 Nova 的 PDF 和 DOCX 文件,最大可达 32 MB,除非您的管理员设置了更低的文件大小限制。请参阅 [AWS Bedrock](/docs/configuration/pre_configured_ai/bedrock)。

## 设置 [#setup]

在添加 `ocr` 配置段到 `librechat.yaml` 之前,OCR 处于关闭状态。管理员可在 [OCR 配置参考](/docs/configuration/librechat_yaml/object_structure/ocr) 中查看策略、密钥和端点的说明。发送到 OCR 的文件类型通过 [`fileConfig`](/docs/configuration/librechat_yaml/object_structure/file_config#ocr) 中的 `fileConfig.ocr.supportedMimeTypes` 进行设置。代理还需要 `ocr` 功能,该功能默认开启。
