### Variabelen [#variables]

Gebruik `{{notes}}` om om tekst te vragen, of `{{length:3 bullets|5 bullets}}` om keuzes aan te bieden:

```text
Summarize these notes in {{length:3 bullets|5 bullets}}.

Notes: {{notes}}
```

LibreChat vraagt om deze waarden wanneer je de prompt in de chat gebruikt. Speciale variabelen zoals `{{current_date}}`, `{{current_datetime}}`, `{{iso_datetime}}` en `{{current_user}}` worden automatisch ingevuld. Andere variabelen blijven als letterlijke tekst staan als er niets is die ze invult.

### Versies en productie [#versions-and-production]

Het opslaan van een bewerking maakt een nieuwe versie aan. Eén versie is gemarkeerd als **Production**. De bibliotheek en het `/`-menu gebruiken die versie.

| Editorinstelling | Wat er gebeurt bij opslaan |
| --- | --- |
| **Geavanceerde prompteditor** uit | De lijst met versies is verborgen. Elke keer dat je opslaat, wordt het Productie. |
| Geavanceerde editor aan; **Maak altijd nieuwe promptversies Productie** aan | Elke keer dat je opslaat, wordt het Productie. Je kunt ook eerdere versies bekijken. |
| Geavanceerde editor aan; automatische Productie uit | Sla een versie op en gebruik vervolgens **Deploy** om deze Productie te maken. |

Deze instellingen gelden voor je browser. Het uitschakelen van de geavanceerde editor zet ook automatisch Productie aan. Je kunt die schakelaar opnieuw wijzigen wanneer de geavanceerde editor aan staat.

### Productie of een vastgezette versie? [#production-or-a-pinned-version]

Kies **Production** om de updates van de eigenaar van de prompt te volgen. Kies een specifieke versie om dezelfde instructies te behouden totdat je de koppeling wijzigt.

![Voordat versie 4 wordt gepromoveerd, gebruiken beide agents versie 3. Na promotie gebruikt de agent die Production volgt versie 4, terwijl de agent die aan versie 3 is vastgezet op versie 3 blijft. Native cache-instellingen kunnen de Production-update vertragen.](/images/features/prompts/production-vs-pinned.svg)

Voor LibreChat-prompts betekent **Production** de revisie die is gemarkeerd als Production. Voor Langfuse-prompts betekent het de versie met het label `production`.

### Wanneer instructies worden toegepast [#when-instructions-are-resolved]

Het opslaan van de agent controleert de prompt, maar kopieert de tekst ervan niet. LibreChat lost de koppeling bij elke beurt opnieuw op. Updates van native prompts kunnen worden vertraagd door de [cache](/docs/configuration/librechat_yaml/object_structure/agents#linkedinstructions); Langfuse-koppelingen worden elke keer opnieuw opgehaald.

Speciale variabelen werken zoals in [inline agent-instructies](/docs/features/agents#instructions-from-a-saved-prompt). Aangepaste variabelen zoals `{{notes}}` worden **niet ingevuld** voor gekoppelde instructies. Het model ontvangt ze als letterlijke tekst.

<Callout type="warning" title="Als de prompt niet beschikbaar is">
  De agent voert die beurt uit met **lege instructies**. Hij gebruikt zijn opgeslagen inline tekst niet.
  De geheugenagent vormt een uitzondering: die gebruikt zijn standaardinstructies.
</Callout>

Gesynchroniseerde Langfuse-prompts hebben een wolkpictogram met het label **Managed in Langfuse**. Je kunt ze bekijken en gebruiken in LibreChat. Bewerk hun inhoud, promoot versies en verwijder ze in Langfuse.

Alleen Langfuse **tekstprompts** worden ondersteund. Wanneer je er een opent, wordt de inhoud uit Langfuse opgehaald zonder deze in de cache op te slaan. Als je hem in Langfuse verwijdert, blijft het bibliotheekitem in LibreChat bestaan, maar kan het niet meer worden opgelost.

### Langfuse-links [#langfuse-links]

Een beheerder moet [prompt-catalogussynchronisatie](/docs/configuration/langfuse#prompt-catalog) en [Langfuse-agentinstructies](/docs/configuration/langfuse#prompts-as-agent-instructions) inschakelen. Koppelen is standaard uitgeschakeld. Catalogussynchronisatie moet ingeschakeld blijven, anders werken opgeslagen koppelingen niet.

Als koppelen is uitgeschakeld, verdwijnen Langfuse-prompts uit de keuzelijst van de Builder, behalve de opgeslagen selectie van de agent. De Builder toont een melding bij die selectie. De koppeling blijft opgeslagen, maar de agent draait zonder die instructies. Door koppelen weer in te schakelen, wordt deze hersteld zonder dat de agent opnieuw hoeft te worden bewerkt.

## Delen en rechten [#sharing-and-permissions]

Een promptbeheerder kan deze delen met gebruikers, groepen of rollen als **Viewer**, **Editor** of **Owner**. Zie [Toegangsbeheer](/docs/features/access_control).

### Wie kan koppelen en wie kan uitvoeren [#who-can-link-and-who-can-run]

| Taak | Benodigde toegang |
| --- | --- |
| De promptbibliotheek gebruiken | De `PROMPTS`-permissie `USE` van je rol en toegang tot de prompt. |
| Een promptlink van een agent toevoegen of wijzigen | `PROMPTS` `USE` en VIEW op de prompt, plus `AGENTS` `CREATE` voor een nieuwe agent of EDIT voor een bestaande agent. |
| Een link behouden of verwijderen; overschakelen naar inline-instructies | Dezelfde toegang op agentniveau. De toegang tot de prompt wordt niet opnieuw gecontroleerd. |
| Chatten met een agent die een prompt gebruikt | Toegang om te chatten met de agent. Toegang tot de gekoppelde prompt is niet vereist. |
| Een prompt delen | `SHARE` voor geselecteerde gebruikers, groepen of rollen; `SHARE_PUBLIC` voor iedereen. |

Een mede-editor zonder toegang tot de prompt ziet **Beperkte prompt**. Die persoon kan de link vervangen of overschakelen naar inline-instructies. Het doel van de link is voor hen niet zichtbaar. Een agent-viewer ziet de link nooit.

Beheerders stellen rolrechten in via het [Admin Panel](/docs/features/admin_panel) of de [toegangsbeheerconfiguratie](/docs/configuration/access_control#feature-permissions). Gedelegeerde beheerders met `manage:prompts` kunnen elke groep bekijken en koppelen zonder een afzonderlijke VIEW-toekenning. Koppelen vereist nog steeds `PROMPTS` `USE`.

## Details en probleemoplossing [#details-and-troubleshooting]

<Accordions type="single" collapsible>
  <Accordion title="Versiegeschiedenis, dupliceren en herstellen">
    Het wijzigen van de prompt, de versie of de bron van de instructies voegt een item toe aan de versiegeschiedenis van de agent.

    **Dupliceren** en **Herstellen** kopiëren de opgeslagen link zonder een nieuwe controle op GEBRUIK of WEERGAVE. Als de nieuwe editor de prompt niet kan bekijken, toont de Builder **Beperkte prompt**.
  </Accordion>
  <Accordion title="Wat het gebruiksaantal betekent">
    Elke gekoppelde agent voegt één gebruik toe nadat deze succesvol is geïnitialiseerd. Dit is dezelfde teller die wordt gebruikt door promptkaarten en het slash-menu. Overdrachten (handoffs) en subagents kunnen in één beurt meerdere gebruiken toevoegen.

    Het hervatten van een gepauzeerde run levert geen extra gebruik op. De geheugenagent voegt nooit extra gebruik toe.
  </Accordion>
  <Accordion title="Beperkingen van de Management API">
    Stel prompt-links in de Agent Builder in. De Management API en de bijbehorende OpenAPI-specificatie accepteren of retourneren `instructionsPrompt` niet.

    Het wijzigen van `instructions` via die API verandert niet wat een gekoppelde agent gebruikt. De koppeling heeft voorrang. Langfuse-koppelingen ondersteunen alleen tekstprompts; native promptgroepen hebben die beperking niet.
  </Accordion>
  <Accordion title="Problemen oplossen met Builder-berichten">

    | Bericht | Wat te doen |
| --- | --- |
| "Deze promptselectie is momenteel niet beschikbaar." | Kies een andere prompt of versie, of probeer het opnieuw zodra het probleem is opgelost. De versie is mogelijk verwijderd, geblokkeerd door beleid of niet beschikbaar in Langfuse. Koppelen is mogelijk uitgeschakeld, of de bron van de groep is gewijzigd. |
| "Je hebt geen toestemming om deze prompt te koppelen." | Vraag een beheerder om `PROMPTS` `USE`, of de eigenaar om VIEW op de groep. |
| "Je hebt geen toegang tot de promptbibliotheek." | De kiezer of versielijst vereist `PROMPTS` `USE` en VIEW op de groep. Vraag een beheerder of de eigenaar. |
| "De bron van deze prompt is momenteel niet beschikbaar." | Controleer de Langfuse-synchronisatieconfiguratie, of vervang de koppeling. Synchronisatie is mogelijk uitgeschakeld of niet geconfigureerd, de bron is mogelijk gewijzigd, of de prompt is inmiddels een chatprompt. |
| "Prompts konden niet worden geladen." | Probeer het opnieuw. Vraag een beheerder om de serverlogboeken te controleren als het probleem aanhoudt. Dit is een onverwachte laadfout, en geen toestemmings- of bronfout. |
| "Geselecteerde versie (niet langer beschikbaar)" | De oorspronkelijke revisie is verwijderd. Selecteer **Production** of een andere versie. |
| "Versie N (niet langer beschikbaar)" | De Langfuse-versie staat niet langer in de lijst. Selecteer **Production** of een andere versie. |
| "Beperkte prompt" | Vraag om VIEW, vervang de koppeling, of schakel over naar inline-instructies. De groep is mogelijk ook verwijderd. Dit kan zelfs voor de eigenaar van de agent verschijnen. |
| "Prompt niet gevonden" | De groep is verwijderd. Selecteer een andere prompt of schakel over naar inline-instructies. Gebruikers met `manage:prompts` of `ADMIN` zien dit in plaats van **Beperkte prompt**. |
| "De gekoppelde prompt kon niet worden gevalideerd. Probeer het opnieuw." | Een onverwachte fout heeft de validatie verhinderd. Probeer opnieuw op te slaan. |

  </Accordion>
</Accordions>
