Artifacts는 에이전트가 코드 덩어리 대신 직접 보고 실행할 수 있는 결과물을 전달하도록 합니다. 예를 들어 React 컴포넌트, HTML 페이지, SVG, Markdown 문서, Mermaid 다이어그램이 이에 해당합니다. 결과물은 채팅 옆의 패널에서 열리며, 여기서 미리 보기, 소스 코드 읽기 및 편집, 다운로드를 할 수 있습니다.

## 에이전트에 아티팩트 활성화 [#turn-on-artifacts-for-an-agent]

아티팩트는 에이전트에 속하므로, 대화하는 에이전트가 아티팩트 사용 여부를 결정합니다.

<Steps>
<Step>
Agent Builder에서 에이전트를 열고 **Tools** 섹션을 찾으세요.
</Step>
<Step>
**Tools** 옆의 **Add**를 선택하고, **Artifacts**를 고른 다음 에이전트에 추가하세요.
</Step>
<Step>
**모드**를 선택한 다음 에이전트를 저장합니다.
</Step>
</Steps>

이 모드는 LibreChat이 아티팩트와 관련하여 모델에게 어떤 지침을 제공할지 제어합니다:

- **일반**: 표준 지침입니다. 에이전트는 React, HTML, SVG, Markdown, Mermaid 아티팩트를 생성할 수 있습니다.
- **shadcn/ui**: shadcn/ui 컴포넌트 라이브러리에 대한 안내를 추가합니다. 미리 만들어진 컴포넌트로 다듬어진 인터페이스 목업을 만들고자 할 때 도움이 됩니다.
- **Custom**: 패널과 렌더링은 계속 켜 둔 상태로 유지되지만, 내장 지침은 전혀 전송되지 않습니다. 아티팩트 구문과 사용할 수 있는 유형을 모델이 이해하도록 하려면 에이전트 자체의 지침에 이를 직접 포함해야 합니다.

사용자 지정 모드의 경우, 지침에는 LibreChat이 찾는 래퍼를 표시해야 합니다:

````md
:::artifact{identifier="unique-id" type="text/html" title="Short Title"}
```
Artifact content here
```
:::
````

`type`은 `text/html`, `application/vnd.react`, `image/svg+xml`, `application/vnd.mermaid`, `text/markdown` 중 하나입니다.

## 아티팩트 열기 [#opening-an-artifact]

에이전트가 아티팩트를 작성하면, 메시지에는 원시 코드 대신 아티팩트의 제목과 유형이 표시된 행이 나타납니다. 이 행을 클릭하면 패널이 열리고, 다시 클릭하면 패널이 닫힙니다. 대화에서 여러 개의 아티팩트가 생성된 경우, 패널 헤더의 버전 메뉴를 통해 아티팩트 간에 전환할 수 있습니다.

Mermaid 코드 블록은 에이전트의 아티팩트 사용 여부와 관계없이 모든 채팅에서 간결한 다이어그램 카드로 렌더링됩니다. 다이어그램에서 **Open as artifact**를 사용하면 패널로 옮길 수 있습니다.

## 패널에서 작업하기 [#working-in-the-panel]

- **미리 보기**는 아티팩트를 렌더링합니다. **새로 고침**은 미리 보기를 다시 불러오며, 대화형 컴포넌트가 잘못된 상태에 빠졌을 때 유용합니다.
- **Code**은 편집기에서 소스를 보여 줍니다. 응답 스트리밍이 끝난 후에는 편집할 수 있으며, 변경 사항은 메시지에 다시 저장되므로 미리 보기와 이후 방문에서도 편집된 버전이 표시됩니다.
- 복사 버튼은 소스를 복사합니다. **다운로드**를 누르면 아티팩트의 제목을 따서 이름을 붙인 파일로 저장됩니다. 코드 실행으로 생성된 파일은 편집하지 않았다면 원본 파일 그대로 다운로드되며, 편집했거나 미리보기 전용인 콘텐츠는 원본과 혼동하지 않도록 파일 이름에 `.preview`가 붙습니다.
- Mermaid 다이어그램에는 대신 패널과 인라인 다이어그램 모두에서 **Export as SVG**와 **Export as PNG**가 있습니다.
- **전체 화면**을 누르면 미리 보기가 화면 전체로 확장되며, Escape 키를 눌러 종료할 수 있습니다. 브라우저가 전체 화면을 허용하지 않는 경우 이 버튼은 표시되지 않습니다.
- **새 창에서 열기**를 누르면 패널이 별도의 브라우저 창으로 분리되며, 보조 모니터를 사용할 때 유용합니다. 응답이 스트리밍되는 동안 아티팩트는 계속 업데이트되고, 저장되지 않은 코드 편집 내용도 함께 옮겨집니다. 채팅 탭을 열어 두십시오. 채팅 탭을 닫으면 창도 함께 닫힙니다. **패널로 다시 도킹**을 누르거나 창을 닫으면 패널이 다시 원래 위치로 돌아오며, LibreChat은 창의 크기와 위치를 기억합니다. 아무것도 열리지 않으면 LibreChat 사이트의 팝업을 허용하십시오. 이 버튼은 좁은 모바일 레이아웃에서는 표시되지 않습니다.

미리보기는 CodeSandbox의 Sandpack을 사용하여 샌드박스된 iframe에서 실행됩니다. React 아티팩트는 고정된 일반 라이브러리 세트를 가져올 수 있으며, 모델에는 사용 가능한 라이브러리가 전달됩니다. 그 밖의 라이브러리는 로드되지 않아 실패합니다.

코드 실행으로 생성되는 파일(예: HTML 보고서, Word 문서, 스프레드시트, 슬라이드 덱)도 이 패널에서 열립니다. 이러한 미리 보기가 어떻게 작동하는지는 [Code Interpreter](/docs/features/code_interpreter)를 참고하세요.

## 설정 [#setup]

에이전트의 경우 Artifacts는 기본적으로 활성화되어 있습니다. 관리자가 제거하지 않는 한 `artifacts` 에이전트 기능이 켜져 있으며, 각 에이전트는 여전히 도구에 Artifacts를 추가해야 합니다. 관리자는 Model Specs에서 Artifacts를 활성화하거나, Sandpack 번들러를 직접 호스팅하거나, 새 창 옵션을 끌 수도 있습니다. 자세한 내용은 [Artifacts 구성](/docs/configuration/artifacts)을 참조하세요.
