Anda dapat menambahkan parameter kueri ke URL chat untuk memilih endpoint dan model, memuat agent atau model spec, mengisi prompt, atau mengubah pengaturan model sebelum chat dimulai. Dengan cara ini, Anda dapat membuat bookmark, shortcut peluncur (Raycast, Alfred, atau kata kunci browser), atau tautan dari aplikasi lain yang langsung membawa seseorang ke pengaturan yang tepat.

```
https://chat.example.com/c/new?endpoint=anthropic&model=claude-sonnet-4-5&prompt=Summarize%20this%20article
```

Parameter bekerja pada chat baru (`/c/new`) maupun chat yang sudah ada (`/c/<conversation-id>`). Setelah LibreChat membacanya, parameter tersebut akan dihapus dari address bar, sehingga memuat ulang halaman tidak akan menerapkannya kembali.

## Pilih endpoint dan model [#pick-the-endpoint-and-model]

`endpoint` dan `model` bersama-sama merupakan kombinasi yang paling dapat diprediksi.

- `endpoint` saja akan beralih ke endpoint tersebut dan menggunakan model terakhir yang Anda pilih di sana, atau model pertama dalam daftarnya.
- `model` saja akan mengganti model di dalam endpoint saat ini, jika endpoint tersebut memilikinya.

Nilai endpoint bawaan adalah `openAI`, `azureOpenAI`, `google`, `anthropic`, `bedrock`, `agents`, `assistants`, dan `azureAssistants`. Untuk [custom endpoint](/docs/quick_start/custom_endpoints), gunakan nama dari konfigurasi Anda; pencocokannya tidak peka terhadap huruf besar/kecil, sehingga `endpoint=openrouter` akan menemukan endpoint bernama `OpenRouter`.

## Memuat agent, assistant, atau model spec [#load-an-agent-assistant-or-model-spec]

```
/c/new?agent_id=agent_abc123
/c/new?assistant_id=asst_abc123
/c/new?spec=meeting-notes
```

`agent_id` dan `assistant_id` menetapkan endpoint untuk Anda. `spec` memuat [model spec](/docs/configuration/librechat_yaml/object_structure/model_specs) berdasarkan `name`-nya. Setiap pengaturan lain dalam URL yang sama diterapkan di atas preset dari spec tersebut. Jika admin Anda menerapkan model specs, sertakan `spec` di setiap tautan, dan perlu diketahui bahwa nilai dari spec itu sendiri akan lebih diutamakan daripada URL.

## Isi atau kirim prompt [#fill-in-or-send-the-prompt]

`prompt` (atau `q` yang lebih pendek) memasukkan teks ke dalam kotak pesan. Jika keduanya ada, `prompt` yang diutamakan.

Tambahkan `submit=true` untuk mengirimkannya segera setelah chat siap:

```
/c/new?endpoint=openAI&model=gpt-4o&prompt=Explain%20quantum%20computing&submit=true
```

Jika pengaturan yang diminta tidak dapat diterapkan dalam beberapa detik, prompt akan tetap berada di kotak pesan dan tidak dikirim. Admin Anda juga dapat mematikan pengiriman otomatis, dalam hal ini `submit=true` hanya mengisi prompt dan Anda harus menekan tombol kirim sendiri.

Nilai harus di-URL-encode. Dalam JavaScript, `encodeURIComponent()` melakukannya:

```js
const url = `/c/new?prompt=${encodeURIComponent('Write a function: def hello()')}`;
// /c/new?prompt=Write%20a%20function%3A%20def%20hello()
```

## Ubah pengaturan model [#change-model-settings]

Salah satu dari parameter ini dapat ditambahkan ke URL. Masing-masing hanya berlaku pada endpoint yang mendukungnya, dan nilainya diperiksa sebelum diterapkan; nilai yang tidak valid akan diabaikan tanpa menampilkan error.

| Endpoint | Parameter |
| --- | --- |
| Semua | `maxContextTokens`, `resendFiles`, `promptPrefix` (instruksi kustom) |
| OpenAI, Azure OpenAI, custom | `temperature`, `top_p`, `presence_penalty`, `frequency_penalty`, `stop`, `max_tokens`, `reasoning_effort`, `reasoning_summary`, `verbosity`, `useResponsesApi`, `disableStreaming`, `imageDetail` (`low`, `auto`, `high`) |
| OpenAI Responses API | `reasoning_mode` (`standard`, `pro`), `reasoning_context` (`auto`, `current_turn`, `all_turns`) |
| OpenAI, Anthropic, Google | `web_search` (`true`/`false`), `fileTokenLimit` (batas token untuk konten file) |
| Anthropic, Google | `temperature`, `topP`, `topK`, `maxOutputTokens`, `thinking`, `thinkingBudget`, `thinkingLevel` |
| Anthropic | `effort` (`low`, `medium`, `high`, `xhigh`, `max`), `thinkingDisplay` (`auto`, `summarized`, `omitted`, atau `updates` untuk hanya catatan kemajuan di antara pemanggilan tool) |
| Anthropic, Bedrock (model Anthropic), OpenRouter | `promptCache` (`true`/`false`), `promptCacheTtl` (`5m` atau `1h`) |
| Google | `url_context=true` memungkinkan Gemini membaca URL dalam pesan Anda |
| Bedrock | `region`, `maxTokens`, `temperature`, `topP`, `reasoning_effort` |
| Assistants | `instructions` (menggantikan instruksi asisten untuk run ini), `append_current_datetime=true` |

Arti dan nilai yang diizinkan dari setiap field tercantum di [model spec preset fields](/docs/configuration/librechat_yaml/object_structure/model_specs). Jika Anda memberikan nilai yang ditolak oleh penyedia (misalnya `max_tokens` yang melebihi batas model), Anda akan mendapatkan error API saat mengirim pesan; mulai **New chat** untuk menghapusnya.

## Atur mode warna [#set-the-color-mode]

Jika admin Anda mengaktifkannya, `theme=light`, `theme=dark`, atau `theme=system` pada sebuah tautan akan mengatur mode warna Anda, sehingga aplikasi yang menautkan ke LibreChat dapat meneruskan tema miliknya sendiri. Pengaturan ini disimpan sebagai preferensi Anda hingga Anda mengubahnya di pengaturan.

## Pengaturan [#setup]

Parameter query berfungsi tanpa konfigurasi tambahan. Admin dapat menghentikan `submit=true` agar tidak dikirim secara otomatis dengan [`interface.autoSubmitFromUrl`](/docs/configuration/librechat_yaml/object_structure/interface#autosubmitfromurl), dan mengaktifkan parameter `theme` dengan [`interface.colorModeFromUrl`](/docs/configuration/librechat_yaml/object_structure/interface#colormodefromurl).
