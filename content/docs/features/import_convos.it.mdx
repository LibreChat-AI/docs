Puoi importare le conversazioni esportate da ChatGPT, Claude e [ChatbotUI v1](https://github.com/mckaywrigley/chatbot-ui/tree/b865b0555f53957e96727bc0bbb369c9eaecd83b?tab=readme-ov-file#legacy-code), così come una conversazione esportata da LibreChat in formato JSON. Le chat importate compaiono nella cronologia come qualsiasi altra. L'esportazione funziona una conversazione alla volta.

## Importa il file [#import-the-file]

Vai su **Impostazioni** > **Dati e privacy**, seleziona **Importa** accanto a "Importa conversazioni da un file JSON", quindi scegli il file. Il selettore accetta solo file `.json`, quindi decomprimi prima gli archivi di ChatGPT e Claude. Il pulsante mostra "Importazione in corso" mentre l'operazione è in esecuzione e, al termine, compare "Conversazioni importate con successo".

LibreChat determina il formato dal contenuto del file, non dal suo nome. Se il file non viene riconosciuto, compare il messaggio "Unsupported import type".

Un'importazione in LibreChat non trasferisce la modalità di approvazione del codice salvata nella conversazione (incluso **Full access**) né il suo stato di lettura. La chat importata utilizza la tua preferenza di approvazione attuale e la policy dell'installazione.

### Limiti [#limits]

- Il file può avere una dimensione massima di 250 MiB, salvo diversa impostazione dell'amministratore. I file più grandi vengono rifiutati prima del caricamento.
- Una singola conversazione o messaggio non può superare circa 16 MB, che è un limite del database.
- Le importazioni sono soggette a limiti di frequenza per utente e per indirizzo IP, quindi l'importazione di molti file consecutivi può essere rifiutata per un certo periodo di tempo.

## Esporta una conversazione [#export-a-conversation]

Apri la conversazione, apri il menu **Opzioni chat** (il pulsante `...` nell'intestazione, oppure il menu dell'intestazione sugli schermi piccoli), e seleziona **Esporta**. Scegli un nome file e un tipo, quindi seleziona **Esporta**.

| Tipo | Cosa ottieni |
| --- | --- |
| `markdown` (.md) | Una trascrizione leggibile. Questo è il valore predefinito. |
| `text` (.txt) | Una trascrizione in testo semplice. |
| `json` (.json) | I dati completi dei messaggi. Questo è il formato che LibreChat può importare di nuovo. |
| `csv` (.csv) | Una riga per ogni messaggio. |
| `screenshot` (.png) | Un'immagine della conversazione così come appare sullo schermo. |

**Esporta tutti i rami dei messaggi** funziona per `json` e `csv`; gli altri tipi esportano solo il ramo che stai visualizzando. **Includi opzioni dell'endpoint** aggiunge il modello e le sue impostazioni, e non è disponibile per `csv` o `screenshot`. Per `json` puoi anche scegliere **Ricorsivo** (messaggi annidati sotto il rispettivo messaggio padre) oppure sequenziale.

Non esiste un'esportazione di tutte le conversazioni in una volta sola, e una nuova chat o un risultato di ricerca non ha nulla da esportare, quindi il menu non compare in quei casi.

## Setup [#setup]

L'importazione e l'esportazione funzionano per ogni utente senza alcuna configurazione. Gli amministratori possono modificare il limite di dimensione dell'importazione con `CONVERSATION_IMPORT_MAX_FILE_SIZE_BYTES` e i limiti di frequenza con le variabili `IMPORT_*`; vedere il [riferimento .env](/docs/configuration/dotenv#conversation-import).
