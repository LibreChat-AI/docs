Code Interpreter 在隔离的沙盒环境中运行代码。智能体可借助它进行原本只能估算的数学运算、分析您上传的电子表格、转换文件，或生成图表和文档。您也可以通过 **Run Code** 手动运行聊天消息中的代码块。

沙箱是一个独立服务,即 [ClickHouse/code-interpreter](https://github.com/ClickHouse/code-interpreter)(开源,Apache 2.0 许可),由管理员部署在 LibreChat 旁边。它支持 Python、Node.js(JavaScript 和 TypeScript)、Go、C 和 C++、Java、PHP、Rust 以及 Fortran。

## 为智能体提供代码执行能力 [#give-an-agent-code-execution]

在智能体构建器中,点击**工具**旁边的**添加**,然后添加**运行代码**。保存智能体。此后,智能体会自行决定何时运行代码;您无需明确要求,不过当您需要精确答案时,说“使用代码来检查这个”会有所帮助。

在代码运行期间,消息中会显示一个可折叠的行。首次运行时显示为**Starting sandbox environment**,随后显示**Analyzing**,完成后显示**Finished analyzing**。展开该行即可查看智能体编写的代码及其**Output**。

## 处理文件 [#working-with-files]

在对话中附加文件并选择**上传到代码环境**,即可让该对话的沙箱使用此文件。在智能体的“运行代码”设置中添加的文件,会在与该智能体的每次对话中都可用。每次运行前,LibreChat 都会将该对话的文件恢复到沙箱中;如果本次运行所需的文件均无法恢复,运行将会停止,并提示您重新附加这些文件,而不会使用过期的副本继续执行。

代码写入的文件会以行的形式返回到消息中。点击某一行即可在[Artifacts](/docs/features/artifacts)面板中打开它,也可以直接下载。HTML、Markdown、纯文本、源代码、CSV以及Office文件(Word、Excel、OpenDocument、PowerPoint演示文稿和模板)会显示内联预览。较大的文件将跳过预览,仅提供下载;默认的源文件大小上限为2 MiB。智能体从沙箱中读取的图片(PNG、JPEG、GIF、WebP)最大1 MiB时会内联显示;更大的图片则保留在沙箱中,智能体仍可对其进行处理。

## 自行运行代码块 [#run-a-code-block-yourself]

聊天消息中的代码块,当其语言为沙箱可运行的语言(Python、JavaScript、TypeScript、Go、C、C++、D、Java、PHP、Rust 或 Fortran)时,会在 **Copy code** 旁边显示 **Run Code** 按钮。点击该按钮后,输出结果会显示在代码块下方。此功能适用于任何对话,而不仅限于智能体对话。

## 长时间运行的代码 [#long-running-code]

如果您的管理员已启用后台工具,则智能体的“运行代码”设置中会显示**后台执行**,默认处于开启状态。智能体可以启动耗时较长的代码,同时继续与您对话,并在运行完成后获取输出和文件;默认情况下,结果会自动通过后续消息送达。对于应始终等待代码执行完成的智能体,请关闭此设置。

内存、CPU 时间、上传大小和网络访问由运行沙箱服务的人员设定,而不是由 LibreChat 设定。如果代码因资源错误而失败,请咨询管理员了解具体限制。

## 有状态的代码会话 [#stateful-code-sessions]

默认情况下，每次运行都是无状态的：不要指望变量或已安装的软件包会保留到下一次运行。有状态代码会话是一项实验性功能，需要管理员手动开启。它为智能体提供一个工作区，可在多次运行之间将文件保存在 `/mnt/data` 下。不过，每次运行仍会启动一个新进程，并且工作区随时可能被重置，因此应将其视为临时的暂存区，而非持久存储。

在智能体的 Run Code 设置中开启 **Stateful code sessions**,并选择一个 **Stateful environment**:

- **用户工作区（推荐）**：为您提供一个专属工作区，供您使用的所有有状态智能体共享。
- **Agent + 用户工作区**:为每个代理提供独立的工作区。
- **对话工作区**:为每个对话提供一个全新的工作区。

新建的智能体会以 **设置 > 数据与隐私 > 代码执行 > 默认有状态工作区** 中设定的范围启动;更改该设置不会影响现有的智能体。智能体在有状态工作区中创建或编辑的文件,会列在其回复中的 **工作区更改** 一行下,每个文件均附有下载链接。

## 在您自己的机器上运行代码 [#running-code-on-your-own-machine]

管理员也可以提供代码执行环境：即运行 `@librechat/code` 工作进程的虚拟机或工作站，该进程会主动连接到 LibreChat。配置完成后，Agent Builder 会显示 **Execution environment** 选择器，而 **Machines available in new chats** 则允许智能体提供多台机器，使每个新对话都可以通过 **Choose another machine** 选择其中一台。

如果您有权限管理代码环境,可以在 **Settings > Data & Privacy > Code execution > Code environments** 下添加您自己的环境:为其命名,选择 **Connect VM**,然后在您的机器上运行其显示的一次性命令。如果您的管理员启用了浏览器设置,则设置命令可以改为打开 **Approve Machine Setup** 页面,您可以在登录状态下在该页面确认请求。

在已连接的机器上,智能体可以在所选工作区中浏览、读取、搜索和编辑文件,并运行 Shell 命令。您上传的聊天附件会在智能体启动前复制到该工作区的 `.librechat/attachments` 目录中。由于这些操作会改变真实机器的状态,输入框会为该对话显示 **Code approval mode(代码审批模式)**。

- **Ask before changes**:在文件编辑和命令执行前询问。
- **接受编辑**:无需询问即可编辑文件,但仍会在执行命令前询问。
- **完全访问**:无需例行确认即可编辑文件并运行命令。机器上的沙盒限制仍然适用。

可供选择的模式取决于管理员的策略。配对机器只是对工作节点进行身份验证以连接 LibreChat,并不会提供沙箱隔离,因此应像对待任何运行不受信任代码的机器一样,对该工作节点进行隔离。

## 从代码中调用 MCP 工具 [#calling-mcp-tools-from-code]

通过程序化工具调用(Programmatic Tool Calling),智能体可以在沙箱内部调用选定的 MCP 工具:它编写一段脚本,循环处理输入、调用工具、筛选结果,并仅返回真正需要的内容。这样每次工具调用都无需经过一次模型往返,从而节省开销。在智能体启用 Run Code 之前,Programmatic 开关保持禁用状态;移除 Run Code 时,这些开关会被清除。脚本运行期间,展开其所在行即可查看 **Tool calls** 跟踪记录;该记录在页面刷新后不会保留。只有注册到该智能体的工具才能以这种方式调用。有关如何标记工具,请参阅[程序化工具调用](/docs/features/agents#programmatic-tool-calling)。

## 设置 [#setup]

代码执行需要管理员部署 Code Interpreter 服务并将 LibreChat 指向该服务;在此之前,代码运行都会失败。**Run Code** 按钮和智能体功能也可以按角色关闭。后台执行、有状态会话和代码环境均为可选启用项。详见 [Code Interpreter 配置](/docs/configuration/tools/code_interpreter)。
