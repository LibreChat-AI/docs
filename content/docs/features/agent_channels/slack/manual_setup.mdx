---
title: Manual Connection
description: Create a dedicated Slack app for one agent from a generated manifest, add its credentials, and activate the connection.
icon: Wrench
---

A manual connection gives one agent its own Slack app. LibreChat generates the app manifest for you, so you mostly copy, paste, and click. Each manual connection is served by its own gateway process, which your operator starts once the connection is active.

Use this path when your deployment does not enable [organization workspaces](/docs/features/agent_channels/slack/organization_setup), for example when the gateway cannot accept public HTTPS traffic.

## Before you start

<Callout type="info" title="Checklist">
- Your operator has enabled Channels in `librechat.yaml` and chosen a transport (Socket Mode or webhook). See [Deploy the gateway](/docs/features/agent_channels/deployment#manual-connection).
- Your role can use **Remote Agents**, and you can share the agent you want to connect.
- You can create and install apps in the Slack workspace.
</Callout>

The agent must be saved before it can be connected. New agents show **Save this Agent to configure channels.** in the Channels section until then.

## 1. Choose who can use the bot

<Steps>
<Step>

Open the agent in the Agent Builder. In the **Channels** section, select **Add**, then choose **Slack** in the Channel Library.

  light="/images/features/agent_channels/channel-library-light.png"
  dark="/images/features/agent_channels/channel-library-dark.png"
  alt="Channels dialog with a search box and the Slack card in the Channel Library"
  width={640}
/>

</Step>
<Step>

Pick an identity mode, then select **Continue**.

- **Per-user accounts**: each person links and uses their own LibreChat account and permissions.
- **Channel owner only**: only you can use the bot, with your account. Other people's messages are not run.

  alt="Add Slack channel dialog asking Who can use this connection, with Per-user accounts selected and Channel owner only as the other choice"
  width={672}
/>

</Step>
</Steps>

## 2. Create the Slack app

The **Connect to Slack** wizard opens on the **Create** step.

<ThemeImage
  light="/images/features/agent_channels/manual-create-light.png"
  dark="/images/features/agent_channels/manual-create-dark.png"
  alt="Connect to Slack wizard on the Create step, with a Create in Slack button and the manual manifest fallback"
  width={672}
/>

<Steps>
<Step>

Select **Create in Slack**. Slack opens with the manifest already filled in: the bot name, scopes, events, the Messages tab, and the right transport settings.

</Step>
<Step>

Choose your workspace, select **Next**, then **Create**.

</Step>
<Step>

In the new app, open **Install App**, select **Install to Workspace**, then **Allow**.

</Step>
</Steps>

If the link does not open the manifest, expand **Link not working? Paste the manifest manually**, copy it, and paste it into **Create New App → From a manifest** in Slack.

Back in LibreChat, select **Continue**.

## 3. Add the credentials

Copy these values from your new Slack app:

| LibreChat field | Where to find it in Slack |
| --- | --- |
| **Slack app ID** | **Basic Information → App Credentials → App ID** (starts with `A`) |
| **Bot token** | **OAuth & Permissions → Bot User OAuth Token** (starts with `xoxb-`) |
| **Signing secret** | **Basic Information → App Credentials → Signing Secret**. Required for webhook transport, optional for Socket Mode. |

<ThemeImage
  light="/images/features/agent_channels/manual-credentials-light.png"
  dark="/images/features/agent_channels/manual-credentials-dark.png"
  alt="Credentials step with Slack app ID, Bot token and optional Signing secret fields"
  width={672}
/>

Select **Continue**.

## 4. Activate

The **Activate** step summarizes what you entered, with the token masked. Check the app ID, then select **Activate channel**. LibreChat verifies the bot token with Slack and stores the credentials encrypted.

## 5. Start the gateway

The connection is active, but Slack can only reach the agent once its gateway is running.

<Steps>
<Step>

Open the connection's **Manage connection** dialog (shown below) and hover over or focus the Slack icon in its header. A **Connection details** card appears with the **Connection ID**.

</Step>
<Step>

Send the Connection ID to your operator. For Socket Mode, they also need an app-level token: in Slack, open **Basic Information → App-Level Tokens**, select **Generate Token and Scopes**, add the `connections:write` scope, and share the `xapp-` token through your usual secret channel.

</Step>
<Step>

The operator [starts the gateway](/docs/features/agent_channels/deployment#manual-connection) for that connection. For webhook transport, the manifest already points Slack at the gateway's public URL.

</Step>
</Steps>

<ThemeImage
  light="/images/features/agent_channels/manual-manage-light.png"
  dark="/images/features/agent_channels/manual-manage-dark.png"
  alt="Manage connection dialog for an active manual connection with usage instructions for @support_assistant, the identity mode, the manifest and a Disable button"
  width={672}
/>

The **Manage connection** dialog now shows how to reach the bot: invite it with `/invite @your_bot`, mention it, or message it from **Apps**. Next, [link your account and send a first request](/docs/features/agent_channels/slack/using_slack).

## Manage a manual connection

<Accordions type="single" collapsible>
<Accordion title="Disable or reactivate">

Select **Disable** in **Manage connection** and confirm. Slack stops getting answers until you activate it again. To reactivate, open **Setup**, re-enter the bot token (and signing secret for webhooks), and select **Activate channel**. Everyone must link their account again.

</Accordion>
<Accordion title="Change who can use it">

Changing the identity mode ends every existing link and pending request.

1. In **Manage connection**, select the pencil next to the identity mode. If the connection is active, confirm **Disable and change**.
2. Choose the new mode and select **Save**.
3. Open **Setup**, keep the existing Slack app, and re-enter its bot token (and signing secret for webhooks).
4. Select **Activate channel**. Each person links and confirms their account again.

</Accordion>
<Accordion title="Update the Slack app">

Make changes to the app in Slack's app settings. Expand **Manifest** in **Manage connection** to copy the manifest LibreChat expects. Reinstall the app in Slack after changing scopes.

</Accordion>
<Accordion title="Delete the connection">

Hover over or focus the connection in the Channels section, select the **X** (**Delete connection**), and confirm. This removes the connection and its saved credentials. The Slack app stays installed in your workspace; uninstall it in Slack if you no longer need it. Ask your operator to stop its gateway.

</Accordion>
</Accordions>
