공유 가능한 링크를 사용하면 대화의 읽기 전용 브랜치를 게시하여 다른 사람들이 생성된 URL이나 QR 코드를 통해 열어볼 수 있습니다. 수신자는 원본을 변경하지 않고 게시된 메시지, 브랜치 및 아티팩트를 볼 수 있습니다. 로그인한 수신자는 표시된 브랜치부터 개인 복사본으로 대화를 이어갈 수 있습니다.

## 주요 기능 [#key-features]

- **간편한 공유**: 몇 번의 클릭만으로 링크를 생성하세요.
- **QR codes**: 코드를 스캔하여 휴대폰에서 대화를 엽니다.
- **브랜칭(Branching)**: 공유 링크는 대화의 모든 브랜치를 유지합니다.
- **Artifacts**: React 컴포넌트, HTML 미리보기 및 Mermaid 다이어그램이 대화형으로 유지됩니다.
- **파일 스냅샷**: 공유된 링크를 통해 참조된 대화 파일을 미리 보거나 다운로드할 수 있으며, 이때 수신자에게 소유자의 라이브 파일 ACL에 대한 액세스 권한을 부여하지 않아도 됩니다.
- **복사하여 계속하기**: 로그인한 사용자는 현재 보이는 브랜치를 자신의 대화 기록으로 복사하여 대화를 계속할 수 있습니다.
- **수신자 기본 설정**: 뷰어는 언어와 테마를 전환할 수 있습니다.
- **안정적인 업데이트**: URL을 변경하지 않고 최신 턴과 현재 파일 선택 항목을 게시합니다.
- **공유 배지**: 활성 링크는 대화 목록과 채팅 헤더에 표시됩니다.
- **링크 관리**: 생성한 모든 링크를 검토하거나 취소할 수 있는 단일 대시보드입니다.

## 공유 링크 옵션 [#share-link-options]

링크를 생성하면 대화가 수신자에게 어떻게 표시될지 제어할 수 있는 모달이 열립니다.

![공유 링크 생성 모달](/images/shared-links/share-modal-create.png)

![관리 옵션이 포함된 공유 링크 모달](/images/shared-links/share-modal-options.png)

링크가 생성되면, 모달에서 다음 작업들을 수행할 수 있습니다:

- **Update link**: 선택한 브랜치 끝과 현재 파일 공유 선택 항목을 통해 최신 메시지를 다시 게시하며, 동일한 URL을 유지합니다.
- **Show QR Code** / **Hide QR Code**: 모바일 접속을 위한 QR 코드를 표시하거나 숨깁니다.
- **Copy link**: 공유 가능한 URL을 복사합니다.
- **Manage Access**: 링크를 열 수 있는 사용자를 관리하려면 액세스 대화 상자를 엽니다. 이 항목은 역할에 공유 링크에 대한 공유 권한이 있고 해당 링크에 대한 공유 비트를 보유한 경우에만 표시됩니다.
- **삭제 링크**: 링크를 삭제하고, 이 링크를 가진 모든 사용자의 접근 권한을 취소합니다.

파일 스냅샷이 활성화되면, 사용자는 공유된 메시지에서 참조된 파일을 링크에 포함할지 여부를 선택할 수 있습니다. 선택된 파일은 해당 공유 리비전에 고정되며, 소유자의 라이브 파일 ACL에 대한 액세스 권한을 부여하지 않고 공유 전용 경로를 통해 제공됩니다. 링크를 업데이트하면 고정된 파일 세트와 파일 공유 선택 사항이 대체됩니다. 안정적인 파일 URL은 재검증되므로, 제거되거나 교체된 스냅샷은 이전 브라우저 캐시에서 제공되지 않습니다.

게시는 선택한 브랜치의 정확한 지속형 테일(persisted tail)과 연결됩니다. 최신 메시지가 여전히 저장 중인 경우, LibreChat은 다른 브랜치로 전환하지 않고 한 번 재시도합니다. 테일을 여전히 사용할 수 없거나 대화에 아직 지속된 메시지가 없는 경우, 모달에 특정 오류가 표시되어 대기 후 재시도할 수 있습니다. 사용할 수 없는 공유 링크 뷰에서도 동일한 URL을 다시 가져오기 위한 **Retry**를 제공합니다.

## QR 코드 [#qr-codes]

공유된 대화에 대한 QR 코드를 생성한 다음, 휴대폰 카메라로 스캔하여 링크를 엽니다. 이 코드는 동일한 공유 URL로 연결됩니다.

![공유 링크를 위해 생성된 QR 코드](/images/shared-links/qr-code.png)

![QR 코드 다운로드 옵션](/images/shared-links/qr-code-download.png)

QR 코드는 프레젠테이션, 빠른 모바일 액세스, 인쇄물 배포 및 컨퍼런스 데모에 유용합니다.

![수신자가 보는 공유 대화](/images/shared-links/shared-view.png)

## 공유된 대화 이어가기 [#continue-a-shared-conversation]

인증된 뷰어는 **Continue this chat**을 선택하여 현재 표시된 브랜치에서 개인 대화를 생성할 수 있습니다. LibreChat은 활성 메시지로 이어지는 직접적인 경로만 복사하며, 여기에는 적격한 스냅샷 파일 참조가 포함됩니다. 이후 뷰어의 계정으로 새로운 대화가 열립니다.

계속하기를 눌러도 공유된 스냅샷이나 소유자의 대화 내용은 변경되지 않습니다. 공개 뷰어는 LibreChat이 사본을 생성하기 전에 반드시 로그인해야 합니다.

복사 요청은 뷰어가 로드한 공유 리비전과 연결되어 있습니다. 뷰어가 작업을 계속하기 전에 소유자가 동일한 링크를 업데이트하면, LibreChat은 오래된 콘텐츠에서 메시지 위치를 복사하는 대신 현재 리비전을 다시 로드하고 뷰어에게 재시도를 요청합니다.

## 브랜칭 [#branching]

공유 링크는 대화의 분기를 보존하므로, 수신자는 대화가 진행된 다양한 경로를 따라갈 수 있습니다. 분기 탐색 화살표를 사용하여 경로 간을 이동하세요.

![공유된 대화 내 브랜치 탐색 메뉴](/images/shared-links/branching-menu.png)

![공유 대화에서 브랜치 탐색하기](/images/shared-links/branching-support.png)

이는 서로 다른 프롬프트가 어떻게 서로 다른 AI 응답을 이끌어내는지, 또는 하나의 문제를 여러 방식으로 어떻게 접근할 수 있는지 보여주는 데 유용합니다.

## Artifacts [#artifacts]

대화 중에 생성된 Artifacts는 공유 링크에서도 완전히 정상적으로 작동합니다.

![공유된 대화 내의 대화형 아티팩트](/images/shared-links/artifacts-support.png)

수신자는 다음을 수행할 수 있습니다:

- 대화형 React 컴포넌트를 확인하세요.
- HTML 미리보기를 참조하세요.
- Mermaid 다이어그램을 검토하세요.
- 기본 코드와 해당 코드가 생성된 맥락을 읽어보세요.

## 수신자 기본 설정 [#recipient-preferences]

사용자는 본인의 설정을 변경하지 않고도 인터페이스를 원하는 대로 조정할 수 있습니다.

![공유 링크의 언어 및 테마 설정](/images/shared-links/recipient-settings.png)

- **테마**: 라이트, 다크 또는 시스템.
- **언어**: 선호하는 언어로 인터페이스를 확인합니다.

## 공유 링크 관리하기 [#managing-your-shared-links]

**Settings > Data & Privacy > Your data > Shared chats** 경로에서 **Shared chats** 대시보드를 열어, 공유한 모든 대화를 확인하세요.

![공유 링크 관리 대시보드](/images/shared-links/management-modal.png)

![개별 공유 링크에 대한 세부 정보 및 옵션](/images/shared-links/management-details.png)

대시보드에서 다음을 수행할 수 있습니다:

- **모든 링크 보기**: 공유한 모든 대화를 확인하세요.
- **검색 및 필터링**: 특정 공유 링크를 찾고 해당 콘텐츠를 미리 봅니다.
- **액세스 취소**: 링크를 삭제하여 즉시 공유를 중단합니다.

활성 공유 링크가 있는 대화는 사이드바에 링크 배지가 표시되며, 채팅 헤더의 공유 컨트롤에도 동일한 활성 상태가 표시됩니다.

## 구성 [#configuration]

`.env` 파일에 있는 세 개의 환경 변수가 이 기능을 제어합니다:

- **`ALLOW_SHARED_LINKS`** (기본값: `true`): 공유 링크 기능을 활성화합니다. 사용자가 링크를 생성하지 못하게 하려면 `false`로 설정하세요.
- **`ALLOW_SHARED_LINKS_PUBLIC`** (기본값: `false`): 인증 없이 링크를 열 수 있는지 여부를 제어합니다. 기본적으로 수신자는 로그인해야 합니다. 공개적이고 인증되지 않은 액세스를 허용하려면 `true`로 설정하세요.
- **`SHARED_LINKS_SNAPSHOT_FILES`** (기본값: `true`): 공유 링크에 참조된 대화 파일을 포함할 수 있는지 여부를 제어합니다. 이 환경 변수가 설정되면 [`interface.sharedLinks.snapshotFiles`](/docs/configuration/librechat_yaml/object_structure/interface#sharedlinks) 설정을 재정의합니다.

```bash title=".env"
# Enable shared links (default)
ALLOW_SHARED_LINKS=true

# Require authentication to view shared links (default)
ALLOW_SHARED_LINKS_PUBLIC=false

# Include referenced files in shared-link snapshots (default)
SHARED_LINKS_SNAPSHOT_FILES=true
```

역할 권한은 어떤 사용자가 링크를 생성하고, 인증된 사용자와 공유하거나, 인스턴스의 모든 사용자에게 공개할 수 있는지 결정합니다:

```yaml title="librechat.yaml"
interface:
  sharedLinks:
    create: true
    share: true
    public: false
    snapshotFiles: true
```

`sharedLinks.public`는 사용자가 "모두와 공유"를 토글할 수 있는지 여부를 제어합니다. `ALLOW_SHARED_LINKS_PUBLIC`은 해당 공개 링크를 로그인 없이 볼 수 있는지 여부를 여전히 결정합니다. `sharedLinks.snapshotFiles`는 YAML에서 파일 스냅샷 기본 동작을 제어하며, `SHARED_LINKS_SNAPSHOT_FILES`를 통해 이를 전역적으로 재정의하거나 비활성화할 수 있습니다.

<Callout type="info">
전체 환경 변수 참조는 [.env Configuration](/docs/configuration/dotenv#shared-links) 페이지를 참조하세요.
</Callout>

## 자주 묻는 질문 (FAQ) [#frequently-asked-questions]

<Accordions type="single" collapsible>
<Accordion title="공유된 대화에 수신자가 응답할 수 있나요?">

공유된 스냅샷은 읽기 전용으로 유지됩니다. 로그인한 수신자는 **Continue this chat**을 선택하여 개인 사본을 생성하고 해당 대화에서 AI와 상호작용할 수 있습니다.

</Accordion>
<Accordion title="공유한 대화를 삭제하면 어떻게 되나요?">

링크가 작동을 멈춥니다. 해당 링크로 이동하는 모든 사용자는 "Shared link not found" 페이지를 보게 됩니다.

</Accordion>
<Accordion title="공유한 대화를 편집할 수 있나요?">

네. 링크에 이미 포함된 메시지에 대한 수정 사항은 공유된 보기에도 나타납니다. 게시된 브랜치 끝부분 외부에 추가된 새로운 대화는 **Update link**를 선택한 후에만 나타나며, URL은 동일하게 유지됩니다.

</Accordion>
<Accordion title="공유 링크는 오프라인에서도 작동하나요?">

아니요. 공유된 대화를 보려면 수신자에게 인터넷 연결이 필요합니다.

</Accordion>
</Accordions>
