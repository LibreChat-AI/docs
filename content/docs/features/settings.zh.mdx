打开账户菜单，选择**设置**。该对话框包含**常规**、**聊天**、**语音**、**数据与隐私**和**账户**等选项卡，在提供相应功能的部署中还包括**Langfuse**和**关于**。如果你大致知道要查找的内容，可以直接在**搜索设置**中输入：它会匹配标签及相关词汇（如"dark"、"rtl"、"paste"），并跳转到对应的选项卡和部分。

大多数偏好设置保存在当前浏览器中,而不是您的账户里。在笔记本电脑上更改的设置不会同步到手机上。下文会说明例外情况。

## 常规 [#general]

| 设置 | 作用 | 默认值 |
|---|---|---|
| 主题 | **跟随系统**、**浅色**、**深色**,或高对比度浅色或深色主题。 | 跟随系统 |
| 语言 | 界面语言。 | 浏览器语言 |
| 消息字体大小 | 消息文本大小,从**极小**到**极大**。 | 中 |
| 界面缩放 | 在 50% 到 150% 之间缩放整个界面,与浏览器缩放无关。 | 100% |
| 聊天方向 | **自动**、从左到右或从右到左。 | 自动 |
| 时间格式 | 系统、12 小时制或 24 小时制,适用于消息、日程和日期中的时间。 | 系统 |
| 每周起始日 | 系统、周日或周一。仅更改[定时聊天](/docs/features/scheduled_chats)中星期的排列顺序,不影响日程的运行时间。 | 系统 |
| 最大化聊天空间 | 加宽对话栏。 | 关 |
| 欢迎界面居中聊天输入框 | 将消息输入框置于新聊天的中央。 | 开 |
| 在欢迎界面显示 Lia | 消息输入框周围的一个小型装饰性像素吉祥物。仅在部署允许时显示。 | 关 |
| 滚动到底部按钮 | 一个可跳转到最新消息的按钮。 | 开 |
| 在移动端侧边栏旁显示聊天 | 在[移动端抽屉](/docs/features/navigation#mobile-drawer)旁保留一条可见的对话区域;点击该区域即可关闭抽屉。 | 关 |
| 在标签页中显示聊天标题 | 将对话标题用作浏览器标签页标题。 | 开 |
| 生成回复时保持屏幕常亮 | 要求浏览器在回复流式输出时不要变暗或锁定屏幕。 | 开 |

管理员在此处也会看到 **Admin Panel** 链接(前提是该部署包含管理面板)。

### 通知 [#notifications]

这些设置用于控制当您位于其他对话或其他标签页时,如何获知回复已完成的通知:

- **在标签页标题中显示未读数量**会在标签页标题和图标中显示包含未读回复的对话数量。默认开启。
- **Notify me when a reply arrives** 会显示桌面通知。默认关闭。首次开启时,浏览器会请求通知权限;当你正在查看 LibreChat 时,不会显示任何通知。
- **播放新回复提示音** 会播放一段简短的提示音。默认关闭。浏览器会在您在页面上点击之前阻止音频播放,因此打开标签页后的第一次提示音可能没有声音。

这些开关按设备单独生效;未读状态本身则保存到您的账户中(参见[未读回复](/docs/features/navigation#unread-replies))。如果其中某个开关不见了,说明管理员通过 [`interface.replyNotifications`](/docs/configuration/librechat_yaml/object_structure/interface#replynotifications) 将其关闭了。

## 聊天 [#chat]

| 设置 | 作用 | 默认值 |
|---|---|---|
| Press Enter to send messages | 关闭后,Enter 会换行,<kbd>Ctrl</kbd>+<kbd>Enter</kbd>(macOS 上为 <kbd>Cmd</kbd>+<kbd>Enter</kbd>)发送消息。 | 开启 |
| While generating, Enter will | 回复仍在流式输出时,发送操作的行为:**Steer**(引导)、**Interrupt**(中断)或 **Queue**(排队)。参见 [Composer](/docs/features/composer)。 | Steer |
| Save drafts locally | 在消息发送前,将未发送的文本和附件保存在此设备上。 | 开启 |
| Resize images before upload | 上传前在浏览器中缩小较大的 JPEG、PNG 和 WebP 图片。 | 开启 |
| Paste long text as a file | 将超长粘贴内容作为文本文件附加,而不是填入消息框。参见 [Upload as Text](/docs/features/upload_as_text)。 | 开启 |
| Save badges state | 新建聊天时保留上一次聊天中的工具徽章,而不是重置。 | 关闭 |
| Toggle command "@" / "+" / "/" | 开启或关闭 `@`(切换模型或端点)、`+`(添加并行回复)和 `/`(插入提示词)命令。`+` 和 `/` 仅在相应功能可用时显示。 | 开启 |
| Render user messages as markdown | 将您自己的消息格式化为 Markdown。 | 开启 |
| Collapse long user messages | 您发送的长消息会以预览形式显示,并带有 **Show more**(显示更多)按钮。完整文本仍保留在页面中,便于复制和搜索。 | 开启 |
| Display username in messages | 在您的消息上方显示您的名称,而不是"You"。 | 开启 |
| Parsing LaTeX in messages | 渲染数学公式。关闭后将不再渲染 `$...$` 行内公式;`$$...$$`、`\(...\)` 和 `\[...\]` 仍会渲染。 | 开启 |
| Open Thinking Dropdowns by Default | 默认展开模型的推理内容,而不是折叠。 | 关闭 |
| Smooth streaming text | 回复流式输出时,新词语以淡入方式显示。参见 [Smooth Streaming](/docs/features/smooth_streaming)。 | 开启 |
| Copy messages as rich text | 复制消息时,同时将格式化版本放入剪贴板,便于粘贴到 Word、Outlook 或 Teams 中。 | 关闭 |
| Auto-expand tool details | 默认展开工具调用详情。 | 关闭 |
| Switch to Chat History on new chat | 在打开 Prompts、Memories 或其他面板时开始新聊天,侧边栏会切换回您的聊天记录。 | 开启 |
| Auto-Scroll to latest message on chat open | 打开聊天时定位到最新消息。关闭后,返回时将保持您上次的位置。 | 开启 |
| Enable switching Endpoints mid-conversation | 允许在同一对话中更改模型或端点。 | 开启 |
| Temporary Chat by default | 新建聊天默认为[临时聊天](/docs/features/temporary_chat)。 | 关闭 |
| Use default fork option | 跳过分支菜单,始终使用您在此处选择的选项。参见 [Forking](/docs/features/fork)。 | 关闭 |
| Advanced prompts editor | 开启提示词的版本管理和生产标签功能。 | 关闭 |
| Always make new prompt versions production | 将每个新的提示词版本标记为当前使用的版本。 | 开启 |
| Send prompts on select | 选择提示词后立即发送。 | 开启 |

**上传前调整图片大小**可能会被锁定:如果管理员设置了 [`fileConfig.clientImageResize.enabled`](/docs/configuration/librechat_yaml/object_structure/config#clientimageresize),则该开关将被禁用,并遵循该配置值。

## 语音 [#speech]

开启或关闭**语音转文字**和**文字转语音**,选择引擎、语言和语音,设置播放速率,并决定是否自动播放回复。可选的引擎取决于部署时的配置;请参阅[语音转文字和文字转语音](/docs/configuration/stt_tts)。

## 数据与隐私 [#data--privacy]

- **记忆**:**引用已保存的记忆**允许助手使用您的[记忆](/docs/features/memory)。该设置保存在您的账户中,因此在所有设备上均生效。
- **代码执行**:**默认有状态工作区**和**代码环境**,当部署提供有状态代码会话时。
- **你的数据**:**导入对话**、**共享对话**(管理您的[共享链接](/docs/features/shareable_links))、**管理文件**、**归档所有对话**,以及在部署收集分析数据时的**允许分析**。**归档所有对话**会将所有活动对话移至[已归档对话](/docs/features/navigation#archived-conversations),但不会删除任何内容。
- **API 密钥**:适用于需要您自行提供密钥的端点的**提供商 API 密钥**、用于 Agents API 的**Agent API 密钥**,以及**撤销所有提供商 API 密钥**。
- **危险区域**:**删除缓存**会清除此浏览器中缓存的文本转语音音频。**删除所有聊天**会永久删除您的对话。

## 账户 [#account]

**头像**，以及在允许邮箱登录的情况下显示的**邮箱地址**。在**安全**下包括：**双因素认证**、开启双因素认证后显示的**备用码**，以及在部署支持时显示的**通行密钥**。**拉取请求账户**用于连接 GitHub 或其他 git 托管平台，以便使用[拉取请求](/docs/features/pull_requests)功能。当部署启用余额跟踪时，会显示**Token 余额**和**自动充值**；当允许用户自行删除账户时，会显示**删除账户**。

## 键盘快捷键 [#keyboard-shortcuts]

打开账户菜单,选择**帮助**,然后选择**键盘快捷键**(或按下 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>/</kbd>)。点击某一行即可录入新的组合键;组合键必须包含 <kbd>Cmd</kbd>、<kbd>Ctrl</kbd> 或 <kbd>Alt</kbd>,如果该组合键已被其他操作占用,LibreChat 会发出警告。**全部重置为默认值**可撤销你的所有更改。**打开面板**下的各行(智能体、提示词、记忆、参数、文件、书签、MCP 设置)在你为其分配按键之前没有默认快捷键。

顶部的 **Keyboard Shortcuts** 开关可以关闭所有快捷键，并隐藏界面中的快捷键提示。您的自定义按键会被保留，待您重新开启时即可使用。该开关和您的按键绑定均保存在此浏览器中。
