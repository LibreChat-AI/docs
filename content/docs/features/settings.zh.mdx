在您的账户菜单中选择**设置**,即可管理 LibreChat 的个人偏好和数据控制选项。标签页包括:通用、聊天、语音、数据与隐私以及账户,当部署环境显示时还会有关于页面。使用**搜索设置**可以通过控件的标签或相关关键词找到对应选项;选择某个搜索结果后,会打开对应的标签页和分区。设置页面的布局会适配移动设备屏幕,且不会隐藏标签页导航。

## 常规 [#general]

**Display chat title in tab** 使用当前对话标题作为浏览器标签页标题。此功能默认开启，并存储在当前浏览器中。将其关闭可使每个标签页始终显示部署的应用标题。新对话在获得正式对话标题之前，将继续使用应用标题。

**时间格式**控制时间显示是采用系统惯例、12 小时制还是 24 小时制。**系统**选项会读取当前浏览器的区域设置，而非所选的 LibreChat 翻译语言。此选项适用于消息时间戳、定时聊天控件和摘要、密钥过期和余额充值日期、智能体和提示词版本日期、记忆以及项目聊天列表。

**Week Starts On** 控制日历风格的周几列表是遵循系统惯例、周日还是周一。系统惯例可能会解析为其他地区的起始日，例如周六。这会改变“定时聊天”（Scheduled Chats）中周几控件和摘要的顺序，但不会改变定时任务运行的具体日期。

两种区域设置偏好都存储在当前浏览器中，因此不同的设备可以遵循各自的区域设置或显式覆盖。

**在移动端侧边栏旁显示聊天**（位于**布局**下）默认处于关闭状态。启用后，移动端抽屉菜单将停在视口的 80% 处，并留出一部分当前对话可见。点击该区域即可关闭抽屉。此偏好设置存储在当前浏览器中；请参阅 [Mobile Drawer](/docs/features/navigation#mobile-drawer)。

此标签页上的其他控件保存在当前浏览器中:

| 设置 | 作用 | 默认值 |
|---|---|---|
| 界面缩放 | 将整个界面缩放至 50% 到 150% 之间。不影响浏览器缩放。 | 100% |
| 消息字体大小 | 消息的文字大小:特小、小、中、大或特大。 | 中 |
| 聊天方向 | 聊天的文字方向:自动、从左到右或从右到左。“自动”会根据输入内容判断方向。 | 自动 |
| 最大化聊天空间 | 为对话在屏幕上提供更多空间。 | 关 |
| 在欢迎界面中居中显示聊天输入框 | 在新聊天的欢迎界面中将输入框居中显示。 | 开 |
| 滚动到底部按钮 | 显示一个按钮,点击后可跳转到最新消息。 | 开 |
| 生成响应时保持屏幕常亮 | 在生成响应期间,请求浏览器不要使屏幕变暗或锁定。 | 开 |
| 在欢迎界面中显示 Lia | 在欢迎界面的输入框周围显示 Lia,一个装饰性的像素吉祥物。仅当部署环境允许时才会显示。 | 关 |

**Archived chats** 位于账户菜单中，而不是此选项卡内；请参阅 [Archived Conversations](/docs/features/navigation#archived-conversations)。

### 通知 [#notifications]

**Notifications** 部分控制 LibreChat 如何在您离开时通知您已完成的回复：

- **Show unread count in the tab title** 会在浏览器标签页标题和图标中显示包含未读回复的对话数量。此功能默认开启。
- **Notify me when a reply arrives** 会显示桌面通知。该功能默认处于关闭状态，开启时会请求浏览器的通知权限。仅当您离开 LibreChat 页面时才会显示通知，因为当您正在查看聊天列表时，回复内容已会被标记出来。
- **Play a sound for new replies** 会在您离开时收到回复时播放短促的提示音。默认情况下此功能处于关闭状态。浏览器会拦截音频播放，直到您与页面进行交互，因此打开标签页后的第一次提示音可能不会播放。

这些偏好设置是按设备存储的，因此笔记本电脑和手机上的设置可以不同；未读状态本身会在设备间同步（请参阅 [未读回复](/docs/features/navigation#unread-replies)）。管理员可以通过 [`interface.replyNotifications`](/docs/configuration/librechat_yaml/object_structure/interface#replynotifications) 为整个部署关闭其中任何一项，这会隐藏相应的切换开关。

## 聊天 [#chat]

**Conversations** 下的 **Switch to Chat History on new chat** 默认处于开启状态，并存储在当前浏览器中。当侧边栏处于其他面板（如 Prompts 或 Memories）时，从侧边栏开始新对话会将侧边栏切换回聊天列表。将其关闭以保持当前面板不变。

**打开聊天时自动滚动到最新消息**默认处于开启状态,会将新打开的对话滚动到最新渲染的消息处。如果关闭该选项,则在返回聊天时保留当前的滚动位置。LibreChat 会等待目标对话的消息行渲染完成后再定位,即使导航与消息加载的完成时间不一致也是如此。

**调整图片大小后上传**允许用户在发送前，于浏览器中缩小较大的 JPEG、PNG 和 WebP 文件。该偏好默认开启，并存储在当前浏览器中。

管理员可以控制这是否仍然是一个个人选择。如果 [`fileConfig.clientImageResize.enabled`](/docs/configuration/librechat_yaml/object_structure/config#clientimageresize) 被显式设置为 `true` 或 `false`，LibreChat 将强制执行该值并锁定用户开关。如果省略该字段，则应用用户的设置。

**Paste long text as a file** 默认处于启用状态，并存储在当前浏览器中。当“Upload as Text”上下文上传功能可用时，在普通消息编辑器中粘贴超过 2,500 个字符的内容会将其作为 `pasted-text.txt` 附加，而不是直接填入输入框。较短的粘贴内容以及在没有 `context` 功能的情况下进行的粘贴将保持内联。请参阅 [Upload Files as Text](/docs/features/upload_as_text#paste-long-text-as-a-file)。

**折叠长用户消息**默认处于开启状态。启用后,高度超过 256 像素的用户消息将以紧凑预览的形式展示,并提供**显示更多**和**显示更少**按钮。折叠仅为视觉效果:完整消息仍可用于复制、浏览器搜索以及辅助技术读取。

**解析消息中的 LaTeX** 默认处于启用状态。该开关用于控制歧义的单美元符号 `$...$` 行内数学公式形式，它遵循边界规则，以确保像 `$50` 这样类似货币的文本保持原样。当该开关关闭时，无歧义的 `$$...$$`、`\(...\)` 和 `\[...\]` 数学公式仍受支持。行内代码、代码块和自动链接不会被解析为单美元符号数学公式。

发送键的说明见 [输入框](/docs/features/composer#keyboard-shortcuts)。此选项卡上的其他控件均保存在当前浏览器中:

| 设置 | 作用 | 默认值 |
|---|---|---|
| 按 Enter 发送消息 | 开启时,按 Enter 发送。关闭时,按 Enter 插入换行,按 Ctrl/Cmd+Enter 发送。 | 开启 |
| 生成过程中,Enter 将 | 响应流式输出时发送的行为:Steer、Interrupt 或 Queue。参见 [Steering and Queued Messages](/docs/features/agents#steering-and-queued-messages)。 | Steer |
| 本地保存草稿 | 将未发送的文本和附件作为草稿保存在本设备上,消息发送后即删除。 | 开启 |
| 保存徽章状态 | 开始新对话时保留聊天徽章(工具)的当前状态,而不是重置。 | 关闭 |
| 切换 "@" 命令,用于切换端点、模型、预设等 | 开启或关闭 `@` 命令。 | 开启 |
| 切换 "+" 命令,用于添加多响应设置 | 开启或关闭 `+` 命令。仅在多响应可用时显示。 | 开启 |
| 切换 "/" 命令,用于通过键盘选择提示词 | 开启或关闭 `/` 命令。仅在提示词可用时显示。 | 开启 |
| 将用户消息渲染为 Markdown | 将你自己的消息渲染为 Markdown。 | 开启 |
| 在消息中显示用户名 | 在你的消息上方显示用户名,而不是 "You"。 | 开启 |
| 默认展开思考下拉框 | 展开模型推理块,而不是折叠。 | 关闭 |
| 自动展开工具详情 | 默认展开工具调用详情。 | 关闭 |

语音输入和播放功能位于 **Speech** 标签页中;详见 [Speech Settings](/docs/configuration/stt_tts)。

## 模型参数 [#model-parameters]

侧边栏中的模型 **Parameters** 面板将对话设置归类在以下标题下：**Identity**、**Sampling**、**Limits**、**Reasoning**、**Context**、**Advanced** 和 **Misc.**。只有当前 endpoint 使用的部分才会显示，而面板无法识别的设置（例如自定义 endpoint 特有的参数）则会列在 **Misc.** 下。标题会显示该部分中有多少设置已被更改，以便您在选择 **Reset** 之前查看有哪些不同之处。**Reset** 和 **Save As Preset** 位于面板底部。请参阅 [Presets](/docs/user_guides/presets)。

## 键盘快捷键 [#keyboard-shortcuts]

从账户菜单中打开 **Keyboard Shortcuts** 以查看或自定义快捷键绑定。**Keyboard Shortcuts** 开关默认处于开启状态。将其关闭将禁用所有快捷键并从界面中移除快捷键提示，同时保留自定义绑定。再次从账户菜单中打开同一对话框即可重新开启快捷键。

快捷键启用状态和自定义绑定存储在当前浏览器中。即使关闭快捷键，绑定行仍保持可见，但在重新启用快捷键之前，编辑和重置控件将保持禁用状态。

## 数据与隐私 [#data--privacy]

**数据与隐私**选项卡分为以下几个部分:

- **记忆**：**引用已保存的记忆**允许助手在回复时使用您已保存的记忆。该设置会保存到您的账户中，并且仅在您的部署环境适用记忆偏好设置时才会显示。
- **代码执行**:**默认有状态工作区**用于选择为新创建的智能体建议的工作区范围。仅当有状态代码会话可用时才会显示;更改该设置不会启用有状态会话,也不会改变现有智能体。**代码环境**在您控制的虚拟机上运行沙箱工作进程,同样受该可用性条件约束。
- **您的数据**:**管理文件**会打开已上传文件管理器。**导入对话**用于导入受支持的对话导出文件。**共享对话**用于列出和管理已发布的对话链接。**归档所有对话**会在确认后将活动对话移至**已归档对话**,不会删除它们。**允许分析**用于更改您对分析提示的回答,且仅当部署已配置分析功能时才会显示。
- **API 密钥**:**提供商 API 密钥**用于管理为已配置提供商提供的密钥,仅当端点接受用户提供的密钥时才会显示。**Agent API 密钥**用于管理 Agents API 的密钥,仅当远程 Agent 可用时才会显示。**撤销所有提供商 API 密钥**会移除所有用户提供的提供商密钥。
- **危险操作区**:**删除缓存**会移除浏览器中缓存的文本转语音音频;当缓存为空时该操作不可用。**删除所有聊天**会在确认后永久删除用户的全部对话。

数据删除和密钥撤销操作由服务器支持，且可能是不可逆的。仅限浏览器的偏好设置和缓存仅适用于当前浏览器配置文件，而非所有设备。

## 账户 [#account]

**Account** 选项卡包含个人资料、安全、账单和删除相关的控制项。其中部分选项仅在部署环境支持时才会显示:

| 设置 | 作用 |
|---|---|
| 头像 | 更改您的个人资料图片。 |
| 备用代码 | 显示并重新生成两步验证的备用代码。仅在启用两步验证时显示。 |
| Token 余额 | 显示您的 Token 积分。仅在启用余额跟踪时显示。 |
| 自动充值 | 显示或配置自动余额充值。仅在启用余额跟踪时显示。 |
| 删除账户 | 永久删除您的账户和数据。仅在部署允许删除账户时显示。 |
