Der Nachrichten-Composer ist das Feld am unteren Rand jedes Chats. Neben dem Textfeld enthält er eine **+**-Schaltfläche, über die alles geöffnet werden kann, was einer Nachricht hinzugefügt werden kann (Dateien, Tools, Skills, MCP-Server und zuvor hochgeladene Dateien), die Chips für die aktuell aktivierten Tools sowie die Steuerelemente für Reasoning, Diktat und das Senden.

## Was befindet sich im Composer [#whats-on-the-composer]

| Element | Was es bewirkt |
|---|---|
| **+** (**Anhang und Tools**) | Öffnet die Palette: Upload-Optionen, Tools, Skills, MCP Server und Ihre kürzlich verwendeten Dateien, alles durchsuchbar über ein einziges Feld. |
| Tool-Chips | Ein Chip pro aktiviertem Tool oder MCP Server neben der **+**-Schaltfläche. Entfernen Sie einen Chip, um das entsprechende Tool zu deaktivieren. |
| Bereitgestellter Kontext | Dateien, Zitate und Skills, die an Ihre nächste Nachricht angehängt sind und über dem Textfeld angezeigt werden. |
| **Thinking** | Überlegungsaufwand für Modelle, die dies unterstützen. |
| Kontextnutzung | Wie viel vom Kontextfenster des Modells die Konversation belegt, sofern die Token-Nutzung verfügbar ist. |
| **Mikrofon verwenden** | Diktieren Sie Ihre Nachricht mittels Spracherkennung, wenn diese aktiviert ist. |
| Senden / Stopp | Sendet die Nachricht oder stoppt die Antwort, die gerade gestreamt wird. |

To see which keys apply right now, such as `/ for prompts`, `@ for models` or `Enter to send`, turn on **Show composer tips** in **Settings > General**. A one-line tip then appears under the text field. It is off by default.

## Dateien hinzufügen [#add-files]

Klicken Sie auf **+** und wählen Sie eine Option im Bereich **Attach**. Sie können Dateien auch per Drag-and-Drop in das Eingabefeld ziehen oder sie einfügen.

Standardmäßig verwendet LibreChat den vereinheitlichten Uploader: Sie wählen lediglich eine Quelle aus, und das System entscheidet basierend auf dem Dateityp und dem endpoint, wie jede Datei das Modell erreicht (nativer Provider-Upload, Textextraktion oder ein Tool wie File Search).

| Option | When it appears |
|---|---|
| **From Local Computer** | Immer, mit dem Standard-Uploader. |
| **From SharePoint** | Wenn die [SharePoint file picker](/docs/configuration/sharepoint) aktiviert ist. |

Wenn ein Administrator [`fileConfig.legacyFileUploadUX: true`](/docs/configuration/librechat_yaml/object_structure/file_config#legacyfileuploadux) festlegt, wählen Sie das Ziel stattdessen selbst aus. Der Bereich **Anhängen** zeigt dann zuerst die Hauptoption an und verbirgt den Rest hinter **Weitere Upload-Optionen**:

| Option | Wann es erscheint |
|---|---|
| **Upload to Provider** | Der Anbieter akzeptiert Dokumente direkt (zum Beispiel OpenAI, Anthropic, Google, Bedrock, OpenRouter und benutzerdefinierte endpoints, oder Azure OpenAI mit aktivierter Responses API). |
| **Upload Image** | Wird anstelle von **Upload to Provider** angezeigt, wenn der Anbieter nur Bilder akzeptiert. |
| **Upload as Text** | Die [context capability](/docs/features/upload_as_text) ist aktiviert. |
| **Upload for File Search** | File Search ist aktiviert und für den aktuellen Agenten erlaubt. Die Auswahl aktiviert ebenfalls File Search. |
| **Upload to Code Environment** | Code-Ausführung ist aktiviert und für den aktuellen Agenten erlaubt. Die Auswahl aktiviert ebenfalls **Run Code**. |
| **Attach Files** | Assistants endpoints, die Dateien mit der eigenen Konfiguration des Assistenten verarbeiten. |

Wenn SharePoint in diesem Modus aktiviert ist, verfügt jede Option auch über eine SharePoint-Version, die beispielsweise als **Upload to Provider (From SharePoint)** gekennzeichnet ist.

### Eine zuvor hochgeladene Datei wiederverwenden [#reuse-a-file-you-uploaded-before]

Der Bereich **Your files** in der Palette listet Ihre zuletzt verwendeten Dateien auf. Wählen Sie eine aus, um sie erneut anzuhängen, ohne sie hochladen zu müssen. Die Eingabe in das Suchfeld durchsucht alle Ihre Dateien nach Namen.

Wählen Sie **Show all** im Abschnitt, um alle Dateien in einem Dialog zu durchsuchen, mit Ansichten für **All**, **Images** und **Documents**, einem Suchfeld sowie einer Vorschau für Bilder und PDFs.

Die Palette zeigt bis zu fünf kürzlich verwendete Dateien an. Administratoren können diese Anzahl verringern oder die Liste mit `0` ausblenden, indem sie [`interface.composerRecentFiles`](/docs/configuration/librechat_yaml/object_structure/interface#composerrecentfiles) verwenden.

## Tools, Skills und MCP-Server aktivieren [#turn-on-tools-skills-and-mcp-servers]

Die Palette listet alles auf, was Sie für die aktuelle Konversation aktivieren können, gruppiert in Abschnitte:

- **Tools**: integrierte Tools wie **Web Search**, **Run Code**, **File Search**, **Skills**, **Memory** und **Artifacts**, die jeweils nur angezeigt werden, wenn sie aktiviert sind und Sie Zugriff darauf haben.
- **Skills**: individuelle [skills](/docs/features/skills), die Sie an Ihre nächste Nachricht anhängen können.
- **MCP Servers**: die [MCP servers](/docs/features/mcp), die im Chat verfügbar sind.

Wählen Sie ein Tool oder einen MCP Server aus, um es ein- oder auszuschalten. Die Palette bleibt geöffnet, sodass Sie bei einem Besuch mehrere umschalten können. Jedes eingeschaltete Tool erscheint als Chip im Composer; entfernen Sie den Chip, um es auszuschalten. Einige Chips verfügen über ein Modus-Menü, zum Beispiel der **Artifacts**-Generierungsmodus.

Das Auswählen eines Skills stellt diesen stattdessen für Ihre nächste Nachricht bereit: Er erscheint im [staged context](#staged-context) anstatt als Chip.

Die Zeilen der MCP Server zeigen den Verbindungsstatus jedes Servers an. Die Auswahl eines nicht verbundenen Servers startet dessen Verbindung (einschließlich einer OAuth-Anmeldung, falls der Server diese benötigt) oder öffnet zuerst dessen Konfiguration, falls Anmeldedaten erforderlich sind. Sobald die Verbindung hergestellt ist, verfügen Server, die Benutzeranmeldedaten erfordern, über ein **Configure**-Steuerelement in der Zeile, und **Web Search** besitzt eines für seine API-Schlüssel.

<Callout type="info" title="Agents bringen ihre eigenen Tools mit">
  Wenn ein Agent ausgewählt ist, werden die Abschnitte **Tools** und **MCP Servers** ausgeblendet, da die eigene Konfiguration des Agenten bestimmt, welche Tools er verwendet. Bei anderen endpoints blendet ein [model spec](/docs/configuration/librechat_yaml/object_structure/model_specs#hidebadgerow) mit `hideBadgeRow: true` die Abschnitte **Tools**, **Skills** und **MCP Servers** aus. **Attach** und **Your files** bleiben in jedem Fall verfügbar.
</Callout>

### Alle anzeigen [#show-all]

Die Palette zeigt eine Handvoll Zeilen pro Abschnitt. Wählen Sie **Alle anzeigen** in der Kopfzeile von **Skills**, **MCP Servers** oder **Your files**, um ein Dialogfeld mit der vollständigen Liste, einem Suchfeld und Filtern zu öffnen. Skills und MCP Servers verfügen über drei Ansichten: **Alle**, **Von Ihnen erstellt** und **Favoriten**.

### Favoriten und angeheftete Tools [#favorites-and-pinned-tools]

Markieren Sie eine Zeile mit einem Stern, um sie zu den **Favoriten** hinzuzufügen, die ganz oben in der Palette angezeigt werden. Wenn eine Zeile markiert ist, drücken Sie <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd> unter macOS), um sie als Favorit zu markieren oder die Markierung aufzuheben. Favoriten werden in Ihrem Konto gespeichert.

Administratoren können integrierte Tools mit [`interface.defaultPinnedTools`](/docs/configuration/librechat_yaml/object_structure/interface#defaultpinnedtools) anheften. Ein angeheftetes Tool behält seinen Chip im Composer bei, auch wenn es deaktiviert ist, sodass Sie es mit einem Klick einschalten können. Das Entfernen des Chips eines angehefteten Tools, das deaktiviert ist, hebt die Anheftung auf.

## Gestufter Kontext [#staged-context]

Alles, was an Ihre nächste Nachricht angehängt wird, erscheint vor dem Senden über dem Textfeld:

- **Dateien**, mit Upload-Fortschritt und einer Vorschau für Bilder. Lange eingefügte Texte können hier ebenfalls als Datei landen, die Sie bearbeiten oder zurück in die Nachricht verschieben können.
- **Zitate**, die Sie aus früheren Nachrichten ausgewählt haben.
- **Skills**, die Sie aus der Palette oder mit dem Befehl `$` ausgewählt haben.

Entferne jedes Element mit der dazugehörigen Schaltfläche zum Entfernen. Alles, was bereitgestellt wurde, wird mit deiner nächsten Nachricht gesendet.

## Denken und Aufwand [#thinking-and-effort]

Für Modelle mit einer Einstellung für Schlussfolgerungen (Reasoning) öffnet das **Thinking**-Steuerelement einen Schieberegler, der von **Faster** (schneller) bis **Smarter** (intelligenter) reicht, zuzüglich der separaten Modi des Anbieters wie **Auto** oder „aus“. Es ändert denselben Parameter wie das Parameter-Panel und wird daher ausgeblendet, wenn das Modell keine Einstellung für Schlussfolgerungen hat oder wenn die Bereitstellung Parameter über `interface.parameters` deaktiviert.

## In die Warteschlange einreihen und steuern, während eine Antwort gestreamt wird [#queue-and-steer-while-a-response-streams]

Sie können weiter tippen, während eine Antwort gestreamt wird. Abhängig vom endpoint und Ihren Einstellungen bewirkt das Drücken von <kbd>Enter</kbd>, dass die Nachricht entweder in die Warteschlange gestellt wird, um nach der Antwort gesendet zu werden, oder die aktuelle Antwort eines Agents steuert. Der Hinweis im Composer benennt die Aktion, die <kbd>Enter</kbd> in diesem Moment ausführt.

In der Warteschlange befindliche Nachrichten erscheinen in einer **Queued messages**-Leiste über dem Composer, wo Sie:

- **Nachricht bearbeiten**, um sie zurück in das Textfeld zu verschieben.
- **Remove message**, um sie aus der Warteschlange zu entfernen.
- **Send now** (Jetzt senden), um es sofort zu versenden, anstatt zu warten.
- Ordnen Sie Nachrichten durch Ziehen neu an oder indem Sie eine Nachricht fokussieren und die Pfeiltasten nach oben und unten drücken.

Informationen dazu, wie Steering funktioniert und wann es verfügbar ist, finden Sie unter [Steering and Queued Messages](/docs/features/agents#steering-and-queued-messages).

## Tastaturkürzel [#keyboard-shortcuts]

### Im Textfeld [#in-the-text-field]

| Tasten | Aktion |
|---|---|
| <kbd>Enter</kbd> | Nachricht senden (in die Warteschlange einreihen oder steuern, während eine Antwort gestreamt wird). |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Neue Zeile. |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) | Während eine Antwort gestreamt wird: die alternative Aktion, **jetzt senden**, wenn <kbd>Enter</kbd> in die Warteschlange einreiht, oder **in die Warteschlange einreihen**, wenn <kbd>Enter</kbd> steuert. |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> (<kbd>Option</kbd>+<kbd>Enter</kbd>) | Während ein Agent antwortet: unterbrechen und senden, falls verfügbar. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>) | Antwort stoppen. |
| `/` | Einen gespeicherten Prompt einfügen. |
| `@` | Zu einem anderen Modell, Preset oder Agent wechseln. |
| `+` | Ein Modell oder Preset für eine zusätzliche Antwort hinzufügen. |
| `$` | Eine Fähigkeit für die nächste Nachricht auswählen. |

Wenn Sie **Drücken Sie die Eingabetaste, um Nachrichten zu senden** deaktiviert haben, sendet <kbd>Strg</kbd>+<kbd>Eingabetaste</kbd> (<kbd>Cmd</kbd>+<kbd>Eingabetaste</kbd>) die Nachricht ab, während <kbd>Eingabetaste</kbd> eine neue Zeile hinzufügt.

### In der Palette [#in-the-palette]

| Tasten | Aktion |
|---|---|
| Eingabe | Durchsuche Tools, Skills, Server, Upload-Optionen und Dateien. |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Durch die Zeilen navigieren. |
| <kbd>Enter</kbd> | Die markierte Zeile auswählen. |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd>) | Die markierte Zeile zu Favoriten hinzufügen oder daraus entfernen. |
| <kbd>Backspace</kbd> bei leerer Suche | Die Palette schließen. |
| <kbd>Escape</kbd> | Die Palette schließen. |
