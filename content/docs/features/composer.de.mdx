Der Composer ist das Eingabefeld am unteren Rand jedes Chats. Neben dem Textfeld befinden sich eine Schaltfläche **+** für Dateien, Tools, Skills und MCP-Server, ein Chip für jedes aktivierte Tool sowie die Bedienelemente für Denkaufwand, Diktieren und Senden.

Klicken Sie auf **+** (Screenreader kündigen es als **Anhängen und Werkzeuge** an), um die Palette zu öffnen. Alles darin ist über das Feld oben durchsuchbar, daher ist die Eingabe weniger Buchstaben meist schneller als das Scrollen.

## Dateien hinzufügen [#add-files]

Wählen Sie im Bereich **Anhängen** die Option **Vom lokalen Computer**, ziehen Sie Dateien in das Eingabefeld oder fügen Sie sie ein. LibreChat entscheidet anhand des Dateityps und des Endpunkts, wie jede Datei das Modell erreicht (direkt an den Anbieter gesendet, als Text extrahiert oder für File Search indexiert). Sie wählen daher nur, woher die Datei stammt. **Von SharePoint** wird daneben angezeigt, wenn Ihr Administrator SharePoint verbunden hat.

Einige Bereitstellungen verwenden den älteren Uploader, bei dem du das Ziel selbst auswählst: **Upload an Provider** (oder **Bild hochladen** für Provider, die nur Bilder akzeptieren), **Als Text hochladen**, **Für Dateisuche hochladen** und **In Code-Umgebung hochladen**. Die erste Option wird angezeigt, die übrigen befinden sich unter **Weitere Upload-Optionen**. Wenn du **Für Dateisuche hochladen** oder **In Code-Umgebung hochladen** auswählst, wird das jeweilige Tool zusätzlich aktiviert.

### Eine zuvor hochgeladene Datei wiederverwenden [#reuse-a-file-you-uploaded-before]

**Ihre Dateien** in der Palette listet Ihre zuletzt verwendeten Dateien auf (standardmäßig fünf). Wählen Sie eine aus, um sie erneut anzuhängen, ohne sie erneut hochzuladen. Eine Eingabe im Suchfeld durchsucht alle Ihre Dateien nach Namen, und **Alle anzeigen** öffnet einen Dialog mit sämtlichen Dateien, unterteilt in **Alle**, **Bilder** und **Dokumente**, mit Vorschauen für Bilder und PDFs.

## Tools, Skills und MCP-Server aktivieren [#turn-on-tools-skills-and-mcp-servers]

Unterhalb von **Attach** gruppiert die Palette die Elemente, die du der Unterhaltung hinzufügen kannst:

- **Tools**: integrierte Werkzeuge wie **Web Search**, **Run Code**, **File Search**, **Skills**, **Memory** und **Artifacts**. Du siehst nur diejenigen, die aktiviert sind und auf die du Zugriff hast.
- **Skills**: [Skills](/docs/features/skills), die Sie Ihrer nächsten Nachricht hinzufügen können.
- **MCP Servers**: die [MCP-Server](/docs/features/mcp), die im Chat verfügbar sind, jeweils mit ihrem Verbindungsstatus.

Das Auswählen eines Tools oder MCP-Servers schaltet es ein oder aus, und die Palette bleibt geöffnet, sodass Sie mehrere auf einmal umschalten können. Jedes eingeschaltete Element erhält einen Chip im Eingabebereich; entfernen Sie den Chip, um es wieder auszuschalten. Manche Chips haben ein eigenes Menü, zum Beispiel den Generierungsmodus für **Artifacts**.

Die Auswahl eines Skills funktioniert anders: Er wird für Ihre nächste Nachricht vorgemerkt (siehe [Vorbereiteter Kontext](#staged-context)), anstatt zu einem Chip zu werden.

Wenn ein MCP-Server noch nicht verbunden ist, startet die Auswahl die Verbindung, einschließlich einer OAuth-Anmeldung, falls der Server dies erfordert. Server, die Ihre eigenen Zugangsdaten benötigen, fragen diese zuerst ab und behalten anschließend eine **Configure**-Schaltfläche in der Zeile, damit Sie diese später ändern können.

Mit einem ausgewählten Agenten verschwinden die Abschnitte **Tools** und **MCP Servers**, da die eigene Konfiguration des Agenten bestimmt, welche Tools er verwendet. Dasselbe gilt für Assistants.

### Alle anzeigen und Favoriten [#show-all-and-favorites]

Jeder Abschnitt zeigt bis zu fünf Zeilen an. Ein Klick auf **Alle anzeigen** in der Kopfzeile von **Skills**, **MCP Servers** oder **Your files** öffnet die vollständige Liste mit Suche und Filtern. Skills und Server lassen sich auf **Von dir erstellt** oder **Favoriten** eingrenzen.

Um eine Zeile als Favorit zu markieren, wählen Sie sie aus und drücken Sie <kbd>Strg</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd> unter macOS). Favoriten werden an den Anfang der Palette verschoben und in Ihrem Konto gespeichert.

Ihr Administrator kann auch integrierte Tools anpinnen. Ein angepinntes Tool behält seinen Chip im Eingabebereich bei, auch wenn es deaktiviert ist, sodass es mit einem Klick erreichbar bleibt. Wenn Sie den Chip eines deaktivierten, angepinnten Tools entfernen, wird das Tool für Sie wieder abgepinnt.

## Gestufter Kontext [#staged-context]

Alles, was Sie an Ihre nächste Nachricht anhängen, wird vor dem Absenden oberhalb des Textfelds angezeigt:

- Dateien, mit Upload-Fortschritt und einer Bildvorschau.
- Lange Texteinfügungen. Wenn [Als Text hochladen](/docs/features/upload_as_text#pasting-long-text) verfügbar ist, wird beim Einfügen von mehr als 2.500 Zeichen der Text als `pasted-text.txt` angehängt, anstatt das Eingabefeld zu füllen. Wählen Sie ihn aus, um den Text in einem größeren Dialog zu bearbeiten, oder wählen Sie **In Nachricht zurückverschieben**, um ihn wieder in das Textfeld zu übernehmen. Deaktivieren Sie dies über **Langen Text als Datei einfügen** unter **Einstellungen > Chat**.
- Ausschnitte, die Sie aus früheren Nachrichten mit **Zum Chat hinzufügen** zitiert haben (siehe [Ausschnitte zitieren](/docs/features/message_actions#quote-excerpts)).
- Skills, die du aus der Palette oder mit `$` ausgewählt hast.

Entferne alles, was du nicht mehr möchtest, bevor du sendest; alles, was übrig bleibt, wird zusammen mit der Nachricht gesendet. Du kannst Dateien auch ohne Text senden.

## Denken [#thinking]

Bei Modellen mit einer Denkeinstellung öffnet das Steuerelement **Thinking** einen Schieberegler von **Faster** bis **Smarter**, zusätzlich zu allen separaten Modi, die der Anbieter anbietet, etwa **Auto**. Es ändert denselben Wert wie das Parameters-Panel. Wenn das Modell keine Denkeinstellung besitzt oder Ihr Administrator Parameter ausgeblendet hat, wird das Steuerelement nicht angezeigt.

## In die Warteschlange einreihen und steuern, während eine Antwort gestreamt wird [#queue-and-steer-while-a-response-streams]

Sie können weiter tippen, während eine Antwort gestreamt wird. Was das Absenden in diesem Fall bewirkt, hängt von der Standardeinstellung ab, die Sie unter **While generating, Enter will** in **Settings > Chat** festlegen (siehe [Personal Settings](/docs/features/settings#chat)):

- Warteschlange: Die Nachricht wartet und wird gesendet, sobald die Antwort abgeschlossen ist.
- Steuern: Die laufende Antwort übernimmt deine Nachricht am nächsten sicheren Punkt, ohne Tools oder Reasoning abzubrechen.
- Unterbrechung: Aktive Tools und Schlussfolgerungen werden abgebrochen, bereits abgeschlossene Ausgaben bleiben erhalten, und die Antwort wird mit Ihrer Nachricht fortgesetzt.

Informationen darüber, wie Steuerung bei Agenten funktioniert und wann sie verfügbar ist, finden Sie unter [Steuerung und Warteschlangennachrichten](/docs/features/agents#steering-and-queued-messages).

In die Warteschlange eingereihte Nachrichten warten in einer Liste **Queued messages** oberhalb des Eingabefelds. Für jede Nachricht kannst du **Send now** wählen, **Remove message** ausführen oder **More options** öffnen, um **Edit message** (verschiebt sie zurück in das Textfeld), **Start in a new chat** oder **Disable Queue** zu wählen, sodass sie nicht automatisch gesendet wird. Ziehe Nachrichten, um ihre Reihenfolge zu ändern, oder fokussiere eine Nachricht und verwende die Pfeiltasten nach oben und unten.

## Tastaturkürzel [#keyboard-shortcuts]

### Im Textfeld [#in-the-text-field]

Die Tabelle setzt voraus, dass **Mit Enter Nachrichten senden** aktiviert ist, was die Standardeinstellung ist. Ist die Option deaktiviert, fügt <kbd>Enter</kbd> einen Zeilenumbruch hinzu, und <kbd>Ctrl</kbd>+<kbd>Enter</kbd> sendet die Nachricht.

| Tasten | Aktion |
|---|---|
| <kbd>Enter</kbd> | Senden. Während eine Antwort gestreamt wird, führt <kbd>Enter</kbd> Ihre **While generating, Enter will**-Auswahl aus. |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Neue Zeile. |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) | Neue Zeile. Während eine Antwort gestreamt wird, die andere Aktion: sofort senden, falls <kbd>Enter</kbd> in die Warteschlange stellt, in die Warteschlange stellen, falls <kbd>Enter</kbd> steuert oder unterbricht. |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> (<kbd>Option</kbd>+<kbd>Enter</kbd>) | Während eine Antwort gestreamt wird: mit Ihrer Nachricht unterbrechen, sofern der Durchlauf dies zulässt. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd>) | Entspricht <kbd>Alt</kbd>+<kbd>Enter</kbd>. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>) | Antwort stoppen. |
| `/` | Gespeicherten Prompt einfügen. |
| `@` | Modell, Preset oder Agent wechseln. |
| `+` | Ein weiteres Modell oder Preset für eine Antwort nebeneinander hinzufügen. |
| `$` | Einen Skill für die nächste Nachricht auswählen. |

Sie können Tastenkürzel über das Kontomenü neu zuweisen oder deaktivieren; siehe [Tastenkürzel](/docs/features/settings#keyboard-shortcuts).

### In der Palette [#in-the-palette]

| Tasten | Aktion |
|---|---|
| Eingeben | Tools, Skills, Server, Upload-Optionen und Dateien durchsuchen. |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Zwischen Zeilen wechseln. |
| <kbd>Enter</kbd> | Die markierte Zeile auswählen. |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd>) | Die markierte Zeile als Favorit markieren oder Favorit entfernen. |
| <kbd>Backspace</kbd> bei leerer Suche oder <kbd>Escape</kbd> | Die Palette schließen. |

## Einrichtung [#setup]

Der Composer benötigt keine Einrichtung. Administratoren steuern, was darin angezeigt wird: den älteren Uploader mit [`fileConfig.legacyFileUploadUX`](/docs/configuration/librechat_yaml/object_structure/file_config#legacyfileuploadux), die Anzahl der zuletzt verwendeten Dateien mit [`interface.composerRecentFiles`](/docs/configuration/librechat_yaml/object_structure/interface#composerrecentfiles), angeheftete Werkzeuge mit [`interface.defaultPinnedTools`](/docs/configuration/librechat_yaml/object_structure/interface#defaultpinnedtools) und SharePoint über die [SharePoint-Integration](/docs/configuration/sharepoint). Eine [Model Spec](/docs/configuration/librechat_yaml/object_structure/model_specs#hidebadgerow) mit `hideBadgeRow` blendet die Werkzeugbereiche für diese Spec aus.
