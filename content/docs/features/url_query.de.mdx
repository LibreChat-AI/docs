Du kannst einer Chat-URL Query-Parameter hinzufügen, um den Endpoint und das Modell auszuwählen, einen Agenten oder eine Model Spec zu laden, den Prompt vorzubefüllen oder Modelleinstellungen anzupassen, bevor der Chat beginnt. So erstellst du ein Lesezeichen, einen Launcher-Shortcut (Raycast, Alfred, ein Browser-Keyword) oder einen Link aus einer anderen App, der jemanden direkt in die richtige Konfiguration führt.

```
https://chat.example.com/c/new?endpoint=anthropic&model=claude-sonnet-4-5&prompt=Summarize%20this%20article
```

Parameter funktionieren sowohl in einem neuen Chat (`/c/new`) als auch in einem bestehenden (`/c/<conversation-id>`). Nachdem LibreChat sie eingelesen hat, entfernt es sie aus der Adressleiste, sodass ein Neuladen der Seite sie nicht erneut anwendet.

## Den Endpoint und das Modell auswählen [#pick-the-endpoint-and-model]

`endpoint` und `model` zusammen sind die vorhersehbarste Kombination.

- `endpoint` allein wechselt zu diesem Endpoint und verwendet das Modell, das du dort zuletzt ausgewählt hast, oder das erste Modell in dessen Liste.
- `model` allein wechselt das Modell innerhalb des aktuellen Endpunkts, sofern dieser es unterstützt.

Integrierte Endpunktwerte sind `openAI`, `azureOpenAI`, `google`, `anthropic`, `bedrock`, `agents`, `assistants` und `azureAssistants`. Für einen [benutzerdefinierten Endpunkt](/docs/quick_start/custom_endpoints) verwenden Sie den Namen aus Ihrer Konfiguration; der Abgleich erfolgt ohne Berücksichtigung der Groß- und Kleinschreibung, daher findet `endpoint=openrouter` einen Endpunkt mit dem Namen `OpenRouter`.

## Einen Agenten, Assistenten oder eine Model Spec laden [#load-an-agent-assistant-or-model-spec]

```
/c/new?agent_id=agent_abc123
/c/new?assistant_id=asst_abc123
/c/new?spec=meeting-notes
```

`agent_id` und `assistant_id` legen den Endpunkt für dich fest. `spec` lädt eine [Model Spec](/docs/configuration/librechat_yaml/object_structure/model_specs) anhand ihres `name`. Alle anderen Einstellungen in derselben URL werden auf die Voreinstellung der Spec angewendet. Wenn dein Administrator Model Specs erzwingt, füge `spec` in jeden Link ein und erwarte, dass die eigenen Werte der Spec Vorrang vor der URL haben.

## Fülle den Prompt aus oder sende ihn [#fill-in-or-send-the-prompt]

`prompt` (oder das kürzere `q`) fügt Text in das Nachrichtenfeld ein. Wenn beide vorhanden sind, hat `prompt` Vorrang.

Füge `submit=true` hinzu, um die Nachricht zu senden, sobald der Chat bereit ist:

```
/c/new?endpoint=openAI&model=gpt-4o&prompt=Explain%20quantum%20computing&submit=true
```

Wenn die angeforderten Einstellungen nicht innerhalb weniger Sekunden angewendet werden können, bleibt der Prompt im Nachrichtenfeld, anstatt gesendet zu werden. Ihr Administrator kann das automatische Senden auch deaktivieren. In diesem Fall füllt `submit=true` lediglich den Prompt aus, und Sie drücken selbst auf Senden.

Werte müssen URL-kodiert sein. In JavaScript erledigt `encodeURIComponent()` dies:

```js
const url = `/c/new?prompt=${encodeURIComponent('Write a function: def hello()')}`;
// /c/new?prompt=Write%20a%20function%3A%20def%20hello()
```

## Modelleinstellungen ändern [#change-model-settings]

Jede dieser Optionen kann der URL hinzugefügt werden. Jede wirkt sich nur auf Endpunkte aus, die sie unterstützen, und die Werte werden vor der Anwendung geprüft; ungültige Angaben werden stillschweigend verworfen, ohne Fehlermeldung.

| Endpunkt | Parameter |
| --- | --- |
| Beliebig | `maxContextTokens`, `resendFiles`, `promptPrefix` (benutzerdefinierte Anweisungen) |
| OpenAI, Azure OpenAI, benutzerdefiniert | `temperature`, `top_p`, `presence_penalty`, `frequency_penalty`, `stop`, `max_tokens`, `reasoning_effort`, `reasoning_summary`, `verbosity`, `useResponsesApi`, `disableStreaming`, `imageDetail` (`low`, `auto`, `high`) |
| OpenAI Responses API | `reasoning_mode` (`standard`, `pro`), `reasoning_context` (`auto`, `current_turn`, `all_turns`) |
| OpenAI, Anthropic, Google | `web_search` (`true`/`false`), `fileTokenLimit` (Token-Obergrenze für Dateiinhalte) |
| Anthropic, Google | `temperature`, `topP`, `topK`, `maxOutputTokens`, `thinking`, `thinkingBudget`, `thinkingLevel` |
| Anthropic | `effort` (`low`, `medium`, `high`, `xhigh`, `max`), `thinkingDisplay` (`auto`, `summarized`, `omitted`, oder `updates` für nur die Fortschrittsnotizen zwischen Tool-Aufrufen) |
| Anthropic, Bedrock (Anthropic-Modelle), OpenRouter | `promptCache` (`true`/`false`), `promptCacheTtl` (`5m` oder `1h`) |
| Google | `url_context=true` ermöglicht Gemini, URLs in Ihrer Nachricht zu lesen |
| Bedrock | `region`, `maxTokens`, `temperature`, `topP`, `reasoning_effort` |
| Assistants | `instructions` (ersetzt die Anweisungen des Assistenten für diesen Durchlauf), `append_current_datetime=true` |

Die Bedeutung und die zulässigen Werte jedes Feldes sind unter [Modellspezifikations-Preset-Felder](/docs/configuration/librechat_yaml/object_structure/model_specs) aufgeführt. Wenn Sie einen Wert übergeben, den der Anbieter ablehnt (z. B. ein `max_tokens` über dem Limit des Modells), erhalten Sie beim Senden einen API-Fehler; starten Sie einen **Neuen Chat**, um ihn zu beheben.

## Farbmodus festlegen [#set-the-color-mode]

Wenn Ihr Administrator dies aktiviert, legt `theme=light`, `theme=dark` oder `theme=system` in einem Link Ihren Farbmodus fest. So kann eine App, die auf LibreChat verlinkt, ihren eigenen Modus übergeben. Er wird als Ihre Einstellung gespeichert, bis Sie ihn in den Einstellungen ändern.

## Einrichtung [#setup]

Abfrageparameter funktionieren ohne Einrichtung. Administratoren können mit [`interface.autoSubmitFromUrl`](/docs/configuration/librechat_yaml/object_structure/interface#autosubmitfromurl) verhindern, dass `submit=true` automatisch sendet, und mit [`interface.colorModeFromUrl`](/docs/configuration/librechat_yaml/object_structure/interface#colormodefromurl) den Parameter `theme` aktivieren.
