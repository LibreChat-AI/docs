Artifacts pozwalają agentom LibreChat renderować wygenerowane komponenty React, HTML, SVG, Markdown oraz zawartość Mermaid w dedykowanym interaktywnym widoku. Użytkownicy mogą kontynuować konwersację, aby poprawić wynik, zachowując jednocześnie wygenerowaną zawartość oddzielnie od odpowiedzi na czacie.

## Włączanie Artifacts dla Agenta [#enable-artifacts-for-an-agent]

1. Utwórz lub edytuj [Agent](/docs/features/agents).
2. Otwórz **Add tools** i wybierz **Artifacts**.
3. Wybierz tryb instrukcji artefaktów.
4. Zapisz agenta.

Dostępne tryby to:

- **Normal**: Wstrzykuje standardowe instrukcje LibreChat dla artefaktów React, HTML, SVG, Markdown i Mermaid.
- **shadcn/ui**: Dodaje wskazówki dotyczące biblioteki komponentów shadcn/ui dla bardziej dopracowanych generowanych interfejsów.
- **Custom**: Utrzymuje włączone renderowanie artefaktów, ale nie wstrzykuje żadnych wbudowanych instrukcji. Umieść pełne zachowanie artefaktu, jakiego oczekujesz, w instrukcjach agenta.

Konfiguracja na poziomie agenta jest preferowana, ponieważ każdy agent może korzystać z trybu i instrukcji odpowiednich dla swojego celu. Administrator może ukryć Artifacts, usuwając `artifacts` z [możliwości agenta](/docs/configuration/librechat_yaml/object_structure/agents#capabilities).

## Co obsługują Artifacts [#what-artifacts-support]

- Interaktywne komponenty React i strony HTML
- Obrazy SVG i diagramy Mermaid
- Wyrenderowane dokumenty Markdown
- Iteracyjne aktualizacje poprzez wiadomości uzupełniające
- Każdy model dostępny dla skonfigurowanego agenta

## Podgląd i eksport [#preview-and-export]

Użyj kontrolki pełnego ekranu w podglądzie wyrenderowanego artefaktu, aby rozszerzyć go na cały obszar przeglądarki. Kontrolka podąża za stanem Fullscreen API przeglądarki, wychodzi z trybu pełnoekranowego w standardowy sposób za pomocą klawisza Escape lub kontrolek przeglądarki i jest ukrywana, gdy tryb pełnoekranowy jest niedostępny.

Na komputerze stacjonarnym wybierz **Open in new window** w nagłówku panelu artefaktów, aby przenieść panel do osobnego okna przeglądarki, na przykład w celu umieszczenia go na drugim ekranie. Artefakt jest aktualizowany na bieżąco w miarę przesyłania odpowiedzi, a niezapisane zmiany w kodzie oraz wybrana karta są przenoszone. Aby przywrócić panel do czatu, wybierz **Dock back to panel** lub zamknij okno. LibreChat zapamiętuje rozmiar i położenie okna przy następnym użyciu.

- Pozostaw kartę czatu otwartą: okno jest kontrolowane przez kartę czatu, a zamknięcie tej karty powoduje również zamknięcie okna.
- Jeśli przeglądarka blokuje okno, LibreChat wyświetli powiadomienie. Zezwól na wyskakujące okienka dla tej witryny i spróbuj ponownie.
- Przycisk nie jest wyświetlany w układach wąskich (mobilnych).

Administratorzy mogą usunąć przycisk i zachować artefakty w panelu bocznym, ustawiając [`interface.artifactUndocking: false`](/docs/configuration/librechat_yaml/object_structure/interface#artifactundocking).

Diagramy Mermaid wyświetlane są jako kompaktowe karty w tekście, które można otworzyć w panelu artefaktów. Wyeksportuj diagram jako SVG lub PNG bezpośrednio z karty w tekście lub z panelu. Podglądy Mermaid renderowane są bezpośrednio, zamiast ładować bundler Sandpack; eksport do PNG stosuje ograniczone wymiary płótna, aby chronić przeglądarkę przed zbyt dużymi diagramami.

Artefakty utworzone przez model są pobierane pod swoim tytułem lub nagłówkiem Markdown z rozszerzeniem odpowiadającym wyeksportowanej zawartości. Niezmieniony artefakt oparty na pliku pobiera pełną oryginalną wersję z oryginalną nazwą pliku i formatem, jeśli są dostępne. Pobieranie edytowanej lub zapisanej w pamięci podręcznej zawartości podglądu wykorzystuje kwalifikator `.preview`, aby nie została ona pomylona z oryginalnym plikiem.

## Content-Security-Policy

Może być konieczna aktualizacja nagłówka Content-Security-Policy Twojego serwera WWW, aby uwzględnić `frame-src 'self' https://*.codesandbox.io` w celu ładowania wygenerowanych aplikacji HTML w panelu Artifacts. Jest to zależność biblioteki [sandpack](https://sandpack.codesandbox.io/).

## Samodzielne hostowanie bundlera Sandpack [#self-hosting-the-sandpack-bundler]

Artefakty w LibreChat wykorzystują bibliotekę Sandpack od CodeSandbox do bezpiecznego renderowania kodu HTML/JS. Domyślnie LibreChat łączy się z publiczną siecią CDN CodeSandbox, która może również przesyłać telemetrię dotyczącą jej użycia.

Aby zapewnić zwiększoną prywatność, zgodność z wymogami bezpieczeństwa lub w przypadku odizolowanych środowisk sieciowych, możesz [samodzielnie hostować bundler.](https://sandpack.codesandbox.io/docs/guides/hosting-the-bundler)

### Dlaczego warto samodzielnie hostować Sandpack Bundler? [#why-self-host-the-sandpack-bundler]

[Self-hosting the bundler](https://sandpack.codesandbox.io/docs/guides/hosting-the-bundler) zapewnia kilka korzyści:

- **Prywatność i bezpieczeństwo**: Utrzymuj wykonywanie kodu we własnej infrastrukturze
- **Niezawodność**: Usuń zależność od usług zewnętrznych
- **Wydajność**: Zmniejsz opóźnienia, hostując bundler w swojej sieci
- **Zgodność**: Spełnienie wymagań organizacyjnych dotyczących przetwarzania danych
- **Kontrola**: Skonfiguruj i dostosuj do swoich konkretnych potrzeb

### Konfiguracja [#configuration]

Gdy masz już skonfigurowany własny bundler, po prostu skonfiguruj LibreChat, aby z niego korzystał, ustawiając zmienną środowiskową:

```bash
# `.env` file
SANDPACK_BUNDLER_URL=http://your-bundler-url
```

### Ogólne uwagi [#general-considerations]

Samodzielne hostowanie bundlera wprowadza dodatkowy narzut:

- **Konfiguracja CORS**: Będziesz musiał zarządzać politykami współdzielenia zasobów między źródłami (cross-origin resource sharing)
- **Zarządzanie bezpieczeństwem**: Stajesz się odpowiedzialny za bezpieczeństwo usługi bundlera
- **Konserwacja**: Aktualizacje i poprawki będą musiały być stosowane ręcznie
- **Wymagania dotyczące zasobów**: Do hostowania bundlera będą potrzebne dodatkowe zasoby serwerowe

Szczegółowe instrukcje dotyczące konfiguracji i utrzymania własnego bundlera znajdują się w [forku repozytorium CodeSandbox](https://github.com/LibreChat-AI/codesandbox-client) dostosowanym do wdrożenia LibreChat, w tym usunięcia telemetrii z Sandpack.
