Forker copie une partie d'une conversation dans un nouveau chat. Utilisez cette fonction lorsque vous souhaitez explorer une autre direction à partir d'un point donné d'un fil de discussion, ou diviser une longue conversation en une conversation distincte, tout en laissant l'original exactement tel qu'il était.

## Fork à partir d'un message [#fork-from-a-message]

Survolez un message et sélectionnez l'icône de bifurcation (**Open Fork Menu**). Un menu contextuel s'ouvre avec trois options de bifurcation, deux cases à cocher et **Remember**. Choisissez une option et la bifurcation s'effectue immédiatement : LibreChat affiche « Forking conversation... », puis ouvre la nouvelle conversation.

Le nouveau chat conserve le titre d'origine. Un fork d'un chat temporaire est également temporaire.

Le forking n'est pas disponible pour les messages de l'endpoint Assistants ni pour les résultats de recherche.

## Ce qui est copié [#what-gets-copied]

Les options déterminent quels messages sont inclus. Le « message cible » est celui à partir duquel vous avez ouvert le popover.

- **Messages visibles uniquement** : le chemin direct depuis le début de la conversation jusqu'au message cible, sans aucune autre branche. C'est ce que vous voyez à l'écran.
- **Inclure les branches associées** : le même chemin, ainsi que les branches alternatives (modifications et régénérations) qui se sont détachées de celui-ci.
- **Inclure tout vers/depuis ici** : chaque message menant à la cible, y compris les branches voisines, qu'elles soient ou non sur le chemin visible. C'est le comportement par défaut.

Survolez l'icône d'une option pour voir la même explication dans l'application.

## Commencez le fork ici et excluez les fichiers [#start-fork-here-and-leave-out-files]

**Start fork here** inverse le sens. Le message depuis lequel vous avez ouvert la fenêtre contextuelle devient le point de départ, et la bifurcation s'étend de là jusqu'au dernier message de la conversation, en utilisant l'option que vous avez choisie.

**Exclure les fichiers** copie les messages sans leurs fichiers joints ou générés, afin que les messages suivants de la bifurcation ne les renvoient pas. Utilisez cette option lorsqu'un fichier volumineux ou défectueux pose problème dans le fil d'origine. Cette case à cocher n'est jamais mémorisée ; vous devez la cocher pour chaque bifurcation.

## Remember et l'option de bifurcation par défaut [#remember-and-the-default-fork-option]

Cocher **Se souvenir** avant de choisir une option enregistre cette option comme valeur par défaut. Par la suite, l'icône de fourche ignore la fenêtre contextuelle et crée la fourche immédiatement avec cette option. La case **Démarrer la fourche ici** est toujours conservée telle que vous l'avez laissée en dernier.

Pour récupérer la fenêtre contextuelle ou modifier le choix enregistré, ouvrez **Paramètres**, accédez à l'onglet **Chat**, puis recherchez les paramètres de fork sous **Conversations** :

- **Utiliser l'option de fork par défaut** : lorsqu'elle est activée, l'icône de fork effectue le fork immédiatement avec l'option par défaut.
- **Option de fourche par défaut** : l'une des trois options à utiliser. Affichée uniquement lorsque le bouton ci-dessus est activé.
- **Démarrer le fork à partir du message cible par défaut** : la valeur par défaut pour **Démarrer le fork ici**.

## Créer un fork d'une conversation partagée [#forking-a-shared-conversation]

Lorsqu'une personne partage une conversation avec vous, **Continuer cette conversation** sur la page partagée la duplique dans votre propre compte, en suivant la branche que vous avez sélectionnée. Voir [Liens partageables](/docs/features/shareable_links#continue-a-shared-chat).

## Configuration [#setup]

La bifurcation est activée pour tous et ne nécessite aucune configuration. Les administrateurs peuvent limiter le débit des requêtes de bifurcation à l'aide des variables `FORK_*` dans la [référence .env](/docs/configuration/dotenv#conversation-forking-rate-limiting).
