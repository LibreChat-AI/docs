Agent Plugin은 LibreChat 서버에 있는 폴더로, 함께 사용되는 [Skills](/docs/features/skills), [MCP servers](/docs/features/mcp), 그리고 선택적인 command hook을 하나로 묶습니다. 운영자는 이 폴더를 plugin 디렉터리에 넣고 LibreChat을 재시작하면 되며, UI에서 설치할 항목은 없습니다. LibreChat은 공개된 Agent Plugins `1.0.0` 패키지 형식을 따르므로, 하나의 패키지를 이를 지원하는 다른 도구와도 공유할 수 있습니다.

Agent Plugins는 실험적 기능입니다. 패키지 형식과 동작은 변경될 수 있습니다.

## 사용자가 보는 것 [#what-users-see]

사용자는 플러그인 자체를 보지 못합니다. 대신 플러그인이 담고 있는 내용을 봅니다.

- 그 스킬은 스킬 목록에서 다른 스킬들과 함께 표시됩니다. 읽기 전용이며, 일반적인 스킬 권한 규칙을 따르고, 다른 스킬과 마찬가지로 **Available to agent** 설정으로 켜거나 끌 수 있습니다.
- 그 MCP 서버는 도구 라이브러리에 표시되며, `librechat.yaml`에 정의된 서버와 같이 에이전트에 추가할 수 있습니다.
- 이 훅은 에이전트 실행 중 특정 시점, 예를 들어 도구 호출 직전이나 실행이 중지될 때 서버에서 실행됩니다. 훅은 도구 호출을 차단하거나, 프롬프트에 컨텍스트를 추가하거나, 실행을 중단할 수 있으며, 사용자는 그 결과만 확인하게 됩니다.

스킬 또는 MCP 서버 이름이 다른 곳에 정의된 이름과 충돌하면, 다른 정의가 우선합니다. 독립형(standalone) 배포 스킬 디렉터리의 스킬은 플러그인 스킬보다 우선하며, `librechat.yaml`에 정의된 서버는 플러그인 서버보다 우선합니다.

## 플러그인이 포함할 수 있는 내용 [#what-a-plugin-can-contain]

플러그인 폴더에는 `plugin.json` 매니페스트와 다음 중 하나 이상이 포함됩니다:

- `skills/` 디렉터리 아래에 스킬마다 하나의 폴더를 두고, 각 폴더에는 `SKILL.md`를 둡니다.
- `mcp.json`, MCP 서버 정의. 로컬(`stdio`) 서버는 플러그인 폴더 내부에서 실행되며 고유한 영구 데이터 디렉터리를 갖습니다.
- `ai.librechat/hooks/hooks.json`, 명령 훅(command hooks). 이 훅은 API 호스트에서 프로세스로 실행되며, 운영자가 활성화하지 않으면 비활성 상태로 유지됩니다.

각 부분은 독립적으로 로드되므로, 손상된 `mcp.json`이 있어도 플러그인의 스킬 로드가 중단되지 않습니다. 문제는 시작 로그에 보고됩니다.

## 설정 [#setup]

플러그인은 기본적으로 프로젝트 루트의 `./plugin`에서 로드되며, 명령 훅(command hook)은 기본적으로 비활성화되어 있습니다. 디렉터리 설정, 패키지 구조, 매니페스트 및 MCP 검증 규칙, 훅 실행 계약에 대해서는 [Agent Plugins 설정](/docs/configuration/agent_plugins)을 참고하세요.
