프로젝트는 고객, 강의, 장기 작업처럼 함께 묶여야 하는 대화를 모아 두는 폴더입니다. 프로젝트 안의 채팅은 프로젝트의 지침을 공유하고 프로젝트의 참조 파일을 활용할 수 있으므로, 새 채팅을 만들 때마다 같은 맥락을 반복해서 입력하지 않고 한 번만 설정하면 됩니다.

프로젝트는 개인용입니다. 다른 사용자는 여러분의 프로젝트나 프로젝트에 포함된 채팅을 볼 수 없으며, 프로젝트를 공유하거나 다른 사람에게 넘길 수도 없습니다. 프로젝트는 모델을 지정하지 않습니다. 각 채팅은 고유의 모델, 에이전트 및 매개변수를 그대로 유지합니다.

## 프로젝트 만들기 [#create-a-project]

사이드바의 **Projects** 섹션 헤더에는 프로젝트 페이지를 여는 **All projects** 버튼이 있습니다. 해당 페이지에서 **New project**를 선택하세요. (프로젝트가 아직 없을 때는 사이드바 섹션에 **New project**가 바로 표시됩니다.) 최대 100자의 이름을 입력하고, 원하는 경우 설명을 추가한 다음 **Create project**를 선택하세요. LibreChat이 새 프로젝트의 워크스페이스를 엽니다.

프로젝트 페이지에는 각 프로젝트가 설명과 채팅 수가 포함된 카드 형태로 표시됩니다. **프로젝트 검색**은 이름과 설명을 기준으로 일치하는 항목을 찾으며, 정렬 메뉴에서는 **최근 활동**, **생성일**, **이름**을 선택할 수 있습니다.

## 채팅 시작 또는 이동 [#start-or-move-chats]

프로젝트의 워크스페이스에서, 또는 사이드바에서 프로젝트 옆에 있는 새 채팅 아이콘을 사용해 **New chat in** 뒤에 프로젝트 이름이 붙은 채팅을 시작하세요. 메시지 입력창에는 프로젝트 칩이 표시되며, 이를 사용해 다른 프로젝트로 전환하거나 메시지를 보내기 전에 × 를 선택하여 프로젝트를 제거할 수 있습니다. 메시지를 보내면 해당 채팅은 프로젝트에 속하게 됩니다.

기존 채팅을 프로젝트에 넣으려면 해당 채팅의 메뉴를 열고 **Change project**를 선택한 다음, 검색 가능한 목록에서 프로젝트를 고르세요. **Remove from project**를 선택하면 다시 프로젝트에서 빠집니다. 데스크톱에서는 채팅을 사이드바의 프로젝트로 끌어다 놓을 수도 있습니다. 채팅은 다음 메시지부터 해당 프로젝트의 지침과 파일을 사용하며, 프로젝트를 벗어나는 즉시 이를 더 이상 사용하지 않습니다.

프로젝트 안의 채팅에서는 대화 상단에 프로젝트 이름이 표시됩니다. 이를 선택하면 워크스페이스가 열립니다. 사이드바에서 각 프로젝트를 펼치면 해당 프로젝트의 채팅 목록이 나타나며, 주 **Chats** 목록에는 어떤 프로젝트에도 속하지 않은 채팅만 표시됩니다. 프로젝트 워크스페이스에는 해당 프로젝트의 채팅만 나열되며, **Updated** 또는 **Created** 기준으로 정렬할 수 있습니다.

## 지침 [#instructions]

**Instructions**는 워크스페이스에서 프로젝트 내 모든 채팅에 대한 배경, 어조, 목표를 설정합니다. 변경하려면 **Edit**을 선택하세요. 서버 자체의 시스템 규칙은 그 위에 그대로 적용됩니다.

지침은 저장한 이후에 보내는 메시지에 적용됩니다. 일반 채팅, 에이전트 채팅, Assistants 채팅 모두 해당됩니다. 이전 응답은 다시 작성되지 않습니다. 기본적으로 최대 16,000자까지 입력할 수 있습니다.

다른 탭에서 프로젝트를 그사이에 수정했다면, 저장 시 **This project was changed in another session. Reload to see the latest version.** 오류가 표시되며 저장에 실패합니다. 페이지를 새로고침하여 최신 버전을 확인한 후 변경 작업을 다시 진행하세요.

## 파일 [#files]

**Files**는 프로젝트의 참고 문서를 보관합니다. **Add files**를 사용해 **Upload from device**로 업로드하거나, **Choose from your files**에서 이전에 업로드한 파일을 선택할 수 있습니다. 각 파일은 색인되는 동안 **Processing**으로 표시되며, 채팅에서 사용할 수 있게 되면 **Ready**로 바뀝니다. **Choose from your files**에는 파일 검색용으로 업로드되었고 만료되지 않은 파일만 나열됩니다. 이후 삭제되거나 만료된 파일은 **Unavailable**로 계속 표시되며 건너뜁니다.

프로젝트의 채팅은 이 파일들을 검색하고, 문서 전체가 아니라 관련 구절만 가져옵니다. 이는 채팅 또는 에이전트에서 **File Search**가 켜져 있을 때만 작동합니다. 서버에 파일 검색이 설정되어 있지 않거나 사용자의 역할에 파일 검색 사용 권한이 없다면, 새 프로젝트 파일을 업로드할 수 없습니다.

프로젝트에는 관리자가 한도를 변경하지 않는 한 최대 50개의 파일을 보관할 수 있습니다. 파일을 삭제하면 이후 메시지에만 영향을 미치며, 이미 해당 파일을 사용한 응답은 그대로 유지됩니다.

## 이름 변경 또는 삭제 [#rename-or-delete]

워크스페이스에서 프로젝트 이름이나 설명을 클릭하여 편집하거나, 사이드바에 있는 프로젝트 메뉴에서 **Edit project**를 사용하세요.

**프로젝트 삭제**를 워크스페이스의 **Project options** 메뉴에서 선택하거나 사이드바 메뉴의 **Delete**를 선택하면 확인을 요청한 뒤 프로젝트만 삭제합니다. 프로젝트에 속한 채팅은 기록에 그대로 남으며, 더 이상 어떤 프로젝트에도 할당되지 않습니다. 프로젝트를 보고 있는 상태에서 해당 프로젝트가 삭제되면 LibreChat은 프로젝트 페이지로 돌아갑니다.

## 설정 [#setup]

프로젝트는 LibreChat v0.8.7부터 모든 사용자에게 제공됩니다. 어떤 설정이나 역할 권한으로도 프로젝트를 숨길 수 없습니다. 관리자는 `librechat.yaml`의 [`projects`](/docs/configuration/librechat_yaml/object_structure/config#projects) 키에서 프로젝트당 파일 제한과 지침 및 설명의 최대 길이를 변경할 수 있습니다. 프로젝트 파일은 [파일 검색](/docs/features/rag_api)을 사용합니다.
