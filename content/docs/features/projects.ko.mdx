Projects를 사용하면 각 사용자가 관련 대화를 이름이 지정된 작업 공간으로 구성할 수 있습니다. 이는 장기적인 작업 흐름, 팀, 클라이언트, 수업 또는 모든 대화에서 배경 정보를 반복하지 않고도 동일한 배경을 공유하는 집중적인 채팅 세트가 필요한 모든 주제에 유용합니다.

<Callout type="info" title="가용성">
  Projects는 LibreChat **v0.8.7**에서 추가되었습니다. Projects를 숨기는 스위치나 역할 권한은 없으므로, 지원되는 버전을 사용하는 모든 로그인한 사용자는 이 기능을 사용할 수 있습니다. 관리자는 `librechat.yaml`의 [`projects`](/docs/configuration/librechat_yaml/object_structure/config#projects) 블록을 통해 지침, 설명 및 파일 제한을 조정할 수 있습니다. 인터페이스 어디에서도 Projects를 찾을 수 없다면, 해당 인스턴스가 이전 버전을 실행 중이므로 업데이트가 필요합니다.
</Callout>

## 프로젝트의 역할 [#what-projects-do]

- 선택적 설명이 포함된 이름이 지정된 작업 공간(workspace)으로 대화 그룹화
- 프로젝트의 모든 채팅에 동일한 **Instructions**를 부여하세요
- 프로젝트 내 채팅에서 검색할 수 있는 참조 **파일**을 첨부하세요
- 특정 프로젝트로 범위가 지정된 새 채팅을 시작하거나, 기존 채팅을 프로젝트 안팎으로 이동하세요.
- 프로젝트 작업 공간에서 채팅을 탐색, 정렬, 이동, 제거 또는 삭제하세요.
- 이름이나 설명으로 프로젝트를 검색하고 최근 활동, 생성 날짜 또는 이름순으로 정렬하세요.

Projects는 이를 생성한 사용자 개인에게 귀속됩니다. 다른 사용자는 귀하의 프로젝트 목록을 볼 수 없으며, 프로젝트를 공유하거나 이전할 수 없습니다. Projects는 모델 설정을 포함하지 않으며, 각 채팅은 고유한 모델, Agent 및 매개변수를 유지합니다.

## 프로젝트 생성 [#create-a-project]

<Steps>
<Step>

**프로젝트 페이지를 엽니다.** 사이드바의 **Projects** 섹션 헤더에는 이를 여는 **All projects** 버튼이 있습니다.

</Step>
<Step>

**Choose New project**를 선택하세요. 이 옵션은 프로젝트 페이지 헤더에서 항상 사용할 수 있습니다.

</Step>
<Step>

**프로젝트 이름을 지정하세요.** 이름은 필수이며 설명은 선택 사항입니다. 이후 LibreChat이 프로젝트 작업 공간을 엽니다.

</Step>
</Steps>

아직 프로젝트가 없더라도 사이드바의 **Projects** 섹션에서 **New project** 버튼을 사용할 수 있습니다. 프로젝트가 생성되면 해당 섹션은 접기 전까지 기본적으로 확장된 상태로 유지됩니다.

프로젝트 이름은 100자로 제한됩니다. 설명은 기본적으로 1,000자로 제한되며, 중복된 프로젝트 이름은 허용됩니다.

프로젝트 페이지는 각 프로젝트를 설명과 채팅 수가 포함된 폴더 카드로 보여줍니다.

## 지침 [#instructions]

Instructions은 프로젝트 내 모든 채팅의 어조, 목표 또는 배경을 설정합니다. 예를 들어, 클라이언트의 스타일 가이드나 특정 채팅 세트가 속한 과정 등을 설정할 수 있습니다. 플랫폼 및 안전 규칙은 이러한 설정 위에 여전히 적용됩니다.

<Steps>
<Step>

**프로젝트 작업 공간(project workspace)**을 열고 **Instructions** 섹션을 찾으세요.

</Step>
<Step>

**편집(Edit)을 선택**하여 지침 대화 상자를 엽니다.

</Step>
<Step>

**작업 공간 지침을 입력하고 저장하세요.** 기본적으로 지침은 최대 16,000자까지 입력할 수 있습니다.

</Step>
</Steps>

지침(Instructions)은 프로젝트의 새 메시지에 사용됩니다. 지침을 변경해도 이전 메시지는 다시 작성되지 않습니다. 이미 생성된 답변은 그대로 유지되며, 프로젝트의 모든 채팅에서 다음 메시지부터 현재 버전의 지침이 적용됩니다. 지침은 일반 모델 채팅, 에이전트(Agents), 그리고 어시스턴트(Assistants) 대화에 적용됩니다.

대화 상자가 열려 있는 동안 다른 세션에서 프로젝트가 변경된 경우, 저장 시 **This project was changed in another session. Reload to see the latest version.**라는 메시지가 표시됩니다. 페이지를 새로고침하고 편집 내용을 다시 적용하세요.

## 파일 [#files]

프로젝트 파일은 프로젝트의 채팅이 참조할 수 있는 문서를 제공합니다. File Search가 활성화되면, 채팅은 전체 파일 대신 해당 파일의 관련 발췌문을 사용합니다.

작업 공간의 **Files** 섹션에서 **Add files**를 선택한 다음:

- **Upload from device**를 클릭하여 새 문서를 업로드하세요. 각 업로드는 **Ready** 상태가 될 때까지 **Processing**으로 표시됩니다.
- **파일에서 선택**을 클릭하여 이미 업로드한 파일을 첨부하세요.

File Search(임베디드 메시지 첨부 파일)를 위해 업로드되었으며 만료되지 않은 파일만 첨부할 수 있으므로, **Choose from your files**에는 해당 파일들만 나열됩니다. 프로젝트는 기본적으로 최대 50개의 파일을 보관합니다.

프로젝트 파일은 File Search를 통해 사용되므로, 채팅에서 파일을 읽을 수 있는 경우는 다음과 같습니다:

- 에이전트(Agent) 또는 일반 채팅에서 **File Search**가 활성화되어 있습니다.
- Agents endpoint에 대해 File Search가 활성화되었으며, 해당 배포의 파일 검색 서비스를 사용할 수 있습니다.

삭제되거나 만료된 파일은 **Unavailable**로 표시되며 건너뜁니다. 프로젝트에서 파일을 제거하는 것은 향후 메시지에 영향을 미치며, 채팅 기록에는 영향을 주지 않습니다.

## 프로젝트에서 작업하기 [#work-in-a-project]

프로젝트를 열어 설명, 지침, 파일 및 할당된 채팅을 확인하세요. 프로젝트 이름이나 설명을 선택하여 그 자리에서 바로 편집할 수 있습니다. 작업 공간의 **Chats** 목록은 마지막 업데이트 날짜 또는 생성 날짜순으로 정렬할 수 있습니다.

작업 공간 헤더의 **New chat**을 사용하여 해당 프로젝트로 범위가 지정된 작성기를 엽니다. 프로젝트 칩을 통해 새 대화가 해당 프로젝트에 할당될 것임을 확인할 수 있습니다. 사이드바의 각 프로젝트 행에서도 동일한 작업을 수행할 수 있습니다.

프로젝트에 속한 채팅은 대화 상단에 프로젝트 이름이 포함된 프로젝트 배지를 표시합니다. 배지를 선택하면 프로젝트 작업 공간이 열립니다.

각 프로젝트 채팅에는 다음과 같은 작업을 수행할 수 있는 오버플로우 메뉴가 있습니다:

- **Change project**는 검색 가능한 프로젝트 선택기를 엽니다.
- **Remove from project**는 대화 내용은 유지하되 프로젝트 할당을 해제합니다.
- **Delete**는 확인 후 대화를 삭제합니다.

## 기존 채팅 이동하기 [#move-existing-chats]

대화 메뉴를 열고 **Change project**를 선택한 다음, 할당할 프로젝트를 선택하세요. 대화를 프로젝트에서 다시 꺼내려면 **Remove from project**를 사용하세요. 이 옵션은 이미 프로젝트에 속해 있는 대화에만 표시됩니다. 데스크톱에서는 대화를 사이드바의 프로젝트로 드래그할 수도 있습니다. [Sidebar and Navigation](/docs/features/navigation#desktop-sidebar)을 참조하세요.

프로젝트 컨텍스트는 메시지를 보낼 때마다 다시 읽어오므로, 프로젝트로 이동한 채팅은 다음 메시지부터 해당 프로젝트의 지침과 파일을 적용하며, 프로젝트에서 제거한 채팅은 더 이상 해당 지침과 파일을 사용하지 않게 됩니다.

사이드바에서 각 프로젝트 행을 확장하면 해당 프로젝트의 채팅 목록이 표시되며, 목록이 길 경우 **Show all**이 나타납니다. **Chats** 섹션에는 프로젝트에 포함되지 않은 대화만 나열되므로, 프로젝트 채팅은 한 곳에만 표시됩니다. 여전히 모든 채팅이 나열되는 경우는 다음 세 가지입니다:

- 대화 내용을 검색하는 동안
- [채팅 목록 메뉴](/docs/features/navigation#filter-and-sort-the-chat-list)의 **보관된 채팅** 보기에서
- 프로젝트를 불러오는 데 실패할 때

## 프로젝트 관리 [#manage-projects]

사이드바의 프로젝트 메뉴를 사용하여 다음을 수행하세요:

- **프로젝트 열기**
- **Edit project**는 워크스페이스의 이름과 설명을 편집할 수 있는 상태로 엽니다.
- 프로젝트 **삭제**

프로젝트 페이지는 동일한 편집 및 삭제 작업을 제공하며, 작업 공간 헤더에는 **Delete project**가 포함된 프로젝트 옵션 메뉴가 있습니다.

프로젝트를 삭제하면 해당 채팅에서 프로젝트 할당이 제거됩니다. 대화 자체는 삭제되지 않습니다.

## 프로젝트 찾기 [#find-a-project]

프로젝트 페이지에는 프로젝트 이름과 설명을 검색할 수 있는 **Search projects** 상자가 있으며, **Latest activity**, **Created**, **Name**으로 정렬할 수 있는 정렬 컨트롤이 있습니다. 목록이 길어지면 **Load more**를 통해 페이지를 불러올 수 있습니다.

## 참고 사항 [#notes]

- 프로젝트에서 시작된 새 채팅은 대화가 생성될 때 해당 할당을 유지합니다.
- 프로젝트 검색은 대소문자를 구분하지 않으며 이름과 설명 모두와 일치합니다.
- 프로젝트를 보고 있는 도중에 해당 프로젝트가 삭제되면, LibreChat은 프로젝트 목록으로 돌아갑니다.
