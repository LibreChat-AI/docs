Artifacts memungkinkan Agen LibreChat untuk merender komponen React, HTML, SVG, Markdown, dan konten Mermaid yang dihasilkan dalam tampilan interaktif khusus. Pengguna dapat melanjutkan percakapan untuk merevisi hasil tersebut sambil tetap memisahkan konten yang dihasilkan dari respons obrolan.

## Mengaktifkan Artifacts untuk Agent [#enable-artifacts-for-an-agent]

1. Buat atau edit [Agent](/docs/features/agents).
2. Buka **Add tools** dan pilih **Artifacts**.
3. Pilih mode instruksi artefak.
4. Simpan agen tersebut.

Mode yang tersedia adalah:

- **Normal**: Menyuntikkan instruksi standar LibreChat untuk artefak React, HTML, SVG, Markdown, dan Mermaid.
- **shadcn/ui**: Menambahkan panduan pustaka komponen shadcn/ui untuk antarmuka yang dihasilkan agar lebih rapi.
- **Custom**: Membiarkan rendering artefak tetap aktif tetapi tidak menyuntikkan instruksi bawaan apa pun. Masukkan perilaku artefak lengkap yang Anda inginkan ke dalam instruksi agen.

Konfigurasi tingkat agen lebih disukai karena setiap agen dapat menggunakan mode dan instruksi yang sesuai dengan tujuannya. Administrator dapat menyembunyikan Artifacts dengan menghapus `artifacts` dari [kemampuan agen](/docs/configuration/librechat_yaml/object_structure/agents#capabilities).

## Dukungan Artifacts [#what-artifacts-support]

- Komponen React interaktif dan halaman HTML
- Gambar SVG dan diagram Mermaid
- Dokumen Markdown yang dirender
- Pembaruan iteratif melalui pesan tindak lanjut
- Model apa pun yang tersedia untuk agen yang dikonfigurasi

## Pratinjau dan Ekspor [#preview-and-export]

Gunakan kontrol layar penuh dalam pratinjau artefak yang dirender untuk memperluasnya ke tampilan peramban secara penuh. Kontrol ini mengikuti status Fullscreen API peramban, keluar secara normal dengan tombol Escape atau kontrol peramban, dan disembunyikan saat layar penuh tidak tersedia.

Di desktop, pilih **Open in new window** di header panel artefak untuk memindahkan panel ke jendela browser terpisah, misalnya untuk menempatkannya di layar kedua. Artefak akan terus diperbarui saat respons mengalir, dan suntingan kode yang belum disimpan serta tab yang dipilih akan terbawa. Untuk mengembalikan panel ke obrolan, pilih **Dock back to panel** atau tutup jendela tersebut. LibreChat akan mengingat ukuran dan posisi jendela untuk penggunaan berikutnya.

- Tetap buka tab chat: jendela dikendalikan oleh tab chat, dan menutup tab tersebut juga akan menutup jendelanya.
- Jika browser memblokir jendela tersebut, LibreChat akan menampilkan pemberitahuan. Izinkan pop-up untuk situs ini dan coba lagi.
- Tombol tersebut tidak ditampilkan pada tata letak sempit (seluler).

Administrator dapat menghapus tombol tersebut dan tetap menyimpan artefak di panel samping dengan mengatur [`interface.artifactUndocking: false`](/docs/configuration/librechat_yaml/object_structure/interface#artifactundocking).

Diagram Mermaid muncul sebagai kartu inline ringkas yang dapat dibuka di panel artefak. Ekspor diagram sebagai SVG atau PNG baik dari kartu inline maupun panel. Pratinjau Mermaid dirender secara langsung alih-alih memuat bundler Sandpack; ekspor PNG menerapkan dimensi kanvas terbatas untuk melindungi browser dari diagram yang terlalu besar.

Artefak yang dibuat oleh model diunduh berdasarkan judul atau heading Markdown-nya dengan ekstensi yang sesuai dengan konten yang diekspor. Artefak berbasis file yang tidak diedit akan mengunduh file asli secara lengkap dengan nama file dan format aslinya jika tersedia. Mengunduh konten pratinjau yang telah diedit atau di-cache menggunakan kualifikator `.preview` agar tidak tertukar dengan file aslinya.

## Content-Security-Policy

Anda mungkin perlu memperbarui Content-Security-Policy pada server web Anda untuk menyertakan `frame-src 'self' https://*.codesandbox.io` agar dapat memuat aplikasi HTML yang dihasilkan di panel Artifacts. Ini adalah dependensi dari pustaka [sandpack](https://sandpack.codesandbox.io/).

## Self-Hosting the Sandpack Bundler [#self-hosting-the-sandpack-bundler]

Artifacts di LibreChat menggunakan pustaka Sandpack dari CodeSandbox untuk merender kode HTML/JS secara aman. Secara default, LibreChat terhubung ke CDN publik CodeSandbox, yang mungkin juga mengirimkan telemetri untuk penggunaannya.

Untuk privasi yang lebih baik, kepatuhan keamanan, atau lingkungan jaringan yang terisolasi, Anda dapat [melakukan self-host pada bundler.](https://sandpack.codesandbox.io/docs/guides/hosting-the-bundler)

### Mengapa Melakukan Self-Host pada Sandpack Bundler? [#why-self-host-the-sandpack-bundler]

[Self-hosting the bundler](https://sandpack.codesandbox.io/docs/guides/hosting-the-bundler) memberikan beberapa keuntungan:

- **Privasi & Keamanan**: Jaga eksekusi kode tetap berada di dalam infrastruktur Anda sendiri
- **Reliabilitas**: Menghapus ketergantungan pada layanan eksternal
- **Performa**: Kurangi latensi dengan menghosting bundler di jaringan Anda
- **Kepatuhan**: Memenuhi persyaratan penanganan data organisasi
- **Kontrol**: Konfigurasikan dan sesuaikan dengan kebutuhan spesifik Anda

### Konfigurasi [#configuration]

Setelah Anda menyiapkan bundler yang di-host sendiri, cukup konfigurasikan LibreChat untuk menggunakannya dengan mengatur variabel lingkungan:

```bash
# `.env` file
SANDPACK_BUNDLER_URL=http://your-bundler-url
```

### Pertimbangan Umum [#general-considerations]

Self-hosting the bundler memperkenalkan beberapa overhead tambahan:

- **Konfigurasi CORS**: Anda perlu mengelola kebijakan cross-origin resource sharing
- **Manajemen Keamanan**: Anda bertanggung jawab atas keamanan layanan bundler
- **Pemeliharaan**: Pembaruan dan patch perlu diterapkan secara manual
- **Persyaratan Sumber Daya**: Sumber daya server tambahan akan diperlukan untuk menampung bundler

Untuk instruksi terperinci mengenai pengaturan dan pemeliharaan bundler yang di-host sendiri, lihat [repositori CodeSandbox yang di-fork](https://github.com/LibreChat-AI/codesandbox-client) yang disesuaikan untuk deployment LibreChat, termasuk penghapusan telemetri dari Sandpack.
