您可以导入从 ChatGPT、Claude 和 [ChatbotUI v1](https://github.com/mckaywrigley/chatbot-ui/tree/b865b0555f53957e96727bc0bbb369c9eaecd83b?tab=readme-ov-file#legacy-code) 导出的对话，也可以导入从 LibreChat 导出的 JSON 格式对话。导入的对话会像其他对话一样显示在您的历史记录中。导出功能每次只能处理一个对话。

## 获取导出文件 [#get-the-export-file]

<Tabs items={["ChatGPT", "Claude", "ChatbotUI v1", "LibreChat"]}>
<Tabs.Tab>

从 ChatGPT 请求导出数据([OpenAI 的说明](https://help.openai.com/en/articles/7260999-how-do-i-export-my-chatgpt-history-and-data))。你会收到一封包含 zip 文件下载链接的电子邮件。解压该文件,并使用其中的 `conversations.json`。

</Tabs.Tab>
<Tabs.Tab>

通过 Claude 请求导出数据([Anthropic 的说明](https://support.claude.com/en/articles/9450526-how-can-i-export-my-claude-data))。你会收到一封包含压缩包下载链接的邮件。解压该压缩包,并使用其中的 `conversations.json` 文件。Claude 的思考块(thinking blocks)会与文本一同导入。

</Tabs.Tab>
<Tabs.Tab>

从 ChatbotUI v1 导出您的对话,并直接使用其生成的 JSON 文件。

</Tabs.Tab>
<Tabs.Tab>

将对话导出为 `json` 格式(参见下方的[导出对话](#export-a-conversation))。这是将对话从一个 LibreChat 实例迁移到另一个实例的方法。

</Tabs.Tab>
</Tabs>

## 导入文件 [#import-the-file]

前往 **设置** > **数据与隐私**,点击 "Import conversations from a JSON file" 旁边的 **Import**,然后选择文件。文件选择器仅接受 `.json` 文件,因此请先解压 ChatGPT 和 Claude 的压缩包。导入过程中按钮会显示"Importing",完成后会出现"Conversations imported successfully"。

LibreChat 根据文件的内容而非文件名来识别格式。如果无法识别该文件,就会出现"Unsupported import type"(不支持的导入类型)错误。

LibreChat 导入不会导入对话中已保存的代码审批模式(包括 **Full access**)或其未读状态。导入后的对话将使用您当前的审批偏好以及部署的策略。

### 限制 [#limits]

- 除非您的管理员设置了其他限制,文件大小最多可达 250 MiB。超过此大小的文件将在上传前被拒绝。
- 单个对话或消息的大小不能超过约 16 MB，这是数据库的限制。
- 导入操作按用户和 IP 地址进行速率限制,因此连续导入大量文件时,可能会在一段时间内被拒绝。

## 导出对话 [#export-a-conversation]

打开对话,点击 **Chat options** 菜单(标题栏中的 `...` 按钮,或小屏幕上的标题栏菜单),然后选择 **Export**。选择文件名和类型,再点击 **Export**。

| 类型 | 你将获得 |
| --- | --- |
| `markdown` (.md) | 可读的对话记录。这是默认格式。 |
| `text` (.txt) | 纯文本格式的对话记录。 |
| `json` (.json) | 完整的消息数据。这是 LibreChat 可以再次导入的格式。 |
| `csv` (.csv) | 每条消息占一行。 |
| `screenshot` (.png) | 屏幕上对话显示效果的图片。 |

**导出所有消息分支**适用于 `json` 和 `csv` 格式;其他类型仅导出您当前查看的分支。**包含端点选项**会添加模型及其设置,但不适用于 `csv` 或 `screenshot` 格式。对于 `json` 格式,您还可以选择**递归**(消息嵌套在其父消息下)或顺序排列。

目前没有一次性导出所有对话的功能。新建对话或搜索结果页面中没有可导出的内容,因此也不会显示导出菜单。

## 设置 [#setup]

导入和导出功能对每位用户开箱即用，无需任何设置。管理员可以通过 `CONVERSATION_IMPORT_MAX_FILE_SIZE_BYTES` 更改导入文件大小上限，并通过 `IMPORT_*` 变量调整速率限制；详见 [.env 参考](/docs/configuration/dotenv#conversation-import)。
