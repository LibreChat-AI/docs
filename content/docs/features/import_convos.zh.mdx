Conversations Import 允许您将从其他 AI 聊天应用程序导出的对话导入到 LibreChat 中。支持的来源包括 [ChatGPT](https://chatgpt.com/)、[Claude](https://claude.ai/) 和 [ChatbotUI v1](https://github.com/mckaywrigley/chatbot-ui/tree/b865b0555f53957e96727bc0bbb369c9eaecd83b?tab=readme-ov-file#legacy-code)。

<Callout type="info" title="在哪里可以找到它">
在 LibreChat 中，导入功能位于 **Settings** → **Data Controls** 下。
</Callout>

## 从源应用程序导出 [#export-from-the-source-application]

首先，从您要迁移的应用程序中导出数据。具体步骤因来源而异。

<Callout type="info" title="想要从 LibreChat 导出数据？">
请参阅本页面底部的 [Export from LibreChat](#export-from-librechat)。
</Callout>

<Tabs items={["ChatGPT", "Claude", "ChatbotUI v1"]}>
<Tabs.Tab>

<Steps>
<Step>

**请求导出。** 按照 [ChatGPT 导出说明](https://help.openai.com/en/articles/7260999-how-do-i-export-my-chatgpt-history-and-data) 来导出您的对话。

</Step>
<Step>

**下载压缩包。** 您将收到一封包含下载链接的电子邮件。该压缩包是一个随机命名的 zip 文件，例如 `d119d98bb3711aff7a2c73bcc7ea53d96c984650d8f7e033faef78386a9907-2024-01-01-10-30-00.zip`。

</Step>
<Step>

**解压归档文件**以访问其中的 `conversations.json` 文件。

</Step>
</Steps>

</Tabs.Tab>
<Tabs.Tab>

<Steps>
<Step>

**请求您的导出。** 请遵循 [Claude 导出说明](https://support.claude.com/en/articles/9450526-how-can-i-export-my-claude-data) 来导出您的对话。

</Step>
<Step>

**下载归档文件。** 您将收到一封包含导出归档文件下载链接的电子邮件。

</Step>
<Step>

**解压归档文件**以访问其中的 `conversations.json` 文件。

</Step>
</Steps>

</Tabs.Tab>

从 [ChatbotUI v1](https://github.com/mckaywrigley/chatbot-ui/tree/b865b0555f53957e96727bc0bbb369c9eaecd83b?tab=readme-ov-file#legacy-code) 导出您的对话，然后直接导入生成的 JSON 文件。无需进行提取步骤。

</Tabs.Tab>

## 导入到 LibreChat [#import-into-librechat]

<Steps>
<Step>

**开放数据控制。** 在 LibreChat 中，前往 **设置** → **数据控制**。

</Step>
<Step>

**选择您的文件。** 点击 **Import** 并从您解压的归档文件中选择 `conversations.json` 文件（或 ChatbotUI v1 的导出 JSON 文件）。

</Step>
<Step>

**等待确认。** 导入完成后会出现一条通知。

</Step>
</Steps>

## 导入的代码审批设置 [#imported-code-approval-settings]

导入 LibreChat 对话时，其保存的代码批准模式（包括 **Full access**）不会被迁移。新的导入将使用接收者现有的偏好设置/默认值以及当前的部署/工作节点策略。批量更新无法覆盖本地存储的批准选项。此安全机制不会追溯重置现有对话；用户仍然可以通过 LibreChat 选择并保存受支持的模式。请参阅 [Attached-environment tool permissions](/docs/features/code_interpreter#attached-environment-tool-permissions)。

## 从 LibreChat 导出 [#export-from-librechat]

导出功能按对话进行，位于聊天页眉的 **Export and Share** 菜单中（在移动端则位于溢出菜单下）。打开您想要的对话，选择 **Export**，挑选一种格式，然后确认即可。

<OptionTable
  options={[
    ['markdown', '.md', '可读的转录。默认设置。', ''],
    ['text', '.txt', '纯文本转录', ''],
    ['json', '.json', '保留完整消息数据的结构化导出。', 'Supports exporting all message branches'],
    ['csv', '.csv', '表格导出，每条消息占一行。', 'Supports exporting all message branches'],

对话框中的两个选项取决于您选择的格式：

- **导出所有消息分支**仅适用于 `json` 和 `csv`。其他格式仅导出当前可见的分支。
- 其余导出选项对于 `csv` 和 `screenshot` 不可用。

<Callout type="info" title="范围">

目前没有一次性批量导出所有对话的内置功能，且全新的对话或搜索结果对话没有任何内容可供导出，因此这些情况下不会显示该菜单。

</Callout>
