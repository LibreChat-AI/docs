对话导入功能可让您将从其他 AI 聊天应用导出的对话导入到 LibreChat 中。支持的来源包括 [ChatGPT](https://chatgpt.com/)、[Claude](https://claude.ai/)、[ChatbotUI v1](https://github.com/mckaywrigley/chatbot-ui/tree/b865b0555f53957e96727bc0bbb369c9eaecd83b?tab=readme-ov-file#legacy-code),以及 LibreChat 自身的 JSON 导出文件(参见[从 LibreChat 导出](#export-from-librechat))。

<Callout type="info" title="在哪里可以找到它">
在 LibreChat 中,导入功能位于 **设置** > **Data & Privacy** > **Your data** > **Import conversations** 下。

Note: "Data & Privacy" and "Your data" and "Import conversations" are UI labels that appear as-is in the interface, so they are kept in English for consistency with the actual product. If you want them translated, let me know.
</Callout>

## 从源应用程序导出 [#export-from-the-source-application]

首先，从您要迁移的应用程序中导出数据。具体步骤因来源而异。

<Callout type="info" title="想要从 LibreChat 导出数据？">
请参阅本页面底部的 [Export from LibreChat](#export-from-librechat)。
</Callout>

<Tabs.Tab>

<Steps>
<Step>

**请求导出。** 按照 [ChatGPT 导出说明](https://help.openai.com/en/articles/7260999-how-do-i-export-my-chatgpt-history-and-data) 来导出您的对话。

</Step>

**下载压缩包。** 您将收到一封包含下载链接的电子邮件。该压缩包是一个随机命名的 zip 文件，例如 `d119d98bb3711aff7a2c73bcc7ea53d96c984650d8f7e033faef78386a9907-2024-01-01-10-30-00.zip`。

</Step>
<Step>

</Step>
</Steps>

## 导入到 LibreChat [#import-into-librechat]

<Steps>
<Step>

**开放数据与隐私。** 在 LibreChat 中，进入 **设置** > **数据与隐私**，然后在 **您的数据** 下找到 **导入对话**。

</Step>
<Step>

**选择文件。** 点击 **Import**,然后从解压后的压缩包中选择 `conversations.json` 文件(或 ChatbotUI v1 或 LibreChat 导出的 JSON 文件)。文件选择器仅接受 `.json` 文件,因此请先解压 ChatGPT 和 Claude 的 zip 压缩包。

</Step>
<Step>

**等待确认。** 导入完成后会出现一条通知。

</Step>
</Steps>

管理员可以使用 [`CONVERSATION_IMPORT_MAX_FILE_SIZE_BYTES`](/docs/configuration/dotenv#conversation-import) 限制上传文件的大小。

## 导入的代码审批设置 [#imported-code-approval-settings]

当导入 LibreChat 对话时,其保存的 Code 审批模式(包括 **Full access**)不会被一并导入。新导入的对话将使用接收方现有的偏好设置/默认值以及当前的部署/工作进程策略。批量更新无法覆盖本地存储的审批选择。此保护机制不会追溯重置现有对话;用户仍可通过 LibreChat 选择并保存受支持的模式。请参阅[附加环境工具权限](/docs/features/code_interpreter#running-code-on-your-own-machine)。

## 从 LibreChat 导出 [#export-from-librechat]

导出是按对话进行的,位于聊天标题栏中的 **Chat options** 菜单内(在移动设备上位于溢出菜单下),与 **Share**、**Rename**、**Pin**、**Duplicate**、**Archive** 和 **Delete** 并列。打开目标对话,选择 **Export**,选择格式,然后确认即可。

  options={[

可以从 **设置** > **数据与隐私** > **您的数据** > **导入对话** 导入之前导出的 `json` 文件,将其重新导入到 LibreChat 中。

对话框中的两个选项取决于您选择的格式：

- **导出所有消息分支**仅适用于 `json` 和 `csv`。其他格式仅导出当前可见的分支。
- 其余导出选项对于 `csv` 和 `screenshot` 不可用。

<Callout type="info" title="范围">

目前没有一次性批量导出所有对话的内置功能，且全新的对话或搜索结果对话没有任何内容可供导出，因此这些情况下不会显示该菜单。

</Callout>
