Ouvrez le menu du compte et choisissez **Settings**. La boîte de dialogue comporte les onglets **General**, **Chat**, **Speech**, **Data & Privacy** et **Account**, ainsi que **Langfuse** et **About** sur les déploiements qui les proposent. Si vous savez à peu près ce que vous recherchez, saisissez-le dans **Search settings** : la recherche correspond aux libellés et aux mots associés (« dark », « rtl », « paste ») et vous amène directement à l'onglet et à la section appropriés.

La plupart des préférences sont enregistrées dans le navigateur actuel, et non dans votre compte. Un paramètre modifié sur votre ordinateur portable ne vous suit pas sur votre téléphone. Les exceptions sont indiquées ci-dessous.

## Général [#general]

| Paramètre | Ce qu'il fait | Par défaut |
|---|---|---|
| Thème | **Système**, **Clair**, **Sombre**, ou un thème clair ou sombre à contraste élevé. | Système |
| Langue | La langue de l'interface. | Langue du navigateur |
| Taille de police des messages | Taille du texte des messages, de **Très petite** à **Très grande**. | Moyenne |
| Échelle de l'interface | Met à l'échelle l'ensemble de l'interface entre 50 % et 150 %, indépendamment du zoom du navigateur. | 100 % |
| Sens du chat | **Automatique**, de gauche à droite, ou de droite à gauche. | Automatique |
| Format de l'heure | Système, heures au format 12 heures ou 24 heures dans les messages, les planifications et les dates. | Système |
| La semaine commence le | Système, dimanche ou lundi. Modifie l'ordre des jours de la semaine dans les [Conversations planifiées](/docs/features/scheduled_chats), et non le moment où une planification s'exécute. | Système |
| Maximiser l'espace de chat | Élargit la colonne de la conversation. | Désactivé |
| Centrer la zone de saisie sur l'écran d'accueil | Place la zone de message au centre d'une nouvelle conversation. | Activé |
| Afficher Lia sur l'écran d'accueil | Une petite mascotte pixel décorative autour de la zone de message. Affichée uniquement si le déploiement l'autorise. | Désactivé |
| Bouton « Aller à la fin » | Un bouton qui permet d'accéder au dernier message. | Activé |
| Afficher le chat à côté de la barre latérale sur mobile | Conserve une bande de la conversation visible à côté du [tiroir mobile](/docs/features/navigation#mobile-drawer) ; touchez la bande pour fermer le tiroir. | Désactivé |
| Afficher le titre du chat dans l'onglet | Utilise le titre de la conversation comme titre de l'onglet du navigateur. | Activé |
| Garder l'écran allumé pendant la génération de réponse | Demande au navigateur de ne pas assombrir ni verrouiller l'écran pendant qu'une réponse est diffusée. | Activé |

Les administrateurs voient également un lien **Admin Panel** ici lorsque le déploiement en dispose.

### Notifications [#notifications]

Ces paramètres déterminent comment vous êtes informé des réponses qui se terminent pendant que vous êtes dans un autre chat ou un autre onglet :

- **Afficher le nombre de messages non lus dans le titre de l'onglet** affiche le nombre de conversations contenant des réponses non lues dans le titre et l'icône de l'onglet. Activé par défaut.
- **Me notifier lorsqu'une réponse arrive** affiche une notification sur le bureau. Désactivée par défaut. Votre navigateur demande l'autorisation la première fois que vous l'activez, et rien n'est affiché lorsque vous consultez LibreChat.
- **Jouer un son pour les nouvelles réponses** joue un court carillon. Désactivé par défaut. Les navigateurs bloquent l'audio tant que vous n'avez pas cliqué quelque part sur la page, de sorte que le premier carillon après l'ouverture d'un onglet peut rester silencieux.

Les bascules sont propres à chaque appareil ; l'état de lecture lui-même est enregistré dans votre compte (voir [Réponses non lues](/docs/features/navigation#unread-replies)). Si l'une de ces bascules est absente, votre administrateur l'a désactivée via [`interface.replyNotifications`](/docs/configuration/librechat_yaml/object_structure/interface#replynotifications).

## Chat [#chat]

| Paramètre | Fonction | Par défaut |
|---|---|---|
| Appuyer sur Entrée pour envoyer les messages | Lorsque désactivé, Entrée ajoute un saut de ligne et <kbd>Ctrl</kbd>+<kbd>Entrée</kbd> (<kbd>Cmd</kbd>+<kbd>Entrée</kbd> sur macOS) envoie le message. | Activé |
| Pendant la génération, Entrée | Ce que fait l'envoi pendant qu'une réponse est encore en cours de diffusion : **Orienter**, **Interrompre** ou **Mettre en file d'attente**. Voir [Composer](/docs/features/composer). | Orienter |
| Enregistrer les brouillons localement | Conserve le texte non envoyé et les pièces jointes sur cet appareil jusqu'à l'envoi du message. | Activé |
| Redimensionner les images avant le téléversement | Réduit dans le navigateur la taille des grandes images JPEG, PNG et WebP avant leur téléversement. | Activé |
| Coller un long texte sous forme de fichier | Joint les textes très longs collés comme fichier texte au lieu de remplir la zone de message. Voir [Téléverser en tant que texte](/docs/features/upload_as_text). | Activé |
| Enregistrer l'état des badges | Les nouvelles conversations conservent les badges d'outils de votre dernière conversation au lieu de les réinitialiser. | Désactivé |
| Activer/désactiver les commandes « @ » / « + » / « / » | Active ou désactive les commandes `@` (changer de modèle ou de point de terminaison), `+` (ajouter une réponse parallèle) et `/` (insérer un prompt). Les commandes `+` et `/` n'apparaissent que lorsque ces fonctionnalités sont disponibles. | Activé |
| Afficher les messages utilisateur en Markdown | Met en forme vos propres messages en Markdown. | Activé |
| Réduire les longs messages utilisateur | Les longs messages que vous avez envoyés s'affichent sous forme d'aperçu avec **Afficher plus**. Le texte complet reste présent sur la page pour la copie et la recherche. | Activé |
| Afficher le nom d'utilisateur dans les messages | Affiche votre nom au-dessus de vos messages au lieu de « Vous ». | Activé |
| Analyser le LaTeX dans les messages | Affiche les formules mathématiques. Désactiver cette option empêche le rendu des formules en ligne `$...$` ; `$$...$$`, `\(...\)` et `\[...\]` restent affichés. | Activé |
| Ouvrir les menus de réflexion par défaut | Développe le raisonnement d'un modèle au lieu de le réduire. | Désactivé |
| Texte en streaming fluide | Fait apparaître progressivement les nouveaux mots pendant la diffusion d'une réponse. Voir [Streaming fluide](/docs/features/smooth_streaming). | Activé |
| Copier les messages en texte enrichi | La copie d'un message place également une version mise en forme dans le presse-papiers, pour un collage dans Word, Outlook ou Teams. | Désactivé |
| Développer automatiquement les détails des outils | Ouvre par défaut les détails des appels d'outils. | Désactivé |
| Basculer vers l'historique des conversations lors d'une nouvelle conversation | Démarrer une nouvelle conversation alors que Prompts, Mémoires ou un autre panneau est ouvert ramène la barre latérale à vos conversations. | Activé |
| Défilement automatique vers le dernier message à l'ouverture d'une conversation | Ouvre une conversation à son message le plus récent. Désactivez cette option pour conserver votre position lorsque vous revenez. | Activé |
| Autoriser le changement de point de terminaison en cours de conversation | Permet de changer de modèle ou de point de terminaison au sein d'une même conversation. | Activé |
| Conversation temporaire par défaut | Les nouvelles conversations démarrent comme [conversations temporaires](/docs/features/temporary_chat). | Désactivé |
| Utiliser l'option de bifurcation par défaut | Ignore le menu de bifurcation et utilise toujours l'option choisie ici. Voir [Bifurcation](/docs/features/fork). | Désactivé |
| Éditeur de prompts avancé | Active les versions et les libellés de production pour les prompts. | Désactivé |
| Toujours faire de chaque nouvelle version de prompt la version de production | Marque chaque nouvelle version de prompt comme celle en cours d'utilisation. | Activé |
| Envoyer les prompts à la sélection | Envoie un prompt dès que vous le sélectionnez. | Activé |

**Redimensionner les images avant le téléversement** peut être verrouillé : si un administrateur définit [`fileConfig.clientImageResize.enabled`](/docs/configuration/librechat_yaml/object_structure/config#clientimageresize), le bouton bascule est désactivé et suit cette valeur.

## Parole [#speech]

Activez ou désactivez **Speech to Text** et **Text to Speech**, choisissez le moteur, la langue et la voix, définissez la vitesse de lecture, et décidez si les réponses sont lues automatiquement. Les moteurs disponibles dépendent de la configuration de votre déploiement ; voir [Speech to Text and Text to Speech](/docs/configuration/stt_tts).

## Données et confidentialité [#data--privacy]

- **Mémoire** : **Référencer les souvenirs enregistrés** permet à l'assistant d'utiliser vos [souvenirs](/docs/features/memory). Enregistré sur votre compte, il s'applique sur tous vos appareils.
- **Exécution de code** : **espace de travail avec état par défaut** et **environnements de code**, lorsque le déploiement propose des sessions de code avec état.
- **Vos données** : **Importer des conversations**, **Discussions partagées** (gérez vos [liens partagés](/docs/features/shareable_links)), **Gérer les fichiers**, **Archiver toutes les discussions**, et **Autoriser les statistiques** si le déploiement collecte des statistiques. **Archiver toutes les discussions** déplace chaque discussion active vers [Discussions archivées](/docs/features/navigation#archived-conversations) sans rien supprimer.
- **Clés API** : **clés API du fournisseur** pour les endpoints qui demandent votre propre clé, **clés API d'agent** pour l'API Agents, et **Révoquer toutes les clés API du fournisseur**.
- **Zone de danger** : **Supprimer le cache** efface les audios de synthèse vocale mis en cache dans ce navigateur. **Supprimer toutes les conversations** supprime définitivement vos conversations.

## Compte [#account]

**Avatar** et, pour les connexions par e-mail lorsque cela est autorisé, **Adresse e-mail**. Sous **Sécurité** : **Authentification à deux facteurs**, **Codes de secours** une fois l'authentification à deux facteurs activée, et **Clés d'accès** si le déploiement les prend en charge. **Compte de pull request** permet de connecter GitHub ou un autre hébergeur Git pour les [pull requests](/docs/features/pull_requests). **Solde de jetons** et **Recharge automatique** apparaissent lorsque le déploiement suit les soldes, et **Supprimer le compte** lorsqu'il permet aux utilisateurs de supprimer leur propre compte.

## Raccourcis clavier [#keyboard-shortcuts]

Ouvrez le menu du compte et choisissez **Aide**, puis **Raccourcis clavier** (ou appuyez sur <kbd>Ctrl</kbd>+<kbd>Maj</kbd>+<kbd>/</kbd>). Cliquez sur une ligne pour enregistrer une nouvelle combinaison ; elle doit inclure <kbd>Cmd</kbd>, <kbd>Ctrl</kbd> ou <kbd>Alt</kbd>, et LibreChat vous avertit si une autre action l'utilise déjà. **Réinitialiser tout par défaut** annule vos modifications. Les lignes sous **Ouvrir les panneaux** (agents, prompts, mémoires, paramètres, fichiers, signets, paramètres MCP) n'ont pas de touches tant que vous ne leur en attribuez pas une.

Le commutateur **Raccourcis clavier** en haut désactive tous les raccourcis et masque les indications dans l'interface. Vos touches personnalisées sont conservées pour lorsque vous le réactiverez. Le commutateur et vos raccourcis sont enregistrés dans ce navigateur.
