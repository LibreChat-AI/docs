### Variáveis [#variables]

Use `{{notes}}` para solicitar texto, ou `{{length:3 bullets|5 bullets}}` para oferecer opções:

```text
Summarize these notes in {{length:3 bullets|5 bullets}}.

Notes: {{notes}}
```

O LibreChat solicita estes valores quando você usa o prompt no chat. Variáveis especiais como `{{current_date}}`, `{{current_datetime}}`, `{{iso_datetime}}` e `{{current_user}}` são preenchidas automaticamente. Outras variáveis permanecem como texto literal caso nada as preencha.

### Versões e Produção [#versions-and-production]

Salvar uma edição cria uma nova versão. Uma versão é marcada como **Production**. A biblioteca e o menu `/` usam essa versão.

| Configuração do editor | O que acontece ao salvar |
| --- | --- |
| **Editor avançado de prompts** desativado | A lista de versões fica oculta. Cada salvamento torna-se Produção. |
| Editor avançado ativado; **Sempre criar novas versões de prompt como Produção** ativado | Cada salvamento torna-se Produção. Você também pode navegar pelas versões anteriores. |
| Editor avançado ativado; produção automática desativada | Salve uma versão e, em seguida, use **Implantar** para torná-la Produção. |

Essas configurações se aplicam ao seu navegador. Desativar o editor avançado também ativa automaticamente a Produção. Você pode alterar essa opção novamente com o editor avançado ativado.

### Produção ou uma versão fixada? [#production-or-a-pinned-version]

Escolha **Production** para seguir as atualizações do proprietário do prompt. Escolha uma versão específica para manter as mesmas instruções até que você altere o link.

![Antes de a versão 4 ser promovida, ambos os agentes usam a versão 3. Após a promoção, o agente que segue a versão de Produção usa a versão 4, enquanto o agente fixado na versão 3 permanece na versão 3. As configurações de cache nativas podem atrasar a atualização de Produção.](/images/features/prompts/production-vs-pinned.svg)

Para prompts do LibreChat, **Production** significa a revisão marcada como Production. Para prompts do Langfuse, significa a versão com o rótulo `production`.

### Quando as instruções são resolvidas [#when-instructions-are-resolved]

Salvar o agente verifica o prompt, mas não copia o texto dele. O LibreChat resolve o link a cada turno. Atualizações de prompts nativos podem ser atrasadas pelo [cache](/docs/configuration/librechat_yaml/object_structure/agents#linkedinstructions); os links do Langfuse são buscados a cada vez.

As variáveis especiais funcionam da mesma forma que nas [instruções inline do agente](/docs/features/agents#instructions-from-a-saved-prompt). Variáveis personalizadas, como `{{notes}}`, **não são preenchidas** para instruções vinculadas. O modelo recebe-as como texto literal.

<Callout type="warning" title="Se o prompt estiver indisponível">
  O agente executa esse turno com **instruções vazias**. Ele não usa o texto inline salvo.
  O agente de memória é uma exceção: ele usa suas instruções padrão.
</Callout>

## Prompts do Langfuse [#prompts-from-langfuse]

Os prompts sincronizados do Langfuse têm um ícone de nuvem com o rótulo **Managed in Langfuse**. Você pode visualizar e usá-los no LibreChat. Edite o conteúdo, promova versões e exclua-os no Langfuse.

Somente **prompts de texto** do Langfuse são suportados. Ao abrir um deles, o conteúdo é buscado no Langfuse sem ser armazenado em cache. Se você excluí-lo no Langfuse, a entrada na biblioteca do LibreChat permanece, mas ela não consegue mais ser resolvida.

### Links do Langfuse [#langfuse-links]

Um administrador deve habilitar a [sincronização do catálogo de prompts](/docs/configuration/langfuse#prompt-catalog) e as [instruções de agente do Langfuse](/docs/configuration/langfuse#prompts-as-agent-instructions). A vinculação vem desativada por padrão. A sincronização do catálogo deve permanecer habilitada para que os vínculos salvos funcionem.

Se a vinculação estiver desativada, os prompts do Langfuse desaparecem do seletor do Builder, exceto a seleção salva do agente. O Builder exibe uma nota sobre essa seleção. O vínculo continua salvo, mas o agente é executado sem essas instruções. Ao reativar a vinculação, ela é restaurada sem necessidade de editar o agente.

## Compartilhamento e permissões [#sharing-and-permissions]

Um proprietário de prompt pode compartilhá-lo com usuários, grupos ou funções como **Viewer**, **Editor** ou **Owner**. Consulte [Access Control](/docs/features/access_control).

### Quem pode vincular e quem pode executar [#who-can-link-and-who-can-run]

| Tarefa | Acesso necessário |
| --- | --- |
| Usar a biblioteca de prompts | A permissão `PROMPTS` `USE` do seu papel e acesso ao prompt. |
| Adicionar ou alterar o vínculo de prompt de um agente | `PROMPTS` `USE` e VIEW no prompt, além de `AGENTS` `CREATE` para um novo agente ou EDIT para um agente existente. |
| Manter ou remover o vínculo; mudar para instruções inline | O mesmo acesso no nível do agente. O acesso ao prompt não é verificado novamente. |
| Conversar com um agente que usa um prompt | Acesso para conversar com o agente. Não é necessário acesso ao prompt vinculado. |
| Compartilhar um prompt | `SHARE` para usuários, grupos ou papéis selecionados; `SHARE_PUBLIC` para todos. |

Um co-editor sem acesso ao prompt vê **Prompt restrito**. Ele pode substituir o link ou mudar para instruções inline. Não consegue ver o destino dele. Um visualizador de agente nunca vê o link.

Administradores definem as permissões de função no [Painel de Administração](/docs/features/admin_panel) ou na [configuração de controle de acesso](/docs/configuration/access_control#feature-permissions). Administradores delegados com `manage:prompts` podem visualizar e vincular qualquer grupo sem uma concessão de VIEW separada. A vinculação ainda exige `PROMPTS` `USE`.

## Detalhes e solução de problemas [#details-and-troubleshooting]

<Accordions type="single" collapsible>
  <Accordion title="Histórico de versões, duplicação e reversão">
    Alterar o prompt, sua versão ou a fonte das instruções adiciona uma entrada ao histórico de versões do agente.

    **Duplicar** e **Reverter** copiam o link salvo sem uma nova verificação de USO ou VISUALIZAÇÃO. Se o novo editor não puder visualizar o prompt, o Construtor exibe **Prompt restrito**.
  </Accordion>
  <Accordion title="O que significa a contagem de uso">
    Cada agente vinculado adiciona um uso após terminar de inicializar com sucesso. Este é o mesmo contador usado pelos cartões de prompt e pelo menu de barra. Transferências (handoffs) e subagentes podem adicionar vários usos em uma única interação.

    Retomar uma execução pausada não adiciona nenhum uso extra. O agente de memória nunca adiciona um uso.
  </Accordion>
  <Accordion title="Limitações da API de gerenciamento">
    Defina links de prompt no Agent Builder. A Management API e a sua especificação OpenAPI não aceitam nem retornam `instructionsPrompt`.

    Alterar `instructions` por meio dessa API não muda o que um agente vinculado utiliza. O vínculo tem precedência. Os vínculos com o Langfuse oferecem suporte apenas a prompts de texto; os grupos de prompts nativos não têm essa restrição.
  </Accordion>
  <Accordion title="Solucionando problemas com mensagens do Builder">

    | Mensagem | O que fazer |
| --- | --- |
| "Esta seleção de prompt não está disponível no momento." | Escolha outro prompt ou versão, ou tente novamente quando o problema for resolvido. A versão pode ter sido excluída, bloqueada por política ou estar indisponível no Langfuse. A vinculação pode estar desativada, ou a origem do grupo pode ter sido alterada. |
| "Você não tem permissão para vincular este prompt." | Solicite a `PROMPTS` `USE` a um administrador, ou a VIEW no grupo ao proprietário. |
| "Você não tem acesso à biblioteca de prompts." | O seletor ou a lista de versões exige `PROMPTS` `USE` e VIEW no grupo. Solicite acesso a um administrador ou ao proprietário. |
| "A origem deste prompt não está disponível no momento." | Verifique a configuração de sincronização com o Langfuse ou substitua o vínculo. A sincronização pode estar desativada ou não configurada, a origem pode ter sido alterada, ou o prompt pode ter se tornado um prompt de chat. |
| "Não foi possível carregar os prompts." | Tente novamente. Peça a um administrador que verifique os logs do servidor se o problema continuar. Trata-se de um erro inesperado de carregamento, e não de um erro de permissão ou de origem. |
| "Versão selecionada (não está mais disponível)" | A revisão nativa foi excluída. Selecione **Production** ou outra versão. |
| "Versão N (não está mais disponível)" | A versão do Langfuse não está mais listada. Selecione **Production** ou outra versão. |
| "Prompt restrito" | Solicite acesso de VIEW, substitua o vínculo ou mude para instruções inline. O grupo também pode ter sido excluído. Essa mensagem pode aparecer até para o proprietário do agente. |
| "Prompt não encontrado" | O grupo foi excluído. Selecione outro prompt ou mude para instruções inline. Usuários com `manage:prompts` ou `ADMIN` veem esta mensagem em vez de **Prompt restrito**. |
| "Não foi possível validar o prompt vinculado. Tente novamente." | Um erro inesperado impediu a validação. Tente salvar novamente. |

  </Accordion>
</Accordions>
