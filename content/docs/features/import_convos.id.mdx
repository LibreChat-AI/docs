Import Percakapan memungkinkan Anda membawa percakapan yang diekspor dari aplikasi chat AI lain ke dalam LibreChat. Sumber yang didukung adalah [ChatGPT](https://chatgpt.com/), [Claude](https://claude.ai/), [ChatbotUI v1](https://github.com/mckaywrigley/chatbot-ui/tree/b865b0555f53957e96727bc0bbb369c9eaecd83b?tab=readme-ov-file#legacy-code), dan ekspor JSON milik LibreChat sendiri (lihat [Ekspor dari LibreChat](#export-from-librechat)).

<Callout type="info" title="Tempat menemukannya">
Impor berada di bawah **Pengaturan** > **Data & Privasi** > **Data Anda** > **Impor percakapan** di LibreChat.
</Callout>

## Ekspor dari aplikasi sumber [#export-from-the-source-application]

Pertama, ekspor data Anda dari aplikasi yang ingin Anda tinggalkan. Langkah-langkahnya berbeda tergantung pada sumbernya.

<Callout type="info" title="Ingin melakukan ekspor dari LibreChat?">
Lihat [Export from LibreChat](#export-from-librechat) di bagian bawah halaman ini.
</Callout>

## Impor ke LibreChat [#import-into-librechat]

<Steps>
<Step>

**Data Terbuka & Privasi.** Di LibreChat, buka **Settings** > **Data & Privacy** lalu cari **Import conversations** di bagian **Your data**.

</Step>
<Step>

**Pilih file Anda.** Klik **Import** dan pilih file `conversations.json` dari arsip yang sudah diekstrak (atau file JSON yang diekspor dari ChatbotUI v1 atau LibreChat). Pemilih file hanya menerima file `.json`, sehingga arsip zip ChatGPT dan Claude harus diekstrak terlebih dahulu.

</Step>
<Step>

**Tunggu konfirmasi.** Sebuah notifikasi akan muncul setelah proses impor selesai.

</Step>
</Steps>

Administrator dapat membatasi ukuran unggahan dengan [`CONVERSATION_IMPORT_MAX_FILE_SIZE_BYTES`](/docs/configuration/dotenv#conversation-import).

## Pengaturan persetujuan kode yang diimpor [#imported-code-approval-settings]

Saat mengimpor percakapan LibreChat, mode persetujuan Kode yang tersimpan (termasuk **Full access**) tidak akan terbawa. Impor baru akan menggunakan preferensi/default penerima yang sudah ada serta kebijakan deployment/worker saat ini. Pembaruan massal tidak dapat menimpa pilihan persetujuan yang tersimpan secara lokal. Perlindungan ini tidak mengatur ulang percakapan yang sudah ada secara retroaktif; pengguna masih dapat memilih dan menyimpan mode yang didukung melalui LibreChat. Lihat [Attached-environment tool permissions](/docs/features/code_interpreter#attached-environment-tool-permissions).

## Ekspor dari LibreChat [#export-from-librechat]

Ekspor dilakukan per percakapan, dan tersedia di menu **Chat options** pada header chat (di bawah menu luapan di perangkat seluler), bersama dengan **Share**, **Rename**, **Pin**, **Duplicate**, **Archive** dan **Delete**. Buka percakapan yang diinginkan, pilih **Export**, pilih format, lalu konfirmasi.

Ekspor `json` dapat diimpor kembali ke LibreChat dari **Pengaturan** > **Data & Privacy** > **Your data** > **Import conversations**.

Dua opsi dalam dialog tersebut bergantung pada format yang Anda pilih:

- **Export all message branches** hanya berlaku untuk `json` dan `csv`. Format lain hanya mengekspor cabang yang terlihat.
- Opsi ekspor lainnya tidak tersedia untuk `csv` dan `screenshot`.

<Callout type="info" title="Cakupan">

Tidak ada fitur bawaan untuk ekspor massal semua percakapan sekaligus, dan percakapan baru atau hasil pencarian tidak memiliki data untuk diekspor, sehingga menu tersebut tidak muncul untuk kondisi tersebut.

</Callout>
