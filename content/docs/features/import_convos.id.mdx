Anda dapat mengimpor percakapan yang diekspor dari ChatGPT, Claude, dan [ChatbotUI v1](https://github.com/mckaywrigley/chatbot-ui/tree/b865b0555f53957e96727bc0bbb369c9eaecd83b?tab=readme-ov-file#legacy-code), serta percakapan yang diekspor dari LibreChat dalam format JSON. Percakapan yang diimpor akan muncul di riwayat Anda seperti percakapan lainnya. Ekspor dilakukan satu percakapan dalam satu waktu.

## Impor berkas [#import-the-file]

Buka **Settings** > **Data & Privacy**, pilih **Import** di samping "Import conversations from a JSON file", lalu pilih file tersebut. Pemilih file hanya menerima `.json`, jadi ekstrak arsip ChatGPT dan Claude terlebih dahulu. Tombol akan menampilkan "Importing" selama proses berjalan, dan "Conversations imported successfully" muncul ketika proses selesai.

LibreChat menentukan format dari isi file, bukan dari namanya. Jika file tidak dikenali, Anda akan mendapatkan pesan "Unsupported import type".

Impor LibreChat tidak membawa mode persetujuan kode yang tersimpan pada percakapan (termasuk **Full access**) maupun status belum dibaca. Percakapan yang diimpor menggunakan preferensi persetujuan Anda saat ini dan kebijakan dari deployment.

### Batasan [#limits]

- File dapat berukuran hingga 250 MiB, kecuali administrator Anda menetapkan batas yang berbeda. File yang lebih besar akan ditolak sebelum diunggah.
- Satu percakapan atau pesan tunggal tidak boleh melebihi sekitar 16 MB, yang merupakan batas database.
- Impor dibatasi laju (rate-limited) per pengguna dan per IP, sehingga mengimpor banyak file secara berurutan dapat ditolak untuk sementara waktu.

## Ekspor percakapan [#export-a-conversation]

Buka percakapan, buka menu **Chat options** (tombol `...` di header, atau menu header pada layar kecil), lalu pilih **Export**. Pilih nama file dan jenisnya, kemudian pilih **Export**.

| Tipe | Yang Anda dapatkan |
| --- | --- |
| `markdown` (.md) | Transkrip yang mudah dibaca. Ini adalah default. |
| `text` (.txt) | Transkrip dalam format teks biasa. |
| `json` (.json) | Data pesan lengkap. Ini adalah format yang dapat diimpor kembali ke LibreChat. |
| `csv` (.csv) | Satu baris per pesan. |
| `screenshot` (.png) | Gambar percakapan sebagaimana tampil di layar. |

**Ekspor semua cabang pesan** berfungsi untuk `json` dan `csv`; tipe lainnya hanya mengekspor cabang yang sedang Anda lihat. **Sertakan opsi endpoint** menambahkan model beserta pengaturannya, dan tidak tersedia untuk `csv` atau `screenshot`. Untuk `json`, Anda juga dapat memilih **Recursive** (pesan bersarang di bawah induknya) atau sequential.

Tidak ada fitur ekspor semua percakapan Anda sekaligus, dan chat baru atau hasil pencarian tidak memiliki apa pun untuk diekspor, sehingga menu tersebut tidak muncul di sana.

## Pengaturan [#setup]

Impor dan ekspor berfungsi untuk setiap pengguna tanpa perlu konfigurasi. Admin dapat mengubah batas ukuran impor dengan `CONVERSATION_IMPORT_MAX_FILE_SIZE_BYTES` dan batas laju dengan variabel `IMPORT_*`; lihat [referensi .env](/docs/configuration/dotenv#conversation-import).
