Memory is a small store of facts about you, saved as key/value pairs, that LibreChat adds to the context of every new message. Tell the model "remember that I write Python and prefer short answers" once, and it will know that in your next conversation too.

It is not a search over your chat history. Nothing from old conversations is recalled unless it was saved as a memory entry, and the whole store goes into each request, so it is meant for a handful of durable facts, not notes or documents.

## Saving a memory

Click **+** in the [message composer](/docs/features/composer) to open the palette, then pick **Memory** in the **Tools** section. With it on, the model gets two tools, `set_memory` and `delete_memory`, and is instructed to use them only when you ask it to remember, update, or forget something. A message like "remember that my team uses pnpm" produces a "Saved memory" step in the reply, labeled with the memory's key; expand it to see the saved value. "Forget where I work" produces "Deleted memory". When the model makes several memory calls in one reply, they are grouped under a single step such as "Ran 2 actions".

The Memory option only appears if your role is allowed to create and update memories. When you are chatting with an agent, the palette has no Memory option; the agent uses memory if Memory is enabled in the Agent Builder.

An agent can also be set to **Keep memories separate for this agent**: it then reads and writes its own store, isolated from your shared memories and from other agents. Those entries follow access to the agent: if you lose access to it, its separate memories can no longer be read or updated, though you can still delete the memories of an agent that has been removed.

Some deployments also run a background memory agent that reviews each exchange and saves facts on its own, without you asking. Whether that happens is your admin's choice.

## Viewing and editing memories

Open **Memories** in the side panel to see everything saved about you. From there you can:

- Filter the list by key or value, or by agent when you have agent-scoped memories (marked "Agent-scoped memory").
- Click **+** (**Create Memory**) to add an entry yourself. Keys use lowercase letters and underscores only, and each key can exist once.
- Edit or delete any entry.

When your admin sets a size limit, the panel shows how much of it you are using. Once the store is full, new saves fail with "Memory Storage Full" until you delete something. Individual entries also have a length cap.

## Turning memory off for yourself

The **Use memory** button in the Memories panel, also available as **Reference saved memories** under **Settings** > **Data & Privacy**, controls whether your saved memories are added to your conversations. Turn it off and LibreChat stops adding them and stops offering the Memory tool; your entries are kept and come back when you turn it on again.

This toggle is only shown when your admin allows users to opt out. Memory can also be limited by role, so some users may see the panel but not be able to create or edit entries.

## Setup

Memory is off until an admin adds a `memory` section to `librechat.yaml`. The background memory agent is a separate opt-in that needs its own model. See [Memory configuration](/docs/configuration/librechat_yaml/object_structure/memory) for limits, allowed keys, the memory agent, and troubleshooting.
