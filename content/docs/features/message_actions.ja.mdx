チャット内のすべてのメッセージの下には、小さなボタンが並んでいます。デスクトップでは、メッセージにマウスカーソルを合わせるか、キーボードのフォーカスをメッセージに移動すると表示されます。返信がストリーミング中は意味を持たないボタンは、返信が完了するまで非表示のままになります。

## 各ボタンの機能 [#what-each-button-does]

| ボタン | 機能 |
|---|---|
| **読み上げ** | 有効になっている場合、テキスト読み上げ機能でメッセージを読み上げます。 |
| **クリップボードにコピー** | メッセージのテキストをコピーします。 |
| **編集** | メッセージをエディターで開きます。[編集と再実行](#edit-and-rerun)を参照してください。 |
| **フォーク** | このメッセージから新しい会話を開始します。[会話のフォーク](/docs/features/fork)を参照してください。 |
| **良い** / **改善が必要** | 返信を評価します。理由とコメントを追加できます。 |
| **再生成** | 同じメッセージに対する新しい返信をモデルに依頼します。以前の返信は以前のバージョンとして引き続き利用できます。 |
| **続ける** | 最新の返信が出力トークンの上限などにより途中で停止した場合に表示されます。中断した箇所から続きを生成します。 |

どのボタンが表示されるかは、エンドポイントとメッセージによって異なります。たとえば、ユーザーメッセージには評価ボタンや**Regenerate**ボタンはありません。

## 編集して再実行 [#edit-and-rerun]

メッセージまたは返信の**編集**を選択します。エディターには3つのボタンがあります。

- **Save** は、新しい内容を生成せずに変更を保存します。
- **Update & rerun** を押すと、編集したメッセージが再送信され、新しい返信を取得します。ボタンは、何も変更していない場合や、返信を編集している場合には **Rerun** と表示されます。返信を編集している場合は、その直前のユーザーメッセージを再実行します。
- **キャンセル** はエディターを閉じます。

編集中、<kbd>Ctrl</kbd>+<kbd>S</kbd>(<kbd>Cmd</kbd>+<kbd>S</kbd>)で保存、<kbd>Ctrl</kbd>+<kbd>Enter</kbd>(<kbd>Cmd</kbd>+<kbd>Enter</kbd>)で再実行、<kbd>Escape</kbd>でキャンセルします。

再実行すると、元のメッセージに添付されていたファイル、引用された抜粋、スキルはそのまま保持されるため、もう一度追加する必要はありません。テキストがなくファイルのみのメッセージも、編集して再実行できます。

エージェントからの返信には、テキストだけでなく他の要素も含まれることがあります。編集エディタで変更できるのはテキストと推論部分のみです。ツール呼び出し、エラー、アーティファクトは表示されますが、読み取り専用です。再実行では一度に1つの編集済み部分のみが適用されるため、複数の部分を変更する場合は **保存** を使用してください。

## コピー [#copy]

**クリップボードにコピー**は、メッセージの表示されているテキストをコピーします。エージェントの返信については、推論、ツール呼び出し、エラーは除外されます。引用は読みやすい参照形式に変換されます。

チームズ、アウトルック、ワードなどのアプリに貼り付ける場合は、**Settings > Chat** で **Copy messages as rich text** を有効にしてください。この設定を有効にすると、コピー時に書式付きのバージョンもクリップボードに保存されるため、見出し、リスト、表、コードのスタイルが保持されます。

## 引用の抜粋 [#quote-excerpts]

任意のメッセージ内のテキストを選択し、**チャットに追加** を選びます。抜粋はコンポーザーの上に一時的に表示され、次のメッセージを送信するときに引用として一緒に送られるため、モデルはどの部分を指しているかを正確に把握できます。1つのメッセージに最大10件の抜粋を添付でき、それぞれ1,500文字で切り詰められます。

引用は[ステアリングとキューに入ったメッセージ](/docs/features/agents#steering-and-queued-messages)でも機能します。抜粋は、キューに入れたメッセージやステアリングに使用したメッセージに引き続き添付されます。

## コードブロック [#code-blocks]

返信内のコードブロックには、ヘッダーに専用のボタンがあります:

- **コードをコピー**でブロックをコピーします。
- **コードをダウンロード** を押すと、ブロックの言語に基づいた名前のファイル(例: `code.py` や `code.toml`)として保存されます。言語が指定されていないブロック、またはファイル拡張子として適切でない言語名のブロックは、`code.txt` としてダウンロードされます。エラーブロックにはダウンロードボタンはありません。
- **Run Code** は、その言語で利用可能な場合に [Code Interpreter](/docs/features/code_interpreter) を使ってブロックを実行します。
