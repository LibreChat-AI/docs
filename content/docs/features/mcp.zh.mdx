MCP (Model Context Protocol) 是一种用于向模型开放工具的开放标准。MCP 服务器可以为模型提供文件系统、浏览器、数据库或贵公司的内部 API,而 LibreChat 可以使用任何遵循该协议的服务器。你可以将服务器附加到普通聊天中以便快速使用,也可以将其工具添加到智能体中。

## 在聊天中使用服务器 [#use-a-server-in-chat]

在 Agents 或 Assistants 以外的端点上,打开输入框的 **+** 面板(**附件和工具**),在 **MCP Servers** 下查看。点击某个服务器即可在当前对话中启用它。它会以标签形式显示在输入框上,该服务器提供的所有工具都会提供给模型使用。面板会保持打开状态,因此你可以一次启用多个服务器;再次点击某个服务器,或移除其标签,即可将其关闭。有关面板的其他内容,请参阅 [输入框](/docs/features/composer#turn-on-tools-skills-and-mcp-servers)。

调色板每次显示几个服务器,每个服务器的状态都由一个彩色圆点表示。点击 **MCP Servers** 标题上的 **Show All** 可打开完整列表,其中包含搜索框以及三个视图:**All**、**Made by you** 和 **Favorites**。

![MCP 服务器对话框已打开并显示"Show All"，列出了一个标记为"Disconnected"的 Github 服务器和一个标记为"Needs Auth"的 Spotify 服务器，并提供"All"、"Made by you"和"Favorites"筛选器](/images/mcp/mcp_servers_catalog.png)

如果服务器尚未连接,点击它会先启动连接,而不是直接选中。需要您自行提供凭据的服务器会先打开一个对话框,供您输入凭据;使用 OAuth 的服务器则会引导您完成登录。连接成功后,LibreChat 会自动为您选中该服务器。

选择支持工具调用的模型,否则该模型永远不会调用服务器的工具。Agents 和 Assistants 拥有各自的工具配置,因此在这些端点上会隐藏模型选择器;管理员也可以将单个服务器从聊天中隐藏,使其仅可供 agents 使用。

## 为智能体添加服务器 [#add-a-server-to-an-agent]

在 Agent Builder 中,点击 **Tools** 旁边的 **Add** 打开 **Tool Library**,然后筛选出 **MCP servers**。添加某个服务器后,会列出该服务器提供的工具;保留智能体应该拥有的工具,移除其余工具,或使用 **Select all** 和 **Deselect all**。即使某个服务器提供数十个工具,在智能体的工具列表中也只占一个条目。

每个附加在智能体上的 MCP 工具还有各自的选项(**Defer loading**、**Programmatic**、**Background**、**Intent label**)。这些选项的具体作用请参阅 [智能体](/docs/features/agents)。

有些服务器依赖仅在聊天请求期间才存在的值,因此无法提前列出其工具。对于这类服务器,工具库会挂载整个服务器,并注明其工具将在聊天过程中于运行时解析。

如果智能体被设置为使用 MCP 工具,但在运行开始时这些工具全部不可用(例如服务器已关闭,或您失去了访问权限),运行将会停止并报错,提示您检查连接和访问权限,而不会在没有工具的情况下继续回答。在工具调用期间按下 **Stop(停止)**,只要 MCP 服务器支持取消操作,也会同时在该服务器上取消此次调用。

## 连接状态 [#connection-status]

在调色板和 **MCP Settings** 中,状态以彩色圆点显示:服务器断开连接时为灰色,需要你登录时为琥珀色。完整状态会朗读给屏幕阅读器,并且 Tool Library 和 **Show All** 列表会在每个服务器旁边明确写出状态。

- **已连接**:可以开始使用。
- **需要认证**:服务器使用 OAuth,而您尚未登录,或您的登录已过期。
- **连接中** / **初始化中**:正在尝试建立连接。
- **Disconnected** 或 **Error**:表示当前没有活动连接,或上一次连接尝试失败。请使用 **Connect** 重新尝试连接。
- **按需**:服务器会为每个请求单独建立连接,因此不存在需要报告的持久连接。
- **未知**:尚未返回任何状态。

当连接失败时,错误信息会说明原因:无法访问服务器、需要您尚未设置的变量(消息中会列出变量名),或需要您重新登录。解决该问题后重新连接即可,无需删除并重新添加服务器。服务器在运行期间也可以新增或移除工具,LibreChat 会自动获取新的工具列表,无需重启。

连接是按用户隔离的。您的 OAuth 令牌和已保存的凭据绝不会用于其他任何人。空闲连接默认在 15 分钟后关闭,您下次使用该服务器时会重新建立连接。

## 使用 OAuth 登录 [#sign-in-with-oauth]

当服务器需要 OAuth 时,连接它会打开 **Connect** 对话框。点击 **Continue with OAuth** 可在新标签页中打开服务提供商的登录页面,或使用 **Copy link** 或 **Show QR Code** 在其他设备上完成操作。授权批准后,该标签页会显示 **Authentication Successful** 并自动关闭,服务器状态随之切换为 **Connected**。

在登录待处理期间,服务器会显示一个加载指示器;将鼠标悬停在上面即可取消。在 Agent Builder 的 MCP 服务器设置中,**Connect** 会变为 **Cancel**,用途相同。你有 10 分钟时间完成登录,否则本次尝试会超时(管理员可以更改此时长)。

如果提供方签发了刷新令牌(refresh token),LibreChat 会在后台为您续期访问权限。当服务器在会话过程中拒绝您的令牌时,LibreChat 会先尝试一次刷新并重新连接,然后才会要求您重新登录。不签发刷新令牌的提供方,会在令牌过期后要求您重新登录。

默认情况下,登录提示会在您发送消息时出现。管理员可以将部分服务器设置为等待代理首次调用其工具时再出现,这样只有在真正需要该服务器时才会要求您登录。

## 凭据与变量 [#credentials-and-variables]

有些服务器需要每位用户提供一个值,例如个人 API 密钥或项目 ID。连接此类服务器时,LibreChat 会在连接前要求你填写这些值。如需之后修改,可在聊天选择器中或 **MCP Settings** 里对该服务器点击 **Configure**。每个字段都有 **Save** 和 **Revoke** 两个按钮。两者都会关闭你当前与该服务器的连接,因此下次使用时会以新值重新连接;而 **Revoke** 还会在当前聊天中关闭该服务器。

值按用户分别存储,并且仅发送至输入该值时所对应的服务器。

## MCP 设置面板 [#mcp-settings-panel]

**MCP 设置**位于侧边栏中,列出了您可以使用的所有服务器,每个服务器图标上都带有一个状态圆点。根据服务器的状态,每张卡片会提供**连接**、**重新连接**、**配置**(用于设置您的变量)或**撤销**(用于删除您的 OAuth 令牌)等操作。您有编辑权限的服务器还会显示**编辑**按钮。

## 从 UI 创建服务器 [#create-a-server-from-the-ui]

如果您的角色允许，可以在 **MCP Settings** 中点击 **Add MCP**（**+** 按钮），无需修改 `librechat.yaml` 或重启即可注册远程服务器。

<Steps>
<Step>
### 描述服务器 [#describe-the-server]

输入 **名称**、可选的 **描述**,以及您想要的图标(如需要)。填写 **MCP 服务器 URL**,并选择 **传输方式**:**Streamable HTTPS** 或 **SSE**。
</Step>
<Step>
### 选择认证方式 [#choose-authentication]

在 **Authentication** 下,选择以下其中一项:

- **无（自动检测）**：LibreChat 会探测服务器，如果服务器请求 OAuth，则自动切换为 OAuth。
- **API 密钥**:输入一个共享密钥,或勾选 **每位用户提供自己的密钥**,使每个用户都通过 **配置** 输入各自的密钥。选择 **Header 格式**:**Bearer**、**Basic**,或 **Custom**(使用您自定义的 Header 名称)。
- **OAuth**：输入 **Client ID**、**Client Secret**、**Authorization URL**、**Token URL** 和 **Scope**。如果提供方支持动态客户端注册，则将客户端相关字段留空。**Token Exchange Method** 默认为 **Auto**，即使用提供方所声明的方式，若未声明则回退为 Basic 授权头（Basic authorization header）；您也可以选择 **Default (POST request)** 或 **Basic authorization header** 来强制使用其中一种方式。
- **On-Behalf-Of (OBO)**：仅当管理员授予您相应权限时才会显示，并且仅当 LibreChat 使用 OpenID Connect（例如 Entra ID）对用户进行身份验证时才有效。请输入要请求的作用域（scopes）；LibreChat 会将您的 OpenID 令牌交换为一个针对 MCP 服务器作用域的令牌。
</Step>
<Step>
### 创建它 [#create-it]

勾选 **I trust this application**,然后点击 **Create**。服务器会立即可用。对于 OAuth 服务器,下一个对话框会显示需要在 OAuth 提供方处注册的 **Redirect URI**,在您登录一次之前,服务器将保持断开连接状态。
</Step>
</Steps>

<ThemeImage
  light="/images/features/mcp/add-server-dialog-light.png"
  dark="/images/features/mcp/add-server-dialog-dark.png"
  alt="添加 MCP 服务器对话框,其中已填写名称和 URL,传输方式设置为 Streamable HTTPS,身份验证设置为 API Key,并勾选了 Each user provides their own key。"
/>

通过此方式创建的服务器只能连接远程 URL;本地 `stdio` 服务器必须在 `librechat.yaml` 中定义。这类服务器也无法使用服务器环境变量或用户配置文件占位符:其请求头中的 `${API_TOKEN}` 或 `{{LIBRECHAT_USER_EMAIL}}` 等值会被移除,因为共享服务器否则会接收到这些值。如果您之后更改了服务器的 URL 或身份验证方式,已输入自有密钥的用户需要重新输入密钥,使用 OAuth 的用户需要重新登录。更改带有已保存客户端密钥的服务器的 URL 或 OAuth 端点时,您还需要重新输入该密钥。如果由旧版本创建的 API 密钥服务器卡在 **Needs Auth** 状态,请使用 **Edit** 打开它并保存一次。

## 共享服务器 [#share-a-server]

在界面中创建的服务器归其创建者所有。所有者可以通过其 **Edit** 对话框,将服务器共享给特定用户、群组、角色或所有人,共享权限分为查看者(可以查看并使用)、编辑者(还可以修改)或所有者。在 `librechat.yaml` 中定义的服务器对所有有权使用 MCP 的用户开放。关于各权限级别如何组合,请参阅[访问控制](/docs/features/access_control)。

## 服务器说明 [#server-instructions]

管理员可以为服务器附加说明，可以使用服务器自带的说明，也可以使用自定义文本。当对话或智能体使用该服务器的工具时，这些说明会被添加到模型的上下文中，这对于那些工具只有按特定顺序使用才有意义的服务器很有帮助。

## MCP Apps [#mcp-apps]

部分服务器会在返回工具结果的同时附带一个交互式视图。开启 MCP Apps 后,工具调用会显示一个**打开应用**按钮,点击后会在沙箱框架中加载该视图;点击**关闭应用**则可将其隐藏。同一时间可打开的应用数量有限;如果达到上限,请先关闭一个应用。

应用不能自行采取行动。当应用想要运行工具时，你会看到**要从应用运行工具吗？**；当它想要发送消息时，你会看到**要从应用发送消息吗？**。在你批准之前，什么都不会发生。发送消息会在当前对话中启动一次模型响应，因此可能会使用所选的智能体及其工具。应用不会在共享对话中渲染。

## 设置 [#setup]

MCP 至少需要一个服务器。管理员在 `librechat.yaml` 中的 `mcpServers` 下定义服务器,修改后需要重启才能生效;具有相应权限的用户可以从 **MCP Settings** 添加远程服务器。有关服务器选项、OAuth 回调 URL 和传输方式,请参阅 [MCP Servers](/docs/configuration/librechat_yaml/object_structure/mcp_servers);有关允许的域名和 MCP Apps,请参阅 [MCP Settings](/docs/configuration/librechat_yaml/object_structure/mcp_settings);有关应用限制,请参阅 [MCP App Sandbox](/docs/configuration/librechat_yaml/object_structure/mcp_app_sandbox);有关谁可以使用、创建和共享服务器的设置,请参阅 [`interface.mcpServers`](/docs/configuration/librechat_yaml/object_structure/interface#mcpservers)。特定服务器的设置指南位于 [MCP Servers](/docs/mcp_servers) 下,[Agent Plugins](/docs/features/agent_plugins) 介绍了如何将 MCP 服务器与 Skills 打包在一起。
