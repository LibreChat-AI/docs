---
title: 메시지 검색
icon: ListFilter
description: LibreChat의 통합 Meilisearch를 사용하여 과거 대화를 빠르게 검색하세요
---

LibreChat은 과거 대화 내용을 빠르고 효율적으로 검색할 수 있도록 **Meilisearch**를 통합하여 사용자 경험을 향상시켰습니다. Meilisearch는 속도와 사용 편의성으로 잘 알려진 강력한 오픈 소스 검색 엔진으로, 대량의 데이터에 대한 빠른 액세스가 필요한 LibreChat과 같은 애플리케이션에 탁월한 선택입니다.

![바나나에 대한 대화 검색](https://github.com/danny-avila/LibreChat/assets/32828263/60ad41b0-1869-4ee9-848b-502b3a5557b5)


이 통합을 통해 사용자는 다음을 수행할 수 있습니다:

- 사이드바에서 대화 제목, 태그 및 색인된 메시지 내용을 검색하세요
- 메타데이터 또는 메시지 중 하나가 일치할 때 대화를 엽니다.
- 대화 기록 전반에 걸쳐 오타 허용 기능과 빠른 실시간 검색 결과를 사용하세요
- Meilisearch의 기존 20개 결과 요청 기본값보다 큰 페이지 크기로 메시지 및 공유 링크 후보를 검색합니다.

쿼리를 입력하지 않고 날짜, endpoint, 첨부 파일, 공유 또는 북마크별로 채팅 목록을 좁히려면 [채팅 목록 메뉴](/docs/features/navigation#filter-and-sort-the-chat-list)를 사용하세요.

LibreChat은 표시되는 대화 페이지를 로드하기 전에 conversation-index와 message-index 일치 항목을 결합합니다. 검색은 Meilisearch에 구성된 `pagination.maxTotalHits`에 의해 제한되며, LibreChat 쿼리에서 사용하는 기본 상한값은 1,000개입니다. 설정, 동기화 및 재인덱싱 동작에 대해서는 [Meilisearch Configuration Guide](/docs/configuration/meilisearch)를 참조하세요.

<Callout type="info" title="키워드 검색, 의미론적 검색 아님">

대화 검색은 **키워드 기반**입니다. 입력한 단어와 일치하는 내용을 찾으므로, "바나나"를 검색하면 "바나나"가 포함된 메시지를 찾을 수 있습니다. "바나나"라는 단어를 사용하지 않은 "과일"에 관한 메시지는 찾을 수 없습니다.

대화 기록에 대한 벡터 또는 의미론적 검색은 없습니다. LibreChat에서의 의미론적 검색은 대화 기록이 아닌 **업로드된 파일**에 적용됩니다. [RAG API](/docs/features/rag_api)는 첨부한 문서를 임베딩하고 PostgreSQL + pgvector를 사용하여 의미에 따라 검색합니다. 이 둘은 별개의 시스템이며, 하나를 활성화한다고 해서 다른 하나에 영향을 주지는 않습니다.

</Callout>
