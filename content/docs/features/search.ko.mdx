메시지 검색은 지금까지 나눈 모든 대화에서 텍스트를 찾아 주므로, 사이드바를 스크롤하지 않고도 3주 전에 받았던 특정 답변으로 바로 돌아갈 수 있습니다. 이 기능은 Meilisearch를 기반으로 하며, 입력하는 동안 실시간으로 결과를 매칭하고 작은 오타도 허용합니다.

## 검색 [#searching]

사이드바의 **메시지 검색** 상자에 입력하거나 Ctrl+/ (macOS에서는 ⌘ /)를 눌러 검색 상자로 이동하세요. 입력을 멈춘 후 잠시 뒤에 결과가 로드됩니다. 기본 영역에는 일치하는 메시지가 개수와 함께 나열되며, 각 메시지에는 해당 대화의 제목이 표시됩니다. 제목을 클릭하면 해당 채팅이 열립니다. 동시에 사이드바의 채팅 목록은 제목이나 태그가 일치하거나 메시지 중 하나가 일치하는 대화로 좁혀집니다.

Escape 키를 누르거나 마지막 문자를 삭제하여 검색을 지울 수 있습니다. 그러면 검색 결과 페이지에서도 벗어나 새 채팅이 시작됩니다.

검색어를 입력하지 않고 날짜, 엔드포인트, 첨부 파일, 공유 여부, 북마크로 채팅 목록을 좁히려면 대신 [채팅 목록 필터](/docs/features/navigation#filter-and-sort-the-chat-list)를 사용하세요.

## 검색 가능한 항목 [#what-is-searchable]

검색은 대화 제목과 태그, 그리고 사용자 본인의 메시지와 어시스턴트의 답변 텍스트를 대상으로 합니다. 다른 사용자의 대화 결과는 절대 표시되지 않습니다.

이 검색은 입력한 단어와 일치하는 항목을 찾으며, 단어의 의미를 기준으로 찾지는 않습니다. 예를 들어 "banana"를 검색하면 "banana"라는 단어가 포함된 메시지를 찾아 주며, 그 단어를 사용하지 않은 과일 관련 메시지는 찾지 않습니다. LibreChat에서 의미 기반 검색은 업로드된 파일에만 적용되며, 이는 [파일 검색](/docs/features/rag_api)을 통해 이루어집니다.

임시 채팅은 색인되지 않으므로 검색 결과에 나타나지 않습니다. 새 메시지는 저장된 직후 곧바로 색인됩니다. 대규모 기존 데이터베이스의 경우, 검색을 활성화한 후 처음 전체 색인을 생성하는 데 시간이 다소 걸릴 수 있으며, 색인이 진행되는 동안 이전 대화가 순차적으로 나타납니다.

## 설정 [#setup]

검색 기능은 관리자가 Meilisearch를 실행하고 `SEARCH=true`로 설정하기 전까지 꺼져 있습니다. 이 설정이 없으면 검색 상자가 나타나지 않습니다. Docker 및 소스 설정 방법과 인덱스 다시 동기화에 대해서는 [Meilisearch](/docs/configuration/meilisearch)를 참조하세요.
