Projects 允许每个用户将相关的对话组织到已命名的工作区中。它们对于长期进行的工作流、团队、客户、课程或任何你希望拥有一组专注的聊天记录的主题非常有用，这些聊天记录共享相同的背景信息，而无需在每次对话中重复。

<Callout type="info" title="可用性">
  Projects（项目）是在 LibreChat **v0.8.7** 中添加的。目前没有隐藏 Projects 的开关或角色权限，因此所有已登录且使用受支持版本的用户都可以使用此功能。管理员可以通过 `librechat.yaml` 中的 [`projects`](/docs/configuration/librechat_yaml/object_structure/config#projects) 代码块来调整指令、描述和文件限制。如果您在界面中找不到 Projects，说明实例运行的是旧版本，需要进行更新。
</Callout>

## Projects 的作用 [#what-projects-do]

- 在命名工作区中对对话进行分组，并可选择添加描述
- 为项目中的每个聊天设置相同的 **Instructions**
- 添加聊天中可供搜索的参考 **Files**
- 启动一个新的已限定在项目范围内的聊天，或移入/移出现有聊天
- 在项目工作区中浏览、排序、移动、移除或删除聊天记录
- 按名称或描述搜索项目，并按最新活动、创建日期或名称进行排序

Projects 是用户个人创建的。其他用户无法查看您的项目列表，且项目无法共享或转移。Projects 不包含模型设置：每个对话都保留其各自的模型、Agent 和参数。

## 创建项目 [#create-a-project]

<Steps>
<Step>

**打开项目页面。** 在侧边栏中，**Projects** 部分标题下有一个 **All projects** 按钮，点击即可打开。

</Step>
<Step>

**选择 New project**，该选项始终位于项目页面标题中。

</Step>
<Step>

**命名项目。** 项目名称是必需的，描述则是可选的。随后 LibreChat 将打开项目工作区。

</Step>
</Steps>

当您还没有项目时，侧边栏的 **Projects** 部分也会提供一个 **New project** 按钮。一旦您有了项目，该部分默认会处于展开状态，直到您将其折叠。

项目名称限制为 100 个字符。描述默认限制为 1,000 个字符，允许项目名称重复。

项目页面将每个项目显示为一个文件夹卡片，其中包含其描述和聊天计数。

## 指令 [#instructions]

Instructions 为项目中的每次对话设定基调、目标或背景，例如客户的风格指南或一系列对话所属的课程。平台和安全规则仍会在此基础上生效。

<Steps>
<Step>

**打开项目工作区**并找到 **Instructions** 部分。

</Step>
<Step>

**选择 Edit** 以打开指令对话框。

</Step>
<Step>

**输入工作区指令并保存。** 默认情况下，指令最多可包含 16,000 个字符。

</Step>
</Steps>

指令用于项目中的新消息。更改指令不会重写之前的消息：已经生成的消息回复将保持原样，而项目中任何聊天记录的下一条消息都将使用当前版本。指令适用于常规模型聊天、Agent 以及 Assistants 对话。

如果对话框打开时项目在另一个会话中被更改，保存时会显示 **This project was changed in another session. Reload to see the latest version.** 请重新加载并重新应用您的编辑。

## 文件 [#files]

项目文件为项目的聊天提供了可供参考的文档。当启用 File Search 时，聊天会使用这些文件中相关的摘录，而不是整个文件。

在工作区 **Files** 部分，选择 **Add files**，然后：

- **从设备上传**以上传新文档。每次上传都会显示**处理中**，直到显示**就绪**。
- **从您的文件中选择**以附加您已经上传的文件。

仅限为 File Search 上传（嵌入式消息附件）且未过期的文件可以被附加，因此 **Choose from your files** 仅列出这些文件。一个项目默认最多可容纳 50 个文件。

项目文件通过 File Search 使用，因此聊天仅在以下情况下可以读取它们：

- Agent 或常规聊天已启用 **File Search**
- Agents endpoint 已启用 File Search，且部署的文件搜索服务可用

被删除或过期的文件将显示为 **Unavailable**（不可用）并被跳过。从项目中移除文件会影响后续的消息，而不会影响聊天记录。

## 在项目中工作 [#work-in-a-project]

打开一个项目以查看其描述、说明、文件和已分配的聊天记录。选择项目名称或描述即可进行就地编辑。工作区中的 **Chats** 列表可以按最后更新日期或创建日期进行排序。

使用工作区标题栏中的 **New chat** 打开一个限定于该项目的编辑器；其项目标签确认新对话将被分配给该项目。侧边栏在每个项目行上也显示了相同的操作。

属于项目的对话会在对话顶部显示一个带有项目名称的项目徽章。选择该徽章即可打开项目工作区。

每个项目聊天都有一个包含以下操作的溢出菜单：

- **Change project** 会打开一个可搜索的项目选择器
- **从项目中移除**会保留对话，但会清除其项目分配。
- **Delete** 会在确认后删除对话

## 迁移现有聊天记录 [#move-existing-chats]

打开对话菜单并选择 **Change project**，然后选择要分配到的项目。若要将聊天从项目中移出，请使用 **Remove from project**，该选项仅在已属于某个项目的聊天中显示。在桌面端，你也可以将聊天拖拽到侧边栏的项目上；请参阅 [Sidebar and Navigation](/docs/features/navigation#desktop-sidebar)。

项目上下文会在每条消息发送时重新读取，因此当您将聊天移入某个项目时，它会在下一条消息中应用该项目的指令和文件；而当您将聊天从项目中移除时，它将停止使用这些内容。

在侧边栏中，每个项目行都可以展开以列出其所属的聊天记录，对于较长的列表，可以使用 **Show all**。**Chats** 部分仅列出不在项目中的对话，因此项目聊天记录只会出现在一个位置。以下三种情况仍会列出所有聊天记录：

- 当您正在搜索对话时
- 在 [聊天列表菜单](/docs/features/navigation#filter-and-sort-the-chat-list) 的 **已归档聊天** 视图中
- 当您的项目无法加载时

## 管理项目 [#manage-projects]

使用侧边栏中的项目菜单来：

- **打开项目**
- **编辑项目**，它将打开工作区，并准备好编辑名称和描述
- **删除**项目

项目页面提供了相同的编辑和删除操作，工作区标题栏中包含一个带有 **Delete project** 的项目选项菜单。

删除项目会移除其对话中的项目分配。对话本身不会被删除。

## 查找项目 [#find-a-project]

项目页面包含一个 **Search projects** 搜索框，可匹配项目名称和描述，以及一个提供 **Latest activity**（最新活动）、**Created**（创建时间）和 **Name**（名称）排序的控件。较长的列表可通过 **Load more**（加载更多）进行分页。

## 注意事项 [#notes]

- 从项目启动的新聊天在创建对话时会保留该分配。
- 项目搜索不区分大小写，且同时匹配名称和描述。
- 如果某个项目在您查看时被删除，LibreChat 会将您返回到项目列表。
