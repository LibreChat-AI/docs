O LibreChat cria e edita imagens por meio de ferramentas de agentes. Dê a um agente uma ferramenta de imagem, descreva o que você quer, e a imagem aparece na conversa. Envie uma foto junto com sua mensagem e o agente poderá alterá-la em vez de começar do zero.

## As ferramentas de imagem [#the-image-tools]

| Ferramenta | O que faz | Edita imagens |
| --- | --- | --- |
| OpenAI Image Tools | Gera a partir de texto e edita imagens enviadas ou geradas anteriormente com os modelos de imagem da OpenAI. Uma boa opção padrão. | Sim |
| Gemini Image Tools | Gera com os modelos de imagem Gemini do Google, opcionalmente usando imagens anteriores como contexto visual. | Sim |
| Flux | Gera com os modelos Flux da Black Forest Labs, incluindo seus próprios modelos ajustados (fine-tuned). | Não |
| Stable Diffusion | Gera no seu próprio servidor Automatic1111, para que nada saia da sua rede. | Não |

Quais delas você vê depende do que o seu administrador configurou.

## Gerar uma imagem [#generate-an-image]

<Steps>
<Step>
Abra o agente no Agent Builder e selecione **Add** ao lado de **Tools**.
</Step>
<Step>
Escolha uma ferramenta de imagem, como **OpenAI Image Tools**, e salve o agente. Se a ferramenta pedir uma chave de API, seu administrador deixou a configuração a cargo de cada usuário; insira a sua própria.
</Step>
<Step>
Inicie um chat com o agente e descreva a imagem.
</Step>
</Steps>

O agente transforma o seu pedido em um prompt para a ferramenta, então você pode conversar de forma natural ("um cartaz para uma venda de bolos, formato largo, com muitas cores pastel"). Pedidos de formato e tamanho são repassados quando a ferramenta oferece suporte a eles: a OpenAI aceita tamanhos quadrado, paisagem ou retrato (os modelos mais recentes também aceitam tamanhos personalizados de até 4K), além de um nível de qualidade e fundo transparente; o Gemini aceita proporções como 16:9 ou 9:16 e, nos modelos mais recentes, uma resolução de até 4K. O Stable Diffusion sempre gera imagens de 1024x1024.

## Editar uma imagem [#edit-an-image]

Anexe uma imagem com **Upload Image** e peça uma alteração: "remova as pessoas do fundo", "faça parecer uma aquarela", "coloque este logo em uma caneca de café". Com o OpenAI Image Tools, o agente chama a ferramenta de edição; com o Gemini, ele envia sua imagem como contexto para uma nova geração.

Você pode continuar trabalhando em uma imagem que o agente acabou de gerar ("agora deixe o céu mais escuro") sem enviar nada. Cada imagem enviada ou gerada tem um ID ao qual o modelo se refere, e isso funciona enquanto a imagem ainda estiver dentro da janela de contexto da conversa. Em uma conversa longa, anexe a imagem novamente.

Flux e Stable Diffusion funcionam apenas a partir de texto, por isso não conseguem editar.

## O que o modelo vê [#what-the-model-sees]

Uma imagem gerada é mostrada ao modelo uma única vez, logo após ser criada, para que ele possa descrever ou verificar o próprio trabalho. Depois disso, o modelo só enxerga as imagens anexadas às suas mensagens. Se você quiser discutir uma imagem mais antiga várias interações depois, anexe-a novamente.

Como a imagem é devolvida ao modelo, use um modelo com capacidade de visão para agentes com ferramentas de imagem. Um modelo somente de texto pode falhar no turno seguinte àquele em que a imagem foi gerada.

As imagens geradas são armazenadas como qualquer outro upload, de acordo com as configurações de armazenamento de arquivos definidas pelo seu administrador. Por padrão, elas são reduzidas para que o lado menor tenha no máximo 768 pixels, portanto, uma solicitação em 4K é salva em um tamanho menor do que o modelo gerou, a menos que seu administrador altere essa configuração.

## Imagens de servidores MCP [#images-from-mcp-servers]

Ferramentas MCP também podem retornar imagens, por exemplo um servidor de navegador que captura screenshots. As imagens que o servidor retorna no formato de imagem do MCP aparecem no chat da mesma forma que a saída das ferramentas integradas. Alguns servidores retornam apenas uma URL para a imagem, o que o LibreChat não trata como saída de imagem.

## Escrevendo prompts [#writing-prompts]

Os modelos de imagem respondem a descrições concretas. Comece pelo assunto e pelo meio (foto, pintura a óleo, ilustração vetorial chapada), depois acrescente a composição, a iluminação e os detalhes que importam. Descreva o que você quer ver, em vez de listar o que evitar. Se um resultado estiver próximo, peça a mudança específica em vez de reescrever o prompt inteiro.

## Configuração [#setup]

Cada ferramenta precisa de uma chave de API ou de uma URL de servidor. Um administrador define essas configurações em `.env`; para as ferramentas baseadas em chave, o administrador também pode deixar a chave para que cada usuário a insira. Configuração de cada ferramenta: [OpenAI Image Tools](/docs/configuration/tools/openai_image_gen), [Gemini Image Tools](/docs/configuration/tools/gemini_image_gen), [Flux](/docs/configuration/tools/flux) e [Stable Diffusion](/docs/configuration/tools/stable_diffusion). O local onde as imagens são armazenadas é definido por [`fileStrategy`](/docs/configuration/librechat_yaml/object_structure/config#filestrategy).
