Chaque message d'une conversation est accompagné d'une rangée de petits boutons en dessous. Sur ordinateur, ils apparaissent lorsque vous survolez le message ou que vous placez le focus du clavier dessus. Les boutons qui n'ont aucun sens pendant qu'une réponse est encore en cours de diffusion restent masqués jusqu'à la fin de celle-ci.

## Ce que fait chaque bouton [#what-each-button-does]

| Bouton | Ce qu'il fait |
|---|---|
| **Lire à voix haute** | Lit le message à voix haute avec la synthèse vocale, lorsqu'elle est activée. |
| **Copier dans le presse-papiers** | Copie le texte du message. |
| **Modifier** | Ouvre le message dans un éditeur. Voir [Modifier et relancer](#edit-and-rerun). |
| **Fork** | Démarre une nouvelle conversation à partir de ce message. Voir [Forking Conversations](/docs/features/fork). |
| **J'aime** / **Doit être amélioré** | Évalue une réponse. Vous pouvez ajouter une raison et un commentaire. |
| **Régénérer** | Demande au modèle une nouvelle réponse au même message. L'ancienne réponse reste disponible en tant que version précédente. |
| **Continuer** | Affiché sur la dernière réponse lorsqu'elle s'est arrêtée avant d'être terminée, par exemple à la limite de jetons de sortie. Reprend là où elle s'est arrêtée. |

Les boutons qui apparaissent dépendent de l'endpoint et du message. Les messages de l'utilisateur, par exemple, n'ont ni bouton d'évaluation ni bouton **Regenerate**.

## Modifier et relancer [#edit-and-rerun]

Choisissez **Modifier** sur votre propre message ou sur une réponse. L'éditeur comporte trois boutons :

- **Enregistrer** conserve votre modification sans générer aucun nouveau contenu.
- **Mettre à jour et relancer** renvoie votre message modifié et obtient une nouvelle réponse. Le bouton affiche **Relancer** lorsque vous n'avez rien modifié, ainsi que lorsque vous modifiez une réponse, auquel cas il rejoue le message de l'utilisateur qui la précède.
- **Annuler** ferme l'éditeur.

Pendant la modification, <kbd>Ctrl</kbd>+<kbd>S</kbd> (<kbd>Cmd</kbd>+<kbd>S</kbd>) enregistre, <kbd>Ctrl</kbd>+<kbd>Entrée</kbd> (<kbd>Cmd</kbd>+<kbd>Entrée</kbd>) relance l'exécution, et <kbd>Échap</kbd> annule.

Une relance conserve les fichiers, les extraits cités et les compétences qui étaient joints au message d'origine, vous n'avez donc pas besoin de les ajouter à nouveau. Un message qui ne contient que des fichiers, sans texte, peut également être modifié et relancé.

Les réponses des agents peuvent contenir plus que du texte. L'éditeur vous permet uniquement de modifier les parties de texte et de raisonnement ; les appels d'outils, les erreurs et les artefacts sont affichés mais en lecture seule. Une relance applique une partie modifiée à la fois. Si vous modifiez plusieurs parties, utilisez **Enregistrer**.

## Copier [#copy]

**Copier dans le presse-papiers** copie le texte visible du message. Pour les réponses d'agent, le raisonnement, les appels d'outils et les erreurs sont exclus. Les citations sont transformées en références lisibles.

Si vous collez dans des applications comme Teams, Outlook ou Word, activez **Copier les messages en texte enrichi** dans **Paramètres > Chat**. La copie place alors aussi une version mise en forme dans le presse-papiers, afin que les titres, listes, tableaux et blocs de code conservent leur style.

## Extraits de citations [#quote-excerpts]

Sélectionnez du texte dans n'importe quel message et choisissez **Ajouter au chat**. L'extrait est préparé au-dessus de la zone de saisie et envoyé avec votre prochain message sous forme de citation, afin que le modèle sache exactement de quelle partie vous parlez. Vous pouvez joindre jusqu'à 10 extraits à un même message, et chacun est tronqué à 1 500 caractères.

Les citations fonctionnent également avec les [messages de pilotage et les messages en file d'attente](/docs/features/agents#steering-and-queued-messages) : un extrait reste attaché au message que vous mettez en file d'attente ou utilisez pour piloter la réponse.

## Blocs de code [#code-blocks]

Les blocs de code d'une réponse disposent de leurs propres boutons dans l'en-tête :

- **Copier le code** copie le bloc.
- **Télécharger le code** enregistre le bloc sous forme de fichier nommé d'après son langage, comme `code.py` ou `code.toml`. Les blocs sans langage, ou dont le langage ne ressemble pas à une extension de fichier, sont téléchargés sous le nom `code.txt`. Les blocs d'erreur ne disposent pas de bouton de téléchargement.
- **Exécuter le code** exécute le bloc avec l'[Interpréteur de code](/docs/features/code_interpreter), lorsqu'il est disponible pour ce langage.
