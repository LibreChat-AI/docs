스무스 스트리밍을 켜면 응답의 새 단어가 화면에 한꺼번에 나타나는 대신 도착하는 순서대로 서서히 나타나므로, 빠르게 출력되는 응답도 따라 읽기 쉬워집니다. 이 기능은 생성 중인 가장 최근 응답에만 적용되며, 펼쳐 놓은 추론(reasoning) 텍스트도 포함됩니다.

기본적으로 켜져 있습니다. 끄려면 **설정** > **채팅** > **메시지**를 열고 **부드러운 스트리밍 텍스트(새 단어 페이드 인)**를 끄세요. 이 설정은 브라우저에 저장됩니다.

## 변경되는 내용과 변경되지 않는 내용 [#what-it-changes-and-what-it-does-not]

페이드는 시각적 효과일 뿐입니다. 토큰은 똑같이 빠르게 도착하며, 페이드 여부와 관계없이 응답 텍스트와 저장된 메시지는 동일합니다. 페이드가 켜져 있는 동안에는 스트림 끝의 블록 커서가 숨겨집니다. 페이드 효과가 이미 텍스트가 아직 생성되고 있음을 보여주기 때문입니다.

코드 블록, 수식, 아티팩트, 인용, MCP UI 콘텐츠는 단어 단위로 페이드되지 않습니다. 스트림이 다시 연결되거나 대화를 전환할 때 이미 화면에 표시되어 있던 텍스트는 다시 애니메이션되지 않습니다.

에이전트 실행이 활동 단계(phase)별로 묶여 있을 때, 새로 생성된 단계 요약은 짧은 전환 효과와 함께 그 위의 활동들을 접힌 그룹 안으로 접어 넣습니다. 이후에 불러오는 기록에서는 그룹이 이미 접힌 상태로 표시됩니다.

기기에서 축소된 모션(`prefers-reduced-motion` 설정)을 요청하면, LibreChat은 토글 설정과 관계없이 이 모든 애니메이션을 건너뜁니다.

## 경과 시간 [#elapsed-time]

생성 중인 응답 아래에는 응답이 얼마나 오래 실행되고 있는지를 보여 주는 타이머가 표시됩니다. 타이머는 처음에는 초 단위로, 이후에는 분 단위로 표시됩니다. 타이머는 메시지를 보낸 시점부터 계산되며, 같은 세션에서 다른 페이지로 이동했다가 돌아온 경우에도 이어서 계산됩니다. 생성 중에 전체 페이지를 새로 고침하면 응답이 다시 나타나는 시점부터 타이머가 다시 시작됩니다. 타이머는 생성 중인 최신 응답에만 표시되며, 저장되지 않습니다. Smooth Streaming을 켜거나 끄든 관계없이 타이머는 계속 표시됩니다.

## 설정 [#setup]

부드러운 스트리밍은 별도의 설정이 필요하지 않으며, 각 사용자가 자신의 설정에서 제어합니다. 활동 단계 요약은 관리자가 활성화하며, 자세한 내용은 [에이전트 활동 그룹](/docs/configuration/librechat_yaml/object_structure/shared_endpoint_settings#agent-activity-groups)을 참조하세요.
