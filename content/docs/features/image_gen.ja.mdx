LibreChatは、エージェントのツールを通じて画像の作成と編集を行います。エージェントに画像ツールを割り当て、作りたい内容を説明すると、画像が会話内に表示されます。メッセージと一緒に画像をアップロードすると、エージェントはゼロから始めるのではなく、その画像を編集できます。

## 画像ツール [#the-image-tools]

| ツール | 機能 | 画像編集 |
| --- | --- | --- |
| OpenAI Image Tools | テキストから画像を生成し、アップロードした画像や以前に生成した画像を OpenAI の画像モデルで編集します。標準として適しています。 | はい |
| Gemini Image Tools | Google の Gemini 画像モデルで画像を生成します。以前の画像を視覚的な文脈として任意で利用できます。 | はい |
| Flux | Black Forest Labs の Flux モデルで画像を生成します。独自にファインチューニングしたモデルも利用できます。 | いいえ |
| Stable Diffusion | 自前の Automatic1111 サーバー上で画像を生成するため、データがネットワークの外に出ることはありません。 | いいえ |

表示されるものは、管理者がどのように設定しているかによって異なります。

## 画像を生成する [#generate-an-image]

<Steps>
<Step>
エージェントビルダーでエージェントを開き、**Tools** の横にある **Add** を選択します。
</Step>
<Step>
画像ツール（例：**OpenAI Image Tools**）を選択し、エージェントを保存してください。ツールからAPIキーを求められた場合は、管理者がAPIキーの設定をユーザーごとに任せています。ご自身のAPIキーを入力してください。
</Step>
<Step>
エージェントとのチャットを開始し、画像を説明してください。
</Step>
</Steps>

エージェントはあなたのリクエストをツール用のプロンプトに変換するため、「ベイクセールのポスター、横長、パステルカラーをたくさん使って」のように普段の言葉で話しかけることができます。形状やサイズの指定は、ツールがサポートしている場合に引き渡されます。OpenAI では正方形、横長、縦長のサイズを指定でき(新しいモデルでは最大 4K までのカスタムサイズも可能)、さらに品質レベルと背景の透過も指定できます。Gemini では 16:9 や 9:16 などのアスペクト比を指定でき、新しいモデルでは最大 4K の解像度も指定できます。Stable Diffusion は常に 1024x1024 の画像を生成します。

## 画像を編集する [#edit-an-image]

画像を添付するには **Upload Image** を使用し、変更を依頼してください。例えば「背景の人物を消して」「水彩画風にして」「このロゴをコーヒーマグに載せて」などです。OpenAI Image Tools を使用している場合、エージェントは編集ツールを呼び出します。Gemini の場合は、添付した画像を新しい生成のためのコンテキストとして渡します。

エージェントが生成した画像に対して、アップロードし直すことなく続けて編集を指示できます(例:「空をもっと暗くして」)。アップロードされた画像や生成された画像にはそれぞれIDがあり、モデルはそのIDを使って画像を参照します。この仕組みは、画像が会話のコンテキストウィンドウ内に残っている限り機能します。会話が長くなった場合は、画像を再度添付してください。

Flux と Stable Diffusion はテキストからのみ動作するため、編集を行うことはできません。

## モデルが見る内容 [#what-the-model-sees]

生成された画像は、作成された直後に一度だけモデルに表示され、モデルが自分の作業内容を説明したり確認したりできるようにします。その後、モデルが参照できるのは、あなたのメッセージに添付された画像のみです。数ターン後に以前の画像について話したい場合は、もう一度添付してください。

画像は再びモデルに渡されるため、画像ツールを使用するエージェントには、ビジョン対応のモデルを使用してください。テキストのみのモデルでは、画像が生成された後のターンで失敗する可能性があります。

生成された画像は、他のアップロードファイルと同様に、管理者のファイルストレージ設定に従って保存されます。デフォルトでは、短い辺が最大768ピクセルになるように縮小されるため、管理者が設定を変更しない限り、4Kで生成をリクエストした場合でもモデルが生成したサイズより小さく保存されます。

## MCP サーバーからの画像 [#images-from-mcp-servers]

MCPツールは画像を返すこともできます。たとえば、スクリーンショットを撮影するブラウザサーバーなどが該当します。サーバーがMCPの画像形式で返した画像は、組み込みツールの出力と同じようにチャット内に表示されます。一方、画像のURLのみを返すサーバーもあり、その場合LibreChatは画像の出力としては扱いません。

## プロンプトの書き方 [#writing-prompts]

画像モデルは、具体的な描写に対して良く反応します。まず被写体と表現媒体（写真、油彩画、フラットなベクターイラストなど）を示し、そのうえで構図、照明、そして重要なディテールを加えてください。避けたいものを列挙するのではなく、見せたいものを描写してください。結果が近いものの場合は、プロンプト全体を書き直すのではなく、求める具体的な変更点を指示してください。

## セットアップ [#setup]

各ツールには API キーまたはサーバー URL が必要です。管理者はこれらを `.env` で設定します。キーを使うツールについては、管理者が代わりにキーを空欄のままにし、各ユーザーが自分でキーを入力できるようにすることもできます。各ツールの設定方法: [OpenAI Image Tools](/docs/configuration/tools/openai_image_gen)、[Gemini Image Tools](/docs/configuration/tools/gemini_image_gen)、[Flux](/docs/configuration/tools/flux)、[Stable Diffusion](/docs/configuration/tools/stable_diffusion)。画像の保存場所は [`fileStrategy`](/docs/configuration/librechat_yaml/object_structure/config#filestrategy) で設定します。
