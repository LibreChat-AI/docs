Un progetto è una cartella per le conversazioni che appartengono insieme, ad esempio un cliente, un corso o un lungo lavoro. Le chat all'interno di un progetto condividono le istruzioni del progetto e possono attingere ai suoi file di riferimento, così imposti il contesto una sola volta invece di ripeterlo in ogni nuova chat.

I progetti sono personali. Nessun altro vede i tuoi progetti né quali chat vi sono contenute, e un progetto non può essere condiviso o trasferito a qualcun altro. Un progetto non imposta un modello: ogni chat mantiene il proprio modello, agente e parametri.

## Crea un progetto [#create-a-project]

Nella barra laterale, l'intestazione della sezione **Progetti** include un pulsante **Tutti i progetti** che apre la pagina dei progetti; lì seleziona **Nuovo progetto**. (Finché non hai un progetto, la sezione della barra laterale mostra direttamente **Nuovo progetto**.) Assegna un nome di massimo 100 caratteri e, se lo desideri, una descrizione, quindi seleziona **Crea progetto**. LibreChat apre l'area di lavoro del nuovo progetto.

La pagina dei progetti mostra ogni progetto come una scheda con la sua descrizione e il numero di chat. **Cerca progetti** trova corrispondenze nei nomi e nelle descrizioni, e il menu di ordinamento offre **Attività più recente**, **Creato** e **Nome**.

## Avviare o spostare le chat [#start-or-move-chats]

Dallo spazio di lavoro di un progetto, oppure tramite l'icona di nuova chat accanto al progetto nella barra laterale, avvia una chat con **New chat in** seguito dal nome del progetto. La casella del messaggio mostra un chip del progetto: usalo per passare a un altro progetto oppure seleziona la sua × per rimuovere il progetto prima di inviare. Una volta inviata, la chat appartiene al progetto.

Per archiviare una chat esistente, apri il suo menu e scegli **Cambia progetto**, quindi seleziona un progetto dall'elenco con funzione di ricerca. **Rimuovi dal progetto** la riporta fuori. Su desktop puoi anche trascinare una chat su un progetto nella barra laterale. Una chat adotta le istruzioni e i file del progetto a partire dal messaggio successivo, e smette di utilizzarli non appena ne esce.

Una chat all'interno di un progetto mostra il nome del progetto in cima alla conversazione; selezionalo per aprire l'area di lavoro. Nella barra laterale, ogni progetto si espande per elencare le proprie chat, mentre l'elenco principale **Chat** mostra solo le chat che non appartengono ad alcun progetto. L'area di lavoro del progetto elenca solo le proprie chat, ordinate per **Aggiornamento** o **Creazione**.

## Istruzioni [#instructions]

**Istruzioni** nell'area di lavoro contengono il contesto, il tono o gli obiettivi per ogni chat del progetto. Seleziona **Modifica** per cambiarle. Le regole di sistema del tuo server restano comunque valide.

Le istruzioni si applicano ai messaggi inviati dopo il salvataggio, nelle chat normali, nelle chat degli agenti e nelle chat degli Assistenti. Le risposte precedenti non vengono riscritte. Possono contenere fino a 16.000 caratteri per impostazione predefinita.

Se hai modificato il progetto in un'altra scheda nel frattempo, il salvataggio non riesce e viene visualizzato il messaggio **This project was changed in another session. Reload to see the latest version.** Ricarica la pagina e ripeti la modifica.

## File [#files]

**File** contiene i documenti di riferimento del progetto. Usa **Aggiungi file** per caricare un file con **Carica dal dispositivo** oppure scegli un file caricato in precedenza con **Scegli tra i tuoi file**. Ogni file mostra **Elaborazione** mentre viene indicizzato e **Pronto** quando le chat possono utilizzarlo. **Scegli tra i tuoi file** elenca solo i file caricati per la ricerca nei file e non scaduti. Un file che viene successivamente eliminato o scade rimane elencato come **Non disponibile** e viene ignorato.

Le chat nel progetto cercano in questi file e recuperano i passaggi pertinenti, non interi documenti. Questo avviene solo quando **File Search** è attivo per la chat o per l'agente. Se il server non ha configurato la ricerca nei file, o se il tuo ruolo non è autorizzato a utilizzarla, non puoi caricare nuovi file di progetto.

Un progetto può contenere fino a 50 file, salvo che il tuo amministratore abbia modificato il limite. Rimuovere un file ha effetto solo sui messaggi futuri; le risposte che lo avevano già utilizzato restano invariate.

## Rinominare o eliminare [#rename-or-delete]

Fai clic sul nome o sulla descrizione del progetto nello spazio di lavoro per modificarlo, oppure usa **Edit project** dal menu del progetto nella barra laterale.

**Elimina progetto**, nel menu **Opzioni progetto** dell'area di lavoro o come **Elimina** nel menu della barra laterale, chiede conferma e rimuove solo il progetto. Le sue chat restano nella cronologia, senza più essere assegnate ad alcun progetto. Se stai visualizzando un progetto nel momento in cui viene eliminato, LibreChat ti riporta alla pagina dei progetti.

## Setup [#setup]

I progetti sono disponibili a ogni utente a partire da LibreChat v0.8.7; nessuna impostazione o autorizzazione di ruolo li nasconde. Gli amministratori possono modificare il limite di file per progetto e la lunghezza massima di istruzioni e descrizioni nella chiave [`projects`](/docs/configuration/librechat_yaml/object_structure/config#projects) di `librechat.yaml`. I file dei progetti si basano sulla [ricerca nei file](/docs/features/rag_api).
