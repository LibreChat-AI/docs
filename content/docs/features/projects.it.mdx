I Projects consentono a ogni utente di organizzare conversazioni correlate in aree di lavoro denominate. Sono utili per flussi di lavoro a lungo termine, team, clienti, lezioni o qualsiasi argomento in cui si desideri un insieme mirato di chat che condividano lo stesso contesto senza doverlo ripetere in ogni conversazione.

<Callout type="info" title="Disponibilità">
  I Projects sono stati aggiunti in LibreChat **v0.8.7**. Non esiste alcun interruttore o autorizzazione di ruolo che nasconda i Projects, quindi ogni utente che ha effettuato l'accesso su una versione supportata dispone di questa funzionalità. Gli amministratori possono regolare le istruzioni, la descrizione e i limiti dei file con il blocco [`projects`](/docs/configuration/librechat_yaml/object_structure/config#projects) in `librechat.yaml`. Se non riesci a trovare i Projects nell'interfaccia, l'istanza sta eseguendo una versione precedente e deve essere aggiornata.
</Callout>

## Cosa fanno i Projects [#what-projects-do]

- Raggruppa le conversazioni in uno spazio di lavoro denominato con una descrizione opzionale
- Assegna a ogni chat nel progetto le stesse **Instructions**
- Allega **Files** di riferimento che le chat nel progetto possono cercare
- Avvia una nuova chat già limitata a un progetto, oppure sposta le chat esistenti dentro o fuori.
- Sfoglia, ordina, sposta, rimuovi o elimina le chat dall'area di lavoro del progetto
- Cerca progetti per nome o descrizione e ordinali per attività recente, data di creazione o nome

I Projects sono personali per l'utente che li crea. Altri utenti non vedono il tuo elenco di progetti e un progetto non può essere condiviso o trasferito. I Projects non mantengono le impostazioni del modello: ogni chat conserva il proprio modello, Agent e parametri.

## Crea un progetto [#create-a-project]

<Steps>
<Step>

**Apri la pagina dei progetti.** Nella barra laterale, l'intestazione della sezione **Projects** contiene un pulsante **All projects** che la apre.

</Step>
<Step>

**Scegli New project**, che è sempre disponibile nell'intestazione della pagina dei progetti.

</Step>
<Step>

**Dai un nome al progetto.** Un nome è obbligatorio e una descrizione è facoltativa. LibreChat aprirà quindi l'area di lavoro del progetto.

</Step>
</Steps>

Finché non hai ancora progetti, la sezione **Projects** nella barra laterale offre anche un pulsante **New project**. Una volta creati dei progetti, la sezione viene espansa per impostazione predefinita finché non la comprimi.

I nomi dei progetti sono limitati a 100 caratteri. Le descrizioni sono limitate a 1.000 caratteri per impostazione predefinita e sono consentiti nomi di progetto duplicati.

La pagina dei progetti mostra ogni progetto come una scheda a forma di cartella con la relativa descrizione e il conteggio delle chat.

## Istruzioni [#instructions]

Le istruzioni impostano il tono, gli obiettivi o il contesto per ogni chat nel progetto, ad esempio la guida di stile di un cliente o il corso a cui appartiene una serie di chat. Le regole della piattaforma e di sicurezza si applicano comunque al di sopra di esse.

<Steps>
<Step>

**Apri l'area di lavoro del progetto** e trova la sezione **Instructions**.

</Step>
<Step>

**Scegli Edit** per aprire la finestra di dialogo delle istruzioni.

</Step>
<Step>

**Inserisci le istruzioni dell'area di lavoro e salva.** Per impostazione predefinita, le istruzioni possono contenere fino a 16.000 caratteri.

</Step>
</Steps>

Le istruzioni vengono utilizzate per i nuovi messaggi nel progetto. Modificarle non riscrive i messaggi precedenti: le risposte già generate rimangono invariate e il messaggio successivo in una qualsiasi delle chat del progetto utilizzerà la versione corrente. Le istruzioni si applicano alle chat con modelli standard, agli Agent e alle conversazioni con gli Assistants.

Se il progetto è stato modificato in un'altra sessione mentre la finestra di dialogo era aperta, il salvataggio mostrerà **This project was changed in another session. Reload to see the latest version.** Ricarica e riapplica la tua modifica.

## File [#files]

I file di progetto forniscono alle chat del progetto documenti a cui fare riferimento. Quando la ricerca di file (File Search) è abilitata, le chat utilizzano estratti pertinenti da questi file anziché i file interi.

Nella sezione **Files** dell'area di lavoro, scegli **Add files** e poi:

- **Carica dal dispositivo** per caricare nuovi documenti. Ogni caricamento mostrerà **Elaborazione in corso** finché non sarà **Pronto**.
- **Scegli dai tuoi file** per allegare file che hai già caricato.

È possibile allegare solo i file caricati per la Ricerca File (allegati ai messaggi incorporati) e che non sono scaduti, pertanto **Scegli dai tuoi file** elenca solo tali file. Un progetto può contenere fino a 50 file per impostazione predefinita.

I file di progetto vengono utilizzati tramite File Search, quindi una chat può leggerli solo quando:

- l'Agent, o la chat regolare, ha **File Search** abilitato
- La ricerca file (File Search) è abilitata per l'endpoint Agents e il servizio di ricerca file della distribuzione è disponibile

Un file eliminato o scaduto rimane elencato come **Unavailable** e viene ignorato. La rimozione di un file dal progetto influisce sui messaggi futuri, non sulla cronologia della chat.

## Lavora in un Project [#work-in-a-project]

Apri un progetto per visualizzarne la descrizione, le istruzioni, i file e le chat assegnate. Seleziona il nome o la descrizione del progetto per modificarli direttamente. L'elenco **Chats** nell'area di lavoro può essere ordinato per data di ultimo aggiornamento o di creazione.

Usa **New chat** nell'intestazione dell'area di lavoro per aprire un compositore limitato al progetto; il suo chip di progetto conferma che la nuova conversazione gli verrà assegnata. La barra laterale mostra la stessa azione su ogni riga del progetto.

Le chat che appartengono a un progetto mostrano un badge del progetto con il nome del progetto nella parte superiore della conversazione. Seleziona il badge per aprire l'area di lavoro del progetto.

Ogni chat di progetto ha un menu di overflow con queste azioni:

- **Change project** apre un selettore di progetti ricercabile
- **Remove from project** mantiene la conversazione ma rimuove la sua assegnazione al progetto
- **Delete** elimina la conversazione dopo una conferma

## Spostare le chat esistenti [#move-existing-chats]

Apri il menu di una conversazione e scegli **Change project**, quindi seleziona il progetto a cui assegnarla. Per rimuovere una chat da un progetto, usa **Remove from project**, che viene mostrato solo per le chat che appartengono già a uno. Su desktop puoi anche trascinare una chat su un progetto nella barra laterale; vedi [Sidebar and Navigation](/docs/features/navigation#desktop-sidebar).

Il contesto del progetto viene letto nuovamente per ogni messaggio, quindi una chat che sposti all'interno di un progetto acquisirà le istruzioni e i file del progetto al messaggio successivo, mentre una chat che rimuovi da un progetto smetterà di utilizzarli.

Nella barra laterale, ogni riga di progetto si espande per elencare le proprie chat, con **Show all** per gli elenchi più lunghi. La sezione **Chats** elenca solo le conversazioni che non si trovano in un progetto, quindi una chat di progetto appare in un unico posto. Tre casi elencano ancora ogni chat:

- mentre stai cercando nelle conversazioni
- nella vista **Chat archiviate** del [menu dell'elenco chat](/docs/features/navigation#filter-and-sort-the-chat-list)
- quando i tuoi progetti non vengono caricati

## Gestisci Progetti [#manage-projects]

Usa il menu di un progetto nella barra laterale per:

- **Apri progetto**
- **Modifica progetto**, che apre l'area di lavoro con il nome e la descrizione pronti per essere modificati
- **Elimina** il progetto

La pagina dei progetti offre le stesse azioni di modifica ed eliminazione, e l'intestazione dell'area di lavoro dispone di un menu delle opzioni del progetto con **Delete project**.

L'eliminazione di un progetto rimuove l'assegnazione del progetto dalle sue chat. Le conversazioni in sé non vengono eliminate.

## Trova un progetto [#find-a-project]

La pagina dei progetti dispone di una casella **Search projects** che trova corrispondenze nei nomi e nelle descrizioni dei progetti, e un controllo di ordinamento che offre **Latest activity**, **Created** e **Name**. Gli elenchi più lunghi vengono paginati con **Load more**.

## Note [#notes]

- Le nuove chat avviate da un progetto mantengono tale assegnazione quando la conversazione viene creata.
- Le ricerche nei progetti non fanno distinzione tra maiuscole e minuscole e corrispondono sia ai nomi che alle descrizioni.
- Se un progetto viene eliminato mentre lo stai visualizzando, LibreChat ti riporta all'elenco dei progetti.
