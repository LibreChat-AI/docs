---

フォーク機能は、会話の一部を新しいチャットにコピーします。スレッドの途中から別の方向性を試したいときや、長い会話を別の会話に分けたいときに使用してください。元の会話はそのまま残ります。

## メッセージからフォーク [#fork-from-a-message]

メッセージにカーソルを合わせ、フォークアイコン(**Open Fork Menu**)を選択します。3つのフォークオプション、2つのチェックボックス、そして**Remember**が表示されるポップオーバーが開きます。オプションを選ぶと、すぐにフォークが実行されます。LibreChatは「Forking conversation...」と表示し、その後新しいチャットを開きます。

新しいチャットは元のタイトルを維持します。一時チャットのフォークもまた一時的です。

Assistants エンドポイントのメッセージや検索結果では、フォーク機能は利用できません。

## コピーされる内容 [#what-gets-copied]

オプションによって、どのメッセージを含めるかが決まります。「対象メッセージ」とは、ポップオーバーを開いた際に選択したメッセージのことです。

- **表示中のメッセージのみ**: 会話の開始から対象のメッセージまでの直接のパスのみで、他の分岐は含まれません。これは画面上に表示されているものです。
- **関連するブランチを含める**: 同じパスに加え、そのパスから分岐した代替ブランチ(編集および再生成)も含まれます。
- **Include all to/from here**: 対象メッセージまでのすべてのメッセージ（表示されている経路上にあるかどうかに関係なく、隣接する分岐を含む）。これがデフォルトです。

アプリ内でオプションのアイコンにカーソルを合わせると、同じ説明が表示されます。

## ここからフォークを開始し、ファイルを除外する [#start-fork-here-and-leave-out-files]

**Start fork here** では方向が反転します。ポップオーバーを開いたメッセージが起点となり、そこから会話の最新メッセージまでがフォークされます。選択したオプションに従って処理されます。

**ファイルを除外**にチェックを入れると、添付ファイルや生成されたファイルを除いてメッセージがコピーされるため、フォーク後のメッセージでそれらのファイルが再送信されなくなります。元のスレッドで大きすぎるファイルや壊れたファイルが問題を起こしている場合に使用してください。このチェックボックスの状態は記憶されません。フォークごとにチェックを入れる必要があります。

## Remember と既定のフォーク オプション [#remember-and-the-default-fork-option]

「Remember」にチェックを入れてからオプションを選ぶと、そのオプションが既定値として保存されます。以降は、フォークアイコンをクリックするとポップオーバーをスキップし、保存されたオプションで直ちにフォークされます。**Start fork here** のチェックボックスは、常に最後に設定した状態のまま維持されます。

ポップオーバーを再表示したり、保存した選択を変更したりするには、**設定**を開き、**チャット**タブに移動して、**会話**の下にあるフォーク設定を見つけてください。

- **デフォルトのフォーク オプションを使用**: オンにすると、フォークアイコンをクリックした際にデフォルトのオプションで即座にフォークされます。
- **デフォルトのフォーク オプション**: 3つのオプションのうち、どれを使用するか。上のトグルがオンの間のみ表示されます。
- **Start fork from target message by default**: **Start fork here** のデフォルト設定です。

## 共有された会話をフォークする [#forking-a-shared-conversation]

誰かが会話を共有してくれた場合、共有ページの **Continue this chat** を使うと、選択中の分岐に従って、その会話があなた自身のアカウントに分岐(フォーク)されます。詳しくは [Shareable Links](/docs/features/shareable_links#continue-a-shared-chat) を参照してください。

## セットアップ [#setup]

フォーク機能は全ユーザーが利用でき、設定は不要です。管理者は`FORK_*`変数を使用して、フォークリクエストのレート制限を設定できます。詳細は[.env リファレンス](/docs/configuration/dotenv#conversation-forking-rate-limiting)を参照してください。
