メモリは、あなたに関する事実をキーと値のペアとして保存した小さなストアで、LibreChat が新しいメッセージのたびにコンテキストへ追加します。「私は Python を書き、短い回答を好むことを覚えておいて」とモデルに一度伝えれば、次の会話でもそれを把握しています。

これは チャット履歴の検索ではありません。過去の会話の内容は、メモリエントリとして保存されたものでない限り呼び出されません。また、保存されたストア全体が各リクエストに含まれるため、メモやドキュメントではなく、少数の永続的な事実を保存するための機能です。

## メモリの保存 [#saving-a-memory]

[message composer](/docs/features/composer)の**+**をクリックしてパレットを開き、**Tools**セクションの**Memory**を選択します。これをオンにすると、モデルには`set_memory`と`delete_memory`の2つのツールが提供され、ユーザーが何かを覚える、更新する、または忘れるよう依頼した場合にのみ使用するよう指示されます。「私のチームはpnpmを使っていることを覚えて」のようなメッセージを送ると、返信に「Saved memory」というステップが表示され、そのメモリのキーがラベルとして付きます。展開すると保存された値を確認できます。「私がどこで働いているか忘れて」と送ると「Deleted memory」と表示されます。1回の返信でモデルが複数のメモリ呼び出しを行った場合は、「Ran 2 actions」のような1つのステップにまとめられます。

Memory オプションは、ロールにメモリの作成および更新が許可されている場合にのみ表示されます。エージェントとチャットしている場合、パレットには Memory オプションは表示されません。エージェントは、Agent Builder で Memory が有効になっている場合にメモリを使用します。

エージェントは **このエージェントのメモリを分離して保持する** に設定することもできます。この場合、エージェントは共有メモリや他のエージェントから隔離された独自のストアを読み書きします。これらのエントリはエージェントへのアクセス権に従います。そのエージェントへのアクセス権を失うと、分離されたメモリは読み取りも更新もできなくなりますが、削除されたエージェントのメモリは引き続き削除することができます。

一部の環境では、各やり取りを確認して、ユーザーからの指示がなくても事実を自動的に保存するバックグラウンドのメモリエージェントも動作しています。これが有効かどうかは、管理者が決めています。

## メモリの閲覧と編集 [#viewing-and-editing-memories]

サイドパネルで**Memories**を開くと、あなたについて保存されているすべての情報を確認できます。そこから次のことができます。

- キー、値、またはエージェントでリストをフィルタリングできます(「エージェントスコープのメモリ」と表示されているもの)。
- **+**(**Create Memory**)をクリックすると、手動でエントリを追加できます。キーには小文字とアンダースコアのみを使用でき、各キーは一意である必要があります。
- 任意のエントリを編集または削除できます。

管理者がサイズ上限を設定している場合、パネルには上限のうちどれだけを使用しているかが表示されます。ストアがいっぱいになると、何かを削除するまで新しい保存は「Memory Storage Full」というエラーで失敗します。個々のエントリにも文字数の上限があります。

## 自分自身のためにメモリをオフにする [#turning-memory-off-for-yourself]

The **Use memory** ボタン(メモリパネルにあるほか、**設定** > **Data & Privacy** の **Reference saved memories** としても利用可能)は、保存されたメモリを会話に追加するかどうかを制御します。オフにすると、LibreChat はメモリの追加を停止し、Memory ツールの提供も停止します。エントリは保持され、再度オンにすると戻ってきます。

このトグルは、管理者がユーザーによるオプトアウトを許可している場合にのみ表示されます。メモリはロールによって制限されることもあるため、パネルは表示されていても、エントリを作成または編集できないユーザーがいる場合があります。

## セットアップ [#setup]

メモリ機能は、管理者が`librechat.yaml`に`memory`セクションを追加するまで無効のままです。バックグラウンドのメモリエージェントは、独自のモデルを必要とする別途のオプトイン機能です。制限事項、許可されるキー、メモリエージェント、およびトラブルシューティングについては、[メモリの設定](/docs/configuration/librechat_yaml/object_structure/memory)を参照してください。
