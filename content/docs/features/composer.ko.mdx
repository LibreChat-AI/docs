메시지 작성기는 모든 채팅 하단에 있는 상자입니다. 텍스트 필드 외에도 메시지에 추가할 수 있는 모든 항목(파일, 도구, 스킬, MCP 서버 및 이전에 업로드한 파일)을 여는 **+** 버튼 하나, 현재 활성화된 도구에 대한 칩, 그리고 추론, 받아쓰기 및 전송을 위한 컨트롤이 포함되어 있습니다.

## 컴포저에 포함된 기능 [#whats-on-the-composer]

| 요소 | 기능 |
|---|---|
| **+** (**첨부 및 도구**) | 팔레트를 엽니다: 업로드 옵션, 도구, 스킬, MCP 서버 및 최근 파일을 하나의 필드에서 모두 검색할 수 있습니다. |
| 도구 칩 | **+** 버튼 옆에 활성화된 각 도구 또는 MCP 서버당 하나의 칩이 표시됩니다. 칩을 제거하여 해당 도구를 끌 수 있습니다. |
| 준비된 컨텍스트 | 다음 메시지에 첨부된 파일, 인용문 및 스킬이 텍스트 필드 위에 표시됩니다. |
| **Thinking** | 이를 지원하는 모델에 대한 추론 노력입니다. |
| 컨텍스트 사용량 | 토큰 사용량을 확인할 수 있을 때, 대화가 모델의 컨텍스트 창을 얼마나 사용하는지 보여줍니다. |
| **마이크 사용** | 음성 텍스트 변환이 활성화된 경우, 음성으로 메시지를 받아씁니다. |
| 전송 / 중지 | 메시지를 전송하거나 스트리밍 중인 응답을 중지합니다. |

`/ for prompts`, `@ for models` 또는 `Enter to send`와 같이 현재 적용되는 키를 확인하려면 **Settings > General**에서 **Show composer tips**를 켜십시오. 그러면 텍스트 필드 아래에 한 줄짜리 팁이 나타납니다. 기본값은 꺼짐(off)입니다.

![+ 팔레트가 열려 있는 컴포저, Attach 및 Tools 섹션 표시](/images/composer/composer-palette.png)

## 파일 추가 [#add-files]

**+**를 클릭하고 **Attach** 섹션에서 옵션을 선택하세요. 파일을 컴포저(composer)로 드래그하거나 붙여넣을 수도 있습니다.

기본적으로 LibreChat은 통합 업로더를 사용합니다. 사용자가 소스만 선택하면, 파일 유형과 endpoint에 따라 각 파일이 모델에 도달하는 방식(네이티브 제공업체 업로드, 텍스트 추출 또는 File Search와 같은 도구)을 시스템이 결정합니다.

| 옵션 | 표시 시점 |
|---|---|
| **From Local Computer** | 항상, 기본 업로더와 함께 표시됩니다. |
| **From SharePoint** | [SharePoint file picker](/docs/configuration/sharepoint)가 활성화되었을 때 표시됩니다. |

관리자가 [`fileConfig.legacyFileUploadUX: true`](/docs/configuration/librechat_yaml/object_structure/file_config#legacyfileuploadux)로 설정한 경우, 대신 직접 업로드 대상을 선택하게 됩니다. 그러면 **Attach** 섹션에 기본 옵션이 먼저 표시되고 나머지는 **More upload options** 뒤로 접혀서 나타납니다:

| 옵션 | 표시 시점 |
|---|---|
| **Upload to Provider** | 제공자가 문서를 직접 허용하는 경우 (예: OpenAI, Anthropic, Google, Bedrock, OpenRouter 및 사용자 지정 endpoint, 또는 Responses API가 켜진 Azure OpenAI). |
| **Upload Image** | 제공자가 이미지만 허용하는 경우 **Upload to Provider** 대신 표시됩니다. |
| **Upload as Text** | [context capability](/docs/features/upload_as_text)가 활성화된 경우. |
| **Upload for File Search** | File Search가 활성화되어 있고 현재 에이전트에서 허용되는 경우. 이를 선택하면 File Search도 켜집니다. |
| **Upload to Code Environment** | 코드 실행이 활성화되어 있고 현재 에이전트에서 허용되는 경우. 이를 선택하면 **Run Code**도 켜집니다. |
| **Attach Files** | 어시스턴트 자체 구성으로 파일을 처리하는 Assistants endpoint. |

이 모드에서 SharePoint가 활성화되면, 각 옵션에도 SharePoint 버전이 포함되며, 예를 들어 **Upload to Provider (From SharePoint)**와 같이 레이블이 지정됩니다.

### 이전에 업로드한 파일 재사용하기 [#reuse-a-file-you-uploaded-before]

팔레트의 **Your files** 섹션에는 가장 최근에 사용한 파일이 나열됩니다. 파일을 다시 업로드하지 않고 첨부하려면 하나를 선택하세요. 검색 필드에 입력하면 모든 파일을 이름으로 검색할 수 있습니다.

섹션에서 **Show all**을 선택하여 대화 상자에서 모든 파일을 탐색할 수 있습니다. 여기에는 **All**, **Images**, **Documents** 보기, 검색 필드, 그리고 이미지 및 PDF 미리보기 기능이 포함되어 있습니다.

팔레트에는 최대 5개의 최근 파일이 표시됩니다. 관리자는 [`interface.composerRecentFiles`](/docs/configuration/librechat_yaml/object_structure/interface#composerrecentfiles)를 사용하여 해당 숫자를 낮추거나 `0`으로 설정하여 목록을 숨길 수 있습니다.

## 도구, 스킬 및 MCP 서버 활성화 [#turn-on-tools-skills-and-mcp-servers]

팔레트에는 현재 대화에 대해 활성화할 수 있는 모든 항목이 섹션별로 그룹화되어 나열됩니다:

- **Tools**: **Web Search**, **Run Code**, **File Search**, **Skills**, **Memory** 및 **Artifacts**와 같은 내장 도구이며, 각 도구는 활성화되어 있고 접근 권한이 있는 경우에만 표시됩니다.
- **Skills**: 다음 메시지에 첨부할 수 있는 개별 [skills](/docs/features/skills)입니다.
- **MCP Servers**: 채팅에서 사용할 수 있는 [MCP servers](/docs/features/mcp)입니다.

도구 또는 MCP 서버를 선택하여 켜거나 끕니다. 팔레트가 열려 있으므로 한 번에 여러 개를 전환할 수 있습니다. 활성화된 각 도구는 컴포저에 칩으로 표시되며, 칩을 제거하여 끌 수 있습니다. 일부 칩에는 **Artifacts** 생성 모드와 같은 모드 메뉴가 포함되어 있습니다.

스킬을 선택하면 해당 스킬이 다음 메시지를 위해 대기 상태가 됩니다. 즉, 칩(chip) 형태가 아닌 [staged context](#staged-context)에 표시됩니다.

MCP 서버 행은 각 서버의 연결 상태를 보여줍니다. 연결되지 않은 서버를 선택하면 연결이 시작되거나(서버에 필요한 경우 OAuth 로그인 포함), 자격 증명이 필요한 경우 먼저 구성이 열립니다. 일단 연결되면 사용자 자격 증명을 사용하는 서버의 행에는 **Configure** 제어 항목이 표시되며, **Web Search**의 경우 API 키를 위한 제어 항목이 표시됩니다.

<Callout type="info" title="에이전트는 자체 도구를 가져옵니다">
  에이전트가 선택되면 **Tools** 및 **MCP Servers** 섹션은 숨겨집니다. 이는 에이전트 자체 구성이 어떤 도구를 사용할지 결정하기 때문입니다. 다른 엔드포인트에서는 `hideBadgeRow: true`가 설정된 [model spec](/docs/configuration/librechat_yaml/object_structure/model_specs#hidebadgerow)이 **Tools**, **Skills** 및 **MCP Servers** 섹션을 숨깁니다. **Attach** 및 **Your files**는 모든 경우에 계속 사용할 수 있습니다.
</Callout>

### 모두 보기 [#show-all]

팔레트는 섹션당 몇 개의 행을 보여줍니다. **Skills**, **MCP Servers** 또는 **Your files** 헤더에서 **Show all**을 선택하면 전체 목록, 검색 필드 및 필터가 포함된 대화 상자가 열립니다. Skills와 MCP 서버에는 **All**, **Made by you**, **Favorites**라는 세 가지 보기가 있습니다.

### 즐겨찾기 및 고정된 도구 [#favorites-and-pinned-tools]

행에 별표를 표시하여 **즐겨찾기(Favorites)**에 추가하면 팔레트 상단에 고정됩니다. 행이 강조 표시된 상태에서 <kbd>Ctrl</kbd>+<kbd>D</kbd>(macOS의 경우 <kbd>Cmd</kbd>+<kbd>D</kbd>)를 눌러 별표를 표시하거나 해제할 수 있습니다. 즐겨찾기는 계정에 저장됩니다.

관리자는 [`interface.defaultPinnedTools`](/docs/configuration/librechat_yaml/object_structure/interface#defaultpinnedtools)를 사용하여 내장 도구를 고정할 수 있습니다. 고정된 도구는 꺼져 있는 상태에서도 작성기(composer)에 칩이 유지되므로, 클릭 한 번으로 바로 켤 수 있습니다. 꺼져 있는 고정 도구의 칩을 제거하면 고정이 해제됩니다.

## Staged context [#staged-context]

다음 메시지에 첨부된 모든 항목은 전송하기 전에 텍스트 필드 위에 표시됩니다:

- **파일(Files)**: 업로드 진행 상황 표시 및 이미지 미리보기를 지원합니다. 길게 붙여넣은 텍스트도 파일로 저장할 수 있으며, 이를 편집하거나 다시 메시지 영역으로 옮길 수 있습니다.
- 이전 메시지에서 선택한 **인용구(Quotes)**입니다.
- 팔레트에서 선택하거나 `$` 명령어로 선택한 **Skills**.

제거 버튼을 사용하여 항목을 제거하세요. 준비된 모든 항목은 다음 메시지와 함께 전송됩니다.

## 사고 및 노력 (Thinking and effort) [#thinking-and-effort]

추론 설정이 있는 모델의 경우, **Thinking** 컨트롤을 클릭하면 **Faster**(더 빠르게)에서 **Smarter**(더 똑똑하게)까지 조절할 수 있는 슬라이더와 함께, 제공업체의 개별 모드(예: **Auto** 또는 끄기)가 표시됩니다. 이는 Parameters 패널과 동일한 매개변수를 변경하므로, 모델에 추론 설정이 없거나 배포 시 `interface.parameters`를 통해 매개변수를 비활성화한 경우에는 이 컨트롤이 숨겨집니다.

## 응답이 스트리밍되는 동안 대기열에 추가하고 제어하기 [#queue-and-steer-while-a-response-streams]

응답이 스트리밍되는 동안에도 계속 입력할 수 있습니다. endpoint 및 설정에 따라 <kbd>Enter</kbd> 키를 누르면 응답 후 전송되도록 메시지를 대기열에 추가하거나, 에이전트의 현재 응답을 유도합니다. 작성기 팁(composer tip)에는 해당 시점에 <kbd>Enter</kbd> 키가 수행하는 작업의 이름이 표시됩니다.

대기 중인 메시지는 작성기 상단의 **Queued messages** 레일에 나타나며, 여기에서 다음을 수행할 수 있습니다:

- **메시지 편집**을 클릭하여 텍스트 필드로 다시 불러옵니다.
- **Remove message**를 클릭하여 대기열에서 제거하세요.
- **Send now**를 클릭하면 대기하지 않고 즉시 전송됩니다.
- 메시지를 드래그하거나, 메시지에 포커스를 맞춘 후 위/아래 화살표 키를 눌러 순서를 변경하세요.

스티어링(steering)의 작동 방식과 사용 가능 시기에 대한 자세한 내용은 [Steering and Queued Messages](/docs/features/agents#steering-and-queued-messages)를 참조하세요.

## 키보드 단축키 [#keyboard-shortcuts]

### 텍스트 필드에서 [#in-the-text-field]

| 키 | 동작 |
|---|---|
| <kbd>Enter</kbd> | 메시지 전송 (응답이 스트리밍되는 동안 대기열에 추가하거나 조종). |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | 줄 바꿈. |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) | 응답이 스트리밍되는 동안: 대체 동작 수행. <kbd>Enter</kbd>가 대기열에 추가할 때는 **즉시 전송**, <kbd>Enter</kbd>가 조종할 때는 **대기열에 추가**. |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> (<kbd>Option</kbd>+<kbd>Enter</kbd>) | 에이전트가 응답하는 동안: 가능할 경우 중단하고 전송. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>) | 응답 중지. |
| `/` | 저장된 프롬프트 삽입. |
| `@` | 다른 모델, 프리셋 또는 에이전트로 전환. |
| `+` | 추가 응답을 위해 모델 또는 프리셋 추가. |
| `$` | 다음 메시지에 사용할 스킬 선택. |

**Press Enter to send messages** 기능을 껐다면, <kbd>Ctrl</kbd>+<kbd>Enter</kbd>(<kbd>Cmd</kbd>+<kbd>Enter</kbd>)을 눌러 메시지를 전송하고 <kbd>Enter</kbd>를 눌러 줄 바꿈을 할 수 있습니다.

### 팔레트 내 [#in-the-palette]

| 키 | 동작 |
|---|---|
| 입력 | 도구, 기술, 서버, 업로드 옵션 및 파일을 검색합니다. |
| <kbd>↑</kbd> / <kbd>↓</kbd> | 행 사이를 이동합니다. |
| <kbd>Enter</kbd> | 강조 표시된 행을 선택합니다. |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd>) | 강조 표시된 행을 즐겨찾기에 추가하거나 제거합니다. |
| 빈 검색창에서 <kbd>Backspace</kbd> | 팔레트를 닫습니다. |
| <kbd>Escape</kbd> | 팔레트를 닫습니다. |
