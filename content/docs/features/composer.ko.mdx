컴포저는 모든 채팅 하단에 있는 입력 상자입니다. 텍스트 입력란 옆에는 파일, 도구, 스킬, MCP 서버를 위한 **+** 버튼이 있고, 활성화한 도구마다 칩이 표시되며, 추론 강도, 음성 받아쓰기, 전송을 위한 컨트롤이 있습니다.

**+** 버튼을 클릭하면(스크린 리더는 이를 **Attach and tools**로 안내합니다) 팔레트가 열립니다. 팔레트의 모든 항목은 상단 입력란에서 검색할 수 있으므로, 목록을 스크롤하는 것보다 몇 글자를 입력하는 것이 보통 더 빠릅니다.

## 파일 추가 [#add-files]

**Attach** 섹션에서 **From Local Computer**를 선택하거나, 파일을 입력창(composer)으로 끌어다 놓거나, 붙여넣을 수 있습니다. LibreChat은 파일 형식과 엔드포인트에 따라 각 파일이 모델에 전달되는 방식(제공자에게 직접 전송, 텍스트로 추출, 또는 File Search를 위해 인덱싱)을 자동으로 결정하므로, 사용자는 파일의 출처만 선택하면 됩니다. 관리자가 SharePoint를 연결한 경우, 그 옆에 **From SharePoint**가 표시됩니다.

일부 배포 환경에서는 대상을 직접 선택하는 이전 업로더를 사용합니다. 이 방식에서는 **Upload to Provider**(이미지만 지원하는 공급자의 경우 **Upload Image**), **Upload as Text**, **Upload for File Search**, **Upload to Code Environment** 중에서 선택합니다. 첫 번째 옵션은 바로 표시되며, 나머지 옵션은 **More upload options** 아래에 있습니다. **Upload for File Search** 또는 **Upload to Code Environment**를 선택하면 해당 도구도 함께 활성화됩니다.

### 이전에 업로드한 파일 재사용하기 [#reuse-a-file-you-uploaded-before]

**Your files**(내 파일) 팔레트에는 가장 최근에 사용한 파일 목록이 표시됩니다(기본값은 5개). 파일을 선택하면 업로드하지 않고도 다시 첨부할 수 있습니다. 검색 필드에 입력하면 이름으로 모든 파일을 검색할 수 있으며, **Show all**(모두 보기)을 클릭하면 모든 파일이 **All**(전체), **Images**(이미지), **Documents**(문서)로 나뉜 대화 상자가 열리고, 이미지와 PDF의 미리 보기도 함께 제공됩니다.

## 도구, 스킬 및 MCP 서버 활성화 [#turn-on-tools-skills-and-mcp-servers]

**Attach** 아래에서, 팔레트는 대화에 추가할 수 있는 항목들을 그룹으로 묶어 보여줍니다:

- **도구**: **웹 검색**, **코드 실행**, **파일 검색**, **스킬**, **메모리**, **아티팩트**와 같은 내장 도구입니다. 활성화되어 있고 사용 권한이 있는 도구만 표시됩니다.
- **Skills**: 다음 메시지에 첨부할 [skills](/docs/features/skills)입니다.
- **MCP Servers**: 채팅에서 사용할 수 있는 [MCP 서버](/docs/features/mcp)와 각 서버의 연결 상태입니다.

도구 또는 MCP 서버를 선택하면 해당 항목이 켜지거나 꺼지며, 팔레트는 열린 상태로 유지되어 여러 항목을 한 번에 전환할 수 있습니다. 켜진 항목마다 입력창(composer)에 칩이 표시되며, 칩을 제거하면 해당 항목이 꺼집니다. 일부 칩에는 고유한 메뉴가 있습니다. 예를 들어 **Artifacts**의 생성 모드가 여기에 해당합니다.

스킬을 선택하는 방식은 다릅니다. 스킬은 칩으로 표시되지 않고, 다음 메시지를 위해 준비됩니다([준비된 컨텍스트](#staged-context) 참조).

MCP 서버가 아직 연결되지 않은 경우, 해당 서버를 선택하면 OAuth 로그인이 필요한 경우 이를 포함하여 연결이 시작됩니다. 사용자 고유의 자격 증명이 필요한 서버는 먼저 자격 증명을 요청하며, 이후에도 해당 행에 **Configure** 버튼이 남아 있어 자격 증명을 변경할 수 있습니다.

에이전트를 선택하면 **Tools**와 **MCP Servers** 섹션이 사라집니다. 에이전트가 사용할 도구는 에이전트 자체의 구성에 따라 결정되기 때문입니다. Assistants도 마찬가지입니다.

### 전체 보기 및 즐겨찾기 [#show-all-and-favorites]

각 섹션에는 최대 다섯 개의 행이 표시됩니다. **Skills**, **MCP Servers** 또는 **Your files** 헤더의 **Show all**을 클릭하면 검색 및 필터 기능이 있는 전체 목록이 열립니다. Skills와 서버는 **Made by you** 또는 **Favorites**로 범위를 좁힐 수 있습니다.

행을 즐겨찾기에 추가하려면 해당 행을 하이라이트한 후 <kbd>Ctrl</kbd>+<kbd>D</kbd>를 누르세요 (macOS에서는 <kbd>Cmd</kbd>+<kbd>D</kbd>). 즐겨찾기는 팔레트의 맨 위로 이동하며 사용자 계정에 저장됩니다.

관리자는 기본 제공 도구를 고정(pin)할 수도 있습니다. 고정된 도구는 꺼져 있어도 입력창에 해당 칩이 그대로 표시되므로 한 번의 클릭으로 바로 사용할 수 있습니다. 꺼져 있는 고정 도구의 칩을 제거하면 해당 도구의 고정이 해제됩니다.

## Staged context [#staged-context]

첨부한 파일은 메시지를 보내기 전에 텍스트 입력란 위에 표시됩니다.

- 파일, 업로드 진행률 및 이미지 미리보기 기능을 제공합니다.
- 긴 붙여넣기. [Upload as Text](/docs/features/upload_as_text#pasting-long-text)를 사용할 수 있는 경우, 2,500자를 초과하는 텍스트를 붙여넣으면 입력창을 채우는 대신 `pasted-text.txt` 파일로 첨부됩니다. 이를 선택하면 더 큰 대화 상자에서 텍스트를 편집할 수 있으며, **Move back into message**를 선택하면 텍스트를 다시 입력창으로 옮길 수 있습니다. **Settings > Chat**에서 **Paste long text as a file**을 끄면 이 기능을 비활성화할 수 있습니다.
- 이전 메시지에서 **채팅에 추가**(참조: [발췌문 인용](/docs/features/message_actions#quote-excerpts))를 사용해 인용한 발췌문.
- 선택한 기술(팔레트에서 선택하거나 `$`로 호출한 기술)입니다.

보내기 전에 더 이상 원하지 않는 항목은 모두 제거하세요. 남아 있는 모든 항목은 메시지와 함께 전송됩니다. 텍스트를 입력하지 않고 파일만 단독으로 보낼 수도 있습니다.

## 생각하기 [#thinking]

추론 설정이 있는 모델에서는 **Thinking** 컨트롤이 **Faster**에서 **Smarter**까지의 슬라이더와, **Auto**와 같이 제공자가 제공하는 별도 모드를 엽니다. 이 컨트롤은 파라미터 패널과 동일한 값을 변경합니다. 모델에 추론 설정이 없거나 관리자가 파라미터를 숨긴 경우에는 이 컨트롤이 표시되지 않습니다.

## 응답이 스트리밍되는 동안 대기열에 추가하고 제어하기 [#queue-and-steer-while-a-response-streams]

응답이 스트리밍되는 동안에도 계속 입력할 수 있습니다. 이때 전송 키를 누르면 동작은 **설정 > 채팅**의 **생성 중 Enter 키 동작** 기본값에 따라 달라집니다([개인 설정](/docs/features/settings#chat) 참고).

- 대기열: 메시지는 대기하다가 응답이 끝나면 전송됩니다.
- Steer: 실행 중인 응답은 도구나 추론을 취소하지 않고 다음 안전 시점에 여러분의 메시지를 반영합니다.
- 중단: 활성 도구와 추론이 취소되며, 완료된 출력은 유지되고 응답은 사용자의 메시지와 함께 계속됩니다.

에이전트에서 steering이 어떻게 동작하고 언제 사용할 수 있는지는 [Steering 및 대기열 메시지](/docs/features/agents#steering-and-queued-messages)를 참고하세요.

대기 중인 메시지는 입력창 위의 **Queued messages** 목록에서 기다립니다. 각 메시지에서 **Send now**를 눌러 바로 보내거나, **Remove message**를 눌러 삭제할 수 있습니다. **More options**를 열면 **Edit message**(메시지를 다시 텍스트 필드로 되돌림), **Start in a new chat**, 또는 **Disable Queue**(자동으로 전송되지 않도록 설정)를 선택할 수 있습니다. 메시지를 드래그하여 순서를 바꾸거나, 메시지에 포커스를 둔 뒤 위쪽 및 아래쪽 화살표 키를 사용할 수도 있습니다.

## 키보드 단축키 [#keyboard-shortcuts]

### 텍스트 필드에서 [#in-the-text-field]

이 표는 **메시지를 보내려면 Enter 누르기**가 켜져 있다고 가정합니다. 이는 기본값입니다. 이 옵션을 끄면 <kbd>Enter</kbd>는 줄바꿈을 추가하고 <kbd>Ctrl</kbd>+<kbd>Enter</kbd>는 메시지를 보냅니다.

| 키 | 동작 |
|---|---|
| <kbd>Enter</kbd> | 전송합니다. 응답이 스트리밍되는 동안에는 **While generating, Enter will** 설정에 따라 동작합니다. |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | 줄을 바꿉니다. |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) | 줄을 바꿉니다. 응답이 스트리밍되는 동안에는 다른 동작을 수행합니다. <kbd>Enter</kbd>가 대기열에 추가하도록 설정되어 있으면 즉시 전송하고, <kbd>Enter</kbd>가 방향을 바꾸거나 중단하도록 설정되어 있으면 대기열에 추가합니다. |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> (<kbd>Option</kbd>+<kbd>Enter</kbd>) | 응답이 스트리밍되는 동안, 실행 환경이 허용하는 경우 메시지로 응답을 중단합니다. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd>) | <kbd>Alt</kbd>+<kbd>Enter</kbd>와 동일합니다. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>) | 응답을 중지합니다. |
| `/` | 저장된 프롬프트를 삽입합니다. |
| `@` | 모델, 프리셋 또는 에이전트를 전환합니다. |
| `+` | 나란히 표시되는 응답을 위해 다른 모델 또는 프리셋을 추가합니다. |
| `$` | 다음 메시지에 사용할 스킬을 선택합니다. |

계정 메뉴에서 단축키를 다시 지정하거나 끌 수 있습니다. 자세한 내용은 [키보드 단축키](/docs/features/settings#keyboard-shortcuts)를 참조하세요.

### 팔레트 내 [#in-the-palette]

| Keys | Action |
|---|---|
| 입력 | 도구, 스킬, 서버, 업로드 옵션 및 파일을 검색합니다. |
| <kbd>↑</kbd> / <kbd>↓</kbd> | 행 사이를 이동합니다. |
| <kbd>Enter</kbd> | 강조 표시된 행을 선택합니다. |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd>) | 강조 표시된 행을 즐겨찾기에 추가하거나 제거합니다. |
| 빈 검색창에서 <kbd>Backspace</kbd>, 또는 <kbd>Escape</kbd> | 팔레트를 닫습니다. |

## 설정 [#setup]

Composer는 별도의 설정이 필요하지 않습니다. 관리자는 Composer에 표시되는 항목을 제어할 수 있습니다. 기존 업로더는 [`fileConfig.legacyFileUploadUX`](/docs/configuration/librechat_yaml/object_structure/file_config#legacyfileuploadux)로, 최근 파일 개수는 [`interface.composerRecentFiles`](/docs/configuration/librechat_yaml/object_structure/interface#composerrecentfiles)로, 고정된 도구는 [`interface.defaultPinnedTools`](/docs/configuration/librechat_yaml/object_structure/interface#defaultpinnedtools)로, SharePoint는 [SharePoint 통합](/docs/configuration/sharepoint)을 통해 설정할 수 있습니다. `hideBadgeRow`가 적용된 [model spec](/docs/configuration/librechat_yaml/object_structure/model_specs#hidebadgerow)은 해당 spec의 도구 섹션을 숨깁니다.
