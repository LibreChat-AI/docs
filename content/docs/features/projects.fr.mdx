Les Projects permettent à chaque utilisateur d'organiser des conversations connexes dans des espaces de travail nommés. Ils sont utiles pour les flux de travail de longue durée, les équipes, les clients, les cours ou tout sujet pour lequel vous souhaitez disposer d'un ensemble ciblé de discussions partageant le même contexte sans avoir à le répéter dans chaque conversation.

<Callout type="info" title="Disponibilité">
  Les Projets ont été ajoutés dans LibreChat **v0.8.7**. Il n'existe aucun commutateur ou autorisation de rôle permettant de masquer les Projets ; par conséquent, chaque utilisateur connecté sur une version prise en charge dispose de cette fonctionnalité. Les administrateurs peuvent ajuster les instructions, la description et les limites de fichiers avec le bloc [`projects`](/docs/configuration/librechat_yaml/object_structure/config#projects) dans `librechat.yaml`. Si vous ne trouvez pas les Projets dans l'interface, l'instance exécute une version antérieure et doit être mise à jour.
</Callout>

## Ce que font les projets [#what-projects-do]

- Regroupez les conversations dans un espace de travail nommé avec une description facultative
- Donnez à chaque chat du projet les mêmes **Instructions**
- Joindre des **fichiers** de référence que les discussions du projet peuvent rechercher
- Démarrez une nouvelle discussion déjà limitée à un projet, ou déplacez des discussions existantes vers l'intérieur ou l'extérieur
- Parcourez, triez, déplacez, supprimez ou effacez des discussions depuis l'espace de travail du projet
- Recherchez des projets par nom ou description et triez-les par activité récente, date de création ou nom

Les Projects sont personnels à l'utilisateur qui les crée. Les autres utilisateurs ne voient pas votre liste de projets, et un projet ne peut être ni partagé ni transféré. Les Projects ne conservent pas les paramètres de modèle : chaque chat conserve son propre modèle, son Agent et ses paramètres.

## Créer un projet [#create-a-project]

<Steps>
<Step>

**Ouvrez la page des projets.** Dans la barre latérale, l'en-tête de la section **Projects** contient un bouton **All projects** qui permet de l'ouvrir.

</Step>
<Step>

**Choisissez New project**, qui est toujours disponible dans l'en-tête de la page des projets.

</Step>
<Step>

**Nommez le projet.** Un nom est requis et une description est facultative. LibreChat ouvre ensuite l'espace de travail du projet.

</Step>
</Steps>

Bien que vous n'ayez pas encore de projets, la section **Projects** de la barre latérale propose également un bouton **New project**. Une fois que vous avez des projets, la section est développée par défaut jusqu'à ce que vous la réduisiez.

Les noms de projet sont limités à 100 caractères. Les descriptions sont limitées à 1 000 caractères par défaut, et les noms de projet en double sont autorisés.

La page des projets affiche chaque projet sous forme de carte de dossier avec sa description et le nombre de discussions.

## Instructions [#instructions]

Les instructions définissent le ton, les objectifs ou le contexte de chaque discussion dans le projet, par exemple le guide de style d'un client ou le cours auquel appartient un ensemble de discussions. Les règles de la plateforme et de sécurité continuent de s'appliquer en complément.

<Steps>
<Step>

**Ouvrez l'espace de travail du projet** et trouvez la section **Instructions**.

</Step>
<Step>

**Choisissez Edit** pour ouvrir la boîte de dialogue des instructions.

</Step>
<Step>

**Saisissez les instructions de l'espace de travail et enregistrez.** Par défaut, les instructions peuvent contenir jusqu'à 16 000 caractères.

</Step>
</Steps>

Les instructions sont utilisées pour les nouveaux messages dans le projet. Les modifier ne réécrit pas les messages précédents : les réponses déjà générées restent telles quelles, et le prochain message dans l'une des discussions du projet utilisera la version actuelle. Les instructions s'appliquent aux discussions classiques avec le modèle, aux Agents, ainsi qu'aux conversations avec des Assistants.

Si le projet a été modifié dans une autre session alors que la boîte de dialogue était ouverte, l'enregistrement affichera **This project was changed in another session. Reload to see the latest version.** Rechargez et réappliquez votre modification.

## Fichiers [#files]

Les fichiers de projet fournissent aux discussions du projet des documents à consulter. Lorsque la recherche de fichiers (File Search) est activée, les discussions utilisent des extraits pertinents de ces fichiers plutôt que les fichiers entiers.

Dans la section **Files** de l'espace de travail, choisissez **Add files** puis :

- **Upload from device** pour télécharger de nouveaux documents. Chaque téléchargement affiche **Processing** jusqu'à ce qu'il soit **Ready**.
- **Choisir parmi vos fichiers** pour joindre des fichiers que vous avez déjà téléchargés.

Seuls les fichiers qui ont été téléchargés pour la recherche de fichiers (pièces jointes intégrées aux messages) et qui n'ont pas expiré peuvent être joints ; par conséquent, **Choisir parmi vos fichiers** ne liste que ces fichiers-là. Un projet peut contenir jusqu'à 50 fichiers par défaut.

Les fichiers de projet sont utilisés via la recherche de fichiers (File Search), donc une discussion ne peut les lire que lorsque :

- l'Agent, ou le chat classique, a la **Recherche de fichiers** activée
- La recherche de fichiers (File Search) est activée pour l'endpoint Agents et le service de recherche de fichiers du déploiement est disponible

Un fichier supprimé ou expiré reste répertorié comme **Unavailable** et est ignoré. La suppression d'un fichier du projet affecte les messages futurs, et non l'historique des discussions.

## Travailler dans un projet [#work-in-a-project]

Ouvrez un projet pour voir sa description, ses instructions, ses fichiers et les chats qui lui sont assignés. Sélectionnez le nom ou la description du projet pour les modifier directement. La liste des **Chats** dans l'espace de travail peut être triée par date de dernière mise à jour ou par date de création.

Utilisez **New chat** dans l'en-tête de l'espace de travail pour ouvrir un compositeur limité au projet ; son badge de projet confirme que la nouvelle conversation lui sera assignée. La barre latérale affiche la même action sur chaque ligne de projet.

Les discussions appartenant à un projet affichent un badge de projet avec le nom du projet en haut de la conversation. Sélectionnez le badge pour ouvrir l'espace de travail du projet.

Chaque discussion de projet dispose d'un menu de débordement avec les actions suivantes :

- **Change project** ouvre un sélecteur de projet consultable
- **Remove from project** conserve la conversation mais supprime son affectation au projet
- **Supprimer** supprime la conversation après confirmation

## Déplacer les discussions existantes [#move-existing-chats]

Ouvrez le menu d'une conversation et choisissez **Change project**, puis sélectionnez le projet auquel l'attribuer. Pour retirer une discussion d'un projet, utilisez **Remove from project**, qui ne s'affiche que pour les discussions qui appartiennent déjà à un projet. Sur ordinateur, vous pouvez également faire glisser une discussion sur un projet dans la barre latérale ; voir [Sidebar and Navigation](/docs/features/navigation#desktop-sidebar).

Le contexte du projet est relu à chaque message ; ainsi, une discussion que vous déplacez dans un projet prend en compte les instructions et les fichiers du projet lors du message suivant, et une discussion que vous retirez d'un projet cesse de les utiliser.

Dans la barre latérale, chaque ligne de projet se développe pour lister ses propres discussions, avec **Show all** pour les listes plus longues. La section **Chats** liste uniquement les conversations qui ne sont pas dans un projet, ainsi une discussion de projet n'apparaît qu'à un seul endroit. Trois cas listent toujours toutes les discussions :

- pendant que vous recherchez des conversations
- dans la vue **Archived chats** du [menu de la liste des chats](/docs/features/navigation#filter-and-sort-the-chat-list)
- lorsque vos projets ne parviennent pas à se charger

## Gérer les projets [#manage-projects]

Utilisez le menu d'un projet dans la barre latérale pour :

- **Ouvrir le projet**
- **Modifier le projet**, qui ouvre l'espace de travail avec le nom et la description prêts à être modifiés
- **Supprimer** le projet

La page des projets offre les mêmes actions de modification et de suppression, et l'en-tête de l'espace de travail dispose d'un menu d'options de projet avec **Delete project**.

La suppression d'un projet retire l'assignation du projet de ses discussions. Les conversations elles-mêmes ne sont pas supprimées.

## Trouver un projet [#find-a-project]

La page des projets dispose d'une zone **Rechercher des projets** qui correspond aux noms et descriptions des projets, ainsi qu'un contrôle de tri proposant **Dernière activité**, **Créé le** et **Nom**. Les listes plus longues se chargent progressivement avec **Charger plus**.

## Notes [#notes]

- Les nouveaux chats démarrés à partir d'un projet conservent cette affectation lors de la création de la conversation.
- Les recherches de projets ne sont pas sensibles à la casse et correspondent à la fois aux noms et aux descriptions.
- Si un projet est supprimé pendant que vous le consultez, LibreChat vous renvoie à la liste des projets.
