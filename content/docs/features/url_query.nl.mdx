U kunt queryparameters aan een chat-URL toevoegen om het endpoint en model te kiezen, een agent of modelspecificatie te laden, de prompt in te vullen of modelinstellingen te wijzigen voordat de chat begint. Zo bouwt u een bladwijzer, een snelkoppeling in een launcher (Raycast, Alfred, een trefwoord in de browser) of een link vanuit een andere app die iemand direct in de juiste configuratie plaatst.

```
https://chat.example.com/c/new?endpoint=anthropic&model=claude-sonnet-4-5&prompt=Summarize%20this%20article
```

Parameters werken op een nieuwe chat (`/c/new`) en op een bestaande chat (`/c/<conversation-id>`). Nadat LibreChat ze heeft gelezen, verwijdert het deze uit de adresbalk, zodat het opnieuw laden van de pagina ze niet opnieuw toepast.

## Kies het endpoint en model [#pick-the-endpoint-and-model]

`endpoint` en `model` samen vormen de meest voorspelbare combinatie.

- `endpoint` alleen schakelt over naar dat endpoint en gebruikt het model dat je daar het laatst hebt gekozen, of het eerste model in de lijst.
- `model` alleen wisselt het model binnen het huidige endpoint, als dat endpoint dit ondersteunt.

Ingebouwde endpointwaarden zijn `openAI`, `azureOpenAI`, `google`, `anthropic`, `bedrock`, `agents`, `assistants` en `azureAssistants`. Voor een [aangepast endpoint](/docs/quick_start/custom_endpoints) gebruik je de naam uit je configuratie; de vergelijking is hoofdletterongevoelig, dus `endpoint=openrouter` vindt een endpoint met de naam `OpenRouter`.

## Een agent, assistent of modelspecificatie laden [#load-an-agent-assistant-or-model-spec]

```
/c/new?agent_id=agent_abc123
/c/new?assistant_id=asst_abc123
/c/new?spec=meeting-notes
```

`agent_id` en `assistant_id` stellen het endpoint voor je in. `spec` laadt een [model spec](/docs/configuration/librechat_yaml/object_structure/model_specs) op basis van zijn `name`. Alle andere instellingen in dezelfde URL worden toegepast bovenop de preset van de spec. Als je beheerder model specs afdwingt, neem dan `spec` op in elke link en houd er rekening mee dat de eigen waarden van de spec voorrang krijgen boven de URL.

## Vul de prompt in of verstuur deze [#fill-in-or-send-the-prompt]

`prompt` (of de kortere `q`) plaatst tekst in het berichtenveld. Als beide aanwezig zijn, heeft `prompt` voorrang.

Voeg `submit=true` toe om het bericht direct te verzenden zodra de chat klaar is:

```
/c/new?endpoint=openAI&model=gpt-4o&prompt=Explain%20quantum%20computing&submit=true
```

Als de gevraagde instellingen niet binnen enkele seconden kunnen worden toegepast, blijft de prompt in het berichtenveld staan in plaats van dat deze wordt verzonden. Je beheerder kan ook automatisch verzenden uitschakelen. In dat geval vult `submit=true` alleen de prompt in, en druk je zelf op verzenden.

Waarden moeten URL-gecodeerd zijn. In JavaScript doet `encodeURIComponent()` dat:

```js
const url = `/c/new?prompt=${encodeURIComponent('Write a function: def hello()')}`;
// /c/new?prompt=Write%20a%20function%3A%20def%20hello()
```

## Modelinstellingen wijzigen [#change-model-settings]

Elk van deze kan aan de URL worden toegevoegd. Elk heeft alleen effect op endpoints die dit ondersteunen, en waarden worden gecontroleerd voordat ze worden toegepast; alles wat ongeldig is, wordt zonder foutmelding genegeerd.

| Endpoint | Parameters |
| --- | --- |
| Elk | `maxContextTokens`, `resendFiles`, `promptPrefix` (aangepaste instructies) |
| OpenAI, Azure OpenAI, custom | `temperature`, `top_p`, `presence_penalty`, `frequency_penalty`, `stop`, `max_tokens`, `reasoning_effort`, `reasoning_summary`, `verbosity`, `useResponsesApi`, `disableStreaming`, `imageDetail` (`low`, `auto`, `high`) |
| OpenAI Responses API | `reasoning_mode` (`standard`, `pro`), `reasoning_context` (`auto`, `current_turn`, `all_turns`) |
| OpenAI, Anthropic, Google | `web_search` (`true`/`false`), `fileTokenLimit` (tokenlimiet voor bestandsinhoud) |
| Anthropic, Google | `temperature`, `topP`, `topK`, `maxOutputTokens`, `thinking`, `thinkingBudget`, `thinkingLevel` |
| Anthropic | `effort` (`low`, `medium`, `high`, `xhigh`, `max`), `thinkingDisplay` (`auto`, `summarized`, `omitted`, of `updates` voor alleen de voortgangsnotities tussen toolaanroepen) |
| Anthropic, Bedrock (Anthropic models), OpenRouter | `promptCache` (`true`/`false`), `promptCacheTtl` (`5m` of `1h`) |
| Google | `url_context=true` laat Gemini URL's in je bericht lezen |
| Bedrock | `region`, `maxTokens`, `temperature`, `topP`, `reasoning_effort` |
| Assistants | `instructions` (vervangt de instructies van de assistent voor deze run), `append_current_datetime=true` |

De betekenis en toegestane waarden van elk veld staan vermeld onder [model spec preset fields](/docs/configuration/librechat_yaml/object_structure/model_specs). Een waarde doorgeven die de provider afwijst (bijvoorbeeld een `max_tokens` boven de limiet van het model) geeft bij het verzenden een API-fout; start een **New chat** om dit te wissen.

## De kleurmodus instellen [#set-the-color-mode]

Als je beheerder dit inschakelt, stelt `theme=light`, `theme=dark` of `theme=system` in een link je kleurmodus in, zodat een app die naar LibreChat linkt zijn eigen thema kan doorgeven. Het wordt opgeslagen als je voorkeur totdat je dit wijzigt in de instellingen.

## Setup [#setup]

Queryparameters werken zonder extra configuratie. Beheerders kunnen met [`interface.autoSubmitFromUrl`](/docs/configuration/librechat_yaml/object_structure/interface#autosubmitfromurl) voorkomen dat `submit=true` automatisch wordt verzonden, en met [`interface.colorModeFromUrl`](/docs/configuration/librechat_yaml/object_structure/interface#colormodefromurl) de `theme`-parameter inschakelen.
