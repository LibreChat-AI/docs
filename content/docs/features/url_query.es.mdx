Puedes añadir parámetros de consulta a la URL de un chat para elegir el endpoint y el modelo, cargar un agente o una especificación de modelo (Model Specs), rellenar el prompt o cambiar la configuración del modelo antes de que comience el chat. Así es como puedes crear un marcador, un acceso directo de lanzador (Raycast, Alfred, una palabra clave del navegador) o un enlace desde otra aplicación que lleve a alguien directamente a la configuración adecuada.

```
https://chat.example.com/c/new?endpoint=anthropic&model=claude-sonnet-4-5&prompt=Summarize%20this%20article
```

Los parámetros funcionan tanto en un chat nuevo (`/c/new`) como en uno existente (`/c/<conversation-id>`). Después de que LibreChat los lee, los elimina de la barra de direcciones, por lo que al recargar la página no se vuelven a aplicar.

## Elige el endpoint y el modelo [#pick-the-endpoint-and-model]

`endpoint` y `model` juntos son la combinación más predecible.

- `endpoint` por sí solo cambia a ese endpoint y utiliza el modelo que seleccionaste por última vez en él, o el primer modelo de su lista.
- `model` por sí solo cambia el modelo dentro del endpoint actual, si ese endpoint lo tiene.

Los valores de endpoint integrados son `openAI`, `azureOpenAI`, `google`, `anthropic`, `bedrock`, `agents`, `assistants` y `azureAssistants`. Para un [endpoint personalizado](/docs/quick_start/custom_endpoints), utiliza el nombre definido en tu configuración; la comparación no distingue entre mayúsculas y minúsculas, por lo que `endpoint=openrouter` encuentra un endpoint llamado `OpenRouter`.

## Cargar un agente, asistente o especificación de modelo [#load-an-agent-assistant-or-model-spec]

```
/c/new?agent_id=agent_abc123
/c/new?assistant_id=asst_abc123
/c/new?spec=meeting-notes
```

`agent_id` y `assistant_id` establecen el endpoint por ti. `spec` carga una [especificación de modelo](/docs/configuration/librechat_yaml/object_structure/model_specs) por su `name`. Cualquier otra configuración en la misma URL se aplica encima del preset de la especificación. Si tu administrador aplica especificaciones de modelo, incluye `spec` en todos los enlaces y ten en cuenta que los valores propios de la especificación prevalecerán sobre la URL.

## Rellena o envía el prompt [#fill-in-or-send-the-prompt]

`prompt` (o el más corto `q`) coloca texto en el cuadro de mensaje. Si ambos están presentes, `prompt` tiene prioridad.

Añade `submit=true` para enviarlo en cuanto el chat esté listo:

```
/c/new?endpoint=openAI&model=gpt-4o&prompt=Explain%20quantum%20computing&submit=true
```

Si los ajustes solicitados no se pueden aplicar en pocos segundos, el prompt se queda en el cuadro de mensaje en lugar de enviarse. Tu administrador también puede desactivar el envío automático, en cuyo caso `submit=true` solo rellena el prompt y tú pulsas enviar manualmente.

Los valores deben estar codificados en URL. En JavaScript, `encodeURIComponent()` hace esto:

```js
const url = `/c/new?prompt=${encodeURIComponent('Write a function: def hello()')}`;
// /c/new?prompt=Write%20a%20function%3A%20def%20hello()
```

## Cambiar la configuración del modelo [#change-model-settings]

Cualquiera de estos parámetros puede añadirse a la URL. Cada uno solo surte efecto en los endpoints que lo admiten, y los valores se validan antes de aplicarse; cualquier valor no válido se descarta sin mostrar ningún error.

| Endpoint | Parámetros |
| --- | --- |
| Cualquiera | `maxContextTokens`, `resendFiles`, `promptPrefix` (instrucciones personalizadas) |
| OpenAI, Azure OpenAI, personalizado | `temperature`, `top_p`, `presence_penalty`, `frequency_penalty`, `stop`, `max_tokens`, `reasoning_effort`, `reasoning_summary`, `verbosity`, `useResponsesApi`, `disableStreaming`, `imageDetail` (`low`, `auto`, `high`) |
| OpenAI Responses API | `reasoning_mode` (`standard`, `pro`), `reasoning_context` (`auto`, `current_turn`, `all_turns`) |
| OpenAI, Anthropic, Google | `web_search` (`true`/`false`), `fileTokenLimit` (límite de tokens para el contenido de los archivos) |
| Anthropic, Google | `temperature`, `topP`, `topK`, `maxOutputTokens`, `thinking`, `thinkingBudget`, `thinkingLevel` |
| Anthropic | `effort` (`low`, `medium`, `high`, `xhigh`, `max`), `thinkingDisplay` (`auto`, `summarized`, `omitted`, o `updates` para mostrar solo las notas de progreso entre las llamadas a herramientas) |
| Anthropic, Bedrock (modelos de Anthropic), OpenRouter | `promptCache` (`true`/`false`), `promptCacheTtl` (`5m` o `1h`) |
| Google | `url_context=true` permite que Gemini lea las URL incluidas en tu mensaje |
| Bedrock | `region`, `maxTokens`, `temperature`, `topP`, `reasoning_effort` |
| Assistants | `instructions` (reemplaza las instrucciones del asistente para esta ejecución), `append_current_datetime=true` |

El significado y los valores permitidos de cada campo se enumeran en [campos de preajustes de especificaciones de modelo](/docs/configuration/librechat_yaml/object_structure/model_specs). Si se pasa un valor que el proveedor rechaza (un `max_tokens` por encima del límite del modelo, por ejemplo), se produce un error de API al enviar; inicie un **New chat** para borrarlo.

## Establecer el modo de color [#set-the-color-mode]

Si tu administrador lo habilita, `theme=light`, `theme=dark` o `theme=system` en un enlace define tu modo de color, de modo que una aplicación que enlace a LibreChat pueda indicar su propio tema. Se guarda como tu preferencia hasta que la cambies en la configuración.

## Configuración [#setup]

Los parámetros de consulta funcionan sin configuración. Los administradores pueden impedir que `submit=true` se envíe automáticamente mediante [`interface.autoSubmitFromUrl`](/docs/configuration/librechat_yaml/object_structure/interface#autosubmitfromurl), y habilitar el parámetro `theme` con [`interface.colorModeFromUrl`](/docs/configuration/librechat_yaml/object_structure/interface#colormodefromurl).
