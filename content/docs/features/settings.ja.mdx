アカウントメニューを開き、**Settings**(設定)を選択すると、LibreChat の個人設定やデータ管理の項目を操作できます。タブは General、Chat、Speech、Data & Privacy、Account の 5 つで、デプロイ環境によっては About も表示されます。**Search settings** を使うと、項目のラベルや関連キーワードから目的の設定を探せます。検索結果を選択すると、該当するタブとセクションが開きます。設定画面はモバイル画面にも対応しており、タブのナビゲーションは非表示になりません。

## 一般 [#general]

**Display chat title in tab** は、現在の会話タイトルをブラウザのタブタイトルとして使用します。これはデフォルトで有効になっており、現在のブラウザに保存されます。これをオフにすると、すべてのタブでデプロイメントのアプリケーションタイトルが維持されます。新しいチャットは、実際の会話タイトルが設定されるまで、アプリケーションタイトルを使用し続けます。

**Clock Format**（時計の形式）は、時刻の表示にシステムの慣習、12時間制、24時間制のいずれを使用するかを制御します。**System**（システム）を選択すると、LibreChatで選択された翻訳ではなく、現在のブラウザの地域ロケールが読み込まれます。この設定は、メッセージのタイムスタンプ、Scheduled Chat（予約チャット）のコントロールと概要、キーの有効期限や残高補充の日付、Agentやプロンプトのバージョン日付、メモリー、プロジェクトチャットリストに適用されます。

**Week Starts On** は、カレンダー形式の曜日リストをシステムの慣習に従うか、日曜日から開始するか、月曜日から開始するかを制御します。システムの慣習は、土曜日など、その地域の週の開始日に解決される場合があります。これは、スケジュールが実行される日を変更することなく、スケジュールされたチャットの曜日コントロールとサマリーの順序を変更します。

どちらの地域設定も現在のブラウザに保存されるため、デバイスごとに異なるロケールや明示的なオーバーライドを適用できます。

**Show chat beside the sidebar on mobile** は、**Layout** の下にあり、デフォルトではオフになっています。これを有効にすると、モバイルドロワーはビューポートの80%の位置で停止し、現在の会話の一部が表示された状態になります。その部分をタップすると、ドロワーが閉じます。この設定は現在のブラウザに保存されます。詳細は [Mobile Drawer](/docs/features/navigation#mobile-drawer) を参照してください。

このタブにあるその他のコントロールは、現在のブラウザに保存されます:

| 設定 | 機能 | デフォルト |
|---|---|---|
| UI scale | インターフェース全体を50%から150%の間で拡大・縮小します。ブラウザのズームには影響しません。 | 100% |
| Message Font Size | メッセージの文字サイズを、Extra Small、Small、Medium、Large、Extra Large から選択します。 | Medium |
| Chat direction | チャットの文字方向を、Auto、left to right(左から右)、right to left(右から左)から選択します。Auto の場合は入力内容から方向を判定します。 | Auto |
| Maximize chat space | 会話表示領域を広げ、画面上でより多くのスペースを確保します。 | Off |
| Center Chat Input on Welcome Screen | 新しいチャットのウェルカム画面で、入力欄を中央に配置します。 | On |
| Scroll to the end button | 最新のメッセージへ移動するボタンを表示します。 | On |
| Keep screen awake during response generation | 応答の生成中に、ブラウザが画面を暗くしたりロックしたりしないようにします。 | On |
| Show Lia on the Welcome Screen | ウェルカム画面の入力欄の周囲に、装飾用のピクセルマスコット「Lia」を表示します。デプロイ環境で許可されている場合にのみ表示されます。 | Off |

**Archived chats**は、このタブではなくアカウントメニュー内にあります。詳細は[Archived Conversations](/docs/features/navigation#archived-conversations)を参照してください。

### 通知 [#notifications]

**Notifications** セクションでは、LibreChat が別の作業をしている間に完了した応答をどのように通知するかを制御します。

- **Show unread count in the tab title** は、ブラウザのタブのタイトルとアイコンに、未読の返信がある会話の数を表示します。デフォルトでオンになっています。
- **Notify me when a reply arrives** は、デスクトップ通知を表示します。デフォルトではオフになっており、オンにするとブラウザの通知許可を求められます。チャットリストで返信を確認している間は通知は表示されず、LibreChat から離れている間のみ通知が表示されます。
- **Play a sound for new replies** は、離席中に返信が届いた際に短いチャイム音を再生します。デフォルトではオフになっています。ブラウザはページを操作するまで音声をブロックするため、タブを開いた後の最初のチャイムは再生されない場合があります。

これらの設定はデバイスごとに保存されるため、ノートパソコンとスマートフォンで異なる設定にすることができます。未読状態自体はデバイス間で同期されます（[未読の返信](/docs/features/navigation#unread-replies)を参照してください）。管理者は [`interface.replyNotifications`](/docs/configuration/librechat_yaml/object_structure/interface#replynotifications) を使用して、デプロイメント全体でこれらのいずれかを無効にすることができ、その場合、該当するトグルは非表示になります。

## チャット [#chat]

**Conversations**（会話）設定内の **Switch to Chat history on new chat**（新規チャット時にチャット履歴へ切り替える）はデフォルトでオンになっており、現在のブラウザに保存されます。Prompts（プロンプト）やMemories（メモリ）などの別のパネルが開いている状態でサイドバーから新規チャットを開始すると、サイドバーはチャットリストに戻ります。現在のパネルを維持するには、この設定をオフにしてください。

**チャットを開いたときに最新メッセージへ自動スクロール**はデフォルトで有効になっており、新しく開いた会話を最新のレンダリング済みメッセージまで移動させます。無効にすると、チャットに戻った際に現在のスクロール位置が維持されます。LibreChatは、ナビゲーションとメッセージの読み込みが異なるタイミングで完了する場合を含め、対象の会話の行がレンダリングされるまで待ってから表示位置を確定します。

**画像をアップロード前にリサイズ**を有効にすると、ブラウザー上で大きな JPEG、PNG、WebP ファイルを送信前に縮小できます。この設定はデフォルトでオンになっており、現在のブラウザーに保存されます。

管理者は、これが個人の選択のままかどうかを制御できます。[`fileConfig.clientImageResize.enabled`](/docs/configuration/librechat_yaml/object_structure/config#clientimageresize) が明示的に `true` または `false` に設定されている場合、LibreChatはその値を強制し、ユーザーの切り替えをロックします。このフィールドが省略された場合、ユーザーの設定が適用されます。

**Paste long text as a file** はデフォルトで有効になっており、現在のブラウザに保存されます。Upload as Text コンテキストのアップロードが利用可能な場合、通常のメッセージコンポーザーで2,500文字を超えるテキストを貼り付けると、入力欄に記入される代わりに `pasted-text.txt` としてテキストが添付されます。短い貼り付けや `context` 機能なしで行われた貼り付けは、インラインのままとなります。詳細は [Upload Files as Text](/docs/features/upload_as_text#paste-long-text-as-a-file) を参照してください。

**長いユーザーメッセージを折りたたむ**はデフォルトで有効になっています。有効にすると、高さが256ピクセルを超えるユーザーメッセージは、**Show more**(さらに表示)と**Show less**(折りたたむ)のコントロールを備えた簡略化されたプレビューとして表示されます。この折りたたみは表示上のみのもので、メッセージ全体はコピー、ブラウザ内検索、支援技術からも引き続き利用できます。

**メッセージ内のLaTeX解析**はデフォルトで有効になっています。このトグルは、`$50`のような通貨風のテキストをリテラルとして保持する境界ルールに従う、曖昧なシングルダラー形式のインライン数式 `$...$` を制御します。トグルがオフの場合でも、曖昧さのない `$$...$$`、`\(...\)`、および `\[...\]` 形式の数式は引き続きサポートされます。インラインコード、フェンスコード、および自動リンクは、シングルダラー形式の数式としては解釈されません。

送信キーについては、[コンポーザー](/docs/features/composer#keyboard-shortcuts)で説明しています。このタブのその他のコントロールは、現在のブラウザに保存されます:

| 設定 | 機能 | デフォルト |
|---|---|---|
| Press Enter to send messages | オンの場合、Enter で送信します。オフの場合、Enter で改行を挿入し、Ctrl/Cmd+Enter で送信します。 | オン |
| While generating, Enter will | 応答のストリーミング中に送信が何をするかを指定します: Steer、Interrupt、Queue のいずれか。[Steering and Queued Messages](/docs/features/agents#steering-and-queued-messages) を参照してください。 | Steer |
| Save drafts locally | 未送信のテキストと添付ファイルをこのデバイス上に下書きとして保存し、メッセージが送信されると削除します。 | オン |
| Save badges state | チャットバッジ (ツール) を、リセットせず新しいチャットを開始したときの状態のまま保持します。 | オフ |
| Toggle command "@" for switching endpoints, models, presets, etc. | `@` コマンドのオン/オフを切り替えます。 | オン |
| Toggle command "+" for adding a multi-response setting | `+` コマンドのオン/オフを切り替えます。複数応答が利用可能な場合にのみ表示されます。 | オン |
| Toggle command "/" for selecting a prompt via keyboard | `/` コマンドのオン/オフを切り替えます。プロンプトが利用可能な場合にのみ表示されます。 | オン |
| Render user messages as markdown | 自分のメッセージを Markdown としてレンダリングします。 | オン |
| Display username in messages | メッセージの上に「You」の代わりにユーザー名を表示します。 | オン |
| Open Thinking Dropdowns by Default | モデルの推論ブロックを折りたたまずに、デフォルトで展開します。 | オフ |
| Auto-expand tool details | ツール呼び出しの詳細をデフォルトで展開します。 | オフ |
| Advanced prompts editor | プロンプトのバージョン管理と本番環境の制御を有効にします。 | オフ |
| Always make new prompt versions production | 新しいプロンプトのバージョンを、常に本番バージョンとして設定します。Advanced prompts editor をオフにすると、この設定はオンに戻ります。 | オン |
| Send prompts on select | プロンプトを選択すると、すぐにチャットに送信します。 | オン |
| Enable switching Endpoints mid-conversation | 1 つの会話の中でエンドポイントやモデルを変更できるようにします。 | オン |

音声入力と再生は**Speech**タブで行います。詳しくは[Speech Settings](/docs/configuration/stt_tts)を参照してください。

## モデルパラメータ [#model-parameters]

サイドパネルにあるモデルの**Parameters**パネルでは、会話の設定が**Identity**、**Sampling**、**Limits**、**Reasoning**、**Context**、**Advanced**、**Misc.**という見出しの下にグループ化されています。現在のendpointで使用されるセクションのみが表示され、カスタムendpoint独自のパラメータなど、パネルが認識しない設定は**Misc.**の下にリストされます。各見出しには、そのセクションで変更された設定の数が表示されるため、**Reset**を選択する前に何が変更されたかを確認できます。**Reset**と**Save As Preset**はパネルの下部に並んで配置されています。[Presets](/docs/user_guides/presets)を参照してください。

## キーボードショートカット [#keyboard-shortcuts]

アカウントメニューから **Keyboard Shortcuts** を開き、キーバインドの確認やカスタマイズを行います。**Keyboard Shortcuts** スイッチはデフォルトで有効になっています。これをオフにすると、すべてのショートカットが無効になり、インターフェースからショートカットのヒントが削除されますが、カスタムバインドは保持されます。ショートカットを再度有効にするには、アカウントメニューから同じダイアログを開いてください。

ショートカットの有効化とカスタムバインディングは、現在のブラウザに保存されます。ショートカットがオフの間もバインディングの行は表示されたままですが、ショートカットを再度有効にするまで、編集およびリセットのコントロールは無効化されたままとなります。

## データとプライバシー [#data--privacy]

**データとプライバシー**タブは、次のセクションに分かれています。

- **メモリ**: **保存されたメモリを参照**を有効にすると、アシスタントは応答時に保存されたメモリを利用できます。これはアカウントに保存され、お使いの環境でメモリの設定が適用される場合にのみ表示されます。
- **コード実行**: **デフォルトのステートフルワークスペース**では、新規作成されるエージェントに提案されるワークスペースのスコープを選択します。この項目は、ステートフルコードセッションが利用可能な場合にのみ表示されます。変更してもステートフルセッションは有効になりませんし、既存のエージェントも変更されません。**コード環境**は、同じ利用条件のもとで、お客様が管理する VM 上で動作するサンドボックス化されたワーカーを組み合わせます。
- **Your data**: **Manage files** でアップロード済みファイルのマネージャーを開きます。**Import conversations** では対応しているエクスポート形式の会話をインポートします。**Shared chats** では公開済みの会話リンクを一覧表示し、管理できます。**Archive all chats** は確認後にアクティブな会話を削除することなく **Archived chats** へ移動します。**Allow analytics** は分析に関するプロンプトへの回答を変更するもので、デプロイメントで分析が設定されている場合にのみ表示されます。
- **APIキー**: **プロバイダーAPIキー**では、構成済みプロバイダーに対して提供されたキーを管理します。これはエンドポイントがユーザー提供のキーを使用する場合にのみ表示されます。**エージェントAPIキー**では、Agents APIのキーを管理します。これはリモートエージェントが利用可能な場合にのみ表示されます。**すべてのプロバイダーAPIキーを取り消す**を選択すると、ユーザーが提供したすべてのプロバイダーキーが削除されます。
- **危険な操作**: **キャッシュを削除**は、ブラウザに保存されている音声読み上げ（テキスト読み上げ）の音声データを削除します。キャッシュが空の場合は利用できません。**すべてのチャットを削除**は、確認後にユーザーの会話をすべて完全に削除します。

データ削除およびキー取り消しのアクションはサーバー側で実行され、元に戻せない場合があります。ブラウザのみの設定やキャッシュは、すべてのデバイスではなく、現在のブラウザプロファイルにのみ適用されます。

## アカウント [#account]

**Account**タブには、プロフィール、セキュリティ、請求、削除に関する設定が含まれています。デプロイ環境によっては、対応している場合にのみ表示される項目もあります。

| 設定 | 機能 |
|---|---|
| アバター | プロフィール画像を変更します。 |
| バックアップコード | 2要素認証のバックアップコードを表示および再生成します。2要素認証が有効な場合にのみ表示されます。 |
| トークン残高 | トークンクレジットを表示します。残高追跡が有効な場合にのみ表示されます。 |
| 自動チャージ | 自動残高チャージの表示または設定を行います。残高追跡が有効な場合にのみ表示されます。 |
| アカウント削除 | アカウントとデータを完全に削除します。デプロイメントでアカウント削除が許可されている場合にのみ表示されます。 |
