title: 個人設定
icon: Settings
description: ユーザーが自分で変更できる設定項目です。テーマやフォントサイズから、送信時の動作、通知、キーボードショートカットまで含まれます。
---

アカウントメニューを開き、**設定**を選択してください。設定ダイアログには、**一般**、**チャット**、**音声**、**データとプライバシー**、**アカウント**のタブがあり、デプロイによっては**Langfuse**と**バージョン情報**も表示されます。設定したい内容がおおよそわかっている場合は、**設定を検索**に入力してください。ラベルや関連する語句(「dark」「rtl」「paste」など)に一致し、該当するタブとセクションに直接移動します。

ほとんどの設定は、アカウントではなく現在のブラウザに保存されます。ノートパソコンで変更した設定は、スマートフォンには反映されません。例外は以下に記載しています。

## 一般 [#general]

| 設定 | 機能 | デフォルト |
|---|---|---|
| テーマ | **システム**、**ライト**、**ダーク**、またはハイコントラストのライトまたはダークテーマ。 | システム |
| 言語 | インターフェースの言語。 | ブラウザの言語 |
| メッセージのフォントサイズ | メッセージの文字サイズ。**極小**から**極大**まで。 | 中 |
| UI スケール | ブラウザのズームとは独立して、インターフェース全体を 50% から 150% の間で拡大縮小します。 | 100% |
| チャットの方向 | **自動**、左から右、または右から左。 | 自動 |
| 時計の形式 | システム、12 時間制、または 24 時間制。メッセージ、スケジュール、日付全体に適用されます。 | システム |
| 週の開始曜日 | システム、日曜日、または月曜日。[スケジュールされたチャット](/docs/features/scheduled_chats)内の曜日の並び順を変更します。スケジュールの実行タイミングは変更されません。 | システム |
| チャット領域を最大化 | 会話の列を広げます。 | オフ |
| ウェルカム画面でチャット入力を中央に配置 | 新しいチャットで、メッセージボックスを画面の中央に配置します。 | オン |
| ウェルカム画面に Lia を表示 | メッセージボックスの周りに表示される小さな装飾用のピクセルマスコット。デプロイ環境で許可されている場合にのみ表示されます。 | オフ |
| 最新メッセージへスクロールボタン | 最新のメッセージへ直接移動するボタン。 | オン |
| モバイルでサイドバーの横にチャットを表示 | [モバイルドロワー](/docs/features/navigation#mobile-drawer)の横に会話の一部を表示したままにします。その部分をタップするとドロワーが閉じます。 | オフ |
| タブにチャットタイトルを表示 | 会話のタイトルをブラウザのタブのタイトルとして使用します。 | オン |
| 応答生成中は画面をスリープさせない | 返信のストリーミング中、ブラウザが画面を暗くしたりロックしたりしないように要求します。 | オン |

管理者の場合、デプロイ環境に管理パネルがあれば、ここに **Admin Panel** へのリンクも表示されます。

### 通知 [#notifications]

これらは、別のチャットや別のタブにいる間に完了した返信についての通知方法を制御します。

- **タブのタイトルに未読数を表示** チャットに未読の返信がある件数をタブのタイトルとアイコンに表示します。デフォルトで有効です。
- **返信が届いたときに通知する** をオンにすると、デスクトップ通知が表示されます。デフォルトではオフです。初めてオンにすると、ブラウザから通知の許可を求められます。LibreChat を表示している間は、通知は表示されません。
- **新しい返信の通知音を再生**を有効にすると、短いチャイム音が鳴ります。初期設定ではオフになっています。ブラウザは、ページをクリックするまで音声の再生をブロックするため、タブを開いてから最初のチャイム音は鳴らないことがあります。

トグルはデバイスごとに設定されます。未読状態そのものはアカウントに保存されます(詳細は[未読の返信](/docs/features/navigation#unread-replies)を参照してください)。これらのトグルのいずれかが表示されない場合、管理者が[`interface.replyNotifications`](/docs/configuration/librechat_yaml/object_structure/interface#replynotifications)によって無効にしています。

## チャット [#chat]

| 設定 | 機能 | デフォルト |
|---|---|---|
| Enter キーでメッセージを送信 | オフにすると、Enter で改行が追加され、<kbd>Ctrl</kbd>+<kbd>Enter</kbd>(macOS では <kbd>Cmd</kbd>+<kbd>Enter</kbd>)で送信されます。 | オン |
| 生成中の Enter の動作 | 返信がストリーミング中に送信した場合の動作を指定します: **Steer**、**Interrupt**、または **Queue**。詳しくは [Composer](/docs/features/composer) を参照してください。 | Steer |
| 下書きをローカルに保存 | 送信されるまで、未送信のテキストと添付ファイルをこのデバイスに保持します。 | オン |
| アップロード前に画像をリサイズ | アップロードする前に、大きな JPEG、PNG、WebP 画像をブラウザ上で縮小します。 | オン |
| 長いテキストの貼り付けをファイルとして添付 | 非常に長い貼り付けテキストをメッセージボックスに入力する代わりにテキストファイルとして添付します。詳しくは [Upload as Text](/docs/features/upload_as_text) を参照してください。 | オン |
| バッジの状態を保存 | 新しいチャットで、前回のチャットのツールバッジをリセットせずに保持します。 | オフ |
| コマンド "@" / "+" / "/" の切り替え | `@`(モデルまたはエンドポイントの切り替え)、`+`(並列応答の追加)、`/`(プロンプトの挿入)のコマンドを有効または無効にします。`+` と `/` は、対応する機能が利用可能な場合にのみ表示されます。 | オン |
| ユーザーメッセージを Markdown としてレンダリング | 自分のメッセージを Markdown 形式で整形します。 | オン |
| 長いユーザーメッセージを折りたたむ | 送信した長いメッセージは **Show more** 付きのプレビューとして表示されます。全文はコピーや検索のためにページ上に残ります。 | オン |
| メッセージにユーザー名を表示 | 「You」の代わりに、自分のメッセージの上に名前を表示します。 | オン |
| メッセージ内の LaTeX を解析 | 数式をレンダリングします。オフにすると `$...$` のインライン数式は表示されなくなりますが、`$$...$$`、`\(...\)`、`\[...\]` は引き続きレンダリングされます。 | オン |
| 思考ドロップダウンをデフォルトで開く | モデルの推論を折りたたまずに展開します。 | オフ |
| テキストのスムーズなストリーミング | 返信がストリーミングされる際に、新しい単語をフェードインで表示します。詳しくは [Smooth Streaming](/docs/features/smooth_streaming) を参照してください。 | オン |
| メッセージをリッチテキストとしてコピー | メッセージをコピーすると、Word、Outlook、Teams に貼り付けるための書式付きバージョンもクリップボードに保存されます。 | オフ |
| ツールの詳細を自動展開 | デフォルトでツール呼び出しの詳細を開きます。 | オフ |
| 新しいチャットで「チャット履歴」に切り替え | プロンプト、メモリ、または他のパネルが開いている状態で新しいチャットを開始すると、サイドバーがチャットの一覧に戻ります。 | オン |
| チャットを開いたときに最新のメッセージに自動スクロール | チャットを最新のメッセージの位置で開きます。オフにすると、戻ってきたときに前回の位置を維持します。 | オン |
| 会話の途中でエンドポイントの切り替えを有効化 | 1 つの会話内でモデルまたはエンドポイントを変更できます。 | オン |
| デフォルトで一時チャット | 新しいチャットを [一時チャット](/docs/features/temporary_chat) として開始します。 | オフ |
| デフォルトの分岐オプションを使用 | 分岐メニューを省略し、ここで選択したオプションを常に使用します。詳しくは [Forking](/docs/features/fork) を参照してください。 | オフ |
| 高度なプロンプトエディター | プロンプトのバージョン管理と本番ラベルを有効にします。 | オフ |
| 新しいプロンプトのバージョンを常に本番として設定 | 新しいプロンプトのバージョンを、使用中のバージョンとしてマークします。 | オン |
| 選択時にプロンプトを送信 | プロンプトを選択するとすぐに送信します。 | オン |

**アップロード前に画像をリサイズ**は固定される場合があります。管理者が[`fileConfig.clientImageResize.enabled`](/docs/configuration/librechat_yaml/object_structure/config#clientimageresize)を設定すると、トグルは無効になり、その値に従います。

## 音声 [#speech]

**Speech to Text**と**Text to Speech**のオン/オフを切り替え、エンジン、言語、音声を選択し、再生速度を設定して、返信を自動再生するかどうかを選べます。表示されるエンジンは、デプロイメントでどのように設定されているかによって異なります。詳しくは[Speech to Text and Text to Speech](/docs/configuration/stt_tts)を参照してください。

## データとプライバシー [#data--privacy]

- **メモリ**: **保存されたメモリを参照**を有効にすると、アシスタントが[メモリ](/docs/features/memory)を利用できるようになります。アカウントに保存されるため、どのデバイスでも適用されます。
- **コード実行**: デプロイ環境がステートフルなコードセッションを提供している場合の**既定のステートフルワークスペース**と**コード環境**。
- **Your data**: **Import conversations**、**Shared chats**([共有リンク](/docs/features/shareable_links)を管理)、**Manage files**、**Archive all chats**、および(デプロイメントが分析データを収集している場合は)**Allow analytics**。**Archive all chats** は、削除することなく、アクティブなすべてのチャットを[Archived chats](/docs/features/navigation#archived-conversations)に移動します。
- **API キー**: エンドポイントで独自のキーを要求する場合の**プロバイダー API キー**、Agents API 用の**エージェント API キー**、そして**すべてのプロバイダー API キーを取り消す**。
- **危険ゾーン**: **キャッシュを削除**を選択すると、このブラウザにキャッシュされた音声読み上げ（text-to-speech）の音声データが削除されます。**すべてのチャットを削除**を選択すると、会話が完全に削除されます。

## アカウント [#account]

**アバター**、そして電子メールによるログインが許可されている場合は**メールアドレス**。**セキュリティ**の下には、**二要素認証**、二要素認証を有効にした後に表示される**バックアップコード**、そしてデプロイ環境が対応している場合の**パスキー**があります。**プルリクエストアカウント**では、[プルリクエスト](/docs/features/pull_requests)のために GitHub や他の git ホストを接続できます。**トークン残高**と**自動補充**は、デプロイ環境が残高を追跡している場合に表示され、**アカウントの削除**は、ユーザーが自分自身を削除することを許可している場合に表示されます。

## キーボードショートカット [#keyboard-shortcuts]

アカウントメニューを開き、**ヘルプ**、続けて**キーボードショートカット**を選択します(または <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>/</kbd> を押します)。行をクリックすると新しいキーの組み合わせを記録できます。組み合わせには <kbd>Cmd</kbd>、<kbd>Ctrl</kbd>、<kbd>Alt</kbd> のいずれかを含める必要があり、別の操作ですでに使用されている場合は LibreChat が警告します。**すべてをデフォルトにリセット**を選択すると、変更内容が元に戻ります。**パネルを開く**の下にある行(エージェント、プロンプト、メモリ、パラメータ、ファイル、ブックマーク、MCP 設定)は、キーを割り当てるまでキーが設定されていません。

上部にある**キーボードショートカット**スイッチをオフにすると、すべてのショートカットが無効になり、インターフェースのヒントも非表示になります。カスタマイズしたキーは保持されるため、再びオンにすると元に戻ります。スイッチとキーの割り当ての両方は、このブラウザに保存されます。

デフォルトのキーバインド(macOSでは<kbd>Ctrl</kbd>の代わりに<kbd>Cmd</kbd>を使用):

| 操作 | キー |
|---|---|
| キーボードショートカットを表示 | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>/</kbd> |
| 新しいチャット | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> |
| チャット入力欄にフォーカス | <kbd>Shift</kbd>+<kbd>Esc</kbd> |
| 最後の応答をコピー | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>;</kbd> |
| ファイルをアップロード | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>U</kbd> |
| メッセージを送信 | <kbd>Ctrl</kbd>+<kbd>Enter</kbd>(**Press Enter to send messages** がオフの場合のみ送信されます) |
| サイドバーの表示切替 | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> |
| モデルセレクターを開く | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> |
| 検索にフォーカス | <kbd>Ctrl</kbd>+<kbd>/</kbd> |
| 設定 | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>,</kbd> |
| 会話をブックマーク | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> |
| 生成を停止 | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> |
| 今すぐ割り込む | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>.</kbd> |
| 応答を再生成 | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> |
| 最後のメッセージを編集 | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> |
| 最後のコードブロックをコピー | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd> |

| 末尾にスクロール | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>↓</kbd> |

| 会話をアーカイブ | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd> |

| 応答を続ける | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> |
