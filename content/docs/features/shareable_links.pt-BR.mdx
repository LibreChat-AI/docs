Links compartilháveis permitem que você publique uma versão somente leitura de uma conversa que outros podem abrir por meio de uma URL gerada ou código QR. Os destinatários veem as mensagens publicadas, ramificações e artefatos sem alterar o original. Destinatários conectados podem continuar a partir da ramificação visível como uma cópia pessoal.

## Principais Recursos [#key-features]

- **Compartilhamento fácil**: Gere um link com apenas alguns cliques.
- **QR codes**: Abra a conversa em um celular escaneando um código.
- **Ramificação**: Links compartilhados mantêm cada ramificação da conversa.
- **Artifacts**: componentes React, visualizações HTML e diagramas Mermaid permanecem interativos.
- **File snapshots**: Arquivos de conversa referenciados podem ser visualizados ou baixados a partir do link compartilhado sem conceder aos destinatários acesso à ACL de arquivos ativos do proprietário.
- **Continue como uma cópia**: Usuários autenticados podem copiar o branch visível para seu próprio histórico de conversas e continuar conversando.
- **Preferências do destinatário**: Os visualizadores podem alternar o idioma e o tema.
- **Atualizações estáveis**: Publica turnos mais recentes e a escolha de arquivo atual sem alterar a URL.
- **Shared badges**: Links ativos são marcados na lista de conversas e no cabeçalho do chat.
- **Gerenciamento de links**: Um painel para revisar ou revogar todos os links que você criou.

## Opções de Link de Compartilhamento [#share-link-options]

Criar um link abre um modal onde você controla como a conversa aparece para os destinatários.

![Modal de criação de link de compartilhamento](/images/shared-links/share-modal-create.png)

![Modal de link de compartilhamento com opções de gerenciamento](/images/shared-links/share-modal-options.png)

Assim que um link existir, o modal oferece estas ações:

- **Link de atualização**: Republicar as mensagens mais recentes através do final da ramificação selecionada e da escolha atual de compartilhamento de arquivos, mantendo a mesma URL.
- **Mostrar QR Code** / **Ocultar QR Code**: Alterna a exibição de um QR code para acesso pelo celular.
- **Copiar link**: Copie a URL compartilhável.
- **Gerenciar acesso**: Abra a caixa de diálogo de acesso para controlar quem pode abrir o link. Ela aparece apenas quando sua função tem a permissão de compartilhamento para links compartilhados e você possui a permissão de compartilhamento nesse link.
- **Excluir Link**: Remove o link e revoga o acesso de todos que o possuem.

Quando os snapshots de arquivos estão habilitados, os usuários podem escolher se o link inclui arquivos referenciados nas mensagens publicadas. Os arquivos selecionados são fixados naquela revisão de compartilhamento e servidos por meio de rotas específicas de compartilhamento, sem conceder acesso à ACL de arquivos ativos do proprietário. Atualizar o link substitui o conjunto fixado e a escolha de compartilhamento de arquivos; URLs de arquivos estáveis são revalidadas para que um snapshot removido ou substituído não seja servido a partir de um cache de navegador antigo.

A publicação está vinculada ao final persistido exato do branch selecionado. Se a mensagem mais recente ainda estiver sendo salva, o LibreChat tenta novamente uma vez sem alternar para outro branch. Se o final ainda estiver indisponível, ou se a conversa ainda não tiver mensagens persistidas, o modal exibirá um erro específico para que você possa aguardar e tentar novamente. Uma visualização de link compartilhado indisponível também oferece a opção **Retry** para buscar a mesma URL novamente.

## Códigos QR [#qr-codes]

Gere um QR code para qualquer conversa compartilhada e, em seguida, escaneie-o com a câmera do celular para abrir o link. O código aponta para a mesma URL compartilhada.

![QR code gerado para um link compartilhado](/images/shared-links/qr-code.png)

![Opções de download do QR code](/images/shared-links/qr-code-download.png)

QR codes são úteis para apresentações, acesso móvel rápido, folhetos impressos e demonstrações em conferências.

![Uma conversa compartilhada como um destinatário a vê](/images/shared-links/shared-view.png)

## Continuar uma Conversa Compartilhada [#continue-a-shared-conversation]

Um visualizador autenticado pode selecionar **Continue this chat** para criar uma conversa pessoal a partir da ramificação exibida no momento. O LibreChat copia apenas o caminho direto para a mensagem ativa, incluindo referências de arquivos instantâneos elegíveis, e abre a nova conversa na conta do visualizador.

Continuar nunca altera o snapshot compartilhado ou a conversa do proprietário. Visualizadores públicos devem fazer login antes que o LibreChat possa criar a cópia deles.

A solicitação de cópia está vinculada à revisão compartilhada que o visualizador carregou. Se o proprietário atualizar o mesmo link antes que o visualizador continue, o LibreChat recarrega a revisão atual e solicita que o visualizador tente novamente, em vez de copiar posições de mensagens de conteúdo desatualizado.

## Ramificação [#branching]

Links compartilhados preservam as ramificações da conversa, para que os destinatários possam seguir os diferentes caminhos que a discussão tomou. Use as setas de navegação de ramificação para alternar entre eles.

![Menu de navegação de ramificação em uma conversa compartilhada](/images/shared-links/branching-menu.png)

![Navegando por ramificações em uma conversa compartilhada](/images/shared-links/branching-support.png)

Isso é útil para mostrar como diferentes prompts levam a diferentes respostas da IA, ou como um único problema pode ser abordado de várias maneiras.

## Artifacts [#artifacts]

Artifacts gerados durante a conversa permanecem totalmente funcionais em links compartilhados.

![Artefatos interativos em uma conversa compartilhada](/images/shared-links/artifacts-support.png)

Os destinatários podem:

- Visualize componentes React interativos.
- Veja as visualizações em HTML.
- Examine os diagramas Mermaid.
- Leia o código subjacente e o contexto em que ele foi gerado.

## Preferências do Destinatário [#recipient-preferences]

Os visualizadores podem ajustar a interface de acordo com suas próprias preferências sem afetar suas configurações.

![Configurações de idioma e tema em um link compartilhado](/images/shared-links/recipient-settings.png)

- **Tema**: Claro, escuro ou do sistema.
- **Idioma**: Visualize a interface no seu idioma de preferência.

## Gerenciando seus Links Compartilhados [#managing-your-shared-links]

Abra o painel **Shared chats** em **Settings > Data & Privacy > Your data > Shared chats** para revisar todas as conversas que você compartilhou.

![Painel de gerenciamento de links compartilhados](/images/shared-links/management-modal.png)

![Detalhes e opções para um link compartilhado individual](/images/shared-links/management-details.png)

A partir do painel, você pode:

- **Ver todos os links**: Veja todas as conversas que você compartilhou.
- **Pesquisar e filtrar**: Encontre um link compartilhado específico e visualize seu conteúdo.
- **Revogar acesso**: Exclua um link para interromper o compartilhamento imediatamente.

Conversas com um link compartilhado ativo também exibem um selo de link na barra lateral, e o controle de compartilhamento no cabeçalho do chat mostra o mesmo estado ativo.

## Configuração [#configuration]

Três variáveis de ambiente no seu arquivo `.env` controlam o recurso:

- **`ALLOW_SHARED_LINKS`** (padrão: `true`): Habilita o recurso de links compartilhados. Defina como `false` para impedir que os usuários criem links.
- **`ALLOW_SHARED_LINKS_PUBLIC`** (padrão: `false`): Controla se os links abrem sem autenticação. Por padrão, os destinatários devem estar logados. Defina como `true` para permitir acesso público e não autenticado.
- **`SHARED_LINKS_SNAPSHOT_FILES`** (padrão: `true`): Controla se os links compartilhados podem incluir arquivos de conversa referenciados. Esta variável de ambiente substitui [`interface.sharedLinks.snapshotFiles`](/docs/configuration/librechat_yaml/object_structure/interface#sharedlinks) quando definida.

```bash title=".env"
# Enable shared links (default)
ALLOW_SHARED_LINKS=true

# Require authentication to view shared links (default)
ALLOW_SHARED_LINKS_PUBLIC=false

# Include referenced files in shared-link snapshots (default)
SHARED_LINKS_SNAPSHOT_FILES=true
```

As permissões de função decidem quais usuários podem criar links, compartilhá-los com usuários autenticados ou torná-los visíveis para todos na instância:

```yaml title="librechat.yaml"
interface:
  sharedLinks:
    create: true
    share: true
    public: false
    snapshotFiles: true
```

`sharedLinks.public` controla se um usuário pode alternar a opção "compartilhar com todos". `ALLOW_SHARED_LINKS_PUBLIC` ainda decide se esses links públicos são visíveis sem a necessidade de login. `sharedLinks.snapshotFiles` controla o comportamento padrão de snapshot de arquivos a partir do YAML, e `SHARED_LINKS_SNAPSHOT_FILES` pode substituir ou desativá-lo globalmente.

<Callout type="info">
Para a referência completa de variáveis de ambiente, consulte a página [.env Configuration](/docs/configuration/dotenv#shared-links).
</Callout>

## Perguntas Frequentes [#frequently-asked-questions]

<Accordions type="single" collapsible>
<Accordion title="Os destinatários podem responder a conversas compartilhadas?">

O snapshot compartilhado permanece somente leitura. Destinatários conectados podem selecionar **Continue this chat** para criar uma cópia pessoal e interagir com a IA a partir dela.

</Accordion>
<Accordion title="O que acontece se eu excluir uma conversa após compartilhá-la?">

O link para de funcionar. Qualquer pessoa que navegue até ele verá uma página "Shared link not found".

</Accordion>
<Accordion title="Posso editar uma conversa após compartilhá-la?">

Sim. Edições em mensagens já incluídas no link aparecem na visualização compartilhada. Novos turnos fora do final da ramificação publicada aparecem apenas após você selecionar **Update link**; a URL permanece a mesma.

</Accordion>
<Accordion title="Links compartilhados funcionam offline?">

Não. Os destinatários precisam de uma conexão com a internet para visualizar conversas compartilhadas.

</Accordion>
</Accordions>
