Proyek adalah sebuah folder untuk percakapan yang saling berkaitan, seperti untuk klien, kursus, atau pekerjaan besar yang panjang. Chat dalam sebuah proyek berbagi instruksi milik proyek tersebut dan dapat memanfaatkan file referensinya, sehingga Anda cukup menetapkan konteks sekali saja tanpa perlu mengulanginya di setiap chat baru.

Proyek bersifat pribadi. Tidak ada orang lain yang dapat melihat proyek Anda atau chat mana saja yang ada di dalamnya, dan sebuah proyek tidak dapat dibagikan atau dialihkan kepada orang lain. Proyek tidak menentukan model: setiap chat tetap memiliki model, agent, dan parameter masing-masing.

## Membuat proyek [#create-a-project]

Di sidebar, header bagian **Projects** memiliki tombol **All projects** yang membuka halaman proyek; pilih **New project** di sana. (Sampai Anda memiliki proyek, bagian sidebar akan langsung menampilkan **New project**.) Berikan nama dengan panjang maksimal 100 karakter dan, jika diinginkan, deskripsi, lalu pilih **Create project**. LibreChat akan membuka ruang kerja proyek baru tersebut.

Halaman proyek menampilkan setiap proyek sebagai kartu dengan deskripsi dan jumlah chat-nya. **Cari proyek** mencocokkan nama dan deskripsi, dan menu urutan menawarkan **Aktivitas terbaru**, **Dibuat**, dan **Nama**.

## Memulai atau memindahkan chat [#start-or-move-chats]

Dari ruang kerja proyek, atau ikon obrolan baru di samping proyek pada bilah sisi, mulai obrolan dengan **New chat in** diikuti nama proyek. Kotak pesan menampilkan chip proyek: gunakan chip tersebut untuk beralih ke proyek lain, atau pilih ikon × untuk menghapus proyek sebelum Anda mengirim pesan. Setelah terkirim, obrolan tersebut menjadi milik proyek.

Untuk mengarsipkan chat yang sudah ada, buka menunya lalu pilih **Change project**, kemudian pilih proyek dari daftar yang dapat dicari. **Remove from project** akan mengeluarkannya kembali. Di desktop, Anda juga dapat menyeret chat ke sebuah proyek di sidebar. Chat akan menggunakan instruksi dan file proyek mulai dari pesan berikutnya, dan berhenti menggunakannya segera setelah chat itu keluar dari proyek.

Chat dalam sebuah proyek menampilkan nama proyek di bagian atas percakapan; pilih nama tersebut untuk membuka workspace. Di sidebar, setiap proyek dapat diperluas untuk menampilkan daftar chat-nya, sedangkan daftar utama **Chats** hanya menampilkan chat yang berada di luar proyek mana pun. Workspace proyek hanya mencantumkan chat miliknya sendiri, yang dapat diurutkan berdasarkan **Updated** atau **Created**.

## Instruksi [#instructions]

**Instruksi** di workspace berisi latar belakang, nada, atau tujuan untuk setiap chat dalam proyek. Pilih **Edit** untuk mengubahnya. Aturan sistem milik server Anda tetap berlaku di atasnya.

Instruksi berlaku untuk pesan yang dikirim setelah Anda menyimpannya, di chat biasa, chat agen, dan chat Assistants. Balasan sebelumnya tidak akan ditulis ulang. Instruksi dapat berisi hingga 16.000 karakter secara default.

Jika Anda mengedit proyek di tab lain dalam rentang waktu tersebut, penyimpanan akan gagal dengan pesan **This project was changed in another session. Reload to see the latest version.** Muat ulang dan lakukan perubahan kembali.

## File [#files]

**Files** menyimpan dokumen referensi untuk proyek. Gunakan **Add files** untuk mengunggah dengan **Upload from device** atau pilih file yang pernah Anda unggah sebelumnya dengan **Choose from your files**. Setiap file menampilkan **Processing** saat sedang diindeks dan **Ready** setelah chat dapat menggunakannya. **Choose from your files** hanya mencantumkan file yang diunggah untuk file search dan belum kedaluwarsa. File yang kemudian dihapus atau kedaluwarsa tetap tercantum sebagai **Unavailable** dan akan dilewati.

Chat dalam proyek mencari di dalam file-file ini dan mengambil bagian yang relevan, bukan seluruh dokumen. Hal ini hanya terjadi ketika **File Search** diaktifkan untuk chat atau agent tersebut. Jika server Anda belum mengatur file search, atau peran Anda tidak diizinkan menggunakannya, Anda tidak dapat mengunggah file proyek baru.

Sebuah proyek dapat menampung hingga 50 file, kecuali admin Anda telah mengubah batas tersebut. Menghapus file hanya memengaruhi pesan di masa mendatang; balasan yang sudah menggunakan file tersebut akan tetap seperti semula.

## Ganti nama atau hapus [#rename-or-delete]

Klik nama atau deskripsi proyek di ruang kerja untuk mengeditnya, atau gunakan **Edit project** dari menu proyek di sidebar.

**Hapus proyek**, di menu **Project options** pada ruang kerja atau sebagai **Delete** di menu sidebar, akan meminta konfirmasi dan hanya menghapus proyek tersebut. Obrolannya tetap ada di riwayat Anda, tetapi tidak lagi ditetapkan ke proyek mana pun. Jika Anda sedang melihat sebuah proyek saat proyek itu dihapus, LibreChat akan mengembalikan Anda ke halaman proyek.

## Pengaturan [#setup]

Proyek tersedia untuk setiap pengguna mulai dari LibreChat v0.8.7; tidak ada pengaturan atau izin peran yang menyembunyikannya. Admin dapat mengubah batas file per proyek serta panjang maksimum instruksi dan deskripsi di bawah kunci [`projects`](/docs/configuration/librechat_yaml/object_structure/config#projects) dalam `librechat.yaml`. File proyek bergantung pada [file search](/docs/features/rag_api).
