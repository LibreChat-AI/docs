Projects memungkinkan setiap pengguna untuk mengatur percakapan terkait ke dalam ruang kerja bernama. Fitur ini berguna untuk alur kerja jangka panjang, tim, klien, kelas, atau topik apa pun di mana Anda menginginkan sekumpulan obrolan terfokus yang berbagi latar belakang yang sama tanpa harus mengulanginya di setiap percakapan.

<Callout type="info" title="Ketersediaan">
  Projects ditambahkan di LibreChat **v0.8.7**. Tidak ada tombol atau izin peran yang menyembunyikan
  Projects, sehingga setiap pengguna yang masuk pada versi yang didukung memiliki fitur ini. Administrator dapat menyesuaikan instruksi,
  deskripsi, dan batas file dengan blok [`projects`](/docs/configuration/librechat_yaml/object_structure/config#projects)
  di dalam `librechat.yaml`. Jika Anda tidak dapat menemukan Projects di mana pun dalam antarmuka, berarti instance
  tersebut menjalankan versi yang lebih lama dan perlu diperbarui.
</Callout>

## Apa yang Dilakukan Projects [#what-projects-do]

- Kelompokkan percakapan dalam ruang kerja bernama dengan deskripsi opsional
- Berikan **Instructions** yang sama untuk setiap chat di dalam proyek tersebut
- Lampirkan **Files** referensi yang dapat dicari oleh obrolan di dalam proyek
- Mulai obrolan baru yang sudah dicakup ke dalam sebuah proyek, atau pindahkan obrolan yang sudah ada ke dalam dan ke luar proyek tersebut
- Telusuri, urutkan, pindahkan, hapus, atau hapus permanen obrolan dari ruang kerja proyek
- Cari proyek berdasarkan nama atau deskripsi dan urutkan berdasarkan aktivitas terbaru, tanggal pembuatan, atau nama

Proyek bersifat pribadi bagi pengguna yang membuatnya. Pengguna lain tidak dapat melihat daftar proyek Anda, dan sebuah proyek tidak dapat dibagikan atau dipindahkan. Proyek tidak membawa pengaturan model: setiap obrolan menyimpan model, Agent, dan parameternya sendiri.

## Membuat Proyek [#create-a-project]

<Steps>
<Step>

**Buka halaman projects.** Di sidebar, header bagian **Projects** memiliki tombol **All projects** yang akan membukanya.

</Step>
<Step>

**Pilih New project**, yang selalu tersedia di header halaman projects.

</Step>
<Step>

**Beri nama proyek.** Nama wajib diisi dan deskripsi bersifat opsional. LibreChat kemudian akan membuka ruang kerja proyek.

</Step>
</Steps>

Meskipun Anda belum memiliki proyek, bagian **Projects** pada bilah sisi juga menawarkan tombol **New project**. Setelah Anda memiliki proyek, bagian tersebut akan diperluas secara default sampai Anda menutupnya.

Nama proyek dibatasi hingga 100 karakter. Deskripsi dibatasi hingga 1.000 karakter secara default, dan nama proyek duplikat diperbolehkan.

Halaman proyek menampilkan setiap proyek sebagai kartu folder beserta deskripsi dan jumlah obrolannya.

## Instruksi [#instructions]

Instruksi menetapkan nada, tujuan, atau latar belakang untuk setiap obrolan dalam proyek, misalnya panduan gaya klien atau kursus tempat sekumpulan obrolan tersebut berada. Aturan platform dan keamanan tetap berlaku di atas instruksi tersebut.

<Steps>
<Step>

**Buka ruang kerja proyek** dan temukan bagian **Instructions**.

</Step>
<Step>

**Pilih Edit** untuk membuka dialog instruksi.

</Step>
<Step>

**Masukkan instruksi ruang kerja dan simpan.** Secara default, instruksi dapat berisi hingga 16.000 karakter.

</Step>
</Steps>

Instruksi digunakan untuk pesan baru dalam proyek. Mengubahnya tidak akan menulis ulang pesan sebelumnya: balasan yang sudah dibuat akan tetap seperti apa adanya, dan pesan berikutnya di obrolan proyek mana pun akan menggunakan versi saat ini. Instruksi berlaku untuk obrolan model reguler dan Agen, serta percakapan Asisten.

Jika proyek diubah di sesi lain saat dialog terbuka, menyimpan akan menampilkan **This project was changed in another session. Reload to see the latest version.** Muat ulang dan terapkan kembali suntingan Anda.

## File [#files]

File proyek memberikan dokumen referensi untuk percakapan proyek. Saat File Search diaktifkan, percakapan akan menggunakan kutipan yang relevan dari file-file tersebut alih-alih menggunakan seluruh isi file.

Di bagian **Files** pada ruang kerja, pilih **Add files** lalu:

- **Upload from device** untuk mengunggah dokumen baru. Setiap unggahan akan menampilkan **Processing** hingga statusnya menjadi **Ready**.
- **Pilih dari file Anda** untuk melampirkan file yang telah Anda unggah sebelumnya.

Hanya file yang diunggah untuk File Search (lampiran pesan yang disematkan) dan belum kedaluwarsa yang dapat dilampirkan, sehingga **Choose from your files** hanya menampilkan file-file tersebut. Sebuah proyek dapat menampung hingga 50 file secara default.

File proyek digunakan melalui File Search, sehingga obrolan hanya dapat membacanya jika:

- Agent, atau obrolan reguler, memiliki **File Search** yang diaktifkan
- File Search diaktifkan untuk endpoint Agents dan layanan pencarian file pada deployment tersebut tersedia

File yang dihapus atau kedaluwarsa akan tetap terdaftar sebagai **Unavailable** dan dilewati. Menghapus file dari proyek akan memengaruhi pesan di masa mendatang, bukan riwayat obrolan.

## Bekerja dalam Proyek [#work-in-a-project]

Buka proyek untuk melihat deskripsi, instruksi, file, dan obrolan yang ditetapkan. Pilih nama atau deskripsi proyek untuk mengeditnya secara langsung. Daftar **Chats** di ruang kerja dapat diurutkan berdasarkan pembaruan terakhir atau tanggal pembuatan.

Gunakan **New chat** di header ruang kerja untuk membuka komposer yang dicakup ke proyek tersebut; chip proyeknya mengonfirmasi bahwa percakapan baru akan ditetapkan ke proyek tersebut. Bilah sisi menampilkan tindakan yang sama pada setiap baris proyek.

Obrolan yang termasuk dalam suatu proyek akan menampilkan lencana proyek dengan nama proyek di bagian atas percakapan. Pilih lencana tersebut untuk membuka ruang kerja proyek.

Setiap obrolan proyek memiliki menu luapan dengan tindakan-tindakan berikut:

- **Change project** membuka pemilih proyek yang dapat dicari
- **Remove from project** tetap menyimpan percakapan tersebut tetapi menghapus penugasan proyeknya
- **Delete** menghapus percakapan setelah konfirmasi

## Memindahkan Obrolan yang Ada [#move-existing-chats]

Buka menu percakapan dan pilih **Change project**, lalu pilih proyek untuk menetapkannya. Untuk mengeluarkan obrolan, gunakan **Remove from project**, yang hanya ditampilkan untuk obrolan yang sudah menjadi bagian dari suatu proyek. Pada desktop, Anda juga dapat menarik obrolan ke dalam proyek di bilah sisi; lihat [Sidebar and Navigation](/docs/features/navigation#desktop-sidebar).

Konteks proyek dibaca kembali untuk setiap pesan, jadi obrolan yang Anda pindahkan ke dalam sebuah proyek akan mengambil instruksi dan file proyek tersebut pada pesan berikutnya, dan obrolan yang Anda hapus dari sebuah proyek akan berhenti menggunakannya.

Di bilah sisi, setiap baris project diperluas untuk menampilkan daftar obrolannya sendiri, dengan **Show all** untuk daftar yang lebih panjang. Bagian **Chats** hanya mencantumkan percakapan yang tidak berada dalam project, sehingga obrolan project hanya muncul di satu tempat. Tiga kasus berikut tetap mencantumkan setiap obrolan:

- saat Anda sedang mencari percakapan
- di tampilan **Archived chats** pada [menu daftar obrolan](/docs/features/navigation#filter-and-sort-the-chat-list)
- ketika proyek Anda gagal dimuat

## Kelola Proyek [#manage-projects]

Gunakan menu proyek di bilah sisi untuk:

- **Buka proyek**
- **Edit project**, yang membuka ruang kerja dengan nama dan deskripsi yang siap untuk diedit
- **Hapus** proyek

Halaman proyek menawarkan tindakan edit dan hapus yang sama, dan header ruang kerja memiliki menu opsi proyek dengan **Delete project**.

Menghapus proyek akan menghapus penugasan proyek dari obrolannya. Percakapan itu sendiri tidak akan dihapus.

## Temukan Proyek [#find-a-project]

Halaman proyek memiliki kotak **Search projects** yang mencocokkan nama dan deskripsi proyek, serta kontrol urutan yang menawarkan **Latest activity**, **Created**, dan **Name**. Daftar yang lebih panjang dapat dimuat dengan **Load more**.

## Catatan [#notes]

- Obrolan baru yang dimulai dari sebuah proyek akan tetap mempertahankan penugasan tersebut saat percakapan dibuat.
- Pencarian proyek tidak peka huruf besar-kecil dan mencocokkan nama serta deskripsi.
- Jika sebuah proyek dihapus saat Anda sedang melihatnya, LibreChat akan mengembalikan Anda ke daftar proyek.
