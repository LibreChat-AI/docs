Artifacts ermöglichen es LibreChat Agents, generierte React-Komponenten, HTML, SVG, Markdown und Mermaid-Inhalte in einer dedizierten interaktiven Ansicht darzustellen. Benutzer können die Konversation fortsetzen, um das Ergebnis zu überarbeiten, während der generierte Inhalt getrennt von der Chat-Antwort bleibt.

## Artifacts für einen Agenten aktivieren [#enable-artifacts-for-an-agent]

1. Erstellen oder bearbeiten Sie einen [Agent](/docs/features/agents).
2. Öffnen Sie **Add tools** und wählen Sie **Artifacts** aus.
3. Wählen Sie einen Modus für Artefakt-Anweisungen.
4. Speichere den Agenten.

Die verfügbaren Modi sind:

- **Normal**: Injiziert die Standardanweisungen von LibreChat für React-, HTML-, SVG-, Markdown- und Mermaid-Artefakte.
- **shadcn/ui**: Fügt Anleitungen zur shadcn/ui-Komponentenbibliothek für ausgefeiltere generierte Oberflächen hinzu.
- **Custom**: Behält das Artifact-Rendering bei, fügt jedoch keine integrierten Anweisungen hinzu. Fügen Sie das gewünschte vollständige Artifact-Verhalten in die Anweisungen des Agenten ein.

Die Konfiguration auf Agentenebene wird bevorzugt, da jeder Agent den für seinen Zweck geeigneten Modus und die entsprechenden Anweisungen verwenden kann. Der Administrator kann Artifacts ausblenden, indem er die `artifacts` [Agent-Funktion](/docs/configuration/librechat_yaml/object_structure/agents#capabilities) entfernt.

## Was Artifacts unterstützen [#what-artifacts-support]

- Interaktive React-Komponenten und HTML-Seiten
- SVG-Bilder und Mermaid-Diagramme
- Gerenderte Markdown-Dokumente
- Iterative Aktualisierungen durch Folge-Nachrichten
- Jedes Modell, das für den konfigurierten Agenten verfügbar ist

## Vorschau und Export [#preview-and-export]

Verwenden Sie das Vollbild-Steuerelement in einer gerenderten Artifact-Vorschau, um diese auf die vollständige Browseranzeige zu erweitern. Das Steuerelement folgt dem Status der Fullscreen API des Browsers, wird normal mit Escape oder über Browser-Steuerelemente beendet und ist ausgeblendet, wenn der Vollbildmodus nicht verfügbar ist.

Wählen Sie auf dem Desktop im Header des Artefakt-Bereichs **Open in new window**, um den Bereich in ein separates Browserfenster zu verschieben, beispielsweise um ihn auf einem zweiten Bildschirm zu platzieren. Das Artefakt wird während des Antwort-Streams kontinuierlich aktualisiert, und nicht gespeicherte Code-Änderungen sowie der ausgewählte Tab bleiben erhalten. Um den Bereich zurück in den Chat zu verschieben, wählen Sie **Dock back to panel** oder schließen Sie das Fenster. LibreChat merkt sich die Größe und Position des Fensters für das nächste Mal.

- Lassen Sie den Chat-Tab geöffnet: Das Fenster wird durch den Chat-Tab gesteuert, und das Schließen dieses Tabs schließt auch das Fenster.
- Wenn der Browser das Fenster blockiert, zeigt LibreChat einen Hinweis an. Erlaube Pop-ups für die Seite und versuche es erneut.
- Die Schaltfläche wird auf schmalen (mobilen) Layouts nicht angezeigt.

Administratoren können die Schaltfläche entfernen und Artefakte in der Seitenleiste behalten, indem sie [`interface.artifactUndocking: false`](/docs/configuration/librechat_yaml/object_structure/interface#artifactundocking) festlegen.

Mermaid-Diagramme erscheinen als kompakte Inline-Karten, die sich im Artefakt-Panel öffnen lassen. Exportieren Sie ein Diagramm entweder über die Inline-Karte oder das Panel als SVG oder PNG. Mermaid-Vorschauen werden direkt gerendert, anstatt den Sandpack-Bundler zu laden; der PNG-Export wendet begrenzte Canvas-Dimensionen an, um den Browser vor zu großen Diagrammen zu schützen.

Von Modellen erstellte Artefakte werden unter ihrem Titel oder ihrer Markdown-Überschrift mit einer Dateiendung heruntergeladen, die dem exportierten Inhalt entspricht. Ein unbearbeitetes, dateibasiertes Artefakt wird als vollständiges Original mit seinem ursprünglichen Dateinamen und Format heruntergeladen, sofern verfügbar. Beim Herunterladen von bearbeiteten oder zwischengespeicherten Vorschauinhalten wird eine `.preview`-Kennung verwendet, damit diese nicht mit der Originaldatei verwechselt werden.

## Content-Security-Policy

Möglicherweise müssen Sie die Content-Security-Policy Ihres Webservers aktualisieren, um `frame-src 'self' https://*.codesandbox.io` einzuschließen, damit generierte HTML-Apps im Artifacts-Panel geladen werden können. Dies ist eine Abhängigkeit der [sandpack](https://sandpack.codesandbox.io/)-Bibliothek.

## Selbst-Hosting des Sandpack Bundlers [#self-hosting-the-sandpack-bundler]

Artifacts in LibreChat verwenden die Sandpack-Bibliothek von CodeSandbox, um HTML/JS-Code sicher zu rendern. Standardmäßig verbindet sich LibreChat mit dem öffentlichen CDN von CodeSandbox, das möglicherweise auch Telemetriedaten zur Nutzung überträgt.

Für verbesserte Privatsphäre, Sicherheits-Compliance oder isolierte Netzwerkumgebungen können Sie [den Bundler selbst hosten.](https://sandpack.codesandbox.io/docs/guides/hosting-the-bundler)

### Warum den Sandpack Bundler selbst hosten? [#why-self-host-the-sandpack-bundler]

[Self-hosting the bundler](https://sandpack.codesandbox.io/docs/guides/hosting-the-bundler) bietet mehrere Vorteile:

- **Datenschutz & Sicherheit**: Halten Sie die Code-Ausführung innerhalb Ihrer eigenen Infrastruktur
- **Zuverlässigkeit**: Abhängigkeit von externen Diensten entfernen
- **Leistung**: Reduzieren Sie die Latenz, indem Sie den Bundler in Ihrem Netzwerk hosten
- **Compliance**: Erfüllen Sie die Anforderungen an die Datenverarbeitung Ihres Unternehmens
- **Steuerung**: Konfigurieren und anpassen an Ihre spezifischen Bedürfnisse

### Konfiguration [#configuration]

Sobald Sie einen selbst gehosteten Bundler eingerichtet haben, konfigurieren Sie LibreChat einfach für dessen Verwendung, indem Sie die Umgebungsvariable setzen:

```bash
# `.env` file
SANDPACK_BUNDLER_URL=http://your-bundler-url
```

### Allgemeine Überlegungen [#general-considerations]

Das Self-Hosting des Bundlers bringt einen zusätzlichen Overhead mit sich:

- **CORS-Konfiguration**: Sie müssen die Richtlinien für Cross-Origin Resource Sharing verwalten
- **Sicherheitsmanagement**: Sie werden für die Sicherheit des Bundler-Dienstes verantwortlich.
- **Wartung**: Updates und Patches müssen manuell angewendet werden
- **Ressourcenanforderungen**: Zusätzliche Serverressourcen werden benötigt, um den Bundler zu hosten.

Für detaillierte Anweisungen zur Einrichtung und Wartung Ihres selbst gehosteten Bundlers, lesen Sie das [geforkte CodeSandbox-Repository](https://github.com/LibreChat-AI/codesandbox-client), das für die LibreChat-Bereitstellung angepasst wurde, einschließlich der Entfernung der Telemetrie aus Sandpack.
