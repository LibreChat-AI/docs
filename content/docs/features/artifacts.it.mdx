Gli Artifacts consentono agli Agenti di LibreChat di eseguire il rendering di componenti React, HTML, SVG, Markdown e contenuti Mermaid generati in una vista interattiva dedicata. Gli utenti possono continuare la conversazione per revisionare il risultato, mantenendo il contenuto generato separato dalla risposta della chat.

## Abilitare gli Artifacts per un Agente [#enable-artifacts-for-an-agent]

1. Crea o modifica un [Agent](/docs/features/agents).
2. Apri **Add tools** e seleziona **Artifacts**.
3. Scegli una modalità di istruzione per gli artifact.
4. Salva l'agente.

Le modalità disponibili sono:

- **Normal**: Inserisce le istruzioni standard di LibreChat per gli artefatti React, HTML, SVG, Markdown e Mermaid.
- **shadcn/ui**: Aggiunge una guida alla libreria di componenti shadcn/ui per interfacce generate più rifinite.
- **Custom**: Mantiene il rendering degli artifact abilitato ma non inietta istruzioni predefinite. Inserisci il comportamento completo desiderato per l'artifact nelle istruzioni dell'agente.

La configurazione a livello di agente è preferibile perché ogni agente può utilizzare la modalità e le istruzioni appropriate al suo scopo. L'amministratore può nascondere gli Artifacts rimuovendo la `artifacts` [funzionalità dell'agente](/docs/configuration/librechat_yaml/object_structure/agents#capabilities).

## Cosa supportano gli Artifacts [#what-artifacts-support]

- Componenti React interattivi e pagine HTML
- Immagini SVG e diagrammi Mermaid
- Documenti Markdown renderizzati
- Aggiornamenti iterativi tramite messaggi di follow-up
- Qualsiasi modello disponibile per l'agente configurato

## Anteprima ed Esportazione [#preview-and-export]

Utilizza il controllo a schermo intero nell'anteprima di un artefatto renderizzato per espanderlo fino a occupare l'intera visualizzazione del browser. Il controllo segue lo stato della Fullscreen API del browser, si chiude normalmente con il tasto Escape o tramite i controlli del browser e viene nascosto quando la modalità a schermo intero non è disponibile.

Su desktop, seleziona **Open in new window** nell'intestazione del pannello degli artifact per spostare il pannello in una finestra del browser separata, ad esempio per posizionarlo su un secondo schermo. L'artifact continua ad aggiornarsi mentre la risposta viene trasmessa in streaming, e le modifiche al codice non salvate e la scheda selezionata vengono mantenute. Per riportare il pannello nella chat, seleziona **Dock back to panel** o chiudi la finestra. LibreChat ricorda le dimensioni e la posizione della finestra per la volta successiva.

- Mantieni aperta la scheda della chat: la finestra è controllata dalla scheda della chat e la chiusura di tale scheda chiude anche la finestra.
- Se il browser blocca la finestra, LibreChat mostra un avviso. Consenti i pop-up per il sito e riprova.
- Il pulsante non viene mostrato nei layout stretti (mobile).

Gli amministratori possono rimuovere il pulsante e mantenere gli artifact nel pannello laterale impostando [`interface.artifactUndocking: false`](/docs/configuration/librechat_yaml/object_structure/interface#artifactundocking).

I diagrammi Mermaid appaiono come schede inline compatte che possono essere aperte nel pannello degli artefatti. Esporta un diagramma come SVG o PNG sia dalla scheda inline che dal pannello. Le anteprime Mermaid vengono renderizzate direttamente invece di caricare il bundler Sandpack; l'esportazione in PNG applica dimensioni limitate alla tela per proteggere il browser da diagrammi troppo grandi.

Gli artefatti creati dal modello vengono scaricati con il loro titolo o intestazione Markdown, utilizzando un'estensione corrispondente al contenuto esportato. Un artefatto basato su file non modificato viene scaricato come copia completa dell'originale, mantenendo il nome file e il formato originali quando disponibili. Il download di contenuti modificati o di anteprime memorizzate nella cache utilizza un qualificatore `.preview`, in modo da non essere confuso con il file originale.

## Content-Security-Policy

Potrebbe essere necessario aggiornare la Content-Security-Policy del proprio server web per includere `frame-src 'self' https://*.codesandbox.io` al fine di caricare le app HTML generate nel pannello Artifacts. Questa è una dipendenza della libreria [sandpack](https://sandpack.codesandbox.io/).

## Self-Hosting del Sandpack Bundler [#self-hosting-the-sandpack-bundler]

Gli Artifacts in LibreChat utilizzano la libreria Sandpack di CodeSandbox per eseguire il rendering sicuro di codice HTML/JS. Per impostazione predefinita, LibreChat si connette alla CDN pubblica di CodeSandbox, che potrebbe anche trasmettere telemetria relativa al suo utilizzo.

Per una maggiore privacy, conformità alla sicurezza o ambienti di rete isolati, è possibile [ospitare autonomamente il bundler.](https://sandpack.codesandbox.io/docs/guides/hosting-the-bundler)

### Perché ospitare autonomamente il Sandpack Bundler? [#why-self-host-the-sandpack-bundler]

[Self-hosting the bundler](https://sandpack.codesandbox.io/docs/guides/hosting-the-bundler) offre diversi vantaggi:

- **Privacy & Security**: Mantieni l'esecuzione del codice all'interno della tua infrastruttura
- **Affidabilità**: Rimuovere la dipendenza da servizi esterni
- **Performance**: Riduci la latenza ospitando il bundler nella tua rete
- **Conformità**: Soddisfa i requisiti organizzativi di gestione dei dati
- **Controllo**: Configura e personalizza in base alle tue esigenze specifiche

### Configurazione [#configuration]

Una volta configurato un bundler self-hosted, è sufficiente configurare LibreChat per utilizzarlo impostando la variabile d'ambiente:

```bash
# `.env` file
SANDPACK_BUNDLER_URL=http://your-bundler-url
```

### Considerazioni generali [#general-considerations]

L'hosting autonomo del bundler introduce un ulteriore sovraccarico:

- **Configurazione CORS**: Dovrai gestire le policy di cross-origin resource sharing
- **Gestione della sicurezza**: Diventi responsabile della sicurezza del servizio bundler
- **Manutenzione**: Gli aggiornamenti e le patch dovranno essere applicati manualmente
- **Requisiti di sistema**: Saranno necessarie risorse server aggiuntive per ospitare il bundler

Per istruzioni dettagliate sulla configurazione e la manutenzione del tuo bundler self-hosted, fai riferimento al [repository forked di CodeSandbox](https://github.com/LibreChat-AI/codesandbox-client) adattato per il deployment di LibreChat, inclusa la rimozione della telemetria da Sandpack.
