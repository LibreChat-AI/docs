Projects を使用すると、各ユーザーは関連する会話を名前付きのワークスペースに整理できます。これは、長期にわたるワークストリーム、チーム、クライアント、クラス、あるいはすべての会話で繰り返すことなく、同じ背景情報を共有するチャットセットに集中したいあらゆるトピックに役立ちます。

<Callout type="info" title="可用性">
  ProjectsはLibreChat **v0.8.7**で追加されました。Projectsを非表示にするスイッチやロール権限は存在しないため、サポートされているバージョンを使用しているすべてのサインイン済みユーザーがこの機能を利用できます。管理者は、`librechat.yaml`内の[`projects`](/docs/configuration/librechat_yaml/object_structure/config#projects)ブロックを使用して、指示、説明、およびファイル制限を調整できます。インターフェースのどこにもProjectsが見当たらない場合は、インスタンスが古いバージョンで実行されているため、更新が必要です。
</Callout>

## Projectsの役割 [#what-projects-do]

- オプションの説明付きで、名前を付けたワークスペースに会話をグループ化します
- プロジェクト内のすべてのチャットに同じ**Instructions**（指示）を与える
- プロジェクト内のチャットが検索できる参照**ファイル**を添付します
- プロジェクトにスコープが設定された状態で新しいチャットを開始するか、既存のチャットをプロジェクトの内外へ移動します。
- プロジェクトワークスペースからチャットの閲覧、並べ替え、移動、削除、または完全削除を行います。
- 名前または説明でプロジェクトを検索し、最終アクティビティ、作成日、または名前で並べ替えます。

Projectsは、それを作成したユーザー個人のものです。他のユーザーがあなたのプロジェクトリストを見ることはできず、プロジェクトを共有したり転送したりすることもできません。Projectsはモデル設定を引き継ぎません。各チャットは独自のモデル、Agent、およびパラメータを保持します。

## プロジェクトを作成する [#create-a-project]

<Steps>
<Step>

**プロジェクトページを開きます。** サイドバーにある **Projects** セクションヘッダーには、それを開くための **All projects** ボタンがあります。

</Step>
<Step>

プロジェクトページヘッダーで常に利用可能な **Choose New project** を選択します。

</Step>
<Step>

**プロジェクトに名前を付けます。** 名前は必須で、説明は任意です。その後、LibreChatがプロジェクトワークスペースを開きます。

</Step>
</Steps>

まだプロジェクトがない場合でも、サイドバーの **Projects** セクションには **New project** ボタンが表示されます。プロジェクトを作成すると、このセクションは折りたたむまでデフォルトで展開された状態になります。

プロジェクト名は100文字までに制限されています。説明はデフォルトで1,000文字までに制限されており、重複するプロジェクト名は許可されています。

プロジェクトページには、各プロジェクトが説明とチャット数を含むフォルダーカードとして表示されます。

## Instructions [#instructions]

Instructionsは、クライアントのスタイルガイドや一連のチャットが属するコースなど、プロジェクト内のすべてのチャットに対してトーン、目標、または背景を設定します。プラットフォームおよび安全に関するルールは、それらの上に引き続き適用されます。

<Steps>
<Step>

**プロジェクトのワークスペースを開き**、**Instructions**セクションを見つけてください。

</Step>
<Step>

**Choose Edit** を選択して、指示ダイアログを開きます。

</Step>
<Step>

**ワークスペースの指示を入力して保存します。** デフォルトでは、指示は最大16,000文字まで入力可能です。

</Step>
</Steps>

Instructionsは、プロジェクト内の新しいメッセージに使用されます。これらを変更しても、以前のメッセージが書き換えられることはありません。すでに生成された返信はそのまま残り、プロジェクトのチャットにおける次のメッセージから現在のバージョンが使用されます。Instructionsは、通常のモデルチャット、Agents、およびAssistantsの会話に適用されます。

ダイアログが開いている間に別のセッションでプロジェクトが変更された場合、保存時に **This project was changed in another session. Reload to see the latest version.** と表示されます。リロードして編集内容を再度適用してください。

## Files [#files]

プロジェクトファイルは、プロジェクトのチャットに参照用のドキュメントを提供します。File Searchが有効な場合、チャットはファイル全体ではなく、関連する抜粋を使用します。

ワークスペースの **Files** セクションで、**Add files** を選択し、次に以下を行います：

- **Upload from device** をクリックして新しいドキュメントをアップロードします。各アップロードは、**Ready** になるまで **Processing** と表示されます。
- **Choose from your files** を選択して、すでにアップロード済みのファイルを添付します。

File Search（埋め込みメッセージ添付ファイル）用にアップロードされ、有効期限が切れていないファイルのみを添付できるため、**Choose from your files**にはそれらのファイルのみが表示されます。1つのプロジェクトにはデフォルトで最大50個のファイルを保持できます。

プロジェクトファイルは File Search を通じて使用されるため、チャットがそれらを読み取れるのは次の場合のみです：

- Agent または通常のチャットで **File Search** が有効になっています
- Agents エンドポイントで File Search が有効になっており、デプロイメントのファイル検索サービスが利用可能です。

削除または期限切れになったファイルは、**Unavailable**（利用不可）としてリストに残り、スキップされます。プロジェクトからファイルを削除しても、過去のチャット履歴には影響せず、今後のメッセージにのみ影響します。

## プロジェクトで作業する [#work-in-a-project]

プロジェクトを開くと、その説明、指示、ファイル、および割り当てられたチャットを確認できます。プロジェクト名または説明を選択すると、その場で編集できます。ワークスペース内の **Chats** リストは、最終更新日または作成日で並べ替えることができます。

ワークスペースヘッダーの **New chat** を使用して、プロジェクトにスコープされたコンポーザーを開きます。プロジェクトチップが表示され、新しい会話がそのプロジェクトに割り当てられることが確認できます。サイドバーの各プロジェクト行にも同じアクションが表示されます。

プロジェクトに属するチャットには、会話の上部にプロジェクト名が記載されたプロジェクトバッジが表示されます。バッジを選択すると、プロジェクトワークスペースが開きます。

各プロジェクトのチャットには、以下の操作が可能なオーバーフローメニューがあります：

- **Change project** は、検索可能なプロジェクトピッカーを開きます。
- **Remove from project** は、会話自体は保持したまま、そのプロジェクトへの割り当てを解除します。
- **Delete** は、確認後に会話を削除します。

## 既存のチャットを移行する [#move-existing-chats]

会話のメニューを開き、**Change project**を選択してから、割り当てるプロジェクトを選択します。チャットをプロジェクトから外すには、**Remove from project**を使用します。これは、すでにプロジェクトに属しているチャットに対してのみ表示されます。デスクトップでは、チャットをサイドバーのプロジェクトにドラッグ＆ドロップすることも可能です。詳細は[Sidebar and Navigation](/docs/features/navigation#desktop-sidebar)を参照してください。

プロジェクトのコンテキストはメッセージごとに再読み込みされるため、プロジェクトに移動したチャットは次のメッセージからそのプロジェクトの指示やファイルを適用し、プロジェクトから削除したチャットはそれらの使用を停止します。

サイドバーでは、各プロジェクトの行を展開してそのプロジェクト内のチャットを表示でき、リストが長い場合は **Show all** が表示されます。**Chats** セクションにはプロジェクトに含まれていない会話のみがリストされるため、プロジェクト内のチャットは一箇所にのみ表示されます。以下の3つのケースでは、引き続きすべてのチャットがリストされます：

- 会話を検索している間
- [チャットリストメニュー](/docs/features/navigation#filter-and-sort-the-chat-list)の**アーカイブ済みチャット**ビュー内
- プロジェクトの読み込みに失敗した場合

## プロジェクトの管理 [#manage-projects]

サイドバーにあるプロジェクトのメニューを使用して、以下の操作を行います：

- **プロジェクトを開く**
- **Edit project**。プロジェクト名と説明を編集可能な状態でワークスペースを開きます。
- プロジェクトを**削除**します

プロジェクトページでは同様の編集および削除アクションが提供されており、ワークスペースヘッダーには**プロジェクトを削除**を含むプロジェクトオプションメニューがあります。

プロジェクトを削除しても、そのチャットからプロジェクトの割り当てが解除されるだけで、会話自体が削除されることはありません。

## プロジェクトを探す [#find-a-project]

プロジェクトページには、プロジェクト名と説明を検索する **Search projects** ボックスがあり、**Latest activity**、**Created**、**Name** で並べ替えができるコントロールが用意されています。リストが長い場合は **Load more** でページを読み込むことができます。

## 注記 [#notes]

- プロジェクトから開始された新しいチャットは、会話が作成される際にその割り当てを保持します。
- プロジェクトの検索は、大文字と小文字を区別せず、名前と説明の両方に一致します。
- プロジェクトの表示中にそのプロジェクトが削除された場合、LibreChatはプロジェクト一覧画面に戻ります。
