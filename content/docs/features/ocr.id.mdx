OCR memungkinkan LibreChat membaca teks yang hanya berupa piksel: foto struk belanja, kontrak hasil pemindaian, atau PDF yang dibuat dari tangkapan layar. Ketika admin Anda telah menyiapkan layanan OCR, file yang ditambahkan sebagai teks akan diproses melalui layanan tersebut terlebih dahulu, sehingga model menerima isi teksnya alih-alih hasil kosong.

## Tempat OCR diterapkan [#where-ocr-applies]

OCR berjalan pada file yang teksnya dimasukkan ke dalam konteks model.

- **Unggah sebagai Teks** di chat, pada deployment yang menampilkan menu unggah eksplisit. Lihat [Unggah sebagai Teks](/docs/features/upload_as_text).
- **Konteks File** di Agent Builder, tempat teks yang diekstrak disertakan dalam konteks agen pada setiap pesan.

Jenis file yang ditangani secara default adalah gambar (JPEG, PNG, GIF, WebP, HEIC, HEIF), PDF, Word, PowerPoint, Excel, EPUB, dan file OpenDocument. File lainnya melewati OCR dan menggunakan ekstraksi teks biasa.

Dengan entri default **From Local Computer**, apa yang terjadi bergantung pada ke mana file tersebut dirutekan. Gambar dan PDF yang diterima oleh penyedia akan dikirim langsung ke model dan melewati OCR. File yang dirutekan ke teks (misalnya dokumen Word, atau PDF yang diatur oleh admin Anda untuk dirutekan ke teks) diekstraksi dengan cara yang sama seperti Upload as Text, sehingga akan melalui OCR jika OCR menangani jenis filenya.

## Tanpa OCR [#without-ocr]

Ekstraksi teks tetap berfungsi tanpa layanan OCR. Parser bawaan LibreChat membaca berkas PDF, DOCX, XLS dan XLSX, ODT, dan ODS berukuran hingga 15 MB yang memiliki lapisan teks asli, yang mencakup sebagian besar dokumen yang diekspor dari editor. Berkas `.doc` lama, PowerPoint, dan EPUB memerlukan OCR. Parser juga tidak dapat membaca gambar: PDF hasil pindai atau foto halaman akan gagal dengan pesan bahwa dokumen mungkin berbasis gambar dan memerlukan layanan OCR.

Jika OCR dikonfigurasi tetapi layanan mengalami error pada sebuah dokumen, LibreChat akan beralih ke parser bawaan untuk file tersebut.

## Layanan OCR [#ocr-services]

Admin memilih satu strategi:

- Mistral OCR melalui API Mistral. Ini adalah strategi default.
- Mistral OCR yang di-deploy pada Azure AI Foundry.
- Mistral OCR yang di-deploy di Google Cloud Vertex AI.
- Parser dokumen lokal saja, tanpa layanan eksternal. Parser ini membaca lapisan teks, tetapi tidak membaca gambar.

Dengan opsi Mistral mana pun, isi file dikirim ke layanan tersebut untuk diproses, sehingga ketentuan penanganan data layanan tersebut berlaku.

## Unggah ke Provider sebagai gantinya [#upload-to-provider-instead]

Banyak model dapat membaca gambar dan PDF secara langsung. Saat dikirim ke penyedia sebagai lampiran, file akan diurai oleh penyedia, yang mempertahankan tata letak dan gambar yang biasanya hilang saat ekstraksi teks. Pengunggah default melakukan ini secara otomatis untuk gambar dan PDF jika penyedia mendukungnya; dengan menu unggah yang lama, pilih **Upload to Provider** di [composer](/docs/features/composer#add-files).

Penyedia yang menerima file dengan cara ini: OpenAI, Anthropic, Google dan Vertex AI, AWS Bedrock, Mistral, DeepSeek, Moonshot, OpenRouter, xAI, dan endpoint kustom. Azure OpenAI menerima PDF dengan cara ini hanya ketika Responses API diaktifkan dalam parameter percakapan; dengan Chat Completions, Azure hanya menerima gambar.

Setiap penyedia menerima parameter yang berbeda-beda.

- Semuanya menerima gambar dan PDF.
- Google, Vertex AI, dan OpenRouter juga menerima audio dan video.
- AWS Bedrock juga menerima CSV, DOC, DOCX, XLS, XLSX, HTML, TXT, dan Markdown, hingga 4,5 MB per dokumen. PDF untuk Claude 4 dan versi yang lebih baru, serta PDF dan DOCX untuk Nova, dapat mencapai 32 MB kecuali admin Anda menetapkan batas ukuran file yang lebih rendah. Lihat [AWS Bedrock](/docs/configuration/pre_configured_ai/bedrock).

## Pengaturan [#setup]

OCR nonaktif hingga admin menambahkan bagian `ocr` ke `librechat.yaml`; strategi, kunci, dan endpoint dijelaskan dalam [referensi konfigurasi OCR](/docs/configuration/librechat_yaml/object_structure/ocr). Jenis file mana yang dikirim ke OCR diatur dengan `fileConfig.ocr.supportedMimeTypes` di dalam [`fileConfig`](/docs/configuration/librechat_yaml/object_structure/file_config#ocr). Agen juga memerlukan kapabilitas `ocr`, yang aktif secara default.
