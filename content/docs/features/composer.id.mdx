Composer adalah kotak di bagian bawah setiap percakapan. Di samping kolom teks terdapat tombol **+** untuk file, alat, skill, dan server MCP, sebuah chip untuk setiap alat yang Anda aktifkan, serta kontrol untuk tingkat penalaran, dikte, dan pengiriman.

Klik **+** (pembaca layar akan mengumumkannya sebagai **Attach and tools**) untuk membuka palet. Semua yang ada di dalamnya dapat dicari dari kolom di bagian atas, sehingga mengetik beberapa huruf biasanya lebih cepat daripada menggulir.

## Tambahkan file [#add-files]

Pilih **From Local Computer** di bagian **Attach**, seret file ke composer, atau tempelkan (paste). LibreChat menentukan cara setiap file sampai ke model (dikirim langsung ke provider, diekstrak sebagai teks, atau diindeks untuk File Search) berdasarkan jenis file dan endpoint, sehingga Anda hanya perlu memilih sumber file. **From SharePoint** akan muncul di sebelahnya ketika administrator Anda telah menghubungkan SharePoint.

Beberapa deployment menggunakan uploader lama, di mana Anda memilih tujuan unggahan secara manual: **Upload to Provider** (atau **Upload Image** untuk penyedia yang hanya menerima gambar), **Upload as Text**, **Upload for File Search**, dan **Upload to Code Environment**. Opsi pertama ditampilkan, sedangkan opsi lainnya berada di balik **More upload options**. Memilih **Upload for File Search** atau **Upload to Code Environment** juga akan mengaktifkan alat tersebut.

### Gunakan kembali file yang telah Anda unggah sebelumnya [#reuse-a-file-you-uploaded-before]

**File Anda** di palet menampilkan daftar file yang paling baru Anda gunakan (lima secara default). Pilih salah satu untuk melampirkannya kembali tanpa mengunggahnya ulang. Mengetik di kolom pencarian akan mencari semua file Anda berdasarkan nama, dan **Tampilkan semua** membuka dialog yang berisi setiap file, dibagi menjadi **Semua**, **Gambar** dan **Dokumen**, dengan pratinjau untuk gambar dan PDF.

## Aktifkan tools, skills, dan MCP servers [#turn-on-tools-skills-and-mcp-servers]

Di bawah **Attach**, palet mengelompokkan apa saja yang dapat Anda tambahkan ke percakapan:

- **Alat**: alat bawaan seperti **Web Search**, **Run Code**, **File Search**, **Skills**, **Memory** dan **Artifacts**. Anda hanya melihat alat yang diaktifkan dan yang Anda miliki aksesnya.
- **Skills**: [skills](/docs/features/skills) untuk dilampirkan ke pesan Anda berikutnya.
- **MCP Servers**: [server MCP](/docs/features/mcp) yang tersedia dalam chat, masing-masing dengan status koneksinya.

Memilih alat atau server MCP akan mengaktifkan atau menonaktifkannya, dan palet tetap terbuka sehingga Anda dapat mengaktifkan beberapa sekaligus. Setiap alat yang aktif akan mendapatkan chip pada composer; hapus chip untuk menonaktifkannya. Beberapa chip memiliki menu sendiri, misalnya mode generasi untuk **Artifacts**.

Memilih skill bekerja secara berbeda: skill tersebut disiapkan untuk pesan Anda berikutnya (lihat [Staged context](#staged-context)) alih-alih menjadi chip.

Jika server MCP belum terhubung, memilihnya akan memulai koneksi, termasuk proses masuk OAuth jika server membutuhkannya. Server yang memerlukan kredensial Anda sendiri akan meminta kredensial tersebut terlebih dahulu, dan setelahnya tombol **Configure** tetap tersedia di baris tersebut sehingga Anda dapat mengubahnya.

Dengan agen yang dipilih, bagian **Tools** dan **MCP Servers** menghilang, karena konfigurasi agen itu sendiri yang menentukan tool mana yang digunakannya. Hal yang sama berlaku untuk Assistants.

### Tampilkan semua dan favorit [#show-all-and-favorites]

Setiap bagian menampilkan hingga lima baris. **Tampilkan semua** pada header **Skills**, **MCP Servers**, atau **Your files** akan membuka daftar lengkap dengan pencarian dan filter; skills dan server dapat dipersempit ke **Dibuat oleh Anda** atau **Favorit**.

Untuk menandai baris sebagai favorit, sorot baris tersebut lalu tekan <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd> di macOS). Favorit akan dipindahkan ke bagian atas palet dan disimpan ke akun Anda.

Administrator Anda juga dapat menyematkan alat bawaan. Alat yang disematkan akan tetap memiliki chip-nya di composer meskipun sedang nonaktif, sehingga dapat diakses hanya dengan satu klik. Menghapus chip dari alat yang disematkan dan sedang nonaktif akan membatalkan penyematannya untuk Anda.

## Staged context [#staged-context]

Apa pun yang dilampirkan pada pesan Anda berikutnya akan muncul di atas kolom teks sebelum Anda mengirimkannya.

- Berkas, dengan progres unggah dan pratinjau gambar.
- Teks panjang yang ditempel. Ketika [Unggah sebagai Teks](/docs/features/upload_as_text#pasting-long-text) tersedia, menempelkan lebih dari 2.500 karakter akan melampirkan teks sebagai `pasted-text.txt` alih-alih mengisi kotak. Pilih file tersebut untuk mengedit teks dalam dialog yang lebih besar, atau pilih **Pindahkan kembali ke pesan** untuk mengembalikannya ke kolom teks. Nonaktifkan fitur ini dengan **Paste long text as a file** di **Settings > Chat**.
- Kutipan yang Anda ambil dari pesan sebelumnya dengan **Tambahkan ke chat** (lihat [Kutip cuplikan](/docs/features/message_actions#quote-excerpts)).
- Skill yang Anda pilih dari palet atau dengan `$`.

Hapus apa pun yang tidak lagi Anda inginkan sebelum mengirim; semua yang tersisa akan dikirim bersama pesan. Anda dapat mengirim file tanpa perlu mengetik apa pun.

## Berpikir [#thinking]

Pada model yang memiliki pengaturan penalaran, kontrol **Thinking** membuka slider dari **Faster** hingga **Smarter**, ditambah mode terpisah yang disediakan oleh penyedia, seperti **Auto**. Kontrol ini mengubah nilai yang sama dengan panel Parameters. Jika model tidak memiliki pengaturan penalaran, atau administrator Anda telah menyembunyikan parameter, kontrol ini tidak ditampilkan.

## Antre dan arahkan saat respons sedang melakukan streaming [#queue-and-steer-while-a-response-streams]

Anda dapat terus mengetik saat balasan sedang di-streaming. Apa yang terjadi saat Anda mengirim pesan pada kondisi tersebut bergantung pada default yang Anda atur di bawah **While generating, Enter will** pada **Settings > Chat** (lihat [Personal Settings](/docs/features/settings#chat)):

- Antrean: pesan menunggu dan dikirim saat balasan selesai.
- Steer: respons yang sedang berjalan menerima pesan Anda pada titik aman berikutnya tanpa membatalkan alat maupun penalaran.
- Interupsi: alat yang sedang aktif dan penalaran dibatalkan, keluaran yang sudah selesai tetap disimpan, dan respons dilanjutkan dengan pesan Anda.

Untuk mengetahui cara kerja steering pada agen, dan kapan fitur tersebut tersedia, lihat [Steering dan Pesan Antrean](/docs/features/agents#steering-and-queued-messages).

Pesan yang diantrikan menunggu dalam daftar **Queued messages** di atas composer. Dari setiap pesan, Anda dapat **Send now**, **Remove message**, atau membuka **More options** untuk **Edit message** (memindahkannya kembali ke kolom teks), **Start in a new chat**, atau **Disable Queue** agar tidak terkirim secara otomatis. Seret pesan untuk mengubah urutannya, atau fokus pada salah satu pesan lalu gunakan tombol panah atas dan bawah.

## Pintasan keyboard [#keyboard-shortcuts]

### Di kolom teks [#in-the-text-field]

Tabel ini mengasumsikan **Press Enter to send messages** aktif, yang merupakan pengaturan bawaan. Jika dinonaktifkan, <kbd>Enter</kbd> akan menambahkan baris baru dan <kbd>Ctrl</kbd>+<kbd>Enter</kbd> digunakan untuk mengirim pesan.

| Tombol | Aksi |
|---|---|
| <kbd>Enter</kbd> | Kirim. Saat balasan sedang di-stream, menjalankan pilihan Anda **While generating, Enter will**. |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Baris baru. |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) | Baris baru. Saat balasan sedang di-stream, aksi lainnya: kirim sekarang jika <kbd>Enter</kbd> mengantrekan, atau antrekan jika <kbd>Enter</kbd> mengarahkan atau menginterupsi. |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> (<kbd>Option</kbd>+<kbd>Enter</kbd>) | Saat balasan sedang di-stream: menginterupsi dengan pesan Anda, jika proses yang berjalan mengizinkannya. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd>) | Sama dengan <kbd>Alt</kbd>+<kbd>Enter</kbd>. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>) | Hentikan balasan. |
| `/` | Sisipkan prompt yang tersimpan. |
| `@` | Ganti model, preset, atau agent. |
| `+` | Tambahkan model atau preset lain untuk balasan berdampingan. |
| `$` | Pilih skill untuk pesan berikutnya. |

Anda dapat mengubah pengikatan atau mematikan pintasan keyboard dari menu akun; lihat [Pintasan Keyboard](/docs/features/settings#keyboard-shortcuts).

### Di dalam palet [#in-the-palette]

| Keys | Action |
|---|---|
| Ketik | Cari alat, skill, server, opsi unggah, dan file. |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Berpindah antar baris. |
| <kbd>Enter</kbd> | Pilih baris yang disorot. |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd>) | Tandai atau hapus tanda favorit pada baris yang disorot. |
| <kbd>Backspace</kbd> pada pencarian kosong, atau <kbd>Escape</kbd> | Tutup palet. |

## Pengaturan [#setup]

Composer tidak memerlukan pengaturan. Administrator mengontrol apa yang muncul di dalamnya: pengunggah versi lama dengan [`fileConfig.legacyFileUploadUX`](/docs/configuration/librechat_yaml/object_structure/file_config#legacyfileuploadux), jumlah file terbaru dengan [`interface.composerRecentFiles`](/docs/configuration/librechat_yaml/object_structure/interface#composerrecentfiles), alat yang disematkan dengan [`interface.defaultPinnedTools`](/docs/configuration/librechat_yaml/object_structure/interface#defaultpinnedtools), dan SharePoint melalui [integrasi SharePoint](/docs/configuration/sharepoint). [Model spec](/docs/configuration/librechat_yaml/object_structure/model_specs#hidebadgerow) dengan `hideBadgeRow` menyembunyikan bagian alat untuk spec tersebut.
