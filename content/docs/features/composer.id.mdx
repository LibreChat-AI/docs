Komposer pesan adalah kotak di bagian bawah setiap obrolan. Selain kolom teks, kotak ini berisi satu tombol **+** yang membuka semua hal yang dapat Anda tambahkan ke dalam pesan (file, alat, keterampilan, server MCP, dan file yang telah Anda unggah sebelumnya), chip untuk alat yang sedang aktif, serta kontrol untuk penalaran, dikte, dan pengiriman.

## Apa yang ada di composer [#whats-on-the-composer]

| Elemen | Fungsi |
|---|---|
| **+** (**Lampirkan dan alat**) | Membuka palet: opsi unggah, alat, keterampilan, server MCP, dan file terbaru Anda, semuanya dapat dicari dari satu kolom. |
| Chip alat | Satu chip per alat atau server MCP yang aktif, di sebelah tombol **+**. Hapus chip untuk menonaktifkan alat tersebut. |
| Konteks bertahap | File, kutipan, dan keterampilan yang dilampirkan ke pesan Anda berikutnya, ditampilkan di atas kolom teks. |
| **Berpikir** | Upaya penalaran untuk model yang mendukungnya. |
| Penggunaan konteks | Seberapa banyak jendela konteks model yang digunakan oleh percakapan, jika penggunaan token tersedia. |
| **Gunakan mikrofon** | Mendiktekan pesan Anda dengan ucapan ke teks, jika ucapan ke teks diaktifkan. |
| Kirim / Berhenti | Mengirim pesan, atau menghentikan respons yang sedang streaming. |

To see which keys apply right now, such as `/ for prompts`, `@ for models` or `Enter to send`, turn on **Show composer tips** in **Settings > General**. A one-line tip then appears under the text field. It is off by default.

## Tambahkan file [#add-files]

Klik **+** dan pilih opsi di bagian **Attach**. Anda juga dapat menarik file ke dalam composer atau menempelkannya.

Secara default, LibreChat menggunakan pengunggah terpadu: Anda hanya perlu memilih sumber, dan sistem akan menentukan bagaimana setiap file mencapai model (unggahan penyedia asli, ekstraksi teks, atau alat seperti File Search) berdasarkan jenis file dan endpoint-nya.

| Opsi | Kapan muncul |
|---|---|
| **From Local Computer** | Selalu, dengan pengunggah default. |
| **From SharePoint** | Saat [SharePoint file picker](/docs/configuration/sharepoint) diaktifkan. |

Jika administrator mengatur [`fileConfig.legacyFileUploadUX: true`](/docs/configuration/librechat_yaml/object_structure/file_config#legacyfileuploadux), Anda memilih tujuannya sendiri. Bagian **Attach** kemudian akan menampilkan opsi utama terlebih dahulu dan melipat sisanya di balik **More upload options**:

| Opsi | Kapan muncul |
|---|---|
| **Upload to Provider** | Penyedia menerima dokumen secara langsung (contohnya OpenAI, Anthropic, Google, Bedrock, OpenRouter dan endpoint kustom, atau Azure OpenAI dengan Responses API aktif). |
| **Upload Image** | Ditampilkan sebagai pengganti **Upload to Provider** ketika penyedia hanya menerima gambar. |
| **Upload as Text** | [context capability](/docs/features/upload_as_text) diaktifkan. |
| **Upload for File Search** | File Search diaktifkan dan diizinkan untuk agen saat ini. Memilihnya juga akan menyalakan File Search. |
| **Upload to Code Environment** | Eksekusi kode diaktifkan dan diizinkan untuk agen saat ini. Memilihnya juga akan menyalakan **Run Code**. |
| **Attach Files** | Endpoint Assistants, yang menangani file dengan konfigurasi asisten itu sendiri. |

Dengan SharePoint diaktifkan dalam mode ini, setiap opsi juga memiliki versi SharePoint, yang diberi label contohnya **Upload to Provider (From SharePoint)**.

### Gunakan kembali file yang telah Anda unggah sebelumnya [#reuse-a-file-you-uploaded-before]

Bagian **Your files** pada palet mencantumkan file yang terakhir Anda gunakan. Pilih salah satu untuk melampirkannya kembali tanpa perlu mengunggahnya. Mengetik di kolom pencarian akan mencari semua file Anda berdasarkan nama.

Pilih **Show all** pada bagian tersebut untuk menelusuri setiap file dalam dialog, dengan tampilan **All**, **Images**, dan **Documents**, kolom pencarian, serta pratinjau untuk gambar dan PDF.

Palet menampilkan hingga lima file terbaru. Administrator dapat menurunkan angka tersebut, atau menyembunyikan daftar dengan `0`, menggunakan [`interface.composerRecentFiles`](/docs/configuration/librechat_yaml/object_structure/interface#composerrecentfiles).

## Aktifkan tools, skills, dan MCP servers [#turn-on-tools-skills-and-mcp-servers]

Palet tersebut mencantumkan semua hal yang dapat Anda aktifkan untuk percakapan saat ini, yang dikelompokkan ke dalam beberapa bagian:

- **Tools**: alat bawaan seperti **Web Search**, **Run Code**, **File Search**, **Skills**, **Memory** dan **Artifacts**, masing-masing hanya ditampilkan saat diaktifkan dan Anda memiliki akses ke alat tersebut.
- **Skills**: [skills](/docs/features/skills) individual yang dapat Anda lampirkan pada pesan Anda berikutnya.
- **MCP Servers**: [MCP servers](/docs/features/mcp) yang tersedia di dalam chat.

Pilih alat atau server MCP untuk menyalakannya atau mematikannya. Palet akan tetap terbuka, sehingga Anda dapat mengganti beberapa alat dalam satu kunjungan. Setiap alat yang aktif akan muncul sebagai chip pada komposer; hapus chip tersebut untuk mematikannya. Beberapa chip memiliki menu mode, contohnya mode pembuatan **Artifacts**.

Memilih sebuah skill akan menempatkannya untuk pesan Anda berikutnya: skill tersebut akan muncul di [staged context](#staged-context) alih-alih sebagai chip.

Baris server MCP menampilkan status koneksi setiap server. Memilih server yang belum terhubung akan memulai koneksinya (termasuk masuk melalui OAuth, jika server memerlukannya) atau membuka konfigurasinya terlebih dahulu jika server tersebut memerlukan kredensial Anda. Setelah terhubung, server yang memerlukan kredensial pengguna juga memiliki kontrol **Configure** pada barisnya, dan **Web Search** memilikinya untuk kunci API-nya.

<Callout type="info" title="Agen membawa alat mereka sendiri">
  Dengan agen yang dipilih, bagian **Tools** dan **MCP Servers** disembunyikan, karena konfigurasi agen itu sendiri yang menentukan alat mana yang digunakannya. Pada endpoint lain, [model spec](/docs/configuration/librechat_yaml/object_structure/model_specs#hidebadgerow) dengan `hideBadgeRow: true` akan menyembunyikan bagian **Tools**, **Skills**, dan **MCP Servers**. **Attach** dan **Your files** tetap tersedia dalam setiap kasus.
</Callout>

### Tampilkan semua [#show-all]

Palet tersebut menampilkan beberapa baris per bagian. Pilih **Show all** pada header **Skills**, **MCP Servers**, atau **Your files** untuk membuka dialog dengan daftar lengkap, kolom pencarian, dan filter. Skills dan MCP servers memiliki tiga tampilan: **All**, **Made by you**, dan **Favorites**.

### Favorit dan alat yang disematkan [#favorites-and-pinned-tools]

Beri bintang pada baris untuk menambahkannya ke **Favorites**, yang terletak di bagian atas palet. Dengan baris yang disorot, tekan <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd> di macOS) untuk memberi atau menghapus bintang. Favorites disimpan ke akun Anda.

Administrator dapat menyematkan alat bawaan dengan [`interface.defaultPinnedTools`](/docs/configuration/librechat_yaml/object_structure/interface#defaultpinnedtools). Alat yang disematkan akan tetap menampilkan chip-nya pada composer meskipun dalam keadaan mati, sehingga Anda dapat menyalakannya dengan satu klik. Menghapus chip dari alat yang disematkan dalam keadaan mati akan melepas sematan alat tersebut.

## Staged context [#staged-context]

Segala sesuatu yang dilampirkan pada pesan Anda berikutnya akan muncul di atas kolom teks sebelum Anda mengirimkannya:

- **Files**, dengan progres unggahan dan pratinjau untuk gambar. Teks panjang yang ditempel juga dapat muncul di sini sebagai file, yang dapat Anda edit atau pindahkan kembali ke dalam pesan.
- **Kutipan** yang Anda pilih dari pesan sebelumnya.
- **Skills** yang Anda pilih dari palet atau dengan perintah `$`.

Hapus item apa pun dengan tombol hapus miliknya. Semua yang telah disiapkan akan dikirim bersama pesan Anda berikutnya.

## Berpikir dan upaya [#thinking-and-effort]

Untuk model dengan pengaturan penalaran, kontrol **Thinking** membuka penggeser yang berjalan dari **Faster** ke **Smarter**, ditambah mode terpisah penyedia seperti **Auto** atau nonaktif. Kontrol ini mengubah parameter yang sama dengan panel Parameters, sehingga kontrol ini disembunyikan saat model tidak memiliki pengaturan penalaran atau saat deployment menonaktifkan parameter dengan `interface.parameters`.

## Antre dan arahkan saat respons sedang melakukan streaming [#queue-and-steer-while-a-response-streams]

Anda dapat terus mengetik saat respons sedang dimuat (streaming). Bergantung pada endpoint dan pengaturan Anda, menekan <kbd>Enter</kbd> akan mengantrekan pesan untuk dikirim setelah respons selesai, atau mengarahkan respons agen yang sedang berlangsung. Tip pada komposer akan menyebutkan tindakan yang dilakukan <kbd>Enter</kbd> pada saat itu.

Pesan yang diantrekan muncul di rel **Queued messages** di atas komposer, di mana Anda dapat:

- **Edit message** untuk memindahkannya kembali ke kolom teks.
- **Hapus pesan** untuk mengeluarkannya dari antrean.
- **Send now** untuk mengirimnya secara langsung alih-alih menunggu.
- Susun ulang pesan dengan menyeretnya, atau dengan memfokuskan salah satu dan menekan tombol panah atas dan bawah.

Untuk cara kerja steering dan kapan fitur ini tersedia, lihat [Steering and Queued Messages](/docs/features/agents#steering-and-queued-messages).

## Pintasan keyboard [#keyboard-shortcuts]

### Di kolom teks [#in-the-text-field]

| Keys | Action |
|---|---|
| <kbd>Enter</kbd> | Mengirim pesan (mengantre atau mengarahkan saat respons sedang mengalir). |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Baris baru. |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) | Saat respons mengalir: tindakan alternatif, **kirim sekarang** saat <kbd>Enter</kbd> mengantre, atau **antre** saat <kbd>Enter</kbd> mengarahkan. |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> (<kbd>Option</kbd>+<kbd>Enter</kbd>) | Saat agen merespons: interupsi dan kirim, jika tersedia. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd>) | Menghentikan respons. |
| `/` | Menyisipkan prompt yang disimpan. |
| `@` | Beralih ke model, preset, atau agen lain. |
| `+` | Menambahkan model atau preset untuk respons tambahan. |
| `$` | Memilih skill untuk pesan berikutnya. |

Jika Anda mematikan **Tekan Enter untuk mengirim pesan**, <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) akan mengirim pesan dan <kbd>Enter</kbd> akan menambahkan baris baru.

### Di dalam palet [#in-the-palette]

| Keys | Action |
|---|---|
| Type | Cari alat, keterampilan, server, opsi unggahan, dan file. |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Bergerak melalui baris. |
| <kbd>Enter</kbd> | Pilih baris yang disorot. |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> (<kbd>Cmd</kbd>+<kbd>D</kbd>) | Tambahkan baris yang disorot ke Favorit, atau hapus. |
| <kbd>Backspace</kbd> pada pencarian kosong | Tutup palet. |
| <kbd>Escape</kbd> | Tutup palet. |
