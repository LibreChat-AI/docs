LibreChat membuat dan mengedit gambar melalui alat agen. Berikan alat gambar kepada agen, jelaskan apa yang Anda inginkan, dan gambar tersebut akan muncul dalam percakapan. Unggah gambar bersama pesan Anda, dan agen dapat mengubahnya alih-alih memulai dari awal.

## Alat Gambar [#the-image-tools]

| Alat | Fungsinya | Mengedit gambar |
| --- | --- | --- |
| OpenAI Image Tools | Menghasilkan gambar dari teks dan mengedit gambar yang diunggah atau gambar sebelumnya dengan model gambar OpenAI. Pilihan default yang baik. | Ya |
| Gemini Image Tools | Menghasilkan gambar dengan model gambar Gemini dari Google, dengan opsi menggunakan gambar sebelumnya sebagai konteks visual. | Ya |
| Flux | Menghasilkan gambar dengan model Flux dari Black Forest Labs, termasuk model fine-tuned milik Anda sendiri. | Tidak |
| Stable Diffusion | Menghasilkan gambar di server Automatic1111 milik Anda sendiri, sehingga tidak ada data yang keluar dari jaringan Anda. | Tidak |

Mana yang Anda lihat bergantung pada apa yang telah dikonfigurasi oleh admin Anda.

## Membuat gambar [#generate-an-image]

<Steps>
<Step>
Buka agen di Agent Builder, lalu pilih **Add** di samping **Tools**.
</Step>
<Step>
Pilih alat gambar, seperti **OpenAI Image Tools**, lalu simpan agen. Jika alat meminta API key, admin Anda membiarkannya untuk diisi oleh setiap pengguna; masukkan API key Anda sendiri.
</Step>
<Step>
Mulai obrolan dengan agen dan deskripsikan gambarnya.
</Step>
</Steps>

Agen mengubah permintaan Anda menjadi prompt untuk alat tersebut, sehingga Anda dapat berbicara secara normal ("poster untuk bazar kue, format lebar, banyak warna pastel"). Permintaan terkait bentuk dan ukuran diteruskan apabila alat mendukungnya: OpenAI menerima ukuran persegi, lanskap, atau potret (model yang lebih baru juga menerima ukuran kustom hingga 4K) serta tingkat kualitas dan latar belakang transparan, sedangkan Gemini menerima rasio aspek seperti 16:9 atau 9:16 dan, pada model yang lebih baru, resolusi hingga 4K. Stable Diffusion selalu menghasilkan gambar berukuran 1024x1024.

## Mengedit gambar [#edit-an-image]

Lampirkan gambar dengan **Upload Image** dan minta perubahan: "hapus orang-orang di latar belakang", "buat tampilannya seperti cat air", "letakkan logo ini pada cangkir kopi". Dengan OpenAI Image Tools, agent memanggil alat pengeditan; dengan Gemini, agent meneruskan gambar Anda sebagai konteks untuk pembuatan gambar baru.

Anda dapat melanjutkan pekerjaan pada gambar yang baru saja dihasilkan agen (misalnya "buat langit lebih gelap") tanpa mengunggah apa pun. Setiap gambar yang diunggah atau dihasilkan memiliki ID yang dirujuk oleh model, dan ini berfungsi selama gambar tersebut masih berada dalam jendela konteks percakapan. Dalam percakapan yang panjang, lampirkan kembali gambar tersebut.

Flux dan Stable Diffusion hanya bekerja dari teks, sehingga keduanya tidak dapat melakukan pengeditan.

## Apa yang dilihat model [#what-the-model-sees]

Gambar yang dihasilkan hanya ditampilkan kepada model sekali, tepat setelah gambar tersebut dibuat, sehingga model dapat mendeskripsikan atau memeriksa hasil karyanya sendiri. Setelah itu, model hanya dapat melihat gambar yang dilampirkan pada pesan Anda. Jika Anda ingin membahas gambar lama beberapa giliran kemudian, lampirkan kembali gambar tersebut.

Karena gambar dikirim kembali ke model, gunakan model yang mendukung visi untuk agen dengan alat gambar. Model yang hanya mendukung teks mungkin gagal pada giliran setelah gambar dihasilkan.

Gambar yang dihasilkan disimpan seperti unggahan file lainnya, sesuai dengan pengaturan penyimpanan file dari admin Anda. Secara default, gambar tersebut diperkecil sehingga sisi yang lebih pendek berukuran paling besar 768 piksel, sehingga permintaan gambar 4K akan disimpan dengan ukuran yang lebih kecil daripada yang dibuat oleh model, kecuali admin Anda mengubah pengaturan tersebut.

## Gambar dari server MCP [#images-from-mcp-servers]

Alat MCP juga dapat mengembalikan gambar, misalnya server browser yang mengambil tangkapan layar. Gambar yang dikembalikan server dalam format gambar MCP akan muncul di chat dengan cara yang sama seperti output dari alat bawaan. Beberapa server hanya mengembalikan URL ke gambar, dan LibreChat tidak memperlakukan hal tersebut sebagai output gambar.

## Menulis prompt [#writing-prompts]

Model gambar merespons deskripsi yang konkret. Mulailah dengan subjek dan medium (foto, lukisan cat minyak, ilustrasi vektor datar), lalu tambahkan komposisi, pencahayaan, dan detail yang penting. Jelaskan apa yang ingin Anda lihat, bukan mendaftar apa yang harus dihindari. Jika hasilnya sudah mendekati, mintalah perubahan spesifik alih-alih menulis ulang seluruh prompt.

## Pengaturan [#setup]

Setiap alat memerlukan API key atau URL server. Admin menetapkan ini di `.env`; untuk alat yang berbasis key, admin juga dapat membiarkan key tersebut untuk dimasukkan oleh setiap pengguna. Pengaturan untuk setiap alat: [OpenAI Image Tools](/docs/configuration/tools/openai_image_gen), [Gemini Image Tools](/docs/configuration/tools/gemini_image_gen), [Flux](/docs/configuration/tools/flux), dan [Stable Diffusion](/docs/configuration/tools/stable_diffusion). Lokasi penyimpanan gambar ditentukan oleh [`fileStrategy`](/docs/configuration/librechat_yaml/object_structure/config#filestrategy).
