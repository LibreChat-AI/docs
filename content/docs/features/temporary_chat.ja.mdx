title: 一時的なチャットとデータ保持
icon: Clock
description: >-
  一時的なチャットを使用して個別の会話を履歴や検索から除外し、管理者が会話データを自動的に期限切れにするか、すべてのチャットを一時的なものに設定できるようにします。
---

一時的なチャット（Temporary chats）を使用すると、履歴を残さずに質問を行うことができます。機密性の高いトピックや簡単な実験、保存する必要のない内容などに活用してください。一時的なチャットは履歴サイドバーに表示されず、検索にもヒットせず、ブックマークもできません。また、保持期間（デフォルトでは30日間）が終了すると自動的に削除されます。

管理者向けの**データ保持**機能も同じ仕組みで動作します。LibreChatでは、すべての会話に有効期限を設定したり、デプロイ全体ですべてのチャットを一時的なものとして強制したりすることが可能です。

<Callout type="info" title="1ページに2つのオーディエンス">
  [一時的なチャットの使用](#using-temporary-chat)は誰でも利用できます。[データ保持](#data-retention)以降は、`librechat.yaml`を設定する管理者向けの内容です。各オプションは[インターフェースリファレンス](/docs/configuration/librechat_yaml/object_structure/interface#temporarychat)にも記載されています。
</Callout>

## 一時的なチャットの使用 [#using-temporary-chat]

### 一時的なチャットを開始する [#start-a-temporary-chat]

新しいチャットを開始し、最初のメッセージを送信する前に **Temporary Chat** をオンにします：

- **デスクトップ:** チャットヘッダーの右端にある **Temporary Chat** ボタン（帽子とメガネのアイコン）を選択します。マウスを合わせるとキーボードショートカットが表示されます。
- **モバイル:** ヘッダーメニューを開き、**Temporary Chat** を選択します。チェックマークが表示されれば有効になっています。
- **キーボード:** `Ctrl+Shift+Y` (`Cmd+Shift+Y` を macOS で) を押します。

![チャットヘッダーの右端にあるTemporary Chatボタンと、そのツールチップ](/images/temporary-chat/temporary-chat-button.png)

オンになっている間、ランディングビューには「**Temporary Chat**」と表示され、「このチャットは履歴に表示されず、自動的に削除されます。」という注記が示されます。また、メッセージボックスには色が付きます。もう一度ボタンを選択するとオフになります。

![新しい一時的なチャット：一時的なチャットのランディングメッセージと色付きのメッセージボックス](/images/temporary-chat/temporary-chat-active.png)

このトグルは、最初のメッセージを送信する前のみ利用可能です。会話が始まると、読み取り専用の **Temporary Chat** バッジがヘッダーに表示され続け、そのチャットが保存されないことを常に確認できます。

### すべての新規チャットを一時的にする [#make-every-new-chat-temporary]

すべての新しいチャットを一時的なものとして開始するには、**Settings > Chat** を開き、**Temporary Chat by default** をオンにします。この設定はブラウザに保存されるため、使用するデバイスごとに設定してください。

### 一時的なチャットの機能 [#what-a-temporary-chat-does]

- チャット履歴のサイドバーには表示されません。
- 検索結果から除外されます。
- ブックマークすることはできません。
- 自動生成されたタイトルは付きません。
- 保持期間が終了するまで保持され、その後自動的に削除されます。デフォルトの期間は30日間ですが、管理者が別の期間を設定している場合があります。

保持期間は、会話、メッセージ、ファイル、および共有リンクに適用されます。一時的なチャットの期限が切れても、[Memories](/docs/features/memory) は削除されません。

<Callout type="note" title="管理者によって強制される一時的なチャット">
  管理者がすべてのチャットを一時的なものに設定している場合、**Temporary Chat** ボタンは常にオンの状態となり、オフにすることはできません。ボタンにホバーまたはフォーカスすると「Temporary Chat is enabled for all chats by your administrator」と表示され、キーボードショートカットは機能しません。
</Callout>

## データ保持 [#data-retention]

管理者は `librechat.yaml` の `interface` 配下にあるいくつかのオプションを使用して保持期間を制御します。主なものは `retentionMode` であり、どのチャットに有効期限を設定するかを決定します。

| モード | 有効期限の対象 | 履歴と検索でチャットは表示されますか？ | ユーザーはオプトアウトできますか？ |
| ----------------------- | ------------------------------------ | --------------------------------------- | -------------------- |
| `temporary` _(デフォルト)_ | ユーザーが一時的とマークしたチャットのみ | 通常のチャットは表示されますが、一時的なチャットは表示されません | はい、チャットごとに可能です |
| `all`                   | すべてのチャット | はい、各チャットの有効期限が切れるまで表示されます | いいえ |
| `ephemeral`             | すべてのチャット | いいえ、すべてのチャットが一時的です | いいえ、トグルはオンに固定されています |

デフォルトは `temporary` であるため、既存のデプロイメントは変更するまで現在の動作を維持します。

### 設定 [#configuration]

```yaml filename="librechat.yaml"
interface:
  # Who may use the Temporary Chat toggle (seeds the TEMPORARY_CHAT permission for the USER role)
  temporaryChat: true

  # Which chats expire: "temporary" (default), "all", or "ephemeral"
  retentionMode: 'temporary'

  # Lifetime of temporary chats, in hours. Default 720 (30 days), range 1 to 8760.
  temporaryChatRetention: 720

  # Lifetime of regular chats under retentionMode "all", in hours. Defaults to temporaryChatRetention.
  # generalChatRetention: 2160

  # Under "all" or "ephemeral", keep files uploaded to agents (knowledge and context files) from expiring.
  retainAgentFiles: false
```

| キー | 型 | デフォルト | 説明 |
| ------------------------ | ----------------------------------------- | ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `retentionMode`          | `"temporary"` \| `"all"` \| `"ephemeral"` | `"temporary"`            | どのチャットに有効期限を設定するかを指定します。[3つのモード](#the-three-modes)を参照してください。 |
| `temporaryChatRetention` | number (時間)                            | `720`                    | 一時的なチャットが最後に保存されてから保持される期間。`ephemeral`モードにおけるすべてのチャットの有効期間でもあります。範囲は `1` から `8760` です。 |
| `generalChatRetention`   | number (時間)                            | `temporaryChatRetention` | `all`モードにおいて通常のチャットが保持される期間。他のモードでは無視されます。範囲は `1` から `8760` です。 |
| `retainAgentFiles`       | boolean                                   | `false`                  | `all`および`ephemeral`モードにおいて、エージェントのリソースにアップロードされたファイルが期限切れにならないようにします。メッセージに添付されたファイルは、チャットの期限とともに期限切れになります。 |
| `temporaryChat`          | boolean                                   | `true`                   | 起動時に組み込みの `USER` ロールに対して `TEMPORARY_CHAT` 権限をシードします。ロールごとの権限管理は [管理パネル](/docs/features/admin_panel) で行えます。 |

`librechat.yaml` の値が `1` から `8760` 時間の範囲外である場合、設定の検証に失敗します。

#### 環境変数 [#environment-variable]

一時的なチャットの保持期間は、`TEMP_CHAT_RETENTION_HOURS` を使用して設定することもできます。両方が設定されている場合は、`interface.temporaryChatRetention` が優先されます。無効な値が指定された場合は `720` にフォールバックされ、`1` から `8760` の範囲外の値は、サーバーログに警告が出力された上でその範囲内に収まるよう調整されます。

<Callout type="warning" title="librechat.yaml を優先する">
  `TEMP_CHAT_RETENTION_HOURS` は非推奨となりました。代わりに `interface.temporaryChatRetention` を使用してください。
</Callout>

### 3つのモード [#the-three-modes]

<Tabs items={['一時的', 'すべて', '一時的']}>
  <Tabs.Tab>
    **`temporary` (デフォルト)**。ユーザーがトグル、または **Temporary Chat by default** 設定を通じて一時的とマークしたチャットのみが期限切れになります。これらは履歴や検索から非表示になり、`temporaryChatRetention` 時間後に削除されます。通常のチャットは期限切れになりません。
  </Tabs.Tab>
  <Tabs.Tab>
    **`all`。** すべての会話とメッセージに有効期限が設定されますが、チャットの操作感は変わりません。チャットは有効期限が切れるまで履歴や検索に残ります。

    - 通常のチャットは `generalChatRetention` を使用し、それが設定されていない場合は `temporaryChatRetention` を使用します。
    - ユーザーが一時的とマークしたチャットは、引き続き一時的なチャットとして動作し、`temporaryChatRetention` が使用されます。
    - アップロードされたファイルや共有リンクも期限切れになります。エージェントのリソースファイルは `retainAgentFiles: true` が設定されている場合にのみ保持されます。

    「N日間すべて保持し、その後削除する」ポリシーには `all` を使用してください。

  </Tabs.Tab>
  <Tabs.Tab>
    **`ephemeral`。** すべてのチャットが一時的なものになります。これは、デプロイ全体に対して「一時的なチャットを常に有効にする」設定です。

    - すべてのチャットは履歴や検索から非表示になり、タイトルは生成されず、`temporaryChatRetention` 時間後に削除されます。`generalChatRetention` は無視されます。
    - **Temporary Chat** トグルは、`TEMPORARY_CHAT` 権限を持たないユーザーを含む全員に対して強制的にオンの状態に固定されています。キーボードショートカットは無効化されています。
    - サーバーがこれを強制します：`isTemporary: false` を送信するクライアントは上書きされます。
    - アップロードされたファイルと共有リンクは、チャットとともに期限切れになります。エージェントのリソースファイルは、`retainAgentFiles: true` が設定されている場合にのみ保持されます。

    会話を長期的に保持する必要がない場合は、`ephemeral` を使用してください。

  </Tabs.Tab>
</Tabs>

### 保持の仕組み [#how-retention-works]

各会話およびメッセージには `expiredAt` 日付が設定されており、一時的なものには `isTemporary: true` というフラグも付けられます。非表示および期限切れのレコードは、削除される前に履歴リストおよび検索インデックスから除外されます。

- **Conversations, messages and shared links** は、`expiredAt` に対する MongoDB の TTL インデックスによって削除されます。MongoDB はこのクリーンアップをバックグラウンドで実行し、通常は期限から約1分以内に行われます。
- **Files**はLibreChat内の定期的なスイープによって削除されます。このプロセスにより、保存されたファイル（ローカルディスク、S3など）とそのレコードが削除されます。

期限はレコードが保存された時に設定されます。会話を保存するたびに期限は先に延びるため、アクティブなチャットは使用されている間は保持されます。各メッセージは、保存された時に設定された期限を維持します。

`all` および `ephemeral` の下では、チャットデータが書き込まれるすべての場所で保持設定が適用されます。これには、すべての endpoint における新しいメッセージ、再生成と分岐、メッセージの編集、フィードバック、アーティファクトの編集、再開された応答、フォーク、複製、およびインポートが含まれます。

- **Forks, duplicates and imports.** `ephemeral` の下では、これらは常に一時的なものとなります。`all` の下では、一時的なチャットのコピーは一時的なままとなり、その他のコピーやインポートは有効期限付きで表示されたままとなります。
- **Shared links**の有効期限は、そのリンク先である会話の有効期限に準じます。そのため、リンクがチャットの寿命を超えることはありません。
- **Memories**には有効期限はなく、いかなる保持モードの影響も受けません。

### モードの切り替え [#switching-modes]

`retentionMode` または保持期間の変更は、それ以降に保存されたレコードにのみ影響します。LibreChatは既存の期限を書き換えることはありません。

- **`all` または `ephemeral` の場合:** 既存のチャットは、次に書き込みが行われた時点で期限が設定されます。`ephemeral` の場合、新しいメッセージ、編集、フィードバック、またはブランチが追加された古い通常のチャットは、その場で一時的なチャットに変換されます。これにより、履歴や検索から除外され、ブックマークも失われます。誰にも触れられていないチャットは、現在の状態が維持されます。
- **`temporary` に戻る:** `all` の下に保存されたチャットには引き続き期限が適用され、削除されます。`ephemeral` の下に保存されたチャットは一時的なチャットのままであり、期限切れとなります。

`all` または `ephemeral` を離れた後に通常のチャットの期限が切れないようにするには、`mongosh` で期限をクリアします：

```js filename="mongosh"
db.conversations.updateMany(
  { isTemporary: false, expiredAt: { $ne: null } },
  { $unset: { expiredAt: 1 } },
)
db.messages.updateMany(
  { isTemporary: false, expiredAt: { $ne: null } },
  { $unset: { expiredAt: 1 } },
)
```

<Callout type="info" title="アップグレード後の検索インデックス">
  MongoDBは、置き換えられたインデックスを自動的に削除しません。`conversations` および `messages` コレクション上に新しい `_meiliIndex_1_isTemporary_1_expiredAt_1` インデックスが作成されたら、両方のコレクションから古い `_meiliIndex_1_expiredAt_1` インデックスを削除できます。
</Callout>

### 例 [#examples]

最後の活動から90日が経過したすべてのチャットを削除し、それまではチャットを表示したままにします：

```yaml filename="librechat.yaml"
interface:
  retentionMode: 'all'
  generalChatRetention: 2160 # 90 days for regular chats
  temporaryChatRetention: 24 # 1 day for chats users mark as temporary
```

すべてのチャットを一時的なものにし、24時間後に削除する：

```yaml filename="librechat.yaml"
interface:
  retentionMode: 'ephemeral'
  temporaryChatRetention: 24
```

すべてのチャットを1週間で一時的なものにしつつ、エージェントに添付されたファイルは保持する：

```yaml filename="librechat.yaml"
interface:
  retentionMode: 'ephemeral'
  temporaryChatRetention: 168
  retainAgentFiles: true
```

## FAQ [#faq]

<Accordions>

<Accordion title="保持期間はチャットが作成された時点から始まりますか、それとも最後に使用された時点から始まりますか？">
  会話が最後に保存された日時です。新しいメッセージが送信されるたびに会話の期限が延長されるため、使用中のアクティブなチャットが削除されることはありません。
</Accordion>

<Accordion title="チャットは期限が切れた瞬間に削除されますか？">
  秒単位ではありません。MongoDBは期限切れの会話やメッセージをバックグラウンド処理で削除しますが、通常は約1分以内に行われます。また、ファイルはLibreChatの定期的なスイープによって削除されます。期限切れのチャットは、それ以前の段階でユーザーから非表示になっています。
</Accordion>

<Accordion title="all と ephemeral の違いは何ですか？">
  `all` はチャットを通常通り表示し、指定した日付で削除します。`ephemeral` はすべてのチャットを一時的なものにし、履歴や検索から非表示にするとともに、トグルをロックします。「N日後に削除」したい場合は `all` を、「会話を一切保存しない」場合は `ephemeral` を選択してください。
</Accordion>

<Accordion title="ユーザーはephemeralの下でTemporary Chatをオフにできますか？">
  いいえ。トグルはオンに固定されており、サーバーはチャットを永続として保存するあらゆるリクエストを上書きします。
</Accordion>

<Accordion title="共有リンクはチャットよりも長く存続できますか？">
  いいえ。共有リンクは、それが指し示す会話の有効期限が切れると同時に無効になります。
</Accordion>

</Accordions>
