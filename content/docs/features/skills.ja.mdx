スキルは `SKILL.md` ファイルです。スキルが適用される場面を示す短いフロントマターブロックと、指示を記述したマークダウン本文で構成されます。スタイルガイド、レビューのチェックリスト、定期的なレポートの手順など、チャットに何度も貼り付けるような内容にはスキルを使用してください。エージェントは関連性がある場合にのみスキルを読み込むため、多数のスキルを用意しておいても、すべてのプロンプトが肥大化することはありません。

LibreChat には、あらかじめ組み込まれたスキルは含まれていません。各スキルは、ユーザーが作成またはアップロードするか、チャット中にエージェントが作成するか、または管理者が提供します。

## スキルを作成する [#create-a-skill]

サイドパネルから**Skills**を開き、**+**をクリックします。**Write skill instructions**を選ぶとエディタで直接スキルを作成でき、**Upload a skill**を選ぶと`.md`ファイル、または`SKILL.md`を含む`.zip`もしくは`.skill`アーカイブをインポートできます。サイドパネルにSkillsが表示されない場合は、管理者がこの機能を無効にしているか、お使いのロールではこの機能を利用できない可能性があります。

A minimal skill:

```md filename="SKILL.md"
---
name: brand-guidelines
description: Use when writing public-facing copy that must follow the company voice and terminology.
---

Write in a concise, practical tone.
Prefer active voice.
Say "workspace", never "project space".
```

スキル名はケバブケース(小文字の英字、数字、ハイフンのみ)で指定し、最大64文字とし、既存のスキル間で一意である必要があります。すでに使用している名前でスキルをアップロードすると、上書きされずに失敗します。`anthropic-` または `claude-` で始まる名前、および `help` や `settings` などのコマンドワードは予約されており、使用できません。

説明文はファイル内のどの部分よりも重要です。モデルはこの説明文を読んで、そのスキルを適用すべきかどうかを判断します。「モバイルアプリのリリースノートを作成するときに使用」は発動しますが、「ライティング補助」では発動しません。トリガーとなるフレーズを先頭に置き、250文字未満に収めてください。長すぎる説明文は、モデルが目にする一覧で途中で切り詰められてしまうためです。説明文の上限は1,024文字、本文の上限は100,000文字です。

### フロントマターのオプション [#frontmatter-options]

スキルには、`name` と `description` に加えて、以下を設定できます:

- `always-apply: true`: ターンごとにモデルからの要求を待つのではなく、毎ターンスキルを読み込みます。
- `user-invocable: false`: `$` メニューから非表示にします。
- `disable-model-invocation: true`: モデルが選択する一覧から除外します。`$` を使えば引き続き呼び出せます。
- `allowed-tools`: スキルが`$`で呼び出されたとき、またはスキルが常に適用されるときに、そのターンでエージェントに付与されるツールのリスト(例: `["execute_code"]`)です。エージェントが通常それらのツールを持っていない場合でも付与されます。
- `compatibility`: 必要とするもの（特定のMCPサーバーなど）に関する自由記述のメモです。LibreChatはこの内容を保持しますが、強制はしません。

`when-to-use` は `description` の代わりに使用でき、`always-apply` の代わりには `alwaysApply` を使用できます。キーは大文字と小文字を区別せず、追加した他のキーはメタデータとして保持されます。

### バンドルされたファイル [#bundled-files]

スキルは複数のファイルを含めることができます。一般的な構成は、長文のドキュメント用の `references/`、エージェントが実行できるコード用の `scripts/`、テンプレート用の `assets/` です。エージェントはスキルの使用時にこれらのファイルを読み込むため、`SKILL.md` は短くまとめ、これらのファイルを参照するだけで済みます。Run Code が有効な場合、これらのファイルは `/mnt/data/skills/<skill-name>/` の下のサンドボックス内でも利用できます。スキルビューアでは、スキル内の Markdown ファイル同士の相対リンクをクリックすると、リンク先のファイルが開きます。

アーカイブ内では、`SKILL.md` はトップレベルか、ちょうど1つのフォルダの中に置く必要があります。アップロードは既定で 50 MB まで(管理者が変更できます)、500 ファイルまで、ファイルごとに 10 MB までに制限されます。安全でないパスを持つファイルはスキップされ、その旨が報告されます。付属ファイルを含むスキルには、Skills サイドバーでその名前の横に矢印が表示されます。矢印を展開するとファイルを閲覧でき、個別のファイルを開くことができます。

## スキルを使用する [#use-a-skill]

スキルが会話に届く経路は3つあります。

- **あなたが選ぶ。** チャット入力欄に `$` と入力し、スキルを選択します。テキストには何も追加されません。スキルは入力欄の上にチップとして表示され、そのメッセージのために読み込まれます。
- **モデルがそれを選択します。** エージェントは利用可能なスキルの名前と説明を確認し、リクエストに合致するものを読み込みます。
- **常に適用されます。** `always-apply: true` が設定されたスキルは、すべてのターンで読み込まれます。

スキルの読み込み中は、メッセージに**Loading**とスキル名が表示され、コンテキストに読み込まれると**Loaded**と表示されます。

モデルが見るのは、一覧にあるスキルの名前と説明だけであり(最大100件)、指示内容は見えません。選択されたスキル、または常に適用されるスキルは、そのターンのために完全な `SKILL.md` を読み込みます。1ターンあたり、選択されたスキルは最大10件、常に適用されるスキルは最大20件、合計30件まで使用できます。これを超えた場合は、常に適用されるスキルから先に除外されます。

## エージェントが使用できるスキル [#which-skills-an-agent-can-use]

2つのことが、それを決めます。

最初に、ご自身のスキル一覧です。各スキルには **Available to agent** のスイッチがあります。これをオフにすると、スキルは削除されることなく、`$` メニュー、モデルが選択できる対象、および常時適用からも非表示になります。ご自身で作成したスキルは最初からオンになっています。他のユーザーから共有されたスキルは、管理者が共有スキルをデフォルトで有効にしていない限り、最初はオフになっています。

2つ目は、エージェントです。エージェントビルダーの**Skills**セクションには、3つの設定があります。

- **オフ**: エージェントはスキルを使用しません。
- **すべて**: 有効にしたすべてのスキル。
- **選択済み**: リストに追加したスキルのみ。

**Selected**は、集中したエージェントにはより適した選択です。サポート用エージェントが40個のスキルから選ぶ場合、必要な3個だけを持つ場合よりも誤ったスキルを選ぶ頻度が高くなります。

## エージェントが作成するSkills [#skills-written-by-agents]

エージェントでスキルが有効になっている場合、作業中にスキルを書き込むこともできます。たとえば、うまくいった手順を保存するような場合です。ロールが新しいスキルの作成を許可されていれば、エージェントは新しいスキルを作成できます。既存のスキルを編集できるのは、編集権限があり、かつそのスキルがエージェントのスコープ内にある場合のみです。管理者から提供されたスキルは読み取り専用のままです。**Selected** を選択して一覧が空の場合、エージェントは既存のスキルを一切参照できませんが、新しいスキルは引き続き作成できます。

## 共有 [#sharing]

スキルは、エージェントやプロンプトと同じ方法で共有され、閲覧者（利用のみ、編集不可）、編集者、所有者のロールがあります。共有するには、ロールに共有権限が必要ですが、この権限は一般ユーザーではデフォルトで無効になっています。詳しくは [アクセス制御](/docs/features/access_control) を参照してください。

管理者は、サーバーのファイルシステム、[Agent Plugins](/docs/features/agent_plugins)、または GitHub リポジトリからミラーリングされたスキルも提供できます。これらは LibreChat では読み取り専用であり、変更はソースで行ってください。ファイルシステムおよびプラグインのスキルは、最初からオンの状態で有効になります。

## セットアップ [#setup]

スキルは、すべてのユーザーに対してデフォルトで有効になっています。管理者は、`skills` エージェント機能を使用してこの機能をオフにできます(詳細は[エージェントエンドポイントの設定](/docs/configuration/librechat_yaml/object_structure/agents#capabilities)を参照してください)。スキルを作成および共有できるユーザーは、[管理パネル](/docs/features/admin_panel)または[`interface.skills`](/docs/configuration/librechat_yaml/object_structure/interface#skills)で制御できます。[スキル同期](/docs/configuration/librechat_yaml/object_structure/skill_sync)で説明されているように、ディスクまたは GitHub からスキルを提供できます。また、[`fileConfig.skills`](/docs/configuration/librechat_yaml/object_structure/file_config#skills)を使用して、アップロードのサイズ上限を変更できます。
