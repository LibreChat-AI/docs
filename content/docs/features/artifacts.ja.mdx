Artifacts（アーティファクト）を使うと、エージェントはコードの羅列ではなく、閲覧して実行できるものを提供できます。たとえば React コンポーネント、HTML ページ、SVG、Markdown ドキュメント、Mermaid ダイアグラムなどです。結果はチャットの横にあるパネルに表示され、そこでプレビューしたり、ソースを読んで編集したり、ダウンロードしたりできます。

## エージェントでアーティファクトを有効にする [#turn-on-artifacts-for-an-agent]

アーティファクトはエージェントに紐づいているため、チャットしているエージェントによって、アーティファクトを利用できるかどうかが決まります。

<Steps>
<Step>
Agent Builderでエージェントを開き、**Tools**セクションを見つけてください。
</Step>
<Step>
**Tools**の横にある**Add**を選択し、**Artifacts**を選んで、エージェントに追加します。
</Step>
<Step>
**Mode**を選択してから、エージェントを保存してください。
</Step>
</Steps>

モードは、アーティファクトに関して LibreChat がモデルに与える指示の内容を制御します:

- **通常**: 標準の指示です。エージェントは React、HTML、SVG、Markdown、Mermaid のアーティファクトを生成できます。
- **shadcn/ui**: shadcn/ui コンポーネントライブラリの手順を追加します。事前構築済みのコンポーネントを使って洗練されたインターフェースのモックアップを作成したい場合に役立ちます。
- **カスタム**: パネルとレンダリングは有効のまま、組み込みの指示は一切送信されません。エージェントのご自身の指示で、モデルにアーティファクトの構文と使用できる種類を教える必要があります。

カスタムモードの場合、LibreChat が参照するラッパーを指示に含める必要があります:

````md
:::artifact{identifier="unique-id" type="text/html" title="Short Title"}
```
Artifact content here
```
:::
````

`type` は `text/html`、`application/vnd.react`、`image/svg+xml`、`application/vnd.mermaid`、`text/markdown` のいずれかです。

## アーティファクトを開く [#opening-an-artifact]

エージェントがアーティファクトを作成すると、メッセージには生のコードの代わりに、アーティファクトのタイトルと種類を示す行が表示されます。その行をクリックするとパネルが開き、再度クリックするとパネルが閉じます。会話で複数のアーティファクトが生成された場合は、パネルのヘッダーにあるバージョンメニューから、それらを切り替えることができます。

Mermaidのコードブロックは、エージェントでアーティファクトが有効になっているかどうかにかかわらず、どのチャットでもコンパクトな図のカードとして表示されます。図の**アーティファクトとして開く**を使うと、その図をパネルに移動できます。

## パネルでの作業 [#working-in-the-panel]

- **プレビュー**はアーティファクトをレンダリングします。**更新**はプレビューを再読み込みします。これは、インタラクティブなコンポーネントが不正な状態になった後に役立ちます。
- **コード** はエディタでソースを表示します。レスポンスのストリーミングが完了した後は編集でき、変更はメッセージに保存されるため、プレビューや後で再度開いたときにも編集後のバージョンが表示されます。
- コピーボタンはソースをコピーします。**ダウンロード**を押すと、アーティファクトのタイトルを名前とした ファイルとして保存されます。コード実行で生成されたファイルは、編集していなければ元のファイルとしてダウンロードされます。編集されたものやプレビューのみのコンテンツには、元のファイルと取り違えないよう、ファイル名に `.preview` が付きます。
- Mermaid図では、代わりに**Export as SVG**と**Export as PNG**があり、パネルとインライン図の両方で利用できます。
- **全画面表示**を押すと、プレビューが画面全体に広がります。終了するには Escape キーを押してください。ブラウザが全画面表示を許可していない場合、このボタンは表示されません。
- **Open in new window**を選ぶと、パネルが別のブラウザウィンドウに移動します。サブモニターがある場合に便利です。レスポンスのストリーミング中もアーティファクトは更新され続け、保存されていないコードの編集内容も引き継がれます。チャットタブは開いたままにしてください。タブを閉じるとウィンドウも閉じてしまいます。**Dock back to panel**を選ぶか、ウィンドウを閉じると、パネルが元の場所に戻ります。LibreChatはウィンドウのサイズと位置を記憶します。何も開かない場合は、LibreChatのサイトでポップアップを許可してください。このボタンは、幅の狭いモバイルレイアウトでは表示されません。

プレビューは、CodeSandboxのSandpackを使用してサンドボックス化されたiframe内で実行されます。Reactアーティファクトは、あらかじめ決められた一般的なライブラリのセットをインポートできます。モデルには利用可能なライブラリが通知されており、それ以外のものは読み込みに失敗します。

コード実行によって作成されるファイル(HTMLレポート、Word文書、スプレッドシート、スライドデッキなど)も、このパネルで開きます。これらのプレビューの仕組みについては、[Code Interpreter](/docs/features/code_interpreter)を参照してください。

## セットアップ [#setup]

エージェントではアーティファクトがデフォルトで有効になっています。管理者が削除しない限り、`artifacts` エージェント機能は有効であり、各エージェントのツールにはアーティファクトを追加する必要があります。管理者は、モデルスペックでアーティファクトを有効にしたり、Sandpack バンドラーをセルフホストしたり、新しいウィンドウのオプションを無効にしたりすることもできます。詳しくは [アーティファクトの設定](/docs/configuration/artifacts) を参照してください。
