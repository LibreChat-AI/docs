LibreChat 的侧边栏提供了对话历史记录、置顶聊天、项目以及为部署启用的任何其他面板。可用的面板列表可以包括聊天、书签、提示词、记忆和 Skills。

## 桌面端侧边栏 [#desktop-sidebar]

使用侧边栏切换按钮来展开或折叠导航栏。从导航栏中选择一个面板，在配置后使用对话搜索功能，或者选择 **New chat** 来开始对话。项目（Projects）拥有其独立的侧边栏区域和作用域限定的“新建对话”快捷方式；请参阅 [Projects](/docs/features/projects)。

统一的 **Pinned** 部分将置顶对话与收藏的模型、Agents 和预设交织在一起。在基于指针的桌面设备上，拖动项目以重新排序；将对话拖动到 **Pinned** 以将其置顶，拖动到 Project 以将其归档，或拖动到 **Chats** 以移除其 Project 分配。置顶对话独立于常规历史记录加载，置顶、取消置顶或重新排序不会被计为新的对话活动。触摸屏设备使用现有菜单代替拖动交互。

## 筛选和排序聊天列表 [#filter-and-sort-the-chat-list]

**Chats** 标题上的 **Filter and sort chats** 按钮可打开聊天列表菜单。它包含三行，每一行都显示其当前值：

- **Show** 用于在 **Active chats** 和 **Archived chats** 之间切换。
- **排序**可按**更新时间**、**创建时间**或**标题**对列表进行排序，在归档视图中还可按**归档日期**排序。在**顺序**下，日期可选择**从新到旧**或**从旧到新**，标题可选择**从 A 到 Z** 或 **从 Z 到 A**。
- **Filter**（筛选器）用于缩小列表范围。其 **Search filters**（搜索筛选器）框可按名称查找筛选器或值。

**Filter** 子菜单提供：

| 筛选器 | 选项 |
| --- | --- |
| **更新时间**, **创建时间** | **任何时间**, **今天**, **过去 7 天**, **过去 30 天**, **过去一年** |
| **Endpoint** | 部署所服务的一个或多个 endpoint |
| **包含附件** | 仅限包含文件的对话 |
| **仅限已分享** | 仅限具有有效共享链接的对话；在启用共享链接时显示 |
| **书签** | 一个或多个书签；向可以使用书签的角色显示 |

当任何设置与默认列表不同时，按钮会显示当前处于活动状态的设置数量。菜单标题中的 **Reset**（重置）可恢复整个列表，而 **Filter**（筛选）子菜单底部的 **Clear filters**（清除筛选）仅清除筛选条件。显示和筛选选项会持续生效，直到您重新加载页面或注销；排序顺序则会在当前浏览器中被记住。管理员可以通过 [`conversationList`](/docs/configuration/librechat_yaml/object_structure/config#conversationlist) 来限制单个筛选器可以选择的 endpoint 数量。

## 未读回复 [#unread-replies]

当您在其他聊天中或离开 LibreChat 时，如果回复完成，该对话会在聊天列表中显示一个未读圆点，直到您打开它并使回复出现在屏幕上。已读状态会保存到您的账户中，因此在一个设备上打开聊天会清除您其他设备上的圆点。

若要稍后返回某个对话，请打开其菜单并选择 **Mark as unread**。当前已打开的对话或已标记为未读的对话不会显示此选项。

临时聊天记录永远不会显示为未读，没有任何内容可读的回复（例如在第一个 token 生成前停止的回复）也不会显示为未读。关于标签页标题计数、桌面通知和声音，请参阅 [Notifications](/docs/features/settings#notifications)。

## 移动端侧边栏 [#mobile-drawer]

在移动设备上，侧边栏默认以全屏抽屉形式打开。其页眉包含侧边栏切换按钮、带标签的面板切换器、一个 **New chat** 图标按钮以及账户控件，且在每个面板上保持一致。拥有 Agent Marketplace 访问权限的用户还会在面板内容上方看到一行 **Agent Marketplace**。底部栏仅包含对话搜索功能，且仅在聊天历史记录面板处于活动状态时显示。

仅限浏览器的 **Settings > General > Layout > Show chat beside the sidebar on mobile** 首选项默认处于关闭状态。开启后，抽屉式导航栏将限制在视口的 80% 范围内，从而使当前对话的暗色条带保持可见。点击该条带即可关闭抽屉并返回对话。

您也可以通过触摸手势进行导航：

- 在聊天面板上向右滑动即可打开侧边栏。
- 在打开的抽屉内向左滑动即可将其关闭。

抽屉组件会跟随手势移动，并根据距离和速度决定最终是保持打开还是关闭状态。在使用默认的全宽抽屉时，通过按钮、键盘或对话触发的关闭操作，可以在不移动已加载内容的情况下显示已定位的聊天界面。当启用聊天栏（chat strip）时，抽屉和可见的对话会同步移动。每种关闭路径在移动界面恢复交互后，都会将焦点恢复到页眉打开器或聊天面板。垂直滚动、文本字段、文本选择以及代码块等水平可滚动内容将保持对其自身手势的控制。减少动画（Reduced-motion）偏好设置将移除抽屉和聊天栏的过渡动画。

## 已归档的对话 [#archived-conversations]

从账户菜单中打开 **Archived chats**（已归档聊天）以浏览或恢复已归档的对话，或者通过 [chat list menu](#filter-and-sort-the-chat-list)（聊天列表菜单）中的 **Show**（显示）将侧边栏列表切换为已归档聊天。新归档的聊天按归档时间排序。在 LibreChat 记录该时间戳之前归档的对话将回退至其创建日期。

若要清除当前聊天列表而不删除其中的对话，请使用 **Settings > Data Controls > Your data** 下的 **Archive all chats** 并确认该操作。

归档、取消归档、置顶和取消置顶操作不再更新对话的聊天活动时间，因此历史记录和项目活动将继续基于实际的对话更改。
