会話インポート（Conversations Import）を使うと、他の AI チャットアプリケーションからエクスポートした会話を LibreChat に取り込めます。対応しているソースは [ChatGPT](https://chatgpt.com/)、[Claude](https://claude.ai/)、[ChatbotUI v1](https://github.com/mckaywrigley/chatbot-ui/tree/b865b0555f53957e96727bc0bbb369c9eaecd83b?tab=readme-ov-file#legacy-code)、そして LibreChat 独自の JSON エクスポート（[Export from LibreChat](#export-from-librechat) を参照）です。

<Callout type="info" title="場所の確認方法">
LibreChat における会話のインポートは、**設定** > **データとプライバシー** > **あなたのデータ** > **会話をインポート** から行えます。
</Callout>

## ソースアプリケーションからのエクスポート [#export-from-the-source-application]

まず、移行元のアプリケーションからデータをエクスポートしてください。手順はソースによって異なります。

<Callout type="info" title="LibreChatからエクスポートする方法をお探しですか？">
このページの下部にある [Export from LibreChat](#export-from-librechat) を参照してください。
</Callout>

<Tabs items={["ChatGPT", "Claude", "ChatbotUI v1"]}>
<Tabs.Tab>

<Steps>
<Step>

**エクスポートをリクエストします。** [ChatGPTのエクスポート手順](https://help.openai.com/en/articles/7260999-how-do-i-export-my-chatgpt-history-and-data) に従って、会話をエクスポートしてください。

</Step>
<Step>

**アーカイブをダウンロードします。** ダウンロードリンクが記載されたメールが届きます。アーカイブは、`d119d98bb3711aff7a2c73bcc7ea53d96c984650d8f7e033faef78386a9907-2024-01-01-10-30-00.zip` のようなランダムな名前のzipファイルです。

</Step>
<Step>

**アーカイブを解凍**して、中にある `conversations.json` ファイルにアクセスします。

</Step>
</Steps>

## LibreChat にインポートする [#import-into-librechat]

<Steps>
<Step>

**オープンデータとプライバシー。** LibreChatで**設定** > **データとプライバシー**に移動し、**あなたのデータ**の下にある**会話をインポート**を見つけてください。

</Step>
<Step>

**ファイルを選択します。** **Import** をクリックし、展開したアーカイブ内の `conversations.json` ファイル(または ChatbotUI v1 もしくは LibreChat からエクスポートした JSON ファイル)を選択します。ファイル選択ダイアログは `.json` ファイルのみを受け付けるため、ChatGPT や Claude の zip アーカイブは事前に展開してください。

</Step>
<Step>

**確認を待機します。** インポートが完了すると通知が表示されます。

</Step>
</Steps>

管理者は、[`CONVERSATION_IMPORT_MAX_FILE_SIZE_BYTES`](/docs/configuration/dotenv#conversation-import) を使用してアップロードサイズの上限を設定できます。

## インポートされたコードの承認設定 [#imported-code-approval-settings]

LibreChat の会話をインポートする際、保存された Code の承認モード(**Full access** を含む)は引き継がれません。新しくインポートされた会話には、受け取り側の既存の設定やデフォルト、現在のデプロイメントおよびワーカーのポリシーが適用されます。一括更新によって、ローカルに保存された承認の選択が上書きされることはありません。この安全対策は既存の会話を遡ってリセットするものではありません。ユーザーは引き続き LibreChat を通じて、サポートされているモードを選択して保存できます。詳細は [Attached-environment tool permissions](/docs/features/code_interpreter#running-code-on-your-own-machine) を参照してください。

## LibreChat からのエクスポート [#export-from-librechat]

エクスポートは会話ごとに行われ、チャットヘッダーの **Chat options** メニュー(モバイルではオーバーフローメニューの下)にあります。このメニューには **Share**、**Rename**、**Pin**、**Duplicate**、**Archive**、**Delete** も並んでいます。対象の会話を開き、**Export** を選択して形式を選び、確定してください。

    ['markdown', '.md', '読み取り可能なトランスクリプト。デフォルト設定。', ''],
    ['text', '.txt', 'プレーンテキストのトランスクリプト', ''],

    ['csv', '.csv', '表形式でのエクスポート（メッセージごとに1行）。', 'Supports exporting all message branches'],
    ['screenshot', '.png', 'レンダリングされた会話の画像', ''],
  ]}
/>

`json`形式のエクスポートは、**設定** > **データとプライバシー** > **あなたのデータ** > **会話をインポート**から、LibreChatに再度インポートできます。

ダイアログ内の2つのオプションは、選択したフォーマットによって異なります。

- **Export all message branches** は `json` および `csv` にのみ適用されます。その他の形式では、表示されているブランチのみがエクスポートされます。
- 残りのエクスポートオプションは、`csv` および `screenshot` では利用できません。

<Callout type="info" title="スコープ">

すべての会話を一度にまとめてエクスポートする組み込み機能はありません。また、作成したばかりの会話や検索結果の会話にはエクスポートする内容がないため、それらの場合にはメニューが表示されません。

</Callout>
