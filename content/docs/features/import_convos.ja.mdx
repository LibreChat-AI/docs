LibreChat からエクスポートした JSON 形式の会話に加えて、ChatGPT、Claude、および [ChatbotUI v1](https://github.com/mckaywrigley/chatbot-ui/tree/b865b0555f53957e96727bc0bbb369c9eaecd83b?tab=readme-ov-file#legacy-code) からエクスポートした会話をインポートできます。インポートされたチャットは、他のチャットと同様に履歴に表示されます。エクスポートは一度に 1 つの会話ずつ行われます。

## ファイルをインポートする [#import-the-file]

**設定** > **データとプライバシー** に移動し、「Import conversations from a JSON file」の横にある **Import** を選択して、ファイルを選んでください。ファイルピッカーは `.json` のみを受け付けるため、ChatGPT と Claude のアーカイブは先に解凍してください。処理中はボタンに「Importing」と表示され、完了すると「Conversations imported successfully」が表示されます。

LibreChat は、ファイル名ではなくファイルの内容からフォーマットを判別します。認識できないファイルの場合、「Unsupported import type」というエラーが表示されます。

LibreChat のインポートでは、会話に保存されていたコードの承認モード（**Full access** を含む）や未読状態は引き継がれません。インポートされたチャットでは、ご自身の現在の承認設定とデプロイのポリシーが適用されます。

### 制限 [#limits]

- ファイルは、管理者が別の上限を設定していない限り、最大250 MiBまでアップロードできます。これより大きいファイルは、アップロード前に拒否されます。
- 1つの会話またはメッセージのサイズは、約16 MBを超えることはできません。これはデータベースの上限によるものです。
- インポートはユーザーごと、およびIPアドレスごとにレート制限されているため、ファイルを連続して大量にインポートすると、一定時間拒否される場合があります。

## 会話をエクスポートする [#export-a-conversation]

会話を開き、**Chat options** メニュー(ヘッダーの `...` ボタン、小さい画面ではヘッダーメニュー)を開いて、**Export** を選択します。ファイル名と形式を選び、**Export** を選択してください。

| Type | 内容 |
| --- | --- |
| `markdown` (.md) | 読みやすい会話の記録。これがデフォルトです。 |
| `text` (.txt) | プレーンテキストの会話の記録。 |
| `json` (.json) | メッセージデータの全体。LibreChat で再インポートできる形式です。 |
| `csv` (.csv) | メッセージごとに 1 行。 |
| `screenshot` (.png) | 画面に表示されている状態の会話の画像。 |

**すべてのメッセージブランチをエクスポート** は `json` と `csv` で動作し、その他の形式では表示中のブランチのみがエクスポートされます。**エンドポイントオプションを含める** を選ぶと、モデルとその設定が追加されます。この機能は `csv` と `screenshot` では利用できません。`json` の場合は、**Recursive**（親メッセージの下にネストされたメッセージ）または sequential（連続）を選択することもできます。

すべての会話を一括でエクスポートする機能はありません。また、新しいチャットや検索結果にはエクスポートする内容がないため、そこにはメニューが表示されません。

## セットアップ [#setup]

インポートとエクスポートは、設定を行わなくてもすべてのユーザーが利用できます。管理者は、`CONVERSATION_IMPORT_MAX_FILE_SIZE_BYTES` でインポートのサイズ上限を、`IMPORT_*` 変数でレート制限を変更できます。詳しくは [.env リファレンス](/docs/configuration/dotenv#conversation-import) を参照してください。
