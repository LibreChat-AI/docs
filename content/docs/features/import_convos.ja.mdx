Conversations Importを使用すると、他のAIチャットアプリケーションからエクスポートされた会話をLibreChatに取り込むことができます。サポートされているソースは、[ChatGPT](https://chatgpt.com/)、[Claude](https://claude.ai/)、および[ChatbotUI v1](https://github.com/mckaywrigley/chatbot-ui/tree/b865b0555f53957e96727bc0bbb369c9eaecd83b?tab=readme-ov-file#legacy-code)です。

<Callout type="info" title="場所の確認方法">
インポートは、LibreChatの**設定** → **データコントロール**から行えます。
</Callout>

## ソースアプリケーションからのエクスポート [#export-from-the-source-application]

まず、移行元のアプリケーションからデータをエクスポートしてください。手順はソースによって異なります。

<Callout type="info" title="LibreChatからエクスポートする方法をお探しですか？">
このページの下部にある [Export from LibreChat](#export-from-librechat) を参照してください。
</Callout>

<Tabs items={["ChatGPT", "Claude", "ChatbotUI v1"]}>
<Tabs.Tab>

<Steps>
<Step>

**エクスポートをリクエストします。** [ChatGPTのエクスポート手順](https://help.openai.com/en/articles/7260999-how-do-i-export-my-chatgpt-history-and-data) に従って、会話をエクスポートしてください。

</Step>
<Step>

**アーカイブをダウンロードします。** ダウンロードリンクが記載されたメールが届きます。アーカイブは、`d119d98bb3711aff7a2c73bcc7ea53d96c984650d8f7e033faef78386a9907-2024-01-01-10-30-00.zip` のようなランダムな名前のzipファイルです。

</Step>
<Step>

**アーカイブを解凍**して、中にある `conversations.json` ファイルにアクセスします。

</Step>
</Steps>

</Tabs.Tab>
<Tabs.Tab>

<Steps>
<Step>

**エクスポートをリクエストします。** [Claudeのエクスポート手順](https://support.claude.com/en/articles/9450526-how-can-i-export-my-claude-data) に従って、会話をエクスポートしてください。

</Step>
<Step>

**アーカイブをダウンロードします。** エクスポートアーカイブのダウンロードリンクが記載されたメールが届きます。

</Step>
<Step>

**アーカイブを解凍**して、中にある `conversations.json` ファイルにアクセスします。

</Step>
</Steps>

</Tabs.Tab>
<Tabs.Tab>

[ChatbotUI v1](https://github.com/mckaywrigley/chatbot-ui/tree/b865b0555f53957e96727bc0bbb369c9eaecd83b?tab=readme-ov-file#legacy-code) から会話をエクスポートし、その結果生成されたJSONファイルを直接インポートしてください。抽出ステップは不要です。

</Tabs.Tab>
</Tabs>

## LibreChat にインポートする [#import-into-librechat]

<Steps>
<Step>

**データ制御を開く。** LibreChatで、**設定** → **データ制御** に移動します。

</Step>
<Step>

**ファイルを選択します。** **Import** をクリックし、展開したアーカイブから `conversations.json` ファイル（または ChatbotUI v1 用のエクスポート済み JSON ファイル）を選択します。

</Step>
<Step>

**確認を待機します。** インポートが完了すると通知が表示されます。

</Step>
</Steps>

## インポートされたコードの承認設定 [#imported-code-approval-settings]

LibreChatの会話をインポートする際、保存されていたコード承認モード（**Full access**を含む）は引き継がれません。新しくインポートされた会話には、受信側の既存の設定やデフォルト、および現在のデプロイメントやワーカーのポリシーが適用されます。一括更新によって、ローカルに保存された承認設定を上書きすることはできません。この保護機能は既存の会話を遡ってリセットするものではなく、ユーザーは引き続きLibreChatを通じてサポートされているモードを選択・保存できます。詳細は [Attached-environment tool permissions](/docs/features/code_interpreter#attached-environment-tool-permissions) を参照してください。

## LibreChat からのエクスポート [#export-from-librechat]

エクスポートは会話ごとに行われ、チャットヘッダーの **Export and Share** メニュー（モバイルではオーバーフローメニュー内）にあります。エクスポートしたい会話を開き、**Export** を選択して形式を選び、確定してください。

<OptionTable
  options={[
    ['markdown', '.md', '読み取り可能なトランスクリプト。デフォルト設定。', ''],
    ['text', '.txt', 'プレーンテキストのトランスクリプト', ''],
    ['json', '.json', '完全なメッセージデータを保持する構造化エクスポート。', 'Supports exporting all message branches'],
    ['csv', '.csv', '表形式でのエクスポート（メッセージごとに1行）。', 'Supports exporting all message branches'],
    ['screenshot', '.png', 'レンダリングされた会話の画像', ''],
  ]}
/>

ダイアログ内の2つのオプションは、選択したフォーマットによって異なります。

- **Export all message branches** は `json` および `csv` にのみ適用されます。その他の形式では、表示されているブランチのみがエクスポートされます。
- 残りのエクスポートオプションは、`csv` および `screenshot` では利用できません。

<Callout type="info" title="スコープ">

すべての会話を一度にまとめてエクスポートする組み込み機能はありません。また、作成したばかりの会話や検索結果の会話にはエクスポートする内容がないため、それらの場合にはメニューが表示されません。

</Callout>
