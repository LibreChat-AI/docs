共享链接允许您发布对话的只读分支，其他人可以通过生成的 URL 或二维码打开该分支。接收者可以查看已发布的消息、分支和工件，而不会更改原始对话。已登录的接收者可以从可见分支继续对话，并将其保存为个人副本。

## 核心功能 [#key-features]

- **轻松共享**：只需点击几下即可生成链接。
- **QR codes**: 通过扫描二维码在手机上打开对话。
- **分支 (Branching)**：共享链接会保留对话的每一个分支。
- **Artifacts**: React 组件、HTML 预览和 Mermaid 图表保持交互性。
- **文件快照**：引用的对话文件可以在共享链接中预览或下载，而无需向接收者授予所有者实时文件 ACL 的访问权限。
- **作为副本继续**：已登录的查看者可以将可见的分支复制到他们自己的对话历史记录中，并继续进行对话。
- **接收者偏好设置**：查看者可以切换语言和主题。
- **稳定更新**：发布新的对话轮次和当前文件选择，且不更改 URL。
- **共享徽章**：活跃链接会在对话列表和聊天标题中进行标记。
- **链接管理**：一个用于查看或撤销您所创建的每一个链接的仪表板。

您可以从两个地方开始共享。

## 分享链接选项 [#share-link-options]

创建链接会打开一个模态框，您可以在其中控制对话对接收者呈现的方式。

![创建共享链接模态框](/images/shared-links/share-modal-create.png)

![带有管理选项的共享链接模态框](/images/shared-links/share-modal-options.png)

一旦链接存在，模态框将提供以下操作：

- **更新链接**：通过选定的分支末端和当前文件共享选项重新发布最新消息，同时保持 URL 不变。
- **Show QR Code** / **Hide QR Code**:切换用于移动端访问的二维码。
- **复制链接**: 复制可分享的 URL。
- **管理访问权限**:打开访问对话框,以控制谁可以打开该链接。仅当您的角色拥有共享链接的分享权限,且您持有该链接的分享权限位时,该选项才会显示。
- **删除链接**:移除该链接,并撤销所有持有该链接的用户的访问权限。

当启用文件快照功能时，用户可以选择链接是否包含已发布消息中引用的文件。所选文件会被固定在该共享版本中，并通过特定于共享的路由提供服务，而不会授予对所有者实时文件 ACL 的访问权限。更新链接会替换已固定的文件集和文件共享选项；稳定的文件 URL 会重新验证，因此已移除或替换的快照不会从旧的浏览器缓存中提供。

发布与所选分支的精确持久化末端（persisted tail）绑定。如果其最新消息仍在保存中，LibreChat 会在不切换到其他分支的情况下重试一次。如果末端仍然不可用，或者对话尚未有任何持久化消息，模态框会显示特定错误，以便您可以等待并重试。不可用的共享链接视图也提供 **Retry**（重试）功能以重新获取相同的 URL。

## 二维码 [#qr-codes]

为任何共享对话生成二维码，然后使用手机摄像头扫描即可打开链接。该二维码指向与共享链接相同的地址。

![为共享链接生成的二维码](/images/shared-links/qr-code.png)

![QR code download options](/images/shared-links/qr-code-download.png)

QR 码在演示文稿、快速移动端访问、打印讲义和会议演示中非常实用。

## 查看共享对话 [#viewing-shared-conversations]

当有人打开您的链接时，他们会看到已发布分支的专注、只读视图，包括其日期、消息和工件。

![接收者视角下的共享对话](/images/shared-links/shared-view.png)

## 继续共享对话 [#continue-a-shared-conversation]

已通过身份验证的查看者可以选择 **Continue this chat**，从当前显示的分支创建一个个人对话。LibreChat 仅会复制通往当前消息的直接路径，包括符合条件的快照文件引用，并在查看者的账户下开启新的对话。

继续操作永远不会更改共享快照或所有者的对话。公开查看者必须先登录，LibreChat 才能创建他们的副本。

复制请求与查看者加载的共享版本相关联。如果所有者在查看者继续操作之前更新了同一个链接，LibreChat 会重新加载当前版本并要求查看者重试，而不是从过时的内容中复制消息位置。

## 分支 (Branching) [#branching]

共享链接会保留对话分支，因此接收者可以跟随讨论的不同路径进行查看。使用分支导航箭头可在这些路径之间切换。

![共享对话中的分支导航菜单](/images/shared-links/branching-menu.png)

![在共享对话中导航分支](/images/shared-links/branching-support.png)

这对于展示不同的提示词如何引导出不同的 AI 回复，或者如何用多种方式解决同一个问题非常有用。

## Artifacts [#artifacts]

对话过程中生成的 Artifacts 在共享链接中保持完全可用。

![共享对话中的交互式工件](/images/shared-links/artifacts-support.png)

接收者可以：

- 查看交互式 React 组件。
- 查看 HTML 预览。
- 检查 Mermaid 图表。
- 阅读底层代码及其生成时所处的上下文。

## 接收者偏好设置 [#recipient-preferences]

查看者可以根据自己的偏好调整界面，而不会影响您的设置。

![共享链接上的语言和主题设置](/images/shared-links/recipient-settings.png)

- **主题**：浅色、深色或系统。
- **语言**：以用户偏好的语言查看界面。

## 管理您的共享链接 [#managing-your-shared-links]

在 **设置 > Data & Privacy > Your data > Shared chats** 下打开 **Shared chats** 仪表板,即可查看您分享过的所有对话。

Note: "Data & Privacy" is a UI label that appears in the settings path. Per the rules I've kept the bold UI-path text, but I should flag that the translation rules only cover specific terms, and the menu labels here are English UI strings; if you want them localized to the Chinese UI, let me know.

![共享链接管理仪表板](/images/shared-links/management-modal.png)

![单个共享链接的详细信息和选项](/images/shared-links/management-details.png)

从仪表板中，您可以：

- **查看所有链接**：查看您分享过的所有对话。
- **搜索和筛选**：查找特定的共享链接并预览其内容。
- **撤销访问权限**：删除链接以立即停止共享。

具有活动共享链接的对话也会在侧边栏中显示一个链接徽章，聊天标题的共享控件也会显示相同的活动状态。

## 配置 [#configuration]

`.env` 文件中的三个环境变量控制此功能：

- **`ALLOW_SHARED_LINKS`** (默认值: `true`): 启用共享链接功能。设置为 `false` 可禁止用户创建链接。
- **`ALLOW_SHARED_LINKS_PUBLIC`** (默认值: `false`): 控制链接是否可以在无需身份验证的情况下打开。默认情况下，接收者必须登录。设置为 `true` 以允许公开、未经身份验证的访问。
- **`SHARED_LINKS_SNAPSHOT_FILES`** (默认值: `true`): 控制共享链接是否可以包含引用的对话文件。当设置此环境变量时，它将覆盖 [`interface.sharedLinks.snapshotFiles`](/docs/configuration/librechat_yaml/object_structure/interface#sharedlinks)。

```bash title=".env"
# Enable shared links (default)
ALLOW_SHARED_LINKS=true

# Require authentication to view shared links (default)
ALLOW_SHARED_LINKS_PUBLIC=false

# Include referenced files in shared-link snapshots (default)
SHARED_LINKS_SNAPSHOT_FILES=true
```

角色权限决定了哪些用户可以创建链接、与已认证用户共享链接，或使其对实例上的所有人可见：

```yaml title="librechat.yaml"
interface:
  sharedLinks:
    create: true
    share: true
    public: false
    snapshotFiles: true
```

`sharedLinks.public` 控制用户是否可以切换“与所有人共享”。`ALLOW_SHARED_LINKS_PUBLIC` 仍然决定这些公开链接是否可以在未登录的情况下查看。`sharedLinks.snapshotFiles` 控制来自 YAML 的默认文件快照行为，而 `SHARED_LINKS_SNAPSHOT_FILES` 可以全局覆盖或禁用该行为。

<Callout type="info">
有关完整的环境变量参考，请参阅 [.env Configuration](/docs/configuration/dotenv#shared-links) 页面。
</Callout>

## 常见问题解答 [#frequently-asked-questions]

<Accordions type="single" collapsible>
<Accordion title="接收者可以回复共享的对话吗？">

共享快照保持只读状态。已登录的接收者可以选择 **Continue this chat** 来创建个人副本，并在其中与 AI 进行交互。

</Accordion>
<Accordion title="如果我在分享对话后将其删除，会发生什么？">

该链接将失效。任何访问该链接的人都会看到“Shared link not found”页面。

</Accordion>
<Accordion title="分享对话后，我可以对其进行编辑吗？">

是的。链接中已包含的消息的编辑内容会显示在共享视图中。已发布分支末尾之外的新对话轮次，只有在您选择 **Update link** 后才会显示；URL 保持不变。

</Accordion>
<Accordion title="共享链接可以离线使用吗？">

不可以。接收者需要互联网连接才能查看共享的对话。

</Accordion>
</Accordions>
