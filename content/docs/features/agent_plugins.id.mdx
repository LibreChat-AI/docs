Agent Plugins memungkinkan operator untuk mengemas [Skills](/docs/features/skills), [MCP servers](/docs/features/mcp), dan command hook opsional yang saling terkait ke dalam sistem berkas LibreChat. LibreChat mengimplementasikan format paket Agent Plugins `1.0.0` dan memuat setiap direktori anak langsung sebagai satu plugin saat startup.

<Callout type="warning" title="Eksperimental">
  Agent Plugins bersifat eksperimental. Format paket, komponen yang didukung, konfigurasi, dan perilaku runtime dapat berubah selama fase eksperimen. Uji plugin sebelum menggunakannya dalam deployment produksi.
</Callout>

## Konfigurasi Direktori [#configure-the-directories]

```bash filename=".env"
# Defaults to ./plugin relative to the LibreChat project root
DEPLOYMENT_PLUGINS_DIR=./plugin

# Persistent data allocated separately for each plugin manifest name
DEPLOYMENT_PLUGIN_DATA_DIR=./data/plugins

# Optional and disabled by default; see Command Hooks below
# DEPLOYMENT_PLUGIN_HOOKS=true
```

Relative paths diselesaikan dari root proyek LibreChat. Jika direktori `./plugin` default tidak ada, startup akan berlanjut tanpa plugin. Jika `DEPLOYMENT_PLUGINS_DIR` diatur secara eksplisit tetapi tidak dapat dibaca, startup akan gagal agar kesalahan deployment tidak diabaikan begitu saja.

Mulai ulang LibreChat setelah menambah, menghapus, atau mengubah plugin.

## Tata Letak Paket [#package-layout]

Setiap anak langsung dari `DEPLOYMENT_PLUGINS_DIR` adalah satu paket plugin:

```text
plugin/
  analytics-tools/
    plugin.json
    skills/
      analyze-events/
        SKILL.md
        scripts/
          analyze.py
    mcp.json
    ai.librechat/
      hooks/
        hooks.json
    scripts/
      guard.sh
```

`plugin.json` diperlukan. `skills/`, `mcp.json`, dan `ai.librechat/hooks/hooks.json` bersifat opsional dan gagal secara independen, sehingga satu komponen yang tidak valid tidak akan mencegah komponen valid lainnya dalam plugin yang sama untuk dimuat. Manifest yang tidak valid atau hilang akan menolak seluruh plugin. Diagnostik ditulis ke dalam log startup LibreChat.

## Manifest [#manifest]

Manifest harus menggunakan URL skema Agent Plugins `1.0.0` yang tepat:

```json filename="plugin.json"
{
  "$schema": "https://agent-plugins.org/schemas/1.0.0/plugin.schema.json",
  "name": "analytics-tools",
  "version": "1.0.0",
  "description": "Skills and tools for analyzing event data"
}
```

`name` juga digunakan untuk direktori data persisten plugin. Nama tersebut harus terdiri dari 1-64 karakter, diawali dan diakhiri dengan huruf kecil atau angka, hanya menggunakan huruf kecil, angka, tanda hubung, dan titik, serta tidak boleh mengandung urutan `--` atau `..` yang berurutan. Nama plugin harus unik dalam deployment.

## Bundled Skills [#bundled-skills]

Letakkan setiap Skill di direktori anak langsung di bawah `skills/`, dengan `SKILL.md` di root anak tersebut. LibreChat memuat entri yang valid sebagai Skill penerapan read-only dan menerapkan kemampuan Skill serta aturan akses yang normal.

[`DEPLOYMENT_SKILLS_DIR`](/docs/features/skills#deployment-skills) mandiri lebih diutamakan daripada Skill plugin dengan nama yang sama. Di dalam direktori plugin, paket pertama yang mengklaim nama Skill akan menang dan konflik berikutnya akan dilewati dengan peringatan.

## Server MCP Bawaan [#bundled-mcp-servers]

Definisikan server MCP opsional di `mcp.json` dengan URL skema `1.0.0` yang tepat:

```json filename="mcp.json"
{
  "$schema": "https://agent-plugins.org/schemas/1.0.0/mcp.schema.json",
  "mcpServers": {
    "analytics": {
      "type": "stdio",
      "command": "node",
      "args": ["${PLUGIN_ROOT}/server.js"],
      "cwd": "${PLUGIN_ROOT}",
      "env": {
        "PLUGIN_CACHE": "${PLUGIN_DATA}/cache"
      }
    }
  }
}
```

Transport yang didukung adalah `stdio`, `streamable-http`, dan `sse`. Transport HTTP jarak jauh harus menggunakan HTTPS kecuali untuk tujuan loopback. Nama server harus tetap tidak berubah setelah normalisasi nama alat MCP oleh LibreChat dan tidak boleh menggunakan nama objek JavaScript yang dicadangkan.

Untuk server `stdio`, `${PLUGIN_ROOT}` dan `${PLUGIN_DATA}` diekspansi satu kali di dalam `args`, `env`, dan `cwd`; kedua nilai tersebut juga ditambahkan ke lingkungan proses yang dijalankan. Konfigurasi MCP plugin tidak mengekspansi variabel arbitrer dari lingkungan host LibreChat. Nilai seperti `${OPENAI_API_KEY}` akan tetap literal melalui penyimpanan registri dan inisialisasi runtime. Simpan kredensial di luar file plugin dan sediakan melalui layanan terautentikasi yang dibuat khusus atau mekanisme lain yang dikontrol oleh deployment.

LibreChat memvalidasi setiap `mcp.json` sebelum mendaftarkan server-servernya:

- `command` harus berupa satu token yang dapat dieksekusi: baik nama sederhana seperti `node` atau path yang diawali `./` di dalam plugin. String shell dan path absolut akan ditolak, dan `${PLUGIN_ROOT}` tidak akan di-expand di dalam `command`.
- `cwd` harus diawali dengan `./`, `${PLUGIN_ROOT}`, atau `${PLUGIN_DATA}`, dan harus mengarah ke lokasi di dalam basis yang disebutkan.
- `env` tidak boleh mendeklarasikan `PLUGIN_ROOT` atau `PLUGIN_DATA`; LibreChat yang menetapkannya.
- Nilai `url` remote harus berupa URL absolut `http` atau `https` tanpa informasi pengguna (user information) atau fragmen (fragment), dan harus menggunakan `https` kecuali host-nya adalah alamat loopback (seperti `localhost` atau `127.0.0.1`).
- Entri server dengan kolom yang tidak dikenal akan ditolak dan dilewati. Kolom tingkat atas yang tidak dikenal, atau `$schema` yang tidak cocok dengan URL skema `1.0.0` yang didukung, akan menonaktifkan MCP untuk seluruh plugin.

Server MCP yang dideklarasikan dalam `librechat.yaml` memiliki prioritas lebih tinggi daripada server plugin dengan nama yang sama. Nama server plugin duplikat akan dilewati dan dicatat dalam log.

## Data Plugin Persisten [#persistent-plugin-data]

LibreChat membuat satu direktori di `<DEPLOYMENT_PLUGIN_DATA_DIR>/<plugin-name>` dan mengeksposnya ke komponen `stdio` sebagai `${PLUGIN_DATA}`. Gunakan direktori ini untuk status persisten milik plugin. Jangan menulis status persisten ke dalam `${PLUGIN_ROOT}`, yang harus diperlakukan sebagai konten paket.

## Command Hooks [#command-hooks]

Agent Plugins dapat menjalankan penangan hook `command` pada batas siklus hidup Agent. Eksekusi hook dinonaktifkan secara default. Aktifkan secara eksplisit dan mulai ulang LibreChat:

```bash filename=".env"
DEPLOYMENT_PLUGIN_HOOKS=true
```

Ketika variabel tersebut bernilai false atau tidak diatur, LibreChat akan mengabaikan dokumen hook dan mencatat peringatan saat startup; Skills dan server MCP yang valid secara independen milik plugin tersebut akan tetap dimuat.

<Callout type="warning" title="Hanya kode terpercaya">
  Command hook menjalankan proses anak yang diinstal operator pada host API LibreChat. Lingkungan yang dibatasi mengurangi paparan yang tidak disengaja namun bukan merupakan sandbox. Aktifkan hook hanya untuk paket plugin yang Anda percayai pada tingkat yang sama dengan kode LibreChat dan modul hook `toolApproval`.
</Callout>

Deklarasikan hook di `ai.librechat/hooks/hooks.json`:

```json filename="ai.librechat/hooks/hooks.json"
{
  "description": "Reject writes outside the workspace",
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          {
            "type": "command",
            "command": "${CLAUDE_PLUGIN_ROOT}/scripts/guard.sh",
            "timeout": 30,
            "allowedEnvVars": ["WORKSPACE_POLICY"]
          }
        ]
      }
    ]
  }
}
```

### Kontrak Eksekusi [#execution-contract]

- LibreChat memulai perintah dari root plugin dan mengirimkan payload event yang kompatibel dengan Claude sebagai JSON pada standard input.
- `${PLUGIN_ROOT}`, `${PLUGIN_DATA}`, dan `${CLAUDE_PLUGIN_ROOT}` diperluas satu kali di dalam `command` dan `args` serta tersedia juga untuk proses anak (child process).
- Lingkungan anak hanya berisi `PATH`, `HOME`, `LANG`, `LC_ALL`, dan `TZ` jika ada, tiga variabel jalur plugin, dan nama-nama yang tercantum secara eksplisit dalam `allowedEnvVars`.
- Exit code `0` berhasil. JSON yang ditulis ke output standar dapat mengembalikan keputusan yang sesuai dengan peristiwa dan konteks terbatas; output biasa hanya diperlakukan sebagai konteks tambahan untuk `SessionStart` dan `UserPromptSubmit`.
- Exit code `2` memblokir tindakan atau kelanjutan yang berlaku dan menggunakan kesalahan standar sebagai alasannya. Exit code bukan nol lainnya dicatat dan diabaikan.
- `timeout` dalam satuan detik, berupa bilangan bulat dari 1 hingga 3600.
- LibreChat menghentikan proses ketika hook dibatalkan atau melewati batas waktu. Pada host POSIX, perintah dijalankan melalui `bash`, yang harus tersedia di host API. Pada host Windows, perintah dijalankan melalui `powershell.exe`, sehingga plugin harus menyediakan `commandWindows` atau memilih PowerShell. Jika shell tidak dapat dimulai, LibreChat mencatat peringatan startup dan hook yang bersifat blocking akan gagal secara tertutup (fail closed).

LibreChat menerjemahkan nama alat Claude yang umum yaitu `Bash`, `Write`, `Edit`, `Read`, dan `WebSearch` serta nama argumen berkasnya ke alat LibreChat yang sesuai. Matcher yang ditulis dengan nama alat asli LibreChat akan mempertahankan bentuk payload aslinya.

Peristiwa sumber yang didukung adalah `RunStart`, `SessionStart`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `PostToolUseFailure`, `PostToolBatch`, `SubagentStart`, `Stop`, `StopFailure`, `PreCompact`, dan `PostCompact`. Peristiwa atau deklarasi yang tidak didukung akan dilewati dan dilaporkan dalam diagnostik startup. Hanya penangan `command` yang dieksekusi dalam rilis ini; penangan `prompt`, `http`, `mcp_tool`, dan `agent` tetap tidak didukung.

`SessionStart` dan handler dengan `once: true` dideduplikasi per percakapan oleh penyimpanan lokal proses yang dibatasi. Dalam penyebaran multi-replika, handler sekali pakai yang sama dapat berjalan satu kali pada setiap proses. Keputusan `ask` memerlukan alur persetujuan manusia yang dapat dilanjutkan di LibreChat; ketika alur tersebut tidak tersedia, LibreChat memperketat keputusan menjadi `deny` alih-alih membiarkan proses tersebut terjeda tanpa jalur untuk melanjutkannya.
