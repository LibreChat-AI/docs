Sebuah Agent Plugin adalah folder di server LibreChat yang menggabungkan [Skills](/docs/features/skills), [MCP servers](/docs/features/mcp), dan command hooks opsional yang saling terkait. Operator cukup memasukkan folder tersebut ke direktori plugin dan me-restart LibreChat; tidak ada yang perlu diinstal dari UI. LibreChat mengikuti format paket Agent Plugins `1.0.0` yang terbuka, sehingga satu paket dapat dibagikan dengan alat lain yang juga mendukung format tersebut.

Plugin Agen bersifat eksperimental. Format paket dan perilakunya dapat berubah.

## Apa yang dilihat pengguna [#what-users-see]

Pengguna tidak pernah melihat plugin sebagai sesuatu yang berdiri sendiri. Yang mereka lihat adalah isi yang terkandung di dalamnya:

- Skill-nya muncul dalam daftar Skills bersama skill lainnya. Skill tersebut bersifat hanya-baca, mengikuti izin Skills yang biasa, dan dapat diaktifkan atau dinonaktifkan dengan **Available to agent** seperti skill lainnya.
- Server MCP-nya muncul di Tool Library dan dapat ditambahkan ke agen seperti server yang didefinisikan dalam `librechat.yaml`.
- Hook-nya berjalan di server pada titik-titik tertentu dalam proses agen, misalnya sebelum pemanggilan tool atau saat proses berhenti. Hook dapat memblokir pemanggilan tool, menambahkan konteks ke prompt, atau menghentikan proses, dan pengguna hanya melihat efeknya.

Jika nama skill atau server MCP bertabrakan dengan yang didefinisikan di tempat lain, definisi lainnya yang akan digunakan: skill di direktori skill deployment mandiri akan mengungguli skill plugin, dan server di `librechat.yaml` akan mengungguli server plugin.

## Apa yang dapat dimuat oleh sebuah plugin [#what-a-plugin-can-contain]

Sebuah folder plugin memiliki manifes `plugin.json` dan salah satu dari:

- `skills/`, satu folder per skill, masing-masing dengan `SKILL.md`.
- `mcp.json`, definisi server MCP. Server lokal (`stdio`) dijalankan dari dalam folder plugin dan mendapatkan direktori data persisten tersendiri.
- `ai.librechat/hooks/hooks.json`, command hooks. Proses ini berjalan di host API dan dinonaktifkan kecuali operator mengaktifkannya.

Setiap bagian dimuat secara terpisah, sehingga `mcp.json` yang rusak tidak menghentikan skill plugin untuk dimuat. Masalah dilaporkan di log startup.

## Pengaturan [#setup]

Plugin dimuat dari `./plugin` di root proyek secara default, dan command hooks dinonaktifkan secara default. Lihat [konfigurasi Agent Plugins](/docs/configuration/agent_plugins) untuk pengaturan direktori, tata letak paket, aturan validasi manifest dan MCP, serta kontrak eksekusi hook.
