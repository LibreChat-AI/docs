Vous pouvez importer des conversations exportées depuis ChatGPT, Claude et [ChatbotUI v1](https://github.com/mckaywrigley/chatbot-ui/tree/b865b0555f53957e96727bc0bbb369c9eaecd83b?tab=readme-ov-file#legacy-code), ainsi qu'une conversation exportée depuis LibreChat au format JSON. Les conversations importées apparaissent dans votre historique comme les autres. L'exportation se fait une conversation à la fois.

## Importer le fichier [#import-the-file]

Allez dans **Paramètres** > **Données et confidentialité**, sélectionnez **Importer** à côté de « Importer les conversations depuis un fichier JSON », puis choisissez le fichier. Le sélecteur n'accepte que les fichiers `.json` ; décompressez donc d'abord les archives ChatGPT et Claude. Le bouton affiche « Importation en cours » pendant le traitement, puis « Conversations importées avec succès » lorsque l'opération est terminée.

LibreChat détermine le format à partir du contenu du fichier, et non de son nom. Si le fichier n'est pas reconnu, un message « Unsupported import type » s'affiche.

Un import LibreChat ne reprend pas le mode d'approbation du code enregistré pour la conversation (y compris **Accès complet**) ni son état de lecture. La conversation importée utilise votre préférence d'approbation actuelle ainsi que la politique du déploiement.

### Limites [#limits]

- Le fichier peut atteindre 250 MiB, sauf si votre administrateur a défini une autre limite. Les fichiers plus volumineux sont rejetés avant le téléversement.
- Une seule conversation ou un seul message ne peut pas dépasser environ 16 Mo, en raison d'une limite de la base de données.
- Les imports sont soumis à une limite de débit par utilisateur et par adresse IP. Il est donc possible que l'importation de nombreux fichiers à la suite soit refusée pendant un certain temps.

## Exporter une conversation [#export-a-conversation]

Ouvrez la conversation, ouvrez le menu **Options de chat** (le bouton `...` dans l'en-tête, ou le menu de l'en-tête sur les petits écrans), puis sélectionnez **Exporter**. Choisissez un nom de fichier et un type, puis sélectionnez **Exporter**.

| Type | Ce que vous obtenez |
| --- | --- |
| `markdown` (.md) | Une transcription lisible. C'est le format par défaut. |
| `text` (.txt) | Une transcription en texte brut. |
| `json` (.json) | Les données complètes des messages. C'est le format que LibreChat peut réimporter. |
| `csv` (.csv) | Une ligne par message. |
| `screenshot` (.png) | Une image de la conversation telle qu'elle apparaît à l'écran. |

**Exporter toutes les branches de messages** fonctionne pour `json` et `csv` ; les autres types n'exportent que la branche que vous consultez. **Inclure les options de l'endpoint** ajoute le modèle et ses paramètres, et n'est pas disponible pour `csv` ou `screenshot`. Pour `json`, vous pouvez également choisir **Récursif** (messages imbriqués sous leur parent) ou séquentiel.

Il n'existe pas d'export de toutes vos conversations en une seule fois, et une nouvelle conversation ou un résultat de recherche n'a rien à exporter, c'est pourquoi le menu n'apparaît pas dans ces cas-là.

## Configuration [#setup]

L'import et l'export fonctionnent pour tous les utilisateurs sans aucune configuration. Les administrateurs peuvent modifier la taille maximale des fichiers d'import avec `CONVERSATION_IMPORT_MAX_FILE_SIZE_BYTES` et les limites de débit avec les variables `IMPORT_*` ; voir la [référence .env](/docs/configuration/dotenv#conversation-import).
