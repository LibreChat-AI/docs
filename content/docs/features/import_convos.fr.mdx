L'importation de conversations vous permet d'intégrer dans LibreChat des conversations exportées depuis d'autres applications de chat IA. Les sources prises en charge sont [ChatGPT](https://chatgpt.com/), [Claude](https://claude.ai/) et [ChatbotUI v1](https://github.com/mckaywrigley/chatbot-ui/tree/b865b0555f53957e96727bc0bbb369c9eaecd83b?tab=readme-ov-file#legacy-code).

<Callout type="info" title="Où le trouver">
L'importation se trouve sous **Settings** → **Data Controls** dans LibreChat.
</Callout>

## Exporter depuis l'application source [#export-from-the-source-application]

Tout d'abord, exportez vos données depuis l'application que vous abandonnez. Les étapes diffèrent selon la source.

<Callout type="info" title="Vous cherchez plutôt à exporter des données depuis LibreChat ?">
Voir [Export from LibreChat](#export-from-librechat) au bas de cette page.
</Callout>

<Tabs items={["ChatGPT", "Claude", "ChatbotUI v1"]}>
<Tabs.Tab>

<Steps>
<Step>

**Demandez votre exportation.** Suivez les [instructions d'exportation de ChatGPT](https://help.openai.com/en/articles/7260999-how-do-i-export-my-chatgpt-history-and-data) pour exporter vos conversations.

</Step>
<Step>

**Téléchargez l'archive.** Vous recevrez un e-mail contenant un lien de téléchargement. L'archive est un fichier zip avec un nom aléatoire tel que `d119d98bb3711aff7a2c73bcc7ea53d96c984650d8f7e033faef78386a9907-2024-01-01-10-30-00.zip`.

</Step>
<Step>

**Extrayez l'archive** pour accéder au fichier `conversations.json` à l'intérieur.

</Step>
</Steps>

</Tabs.Tab>
<Tabs.Tab>

<Steps>
<Step>

**Demandez votre exportation.** Suivez les [instructions d'exportation de Claude](https://support.claude.com/en/articles/9450526-how-can-i-export-my-claude-data) pour exporter vos conversations.

</Step>
<Step>

**Téléchargez l'archive.** Vous recevrez un e-mail contenant un lien de téléchargement pour votre archive d'exportation.

</Step>
<Step>

**Extrayez l'archive** pour accéder au fichier `conversations.json` à l'intérieur.

</Step>
</Steps>

Exportez vos conversations depuis [ChatbotUI v1](https://github.com/mckaywrigley/chatbot-ui/tree/b865b0555f53957e96727bc0bbb369c9eaecd83b?tab=readme-ov-file#legacy-code), puis importez directement le fichier JSON résultant. Aucune étape d'extraction n'est requise.

</Tabs.Tab>

## Importer dans LibreChat [#import-into-librechat]

<Steps>
<Step>

**Contrôles des données ouvertes.** Dans LibreChat, allez dans **Paramètres** → **Contrôles des données**.

</Step>
<Step>

**Sélectionnez votre fichier.** Cliquez sur **Import** et choisissez le fichier `conversations.json` depuis votre archive extraite (ou le fichier JSON exporté pour ChatbotUI v1).

</Step>
<Step>

**Attendez la confirmation.** Une notification apparaît une fois l'importation terminée.

</Step>
</Steps>

## Paramètres d'approbation du code importé [#imported-code-approval-settings]

Lors de l'importation d'une conversation LibreChat, son mode d'approbation de code enregistré (y compris **Accès complet**) n'est pas conservé. Les nouvelles importations utilisent la préférence/valeur par défaut existante du destinataire ainsi que la politique actuelle de déploiement/worker. Une mise à jour en masse ne peut pas écraser un choix d'approbation stocké localement. Cette mesure de sécurité ne réinitialise pas rétroactivement les conversations existantes ; les utilisateurs peuvent toujours choisir et enregistrer un mode pris en charge via LibreChat. Voir [Autorisations de l'outil d'environnement attaché](/docs/features/code_interpreter#attached-environment-tool-permissions).

## Exporter depuis LibreChat [#export-from-librechat]

L'exportation se fait par conversation et se trouve dans le menu **Export and Share** de l'en-tête de discussion (sous le menu de débordement sur mobile). Ouvrez la conversation souhaitée, choisissez **Export**, sélectionnez un format et confirmez.

<OptionTable
  options={[
    ['markdown', '.md', 'Transcription lisible. La valeur par défaut.', ''],
    ['text', '.txt', 'Transcription en texte brut.', ''],
    ['json', '.json', 'Exportation structurée qui préserve l\'intégralité des données des messages.', 'Supports exporting all message branches'],
    ['csv', '.csv', 'Exportation tabulaire, une ligne par message.', 'Supports exporting all message branches'],
    ['screenshot', '.png', 'Image de la conversation rendue.', ''],
  ]}
/>

Deux options dans la boîte de dialogue dépendent du format que vous choisissez :

- **Exporter toutes les branches de messages** s'applique uniquement aux formats `json` et `csv`. Les autres formats n'exportent que la branche visible.
- Les options d'exportation restantes ne sont pas disponibles pour `csv` et `screenshot`.

<Callout type="info" title="Portée">

Il n'existe pas de fonction intégrée d'exportation en masse de toutes les conversations à la fois, et une conversation toute nouvelle ou issue de résultats de recherche n'a rien à exporter ; le menu ne s'affiche donc pas pour celles-ci.

</Callout>
