Code Interpreterは、隔離されたサンドボックス内でコードを実行します。エージェントは、推測に頼ることになる計算を行ったり、アップロードされたスプレッドシートを分析したり、ファイルを変換したり、グラフや文書を作成したりするためにこれを使用します。また、**Run Code**を使ってチャットメッセージ内のコードブロックを自分で実行することもできます。

サンドボックスは、LibreChat と並べてあなたの管理者がデプロイする別サービス [ClickHouse/code-interpreter](https://github.com/ClickHouse/code-interpreter)(オープンソース、Apache 2.0)です。Python、Node.js(JavaScript および TypeScript)、Go、C および C++、Java、PHP、Rust、Fortran をサポートしています。

## コード実行をエージェントに付与する [#give-an-agent-code-execution]

Agent Builder で **Tools** の横にある **Add** を選択し、**Run Code** を追加します。エージェントを保存してください。以降は、エージェントがいつコードを実行するかを自ら判断します。明示的に指示する必要はありませんが、正確な答えが欲しい場合は「コードを使ってこれを確認して」と伝えると効果的です。

コードの実行中、メッセージには折りたたみ可能な行が表示されます。最初の実行時は **Starting sandbox environment** と表示され、その後 **Analyzing**、完了すると **Finished analyzing** に変わります。この行を展開すると、エージェントが書いたコードと **Output** を確認できます。

## ファイルの操作 [#working-with-files]

ファイルを添付し、**Upload to Code Environment** を選択すると、そのチャットの間サンドボックスからファイルを利用できるようになります。エージェントの Run Code 設定で追加したファイルは、そのエージェントを使用するすべてのチャットで利用できます。実行前に LibreChat は、会話のファイルをサンドボックスに復元します。実行に必要なファイルのいずれも復元できない場合は、古いコピーで作業を続けるのではなく、実行を停止して、ファイルを再度添付するよう求めます。

コードが書き出したファイルは、メッセージ内に行として表示されます。行をクリックすると[Artifacts](/docs/features/artifacts)パネルで開き、ダウンロードすることもできます。HTML、Markdown、プレーンテキスト、ソースコード、CSV、Officeファイル（Word、Excel、OpenDocument、PowerPointのプレゼンテーションおよびテンプレート）は、インラインでプレビューされます。サイズの大きいファイルはプレビューされず、ダウンロードのみ可能です。既定の上限は、ソースファイルで2 MiBです。エージェントがサンドボックスから読み取る画像（PNG、JPEG、GIF、WebP）は、1 MiBまでインラインで表示されます。それより大きい画像はサンドボックス内に残り、エージェントは引き続き処理できます。

## 自分でコードブロックを実行する [#run-a-code-block-yourself]

チャットメッセージ内のコードブロックには、そのブロックの言語がサンドボックスで実行可能なもの(Python、JavaScript、TypeScript、Go、C、C++、D、Java、PHP、Rust、Fortran)である場合、**Copy code** の横に **Run Code** ボタンが表示されます。これをクリックすると、ブロックの下に出力が表示されます。この機能はエージェントとの会話に限らず、あらゆる会話で利用できます。

## 長時間実行されるコード [#long-running-code]

管理者がバックグラウンドツールを有効にしている場合、エージェントの「Run Code」設定には**Background execution**が表示され、デフォルトでオンになっています。エージェントは時間のかかるコードを開始した後もユーザーとの会話を続けられ、実行が完了したら出力とファイルを取得できます。デフォルトでは、結果は後続のメッセージとして自動的に届きます。常にコードの完了を待つべきエージェントでは、この設定をオフにしてください。

メモリ、CPU時間、アップロードサイズ、ネットワークアクセスは、LibreChatではなくサンドボックスサービスを運用する管理者が設定します。コードがリソースエラーで失敗した場合は、管理者に制限の内容を確認してください。

## ステートフルなコードセッション [#stateful-code-sessions]

デフォルトでは、各実行はステートレスです。変数やインストール済みのパッケージが次の実行まで引き継がれることを前提にしないでください。ステートフルなコードセッションは、管理者が有効にする必要がある実験的な機能で、エージェントに対して、実行間で `/mnt/data` にファイルを保持するワークスペースを提供します。ただし、各実行では依然として新しいプロセスが開始され、ワークスペースはいつでもリセットされる可能性があります。そのため、永続的なストレージではなく、一時的な作業領域として扱ってください。

エージェントの Run Code 設定で **Stateful code sessions** を有効にし、**Stateful environment** を選択します:

- **ユーザーワークスペース(推奨)**: あなた専用の1つのワークスペースを用意し、あなたが利用するすべてのステートフルなエージェントで共有します。
- **Agent + user workspace**: 各エージェントごとに独立したワークスペースを用意します。
- **会話ワークスペース**: 会話ごとに新しいワークスペースが用意されます。

新しいエージェントは、**設定 > データとプライバシー > コード実行 > デフォルトのステートフルワークスペース** で設定されたスコープで開始されます。この設定を変更しても、既存のエージェントには影響しません。ステートフルワークスペースでエージェントが作成または編集したファイルは、その応答の **Workspace changes** 行に一覧表示され、各ファイルにダウンロードリンクが付きます。

## ご自身のマシン上でコードを実行する [#running-code-on-your-own-machine]

管理者は、コード実行環境を提供することもできます。これは `@librechat/code` ワーカーを実行する VM またはワークステーションで、LibreChat へ外部から接続します。この場合、エージェントビルダーに **Execution environment** セレクターが表示され、**Machines available in new chats** を使うと、エージェントは複数のマシンを提供できます。各新規チャットでは **Choose another machine** を使って、そのうちの 1 台を選択できます。

もし コード環境 を管理する権限がある場合は、**設定 > データとプライバシー > コード実行 > コード環境** で独自の環境を追加できます。名前を付け、**Connect VM** を選択して、表示される一度限りのコマンドを自分のマシンで実行してください。管理者がブラウザでのセットアップを有効にしている場合は、セットアップコマンドによって **Approve Machine Setup** ページが開くことがあります。そのページでサインインした状態でリクエストを確認してください。

接続されたマシンでは、エージェントは選択されたワークスペース内でファイルの閲覧、読み取り、検索、編集、およびシェルコマンドの実行を行うことができます。アップロードしたチャットの添付ファイルは、エージェントが起動する前に、そのワークスペース内の `.librechat/attachments` にコピーされます。これらの操作は実際のマシンを変更するため、コンポーザーには会話ごとの **Code approval mode**（コード承認モード）が表示されます。

- **変更前に確認**: ファイルの編集やコマンドの実行の前に確認を求めます。
- **承認して編集**: 確認なしでファイルを編集しますが、コマンドを実行する前には引き続き確認を求めます。
- **フルアクセス**: 通常の確認プロンプトなしで編集やコマンド実行を行います。マシン上のサンドボックスの制限は引き続き適用されます。

使用できるモードは、管理者のポリシーによって異なります。マシンのペアリングは、ワーカーをLibreChatに対して認証するものであり、サンドboxによる隔離は行いません。そのため、信頼できないコードを実行する他のマシンと同様に、ワーカーを隔離してください。

## コードからMCPツールを呼び出す [#calling-mcp-tools-from-code]

Programmatic Tool Calling を使うと、エージェントはサンドボックス内から選択した MCP ツールを呼び出せます。エージェントは入力をループ処理し、ツールを呼び出し、結果をフィルタリングして、必要なものだけを返すスクリプトを書きます。これにより、ツール呼び出しごとにモデルとのやり取りを往復させる必要がなくなります。Programmatic のトグルは、エージェントに Run Code が設定されるまで無効のままです。Run Code を削除すると、これらのトグルはクリアされます。スクリプトの実行中は、その行を展開して **Tool calls** のトレースを確認できます。このトレースはページを再読み込みすると保持されません。エージェントに登録されたツールのみ、この方法で呼び出せます。ツールに印を付ける方法については、[Programmatic Tool Calling](/docs/features/agents#programmatic-tool-calling) を参照してください。

## セットアップ [#setup]

コード実行を利用するには、管理者が Code Interpreter サービスをデプロイし、LibreChat がそのサービスを参照するように設定する必要があります。それまでは、実行は失敗します。**Run Code** ボタンおよびエージェントの機能は、ロールごとに無効にすることもできます。バックグラウンド実行、ステートフルセッション、コード環境は、それぞれオプトインで有効にします。詳細は [Code Interpreter configuration](/docs/configuration/tools/code_interpreter) を参照してください。
