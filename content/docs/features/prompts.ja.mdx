### 変数 [#variables]

次のテキストを日本語に翻訳してください:

`{{notes}}` を使うとテキストの入力を求め、`{{length:3 bullets|5 bullets}}` を使うと選択肢を提示できます。

```text
Summarize these notes in {{length:3 bullets|5 bullets}}.

Notes: {{notes}}
```

LibreChat は、チャットでプロンプトを使用する際にこれらの値を求めます。`{{current_date}}`、`{{current_datetime}}`、`{{iso_datetime}}`、`{{current_user}}` などの特殊変数は自動的に入力されます。それ以外の変数は、入力する値がない場合、そのままの文字列として残ります。

### バージョンと本番環境 [#versions-and-production]

編集を保存すると、新しいバージョンが作成されます。バージョンのうち1つには**Production**のマークが付けられます。ライブラリと`/`メニューでは、そのバージョンが使用されます。

| エディタの設定 | 保存時の動作 |
| --- | --- |
| **Advanced prompts editor** がオフ | バージョン一覧は非表示になります。保存するたびに Production になります。 |
| Advanced editor がオン、かつ **Always make new prompt versions production** がオン | 保存するたびに Production になります。以前のバージョンも閲覧できます。 |
| Advanced editor がオン、かつ自動 Production がオフ | バージョンを保存したあと、**Deploy** を使って Production にします。 |

これらの設定はお使いのブラウザに適用されます。高度なエディターをオフにすると、自動 Production も有効になります。高度なエディターをオンにすると、そのスイッチを再度変更できます。

### 本番環境、またはバージョンを固定する場合 [#production-or-a-pinned-version]

**Production** を選択すると、プロンプトの所有者による更新に追従します。特定のバージョンを選択すると、リンクを変更するまで同じ指示内容が維持されます。

![バージョン4が昇格される前は、両方のエージェントがバージョン3を使用します。昇格後は、Productionに追従するエージェントがバージョン4を使用し、バージョン3に固定されたエージェントはバージョン3のままです。ネイティブのキャッシュ設定により、Productionへの更新が遅れる場合があります。](/images/features/prompts/production-vs-pinned.svg)

LibreChat のプロンプトにおける **Production** とは、Production とマークされたリビジョンを指します。Langfuse のプロンプトの場合は、`production` ラベルが付けられたバージョンを指します。

### 指示が解決されるタイミング [#when-instructions-are-resolved]

エージェントを保存すると、プロンプトは確認されますが、そのテキストはコピーされません。LibreChatは各ターンでリンクを解決します。ネイティブのプロンプト更新は[キャッシュ](/docs/configuration/librechat_yaml/object_structure/agents#linkedinstructions)によって遅れる場合があります。Langfuseのリンクは毎回取得されます。

特殊変数は、[インラインのエージェント指示](/docs/features/agents#instructions-from-a-saved-prompt)と同様に機能します。`{{notes}}` のようなカスタム変数は、リンクされた指示では**値が埋め込まれません**。モデルにはそれらがそのままのリテラルテキストとして渡されます。

<Callout type="warning" title="プロンプトが利用できない場合">
  エージェントは**空の指示**でそのターンを実行します。保存されているインラインテキストは使用されません。
  メモリエージェントは例外で、デフォルトの指示を使用します。
</Callout>

## Langfuseからのプロンプト [#prompts-from-langfuse]

Langfuse で同期されたプロンプトには、**Managed in Langfuse** というラベルの付いたクラウドアイコンが表示されます。LibreChat でプレビューして使用できます。プロンプトの内容の編集、バージョンの昇格、削除は Langfuse で行ってください。

<ImageZoom src="/images/features/prompts/langfuse-preview.jpg" alt="Langfuseの読み取り専用プロンプトプレビュー（バージョン、ラベル、Open in Langfuse付き）">
      <span className="relative mx-auto block w-full overflow-hidden rounded-lg" style={{ maxWidth: 1028, aspectRatio: '1028 / 445' }}>
        <img src="/images/features/prompts/langfuse-preview.jpg" alt="Langfuseの読み取り専用プロンプトプレビュー（バージョン、ラベル、Open in Langfuse付き）" loading="lazy" style={{ position: 'absolute', width: '168.09339%', maxWidth: 'none', top: '-42.24719%', left: '-34.04669%' }} />
      </span>
    </ImageZoom>

Langfuseの**テキストプロンプト**のみがサポートされています。開くと、その内容はキャッシュせずにLangfuseから取得されます。Langfuse側で削除しても、LibreChatのライブラリ内のエントリは残りますが、そのエントリはもう解決できなくなります。

### Langfuseリンク [#langfuse-links]

管理者は、[プロンプトカタログの同期](/docs/configuration/langfuse#prompt-catalog)と[Langfuseのエージェント指示](/docs/configuration/langfuse#prompts-as-agent-instructions)を有効にする必要があります。リンク機能はデフォルトでオフになっています。保存されたリンクを機能させるには、カタログの同期を有効にしたままにしておく必要があります。

リンクが無効になっている場合、Langfuse のプロンプトは Builder のピッカーから消えますが、エージェントに保存された選択は除きます。Builder には、その選択に関する注記が表示されます。リンクは保存されたままですが、エージェントはそれらの指示なしで実行されます。リンクを再度有効にすると、エージェントを編集しなくても元に戻ります。

## 共有と権限 [#sharing-and-permissions]

プロンプトの所有者は、ユーザー、グループ、またはロールに対して **Viewer**、**Editor**、または **Owner** としてプロンプトを共有できます。詳細は [Access Control](/docs/features/access_control) を参照してください。

### 誰がリンクでき、誰が実行できるか [#who-can-link-and-who-can-run]

| タスク | 必要なアクセス |
| --- | --- |
| プロンプトライブラリを使用する | ロールの `PROMPTS` `USE` 権限と、そのプロンプトへのアクセス。 |
| エージェントのプロンプトリンクを追加または変更する | プロンプトに対する `PROMPTS` `USE` と VIEW に加え、新規エージェントの場合は `AGENTS` `CREATE`、既存エージェントの場合は EDIT。 |
| リンクを保持または削除する。インライン指示に切り替える | エージェントレベルで同じアクセス権が必要です。プロンプトのアクセス権は再度チェックされません。 |
| プロンプトを使用するエージェントとチャットする | そのエージェントとチャットするためのアクセス権。リンクされたプロンプトへのアクセス権は必要ありません。 |
| プロンプトを共有する | 選択したユーザー、グループ、またはロールには `SHARE`、全員には `SHARE_PUBLIC`。 |

共同編集者がプロンプトへのアクセス権を持たない場合、**Restricted prompt** と表示されます。その場合、リンクを差し替えるか、インライン指示に切り替えることができます。リンク先は表示されません。エージェントの閲覧者にはリンク自体が表示されません。

管理者は、[管理パネル](/docs/features/admin_panel)または[アクセス制御の設定](/docs/configuration/access_control#feature-permissions)でロールの権限を設定します。`manage:prompts` を持つ委任管理者は、個別の VIEW 権限がなくても、任意のグループを表示およびリンクできます。ただし、リンクには引き続き `PROMPTS` の `USE` 権限が必要です。

## 詳細とトラブルシューティング [#details-and-troubleshooting]

<Accordions type="single" collapsible>
  <Accordion title="バージョン履歴、複製、元に戻す">
    プロンプト、そのバージョン、または指示の取得元を変更すると、エージェントのバージョン履歴にエントリが追加されます。

    **複製**と**元に戻す**は、保存済みのリンクを、新しいUSEまたはVIEWの確認を行わずにコピーします。新しい編集者がプロンプトを表示できない場合、ビルダーには**制限付きプロンプト**と表示されます。
  </Accordion>
  <Accordion title="使用回数の意味">
    各リンクされたエージェントは、初期化が正常に完了すると1回分の使用回数を加算します。これはプロンプトカードやスラッシュメニューで使われているものと同じカウンターです。ハンドオフやサブエージェントは、1つのターンで複数回の使用回数を加算することがあります。

    再開された一時停止中の実行では、追加の利用は発生しません。メモリエージェントも利用を追加することはありません。
  </Accordion>
  <Accordion title="Management API の制限事項">
    エージェントビルダーでプロンプトへのリンクを設定します。Management APIとそのOpenAPI仕様は、`instructionsPrompt`を受け付けず、返却もしません。

    `instructions` をその API 経由で変更しても、リンクされたエージェントが使用する内容は変わりません。リンクが優先されます。Langfuse のリンクはテキストプロンプトのみをサポートします。ネイティブのプロンプトグループには、この制限はありません。
  </Accordion>
  <Accordion title="Builder メッセージのトラブルシューティング">

    | メッセージ | 対処方法 |
| --- | --- |
| "This prompt selection isn't available right now." | 別のプロンプトまたはバージョンを選択するか、問題が解決してから再試行してください。バージョンが削除されているか、ポリシーによりブロックされているか、Langfuse から利用できない可能性があります。リンクが無効になっているか、グループのソースが変更された可能性があります。 |
| "You don't have permission to link this prompt." | 管理者に `PROMPTS` `USE` 権限を依頼するか、グループの VIEW 権限についてオーナーに依頼してください。 |
| "You don't have access to the prompt library." | ピッカーやバージョン一覧には `PROMPTS` `USE` とグループの VIEW 権限が必要です。管理者またはオーナーに依頼してください。 |
| "This prompt's source isn't available right now." | Langfuse の同期設定を確認するか、リンクを置き換えてください。同期が無効または未設定である、ソースが変更された、またはプロンプトがチャットプロンプトに変わった可能性があります。 |
| "Couldn't load prompts." | 再試行してください。問題が続く場合は、管理者にサーバーログの確認を依頼してください。これは権限やソースのエラーではなく、予期しない読み込みエラーです。 |
| "Selected version (no longer available)" | ネイティブのリビジョンが削除されました。**Production** または別のバージョンを選択してください。 |
| "Version N (no longer available)" | Langfuse のそのバージョンはもう一覧に表示されていません。**Production** または別のバージョンを選択してください。 |
| "Restricted prompt" | VIEW 権限を依頼するか、リンクを置き換えるか、インラインの指示に切り替えてください。グループが削除されている可能性もあります。エージェントのオーナーであってもこの表示が出ることがあります。 |
| "Prompt not found" | グループが削除されています。別のプロンプトを選択するか、インラインの指示に切り替えてください。`manage:prompts` または `ADMIN` 権限を持つユーザーには、**Restricted prompt** の代わりにこの表示が出ます。 |
| "Couldn't validate the linked prompt. Please try again." | 予期しないエラーにより検証できませんでした。もう一度保存してみてください。 |

  </Accordion>
</Accordions>

## 設定リファレンス [#configuration-reference]

- [Linked instructions](/docs/configuration/librechat_yaml/object_structure/agents#linkedinstructions): タイムアウト、ネイティブキャッシュ、ランタイムの動作、および障害の原因。
- [Langfuse のセットアップとロールアウト](/docs/configuration/langfuse#prompts-as-agent-instructions): すべてのサーバーが更新された後にリンクを有効にしてください。
- [Feature permissions](/docs/configuration/access_control#feature-permissions): ロールごとにプロンプトへのアクセスを制御します。[`interface.prompts`](/docs/configuration/librechat_yaml/object_structure/interface#prompts) はデフォルトロールの権限の初期値を設定します。
