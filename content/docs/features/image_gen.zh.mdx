---
title: 图像生成与编辑
icon: Image
description: 通过与带有图像工具的智能体对话来生成和编辑图像，可使用 OpenAI、Gemini、Flux 或本地 Stable Diffusion 服务器。
---

LibreChat 通过智能体工具创建和编辑图像。为智能体添加图像工具,描述您想要的内容,图像就会出现在对话中。随消息上传一张图片,智能体可以对其进行修改,而无需从头开始。

## 图像工具 [#the-image-tools]

| 工具 | 功能 | 编辑图像 |
| --- | --- | --- |
| OpenAI Image Tools | 根据文本生成图像,并使用 OpenAI 图像模型编辑上传的或之前生成的图像。推荐的默认选项。 | 是 |
| Gemini Image Tools | 使用 Google 的 Gemini 图像模型生成图像,可选择将之前的图像作为视觉上下文。 | 是 |
| Flux | 使用 Black Forest Labs 的 Flux 模型生成图像,包括您自己微调的模型。 | 否 |
| Stable Diffusion | 在您自己的 Automatic1111 服务器上生成图像,因此数据不会离开您的网络。 | 否 |

您所看到的内容取决于管理员的配置。

## 生成图片 [#generate-an-image]

<Steps>
<Step>
在 Agent Builder 中打开该智能体,然后点击 **Tools** 旁边的 **Add**。
</Step>
<Step>
选择一个图像工具,例如 **OpenAI Image Tools**,然后保存智能体。如果该工具要求输入 API 密钥,说明管理员将其留给每位用户自行配置;请输入您自己的密钥。
</Step>
<Step>
与智能体开始对话,并描述该图像。
</Step>
</Steps>

智能体会将您的请求转换为工具的提示词,因此您可以正常对话(例如"一张义卖活动海报,宽幅,色彩丰富的粉彩色调")。当工具支持时,形状和尺寸请求会被直接传递:OpenAI 支持正方形、横向或纵向尺寸(较新的模型还支持最高 4K 的自定义尺寸),以及质量等级和透明背景;Gemini 支持 16:9 或 9:16 等宽高比,并且在较新的模型上支持最高 4K 的分辨率。Stable Diffusion 始终生成 1024x1024 的图像。

## 编辑图像 [#edit-an-image]

使用 **上传图片** 附加一张图片,然后提出修改要求,例如:“去掉背景中的人物”、“让它看起来像水彩画”、“把这个 logo 放到一个咖啡杯上”。使用 OpenAI Image Tools 时,智能体会调用图片编辑工具;使用 Gemini 时,它会将你的图片作为上下文,用于生成新的图片。

你可以在智能体刚生成的图片基础上继续操作(例如"把天空调暗一些"),无需重新上传任何内容。每张上传或生成的图片都有一个模型可以引用的 ID,只要图片仍在对话的上下文窗口内,这一方式就有效。在较长的对话中,请重新附加该图片。

Flux 和 Stable Diffusion 只能根据文本生成图像,因此无法进行编辑。

## 模型所看到的内容 [#what-the-model-sees]

生成的图像在创建后会立即向模型展示一次,以便模型描述或检查自己的作品。此后,模型只能看到您消息中附带的图像。如果您想在几轮对话之后再讨论较早的图像,请重新附加该图像。

由于图像会回传给模型,对于带有图像工具的智能体,请使用支持视觉的模型。纯文本模型可能会在图像生成后的下一轮对话中失败。

生成的图片与其他上传文件一样，存储在管理员设置的文件存储中。默认情况下，图片会被缩小，使其较短一边不超过 768 像素，因此即使请求的是 4K 图片，保存的尺寸也会比模型生成的小，除非管理员修改了该设置。

## 来自 MCP 服务器的图片 [#images-from-mcp-servers]

MCP 工具也可以返回图片，例如一个会截取屏幕截图的浏览器服务器。服务器以 MCP 图片格式返回的图片，会以与内置工具输出相同的方式显示在聊天中。部分服务器仅返回图片的 URL，LibreChat 不会将其视为图片输出。

## 编写提示词 [#writing-prompts]

图像模型会对具体的描述作出响应。先写主体和媒介(照片、油画、扁平矢量插画),再补充构图、光线以及真正重要的细节。描述你希望看到的画面,而不是列出需要避免的内容。如果结果已经接近目标,请针对具体的修改提出要求,而不必重写整个提示词。

## 设置 [#setup]

每个工具都需要 API 密钥或服务器 URL。管理员在 `.env` 中设置这些内容;对于基于密钥的工具,管理员也可以不设置密钥,而是让每个用户自行输入。各工具的设置方法:[OpenAI 图像工具](/docs/configuration/tools/openai_image_gen)、[Gemini 图像工具](/docs/configuration/tools/gemini_image_gen)、[Flux](/docs/configuration/tools/flux) 和 [Stable Diffusion](/docs/configuration/tools/stable_diffusion)。图像的存储位置由 [`fileStrategy`](/docs/configuration/librechat_yaml/object_structure/config#filestrategy) 设置。
