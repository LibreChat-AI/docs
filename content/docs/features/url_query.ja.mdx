description: >-
  LibreChatを開き、チャットのURLにクエリパラメータを追加することで、エンドポイント、モデル、エージェント、プロンプト、設定をあらかじめ選択した状態で起動します。
---

チャットの URL にクエリパラメータを追加すると、チャットを開始する前にエンドポイントとモデルを選択したり、エージェントやモデルスペックを読み込んだり、プロンプトを入力したり、モデルの設定を変更したりできます。これを使うと、ブックマーク、ランチャーのショートカット（Raycast、Alfred、ブラウザのキーワードなど）、または他のアプリからのリンクを作成し、利用者を適切な設定の状態へ直接誘導できます。

```
https://chat.example.com/c/new?endpoint=anthropic&model=claude-sonnet-4-5&prompt=Summarize%20this%20article
```

パラメータは、新しいチャット(`/c/new`)と既存のチャット(`/c/<conversation-id>`)の両方で動作します。LibreChat がパラメータを読み取った後、アドレスバーからそれらを削除するため、ページを再読み込みしても再度適用されることはありません。

## エンドポイントとモデルを選択する [#pick-the-endpoint-and-model]

`endpoint`と`model`の組み合わせが、最も予測可能な設定です。

- `endpoint` だけを指定すると、そのエンドポイントに切り替わり、そこで最後に選択したモデル、またはそのリストの最初のモデルが使用されます。
- `model` だけを指定すると、現在のエンドポイント内でモデルを切り替えます（そのエンドポイントがモデルの切り替えに対応している場合）。

組み込みのエンドポイント値は、`openAI`、`azureOpenAI`、`google`、`anthropic`、`bedrock`、`agents`、`assistants`、`azureAssistants` です。[カスタムエンドポイント](/docs/quick_start/custom_endpoints)の場合は、設定ファイルで指定した名前を使用してください。大文字と小文字は区別されないため、`endpoint=openrouter` は `OpenRouter` という名前のエンドポイントに一致します。

## エージェント、アシスタント、またはモデル仕様を読み込む [#load-an-agent-assistant-or-model-spec]

```
/c/new?agent_id=agent_abc123
/c/new?assistant_id=asst_abc123
/c/new?spec=meeting-notes
```

`agent_id` と `assistant_id` は、エンドポイントを自動的に設定します。`spec` は、その `name` を指定して [モデルスペック](/docs/configuration/librechat_yaml/object_structure/model_specs) を読み込みます。同じURLに含まれるその他の設定は、スペックのプリセットの上に適用されます。管理者がモデルスペックを強制している場合は、すべてのリンクに `spec` を含めてください。その場合、URLよりもスペック自体の値が優先されることに注意してください。

## プロンプトを入力または送信する [#fill-in-or-send-the-prompt]

`prompt`(または短縮形の`q`)は、メッセージ入力欄にテキストを入力します。両方が指定されている場合は、`prompt`が優先されます。

チャットの準備ができたらすぐに送信するには、`submit=true` を追加します:

```
/c/new?endpoint=openAI&model=gpt-4o&prompt=Explain%20quantum%20computing&submit=true
```

要求された設定を数秒以内に適用できない場合、プロンプトは送信されず、メッセージ入力欄に残ります。管理者は自動送信をオフにすることもできます。その場合、`submit=true` はプロンプトを入力欄に入れるだけで、送信は利用者自身が行う必要があります。

値はURLエンコードされている必要があります。JavaScriptでは、`encodeURIComponent()`を使うとこれを行えます:

```js
const url = `/c/new?prompt=${encodeURIComponent('Write a function: def hello()')}`;
// /c/new?prompt=Write%20a%20function%3A%20def%20hello()
```

## モデル設定の変更 [#change-model-settings]

これらのいずれもURLに追加できます。それぞれは対応するエンドポイントでのみ有効になり、値は適用前に検証されます。無効な値は、エラーを出さずに破棄されます。

| エンドポイント | パラメータ |
| --- | --- |
| 任意 | `maxContextTokens`、`resendFiles`、`promptPrefix`(カスタム指示) |
| OpenAI、Azure OpenAI、カスタム | `temperature`、`top_p`、`presence_penalty`、`frequency_penalty`、`stop`、`max_tokens`、`reasoning_effort`、`reasoning_summary`、`verbosity`、`useResponsesApi`、`disableStreaming`、`imageDetail`(`low`、`auto`、`high`) |
| OpenAI Responses API | `reasoning_mode`(`standard`、`pro`)、`reasoning_context`(`auto`、`current_turn`、`all_turns`) |
| OpenAI、Anthropic、Google | `web_search`(`true`/`false`)、`fileTokenLimit`(ファイル内容のトークン上限) |
| Anthropic、Google | `temperature`、`topP`、`topK`、`maxOutputTokens`、`thinking`、`thinkingBudget`、`thinkingLevel` |
| Anthropic | `effort`(`low`、`medium`、`high`、`xhigh`、`max`)、`thinkingDisplay`(`auto`、`summarized`、`omitted`、または、ツール呼び出しの間の進捗メモのみを表示する `updates`) |
| Anthropic、Bedrock(Anthropicモデル)、OpenRouter | `promptCache`(`true`/`false`)、`promptCacheTtl`(`5m` または `1h`) |
| Google | `url_context=true` を設定すると、Gemini がメッセージ内の URL を読み取れるようになります |
| Bedrock | `region`、`maxTokens`、`temperature`、`topP`、`reasoning_effort` |
| Assistants | `instructions`(この実行に限り、アシスタントの指示を置き換えます)、`append_current_datetime=true` |

各フィールドの意味と指定可能な値は、[モデル仕様プリセットのフィールド](/docs/configuration/librechat_yaml/object_structure/model_specs)に記載されています。プロバイダーが拒否する値を渡した場合（例えば、モデルの上限を超える `max_tokens`）、送信時に API エラーが発生します。その場合は、**New chat** を開始するとクリアできます。

## カラーモードを設定する [#set-the-color-mode]

管理者が有効にしている場合、リンクに `theme=light`、`theme=dark`、または `theme=system` を指定すると、カラーモードを設定できます。これにより、LibreChat にリンクするアプリは独自のテーマを引き継ぐことができます。設定画面で変更するまで、この設定はユーザーの環境設定として保存されます。

## セットアップ [#setup]

クエリパラメータは、設定なしですぐに使えます。管理者は、[`interface.autoSubmitFromUrl`](/docs/configuration/librechat_yaml/object_structure/interface#autosubmitfromurl) を使って、`submit=true` による自動送信を停止できます。また、[`interface.colorModeFromUrl`](/docs/configuration/librechat_yaml/object_structure/interface#colormodefromurl) を使うと、`theme` パラメータを有効にできます。
