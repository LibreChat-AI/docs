Jede Nachricht in einem Chat hat unter sich eine Reihe kleiner Schaltflächen. Auf dem Desktop erscheinen sie, wenn Sie mit dem Mauszeiger über die Nachricht fahren oder den Tastaturfokus darauf setzen. Schaltflächen, die während einer noch laufenden Antwort keinen Sinn ergeben, bleiben ausgeblendet, bis die Antwort abgeschlossen ist.

## Was jede Schaltfläche bewirkt [#what-each-button-does]

| Schaltfläche | Was sie bewirkt |
|---|---|
| **Vorlesen** | Liest die Nachricht mit Text-to-Speech laut vor, sofern aktiviert. |
| **In die Zwischenablage kopieren** | Kopiert den Nachrichtentext. |
| **Bearbeiten** | Öffnet die Nachricht in einem Editor. Siehe [Bearbeiten und erneut ausführen](#edit-and-rerun). |
| **Forken** | Startet eine neue Unterhaltung ab dieser Nachricht. Siehe [Unterhaltungen forken](/docs/features/fork). |
| **Gefällt mir** / **Verbesserungsbedarf** | Bewertet eine Antwort. Du kannst einen Grund und einen Kommentar hinzufügen. |
| **Neu generieren** | Fordert vom Modell eine neue Antwort auf dieselbe Nachricht an. Die alte Antwort bleibt als frühere Version verfügbar. |
| **Fortsetzen** | Wird bei der neuesten Antwort angezeigt, wenn sie vor dem Ende abgebrochen wurde, etwa beim Erreichen des Ausgabe-Token-Limits. Setzt die Antwort an der Stelle fort, an der sie aufgehört hat. |

Welche Schaltflächen angezeigt werden, hängt vom Endpoint und der Nachricht ab. Benutzernachrichten haben beispielsweise keine Bewertungs- oder **Regenerieren**-Schaltfläche.

## Bearbeiten und erneut ausführen [#edit-and-rerun]

Wähle **Bearbeiten** bei deiner eigenen Nachricht oder bei einer Antwort. Der Editor hat drei Schaltflächen:

- **Speichern** behält deine Änderung bei, ohne etwas Neues zu generieren.
- **Aktualisieren & erneut ausführen** sendet deine bearbeitete Nachricht erneut und erhält eine neue Antwort. Die Schaltfläche heißt **Erneut ausführen**, wenn du nichts geändert hast, und wenn du eine Antwort bearbeitest, wo sie die Benutzernachricht erneut abspielt, die davor stand.
- **Abbrechen** schließt den Editor.

Während der Bearbeitung speichert <kbd>Strg</kbd>+<kbd>S</kbd> (<kbd>Cmd</kbd>+<kbd>S</kbd>), <kbd>Strg</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>) führt erneut aus, und <kbd>Escape</kbd> bricht ab.

Ein erneuter Durchlauf behält die Dateien, zitierten Auszüge und Skills bei, die der ursprünglichen Nachricht angehängt waren, sodass Sie diese nicht erneut hinzufügen müssen. Eine Nachricht, die nur Dateien und keinen Text enthält, kann ebenfalls bearbeitet und erneut ausgeführt werden.

Antworten von Agenten können mehr als nur Text enthalten. Der Editor erlaubt nur das Bearbeiten der Text- und Reasoning-Teile; Tool-Aufrufe, Fehler und Artefakte werden angezeigt, sind aber schreibgeschützt. Ein erneuter Durchlauf wendet jeweils nur einen bearbeiteten Teil an. Wenn du mehrere Teile änderst, verwende daher **Speichern**.

## Kopieren [#copy]

**In die Zwischenablage kopieren** kopiert den sichtbaren Text der Nachricht. Bei Antworten von Agenten werden Begründungen, Tool-Aufrufe und Fehler weggelassen. Zitate werden in lesbare Verweise umgewandelt.

Wenn Sie in Apps wie Teams, Outlook oder Word einfügen, aktivieren Sie **Nachrichten als Rich Text kopieren** unter **Einstellungen > Chat**. Beim Kopieren wird dann zusätzlich eine formatierte Version in die Zwischenablage gelegt, sodass Überschriften, Listen, Tabellen und Code ihre Formatierung behalten.

## Zitat-Auszüge [#quote-excerpts]

Markiere einen Text in einer beliebigen Nachricht und wähle **Zum Chat hinzufügen**. Der Auszug wird über dem Eingabefeld bereitgestellt und mit deiner nächsten Nachricht als Zitat gesendet, sodass das Modell genau weiß, welchen Teil du meinst. Du kannst bis zu 10 Auszüge an eine Nachricht anhängen, wobei jeder auf 1.500 Zeichen gekürzt wird.

Zitate funktionieren auch mit [Steuerungs- und Warteschlangennachrichten](/docs/features/agents#steering-and-queued-messages): Ein Auszug bleibt an die Nachricht gebunden, die Sie in die Warteschlange stellen oder mit der Sie steuern.

## Codeblöcke [#code-blocks]

Codeblöcke in einer Antwort haben eigene Schaltflächen in der Kopfzeile:

- **Code kopieren** kopiert den Block.
- **Code herunterladen** speichert den Code als Datei mit dem Namen der Sprache des Blocks, zum Beispiel `code.py` oder `code.toml`. Blöcke ohne Sprachangabe oder mit einer Angabe, die nicht wie eine Dateiendung aussieht, werden als `code.txt` heruntergeladen. Fehlerblöcke haben keine Download-Schaltfläche.
- **Code ausführen** führt den Block mit dem [Code Interpreter](/docs/features/code_interpreter) aus, sofern dieser für die jeweilige Sprache verfügbar ist.
