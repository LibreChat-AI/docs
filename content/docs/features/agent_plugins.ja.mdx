title: エージェントプラグイン

Agent Plugin は、LibreChat サーバー上にあるフォルダーで、関連し合う [Skills](/docs/features/skills)、[MCP servers](/docs/features/mcp)、および任意のコマンドフックをまとめたものです。オペレーターはこのフォルダーをプラグインディレクトリに配置して LibreChat を再起動するだけで、UI からインストールする操作は不要です。LibreChat はオープンな Agent Plugins `1.0.0` パッケージ形式に従うため、対応している他のツールとも同じパッケージを共有できます。

Agent Pluginsは実験的な機能です。パッケージの形式や動作は変更される可能性があります。

## ユーザーの表示画面 [#what-users-see]

ユーザーがプラグインそのものを目にすることはありません。見えるのは、プラグインが含む内容です。

- そのスキルは、他のスキルと並んでスキル一覧に表示されます。読み取り専用で、通常のスキルの権限に従い、他のスキルと同様に **Available to agent** でオン・オフを切り替えられます。
- そのMCPサーバーはツールライブラリに表示され、`librechat.yaml`で定義されたサーバーと同様にエージェントに追加できます。
- そのフックは、エージェントの実行中の特定のタイミング(ツール呼び出しの前や、実行が停止したときなど)でサーバー上で実行されます。フックは、ツール呼び出しをブロックしたり、プロンプトにコンテキストを追加したり、実行を停止したりすることができ、ユーザーにはその結果だけが表示されます。

スキルまたはMCPサーバーの名前が他で定義されたものと衝突する場合、もう一方の定義が優先されます。スタンドアロンのデプロイスキルディレクトリにあるスキルは、プラグインのスキルよりも優先されます。また、`librechat.yaml`で定義されたサーバーは、プラグインのサーバーよりも優先されます。

## プラグインに含めることができるもの [#what-a-plugin-can-contain]

プラグインフォルダには、`plugin.json` マニフェストと、以下のいずれかが含まれます:

- `skills/` 配下に、スキルごとに1つのフォルダがあり、それぞれに `SKILL.md` が含まれています。
- `mcp.json`、MCPサーバー定義。ローカル(`stdio`)サーバーはプラグインフォルダー内から実行され、独自の永続データディレクトリを持ちます。
- `ai.librechat/hooks/hooks.json`、コマンドフック。これらはAPIホスト上でプロセスとして実行され、運用者が有効にしない限り無効になっています。

各パーツは個別に読み込まれるため、`mcp.json` が壊れていても、プラグインのスキルの読み込みは停止しません。問題は起動時のログに報告されます。

## セットアップ [#setup]

プラグインは、デフォルトではプロジェクトルートの `./plugin` から読み込まれ、コマンドフックはデフォルトで無効になっています。ディレクトリ設定、パッケージのレイアウト、マニフェストとMCPの検証ルール、フックの実行契約については、[Agent Plugins configuration](/docs/configuration/agent_plugins) を参照してください。
