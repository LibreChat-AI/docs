채팅의 모든 메시지 아래에는 작은 버튼들이 한 줄로 나타납니다. 데스크톱에서는 메시지 위에 마우스를 올리거나 키보드 포커스를 해당 메시지로 옮기면 이 버튼들이 표시됩니다. 응답이 아직 스트리밍 중일 때는 의미가 없는 버튼들이 응답이 끝날 때까지 숨겨진 상태로 유지됩니다.

## 각 버튼의 기능 [#what-each-button-does]

| 버튼 | 기능 |
|---|---|
| **소리 내어 읽기** | 활성화된 경우 텍스트 음성 변환으로 메시지를 소리 내어 읽어 줍니다. |
| **클립보드에 복사** | 메시지 텍스트를 복사합니다. |
| **편집** | 메시지를 편집기에서 엽니다. [편집 및 다시 실행](#edit-and-rerun)을 참조하세요. |
| **포크** | 이 메시지에서 새 대화를 시작합니다. [대화 포크](/docs/features/fork)를 참조하세요. |
| **마음에 들어요** / **개선 필요** | 응답을 평가합니다. 이유와 의견을 추가할 수 있습니다. |
| **다시 생성** | 같은 메시지에 대해 모델에 새로운 응답을 요청합니다. 이전 응답은 이전 버전으로 계속 사용할 수 있습니다. |
| **계속** | 최신 응답이 출력 토큰 한도 등으로 완료되기 전에 중단된 경우 표시됩니다. 중단된 지점부터 이어서 생성합니다. |

어떤 버튼이 표시되는지는 엔드포인트와 메시지에 따라 달라집니다. 예를 들어, 사용자 메시지에는 평가 버튼이나 **Regenerate** 버튼이 없습니다.

## 편집 후 다시 실행 [#edit-and-rerun]

**편집**을 선택하여 자신의 메시지나 답변을 수정하세요. 편집기에는 세 개의 버튼이 있습니다.

- **Save**는 아무것도 새로 생성하지 않고 변경 사항을 유지합니다.
- **업데이트 및 다시 실행**은 수정한 메시지를 다시 보내고 새로운 답변을 받습니다. 수정한 내용이 없거나 답변을 편집 중일 때는 버튼이 **다시 실행**으로 표시되며, 이 경우 편집 중인 답변 앞에 있던 사용자 메시지를 다시 실행합니다.
- **Cancel**은 편집기를 닫습니다.

편집하는 동안 <kbd>Ctrl</kbd>+<kbd>S</kbd> (<kbd>Cmd</kbd>+<kbd>S</kbd>)는 저장하고, <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd>)는 다시 실행하며, <kbd>Escape</kbd>는 취소합니다.

재실행하면 원래 메시지에 첨부되었던 파일, 인용된 발췌 내용, 스킬이 그대로 유지되므로 다시 추가할 필요가 없습니다. 텍스트 없이 파일만 있는 메시지도 편집하여 재실행할 수 있습니다.

에이전트의 응답에는 텍스트 이상의 내용이 포함될 수 있습니다. 편집기에서는 텍스트와 추론(reasoning) 부분만 수정할 수 있으며, 도구 호출, 오류 및 아티팩트는 표시되지만 읽기 전용입니다. 다시 실행(rerun)은 한 번에 하나의 편집된 부분만 적용하므로, 여러 부분을 변경한 경우에는 **저장**을 사용하세요.

## 복사 [#copy]

**클립보드에 복사**는 메시지에 표시된 텍스트를 복사합니다. 에이전트 응답의 경우 추론, 도구 호출 및 오류는 제외됩니다. 인용은 읽기 쉬운 참조 형태로 변환됩니다.

Teams, Outlook 또는 Word와 같은 앱에 붙여넣으려면 **Settings > Chat**에서 **Copy messages as rich text**를 켜세요. 그러면 복사할 때 서식이 적용된 버전도 클립보드에 함께 저장되어, 제목, 목록, 표, 코드의 스타일이 그대로 유지됩니다.

## 인용문 발췌 [#quote-excerpts]

어떤 메시지에서든 텍스트를 선택한 후 **Add to chat**을 선택하세요. 선택한 발췌문은 입력창 위에 임시로 표시되며, 다음 메시지를 보낼 때 인용문으로 함께 전송되므로 모델이 정확히 어느 부분을 가리키는지 알 수 있습니다. 하나의 메시지에 최대 10개의 발췌문을 첨부할 수 있으며, 각 발췌문은 1,500자까지만 포함됩니다.

인용문도 [방향 전환 및 대기열 메시지](/docs/features/agents#steering-and-queued-messages)와 함께 사용할 수 있습니다. 발췌문은 대기열에 넣거나 방향 전환에 사용하는 메시지에 계속 첨부된 상태로 유지됩니다.

## 코드 블록 [#code-blocks]

답변의 코드 블록에는 헤더에 전용 버튼이 있습니다:

- **코드 복사**는 해당 블록을 복사합니다.
- **코드 다운로드**를 선택하면 블록의 언어에 따라 `code.py` 또는 `code.toml`과 같은 이름의 파일로 저장됩니다. 언어가 지정되지 않았거나 파일 확장자로 보이지 않는 경우에는 `code.txt`로 다운로드됩니다. 오류 블록에는 다운로드 버튼이 없습니다.
- **Run Code**은 해당 언어를 지원하는 경우 [Code Interpreter](/docs/features/code_interpreter)로 코드 블록을 실행합니다.
