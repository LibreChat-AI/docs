LibreChat은 에이전트 도구를 통해 이미지를 만들고 편집합니다. 에이전트에 이미지 도구를 부여하고 원하는 내용을 설명하면, 이미지가 대화에 나타납니다. 메시지와 함께 사진을 업로드하면 에이전트가 처음부터 다시 만드는 대신 해당 사진을 수정할 수 있습니다.

## 이미지 도구 [#the-image-tools]

| 도구 | 기능 | 이미지 편집 |
| --- | --- | --- |
| OpenAI Image Tools | OpenAI 이미지 모델로 텍스트에서 이미지를 생성하고, 업로드하거나 이전에 생성한 이미지를 편집합니다. 기본으로 사용하기 좋습니다. | 예 |
| Gemini Image Tools | Google의 Gemini 이미지 모델로 이미지를 생성하며, 선택적으로 이전 이미지를 시각적 컨텍스트로 활용합니다. | 예 |
| Flux | Black Forest Labs의 Flux 모델로 이미지를 생성하며, 직접 파인튜닝한 모델도 사용할 수 있습니다. | 아니요 |
| Stable Diffusion | 자체 Automatic1111 서버에서 이미지를 생성하므로 데이터가 네트워크 밖으로 나가지 않습니다. | 아니요 |

어떤 항목이 보이는지는 관리자가 구성한 설정에 따라 달라집니다.

## 이미지 생성 [#generate-an-image]

<Steps>
<Step>
Agent Builder에서 에이전트를 열고, **Tools** 옆의 **Add**를 선택하세요.
</Step>
<Step>
이미지 도구(예: **OpenAI Image Tools**)를 선택한 후 에이전트를 저장하세요. 도구가 API 키를 요구하는 경우, 관리자가 키 설정을 각 사용자에게 맡겨 둔 것이므로 본인의 API 키를 입력하세요.
</Step>
<Step>
에이전트와 채팅을 시작하고 이미지를 설명하세요.
</Step>
</Steps>

에이전트는 요청을 도구에 전달할 프롬프트로 바꾸므로, 평소처럼 자연스럽게 말하면 됩니다("제과 바자회 포스터, 가로로 긴 형식, 파스텔 색상을 많이"). 도구가 지원하는 경우 모양과 크기 요청도 함께 전달됩니다. OpenAI는 정사각형, 가로형, 세로형 크기를 지원하며(최신 모델은 최대 4K까지 사용자 지정 크기도 지원), 품질 수준과 투명 배경도 설정할 수 있습니다. Gemini는 16:9나 9:16 같은 화면 비율을 지원하며, 최신 모델에서는 최대 4K 해상도도 지원합니다. Stable Diffusion은 항상 1024x1024 크기로 생성합니다.

## 이미지 편집 [#edit-an-image]

이미지를 첨부하려면 **Upload Image**를 사용한 뒤 변경 사항을 요청하세요. 예: "배경의 사람들을 제거해 줘", "수채화 느낌으로 바꿔 줘", "이 로고를 커피잔에 넣어 줘". OpenAI Image Tools를 사용하면 에이전트가 이미지 편집 도구를 호출하고, Gemini를 사용하면 첨부한 이미지를 새 이미지 생성을 위한 컨텍스트로 전달합니다.

에이전트가 방금 생성한 이미지를 기준으로 "하늘을 더 어둡게 해줘"와 같이 업로드 없이 작업을 이어갈 수 있습니다. 업로드되거나 생성된 모든 이미지에는 모델이 참조하는 ID가 있으며, 이 ID는 이미지가 대화의 컨텍스트 윈도우 안에 남아 있는 동안 작동합니다. 대화가 길어지면 이미지를 다시 첨부하세요.

Flux와 Stable Diffusion은 텍스트로만 작동하므로 편집할 수 없습니다.

## 모델이 보는 내용 [#what-the-model-sees]

생성된 이미지는 생성 직후 모델에게 한 번 보여지며, 이를 통해 모델이 자신의 작업물을 설명하거나 확인할 수 있습니다. 그 이후에는 모델이 사용자의 메시지에 첨부된 이미지만 볼 수 있습니다. 몇 차례 대화가 지난 후에 이전 이미지에 대해 논의하고 싶다면, 해당 이미지를 다시 첨부하세요.

이미지가 모델로 다시 전달되므로, 이미지 도구를 사용하는 에이전트에는 비전(vision)을 지원하는 모델을 사용하세요. 텍스트 전용 모델은 이미지가 생성된 다음 턴에서 실패할 수 있습니다.

생성된 이미지는 다른 업로드 파일과 마찬가지로 관리자의 파일 스토리지 설정에 따라 저장됩니다. 기본적으로 짧은 쪽의 길이가 최대 768픽셀이 되도록 축소되므로, 관리자가 이 설정을 변경하지 않는 한 4K로 요청한 이미지도 모델이 생성한 크기보다 작게 저장됩니다.

## MCP 서버의 이미지 [#images-from-mcp-servers]

MCP 도구는 이미지도 반환할 수 있습니다. 예를 들어 스크린샷을 찍는 브라우저 서버가 있습니다. 서버가 MCP의 이미지 형식으로 반환한 이미지는 기본 제공 도구의 출력과 동일한 방식으로 채팅에 표시됩니다. 일부 서버는 이미지에 대한 URL만 반환하는데, 이 경우 LibreChat은 이를 이미지 출력으로 취급하지 않습니다.

## 프롬프트 작성하기 [#writing-prompts]

이미지 모델은 구체적인 묘사에 잘 반응합니다. 피사체와 매체(사진, 유화, 플랫 벡터 일러스트레이션)를 먼저 밝힌 다음, 구도, 조명, 그리고 중요한 세부 사항을 덧붙이세요. 피하고 싶은 것을 나열하기보다 보고 싶은 것을 설명하세요. 결과물이 원하는 것과 가깝다면 프롬프트 전체를 다시 쓰지 말고, 필요한 특정 변경 사항을 요청하세요.

## 설정 [#setup]

각 도구에는 API 키 또는 서버 URL이 필요합니다. 관리자는 `.env`에서 이를 설정하며, 키 기반 도구의 경우 관리자가 키를 비워 두고 각 사용자가 직접 입력하도록 할 수도 있습니다. 각 도구의 설정 방법은 다음과 같습니다: [OpenAI Image Tools](/docs/configuration/tools/openai_image_gen), [Gemini Image Tools](/docs/configuration/tools/gemini_image_gen), [Flux](/docs/configuration/tools/flux), [Stable Diffusion](/docs/configuration/tools/stable_diffusion). 이미지가 저장되는 위치는 [`fileStrategy`](/docs/configuration/librechat_yaml/object_structure/config#filestrategy)에서 설정합니다.
