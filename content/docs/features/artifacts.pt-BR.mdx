Artefatos permitem que um agente entregue algo que você pode visualizar e executar, em vez de um bloco extenso de código: um componente React, uma página HTML, um SVG, um documento Markdown ou um diagrama Mermaid. O resultado é exibido em um painel ao lado do chat, onde você pode visualizá-lo, ler e editar o código-fonte e fazer o download.

## Ativar artefatos para um agente [#turn-on-artifacts-for-an-agent]

Artefatos pertencem a um agente, então o agente com o qual você conversa decide se você poderá usá-los.

<Steps>
<Step>
Abra o agente no Agent Builder e localize a seção **Tools**.
</Step>
<Step>
Selecione **Add** ao lado de **Tools**, escolha **Artifacts** e adicione-o ao agente.
</Step>
<Step>
Escolha um **Modo** e, em seguida, salve o agente.
</Step>
</Steps>

O modo controla quais instruções o LibreChat fornece ao modelo sobre artefatos:

- **Normal**: as instruções padrão. O agente pode produzir artefatos React, HTML, SVG, Markdown e Mermaid.
- **shadcn/ui**: adiciona instruções para a biblioteca de componentes shadcn/ui, que ajuda quando você quer protótipos de interface refinados, construídos a partir de componentes pré-prontos.
- **Personalizado**: mantém o painel e a renderização ativados, mas não envia instruções integradas. As instruções do seu agente precisam ensinar ao modelo a sintaxe dos artefatos e quais tipos ele pode usar.

Para o modo Custom, as instruções precisam mostrar o wrapper que o LibreChat procura:

````md
:::artifact{identifier="unique-id" type="text/html" title="Short Title"}
```
Artifact content here
```
:::
````

`type` é um dos seguintes valores: `text/html`, `application/vnd.react`, `image/svg+xml`, `application/vnd.mermaid` ou `text/markdown`.

## Abrindo um artefato [#opening-an-artifact]

Quando o agente gera um artefato, a mensagem exibe uma linha com o título e o tipo do artefato em vez do código bruto. Clique nela para abrir o painel e clique novamente para fechá-lo. Se uma conversa produziu vários artefatos, um menu de versões no cabeçalho do painel permite alternar entre eles.

Blocos de código Mermaid são exibidos como cartões compactos de diagrama em qualquer chat, independentemente de o agente ter artifacts habilitados. Use **Open as artifact** em um diagrama para movê-lo para o painel.

## Trabalhando no painel [#working-in-the-panel]

- **Pré-visualização** renderiza o artefato. **Atualizar** recarrega a pré-visualização, o que é útil quando um componente interativo entra em um estado inadequado.
- **Code** mostra o código-fonte em um editor. Você pode editá-lo depois que a resposta terminar de ser transmitida, e suas alterações são salvas de volta na mensagem, de modo que a visualização e as visitas posteriores mostram a versão editada.
- O botão de cópia copia o código-fonte. **Download** salva o conteúdo como um arquivo com o nome do título do artefato. Um arquivo proveniente de execução de código é baixado como o arquivo original, caso você não o tenha editado; conteúdo editado ou somente de visualização recebe `.preview` no nome, para que você não o confunda com o original.
- Os diagramas Mermaid têm **Export as SVG** e **Export as PNG** em vez disso, tanto no painel quanto no diagrama embutido.
- **Entrar em tela cheia** expande a pré-visualização para a tela inteira; pressione Escape para sair. O botão fica oculto quando o seu navegador não permite o modo de tela cheia.
- **Abrir em nova janela** move o painel para uma janela separada do navegador, o que é útil em um segundo monitor. O artefato continua sendo atualizado enquanto a resposta é transmitida, e as edições de código não salvas são mantidas. Mantenha a aba do chat aberta, pois fechá-la também fecha a janela. **Acoplar de volta ao painel** (ou fechar a janela) traz o painel de volta, e o LibreChat lembra o tamanho e a posição da janela. Se nada for aberto, permita pop-ups para o seu site do LibreChat. O botão não é exibido em layouts móveis estreitos.

A pré-visualização é executada em um iframe isolado (sandbox) usando o Sandpack, do CodeSandbox. Os artefatos React podem importar um conjunto fixo de bibliotecas comuns; o modelo é informado sobre o que está disponível, e qualquer outra biblioteca falhará ao carregar.

Arquivos gravados pela execução de código, como relatórios HTML, documentos do Word, planilhas e apresentações de slides, também são abertos neste painel. Consulte [Code Interpreter](/docs/features/code_interpreter) para saber como funcionam essas pré-visualizações.

## Configuração [#setup]

Os artefatos estão ativados por padrão para os agentes: a capacidade de agente `artifacts` fica habilitada, a menos que um administrador a remova, e cada agente ainda precisa ter Artifacts adicionado em suas ferramentas. Os administradores também podem ativar artefatos em uma especificação de modelo (Model Specs), hospedar por conta própria o empacotador Sandpack ou desativar a opção de nova janela. Consulte [Configuração de artefatos](/docs/configuration/artifacts).
