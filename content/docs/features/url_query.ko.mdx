채팅 URL에 쿼리 파라미터를 추가하여 엔드포인트와 모델을 선택하거나, 에이전트 또는 모델 사양을 불러오거나, 프롬프트를 미리 채우거나, 채팅이 시작되기 전에 모델 설정을 변경할 수 있습니다. 이를 활용하면 북마크, 런처 바로가기(Raycast, Alfred, 브라우저 키워드), 또는 다른 앱에서 연결되는 링크를 만들어 사용자가 올바른 설정으로 바로 이동하도록 할 수 있습니다.

```
https://chat.example.com/c/new?endpoint=anthropic&model=claude-sonnet-4-5&prompt=Summarize%20this%20article
```

매개변수는 새 채팅(`/c/new`)과 기존 채팅(`/c/<conversation-id>`) 모두에서 작동합니다. LibreChat이 매개변수를 읽은 후에는 주소 표시줄에서 해당 매개변수를 지우므로, 페이지를 새로 고쳐도 같은 매개변수가 다시 적용되지 않습니다.

## 엔드포인트와 모델 선택 [#pick-the-endpoint-and-model]

`endpoint`와 `model`을 함께 사용하는 것이 가장 예측 가능한 조합입니다.

- `endpoint`만 지정하면 해당 엔드포인트로 전환되며, 마지막으로 그곳에서 선택했던 모델 또는 목록의 첫 번째 모델을 사용합니다.
- `model`만 지정하면 해당 endpoint에 모델이 있는 경우, 현재 endpoint 내에서 모델이 전환됩니다.

내장 엔드포인트 값은 `openAI`, `azureOpenAI`, `google`, `anthropic`, `bedrock`, `agents`, `assistants`, `azureAssistants`입니다. [커스텀 엔드포인트](/docs/quick_start/custom_endpoints)의 경우 설정 파일에 있는 이름을 사용하세요. 대소문자를 구분하지 않으므로 `endpoint=openrouter`는 `OpenRouter`라는 이름의 엔드포인트와 일치합니다.

## 에이전트, 어시스턴트 또는 모델 스펙 불러오기 [#load-an-agent-assistant-or-model-spec]

```
/c/new?agent_id=agent_abc123
/c/new?assistant_id=asst_abc123
/c/new?spec=meeting-notes
```

`agent_id`와 `assistant_id`는 엔드포인트를 자동으로 설정합니다. `spec`은 [모델 스펙](/docs/configuration/librechat_yaml/object_structure/model_specs)을 `name`으로 불러옵니다. 같은 URL에 포함된 다른 설정은 스펙의 프리셋 위에 적용됩니다. 관리자가 모델 스펙을 강제하는 경우, 모든 링크에 `spec`을 포함하고 URL보다 스펙 자체의 값이 우선 적용된다는 점을 참고하세요.

## 프롬프트 입력 또는 전송 [#fill-in-or-send-the-prompt]

`prompt`(또는 더 짧은 `q`)은 메시지 입력창에 텍스트를 넣습니다. 두 가지가 모두 있으면 `prompt`가 우선합니다.

다음 내용이 준비되면 바로 전송되도록 `submit=true`를 추가하세요:

```
/c/new?endpoint=openAI&model=gpt-4o&prompt=Explain%20quantum%20computing&submit=true
```

요청한 설정을 몇 초 안에 적용할 수 없으면 프롬프트는 전송되지 않고 메시지 입력창에 그대로 남습니다. 관리자가 자동 전송을 끈 경우에는 `submit=true`를 사용해도 프롬프트만 입력되고, 전송 버튼은 직접 눌러야 합니다.

값은 URL 인코딩되어야 합니다. JavaScript에서는 `encodeURIComponent()`를 사용하면 됩니다:

```js
const url = `/c/new?prompt=${encodeURIComponent('Write a function: def hello()')}`;
// /c/new?prompt=Write%20a%20function%3A%20def%20hello()
```

## 모델 설정 변경 [#change-model-settings]

다음 중 어떤 항목이든 URL에 추가할 수 있습니다. 각 항목은 이를 지원하는 엔드포인트에서만 적용되며, 값은 적용 전에 검증됩니다. 유효하지 않은 값은 오류 없이 무시됩니다.

| 엔드포인트 | 매개변수 |
| --- | --- |
| 모든 엔드포인트 | `maxContextTokens`, `resendFiles`, `promptPrefix` (사용자 지정 지침) |
| OpenAI, Azure OpenAI, 사용자 지정 | `temperature`, `top_p`, `presence_penalty`, `frequency_penalty`, `stop`, `max_tokens`, `reasoning_effort`, `reasoning_summary`, `verbosity`, `useResponsesApi`, `disableStreaming`, `imageDetail` (`low`, `auto`, `high`) |
| OpenAI Responses API | `reasoning_mode` (`standard`, `pro`), `reasoning_context` (`auto`, `current_turn`, `all_turns`) |
| OpenAI, Anthropic, Google | `web_search` (`true`/`false`), `fileTokenLimit` (파일 내용에 대한 토큰 상한) |
| Anthropic, Google | `temperature`, `topP`, `topK`, `maxOutputTokens`, `thinking`, `thinkingBudget`, `thinkingLevel` |
| Anthropic | `effort` (`low`, `medium`, `high`, `xhigh`, `max`), `thinkingDisplay` (`auto`, `summarized`, `omitted`, 또는 도구 호출 사이의 진행 메모만 표시하는 `updates`) |
| Anthropic, Bedrock (Anthropic 모델), OpenRouter | `promptCache` (`true`/`false`), `promptCacheTtl` (`5m` 또는 `1h`) |
| Google | `url_context=true` 설정 시 Gemini가 메시지에 포함된 URL을 읽을 수 있습니다 |
| Bedrock | `region`, `maxTokens`, `temperature`, `topP`, `reasoning_effort` |
| Assistants | `instructions` (이번 실행에 한해 어시스턴트의 지침을 대체), `append_current_datetime=true` |

각 필드의 의미와 허용되는 값은 [모델 스펙 프리셋 필드](/docs/configuration/librechat_yaml/object_structure/model_specs)에 나와 있습니다. 제공업체가 거부하는 값을 전달하면(예: 모델의 한도를 넘는 `max_tokens`), 전송 시 API 오류가 발생합니다. 이때는 **New chat**을 시작하여 해당 설정을 지우십시오.

## 색상 모드 설정 [#set-the-color-mode]

관리자가 활성화하면 링크에 `theme=light`, `theme=dark`, 또는 `theme=system`을 지정하여 색상 모드를 설정할 수 있습니다. 따라서 LibreChat으로 연결되는 앱이 자체 테마를 전달할 수 있습니다. 이 설정은 설정에서 직접 변경하기 전까지 사용자의 환경설정으로 저장됩니다.

## 설정 [#setup]

쿼리 매개변수는 별도의 설정 없이 작동합니다. 관리자는 [`interface.autoSubmitFromUrl`](/docs/configuration/librechat_yaml/object_structure/interface#autosubmitfromurl)을 사용하여 `submit=true`가 자동으로 전송되지 않도록 설정할 수 있으며, [`interface.colorModeFromUrl`](/docs/configuration/librechat_yaml/object_structure/interface#colormodefromurl)을 사용하여 `theme` 매개변수를 활성화할 수 있습니다.
