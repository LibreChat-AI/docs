记忆是一个小型的事实存储,以键值对的形式保存关于你的信息,LibreChat 会将其添加到每条新消息的上下文中。只需告诉模型一次“记住我用 Python 写代码,并且偏好简短的回答”,它在你下一次对话时也会记得这些内容。

这不是对您聊天记录的搜索。除非已保存为记忆条目,否则不会调取任何旧对话中的内容。整个记忆存储会包含在每次请求中,因此它适用于少量持久性事实,而不适用于笔记或文档。

## 保存记忆 [#saving-a-memory]

在 [消息输入框](/docs/features/composer) 中点击 **+** 以打开面板,然后在 **Tools** 部分选择 **Memory**。开启后,模型将获得两个工具,`set_memory` 和 `delete_memory`,并被指示仅在您要求其记住、更新或忘记某些内容时才使用它们。诸如“记住我的团队使用 pnpm”之类的消息会在回复中生成一个“Saved memory”步骤,并以记忆的键命名;展开该步骤即可查看已保存的值。“忘记我工作的地方”则会生成“Deleted memory”。当模型在一次回复中进行多次记忆调用时,这些调用会被归入同一个步骤下,例如“Ran 2 actions”。

只有当你的角色被允许创建和更新记忆时,才会显示"记忆"选项。与智能体聊天时,工具面板中没有"记忆"选项;如果在智能体构建器中启用了记忆,智能体便会使用记忆功能。

代理还可以设置为**为此代理单独保存记忆**:此时它会读取和写入自己的存储,与您的共享记忆以及其他代理的记忆相互隔离。这些条目跟随对代理的访问权限:如果您失去对该代理的访问权限,其单独保存的记忆将无法再被读取或更新,但对于已被删除的代理,您仍可以删除其记忆。

部分部署还会运行一个后台记忆代理,它会审查每次对话并自动保存事实,无需您主动要求。是否启用此功能由您的管理员决定。

## 查看和编辑记忆 [#viewing-and-editing-memories]

在侧边栏中打开 **Memories** 即可查看所有已保存的关于您的信息。在此处您可以:

- 按键或值筛选列表，或者当您拥有代理范围的记忆（标记为"Agent-scoped memory"）时，按代理进行筛选。
- 点击 **+**(**Create Memory**)可自行添加条目。键名只能使用小写字母和下划线,且每个键名只能存在一次。
- 编辑或删除任意条目。

当管理员设置了大小限制时,面板会显示您已使用的容量。存储空间满后,新的保存操作会失败并提示"Memory Storage Full",直到您删除部分内容为止。单个条目也有长度上限。

## 为自己关闭记忆功能 [#turning-memory-off-for-yourself]

在 Memories 面板中的 **Use memory** 按钮(也可在 **Settings** > **Data & Privacy** 下的 **Reference saved memories** 中找到)用于控制是否将您保存的记忆添加到对话中。关闭后,LibreChat 将停止添加这些记忆,也不再提供 Memory 工具;您的条目会被保留,重新开启后即可再次使用。

只有在管理员允许用户选择退出时,才会显示此开关。记忆功能也可以按角色进行限制,因此部分用户可能会看到该面板,但无法创建或编辑条目。

## 设置 [#setup]

在管理员于 `librechat.yaml` 中添加 `memory` 部分之前,记忆功能处于关闭状态。后台记忆代理是一项单独的可选功能,需要其own模型。有关限制、允许的键、记忆代理和故障排除,请参阅 [Memory configuration](/docs/configuration/librechat_yaml/object_structure/memory)。
