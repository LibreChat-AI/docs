Admin Insights 是一个可选启用的仪表板,用于查看 Agents 的使用情况,数据来源于部署环境主 MongoDB 中存储的活动记录。它按时间展示查看者可见的 Agents 的对话数、唯一用户数、已保存的消息数以及已记录的 Token 数,并提供热门用户、用户流失和最近对话等视图。

## 启用 Insights [#enable-insights]

在 `.env` 中设置 `ENABLE_INSIGHTS=true`，然后重启 LibreChat：

```sh filename=".env"
ENABLE_INSIGHTS=true
```

当账户可以查看至少一个 Agent 的洞察时,启用后,**Insights** 会出现在桌面端侧边栏和移动端面板切换器中。禁用时,访问路由和数据路由将返回 `404`,并且导航项保持隐藏。

## 访问要求 [#access-requirements]

根据登录账户的身份不同,其可以查看的 Agents 也有所区别:

- 拥有 `ADMIN` 角色的账户可以查看所有 Agent。
- 拥有 `read:insights` 系统能力的账户可以查看所有 Agent。
- 所有其他用户只能看到通过智能体的访问列表被授予 **VIEW** 和 **View insights** 权限的智能体。

`GET /api/insights/access` 仅在该账户无法访问任何 Agent 时返回 `403`；当请求中指定的 Agent 不在该可访问集合内时，仪表板路由同样返回 `403`。

只有管理员才能授予智能体的**查看洞察**权限。它是智能体共享对话框中的一个独立开关,其他用户看不到该开关,并且不能授予公开主体。管理员始终拥有访问权限。请使用[管理面板](/docs/features/admin_panel)分配 `read:insights` 能力,有关权限位的说明请参阅[访问控制](/docs/features/access_control)。

每个 Insights 查询的租户范围均来自已认证的账户。租户账户只能查看本租户的 Agents 和记录;没有租户的账户只能查看未划分租户范围的记录。

<Callout type="warning" title="敏感操作数据">
  Insights 可以显示用户名、电子邮件地址、会话 ID，以及最近会话中的第一条消息。请仅将 `read:insights` 或 **View insights** 权限授予需要查看这些数据的人员。
</Callout>

## 仪表板指标 [#dashboard-metrics]

指标的统计范围限定为查看者可见的智能体所参与的对话,并可通过智能体筛选器进一步缩小范围。四项汇总指标及其每日迷你趋势图均使用所选的日期范围。

- **对话:** 在所选时间范围内与所选 Agents 创建的对话
- **唯一用户数:** 在这些对话中,由匹配的已持久化消息活动所代表的用户
- **消息:** 这些对话中持久化保存的用户消息和助手消息
- **Tokens:** 记录的 `tokenCount` 值总和

仪表板还包括：

- **Top users:** 最多八位用户，按消息数量排序，包含其对话和消息总数
- **流失用户:** 在所选时间范围内,最近一次发送给任一所选 Agent 的消息已满 28 天的用户,最多八名。
- **最新对话：** 带有日期、所有者、第一条消息、持久化消息计数和已记录 token 的分页对话

这些是数据库活动指标，而非计费或 Langfuse 分析。Token 总数取决于随消息持久化的值，并不计算货币成本。

## 日期范围与搜索 [#date-ranges-and-search]

默认范围为七天。预设涵盖过去 24 小时、7 天或 30 天。自定义范围最多可跨越 30 个日历日，并按浏览器当前的时区进行分组。

Agent 过滤器使用带有固定 **All agents** 控件的显式复选框，用于选择或清除所有可访问的 Agent。当有超过十个 Agent 可用时，搜索过滤器会进行不区分大小写的名称匹配，且不会丢弃当前结果之外的已选项。

最近对话搜索匹配对话 ID 或用户身份。搜索从三个字符开始，最多接受 200 个字符，并将最新对话表格保持为每页 10 行的分页显示。摘要卡片、顶级用户和流失指标继续代表所选日期范围，而不是搜索结果子集。

## 数据与部署说明 [#data-and-deployment-notes]

Insights 直接查询现有的 Conversation、Message 和 User 集合，无需单独的分析数据库。结果仅反映持久化记录：不再存在于 MongoDB 中的临时数据或已删除数据无法显示。API 在运行聚合之前会限制自定义范围、结果列表、页面大小、搜索输入和租户范围。

请参阅 [`ENABLE_INSIGHTS`](/docs/configuration/dotenv#admin-insights) 以获取部署开关。
