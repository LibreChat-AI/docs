Insights 是一个仪表板,用于回答“谁在使用这个智能体,使用了多少?”。它会统计您有权查看的智能体的对话数、用户数、消息数和令牌数,并列出这些数字背后的用户和近期对话。该功能默认关闭,面向管理员和智能体所有者,而非所有用户。

## 打开仪表盘 [#opening-the-dashboard]

当启用 Insights 且您至少可以审查一个智能体时,侧边栏(以及移动端的面板切换器)中会显示 **Insights**。如果您无法审查任何智能体,则不会显示该入口。

谁可以审核哪些智能体:

- 拥有 `ADMIN` 角色的用户以及被授予 `read:insights` 权限的用户可以查看所有智能体。
- 对于其他人，只能看到他们同时拥有该智能体访问权限和 **View insights** 权限的智能体。

**查看洞察**是智能体分享对话框中的一个独立开关。只有管理员可以看到并开启该选项,它不属于查看者、编辑者或所有者角色,也不能授予所有人。在多租户部署中,每个账户只能看到其所属租户的智能体和数据。

Insights 显示用户名、电子邮件地址、对话 ID 以及近期对话的第一条消息。请将 **View insights** 和 `read:insights` 视为对这些数据的访问权限,而不仅仅是对图表的访问权限。

## 阅读这些数字 [#reading-the-numbers]

使用 **24h**、**7d**(默认)或 **30d** 选择时间范围,也可以自行选择开始和结束日期,但两者相隔不能超过 30 天。智能体选择器默认选中 **All agents**;您可以将其缩小到特定智能体,当智能体超过十个时,还可以按名称搜索。

顶部的四张卡片展示所选时间范围和智能体的数据,每张卡片都包含一个按日显示的小型图表:

- **对话**：在该时间范围内与这些智能体创建的对话。
- **唯一用户**:在这些对话中拥有已保存消息的用户。
- **消息**:保存在这些对话中的用户消息和助手消息。
- **Tokens**:这些消息上记录的 token 数量。这不是成本数字。

下方:

- **Top users** 列出消息数最多的最多八位用户，并显示他们的对话总数和消息总数。
- **流失用户**列出最多八名用户，他们最后一次向任一所选智能体发送消息的时间在所选范围内已满 28 天，这是一种快速发现哪些用户不再回来的方法。
- **最新对话**是一个分页表格(每页 10 条),包含日期、用户、首条消息以及消息数和 token 数。输入三个字符后,**按对话 ID 或用户搜索**即可过滤此表格;上方的卡片和用户列表仍会显示完整范围的数据。

## 计入与不计入的范围 [#what-it-does-and-does-not-count]

Insights 直接读取 LibreChat 的 MongoDB 数据库中已有的对话、消息和用户数据。它没有单独的分析存储,因此任何已被删除的内容,以及临时对话在过期后,也都会从 Insights 中消失。Insights 与 Langfuse 追踪数据、余额及计费数据均无关联。

## 设置 [#setup]

管理员通过 `ENABLE_INSIGHTS=true` 并重启来开启该功能;此后,管理员可立即访问,并可通过 `read:insights` 或 **View insights** 开关将访问权限授予其他人。参见 [Admin Insights configuration](/docs/configuration/access_control#admin-insights)。
