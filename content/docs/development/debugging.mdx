## Useful Settings

- Set `DEBUG_CONSOLE=true` in `.env` for verbose server output in the console.
- Run `npm run backend:inspect` to start the backend with the Node.js inspector (`--inspect`) and `--expose-gc`, so you can attach a debugger.

See also: [Logging System](/docs/configuration/logging)
