## Paramètres utiles [#useful-settings]

- Définissez `DEBUG_CONSOLE=true` dans `.env` pour obtenir une sortie serveur détaillée dans la console.
- Exécutez `npm run backend:inspect` pour démarrer le backend avec l'inspecteur Node.js (`--inspect`) et `--expose-gc`, afin de pouvoir attacher un débogueur.

Voir aussi : [Système de journalisation](/docs/configuration/logging)
