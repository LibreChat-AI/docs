## Menyiapkan Lingkungan [#prepare-the-environment]

### Node.js dan npm [#nodejs-and-npm]

Jika Anda menggunakan `nvm`, instal dan pilih versi Node.js yang direkomendasikan sebelum menginstal LibreChat:

```sh filename="Use Node.js 24"
nvm install 24.22.1
nvm use 24.22.1
npm install -g npm@11.16.0
```

File `.nvmrc` di repositori LibreChat adalah sumber kebenaran untuk versi Node.js; menjalankan `nvm use` dari root repositori akan memilihnya.

Pastikan shell Anda menggunakan versi yang diharapkan:

```sh filename="Check Node.js and npm"
node -v
npm -v
```

```txt filename="Expected versions"
v24.22.1
11.16.0
```

### GitHub [#github]

- Fork repositori LibreChat: [https://github.com/LibreChat-AI/LibreChat/fork](https://github.com/LibreChat-AI/LibreChat/fork)

- Clone fork Anda dan tambahkan repositori asli sebagai `upstream`. Kontribusi bercabang dari dan ditujukan ke `dev`; `main` hanya diperbarui saat rilis.

```sh filename="Clone your fork and sync dev"
git clone https://github.com/username/LibreChat.git
cd LibreChat
git remote add upstream https://github.com/LibreChat-AI/LibreChat.git
git fetch upstream dev
git checkout -B dev upstream/dev
```

- Buat cabang (branch) baru yang deskriptif dan menggunakan garis miring (slash) dari `dev`:

```sh filename="Create your working branch"
git checkout -b new/feature/x
```

> Ganti `username` dan nama branch dengan detail Anda. Jangan gunakan `npm run update` untuk memperbarui branch pengembangan; perintah tersebut adalah pembaruan untuk self-host dan akan melakukan checkout ke `main`.

### Persiapkan LibreChat [#prepare-librechat]

- Buka terminal di VS Code dengan `ctrl`+`shift`+`` ```

  > Sebagai alternatif, gunakan `ctrl`+`j` untuk membuka panel bawah dan pilih terminal.

- ```sh filename="Install LibreChat dependencies"
  npm run smart-reinstall
  ```

  > Jika Anda baru saja mengubah versi Node.js atau npm, gunakan `npm run reinstall` sekali untuk instalasi yang bersih.

- ```sh filename="Build all compiled code"
  npm run build
  ```

- Konfigurasi .env
  - Buat file `.env`. Jika Anda belum memilikinya, duplikat `.env.example` dan konfigurasikan file tersebut.

- Git hooks
  - `npm install` menyiapkan pemeriksaan pre-commit husky, yang menjalankan job CI Static Checks secara lokal pada file di setiap commit (ESLint, Prettier, urutan import, dan dependensi sirkular). Atur `HUSKY=0` untuk menonaktifkannya, dan jalankan pemeriksaan secara manual dengan `npm run static-checks`.

<Callout type="warning" title="Peringatan">
  Nilai default di dalam `.env.example` biasanya sudah cukup, kecuali untuk `MONGO_URI`. Sediakan nilai Anda sendiri.
  Pastikan untuk menginstal MongoDB dan mengonfigurasi `MONGO_URI` dengan benar untuk terhubung ke instans MongoDB Anda. Gunakan [MongoDB Community Server](https://www.mongodb.com/try/download/community) atau [MongoDB Atlas Cloud](https://www.mongodb.com/cloud/atlas/register).
</Callout>

### Alur Kerja Pengembangan [#development-workflow]

Untuk pekerjaan yang efisien di LibreChat, gunakan perintah-perintah berikut:

- **Memulai Backend:**
  - Gunakan `npm run backend` untuk pengoperasian normal.
  - Untuk pengembangan aktif, gunakan `npm run backend:dev` untuk memantau perubahan.
  - Akses di `http://localhost:3080/`.

- **Menjalankan Frontend dalam Mode Pengembangan:**
  - **Pastikan backend sedang berjalan.**
  - Gunakan `npm run frontend:dev` untuk memantau perubahan frontend.
  - Lihat di `http://localhost:3090/`.

<Callout type="tip" title="Tips Pro">
  - Untuk pembaruan waktu nyata selama pengembangan frontend, jalankan `npm run frontend:dev` agar perubahan frontend diperbarui pada port `3090`.
  - Atur `DEBUG_CONSOLE=true` di dalam `.env` untuk output server yang lebih rinci di konsol.
</Callout>

## Commit, Push, Pull Request (PR) [#commit-push-pull-request-pr]

### Lakukan Commit [#make-a-commit]

**Commit** menandai titik pemeriksaan logis dalam pengembangan. Gunakan pesan commit konvensional yang diawali dengan tipe seperti `feat`, `fix`, `docs`, atau `refactor`, diikuti dengan ringkasan singkat.

**Contoh:**

```bash filename=" "
git add .
git commit -m "feat: Add login functionality"
```

### Push Perubahan [#push-changes]

**Push** perubahan ke repositori remote setelah menyelesaikan fitur atau memperbaiki masalah.

**Contoh:**

```bash filename=" "
git push origin feature-branch-name
```

### Membuat Pull Request (PR) [#create-a-pull-request-pr]

**Pull Request** menggabungkan perubahan dari feature branch ke dalam branch `dev`.

1. Tarik perubahan terbaru dari `dev` dan selesaikan konflik.
2. Push branch fitur yang telah diperbarui.
3. Pastikan kode mengikuti pedoman proyek.

**Contoh:**

```bash filename=" "
git fetch upstream dev
git checkout feature-branch-name
git rebase upstream/dev
# Resolve conflicts if any
git push origin feature-branch-name
# Open PR on GitHub
```

Akses fork Anda di browser lalu klik "Contribute", dan pastikan pull request menargetkan `dev`.

<Callout type="info" title="Catatan:">
  Berikan deskripsi PR yang mendetail untuk menjelaskan perubahan dan nilainya. Referensikan isu terkait.
</Callout>

<Callout type="tip" title="Tips">
  Gunakan GitHub Desktop untuk melacak perubahan.
</Callout>

<Callout type="warning" title="Peringatan">
  Jika `git commit` gagal karena kesalahan ESLint, pahami dan perbaiki masalah tersebut.
</Callout>

## Mengembalikan Commit dengan Aman [#revert-commits-safely]

Untuk membatalkan perubahan di feature branch, ikuti langkah-langkah ini dengan hati-hati:

- ```bash filename="1. Update local repository from feature branch:"
  git pull origin feature-branch-name
  ```

- ```bash filename="2. Review commit history to determine commits to revert:"
  git log
  ```

- ```bash filename="3. Start an interactive rebase for 'N' commits to revert:"
  git rebase -i HEAD~N
  ```

  > Ganti `pick` dengan `drop` untuk commit yang ingin dihapus. Simpan dan keluar dari editor.

- ```bash filename="4. Force push changes to remote repository:"
  git push --force-with-lease origin feature-branch-name
  ```
