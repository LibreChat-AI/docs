## Handige instellingen [#useful-settings]

- Stel `DEBUG_CONSOLE=true` in in `.env` voor uitgebreide server-output in de console.
- Voer `npm run backend:inspect` uit om de backend te starten met de Node.js-inspector (`--inspect`) en `--expose-gc`, zodat je een debugger kunt koppelen.

Zie ook: [Logsysteem](/docs/configuration/logging)
