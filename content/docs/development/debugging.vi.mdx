## Các cài đặt hữu ích [#useful-settings]

- Đặt `DEBUG_CONSOLE=true` trong `.env` để nhận đầu ra máy chủ chi tiết trong console.
- Chạy `npm run backend:inspect` để khởi động backend với trình kiểm tra Node.js (`--inspect`) và `--expose-gc`, giúp bạn đính kèm trình gỡ lỗi.
