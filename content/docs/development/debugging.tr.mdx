## Kullanışlı Ayarlar [#useful-settings]

- Konsolda ayrıntılı sunucu çıktısı almak için `.env` dosyasında `DEBUG_CONSOLE=true` ayarını yapın.
- `npm run backend:inspect` komutunu çalıştırarak backend'i Node.js inspector (`--inspect`) ve `--expose-gc` seçenekleriyle başlatabilirsiniz; böylece bir hata ayıklayıcı (debugger) ekleyebilirsiniz.

Ayrıca bakınız: [Günlük Kayıt Sistemi](/docs/configuration/logging)
