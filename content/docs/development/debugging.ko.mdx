## 유용한 설정 [#useful-settings]

- 콘솔에서 자세한 서버 출력을 확인하려면 `.env` 파일에 `DEBUG_CONSOLE=true`를 설정하세요.
- `npm run backend:inspect`를 실행하면 Node.js 인스펙터(`--inspect`)와 `--expose-gc` 옵션이 적용된 상태로 백엔드가 시작되며, 이를 통해 디버거를 연결할 수 있습니다.

참고: [로깅 시스템](/docs/configuration/logging)
