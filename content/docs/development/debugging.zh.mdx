## 实用设置 [#useful-settings]

- 在 `.env` 中设置 `DEBUG_CONSOLE=true` 以在控制台中获取详细的服务器输出。
- 运行 `npm run backend:inspect`,即可使用 Node.js 检查器(`--inspect`)并启用 `--expose-gc` 启动后端,从而附加调试器。

另请参阅:[日志系统](/docs/configuration/logging)
