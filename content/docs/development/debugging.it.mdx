## Impostazioni utili [#useful-settings]

- Imposta `DEBUG_CONSOLE=true` nel file `.env` per un output dettagliato del server nella console.
- Esegui `npm run backend:inspect` per avviare il backend con l'ispettore di Node.js (`--inspect`) e `--expose-gc`, così da poter collegare un debugger.

Vedi anche: [Sistema di logging](/docs/configuration/logging)
