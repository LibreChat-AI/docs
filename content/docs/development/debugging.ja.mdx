## 便利な設定 [#useful-settings]

- `.env` に `DEBUG_CONSOLE=true` を設定すると、コンソールに詳細なサーバー出力が表示されます。
- `npm run backend:inspect` を実行すると、Node.js インスペクター（`--inspect`）と `--expose-gc` を有効にした状態でバックエンドが起動し、デバッガーをアタッチできます。

参照: [ロギングシステム](/docs/configuration/logging)
