## Przydatne ustawienia [#useful-settings]

- Ustaw `DEBUG_CONSOLE=true` w pliku `.env`, aby uzyskać szczegółowe dane wyjściowe serwera w konsoli.
- Uruchom `npm run backend:inspect`, aby uruchomić backend z inspektorem Node.js (`--inspect`) oraz `--expose-gc`, dzięki czemu możesz podłączyć debugger.

Zobacz także: [System logowania](/docs/configuration/logging)
