## Nützliche Einstellungen [#useful-settings]

- Setzen Sie `DEBUG_CONSOLE=true` in der `.env` für ausführliche Server-Ausgaben in der Konsole.
- Führe `npm run backend:inspect` aus, um das Backend mit dem Node.js-Inspector (`--inspect`) und `--expose-gc` zu starten, damit du einen Debugger anhängen kannst.

Siehe auch: [Logging-System](/docs/configuration/logging)
