## Configuraciones útiles [#useful-settings]

- Establezca `DEBUG_CONSOLE=true` en `.env` para obtener una salida detallada del servidor en la consola.
- Ejecuta `npm run backend:inspect` para iniciar el backend con el inspector de Node.js (`--inspect`) y `--expose-gc`, de modo que puedas conectar un depurador.

Ver también: [Sistema de registro](/docs/configuration/logging)
