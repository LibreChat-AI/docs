## Pengaturan yang Berguna [#useful-settings]

- Atur `DEBUG_CONSOLE=true` di dalam `.env` untuk output server yang lebih rinci di konsol.
- Jalankan `npm run backend:inspect` untuk memulai backend dengan Node.js inspector (`--inspect`) dan `--expose-gc`, sehingga Anda dapat menghubungkan debugger.

Lihat juga: [Sistem Logging](/docs/configuration/logging)
