LibreChat의 인터페이스는 npm에 `@librechat/client`로 배포된 공유 React 컴포넌트 세트로 구성되어 있습니다. 이 섹션의 페이지들은 각 컴포넌트를 게시된 패키지에서 렌더링한 실시간 화면으로 보여주며, 앱과 동일한 테마를 사용합니다. 각 화면 아래에는 해당 컴포넌트를 렌더링하는 코드가 함께 표시됩니다.

모든 미리보기는 이 사이트의 라이트 모드 또는 다크 모드를 따릅니다. 예시는 LibreChat 자체 코드가 이 컴포넌트를 사용하는 방식에 맞춰 작성되었습니다. 즉, 레이블은 해당 필드와 연결되어 있고, 문자열은 현지화되어 있으며, 원시 팔레트 색상 대신 시맨틱 색상 토큰을 사용합니다.

## 설치 [#install]

```bash
npm install @librechat/client
```

패키지는 런타임 라이브러리(React, Tailwind CSS 4, Radix UI, Ariakit 등)를 피어 의존성(peer dependencies)으로 나열하므로, 호스트는 필요한 버전을 한 번만 설치하고 이를 공유합니다. 누락된 항목이 있으면 패키지 관리자가 이를 알려줍니다.

## 스타일 설정하기 [#set-up-the-styles]

컴포넌트는 Tailwind CSS 4와 LibreChat의 테마 토큰을 사용하여 스타일이 적용됩니다. Tailwind 다음에 패키지의 테마 및 컴포넌트 스타일을 가져온 후, 패키지 프리셋을 사용하는 Tailwind 설정을 불러오세요:

```css title="style.css"
@import 'tailwindcss';
@import '@librechat/client/theme.css';
@import '@librechat/client/style.css';
@config './tailwind.config.js';
```

```js title="tailwind.config.js"
const libreChatTailwindPreset = require('@librechat/client/tailwind-preset')

module.exports = {
  presets: [libreChatTailwindPreset],
  content: [
    './src/**/*.{js,jsx,ts,tsx}',
    './node_modules/@librechat/client/dist/**/*.{js,mjs,cjs}',
  ],
  darkMode: ['class'],
}
```

그런 다음 앱을 `ThemeProvider`로 감싸는데, 이는 라이트, 다크 또는 시스템 모드와 사용자 지정 테마를 적용합니다:

```tsx
import { ThemeProvider } from '@librechat/client'

export function App({ children }) {
  return <ThemeProvider initialTheme="system">{children}</ThemeProvider>
}
```

일부 컴포넌트는 대화 상자의 취소 버튼과 같은 기본 제공 레이블을 `react-i18next`를 통해 읽어오므로, LibreChat의 번역 또는 동일한 키에 대한 자체 문자열로 i18next를 초기화하세요.
