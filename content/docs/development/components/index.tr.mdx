LibreChat'in arayüzü, npm üzerinde `@librechat/client` adıyla yayınlanan ortak bir React bileşen kümesinden oluşturulmuştur. Bu bölümdeki sayfalar her bileşeni, yayınlanmış paketten oluşturulmuş olarak ve uygulamanın kullandığı aynı tema ile canlı şekilde gösterir; bileşeni oluşturan kod da altında yer alır.

Bu sitedeki her önizleme, sitenin açık veya koyu modunu takip eder. Örnekler, LibreChat'in kendi kodunun bileşenleri kullanma biçimine uygun olarak yazılmıştır: etiketler alanlarına bağlıdır, metinler yerelleştirilmiştir ve ham palet renkleri yerine anlamsal renk belirteçleri kullanılır.

## Kurulum [#install]

```bash
npm install @librechat/client
```

Paket, çalışma zamanı kütüphanelerini eş bağımlılıklar (React, Tailwind CSS 4, Radix UI, Ariakit ve diğerleri) olarak listeler; bu sayede bir ana uygulama ihtiyaç duyduğu sürümleri bir kez kurar ve paylaşır. Paket yöneticiniz eksik olanları bildirir.

## Stilleri ayarlayın [#set-up-the-styles]

Bileşenler Tailwind CSS 4 ve LibreChat'in tema belirteçleriyle stillendirilmiştir. Paketin tema ve bileşen stillerini Tailwind'den sonra içe aktarın, ardından paket ön ayarını kullanan bir Tailwind yapılandırması yükleyin:

```css title="style.css"
@import 'tailwindcss';
@import '@librechat/client/theme.css';
@import '@librechat/client/style.css';
@config './tailwind.config.js';
```

```js title="tailwind.config.js"
const libreChatTailwindPreset = require('@librechat/client/tailwind-preset')

module.exports = {
  presets: [libreChatTailwindPreset],
  content: [
    './src/**/*.{js,jsx,ts,tsx}',
    './node_modules/@librechat/client/dist/**/*.{js,mjs,cjs}',
  ],
  darkMode: ['class'],
}
```

Ardından uygulamanızı `ThemeProvider` ile sarın; bu sağlayıcı açık, koyu veya sistem modunu ve varsa özel temayı uygular:

```tsx
import { ThemeProvider } from '@librechat/client'

export function App({ children }) {
  return <ThemeProvider initialTheme="system">{children}</ThemeProvider>
}
```

Bazı bileşenler yerleşik etiketlerini (örneğin bir iletişim kutusundaki İptal düğmesi) `react-i18next` aracılığıyla okur; bu nedenle i18next'i LibreChat'in çevirileriyle veya aynı anahtarlar için kendi metinlerinizle başlatın.
