Antarmuka LibreChat dibangun dari sekumpulan komponen React bersama yang dipublikasikan di npm sebagai `@librechat/client`. Halaman-halaman di bagian ini menampilkan setiap komponen secara langsung, dirender dari paket yang dipublikasikan dengan tema yang sama seperti yang digunakan aplikasi, beserta kode yang merendernya di bawahnya.

Setiap pratinjau mengikuti mode terang atau gelap dari situs ini. Contoh-contohnya ditulis sebagaimana kode LibreChat sendiri menggunakan komponen tersebut: label yang terkait dengan field-nya, string yang dilokalkan, dan token warna semantik, bukan warna palet mentah.

## Instalasi [#install]

```bash
npm install @librechat/client
```

Paket ini mencantumkan pustaka runtime-nya sebagai peer dependencies (React, Tailwind CSS 4, Radix UI, Ariakit dan lainnya), sehingga host cukup menginstal versi yang dibutuhkan sekali saja dan membagikannya. Manajer paket Anda akan melaporkan dependensi apa pun yang belum terpasang.

## Mengatur gaya [#set-up-the-styles]

Komponen-komponen ini di-styling menggunakan Tailwind CSS 4 dan token tema LibreChat. Impor gaya tema dan komponen dari paket setelah Tailwind, lalu muat konfigurasi Tailwind yang menggunakan preset paket:

```css title="style.css"
@import 'tailwindcss';
@import '@librechat/client/theme.css';
@import '@librechat/client/style.css';
@config './tailwind.config.js';
```

```js title="tailwind.config.js"
const libreChatTailwindPreset = require('@librechat/client/tailwind-preset')

module.exports = {
  presets: [libreChatTailwindPreset],
  content: [
    './src/**/*.{js,jsx,ts,tsx}',
    './node_modules/@librechat/client/dist/**/*.{js,mjs,cjs}',
  ],
  darkMode: ['class'],
}
```

Kemudian bungkus aplikasi Anda dengan `ThemeProvider`, yang menerapkan mode terang, gelap, atau sistem serta tema kustom apa pun:

```tsx
import { ThemeProvider } from '@librechat/client'

export function App({ children }) {
  return <ThemeProvider initialTheme="system">{children}</ThemeProvider>
}
```

Beberapa komponen membaca label bawaannya (seperti tombol Cancel pada dialog) melalui `react-i18next`, sehingga inisialisasi i18next dengan terjemahan LibreChat atau string Anda sendiri untuk kunci yang sama.
