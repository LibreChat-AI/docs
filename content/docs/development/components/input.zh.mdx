`Input` 是 LibreChat 表单中使用的文本字段。将它与 `Label` 配对使用,并为每个字段使用 React 的 `useId()` 生成 id,这样即使组件被多次渲染,标签仍能正确指向对应的字段。

## 无效 [#invalid]

将验证失败的字段标记为 `aria-invalid`,并通过 `aria-describedby` 将错误消息与该字段关联。该字段的边框使用主题中的 destructive 颜色绘制。

<ComponentPreview example="input/invalid" title="输入处于无效状态" />

## 属性 [#props]

`Input` 接受所有原生 `input` 属性。其中它会应用样式的属性包括:

| 属性 | 类型 | 描述 |
| --- | --- | --- |
| `aria-invalid` | `boolean` | 显示红色边框,并告知辅助技术该值无效。 |
| `disabled` | `boolean` | 淡化字段外观并禁止编辑。 |
| `placeholder` | `string` | 字段为空时显示的示例文本。它不是标签。 |

## 无障碍访问 [#accessibility]

- 每个字段都需要可见的标签:使用带有 `htmlFor` 的 `Label`,或使用 `aria-labelledby`。
- Ids 来自 `useId()`,切勿使用字面字符串。
- 错误文本使用 `text-text-destructive` 样式令牌并带有 `role="alert"` 属性,因此出现时会被屏幕阅读器朗读。
