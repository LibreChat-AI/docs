`Dropdown` is het enkelvoudige selectieveld van LibreChat. Gebruik in een formulier de variant `field`, die overeenkomt met `Input`. Voor een menu met acties in plaats van waarden gebruik je `DropdownPopup`.

## Props [#props]

| Prop | Type | Standaard | Beschrijving |
| --- | --- | --- | --- |
| `value` | `string` | | De waarde van de geselecteerde optie. |
| `onChange` | `(value: string) => void` | | Wordt aangeroepen met de waarde van de gekozen optie. |
| `options` | `Array<string \| { value, label, icon?, disabled? } \| { divider: true }>` | | De keuzes, in volgorde. |
| `variant` | `'default' \| 'field' \| 'compact'` | `'default'` | `field` komt overeen met `Input` in formulieren; `compact` past in werkbalken. |
| `placeholder` | `string` | | Wordt in de secundaire tint getoond zolang er niets is gekozen. |
| `searchable` | `boolean` | `false` | Voegt een zoekveld toe bovenaan de lijst. |
| `aria-labelledby` | `string` | | Verwijst naar het zichtbare label van het veld. De geselecteerde waarde wordt hiermee voorgelezen. |
| `aria-invalid` | `boolean` | | Markeert een `field`-keuzelijst als ongeldig. |
| `disabled` | `boolean` | `false` | Voorkomt dat de lijst wordt geopend. |
| `portal` | `boolean` | `true`, of `false` binnen een dialoog | Rendert de lijst in een portal. Binnen een dialoog blijft de lijst in de dialoog, zodat focus en schermlezers deze kunnen bereiken. |

## Toegankelijkheid [#accessibility]

De trigger is een `combobox` die een `listbox` opent. Geef deze een naam met `aria-labelledby` dat verwijst naar een zichtbaar label, of met `aria-label` wanneer er geen label is.

| Sleutel | Actie |
| --- | --- |
| <kbd>Enter</kbd>, <kbd>Space</kbd> of <kbd>↓</kbd> | Opent de lijst |
| <kbd>↑</kbd> en <kbd>↓</kbd> | Navigeert door de opties |
| <kbd>Enter</kbd> | Selecteert de actieve optie en sluit de lijst |
| <kbd>Escape</kbd> | Sluit de lijst zonder de waarde te wijzigen |
