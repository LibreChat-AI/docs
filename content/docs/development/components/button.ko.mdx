`Button`은 LibreChat에서 클릭 가능한 모든 동작을 렌더링하며, 여기에는 펼치기 캐럿이나 복사 아이콘처럼 버튼처럼 보이지 않는 컨트롤도 포함됩니다. 동작의 종류에 따라 variant를 선택하세요.

## 변형 [#variants]

<ComponentPreview example="button/variants" title="버튼 변형" />

| Variant | 사용 용도 |
| --- | --- |
| `default` | 대화 상자를 열거나 흐름을 시작하는 기본 작업 |
| `submit` | 저장 또는 생성: 양식의 주요 작업 |
| `outline` | 취소, 닫기 또는 보조 작업 |
| `destructive` | 삭제 또는 기타 되돌릴 수 없는 작업, 보통 확인 대화 상자 내부에서 사용 |
| `ghost` | 강조가 낮은 작업, 아이콘 전용, 도구 모음 및 행 작업 |
| `link` | 텍스트 내 인라인 작업 |

## Props [#props]

| Prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `variant` | `'default' \| 'submit' \| 'outline' \| 'destructive' \| 'ghost' \| 'link' \| ...` | `'default'` | 작업의 시각적 역할입니다. |
| `size` | `'default' \| 'sm' \| 'lg' \| 'icon' \| 'icon-sm' \| ...` | `'default'` | 높이와 패딩입니다. `icon` 크기는 정사각형입니다. |
| `shape` | `'theme' \| 'round' \| ...` | 설정 안 됨 | 모서리의 둥근 정도입니다. 설정하지 않으면 variant 자체의 모서리 반경이 적용되며, `theme`과 `round`는 테마의 컨트롤 모양을 따릅니다. |
| `asChild` | `boolean` | `false` | 자식 요소(예: 링크)를 버튼 스타일로 렌더링합니다. |

`Button`은 네이티브 `button` 속성을 모두 허용합니다.

## 접근성 [#accessibility]

- 아이콘만 있는 버튼에는 `aria-label`을 지정하고, 아이콘 자체에는 `aria-hidden`을 지정하세요.
- `type="submit"`을 폼의 주요 버튼에 설정하세요.
- 비활성화된 버튼도 레이블은 읽을 수 있도록 유지해야 합니다. 작업을 사용할 수 없는 이유를 숨기기보다 설명하는 것을 우선하세요.

| Key | Action |
| --- | --- |
| <kbd>Enter</kbd> 또는 <kbd>Space</kbd> | 버튼을 활성화합니다 |
