Modal dialog LibreChat dibangun dari `OGDialog` dan bagian-bagiannya. Untuk dialog standar dengan judul, badan, dan aksi konfirmasi, `OGDialogTemplate` menyusun semuanya dan menambahkan tombol Batal yang sudah dilokalisasi.

<ComponentPreview example="dialog/confirm" title="Dialog konfirmasi" minHeight={320} />

<Callout type="info">
Rilis berikutnya dari `@librechat/client` juga mengekspor bagian-bagian ini dengan nama sederhana (`Dialog`, `DialogContent`, `DialogTemplate`, dan lainnya). Komponen-komponen ini sama, sehingga kedua nama dapat digunakan setelah rilis tersebut tersedia.
</Callout>

## Bagian [#parts]

| Bagian | Peran |
| --- | --- |
| `OGDialog` | Akar; mengontrol apakah dialog terbuka. |
| `OGDialogTrigger` | Elemen yang membukanya. Gunakan `asChild` dengan `Button`. |
| `OGDialogContent` | Permukaan dialog, dengan tombol tutup opsional. |
| `OGDialogHeader`, `OGDialogTitle`, `OGDialogDescription` | Area judul. Setiap dialog memerlukan judul. |
| `OGDialogFooter`, `OGDialogClose` | Baris aksi dan kontrol yang menutup dialog. |
| `OGDialogTemplate` | Dialog lengkap: `title`, `main`, `selection` dan tombol Batal opsional. |

## Lebar dan penutupan [#width-and-dismissal]

Batasi dialog ke `w-11/12` ditambah batas `max-w-*` agar tetap nyaman digunakan dari desktop hingga ponsel, dan berikan tepat satu cara yang jelas untuk menutupnya: tombol tutup atau tombol Batal.

## Aksesibilitas [#accessibility]

Membuka dialog akan memindahkan fokus ke dalamnya dan menjaga fokus tetap berada di dalam dialog hingga dialog ditutup; saat ditutup, fokus kembali ke pemicunya. Untuk konfirmasi yang bersifat destruktif, `AlertDialog` memberikan peran `alertdialog` yang lebih kuat kepada pembaca layar.

| Tombol | Tindakan |
| --- | --- |
| <kbd>Tab</kbd> dan <kbd>Shift</kbd>+<kbd>Tab</kbd> | Berpindah di antara kontrol dialog |
| <kbd>Escape</kbd> | Menutup dialog dan mengembalikan fokus ke pemicu |
