Giao diện của LibreChat được xây dựng từ một tập hợp các thành phần React dùng chung, được xuất bản trên npm dưới tên `@librechat/client`. Các trang trong phần này hiển thị trực tiếp từng thành phần, được render từ gói đã xuất bản với cùng chủ đề mà ứng dụng sử dụng, kèm theo đoạn mã render chúng bên dưới.

Mỗi bản xem trước đều theo chế độ sáng hoặc tối của trang web này. Các ví dụ được viết theo cách mã nguồn của LibreChat sử dụng các thành phần: nhãn được gắn với trường tương ứng, chuỗi văn bản được bản địa hóa, và sử dụng các màu ngữ nghĩa thay vì bảng màu thô.

## Cài đặt [#install]

```bash
npm install @librechat/client
```

Gói này liệt kê các thư viện runtime của nó dưới dạng peer dependencies (React, Tailwind CSS 4, Radix UI, Ariakit và những thư viện khác), vì vậy host chỉ cần cài đặt các phiên bản cần thiết một lần và dùng chung. Trình quản lý gói của bạn sẽ báo cáo những thư viện nào còn thiếu.

## Thiết lập các kiểu dáng [#set-up-the-styles]

Các thành phần được tạo kiểu bằng Tailwind CSS 4 và các token giao diện (theme tokens) của LibreChat. Hãy nhập kiểu theme và kiểu thành phần của gói sau Tailwind, sau đó tải một cấu hình Tailwind sử dụng preset của gói:

```css title="style.css"
@import 'tailwindcss';
@import '@librechat/client/theme.css';
@import '@librechat/client/style.css';
@config './tailwind.config.js';
```

```js title="tailwind.config.js"
const libreChatTailwindPreset = require('@librechat/client/tailwind-preset')

module.exports = {
  presets: [libreChatTailwindPreset],
  content: [
    './src/**/*.{js,jsx,ts,tsx}',
    './node_modules/@librechat/client/dist/**/*.{js,mjs,cjs}',
  ],
  darkMode: ['class'],
}
```

Sau đó, bọc ứng dụng của bạn trong `ThemeProvider`, component này áp dụng chế độ sáng, tối hoặc theo hệ thống cùng bất kỳ chủ đề tùy chỉnh nào:

```tsx
import { ThemeProvider } from '@librechat/client'

export function App({ children }) {
  return <ThemeProvider initialTheme="system">{children}</ThemeProvider>
}
```

Một số thành phần đọc các nhãn có sẵn của chúng (chẳng hạn như nút Cancel của hộp thoại) thông qua `react-i18next`, vì vậy hãy khởi tạo i18next với bản dịch của LibreChat hoặc với các chuỗi của riêng bạn cho cùng các khóa đó.
