`Dropdown` es el selector de valor único de LibreChat. En un formulario, usa la variante `field`, que coincide con `Input`. Para un menú de acciones en lugar de valores, usa `DropdownPopup`.

## Props [#props]

| Prop | Tipo | Por defecto | Descripción |
| --- | --- | --- | --- |
| `value` | `string` | | El valor de la opción seleccionada. |
| `onChange` | `(value: string) => void` | | Se invoca con el valor de la opción elegida. |
| `options` | `Array<string \| { value, label, icon?, disabled? } \| { divider: true }>` | | Las opciones, en orden. |
| `variant` | `'default' \| 'field' \| 'compact'` | `'default'` | `field` coincide con `Input` en los formularios; `compact` se ajusta a las barras de herramientas. |
| `placeholder` | `string` | | Se muestra con el tono secundario mientras no hay nada seleccionado. |
| `searchable` | `boolean` | `false` | Añade un campo de búsqueda en la parte superior de la lista. |
| `aria-labelledby` | `string` | | Apunta a la etiqueta visible del campo. El valor seleccionado se anuncia junto con ella. |
| `aria-invalid` | `boolean` | | Marca un desplegable `field` como no válido. |
| `disabled` | `boolean` | `false` | Impide abrir la lista. |
| `portal` | `boolean` | `true`, o `false` dentro de un diálogo | Renderiza la lista en un portal. Dentro de un diálogo, la lista permanece en el diálogo para que el foco y los lectores de pantalla puedan acceder a ella. |

## Accesibilidad [#accessibility]

El disparador es un `combobox` que abre un `listbox`. Asígnale un nombre con `aria-labelledby` que apunte a una etiqueta visible, o usa `aria-label` cuando no exista una.

| Clave | Acción |
| --- | --- |
| <kbd>Enter</kbd>, <kbd>Espacio</kbd> o <kbd>↓</kbd> | Abre la lista |
| <kbd>↑</kbd> y <kbd>↓</kbd> | Se desplaza por las opciones |
| <kbd>Enter</kbd> | Selecciona la opción activa y cierra la lista |
| <kbd>Escape</kbd> | Cierra la lista sin cambiar el valor |
