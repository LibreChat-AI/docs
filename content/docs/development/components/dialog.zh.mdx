LibreChat 的模态对话框由 `OGDialog` 及其组成部分构建。对于包含标题、正文和确认操作的标准对话框,`OGDialogTemplate` 会将它们组装在一起,并添加一个本地化的取消按钮。

<ComponentPreview example="dialog/confirm" title="确认对话框" minHeight={320} />

<Callout type="info">
下一个版本的 `@librechat/client` 也会以普通名称导出以下组件(`Dialog`、`DialogContent`、`DialogTemplate` 等)。它们与之前的组件相同,因此在该版本发布后,使用任一名称均可。
</Callout>

## 部件 [#parts]

| 组件 | 作用 |
| --- | --- |
| `OGDialog` | 根组件,用于控制对话框是否打开。 |
| `OGDialogTrigger` | 打开对话框的元素。配合 `Button` 使用 `asChild`。 |
| `OGDialogContent` | 对话框主体,可选择是否包含关闭按钮。 |
| `OGDialogHeader`、`OGDialogTitle`、`OGDialogDescription` | 标题区域。每个对话框都需要一个标题。 |
| `OGDialogFooter`、`OGDialogClose` | 操作按钮行以及用于关闭对话框的控件。 |
| `OGDialogTemplate` | 完整的对话框,包含 `title`、`main`、`selection` 以及可选的取消按钮。 |

## 宽度与关闭 [#width-and-dismissal]

将对话框限制为 `w-11/12` 加上 `max-w-*` 上限,使其在桌面到手机的各种屏幕上都能良好显示,并且只提供一种明确的退出方式:关闭按钮或取消按钮。

## 无障碍访问 [#accessibility]

打开对话框会将焦点移入其中，并在关闭之前始终将焦点保持在对话框内；关闭后，焦点会返回到触发元素。对于破坏性确认操作，`AlertDialog` 会为屏幕阅读器提供更强的 `alertdialog` 角色。

| 按键 | 操作 |
| --- | --- |
| <kbd>Tab</kbd> 和 <kbd>Shift</kbd>+<kbd>Tab</kbd> | 在对话框的控件之间移动 |
| <kbd>Escape</kbd> | 关闭对话框并将焦点返回到触发元素 |
