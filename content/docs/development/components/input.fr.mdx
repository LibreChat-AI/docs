`Input` est le champ de texte utilisé dans les formulaires de LibreChat. Associez-le à un `Label`, et attribuez à chaque champ un id généré par `useId()` de React, afin que le label reste correctement lié au bon champ lorsque le composant est rendu plusieurs fois.

## Invalide [#invalid]

Marquez un champ qui n'a pas réussi la validation avec `aria-invalid`, et associez le message à celui-ci avec `aria-describedby`. Le champ affiche sa bordure dans la couleur destructive du thème.

<ComponentPreview example="input/invalid" title="État d'entrée invalide" />

## Props [#props]

`Input` accepte tous les attributs natifs de `input`. Voici ceux qu'il met en forme :

| Prop | Type | Description |
| --- | --- | --- |
| `aria-invalid` | `boolean` | Affiche la bordure destructive et indique aux technologies d'assistance que la valeur est invalide. |
| `disabled` | `boolean` | Atténue le champ et bloque la modification. |
| `placeholder` | `string` | Texte d'exemple affiché tant que le champ est vide. Il ne s'agit pas d'un libellé. |

## Accessibilité [#accessibility]

- Chaque champ doit avoir un libellé visible : `Label` avec `htmlFor`, ou `aria-labelledby`.
- Les identifiants proviennent de `useId()`, jamais d'une chaîne littérale.
- Le texte d'erreur utilise le jeton `text-text-destructive` et `role="alert"` afin qu'il soit annoncé lorsqu'il apparaît.
