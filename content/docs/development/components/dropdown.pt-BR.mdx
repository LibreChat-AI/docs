`Dropdown` é o seletor de valor único do LibreChat. Em um formulário, use a variante `field`, que corresponde ao `Input`. Para um menu de ações em vez de valores, use `DropdownPopup`.

## Props [#props]

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `value` | `string` | | O valor da opção selecionada. |
| `onChange` | `(value: string) => void` | | Chamado com o valor da opção escolhida. |
| `options` | `Array<string \| { value, label, icon?, disabled? } \| { divider: true }>` | | As opções, em ordem. |
| `variant` | `'default' \| 'field' \| 'compact'` | `'default'` | `field` corresponde ao `Input` em formulários; `compact` se adapta a barras de ferramentas. |
| `placeholder` | `string` | | Exibido no tom secundário enquanto nada estiver selecionado. |
| `searchable` | `boolean` | `false` | Adiciona um campo de busca no topo da lista. |
| `aria-labelledby` | `string` | | Aponta para o rótulo visível do campo. O valor selecionado é anunciado junto com ele. |
| `aria-invalid` | `boolean` | | Marca um dropdown do tipo `field` como inválido. |
| `disabled` | `boolean` | `false` | Impede a abertura da lista. |
| `portal` | `boolean` | `true`, ou `false` dentro de um diálogo | Renderiza a lista em um portal. Dentro de um diálogo, a lista permanece no diálogo para que o foco e os leitores de tela possam alcançá-la. |

## Acessibilidade [#accessibility]

O gatilho é um `combobox` que abre um `listbox`. Dê a ele um nome com `aria-labelledby` apontando para um rótulo visível, ou use `aria-label` quando não houver rótulo.

| Tecla | Ação |
| --- | --- |
| <kbd>Enter</kbd>, <kbd>Space</kbd> ou <kbd>↓</kbd> | Abre a lista |
| <kbd>↑</kbd> e <kbd>↓</kbd> | Navegam entre as opções |
| <kbd>Enter</kbd> | Seleciona a opção ativa e fecha a lista |
| <kbd>Escape</kbd> | Fecha a lista sem alterar o valor |
