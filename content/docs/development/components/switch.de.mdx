Verwenden Sie `Switch` für eine Einstellung, die sofort wirksam wird, sobald sie geändert wird. Für eine Option, die beim Absenden eines Formulars angewendet wird, verwenden Sie stattdessen eine Checkbox.

<ComponentPreview example="switch/default" title="Schalter mit einer Beschriftung" />

## Props [#props]

| Prop | Typ | Beschreibung |
| --- | --- | --- |
| `checked` | `boolean` | Der kontrollierte Zustand. |
| `onCheckedChange` | `(checked: boolean) => void` | Wird aufgerufen, wenn der Benutzer den Schalter umschaltet. |
| `defaultChecked` | `boolean` | Der Anfangszustand im unkontrollierten Modus. |
| `disabled` | `boolean` | Verhindert das Umschalten. |
| `aria-label` oder `aria-labelledby` | `string` | Erforderlich: genau eines von beiden benennt den Schalter. |

## Barrierefreiheit [#accessibility]

Der Schalter stellt die Rolle `switch` mit seinem Auswahlzustand bereit, und sein Typ erfordert einen zugänglichen Namen.

| Schlüssel | Aktion |
| --- | --- |
| <kbd>Space</kbd> oder <kbd>Enter</kbd> | Schaltet den Schalter um |
