Use `Switch` para uma configuração que tem efeito assim que é alterada. Para uma opção que é aplicada quando um formulário é enviado, use uma checkbox.

<ComponentPreview example="switch/default" title="Alternar com um rótulo" />

## Props [#props]

| Prop | Tipo | Descrição |
| --- | --- | --- |
| `checked` | `boolean` | O estado controlado. |
| `onCheckedChange` | `(checked: boolean) => void` | Chamado quando o usuário alterna o switch. |
| `defaultChecked` | `boolean` | O estado inicial quando não controlado. |
| `disabled` | `boolean` | Bloqueia a alternância. |
| `aria-label` ou `aria-labelledby` | `string` | Obrigatório: exatamente um deles nomeia o switch. |

## Acessibilidade [#accessibility]

O switch expõe o papel `switch` com o seu estado marcado (checked), e o seu tipo exige um nome acessível.

| Chave | Ação |
| --- | --- |
| <kbd>Space</kbd> ou <kbd>Enter</kbd> | Alterna a chave |
