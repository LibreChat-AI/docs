`Dropdown`은 LibreChat의 단일 값 선택 컴포넌트입니다. 폼에서는 `Input`과 일치하는 `field` 변형을 사용하십시오. 값 대신 작업 메뉴가 필요하다면 `DropdownPopup`을 사용하십시오.

## Props [#props]

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | | 선택된 옵션의 값입니다. |
| `onChange` | `(value: string) => void` | | 선택한 옵션의 값과 함께 호출됩니다. |
| `options` | `Array<string \| { value, label, icon?, disabled? } \| { divider: true }>` | | 순서대로 나열된 선택지입니다. |
| `variant` | `'default' \| 'field' \| 'compact'` | `'default'` | `field`는 폼의 `Input`과 모양을 맞춥니다. `compact`는 툴바에 맞습니다. |
| `placeholder` | `string` | | 아무것도 선택되지 않은 동안 보조 색조로 표시됩니다. |
| `searchable` | `boolean` | `false` | 목록 상단에 검색 필드를 추가합니다. |
| `aria-labelledby` | `string` | | 필드의 시각적 레이블을 가리킵니다. 선택된 값은 이 레이블과 함께 읽힙니다. |
| `aria-invalid` | `boolean` | | `field` 드롭다운을 유효하지 않음으로 표시합니다. |
| `disabled` | `boolean` | `false` | 목록 열기를 차단합니다. |
| `portal` | `boolean` | `true`, 대화 상자 내부에서는 `false` | 목록을 포털에 렌더링합니다. 대화 상자 내부에서는 목록이 대화 상자 안에 남아 포커스와 스크린 리더가 접근할 수 있습니다. |

## 접근성 [#accessibility]

트리거는 `listbox`를 여는 `combobox`입니다. 보이는 레이블이 있으면 `aria-labelledby`로 해당 레이블을 가리키고, 레이블이 없으면 `aria-label`로 이름을 지정합니다.

| 키 | 동작 |
| --- | --- |
| <kbd>Enter</kbd>, <kbd>Space</kbd> 또는 <kbd>↓</kbd> | 목록을 엽니다 |
| <kbd>↑</kbd> 및 <kbd>↓</kbd> | 옵션 사이를 이동합니다 |
| <kbd>Enter</kbd> | 활성화된 옵션을 선택하고 목록을 닫습니다 |
| <kbd>Escape</kbd> | 값을 변경하지 않고 목록을 닫습니다 |
