`Dropdown` to pojedynczowartościowy element wyboru w LibreChat. W formularzu należy użyć wariantu `field`, który odpowiada komponentowi `Input`. Jeśli zamiast wartości potrzebujesz menu z akcjami, użyj `DropdownPopup`.

## Właściwości [#props]

| Właściwość | Typ | Domyślnie | Opis |
| --- | --- | --- | --- |
| `value` | `string` | | Wartość wybranej opcji. |
| `onChange` | `(value: string) => void` | | Wywoływana z wartością wybranej opcji. |
| `options` | `Array<string \| { value, label, icon?, disabled? } \| { divider: true }>` | | Dostępne wybory, w kolejności. |
| `variant` | `'default' \| 'field' \| 'compact'` | `'default'` | `field` pasuje do `Input` w formularzach; `compact` nadaje się do pasków narzędzi. |
| `placeholder` | `string` | | Wyświetlany drugorzędnym kolorem, dopóki nic nie zostało wybrane. |
| `searchable` | `boolean` | `false` | Dodaje pole wyszukiwania na górze listy. |
| `aria-labelledby` | `string` | | Wskazuje widoczną etykietę pola. Razem z nią ogłaszana jest wybrana wartość. |
| `aria-invalid` | `boolean` | | Oznacza rozwijaną listę `field` jako nieprawidłową. |
| `disabled` | `boolean` | `false` | Blokuje otwieranie listy. |
| `portal` | `boolean` | `true`, lub `false` wewnątrz dialogu | Renderuje listę w portalu. Wewnątrz dialogu lista pozostaje w obrębie dialogu, dzięki czemu fokus i czytniki ekranu mogą do niej dotrzeć. |

## Dostępność [#accessibility]

Wyzwalaczem jest `combobox`, który otwiera `listbox`. Nadaj mu nazwę za pomocą `aria-labelledby` wskazującego na widoczną etykietę lub `aria-label`, gdy etykiety nie ma.

| Klawisz | Działanie |
| --- | --- |
| <kbd>Enter</kbd>, <kbd>Space</kbd> lub <kbd>↓</kbd> | Otwiera listę |
| <kbd>↑</kbd> i <kbd>↓</kbd> | Przemieszczanie się między opcjami |
| <kbd>Enter</kbd> | Wybiera aktywną opcję i zamyka listę |
| <kbd>Escape</kbd> | Zamyka listę bez zmiany wartości |
