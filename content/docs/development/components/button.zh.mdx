`Button` 用于渲染 LibreChat 中所有可点击的操作，包括那些看起来不像按钮的控件，例如展开折叠的箭头或复制图标。请根据操作的作用来选择变体。

## 变体 [#variants]

<ComponentPreview example="button/variants" title="按钮变体" />

| 变体 | 适用场景 |
| --- | --- |
| `default` | 打开对话框或启动流程的主要操作 |
| `submit` | 保存或创建:表单的主要操作 |
| `outline` | 取消、关闭或次要操作 |
| `destructive` | 删除或其他不可逆操作,通常位于确认对话框中 |
| `ghost` | 低强调度的操作,包括纯图标、工具栏和行内操作 |
| `link` | 行内文本操作 |

## 属性 [#props]

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `variant` | `'default' \| 'submit' \| 'outline' \| 'destructive' \| 'ghost' \| 'link' \| ...` | `'default'` | 操作的视觉角色。 |
| `size` | `'default' \| 'sm' \| 'lg' \| 'icon' \| 'icon-sm' \| ...` | `'default'` | 高度和内边距。`icon` 尺寸为正方形。 |
| `shape` | `'theme' \| 'round' \| ...` | 未设置 | 圆角半径。未设置时,应用该变体自身的圆角;`theme` 和 `round` 遵循主题的控件形状。 |
| `asChild` | `boolean` | `false` | 以按钮样式渲染子元素(例如链接)。 |

`Button` 也接受所有原生 `button` 属性。

## 无障碍访问 [#accessibility]

- 为仅包含图标的按钮添加 `aria-label`;图标本身应设置为 `aria-hidden`。
- 将表单的主按钮设置为 `type="submit"`。
- 禁用的按钮应保持其标签可读;相比隐藏某项操作,更推荐说明该操作不可用的原因。

| Key | Action |
| --- | --- |
| <kbd>Enter</kbd> 或 <kbd>Space</kbd> | 激活按钮 |
