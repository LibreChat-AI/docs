L'interfaccia di LibreChat è costruita a partire da un insieme condiviso di componenti React pubblicati su npm come `@librechat/client`. Le pagine di questa sezione mostrano ciascuno di essi dal vivo, renderizzati dal pacchetto pubblicato con lo stesso tema utilizzato dall'app, con il codice che li genera sottostante.

Ogni anteprima segue la modalità chiara o scura di questo sito. Gli esempi sono scritti nel modo in cui il codice di LibreChat utilizza i componenti: etichette collegate ai rispettivi campi, stringhe localizzate e token di colore semantici anziché colori grezzi della palette.

## Installazione [#install]

```bash
npm install @librechat/client
```

Il pacchetto elenca le sue librerie di runtime come peer dependencies (React, Tailwind CSS 4, Radix UI, Ariakit e altre), quindi un host installa una sola volta le versioni di cui ha bisogno e le condivide. Il tuo package manager segnala quelle mancanti.

## Configura gli stili [#set-up-the-styles]

I componenti sono stilizzati con Tailwind CSS 4 e con i token del tema di LibreChat. Importa gli stili del tema e dei componenti del pacchetto dopo Tailwind, quindi carica una configurazione di Tailwind che utilizza il preset del pacchetto:

```css title="style.css"
@import 'tailwindcss';
@import '@librechat/client/theme.css';
@import '@librechat/client/style.css';
@config './tailwind.config.js';
```

```js title="tailwind.config.js"
const libreChatTailwindPreset = require('@librechat/client/tailwind-preset')

module.exports = {
  presets: [libreChatTailwindPreset],
  content: [
    './src/**/*.{js,jsx,ts,tsx}',
    './node_modules/@librechat/client/dist/**/*.{js,mjs,cjs}',
  ],
  darkMode: ['class'],
}
```

Poi avvolgi la tua app in `ThemeProvider`, che applica la modalità chiara, scura o di sistema e qualsiasi tema personalizzato:

```tsx
import { ThemeProvider } from '@librechat/client'

export function App({ children }) {
  return <ThemeProvider initialTheme="system">{children}</ThemeProvider>
}
```

Alcuni componenti leggono le proprie etichette predefinite (come il pulsante Annulla di una finestra di dialogo) tramite `react-i18next`, quindi inizializza i18next con le traduzioni di LibreChat oppure con le tue stringhe per le stesse chiavi.
