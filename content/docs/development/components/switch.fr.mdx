---

Utilisez `Switch` pour un paramètre qui prend effet dès qu'il est modifié. Pour une option appliquée lors de la soumission d'un formulaire, utilisez plutôt une case à cocher.

<ComponentPreview example="switch/default" title="Basculer avec un libellé" />

## Props [#props]

| Prop | Type | Description |
| --- | --- | --- |
| `checked` | `boolean` | L'état contrôlé. |
| `onCheckedChange` | `(checked: boolean) => void` | Appelée lorsque l'utilisateur bascule l'interrupteur. |
| `defaultChecked` | `boolean` | L'état initial lorsque le composant n'est pas contrôlé. |
| `disabled` | `boolean` | Bloque le basculement. |
| `aria-label` or `aria-labelledby` | `string` | Obligatoire : exactement l'un des deux nomme l'interrupteur. |

## Accessibilité [#accessibility]

Le commutateur expose le rôle `switch` avec son état coché, et son type exige un nom accessible.

| Clé | Action |
| --- | --- |
| <kbd>Espace</kbd> ou <kbd>Entrée</kbd> | Active ou désactive l'interrupteur |
