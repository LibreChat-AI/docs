`Dropdown` adalah elemen pilih nilai tunggal di LibreChat. Dalam formulir, gunakan varian `field`, yang sesuai dengan `Input`. Untuk menu berisi aksi, bukan nilai, gunakan `DropdownPopup`.

## Props [#props]

| Prop | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `value` | `string` | | Nilai dari opsi yang dipilih. |
| `onChange` | `(value: string) => void` | | Dipanggil dengan nilai dari opsi yang dipilih. |
| `options` | `Array<string \| { value, label, icon?, disabled? } \| { divider: true }>` | | Pilihan yang tersedia, sesuai urutannya. |
| `variant` | `'default' \| 'field' \| 'compact'` | `'default'` | `field` menyerupai `Input` pada formulir; `compact` cocok untuk toolbar. |
| `placeholder` | `string` | | Ditampilkan dengan nada sekunder selama belum ada pilihan. |
| `searchable` | `boolean` | `false` | Menambahkan kolom pencarian di bagian atas daftar. |
| `aria-labelledby` | `string` | | Mengarah ke label field yang terlihat. Nilai yang dipilih akan diumumkan bersama label tersebut. |
| `aria-invalid` | `boolean` | | Menandai dropdown `field` sebagai tidak valid. |
| `disabled` | `boolean` | `false` | Mencegah daftar dibuka. |
| `portal` | `boolean` | `true`, atau `false` di dalam dialog | Merender daftar dalam portal. Di dalam dialog, daftar tetap berada di dalam dialog agar fokus dan pembaca layar dapat menjangkaunya. |

## Aksesibilitas [#accessibility]

Trigger adalah `combobox` yang membuka `listbox`. Beri nama dengan `aria-labelledby` yang mengarah ke label yang terlihat, atau `aria-label` jika tidak ada label.

| Kunci | Tindakan |
| --- | --- |
| <kbd>Enter</kbd>, <kbd>Space</kbd> atau <kbd>↓</kbd> | Membuka daftar |
| <kbd>↑</kbd> dan <kbd>↓</kbd> | Berpindah di antara opsi |
| <kbd>Enter</kbd> | Memilih opsi aktif dan menutup daftar |
| <kbd>Escape</kbd> | Menutup daftar tanpa mengubah nilai |
