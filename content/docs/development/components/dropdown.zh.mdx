`Dropdown` 是 LibreChat 的单值选择组件。在表单中,请使用与 `Input` 匹配的 `field` 变体。如需提供操作菜单而非值选择,请使用 `DropdownPopup`。

## 属性 [#props]

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `value` | `string` | | 所选选项的值。 |
| `onChange` | `(value: string) => void` | | 以所选选项的值调用。 |
| `options` | `Array<string \| { value, label, icon?, disabled? } \| { divider: true }>` | | 按顺序排列的可选项。 |
| `variant` | `'default' \| 'field' \| 'compact'` | `'default'` | `field` 与表单中的 `Input` 外观一致;`compact` 适用于工具栏。 |
| `placeholder` | `string` | | 未选择任何选项时以次要色调显示。 |
| `searchable` | `boolean` | `false` | 在列表顶部添加搜索字段。 |
| `aria-labelledby` | `string` | | 指向字段的可见标签。所选值会随该标签一同被朗读。 |
| `aria-invalid` | `boolean` | | 将 `field` 下拉菜单标记为无效。 |
| `disabled` | `boolean` | `false` | 禁止打开列表。 |
| `portal` | `boolean` | 默认为 `true`;在对话框内为 `false` | 将列表渲染到 Portal 中。在对话框内时,列表保留在对话框中,以便焦点和屏幕阅读器能够访问。 |

## 无障碍访问 [#accessibility]

触发器是一个 `combobox`,它会打开一个 `listbox`。使用 `aria-labelledby` 指向一个可见的标签为其命名;如果没有可见标签,则使用 `aria-label`。

| 按键 | 操作 |
| --- | --- |
| <kbd>Enter</kbd>、<kbd>Space</kbd> 或 <kbd>↓</kbd> | 打开列表 |
| <kbd>↑</kbd> 和 <kbd>↓</kbd> | 在选项之间移动 |
| <kbd>Enter</kbd> | 选择当前激活的选项并关闭列表 |
| <kbd>Escape</kbd> | 关闭列表，不更改当前值 |
