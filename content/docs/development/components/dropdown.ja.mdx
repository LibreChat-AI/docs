title: ドロップダウン

`Dropdown`は LibreChat の単一値選択コンポーネントです。フォームでは、`Input`と一致する`field`バリアントを使用してください。値の選択ではなくアクションのメニューが必要な場合は、`DropdownPopup`を使用します。

## プロパティ [#props]

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | | 選択されたオプションの値です。 |
| `onChange` | `(value: string) => void` | | 選択されたオプションの値を引数として呼び出されます。 |
| `options` | `Array<string \| { value, label, icon?, disabled? } \| { divider: true }>` | | 選択肢を順番に指定します。 |
| `variant` | `'default' \| 'field' \| 'compact'` | `'default'` | `field` はフォーム内の `Input` と見た目を合わせます。`compact` はツールバーに収まるサイズになります。 |
| `placeholder` | `string` | | 何も選択されていない間、セカンダリのトーンで表示されます。 |
| `searchable` | `boolean` | `false` | リストの上部に検索フィールドを追加します。 |
| `aria-labelledby` | `string` | | フィールドの表示ラベルを指定します。選択された値は、このラベルとともに読み上げられます。 |
| `aria-invalid` | `boolean` | | `field` のドロップダウンを無効な状態としてマークします。 |
| `disabled` | `boolean` | `false` | リストを開けないようにします。 |
| `portal` | `boolean` | `true`、ダイアログ内では `false` | リストをポータルにレンダリングします。ダイアログ内ではリストがダイアログ内に留まり、フォーカスとスクリーンリーダーが到達できるようにします。 |

## アクセシビリティ [#accessibility]

トリガーは、`listbox` を開く `combobox` です。表示されているラベルを指す `aria-labelledby` で名前を付けてください。表示ラベルがない場合は `aria-label` を使用します。

| キー | 操作 |
| --- | --- |
| <kbd>Enter</kbd>、<kbd>Space</kbd> または <kbd>↓</kbd> | リストを開く |
| <kbd>↑</kbd> と <kbd>↓</kbd> | 選択肢を移動する |
| <kbd>Enter</kbd> | アクティブな選択肢を選び、リストを閉じる |
| <kbd>Escape</kbd> | 値を変更せずにリストを閉じる |
