`Dropdown` ist das Einzelwert-Auswahlfeld von LibreChat. In einem Formular verwenden Sie die Variante `field`, die zu `Input` passt. Für ein Menü mit Aktionen statt Werten verwenden Sie `DropdownPopup`.

## Props [#props]

| Prop | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `value` | `string` | | Der Wert der ausgewählten Option. |
| `onChange` | `(value: string) => void` | | Wird mit dem Wert der gewählten Option aufgerufen. |
| `options` | `Array<string \| { value, label, icon?, disabled? } \| { divider: true }>` | | Die Auswahlmöglichkeiten, in Reihenfolge. |
| `variant` | `'default' \| 'field' \| 'compact'` | `'default'` | `field` entspricht `Input` in Formularen; `compact` passt in Werkzeugleisten. |
| `placeholder` | `string` | | Wird im sekundären Farbton angezeigt, solange nichts ausgewählt ist. |
| `searchable` | `boolean` | `false` | Fügt oben in der Liste ein Suchfeld hinzu. |
| `aria-labelledby` | `string` | | Verweist auf das sichtbare Label des Feldes. Zusammen damit wird der ausgewählte Wert angekündigt. |
| `aria-invalid` | `boolean` | | Markiert ein `field`-Dropdown als ungültig. |
| `disabled` | `boolean` | `false` | Verhindert das Öffnen der Liste. |
| `portal` | `boolean` | `true`, bzw. `false` innerhalb eines Dialogs | Rendert die Liste in einem Portal. Innerhalb eines Dialogs bleibt die Liste im Dialog, damit Fokus und Screenreader sie erreichen können. |

## Barrierefreiheit [#accessibility]

Der Auslöser ist eine `combobox`, die eine `listbox` öffnet. Benennen Sie ihn mit `aria-labelledby`, das auf ein sichtbares Label verweist, oder mit `aria-label`, wenn kein solches Label vorhanden ist.

| Taste | Aktion |
| --- | --- |
| <kbd>Enter</kbd>, <kbd>Space</kbd> oder <kbd>↓</kbd> | Öffnet die Liste |
| <kbd>↑</kbd> und <kbd>↓</kbd> | Bewegt sich durch die Optionen |
| <kbd>Enter</kbd> | Wählt die aktive Option aus und schließt die Liste |
| <kbd>Escape</kbd> | Schließt die Liste, ohne den Wert zu ändern |
