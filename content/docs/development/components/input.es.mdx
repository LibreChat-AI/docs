`Input` es el campo de texto utilizado en los formularios de LibreChat. Asócialo con `Label` y asigna a cada campo un id generado con `useId()` de React, de modo que la etiqueta siga apuntando al campo correcto cuando el componente se renderiza más de una vez.

## Inválido [#invalid]

Marca un campo que no pasó la validación con `aria-invalid`, y vincula el mensaje a él mediante `aria-describedby`. El campo dibuja su borde con el color destructivo del tema.

<ComponentPreview example="input/invalid" title="Entrada en un estado no válido" />

## Props [#props]

`Input` acepta todos los atributos nativos de `input`. Los que aplica estilos son:

| Prop | Tipo | Descripción |
| --- | --- | --- |
| `aria-invalid` | `boolean` | Dibuja el borde de estilo destructivo e indica a las tecnologías de asistencia que el valor no es válido. |
| `disabled` | `boolean` | Atenúa el campo y bloquea la edición. |
| `placeholder` | `string` | Texto de ejemplo que se muestra mientras el campo está vacío. No es una etiqueta. |

## Accesibilidad [#accessibility]

- Cada campo necesita una etiqueta visible: `Label` con `htmlFor`, o `aria-labelledby`.
- Los ids provienen de `useId()`, nunca de una cadena literal.
- El texto de error usa el token `text-text-destructive` y `role="alert"` para que se anuncie cuando aparece.
