설정이 변경되자마자 바로 적용되는 경우에는 `Switch`를 사용하세요. 폼을 제출할 때 적용되는 옵션에는 대신 체크박스를 사용하세요.

<ComponentPreview example="switch/default" title="라벨이 있는 스위치" />

## Props [#props]

| Prop | 타입 | 설명 |
| --- | --- | --- |
| `checked` | `boolean` | 제어되는 상태입니다. |
| `onCheckedChange` | `(checked: boolean) => void` | 사용자가 스위치를 전환할 때 호출됩니다. |
| `defaultChecked` | `boolean` | 비제어 상태일 때의 초기 상태입니다. |
| `disabled` | `boolean` | 전환을 차단합니다. |
| `aria-label` 또는 `aria-labelledby` | `string` | 필수: 둘 중 정확히 하나가 스위치의 이름을 지정해야 합니다. |

## 접근성 [#accessibility]

The switch exposes the `switch` role with its checked state, and its type requires an accessible name.

| Key | Action |
| --- | --- |
| <kbd>Space</kbd> 또는 <kbd>Enter</kbd> | 스위치를 전환합니다 |
