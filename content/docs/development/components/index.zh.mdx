LibreChat 的界面由一组共享的 React 组件构建而成，这些组件以 `@librechat/client` 的名称发布在 npm 上。本节中的页面会以与应用相同的主题，直接渲染已发布包中的每个组件，并在下方展示渲染它的代码。

每个预览都会跟随本站的浅色或深色模式。示例的编写方式与 LibreChat 自身代码中使用这些组件的方式一致:标签与其对应字段关联,字符串经过本地化处理,并使用语义化颜色令牌,而非原始调色板颜色。

## 安装 [#install]

```bash
npm install @librechat/client
```

该包将其运行时库列为对等依赖(React、Tailwind CSS 4、Radix UI、Ariakit 等),因此宿主应用只需安装一次所需版本并与之共享。包管理器会报告缺失的依赖。

## 设置样式 [#set-up-the-styles]

组件使用 Tailwind CSS 4 和 LibreChat 的主题令牌进行样式设置。在 Tailwind 之后导入该包的主题和组件样式,然后加载使用该包预设的 Tailwind 配置:

```css title="style.css"
@import 'tailwindcss';
@import '@librechat/client/theme.css';
@import '@librechat/client/style.css';
@config './tailwind.config.js';
```

```js title="tailwind.config.js"
const libreChatTailwindPreset = require('@librechat/client/tailwind-preset')

module.exports = {
  presets: [libreChatTailwindPreset],
  content: [
    './src/**/*.{js,jsx,ts,tsx}',
    './node_modules/@librechat/client/dist/**/*.{js,mjs,cjs}',
  ],
  darkMode: ['class'],
}
```

然后用 `ThemeProvider` 包裹你的应用,它会应用浅色、深色或跟随系统的模式,以及任何自定义主题:

```tsx
import { ThemeProvider } from '@librechat/client'

export function App({ children }) {
  return <ThemeProvider initialTheme="system">{children}</ThemeProvider>
}
```

一些组件通过 `react-i18next` 读取其内置标签(例如对话框的取消按钮),因此需要使用 LibreChat 的翻译或您自己针对相同键的字符串来初始化 i18next。
