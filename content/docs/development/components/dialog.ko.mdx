LibreChat의 모달 대화상자는 `OGDialog`와 그 하위 구성 요소로 만들어집니다. 제목, 본문, 확인 동작이 있는 표준 대화상자의 경우 `OGDialogTemplate`이 이들을 조합하고 현지화된 취소 버튼을 추가합니다.

<ComponentPreview example="dialog/confirm" title="확인 대화 상자" minHeight={320} />

<Callout type="info">
다음 릴리스의 `@librechat/client`에서는 `Dialog`, `DialogContent`, `DialogTemplate` 등의 부품도 일반 이름으로 내보냅니다. 이들은 동일한 컴포넌트이므로, 해당 릴리스가 출시되면 두 이름 중 어느 것을 사용해도 됩니다.
</Callout>

## 부품 [#parts]

| Part | Role |
| --- | --- |
| `OGDialog` | 루트 요소이며, 대화 상자가 열려 있는지 여부를 제어합니다. |
| `OGDialogTrigger` | 대화 상자를 여는 요소입니다. `Button`과 함께 `asChild`를 사용하세요. |
| `OGDialogContent` | 대화 상자 표면이며, 선택적으로 닫기 버튼을 포함합니다. |
| `OGDialogHeader`, `OGDialogTitle`, `OGDialogDescription` | 제목 영역입니다. 모든 대화 상자에는 제목이 필요합니다. |
| `OGDialogFooter`, `OGDialogClose` | 작업 버튼 행과 대화 상자를 닫는 컨트롤입니다. |
| `OGDialogTemplate` | 완전한 대화 상자로, `title`, `main`, `selection` 및 선택적인 취소 버튼을 포함합니다. |

## 너비 및 닫기 [#width-and-dismissal]

다이얼로그가 데스크톱에서 휴대폰까지 잘 보이도록 `w-11/12`에 `max-w-*` 상한을 함께 지정하고, 빠져나갈 수 있는 방법은 닫기 버튼 또는 취소 버튼 중 하나로 명확하게 하나만 제공합니다.

## 접근성 [#accessibility]

대화 상자를 열면 포커스가 대화 상자 안으로 이동하며, 닫힐 때까지 포커스는 그 안에 머뭅니다. 대화 상자를 닫으면 포커스는 트리거 요소로 돌아갑니다. 삭제와 같은 되돌릴 수 없는 작업을 확인하는 경우에는 `AlertDialog`를 사용하면 스크린 리더에 더 강한 `alertdialog` 역할이 전달됩니다.

| 키 | 동작 |
| --- | --- |
| <kbd>Tab</kbd> 및 <kbd>Shift</kbd>+<kbd>Tab</kbd> | 대화 상자의 컨트롤 간 이동 |
| <kbd>Escape</kbd> | 대화 상자를 닫고 포커스를 트리거로 되돌림 |
