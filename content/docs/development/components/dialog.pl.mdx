LibreChat's modal dialog is built from `OGDialog` and its parts. For a standard dialog with a title, a body and a confirm action, `OGDialogTemplate` assembles them and adds a localized Cancel button.

<ComponentPreview example="dialog/confirm" title="Dialog potwierdzenia" minHeight={320} />

<Callout type="info">
Kolejne wydanie `@librechat/client` eksportuje te elementy również pod prostymi nazwami (`Dialog`, `DialogContent`, `DialogTemplate` i pozostałe). Są to te same komponenty, więc po wydaniu tej wersji można użyć dowolnej z tych nazw.
</Callout>

## Części [#parts]

| Część | Rola |
| --- | --- |
| `OGDialog` | Element nadrzędny; steruje tym, czy okno dialogowe jest otwarte. |
| `OGDialogTrigger` | Element, który je otwiera. Użyj `asChild` z `Button`. |
| `OGDialogContent` | Powierzchnia okna dialogowego, z opcjonalnym przyciskiem zamknięcia. |
| `OGDialogHeader`, `OGDialogTitle`, `OGDialogDescription` | Obszar nagłówka. Każde okno dialogowe musi mieć tytuł. |
| `OGDialogFooter`, `OGDialogClose` | Wiersz akcji oraz kontrolka zamykająca okno dialogowe. |
| `OGDialogTemplate` | Gotowe okno dialogowe: `title`, `main`, `selection` oraz opcjonalny przycisk Anuluj. |

## Szerokość i zamykanie [#width-and-dismissal]

Ogranicz dialog do `w-11/12` oraz limitu `max-w-*`, aby dobrze wyglądał zarówno na komputerze, jak i na telefonie, i zapewnij jeden wyraźny sposób wyjścia: przycisk zamknięcia lub przycisk Anuluj.

## Dostępność [#accessibility]

Otwarcie okna dialogowego przenosi fokus do jego wnętrza i utrzymuje go tam do momentu zamknięcia; po zamknięciu fokus wraca do elementu wyzwalającego. Dla potwierdzenia operacji destrukcyjnej `AlertDialog` zapewnia czytnikom ekranu silniejszą rolę `alertdialog`.

| Klawisz | Działanie |
| --- | --- |
| <kbd>Tab</kbd> i <kbd>Shift</kbd>+<kbd>Tab</kbd> | Przemieszczanie się między elementami sterującymi okna dialogowego |
| <kbd>Escape</kbd> | Zamyka okno dialogowe i przenosi fokus z powrotem na element wyzwalający |
