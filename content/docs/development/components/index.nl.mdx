LibreChat's interface is built from a shared set of React components published on npm as `@librechat/client`. The pages in this section show each one live, rendered from the published package in the same theme the app uses, with the code that renders it underneath.

Elke preview volgt de lichte of donkere modus van deze site. De voorbeelden zijn geschreven zoals de eigen code van LibreChat de componenten gebruikt: labels die aan hun velden zijn gekoppeld, gelokaliseerde teksten en semantische kleurtokens in plaats van ruwe palettekleuren.

## Installeren [#install]

```bash
npm install @librechat/client
```

Het pakket somt zijn runtime-bibliotheken op als peer dependencies (React, Tailwind CSS 4, Radix UI, Ariakit en andere), zodat een host de benodigde versies één keer installeert en deelt. Je pakketbeheerder meldt eventuele ontbrekende versies.

## De stijlen instellen [#set-up-the-styles]

De componenten zijn gestyled met Tailwind CSS 4 en de thematokens van LibreChat. Importeer de thema- en componentstijlen van het pakket na Tailwind, en laad vervolgens een Tailwind-configuratie die de preset van het pakket gebruikt:

```css title="style.css"
@import 'tailwindcss';
@import '@librechat/client/theme.css';
@import '@librechat/client/style.css';
@config './tailwind.config.js';
```

```js title="tailwind.config.js"
const libreChatTailwindPreset = require('@librechat/client/tailwind-preset')

module.exports = {
  presets: [libreChatTailwindPreset],
  content: [
    './src/**/*.{js,jsx,ts,tsx}',
    './node_modules/@librechat/client/dist/**/*.{js,mjs,cjs}',
  ],
  darkMode: ['class'],
}
```

Pak vervolgens je app in met `ThemeProvider`, die de lichte, donkere of systeemmodus toepast, evenals elk aangepast thema:

```tsx
import { ThemeProvider } from '@librechat/client'

export function App({ children }) {
  return <ThemeProvider initialTheme="system">{children}</ThemeProvider>
}
```

Sommige componenten lezen hun ingebouwde labels (zoals de knop Annuleren van een dialoogvenster) via `react-i18next`, dus initialiseer i18next met de vertalingen van LibreChat of met je eigen teksten voor dezelfde sleutels.
