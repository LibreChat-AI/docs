LibreChat のモーダルダイアログは `OGDialog` とそのパーツで構成されています。タイトル、本文、確認アクションを備えた標準的なダイアログの場合は、`OGDialogTemplate` がこれらを組み立て、ローカライズされたキャンセルボタンを追加します。

<ComponentPreview example="dialog/confirm" title="確認ダイアログ" minHeight={320} />

<Callout type="info">
次のリリースでは、`@librechat/client` はこれらのパーツをプレーンな名前(`Dialog`、`DialogContent`、`DialogTemplate` など)でもエクスポートします。これらは同じコンポーネントなので、そのリリースが公開されればどちらの名前でも使用できます。
</Callout>

## パーツ [#parts]

| 部品 | 役割 |
| --- | --- |
| `OGDialog` | ルートです。ダイアログを開いているかどうかを制御します。 |
| `OGDialogTrigger` | ダイアログを開く要素です。`Button` と組み合わせて `asChild` を使用します。 |
| `OGDialogContent` | ダイアログの表示領域です。任意で閉じるボタンを含めることができます。 |
| `OGDialogHeader`, `OGDialogTitle`, `OGDialogDescription` | 見出しの領域です。すべてのダイアログにはタイトルが必要です。 |
| `OGDialogFooter`, `OGDialogClose` | 操作ボタンの行と、ダイアログを閉じるためのコントロールです。 |
| `OGDialogTemplate` | 完全なダイアログです。`title`、`main`、`selection`、および任意のキャンセルボタンを含みます。 |

## 幅と閉じる操作 [#width-and-dismissal]

`w-11/12` で幅を制限し、`max-w-*` で最大幅を設定することで、デスクトップからスマートフォンまで対応できるダイアログにしましょう。また、閉じる方法は明確に一つだけにしてください。閉じるボタンまたはキャンセルボタンのいずれかです。

## アクセシビリティ [#accessibility]

ダイアログを開くと、フォーカスがダイアログ内に移動し、閉じるまでフォーカスはダイアログ内に保持されます。閉じると、フォーカスはトリガー要素に戻ります。破壊的な操作の確認には、`AlertDialog` を使用します。これにより、スクリーンリーダーに、より強い意味を持つ `alertdialog` ロールが提供されます。

| キー | 操作 |
| --- | --- |
| <kbd>Tab</kbd> および <kbd>Shift</kbd>+<kbd>Tab</kbd> | ダイアログ内のコントロール間を移動する |
| <kbd>Escape</kbd> | ダイアログを閉じ、フォーカスをトリガーに戻す |
