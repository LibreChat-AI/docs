`Dropdown` è il selettore a valore singolo di LibreChat. In un modulo, usa la variante `field`, che corrisponde a `Input`. Per un menu di azioni anziché di valori, usa `DropdownPopup`.

## Props [#props]

| Prop | Tipo | Predefinito | Descrizione |
| --- | --- | --- | --- |
| `value` | `string` | | Il valore dell'opzione selezionata. |
| `onChange` | `(value: string) => void` | | Viene chiamata con il valore dell'opzione scelta. |
| `options` | `Array<string \| { value, label, icon?, disabled? } \| { divider: true }>` | | Le scelte, nell'ordine in cui compaiono. |
| `variant` | `'default' \| 'field' \| 'compact'` | `'default'` | `field` corrisponde a `Input` nei moduli; `compact` si adatta alle barre degli strumenti. |
| `placeholder` | `string` | | Mostrato con il tono secondario finché non viene scelto nulla. |
| `searchable` | `boolean` | `false` | Aggiunge un campo di ricerca in cima all'elenco. |
| `aria-labelledby` | `string` | | Punta all'etichetta visibile del campo. Il valore selezionato viene annunciato insieme ad essa. |
| `aria-invalid` | `boolean` | | Contrassegna un menu a discesa `field` come non valido. |
| `disabled` | `boolean` | `false` | Impedisce l'apertura dell'elenco. |
| `portal` | `boolean` | `true`, oppure `false` all'interno di una finestra di dialogo | Visualizza l'elenco in un portale. All'interno di una finestra di dialogo l'elenco rimane nella finestra, così che il focus e gli screen reader possano raggiungerlo. |

## Accessibilità [#accessibility]

Il trigger è un `combobox` che apre un `listbox`. Assegnagli un nome tramite `aria-labelledby` che punti a un'etichetta visibile, oppure tramite `aria-label` quando non è presente alcuna etichetta.

| Chiave | Azione |
| --- | --- |
| <kbd>Enter</kbd>, <kbd>Spazio</kbd> o <kbd>↓</kbd> | Apre l'elenco |
| <kbd>↑</kbd> e <kbd>↓</kbd> | Si sposta tra le opzioni |
| <kbd>Enter</kbd> | Seleziona l'opzione attiva e chiude l'elenco |
| <kbd>Escape</kbd> | Chiude l'elenco senza modificare il valore |
