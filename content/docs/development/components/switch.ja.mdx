設定の変更が即座に反映される場合は `Switch` を使用してください。フォームの送信時に適用されるオプションの場合は、代わりにチェックボックスを使用してください。

## プロパティ [#props]

| Prop | Type | Description |
| --- | --- | --- |
| `checked` | `boolean` | 制御された状態です。 |
| `onCheckedChange` | `(checked: boolean) => void` | ユーザーがスイッチを切り替えたときに呼び出されます。 |
| `defaultChecked` | `boolean` | 非制御の場合の初期状態です。 |
| `disabled` | `boolean` | 切り替えをブロックします。 |
| `aria-label` or `aria-labelledby` | `string` | 必須: どちらか一方のみを指定して、スイッチに名前を付けます。 |

## アクセシビリティ [#accessibility]

The switch exposes the `switch` role with its checked state, and its type requires an accessible name.

| Key | Action |
| --- | --- |
| <kbd>Space</kbd> または <kbd>Enter</kbd> | スイッチを切り替えます |
