title: 开关

description: 一种立即生效的开/关设置。
---

使用 `Switch` 来设置那些在更改后立即生效的选项。对于需要在提交表单时才应用的选项,请改用复选框。

<ComponentPreview example="switch/default" title="带标签的开关" />

## 属性 [#props]

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `checked` | `boolean` | 受控状态。 |
| `onCheckedChange` | `(checked: boolean) => void` | 用户切换开关时调用。 |
| `defaultChecked` | `boolean` | 非受控时的初始状态。 |
| `disabled` | `boolean` | 阻止切换。 |
| `aria-label` 或 `aria-labelledby` | `string` | 必填:二者中必须且只能有一个用于为开关命名。 |

## 无障碍访问 [#accessibility]

该开关暴露了 `switch` 角色及其选中状态,其类型要求提供可访问名称。

| 键 | 操作 |
| --- | --- |
| <kbd>Space</kbd> 或 <kbd>Enter</kbd> | 切换开关 |
