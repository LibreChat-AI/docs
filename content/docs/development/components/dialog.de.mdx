Der Modaldialog von LibreChat wird aus `OGDialog` und dessen Bestandteilen aufgebaut. Für einen Standarddialog mit Titel, Inhalt und Bestätigungsaktion setzt `OGDialogTemplate` diese zusammen und fügt eine lokalisierte Schaltfläche „Abbrechen“ hinzu.

<ComponentPreview example="dialog/confirm" title="Bestätigungsdialog" minHeight={320} />

<Callout type="info">
Die nächste Version von `@librechat/client` exportiert diese Teile außerdem unter einfachen Namen (`Dialog`, `DialogContent`, `DialogTemplate` und die übrigen). Es handelt sich um dieselben Komponenten, daher funktioniert nach Veröffentlichung dieser Version jeder der beiden Namen.
</Callout>

## Teile [#parts]

| Teil | Rolle |
| --- | --- |
| `OGDialog` | Das Wurzelelement; steuert, ob der Dialog geöffnet ist. |
| `OGDialogTrigger` | Das Element, das ihn öffnet. Verwende `asChild` mit einem `Button`. |
| `OGDialogContent` | Die Dialogfläche mit optionaler Schließen-Schaltfläche. |
| `OGDialogHeader`, `OGDialogTitle`, `OGDialogDescription` | Der Kopfbereich. Jeder Dialog benötigt einen Titel. |
| `OGDialogFooter`, `OGDialogClose` | Die Aktionszeile und ein Steuerelement, das den Dialog schließt. |
| `OGDialogTemplate` | Ein vollständiger Dialog: `title`, `main`, `selection` und optional eine Abbrechen-Schaltfläche. |

## Breite und Schließen [#width-and-dismissal]

Begrenze einen Dialog auf `w-11/12` plus eine `max-w-*`-Obergrenze, damit er vom Desktop bis zum Smartphone gut funktioniert, und gib ihm genau einen klaren Weg zum Schließen: den Schließen-Button oder einen Abbrechen-Button.

## Barrierefreiheit [#accessibility]

Das Öffnen des Dialogs verschiebt den Fokus in ihn und hält den Fokus darin, bis er geschlossen wird; beim Schließen kehrt der Fokus zum Auslöser zurück. Für eine destruktive Bestätigung gibt `AlertDialog` Screenreadern die stärkere Rolle `alertdialog`.

| Taste | Aktion |
| --- | --- |
| <kbd>Tab</kbd> und <kbd>Shift</kbd>+<kbd>Tab</kbd> | Zwischen den Steuerelementen des Dialogs wechseln |
| <kbd>Escape</kbd> | Schließt den Dialog und gibt den Fokus an den Auslöser zurück |
