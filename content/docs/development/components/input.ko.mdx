`Input`은 LibreChat 폼에서 사용되는 텍스트 필드입니다. 이를 `Label`과 함께 사용하고, 모든 필드에 React의 `useId()`로 생성한 id를 부여하세요. 그렇게 하면 컴포넌트가 여러 번 렌더링되더라도 레이블이 올바른 필드를 가리킵니다.

## 잘못된 항목 [#invalid]

검증에 실패한 필드에는 `aria-invalid`를 표시하고, `aria-describedby`로 오류 메시지를 해당 필드와 연결합니다. 이 필드의 테두리는 테마의 destructive 색상으로 표시됩니다.

<ComponentPreview example="input/invalid" title="잘못된 상태의 입력" />

## Props [#props]

`Input`은 기본 `input` 속성을 모두 받습니다. 그중 스타일이 적용되는 속성은 다음과 같습니다:

| Prop | 타입 | 설명 |
| --- | --- | --- |
| `aria-invalid` | `boolean` | 값이 잘못되었음을 나타내기 위해 빨간색(destructive) 테두리를 표시하고 보조 기술에 값이 유효하지 않음을 알립니다. |
| `disabled` | `boolean` | 필드를 흐리게 표시하고 편집을 차단합니다. |
| `placeholder` | `string` | 필드가 비어 있을 때 표시되는 예시 텍스트입니다. 레이블이 아닙니다. |

## 접근성 [#accessibility]

- 모든 필드에는 보이는 레이블이 있어야 합니다: `htmlFor`가 지정된 `Label`, 또는 `aria-labelledby`.
- IDs는 항상 `useId()`에서 가져오며, 리터럴 문자열을 사용하지 않습니다.
- 에러 텍스트는 `text-text-destructive` 토큰을 사용하며, 표시될 때 알림으로 전달되도록 `role="alert"`를 사용합니다.
