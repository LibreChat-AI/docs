`Button`は、LibreChatにおけるすべてのクリック可能なアクションをレンダリングします。これには、開閉用のキャレットやコピーアイコンなど、ボタンに見えないコントロールも含まれます。アクションの内容に応じてバリアントを選択してください。

## バリエーション [#variants]

<ComponentPreview example="button/variants" title="ボタンのバリアント" />

| Variant | 用途 |
| --- | --- |
| `default` | ダイアログを開く、またはフローを開始する主要なアクション |
| `submit` | 保存または作成：フォームの主要なアクション |
| `outline` | キャンセル、閉じる、またはセカンダリアクション |
| `destructive` | 削除やその他の取り消しできないアクション。通常は確認ダイアログ内で使用 |
| `ghost` | 強調度の低いアクション。アイコンのみのボタン、ツールバーや行内のアクション |
| `link` | インラインのテキストアクション |

## プロパティ [#props]

| Prop | 型 | デフォルト | 説明 |
| --- | --- | --- | --- |
| `variant` | `'default' \| 'submit' \| 'outline' \| 'destructive' \| 'ghost' \| 'link' \| ...` | `'default'` | アクションの視覚的な役割を指定します。 |
| `size` | `'default' \| 'sm' \| 'lg' \| 'icon' \| 'icon-sm' \| ...` | `'default'` | 高さと余白を指定します。`icon` サイズは正方形になります。 |
| `shape` | `'theme' \| 'round' \| ...` | 未設定 | 角の丸みを指定します。未設定の場合は、バリアント自体の角丸が適用されます。`theme` と `round` は、テーマのコントロール形状に従います。 |
| `asChild` | `boolean` | `false` | 子要素(例:リンク)をボタンのスタイルでレンダリングします。 |

`Button` は、ネイティブの `button` 属性をすべて受け付けます。

## アクセシビリティ [#accessibility]

- アイコンのみのボタンには `aria-label` を付与してください。アイコン自体には `aria-hidden` を設定します。
- フォームのメインボタンには `type="submit"` を設定してください。
- 無効化されたボタンでも、ラベルは読めるようにしてください。操作ができない理由を説明することを優先し、ボタンを非表示にするよりも、その理由を明示するほうが望ましいです。

| Key | Action |
| --- | --- |
| <kbd>Enter</kbd> または <kbd>Space</kbd> | ボタンを有効化する |
