`Input` é o campo de texto usado nos formulários do LibreChat. Associe-o a um `Label` e atribua a cada campo um id gerado por `useId()` do React, para que o label continue apontando para o campo correto quando o componente for renderizado mais de uma vez.

## Inválido [#invalid]

Marque um campo que falhou na validação com `aria-invalid`, e associe a mensagem a ele com `aria-describedby`. O campo desenha sua borda na cor destrutiva do tema.

<ComponentPreview example="input/invalid" title="Estado de entrada inválido" />

## Props [#props]

`Input` aceita todos os atributos nativos de `input`. Os que ele estiliza:

| Prop | Tipo | Descrição |
| --- | --- | --- |
| `aria-invalid` | `boolean` | Desenha a borda de destaque de erro e informa às tecnologias assistivas que o valor é inválido. |
| `disabled` | `boolean` | Esmaece o campo e bloqueia a edição. |
| `placeholder` | `string` | Texto de exemplo exibido enquanto o campo está vazio. Não é um rótulo. |

## Acessibilidade [#accessibility]

- Todo campo precisa de um rótulo visível: `Label` com `htmlFor`, ou `aria-labelledby`.
- Os IDs vêm de `useId()`, nunca de uma string literal.
- O texto de erro usa o token `text-text-destructive` e `role="alert"`, para que seja anunciado quando aparecer.
