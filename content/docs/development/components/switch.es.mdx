title: Interruptor
icon: ToggleRight
description: Una configuración de activado o desactivado que se aplica de inmediato.
---

Use `Switch` para una configuración que surte efecto en cuanto cambia. Para una opción que se aplica al enviar un formulario, use una casilla de verificación (checkbox) en su lugar.

<ComponentPreview example="switch/default" title="Cambiar con una etiqueta" />

## Props [#props]

| Prop | Tipo | Descripción |
| --- | --- | --- |
| `checked` | `boolean` | El estado controlado. |
| `onCheckedChange` | `(checked: boolean) => void` | Se invoca cuando el usuario cambia el interruptor. |
| `defaultChecked` | `boolean` | El estado inicial cuando no está controlado. |
| `disabled` | `boolean` | Impide cambiar el estado. |
| `aria-label` o `aria-labelledby` | `string` | Obligatorio: exactamente uno debe nombrar el interruptor. |

## Accesibilidad [#accessibility]

El switch expone el rol `switch` con su estado de marcado (checked), y su tipo requiere un nombre accesible.

| Clave | Acción |
| --- | --- |
| <kbd>Space</kbd> o <kbd>Enter</kbd> | Activa o desactiva el interruptor |
