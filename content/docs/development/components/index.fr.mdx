L'interface de LibreChat est construite à partir d'un ensemble partagé de composants React publiés sur npm sous le nom `@librechat/client`. Les pages de cette section présentent chacun d'eux en direct, rendus à partir du package publié dans le même thème que celui utilisé par l'application, avec le code qui les génère juste en dessous.

Chaque aperçu suit le mode clair ou sombre de ce site. Les exemples sont écrits de la même manière que le code de LibreChat utilise ces composants : étiquettes liées à leurs champs, chaînes localisées et jetons de couleur sémantiques plutôt que des couleurs de palette brutes.

## Installation [#install]

```bash
npm install @librechat/client
```

Le paquet déclare ses bibliothèques d'exécution comme dépendances pairs (React, Tailwind CSS 4, Radix UI, Ariakit et d'autres), de sorte qu'un hôte installe une seule fois les versions dont il a besoin et les partage. Votre gestionnaire de paquets signale celles qui manquent.

## Configurer les styles [#set-up-the-styles]

Les composants sont stylisés avec Tailwind CSS 4 et les jetons de thème de LibreChat. Importez les styles du thème et des composants du package après Tailwind, puis chargez une configuration Tailwind qui utilise le preset du package :

```css title="style.css"
@import 'tailwindcss';
@import '@librechat/client/theme.css';
@import '@librechat/client/style.css';
@config './tailwind.config.js';
```

```js title="tailwind.config.js"
const libreChatTailwindPreset = require('@librechat/client/tailwind-preset')

module.exports = {
  presets: [libreChatTailwindPreset],
  content: [
    './src/**/*.{js,jsx,ts,tsx}',
    './node_modules/@librechat/client/dist/**/*.{js,mjs,cjs}',
  ],
  darkMode: ['class'],
}
```

Ensuite, enveloppez votre application dans `ThemeProvider`, qui applique le mode clair, sombre ou système ainsi que tout thème personnalisé :

```tsx
import { ThemeProvider } from '@librechat/client'

export function App({ children }) {
  return <ThemeProvider initialTheme="system">{children}</ThemeProvider>
}
```

Certains composants lisent leurs libellés intégrés (comme le bouton Annuler d'une boîte de dialogue) via `react-i18next`. Il faut donc initialiser i18next avec les traductions de LibreChat ou avec vos propres chaînes pour les mêmes clés.
