La interfaz de LibreChat se compone de un conjunto compartido de componentes de React publicados en npm como `@librechat/client`. Las páginas de esta sección muestran cada uno de ellos en vivo, renderizados a partir del paquete publicado con el mismo tema que usa la aplicación, junto con el código que los renderiza debajo.

Cada vista previa sigue el modo claro u oscuro de este sitio. Los ejemplos están escritos del mismo modo en que el código propio de LibreChat utiliza los componentes: etiquetas asociadas a sus campos, cadenas localizadas y tokens de color semánticos en lugar de colores de paleta sin procesar.

## Instalación [#install]

```bash
npm install @librechat/client
```

El paquete enumera sus bibliotecas de ejecución como dependencias peer (React, Tailwind CSS 4, Radix UI, Ariakit y otras), de modo que el host instala una sola vez las versiones que necesita y las comparte. Tu gestor de paquetes informa de cualquiera que falte.

## Configura los estilos [#set-up-the-styles]

Los componentes se estilizan con Tailwind CSS 4 y los tokens de tema de LibreChat. Importa los estilos del tema y de los componentes del paquete después de Tailwind, y luego carga una configuración de Tailwind que use el preset del paquete:

```css title="style.css"
@import 'tailwindcss';
@import '@librechat/client/theme.css';
@import '@librechat/client/style.css';
@config './tailwind.config.js';
```

```js title="tailwind.config.js"
const libreChatTailwindPreset = require('@librechat/client/tailwind-preset')

module.exports = {
  presets: [libreChatTailwindPreset],
  content: [
    './src/**/*.{js,jsx,ts,tsx}',
    './node_modules/@librechat/client/dist/**/*.{js,mjs,cjs}',
  ],
  darkMode: ['class'],
}
```

Luego envuelve tu aplicación en `ThemeProvider`, que aplica el modo claro, oscuro o del sistema, así como cualquier tema personalizado:

```tsx
import { ThemeProvider } from '@librechat/client'

export function App({ children }) {
  return <ThemeProvider initialTheme="system">{children}</ThemeProvider>
}
```

Algunos componentes leen sus etiquetas integradas (como el botón Cancel de un diálogo) a través de `react-i18next`, por lo que debes inicializar i18next con las traducciones de LibreChat o con tus propias cadenas para las mismas claves.
