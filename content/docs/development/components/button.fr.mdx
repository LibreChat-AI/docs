`Button` affiche chaque action cliquable de LibreChat, y compris les contrôles qui ne ressemblent pas à des boutons, comme un caret de dépliage ou une icône de copie. Choisissez la variante en fonction de ce que fait l'action.

## Variantes [#variants]

<ComponentPreview example="button/variants" title="Variantes de bouton" />

| Variante | Utiliser pour |
| --- | --- |
| `default` | Une action principale qui ouvre une boîte de dialogue ou lance un flux |
| `submit` | Enregistrer ou créer : l'action principale du formulaire |
| `outline` | Annuler, fermer ou une action secondaire |
| `destructive` | Supprimer ou toute autre action irréversible, généralement dans une boîte de dialogue de confirmation |
| `ghost` | Actions à faible emphase, icônes seules, barres d'outils et actions de ligne |
| `link` | Une action textuelle en ligne |

## Props [#props]

| Prop | Type | Défaut | Description |
| --- | --- | --- | --- |
| `variant` | `'default' \| 'submit' \| 'outline' \| 'destructive' \| 'ghost' \| 'link' \| ...` | `'default'` | Le rôle visuel de l'action. |
| `size` | `'default' \| 'sm' \| 'lg' \| 'icon' \| 'icon-sm' \| ...` | `'default'` | La hauteur et le rembourrage. Les tailles `icon` sont carrées. |
| `shape` | `'theme' \| 'round' \| ...` | Non défini | Le rayon des coins. Non défini, c'est le rayon propre à la variante qui s'applique ; `theme` et `round` suivent la forme de contrôle du thème. |
| `asChild` | `boolean` | `false` | Rend l'élément enfant (par exemple un lien) avec les styles du bouton. |

`Button` accepte également tous les attributs natifs de `button`.

## Accessibilité [#accessibility]

- Donnez à un bouton ne contenant qu'une icône un `aria-label` ; l'icône elle-même doit avoir `aria-hidden`.
- Définissez `type="submit"` sur le bouton principal d'un formulaire.
- Un bouton désactivé conserve un libellé lisible ; il est préférable d'expliquer pourquoi une action est indisponible plutôt que de la masquer.

| Clé | Action |
| --- | --- |
| <kbd>Enter</kbd> ou <kbd>Space</kbd> | Active le bouton |
