`Dropdown`, LibreChat'in tek değerli seçim bileşenidir. Bir formda, `Input` ile eşleşen `field` varyantını kullanın. Değerler yerine bir eylem menüsü için `DropdownPopup` kullanın.

## Özellikler [#props]

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | | Seçili seçeneğin değeri. |
| `onChange` | `(value: string) => void` | | Seçilen seçeneğin değeriyle çağrılır. |
| `options` | `Array<string \| { value, label, icon?, disabled? } \| { divider: true }>` | | Seçenekler, sırasıyla. |
| `variant` | `'default' \| 'field' \| 'compact'` | `'default'` | `field`, formlardaki `Input` ile eşleşir; `compact` araç çubuklarına uygun olur. |
| `placeholder` | `string` | | Hiçbir şey seçilmediğinde ikincil tonda gösterilir. |
| `searchable` | `boolean` | `false` | Listenin en üstüne bir arama alanı ekler. |
| `aria-labelledby` | `string` | | Alanın görünür etiketine işaret eder. Seçili değer bununla birlikte duyurulur. |
| `aria-invalid` | `boolean` | | Bir `field` açılır listesini geçersiz olarak işaretler. |
| `disabled` | `boolean` | `false` | Listenin açılmasını engeller. |
| `portal` | `boolean` | `true`, veya bir diyalog içindeyken `false` | Listeyi bir portal içinde oluşturur. Bir diyalog içinde liste diyalog içinde kalır, böylece odak ve ekran okuyucular ona ulaşabilir. |

## Erişilebilirlik [#accessibility]

Tetikleyici, bir `listbox` açan bir `combobox`'tır. Görünür bir etikete işaret eden `aria-labelledby` ile adlandırın; etiket yoksa `aria-label` kullanın.

| Anahtar | Eylem |
| --- | --- |
| <kbd>Enter</kbd>, <kbd>Space</kbd> veya <kbd>↓</kbd> | Listeyi açar |
| <kbd>↑</kbd> ve <kbd>↓</kbd> | Seçenekler arasında gezinir |
| <kbd>Enter</kbd> | Etkin seçeneği seçer ve listeyi kapatır |
| <kbd>Escape</kbd> | Değeri değiştirmeden listeyi kapatır |
