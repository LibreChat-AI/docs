LibreChatのインターフェースは、npmで`@librechat/client`として公開されている共通のReactコンポーネント群から構成されています。このセクションのページでは、各コンポーネントを公開されたパッケージからレンダリングし、アプリで使用しているものと同じテーマで実際に表示しています。その下には、それを描画するコードも掲載しています。

すべてのプレビューは、このサイトのライトモードまたはダークモードに従います。例は、LibreChat 自身のコードがこれらのコンポーネントを使用する方法に沿って記述されています。つまり、ラベルは対応するフィールドに関連付けられ、文字列はローカライズされ、生のパレットカラーではなくセマンティックなカラートークンを使用しています。

## インストール [#install]

```bash
npm install @librechat/client
```

このパッケージは、ランタイムライブラリ（React、Tailwind CSS 4、Radix UI、Ariakit など）をピア依存関係として記載しています。そのため、ホストアプリケーションは必要なバージョンを一度だけインストールし、それを共有して利用します。不足しているものがあれば、パッケージマネージャーが報告します。

## スタイルを設定する [#set-up-the-styles]

コンポーネントは Tailwind CSS 4 と LibreChat のテーマトークンでスタイル設定されています。Tailwind の後にパッケージのテーマおよびコンポーネントのスタイルをインポートし、次にパッケージのプリセットを使用する Tailwind 設定を読み込んでください:

```css title="style.css"
@import 'tailwindcss';
@import '@librechat/client/theme.css';
@import '@librechat/client/style.css';
@config './tailwind.config.js';
```

```js title="tailwind.config.js"
const libreChatTailwindPreset = require('@librechat/client/tailwind-preset')

module.exports = {
  presets: [libreChatTailwindPreset],
  content: [
    './src/**/*.{js,jsx,ts,tsx}',
    './node_modules/@librechat/client/dist/**/*.{js,mjs,cjs}',
  ],
  darkMode: ['class'],
}
```

次に、アプリを`ThemeProvider`でラップします。これにより、ライト、ダーク、システムのモードおよびカスタムテーマが適用されます:

```tsx
import { ThemeProvider } from '@librechat/client'

export function App({ children }) {
  return <ThemeProvider initialTheme="system">{children}</ThemeProvider>
}
```

一部のコンポーネントは組み込みのラベル(ダイアログのキャンセルボタンなど)を`react-i18next`経由で読み込むため、LibreChatの翻訳、または同じキーに対応する独自の文字列を使ってi18nextを初期化してください。
