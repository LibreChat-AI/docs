Le composant `Dropdown` est le sélecteur à valeur unique de LibreChat. Dans un formulaire, utilisez la variante `field`, qui correspond à `Input`. Pour un menu d'actions plutôt qu'un ensemble de valeurs, utilisez `DropdownPopup`.

## Props [#props]

| Prop | Type | Par défaut | Description |
| --- | --- | --- | --- |
| `value` | `string` | | La valeur de l'option sélectionnée. |
| `onChange` | `(value: string) => void` | | Appelée avec la valeur de l'option choisie. |
| `options` | `Array<string \| { value, label, icon?, disabled? } \| { divider: true }>` | | Les choix, dans l'ordre. |
| `variant` | `'default' \| 'field' \| 'compact'` | `'default'` | `field` correspond à `Input` dans les formulaires ; `compact` convient aux barres d'outils. |
| `placeholder` | `string` | | Affiché dans le ton secondaire tant qu'aucune option n'est choisie. |
| `searchable` | `boolean` | `false` | Ajoute un champ de recherche en haut de la liste. |
| `aria-labelledby` | `string` | | Pointe vers le libellé visible du champ. La valeur sélectionnée est annoncée avec celui-ci. |
| `aria-invalid` | `boolean` | | Marque une liste déroulante `field` comme invalide. |
| `disabled` | `boolean` | `false` | Empêche l'ouverture de la liste. |
| `portal` | `boolean` | `true`, ou `false` à l'intérieur d'une boîte de dialogue | Affiche la liste dans un portail. Dans une boîte de dialogue, la liste reste dans celle-ci afin que le focus et les lecteurs d'écran puissent l'atteindre. |

## Accessibilité [#accessibility]

Le déclencheur est un `combobox` qui ouvre une `listbox`. Nommez-le avec `aria-labelledby` pointant vers un libellé visible, ou avec `aria-label` lorsqu'il n'en existe aucun.

| Touche | Action |
| --- | --- |
| <kbd>Enter</kbd>, <kbd>Espace</kbd> ou <kbd>↓</kbd> | Ouvre la liste |
| <kbd>↑</kbd> et <kbd>↓</kbd> | Permettent de parcourir les options |
| <kbd>Enter</kbd> | Sélectionne l'option active et ferme la liste |
| <kbd>Échap</kbd> | Ferme la liste sans modifier la valeur |
