LibreChats Benutzeroberfläche basiert auf einer gemeinsamen Gruppe von React-Komponenten, die auf npm als `@librechat/client` veröffentlicht sind. Die Seiten in diesem Abschnitt zeigen jede davon live, gerendert aus dem veröffentlichten Paket im selben Design, das die App verwendet, mit dem Code, der sie rendert, darunter.

Jede Vorschau folgt dem Hell- oder Dunkelmodus dieser Website. Die Beispiele sind so geschrieben, wie LibreChat selbst die Komponenten verwendet: Beschriftungen sind ihren Feldern zugeordnet, Texte sind lokalisiert, und es werden semantische Farbtoken statt roher Farbpaletten-Werte verwendet.

## Installation [#install]

```bash
npm install @librechat/client
```

Das Paket führt seine Laufzeitbibliotheken als Peer-Dependencies auf (React, Tailwind CSS 4, Radix UI, Ariakit und weitere), sodass ein Host die benötigten Versionen einmal installiert und gemeinsam nutzt. Ihr Paketmanager meldet alle fehlenden Abhängigkeiten.

## Stile einrichten [#set-up-the-styles]

Die Komponenten werden mit Tailwind CSS 4 und den Theme-Tokens von LibreChat gestylt. Importiere die Theme- und Komponenten-Styles des Pakets nach Tailwind und lade anschließend eine Tailwind-Konfiguration, die das Preset des Pakets verwendet:

```css title="style.css"
@import 'tailwindcss';
@import '@librechat/client/theme.css';
@import '@librechat/client/style.css';
@config './tailwind.config.js';
```

```js title="tailwind.config.js"
const libreChatTailwindPreset = require('@librechat/client/tailwind-preset')

module.exports = {
  presets: [libreChatTailwindPreset],
  content: [
    './src/**/*.{js,jsx,ts,tsx}',
    './node_modules/@librechat/client/dist/**/*.{js,mjs,cjs}',
  ],
  darkMode: ['class'],
}
```

Wrappe anschließend deine App in `ThemeProvider`, das den hellen, dunklen oder systembasierten Modus sowie ein benutzerdefiniertes Theme anwendet:

```tsx
import { ThemeProvider } from '@librechat/client'

export function App({ children }) {
  return <ThemeProvider initialTheme="system">{children}</ThemeProvider>
}
```

Einige Komponenten lesen ihre integrierten Beschriftungen (etwa die Schaltfläche Abbrechen eines Dialogs) über `react-i18next`. Initialisiere i18next daher mit den Übersetzungen von LibreChat oder mit eigenen Zeichenketten für dieselben Schlüssel.
