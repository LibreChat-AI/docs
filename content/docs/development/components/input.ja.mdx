`Input`は、LibreChatのフォームで使用されるテキストフィールドです。`Label`と組み合わせ、各フィールドにReactの`useId()`で生成したidを割り当ててください。こうすることで、コンポーネントが複数回レンダリングされても、ラベルが正しいフィールドを参照し続けます。

## 無効 [#invalid]

検証に失敗したフィールドには `aria-invalid` を設定し、`aria-describedby` でエラーメッセージとそのフィールドを関連付けます。フィールドの枠線はテーマの destructive カラーで表示されます。

<ComponentPreview example="input/invalid" title="入力が無効な状態" />

## プロパティ [#props]

`Input` は、ネイティブの `input` 属性をすべて受け付けます。スタイルが適用される属性は以下のとおりです:

| Prop | Type | Description |
| --- | --- | --- |
| `aria-invalid` | `boolean` | 破壊的(destructive)なボーダーを表示し、値が無効であることを支援技術に伝えます。 |
| `disabled` | `boolean` | フィールドの表示を薄くし、編集をブロックします。 |
| `placeholder` | `string` | フィールドが空のときに表示される入力例のテキストです。ラベルではありません。 |

## アクセシビリティ [#accessibility]

- すべてのフィールドには、表示されるラベルが必要です。`htmlFor` を指定した `Label`、または `aria-labelledby` を使用してください。
- IDは`useId()`から取得し、リテラル文字列を使用しないこと。
- エラーテキストは `text-text-destructive` トークンと `role="alert"` を使用しており、表示されたときに読み上げられます。
