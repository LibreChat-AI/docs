El diálogo modal de LibreChat se construye a partir de `OGDialog` y sus partes. Para un diálogo estándar con título, cuerpo y acción de confirmación, `OGDialogTemplate` las combina y añade un botón Cancelar localizado.

<ComponentPreview example="dialog/confirm" title="Diálogo de confirmación" minHeight={320} />

<Callout type="info">
El próximo lanzamiento de `@librechat/client` también exporta estas piezas con nombres simples (`Dialog`, `DialogContent`, `DialogTemplate` y el resto). Son los mismos componentes, así que cualquiera de los dos nombres funciona una vez que esa versión esté disponible.
</Callout>

## Partes [#parts]

| Parte | Función |
| --- | --- |
| `OGDialog` | El elemento raíz; controla si el diálogo está abierto. |
| `OGDialogTrigger` | El elemento que lo abre. Usa `asChild` con un `Button`. |
| `OGDialogContent` | La superficie del diálogo, con un botón de cierre opcional. |
| `OGDialogHeader`, `OGDialogTitle`, `OGDialogDescription` | El área del encabezado. Todo diálogo necesita un título. |
| `OGDialogFooter`, `OGDialogClose` | La fila de acciones y un control que cierra el diálogo. |
| `OGDialogTemplate` | Un diálogo completo: `title`, `main`, `selection` y un botón Cancelar opcional. |

## Ancho y cierre [#width-and-dismissal]

Limita un diálogo a `w-11/12` más un límite `max-w-*` para que se adapte desde el escritorio hasta el teléfono, y ofrécele exactamente una salida clara: el botón de cerrar o un botón Cancelar.

## Accesibilidad [#accessibility]

Al abrir el diálogo, el foco se mueve al interior y permanece dentro hasta que se cierra; al cerrarlo, el foco regresa al disparador. Para una confirmación destructiva, `AlertDialog` ofrece a los lectores de pantalla el rol `alertdialog`, más expresivo.

| Tecla | Acción |
| --- | --- |
| <kbd>Tab</kbd> y <kbd>Shift</kbd>+<kbd>Tab</kbd> | Moverse entre los controles del diálogo |
| <kbd>Escape</kbd> | Cierra el diálogo y devuelve el foco al elemento que lo activó |
