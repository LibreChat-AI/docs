LibreChat's interface jest zbudowany z zestawu współdzielonych komponentów React, opublikowanych w npm jako `@librechat/client`. Strony w tej sekcji prezentują każdy z nich na żywo, renderowany z opublikowanego pakietu w tym samym motywie, którego używa aplikacja, wraz z kodem, który go renderuje.

Każdy podgląd dostosowuje się do trybu jasnego lub ciemnego tej strony. Przykłady są napisane w taki sposób, w jaki kod LibreChat używa tych komponentów: etykiety są powiązane z polami, teksty są zlokalizowane, a kolory odwołują się do semantycznych tokenów kolorów, a nie do surowych kolorów z palety.

## Instalacja [#install]

```bash
npm install @librechat/client
```

Pakiet wymienia swoje biblioteki uruchomieniowe jako zależności peer (React, Tailwind CSS 4, Radix UI, Ariakit i inne), dzięki czemu host instaluje potrzebne wersje jednokrotnie i udostępnia je wspólnie. Menedżer pakietów zgłasza wszystkie brakujące.

## Konfiguracja stylów [#set-up-the-styles]

Komponenty są stylizowane za pomocą Tailwind CSS 4 i tokenów motywu LibreChat. Zaimportuj style motywu i komponentów pakietu po Tailwind, a następnie załaduj konfigurację Tailwind, która używa presetu pakietu:

```css title="style.css"
@import 'tailwindcss';
@import '@librechat/client/theme.css';
@import '@librechat/client/style.css';
@config './tailwind.config.js';
```

```js title="tailwind.config.js"
const libreChatTailwindPreset = require('@librechat/client/tailwind-preset')

module.exports = {
  presets: [libreChatTailwindPreset],
  content: [
    './src/**/*.{js,jsx,ts,tsx}',
    './node_modules/@librechat/client/dist/**/*.{js,mjs,cjs}',
  ],
  darkMode: ['class'],
}
```

Następnie owiń swoją aplikację w `ThemeProvider`, który stosuje tryb jasny, ciemny lub systemowy oraz dowolny niestandardowy motyw:

```tsx
import { ThemeProvider } from '@librechat/client'

export function App({ children }) {
  return <ThemeProvider initialTheme="system">{children}</ThemeProvider>
}
```

Niektóre komponenty odczytują swoje wbudowane etykiety (np. przycisk Anuluj w oknie dialogowym) za pośrednictwem `react-i18next`, dlatego należy zainicjalizować i18next z tłumaczeniami LibreChat lub z własnymi ciągami znaków dla tych samych kluczy.
