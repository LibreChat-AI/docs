O data-brand do LibreChat é construída a partir de um conjunto compartilhado de componentes React publicados no npm como `@librechat/client`. As páginas desta seção mostram cada um deles ao vivo, renderizados a partir do pacote publicado no mesmo tema usado pelo aplicativo, com o código que os renderiza logo abaixo.

Cada pré-visualização segue o modo claro ou escuro deste site. Os exemplos são escritos da mesma forma que o próprio código do LibreChat usa os componentes: rótulos vinculados aos seus campos, strings localizadas e tokens de cor semânticos em vez de cores de paleta brutas.

## Instalação [#install]

```bash
npm install @librechat/client
```

O pacote lista suas bibliotecas de execução como dependências peer (React, Tailwind CSS 4, Radix UI, Ariakit e outras), de modo que o host instala uma vez as versões de que precisa e as compartilha. O seu gerenciador de pacotes informa quais estiverem faltando.

## Configure os estilos [#set-up-the-styles]

Os componentes são estilizados com Tailwind CSS 4 e os tokens de tema do LibreChat. Importe os estilos de tema e de componentes do pacote após o Tailwind e, em seguida, carregue uma configuração do Tailwind que use o preset do pacote:

```css title="style.css"
@import 'tailwindcss';
@import '@librechat/client/theme.css';
@import '@librechat/client/style.css';
@config './tailwind.config.js';
```

```js title="tailwind.config.js"
const libreChatTailwindPreset = require('@librechat/client/tailwind-preset')

module.exports = {
  presets: [libreChatTailwindPreset],
  content: [
    './src/**/*.{js,jsx,ts,tsx}',
    './node_modules/@librechat/client/dist/**/*.{js,mjs,cjs}',
  ],
  darkMode: ['class'],
}
```

Em seguida, envolva seu aplicativo em `ThemeProvider`, que aplica o modo claro, escuro ou do sistema e qualquer tema personalizado:

```tsx
import { ThemeProvider } from '@librechat/client'

export function App({ children }) {
  return <ThemeProvider initialTheme="system">{children}</ThemeProvider>
}
```

Alguns componentes leem seus rótulos integrados (como o botão Cancelar de um diálogo) por meio do `react-i18next`, por isso inicialize o i18next com as traduções do LibreChat ou com suas próprias strings para as mesmas chaves.
