## Configurações Úteis [#useful-settings]

- Defina `DEBUG_CONSOLE=true` no `.env` para obter uma saída detalhada do servidor no console.
- Execute `npm run backend:inspect` para iniciar o backend com o inspetor do Node.js (`--inspect`) e `--expose-gc`, permitindo que você conecte um depurador.
