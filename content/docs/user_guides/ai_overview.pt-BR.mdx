O LibreChat permite que você configure e integre vários provedores de IA, APIs e suas respectivas credenciais. Isso possibilita a utilização de diferentes modelos de IA, configurações e funcionalidades com base em suas necessidades e requisitos.

## Conceitos-chave [#key-concepts]

- **Endpoints**: Um endpoint refere-se a um provedor de IA, configuração ou API que determina os modelos e as configurações disponíveis para uma solicitação de chat. Exemplos incluem OpenAI, Google, Anthropic e outros.

- **Presets**: Um preset é uma combinação salva de um endpoint, modelo e configurações de conversa. Você pode criar e gerenciar múltiplos presets para atender a diferentes casos de uso.

- **Default Endpoint**: Se você tiver vários endpoints configurados, você pode especificar um endpoint padrão a ser usado ao criar uma nova conversa.

- **Default Preset**: Da mesma forma, você pode definir um preset padrão para ser usado automaticamente ao iniciar uma nova conversa.

## Funcionalidade [#functionality]

1. **Provedores de IA**: Configure vários provedores de IA pré-configurados fornecendo as credenciais e chaves de API necessárias.

2. **Gerenciar endpoints**: Habilite ou desabilite diferentes endpoints com base em seus requisitos.

3. **Criar e Gerenciar Presets**: Defina e salve combinações específicas de endpoints, modelos e configurações de conversa como presets.

4. **Definir Endpoint e Preset Padrão**: Especifique um endpoint e um preset padrão para otimizar o processo de iniciar novas conversas. Aqui está um vídeo para demonstrar: **[Configurando um Preset Padrão](https://github.com/danny-avila/LibreChat/assets/110412045/bbde830f-18d9-4884-88e5-1bd8f7ac585d)**

5. **Personalizar Configurações**: Explore opções avançadas de configuração, como adicionar endpoints personalizados como Ollama, Mistral AI ou OpenRouter.

## Pesquisa [#searching]

O LibreChat possui recursos de busca separados para a web, para seus arquivos e para suas conversas:

- **Pesquisar na web**: Permita que a IA consulte informações atuais. Em um chat comum, abra a paleta **+** no [compositor de mensagens](/docs/features/composer) e selecione **Pesquisa na Web**. Para um agente, habilite o recurso **Pesquisa na Web** no Agent Builder. A pesquisa na web exige um provedor de busca e um scraper, configurados pelo seu administrador ou com suas próprias chaves de API quando solicitado. Consulte [Pesquisa na Web](/docs/features/web_search).

- **Pesquise seus arquivos**: faça perguntas sobre documentos que você enviar. Em um chat comum, selecione **File Search** no menu **+**. Para um agente, habilite a capacidade **File Search** no Agent Builder. O File Search encontra trechos por significado usando a RAG API, que o seu administrador implanta. Consulte [RAG API (Chat with Files)](/docs/features/rag_api).

- **Pesquise suas conversas**: Use a caixa de pesquisa na barra lateral para encontrar mensagens anteriores. Ela aparece apenas quando o administrador habilitou o Meilisearch. Consulte [Pesquisa de Mensagens](/docs/features/search).

A Pesquisa na Web e a Pesquisa em Arquivos são opcionais. Elas aparecem apenas quando sua implantação as habilita, o que inclui ativar a capacidade de agente `web_search` ou `file_search` e conceder ao seu perfil a permissão correspondente. Se alguma delas não estiver visível, peça ao seu administrador ou consulte [Opção de Pesquisa na Web não está visível](/docs/features/web_search#web-search-option-is-not-visible) e a [configuração de interface `fileSearch`](/docs/configuration/librechat_yaml/object_structure/interface#filesearch).
