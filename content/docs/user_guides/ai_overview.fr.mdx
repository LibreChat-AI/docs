LibreChat vous permet de configurer et d'intégrer divers fournisseurs d'IA, API et leurs identifiants correspondants. Cela vous permet d'utiliser différents modèles d'IA, paramètres et fonctionnalités en fonction de vos besoins et exigences.

## Concepts clés [#key-concepts]

- **Endpoints** : Un endpoint désigne un fournisseur d'IA, une configuration ou une API qui détermine les modèles disponibles et les paramètres d'une requête de chat. Parmi les exemples figurent OpenAI, Google, Anthropic et d'autres.

- **Presets** : Un preset est une combinaison enregistrée d'un endpoint, d'un modèle et de paramètres de conversation. Vous pouvez créer et gérer plusieurs presets pour répondre à différents cas d'utilisation.

- **Default Endpoint** : Si vous avez plusieurs endpoints configurés, vous pouvez spécifier un endpoint par défaut à utiliser lors de la création d'une nouvelle conversation.

- **Préréglage par défaut** : De même, vous pouvez définir un préréglage par défaut qui sera utilisé automatiquement lors du démarrage d'une nouvelle conversation.

## Fonctionnalités [#functionality]

1. **Fournisseurs d'IA** : Configurez divers fournisseurs d'IA préconfigurés en fournissant les identifiants et les clés API nécessaires.

2. **Gérer les endpoints** : Activez ou désactivez différents endpoints selon vos besoins.

3. **Créer et gérer des préréglages** : Définissez et enregistrez des combinaisons spécifiques d'endpoint, de modèles et de paramètres de conversation en tant que préréglages.

4. **Définir l'endpoint et le preset par défaut** : Spécifiez un endpoint et un preset par défaut pour simplifier le processus de démarrage de nouvelles conversations. Voici une vidéo de démonstration : **[Définir un preset par défaut](https://github.com/danny-avila/LibreChat/assets/110412045/bbde830f-18d9-4884-88e5-1bd8f7ac585d)**

5. **Personnaliser les configurations** : Explorez des options de configuration avancées, telles que l'ajout d'endpoints personnalisés comme Ollama, Mistral AI ou OpenRouter.

## Recherche [#searching]

LibreChat propose des fonctionnalités de recherche distinctes pour le web, vos fichiers et vos conversations :

- **Rechercher sur le Web** : Permettez à l'IA de consulter des informations actuelles. Dans un chat classique, ouvrez la palette **+** dans le [compositeur de messages](/docs/features/composer) et sélectionnez **Web Search**. Pour un agent, activez plutôt la capacité **Web Search** dans l'Agent Builder. La recherche sur le Web nécessite à la fois un fournisseur de recherche et un outil d'extraction de contenu (scraper), configurés par votre administrateur ou avec vos propres clés API lorsque cela vous est demandé. Voir [Recherche sur le Web](/docs/features/web_search).

- **Rechercher dans vos fichiers** : posez des questions sur les documents que vous importez. Dans un chat classique, sélectionnez **File Search** depuis la palette **+**. Pour un agent, activez la capacité **File Search** dans l'Agent Builder. File Search trouve des passages par leur sens à l'aide de l'API RAG, que votre administrateur déploie. Voir [RAG API (Chat with Files)](/docs/features/rag_api).

- **Rechercher dans vos conversations** : Utilisez la zone de recherche dans la barre latérale pour retrouver les messages passés. Elle n'apparaît que si l'administrateur a activé Meilisearch. Voir [Recherche de messages](/docs/features/search).

La recherche web et la recherche de fichiers sont facultatives. Elles n'apparaissent que si votre déploiement les active, ce qui implique d'activer la capacité d'agent `web_search` ou `file_search` et d'accorder à votre rôle la permission correspondante. Si l'une d'elles est absente, demandez à votre administrateur, ou consultez [L'option de recherche web n'est pas visible](/docs/features/web_search#web-search-option-is-not-visible) et le [paramètre d'interface `fileSearch`](/docs/configuration/librechat_yaml/object_structure/interface#filesearch).
