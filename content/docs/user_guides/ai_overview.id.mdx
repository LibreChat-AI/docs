LibreChat memungkinkan Anda untuk mengonfigurasi dan mengintegrasikan berbagai penyedia AI, API, serta kredensial terkait. Hal ini memungkinkan Anda untuk memanfaatkan berbagai model AI, pengaturan, dan fungsionalitas berdasarkan kebutuhan dan persyaratan Anda.

## Konsep Utama [#key-concepts]

- **Endpoints**: Sebuah endpoint merujuk pada penyedia AI, konfigurasi, atau API yang menentukan model dan pengaturan yang tersedia untuk sebuah permintaan chat. Contohnya termasuk OpenAI, Google, Anthropic, dan lainnya.

- **Presets**: Preset adalah kombinasi tersimpan dari endpoint, model, dan pengaturan percakapan. Anda dapat membuat dan mengelola beberapa preset untuk menyesuaikan dengan berbagai kasus penggunaan.

- **Default Endpoint**: Jika Anda memiliki beberapa endpoint yang dikonfigurasi, Anda dapat menentukan endpoint default yang akan digunakan saat membuat percakapan baru.

- **Default Preset**: Demikian pula, Anda dapat mengatur preset default agar digunakan secara otomatis saat memulai percakapan baru.

## Fungsionalitas [#functionality]

1. **Penyedia AI**: Siapkan berbagai penyedia AI yang telah dikonfigurasi sebelumnya dengan memberikan kredensial dan kunci API yang diperlukan.

2. **Kelola endpoint**: Aktifkan atau nonaktifkan berbagai endpoint berdasarkan kebutuhan Anda.

3. **Membuat dan Mengelola Preset**: Tentukan dan simpan kombinasi spesifik dari endpoint, model, dan pengaturan percakapan sebagai preset.

4. **Atur Endpoint dan Preset Default**: Tentukan endpoint dan preset default untuk menyederhanakan proses memulai percakapan baru. Berikut adalah video untuk mendemonstrasikannya: **[Mengatur Preset Default](https://github.com/danny-avila/LibreChat/assets/110412045/bbde830f-18d9-4884-88e5-1bd8f7ac585d)**

5. **Sesuaikan Konfigurasi**: Jelajahi opsi konfigurasi tingkat lanjut, seperti menambahkan endpoint kustom seperti Ollama, Mistral AI, atau OpenRouter.

## Pencarian [#searching]

LibreChat memiliki fitur pencarian terpisah untuk web, file Anda, dan percakapan Anda:

- **Cari di web**: Biarkan AI mencari informasi terkini. Dalam chat biasa, buka palet **+** di [message composer](/docs/features/composer) dan pilih **Web Search**. Untuk agen, aktifkan kapabilitas **Web Search** di Agent Builder. Pencarian web memerlukan penyedia pencarian dan scraper, yang dikonfigurasi oleh admin Anda atau dengan kunci API Anda sendiri saat diminta. Lihat [Web Search](/docs/features/web_search).

- **Cari dalam file Anda**: Ajukan pertanyaan tentang dokumen yang Anda unggah. Dalam obrolan biasa, pilih **File Search** dari palet **+**. Untuk agen, aktifkan kapabilitas **File Search** di Agent Builder. File Search menemukan bagian teks berdasarkan makna menggunakan RAG API, yang di-deploy oleh admin Anda. Lihat [RAG API (Chat with Files)](/docs/features/rag_api).

- **Cari percakapan Anda**: Gunakan kotak pencarian di sidebar untuk menemukan pesan sebelumnya. Kotak ini hanya muncul ketika admin telah mengaktifkan Meilisearch. Lihat [Pencarian Pesan](/docs/features/search).

Web Search dan File Search bersifat opsional. Keduanya hanya muncul ketika deployment Anda mengaktifkannya, yaitu dengan mengaktifkan kapabilitas agen `web_search` atau `file_search` dan memberikan izin yang sesuai pada peran Anda. Jika salah satunya tidak tersedia, minta bantuan admin Anda, atau lihat [Web Search option is not visible](/docs/features/web_search#web-search-option-is-not-visible) dan [pengaturan interface `fileSearch`](/docs/configuration/librechat_yaml/object_structure/interface#filesearch).
