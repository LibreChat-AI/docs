LibreChat le permite configurar e integrar varios proveedores de IA, APIs y sus credenciales correspondientes. Esto le permite utilizar diferentes modelos de IA, configuraciones y funcionalidades según sus necesidades y requisitos.

## Conceptos clave [#key-concepts]

- **Endpoints**: Un endpoint hace referencia a un proveedor de IA, configuración o API que determina los modelos y ajustes disponibles para una solicitud de chat. Algunos ejemplos son OpenAI, Google, Anthropic y otros.

- **Presets**: Un preset es una combinación guardada de un endpoint, modelo y ajustes de conversación. Puedes crear y gestionar múltiples presets para adaptarlos a diferentes casos de uso.

- **Default Endpoint**: Si tienes múltiples endpoints configurados, puedes especificar un endpoint predeterminado que se utilizará al crear una nueva conversación.

- **Default Preset**: De manera similar, puedes establecer un preset predeterminado para que se utilice automáticamente al iniciar una nueva conversación.

## Funcionalidad [#functionality]

1. **Proveedores de IA**: Configure varios proveedores de IA preconfigurados proporcionando las credenciales y claves API necesarias.

2. **Gestionar endpoints**: Habilite o deshabilite diferentes endpoints según sus requisitos.

3. **Crear y gestionar Presets**: Define y guarda combinaciones específicas de endpoints, modelos y configuraciones de conversación como presets.

4. **Establecer endpoint y preset predeterminados**: Especifique un endpoint y un preset predeterminados para agilizar el proceso de iniciar nuevas conversaciones. Aquí hay un video para demostrarlo: **[Configuración de un preset predeterminado](https://github.com/danny-avila/LibreChat/assets/110412045/bbde830f-18d9-4884-88e5-1bd8f7ac585d)**

5. **Personalizar configuraciones**: Explore opciones de configuración avanzadas, como añadir endpoints personalizados como Ollama, Mistral AI o OpenRouter.

## Búsqueda [#searching]

LibreChat tiene funciones de búsqueda separadas para la web, tus archivos y tus conversaciones:

- **Buscar en la web**: Permite que la IA consulte información actualizada. En un chat normal, abre la paleta **+** en el [compositor de mensajes](/docs/features/composer) y selecciona **Web Search**. Para un agente, habilita la capacidad **Web Search** en el Agent Builder. La búsqueda web requiere tanto un proveedor de búsqueda como un scraper, que deben ser configurados por tu administrador o con tus propias claves API cuando se te solicite. Consulta [Web Search](/docs/features/web_search).

- **Busca en tus archivos**: Haz preguntas sobre los documentos que subas. En un chat normal, selecciona **File Search** desde la paleta **+**. Para un agente, activa la capacidad **File Search** en el Agent Builder. File Search encuentra pasajes por significado usando la RAG API, que tu administrador despliega. Consulta [RAG API (Chat with Files)](/docs/features/rag_api).

- **Buscar en tus conversaciones**: Usa el cuadro de búsqueda en la barra lateral para encontrar mensajes anteriores. Solo aparece cuando el administrador ha habilitado Meilisearch. Consulta [Búsqueda de mensajes](/docs/features/search).

La Búsqueda web y la Búsqueda de archivos son opcionales. Solo aparecen cuando tu implementación las habilita, lo que incluye activar la capacidad de agente `web_search` o `file_search` y otorgar a tu rol el permiso correspondiente. Si falta alguna, consulta a tu administrador, o consulta [Web Search option is not visible](/docs/features/web_search#web-search-option-is-not-visible) y la [configuración de interfaz `fileSearch`](/docs/configuration/librechat_yaml/object_structure/interface#filesearch).
