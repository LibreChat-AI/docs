LibreChat 允许您配置和集成各种 AI 提供商、API 及其相应的凭据。这使您能够根据自己的需求和要求使用不同的 AI 模型、设置和功能。

## 关键概念 [#key-concepts]

- **Endpoints**:端点(endpoint)是指决定聊天请求可用模型和设置的 AI 提供商、配置或 API。例如 OpenAI、Google、Anthropic 等。

- **Presets**: 预设（Preset）是端点（endpoint）、模型和对话设置的保存组合。您可以创建并管理多个预设，以适应不同的使用场景。

- **默认 endpoint**：如果您配置了多个 endpoint，则可以指定一个在创建新对话时使用的默认 endpoint。

- **默认预设 (Default Preset)**：同样地，您可以设置一个默认预设，以便在开始新对话时自动使用。

## 功能 [#functionality]

1. **AI Providers**: 通过提供必要的凭据和 API 密钥，设置各种预配置的 AI 提供商。

2. **管理 Endpoints**：根据您的需求启用或禁用不同的 Endpoints。

3. **创建和管理预设 (Presets)**：定义并保存 endpoint、模型和对话设置的特定组合作为预设。

4. **设置默认 endpoint 和预设 (Preset)**：指定一个默认的 endpoint 和预设，以简化开始新对话的过程。以下是演示视频：**[设置默认预设](https://github.com/danny-avila/LibreChat/assets/110412045/bbde830f-18d9-4884-88e5-1bd8f7ac585d)**

5. **自定义配置**：探索高级配置选项，例如添加自定义 endpoint，如 Ollama、Mistral AI 或 OpenRouter。

## 搜索 [#searching]

LibreChat 为网页、您的文件和您的对话分别提供了独立的搜索功能:

- **搜索网络**:让 AI 查询最新信息。在常规聊天中,打开[消息编辑器](/docs/features/composer)中的 **+** 面板,然后选择 **Web Search**。对于智能体,请改为在智能体构建器中启用 **Web Search** 功能。网络搜索需要同时配置搜索提供商和抓取器,可由管理员配置,也可在提示时使用您自己的 API 密钥进行配置。参见 [Web Search](/docs/features/web_search)。

- **搜索您的文件**:就您上传的文档提问。在常规聊天中,从 **+** 面板中选择 **File Search**。对于智能体,在 Agent Builder 中启用 **File Search** 功能。File Search 使用 RAG API 按语义查找段落,该 API 由您的管理员部署。请参阅 [RAG API (Chat with Files)](/docs/features/rag_api)。

- **搜索您的对话**:使用侧边栏中的搜索框查找过往消息。仅当管理员启用了 Meilisearch 时才会显示该搜索框。请参阅 [消息搜索](/docs/features/search)。

Web Search 和 File Search 是可选功能。只有在您的部署中启用它们时才会显示,这包括开启 `web_search` 或 `file_search` 智能体功能,并为您的角色授予相应权限。如果找不到这些选项,请联系管理员,或参阅 [Web Search option is not visible](/docs/features/web_search#web-search-option-is-not-visible) 以及 [`fileSearch` interface setting](/docs/configuration/librechat_yaml/object_structure/interface#filesearch)。
