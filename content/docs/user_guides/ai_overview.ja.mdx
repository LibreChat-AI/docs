LibreChatでは、さまざまなAIプロバイダー、API、およびそれらに対応する認証情報を設定・統合することができます。これにより、ニーズや要件に応じて、異なるAIモデル、設定、機能を活用することが可能になります。

## 主要な概念 [#key-concepts]

- **Endpoints**: エンドポイントとは、チャットリクエストで利用可能なモデルや設定を決定する AI プロバイダー、設定、または API を指します。例としては OpenAI、Google、Anthropic などがあります。

- **Presets**: プリセットは、endpoint、モデル、および会話設定を組み合わせた保存済みの構成です。さまざまなユースケースに合わせて、複数のプリセットを作成および管理できます。

- **Default Endpoint**: 複数のendpointが設定されている場合、新しい会話を作成する際に使用されるデフォルトのendpointを指定できます。

- **Default Preset**: 同様に、新しい会話を開始する際に自動的に使用されるデフォルトのプリセットを設定できます。

## 機能 [#functionality]

1. **AI Providers**: 必要な認証情報とAPIキーを提供することで、あらかじめ設定されたさまざまなAIプロバイダーをセットアップします。

2. **Manage Endpoints**: 要件に基づいて、さまざまな endpoint を有効または無効にします。

3. **プリセットの作成と管理**: 特定のendpoint、モデル、および会話設定の組み合わせをプリセットとして定義し、保存します。

4. **デフォルトのendpointとプリセットの設定**: 新しい会話を開始するプロセスを効率化するために、デフォルトのendpointとプリセットを指定します。デモンストレーションの動画はこちらです: **[デフォルトプリセットの設定](https://github.com/danny-avila/LibreChat/assets/110412045/bbde830f-18d9-4884-88e5-1bd8f7ac585d)**

5. **設定のカスタマイズ**: Ollama、Mistral AI、OpenRouterなどのカスタムendpointを追加するなど、高度な設定オプションを探索します。

## 検索 [#searching]

LibreChatには、ウェブ、ファイル、会話の3つを対象とする個別の検索機能があります:

- **Web検索**: AIに最新の情報を検索させます。通常のチャットでは、[メッセージコンポーザー](/docs/features/composer)の **+** パレットを開き、**Web Search** を選択します。エージェントの場合は、代わりにAgent Builderで **Web Search** 機能を有効にしてください。Web検索には検索プロバイダーとスクレイパーの両方の設定が必要です。これは管理者が設定するか、求められたときに自分のAPIキーを使用して設定します。詳細は [Web Search](/docs/features/web_search) を参照してください。

- **ファイルを検索**: アップロードしたドキュメントについて質問できます。通常のチャットでは、**+** パレットから **File Search** を選択します。エージェントの場合は、Agent Builder で **File Search** 機能を有効にします。File Search は、管理者がデプロイする RAG API を使用して、意味に基づいて文章を検索します。詳細は [RAG API (Chat with Files)](/docs/features/rag_api) を参照してください。

- **会話を検索**: サイドバーの検索ボックスを使って過去のメッセージを検索できます。この検索ボックスは、管理者が Meilisearch を有効にしている場合にのみ表示されます。詳細は [メッセージ検索](/docs/features/search) を参照してください。

Web SearchとFile Searchはオプションです。デプロイ環境でこれらが有効になっている場合にのみ表示されます。これには、`web_search`または`file_search`のエージェント機能をオンにし、ご自身のロールに対応する権限を付与することが含まれます。いずれかが表示されない場合は、管理者にお問い合わせいただくか、[Web Search option is not visible](/docs/features/web_search#web-search-option-is-not-visible)および[`fileSearch` interface setting](/docs/configuration/librechat_yaml/object_structure/interface#filesearch)をご覧ください。
