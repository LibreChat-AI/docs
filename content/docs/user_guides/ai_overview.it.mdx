LibreChat ti consente di configurare e integrare vari provider di IA, API e le relative credenziali. Ciò ti permette di utilizzare diversi modelli di IA, impostazioni e funzionalità in base alle tue necessità e ai tuoi requisiti.

## Concetti chiave [#key-concepts]

- **Endpoint**: Un endpoint indica un provider di IA, una configurazione o un'API che determina i modelli disponibili e le impostazioni per una richiesta di chat. Esempi includono OpenAI, Google, Anthropic e altri.

- **Presets**: Un preset è una combinazione salvata di un endpoint, un modello e impostazioni di conversazione. Puoi creare e gestire più preset per adattarli a diversi casi d'uso.

- **Endpoint predefinito**: Se hai configurato più endpoint, puoi specificare un endpoint predefinito da utilizzare durante la creazione di una nuova conversazione.

- **Default Preset**: Analogamente, puoi impostare un preset predefinito da utilizzare automaticamente all'avvio di una nuova conversazione.

## Funzionalità [#functionality]

1. **AI Providers**: Configura vari provider di AI predefiniti fornendo le credenziali e le API key necessarie.

2. **Gestione degli endpoint**: Abilita o disabilita diversi endpoint in base ai tuoi requisiti.

3. **Creazione e gestione dei Preset**: Definisci e salva combinazioni specifiche di endpoint, modelli e impostazioni di conversazione come preset.

4. **Imposta endpoint e preset predefiniti**: Specifica un endpoint e un preset predefiniti per semplificare il processo di avvio di nuove conversazioni. Ecco un video dimostrativo: **[Impostazione di un preset predefinito](https://github.com/danny-avila/LibreChat/assets/110412045/bbde830f-18d9-4884-88e5-1bd8f7ac585d)**

5. **Personalizza le configurazioni**: Esplora opzioni di configurazione avanzate, come l'aggiunta di endpoint personalizzati come Ollama, Mistral AI o OpenRouter.

## Ricerca [#searching]

LibreChat ha funzionalità di ricerca separate per il web, per i tuoi file e per le tue conversazioni:

- **Cerca sul web**: lascia che l'IA consulti informazioni aggiornate. In una chat normale, apri la palette **+** nel [compositore di messaggi](/docs/features/composer) e seleziona **Ricerca web**. Per un agente, abilita invece la capacità **Ricerca web** nell'Agent Builder. La ricerca web richiede sia un provider di ricerca sia uno scraper, configurati dal tuo amministratore oppure con le tue chiavi API personali quando richiesto. Vedi [Ricerca web](/docs/features/web_search).

- **Cerca nei tuoi file**: Fai domande sui documenti che carichi. In una chat normale, seleziona **File Search** dal menu **+**. Per un agente, abilita la funzionalità **File Search** nell'Agent Builder. File Search trova i passaggi in base al significato utilizzando la RAG API, che il tuo amministratore distribuisce. Vedi [RAG API (Chat with Files)](/docs/features/rag_api).

- **Cerca nelle tue conversazioni**: Usa la casella di ricerca nella barra laterale per trovare i messaggi passati. Appare solo quando l'amministratore ha abilitato Meilisearch. Vedi [Ricerca nei messaggi](/docs/features/search).

La Ricerca web e la Ricerca nei file sono opzionali. Compaiono solo quando la tua installazione le abilita, il che include l'attivazione della capacità dell'agente `web_search` o `file_search` e l'assegnazione al tuo ruolo del permesso corrispondente. Se una delle due non è visibile, chiedi al tuo amministratore, oppure consulta [Web Search option is not visible](/docs/features/web_search#web-search-option-is-not-visible) e l'[impostazione di interfaccia `fileSearch`](/docs/configuration/librechat_yaml/object_structure/interface#filesearch).
