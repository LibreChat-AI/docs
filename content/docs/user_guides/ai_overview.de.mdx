LibreChat ermöglicht es Ihnen, verschiedene KI-Anbieter, APIs und die dazugehörigen Anmeldedaten zu konfigurieren und zu integrieren. Dies ermöglicht es Ihnen, je nach Bedarf und Anforderungen unterschiedliche KI-Modelle, Einstellungen und Funktionalitäten zu nutzen.

## Grundlegende Konzepte [#key-concepts]

- **Endpoints**: Ein Endpoint bezeichnet einen KI-Anbieter, eine Konfiguration oder eine API, die die verfügbaren Modelle und Einstellungen für eine Chat-Anfrage bestimmt. Beispiele sind OpenAI, Google, Anthropic und andere.

- **Presets**: Ein Preset ist eine gespeicherte Kombination aus einem endpoint, einem Modell und Konversationseinstellungen. Sie können mehrere Presets erstellen und verwalten, um sie an verschiedene Anwendungsfälle anzupassen.

- **Standard-Endpoint**: Wenn Sie mehrere Endpoints konfiguriert haben, können Sie einen Standard-Endpoint festlegen, der beim Erstellen einer neuen Konversation verwendet werden soll.

- **Standard-Voreinstellung**: Ebenso können Sie eine Standard-Voreinstellung festlegen, die automatisch beim Starten einer neuen Konversation verwendet wird.

## Funktionalität [#functionality]

1. **AI-Anbieter**: Richten Sie verschiedene vorkonfigurierte AI-Anbieter ein, indem Sie die erforderlichen Anmeldedaten und API-Schlüssel bereitstellen.

2. **Endpoints verwalten**: Aktivieren oder deaktivieren Sie verschiedene Endpoints basierend auf Ihren Anforderungen.

3. **Presets erstellen und verwalten**: Definieren und speichern Sie spezifische Kombinationen aus endpoints, Modellen und Konversationseinstellungen als Presets.

4. **Standard-endpoint und -Voreinstellung festlegen**: Geben Sie einen Standard-endpoint und eine Voreinstellung an, um den Prozess zum Starten neuer Konversationen zu optimieren. Hier ist ein Video zur Demonstration: **[Festlegen einer Standard-Voreinstellung](https://github.com/danny-avila/LibreChat/assets/110412045/bbde830f-18d9-4884-88e5-1bd8f7ac585d)**

5. **Konfigurationen anpassen**: Entdecken Sie erweiterte Konfigurationsoptionen, wie das Hinzufügen benutzerdefinierter endpoints wie Ollama, Mistral AI oder OpenRouter.

## Suche [#searching]

LibreChat bietet separate Suchfunktionen für das Web, Ihre Dateien und Ihre Unterhaltungen:

- **Im Web suchen**: Lassen Sie die KI aktuelle Informationen nachschlagen. Öffnen Sie in einem normalen Chat die Palette **+** im [Nachrichteneditor](/docs/features/composer) und wählen Sie **Web Search**. Für einen Agenten aktivieren Sie stattdessen die Fähigkeit **Web Search** im Agent Builder. Die Websuche benötigt sowohl einen Suchanbieter als auch einen Scraper, die von Ihrem Administrator konfiguriert werden oder für die Sie bei Aufforderung eigene API-Schlüssel angeben. Siehe [Web Search](/docs/features/web_search).

- **Dateien durchsuchen**: Stelle Fragen zu Dokumenten, die du hochlädst. In einem regulären Chat wählst du **Dateisuche** aus der **+**-Palette aus. Für einen Agenten aktivierst du die Funktion **Dateisuche** im Agent Builder. Die Dateisuche findet Textpassagen anhand ihrer Bedeutung über die RAG API, die dein Administrator bereitstellt. Siehe [RAG API (Chat mit Dateien)](/docs/features/rag_api).

- **Konversationen durchsuchen**: Verwende das Suchfeld in der Seitenleiste, um frühere Nachrichten zu finden. Es wird nur angezeigt, wenn der Administrator Meilisearch aktiviert hat. Siehe [Nachrichtensuche](/docs/features/search).

Web Search und File Search sind optional. Sie werden nur angezeigt, wenn Ihre Bereitstellung sie aktiviert, was das Einschalten der Agent-Fähigkeit `web_search` oder `file_search` und die Vergabe der passenden Berechtigung für Ihre Rolle einschließt. Fehlt eine dieser Optionen, fragen Sie Ihren Administrator oder lesen Sie [Web Search option is not visible](/docs/features/web_search#web-search-option-is-not-visible) sowie die [`fileSearch`-Einstellung der Benutzeroberfläche](/docs/configuration/librechat_yaml/object_structure/interface#filesearch).
