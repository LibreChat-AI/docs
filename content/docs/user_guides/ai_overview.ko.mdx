LibreChat을 사용하면 다양한 AI 제공업체, API 및 해당 자격 증명을 구성하고 통합할 수 있습니다. 이를 통해 필요와 요구 사항에 따라 다양한 AI 모델, 설정 및 기능을 활용할 수 있습니다.

## 주요 개념 [#key-concepts]

- **Endpoints**: 엔드포인트(endpoint)는 채팅 요청에 사용 가능한 모델과 설정을 결정하는 AI 제공자, 구성 또는 API를 의미합니다. 예로는 OpenAI, Google, Anthropic 등이 있습니다.

- **Presets**: 프리셋은 endpoint, 모델, 대화 설정이 저장된 조합입니다. 다양한 사용 사례에 맞춰 여러 프리셋을 생성하고 관리할 수 있습니다.

- **Default Endpoint**: 여러 endpoint가 구성되어 있는 경우, 새 대화를 시작할 때 사용할 기본 endpoint를 지정할 수 있습니다.

- **Default Preset**: 마찬가지로, 새 대화를 시작할 때 자동으로 사용될 기본 프리셋을 설정할 수 있습니다.

## 기능 [#functionality]

1. **AI Providers**: 필요한 자격 증명과 API 키를 제공하여 미리 구성된 다양한 AI 제공업체를 설정하세요.

2. **Manage Endpoints**: 요구 사항에 따라 다양한 endpoint를 활성화하거나 비활성화합니다.

3. **프리셋 생성 및 관리**: 특정 endpoint, 모델 및 대화 설정 조합을 프리셋으로 정의하고 저장하세요.

4. **기본 endpoint 및 프리셋 설정**: 새 대화를 시작하는 과정을 간소화하기 위해 기본 endpoint와 프리셋을 지정하세요. 다음은 이를 보여주는 영상입니다: **[기본 프리셋 설정하기](https://github.com/danny-avila/LibreChat/assets/110412045/bbde830f-18d9-4884-88e5-1bd8f7ac585d)**

5. **구성 사용자 지정**: Ollama, Mistral AI 또는 OpenRouter와 같은 사용자 지정 endpoint를 추가하는 등 고급 구성 옵션을 살펴보세요.

## 검색 [#searching]

LibreChat에는 웹, 파일, 대화 내용을 각각 검색하는 별도의 검색 기능이 있습니다.

- **웹 검색**: AI가 최신 정보를 찾아볼 수 있도록 합니다. 일반 채팅에서는 [메시지 작성기](/docs/features/composer)의 **+** 팔레트를 열고 **Web Search**를 선택하세요. 에이전트의 경우 대신 Agent Builder에서 **Web Search** 기능을 활성화하세요. 웹 검색에는 검색 제공자와 스크레이퍼가 모두 필요하며, 관리자가 구성하거나 요청 시 개인 API 키를 직접 입력하여 설정할 수 있습니다. 자세한 내용은 [Web Search](/docs/features/web_search)를 참조하세요.

- **파일 검색**: 업로드한 문서에 대해 질문하세요. 일반 채팅에서는 **+** 팔레트에서 **File Search**를 선택합니다. 에이전트의 경우 Agent Builder에서 **File Search** 기능을 활성화합니다. File Search는 관리자가 배포한 RAG API를 사용하여 의미를 기준으로 구절을 찾습니다. [RAG API (Chat with Files)](/docs/features/rag_api)를 참조하세요.

- **대화 검색**: 사이드바의 검색창을 사용하여 이전 메시지를 찾을 수 있습니다. 관리자가 Meilisearch를 활성화한 경우에만 표시됩니다. [메시지 검색](/docs/features/search)을 참조하세요.

웹 검색과 파일 검색은 선택 기능입니다. 배포 환경에서 이를 활성화한 경우에만 표시되며, 여기에는 `web_search` 또는 `file_search` 에이전트 기능을 켜고 사용자 역할에 해당 권한을 부여하는 작업이 포함됩니다. 둘 중 하나가 보이지 않는다면 관리자에게 문의하거나, [Web Search option is not visible](/docs/features/web_search#web-search-option-is-not-visible) 및 [`fileSearch` interface 설정](/docs/configuration/librechat_yaml/object_structure/interface#filesearch)을 참고하세요.
