ほとんどのシナリオにおいて、Docker Composeはシンプルさ、使いやすさ、信頼性の観点から推奨されるインストール方法です。npmを使用したい場合は、以下の手順に従ってください。

## 前提条件 [#prerequisites]

- Node.js `v24.22.1`: [https://nodejs.org/en/download](https://nodejs.org/en/download)
- npm `v11.16.0`
  - LibreChatはCommonJS (CJS) とopenid-client v6を使用しています。Node 24は、必要なCJS/ESMの相互運用性、WebCrypto、およびFetch APIのランタイムサポートを満たしています。
- Git: https://git-scm.com/download/
- MongoDB (Atlas または Community Server)
  - [MongoDB Atlas](/docs/configuration/mongodb/mongodb_atlas)
  - [MongoDB Community Server](/docs/configuration/mongodb/mongodb_community)
- LibreChatを実行するには、少なくとも1 GiBのRAMと1 vCPUが必要です。さらにサービスを追加する場合やモデルをローカルで実行する場合に見込むべき要件については、[システム要件](/docs/local/docker#system-requirements)を参照してください。
  - ソースからフロントエンドをビルドする（`npm run frontend`、これは `npm run reinstall` でも実行されます）には、実行時よりもはるかに多くのメモリが必要です。クライアントのビルドでは、Node.js のヒープを最大 8 GB まで使用できます。メモリの少ないマシンでは、代わりに事前ビルド済みの [Docker](/docs/local/docker) イメージを使用してください。

`nvm` を使用している場合は、推奨される Node.js バージョンをインストールして選択し、その後 npm を更新してください：

```bash filename="Use Node.js 24 and npm 11"
nvm install 24.22.1
nvm use 24.22.1
npm install -g npm@11.16.0
node -v
npm -v
```

LibreChatの依存関係をインストールする前に、Node.jsが`v24.22.1`、npmが`11.16.0`であることを確認してください。

## インストール手順 [#installation-steps]

### 準備 [#preparation]

ターミナルで以下のコマンドを実行してください：

```bash filename="Clone the Repository"
git clone https://github.com/LibreChat-AI/LibreChat.git
```

```bash filename="Navigate to the LibreChat Directory"
cd LibreChat
```

```bash filename="Create a .env File from .env.example"
cp .env.example .env
```

> **注:** **Windows 10を使用している場合、`cp`の代わりに`copy`を使用する必要があるかもしれません。**

<Callout title="MONGO_URI を更新する" emoji="❗">
  新しく作成した `.env` ファイルを編集し、`MONGO_URI` を、ご自身の MongoDB インスタンスの接続文字列に設定してください。
</Callout>

### ビルドと起動 [#build-and-start]

準備手順が完了したら、以下のコマンドを実行してください：

```bash filename="Install dependencies"
npm run reinstall
```

`npm run reinstall` は、依存関係のクリーンインストールを実行し、LibreChatをビルドします。Node.jsやnpmのバージョンを変更した後に使用することで、ネイティブパッケージがアクティブなランタイムに合わせて再ビルドされます。

```bash filename="Start LibreChat!"
npm run backend
```

<Callout type="success" title="LibreChat にアクセス！" emoji="🎉">
  **[http://localhost:3080/](http://localhost:3080/) にアクセスしてください**
</Callout>

アカウントを登録し、[Your First Chat](/docs/quick_start/first_chat) に従ってモデルのAPIキーを追加し、最初のメッセージを送信してください。

<Callout type="example" title="ヒント" emoji="🔥">
  - 次回LibreChatを起動する際は、`npm run backend`を実行するだけで済みます。
</Callout>

## LibreChat の更新 [#update-librechat]

LibreChatを最新バージョンに更新するには、以下のコマンドを実行してください：

<Callout type="warning" emoji="">
  まず、LibreChatを停止してください（まだ停止していない場合）。
</Callout>

```bash filename="Pull latest project changes"
git pull
```

```bash filename="Update dependencies"
npm run smart-reinstall
```

アップデート中にNode.jsまたはnpmのバージョンを変更した場合は、代わりに `npm run reinstall` を実行してください。

```bash filename="Start LibreChat!"
npm run backend
```
