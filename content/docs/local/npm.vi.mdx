Đối với hầu hết các trường hợp, Docker Compose là phương pháp cài đặt được khuyến nghị nhờ sự đơn giản, dễ sử dụng và độ tin cậy cao. Nếu bạn muốn sử dụng npm, bạn có thể làm theo các hướng dẫn sau.

## Điều kiện tiên quyết [#prerequisites]

- Node.js `v24.22.1`: [https://nodejs.org/en/download](https://nodejs.org/en/download)
- npm `v11.13.0`
  - LibreChat sử dụng CommonJS (CJS) và openid-client v6; Node 24 đáp ứng các yêu cầu về khả năng tương tác CJS/ESM, WebCrypto và hỗ trợ runtime Fetch API.
- Git: https://git-scm.com/download/
- MongoDB (Atlas hoặc Community Server)
  - [MongoDB Atlas](/docs/configuration/mongodb/mongodb_atlas)
  - [MongoDB Community Server](/docs/configuration/mongodb/mongodb_community)
- Tối thiểu 1 GiB RAM và 1 vCPU để chạy LibreChat. Xem [Yêu cầu hệ thống](/docs/local/docker#system-requirements) để biết những gì cần chuẩn bị khi bạn thêm các dịch vụ khác hoặc chạy mô hình cục bộ.
  - Việc build frontend từ mã nguồn (`npm run frontend`, lệnh mà `npm run reinstall` cũng chạy) cần nhiều bộ nhớ hơn đáng kể so với khi chỉ chạy ứng dụng: quá trình build client cho phép Node.js sử dụng heap tối đa 8 GB. Trên máy có bộ nhớ thấp, hãy sử dụng các image [Docker](/docs/local/docker) đã được build sẵn thay thế.

Nếu bạn sử dụng `nvm`, hãy cài đặt và chọn phiên bản Node.js được khuyến nghị, sau đó cập nhật npm:

```bash filename="Use Node.js 24 and npm 11"
nvm install 24.22.1
nvm use 24.22.1
npm install -g npm@11.13.0
node -v
npm -v
```

Bạn sẽ thấy `v24.22.1` cho Node.js và `11.13.0` cho npm trước khi cài đặt các phụ thuộc của LibreChat. Tệp `.nvmrc` trong kho lưu trữ LibreChat là nguồn chuẩn cho phiên bản Node.js, vì vậy chạy `nvm use` từ thư mục gốc của kho lưu trữ sẽ chọn đúng phiên bản.

## Các bước cài đặt [#installation-steps]

### Chuẩn bị [#preparation]

Chạy các lệnh sau trong terminal của bạn:

```bash filename="Clone the Repository"
git clone https://github.com/LibreChat-AI/LibreChat.git
```

```bash filename="Navigate to the LibreChat Directory"
cd LibreChat
```

```bash filename="Create a .env File from .env.example"
cp .env.example .env
```

> **Lưu ý:** **Nếu bạn đang sử dụng Windows 10, bạn có thể cần sử dụng `copy` thay vì `cp`.**

<Callout title="Cập nhật MONGO_URI" emoji="❗">
  Chỉnh sửa tệp `.env` vừa tạo và đặt `MONGO_URI` thành chuỗi kết nối của phiên bản MongoDB của bạn.
</Callout>

### Xây dựng và Khởi chạy [#build-and-start]

Sau khi bạn đã hoàn tất các bước chuẩn bị, hãy chạy các lệnh sau:

```bash filename="Install dependencies"
npm run reinstall
```

`npm run reinstall` thực hiện cài đặt lại các phụ thuộc một cách sạch sẽ và build LibreChat. Hãy sử dụng lệnh này sau khi thay đổi phiên bản Node.js hoặc npm để các gói native được build lại tương thích với runtime đang hoạt động.

```bash filename="Start LibreChat!"
npm run backend
```

<Callout type="success" title="Truy cập LibreChat!" emoji="🎉">
  **Truy cập [http://localhost:3080/](http://localhost:3080/)**
</Callout>

Đăng ký tài khoản, sau đó làm theo [Your First Chat](/docs/quick_start/first_chat) để thêm khóa API model và gửi tin nhắn đầu tiên của bạn.

<Callout type="example" title="Mẹo" emoji="🔥">
  - Lần tới khi bạn muốn khởi động LibreChat, bạn chỉ cần thực thi `npm run backend`
</Callout>

## Cập nhật LibreChat [#update-librechat]

Để cập nhật LibreChat lên phiên bản mới nhất, hãy chạy các lệnh sau:

<Callout type="warning" emoji="">
  Trước tiên, hãy dừng LibreChat (nếu bạn chưa thực hiện việc này).
</Callout>

```bash filename="Pull latest project changes"
git pull
```

```bash filename="Update dependencies"
npm run smart-reinstall
```

Nếu bạn đã thay đổi phiên bản Node.js hoặc npm trong quá trình cập nhật, hãy chạy `npm run reinstall` thay thế.

```bash filename="Start LibreChat!"
npm run backend
```

- Tích hợp Meilisearch
- Kết nối RAG API
- Các endpoint tùy chỉnh
- Các tùy chọn cấu hình nâng cao khác
- Và nhiều hơn nữa

Điều này sẽ cho phép bạn tùy chỉnh trải nghiệm LibreChat của mình với các tính năng tùy chọn.
