## What's Changed

This release follows [v0.8.9-rc1](/changelog/v0.8.9-rc1). Operator configuration changes in the release candidate are described in [Config v1.3.18](/changelog/config_v1.3.18).

### 🏞️ Highlights

- Chat Projects with shared instructions and reference files
- Passkeys, email changes, and stronger account protection
- MCP Apps, approval choices, and attached-machine workflows
- Inline Ask User questions with more reliable pause and resume
- Langfuse prompts in the catalog and linked to Agent instructions
- Redesigned chat controls, notifications, and right-to-left layouts
- Hindi, Marathi, and Tamil translations
- Faster chat rendering and stronger request, auth, and tool safeguards
