## What's Changed

Operator-facing YAML, environment, default, and migration changes are collected in [Config v1.3.16](/changelog/config_v1.3.16).

### 🏞️ Highlights

- Interrupt, steer, or queue Agent runs, with HITL approvals, questions, and tool-limit recovery
- Scheduled Chats with cron, time zones, MCP readiness checks, and Project destinations
- New models: GPT-5.6 and GPT-6 Astra; Claude Fable 5.1, Opus 5, and Sonnet 5; Gemini 3.8, 3.7, 3.6 Flash, and 3.5 Flash-Lite
- Live activity, phase, reasoning, and tool-intent labels
- Unified Agent Builder with Skill authoring, background tools, and Programmatic Tool Calling
- Beta durable Agent Events and saved Agent teams with background wakeups and automatic continuation
- Beta Agent Plugins and highly experimental selectable Code workspaces with saved defaults and guarded permissions
- Beta Agent Management API for Agent and Skill automation with M2M OIDC
- Context Usage for dialogue, tool traffic, cache, instructions, cost, and runway pressure
- Unified draggable Pinned section, manual compaction, mobile polish, and rich-text copy
- Unified attachments with automatic model routing and lazy File Search or Code provisioning
- Stronger MCP, OpenID, shared-link, tenant, file, Redis, and DocumentDB safeguards
- Conversation Trace Viewer, run-scoped Subagent file sharing, and chat-list filtering
