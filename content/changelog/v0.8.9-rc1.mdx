## What's Changed

### 🏞️ Highlights

- Chat Projects with shared instructions and reference files
- Passkey sign-in, email changes, and stronger two-factor account protection
- Redesigned chat controls, reply notifications, and right-to-left layouts
- Deployment themes with configurable colors and appearance
- MCP Apps and more deliberate tool-approval choices
- Attached-machine enrollment, per-chat workspace choices, attachment copies, and pull request status
- Langfuse prompts in the catalog and slash command
- Recoverable subagent transcripts and clearer background-task progress
- Node.js 24.22.1 security updates and bounded history/tool previews

### Upgrade Notes

This candidate uses config `1.3.18`. Read the [upgrade guide](/docs/configuration/upgrade) and [config changelog](/changelog/config_v1.3.18) before a rolling deployment. Stateful Code sessions remain highly experimental and require compatible Code API and worker builds.

Release source: [`8d3da9bbb220`](https://github.com/LibreChat-AI/LibreChat/commit/8d3da9bbb220a0a96be9330a2e1cbd385fb786d5).
