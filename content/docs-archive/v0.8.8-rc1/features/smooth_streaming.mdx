---
title: Smooth Streaming
icon: Waves
description: Fade newly streamed assistant text into the conversation as it arrives.
---

Smooth Streaming makes live responses easier to follow by fading in newly streamed words. It applies to the latest assistant message while a response is generating, including expanded reasoning text.

The setting is enabled by default. To change it, open **Settings → Chat → Messages** and toggle **Smooth streaming text (fade in new words)**.

Smooth Streaming is visual only. It does not delay token delivery, change response content, or alter saved messages. Previously loaded text is treated as existing content when a stream reconnects or a conversation changes, so it does not replay the animation. Structured regions such as code, math, artifacts, citations, and MCP UI content are not animated.

LibreChat automatically disables the animation when the device reports the `prefers-reduced-motion` accessibility preference, regardless of the saved toggle.
