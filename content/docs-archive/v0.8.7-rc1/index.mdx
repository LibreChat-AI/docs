<Callout type="info" title="Looking for a desktop installer?">

LibreChat is a self-hosted web application, not a native Windows app or Linux AppImage. On Windows, use [Docker Desktop](/v0.8.7-rc1/docs/local/docker) for the simplest local setup. For Linux desktops or servers, use [Docker](/v0.8.7-rc1/docs/local/docker), [npm](/v0.8.7-rc1/docs/local/npm), or a [remote hosting guide](/v0.8.7-rc1/docs/remote).

</Callout>
